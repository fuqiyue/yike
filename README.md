# 一刻 · 任务、处境与周易学习

一个以本地记录为主的 Windows 桌面应用。用四象限整理任务，用个人条件与笔记档案补充背景，再把分析产生的方向保留为可验证的机会。

## 功能

- **任务**：紧急与重要四象限，开始、暂停、完成，角色与备注。
- **个人情况**：个人条件、笔记档案、周期信息三个直接入口。支持自定义角色，周期信息支持开始日期、每周/月/季度/年、金额与增改删。
- **分析与机会**：分析单个任务、全部任务、未来方向、角色、档案或机会；保存分析结果，手动整理候选方向与下一步。
- **AI 写入**：把用户提供的情况整理为个人条件。支持指定角色或自动匹配已有角色。
- **学习与查阅**：三画八卦入门、六十四卦课程、手算练习、自测及知识卡阅读。
- **纸墨主题**：宋体标题、纸色背景与朱砂操作，按需展开较长信息。

## 启动与构建

开发需要 Node.js 22+ 和 npm。桌面打包目标为 Windows x64，正式构建建议在 Windows 上执行。

```powershell
npm ci
npm test
npm run desktop
```

构建安装包和免安装版：

```powershell
npm run dist
npm run test:packaged
```

产物位于 `dist/交付/<版本>/`。安装版与免安装版共用用户数据，运行 EXE 无需另装 Node.js。构建依赖 Electron 和 electron-builder，首次安装依赖及构建需联网下载。项目未配置自动更新，也未配置代码签名证书。

只使用网页界面：

```powershell
node 网页/server.mjs
```

打开 http://127.0.0.1:3210 。网页与桌面的数据目录独立；网页学习进度保存在浏览器中。模型配置与加密密钥由桌面版提供。

## 数据与隐私

- 这是经过白名单导出的**程序源码仓库**，使用独立提交历史，不包含开发者的个人任务、条件、档案、机会、分析结果、导入文件或原私用仓库历史。
- 桌面数据默认保存在 `%APPDATA%\Yike\data`；API Key 通过 Electron safeStorage 加密保存在用户配置目录。应用不预置模型账号或密钥。
- 使用 AI 时，在设置中填写兼容 Chat Completions 的服务地址、模型名与 API Key。只有显式发送后，预览中的材料才会发送到所配置的服务。
- 备份与导入在设置中操作。更新或卸载不会主动清除个人数据；回退到较老的数据格式前应保留完整备份。
- 测试使用临时目录或独立测试 profile 与合成数据。请勿把真实 profile、日志、截图、备份或 `.env` 提交到公开仓库。
- 知识卡区分经文、结构、义理与推测；分析是需要核对依据的辅助建议，机会是候选方向，不能当作已证实事实。

## 目录

| `桌面/` | Electron、安全存储、打包及隔离验收 |

`PUBLIC_SOURCE_MANIFEST.json` 记录本次导出的文件和 SHA-256。后续修改文件后应重新生成清单。公开可见不等于自动授予开源许可；本仓库暂未声明开源许可证。

知识卡保留原有来源标注，经文与现代讲解、项目整理应分别看待。公开此仓库不表示对第三方讲解内容享有独占著作权。
