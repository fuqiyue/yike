# 知识卡 01 · 乾卦（天）

> 定位法知识库 · 第一张卡
> 数据来源：《周易》经文、彖传、象传、文言传、系辞传；义理解读依据讲解材料《天规地道：正职与副手的进退荣枯》
> 用途：供"定域 → 定位 → 定势"三步诊断调用。字段口径为全库统一模板，后续各卦照此填写。
>
> ⚠️ **「历史镜鉴」字段的性质**：该字段是**类比，不是史证**。其中的人物与事件只用来说明爻位的结构处境，**具体史实细节未经本库独立核对**。**读它取结构，不要取史论**；凡与史学结论冲突，以史学为准。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 乾 · 第一卦 |
| **卦象** | 上乾下乾，六爻皆阳（☰☰），纯阳 |
| **五行 / 方位** | 金 · 西北 |
| **领域定义（这一卦管什么）** | **主导者之路**。一个人作为"说了能算"的核心——创始人、一把手、家里顶梁柱、某个领域的领跑者——从无名到成就再到衰落的完整生命周期。凡是"我想成为某件事的主心骨"，都落在乾卦。 |
| **不归本卦的情况** | 作为辅佐者、执行层、副手的问题 → 坤卦；事情刚起步、根基不稳的问题 → 屯卦。同一个人在不同关系里可能分属不同卦，先问"哪一段关系、哪一件事"。 |
| **卦辞原文** | 元，亨，利，贞。 |
| **卦辞现代解** | 四德即成事的四个指标：**元**——敢于启动，去做去拼才有后续（善之长）；**亨**——懂规律、顺人性，让人才和资源向你汇聚（嘉之会）；**利**——做大蛋糕、分享增量，让相关各方各得其宜，不搞零和（义之和）；**贞**——公平公正、守住底线、有公信力（事之干）。 |
| **卦象逻辑** | 纯阳如金，金须高温锻打去除杂质方成神兵——乾卦的刚健不是天生的锋利，而是被锤炼出来的担当：遇事不退、扛得住、越练越精神。 |
| **大象传（行动纲领）** | 天行健，君子以自强不息。 |
| **总铁律** | ① 想成龙就绕不开六爻，每一爻都有它的位置属性，越位必凶；② 龙的一生是"潜—现—惕—跃—飞—亢"的抛物线，只能延缓不能改变，智慧的意义是把大灾化小灾；③ 最高境界不是飞龙在天，而是"群龙无首"——不独尊、不为首、让每个位置的人各尽其能。 |
| **爻位通则** | 初、三、五为阳位，二、四、上为阴位；阳爻居阳位为"当位"。二、五居上下卦之中为"得中"。系辞："二多誉，三多凶，四多惧，五多功。"六爻对应事物完整周期：初＝发端，二＝展露，三＝小成忧惧，四＝进阶审慎，五＝鼎盛尊贵，上＝物极必反。 |

## 二、爻级字段

### 初九 · 潜龙

| 字段 | 内容 |
|---|---|
| **爻辞原文** | 潜龙，勿用。 |
| **象传** | 潜龙勿用，阳在下也。 |
| **位属性** | 阳爻居阳位，**当位**；不得中。风险属性：低——只要"潜"下去就能平安，是六爻中最安全的一爻。 |
| **判词 → 行动语义** | 勿用 → **守**。不是什么都不干，核心在"潜"不在"勿"：做好充分准备、蓄势待发。 |
| **识别信号** | ① 没有人知道你，或知道你的人不多；② 手里没有不可替代的本事，或有本事但外部环境不允许你出头；③ 处于学习期、新入职期、行业新人期；④ 有雄心，但资源、人脉、话语权几乎为零。 |
| **该做** | 藏锋、低调、闭嘴，像海绵一样吸收资源和技艺；一天不浪费地攒力量；精心钻研自己不可替代的核心竞争力；为下一阶段储备突破的资本。 |
| **不该做** | 没准备好就冒冒失失地表现；让"大块头"注意到弱小的你；急于自己立一摊。 |
| **常见误判** | 高估型：以为自己已是"见龙"，过早冒头，被剽窃或被打压后一无所有。低估型：真有本事了仍然潜着不动，把潜龙过成了一辈子。 |
| **下一阶段 · 条件 · 代价** | → 九二见龙。条件：核心竞争力开始出成绩、"藏不住了"。代价：从九二开始风险陡增，出场即成靶子。 |
| **历史镜鉴** | 赵匡胤无名军官时期；任何在乱世中"闷声发育"的开国者早年。 |
| **现代类比** | 刚入社会的头几年；创业项目的隐身研发期。 |

### 九二 · 见龙

| 字段 | 内容 |
|---|---|
| **爻辞原文** | 见龙在田，利见大人。 |
| **象传** | 见龙在田，德施普也。 |
| **位属性** | 阳爻居阴位，**不当位**；**得中**（下卦中位）。风险属性：中——不当位所以名不正言不顺、危险比初九骤增；但得中，所以即便被打下去也有重来的机会（"二多誉"）。 |
| **判词 → 行动语义** | 利见大人 → **进，但必须借力**。这一爻不存在"原地爆炸升空"，一定要有大人提你。 |
| **识别信号** | ① 所有人都看到你了，出了成绩、有了名声；② 开始有人想拉拢你，也开始有人想复制你、打压你；③ 还没有能保你、提你的人，或正在找；④ 你能做事，但话语权和位置不匹配。 |
| **该做** | 两手同时抓：**得施普也**——分享利益、团结众人，让别人觉得你代表大家的共同利益，形成自己的基本面；**利见大人**——抬头看天，寻找并争取上位者的赏识和庇护。做到"忠心、安全、能干、不捅娄子"，这是大人评估你的四条标准。 |
| **不该做** | 一亮相就踩了所有人、显得独占好处；指望巨头讲良心（巨头对新星的第一反应是"剽窃成果或拉拢你哪个成本低"）；无大人之助而硬闯。 |
| **常见误判** | 以为出了名就等于站稳了。实际上见龙比潜龙凶得多，"走过潜龙关的现龙又有一大半倒在了这一关"。 |
| **下一阶段 · 条件 · 代价** | → 九三惕龙。条件：得到大人之助，进入中层。摔下去的代价：回到潜龙重来，尚可挽回。 |
| **历史镜鉴** | 刘邦起步靠项家、曹操靠袁绍和汉室招牌——所有弱势者的上位都是抱着优势者的腿上来的。 |
| **现代类比** | 崭露头角的骨干；拿到早期融资前的创业公司。 |

### 九三 · 惕龙

| 字段 | 内容 |
|---|---|
| **爻辞原文** | 君子终日乾乾，夕惕若，厉，无咎。 |
| **象传** | 终日乾乾，反复道也。 |
| **位属性** | 阳爻居阳位，**当位**；不得中，居下卦之顶（"三多凶"）。风险属性：中高但可控——只要日夜警惕就不会翻车，且这一爻**可以长期停留**。 |
| **判词 → 行动语义** | 厉，无咎 → **守中带惕**。"无咎"不是吉利，是"善补过"——善于修补漏洞才没有灾祸。 |
| **识别信号** | ① 已到中层，有名有利，活在多数人的羡慕里；② 在聚光灯下，任何小漏洞都会被放大；③ 下有人盼你塌房、平有人找你弱点、上有人审视你的忠诚和能力；④ 失去了自由和"凡人的快乐"。 |
| **该做** | 时时刻刻修补漏洞，如履薄冰；接受"有得必有失"，别觉得自己吃了亏；**做一次综合盘点**——细数能力、资源、人脉、威望，判断自己是否真有"跃"的本钱。 |
| **不该做** | 在名利上头时肆意妄为；不做盘点就往九四冲。 |
| **常见误判** | 把"九三就挺好"当成不够上进。事实上"绝大多数牛人一辈子最佳状态就是九三"，这一爻只要不作死就是一辈子的荣华富贵。 |
| **下一阶段 · 条件 · 代价** | → 九四跃龙。这是全卦最关键的一次抉择：一旦踏入九四就再无回头路，摔下去不是回到九三，而是坠入深渊。**在九三平稳着陆是完全合理的选项。** |
| **历史镜鉴** | 赵弘殷（赵匡胤之父）：五代乱世的中上层军官，不作死便一生富贵；刘邦的丰沛老兄弟多数善终，因为他们停在了九三。 |
| **现代类比** | 大公司的中高层、成熟行业的头部从业者；已经稳定盈利、不再需要拼命扩张的中型企业老板。 |

### 九四 · 跃龙

| 字段 | 内容 |
|---|---|
| **爻辞原文** | 或跃在渊，无咎。 |
| **象传** | 或跃在渊，进无咎也。 |
| **位属性** | 阳爻居阴位，**不当位**；不得中（"四多惧"）。风险属性：**全卦最凶**——前是九五之尊，后是万丈深渊，没有中间态。 |
| **判词 → 行动语义** | 无咎（有条件） → **进，且只能进**。象传补的那个"进"字是精髓：到了这里已不是"惕不惕"的问题，只有越过去才无咎。 |
| **识别信号** | ① 你所在的位置只剩最高位在前面，没有平级可去；② 你已经具备"人主"的实力，让在位者感到威胁；③ 低调和小心已经不再能保命；④ 名额极少，竞争者与你不死不休。 |
| **该做** | 用毕生所学和毕生资源，一往无前地越过去；跃之前就要想清楚"必得天下"的决心和布局。 |
| **不该做** | 以为"低调就行""不争就行"（韩信之误：以为退让、交出兵权就能保命，**错在他根本不该走到九四**）；抱着九三的心态待在九四的位置。<br>⚠️ **本行原有一句引语作"世卫之地者死"，文字已残、无法核出出处，本轮改为义理表述。** |
| **常见误判** | **最危险的误判就在这一爻**：很多人以为自己还是九三，其实已经站到了九四——位置一到，人主就不会放过你，不管你想不想争。 |
| **下一阶段 · 条件 · 代价** | → 九五飞龙（极少数）。跃不过去 → 坠渊，与九五"天渊之别"，几乎没有善终。所以此爻的真正决策点在九三：**要不要来**。 |
| **历史镜鉴** | 五代的侍卫亲军马步军都指挥使、殿前都点检：越过去的石敬瑭、刘知远、赵匡胤做了皇帝，没越过去的康义诚、杨光远、史弘肇几乎全无善终；刘邦不容韩信彭越英布，曹操不容刘备。 |
| **现代类比** | 集团二号人物 vs 一号人物；行业里被龙头视为唯一威胁的挑战者。 |

### 九五 · 飞龙

| 字段 | 内容 |
|---|---|
| **爻辞原文** | 飞龙在天，利见大人。 |
| **象传** | 飞龙在天，大人造也。 |
| **位属性** | 阳爻居阳位，**当位**；**得中**（上卦中位）。乾卦最佳的一爻，既得中又得位（"五多功"）。 |
| **判词 → 行动语义** | 利见大人 → **成，并持续引入新鲜血液**。此处"利见大人"的味道变了：不再是求人提携，而是自己成为大人的同时，大量发掘人才共襄盛举。 |
| **识别信号** | ① 能力、智慧、人望、地位均入大成，挥洒自如；② 你已是别人眼中的"大人"和榜样；③ 你的下面永远有跃跃欲试的跃龙。 |
| **该做** | 不断吸纳新人、补充燃料（汉三杰、云台二十八将、贞观群臣）；保持与下层的"血肉联系"——你飞得高是因为下面有源源不断的力量托举。 |
| **不该做** | 自满、独占、自毁长城；消灭所有大人、断绝新鲜血液；忘乎所以。 |
| **常见误判** | 以为到顶就安全了。飞龙忘乎所以，同样会被贬下凡尘。 |
| **下一阶段 · 条件 · 代价** | 若守"利见大人"可长期延缓 → 停在九五；若把事做绝、力用尽 → 上九亢龙，不可避免。 |
| **历史镜鉴** | 李世民：外战多用归附力量为主力，在东亚范围内"利见大人"让别人为自己燃烧，故为飞龙之最。 |
| **现代类比** | 行业龙头、组织的一把手在鼎盛期。 |

### 上九 · 亢龙

| 字段 | 内容 |
|---|---|
| **爻辞原文** | 亢龙，有悔。 |
| **象传** | 亢龙有悔，盈不可久也。 |
| **位属性** | 阳爻居阴位，**不当位**；不得中；居全卦之极，该止之地却不知止。风险属性：高，且是**结构性**的——盛极必衰，只能延缓。 |
| **判词 → 行动语义** | 有悔 → **退 / 止 / 舍**。 |
| **识别信号** | ① 知进不知退、知存不知亡、知得不知丧；② 把势能用尽、把功劳揽尽、把对手做绝；③ 外部不再有新鲜血液涌入；④ 感觉"自己是世界的核心、无所不能"——这是要倒霉的前兆。 |
| **该做** | 常思盈亏之理、常怀舍得之心、常克奢靡之欲、常秉谦卑之行；适可而止，主动自我革命、自我进化；用自谦免灾祸、用自亏免祸、用自舍免祸。 |
| **不该做** | 凡事太尽；为证明自己而继续攒功；对每个对手都做绝。 |
| **常见误判** | 以为"再拼一把就能永远飞在九天之上"。有兴就有衰，你只能让秋老虎长一点，秋天依旧会来。 |
| **下一阶段 · 条件 · 代价** | 若能退 → 平稳着陆，家业或组织得以延续；若不退 → 势尽而坠，且往往连带后人。 |
| **历史镜鉴** | 刘裕：一代用尽江南全部势能，对每个对手极端处置，死后南朝再无做大蛋糕的人。 |
| **现代类比** | 到达顶峰后仍不断加杠杆、清洗合作伙伴、不培养接班人的企业家。 |

### 用九 · 群龙无首（乾卦总纲，非独立阶段）

| 字段 | 内容 |
|---|---|
| **爻辞原文** | 见群龙无首，吉。 |
| **象传** | 用九，天德不可为首也。 |
| **性质** | 对乾卦六爻的升华与补全：破解上九的穷尽之灾，说明**如何正确运用阳刚之道而不是滥用阳刚之力**。 |
| **判词 → 行动语义** | 吉 → **不居首、不独尊、不垄断话语权**。 |
| **核心解读** | "无首"不是没有首领，而是不把自己放在唯一至高的主宰位置。天道四季各行其道，无所谓谁为首。潜龙、见龙、惕龙、跃龙、飞龙、亢龙各在其位、各尽其能、互不争强，才是天道层面的长久之吉。 |
| **对一把手的具体要求** | 不搞一言堂、不大权独揽；搭平台、带团队，让每个干部独当一面；飞龙不干涉惕龙的具体事务，惕龙不让潜龙去承担见龙的责任；律己而非凌人；心中有敬畏。 |
| **诊断用法** | 作为九五和上九的"校验项"：一个人在高位时是否具备"无首"之心，是判断他会停在九五还是滑向上九的关键指标。 |

## 三、乾卦定位速查表

| 爻 | 阶段名 | 一句话识别 | 位属性 | 行动语义 | 可否长留 |
|---|---|---|---|---|---|
| 初九 | 潜龙 | 没人知道你，也没资源 | 当位·不得中 | 守·蓄力 | 可 |
| 九二 | 见龙 | 人人看到你，但没人保你 | 不当位·得中 | 进·借力 | 不宜久 |
| 九三 | 惕龙 | 已到中层，聚光灯下 | 当位·不得中 | 守·日惕 | **可，且推荐** |
| 九四 | 跃龙 | 前面只剩最高位，退无可退 | 不当位·不得中 | 只能进 | **不可** |
| 九五 | 飞龙 | 位居顶端，众望所归 | 当位·得中 | 成·纳新 | 可（条件：利见大人） |
| 上九 | 亢龙 | 把一切用尽，感觉无所不能 | 不当位·不得中 | 退·舍 | 不可 |
| 用九 | 群龙无首 | （总纲）不为首、不独尊 | — | 校验项 | — |

**全卦最重要的一条铁律：真正的抉择点在九三，不在九四。** 九四的凶不是能不能跃的问题，而是"该不该来"的问题。

| 离 ☲ | 火 | 中女 | 火 | 南 | 明 / 丽 | 不用担责，奔放自由 |

- 记法：父全阳、母全阴；三子卦随母（两阴一阳，阳爻做主），三女卦随父（两阳一阴，阴爻做主）。**少者为尊**——单独那一爻决定卦性。
- 定域时的用法：用户的**内在状态**对应下卦，**外部环境**对应上卦，两者组合即处境卦。例：内心想动（震）而外有风险（坎）→ 水雷屯。
