# 知识卡 02 · 坤卦（地）

> 与知识卡 01 乾卦互为一组：乾＝主导者之路，坤＝辅佐者之路。同一个人对上是坤、对下是乾，诊断时必须先问"你问的是哪一段关系"。
>
> ⚠️ **「历史镜鉴」字段的性质**：该字段是**类比，不是史证**。其中的人物与事件只用来说明爻位的结构处境，**具体史实细节未经本库独立核对**。**读它取结构，不要取史论**；凡与史学结论冲突，以史学为准。

---

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 坤 · 第二卦 |
| **卦象** | 上坤下坤，六爻皆阴（☷☷），纯阴 |
| **五行 / 方位** | 土 · 西南 |
| **领域定义** | **辅佐者之路**。臣、副手、执行层、下属、大后方——**这才是绝大多数人真正的主战场**。凡是"我在某个体系里辅佐别人、执行别人的战略"，都落在坤卦。 |
| **不归本卦的情况** | 你自己就是那件事的主心骨 → 乾卦。注意：诸葛亮对刘禅是坤六五，统大军北伐时是乾九三——**角色随关系切换**。 |
| **卦辞原文** | 元亨，利牝马之贞。君子有攸往，先迷后得主，利。西南得朋，东北丧朋，安贞吉。 |
| **卦辞现代解** | **牝马之贞**——母马是"地上的龙"，行健不息却顺从驾驭；坤道之贞不是柔弱，是"顺承天道而不违逆"的柔顺之德。**君子有攸往**——坤卦也必须行动、必须干实事，不是躺着。**先迷后得主**——抢戏、越位、抢了主导者的事，必然迷失方向；居后顺承、找准自己的辅佐对象和定位，才能得长远之利。**西南得朋，东北丧朋**——彖传补"乃与类行 / 乃终有庆"：和同类扎堆看似顺，实则陷入纯阴无阳的局限；坤卦的终极使命是去找异类、阴阳合合。**安贞吉**——全卦总开关：认清定位、安于本分、坚守正道。 |
| **卦象逻辑** | 土最厚德载物，金木水火任其折腾，土只是承受。四川处坤位（西南），是绝佳大后方却天生不具开拓之气。刘备在汉中打仗、诸葛亮在成都筹兵筹粮，就是标准的乾坤分工。 |
| **大象传（行动纲领）** | 地势坤，君子以厚德载物。 |
| **总铁律** | ① 坤道的核心是**顺承、承载、有原则**，既不是唯命是从的奴才，也不是顶撞犯上的颠覆者；② 越是不居功、不越位、不抢名，越能获得信任并被托举上去——**不居功反而成了功，不抢权反而得了权**；③ 前五爻每一步都有回头余地，只有上六把所有退路自己堵死。 |
| **口诀** | 乾＝自强不息；坤＝厚德载物。 |
| **底线条款** | 顺承有一票否决项：领导脾气差、有小毛病，那是"大"字要包容的范围；但若触犯伤天害理、不给你应得的回报、或本身是卖国贼，则"缘分到此为止"——初六"履霜坚冰至"就是提醒你，那是一艘要沉的船。 |

## 二、爻级字段

### 初六 · 履霜

| 字段 | 内容 |
|---|---|
| **爻辞** | 履霜，坚冰至。 |
| **象传** | 履霜坚冰，阴始凝也。驯致其道，至坚冰也。 |
| **位属性** | 阴爻居阳位，**不当位**；不得中。风险属性：低，但这是**趋势预警爻**——阴的力量在本该阳主动的开端位置萌生。 |
| **判词 → 行动语义** | 无判词 → **察 / 防**。 |
| **识别信号** | ① 你察觉到一些"小事"：领导的某个决定不对味、单位的某个风气在变、自己某个小习惯在滑坡；② 还没出事，但征兆已现；③ 你倾向于"这点小事不至于"。 |
| **该做** | 见微知著。从最细微处不断修正自己的弱点和漏洞；顺着规律一步一个脚印积累好习惯；发现根源不在你，至少提前做准备。 |
| **不该做** | 把秋霜不当回事（准确说，看到霜已经有点晚了——清晨叶上凝露时就该知道天要转凉）。 |
| **常见误判** | 以为趋势是突然发生的。实际上"祸患的爆发还是功成名就，都是长期积累的结局"。 |
| **经典镜鉴** | 见微知著——箕子见纣王用象牙筷子便知必亡（此即"象箸"之喻，出《韩非子·喻老》）：筷子换了，餐具就得换，食物就得换，接着是宫室、是淫欲、是敝民，最终失民必亡。 |
| **下一阶段** | → 六二。修正得当则进入坤德正轨；忽视则趋势自行滑向后面各爻的凶险。 |

### 六二 · 直方大

| 字段 | 内容 |
|---|---|
| **爻辞** | 直方大，不习无不利。 |
| **象传** | 六二之动，直以方也。不习无不利，地道光也。 |
| **位属性** | 阴爻居阴位，**当位**；**得中**。**坤卦的最佳状态**（得中又得位）。 |
| **判词 → 行动语义** | 无不利 → **守本心**。"无不利"在周易吉凶序列中仅次于元吉，约等于大吉，做任何事都顺遂有利。 |
| **三字纲领** | **直**＝真诚、无私无偏，高山大海花鸟鱼虫来到大地都一样承载；**方**＝有原则、有边界、有底线，大地虽包容却有恒定法则（该春生就春生，该秋收就秋收）；**大**＝格局广大、海纳百川。 |
| **"不习"的关键** | "习"是小鸟反复练习飞行，此处指刻意模仿。**不习**＝不是后天刻意模仿、造作、表演出来的，而是发自内心认可、写进内心操作系统。刻意和表演在高段位选手眼里就像小丑，一演就被看穿。 |
| **识别信号** | ① 你对上级的尊重是"本来就应该"，不需要刻意讨好、投机取巧；② 你有自己不可动摇的准则和底线；③ 你能包容领导和同事的小毛病。 |
| **该做** | 秉承本就该顺承的态度处理工作，这种气场自然会得到每位上级的认可和同仁的尊重；上级宠信的人不看僧面看佛面地给面子，上级冷落的人保持距离（人家这么做必有全局考量）。 |
| **不该做** | 功利性假装；一知半解地模仿；用表演代替真诚——到头来糊弄的是自己。 |
| **常见误判** | 把"顺承"理解成没有原则。"方"字不是白说的：触犯底线，缘分到此为止。 |
| **下一阶段 · 条件** | → 六三。位置升高、成为高级干部时，六二的"不习无不利"就不够了，必须转入"含章"。 |

### 六三 · 含章

| 字段 | 内容 |
|---|---|
| **爻辞** | 含章可贞，或从王事，无成有终。 |
| **象传** | 含章可贞，以时发也。或从王事，知光大也。 |
| **位属性** | 阴爻居阳位，**不当位**；不得中；居下卦之顶。风险属性：中高——位置高了，锋芒必露则招灾。 |
| **判词 → 行动语义** | 可贞、有终 → **敛 / 归功于上**。 |
| **关键词解** | **含章**："章"是功勋（防功之显著者），含章＝**主动、有分寸地内敛自己的锋芒与功勋**，不是被动压抑。**或**＝相时而动（同"或跃在渊"之或）。**无成**≠没干成，而是**不居功、不抢名，把成事之名归于上级**。 |
| **识别信号** | ① 已是高级干部/骨干，有才有能；② 容易被人嫉妒，或让领导觉得你是威胁、或觉得你言过其实难当大用；③ 手上有可以据为己功的成绩。 |
| **该做** | 和光同尘，搞好同志关系，最起码不树敌；时机未到就含章不发、守正避祸；时机到了顺势而为、做事成事；成了事把功劳归上。 |
| **不该做** | 自作主张、居功自傲、越位争名——不合卦象，难得善终。 |
| **常见误判** | 把"无成有终"当成懦弱妥协。象传说"知光大也"——这是智慧深远、格局广大，是懂权力的运行规律：你把老大托举上去，他位置更高，才能把你也提上去；他上位后一定希望自己原来的位置由最放心的人接手。 |
| **下一阶段 · 条件** | → 六四。做到"无成有终"才有机会留在这个爻位甚至再上一步。 |

---

### 六四 · 括囊

| 字段 | 内容 |
|---|---|
| **爻辞** | 括囊，无咎无誉。 |
| **象传** | 括囊无咎，慎不害也。 |
| **位属性** | 阴爻居阴位，**当位**；不得中；紧邻君位。风险属性：中——只要谨慎就不会被害（与乾卦九四的"不当位即死局"形成鲜明对比）。 |
| **判词 → 行动语义** | 无咎无誉 → **慎 / 闭口**。 |
| **关键词解** | **括**＝扎紧，**囊**＝口袋。括囊＝牢牢扎住口袋、闭紧嘴。**无誉**＝不引人注目，此处正是好事。 |
| **识别信号** | ① 位置已很高，紧邻决策者；② 具体工作和大功大业不再需要你亲自执行；③ 你下面已有人，别人也不容易轻易动你（动你要考虑影响）。 |
| **该做** | 慎言慎行，不议论、不表态；不做出头鸟、不抢风头、不主动争权；有了功劳荣誉继续往上给九五/六五贴金。 |
| **不该做** | 祸从口出；离君位这么近还功高欲大——参考萧何的自污、贾诩的"不结党、子女不攀高门、从不主动献策"。 |
| **常见误判** | 以为"无誉"是没被赏识、吃了亏。在这个生态位上，"无咎无誉"就是最大的深谋智慧。 |
| **与六三的对比（重要）** | 不当位的六三要"含章、或从、无成"（干实事还得功不居己，很难拿捏）；当位的六四只有一个宗旨——**谨慎**。当位与不当位的差别就是这么大。 |
| **下一阶段** | → 六五。保持清醒就能待得住。 |

### 六五 · 黄裳（诸葛亮爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 黄裳，元吉。 |
| **象传** | 黄裳元吉，文在中也。 |
| **位属性** | 阴爻居阳位，**不当位**；但**得中**且居尊位。虽无君名而行君权。 |
| **判词 → 行动语义** | **元吉** → **成，且守臣节**。元吉是周易最高级别的吉祥。吉凶排序：元吉 ＞ 无不利/大吉 ＞ 吉 ＞ 利 ＞ 无咎 ＞ 悔亡 ＞ 悔 ＞ 吝 ＞ 厉 ＞ 凶。 |
| **关键词解** | 五行中黄为土色、坤之本色，土居中央统领四方——黄代表**辅政大臣能居中持正、不偏不倚、公信无私**。上衣下裳，上对应天为君，下裳对应地为臣：**裳再尊贵也始终在衣之下**。黄+裳＝一心为国为民的辅政大臣，永远守好臣心、尽好臣道，虽有君之权而君之责始终以臣自处。 |
| **识别信号** | ① 你实际掌握了远超本职的权力和话语权；② 你有了"名副其实"的机会（甚至有人劝进）；③ 你的决定影响全局。 |
| **该做** | 立法施度、整理戎旅、赏罚必信、科教严明；有名副其实的机会仍把厚德载物进行到极致；不越界、不隐瞒；至死不渝守臣之节，不行僭越之事。 |
| **不该做** | 因得权而生僭越之心。 |
| **为何是元吉** | 前四爻都是在做**份内**的事（知微、直方大、藏锋、慎言）；到六五是**臣至君位却守臣之节，既功盖群臣却不夺君位**——这属于尽了自己责任范围之外的义，是福德溢出的中级大圆满。 |
| **历史镜鉴** | 诸葛亮：白帝托孤后每一分秒都在完美践行黄裳之德；掌权后依法治国、赏罚必信，终身为汉相，断然拒绝李严劝进王爵的提议，终身无半分僭越之心。故身后成为中国史最伟大的丞相，是百姓不求办事也要祭祀的神仙。 |
| **反面提醒** | 天道尽满、福运有数。李渊为四子取名建成、世民、玄霸、元吉，唯有"责任"之名的世民战到最后，其余满极之名皆未得善终。 |
| **下一阶段 · 代价** | 守住六五＝圆满。若不甘心再往前迈一步 → 上六，全卦最凶。 |

### 上六 · 龙战于野

| 字段 | 内容 |
|---|---|
| **爻辞** | 龙战于野，其血玄黄。 |
| **象传** | 龙战于野，其道穷也。 |
| **位属性** | 阴爻居阴位（当位），但居穷极之位，阴柔积累到极致、物极必反。**与乾卦上九并列为各自全卦唯一的纯凶之爻**。 |
| **判词 → 行动语义** | 纯凶 → **此爻不可入**。 |
| **触发条件** | 由顺变逆、由守变夺。你根上背离了自己的道，前面没路了。 |
| **爻象解** | 国都之内为国，去国百里为郊，郊外荒原为野。"战于野"意味着矛盾已无法在朝堂博弈、权力制衡的框架内调和，只能拉出去打大规模战争。乾为天其色玄，坤为地其色黄——**天与地都流了血，这场战争没有胜者，只有两败俱伤**。 |
| **为何必凶** | 回看前五爻，每一步你都有选择、有回头、有避祸的空间：初六防微、六二守本心、六三可以选择不动或不居功、六四不作死就不会死、六五守臣节即圆满。**只有到上六，你把这五条路全都自己堵死了。** |
| **核心质问（诊断时必问）** | 你如果想当九五之尊，可以自己立摊去重走一遍乾卦——你有没有本事当刘邦、刘秀、曹操、李世民？彭城之战三千对十万、官渡差一口气就死、胡陆宣武三千五对河北十万，那是天劫级别的成色测试。**打天下和篡天下完全是两个概念。** |
| **历史镜鉴** | 王莽、司马家族、杨坚、整个五代——自古篡下来的皇位都极难善终。司马懿一门三代才略不假（⚠️ 原文此处作"裁票"，疑为讹字，本轮读作"才略"），但天道终归平衡，最终收在了司马衷（晋惠帝）身上，因为那个体系之下再没有人践行坤道。 |
| **出路** | 别让野心和欲望失控。要么守住六五的圆满，要么自己立摊从乾卦初九重走一遍。 |

### 用六 · 利永贞（坤卦总纲）

| 字段 | 内容 |
|---|---|
| **爻辞** | 利永贞。 |
| **象传** | 用六永贞，以大终也。 |
| **性质** | 坤卦的终极心法，也是破解"龙战于野"的解药。全卦六爻中唯一没有意象、只下了一个永恒定义的爻。 |
| **核心解读** | **利为长远之利，非一时之得。** 坤道容易犯两种错：一是为眼前利而无原则妥协，二是为眼前利而僭越夺取——两者都是小利、都是偷鸡。真正的长远之利在于"永贞"：始终如一地坚守正道本分，始终践行直方大的做人信条，厚德载物之心不因权位变化而动摇。 |
| **一句话** | 不忘初心，方得始终。 |
| **诊断用法** | 作为六三、六四、六五、上六的共同校验项：一个辅佐者是否具备"永贞"，决定他会停在六五的圆满还是滑向上六的两败俱伤。 |

## 三、坤卦定位速查表

| 爻 | 阶段名 | 一句话识别 | 位属性 | 行动语义 | 可否长留 |
|---|---|---|---|---|---|
| 初六 | 履霜 | 察觉到不对味的小征兆 | 不当位 | 察·防微 | 过渡爻 |
| 六二 | 直方大 | 真诚、有原则、有格局，不用刻意表演 | **当位·得中** | 守本心 | **可，最佳** |
| 六三 | 含章 | 已是高级骨干，锋芒和功勋容易招灾 | 不当位 | 敛·功归上 | 可（需含章） |
| 六四 | 括囊 | 紧邻决策者，具体活不用自己干了 | 当位 | 慎·闭口 | 可（需谨慎） |
| 六五 | 黄裳 | 有君之权，有僭越的机会 | 不当位·得中 | 成·守臣节 | **可，元吉** |
| 上六 | 龙战于野 | 由顺变逆、要夺了 | 穷极 | **不可入** | 不可 |
| 用六 | 利永贞 | （总纲）不忘初心 | — | 校验项 | — |

**乾坤对照的一条关键差异**：乾卦的抉择点在九三（要不要去九四）；坤卦的抉择点在六五（要不要越过去）。乾九四"不进则死"，坤上六"进则两败俱伤"——**乾必须跃，坤必须止**。
