# 知识卡 06 · 讼卦（天水讼）

> 序卦传："需者，饮食之道也，饮食必有讼，故受之以讼。"
> **本卦最重要的结构性事实：上乾下坎，初六、九二、六三、九四、上九——除九五之外全部不当位。这说明"讼"这件事从根上就是凶的，是我们每个人都应该极力避开的。**（对比上一卦需卦：除九二外全部当位。）
>
> ⚠️ **「历史镜鉴」字段的性质**：该字段是**类比，不是史证**。其中的人物与事件只用来说明爻位的结构处境，**具体史实细节未经本库独立核对**。**读它取结构，不要取史论**；凡与史学结论冲突，以史学为准。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 讼 · 第六卦 |
| **卦象** | 上乾（天）下坎（水），称"天水讼"。**天往西走，水往东流——这一卦天生背道而驰** |
| **领域定义** | **矛盾、纠纷、争讼的处理**。打官司、劳动仲裁、商业纠纷、债务纠纷、邻里冲突、与平台/大公司对抗、亲属析产。凡是"我和别人起了冲突、要不要争到底"，都落在讼卦。 |
| **卦辞原文** | 有孚窒惕，中吉终凶，利见大人，不利涉大川。 |
| **卦辞现代解** | **有孚**＝中信、守信、你确实有理；**窒**＝窒塞、阻塞；**惕**＝警惕、审慎。<br>**有孚窒惕**——**即便你此时诚心有理、光明正大、有凭有据，即便你就是正当权益被损害了、你占着天大的理、遇到的对方是个恶意歪曲事实欺负老实人的混账**，此时我们依旧要三思：是否要走到打官司这一步？能不能拉出几方势力游说、通过沟通协商甚至威慑提前私了？**对司法、对公权力一定要充满敬畏——能不诉诸法律、有办法私了，还是要提前私了。**<br>**中吉终凶**——**这个"中"不是"过程中间就吉利"，是"适可而止、不极端偏执"**（彖传："讼，有孚窒惕，中吉，刚来而得中也"）。争讼只能是万不得已的手段，甚至就是个威慑武器；如果对方下台阶了、愿意好好说话了、愿意沟通了，**哪怕自己依旧吃亏，只要这事不伤筋动骨、只要对方事后害怕了不再伤害我们，那就尽量见好就收，千万不可穷追猛打、得理不饶人**。<br>**利见大人**——彖传"利见大人，尚中正也"。争讼不一定最后一定要走到官府那一步，哪怕双方都已上头、屡试无效，依旧可以**再开一个副本：找一个公正有威信的大人物做中间人进行裁决**。这个"中正"明面上说的是公信力，**背后的深意更多是：要找一个在双方那里都有面子、甚至都有威慑力的大人物**，否则双方是不会承认他的。<br>**不利涉大川**——**不要像上一卦那样冒险去涉大川**、不要非闯这一把。 |
| **"利见大人"为什么有效（机制解释）** | 双方顶牛那是真僵持，**一旦引入第三方就有回旋的余地了**。也许双方早就有和的意思，但面子上下不来台，**这时候第三方就是一个互相给抬肩的存在**——只要有人能过渡这么一下，双方甚至最后都有可能化敌为友。哪怕咱是吃亏的一方，只要最后能走到"不打不相识"的阶段，其实就是好事、就是吉；前面的成本就当破财消灾了。 |
| **大象传（行动纲领）** | 天与水违行，讼。君子以作事谋始。 |
| **"作事谋始"解（本卦最高层的预防原则）** | 天往西走、水往东流，这一卦天生背道而驰。对于争讼这事，君子要"**作事谋始**"——**从最开始就要谋划好开端、提前明确规则、厘清边界，从根源上最大程度避免走到争讼这一步**。这是人生在世为人处事的准则。 |
| **总铁律** | ① **在古代，无论原告被告、无论输赢都没有赢家，赢家只有官府**——整个讼卦六爻唯一当位得中的就是象征裁决者的九五；② **"终凶，讼不可长也"**——不是说争讼最终赢不了，而是说**争讼这件事本身从来就没有真正的成功可言**；③ 争讼只能是威慑，最好的出路是"冤家宜解不宜结"的适可而止；④ 官司打到最后，双方仇恨已远远超过最开始那点事，**且会上升为两个家族不死不休的无间地狱**，无论输赢都耗尽家财，还要承担无休无止的未来防范寻仇成本。 |
| **⚠️ 一条重要的姿态提醒（避免误读为"一味退让"）** | **不是说要一味逃避争讼这个渠道**——对方一看咱漏了怯，反而更容易变本加厉。而是说：**这个渠道我们最好只作为威慑，我们一定要有"大不了打官司，那就打到败家破产我陪你打到底"的决心；但我们知道，这是让双方掂量成本之后能各退一步、息事宁人的办法。** |

## 二、为什么必须慎讼：古代司法的运行机制（背景知识层，产品中作为"为什么"的说服材料）

| 机制 | 内容 |
|---|---|
| **"官断十条路，九条人不知"** | 在古代，同一件官司的判决**可轻可重、可胜可败，没有固定标准**，其中门道绝大多数老百姓无法知晓。案子只要稍有可作文章的地方，判案官吏的操作空间就大了去了。 |
| **裁量权即敲诈权** | 掌握"定性权"就等于掌握了对方全部财产：说你是汉奸，你所有财产都得充公；说你不是，你们家家产该怎么分？——**只要公权力找到一个由头扯到你身上，不给你剥八层皮是不行的。** |
| **刀笔吏的操作空间** | "押司"是替代办理文书讼诉的地方。"刀笔"源于古代在竹简上刻字记事、用刀刮去错字，后多指写状子搞诉讼——**"刀笔"只要出现十次有九次是贬义**。具体操作：改供词、改案卷；把故意杀人改成过失杀人、把抢劫改成盗窃（**稍微动动性质就是天上地下之别**）；直接删除或弄丢关键证据；实在做不了手脚就直接通风报信。**重罪能改轻罪，主犯能改从犯，小罪能改无罪。** |
| **黑白两道的定价权** | 宋江为什么"平生只好结识江湖好汉"？因为他要通过这帮社会不安定因素打造自己黑白两道的口碑、震慑力和影响力：**体制内他是刀笔精通的郓城押司，体制外整个山东河北黑道他都有人。** 这种影响力在市场上就总结成一句话："我宋江定的价码，是郓城县衙和江湖好汉们都认可的。你想省这钱、想坏规矩，那公明哥哥自然不会说啥，笑呵呵地他一皱眉头，郓城的都头和江湖的好汉自然就帮那人消失了。"——因为**断宋江的财路就是在断吏例的分红、就是在断好汉们的保险**。<br>推论：**宋江有多大的名声，就意味着有多少真正的好人受到了不公的对待。** |
| **拖延与再造案件** | ① 故意将案件移交其他衙门，增加受害人的诉讼成本；② 安排衙门工作人员出差使案件停滞；③ **把受害家庭拖到家败财尽，逼你走和解**；④ 甚至可以**再造一个案子**：派一身地痞流氓去受害者那里制造争端，然后污告受害者，一圈流氓都能作证，随后把受害者关起来——**等受害者在牢里祸害死了，"没有苦主"就成了古代案件中老爷想省事的第一个前提**，随后随手就结了。 |
| **无靠山者的处境** | 在古代如果你颇有家资却没有官府靠山，那些有靠山的豺狼甚至会像上面那样**创造官司**把你拉入是非之中，从而攀剥死你。<br>这就是为什么古代要"多子多福"、为什么"男丁意味着一切"：**家里男丁多意味着生产力高，意味着家族哪怕沦落到最终斩杀线之前还有拼命鱼死网破的最后一条路，意味着官贼和寇贼想祸害死你之前，他要衡量一下成本。** |
| **一句结论** | **民贼跟官贼比起来那是个屁。官司就是祸患、就是大贼、就是无底洞——只要能及时止损，那就是大吉了。** |

## 三、爻级字段

### 初六 · 不永所事（不缠讼）

| 字段 | 内容 |
|---|---|
| **爻辞** | 不永所事，小有言，终吉。 |
| **象传** | 不永所事，讼不可长也。虽小有言，其辩明也。 |
| **位属性** | 阴爻居阳位，**不当位**（本该阳刚之位却以阴柔处之）；处坎险之下——**一上来就是凶险**。讼卦之始就在提醒：慎讼、止讼是本卦核心宗旨。 |
| **判词 → 行动语义** | 终吉 → **不缠讼、及时止损、辩明即止**。 |
| **关键词解** | **不永**："永"为长久持续之意——**不要长久纠缠于刚起的争端中、不要把小事闹大、不要率先发起官司，即便自己占理也尽量及时止损。** 象传："**讼不可长也**"——绝对不可以长久持续下去。 |
| **为什么不可长** | 只要在官府那儿挂上号了，想结案可就不是你能说得算的了。现代也一样：**衙役三班、哪个你打点得不到位，他对你都有"合法伤害权"**；哪怕就是单纯来回来去地叫你去了解案情，你受不受得了？更不要说如果对方使的银子多，人家造假证据也能把你造死。 |
| **"小有言"解** | 哪怕息事宁人会平白受对方的气、会被看热闹的人嗤落，**但我们从最开始就跳出了争讼的黑洞泥潭，避免了矛盾升级带来的无尽消耗和潜在灾祸，能把余粮、精力、时间用在做大蛋糕上。** 君子问灾不问福，君子无灾就是福。 |
| **象传"其辩明也"（本爻精髓）** | 说的是**辩明，不是辩赢**。双方发生矛盾，坐下来把问题摊开了说：澄清事实、说清道理；我吃了亏，你也不是故意的，我给你面子；咱尽头避免；你吃了亏，我给你合理补偿。**不论输赢，只谈利益，仅此而已。**<br>**一谈输赢就容易上头。谁对谁错没有意义，落实到利益上一算账，那就没有那么大火气了**——该赔赔、该还价还价，求财嘛。<br>而且咱不是怂的随便让你欺负：不管是奸官还是恶霸咱都不惧，但**咱俩家两败俱伤有意义吗？没有意义。把话说开了，未来抬头不见低头见的，那还得和气生财呢。** |
| **一条通则** | **绝大多数的灾祸与内耗都源于小事的无限升级。任何矛盾发生之后的第一反应都应该是"不扩大"。** 牢记：**取利不斗气，论事不论人，辩明即止**，就能终获吉祥。 |

### 九二 · 不克讼（弱势方：速退止损）

| 字段 | 内容 |
|---|---|
| **爻辞** | 不克讼，归而逋，其邑人三百户，无眚。 |
| **象传** | 不克讼，归逋窜也。自下讼上，患至掇也。 |
| **位属性** | 阳爻，居下卦——**下卦意味着你是弱势方**。 |
| **判词 → 行动语义** | 无眚 → **立刻停止对抗，速退保存实力**。 |
| **关键词解** | **克**＝胜任、能胜；**不**＝退避；**眚**本义是眼睛生病，引申为灾祸。<br>全句：如果没能忍住、第一步官司还是打起来了，**但一旦预感到这场争讼在资源和地位上你跟人家碰不起、继续下去毫无胜算，那就要立刻停止对抗、低头认灾、收敛锋芒、退到一个毫无威胁的地方。** |
| **两个关键细节** | **"归而逋"**：象传"归逋**窜**也"——"窜"字形容的就是**最快最决绝的速度、火速撤退**。<br>**"其邑人三百户"**：三百户是先秦下大夫的最小食邑，是**最无威胁的封地规模**——表达的是一个**认灾的态度**。只要能及时收手止损，就能保住自己最后的底牌；而且**你退回的这个根据地不会对争讼对手产生威胁，也是用姿态表明"你彻底服了"，从而消灾止仗、保存有生力量。** |
| **象传"自下讼上，患至掇也"（最清醒的一句）** | **争讼这事看的不是什么正义不正义的，而是上下强弱的一个权衡罢了。** 你是下卦意味着你是弱势方，如果自下讼上、以弱抗强，在地位权势资源完全不对等的情况下还要跟人打这官司，**那这祸患就是你自己招来的**（"掇"是拾取、自取之意）。 |
| **典型场景（现代对照）** | 大公司用司法方式绞杀小公司：**如果小公司在还没做好准备时就被大公司盯上了，对方就是要放血拖死你。赶紧低头跟他去谈收购；他如果不同意、就是想整死你，那就去找他的对手谈收购**——能保存多少资源就保存多少。此时**最大化止损是核心目标**：只要我们的价格低于市场价，无论是祸害我们的那家公司还是它的竞争对手，都会对我们进行打折收购。我们也就"归而逋、其邑人三百户、无眚"地从对抗漩涡中抽身而出了。<br>也许确实见脉了、也许未来前景被扼杀了，**但我们至少留得青山在，未来还有机会**——就像乾卦九二"见龙"没有"利见大人"之后又不是九四"跃龙"那样要粉身碎骨，**回到潜龙状态重新来过嘛**。 |
| **最要命的心理误区** | 很多人遇到矛盾和纠纷时，**哪怕知道自己赢不了，也被"面子"活活地拖死了**——因为咽不下一口气就死磕到底，最终耗光时间、心力、财产，连累家人，甚至把命都带进去。 |
| **一句冷话** | **在古代，正义和公理这东西，如果你成年之后还信，那说明你一直没长大。** 绝大多数灾祸，要么是自己争强好胜惹来的，要么是自己天真幻想、不知进退、不懂现实潜规则而招来的。 |
| **一条认清规律的话** | 我们的创意、我们刚跑通的路径也许被大公司剽窃了，我们冤，但我们要死磕到底就没有必要嘛。**自古强亲弱是个现象，我们要认清现实：被微软绞杀的苹果一旦自己起来以后，也会由屠龙少年变成恶龙——因为人性永不变。我们要做的是认清规律、把事做成，而"及时认灾"就是把事做成的一部分。** |

### 六三 · 食旧德（守本分、功归上）

| 字段 | 内容 |
|---|---|
| **爻辞** | 食旧德，贞厉，终吉。或从王事，无成。 |
| **象传** | 食旧德，从上吉也。 |
| **位属性** | 阴爻居阳位，**不当位**且失中，身处坎险之极。 |
| **判词 → 行动语义** | 贞厉终吉 → **守本分、循旧规、低调避争、功归于上**。 |
| **关键词解** | **食旧德**＝遵循旧规则、安享先人余德。两层含义：① **守好自己的本分，不觊觎不属于自己的利益和权位，不惹事生非，避免诉讼开战**；② 即便身处争讼之中，**也可以一面低调、一面借助老一辈的旧位余德去进行说和与沟通**——核心就一点：**息事宁人。只要能停手、能止损，就一定会转危为安。** |
| **象传"从上吉也"的深意（本爻精髓之一）** | 你作为下卦、作为下位者，**安守本分和旧德、不妄争讼、不找事情，这是上位者希望遵守的规则**。上位者不希望下面人天天给自己找事、需要自己去评事；**上面人对下面人的需求是：你把活儿看好、把利润送上来——突出的是一个"无事且稳定"。**<br>**如果上面认为你是个祸头子，你也就到此为止了。当上面认为你不添麻烦、只添利润的时候，你才会越来越稳、越来越吉祥。** |
| **"或从王事，无成"解（与坤卦六三完全同构）** | 此处"无成"**不是"做不成、没能力"的意思，而是"事成不居、功成不贪"**：如果事情由我们做成了，**要将功劳归上，以免功高震主**。<br>坤卦六三是阴爻居阳位不当位、身处坎险之际，九二强调的是"下不讼上"，那么六三强调的就是"**下功归上**"。<br>**如果你不明白"劳谦谨敕、事上尽礼"这一层，如果不明白"只有你把你的上帝抬上去了、你才能够进步"这件事，你这个居功抢功的小门干就该倒霉了——你会生出很多无妄之灾。你的功如果不让，那上面有的是办法把你这个'好同志'变成'坏同志'，从而让你失去上升之路。**（邓艾是怎么从灭国功臣一招被打进槛车的？史万岁是怎么从突厥杀星被杨素构陷、被杀于朝堂的？） |
| **该做** | 身处下位就要时刻明白自己的处境，牢牢记住这个世界的规则：**哪怕乾卦九二也是"见龙在田，利见大人"、需要有人给你提上去；九三也是"终日乾乾夕惕若"、不碍上面的眼。千万别觉得这个世界是个公平的付出兑现机制，而是个优势者毁灭劣势者的世界。**<br>哪个劣势者的上位，也都是抱着优势者的腿借力上来的：刘邦起步抱的是项家，刘秀入河北抱的是云台二十八将，曹操从汉末杀出来抱的是袁绍和大汉的招牌。 |
| **一条正向的发展逻辑（不只是消极避祸）** | 单纯从发展的角度讲，**我们的脱颖而出也是因为我们自身实力与解决问题能力的增强。是非丛生的环境中最稳妥的路，永远是守正道、安本分，在日拱一卒中把竞争者远远甩在后面。**"两岸猿声啼不住，轻舟已过万重山"——发展与进步靠的从来不是加入纷争、争强好胜、打赢多少官司、赢得多少是非，**而是从最开始就做好本分、不踏入争讼的泥潭。** |

### 九四 · 不克讼（强势方：回头改错）

| 字段 | 内容 |
|---|---|
| **爻辞** | 不克讼，复即命，渝安贞，吉。 |
| **象传** | 复即命，渝安贞，不失也。 |
| **位属性** | 阳爻居阴位，**不当位**；身处上卦；四爻又是近君大臣之位，本应劳谦顺上，**却安排了个乾卦之势、以刚健之性居于劳谦臣位**。 |
| **判词 → 行动语义** | 吉（有条件） → **回头、改错、回归正道**。 |
| **与九二"不克讼"的关键区别** | 九二是下卦、是**以下讼上、以下犯上**，弱者先天没有胜算；**九四身处上卦，这个"不克讼"意味着的是"强凌弱"**——意味着你**占据着权位、资源、司法优势之后开始主动挑起争端、祸害弱者**。 |
| **为什么强凌弱也必败** | **恃强凌弱违背天理、不合正道，哪怕一时占了上风，终究会被反噬**：民怨四起之后就是天怒；上位者对于犯了众怒之臣，通常会杀了以平息百姓怒火——**干掉"恃强凌弱、以贵欺贱"之人，本就是这社会成本最小、效果最佳的减压阀，这是九五最爱干的事。** |
| **权术警示（为何九五必然拿你开刀）** | 九五会用这些名义收拾你：**假天责人**——借"天意""人民""国法"等至高无上的名义攻击目标；**借公义之势掩一己之私**——以"替天行道"的名义强行将对手打成反动派；**假民言势、见信以人**——以"人民的名义""百姓的愿望""群众的呼声"将他要干的事包装成顺应民意，借大众之口掩盖独断专行的意图，让自身谋划看似是大众的选择。<br>**千万别不拿民意当回事：想办你时，它就是最好使的刀。顺着潮流走，别被扣上逆流的帽子——扣上了，那就不是小事。千万别当人民的罪人。** |
| **该做（本爻的解药）** | **复**＝回归之意，**渝**＝改变之意。**如果恃强凌弱的上位者能够意识到自己的错误、能够回头改错、回归天理正道，最终依旧能安守正道得吉。** |
| **不做的三个重大隐患（诊断清单）** | **第一，死仇**：被你欺负得家破人亡的家族会结下不死不休的世仇。**你有把握给人家斩草除根吗？不怕贼偷怕贼惦记，你的长久防范成本太高了。再者说，人家万一有个弟弟叫吴用呢？**<br>**第二，被九五替天行道**：你如果干得过分了，九五会代天降罪杀你以平众怒——**届时你恃强凌弱的所有利润，可就都成了九五替天行道的利润了**（在古代抄家本就是补充国库和皇帝小金库的重要手段）。<br>**第三，你不是最终说得算的**：你虽处优势位，但你毕竟不是九五之尊。**万一你的对手通着天呢？万一你惹的这人背后有你惹不起的人呢？万一就是很凑巧——杨乃武有个同学叫吴以同，吴以同的老板叫胡雪岩，胡雪岩认识汪东河，就是有人想借着这个事震动朝堂呢？** |
| **一条给强者的话** | **下位者挑战上位者那是归而逋窜，你跑得不够快都死得老惨了；但上位者只要肯回头，那都是给受害者脸了，都属于回归正道了。"改心则讼散，归正则祸消，知错能改是大善。"**<br>**现实世界已经给予高位者这么多红利了，你回个头就行——千万别给脸不要。** |
| **一条底线** | 即便你身处优势身位，也不要恃强凌弱，**尤其不能颠倒黑白地拿法律屠刀去祸害无辜。** |

### 九五 · 讼元吉（裁决者）

| 字段 | 内容 |
|---|---|
| **爻辞** | 讼，元吉。 |
| **象传** | 讼元吉，以中正也。 |
| **位属性** | 阳爻居阳位，**当位**且**得中**——**是讼卦六爻中唯一当位得中的一爻**。是君位，是**听讼断讼之位，不是原告被告**。 |
| **判词 → 行动语义** | **元吉** → **中正裁决**。 |
| **⚠️ 最容易被误读的一爻** | **看到"元吉"先别觉得"打官司这事大吉大利、官司打到这儿都能讼元吉了"——这爻不是这个意思。** 九五指的**不仅仅是君主，而是"手握最终裁决权的那个大人物"**：在县里，九四是西门庆，九五是县太爷。 |
| **为什么对裁决者是"百利无害"** | **所有的官司打到县太爷那儿，那大老爷都高兴，因为裁决权在他这儿。** 这就跟《大宅门》里白景琪跟对手打官司一样——白景琪得给江文拿钱，孙家被拖起来没完没了的也得拿钱。**掌握最终裁决权的人最乐见其成的就是"你们打官司"**——不打官司的话，他的书吏、账房、六房书吏、三班衙役拿什么养活？朝廷可只给县太爷发工资，像宋江那种押司是没有国家工资的——**你觉得宋江是指望县太爷发工资，还是自己创收呢？** |
| **但依旧要分眼前之利与长远之利** | 象传"讼元吉，**以中正也**"依旧在强调：**手握最终裁决权的大人物要有阳刚决断之力、居中公允之心，不偏不倚地裁决，让双方心服口服，最终止讼息争。** |
| **为什么配得上"元吉"（本爻精髓）** | 九五居乾天正位，**下视争讼的示威取职**——因为**它的职责是化解天下纷争**：所有纷争到了这里都能得到一个双方认可的判决，是止讼、息讼，**从根本上化解矛盾，让所有内耗到此为止、案结事了，而不是挑起后面更大的暴力流血冲突。**<br>**中正裁决能够消弭戾气，能让强者不再肆意妄为地侵弱，让讼棍碰瓷的社会垃圾不敢亵渎司法公正，让社会的总成本降低，让"喜诉好争"的风气被扭转**——所以才配得上"元吉"这个根本性、终极性的吉祥。 |
| **⚠️ 一个必须纠正的误区（中正≠绝对公平）** | **"中正"不是绝对的公平，自古也没有绝对的公平。这个"中正"准确来讲是"折中"之意，是让争讼的双方都能得到一个可以接受的结果，核心目的是化解矛盾、把这事到此为止。**<br>**案例**：尉迟恭被李道宗、任城王等宗亲大员在庆善宫差点弄死这事，从绝对的公正公平来讲，李道宗和尉迟恭都应该受惩罚担责任。但李世民没有责罚，因为这都是最核心的骨干。**李世民是从另一个角度端平这碗水的**：一方面重赏安抚尉迟恭，另一方面还让尉迟恭转为自己的贴身护卫（从此不担心再被阴掉），同时还让尉迟恭立战功打李元吉，从而向老将们证明"为什么要保这员虎将"。<br>**单纯的公平就让亲服分崩离析了、就成了"亲王亲信人人自危"了。让尉迟恭忠心、让老将们没话说、更加内卷地好好干——这是九五的中正争议。** |
| **诊断用法** | 若你正处在"裁决者"角色（领导、家长、仲裁人、社区调解），本爻就是你的行动纲领：**目标是"案结事了、双方可接受"，不是"分清对错"。** |

### 上九 · 或锡之鞶带（穷讼到底）

| 字段 | 内容 |
|---|---|
| **爻辞** | 或锡之鞶带，终朝三褫之。 |
| **象传** | 以讼受服，亦不足敬也。 |
| **位属性** | 阳爻居阴位，**不当位**；该止之地却不知止——**刚愎自用**。 |
| **判词 → 行动语义** | 三褫之 → **此爻不可入**。 |
| **关键词解** | **锡**通"赐"；**鞶带**是皮制的大带，古代官员的服饰。**褫**＝剥夺。<br>全句：**靠争讼到底获胜的，哪怕暂时能得到君王赐予的地位和赏赐，也会在极短的时间里被剥夺。**<br>一句话总结：**穷讼终胜，招赐即夺。** |
| **为什么必然如此（四层原因）** | **第一，来路不正、德不配位**：你的荣宠不是靠建功立业、创造利益换来的，而是**穷尽争讼、将矛盾扩大到极致后惨烈内耗得来的**。<br>**第二，根基已空**：在穷讼过程中你损失了自己的根基、掏空了自己的家底，**非常容易被"螳螂捕蝉黄雀在后"地让第三方钻了空子——你这官司的每一步都在源源不断地往外掏银子。**<br>**第三，口碑崩塌**：无论你多么占理，**官司打久了，无论是你的上风还是周围的亲友、百姓、邻居，都会觉得你是个"惹事生非、麻烦缠身"的人**——这对你自家的口碑是巨大打击，也就是象传的"**以讼受服，亦不足敬也**"。<br>**第四，无力应对下一轮**：这案子结束了，万一你的另一个竞争对手"趁你病要你命"地又来找你打官司呢？你还有这么多财力精力应对吗？就算你不怕、觉得"咱有理咱怕谁"，**但裁决者对你可能已经没有什么好印象了，觉得"又是你来找事"。** |
| **最可怕的是延伸后患** | **败方会绵绵不绝地长久恶意和报复，甚至会造成杀身灭门之祸。**<br>**历史镜鉴**：怀愍（司马家宗室）在司马之乱中死后，最终被判断还皇所害，还皇兵败被杀了；但怀愍被杀这事当时京城令桓伯也参与了，十五岁的桓温因此整个雪耻复仇——**由于桓伯是朝廷官员，桓温没有立即下手，等了三年之后桓伯死了，在丧礼上桓温杀了桓伯的三个儿子。** 桓温对朝廷心存敬畏，只针对私仇复仇，这事事后成为东晋"好少年"的典范。 |
| **更大的延伸（党争的起源）** | **穷讼之胜再延伸一下，也是所有党争的最终结局。所有党争都是从最开始的纷争没有处理好开始的**：一方在皇帝的加持下获得了暂时胜利，**皇帝并没有行九五中正之道去息讼止讼，从而败方觉得受到了巨大的不公且吃了大亏**，此后就是越来越撕扯不清的互相报复。 |
| **整卦的结论** | **成功需要的是实力和根基，而穷讼这事是无限消耗我们实力与根基的行为。即便是强凌弱穷讼得胜，其事后的衍生成本大到无法计数。所以一定要止讼、息争、轻装上阵，方得吉祥。** |

**三条一句话铁律**：
1. **对普通人**：官司没有真正的赢家，只有官府获利。能私了就私了，"冤家宜解不宜结"。
2. **对弱势方**：认灾不是懦弱，"及时认灾就是把事做成的一部分"。
3. **对强势方**：你回个头就行，千万别给脸不要。

**卦位结构对照（务必写进产品的说服层）**：需卦**九五当位**——说明**天道支持你安身养命、建功立业**；讼卦**除九五之外其余五爻全不当位**——说明**天道不支持你争讼**。<br>⚠️ **本轮更正**：原句作"讼卦**五爻**不当位"，会被读成"第五爻不当位"，与本卡开头「除九五之外全部不当位」及 `知识卡65`（讼当位数 1，唯一当位之爻正是九五）冲突。**本库另有两处沿用了这一措辞（噬嗑 21、复 24），已一并更正。**这不是道德劝导，是卦象结构本身给出的定性。
