# 知识卡 07 · 师卦（地水师）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："讼必有众起，故受之以师。"——争讼没能在讼卦止住，矛盾升级为群体对抗，就进入师卦。

---

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 师 · 第七卦 |
| **卦象** | 上坤（地/顺）下坎（水/险），称"地水师"。**一阳（九二）居下卦之中，统五阴**——一将统众之象 |
| **领域定义** | **群体冲突与组织化对抗**。带团队打硬仗、部门间对抗、市场争夺战、诉讼升级为全面战争、家族纠纷扩大为两族对立。凡是"这事已经不是我一个人的事，要组织力量去打"，都落在师卦。 |
| **不归本卦的情况** | 冲突仍是双方私事、未组织化 → 讼卦；已在争取盟友而非对抗 → 比卦。 |
| **"师"字本义** | 军队、众。**注意：坎在下卦**——按本库通则，坎在下意味着"起步即险"，这一卦从根上是被动的、不得已的。 |
| **卦辞原文** | 师：贞，丈人吉，无咎。 |
| **⚠️ 卦辞的关键缺失** | **无元、无亨、无利，只有"贞"。** 这是六卦以来最"吝啬"的卦辞之一——**它不许诺你任何好处，只告诉你唯一的活路是"贞"（正）**。战争这件事，天道不给你元亨利，只给你一条"必须师出有名"的底线。 |
| **卦辞现代解** | **贞**——必须正当、师出有名，否则无从谈起。**丈人吉**——"丈人"是老成持重、德高望重的统帅；**必须由这样的人来主事，才吉、才无咎**。换言之：**这一卦的成败不取决于兵力多少，取决于谁在指挥。** |
| **彖传** | 师，众也；贞，正也。能以众正，可以王矣。刚中而应，行险而顺，以此毒天下而民从之，吉又何咎矣。 |
| **彖传要点** | **能以众正，可以王矣**——能率领众人走正道，才配得上王。**行险而顺**——下坎是险、上坤是顺：**明知是险，但要以"顺"的方式行之**（顺民心、顺大势），不是硬冲。**以此毒天下而民从之**——"毒"是役使、治理之意；战争必然伤害天下，**但只有民众认同，才吉、才无咎**。 |
| **大象传（行动纲领）** | 地中有水，师。君子以容民畜众。 |
| **"容民畜众"解** | 地中含水，水藏于地——**平时把力量蓄在民间、涵养民众，战时才能动员**。这是师卦最高层的原则：**战争的胜负在开战前就决定了，决定于你平时有没有"容民畜众"。** |
| **总铁律** | ① **师出必须以律**（初六），一开始就乱了，后面全废；② **指挥权必须集中于"丈人"**（九二、六五），多头指挥必凶；③ **打完之后必须处理好分配和用人**（上六"小人勿用"），否则赢了也白赢。 |

## 二、爻级字段

### 初六 · 师出以律

| 字段 | 内容 |
|---|---|
| **爻辞** | 师出以律，否臧凶。 |
| **象传** | 师出以律，失律凶也。 |
| **位属性** | 阴爻居阳位，**不当位**；处坎险之下——一上来就是险。 |
| **判词 → 行动语义** | 否臧凶 → **立规矩、定纪律，否则不动**。 |
| **关键词解** | **律**＝纪律、法度、号令。**否臧**＝不善、不好。全句：出兵必须有严明的纪律；**否则，无论结果好坏都是凶**。 |
| **识别信号** | ① 冲突刚要组织化，人刚要拉起来；② 大家七嘴八舌，还没有统一的规则和指挥；③ 你倾向于"先干起来，边打边理"。 |
| **该做** | 开打之前先立三件事：**谁做最后决定、什么事不能做、赢了怎么分**。 |
| **不该做** | 靠热情和义气组织人。**"边打边理"在师卦是死路**——象传只留了"失律凶也"四个字，没有余地。 |
| **与屯卦"经纶"呼应** | 屯卦大象传讲"先立不变的经线，再穿灵活的纬线"。**师卦初六就是那根"经"**：纪律是不可有一寸偏移的骨架。 |

### 九二 · 在师中吉（本卦唯一阳爻，卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 在师中吉，无咎，王三锡命。 |
| **象传** | 在师中吉，承天宠也。王三锡命，怀万邦也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**；**是全卦唯一的阳爻**，五阴所归——**卦主**，即卦辞所说的"丈人"。 |
| **判词 → 行动语义** | 中吉，无咎 → **居中主事、独任其责**。 |
| **爻义** | **在师中**：身在军中而居中不偏——既指位置（下卦之中），也指心态（不偏激、不冒进）。**王三锡命**：君王三次加以任命嘉奖，**是授权、是信任的确认**。 |
| **本爻的关键（为什么不当位反而是卦主）** | 阳爻居阴位本是"名不正言不顺"，但**在师卦这是优势**：**统帅本不该居君位**（那是六五的事），他的价值在于"得中"——**有实权、能决断、却不越位**。这与坤卦六五"虽有君之权而以臣自处"同理。 |
| **识别信号** | ① 你是这场对抗实际的组织者和决策者；② 上面授权给你、信任你；③ 你既有决断权，又清楚自己不是最终拍板的那个人。 |
| **该做** | 承担全部指挥责任、居中不偏；把授权用足，但不越位。 |
| **不该做** | 把指挥权分给别人（见六五"弟子舆尸，贞凶"）；或反过来，凭战功挑战六五。 |
| **对应关系** | **九二 ↔ 六五**：六五授权、九二执行。**这是全卦唯一的吉配**（与蒙卦九二↔六五结构完全同构）。 |

### 六三 · 师或舆尸

| 字段 | 内容 |
|---|---|
| **爻辞** | 师或舆尸，凶。 |
| **象传** | 师或舆尸，大无功也。 |
| **位属性** | 阴爻居阳位，**不当位**且失中，居坎险之顶。 |
| **判词 → 行动语义** | **凶** → **此爻不可入**。 |
| **爻义** | **舆尸**＝用车装载尸体运回——**大败**之象。象传"大无功也"：不仅败，而且毫无战果。 |
| **触发条件** | 阴柔之才居阳刚之位而妄动：**没有能力却抢了指挥权，或不该出战而出战**。 |
| **识别信号（诊断清单）** | ① 指挥权不在最有能力的人手里；② 有人越过九二自行行动；③ 你自己能力不足却被推上前台，或主动争了这个位置。 |
| **该做** | 立即把指挥权交还九二。**这一爻的解药不在爻内，在于不要来。** |
| **与乾卦九四的对比** | 乾九四"不进则死"，凶但有一线；**师六三是直接"凶"、"大无功"，无一线**。区别在于：乾九四是有实力者面对唯一通路；师六三是无实力者占了错位置。 |

### 六四 · 师左次

| 字段 | 内容 |
|---|---|
| **爻辞** | 师左次，无咎。 |
| **象传** | 左次无咎，未失常也。 |
| **位属性** | 阴爻居阴位，**当位**；已入上卦坤顺。 |
| **判词 → 行动语义** | 无咎 → **退驻、不战、保存实力**。 |
| **关键词解** | **左次**＝退驻、驻扎于后（古代军制以右为前进、左为退守）。**主动后撤扎营，不打这一仗**。 |
| **本爻的价值（易被低估）** | 象传"**未失常也**"——退不是失败，**是没有违背常理**。在整卦"无元无亨无利"的底色下，**"无咎"已经是很好的结果**：不打，就是赢。 |
| **识别信号** | ① 你有能力打，但打了不划算；② 时机、地利、人心有一项不在你这边；③ 周围有人在催你"必须表个态"。 |
| **该做** | 主动后撤扎营，把力量收回来；等条件变化。 |
| **不该做** | 为了面子或表态而战。 |
| **与讼卦九二呼应** | 讼九二"归而逋，其邑人三百户，无眚"＝弱势方火速退；**师六四"左次"＝有实力者的主动战略后撤**。两者都是"退才无灾"，但后者是从容的选择，前者是被迫的止损。 |

---

### 六五 · 田有禽（授权者）

| 字段 | 内容 |
|---|---|
| **爻辞** | 田有禽，利执言，无咎。长子帅师，弟子舆尸，贞凶。 |
| **象传** | 长子帅师，以中行也。弟子舆尸，使不当也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位——是授权者、决策者，不是带兵的人。 |
| **判词 → 行动语义** | 无咎 / 贞凶（两种结局） → **用对人则无咎，用错人则凶**。 |
| **爻义** | **田有禽**＝田里有禽兽为害——**敌人来犯、祸患已现**，是不得已而战的正当理由。**利执言**＝适宜公开申明理由（师出有名）。**长子帅师**＝让"长子"（即九二那位有中正之德的统帅）带兵，则无咎；**弟子舆尸**＝让不合格的人带兵，则大败，**贞凶**。 |
| **本爻是全卦的枢纽（最重要的一条）** | 象传把原因说得极其直白：**"弟子舆尸，使不当也"——败仗的根源不是敌人强，是"用人不当"。** 六五自己不上战场，**它唯一的动作就是"选谁"，而这个选择决定全卦成败。** |
| **识别信号（若你是六五）** | ① 你是拍板的人，但不亲自执行；② 你面前有多个人选；③ 你可能出于亲疏、忠诚度、平衡考虑而想用"弟子"。 |
| **该做** | ① 先确认"田有禽"——这仗是被迫的、正当的；② 公开申明理由（利执言）；③ **把指挥权完整交给"长子"，不分权、不掺沙子。** |
| **不该做** | 为了制衡而多头指挥；用听话的人代替能打的人。 |
| **与讼卦九五的差异** | 讼九五的职责是"中正裁决、案结事了"；**师六五的职责是"选对人、然后放手"**。都是尊位，动作完全不同。 |

### 上六 · 大君有命

| 字段 | 内容 |
|---|---|
| **爻辞** | 大君有命，开国承家，小人勿用。 |
| **象传** | 大君有命，以正功也。小人勿用，必乱邦也。 |
| **位属性** | 阴爻居阴位，**当位**；居全卦之终——**战后论功行赏阶段**。 |
| **判词 → 行动语义** | 小人勿用 → **论功、封赏，但绝不能用无德之人**。 |
| **爻义** | **大君有命**＝最高决策者下达封赏之命；**开国承家**＝封侯建国、承继家业（论功行赏的最高规格）；**小人勿用**＝无德之人绝不可用。 |
| **本爻的特殊之处（师卦唯一的"善终"爻）** | 全卦六爻中，初六讲纪律、六三大凶、六四退守、六五讲用人，**只有上六是"打完之后"**。象传"**以正功也**"——赏罚必须公正，这是收尾；"**小人勿用，必乱邦也**"——**赏错了人，赢了的仗也会输掉。** |
| **识别信号** | ① 这场对抗已经结束；② 要分战果、要安排人；③ 有人战功大但德行有亏。 |
| **该做** | 公正论功（正功）；重赏有功者；**但坚决不把权位交给无德之人——"必乱邦也"** 是明确的因果判断。 |
| **不该做** | 因战功而无视德行。这与蒙卦"蒙以养正"完全呼应：**绝不能将一身本领/权位交给无德之人。** |
| **与需卦九五呼应** | 需九五讲上岸后"感恩、分享、节制"；**师上六讲战后"论功、封赏、但择人"**。两者是同一个阶段的两面：**分享是必须的，但分给谁是有底线的。** |

## 三、师卦定位速查表

| 爻 | 角色 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | 组织者 | 师出以律 | 人刚拉起来，还没有纪律 | 不当位·险下 | 立律，**失律凶** |
| 九二 | **统帅（卦主）** | 在师中吉 | 你是实际决策者，且获授权 | 不当位但**得中** | **中吉·无咎**·居中独任 |
| 六三 | 越位者 | 师或舆尸 | 指挥权在错误的人手里 | 不当位·失中·险顶 | **凶·大无功**·不可入 |
| 六四 | 有实力者 | 师左次 | 能打但不划算 | 当位 | **无咎**·主动后撤 |
| 六五 | **授权者** | 田有禽 | 你要选谁带兵 | 不当位·得中居尊 | 无咎 / **贞凶**·全看用人 |
| 上六 | 决策者 | 大君有命 | 打完了要分战果 | 当位 | 正功·**小人勿用** |

**师卦三句话**：
1. 开打前——**没有纪律就不要动**（初六）。
2. 打的时候——**指挥权只能给一个人，且必须是最合格的那个**（九二、六五）。
3. 打完之后——**赏要公，但人要择；赏错人比打败仗更危险**（上六）。

**本卦最反直觉的一条**：卦辞无元无亨无利，只有"贞"。**《周易》对战争不许诺任何好处，只给一条底线。** 这与讼卦"终凶"是同一个态度——**冲突升级这条路，天道从不鼓励，只教你怎么少死人。**
