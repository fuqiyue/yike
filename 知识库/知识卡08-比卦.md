# 知识卡 08 · 比卦（水地比）

> ⚠️ **来源标注**：经文层出自《周易》原文；义理层为按本库框架的推演，**待校**。
> 序卦传："众必有所比，故受之以比。"——组织起来打过仗之后，人必然要寻求归附与联合。
> **本卦与师卦是同一组卦的翻转**（师上坤下坎，比上坎下坤），一体两面：**师讲对抗，比讲联合。**

---

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 比 · 第八卦 |
| **卦象** | 上坎（水）下坤（地），称"水地比"。**一阳（九五）居上卦之中，统五阴**——众所归附之象。水在地上，亲密无间 |
| **与师卦的结构对照** | 师卦一阳在**二**（下卦之中）＝统帅在军中；比卦一阳在**五**（上卦之中）＝**君主在位、众人来归**。同是"一阳统五阴"，位置差异决定性质完全不同 |
| **领域定义** | **归附、联合、结盟、择主、建立信任关系**。选团队、选老板、选合作方、选平台、拉盟友、经营人际关系网。凡是"我要跟谁站在一起"或"如何让人愿意跟我"，都落在比卦。 |
| **"比"字本义** | 甲骨文象二人并列相从——**亲近、并列、归附、类比**。 |
| **卦辞原文** | 比：吉。原筮，元永贞，无咎。不宁方来，后夫凶。 |
| **⚠️ 卦辞的特殊之处** | **一上来就是"吉"**——这是前八卦中唯一开门就给"吉"字的（屯蒙需讼皆无）。**归附联合本身是天道所许的好事**。但紧接着给了三重条件。 |
| **卦辞现代解** | **原筮**——"原"是再、重新，"筮"是审断：**要反复审慎地判断，不可草率归附**。<br>**元永贞**——三重条件：**元**（所归附的对象必须有开创之德、是正源）、**永**（这段关系要能长久）、**贞**（必须正道）。三者齐备才"无咎"。<br>**不宁方来**——不安宁的邦国前来归附：**天下不安时，人自然会寻求依附**，这是常态。<br>**后夫凶**——**来晚的那个凶**。这是本卦最锋利的一句：**归附是有时间窗口的，你观望太久、等大局已定才来，就没位置了，甚至成为被清算的对象。** |
| **彖传** | 比，吉也；比，辅也，下顺从也。原筮元永贞，无咎，以刚中也。不宁方来，上下应也。后夫凶，其道穷也。 |
| **彖传要点** | **比，辅也，下顺从也**——比的本质是"辅"，是下对上的顺从。**以刚中也**——之所以能"无咎"，是因为有九五这个"刚中"的核心可归。**后夫凶，其道穷也**——来晚了，路就走窄了（与屯六三"往吝穷也"同一个"穷"字）。 |
| **大象传（行动纲领）** | 地上有水，比。先王以建万国，亲诸侯。 |
| **总铁律** | ① **归附前必须"原筮"**——反复审断，看清"元永贞"三条；② **归附要及时**——"后夫凶"，观望是有代价的；③ **归附必须有诚（孚）**——全卦四次出现"孚"字概念，诚信是关系的唯一地基；④ **不可无所归附**（上六"比之无首，凶"）。 |

## 二、爻级字段

### 初六 · 有孚比之

| 字段 | 内容 |
|---|---|
| **爻辞** | 有孚比之，无咎。有孚盈缶，终来有他，吉。 |
| **象传** | 比之初六，有他吉也。 |
| **位属性** | 阴爻居阳位，**不当位**；居全卦之始——**关系刚建立的阶段**。 |
| **判词 → 行动语义** | 无咎 → 吉 → **以诚为地基**。 |
| **关键词解** | **孚**＝中信、诚信（与需卦"有孚"、讼卦"有孚"同字）。**缶**＝瓦罐，是最朴素的器皿。**有孚盈缶**＝**诚信充满瓦罐**——不是用金玉之器盛华丽的东西，而是用最朴素的容器装最实在的诚意。**终来有他**＝最终会有别人也来归附。 |
| **本爻精髓** | **"盈缶"三字是全卦最重要的意象**：建立关系的第一步不是拿出漂亮的条件，而是**拿出朴素而充实的诚意**。诚意够了，不但当下无咎，**还会吸引更多人（"终来有他"）**。 |
| **识别信号** | ① 关系刚开始，你还没有资源和地位；② 你能给出的只有态度和诚意；③ 你倾向于用许诺或包装来弥补实力不足。 |
| **该做** | 用朴素的、可验证的诚意打底。**"缶"就是承认自己现在只有瓦罐——但瓦罐是满的。** |
| **不该做** | 以虚饰代替诚意。**这与屯卦六二"匪寇婚媾"是同一件事的另一面**：屯六二教你识别别人的虚假求婚，比初六教你自己不要做那个虚假求婚的人。 |

### 六二 · 比之自内

| 字段 | 内容 |
|---|---|
| **爻辞** | 比之自内，贞吉。 |
| **象传** | 比之自内，不自失也。 |
| **位属性** | 阴爻居阴位，**当位**且**得中**——**下卦最佳之爻**（与坤六二"直方大"同位）。 |
| **判词 → 行动语义** | 贞吉 → **从内心出发去归附，且不失自我**。 |
| **爻义** | **自内**＝发自内心、由内而外，不是外力驱使、不是权衡利弊。 |
| **象传"不自失也"（本爻精髓）** | **归附而不失去自己**——这是全卦最重要的一条平衡。**顺从不等于丢掉自我**：因为是"自内"的选择，所以顺从的同时保有本心和判断。 |
| **与坤六二完全同构** | 坤六二"直方大，不习无不利"——**不是后天刻意模仿造作，而是发自内心认可**。比六二"比之自内，不自失也"是同一个道理：**真诚不是装出来的，归附也不是演出来的。** |
| **识别信号** | ① 你归附/追随某人某组织，是因为真的认同；② 你不需要刻意讨好、投机取巧；③ 你在关系中依然保有自己的原则。 |
| **该做** | 让归附出于内心认同；同时守住"方"（原则边界）。 |
| **不该做** | 因外部压力、因利益权衡而归附——那不是"自内"，早晚"自失"。 |

### 六三 · 比之匪人

| 字段 | 内容 |
|---|---|
| **爻辞** | 比之匪人。 |
| **象传** | 比之匪人，不亦伤乎。 |
| **位属性** | 阴爻居阳位，**不当位**且失中——上下皆阴，无阳可依，且距九五最远。 |
| **判词 → 行动语义** | （无判词，象传直断"不亦伤乎"） → **跟错了人**。 |
| **爻义** | **匪人**＝不当之人、非其人、不该亲附的人。**注意此处"匪"是本义"不当/非类"，与屯六二、蒙卦的"匪"（通"非"作否定副词）用法不同。** |
| **本爻的严厉之处** | **全卦六爻中爻辞最短的一爻——只有四个字，没有任何判词**。象传补了一句反问：**"不亦伤乎"——这不是很可悲吗？** 不给凶，不给吝，只给一声叹息。这种写法本身就是判词：**跟错人这件事，连"凶"都不配给你，因为是你自己选的。** |
| **识别信号（诊断清单）** | ① 你依附的对象没有"元"（不是正源、没有开创之德）；② 关系不"永"（明显是短期利用）；③ 关系不"贞"（做的事不正）；④ 你身边没有可靠的人，能接触到的都是同类相斥的处境。 |
| **该做** | 立刻重新"原筮"——回到卦辞，用"元永贞"三条重新审断。**若三条都不满足，这段关系本身就是错的。** |
| **与蒙卦六三呼应** | 蒙六三"勿用取女，见金夫"讲的是"不要跟这样的人"；**比六三讲的是"你已经跟了这样的人"**。前者是预防，后者是诊断。 |

### 六四 · 外比之

| 字段 | 内容 |
|---|---|
| **爻辞** | 外比之，贞吉。 |
| **象传** | 外比于贤，以从上也。 |
| **位属性** | 阴爻居阴位，**当位**；已入上卦，紧邻九五。 |
| **判词 → 行动语义** | 贞吉 → **向外、向上归附于贤者**。 |
| **爻义** | **外**＝向外、向上（相对于六二的"内"）。象传点明了"外"的具体所指：**"外比于贤"——归附的是"贤"，"以从上也"——顺从的是上位的九五。** |
| **本爻与六二的对照（重要）** | **六二"自内"、六四"向外"，两者都是"贞吉"，但机制不同**：<br>**六二**＝内在认同（我为什么跟）；<br>**六四**＝对象正确（我跟谁）。<br>**两条都满足才是完整的"比"**：出于真心，且跟对了人。 |
| **识别信号** | ① 你处在一个可以选择归附对象的位置；② 你已经能够接近真正的核心（九五）；③ 你在犹豫是抱团（跟同类）还是向上（跟贤者）。 |
| **该做** | **向上、向贤，不向同类抱团。** |
| **与坤卦"西南得朋，东北丧朋"完全呼应** | 坤卦彖传："西南得朋，乃与类行；东北丧朋，乃终有庆。"——**和同类扎堆看似顺，实则陷入纯阴无阳的局限；终极使命是去找异类、阴阳合合。** 比六四"外比于贤"就是这条原则的执行：**离开同类，去归附那个阳刚的核心。** |

### 九五 · 显比（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 显比，王用三驱，失前禽，邑人不诫，吉。 |
| **象传** | 显比之吉，位正中也。舍逆取顺，失前禽也。邑人不诫，上使中也。 |
| **位属性** | 阳爻居阳位，**当位**且**得中**；**全卦唯一阳爻**，五阴所归——**卦主**。 |
| **判词 → 行动语义** | 吉 → **光明正大地被归附，且不强求**。 |
| **爻义** | **显比**＝光明、公开地比——**不搞私下结党，不搞暗中拉拢**。<br>**王用三驱，失前禽**＝古代田猎之礼，三面驱赶而留一面放生，跑掉的猎物就让它跑。象传解为"**舍逆取顺**"——**逆着跑的就放它走，顺着来的才收下**。<br>**邑人不诫**＝城邑之人不需要戒备、不必被强迫动员。 |
| **本爻精髓（全卦最高智慧）** | **"失前禽"三字是比卦的灵魂：真正的归附不能强求。** 你三面驱赶已经足够，留一面让不愿来的走掉——**跑掉的那些，本来就不是你的。**<br>而"邑人不诫"是这条原则的结果：**因为你不强求，所以自己人不需要提防你、不必被动员**，象传"上使中也"——上位者行事居中，下面才安心。 |
| **识别信号（若你是九五）** | ① 你是那个被归附的核心；② 有人愿意来，也有人在观望或反向而行；③ 你有能力强行拉拢或施压。 |
| **该做** | 把标准和态度公开摆出来（显）；顺者纳之，逆者放之；**不强求、不施压、不搞暗盘。** |
| **不该做** | 为了"一个都不能少"而强行拉拢——那就成了"不显"，就会让"邑人诫"。 |
| **与讼九五、师六五的对照（三个尊位）** | **讼九五**＝中正裁决，目标是"案结事了"；**师六五**＝选对人然后放手；**比九五**＝光明示人、不强求归附。**三个尊位的共同点：都不靠强力，都靠"中正"。** |

### 上六 · 比之无首

| 字段 | 内容 |
|---|---|
| **爻辞** | 比之无首，凶。 |
| **象传** | 比之无首，无所终也。 |
| **位属性** | 阴爻居阴位（当位），但居全卦之终、已过九五——**来晚了，也无所可归**。 |
| **判词 → 行动语义** | **凶** → **此爻不可入**。 |
| **爻义** | **无首**＝没有归附的对象、没有开端。象传"**无所终也**"——**没有开始，也就没有结果。** |
| **⚠️ 极重要：此"无首"与乾卦用九的"无首"含义完全相反** | **乾用九"见群龙无首，吉"**——"无首"是**不居首、不独尊、不垄断话语权**，是主导者的最高境界。<br>**比上六"比之无首，凶"**——"无首"是**无所归附、没有可依的核心**，是追随者的绝路。<br>**同一个词，在"主导者之路"和"归附之路"上意义完全颠倒。这是产品必须处理的一处歧义，绝不能混用。** |
| **触发条件** | 卦辞已经预警："**后夫凶**"——观望太久、等大局已定才来，就没位置了。 |
| **识别信号** | ① 你迟迟不做选择、想再看看；② 该站队的时候你保持了"中立"；③ 现在格局已定，各方都有了自己的人，没有你的位置。 |
| **出路** | 此爻本身无出路。**它的解药全在卦辞的"后夫凶"和六四的"外比于贤"——归附是有时间窗口的。** |

## 三、比卦定位速查表

| 爻 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|
| 初六 | 有孚盈缶 | 关系刚开始，你只有诚意 | 不当位 | 无咎→**吉**·以朴素诚意打底 |
| 六二 | 比之自内 | 出于真心追随，且没丢掉自己 | **当位·得中** | **贞吉**·自内·不自失 |
| 六三 | 比之匪人 | 你跟错了人 | 不当位·失中·无所依 | **不亦伤乎**·重新原筮 |
| 六四 | 外比于贤 | 在"抱团"和"向上"之间犹豫 | 当位·近君 | **贞吉**·向外向贤，不与类行 |
| 九五 | **显比（卦主）** | 你是被归附的核心 | **当位·得中** | **吉**·显·失前禽·不强求 |
| 上六 | 比之无首 | 观望太久，已无位置 | 当位但已过五 | **凶**·不可入 |

**比卦四句话**：
1. **归附前要"原筮"**——反复审断，看"元、永、贞"三条是否齐备。
2. **归附要及时**——"后夫凶"，观望本身就是代价。
3. **要向上向贤，不与同类抱团**——与坤卦"东北丧朋，乃终有庆"同理。
4. **若你是被归附的一方，"失前禽"是本事**——不强求，才有"邑人不诫"。

**师比一组的对照总结**：

| | 师（第7卦） | 比（第8卦） |
|---|---|---|
| 卦象 | 上坤下坎 | 上坎下坤 |
| 一阳所在 | 九二（下卦之中） | 九五（上卦之中） |
| 性质 | **对抗** | **联合** |
| 卦辞开局 | 无元亨利，只有"贞" | 直接给"**吉**" |
| 核心动作 | 立律、择帅、正功 | 原筮、自内、向贤、不强求 |
| 天道态度 | **不鼓励，只教你少死人** | **许可且鼓励，但有三重条件** |
