# 知识卡 09 · 小畜卦（风天小畜）

> ⚠️ **来源标注**：经文层出自《周易》原文；义理层为按本库框架的推演，**待校**。
> 序卦传："比必有所畜，故受之以小畜。"——有了归附联合，就开始有积蓄。
> **本卦是"力量不足时如何积累"的专卦，也是全书讲"以柔制刚"的典型。**

---

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 小畜 · 第九卦 |
| **卦象** | 上巽（风）下乾（天），称"风天小畜"。**一阴（六四）欲畜止五阳**——以一柔制五刚，故只能"小畜" |
| **领域定义** | **力量不足时的积累与克制期**。资源不够但必须蓄力、条件未成熟但已在准备、小团队面对大势、以柔性手段影响强势方。凡是"我现在还不够，但正在攒"，都落在小畜卦。 |
| **与屯卦的区别（重要）** | **屯卦是"从零开始扎根"**——完全没有根基；**小畜卦是"已有实力但被压制/条件不足"**——你是五阳（乾），有刚健之力，但被一阴畜止，蓄而未发。**屯是没有，小畜是有而不得发。** |
| **"畜"字义** | 积蓄、畜养、畜止（约束）。**"小"字定性了本卦的天花板：这种积累是有限的、这种约束是不牢固的。** |
| **卦辞原文** | 小畜：亨。密云不雨，自我西郊。 |
| **⚠️ 卦辞的关键特征** | **只有"亨"，无元、无利、无贞。** 且给出的意象是"密云不雨"——**它明确告诉你：现在还成不了事。** |
| **卦辞现代解** | **亨**——路是通的，方向没错。<br>**密云不雨**（全卦最重要的意象）——**浓云已经积满，但雨还下不来**。这是"蓄而未发"的完美写照：条件在积累，能量在聚集，**但临界点还没到**。<br>**自我西郊**——云从西郊而来。西为阴方，云气自阴方来而阳气不应，故不成雨。**深意：动力方向不对，或者说主客双方还没有真正合上。** |
| **与屯卦"云雷屯"的对照** | 屯卦大象是"**云雷屯**"——雷雨已备而将下未下，是**初生的将成之势**；小畜是"**密云不雨**"——**云满了但下不来，是被畜止的未成之势**。同为"未下的雨"，屯是时候未到，小畜是力量不够。 |
| **彖传** | 小畜，柔得位而上下应之，曰小畜。健而巽，刚中而志行，乃亨。密云不雨，尚往也。自我西郊，施未行也。 |
| **彖传要点** | **柔得位而上下应之**——六四这个阴爻当位，上下五阳都与它相应，所以叫"小畜"。**健而巽**——下乾健、上巽顺：**内里刚健，外表柔顺**。**刚中而志行，乃亨**——九二、九五刚而得中，志向能行，所以"亨"。**施未行也**——**恩施还没能推行**：不是不行，是还没到时候。 |
| **大象传（行动纲领）** | 风行天上，小畜。君子以懿文德。 |
| **"懿文德"解（本卦最实用的一条）** | 风行天上，还未落到地面成事——**此时君子应当"懿文德"：修养美好的文采与德行。**<br>**深意：当外部条件不允许你建功立业时，正确的动作是向内修德修文、提升自身，而不是硬要出手。** 这是"密云不雨"期唯一正确的作业。 |
| **总铁律** | ① **蓄力期的正业是修己（懿文德），不是硬发**；② **以柔制刚只能"小畜"，不要指望靠柔性手段长期压住刚健之力**（九三"夫妻反目"就是崩盘）；③ **蓄满之后（上九）反而最危险**——"月几望，君子征凶"。 |

## 二、爻级字段

### 初九 · 复自道

| 字段 | 内容 |
|---|---|
| **爻辞** | 复自道，何其咎，吉。 |
| **象传** | 复自道，其义吉也。 |
| **位属性** | 阳爻居阳位，**当位**；居全卦之始，距畜止者（六四）尚远。 |
| **判词 → 行动语义** | 吉 → **回到自己的正道上**。 |
| **爻义** | **复**＝返回；**自道**＝自己本来的道路。**回归自己的正道，有什么灾咎呢？吉。** |
| **本爻精髓** | 在被畜止、蓄而未发的处境里，**最初的、也是最正确的动作是"复自道"——回到自己该走的路上，不因外部压制而改变方向。** 象传"其义吉也"：**在道义上就是吉的**，不需要看结果。 |
| **识别信号** | ① 你被压制、蓄而未发；② 你开始怀疑自己的方向，或想换条路走；③ 你有条件回到本业上。 |
| **该做** | 确认并回到自己的正道；把"密云不雨"当成修己的时间，而不是转向的理由。 |
| **不该做** | 因为一时不得发就改弦易辙。 |
| **与乾初九呼应** | 乾初九"潜龙勿用，阳在下也"——核心在"潜"不在"勿"。**小畜初九"复自道"是同一阶段的另一角度：潜的时候要潜在自己的道上。** |

---

### 九二 · 牵复

| 字段 | 内容 |
|---|---|
| **爻辞** | 牵复，吉。 |
| **象传** | 牵复在中，亦无咎也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**。 |
| **判词 → 行动语义** | 吉 → **带着人一起回到正道**。 |
| **爻义** | **牵**＝牵引、带领。**牵复**＝**牵引着（初九等）一同返回正道**。 |
| **本爻与初九的递进关系（重要）** | **初九是"自己回来"，九二是"带着人一起回来"。** 九二得中、居下卦之中，是"干事核心与基层枢纽"（本库爻位通则），**所以它的责任不只是自己不走偏，还要把队伍带回正轨。** |
| **识别信号** | ① 你是团队里的骨干或实际带头人；② 大家在压制期有些散、有些动摇；③ 你自己方向是清楚的。 |
| **该做** | 把队伍牵回来。象传"牵复在中"——**因为得中，所以有资格也有能力做这件事。** |
| **与师九二呼应** | 师九二"在师中吉"，也是不当位而得中、是下卦之中的实际承担者。**两卦的九二都在说：位置不正不要紧，得中就有担当的资格。** |

### 九三 · 舆说辐

| 字段 | 内容 |
|---|---|
| **爻辞** | 舆说辐，夫妻反目。 |
| **象传** | 夫妻反目，不能正室也。 |
| **位属性** | 阳爻居阳位（当位），但居下卦之顶、**紧贴六四**——与畜止者直接冲撞。 |
| **判词 → 行动语义** | （无判词，象直断"不能正室"） → **硬顶必崩**。 |
| **爻义** | **舆说辐**："说"通"脱"，**车厢脱离了辐条/车轴——车坏了、走不动了**。<br>**夫妻反目**＝九三（阳）与六四（阴）直接冲突，本该相合却反目成仇。 |
| **本爻精髓（小畜卦的崩盘点）** | 九三是**唯一与六四直接接触的阳爻**，也是全卦冲突最激烈的一爻。**它当位、刚健、又居下卦之顶，最想突破畜止——但正因如此，它撞得最狠：车毁了，关系裂了。**<br>象传"**不能正室也**"：连自己的内部关系都摆不平。**深意：在蓄力未成期硬要突破，第一个坏掉的不是外部阻力，是你自己的内部结构和关系。** |
| **识别信号（诊断清单）** | ① 你实力最足、最不甘心被压；② 你和那个"约束你的因素/人"正面冲突了；③ 你的车已经在坏了——内部关系紧张、协作破裂、班子不和。 |
| **该做** | 退回九二的"牵复"，或转向六四的"血去惕出"路径。**不要在这一爻上硬耗。** |
| **不该做** | 与畜止者硬顶。**"以柔制刚"虽然只是"小畜"，但你硬碰它，坏的是你的车。** |
| **与乾九三的强烈对照** | 乾九三"终日乾乾，夕惕若，厉，无咎"——**当位、可长留、只要警惕就不翻车**；小畜九三**同样当位，却直接"舆说辐、夫妻反目"**。<br>**差别在于：乾卦是纯阳自主，九三上面还有路；小畜九三上面顶着六四这个畜止者，硬冲无路。同一个爻位，卦境不同，结论相反——这是"必须先定卦，再定爻"的最好证明。** |

### 六四 · 血去惕出（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 血去惕出，无咎。<br>⚠️ **版本待核（本轮标记）**：诸通行本多作「**有孚**，血去惕出，无咎」，本卡原文缺「有孚」二字；亦有断作「有孚血去，惕出无咎」者。**本处关系到全库「孚」字统计，请优先核底本。** |
| **象传** | 血去惕出，上合志也。<br>⚠️ **版本待核（本轮标记）**：通行本小象多作「**有孚惕出**，上合志也」，**不含「血去」**——小象与爻辞用字不一致是本处的著名疑点，建议核底本。 |
| **位属性** | 阴爻居阴位，**当位**；**全卦唯一阴爻**——**卦主**，是那个"畜止五阳"的力量。 |
| **判词 → 行动语义** | 无咎 → **化解流血、脱离恐惧，靠向上合志**。 |
| **爻义** | **血去**＝流血的局面消除了（承接九三的"夫妻反目"）；**惕出**＝从惊惧中脱出。 |
| **本爻精髓（一阴制五阳的生存之道）** | 六四以一柔畜止五刚，本是极危险的位置（九三刚撞过来）。**它凭什么"无咎"？** 象传给了答案：**"上合志也"——它向上与九五合志。**<br>**深意：柔弱者能约束强者，靠的绝不是自己的力量，而是与更高层的核心（九五）意志相合。** 一旦失去这个支撑，六四立刻危险。 |
| **识别信号（若你是六四）** | ① 你处在"以弱制强"的位置——权小责重、要管住比你强的人/因素；② 刚刚经历过一次正面冲突；③ 你唯一的凭仗是上级的支持。 |
| **该做** | ① 先化解冲突（血去）；② 稳住自己（惕出）；③ **最关键：确保与九五"合志"**——你的合法性来自上面，不来自你自己。 |
| **不该做** | 以为自己真有能力压住五阳。**"小畜"的"小"就是在提醒你：这个约束是有限的、暂时的。** |
| **与坤六四"括囊"呼应** | 坤六四"括囊，无咎无誉"，象传"慎不害也"——近君之位，慎则不害。**小畜六四同样当位、同样"无咎"，同样靠的是与上位的关系而非自身力量。** |

### 九五 · 有孚挛如

| 字段 | 内容 |
|---|---|
| **爻辞** | 有孚挛如，富以其邻。 |
| **象传** | 有孚挛如，不独富也。 |
| **位属性** | 阳爻居阳位，**当位**且**得中**，居尊位。 |
| **判词 → 行动语义** | （无判词，纯正面陈述） → **以诚相系，与邻共富**。 |
| **爻义** | **孚**＝中信、诚信；**挛如**＝紧密相连、牵系不断。**富以其邻**＝**把富裕带给邻居/与近者共富**。 |
| **本爻精髓** | 象传直接点破：**"不独富也"——不独占财富。**<br>这是九五在蓄力期的正确姿态：**你是核心，你有资源，但你要用诚信把大家系在一起（挛如），并且让邻近者一同受益（富以其邻）。** |
| **与需九五、师上六完全同构（重要）** | **需九五**"需于酒食，贞吉"——上岸后要**分享利益**给风雨同舟的兄弟（三大陷阱之二就是"贪功独占"）；<br>**师上六**"大君有命，开国承家"——战后要**公正论功封赏**；<br>**小畜九五**"富以其邻"，象传"不独富也"。<br>**三处指向同一条铁律：核心位置者必须分享，不可独占。** 这可以在产品里做成一个跨卦聚合主题。 |
| **识别信号** | ① 你是这个局面的核心，掌握主要资源；② 周围有一批与你紧密相关的人；③ 你面临"独占还是分享"的选择。 |
| **该做** | 以诚信维系关系网（挛如）；主动让邻近者受益（富以其邻）。 |
| **不该做** | 独富。参照需卦上六——独占的结果是"入于穴，有不速之客三人来"。 |

### 上九 · 既雨既处

| 字段 | 内容 |
|---|---|
| **爻辞** | 既雨既处，尚德载，妇贞厉。月几望，君子征凶。 |
| **象传** | 既雨既处，德积载也。君子征凶，有所疑也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终——**蓄积已满之时**。 |
| **判词 → 行动语义** | 妇贞厉 / 君子征凶 → **蓄满即止，绝不可动**。 |
| **爻义（逐句）** | **既雨既处**＝雨终于下了、也停住了——**"密云不雨"的局面结束了，蓄积完成了**。象传"**德积载也**"：德已积累到满载。<br>**尚德载**＝崇尚德行的积载，此为正面。<br>**妇贞厉**＝"妇"指六四那个柔顺者，它若继续坚持畜止之道就危险了——**约束已经完成任务，再继续约束就是危险**。<br>**月几望**＝月亮将满未满（**几望即近满**）。这是全卦最精妙的意象：**满了，但还没圆——已到极限，再进一步就要亏。**<br>**君子征凶**＝此时君子若出征、若有所行动，**凶**。象传"**有所疑也**"：因为前路仍有疑虑未明。 |
| **本爻精髓（最反直觉的一条）** | **常人的逻辑是"蓄满了就该发"，但小畜上九明确说：蓄满之时恰恰是"君子征凶"。**<br>原因：① 这只是"**小**畜"——积累的量级本来就有限，不足以支撑大动作；② "月几望"——**盈满即将转亏，此时动就是逆势**；③ "有所疑也"——**前路条件尚未明朗**。 |
| **与乾上九、坤上六的对照** | 乾上九"亢龙有悔，盈不可久也"、坤上六"龙战于野"——**都是盈极而凶**。<br>**小畜上九更进一层：它甚至不是"已经过头了"，而是"刚刚满、还没圆"就已经"征凶"。** 这说明：**在小畜这种"力量本就有限"的卦境里，安全边界比常态更窄。** |
| **与屯九五的强烈呼应（最实用的一条）** | 屯九五"屯其膏，**小贞吉，大贞凶**"——刚有积累就大举扩张必凶。<br>**小畜上九"月几望，君子征凶"是同一条铁律的另一种表述：积累到临界点时，最大的诱惑就是出手，而这恰恰是最凶的时刻。**<br>**⚠️ 2026-09-05 修正（RULE-012 全样本核查）**：此处原写"凡卦名带'小'、凡处于积累期，'蓄满即发'都是陷阱"。**后半句已核实不成立，现予撤销。**<br>**全样本**：蓄养类五卦（小畜9・大畜26・颐27・升46・井48）的上爻判词——**负面仅 1/5**（只有小畜上九"征凶"）。**反例三条**：大畜上九"何天之衢，**亨**"（象"道大行也"，见 `知识卡26`：**大畜的顶不是物极必反，是路开了**）；井上六"井收勿幕，有孚**元吉**"；颐上九"由颐，**厉吉**"。升上六**无判词**。<br>**现在的口径（限定域）**：**"蓄满即发是陷阱"是小畜专属，不是积累期通则。** 分界见 `知识卡00` §G 路由表原话：**压住你的是一阵风 → 小畜（蓄满即凶）；是一座山 → 大畜（蓄足则通）。**<br>**仍然成立的部分**：屯九五↔小畜上九这一对**是 2/2**——**但它们的共同点是"量级本就有限"（屯"小贞吉，大贞凶"／小畜之"小"），不是"处在积累期"。** |
| **该做** | 承认这只是"小畜"；受住"蓄满了该发"的冲动；等条件明朗（解"有所疑"）再说。 |

## 三、小畜卦定位速查表

| 爻 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|
| 初九 | 复自道 | 被压制，开始怀疑方向 | 当位 | **吉**·回到自己的正道 |
| 九二 | 牵复 | 你是骨干，队伍有些散 | 不当位但**得中** | **吉**·带着人一起回正轨 |
| 九三 | 舆说辐 | 实力最足、最不甘，正面顶上了 | 当位但撞六四 | **车毁·反目**·硬顶必崩 |
| 六四 | **血去惕出（卦主）** | 你在以弱制强，刚经历冲突 | 当位 | **无咎**·化解+上合志 |
| 九五 | 有孚挛如 | 你是核心，掌握资源 | **当位·得中** | 富以其邻·**不独富** |
| 上九 | 既雨既处 | 终于蓄满了，想出手 | 不当位·盈极 | **君子征凶**·蓄满即止 |

**小畜卦四句话**：
1. **蓄力期的正业是"懿文德"**——修己，不是硬发。
2. **别在九三硬顶**——你顶坏的是自己的车和自己的班子。
3. **以柔制刚靠的是"上合志"**——柔弱者的合法性来自更高层，不来自自身。
4. **蓄满之时最凶**——"月几望，君子征凶"，与屯九五"大贞凶"同理。

**一条方法论上的重要发现**：
**乾九三与小畜九三同为"阳爻居阳位、当位、居下卦之顶"，但结论完全相反**——乾九三"厉，无咎"且可长留，小畜九三"舆说辐、夫妻反目"直接崩盘。
**差别只在于：上面顶着什么。** 这证明本库"三步定位法"的顺序不可颠倒：**必须先定卦（外部环境是什么），再定爻（我在第几阶段）。同一个爻位，卦境不同，吉凶可以完全相反。**
