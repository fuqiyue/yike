# 知识卡 10 · 履卦（天泽履）

> ⚠️ **来源标注**：经文层出自《周易》原文；义理层为按本库框架的推演，**待校**。
> 序卦传："物畜然后有礼，故受之以履。"——有了积蓄，就要讲规矩、讲分寸。
> **本卦是全书讲"如何在危险的等级结构中安全行走"的专卦，核心意象是"履虎尾"。**

---

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 履 · 第十卦 |
| **卦象** | 上乾（天）下兑（泽），称"天泽履"。**一阴（六三）在五阳之中，以柔履刚**——踩在老虎尾巴上之象 |
| **领域定义** | **在等级结构中处世行事**。在强势的上级/平台/体制/大客户面前行动，与远比自己强大的对象打交道，处理上下尊卑关系。凡是"我在跟远比我强的力量共处，一步走错就出事"，都落在履卦。 |
| **"履"字义** | 践、踩、行走；引申为**践行、履历、礼制**（"履"与"礼"古音义相通）。 |
| **卦辞原文** | 履虎尾，不咥人，亨。 |
| **⚠️ 卦辞的特殊之处** | **只有"亨"，无元利贞**（与小畜同）。但它给出的是一个惊心动魄的意象：**踩在虎尾上，老虎却不咬人。** |
| **卦辞现代解** | **履虎尾**——**处境极险**：你走的这条路，等于踩在猛虎的尾巴上。<br>**不咥人**——"咥"是咬。**老虎却不咬你**——这不是运气，是因为你的方式对了（见彖传）。<br>**亨**——所以路是通的。<br>**深意：极险的处境里也有安全的走法。履卦全部内容就是讲这个"走法"。** |
| **彖传** | 履，柔履刚也。说而应乎乾，是以履虎尾，不咥人，亨。刚中正，履帝位而不疚，光明也。 |
| **彖传要点（本卦最关键的机制解释）** | **柔履刚也**——以柔踩在刚上，这是本卦的基本处境。<br>**说而应乎乾**——"说"通"悦"：**下卦兑是悦、是和顺；因为你以和悦顺应的态度对待乾（强者），所以踩了虎尾它也不咬你。**<br>**这就是"不咥人"的全部秘密：不是虎变温顺了，是你的姿态对了。**<br>**刚中正，履帝位而不疚**——九五刚健中正，居帝位而无愧疚，光明正大。 |
| **大象传（行动纲领）** | 上天下泽，履。君子以辩上下，定民志。 |
| **"辩上下，定民志"解** | 天在上、泽在下，位分明确——**君子由此分辨上下之别，安定民心之志**。<br>**深意：履卦的安全不是靠圆滑，是靠"位分清楚"。你清楚自己在哪一层、该守什么规矩，虎就不咬你。反之，位分不清就是六三的"咥人凶"。** |
| **总铁律** | ① **在强者面前的安全来自"说而应"（和悦顺应）＋位分清楚**，不是来自能力对抗；② **最凶的一爻是"以为自己能行"的六三**（眇能视、跛能履）；③ **连九五这个尊位也有"贞厉"的警告**（夬履）——**履卦里没有绝对安全的位置**。 |

## 二、爻级字段

### 初九 · 素履往

| 字段 | 内容 |
|---|---|
| **爻辞** | 素履往，无咎。 |
| **象传** | 素履之往，独行愿也。 |
| **位属性** | 阳爻居阳位，**当位**；居全卦之始，距虎尾（六三/上乾）最远。 |
| **判词 → 行动语义** | 无咎 → **朴素而行，不带附加**。 |
| **爻义** | **素**＝质朴、本色、不加修饰（如"素衣""素心"）。**素履往**＝**以朴素本色的姿态前行**。 |
| **本爻精髓** | 象传"**独行愿也**"——**独自践行自己的心愿**：不结党、不攀附、不靠包装，就以本色往前走。<br>**深意：在等级结构里，最初的安全策略是"素"——不显眼、不多余、不装饰。** |
| **识别信号** | ① 你刚进入一个层级结构（新公司、新体制、新圈子）；② 你位置最低，也最远离风险中心；③ 你有冲动想快速"表现"或"贴上去"。 |
| **该做** | 保持本色；独立践行自己认定的事；不急于攀附。 |
| **不该做** | 用包装和攀附来加速。 |
| **与坤六二"不习"呼应** | 坤六二"直方大，**不习**无不利"——不刻意模仿造作、不表演。**履初九的"素"是同一件事：真诚和本色在任何卦里都是最低成本的安全策略。** |

### 九二 · 履道坦坦

| 字段 | 内容 |
|---|---|
| **爻辞** | 履道坦坦，幽人贞吉。 |
| **象传** | 履道坦坦，中不自乱也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**。 |
| **判词 → 行动语义** | 贞吉 → **走宽路、守幽静**。 |
| **爻义** | **履道坦坦**＝所行之道平坦宽阔。**幽人**＝幽静恬淡、不慕荣利之人。**幽人贞吉**＝以这样的心态守正，则吉。 |
| **本爻精髓** | 象传"**中不自乱也**"——**因为居中，所以内心不自乱。**<br>**这是全卦最舒服的一爻**：路是平的，人是静的，心是不乱的。<br>**深意：在险境结构中，"路坦坦"不是因为外部变安全了，是因为你"中不自乱"。心不乱，路就宽。** |
| **识别信号** | ① 你在结构中站住了脚，暂时无人为难；② 你有机会去追逐更多名利，也有机会保持低调；③ 你内心是稳的还是躁的，是这一爻的分水岭。 |
| **该做** | 走大路、守本分、做"幽人"——不慕荣利，内心不乱。 |
| **不该做** | 在坦途上开始躁动、追逐、攀比。**一躁就会往六三去。** |
| **与需九二呼应** | 需九二"需于沙，小有言，终吉"，象传"衍在中也"——**因为得中，所以有余量、心态不偏激、不为小言所激怒。** 履九二"中不自乱"是完全同一个机制。**两卦九二联读，可提炼一条通则：得中之爻的价值在于"心态余量"。** |

### 六三 · 眇能视，跛能履（全卦唯一凶爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 眇能视，跛能履，履虎尾，咥人，凶。武人为于大君。 |
| **象传** | 眇能视，不足以有明也。跛能履，不足以与行也。咥人之凶，位不当也。武人为于大君，志刚也。 |
| **位属性** | 阴爻居阳位，**不当位**且失中；**全卦唯一阴爻**，处五阳之中——**它就是那个踩虎尾的人**。 |
| **判词 → 行动语义** | **凶** → **此爻不可入**。 |
| **爻义（逐句）** | **眇能视**＝一只眼瞎却自以为看得清；**跛能履**＝腿脚有残却自以为走得动。<br>**履虎尾，咥人，凶**＝**同样是踩虎尾，别人不被咬，你被咬了**。<br>**武人为于大君**＝一个武夫却想干大君的事——**才不配位而志气刚强**。 |
| **本爻精髓（履卦的核心警告）** | 卦辞说"履虎尾，**不咥人**"，六三说"履虎尾，**咥人，凶**"。**同一个动作，两个相反结果——差别在哪？**<br>象传给了三条答案：<br>① "**不足以有明也**"——你自以为看得清，其实看不清（**认知不足却自信**）；<br>② "**不足以与行也**"——你自以为走得动，其实走不了（**能力不足却行动**）；<br>③ "**位不当也**"——**位置不对**。<br>加上第四条："**志刚也**"——**才不配位而心气过刚**。<br>**结论：被虎咬的原因从来不是虎，是"眇而自以为明、跛而自以为行、位不当而志刚"。** |
| **识别信号（诊断清单，极重要）** | ① 你对局势的判断建立在不完整的信息上，但你很自信；② 你的能力不足以支撑你要做的事，但你觉得可以；③ **你所处的位置本不该做这个决定，但你做了**；④ 你的心气很刚，别人劝不动你。 |
| **该做** | **退回九二。** 承认"眇"和"跛"——**这一爻的解药是"自知"，不是"更努力"。** |
| **与需卦"敬慎不败"的对照** | 需九三"需于泥，致寇至"，象传"**敬慎不败也**"——临险时以敬畏和谨慎立于不败。**履六三恰恰是"敬慎"的反面：不敬（志刚）、不慎（自以为能）。** |
| **与师六三的呼应** | 师六三"师或舆尸，凶"，象传"大无功也"——**无能力者占了指挥位置**。**履六三"武人为于大君"是完全同一个病：才不配位。** 两卦六三皆凶，皆因此。 |

### 九四 · 履虎尾，愬愬

| 字段 | 内容 |
|---|---|
| **爻辞** | 履虎尾，愬愬，终吉。 |
| **象传** | 愬愬终吉，志行也。 |
| **位属性** | 阳爻居阴位，**不当位**；紧邻九五——**距离最高权力最近，也最危险**。 |
| **判词 → 行动语义** | 终吉 → **恐惧戒惧则终吉**。 |
| **爻义** | **愬愬**（sù sù）＝恐惧、戒慎不安的样子。**同样踩虎尾，但因为"愬愬"（心里怕、极其小心），所以终吉。** |
| **本爻精髓（与六三的对照是全卦最重要的一对）** | **六三：履虎尾 → 咥人，凶**（因为"志刚"、自以为能）<br>**九四：履虎尾 → 愬愬，终吉**（因为知道怕、极其戒慎）<br>**同一个危险动作，一个凶一个吉，差别只在"你怕不怕"。**<br>象传"**志行也**"——**正因为戒惧，志向才反而能推行。** |
| **识别信号** | ① 你紧邻最高权力/最大风险源；② 你名不正言不顺（不当位），但事情要经你的手；③ 你心里发怵。**——发怵在这一爻是好事。** |
| **该做** | 保持戒惧，把"怕"当成安全带。 |
| **不该做** | 因为离权力近而放松、自以为安全。 |
| **与乾九三"夕惕若"完全同构** | 乾九三"君子终日乾乾，**夕惕若**，厉，无咎"，"无咎"＝善补过才无灾。**履九四"愬愬"就是"夕惕若"在履卦的表述。**<br>**两处联读的产品价值：可以提炼"惕/愬"为一个跨卦的行动语义标签——"在高位/近险处，恐惧本身就是安全条件"。** |
| **与坤六四"括囊"的呼应** | 坤六四同样是近君之位、同样不显山不露水（无咎无誉），象传"**慎不害也**"。**三卦的四爻（乾九四、坤六四、履九四）都在讲同一件事：紧邻最高位是最危险的生态位，各自的解法是"跃"、"括囊"、"愬愬"。** |

### 九五 · 夬履（尊位也有警告）

| 字段 | 内容 |
|---|---|
| **爻辞** | 夬履，贞厉。 |
| **象传** | 夬履贞厉，位正当也。 |
| **位属性** | 阳爻居阳位，**当位**且**得中**，居尊位——**位置完美**。 |
| **判词 → 行动语义** | **贞厉** → **警告：过于刚决则危**。 |
| **爻义** | **夬**（guài）＝决断、果决、刚断。**夬履**＝以刚决果断的方式行事。**贞厉**＝即便守正，也有危险。 |
| **⚠️ 本爻是全库目前最反直觉的一爻** | **九五当位、得中、居尊，条件是全卦最好的，却得到"厉"（警告）。**<br>而象传的解释更耐人寻味："**位正当也**"——**正因为你位置太正当了！**<br>**深意：位置越正当，越容易变得刚决独断；越刚决独断，越危险。** 权力的正当性本身就是过度自信的来源。 |
| **对照乾九五、坤六五的差异（重要）** | **乾九五**"飞龙在天，**利见大人**"——鼎盛期仍要不断吸纳新血，象传"大人造也"；<br>**坤六五**"黄裳**元吉**"——臣至君位而守臣节，是最高吉祥；<br>**履九五**"夬履，**贞厉**"——**同样的尊位，却是警告。**<br>**差别在卦境**：乾是纯阳自主之路，坤是辅佐守节之路，**履是"在危险的等级结构中行走"——这个卦境里，连最高位也要防止刚决。** |
| **识别信号（若你是九五）** | ① 你位置正当、权力充分、决策合法；② 你倾向于快速果断地拍板、以刚决方式推行；③ 没有人能否决你。**——这就是"厉"的来源。** |
| **该做** | 在正当性最充分的时候，**主动给自己加上"不夬"的约束**：多听、慢决、留余地。参照乾九五"利见大人"、乾用九"天德不可为首"。 |
| **不该做** | 以"我是对的、我有权"为理由行刚决之事。 |

### 上九 · 视履考祥

| 字段 | 内容 |
|---|---|
| **爻辞** | 视履考祥，其旋元吉。 |
| **象传** | 元吉在上，大有庆也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终。 |
| **判词 → 行动语义** | **元吉** → **回顾全程、复盘吉凶，循环往复**。 |
| **⚠️ 本爻是全库目前第二个"上爻得元吉"的特例** | 乾上九"亢龙有悔"、坤上六"龙战于野"、屯上六"泣血涟如"、需上六"入于穴"、比上六"比之无首凶"——**前面各卦的上爻几乎都是凶或悔。而履上九却是"元吉"，且象传说"大有庆也"。为什么？** |
| **爻义（答案就在爻辞里）** | **视履**＝回顾自己走过的全程；**考祥**＝考察、检验其吉凶祸福；**其旋**＝"旋"是回旋、循环、周而复始。<br>**因为它不是"走到尽头就停了"，而是"回顾—检验—重新开始"——它把终点变成了新的起点。** |
| **本爻精髓（本卦最高智慧）** | **履卦不以"到达"为终点，以"复盘并重来"为终点。**<br>**深意：在危险的等级结构中行走，唯一能得"元吉"的方式，是走完之后回头审视全程、检验得失、然后重新开始——而不是认为自己已经走完了。** |
| **与乾用九"群龙无首"呼应（重要）** | 乾用九的核心是"**天道运行车而复始……天地之间本质无始无终**"，规避"亢龙有悔"的穷途，**保持生生不息的循环可能**。<br>**履上九"其旋元吉"就是这条原则在具体卦中的落地：靠"旋"（循环）避免"穷"。**<br>**两处联读可提炼一条通则：《周易》给出的终极解药从来不是"到达顶点"，而是"进入循环"。** |
| **识别信号** | ① 一个阶段/项目/任期走完了；② 你倾向于"结束了、松口气了"；③ 你还没有系统复盘过。 |
| **该做** | **视履考祥**——完整回顾走过的每一步，检验哪些对、哪些错；然后"其旋"——带着结论重新开始。 |
| **产品落地建议** | **这一爻可以直接做成产品的"复盘功能"的理论依据**：本库大纲第六部分的"追踪层"（每次定位存档、定期复盘），**其经典出处就是履上九"视履考祥，其旋元吉"。** |

## 三、履卦定位速查表

| 爻 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|
| 初九 | 素履往 | 刚进入结构，位置最低 | 当位 | **无咎**·本色而行·不攀附 |
| 九二 | 履道坦坦 | 站住脚了，路暂时是平的 | 不当位但**得中** | **贞吉**·幽人·中不自乱 |
| 六三 | 眇能视，跛能履 | 认知/能力/位置都不够，却很自信 | 不当位·失中 | **咥人·凶**·不可入 |
| 九四 | 履虎尾，愬愬 | 紧邻最高权力，心里发怵 | 不当位·近君 | **终吉**·愬愬·怕就是安全带 |
| 九五 | 夬履 | 位置最正当、权力最充分 | **当位·得中** | **贞厉**·警告：勿刚决 |
| 上九 | 视履考祥 | 一个阶段走完了 | 不当位·卦终 | **元吉**·复盘+重新开始 |

**履卦五句话**：
1. **"履虎尾而不咥人"的秘密是"说而应"**——以和悦顺应的姿态对待强者，不是靠对抗。
2. **安全靠"辩上下"**——位分清楚，虎就不咬。
3. **六三与九四是全卦最重要的一对照**：同踩虎尾，**自以为能则凶，知道怕则吉**。
4. **九五"位正当也"反而是"厉"的原因**——正当性是过度自信的来源。
5. **上九"其旋元吉"**——履卦的圆满不在到达，在复盘后重新开始。

**跨卦标签（可入产品的通用语义）**：
- **「惕/愬」**＝在高位或近险处，恐惧本身即安全条件（乾九三、履九四、屯彖传"而不宁"）。
- **「才不配位」**＝师六三、履六三皆凶之共同病根。
- **「旋/复始」**＝乾用九、履上九共同给出的终极解药：进入循环，而非到达顶点。
