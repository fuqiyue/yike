# 知识卡 11–12 · 泰卦（地天泰）与否卦（天地否）

> ⚠️ **来源标注**：经文层出自《周易》原文；义理层为按本库框架的推演，**待校**。
> 序卦传："履而泰，然后安，故受之以泰。泰者，通也。物不可以终通，故受之以否。"
> **这两卦是《周易》最经典的一对反卦（上下完全颠倒），必须合卡对照，单独看必失其义。**

---

## 零、为什么合成一张卡

| 对照项 | 泰（第11卦） | 否（第12卦） |
|---|---|---|
| 卦象 | 上坤（地）下乾（天） | 上乾（天）下坤（地） |
| 直觉 | "天在下、地在上"——**看起来颠倒** | "天在上、地在下"——**看起来正常** |
| 实际定性 | **吉、亨（顺境）** | **不利君子贞（逆境）** |
| 机制 | **天气上升、地气下降 → 二气相交 → 通** | 天气上升、地气下降 → **二气背离 → 不交 → 塞** |
| 卦辞 | 小往大来，吉，亨 | 否之匪人，不利君子贞，大往小来 |
| 大象传 | 天地交，泰 | 天地不交，否 |

**这一对卦给出的核心方法论（本库最重要的一条通则之一）**：
**"看起来正常"的不一定是好的，"看起来颠倒"的不一定是坏的。判断吉凶的唯一标准是"交不交"——上下是否真实沟通、能量是否真实流动。**

产品落地：**定域问诊时不要问"你现在顺不顺"，要问"上下通不通、信息和资源流不流动"。**

# 第一部分 · 泰卦（第 11 卦）

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦象** | 上坤下乾，"地天泰"。**三阴在上、三阳在下**，阴阳各半而相交 |
| **领域定义** | **顺境、通达期、上下和谐期**。事业上升期、组织氛围好、政令畅通、家庭和睦、市场向好。凡是"现在挺顺、上下通气"，都落在泰卦。 |
| **卦辞原文** | 泰：小往大来，吉，亨。 |
| **卦辞解** | **小往大来**——"小"（阴）往外去，"大"（阳）到内来：**实质性的力量在向自己聚集**。故吉、亨。 |
| **彖传** | 泰，小往大来，吉亨。则是天地交而万物通也，上下交而其志同也。内阳而外阴，内健而外顺，内君子而外小人，君子道长，小人道消也。 |
| **彖传要点** | **天地交而万物通**、**上下交而其志同**——泰的本质是"交"。<br>**内阳外阴、内健外顺**——内里刚健、外表柔顺（与小畜彖传"健而巽"同一句式）。<br>**君子道长，小人道消**。 |
| **大象传** | 天地交，泰。后以财成天地之道，辅相天地之宜，以左右民。 |
| **大象传解（本卦最实用一条）** | "财"通"裁"。**裁成天地之道、辅相天地之宜**——**顺境中的正确动作是"裁"和"辅"：顺应大势去修剪、调节、辅助，而不是坐享其成。** 顺境不是躺平期，是治理期。 |
| **总铁律** | ① **泰的本质是"交"，维护顺境就是维护"上下交"这条通道**；② 全卦最重的一句警告在九三："**无平不陂，无往不复**"——**顺境必转，从一开始就要有这个预期**；③ **上六"城复于隍"是顺境崩塌的终点**，且解法只有"自邑告命"。 |

## 二、泰卦爻级字段

### 初九 · 拔茅茹
| 字段 | 内容 |
|---|---|
| **爻辞** | 拔茅茹，以其汇，征吉。 |
| **象传** | 拔茅征吉，志在外也。 |
| **位属性** | 阳爻居阳位，**当位**；顺境之始。 |
| **判词 → 行动语义** | 征吉 → **带着同类一起行动**。 |
| **爻义** | **茅茹**＝茅草的根须；**汇**＝类、同类。拔一根茅草，根须相连、同类一并带起——**顺境开始时，正确的动作是带着一群人一起走，不是单干**。象传"志在外也"：志向朝外、朝上，有所作为。 |
| **注意** | **否卦初六爻辞几乎完全相同（"拔茅茹，以其汇，贞吉，亨"），但语义相反**——见否卦部分对照。 |

### 九二 · 包荒
| 字段 | 内容 |
|---|---|
| **爻辞** | 包荒，用冯河，不遐遗，朋亡，得尚于中行。 |
| **象传** | 包荒，得尚于中行，以光大也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**——顺境中的干事核心。 |
| **判词 → 行动语义** | 得尚于中行 → **包容+果决+不徇私**。 |
| **爻义（四个动作）** | **包荒**＝包容荒秽、容得下不完美的人和事（**顺境中的第一要务是容量**）；**用冯河**＝"冯"通"凭"，徒步涉河——**有果决涉险的行动力**；**不遐遗**＝远处的人也不遗漏，**不因距离远近而偏心**；**朋亡**＝**舍弃私党、不结朋党**（与坤卦"东北丧朋，乃终有庆"、比卦"外比于贤"完全同构）。<br>四者齐备，才"得尚于中行"——符合中道。 |
| **本爻精髓** | **顺境最容易滋生的病是"结党"和"偏私"。九二给出的解药是"朋亡"——主动放弃自己的小圈子。** |

### 九三 · 无平不陂（全卦最重的警告）
| 字段 | 内容 |
|---|---|
| **爻辞** | 无平不陂，无往不复，艰贞无咎。勿恤其孚，于食有福。 |
| **象传** | 无往不复，天地际也。 |
| **位属性** | 阳爻居阳位，**当位**；居下卦之顶——**阳的极限，即将交入阴的领域**。 |
| **判词 → 行动语义** | 艰贞无咎 → **在最顺的时候预知会转，守正于艰难**。 |
| **爻义** | **无平不陂**＝没有永远平坦而不倾斜的；**无往不复**＝没有一直往前而不返回的。象传"**天地际也**"——**你正处在天地交界处，就是转折点上。**<br>**艰贞无咎**＝在艰难中守正，才无灾。**勿恤其孚，于食有福**＝不必忧虑自己的诚信不被认可，在饮食（安身养命）上自有福分。 |
| **⚠️ 本爻是泰卦的灵魂，也是全库最重要的一条通则** | **"无平不陂，无往不复"是《周易》对"顺境必转"最直白的表述。**<br>它出现的位置极有讲究：**不在上六（崩塌时），而在九三（还很顺的时候）。**<br>**深意：对顺境将转的预判，必须在顺境的顶点就建立，而不是等崩塌了才明白。** |
| **与乾九三、坤初六的三处联读（可入产品）** | **乾九三**"终日乾乾，夕惕若"——中层要日夜警惕；<br>**坤初六**"履霜，坚冰至"——见微知著，趋势预警；<br>**泰九三**"无平不陂，无往不复"——顺境必转。<br>**三条共同构成本库的"趋势预警"标签组。** |

### 六四 · 翩翩不富
| 字段 | 内容 |
|---|---|
| **爻辞** | 翩翩不富，以其邻，不戒以孚。 |
| **象传** | 翩翩不富，皆失实也。不戒以孚，中心愿也。 |
| **位属性** | 阴爻居阴位，**当位**；已入上卦。 |
| **判词 → 行动语义** | 不戒以孚 → **不靠戒备、靠诚信**。 |
| **爻义** | **翩翩**＝轻快下降之貌（阴气下交）；**不富**＝不以财富自恃，象传"皆失实也"——**阴爻本虚，不实在**。**以其邻**＝与邻近者一同；**不戒以孚**＝**不需要戒备提防，凭的是诚信**，象传"中心愿也"——出于内心的意愿。 |
| **与比九五"邑人不诫"完全同构** | 比九五"**邑人不诫**，吉"，象传"上使中也"——**上位者行事居中，下面就不必戒备**。<br>泰六四"**不戒以孚**"，象传"中心愿也"。<br>**两处联读：真正好的关系状态是"不需要提防"，且这来自诚信与居中，不来自控制。** |

### 六五 · 帝乙归妹
| 字段 | 内容 |
|---|---|
| **爻辞** | 帝乙归妹，以祉元吉。 |
| **象传** | 以祉元吉，中以行愿也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位。 |
| **判词 → 行动语义** | **元吉** → **居尊而下嫁、主动向下结合**。 |
| **爻义** | **帝乙归妹**＝商王帝乙把女儿嫁出去（"归妹"即嫁女）。**以祉**＝因此获福。 |
| **本爻精髓** | **居尊位者主动"下嫁"——放下身段与下位者结合，故得元吉。** 象传"中以行愿也"：因为得中，所以能践行心愿。 |
| **⚠️ 这是全库第四处"尊位放下身段得元吉"的实例（极重要的跨卦模式）** | **乾九五**"飞龙在天，**利见大人**"——鼎盛仍需吸纳新血；<br>**坤六五**"黄裳**元吉**"——臣至君位而守臣节；<br>**蒙六五**"童蒙，**吉**"——居尊而以赤子之心求教；<br>**比九五**"显比……失前禽"——不强求归附；<br>**泰六五**"帝乙归妹，以祉**元吉**"——居尊而主动下嫁。<br>**五处指向同一条铁律：五爻（尊位）的吉，全部来自"向下、向外、放下身段"，没有一处来自"向上、独占、刚决"。**<br>（反证：**履九五"夬履，贞厉"**——正是因为刚决独断而得警告。）<br>**这一组可以做成产品里最有说服力的一个专题页。** |

### 上六 · 城复于隍
| 字段 | 内容 |
|---|---|
| **爻辞** | 城复于隍，勿用师。自邑告命，贞吉。 |
| **象传** | 城复于隍，其命乱也。 |
| **位属性** | 阴爻居阴位（当位），居泰卦之终——**顺境终结之时**。 |
| **判词 → 行动语义** | 勿用师 / 自邑告命 → **不可动武，只能自内整肃**。 |
| **爻义** | **城复于隍**＝城墙倾覆坍回护城的干壕里——**建成的秩序垮了**。象传"**其命乱也**"：政令已乱。<br>**勿用师**＝**此时绝不可动用武力**（对照师卦：矛盾升级为战争在此是死路）。<br>**自邑告命**＝从自己的城邑内部发布命令、整肃自身。**贞吉**＝守正则吉。 |
| **本爻精髓（顺境崩塌时的唯一活路）** | **顺境崩塌时，向外用武是错的，唯一的活路是"自邑告命"——回到内部，从自己这里重建秩序。**<br>这与讼卦"作事谋始"、师卦"容民畜众"是同一逻辑：**外部秩序垮了，只能靠内部根基重建。** |

# 第二部分 · 否卦（第 12 卦）

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦象** | 上乾下坤，"天地否"。**三阳在上、三阴在下**，各趋其位而不相交 |
| **领域定义** | **逆境、闭塞期、上下不通期**。事业停滞、组织板结、政令不通、小人得势、正道难行。凡是"上下不通气、正事做不动"，都落在否卦。 |
| **卦辞原文** | 否：否之匪人，不利君子贞，大往小来。 |
| **卦辞解** | **否之匪人**——闭塞之世不是"人"该处的境地（"匪人"＝非其人/不当之人，与比六三"比之匪人"同一用法）。<br>**不利君子贞**——**在这种环境里，君子守正是"不利"的**（不是不该守正，而是守正得不到好处）。<br>**大往小来**——"大"（阳）往外去，"小"（阴）到内来：**实质性力量在流失。** |
| **⚠️ 卦辞里的一句狠话** | **"不利君子贞"是《周易》里少见的、直接承认"守正没有好处"的表述。** 它不欺骗你，而是告诉你：**在否的环境里，不要期待守正能换来回报；守正是为了不失自己，不是为了得利。** |
| **彖传** | 否之匪人，不利君子贞，大往小来。则是天地不交而万物不通也，上下不交而天下无邦也。内阴而外阳，内柔而外刚，内小人而外君子。小人道长，君子道消也。 |
| **彖传要点** | **上下不交而天下无邦**——**上下不沟通，国家就不成国家。**<br>**内阴外阳、内柔外刚**——**里面虚、外面硬**（正是泰卦"内健外顺"的反面：**外强中干**）。<br>**小人道长，君子道消。** |
| **大象传** | 天地不交，否。君子以俭德辟难。 |
| **大象传解（否卦最实用的一条，堪比屯卦"经纶"）** | **"俭德辟难"——以节俭收敛之德来避开祸难。**<br>**深意：逆境中的正确动作不是奋起对抗，而是"俭"（收敛、降低消耗、缩小暴露面）以"辟难"（避开灾祸）。**<br>**这是本库"逆境作业指南"的经典出处。** |
| **总铁律** | ① **逆境的作业是"俭德辟难"**，不是硬闯；② **否卦有一条独特的"上升通道"：九四"有命"、九五"休否"、上九"倾否"——闭塞不是永恒的，而且转机来自上位者**；③ **九五"其亡其亡，系于苞桑"是全书最著名的危机意识警句。** |

## 二、否卦爻级字段

### 初六 · 拔茅茹（与泰初九的关键对照）
| 字段 | 内容 |
|---|---|
| **爻辞** | 拔茅茹，以其汇，贞吉，亨。 |
| **象传** | 拔茅贞吉，志在君也。 |
| **位属性** | 阴爻居阳位，**不当位**；逆境之始。 |
| **判词 → 行动语义** | 贞吉，亨 → **带着同类一起守正**。 |
| **⚠️ 与泰初九的对照（本卦最精彩的设计）** | **泰初九**："拔茅茹，以其汇，**征吉**"，象传"**志在外也**"——**顺境之始要"征"（出去做事），志向朝外。**<br>**否初六**："拔茅茹，以其汇，**贞吉，亨**"，象传"**志在君也**"——**逆境之始要"贞"（守正），志向朝着君（守住忠贞与内在方向）。**<br>**同样的动作（带着同类），顺境用"征"，逆境用"贞"。这是《周易》"同象异用"的教科书级示范。**<br>**产品价值：这说明"该做什么"永远由卦境决定，不由动作本身决定。** |

### 六二 · 包承
| 字段 | 内容 |
|---|---|
| **爻辞** | 包承，小人吉，大人否亨。 |
| **象传** | 大人否亨，不乱群也。 |
| **位属性** | 阴爻居阴位，**当位**且**得中**——但在否卦中，得位得中也只能如此。 |
| **判词 → 行动语义** | 小人吉 / 大人否亨 → **同一处境，两种人两种结果**。 |
| **爻义** | **包承**＝包容承顺。<br>**小人吉**——对于小人（趋利者），此时包容承顺是吉的（能得利）。<br>**大人否亨**——**对于大人（守正者），要"否"（拒绝、不参与）才能亨。**<br>象传"**不乱群也**"：不与那一群人混同。 |
| **本爻精髓** | **否卦六二明确区分了两条路：随波逐流的人此时能得利，守正的人必须选择"不参与"。**<br>**"大人否亨"三字是逆境中最重要的行动指令：亨通的方式是"否"——说不、退出、不合污。** |
| **与蒙六三、讼六三的呼应** | 蒙六三"见金夫"是随利而动的反面教材；讼六三"食旧德"是守本分不参与争讼。**否六二"大人否亨"是这一系列"拒绝参与"的最高表述。** |

### 六三 · 包羞
| 字段 | 内容 |
|---|---|
| **爻辞** | 包羞。 |
| **象传** | 包羞，位不当也。 |
| **位属性** | 阴爻居阳位，**不当位**且失中；居下卦之顶。 |
| **判词 → 行动语义** | （无判词） → **承受羞辱**。 |
| **爻义** | **包羞**＝包藏羞辱、忍受羞耻。象传只给四个字："**位不当也**"——**因为位置不当。** |
| **本爻精髓（与比六三、师六三的写法完全一致）** | **全卦爻辞最短的一爻，只有两个字，没有判词。**<br>**比六三**"比之匪人"（四字，象传叹"不亦伤乎"）；<br>**师六三**"师或舆尸，凶"；<br>**否六三**"包羞"（二字，象传断"位不当也"）。<br>**三个六三皆因"位不当"而受最严厉的对待。本库可提炼一条通则：三爻本就"多凶"，若又不当位、又在闭塞/冲突之卦，则几乎无解——解药只在"不要来到这个位置"。** |

### 九四 · 有命无咎（转机开始）
| 字段 | 内容 |
|---|---|
| **爻辞** | 有命无咎，畴离祉。 |
| **象传** | 有命无咎，志行也。 |
| **位属性** | 阳爻居阴位，**不当位**；已入上卦，近君之位。 |
| **判词 → 行动语义** | 无咎 → **等到"命"（时机/授命）出现，转机开始**。 |
| **爻义** | **有命**＝有天命/君命降临——**时机开始出现**。**畴离祉**＝"畴"是同类，"离"通"丽"（附着），**同类都能附着获福**。<br>象传"**志行也**"——**志向可以推行了。**（与履九四象传同为"志行也"。） |
| **本爻的结构意义（否卦最重要的转折点）** | **否卦从九四开始翻转。** 前三爻（初六、六二、六三）是闭塞的煎熬期，作业是"贞"、"否"、"包羞"；**从九四起进入"有命 → 休否 → 倾否"的破局三部曲。**<br>**深意：逆境的转机不来自下面的挣扎，来自上面的"命"（时机与授权）。这也是否卦为什么强调"俭德辟难"——你要活到"有命"那一刻。** |

### 九五 · 休否（全书最著名的危机意识警句）
| 字段 | 内容 |
|---|---|
| **爻辞** | 休否，大人吉。其亡其亡，系于苞桑。 |
| **象传** | 大人之吉，位正当也。 |
| **位属性** | 阳爻居阳位，**当位**且**得中**，居尊位。 |
| **判词 → 行动语义** | 大人吉 → **止息闭塞，同时保持最高级的危机意识**。 |
| **爻义** | **休否**＝使闭塞停止、终结否的局面。**大人吉**＝对有德位者是吉的。<br>**其亡其亡，系于苞桑**——**"要亡了！要亡了！"这样念念在心，就像把国家系在丛生的桑树根上一样牢固。**（"苞桑"＝丛生的桑树，根系极深牢） |
| **⚠️ "其亡其亡，系于苞桑"是《周易》最有名的忧患警句之一** | **它的逻辑是反直觉的：正因为你时刻念着"要亡了"，所以才能牢固如系于苞桑。**<br>**危机意识本身就是稳固的来源。** |
| **与本库"惕/愬"标签组的联读（重要）** | **乾九三**"夕惕若"、**履九四**"愬愬"、**屯彖传**"宜建侯而不宁"、**否九五**"其亡其亡"。<br>**四处共同构成本库最强的一个跨卦标签：「忧患即安全」——恐惧、警惕、危机感本身就是安全条件，而非负担。**<br>**且注意：否九五是这组里唯一出现在"尊位"上的，说明地位越高，越需要"其亡其亡"。** |
| **与履九五的强烈对照** | **履九五**"夬履，**贞厉**"，象传"**位正当也**"——位置正当反而危险（因刚决）；<br>**否九五**"休否，**大人吉**"，象传"**位正当也**"——**同样的"位正当也"，一个是警告，一个是吉。**<br>**差别就在"其亡其亡"这四个字：同样正当的高位，有危机意识则吉，无危机意识而刚决则厉。** |

### 上九 · 倾否
| 字段 | 内容 |
|---|---|
| **爻辞** | 倾否，先否后喜。 |
| **象传** | 否终则倾，何可长也。 |
| **位属性** | 阳爻居阴位，**不当位**；居否卦之终。 |
| **判词 → 行动语义** | 先否后喜 → **闭塞倾覆，转为通达**。 |
| **爻义** | **倾否**＝**把"否"倾覆掉**。**先否后喜**＝先是闭塞，后来欢喜。<br>象传"**否终则倾，何可长也**"——**闭塞到了尽头必然倾覆，它怎么可能长久呢？** |
| **⚠️ 这是本库目前唯一一个"上爻由凶转吉"的卦** | 对照：乾上九"亢龙有悔"、坤上六"龙战于野"、屯上六"泣血涟如"、需上六"入于穴"、比上六"比之无首凶"、泰上六"城复于隍"——**都是由好转坏**。<br>**只有否上九是"由坏转好"。**<br>**为什么？因为否卦本身就是坏的底色——盛极必衰的另一面，就是"衰极必兴"。** |
| **本爻精髓（否卦给人的最大希望）** | **"何可长也"这四个字，在别的卦里是警告（盈不可长久），在否卦里是安慰（闭塞不可长久）。**<br>**同一句话，在顺境是刀，在逆境是药。** |
| **该做** | 在闭塞的最后阶段坚持住。**否卦全卦的作业连起来就是：贞（初六）→ 否（六二）→ 忍羞（六三）→ 等命（九四）→ 存忧患（九五）→ 待倾（上九）。** |

## 四、这一对卦给本库贡献的四条通则

1. **判断吉凶看"交不交"，不看"正不正"。** 泰卦上下颠倒却吉，否卦上下端正却塞。**问诊时问"上下通不通"，不问"看起来顺不顺"。**

2. **同一个动作，顺境用"征"、逆境用"贞"。** 泰初九与否初六爻辞几乎相同而判词不同，象传一个"志在外"、一个"志在君"。**这是"必须先定卦、再定势"的最强证据。**

3. **顺境的警告在九三（还很顺的时候），逆境的转机在九四（还很塞的时候）。** 都不在终点。**预判必须提前一步，这是《周易》给出的时间感。**

4. **"何可长也"是双刃：** 顺境中它是"盈不可久"的警告，逆境中它是"否终则倾"的希望。**同一条规律，在不同处境里给出相反的安慰——这就是本库"定卦优先"的哲学根据。**
