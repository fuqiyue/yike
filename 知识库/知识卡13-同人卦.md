# 知识卡 13 · 同人卦（天火同人）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："物不可以终否，故受之以同人。"——闭塞不可能永远持续下去。**而打破否塞的第一步不是硬闯，是"与人同"**：否卦彖传说"上下不交而天下无邦"，同人卦就是重新把人接上去。
> **本卦与大有（14）是一对反卦（覆卦）**：同人＝上乾下离，大有＝上离下乾。**两卦都只由乾＋离组成，只是上下互换**——这是本库"离在下／离在上结构律"最干净的一组实证（详见末节，逐爻验证）。
> **一句话记住这一对**：**同人＝火向上去附天，人往外走去求同；大有＝光升到天上普照，物向内聚而成有。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 同人 · 第十三卦 |
| **卦象** | 上乾（天／健）下离（火／明），称"天火同人"。**火性上炎，附天而上行**——火要往上走去与天会合，故为"与人求同"。<br>**六爻自下而上：阳、阴、阳｜阳、阳、阳。全卦唯一的阴爻是六二**，居下离之中，即彖传"柔得位得中而应乎乾"所指之爻。<br>**按本库结构律逐爻核定**：**离在下 → 下体三爻全部当位**（初九当位、六二当位且得中、九三当位）；**乾在上 → 五当位、四与上不当位**（九四不当位、九五当位且得中、上九不当位）。**全卦四当位、二不当位。** |
| **领域定义** | **与人求同、凝聚共识、建立平等的共同体**。找志同道合的人一起做事；跨部门／跨公司协同；建立行业标准、联盟、开源社区；在多元群体里把人拢到一个方向上；合伙与婚恋中的"三观是否一致"；组织的价值观建设。凡是"我要跟人达成一致、要找到同路人"，都落在同人卦。 |
| **不归本卦的情况** | ① **已经确定要归附某个核心，问的是"我跟谁站"** → **比卦（8）**。比卦彖传"比，辅也，下顺从也"，是**垂直的归附**（一阳在五，五阴来归）；同人是**水平的求同**（一阴在二，与九五遥相呼应，中间还被阻隔）。<br>② **冲突已经组织化、要动员力量去打** → **师卦（7）**。<br>③ **在强弱悬殊的等级结构里求安全通行** → **履卦（10）**。**同人讲的是"平等地找同类"，履讲的是"不平等地保安全"。** |
| **"同"字本义** | 会合、齐一。**同人＝与人同。** 注意本卦最容易误读的地方：**"同"不是"一样"，是"志同"（方向一致）。** 彖传落脚在"**通天下之志**"——同的是"志"，不是同好、同乡、同一套说法。而大象传"类族辨物"更进一步：**求同之前先要能分辨类别，不辨而同，同的是一群本来不同的人。** |
| **卦辞原文** | 同人于野，亨。利涉大川，利君子贞。 |
| **⚠️ 卦辞的关键结构** | **有亨、有利、有贞，独缺"元"。** 而且"利"字出现两次，各带一个宾语：**利涉大川**、**利君子贞**。<br>**缺"元"的含义**：求同这件事**不是开创性的**——它不给你从无到有的那一下，它只是把已经存在的人接到一起。真正的"元"要到下一卦"大有"（卦辞正是"元亨"）才出现。**序卦传的顺序在这里是有机制的：先同人（亨利贞），后大有（元亨）——先把人接通，才谈得上大。**<br>**"利涉大川"的含义**：彖传把它归给"**乾行也**"——能涉大川是因为上卦是乾（刚健），不是因为人多。**求同不能替代实力。** |
| **卦辞现代解** | **同人于野**——"野"是郊外荒原、最开阔无人处（参本库坤上六对地理层级的训解：**国都之内为国，去国百里为郊，郊外荒原为野**）。**在旷野上与人求同＝把求同的范围放到最大、最不设边界、最不偏私。这是全卦的最高标准。**<br>**亨**——如此则通。<br>**利涉大川**——可以拿去做涉险的大事（靠的是上卦乾之健）。<br>**利君子贞**——**适宜君子守正**。注意它没说"利君子"，说的是"利君子**贞**"：**求同这件事，好处只落给"守正的求同"，不落给"结党的求同"。** |
| **彖传** | 同人，柔得位得中，而应乎乾，曰同人。同人曰："同人于野，亨。利涉大川"，乾行也。文明以健，中正而应，君子正也。唯君子为能通天下之志。 |
| **彖传要点** | ① **柔得位得中，而应乎乾，曰同人**——**整卦之所以叫"同人"，全靠六二这一个阴爻**：它当位、得中，并与上卦的乾（尤其九五）相应。**"同"的支点是那个唯一的柔，不是那五个刚。**<br>② **文明以健**——下离是"文明"（明察、有条理），上乾是"健"。**先明后健：先看清楚，再使劲。** 这与小畜彖传"健而巽"、泰彖传"内健而外顺"是同一句式，但**同人是"内明而外健"——明在里面，力在外面。**<br>③ **唯君子为能通天下之志**——**只有君子做得到"通天下之志"。** 这是给"于野"下的定义：**通的是"志"，而且门槛极高。** |
| **大象传（行动纲领）** | 天与火，同人。君子以类族辨物。 |
| **"类族辨物"解** | 天与火同性上行，故为"同"。而君子从这个象里取出的动作却是**"辨"**：**类族**＝把人按类归族；**辨物**＝辨别事物的性质异同。<br>**这是本卦最反直觉的纲领：一个讲"求同"的卦，最高原则是"分辨"。** 理由在下卦离——**离＝明，明的功能就是看清区别**。<br>**操作含义**：**求同的第一步不是找共同点，是把"谁跟谁本来是一类、哪件事跟哪件事本来是两回事"分清楚。** 分不清而求同，得到的是六二的"于宗"（把自己人当成天下人）和九三的"伏戎"（把同路人当成敌人）。 |
| **总铁律** | ① **求同的范围决定成败**。卦辞的标准是"于野"，六二"于宗"就被判"**吝道也**"——**同的对象越窄，路越走越窄**。<br>② **求同之前必须"辨"**（大象传）。**不辨而同，同的是一群本来不同的人。**<br>③ **中间的阻隔必须打通，且代价必须预先接受**。九三伏戎、九四乘墉，都是挡在六二与九五之间的人；九五要"先号咷"、要"大师克"，才能"相遇"。**求同最大的敌人不是对面的人，是挡在中间想把"同"据为私有的人。** |

## 二、爻级字段

（**本卦六爻有一条明显的"距离阶梯"：门（初九）→ 宗（六二）→ ……→ 郊（上九），而卦辞的标准是"野"。** 由内到外依次是：**宗 ＜ 门 ＜ 郊 ＜ 野**。读爻时先看它站在哪一格。）

### 初九 · 同人于门

| 字段 | 内容 |
|---|---|
| **爻辞** | 同人于门，无咎。 |
| **象传** | 出门同人，又谁咎也。 |
| **位属性** | 阳爻居阳位，**当位**；居全卦之始，也是"离在下＝三爻全当位"的第一爻；距九五最远，不涉阻隔。 |
| **判词 → 行动语义** | 无咎（按本库口径：**无灾，不等于吉利**） → **走出自己的门去找人，不预设范围**。 |
| **关键词解** | **于门**＝在门口、刚出门处。**注意象传把"于门"改写成了"出门"**——它给出的是动作，不是位置：**"同人于门"的意思是"出了门就跟人求同"，而不是"在门口跟人求同"。** **又谁咎也**＝还有谁能责难你呢（反问句式，等于说"没有任何可责之处"）。 |
| **⚠️ 本爻的要点** | 全卦六爻里**只有这一爻是"无咎"且象传用反问加强**。为什么这么干净？因为**它站在"门"这一格：刚出门，还没有形成任何"宗"（圈子）**。<br>**结论：求同最安全的时刻，是你还没有圈子的时刻。** 一旦有了圈子，就要面对六二"于宗"的吝道。 |
| **识别信号** | ① 你刚要开始找同路人，还没有既定的小团体；② 你手上没有需要保护的既得关系；③ 你对"该跟谁一起做"还是开放的。 |
| **该做** | **出门。** 把接触面主动扩到自己熟人圈之外——按大象传"类族辨物"先分类，再一类一类去接。**此时的成本最低，因为你还没有需要维护的"宗"。** |
| **不该做** | 一上来就在自己熟悉的小圈子里"求同"。**那不是同人于门，是同人于宗。** |
| **与履初九、比初六的三角对照** | **履初九**"素履往，无咎"，象传"独行愿也"——**刚进入等级结构，以本色独行**；**比初六**"有孚盈缶……吉"——**刚建立关系，只有朴素诚意可拿出来**；**同人初九"出门同人，无咎"——刚开始求同，唯一的正确动作是把门打开。** 三个初爻共同印证一条：**关系类的卦，起点的作业都是"不加修饰、不预设范围"。** 区别在于履是"往上走"、比是"往上靠"、**同人是"往外走"**。 |

### 六二 · 同人于宗（⚠️ 全卦唯一阴爻、彖传的支点，却是全卦唯一的负面判词）

| 字段 | 内容 |
|---|---|
| **爻辞** | 同人于宗，吝。 |
| **象传** | 同人于宗，吝道也。 |
| **位属性** | 阴爻居阴位，**当位且得中**；**全卦唯一阴爻**，居下离之中——彖传"柔得位得中而应乎乾"就是它，**它是整卦得名"同人"的原因**。<br>**⚠️ 严格按本库乘刚定义逐爻检查：六二直接乘于初九之上，构成"乘刚"。**（此处与震卦不同，说明见末节第 3 条。） |
| **判词 → 行动语义** | **吝**（按本库口径：**路越走越窄，趋势极差**） → **把求同的范围从"宗"往外扩，否则越走越窄**。 |
| **关键词解** | **宗**＝宗族、本宗、自己那一党。**同人于宗**＝**只跟自己人求同**。**吝道**＝"这是一条越走越窄的路"（象传把"吝"直接定性成"道"，即**这不是一次失误，是一个方向**）。 |
| **⚠️ 本爻是全卦最重要的一条（彖传夸它，爻辞判它"吝"）** | **彖传把整卦的成立归功于六二**（柔得位得中而应乎乾）；**爻辞却给了全卦唯一的负面判词。** 这不是矛盾，是《周易》最锋利的一次提醒：<br>**六二有"应"——它与九五遥相呼应。而"有应"恰恰是它的陷阱**：因为有那个明确的、门当户对的、自己人的呼应对象，它就只跟这一支来往，把"同人"缩成了"同宗"。<br>**结论：条件最好的那个位置（当位＋得中＋有应）最容易犯的错，是把"我的人"当成"天下人"。** 卦辞给的标准是"于野"（最开阔），它退到了"宗"（最狭窄）。**从野到宗，是全卦最大的落差。** |
| **识别信号（诊断清单）** | ① 你的"共识"只在一个固定的小圈子里成立，出了这个圈就讲不通；② 你判断一个人可不可信，主要看他是不是"我们这边的"；③ 你有一个很强的对口关系（上级、老同学、老班底），你的资源和信息基本都走这一条线；④ 有人提出圈外的方案，你的第一反应是"他不是我们的人"。 |
| **该做** | **主动做一次"类族辨物"**：把你现在的共识对象按类列出来，看有几类；**然后强制自己去接触至少一类新的**。回到初九的动作——**出门**。 |
| **不该做** | 用"我们关系好""大家都是自己人"来替代论证。**"吝"不是灾，是趋势：它不会立刻出事，它只会让你的路一年比一年窄。** |
| **与比六二、坤六二的三爻对照（本库"二爻"专题的第一个反例）** | **坤六二**"直方大，不习无不利"，**当位得中，判"无不利"（约等于大吉）**；**比六二**"比之自内，贞吉"，象传"不自失也"，**当位得中，判"贞吉"**；**同人六二"同人于宗"，同样当位得中，判"吝"。**<br>**这是本库"二爻多誉"通则的第一个明确反例。** 差别在哪？坤六二与比六二的德是"由内而发"（直、自内）；**同人六二的病是"由内而不出"——同一份"内"，在坤卦是真诚，在同人卦是封闭。**<br>**可入库的结论：得位得中只保证"你在正确的位置上"，不保证"你朝正确的方向用力"。** |

### 九三 · 伏戎于莽

| 字段 | 内容 |
|---|---|
| **爻辞** | 伏戎于莽，升其高陵，三岁不兴。 |
| **象传** | 伏戎于莽，敌刚也。三岁不兴，安行也。 |
| **位属性** | 阳爻居阳位，**当位**（离在下之律，三爻全当位）；居下卦之顶，本库通则"**三多凶**"；**紧邻六二之上，又直面上卦三阳**。 |
| **判词 → 行动语义** | **无吉凶判词**，只给一个时间结果"三岁不兴" → **你根本发动不起来；停手，别再等三年**。 |
| **关键词解** | **戎**＝兵、军队。**莽**＝草丛。**伏戎于莽**＝把兵埋伏在草丛里。**升其高陵**＝登上高丘（察看敌情、找制高点）。**三岁不兴**＝三年都发动不起来（"兴"＝起、发动）。<br>**象传两句**：**敌刚也**＝**你的对手是刚强的**（指上卦之乾，特别是九五）；**安行也**＝"安"通"焉"，**还能怎么行动呢**（反问，等于"根本无从行动"）。 |
| **⚠️ 本爻在一个讲"求同"的卦里讲埋伏，原因必须说清** | 六二是全卦唯一的阴爻，**九三与它相邻，九五与它相应**。九三想把六二据为己有，就必须挡住九五——**于是它埋伏、它抢制高点。**<br>**这就是"同人"最真实的失败形态：不是没人愿意同，是有人想把"同"变成自己的私产。**<br>而结果是象传那四个字：**"敌刚也"——你要挡的那个人比你强。** 于是伏了三年，一次都没发动。 |
| **本爻的损失类型（按本库口径归类）** | **无判词、只有时间刻度**，与震九四"遂泥，未光也"同类：**不惨、不死，就是白费。** 唯一的损失是**三年时间和一次战机**。<br>**对照本库的时间刻度体系**：**震六二"七日得"（冲击型，短周期，会回来）｜坎上六"三岁不得，凶"（滞留型，长周期，会固化）｜同人九三"三岁不兴"（阻隔型，长周期，什么都没发生）。** 三者依次是"损失可回／损失固化／完全空转"。 |
| **识别信号** | ① 你和某个人／某个团体之间，隔着一个比你强的第三方；② 你在暗中准备、找机会、占位置，但一直没有真正动手；③ 已经过了很长时间（一年以上），局面没有任何变化；④ 你把精力主要花在"防着那个人"上，而不是花在做事上。 |
| **该做** | **承认"敌刚也"。** 把这件事从"要不要打"改成"要不要来"：**九三的解药不在爻内，在于放弃据有六二。** 具体动作是回到大象传"类族辨物"——**你要的"同"不一定只有这一个来源。** |
| **不该做** | 继续埋伏、继续等时机。**"三岁不兴"是《周易》先告诉你结果：这个局面不会因为你多等一年而改变。** |
| **与师六三、坎上六的对照** | **师六三**"师或舆尸，凶"，象传"大无功也"——**无能力者抢了指挥权，直接大败**；**坎上六**"三岁不得，凶"——**久困失道，凶**；**同人九三"三岁不兴"——有能力（阳爻当位）、有准备（伏戎、升陵），却因为对手更强而三年空转，连"凶"都没给。**<br>**三者的分野极清楚：师六三是才不配位（凶），坎上六是失道久困（凶），同人九三是才配位但方向错（无判词，只赔时间）。** |

### 九四 · 乘其墉，弗克攻

| 字段 | 内容 |
|---|---|
| **爻辞** | 乘其墉，弗克攻，吉。 |
| **象传** | 乘其墉，义弗克也。其吉，则困而反则也。 |
| **位属性** | 阳爻居阴位，**不当位**（乾在上之律：四不当位）；紧邻九五，本库通则"**四多惧**"；与九三同为挡在六二与九五之间的阻隔者。 |
| **判词 → 行动语义** | **吉** → **攻不下来就别攻了；被困住而返回法则，正是吉的来源**。 |
| **关键词解** | **乘**＝登上（此处是"登"，**不是本库术语"乘刚"**）。**墉**＝城墙。**乘其墉**＝已经登上了对方的城墙。**弗克攻**＝**攻不下来**（"克"＝能、胜）。<br>**象传两句**：**义弗克也**＝**在道义上他本就攻不下来**（不是力量不够，是"义"不在他这边）；**则困而反则也**＝**因为被困住，反而返回了"则"（法度、规则）**。 |
| **⚠️ 本爻是全卦最精妙的一处（"失败"本身是吉的来源）** | 九四已经登上城墙——**距离成功只有一步**。然后爻辞说：攻不下来。然后判词是：**吉。**<br>象传把因果写得极清楚：**① "义弗克也"——你攻不下来的真正原因不是实力，是这件事本身不义；② "困而反则"——正因为撞了墙，你才回到了规则上。**<br>**结论：在同人卦里，"抢不到"是一种恩惠。** 如果九四攻成了，它就把"同人"变成了私占；攻不成，它才有机会回到"于野"的正道上。 |
| **本爻与九三的对照（同为阻隔者，一个空转一个转吉）** | **九三**：当位，却"三岁不兴"，无判词——**它还没撞墙，所以一直在等**。<br>**九四**：不当位，却"吉"——**它撞了墙，所以醒了。**<br>**同为阻隔者，差别只在有没有真的撞上去一次。** 这也解释了为什么九四不当位反而更好：**不当位的人更早撞墙，也就更早"反则"。** |
| **识别信号** | ① 你已经非常接近拿下某个位置／某段关系／某个山头；② 你发现最后一步就是过不去；③ 你心里其实清楚这件事"于义不合"（你在抢别人的、或在把公共的变成自己的）；④ 你正在纠结要不要再加一把力。 |
| **该做** | **停在墙上，然后下来。** 把"攻不下来"当成信息而不是挫折——**它在告诉你"义弗克"。** 具体动作：**回到"则"**，即回到规则、程序、公开的标准上，把你想要的东西改成用规则去争。 |
| **不该做** | 再加一把力。**在这一爻里，成功就是灾难——攻下来，你就从"困而反则"掉回九三的"伏戎"逻辑里。** |
| **与师六四的对照（两种"不打"）** | **师六四**"师左次，无咎"，象传"未失常也"——**有实力者主动后撤扎营，判"无咎"**；**同人九四"弗克攻，吉"——想打而打不成，被迫回到法则，判"吉"。**<br>**同样是"这一仗没打"，师六四是从容的选择，只换来"无咎"；同人九四是被迫的失败，反而换来"吉"。** 差别在卦境：**师卦无元无亨无利，不打已是上限；同人卦要的是"于野"，所以一次"打不成"正好把人从"于宗"推回"于野"。** |

### 九五 · 先号咷而后笑（卦主·尊位）

| 字段 | 内容 |
|---|---|
| **爻辞** | 同人先号咷而后笑，大师克相遇。 |
| **象传** | 同人之先，以中直也。大师相遇，言相克也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位（乾在上之律：五当位）——**全卦位置最正的一爻**；与六二相应，但中间隔着九三、九四。 |
| **判词 → 行动语义** | **无吉凶判词，但给出完整过程**（号咷 → 笑 → 相遇） → **先接受痛哭，再动员全部力量打通阻隔，然后才有相遇**。 |
| **关键词解** | **号咷**（háo táo）＝放声大哭。**大师**＝大军（与师卦同字）。**克**＝战胜／能够。**大师克相遇**＝**要动用大军、战胜阻隔，才能与所同之人相遇**。<br>**象传两句**：**以中直也**＝之所以先号咷，是因为他"中且直"（居中而正直，所以被阻隔时是真的痛）；**言相克也**＝**说的正是"相克"（相战）这件事**——象传把"克"确认为"战胜"，不是"能够"。 |
| **⚠️ 本爻是全卦的收束，也是最重的一条** | 九五是全卦位置最正、条件最好的一爻，**它想要的只是与六二"相遇"（这本是它的正应）**，结果爻辞给了两个代价：<br>**① 先号咷——它要先痛哭一场**；**② 大师克——它要动用大军去打通。**<br>**结论：《周易》在这里明确否定了"求同是件温和的事"。全卦最高一爻告诉你：真正的大同，是先哭，再打，然后才笑。** |
| **"先—后"的顺序是硬性的（与震卦完全同构）** | **震卦辞**"震来虩虩（先怕），笑言哑哑（后笑）"，**震初九**"震来虩虩，**后**笑言哑哑，吉"——本库已定：**顺序颠倒就全废**（先笑后怕就掉到震上六）。<br>**同人九五"先号咷而后笑"是同一条律在本卦的落实。**<br>再加上**离六五**"出涕沱若，戚嗟若，**吉**"——**居尊位而痛哭是吉**。<br>**三处合起来是本库「忧患即安全」标签的第三种形态：乾九三是"惕"，履九四是"愬"，同人九五与离六五是"哭"。且都在最高或次高位上。** |
| **识别信号（若你是九五）** | ① 你在位置最正、最有资格拍板的地方；② 你和真正应该与你同心的那个人／那个部门／那个群体之间，隔着几层人；③ 你为这件事真的难受过（不是策略性的难受）；④ 你面前的选择是"忍着算了"还是"把全部力量调上来打通"。 |
| **该做** | **① 允许自己先号咷**——象传说这是"中直"的证据，不是软弱；**② 然后调动全部力量打通阻隔（大师克），不要用小动作试探**；③ 打通之后才是"笑"。 |
| **不该做** | 跳过号咷直接笑（假装没事，问题会留在九三九四那里）；或者只号咷不"大师克"（哭完就算了，阻隔照旧）。**两个动作缺一个，都到不了"相遇"。** |
| **与讼九五、比九五、师六五的对照（四个尊位）** | **讼九五**＝中正裁决，案结事了；**师六五**＝选对人然后放手；**比九五**＝显比、失前禽、不强求归附；**同人九五＝为了相遇而痛哭并动员大军。**<br>**⚠️ 关键差异：前三个尊位的动作都是"不用强"（本库已提炼"三个尊位都靠中正、不靠强力"）；同人九五是第一个明确"用强"的尊位。** 为什么允许？因为**它用强的对象不是要同的人，是挡在中间的人**——与谦六五"利用侵伐，征不服也"是同一条边界（详见知识卡 15）。 |

### 上九 · 同人于郊

| 字段 | 内容 |
|---|---|
| **爻辞** | 同人于郊，无悔。 |
| **象传** | 同人于郊，志未得也。 |
| **位属性** | 阳爻居阴位，**不当位**（乾在上之律：上不当位）；居全卦之终。 |
| **判词 → 行动语义** | **无悔**（⚠️ 本库判词表原未收此词，见下） → **走到了城外，没什么可后悔的；但你要知道自己并没有做成**。 |
| **关键词解** | **郊**＝去国百里之地（参本库坤上六的地理训解：**国都之内为国，去国百里为郊，郊外荒原为野**）。**同人于郊**＝**走到城外去与人求同**。**无悔**＝没有可后悔的。<br>**象传**：**志未得也**＝**志向没有实现。** |
| **⚠️ "无悔"在本库判词表中的定位（建议入库）** | 本库现有序列：无咎 ＞ 悔亡 ＞ 悔。**"无悔"与"无咎"同属"没出事"档，但更轻**：<br>**无咎**＝有咎的可能，但善补过所以没灾（需要动作）；**悔亡**＝本该有的悔恨消失了（挽回级）；**无悔＝根本没有可后悔的事，因为你没做错，也没做成。**<br>**配上象传"志未得也"，本爻的完整语义是：你走得比谁都远，你没有任何过失，你也没有达成目标。** 按本库口径，这与震九四"未光也"同属**不在吉凶十级之内**的一类：**代价只有时间与未实现的志向。** |
| **⚠️ 本爻是全卦最扎人的一条（卦辞的标准，六爻无一达到）** | 把六爻的位置排成阶梯：**六二"于宗"（最内，吝）→ 初九"于门"（刚出门，无咎）→ 上九"于郊"（去国百里，无悔）**。<br>**而卦辞的标准是"于野"——郊外的荒原，比郊还远一层。**<br>**全卦六爻，没有一爻走到"野"。走得最远的上九只到"郊"，而象传立刻补一句"志未得也"。**<br>**结论（本卦最重要的一条）：《周易》把最高标准写在卦辞里，然后用六爻老实告诉你——现实中你只能一格一格往外走，而且很可能一辈子到不了"野"。** 这不是泄气，是给尺度：**判断自己在同人卦的哪一格，比宣称自己"于野"重要得多。** |
| **识别信号** | ① 你已经把求同的范围扩得很开，超出了自己原来的圈子；② 你没有结党、没有偏私，也没什么可后悔的；③ 但你想凝聚的那个共识，其实并没有真正达成；④ 你有一种"我做对了所有事，可是没成"的感觉。 |
| **该做** | **接受"志未得"，并把它当成刻度而不是失败。** 具体动作：**继续往外走一格**（郊 → 野），同时按大象传"类族辨物"重新分类——**到了郊上还没成，通常不是走得不够远，是"类"没有分对。** |
| **不该做** | 因为"志未得"而缩回"宗"。**从郊退回宗，就是从"无悔"退回"吝"——这是全卦落差最大的一次退步。** |
| **与履上九、震九四的对照** | **履上九**"视履考祥，**其旋元吉**"，象传"大有庆也"——**走完全程之后回头复盘、重新开始，故得元吉**；**同人上九"于郊，无悔"，象传"志未得也"——走到最远处，没有过失，也没有结果。**<br>**同为上爻、同为阳爻居阴位、同样不当位，一个"元吉"一个"无悔"。差别只有一件事：履上九"旋"（进入循环、重新开始），同人上九停在了郊上。**<br>**本库"「旋／复始」"标签在这里得到反证：不"旋"的上爻，最好的结果也只是"无悔"。** |

## 三、同人卦定位速查表

| 爻 | 站在哪一格 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | **门**（刚出门） | 同人于门 | 刚开始找同路人，还没有圈子 | **当位** | **无咎**·出门·不预设范围 |
| 六二 | **宗**（最内，**卦之支点**） | 同人于宗 | 共识只在自己那一党里成立 | **当位·得中**（乘初九之刚） | **吝**·吝道也·必须往外扩 |
| 九三 | 阻隔者（下） | 伏戎于莽 | 隔着一个更强的人，暗中准备了很久 | 当位·三多凶 | **三岁不兴**·敌刚也·别再等 |
| 九四 | 阻隔者（上） | 乘其墉，弗克攻 | 最后一步过不去，心里知道于义不合 | **不当位**·近君 | **吉**·困而反则·停手即得 |
| 九五 | **正位**（卦主） | 先号咷而后笑 | 与该同心的人之间隔着几层 | **当位·得中·居尊** | 先号咷 → **大师克** → 后笑 |
| 上九 | **郊**（最远） | 同人于郊 | 范围已扩得很开，但共识没达成 | 不当位·卦终 | **无悔**·志未得也·再往外一格 |

**同人卦三句话**：
1. **求同的范围决定成败。** 卦辞给的标准是"**于野**"（最开阔），六二退到"**宗**"就被判"**吝道也**"——**同的对象越窄，路越走越窄。**
2. **求同之前先"辨"**（大象传"类族辨物"）。**离在下＝明在内：先看清谁跟谁本来是一类，再谈同。不辨而同，同的是一群本来不同的人。**
3. **真正的大同不是和气得来的。** 全卦最正的九五要"**先号咷**"、要"**大师克**"，才有"**相遇**"；而挡路的从来不是对面的人，是九三九四这种**想把"同"据为私有的中间人**。

**本卦最反直觉的两条**：
- **卦辞的标准"同人于野"，六爻中没有一爻做到。** 最远的上九只到"郊"，象传还补一句"志未得也"；而当位、得中、被彖传专门表彰为全卦支点的六二，爻辞恰恰是"于宗，**吝**"。**位置最好的那一爻，犯了全卦唯一的错。**
- **九四"弗克攻"（攻不下来）判词是"吉"。** 象传说得极直白：**"义弗克也"（本就不义所以攻不下）＋"困而反则也"（撞了墙才回到规则上）。在同人卦里，抢不到是一种恩惠。**

## 四、⚠️ 本卡对全库的意义

### 1. 与大有（14）合成本库"离在下／离在上结构律"的第一组完整实证

离卦卡（30）已立下这条律：**离（阳阴阳）在下 → 三爻全当位；在上 → 三爻全不当位。** 同人与大有是**只由乾＋离组成、上下互换**的一对，因此是这条律最干净的检验样本。**逐爻验证如下**：

| | **同人 13（上乾下离）** | **大有 14（上离下乾）** |
|---|---|---|
| **初** | 初九 阳居阳位 → **当位** | 初九 阳居阳位 → **当位** |
| **二** | 六二 阴居阴位 → **当位·得中** | 九二 阳居阴位 → **不当位**·得中 |
| **三** | 九三 阳居阳位 → **当位** | 九三 阳居阳位 → **当位** |
| **四** | 九四 阳居阴位 → **不当位** | 九四 阳居阴位 → **不当位** |
| **五** | 九五 阳居阳位 → **当位·得中** | 六五 阴居阳位 → **不当位**·得中·居尊 |
| **上** | 上九 阳居阴位 → **不当位** | 上九 阳居阴位 → **不当位** |
| **下体（离／乾）** | **离在下：初二三全部当位** ✅ | 乾在下：初三当位、二不当位 ✅ |
| **上体（乾／离）** | 乾在上：五当位、四上不当位 ✅ | **离在上：四五上全部不当位** ✅ |
| **当位合计** | **4 当位 / 2 不当位** | **2 当位 / 4 不当位** |

> **两条结构律（离在下全当位、离在上全不当位；乾在下初三当位、乾在上五当位）在这一对卦上同时精确成立，无一例外。**
> **并且这对卦证明了"上下互换"的代价是可以量化的：同一组六个爻，上下一换，当位数从 4 掉到 2。**

### 2. 由此得到的定势口径（可直接用于第三步"定势"）

> **同人（离在下）＝明德在内、名正言顺。** 下体三爻全当位——**求同的资格是你自己长出来的**。所以本卦的病不在"位不正"，而在"**方向太窄**"（六二于宗、九三伏戎）：**位置都对，力用错了方向。**
> **大有（离在上）＝光在你身外、名不正言不顺。** 上体三爻全不当位——**所有那些"多"是位置／舞台／时势给你的**。所以本卦的病不在方向，而在"**盈满**"：解药只能是减损（九四"匪其彭"、六五以柔居尊）。
>
> **一句话对读：同人要"往外扩"，大有要"往下减"。**

### 3. 对"乘刚"通则的一处必要修正（本卡的技术增量）

按本库乘刚定义（阴爻直接压在阳爻之上）**逐爻机械检查，同人六二确实乘于初九之上**。但本卦六二并没有像震六二那样"亿丧贝"。原因必须写清，否则通则会被误用：

| 卦 | 乘刚之爻 | 下方阳爻的来源 | 象传是否点名"乘刚" | 结果 |
|---|---|---|---|---|
| **震 51** | 六二 | 震之初九（**一阳在最下往上顶**） | **是**（"震来厉，乘刚也"） | 厉·亿丧贝 |
| **屯 3** | 六二 | 下震之初九（同上） | 否（本库已判为同构） | 难 |
| **同人 13** | 六二 | **离之初九（一阴丽于二阳之中，阳是夹持／承托）** | **否** | 吝（且吝的原因是"于宗"，与乘刚无关） |

> **修正后的口径**：**乘刚要真正"咬人"，取决于那个阳爻的动势，而不只是位置的上下。**
> **震把一个阳放在最底下往上顶 → 是冲击，六二／六五必受其迫（象传两次明写"乘刚也"：震六二、豫六五）。**
> **离是一阴丽于二阳之中，上下两阳是夹持与承托 → 是"丽"（附着），不是"迫"。** 所以离体内部虽有阴居阳上的形式，象传从不以"乘刚"为释（离六二、离六五、同人六二、大有六五皆如此）。
> **艮把一个阳放在最上往下压 → 其内部不制造乘刚**（艮卦卡已立）。
> **合成一条可入库的通则：乘刚的强度＝震 ＞ 巽／兑等 ＞ 离（几乎不构成迫）；判定时先看那个阳爻属于哪个三画卦、朝哪个方向用力。**

### 4. 本卦补上的机制缺口与新增标签

| 项目 | 内容 |
|---|---|
| **补的缺口** | 本库已有**比卦（8）＝垂直的归附**（一阳在五，五阴来归，"下顺从也"），此前缺**水平的求同**。**同人补上这一环**：一阴在二，与九五遥应而被阻隔。**比问"我跟谁站"，同人问"我怎么跟人达成一致"。** 两卦合起来，本库的"关系类"才完整：**归附（比）— 求同（同人）— 对抗（师）。** |
| **对照组** | ① **同人 13 ↔ 大有 14**：覆卦，求同与大有（见上）。<br>② **同人六二 ↔ 比六二 ↔ 坤六二**：三个"当位得中"的二爻，判词分别是**吝／贞吉／无不利**——**本库"二多誉"通则的第一个明确反例**。<br>③ **同人九五 ↔ 震初九／离六五**：「先负面情绪、后笑／吉」的第三例，**且顺序是硬性的**。<br>④ **同人九四 ↔ 师六四**：两种"这一仗没打"，被迫的失败（吉）反而重于从容的后撤（无咎）。 |
| **新增判词** | **无悔**——建议补入本库判词表，位于"无咎"之下、与"悔亡"分列：**无咎＝善补过才没灾（需要动作）；悔亡＝本该有的悔恨消失了（挽回级）；无悔＝根本没有可后悔的，因为既没做错也没做成。** 配"志未得也"读，属**不在吉凶十级之内**的一类。 |
| **新增标签** | **「范围尺度」**——同人独有的一条空间阶梯：**宗（吝）＜ 门（无咎）＜ 郊（无悔·志未得）＜ 野（亨，卦辞标准）**。可直接做成产品里的一把尺子：**让用户指出自己现在的"求同半径"落在哪一格。** |
| **与已有标签的合并** | 「忧患即安全」＋**同人九五"先号咷"**；「三爻多凶」＋**同人九三"三岁不兴"（但属"只赔时间"档，不是凶）**；「旋／复始」的**反证＋同人上九"于郊，无悔·志未得"（不旋的上爻，上限就是无悔）**。 |
