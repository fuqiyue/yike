# 知识卡 15 · 谦卦（地山谦）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传/系辞传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："有大者不可以盈，故受之以谦。"——**东西多了（大有），第一件事不是继续多，是不能"盈"**。谦卦紧接大有，就是给"已经有了"的人的那一课。
> **⚠️ 本卦是艮卦卡（52）明确点出的优先缺口**：艮卡末节写道"**谦 15（上坤下艮）正是坤卦（辅佐者纲领）与履卦（处世行事）之间缺失的一环**"。**本卡补上这一环：坤讲"顺承"，履讲"在强者旁边怎么走"，谦讲"你自己已经有了实力，怎么摆自己的位置"。**
> **⚠️ 本卦是《周易》里罕见的"全卦无凶"**：六爻判词依次为 **吉／贞吉／吉／无不利／无不利／利**——**无一凶、无一悔、无一吝、无一厉，且六爻全部落在"吉／无不利／利"三档之内。** 原因不是运气，是结构，详见第三、四节。
> **本卦与豫（16）是一对反卦（覆卦）**：谦（阴阴阳｜阴阴阴）倒过来读就是豫（阴阴阴｜阳阴阴）。**同样的六个爻，倒过来读，当位数从 4 掉到 2，判词从"全卦无凶"变成"开局即凶"。** 两卦必须合读。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 谦 · 第十五卦 |
| **卦象** | 上坤（地／顺）下艮（山／止），称"地山谦"。**山本高于地，却藏在地之中**——**高者自处于低，这就是"谦"的全部字面含义**。<br>**六爻自下而上：阴、阴、阳｜阴、阴、阴。全卦唯一的阳爻是九三**，居下艮之顶——**卦主**。<br>**按本库结构律逐爻核定**：**艮在下 → 初不当位、二三当位**（初六不当位、六二当位且得中、九三当位）；**坤在上 → 四上当位、五不当位**（六四当位、六五不当位但得中居尊、上六当位）。**全卦四当位、二不当位；而两个不当位的爻恰好是风险最低的初爻和有"得中"可救的五爻。**<br>**⚠️ 逐爻检查乘刚：六四直接乘于九三之上——本卦唯一的乘刚之爻，而判词是"无不利"**（本库乘刚破解的第三例，也是最好的一例，见六四）。 |
| **⚠️ 艮在下的定势含义（本卦全部义理的根）** | 本库结构律：**艮在上＝被压住不许动（有人在上面压着你）；艮在下＝止在内、知止在自己这一边。**<br>**谦卦是艮在下**：**"止"是你自己主动放在里面的，不是别人加给你的。** 所以谦不是被迫的低头，是**有能力继续、却主动把自己往下放**。<br>再加上艮卦大象传"**思不出其位**"——**谦卦的"止"具体止的是"念头越界"：不去想那些不属于你位置的东西。** |
| **领域定义** | **已经有了实力／功劳／地位之后，如何自处与如何分配**。升职之后、拿到成绩之后、成为专家之后、公司做大之后、家族兴盛之后；具体场景：**功劳该怎么摆（要不要认）、多出来的资源该怎么分、面对不服的人怎么办、怎么不被"盈"反噬、怎么在一群人里当那个"最强却最低"的人。** 凡是"我已经有了，接下来怎么摆自己的位置"，都落在谦卦。 |
| **不归本卦的情况** | ① **你还在辅佐、还没有自己的实力** → **坤卦（2）**。**坤讲"顺承"（我在别人的体系里执行），谦讲"减损"（我自己已经有了，主动往下放）。** 分界线是：**你手上有没有一份别人拿不走的功劳（九三"劳"）。**<br>② **要在强弱悬殊的等级结构里安全通行** → **履卦（10）**。**履的安全靠"辩上下、位分清楚"（外部危险）；谦的安全靠"裒多益寡"（自己主动减）。**<br>③ **要主动停下来、退出、划边界** → **艮卦（52）**。**艮是"你有能力继续，但你决定不继续"；谦是"你有能力继续，而且你继续，只是把自己放低"。** 这条分界很实用：**谦不是退出。**<br>④ **顺境本身的通与塞** → **泰否（11-12）**。 |
| **"谦"字本义** | 《说文》："謙，敬也。从言兼聲。"**本义是敬、让、不自满。**<br>**但本卦不把它当态度用。** 大象传给的是一个**可执行的动作**："**裒多益寡，称物平施**"——**把多的减下来、把少的补上去、公平分配。**<br>**引申与警告**：**不做这个动作的"谦"，只是客气。** 本卦的谦是有具体标的物的：**多出来的那部分东西。** |
| **卦辞原文** | 谦：亨，君子有终。 |
| **⚠️ 卦辞的关键结构** | **只有"亨"，无元、无利、无贞——却多出了一句全书少见的话："君子有终"。**<br>**这是《周易》卦辞里罕见的、对"结局"的直接许诺。** 对照：师卦"贞，丈人吉，无咎"（只给底线）／履卦"履虎尾，不咥人，亨"（只给通路）／艮卦"……无咎"（只给不出事）。<br>**谦卦的态度很特殊：它不许诺好处（无利），不许诺开创（无元），甚至不强调守正（无贞）——它直接许诺你一个"终"（善终、有结果）。**<br>**而且这句话在全卦重复了三次**：卦辞"君子有终"、九三爻辞"君子有终，吉"、彖传结句"君子之终也"。**《周易》很少这样重复一句话。** |
| **卦辞现代解** | **亨**——谦这条路是通的。<br>**君子有终**——**"终"不是"结束"，是"有个结局／能走到底／不半途崩掉"。** 按本库判词口径，这与"无成有终"（坤六三）里的"有终"同义：**不居功、不抢名，但事情有它的结果，而且这个结果落在你身上。**<br>**⚠️ 注意"君子"二字是限定词**：**有终的是君子，不是所有做出谦让姿态的人。** 什么是"君子"？彖传给了标准（谦尊而光、卑而不可逾），九三给了动作（劳谦），系辞传给了心法（劳而不伐，有功而不德）。 |
| **彖传** | 谦，亨。天道下济而光明，地道卑而上行。天道亏盈而益谦，地道变盈而流谦，鬼神害盈而福谦，人道恶盈而好谦。谦尊而光，卑而不可逾，君子之终也。 |
| **⚠️ 彖传要点（全书最有名的段落之一，也是"全卦无凶"的第一个理由）** | ① **天道亏盈而益谦，地道变盈而流谦，鬼神害盈而福谦，人道恶盈而好谦**——**天、地、鬼神、人，四重力量全部"恶盈而好谦"。**<br>**这是《周易》里唯一一处四重力量同时为一卦作保。** 按本库口径，**全书绝大多数"凶"的根源都是"盈"**（乾上九盈极不知止、坤上六由顺变夺、履六三志刚、否六三位不当而受羞）。**而谦从定义上就不会"盈"——它主动减。所以它在结构上排除了产生凶的主要机制。**<br>② **天道下济而光明，地道卑而上行**——**天在上却往下施，地在下却往上行。上下两边都在往对方走**（与泰卦彖传"天地交而万物通"同一机制）。<br>③ **谦尊而光，卑而不可逾**——**谦虚的人处在尊位反而更光明，处在卑位却不可被逾越。** 这八个字是本卦最实用的一句：**谦不会让你被人踩，它让你"不可逾"。** |
| **大象传（行动纲领）** | 地中有山，谦。君子以裒多益寡，称物平施。 |
| **"裒多益寡，称物平施"解** | **裒**（póu）＝聚而减之、取多者。**裒多益寡**＝**减损多的、增益少的**。**称物**＝衡量事物（"称"是量）。**平施**＝**公平地施予**。<br>**⚠️ 这是全卦最高层的原则，而且它是一个财务／资源动作，不是一个态度**：<br>**山高出地面的那一部分，被削下来填到低处，直到"地中有山"（山藏在地里）——这就是"裒多益寡"的字面画面。**<br>**操作含义**：**你手上多出来的那部分（钱、机会、曝光、话语权、功劳），要主动削下来补到少的地方去，并且要"称"（衡量）之后"平施"（公平地给）。**<br>**⚠️ 与师卦大象传的对照（同一个"地中有X"）**：**师卦"地中有水，君子以容民畜众"——把力量蓄在民间（蓄）；谦卦"地中有山，君子以裒多益寡"——把多的削下来分掉（减）。同一个"地中有X"的句式，一个是攒，一个是分。** |
| **总铁律** | ① **谦不是姿态，是"裒多益寡，称物平施"的实际动作**（大象传）。**不做这个动作的谦只是客气。**<br>② **谦的许诺是"终"，不是"利"**（卦辞、九三、彖传三次重复"有终"）。**它不给你好处，它给你一个结局。**<br>③ **谦到尊位反而"利用侵伐"**（六五、上六）——**谦不等于不能用强**；但用强的对象被严格限定为两类：**"不服"者**（六五象传"征不服也"）和**"自己的邑国"**（上六"征邑国"）。**这条限定是谦卦保住"全卦无凶"的关键。** |

## 二、爻级字段

（**本卦六爻是一条"谦的强度与位置"曲线**：谦谦（初六，谦到极处）→ 鸣谦（六二，谦而有声名）→ 劳谦（九三，有功而谦，卦主）→ 撝谦（六四，把谦发挥出去）→ 侵伐（六五，对不服者用强）→ 鸣谦·行师（上六，回头整肃自己）。**注意后两爻都在用兵——这是本卦最容易被漏掉的部分。**）

### 初六 · 谦谦君子

| 字段 | 内容 |
|---|---|
| **爻辞** | 谦谦君子，用涉大川，吉。 |
| **象传** | 谦谦君子，卑以自牧也。 |
| **位属性** | 阴爻居阳位，**不当位**（艮在下之律：初不当位）；居全卦最下——**位置最低，谦得最彻底**。 |
| **判词 → 行动语义** | **吉** → **谦到极处，反而可以去做涉险的大事**。 |
| **关键词解** | **谦谦**＝谦而又谦（叠字表极致）。**用涉大川**＝**可以用它来渡大河**（"用"＝可用、以此；"涉大川"是《周易》里"担当涉险大事"的标准意象）。<br>**象传**：**卑以自牧也**——**用卑下之道来"牧"（牧＝养、治、管束）自己。** 注意"自牧"两字：**这是自己管自己，不是给别人看的。** |
| **⚠️ 本爻是全卦最反直觉的一条（谦到极处＝可以涉大川）** | 一般理解里"谦"意味着退、守、不出头。**这一爻直接把"谦谦"和"涉大川"接在一起：谦得最彻底的人，恰恰是可以去干最险的大事的人。**<br>**理由在象传"卑以自牧"**：**因为他管住了自己（没有可乘之隙），所以险境里没有东西能拿住他。** 这与履卦的机制正好互补：**履卦靠"辩上下"（外部位分清楚）保安全，谦初六靠"自牧"（内部无隙）保安全。**<br>**⚠️ 与本批同人卦的一处精彩对照**：**同人卦辞"利涉大川"，彖传归因于"乾行也"（靠上卦乾之刚健）；谦初六"用涉大川"，象传归因于"卑以自牧也"（靠谦之至）。同一个"涉大川"，一个靠刚健，一个靠谦卑——《周易》给了两条完全不同的涉险资格。** |
| **识别信号** | ① 你在一个体系里位置最低，或刚开始有一点成绩；② 你没有任何需要维护的架子、排场、面子；③ 你对自己的约束是自己给的，不是别人要求的；④ 你面前有一件明显超出你现有位置的难事。 |
| **该做** | **把"卑"变成对自己的管理制度（自牧）**：不给自己特殊待遇、不接受超出本分的礼遇、不用位置去换方便。**做到了这一步，就可以接那件难事（用涉大川）。** |
| **不该做** | 把谦当成对外的表演。**"自牧"两个字排除了表演——牧的是自己，不是别人的观感。** |
| **与坤初六、艮初六的三角对照** | **坤初六**"履霜，坚冰至"，象传"阴始凝也"——**辅佐者在最下位要见微知著、防趋势**；**艮初六**"艮其趾，无咎，利永贞"，象传"未失正也"——**在脚趾刚要迈出时就止住，零成本**；**谦初六"谦谦君子，用涉大川，吉"，象传"卑以自牧也"——谦到极处而可涉大川。**<br>**三个初六全部不当位，判词依次是"无判词（察·防）／无咎／吉"。谦初六是三者中唯一得"吉"的。** 差别在于：**坤初六在看趋势，艮初六在收手，谦初六在管自己——只有第三个动作能把"不当位"的劣势直接转成"可以担大事"。** |

### 六二 · 鸣谦

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸣谦，贞吉。 |
| **象传** | 鸣谦贞吉，中心得也。 |
| **位属性** | 阴爻居阴位，**当位且得中**（艮在下之律：二当位）——**全卦位置最正的一爻**；本库通则"**二多誉**"。 |
| **判词 → 行动语义** | **贞吉** → **谦德已经传出名声了；守住它，因为它是从心里长出来的**。 |
| **关键词解** | **鸣**＝出声、发声、名声外扬（如"鸣于九皋"）。**鸣谦**＝**谦德发而有声，被人知道了**。<br>**象传**：**中心得也**——**从心中真实得到的**（"中心"＝内心；"得"＝有所得、真有）。 |
| **⚠️ 本爻与豫卦初六的对照，是本批四卦中最重要的一处发现** | **谦六二："鸣谦，贞吉"，象传"中心得也"。**<br>**豫初六："鸣豫，凶"，象传"志穷凶也"。**<br>**同一个"鸣"字，一个贞吉，一个凶——而且这两卦是一对覆卦（谦倒过来就是豫）。**<br>**差别是什么？象传写得极清楚**：<br>**谦六二"中心得也"——里面是实的，所以鸣出来是名副其实；**<br>**豫初六"志穷凶也"——里面已经穷了，所以鸣出来是虚张声势。**<br>**再加谦上六"鸣谦"，象传"志未得也"——里面还没得到，所以"鸣"之后还要"行师、征邑国"（回头整肃自己）。**<br>**⚠️ 可入库的通则：声名外扬（鸣）本身没有吉凶，吉凶取决于"中心得"还是"志穷／志未得"。**<br>**这与本库已有的"泰初九／否初六同为'拔茅茹'而判词相反"是同一级别的"同象异用"教科书案例，而且这一组更狠：泰否是两卦之间，谦卦自己内部（六二 vs 上六）就已经不同。** |
| **识别信号** | ① 你的低调、公平、不占便宜，已经被周围人看在眼里并谈论；② 你并不是为了让人看见才这么做的；③ 你在"干事的核心与基层枢纽"位置上（本库通则：二爻）；④ 你开始享受这个名声，或者开始担心它。 |
| **该做** | **守住（贞）。** 具体动作：**继续做同样的事，不因为有了名声而升级动作。** 名声来了之后最容易犯的错是"把谦做大"——**做大就变成表演，就掉到豫初六的"鸣"。** |
| **不该做** | 用这份名声去换东西（位置、资源、影响力）。**一换，"中心得"就变成"志穷"。** |
| **与坤六二、比六二、同人六二的四爻对照（本库"二爻"专题的完整谱）** | **坤六二**"直方大，**不习**无不利"，象传"地道光也"——**真诚不是刻意模仿出来的**；**比六二**"比之自内，**贞吉**"，象传"不自失也"——**归附出于内心，且不丢掉自己**；**同人六二**"同人于宗，**吝**"，象传"吝道也"——**当位得中却只跟自己人求同**；**谦六二"鸣谦，贞吉"，象传"中心得也"——谦德发自内心，所以有了名声也无妨。**<br>**四爻全部在第二位，前三个的关键词是"不习／自内／于宗"，谦六二是"中心"——四处说的是同一件事：二爻的吉凶，取决于那个东西是不是从里面长出来的。** |

### 九三 · 劳谦（⚠️ 全卦唯一阳爻·卦主·全卦最重的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 劳谦，君子有终，吉。 |
| **象传** | 劳谦君子，万民服也。 |
| **位属性** | 阳爻居阳位，**当位**（艮在下之律：三当位）；居下艮之顶，本库通则"**三多凶**"——**但本爻是"吉"**；**全卦唯一阳爻，五阴所归——卦主**。 |
| **判词 → 行动语义** | **君子有终 ＋ 吉** → **有实实在在的功劳，而且把功劳谦下于人；这是全卦"有终"的兑现处**。 |
| **关键词解** | **劳**＝劳苦、有功劳（"劳"在此兼"辛劳"与"功劳"两义，本卦取其合义）。**劳谦**＝**有功劳而能谦**。**君子有终**＝与卦辞同文，**在这一爻上兑现**。 |
| **⚠️ 系辞传对本爻的专门解释（全书对"谦"最完整的定义）** | 系辞上传："《易》曰：'劳谦君子，有终吉。'子曰：'**劳而不伐，有功而不德，厚之至也。语以其功下人者也。德言盛，礼言恭，谦也者，致恭以存其位者也。**'" ⚠️ **系辞引文作"有终吉"，爻辞本文作"君子有终，吉"——版本差异，两处并存。**<br>**逐句训解（这是本卦最实用的一段）**：<br>**劳而不伐**——**辛劳而不夸耀**（"伐"＝自夸）；<br>**有功而不德**——**有功劳而不自以为有德**（不把功劳记成自己的品德）；<br>**厚之至也**——这是"厚"的极致（对照坤卦"厚德载物"）；<br>**语以其功下人者也**——**说的正是"拿自己的功劳去谦下于人"**；<br>**德言盛，礼言恭**——德要讲盛大，礼要讲恭敬；<br>**⚠️ 谦也者，致恭以存其位者也**——**谦，就是用极致的恭敬来保住自己的位置。**<br>**最后一句是《周易》对"谦有什么用"最直白的回答：不是为了显得好，是为了"存其位"（保住你已经得到的东西）。** |
| **本爻为什么是"三多凶"的例外** | 本库已有四个"三爻多凶·位不当"的实例（师六三舆尸、履六三咥人、比六三匪人、否六三包羞），共同病根是**"才不配位而志刚"**。<br>**谦九三恰好是它的完全反面：才配位（阳居阳位，当位）＋志不刚（劳而不伐）。** 所以象传不给凶，给的是"**万民服也**"——**万民都服他。**<br>**这是全库"三爻"里最好的结果，而且它证明了"三多凶"的真正条件不是位置，是"配不配位＋志刚不刚"。** |
| **⚠️ 与坤六三的对照（本库"辅佐者—有实力者"这条线的接续处）** | **坤六三**"含章可贞，或从王事，**无成有终**"，象传"知光大也"——**内敛锋芒、不居功、把成事之名归于上，得"有终"**；<br>**谦九三"劳谦，君子有终，吉"，象传"万民服也"——有实功而以功下人，得"有终"＋"吉"＋"万民服"。**<br>**两爻同在第三位，同讲"有功不居功"，同得"有终"。但差别极重要**：<br>**坤六三是阴爻不当位——它必须"含章"（把锋芒藏起来），因为一露就招灾，最好的结果只是"有终"；**<br>**谦九三是阳爻当位——它不需要藏，它是"劳"（功劳明摆着），做法是"以其功下人"，结果是"有终、吉、万民服"。**<br>**⚠️ 这正是艮卦卡指出的那个缺口被补上的地方：坤讲"我在别人的体系里不居功"，谦九三讲"我自己就是那份功劳的主人，我把它谦下于人"。前者是保命，后者是"存其位"。** |
| **识别信号（若你是九三）** | ① 你手上有一份明确的、别人拿不走的功劳或能力；② 周围的人实际上是靠你在支撑（五阴归一阳）；③ 你有充分的理由去要名分、要待遇、要说法；④ 你正在犹豫要不要"把话说明白"。 |
| **该做** | **劳而不伐，有功而不德。** 具体三个动作：**① 不主动叙功（伐）；② 不把功劳解释成自己的品德（不德）；③ 主动把功劳的说法让给参与的人（以其功下人）。** 然后执行大象传：**把多出来的那部分实际削下来分掉（裒多益寡）。** |
| **不该做** | 叙功、争名分、把"我扛的"变成口头资本。**注意系辞传给的理由极其务实："致恭以存其位"——你叙功是为了保住位置，而《周易》告诉你反过来才有效。** |

### 六四 · 撝谦（⚠️ 全卦唯一乘刚之爻，判词却是"无不利"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 无不利，撝谦。 |
| **象传** | 无不利，撝谦，不违则也。 ⚠️ **象传前半完整复述爻辞**，只加"不违则也"四字 |
| **位属性** | 阴爻居阴位，**当位**（坤在上之律：四当位）；**直接乘于九三之上——全卦唯一的乘刚之爻**；本库通则"**四多惧**"。 |
| **判词 → 行动语义** | **无不利**（按本库吉凶序：**仅次于元吉，约等于大吉**） → **主动把谦德发挥出去、施布于上下；不越法则**。 |
| **关键词解** | **撝**（huī）＝通"挥"，**挥发、施布、发挥出去**。**撝谦**＝**把谦德挥洒出来、落实到具体行动上、遍施于上下**（不是自己谦，是把"谦"这件事推行开）。<br>**象传**：**不违则也**——**不违背法则**（"则"＝法度、本分、规矩；与同人九四"困而反则也"同一个"则"字）。 |
| **⚠️ 本爻是本库"乘刚"规则下的第三个破解方式，而且是最好的一个** | 本库乘刚通则：**阴爻居阳爻之上，天然被下方阳刚逼迫冲击**（震六二"亿丧贝"、屯六二"虽当位得中仍难"）。已有两个破解：<br>**① 艮六四"艮其身，无咎"，象传"止诸躬也"——把范围收回到自己这一身；**<br>**② 巽六四"田获三品"——交付可分配的实际成果。**<br>**谦六四补上第三个，也是判词最高的一个："无不利，撝谦"，象传"不违则也"——把谦德挥发出去，不越法则。**<br>**⚠️ 而且谦六四的乘刚是全库最难的一种**：**它乘的是九三——那个"万民服也"的卦主。** 头顶上没有人，脚底下踩着全公司最被服气的人，这是最尴尬的生态位。<br>**《周易》给的答案是"撝谦"：不去争那个"万民服"，而是把"谦"这件事本身推行开、变成上下共同的规矩（不违则）。** |
| **三种乘刚破解方式的对照（可直接入库）** | | 爻 | 动作 | 象传 | 判词 |<br>|---|---|---|---|<br>| **艮六四** | 止诸躬（**收缩范围**） | 止诸躬也 | 无咎 |<br>| **巽六四** | 田获三品（**交付成果**） | — | — |<br>| **谦六四** | 撝谦（**推行规矩**） | **不违则也** | **无不利** |<br>**三者由低到高：收缩自己 ＜ 交出成果 ＜ 把规矩推行开。** 越是把动作从"我"扩到"规矩"，乘刚的压迫就越不构成灾。 |
| **识别信号** | ① 你的位置在一个极强的人之上（职级更高、名义在前），但那个人才是实际被服气的；② 你自己当位（名分是正的），却明显感到下方的顶迫；③ 你想去证明自己也很行，或者想去压一压那个人；④ 你也可能反过来，想干脆把位置让掉。 |
| **该做** | **撝谦——把"谦"变成上下共同的规则，而不是你个人的姿态。** 具体动作：**① 公开承认九三的功劳（这是"裒多益寡"里的"益寡"，你把名分补给他）；② 把公平分配变成制度（称物平施）；③ 严守自己位置的法度（不违则），不多做一件、也不少做一件。** |
| **不该做** | 与九三比高低（争"万民服"）；或者辞位躲开。**注意判词是"无不利"——本库口径里约等于大吉。这说明这个尴尬的生态位有一个非常好的解，前提是你做"撝谦"而不是做"比较"。** |
| **与坤六四的对照** | **坤六四**"括囊，**无咎无誉**"，象传"慎不害也"——**辅佐者在近君之位闭紧嘴，不引人注目正是好事**；**谦六四"无不利，撝谦"，象传"不违则也"——把谦德挥发出去。**<br>**同为四位、同为阴爻当位，一个"无咎无誉"，一个"无不利"（高出好几档）。** 差别在卦德：**坤卦的德是"顺承"，所以四爻只能收（括囊）；谦卦的德就是"谦"本身，所以四爻可以放（撝）——把本卦之德发挥出去，是全库"卦德与爻德相合则位不构成障碍"的又一实例。** |

### 六五 · 不富以其邻（⚠️ 谦卦竟然"利用侵伐"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 不富以其邻，利用侵伐，无不利。 |
| **象传** | 利用侵伐，征不服也。 |
| **位属性** | 阴爻居阳位，**不当位**（坤在上之律：五不当位），但**得中**且居尊位——**本库通则"得中可救不当位"的又一实例**。 |
| **判词 → 行动语义** | **利用侵伐 ＋ 无不利** → **对那些不服的，该征就征；范围严格限定在"不服"者**。 |
| **关键词解** | **不富**＝不富有（阴爻为虚、为不富；此处指**居尊位而不以财货自恃、也不独占**）。**以**＝率领、与、带着。**不富以其邻**＝**自己不据财自重，而能带着邻近的人（六四、上六）一起**。<br>**利用侵伐**＝**适宜用来征伐**（"用"＝以此、用它）。<br>**象传**：**征不服也**——**征讨的是那些"不服"的**。四个字把打击面锁死了。 |
| **⚠️ 本爻是全卦最反直觉的一条（谦卦教你打仗）** | 一个"全卦无凶"、讲"裒多益寡"的卦，居然在尊位上说"**利用侵伐**"，而且判"**无不利**"（约等于大吉）。<br**为什么允许？象传只给四个字："征不服也"。** 逻辑链是这样的：<br>**① 你已经执行了大象传——"裒多益寡，称物平施"，多的削了、少的补了、分配是公平的（爻辞"不富以其邻"就是这个动作的完成态）；**<br>**② 在公平已经做到的前提下，还"不服"的那部分，就不是"谦"能解决的了；**<br>**③ 所以此时用强是正当的，而且"无不利"。**<br>**⚠️ 结论（本卦最重要的一条实用铁律）：谦不等于不能用强。但用强的资格是挣来的——先做完"平施"，才有"征不服"的名分。顺序颠倒（先征后分），就不是谦卦，是师卦（而师卦"无元无亨无利"）。** |
| **"不富以其邻"在本库中的第三次出现（重要）** | **小畜九五**"有孚挛如，**富以其邻**"——**有实力者与邻共富（本库"不独富"）**；<br>**泰六四**"翩翩**不富，以其邻**，不戒以孚"，象传"皆失实也／中心愿也"——**顺境中阴爻下交，不以富自恃，靠诚信不靠戒备**；<br>**谦六五"不富以其邻，利用侵伐，无不利"——居尊而不据富，带着邻近的人，然后征不服。**<br>**三处同一个句式，三种用法**：**小畜是"共富"（分给邻），泰六四是"不以富自恃"（不设防），谦六五是"不据富而能率邻"（然后可以用强）。**<br>**合成一条通则：《周易》里"富"从来不是资源问题，是"你和邻近的人的关系"问题。三处都在讲同一件事——手上的东西必须与旁边的人发生关系，否则它就是负担。** |
| **与师六五的对照（两个"该不该打"的尊位）** | **师六五**"田有禽，**利执言**，无咎。长子帅师，弟子舆尸，**贞凶**"，象传"使不当也"——**战的正当性来自"田有禽"（敌人已来犯），而成败全在用人**；<br>**谦六五"利用侵伐，无不利"，象传"征不服也"——战的正当性来自"平施已做到、对方仍不服"。**<br>**⚠️ 两者的差别是本库一条重要的分野**：<br>**师六五要"利执言"（公开申明理由）——因为师卦的战争天然缺正当性（卦辞无元无亨无利）；**<br>**谦六五不需要申明——因为"裒多益寡、称物平施"已经把正当性做在前面了。**<br>**可入库的口径：用强之前，正当性要么靠"申明"（师），要么靠"已经做到的公平"（谦）。后者比前者结实——师六五最好的结果是"无咎"，谦六五是"无不利"。** |
| **识别信号（若你是六五）** | ① 你在拍板的位置上，但名分未必完全够（不当位），靠的是居中和众人认可；② 你已经做过实际的公平分配（不是口头的）；③ 分配之后，仍有一部分人／一个部门／一个对手明确"不服"；④ 你担心"用强"会破坏自己"谦"的形象。 |
| **该做** | **① 先自查："裒多益寡、称物平施"我真做到了吗？做到了才有下一步；② 明确区分"不服"与"有意见"——只处理前者；③ 对"不服"者用足力量（利用侵伐），但不扩大到有意见的人。**（打击面的克制参照离上九"折首而不获丑"。） |
| **不该做** | 因为"要维持谦的形象"而放着"不服"不管。**这一爻的存在本身就是《周易》在说：容忍不服不是谦，是失职——而且判词给到"无不利"，态度非常明确。** |

### 上六 · 鸣谦，征邑国

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸣谦，利用行师，征邑国。 |
| **象传** | 鸣谦，志未得也。可用行师，征邑国也。 |
| **位属性** | 阴爻居阴位，**当位**（坤在上之律：上当位）；居全卦之终。 |
| **判词 → 行动语义** | **利**（按本库口径：**可行·有益**，是六爻里最轻的一档，但仍是正面） → **谦名已扬而志未实现；可以用兵，但只能用来征自己的邑国（整肃内部）**。 |
| **关键词解** | **鸣谦**＝与六二同文，**谦德已有声名**。**行师**＝出兵、动员（与师卦同字）。**邑国**＝**自己的封邑之国，即自己的地盘、自己的内部**。<br>**象传两句**：**志未得也**——**志向还没有实现**（与同人上九象传同文）；**可用行师，征邑国也**——**可以用兵，而且只能用在"征邑国"上**。（注意象传把爻辞的"利用"改写为"可用"，语气更收：**是"可以"，不是"应该"。**） |
| **⚠️ 本爻与六二"鸣谦"的对照（同一个词，两处不同）** | **六二"鸣谦，贞吉"，象传"中心得也"——里面是实的，所以鸣是名副其实；**<br>**上六"鸣谦，利用行师"，象传"志未得也"——里面还没得到，所以鸣之后必须回头做事。**<br>**结论：同一个"鸣谦"，在六二是结果，在上六是提醒。上六的谦名已经很大了（居全卦之极），但"志未得"——名声跑到了实绩前面。所以它的作业不是继续鸣，是"征邑国"（回头整肃自己的地盘）。** |
| **⚠️ 与泰上六的对照（两个上爻，同一条限定）** | **泰上六**"城复于隍，**勿用师**。**自邑告命**，贞吉"，象传"其命乱也"——**顺境崩塌时绝不可对外动武，唯一活路是从自己的城邑内部发布命令、整肃自身**；<br>**谦上六"利用行师，**征邑国**"，象传"可用行师，征邑国也"——可以用兵，但只能对着自己的邑国。**<br>**⚠️ 两处把"上爻的用兵"限定得完全一致：只能对内。** 差别只在语气：**泰上六是禁令（勿用师）＋替代方案（自邑告命）；谦上六是许可（可用行师）＋范围限定（征邑国）。**<br>**可入库的通则：凡上爻涉及用兵，打击方向必须是"向内"。这条与本库"上爻之凶只来自不知止"是配套的——向外扩张就是"不知止"，向内整肃就是"知止"。** |
| **本爻为什么当位却只得"利"（全卦判词最低的一爻）** | 上六阴居阴位，**当位**，理应不错。但它的判词只有"利"（本库序列中低于吉、低于无不利）。**原因就是象传那四个字："志未得也"。**<br>**这也是本卦"全卦无凶"的边界所在**：**谦卦保住了无凶，但它没有保住"圆满"。走到最后，名声在、位置正、也没有灾，就是志向没实现。** 而《周易》给的处理方式极务实：**别对外，回头整肃自己。** |
| **识别信号** | ① 你"谦"的名声已经很响，超过了你实际的成就；② 你想做的那件事其实还没做成（志未得）；③ 你有向外扩张、去别处证明自己的冲动；④ 你自己的地盘（团队、家里、本职）其实有一堆没理清的事。 |
| **该做** | **把力量转向内部**：整肃自己的团队、清理自己的旧账、把本职范围内没做完的事做完（征邑国）。**同时接受"志未得"这个事实，不用名声去替代它。** |
| **不该做** | 拿着这份谦名去外面开新战场。**象传把"利用"降级成"可用"，又把范围锁在"邑国"——两道限制叠在一起，意思很清楚：可以用力，但不能往外。** |

## 三、谦卦定位速查表

| 爻 | 谦的形态 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | **谦谦**（谦到极处） | 谦谦君子 | 位置最低，没有任何架子，面前有件难事 | 不当位 | **吉**·卑以自牧·**可涉大川** |
| 六二 | **鸣谦**（谦而有声名） | 鸣谦 | 你的低调公平已被人看见并谈论 | **当位·得中** | **贞吉**·中心得也·守住不升级 |
| 九三 | **劳谦**（有功而谦，**卦主**） | 劳谦 | 有一份别人拿不走的功劳，大家靠你撑着 | **当位**·三多凶（**不凶**） | **君子有终·吉**·万民服·劳而不伐 |
| 六四 | **撝谦**（把谦推行开） | 撝谦 | 你名义在前，脚下踩着那个真被服气的人 | 当位·**唯一乘刚** | **无不利**·不违则·推行规矩 |
| 六五 | **平施后用强** | 不富以其邻 | 公平已经做到，仍有人明确不服 | 不当位但**得中居尊** | **无不利**·**利用侵伐**·只征不服 |
| 上六 | **鸣而志未得** | 征邑国 | 谦名超过了实绩，想去外面证明自己 | 当位·卦终 | **利**·志未得·**只能向内整肃** |

**谦卦三句话**：
1. **谦不是姿态，是动作。** 大象传给的是"**裒多益寡，称物平施**"——**把多的削下来、把少的补上去、公平分配。** 不做这个动作的谦只是客气。
2. **谦的许诺是"终"，不是"利"。** 卦辞"君子有终"、九三"君子有终"、彖传"君子之终也"——**三次重复同一句。它不给你好处，它给你一个结局。** 系辞传把用途说得最白：**"谦也者，致恭以存其位者也"——谦是用来保住你已经得到的东西的。**
3. **谦不等于不能用强。** 六五"**利用侵伐**"（只征不服）、上六"**利用行师，征邑国**"（只对内）。**用强的资格靠"平施已做到"挣来，打击的方向被锁死在"不服者"和"自己的地盘"。**

**⚠️ 为什么谦卦"全卦无凶"（本卡的核心结论，三条理由）**：

**第一，判词核实。** 六爻判词依次是：**初六吉 ／ 六二贞吉 ／ 九三君子有终·吉 ／ 六四无不利 ／ 六五无不利 ／ 上六利**。**无一凶、无一悔、无一吝、无一厉，而且六爻全部落在"吉／无不利／利"三档正面判词之内**——连一个"无咎"都没有（**注意：按本库口径"无咎≠吉利"，所以"没有无咎"反而是更强的证据**）。对照本批的大有卦：大有也无凶，但有"匪咎"一处、"无咎"三处，**只有六五、上九是"吉"。所以谦比大有更彻底。**

**第二，机制原因（彖传给的）。** 彖传写了四句排比：**"天道亏盈而益谦，地道变盈而流谦，鬼神害盈而福谦，人道恶盈而好谦。"** **天、地、鬼神、人四重力量同时站在"谦"这一边——这是《周易》唯一一处这样写的卦。** 而按本库口径，**全书绝大多数"凶"的根源都是"盈"**：乾上九盈极不知止（悔）、坤上六由顺变夺（凶）、履六三志刚而才不配位（凶）、比上六观望太久而无所归（凶）、否六三位不当而受羞。**谦从定义上就在减，所以它在源头上排除了产生凶的主要机制。**

**第三，结构原因（当位分布最优）。** **艮在下 → 初不当、二三当位；坤在上 → 四上当位、五不当。合计四爻当位（六二、九三、六四、上六）、两爻不当位（初六、六五）。而这两个不当位的爻恰好落在风险最低和最有救的位置上**：
- **初六不当位，但它在最下、成本最低，而且它的动作"卑以自牧"正是把不当位的劣势降到零；**
- **六五不当位，但它得中且居尊——本库通则"得中可救不当位"（震六五"亿无丧"是标准例）。**
**换句话说：谦卦把它两处结构缺陷，一个放在最不要紧的地方，一个放在有解药的地方。**
**再加上唯一的阳爻（九三）当位、且被写成"劳谦"（有实力而不刚）——全卦没有一爻处在"以刚居尊"或"以柔抢刚"的错位上。这就是"无凶"的结构基础。**

**本卦最反直觉的一条**：**一个全卦无凶的卦，靠的不是一味退让，而是"该打的时候打"。** 六五"**利用侵伐**"、上六"**利用行师**"——**六爻里有两爻在用兵，而且都是正面判词。** 谦卦真正教的不是"不争"，是**把"减损自己"做在前面，从而把"用强"的正当性挣到手，并且把打击面锁死在"不服者"与"自己的地盘"。**

## 四、⚠️ 本卡对全库的意义

### 1. 补上艮卡点名的那个缺口：坤 — 谦 — 履 三卡的分工

| 卡 | 处境 | 你有没有实力 | 核心动作 | 纲领 |
|---|---|---|---|---|
| **坤 2** | 在别人的体系里辅佐 | **没有独立实力** | 顺承、不越位、功归上 | 厚德载物 |
| **谦 15** | **自己已经有了实力／功劳** | **有** | **减损自己、公平分配、以功下人** | **裒多益寡，称物平施** |
| **履 10** | 在强弱悬殊的结构中行走 | 有一点，但远弱于对方 | 和悦顺应、位分清楚、戒惧 | 辩上下，定民志 |
| **艮 52** | 该停的时候 | 有（还能继续） | **不继续** | 思不出其位 |

> **四卡的分界线可以做成一道问诊题**：
> **"你手上有没有一份别人拿不走的功劳？"** 没有 → 坤；有，且你还要继续 → **谦**；有，但你决定不继续 → 艮；对方强到你只能求安全通行 → 履。
> **⚠️ 谦卦是这四卡里唯一"既承认你有实力、又要求你主动往下放"的一卦。** 本库路由表上"该不该抢功""要不要出头""功劳怎么摆"这类高频问题，正解在此。

### 2. 与豫（16）合成第二组覆卦实证：同样六个爻，倒过来读，当位数从 4 掉到 2

谦（阴阴阳｜阴阴阴）**上下颠倒**读就是豫（阴阴阴｜阳阴阴）。**逐位映射**：

| 谦 | 位属性 | ↕ 倒读后落到 | 豫 | 位属性 | 得失 |
|---|---|---|---|---|---|
| 初六 阴居阳 | 不当位 | → 上 | 上六 阴居阴 | **当位** | **＋** |
| 六二 阴居阴 | **当位·得中** | → 五 | 六五 阴居阳 | 不当位·得中 | － |
| 九三 阳居阳 | **当位**（卦主） | → 四 | 九四 阳居阴 | **不当位**（卦主） | － |
| 六四 阴居阴 | **当位**（乘刚） | → 三 | 六三 阴居阳 | 不当位 | － |
| 六五 阴居阳 | 不当位·得中 | → 二 | 六二 阴居阴 | **当位·得中** | **＋** |
| 上六 阴居阴 | **当位** | → 初 | 初六 阴居阳 | 不当位 | － |
| **合计** | **4 当位** | | | **2 当位** | **－2** |

> **结果对照**：**谦（4 当位）＝全卦无凶，六爻全部正面判词；豫（2 当位）＝初六"凶"、六三"悔；迟有悔"、六五"贞疾"。**
> **⚠️ 这是本库"位属性决定一切"最干净的一次证明：爻的阴阳一个没变，只是倒过来读，判词就从"全卦无凶"变成"开局即凶"。**
> **并且它与本批另一组（同人 4 当位 / 大有 2 当位）在数字上完全一致——两组覆卦都是 4↔2。**

### 3. "唯一阳爻上移一位"带来的连锁反应（本卡最有技术含量的一条）

**谦与豫都只有一个阳爻，而且倒读之后它从第三位移到了第四位。** 一位之差，牵动三件事：

| | **谦九三**（阳在三） | **豫九四**（阳在四） |
|---|---|---|
| **当位** | **当位**（阳居阳位） | **不当位**（阳居阴位） |
| **所在** | 下艮之顶——**止在内，力量在自己这边** | 上震之始——**动在头顶，力量在别人头上** |
| **爻辞** | 劳谦，君子有终，**吉** | 由豫，**大有得**。勿疑，朋盍簪 |
| **象传** | **万民服也** | **志大行也** |
| **它制造的乘刚** | **六四乘刚**（阴在四乘三之刚） | **六五乘刚**（阴在五乘四之刚，**象传明写"乘刚也"**） |
| **受害者的结局** | 六四"**无不利**"（撝谦可解） | 六五"**贞疾，恒不死**"（在尊位，无解只能带病维持） |

> **⚠️ 结论（可入库为通则）**：**乘刚落在第四位还有解（六四可以"止诸躬""撝谦""田获三品"，把范围收回或把规矩推开）；落在第五位就没有解，因为尊位不能缩小范围。**
> **这就是本库"震在上＝动在头顶（你做不了主）"这条定势的最深层原因：震在上必然把乘刚推到六五，而六五是全卦唯一不能靠"缩小自己"来自救的位置。**
