# 知识卡 16 · 豫卦（雷地豫）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传/系辞传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："有大而能谦必豫，故受之以豫。"——**东西多了（大有）又能谦（谦），必然就"豫"了**。序卦把豫定义为"大有＋谦"的自然结果：**顺了、可以动了，同时也开始想享受了。**
> **⚠️ 本卦是震卦卡（51）明确点出的优先缺口**：震卡末节写道"**豫 16（上震下坤）……卦辞'利建侯行师'直接衔接师卦（7），是现有 12 卦最近的一个缺口**"。**本卡与师卦（07）做实质对照，见卦级字段与末节。**
> **本卦与谦（15）是一对反卦（覆卦）**：谦（阴阴阳｜阴阴阴）倒过来读就是豫（阴阴阴｜阳阴阴）。**同样的六个爻，倒过来读，当位数从 4 掉到 2，判词从"全卦无凶"变成"开局即凶"。** 两卦必须合读。
> **⚠️ 本卦是本库"震在上则六五必乘刚"的教科书实证**：豫六五象传直接写"**乘刚也**"——**这是全书第二处（也是最后一处）象传明写"乘刚"的地方，第一处是震六二。** 逐爻验证见末节。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 豫 · 第十六卦 |
| **卦象** | 上震（雷／动）下坤（地／顺），称"雷地豫"。**雷从地里出来，奋然而起**（大象传"雷出地奋"）——**底下是顺，上面是动：顺着势头动起来**，故为"豫"。<br>**六爻自下而上：阴、阴、阴｜阳、阴、阴。全卦唯一的阳爻是九四**，居上震之始——**卦主**。<br>**按本库结构律逐爻核定**：**坤在下 → 二当位、初三不当位**（初六不当位、六二当位且得中、六三不当位）；**震在上 → 四五不当位、上当位**（九四不当位、六五不当位但得中居尊、上六当位）。**全卦仅二当位（六二、上六）、四不当位。**<br>**⚠️ 逐爻检查乘刚：六五直接乘于九四之上——本卦唯一的乘刚之爻，象传明写"乘刚也"，判词"贞疾"。** |
| **⚠️ 震在上的定势含义（本卦全部风险的根）** | 本库结构律：**震在上＝动在头顶（你做不了主）**，且**震在上则六五必乘刚**。<br>**豫卦正是这条律的完整演示**：**九四（唯一阳爻）在第四位——它是全卦动力的来源，"志大行也"；而它上面的六五虽居尊位，却被顶在下面的刚上，只能"贞疾，恒不死"。**<br>**一句话记住：豫卦的动力在四，名分在五，两者不在同一个人身上。** 这是本卦所有困境的结构成因。 |
| **领域定义** | **顺势启动期，以及随之而来的松懈与享乐**。项目获批、预算到位、上下都顺、可以放手大干；组织扩张期、庆功期、分红期、行业风口期；也包括**耽于安逸、把顺势当本事、把庆祝当成果**。凡是"现在顺了、可以动了，同时也开始想享受了"，都落在豫卦。 |
| **不归本卦的情况** | ① **突发冲击的第一刻、还没反应过来** → **震卦（51）**。**豫的震在上、底下是坤顺，是"顺着动"；震卦是被砸。** 分界：**你是主动动的，还是被动的？**<br>② **组织化对抗的规矩本身** → **师卦（7）**。**豫讲"利建侯行师"是授权与动员的前提条件，师讲打起来之后的纪律、择帅、论功。**<br>③ **顺境的通与塞** → **泰否（11-12）**。**泰讲"上下交不交"，豫讲"顺了之后动不动、乐不乐"。**<br>④ **已经有了实力、要不要往下放** → **谦（15）**（本卦的覆卦，必须合读）。 |
| **"豫"字义（三义并存，必须合读）** | ① **悦乐**——豫＝乐、安乐（本卦主义）；② **预备**——豫通"预"，预先、事先（大象传"作乐崇德"就是预先立制度）；③ **犹豫、怠惰**——迟疑不决、松懈（六三"迟有悔"、上六"冥豫"）。<br>**⚠️ 三义必须合起来读，这是本卦的义理核心**：**顺势而动会带来乐（义①），而这份乐必须先有"预"（义②，制度化）来接住，否则就滑向怠与冥（义③）。**<br>**本卦六爻正是这三义的展开**：初六是没有"预"就先"鸣"（凶）；六二是有"预"（介于石，不终日）；九四是"由豫"（成为乐的来源）；上六是滑到"冥豫"（沉溺）。 |
| **卦辞原文** | 豫：利建侯行师。 |
| **⚠️ 卦辞的关键结构（与师卦的直接衔接处）** | **只有一个"利"字，无元、无亨、无贞。而且这个"利"带了两个极具体的宾语："建侯"与"行师"。**<br>**全书卦辞只给"利"＋两个具体动作的，只有这里。**<br>**⚠️ 与师卦的对照（本库路由上必须打通的一条）**：<br>**师卦辞**："师：**贞**，丈人吉，无咎。"——**无元无亨无利，只有"贞"。本库已判：天道对战争不许诺任何好处，只给一条"必须师出有名"的底线。**<br>**豫卦辞**："豫：**利**建侯行师。"——**这是《周易》里唯一一处说"行师"是"利"的。**<br>**两处合读，机制立刻清楚：师卦讲的是"打起来之后怎么办"（立律、择帅、论功），它不许诺好处；豫卦讲的是"什么条件下动员才是有利的"，而那个条件写在彖传里——"顺以动"。**<br>**⚠️ 结论（可入库）：《周易》不反对动员，它反对"不顺而动"。豫卦是师卦的前置条件卡；师卦是豫卦的后果卡。用户如果问"我该不该发动这件事"，先看豫（顺不顺）；已经发动了问"怎么打"，才转师。** |
| **卦辞现代解** | **建侯**——**分封诸侯、建立分支、授权他人独当一面**（现代形态：设分公司、立事业部、授权项目负责人、扶持代理人）。<br>**行师**——**动员组织化的力量去做一件事**（不限于打仗）。<br>**利**——**这两件事在豫卦的条件下是有益的、可行的。**<br>**⚠️ 为什么偏偏是这两件事？** 因为**豫的卦象是"一阳统五阴，且那个阳在四位不在五位"**：**九四有实际动能却不居尊位——这正是"建侯"（授出去一块地盘让人自己干）与"行师"（把力量交给一个统帅）的结构形态。** 换句话说：**豫卦的"利"，利在"授权与动员"，不利在"自己独揽"。** |
| **彖传** | 豫，刚应而志行，顺以动，豫。豫顺以动，故天地如之，而况建侯行师乎。天地以顺动，故日月不过，而四时不忒。圣人以顺动，则刑罚清而民服。豫之时义大矣哉。 |
| **⚠️ 彖传要点（本卦的操作总纲）** | ① **刚应而志行**——**那一个刚（九四）与众阴相应，所以志向得以推行**（与九四象传"志大行也"完全对应）。**豫卦的动力只有一个来源，就是那一个阳。**<br>② **顺以动，豫**（并重复强调"豫顺以动"）——**下坤是顺、上震是动：先有"顺"的底子，才有"动"的资格。** 这是全卦最重要的四个字。<br>**⚠️ 与师卦彖传的对照**：**师卦"行险而顺"（下坎险、上坤顺）——明知是险，要以顺的方式行之；豫卦"顺以动"（下坤顺、上震动）——先顺，然后才动。** **两卦都把"顺"作为唯一的通行证，但位置不同：师的顺在上（用顺的方式做险事），豫的顺在下（在顺的基础上发动）。**<br>③ **天地以顺动，故日月不过，而四时不忒**——"不过"＝不失其度，"忒"＝差错。**连天地都是"顺动"，所以日月不越轨、四季不出错。**<br>④ **圣人以顺动，则刑罚清而民服**——**顺着来动，刑罚就清简而民众服从**（对照师卦"以此毒天下而民从之"：师是伤害天下而民仍从，豫是刑罚清简而民服。**代价差了一个量级**）。<br>⑤ **豫之时义大矣哉**——**"时义"两个字是关键：豫的价值全在"时"。** 该动的时候动才是豫，不该动的时候动就是初六的"鸣"。 |
| **大象传（行动纲领）** | 雷出地奋，豫。先王以作乐崇德，殷荐之上帝，以配祖考。 |
| **⚠️ "作乐崇德，殷荐之上帝，以配祖考"解（全书唯一一条"做音乐"的纲领）** | **作乐**＝制作音乐、创制礼乐。**崇德**＝用它来推崇德行。**殷**＝盛大。**荐**＝进献。**殷荐之上帝**＝盛大地献祭于上帝。**以配祖考**＝并以祖先配享（"祖考"＝先祖先父）。<br>**⚠️ 这是《周易》六十四卦大象传里唯一一条以"音乐"为行动纲领的。为什么？**<br>**因为豫＝乐。而《周易》处理"乐"的方式不是禁止，是"作"——把它制度化、公共化、指向德与祖考。**<br>**操作含义（本卦最实用的一条）**：**顺势起来的这份喜悦、这份势头，必须立刻被做成"制度／仪式／可共享的形式"，并且明确它归功于谁（上帝、祖考，即比你更大的来源）。**<br>**做到了，就是九四的"由豫，大有得"（众人的乐由你而来）；没做，就是初六的"鸣豫，凶"（把这份乐当成自己的资本鸣叫出来）。**<br>**⚠️ 这就是"豫"三义合读的落地处：乐（义①）必须先有"预"（义②：作乐、立制度）来接住，否则滑向怠（义③：冥豫）。** |
| **总铁律** | ① **顺以动，不是随便动**（彖传）。**"顺"（下坤）是"动"（上震）的资格证；无顺而动，就是初六。**<br>② **这份乐必须制度化、公共化、归功于更大的来源**（大象传"作乐崇德……以配祖考"）。**私自把它鸣出来是凶（初六），让众人由你而乐是大有得（九四）。**<br>③ **豫的病叫"冥"**（上六"冥豫成"）——沉溺到昏冥。**唯一的解药是"有渝"（改），而象传只留一句"何可长也"。**<br>④ **豫卦的动力在四、名分在五，两者不在同一个人身上**（九四"志大行"、六五"贞疾·乘刚"）。**这是本卦一切别扭的结构成因，也是它"利建侯行师"（必须授权出去）的原因。** |

## 二、爻级字段

（**本卦六爻是"豫"这一个字的六种用法**：鸣豫（初六）→ 介于石（六二，唯一不豫的一爻）→ 盱豫（六三）→ 由豫（九四，卦主）→ 贞疾（六五）→ 冥豫（上六）。**读爻时先问：你是在"鸣"、在"盱"、在"由"，还是已经在"冥"。**）

### 初六 · 鸣豫（⚠️ 全卦唯一的"凶"，与九四构成本卦核心对照）

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸣豫，凶。 |
| **象传** | 初六鸣豫，志穷凶也。 |
| **位属性** | 阴爻居阳位，**不当位**（坤在下之律：初不当位）；居全卦最下；**与九四为正应**——**它有一个极强的靠山，而这正是它的祸根**。 |
| **判词 → 行动语义** | **凶**（按本库口径：**周易所有结局中最坏的，别不当回事**） → **此爻不可入**。 |
| **关键词解** | **鸣**＝出声、叫嚷、向外张扬。**鸣豫**＝**把自己的这份乐（或自己有靠山这件事）叫嚷出来**。<br>**象传**：**志穷凶也**——**志已经穷了，所以凶**（"穷"＝走到尽头、无路可走；与比卦彖传"后夫凶，其道穷也"、屯六三"往吝穷也"同一个"穷"字）。 |
| **⚠️ 本爻是全卦最重要的一条，必须与九四合读** | **初六与九四是本卦唯一的一对正应**：**九四是全卦唯一的阳爻、动力的来源；初六在最下，与它相应。**<br>**于是初六手上有了一样东西：一个极强的靠山。它做的事是"鸣"——把这件事叫出来。判词是"凶"。**<br>**而九四手上有同一样东西的另一头：它是那份乐的来源。它做的事是"由"——让众人的乐由它而出。判词是"大有得"。**<br>**⚠️ 逐项对照（这是本卡的核心）**：<br>**位属性：初六不当位，九四也不当位——完全相同。**<br>**关系：两爻互为正应——是同一条关系的两端。**<br>**动作：初六"鸣"（向外叫嚷"我有"），九四"由"（让它从我这里流出去）。**<br>**判词：凶 ↔ 大有得。按本库吉凶序，这两者之间隔了整整十级。**<br>**结论（本卦最反直觉的一条）：位属性完全相同、关系完全相同，判词隔了十级，差别只在一个字——"鸣"还是"由"。** |
| **"鸣"在本批两卦中的三次出现（重要）** | **谦六二"鸣谦，贞吉"，象传"中心得也"——里面是实的；**<br>**谦上六"鸣谦，利用行师"，象传"志未得也"——里面还没得到，所以要回头做事；**<br>**豫初六"鸣豫，凶"，象传"志穷凶也"——里面已经穷了。**<br>**⚠️ 通则：声名外扬（鸣）本身没有吉凶，吉凶取决于里面是"中心得"、"志未得"还是"志穷"。** 而且**谦与豫是一对覆卦，同一个"鸣"字随卦一翻就从"贞吉"变成"凶"**——这与本库"泰初九／否初六同为'拔茅茹'而判词相反"是同级的"同象异用"案例。 |
| **识别信号（诊断清单）** | ① 局面刚顺起来，你在最底层的位置上；② 你有一个很强的关系／靠山／对口资源（正应）；③ 你开始把这件事说出去——"我跟某某很熟""这事我能办""我们现在特别顺"；④ 你实际能拿出的成果远小于你叫出来的声势；⑤ 你把"势头顺"当成了"我很行"。 |
| **该做** | **闭嘴，把动作换成"预"。** 具体：**① 不说与靠山的关系；② 把顺势期的时间用在建立可验证的成果上；③ 参照大象传"作乐崇德"——把这份势头做成对别人有用的东西，而不是自己的谈资。**<br>**⚠️ 但要老实说明：按本库口径，"凶"级之爻的真正解药通常不在爻内，在于不要走到这里。** 初六的解药是**不"鸣"** ——而它一鸣，象传就断"志穷"。 |
| **不该做** | 借势叫嚷。**注意象传的因果方向：不是"鸣了以后志才穷"，是"志已经穷了所以才要鸣"。叫嚷本身是内里空了的症状，不只是原因。** |
| **与坤初六、比上六的对照** | **坤初六**"履霜，坚冰至"，象传"阴始凝也"——**在最下位要见微知著、防趋势**；**比上六**"比之无首，**凶**"，象传"无所终也"——**观望太久、已无所归，凶**；**豫初六"鸣豫，凶"，象传"志穷凶也"——顺势之初借势叫嚷，凶。**<br>**⚠️ 三个"最外围"位置的对照极有用：坤初六是"看"（察微），比上六是"晚"（错过窗口），豫初六是"早且响"（还什么都没有就先叫）。** 三者里只有豫初六是**在顺境里得凶的**——**这说明顺境的凶不来自外部，只来自"内里空而声势大"。** |

### 六二 · 介于石（⚠️ 全卦唯一"中正"之爻，也是唯一不"豫"的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 介于石，不终日，贞吉。 |
| **象传** | 不终日贞吉，以中正也。 |
| **位属性** | 阴爻居阴位，**当位且得中**（坤在下之律：二当位）——**全卦唯一"当位＋得中"之爻，象传直接称"中正"**；本库通则"**二多誉**"。 |
| **判词 → 行动语义** | **贞吉** → **像石头一样耿介不动，而且不等一天就做出判断**。 |
| **关键词解** | **介**＝耿介、坚定不移（一说"介"＝界，划界自守；两义相通）。**介于石**＝**坚定如石**。**不终日**＝**不等一整天**（"终日"＝整天）——极言其快。<br>**象传**：**以中正也**——**因为它中且正**（当位＝正，得中＝中）。**全卦只有这一爻可以被称为"中正"。** |
| **⚠️ 系辞传对本爻的专门解释（本爻全部重量所在）** | 系辞下传："《易》曰：'介于石，不终日，贞吉。'子曰：'**知几其神乎！君子上交不谄，下交不渎，知几也。介如石焉，宁用终日，断可识矣。君子知微知彰，知柔知刚，万夫之望。**'" ⚠️ **系辞引文文字待核（大意确切，个别虚字或有异文）。**<br>**逐句训解（这是全书对"判断力"最高的一段评价）**：<br>**知几其神乎**——**"几"是极细微的先兆。能知"几"，几乎近于神了。**<br>**上交不谄，下交不渎**——**对上不谄媚，对下不轻慢**：这就是"知几"的日常形态（**知几不是预测，是不在关系里失态**）。<br>**介如石焉，宁用终日，断可识矣**——**坚定如石，何必等一整天？决断当下就可以做出。**<br>**君子知微知彰，知柔知刚，万夫之望**——**知细微也知显著，知柔也知刚，所以是万人所仰望的。**<br>**⚠️ 结论：在一个"大家都在享乐"的卦里，《周易》把最高评价给了那个"不等一天就走"的人。** |
| **⚠️ 本爻在豫卦中的位置（唯一不"豫"的一爻）** | **六爻里五爻都在讲"豫"（鸣豫、盱豫、由豫、贞疾、冥豫），只有六二不带"豫"字。** 它讲的是**在众人耽于豫乐之时，一个人坚定如石、当天就做出判断并抽身。**<br>**这就是本卦给普通人的正解**：**豫卦最好的位置不是"由豫"（那要你是九四那种唯一的动力源），是"介于石"——在顺势与享乐里保持不被裹进去的判断力。** |
| **与坤六二、艮初六、坤初六的三角对照** | **坤六二**"直方大，**不习**无不利"，象传"地道光也"——**当位得中，德发自内而不刻意**；**艮初六**"艮其趾，无咎，利永贞"，象传"未失正也"——**在脚趾刚要迈出时就止住，止的代价与时机成反比**；**坤初六**"履霜，坚冰至"——**见微知著。**<br>**⚠️ 豫六二把这三条合成了一条**：**它有坤六二的"中正"（当位得中）、有坤初六的"知微"（系辞"知几"）、有艮初六的"止得早"（不终日）。**<br>**可入库的口径：本库「趋势预警」标签（坤初六"履霜"、乾九三"夕惕若"、泰九三"无平不陂"）应补入豫六二——而且它是这一组里唯一同时给出"多快做决定"的（不终日）。** |
| **识别信号** | ① 周围人都处在兴奋、庆祝、觉得"这波稳了"的状态；② 你在干事的核心与基层枢纽位置上（本库通则：二爻）；③ 你心里有一个明确的不安，且能指出具体的那个"几"（细微征兆）；④ 你在犹豫要不要"再看一天"。 |
| **该做** | **当天就决断（不终日），并且坚定如石（介）。** 具体三条，直接照系辞传：**① 不谄上、不渎下（保持关系里的清醒）；② 把那个"几"写下来，指认具体；③ 立刻按判断动作，不给自己"再观察一天"的余地。** |
| **不该做** | 跟着大家的情绪走；或者判断已经清楚了还要拖。**"不终日"三个字是硬指标——它不是形容果断，它是时限。** |

### 六三 · 盱豫

| 字段 | 内容 |
|---|---|
| **爻辞** | 盱豫，悔；迟有悔。 |
| **象传** | 盱豫有悔，位不当也。 |
| **位属性** | 阴爻居阳位，**不当位**（坤在下之律：三不当位）且失中；居下坤之顶，本库通则"**三多凶**"；**紧贴九四之下**。 |
| **判词 → 行动语义** | **悔 ＋ 迟有悔**（同一爻两次给"悔"） → **退·止·舍；而且拖着不改也一样有悔**。 |
| **关键词解** | **盱**（xū）＝张目上视、仰头看（引申为**谄媚地仰望**）。**盱豫**＝**眼睛往上盯着（九四）来求这份乐**——**自己没有，靠仰望别人来分一点**。<br>**悔**＝按本库口径"**退·止·舍**"。**迟有悔**＝**迟疑（不改）也会有悔**。<br>**象传**：**位不当也**——**只给四个字，就是"位置不对"。** |
| **⚠️ 本爻的两个"悔"是一个封闭结构** | 爻辞把两条路都写死了：**做（盱豫）→ 悔；不做而拖着（迟）→ 也有悔。**<br>**这不是"怎么都不行"，而是在逼一个动作：既然做也悔、拖也悔，那唯一没被判悔的选项就是"立刻改"。** 按本库口径，**"悔"的行动语义正是"退·止·舍"** ——**爻辞用两个悔把你逼到"退"这一个出口上。**<br>**对照六二的"不终日"：六二当天就走，所以"贞吉"；六三仰望着、犹豫着，所以两头都是悔。同一个下坤，差一个位置。** |
| **象传只给"位不当也"的写法（本库已有系列）** | **否六三**"包羞"（二字），象传"**位不当也**"；**震六三**"震苏苏"，象传"**位不当也**"；**豫六三"盱豫，悔；迟有悔"，象传"位不当也"。**<br>**三处象传都只用这四个字，不给任何别的解释。** 按本库通则「三爻多凶·位不当」（师六三、履六三、比六三、否六三），**豫六三是第五例。**<br>**⚠️ 但要注意一个分野**：**震六三"位不当也"之后给的是"震行无眚"（顺着动就没灾，因为不正的位置在剧变中不值得守）；豫六三"位不当也"之后给的是两个"悔"（因为豫卦是顺境，位置不正在顺境里没有被冲掉的机会，只能靠自己改）。** **同一句象传，在剧变卦里是机会，在顺境卦里是问题。** |
| **识别信号** | ① 局面很顺，但那份顺不是你造成的；② 你的做法是盯着上面那个人（老板、大客户、核心项目负责人），跟着他分一点；③ 你的位置本来就名不正言不顺（资历、授权、名分有一样不足）；④ 你已经觉得这样不对，但一直在拖。 |
| **该做** | **立刻改。** 具体：**① 停止"盱"（停止把注意力放在仰望上面那个人）；② 回到六二的动作——找到自己那个可以"介于石"的判断，当天就做；③ 或者主动申请一个名分正的位置（这是震六三"震行无眚"的用法，在顺境里要主动去换，不会有人来换你）。** |
| **不该做** | 继续仰望着等分配；或者拖。**"迟有悔"四个字是《周易》预先把"拖"这个选项也判掉了。** |

### 九四 · 由豫（⚠️ 全卦唯一阳爻·卦主·与初六构成本卦核心对照）

| 字段 | 内容 |
|---|---|
| **爻辞** | 由豫，大有得。勿疑，朋盍簪。 |
| **象传** | 由豫大有得，志大行也。 ⚠️ 象传前半复述爻辞，后加"志大行也" |
| **位属性** | 阳爻居阴位，**不当位**（震在上之律：四不当位）；**全卦唯一阳爻，五阴所应——卦主**，即彖传"刚应而志行"之爻；本库通则"**四多惧**"（**但本爻不惧**）。<br>**⚠️ 它是本卦"乘刚"的制造者：它上面的六五因它而乘刚。** |
| **判词 → 行动语义** | **大有得** → **让全卦的乐由你而出；不要猜疑，人自然聚过来**。 |
| **关键词解** | **由**＝从、自、因由。**由豫**＝**这份"豫"是从他这里出来的**（全卦五阴之乐皆由九四而来）。**大有得**＝**大有所得**（⚠️ 注意与第 14 卦"大有"同字，但此处是"大大地有所得"，不是卦名）。<br>**勿疑**＝**不要猜疑**（不要怀疑那些聚过来的人）。**朋盍簪**——**"朋"＝朋类、同伙；"盍"＝合、聚；"簪"＝束发之簪**。**朋盍簪**＝**朋类聚合起来，像发簪把头发束在一起那样。**<br>**象传**：**志大行也**——**志向大大地推行开了**（与彖传"刚应而志行"呼应）。 |
| **⚠️ 本爻与初六的对照是全卦核心（必须合读）** | **初六与九四互为正应——是同一条关系的两端。**<br>**两爻位属性完全相同：都不当位。**<br>**两爻面对的是同一样东西：这份"豫"（顺势带来的乐与势头）。**<br>**动作不同**：<br>**初六"鸣"——把它叫出去（"我有这个"）→ 象传"志穷" → 凶。**<br>**九四"由"——让它从自己这里流出去（"这个从我这来，给你们"）→ 象传"志大行" → 大有得。**<br>**⚠️ 结论（本卦最重要的一条，可直接入库）：同一份资源、同一种位属性、同一条关系，"向外叫嚷自己拥有它"是凶，"成为它的来源并让它流出去"是大有得。差别只在一个字，判词隔了十级。**<br>**而这正是大象传的落地**：**"作乐崇德，殷荐之上帝，以配祖考"——把乐做成公共的、指向更大来源的，就是"由"；把乐当成自己的资本，就是"鸣"。** |
| **"勿疑"两个字为什么必要（本爻最实用的一条）** | 九四是**唯一的阳，被五个阴围着**，而且**不当位**（名分不足）。这样的人天然会疑：**这些人是真心跟我，还是来分好处的？**<br>**爻辞的回答只有两个字："勿疑"，然后给了一个结果："朋盍簪"（人像发簪束发那样自然聚起来）。**<br>**逻辑是：你是"由"（乐的来源），聚过来是结构决定的，不是人心决定的。一疑，你就会开始筛人、控制、分配不公——"由"立刻断掉，"朋"立刻散掉。** |
| **⚠️ 与师九二的对照（本库"一阳统五阴"的第三个实例）** | 本库已有两个"一阳统五阴"的卦：**师（一阳在九二，下卦之中）＝统帅在军中；比（一阳在九五，上卦之中）＝君主在位、众人来归。**<br>**豫补上第三个：一阳在九四——既不在下卦之中，也不在上卦之中，而在"上卦之始、紧贴尊位之下"。**<br>| | 一阳所在 | 身份 | 判词 | 与尊位的关系 |<br>|---|---|---|---|---|<br>| **师 7** | 九二（下卦之中，**得中**） | 统帅（丈人） | 在师**中吉**，无咎，王三锡命 | **六五授权、九二执行——全卦唯一吉配** |<br>| **比 8** | 九五（上卦之中，**得中·当位**） | 君主 | **吉**（显比） | **它自己就是尊位** |<br>| **豫 16** | 九四（**不当位·不得中**） | 实际动力源 | **大有得**（由豫） | **它顶在六五之下——六五因它而"贞疾"** |<br>**⚠️ 结论：同样是"一阳统五阴"，位置决定它与尊位的关系。九二得中而受授权（吉配）；九五自己就是尊位（吉）；九四既不得中又不当位，它的力量不来自名分而来自"由"（众人的乐从它出），代价是它把尊位顶成了"贞疾"。**<br>**这也解释了豫卦辞为什么是"利建侯行师"：九四这种"有实际动能而无尊位"的形态，正是"建侯"（授出一块地盘）与"行师"（把兵交给一个统帅）的结构形态。** |
| **识别信号（若你是九四）** | ① 整个局面的动能实际上来自你（人、事、势都靠你带起来）；② 你的名分不够（不当位）——职级、授权、资历有一样不足；③ 上面那个位置的人在这件事上做不了主，甚至处境别扭；④ 有很多人聚过来；⑤ 你开始怀疑他们的动机。 |
| **该做** | **① 保持"由"——让好处、机会、荣誉持续从你这里流向别人，而不是流向你自己**（这正是大象传"作乐崇德"）；**② 勿疑——不要筛人、不要试探忠诚度**；**③ 主动处理与六五的关系**：**参照师九二"把授权用足，但不越位"，以及坤六五"虽有君之权而以臣自处"。** 九四的最大风险不是别人不跟，是它把六五顶得太难受。 |
| **不该做** | 把这份"由"变成"有"（据为己有）；猜疑聚过来的人；或者去争六五那个名分。**注意九四不当位是结构性的（震在上则四必不当位），争不来。** |

### 六五 · 贞疾（⚠️ 全书第二处象传明写"乘刚也"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 贞疾，恒不死。 |
| **象传** | 六五贞疾，乘刚也。 |
| **位属性** | 阴爻居阳位，**不当位**（震在上之律：五不当位），但**得中**且居尊位；**直接乘于九四之上——乘刚，且象传直接点名**。 |
| **判词 → 行动语义** | **贞疾 ＋ 恒不死**（⚠️ 本库判词表原未收"贞疾"，见下） → **守着这个位置就带着病；病不会好，但也死不了**。 |
| **关键词解** | **贞**＝守持、固守（与"贞凶"的"贞"同用法：**守正／守持**）。**疾**＝病。**贞疾**＝**守持着而有病／病成了常态**。**恒**＝长久、恒常。**恒不死**＝**长久地不死**。<br>**象传**：**乘刚也**——**因为它乘在刚（九四）之上。** 三个字，就是全部原因。 |
| **⚠️ 本爻是本库"震在上则六五必乘刚"的完整实证** | 震卡（51）立下的律：**"震把阳放在最下往上顶，所以震在下则六二必乘刚，震在上则六五必乘刚。"** 并指出**震六二象传"震来厉，乘刚也"是全书把这三个字直接写出来的地方。**<br>**⚠️ 豫六五是第二处，也是全书最后一处**：**"六五贞疾，乘刚也。"**<br>**两处合起来，这条通则从"推论"升级为"经文明证"**：<br>**震在下 → 六二乘刚 → 震六二"震来厉，亿丧贝"（大损）；**<br>**震在上 → 六五乘刚 → 豫六五"贞疾，恒不死"（带病维持）。**<br>**⚠️ 而且两处的受害程度不同，原因清楚：六二在下卦，可以"跻于九陵"（上高地）、可以"勿逐"（不追）——它有闪避空间；六五在尊位上，不能缩小范围、不能躲，所以只能"恒不死"。** |
| **⚠️ "贞疾"是本库判词表未收的新判词（建议入库）** | 本库现有相关词条：**贞凶＝守正也凶（问题不在品德，在处境与选择的根本错位）；无判词＋象传"未光也"＝不在吉凶十级之内。**<br>**"贞疾，恒不死"应单列一条**：<br>**语义：守着这个位置就必然带病，病是慢性的、不会好；但也不会死。**<br>**行动语义：不要试图治好它，要学会带病运转——把资源放在"不死"上，不放在"痊愈"上。**<br>**在吉凶序中的位置：它不在十级之内**（既不是凶，也不是厉，也不是悔）。**它是一种"慢性化的失能状态"——与震九四"遂泥／未光也"（白费力气）同属"不判吉凶、只描述处境"的一类，但比它重：震九四是一时动不了，豫六五是长期带病。**<br>**⚠️ 与"贞凶"的分别（极重要）**：**"贞凶"＝守正也凶，问题在处境与选择的根本错位，要改选择；"贞疾"＝守正而有病，病不会好也不会死，处境无法改变（因为乘刚不是你的对错造成的），只能改运转方式。** |
| **本爻在"六五／九五"专题中的特殊性（本库第七例，也是最难的一例）** | 已有六例：**乾九五**（居尊而求贤）、**坤六五**（有君之权而守臣节）、**蒙六五**（居尊而不失赤子之心）、**离六五**（居尊而痛哭）、**艮六五**（居尊而闭嘴）、**大有六五**（居尊而以柔容众但保住威）。<br>**⚠️ 豫六五是第七种，也是唯一一种"没有主动动作可做"的**：**它不是"放弃某样特权"，是"它的权本来就不在自己手上"（动能在九四）。**<br>**所以爻辞没有给它任何指令，只给了一个状态："贞疾，恒不死"。**<br>**按本库口径（"无判词＋只给心理／身体状态"）：《周易》承认你的处境，但不判你有咎，也不授权你去夺回来。** 这与**艮六二**"其心不快"（当位得中，却救不了它跟随的人，象传"未退听也"）是完全同一种写法——**只不过艮六二是辅佐者的憋屈，豫六五是决策者的带病。** |
| **识别信号（若你是六五）** | ① 你在名义上的最高位置上；② 实际的动能、人望、执行力在你下面那个人手里（九四）；③ 你的名分不完全够（不当位），靠的是居中和众人默认；④ 你长期处在一种"难受但不致命"的状态：说不上哪里出了问题，但每件事都要经过那个人；⑤ 你想过一次性解决它。 |
| **该做** | **① 承认"乘刚"不是你的错**——象传只给了三个字，它没有责备你；**② 把目标从"治好"改成"不死"**：守住你唯一的资本"得中"（本库通则：**得中可救不当位**，震六五"其事在中也／亿无丧"是标准例）；**③ 参照师六五"选对人然后放手"** ——**豫六五真正可行的动作，是把九四的位置正式化（这正是卦辞"利建侯"：授出去，让他名正言顺地干），而不是去压他。** 压不动，还会把"贞疾"变成对抗。 |
| **不该做** | 试图一次性夺回动能（乘刚的压力来自结构，不来自九四的对错）；或者反过来彻底放手不管（"恒不死"的前提是你还在这个位置上守着）。 |
| **与师六五、震六五的三角对照** | **师六五**"田有禽，利执言，无咎。长子帅师，弟子舆尸，**贞凶**"，象传"使不当也"——**居尊不亲自上阵，唯一动作是"选谁"，用对则无咎、用错则贞凶**；**震六五**"震往来厉，**亿无丧**，有事"，象传"其事在中也"——**前后都在震，只守住那件不能停的本职**；**豫六五"贞疾，恒不死"，象传"乘刚也"——名分在我、动能在他，长期带病维持。**<br>**⚠️ 三个五爻都不当位而得中，动作依次递减：师六五还能"选"，震六五还能"守本职"，豫六五什么都不能做，只能"不死"。**<br>**而它们的救法是同一个："得中"。** 本库通则"**得中可救不当位**"在这里显示了它的下限：**得中能救到的最低程度，就是"恒不死"。** |

### 上六 · 冥豫

| 字段 | 内容 |
|---|---|
| **爻辞** | 冥豫成，有渝，无咎。 |
| **象传** | 冥豫在上，何可长也。 |
| **位属性** | 阴爻居阴位，**当位**（震在上之律：上当位）；居全卦之终。 |
| **判词 → 行动语义** | **无咎（有条件）** → **沉溺已成定局；只要改，就没灾**。 |
| **关键词解** | **冥**＝昏冥、昏暗、沉溺不明。**冥豫**＝**沉溺在豫乐里而昏昏不明**。**成**＝已成、成了定局（习惯已经养成）。**有渝**＝**有所变改**（"渝"＝变）。**无咎**＝则无灾。<br>**象传**：**何可长也**——**这怎么可能长久呢。** |
| **⚠️ 本爻的判词结构（"成"与"渝"的对立是全爻的重量）** | 爻辞把两个字并列摆出来：**"成"（已经定型了）与"渝"（改）。**<br>**"冥豫成"是承认现实：沉溺已经不是一次行为，是已经成型的状态（对照初六"鸣豫"还只是一个动作）。**<br>**"有渝，无咎"是唯一的出口：只要有变改，就没灾。**<br>**⚠️ 注意《周易》在这里的宽厚：一个沉溺到"冥"、而且已经"成"的人，只要"有渝"，判词就是"无咎"。** 按本库口径，**无咎≠吉利**——**它不许诺你能挽回什么，只承诺"不会有灾"。这已经是这个位置能给的上限。** |
| **"何可长也"的双刃在本爻的用法（本库已有通则）** | 泰否卡已立：**"何可长也"是双刃——顺境中它是"盈不可久"的警告，逆境中它是"否终则倾"的希望**（否上九"否终则倾，何可长也"是安慰；离九三"何可久也"是警告）。<br>**豫上六的"何可长也"是警告那一侧**：**沉溺这件事不可能长久——所以你必须"渝"。**<br>**三处并读：离九三"何可久也"（光明不可久，要接受）／否上九"何可长也"（闭塞不可久，要撑住）／豫上六"何可长也"（沉溺不可久，要改）。同一句话，三种用法，全看卦境。** |
| **本爻在"上爻"通则中的位置（艮卡通则表的补充）** | 艮卡（52）已立：**"上＝物极必反"要加限定——反的是"不知止的极"。** 并列出纯卦上爻序列（乾悔／坤凶／坎凶／离无咎／震征凶无咎／艮吉）。<br>**豫上六补上一种新的脱险机制**：**乾坤是"不知止"（凶／悔），艮是"知止"（吉），大有是"交出"（吉），豫上六是"改"（渝 → 无咎）。**<br>**⚠️ 可入库：上爻脱离凶险共有三条路——知止（艮）、交出（大有）、变改（豫）。乾上九"有悔"，是因为三条都没走。** |
| **本爻当位却只得"有条件的无咎"** | 上六阴居阴位，**当位**。但当位在这里救不了它——**因为它的问题不是位置，是状态（冥）。**<br>**对照本库其他"当位的上爻"**：**坤上六**当位而"龙战于野"（**凶**，由顺变夺）；**泰上六**当位而"城复于隍"（顺境崩塌，只能自邑告命）；**震上六**当位而"征凶……无咎"（畏邻戒则无咎）。<br>**通则：上爻的当位不决定吉凶；决定吉凶的是它做不做那个本卦要求的收尾动作。** |
| **识别信号** | ① 顺势期已经持续了很久，你在最上面／最远的位置上；② 享乐、松懈、"这样就挺好"已经变成常态和习惯（成）；③ 你已经想不起当初为什么要做这件事；④ 你隐约知道这样下去不行，但觉得"已经这样了"。 |
| **该做** | **就一个字：渝（改）。** 具体：**① 承认"成"——不要骗自己说这只是暂时松一下；② 做一个具体的、可验证的改变（不是决心，是动作）；③ 回到大象传"作乐崇德"——把这份乐重新接到"德"和"更大的来源"上去。**<br>**注意判词只承诺"无咎"（无灾），不承诺挽回。所以越早"渝"越好。** |
| **不该做** | 用"已经这样了"来合理化。**象传"何可长也"是《周易》在这里唯一的态度：它不骂你，它只告诉你这个状态没有未来。** |

**豫卦三句话**：
1. **"顺以动"才叫豫。** 下坤是顺、上震是动——**"顺"（底子）是"动"（发动）的资格证。** 彖传把话说到天地上："**天地以顺动，故日月不过，而四时不忒**"。**无顺而动，就是初六。**
2. **这份乐必须被"作"成制度。** 大象传"**作乐崇德，殷荐之上帝，以配祖考**"是全书唯一一条以音乐为纲领的——**把顺势带来的喜悦做成公共的、指向更大来源的东西**。做到了是九四"由豫"，没做就是初六"鸣豫"。
3. **豫卦的动力在四、名分在五，不在同一个人身上。** 九四"志大行也"，六五"贞疾，乘刚也"。**所以卦辞只给一个"利"，而且利在"建侯行师"——授权出去，不要自己独揽。**

**本卦最反直觉的两条**：
- **初六与九四位属性完全相同（都不当位）、互为正应（是同一条关系的两端）、面对的是同一份"豫"，判词却是"凶"与"大有得"——按本库吉凶序隔了整整十级。** 差别只在一个字：**"鸣"（向外叫嚷自己拥有它）还是"由"（成为它的来源，让它流出去）。**
- **全卦六爻里，唯一"当位＋得中"的六二，是唯一不讲"豫"的一爻。** 在一个人人都在享乐的卦里，《周易》把最高评价（系辞传"**知几其神乎**……**万夫之望**"）给了那个"**不终日**"就抽身的人。**豫卦给普通人的正解不是"由豫"，是"介于石"。**

## 四、⚠️ 本卡对全库的意义

### 1. 与师卦（07）的实质对照：豫是师的前置条件卡

震卡点名"豫卦卦辞'利建侯行师'直接衔接师卦"。**逐项对照如下**：

| 对照项 | **豫 16（上震下坤）** | **师 7（上坤下坎）** |
|---|---|---|
| **卦象** | 顺在下、动在上 | 险在下、顺在上 |
| **彖传核心** | **顺以动**（先顺，然后动） | **行险而顺**（明知是险，以顺的方式行之） |
| **卦辞** | **利**建侯行师（**唯一说"行师"是"利"的地方**） | **贞**，丈人吉，无咎（**无元无亨无利，只有贞**） |
| **天道态度** | **许可并鼓励"授权与动员"** | **不鼓励，只教你少死人** |
| **民众代价** | 圣人以顺动，则**刑罚清而民服** | 以此**毒天下**而民从之 |
| **一阳所在** | 九四（**不当位**，动能源，但无尊位） | 九二（**得中**，统帅，受六五授权） |
| **尊位状态** | 六五"**贞疾，恒不死**"（被九四顶着，做不了主） | 六五"田有禽，利执言"（**唯一动作是"选谁"，决定全卦成败**） |
| **它管的问题** | **该不该发动**（顺不顺、授不授权） | **发动之后怎么办**（立律、择帅、退守、论功） |

> **⚠️ 可直接入库的路由口径**：
> **用户问"我该不该发动这件事／要不要扩张／要不要授权给某人独当一面" → 先走豫卦**（查"顺"在不在：底下的基础顺不顺、势头是不是真的；再查"你是九四还是六五"）。
> **已经发动了，问"怎么打／怎么带／谁指挥／打完怎么分" → 转师卦。**
> **两卦合起来是一条完整的链：豫（顺以动，利建侯行师）→ 师（贞，丈人吉，师出以律……小人勿用）。而《周易》的态度极一致：发动本身可以是"利"的，但发动之后就没有任何好处可许诺了。**

| 六二 | **当位·得中** | → 五 | 六五 | 不当位·得中·**乘刚** |
| 九三 | **当位**（卦主） | → 四 | 九四 | **不当位**（卦主） |
| 六四 | **当位**·乘刚 | → 三 | 六三 | 不当位 |
| 六五 | 不当位·得中 | → 二 | 六二 | **当位·得中** |
| 上六 | **当位** | → 初 | 初六 | 不当位 |
| **合计** | **4 当位** | | | **2 当位** |

|---|---|---|
| **当位数** | **4** | **2** |
| **六爻判词** | 吉／贞吉／吉／无不利／无不利／利 | **凶**／贞吉／**悔·迟有悔**／大有得／**贞疾**／有渝无咎 |

### 3. "震在上则六五必乘刚"从推论升级为经文明证

震卡（51）立律：**震把阳放在最下往上顶 → 震在下则六二必乘刚，震在上则六五必乘刚。** 并指出**震六二象传"震来厉，乘刚也"是全书把这三个字直接写出来的地方。**

**⚠️ 豫六五象传"六五贞疾，乘刚也"是第二处，也是全书最后一处。两处合起来，这条律有了双向的经文明证：**

| 震所在 | 乘刚之爻 | 爻辞 | 象传 | 可否闪避 | 结果 |
|---|---|---|---|---|---|
| **震在下**（震 51、屯 3） | **六二** | 震来厉，亿丧贝，跻于九陵，勿逐，七日得 | **"乘刚也"** | **能**（上高地、不追） | **厉**·大损但七日可回 |
| **震在上**（豫 16） | **六五** | 贞疾，恒不死 | **"乘刚也"** | **不能**（尊位无法缩小范围） | **贞疾**·长期带病 |

> **⚠️ 结论（本卡最重要的技术增量，与谦卡的六四合读）**：
> **乘刚落在第四位还有解**——六四可以"止诸躬"（艮，收缩范围）、"田获三品"（巽，交付成果）、"撝谦"（谦，推行规矩），判词分别是无咎／—／**无不利**。
> **乘刚落在第五位就没有解**——**因为尊位不能靠"缩小自己"来自救**。所以豫六五只能"恒不死"。
> **这就是本库"震在上＝动在头顶（你做不了主）"这条定势最深层的原因：震在上必然把乘刚推到六五，而六五是全卦唯一不能用"缩小范围"自救的位置。**
> **同时，本库"乘刚的来源＝震"这条通则得到进一步精确化**（另见知识卡 13 末节第 3 条）：**离体内部虽有阴居阳上的形式（离六二、离六五、同人六二、大有六五），象传从不以"乘刚"为释——因为离是"一阴丽于二阳"，阳是夹持与承托，不是上顶。乘刚的强度取决于那个阳爻朝哪个方向用力。**

### 4. 新增与修订的通则

| 项目 | 内容 |
|---|---|
| **新判词：贞疾** | **贞疾，恒不死**（豫六五）。**语义：守着这个位置就必然带病；病是慢性的、不会好，但也不会死。行动语义：不要试图治好它，把资源放在"不死"上而不是"痊愈"上。** 在吉凶序中**不在十级之内**（与震九四"未光也"同类，但更重：震九四是一时动不了，豫六五是长期带病）。**与"贞凶"的分别：贞凶＝要改选择；贞疾＝处境改不了（乘刚不是你的对错），只能改运转方式。** |
| **新律：「鸣」的吉凶取决于内实** | **谦六二"鸣谦，贞吉"（中心得也）／谦上六"鸣谦，利用行师"（志未得也）／豫初六"鸣豫，凶"（志穷凶也）。** 三处三判，且谦豫互为覆卦。**通则：声名外扬本身没有吉凶，取决于里面是"中心得"、"志未得"还是"志穷"。** 与本库已有"泰初九／否初六同为拔茅茹而判词相反"同级。 |
| **新律：「鸣」与「由」（本卡最实用的一条）** | **初六"鸣豫，凶" ↔ 九四"由豫，大有得"。** 两爻位属性相同（都不当位）、互为正应、面对同一份资源，判词隔十级。**通则：同一份势头，"向外叫嚷自己拥有它"是凶，"成为它的来源并让它流出去"是大有得。** 建议做成产品里的一道诊断题：**你现在是在"鸣"还是在"由"？** |
| **补"一阳统五阴"专题第三例** | **师九二（得中，受授权，吉配）／比九五（自己就是尊位，吉）／豫九四（不当位不得中，力量来自"由"而非名分，代价是把尊位顶成"贞疾"）。** 通则：**同样是一阳统五阴，那个阳在哪一位，决定它与尊位是"配合／同体／相顶"三种关系中的哪一种。** |
| **补"六五／九五"专题第七例** | 乾九五（求贤）／坤六五（守臣节）／蒙六五（童心）／离六五（眼泪）／艮六五（闭嘴）／大有六五（柔中留威）／**豫六五（唯一"没有主动动作可做"的一例：权本来就不在自己手上，爻辞只给状态"贞疾，恒不死"）**。**写法与艮六二"其心不快"完全同构：《周易》承认你的处境，但不判你有咎，也不授权你去夺回来。** |
| **补"上爻脱险路径"** | 艮卡已立"上爻之凶只来自不知止"。**三条脱险路径：知止（艮上九"敦艮，吉"）／交出（大有上九"自天佑之，吉"）／变改（豫上六"有渝，无咎"）。乾上九"有悔"是因为三条都没走。** |
| **补「趋势预警」标签（并补时限）** | 坤初六"履霜坚冰至"、乾九三"夕惕若"、泰九三"无平不陂，无往不复"、**豫六二"介于石，不终日"＋系辞传"知几其神乎"**。**⚠️ 豫六二是这一组里唯一给出时限的：不终日。** |
| **补「三爻多凶·位不当」第五例** | 师六三"舆尸"、履六三"咥人"、比六三"匪人"、否六三"包羞"、**豫六三"盱豫，悔；迟有悔"（象传同样只给"位不当也"四字）**。**⚠️ 并补一条分野：同一句"位不当也"，在震六三之后接的是"震行无眚"（剧变中动是机会），在豫六三之后接的是两个"悔"（顺境中位置不正没有被冲掉的机会，只能自己改）。** |
