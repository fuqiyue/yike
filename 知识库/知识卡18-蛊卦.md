# 知识卡 18 · 蛊卦（山风蛊）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："以喜随人者必有事，故受之以蛊。蛊者，事也。"——**凭着高兴跟着别人走，必然会积下事情**，所以随（17）之后接蛊。**序卦传自己把"蛊"训为"事"，而且给出了因果：喜随人 → 必有事。**
> ⚠️ **本卦是全库唯一一卦直接讲"接手上一代／前任留下的烂摊子"**：**六爻中五爻都在讲"干父之蛊／干母之蛊"（整治上一代留下的积弊），只有上九跳出这件事**（详见第二节与末节）。
> ⚠️ **本卦卦辞"先甲三日，后甲三日"与本库巽卦（57）九五"先庚三日，后庚三日"是全书唯一的一对姊妹句**（**甲＝始事，庚＝更事**），**两卦必须合读**。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 蛊 · 第十八卦 |
| **卦象** | 上艮（山/止）下巽（风/顺入），称"**山风蛊**"。大象传"**山下有风**"——**风被山压在下面，吹不出去**；空气不流通，所以生蛊（腐坏）。彖传的定性是"**刚上而柔下，巽而止**"。 |
| **⚠️ 卦象直接解释了病因（本卦最重要的结构读法）** | **"巽而止"这三个字就是积弊的成因公式**：<br>**巽＝顺（下面一味地顺从、不提意见、不作声）；艮＝止（上面压着、停滞、不许动）。**<br>**一味顺 ＋ 停着不动 ＝ 生蛊。**<br>**这不是比喻。器皿之所以生虫，不是因为有人往里放了虫，是因为它久置不动、不通风。所以蛊卦的病因是结构性的：没人做坏事，弊也会长出来。**<br>**⚠️ 这一条是本卦对全库最重要的贡献：本库此前所有讲困境的卦（坎＝陷险、震＝突变、讼＝争讼、否＝闭塞）都有一个外部起因；蛊是唯一一个"没有起因、只因为久了"的困境。** |
| **⚠️ 本卦的当位分布（按本库第 4 节结构律逐爻验证）** | **巽在下 → 初六不当位、九二不当位（得中）、九三当位**；**艮在上 → 六四当位、六五不当位、上九不当位**。<br>**逐爻核对**：初六（阴居阳位）不当位 ✓｜九二（阳居阴位）不当位但得中 ✓｜九三（阳居阳位）当位 ✓｜六四（阴居阴位）当位 ✓｜六五（阴居阳位）不当位但得中居尊 ✓｜上九（阳居阴位）不当位 ✓。<br>**⚠️ 六四是全卦唯一乘刚之爻**（阴爻六四直接压在阳爻九三之上）。**这个乘刚出现在上下卦交界处：下卦巽以阳爻收尾（九三），上卦艮以阴爻起头（六四）。** 本库巽卦六四、艮卦六四的乘刚同出于此。 |
| **领域定义** | **接手一个已经坏掉的局面，整治长期积下的弊病**。① 接手一个烂摊子部门／公司／项目，前任留下一堆没人愿意碰的问题；② 继承家业，同时继承了历史债务与旧人事；③ 新任负责人面对沿用多年的旧制度、旧班底、旧潜规则；④ 家庭里父辈遗留的问题（债务、亲戚关系、代际习惯、一直不许提的那件事）；⑤ 行业长期形成的积弊与潜规则；⑥ **自己身上长期形成的坏习惯与旧模式**——此时你就是自己的"父"。<br>凡是"这个问题不是我造成的，但现在得我来收拾"，都落在蛊卦。 |
| **不归本卦的情况** | ① 是从零开始、什么都没有 → **屯卦**（3）：**屯是"没有"，蛊是"有，但坏了"**；② 是突然砸下来的新冲击 → **震卦**（51）：**震是七日型的冲击，蛊是几十年攒出来的**；③ 是已经陷在险里出不来 → **坎卦**（29）；④ 是要柔性推行一套新规矩 → **巽卦**（57）：**巽是"行新"（更事用庚），蛊是"治旧"（始事用甲）**；⑤ 是该收手不干了 → **艮卦**（52）——**但蛊上九正是蛊卦里那个"艮"的选项**。 |
| **"蛊"字本义** | **字形从"虫"在"皿"中**——**器皿里生了虫**。本义指**器物、食物久置不用而腐坏生虫**，引申为**积久而成的弊病、蠹害、烂摊子**。<br>**⚠️ 序卦传特意把它训成另一个字："蛊者，事也。"** 这个训解极关键：**《周易》不把蛊看成"灾"，看成"事"——是待办事项，不是判决书。** 彖传接着说"**蛊，元亨而天下治也**"：**把蛊治好，是通天下的大事。** |
| **卦辞原文** | 蛊：元亨，利涉大川。先甲三日，后甲三日。 |
| **⚠️ 卦辞的关键结构（有元、有亨、有利，独缺"贞"）** | **元、亨、利（利涉大川）三者齐备，唯独没有"贞"。**<br>**在本库现有各卦的对照里，这个缺失极其醒目**：师卦"只有贞"（天道对战争不许诺好处）；随卦"元亨利贞全给"（但补一句无咎）；**蛊卦反过来——好处给足（元亨），大事许你去做（利涉大川），偏偏不给"贞"。**<br>**⚠️ 而这个缺失在爻里得到了正面确认：九二"干母之蛊，不可贞"——《周易》直接写出"不可贞"三个字。**<br>**合读结论（本卦最重要的一条口径）：治积弊这件事，天道许你成大功（元亨），但不许你用"守正到底"的方式去做。有些局面根本不容许一刀切的正。这就是"贞"字缺席的原因。** |
| **卦辞现代解** | **元亨**——治蛊能通到根本上，是最高级别的许诺（彖传"元亨而天下治也"）。<br>**利涉大川**——宜于渡大河，即**宜于去做这件大而险的事**。彖传解为"**往有事也**"——**你去，是有事情要做的**，不是去观望。<br>**先甲三日，后甲三日**——见下条。 |
| **⚠️ "先甲三日，后甲三日"解（与巽九五的姊妹句）** | **"甲"是十天干之首，古义即"始"**——**始事用甲**。（对照本库巽九五"**先庚三日，后庚三日**"，"庚"通"更"，即变更——**更事用庚**。）<br>**全句：在正式动手整治的那一天之前三天、之后三天，都要反复申明。**<br>**彖传给了这句话的理由，也是全书最好的一句时间观："终则有始，天行也"——一件事结束了才有新的开始，这是天道的运行方式。**<br>**操作含义**：<br>**① 前三日**——把"哪些算积弊、为什么现在动、动到哪一步为止"反复讲清楚；<br>**② 中间那一日（甲日）**——才是真正动手的那一天；<br>**③ 后三日**——反复确认"改到了没有、谁没跟上、哪里卡住"。<br>**⚠️ 与巽九五的分工必须记住：巽的"庚"是改一个现有规矩；蛊的"甲"是重新开一个头。治蛊不是修补，是"终则有始"——先承认旧的那一段已经结束了。** |
| **彖传** | 蛊，刚上而柔下，巽而止，蛊。蛊，元亨而天下治也。利涉大川，往有事也。先甲三日，后甲三日，终则有始，天行也。 |
| **彖传要点** | ① **"巽而止，蛊"**——见上文"卦象直接解释了病因"：**一味顺 ＋ 停滞不动 ＝ 生蛊**。<br>② **"元亨而天下治也"**——**把蛊治好，天下就治了**。**《周易》给治蛊的评价极高，与卦辞"元亨"完全对应。**<br>③ **"往有事也"**——**"利涉大川"不是叫你去冒险，是叫你去干活。**<br>④ **"终则有始，天行也"**——**这是"先甲后甲"的理由，也是本卦最高层的时间观：治蛊的第一个动作是给旧的那一段划上句号。** |
| **大象传（行动纲领）** | 山下有风，蛊。君子以振民育德。 |
| **⚠️ "振民育德"解（本卦最容易被跳过、却最要紧的一条）** | **振**＝振起、振作、摇动（与"震"同源，是把停滞的东西动起来）；**民**＝众人；**育德**＝培育德行。<br>**全句：把人振作起来，把德养起来。**<br>**⚠️ 注意这条纲领在讲什么：它一个字都没提"治蛊"。** 六爻讲了五遍怎么"干蛊"，**而最高纲领讲的是先动人、先育德。**<br>**为什么？因为病因是"巽而止"（顺而不动）。所以解药不是先动制度，是先把人从"一味顺、不作声、不动"的状态里振起来。**<br>**操作含义（本卦最高原则）：治积弊的第一步不是清理事，是让人重新动起来、重新有标准。事是靠人治的；人还在原来那个"顺而止"的状态里，制度改一百遍也会长回来。** |
| **总铁律** | ① **蛊是内生的（巽而止），不是外来的**——**不要去找一个该负责的坏人**；② **动手之前先"振民育德"**（大象传）：先动人，再动事；③ **动作是改，用意是承**（初六象传"意承考也"）——**整治不是清算前任**；④ **"干父之蛊"可以刚（初六厉终吉、九三小有悔），"干母之蛊"不可贞（九二）**——**对刚硬的积弊可以硬来，对柔软的积弊不可以**；⑤ **最危险的不是干错，是"裕"（宽纵不管）**——六四"裕父之蛊，往见吝"；⑥ **居尊治蛊要"用誉"，不用刑**（六五）；⑦ **"不事王侯"是本卦唯一的出局选项，而且《周易》许可它**（上九"志可则也"）。 |

## 二、爻级字段

> ⚠️ **本卦的六爻结构是全书最特殊的之一，读之前先看这张结构表**：

| 爻 | 干谁的蛊 | 动作 | 判词 |
|---|---|---|---|
| 初六 | **父**（干） | 干父之蛊，有子，考无咎 | **厉 → 终吉** |
| 九二 | **母**（干） | 干母之蛊 | **不可贞** |
| 九三 | **父**（干） | 干父之蛊 | **小有悔，无大咎** |
| 六四 | **父**（**裕**——不干） | 裕父之蛊 | **往见吝** |
| 六五 | **父**（干） | 干父之蛊 | **用誉** |
| 上九 | **不干了** | 不事王侯，高尚其事 | **无判词，象传"志可则也"** |

> **三条结构性事实**：
> ① **初六到六五，五爻全部在处理"上一代留下的蛊"**——这在六十四卦里是唯一的。**《周易》用整整五爻只讲一件事：怎么收拾前人留下的摊子。**
> ② **五爻中四爻是"干"（整治），只有六四是"裕"（宽纵放任）——而六四是这五爻里唯一被判"吝"的。**
> ③ **上九是唯一跳出这件事的一爻**，它不干蛊，而《周易》不判它有咎，反而说"**志可则也**"（其志可以作为法则）。

### 初六 · 干父之蛊（动作是改，用意是承）

| 字段 | 内容 |
|---|---|
| **爻辞** | 干父之蛊，有子，考无咎，厉终吉。 |
| **象传** | 干父之蛊，意承考也。 |
| **位属性** | 阴爻居阳位，**不当位**（巽在下 → 初必不当位）；居全卦最下——**积弊最初、最微、最好动的地方** |
| **判词 → 行动语义** | **厉 → 终吉**（按本库口径：**厉＝警告，非判死**） → **趁最微处就动手，过程有危，结果终吉** |
| **关键词解** | **干**＝治、整治、匡正（读 gàn，与"干事"同义；一说通"乾"，有强力承担之意）。**蛊**＝积弊。**有子**＝有（能承担的）儿子。**考**＝**对已故父亲的称谓**（《礼记》"生曰父，死曰考"）。**考无咎**＝**父亲因此得以无咎**。<br>**⚠️ 断句异文**：亦有断作"**有子考，无咎**"者，义则相近。**经文用字不变。** |
| **⚠️ 本爻最重的一句是"有子，考无咎"（全书唯一）** | **"因为有这样一个儿子去整治，那位已故的父亲才得以无咎。"**<br>**这是六十四卦里唯一一处说"你的整治能让前任免于咎责"。** 它把治蛊的性质彻底定了下来：<br>**治蛊不是审判前任，是替前任把账做平。** |
| **⚠️ 象传"意承考也"是本卦全部姿态的来源** | **"意"＝用意、动机；"承"＝承继。全句：用意是承继父亲。**<br>**这四个字与"干"（整治）形成了本卦最重要的一组张力**：<br>**动作上你在改他留下的东西，用意上你是在承继他。**<br>**本库口径（可直接给读者的一句话）：治蛊的合法性不来自"前任错了"，来自"我要把他没做完的做完"。凡是以否定前任来为自己的整治找合法性的，都不是"意承考"，而是另立一摊——那已经不是蛊卦的动作了。** |
| **"厉终吉"的读法** | **过程有危（厉），结局是吉（终吉）。**<br>**按本库吉凶序，"厉"是警告不是判死；而"终吉"是明确的好结局。** 这个组合在说：**在最微处动手，会挨骂、会碰人、会有风险，但这是全卦成本最低的时机。** |
| **识别信号** | ① 你刚接手，问题还只是些"大家都知道但没人说"的小事；② 你还没有得罪任何人，也还没有动任何人的利益；③ 你的名分尚不足（不当位）——你是新来的；④ 你倾向于"先熟悉一段时间再说"。 |
| **该做** | **① 先明确宣告"我是来承继的，不是来清算的"（意承考）；② 在最小、最不涉及人事的那一处先动手；③ 接受过程中的"厉"（有人会不高兴），不因此停手。** |
| **不该做** | 用否定前任来给自己的整治找合法性。**也不要"先熟悉一段时间"——初六是全卦成本最低的窗口，过了这个窗口，就要付九三的"小有悔"。** |
| **与艮初六"艮其趾"的呼应（同一条时机律）** | **艮初六"艮其趾，无咎，利永贞"，象传"未失正也"——止得足够早，几乎零成本；拖到"限"（腰）上再止，就要"列其夤"（撕裂脊背）。**<br>**蛊初六"干父之蛊…厉终吉"——干得足够早，只需承受"厉"。**<br>**两卦一止一干，给的是同一条律：处理旧问题的代价与动手的时机成反比。本库到此可以立一条通则：无论是"止"还是"干"，最下面那一爻永远是成本最低的窗口。** |
| **与蒙初六的对照** | **蒙初六"发蒙，利用刑人…以往吝"——开蒙第一式是立规矩，但禁忌是急于求成**；**蛊初六"干父之蛊…厉终吉"——治蛊第一式是趁早动手，禁忌是等待观望。**<br>**两个初六方向相反：蒙卦叫你慢，蛊卦叫你快。分辨依据：蒙卦面对的是"还在长的东西"（拔苗会死），蛊卦面对的是"正在坏的东西"（等下去会烂透）。** |

### 九二 · 干母之蛊（⚠️ 全书罕见的"不可贞"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 干母之蛊，不可贞。 |
| **象传** | 干母之蛊，得中道也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**（下巽之中）——按本库通则"**⚠️ 得中可救不当位**" |
| **判词 → 行动语义** | **不可贞**（**⚠️ 本库判词表未收的判词**） → **不可以硬用"守正到底"的方式去治，只能用中道** |
| **关键词解** | **母**＝阴柔的一方。**在本卦的语境里，"父之蛊"与"母之蛊"是两类不同性质的积弊**：**父之蛊＝刚性的积弊**（制度、规矩、明面上的做法、可以摆到桌上说的事）；**母之蛊＝柔性的积弊**（人情、旧交、面子、家里的老习惯、大家心里有数但不能挑明的那部分）。<br>**贞**＝正、守正不移。**不可贞**＝**不可以固执于"正"**。 |
| **⚠️ 本爻是全书对"贞"字最重要的一条限定** | **本库判词表现有"贞凶"一条：守正也凶——问题不在品德，在处境与选择的根本错位。**<br>**蛊九二比"贞凶"又进了一层：它不说"贞了会凶"，它直接说"不可贞"——这个局面根本不许你去贞。**<br>**这三个字也正好解释了卦辞为什么独缺"贞"**（元、亨、利全给，贞不给）。**卦辞的缺口，在这一爻被写成了明文。** |
| **⚠️ 为什么"干母之蛊"不可贞** | **因为对象是柔的、是有情的。**<br>**你用刚正的原则去切一个柔性的积弊，切下去的不是弊，是关系本身。** 制度可以推翻重写；**人情、旧交、面子、几十年的家庭默契，一刀切下去，整个局面会连着一起崩。**<br>**所以象传给的解药不是"更正"，是"得中道也"——用中，不用正。**<br>**⚠️ 本库口径（可直接入库）："中"与"正"在《周易》里不是同一件事。九二不当位（不正），但得中——它靠"中"办事，不靠"正"办事。蛊九二把这条差别写到了极处：有些事只能中，不能正。** |
| **"用中道"的具体形态（本爻最实用的部分）** | ① **不彻底**——只处理到"不再继续坏"，不追求"彻底清干净"；② **不一刀切**——留过渡期、留台阶、留人的面子；③ **不当场纠正**——不在众人面前挑明；④ **分步来**——把一次大改拆成几次小调整；⑤ **不追责**——柔性积弊往往找不到该负责的人，找也没有意义。 |
| **识别信号** | ① 你要动的这件事牵着人情、旧交、长辈、面子，或"大家心里都清楚但从没人说"；② 你的位置名分不完全够（不当位），但事情实际要靠你办（得中）；③ 你手里有一条明确的原则，很想直接拿它去对齐；④ 你已经预感到"讲原则会崩"。 |
| **该做** | **用中道：先止住继续变坏，再慢慢挪。给对方留台阶，给自己留回旋。** |
| **不该做** | **讲原则、立规矩、当场纠正、一次改到底。** 在这一爻里，**"我只是坚持了正确的做法"不构成任何豁免——爻辞明写"不可贞"。** |
| **与巽九二的对照（两个不当位而得中的九二，同一个巽）** | **巽九二"巽在床下，用史巫纷若，吉，无咎"，象传"得中也"——面对强势得多的对象、位置又不正，靠"低姿态＋高频次沟通"办成事。**<br>**蛊九二"干母之蛊，不可贞"，象传"得中道也"——面对柔性积弊、位置又不正，靠"不刚决、走中道"办成事。**<br>**两爻同为下巽之中、同为阳居阴位、同以"得中"为唯一理由。合读结论：位置不正的人办事，靠的是"中"，不是"正"。这是本库"得中可救不当位"这条通则最干净的一对实例。** |
| **与艮六二"其心不快"的对照** | **艮六二当位得中，止住了自己却救不了上面的人，象传"未退听也"，判词只有"其心不快"**；**蛊九二不当位而得中，面对的是柔性积弊，得到的指令是"不可贞"。**<br>**两爻合起来是本库对"你没法用正确去解决的局面"的完整口径：艮六二承认你的难受但不授权你越位；蛊九二承认你的正确但不授权你使用它。** |

### 九三 · 干父之蛊（宁可硬）

| 字段 | 内容 |
|---|---|
| **爻辞** | 干父之蛊，小有悔，无大咎。 |
| **象传** | 干父之蛊，终无咎也。 |
| **位属性** | 阳爻居阳位，**当位**（巽在下 → 三必当位）；居下巽之顶、上下两卦之交；本库通则"**三多凶**" |
| **判词 → 行动语义** | **小有悔 ＋ 无大咎**（象传收到"**终无咎也**"） → **该硬就硬，接受"小有悔"这个必付的代价** |
| **关键词解** | **小有悔**＝有一点悔恨（按本库口径，**悔＝退·止·舍**，但此处加了"小"字限定）。**无大咎**＝没有大的灾。**象传"终无咎也"**＝**最终是无咎的**——**象传的口气比爻辞更宽。** |
| **⚠️ 本爻是全卦刚决之爻，也是判词最"划算"的一爻** | **九三是巽的当位之阳，居下卦之顶，是全卦最有力量的执行位置。**<br>**它的账很清楚：小有悔（会有一点后悔、会伤到人、会觉得当时话说重了），换来"无大咎"、并且象传直接判"终无咎也"。**<br>**在一个整卦都在讲"怎么收拾烂摊子"的语境里，这个组合的含义非常实际：干总比不干划算。** |
| **⚠️ 与巽九三"频巽，吝"的对照（本卡最有价值的一组）** | **两爻位置完全相同：九三、阳居阳位、当位、居下巽之顶、三多凶。**<br>**巽九三"频巽，吝"，象传"志穷也"——当位的刚爻反复卑顺退让，路越走越窄、心志走穷。**<br>**蛊九三"干父之蛊，小有悔，无大咎"，象传"终无咎也"——当位的刚爻硬着干，只付"小有悔"。**<br>**⚠️ 结论（可直接入库为通则）：同一个位置、同一个巽的当位之阳，软下来是"吝"（趋势极差），硬起来只是"小有悔"（可承受的代价）。按本库吉凶序，悔重于吝——但"小有悔＋无大咎＋终无咎"合起来，明显好过"吝·志穷"。**<br>**在蛊卦里，宁可硬。** |
| **九三与九二的分工（本卦最需要分清的一条）** | **同为下巽之阳，九二"不可贞"（不能硬），九三"小有悔"（可以硬）。差别只有一条：干的是谁的蛊。**<br>**九二干"母之蛊"（柔性积弊：人情、面子、默契）→ 不可硬；**<br>**九三干"父之蛊"（刚性积弊：制度、规矩、明面做法）→ 可以硬，代价是小有悔。**<br>**⚠️ 这是本卦最实用的一条判别：动手之前先分清你要动的是"父之蛊"还是"母之蛊"。分错了，硬的地方软了成"吝"，软的地方硬了会崩。** |
| **识别信号** | ① 你要动的是明面上的东西（流程、规矩、分工、标准、账目）；② 你有位置、有力量去动它（当位）；③ 你在犹豫，因为动了一定会有人不舒服、你事后一定会有点后悔；④ 你处在上下之间的交界位置（三位），动一下上下都会感觉到。 |
| **该做** | **动。并且预先把"小有悔"记进成本里**——**知道会后悔，就不会因为后悔而回头。** |
| **不该做** | 因为"怕得罪人、怕自己后悔"而反复退让。**那就从蛊九三滑到了巽九三的"频巽，吝"。** |

### 六四 · 裕父之蛊（⚠️ 全卦唯一不"干"的一爻，也是唯一乘刚的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 裕父之蛊，往见吝。 |
| **象传** | 裕父之蛊，往未得也。 |
| **位属性** | 阴爻居阴位，**当位**（艮在上 → 四必当位）；**乘于九三之上——乘刚**（**全卦唯一乘刚之爻**，出现在上下卦交界处）；本库通则"**四多惧**" |
| **判词 → 行动语义** | **吝**（按本库口径：**路越走越窄，趋势极差**） → **停止宽纵；不作为在本卦是唯一被判负的选项** |
| **关键词解** | **裕**＝宽裕、宽缓、**宽纵放任**（与"干"（整治）正相反）。**裕父之蛊**＝**对上一代留下的积弊采取宽容、拖着、不去动的态度**。**往见吝**＝这样往前走，会遇到"吝"。**象传"往未得也"**＝**这样往前走，什么也得不到。** |
| **⚠️ 本爻是全卦的负面样本，而且是唯一的负面样本** | **五个讲"蛊"的爻里，四个是"干"（初六厉终吉、九二不可贞但得中道、九三小有悔无大咎、六五用誉），只有六四是"裕"——不干。**<br>**《周易》给它的判词是"吝"，象传补一句"往未得也"。**<br>**合起来的含义极清楚：在蛊卦里，最危险的不是干错，是不干。**<br>**为什么？因为蛊的病因是"巽而止"（一味顺 ＋ 停滞不动）。"裕"正是这个病因本身——你用"宽容"的名义，把生蛊的条件又维持了一遍。** |

#### ⚠️ 六四专项：本库"乘刚的破解方式"的第一个反例

本库索引第五节已收两条**乘刚的破解方式**，蛊六四补上第三种情形——**不破解**：

| 卦·爻 | 位属性 | 动作 | 判词 |
|---|---|---|---|
| **艮六四** · 艮其身 | 当位·**乘刚** | **止诸躬**（把范围收回到自己这一身） | **无咎** |
| **巽六四** · 田获三品 | 当位·**乘刚** | **田获三品**（交付可分配的实际成果） | **悔亡·有功** |
| **蛊六四** · 裕父之蛊 | 当位·**乘刚** | **裕**（宽纵、不动手） | **吝**（象传"往未得也"） |

> **三爻的位属性完全相同：阴爻居四位、当位、乘刚（都乘着下卦顶上的那个阳爻）。**
> **⚠️ 结论（建议补入索引第五节"乘刚的破解方式"）**：**乘刚的压迫无法消除，破解方式只有"做一件收得住的事"——收回到自己（艮六四）或交出成果（巽六四）。而什么都不做，就是蛊六四的"裕"，判词是"吝"。**
> **也就是说：乘刚这个处境不允许"再看看"。它给你两个动作可选，但没有"不动"这个选项。**

| 字段 | 内容 |
|---|---|
| **识别信号（诊断清单）** | ① 你已经看清了这个烂摊子的问题所在；② 你也有位置去处理（当位）；③ 但你下面顶着一股硬力量（前任的旧人、既得利益者、一个你动不了的老资格）——**这就是乘刚**；④ 你选择了"再观察一段时间""让时间解决""不必上升到那个层面"；⑤ 你为这个选择找到的理由是"宽容""稳定""不折腾"。 |
| **该做** | **换成另外两个动作之一：① 收回到自己这一身——把你职责范围内那一小块先干净（艮六四"止诸躬"）；② 或者交出一个实际成果——先做出一件能分配给各方的东西，用它换动手的空间（巽六四"田获三品"）。** |
| **不该做** | 以"宽容""稳定"为名继续拖。**"吝"是趋势判词——它不说你现在有多糟，它说你正在走窄。而象传把结果说得更死："往未得也"，往前走什么也得不到。** |
| **与蒙六四"困蒙，吝"的呼应（两个"吝"的六四）** | **蒙六四"困蒙，吝"，象传"独远实也"——学不明白，也没有出去找人，因为远离了"实"。**<br>**蛊六四"裕父之蛊，往见吝"，象传"往未得也"——看清了问题，也没有去动它。**<br>**两个六四同判"吝"，病根是同一个：知道了却不动。本库"吝"字条已收屯六三、蒙六四、蒙上九、巽九三，蛊六四是第五例，也是最纯粹的一例——它的"吝"不是做错了什么，是什么都没做。** |

### 六五 · 干父之蛊（用誉，本卦最顺的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 干父之蛊，用誉。 |
| **象传** | 干父用誉，承以德也。 |
| **位属性** | 阴爻居阳位，**不当位**（艮在上 → 五必不当位），但**得中**且居尊位——**本卦的决策者** |
| **判词 → 行动语义** | **用誉**（**⚠️ 无吉凶判词，但"誉"是明确的正面**；对照本库通则"**二多誉**"，此处誉出现在五位） → **居尊治蛊，用声誉与德，不用权力与刑** |
| **关键词解** | **誉**＝美誉、声望、称赞。**用誉**＝**以美誉行之**（借声望去推动整治），一说**因此而获得美誉**。**两读并存，本库取合读：以誉行之，故得誉。**<br>**象传"承以德也"**＝**以德来承继**（"承"字与初六象传"意承考也"的"承"完全同一个字）。 |
| **⚠️ 本爻是全卦最顺的一爻，而它不当位** | **六五阴居阳位，不当位；论位置正当性，它不如九三（当位）、不如六四（当位）。**<br>**但它是全卦唯一没有付任何代价的治蛊之爻**：初六付"厉"，九二被禁止用"贞"，九三付"小有悔"，六四判"吝"，**只有六五得到"用誉"。**<br>**理由在象传里，只有三个字："承以德也"——它靠的不是位置，是德。**<br>**这是本库"义理可救位"的又一个实例**（对照艮上九"敦艮，吉"：不当位而德与卦相合，故吉）。 |
| **⚠️ 为什么居尊者治蛊要"用誉"而不用权** | **居尊者手里有权、有刑、有人事，最容易的做法是下令清理。但蛊的病因是"巽而止"（下面一味顺、不作声）——用权力清理，只会让下面更顺、更不作声，弊会重新长出来。**<br>**"用誉"是反过来的做法：把要树立的标准变成被称赞的东西，让人为了誉而自己动起来。** 这正是大象传"**振民育德**"在爻上的落实——**振民靠誉，不靠令。** |
| **识别信号** | ① 你是这个烂摊子的最高负责人；② 你手上有权力可以强行清理；③ 下面的人都很"顺"（没人反对，也没人真动）；④ 你的名分不完全正（不当位，比如你是空降的、是代管的、是继任者）；⑤ 你倾向于"先立威"。 |
| **该做** | **① 公开表彰第一批按新标准做事的人（用誉）；② 把整治说成"承继"而不是"纠错"（承以德）；③ 把标准变成荣誉，让人争着去做。** |
| **不该做** | 靠权力和处罚推进。**在这一卦里，权力越用，"巽而止"越牢。** |
| **⚠️ 本库"居尊位者必须放弃一样特权"专题的第六例** | 本库索引已列五例：**乾九五**（放弃独断，去求贤）、**坤六五**（放弃权柄，守臣节）、**蒙六五**（放弃架子，存赤子之心）、**离六五**（放弃坚强，哭得出来）、**艮六五**（放弃说话的自由，言有序）。<br>**蛊六五补上第六种：放弃用权，改用誉与德。**<br>**六例完全同构——居尊位者必须主动放弃一样最顺手的特权，而且放弃的恰恰是这一卦里最能立刻见效的那一样。** |
| **与师六五、比九五的对照（三个尊位面对"人"的三种动作）** | **师六五"长子帅师，弟子舆尸，贞凶"——选对人，然后放手**；**比九五"显比…失前禽"——公开标准，顺者纳、逆者放，不强求**；**蛊六五"干父之蛊，用誉"——不动人，只立誉。**<br>**三个尊位的共同点：都不靠强力。而蛊六五是三者中动作最少的——它连"选人"和"纳人"都不做，只做一件事：让做对的人被称赞。** |

### 上九 · 不事王侯（⚠️ 全卦唯一跳出"干蛊"的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 不事王侯，高尚其事。 |
| **象传** | 不事王侯，志可则也。 |
| **位属性** | 阳爻居阴位，**不当位**（艮在上 → 上必不当位）；居全卦之终，**也是上艮（止）之极** |
| **判词 → 行动语义** | **无吉凶判词，仅象传"志可则也"** → **不再参与治蛊，把自己所做的事放到更高的层面上去** |
| **关键词解** | **事**（前一个，动词）＝事奉、供职。**王侯**＝在位掌权者。**不事王侯**＝**不去事奉王侯，即不在这个局里任事**。<br>**高**＝使之高；**尚**＝崇尚、推崇；**其事**＝自己所从事的事。**高尚其事**＝**把自己所做的事提到更高的层次上去**（**注意：这是本卦造出"高尚"一词的地方，其原义是动宾结构"使自己的事高而可尚"，不是形容词**）。<br>**象传"志可则也"**＝**他的心志可以作为法则**（"则"＝法则、准则、可效法）。 |

#### ⚠️ 上九专项：全库唯一被许可的"我不干这个了"

| 字段 | 内容 |
|---|---|
| **① 这一爻在结构上为什么必然出现** | **上九居上艮之极。艮的德就是"止"**（本库艮卦卡："艮判断的是'时'，该行则行、该止则止"）。<br>**所以蛊卦的最后一爻，必然是那个"该止就止"的位置**——**一卦讲了五爻"怎么干"，最后必须有一爻讲"什么时候不干"。**<br>**这也解释了它为什么不当位：它已经不在实位上了。** |
| **② 《周易》对它的态度：不判吉凶，但给了极高的评价** | **爻辞不给判词（没有吉、没有咎、没有厉）；象传只给四个字："志可则也"。**<br>**按本库口径，"无判词"通常意味着"不奖不罚"（如兑上六"引兑"、震九四"遂泥"，象传都判"未光也"）。但蛊上九不同——它的象传是全部无判词之爻里最正面的一句：其志可以作为法则。**<br>**⚠️ 这是一个新的档位，建议补入本库判词表：无判词 ＋ 象传"志可则也"＝《周易》不给你好处，但认可你的选择本身值得效法。** |
| **③ ⚠️ "不事王侯"与六四"裕父之蛊"的分界（本爻最要紧的一条）** | **两爻表面上都是"不干"，一个判"吝"，一个"志可则"。分界有三条，缺一条就落回六四**：<br>**① 位置**：**六四在实位上（当位、有职责在身），上九已在局外（不当位、居终）。在位不干＝失职；不在位不干＝退。**<br>**② 有没有"高尚其事"**：**上九不是什么都不做，它把自己的事换到了更高的层面。六四是把事丢在那里。**<br>**③ 是不是"止其所"**（艮卦彖传"艮其止，止其所也"）：**上九止在该止的地方（局已到尽头）；六四止在承重位置上，那是艮九三"列其夤"（撕裂）的位置。**<br>**一句话判别：你是把摊子丢给了别人（六四的"裕"），还是确认了这个蛊已不该由你来干、并且转去做了更值得做的事（上九）？** |
| **识别信号** | ① 你曾经深度参与这个烂摊子的整治；② 你已经确认：靠你现在的位置和方式，这件事不可能被治好；③ 你不在实职上，或已经可以不在；④ 你手上有一件更值得做、层次更高的事可以转去做；⑤ 你想走，但担心这算不算逃避责任。 |
| **该做** | **① 先确认自己已不在实位（否则你是六四）；② 把要退出的部分交代清楚（这仍是"意承考"的一部分）；③ 明确转去做那件"更高"的事——退出必须配一个新的去处，否则不成立。** |
| **不该做** | 一边挂着职责，一边不再任事。**那不是上九的"不事王侯"，那是六四的"裕父之蛊，往见吝"。** |
| **⚠️ 与巽上九"贞凶"的对照（两个不当位的上九，同在到顶位置）** | **巽上九"巽在床下，丧其资斧，贞凶"，象传"上穷也""正乎凶也"——到顶而一味卑顺，把本钱和决断力都丢了，即使守正也凶。**<br>**蛊上九"不事王侯，高尚其事"，象传"志可则也"——到顶而主动不任事，其志可法。**<br>**⚠️ 差别只有一条：是不是自己选的。巽上九是"想干却已丧失了干的能力"（丧其资斧）；蛊上九是"有能力而主动不干"（高尚其事）。**<br>**本库通则可补一条：到顶位置上的"不作为"，其吉凶取决于你手里是否还握着"斧"（决断能力）——握着而选择不用，是"志可则"；已经丢了才不用，是"贞凶"。** |
| **与四个上爻的四角对照（本库"到顶之后"专题的第五例）** | 本库兑卦卡已立四角：**乾上九"亢龙有悔"（过刚不知止，悔）｜巽上九"贞凶"（过柔而丧决断，凶）｜艮上九"敦艮，吉"（主动止到极处，吉）｜兑上六"引兑，未光"（不刚不柔，没内容了）。**<br>**蛊上九补上第五种：主动退出而另有所事——无判词，但"志可则也"。**<br>**五句话记住"到顶之后"：过刚则悔，过柔则凶，知止则吉，无内容则白过，另有所事则其志可法。** |

## 三、蛊卦定位速查表

| 爻 | 干什么蛊 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | **父**（刚性） | 干父之蛊 | 刚接手，问题还只是"大家都知道但没人说" | 不当位 | **厉→终吉**·趁最微处动手·**意承考** |
| 九二 | **母**（柔性） | 干母之蛊 | 要动的事牵着人情、面子、旧交 | 不当位但**得中** | **不可贞**·只能走中道 |
| 九三 | **父**（刚性） | 干父之蛊 | 要动明面上的规矩，动了一定有人不舒服 | **当位**·三多凶 | **小有悔·无大咎**·该硬就硬 |
| 六四 | **父**（**不干**） | 裕父之蛊 | 看清了问题，下面顶着硬力量，你选择"再看看" | 当位·**乘刚**·四多惧 | **吝·往未得**·换成止诸躬或田获三品 |
| 六五 | **父**（居尊） | 干父之蛊 | 你是最高负责人，手上有权，下面很"顺" | 不当位但**得中居尊** | **用誉**·承以德·不用权 |
| 上九 | **不干了** | 不事王侯 | 已不在实位，且确认此蛊不该由你来治 | 不当位·艮极 | **无判词·志可则也**·高尚其事 |

**蛊卦三句话**：
1. **蛊是内生的，不是外来的**（彖传"巽而止，蛊"）——**一味顺 ＋ 停滞不动 ＝ 生蛊。所以不要去找一个该负责的坏人；也所以最高纲领是"振民育德"（先动人，再动事）。**
2. **动作是改，用意是承**（初六象传"意承考也"）。**治蛊的合法性不来自"前任错了"，来自"我要把他没做完的做完"。**
3. **动手前先分清是"父之蛊"还是"母之蛊"**：**刚性积弊（制度、规矩、明面做法）可以硬，代价是"小有悔"（九三）；柔性积弊（人情、面子、默契）"不可贞"，只能走中道（九二）。** 而**最危险的不是干错，是"裕"（宽纵不管）——判词是"吝"，象传是"往未得也"（六四）。**

**本卦最反直觉的三条**：
- **卦辞给足了元、亨、利，独独不给"贞"；而九二直接写出"不可贞"三个字。** **《周易》在这一卦里明确告诉你：有些局面根本不许你用"守正到底"的方式去处理。这是全书对"贞"字最重的一条限定。**
- **全卦唯一被判负的，是那个什么都没做的六四（"裕父之蛊，往见吝"）；而它当位。** 反过来，**唯一不当位的治蛊者六五，却是全卦最顺的一爻（"用誉"）**——**因为它靠的不是位置，是德（象传"承以德也"）。**
- **上九"不事王侯"是全书唯一被明确许可的"我不干这个了"**，而且象传给了极高的评价："**志可则也**"。**但它与六四的"裕"只隔三条线：你在不在实位、有没有转去做更高的事、止的位置对不对。**

## 四、⚠️ 本卡对全库的意义

### 1. 补上全库唯一的"接手前任遗留问题"领域

本库现有 18 卦覆盖了草创（屯）、教育（蒙）、取利（需）、争讼（讼）、群体对抗（师）、归附（比）、蓄力（小畜）、处世（履）、顺逆（泰否）以及八纯卦的八种基础处境。
**其中没有一卦处理"这个问题不是我造成的，但现在得我来收拾"。** 而这是现代最高频的处境之一——**新任管理者、继承者、接盘者、以及每一个要处理自己旧习惯的人。**

| 困境形态 | 此前会被误路由到 | **正确归属** |
|---|---|---|
| 接手烂摊子部门／公司 | 屯（草创）——**错，屯是"没有"，蛊是"有但坏了"** | **蛊 18** |
| 继承家业带着历史债务 | 坎（久困）——**错，坎无出口，蛊卦辞给"元亨"** | **蛊 18** |
| 新领导面对旧制度旧班底 | 巽（渗透推行）——**巽是"行新"，蛊是"治旧"** | **蛊 18**（配合巽卦读） |
| 父辈遗留的家庭问题 | 无归属 | **蛊 18**（初六"意承考也"是关键） |
| 自己长期形成的坏习惯 | 艮（戒断）——**艮讲怎么停，蛊讲怎么治** | **蛊 18**（此时你是自己的"父"） |

> **本卦的领域标识句**：**"这个摊子不是我摊的，但现在得我收。"**

### 2. "先甲三日"↔"先庚三日"：全书唯一的一对姊妹句（合读表）

本库巽卦卡已指出这一对必须合读。现给出完整对照：

| | **蛊 18**（卦辞） | **巽 57**（九五） |
|---|---|---|
| 原文 | **先甲三日，后甲三日** | **先庚三日，后庚三日** |
| 天干义 | **甲＝十干之首＝始** → **始事用甲** | **庚通"更"＝变更** → **更事用庚** |
| 出现层级 | **卦辞**（全卦级别的原则） | **九五爻辞**（居尊者的具体动作） |
| 所配的传 | 彖传"**终则有始，天行也**" | 彖传"**重巽以申命**"、大象传"**申命行事**" |
| 处境 | **旧的已经坏了，要重开一个头** | **旧的还能用，要改一处规矩** |
| 判词 | 卦辞"元亨，利涉大川"（**无贞**） | **贞吉·悔亡·无不利·吉**（全卦判词最密集之爻） |

> **合读结论（本卡与巽卡之间最有价值的一条互补）**：
> **两句的形式完全一样（前三日、后三日），操作纪律也完全一样（真正动手的只有中间那一天，占全过程七分之一）——差别只在你面对的是"改"还是"重开"。**
> **而这个差别决定了第一个动作：改（庚）的第一动作是"申命"（反复讲清要改什么）；重开（甲）的第一动作是"终"——先给旧的那一段划上句号（彖传"终则有始"）。**
> **⚠️ 实操判别：如果你发现自己在反复申明一个改动，而下面的人总能把它绕回原样，那说明你用的是"庚"，而这个局面需要"甲"——旧的那一段还没有被结束掉。**

### 3. 结构律的组合验证：巽在下 ＋ 艮在上 ＝ 生蛊的机制

| | 占初、二、三位（下卦） | 占四、五、上位（上卦） |
|---|---|---|
| **巽**（阴阳阳） | 初六不当位、九二不当位（**得中**）、九三**当位** | 六四当位、九五当位（得中居尊）、上九不当位 |
| **艮**（阴阴阳） | 初六不当位、六二当位、九三当位 | **六四当位**、六五不当位（**得中**）、上九不当位 |

**蛊 18 的逐爻验证全部吻合**：初六不当位｜九二不当位得中｜九三当位｜六四当位｜六五不当位得中居尊｜上九不当位。

> **⚠️ 但本卡的真正增量不在当位表，在这一句**：本库索引第五节列了"**六条最危险的位置**"，其中两条是"**巽在下＝柔在底下，易犯犹豫与滥让**"和"**艮在上＝被压住不许动**"。
> **蛊卦是这两条最危险位置的直接叠加，而彖传给它起了一个名字："巽而止"。**
> **这就是本库第一次看到"两条危险结构叠加会产生什么"——答案是：生蛊。**
> **下面一味顺、不作声（巽在下），上面压着、不许动（艮在上），于是不需要任何人做坏事，弊病自己就长出来了。**
> **建议补入索引第五节：结构律不只判单个爻的吉凶，两条危险结构叠加会生成一种新的困境类型。蛊 18（巽在下＋艮在上）是第一个实例。**

### 4. 三个"当位·乘刚的六四"：本库乘刚规则的完整闭环

| 卦·爻 | 动作 | 判词 | 性质 |
|---|---|---|---|
| **艮六四** | **止诸躬**（收回到自己一身） | **无咎** | 破解方式① |
| **巽六四** | **田获三品**（交出可分配成果） | **悔亡·有功** | 破解方式② |
| **蛊六四** | **裕**（宽纵、不动手） | **吝**（往未得也） | **⚠️ 反例：不破解** |

> **三爻位属性完全相同（阴居四位、当位、乘着下卦顶上的阳爻），且三卦的下卦顶爻都是九三。**
> **⚠️ 结论（建议补入索引"乘刚的破解方式"条）：乘刚这个处境不提供"不动"这个选项。它只有两个合格动作——收回到自己，或交出成果。选择"再看看"就是蛊六四，判词是吝。**

### 5. 新增／补正的判词与通则（建议补入索引第四、五节）

| 项 | 内容 | 出处 |
|---|---|---|
| **⚠️ 新判词：不可贞** | **不是"贞了会凶"（贞凶），而是"这个局面根本不许你贞"。** 对象是柔性积弊（人情、面子、默契）时，守正到底会把关系本身切断。解药是象传的"得中道也"——**用中，不用正。** | **蛊九二** |

| **专题第六例：居尊位者放弃一样特权** | **蛊六五＝放弃用权，改用誉与德**（象传"承以德也"）。前五例：乾九五放弃独断、坤六五放弃权柄、蒙六五放弃架子、离六五放弃坚强、艮六五放弃说话的自由。 | 蛊六五 |

### 6. 序卦链 17→18→19 的衔接

> 序卦传："**以喜随人者必有事，故受之以蛊。蛊者，事也。**"——**凭着高兴跟着别人走，必然积下事情。**
> 序卦传："**蛊者，事也。有事而后可大，故受之以临。**"——**有事情可做（并且做成了）之后，才能壮大。**

**这两句把 17→18→19 串成一条极实用的因果链**：
> **随（跟着走）→ 蛊（跟着走就会积下一堆事）→ 临（把事治完了才能大起来）。**
> **⚠️ 对读者最有价值的一条**：**"蛊"不是意外，是"随"的必然产物**（序卦传原话）。**所以蛊卦不该被当成倒霉，它是每一个跟着别人／跟着惯性走过一段路的组织和人，必然会到的下一站。** 而序卦传给的出路也很明确：**治蛊不是终点，"有事而后可大"——蛊治完了才能进入临（19，居上临下、势头渐长）。**

### 7. 本卦打开的新格

按本库巽卦卡与艮卦卡的展开表，**蛊 18 同时出现在"巽在下"与"艮在上"两列**，是这两族的交点；与它成对的是 **随 17（上兑下震）** 在序卦上的相邻，以及结构上的翻转卦 **渐 53（上巽下艮）**。
> **优先建议**：**渐 53（上巽下艮）**——**蛊的上下颠倒（艮在下＝自己收手，巽在上＝柔在上位最正）**。"渐"是循序渐进，**恰是蛊卦"不可贞、走中道"那条指令的正面展开**，两卦合读可以说清"积弊要慢慢治"的全部刻度。
> 其次是 **临 19（上坤下兑）**——序卦传直接的下一卦，且"有事而后可大"这条因果需要两卡才讲得完。
