# 知识卡 19 · 临卦（地泽临）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："蛊者，事也。有事而后可大，故受之以临。临者，大也。"——**有事情可做（并且治成了）之后才能壮大**，所以蛊（18）之后接临。**⚠️ 序卦传把"临"直接训为"大"**，这是本卦第一层意思的来源。
> ⚠️ **本卦与观卦（20）是本批最重要的一对，必须合读**：**临＝你去看下面的人；观＝下面的人看你。** 两卦二阳的位置正好上下颠倒（**临是二阳在下往上长，观是二阳在上被仰望**），详见末节的完整对照表。
> ⚠️ **本卡还提供本库"兑在下＝易落入讨好的陷阱"这条通则的第二个实证**：**临六三"甘临"的象传与兑六三"来兑"的象传是完全相同的四个字——"位不当也"。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 临 · 第十九卦 |
| **卦象** | 上坤（地/顺）下兑（泽/悦），称"地泽临"。大象传"**泽上有地**"——**地在泽之上，站在岸上俯临下面的水**，这就是"临"（居高临下）之象。<br>**二阳（初九、九二）在最下，正在往上生长**——彖传"**刚浸而长**"（"浸"是渐渐地）。**这是十二消息卦中阳气渐长的一卦：势头正在起来。** |
| **⚠️ 本卦的当位分布（按本库第 4 节结构律逐爻验证）** | **兑在下 → 初九当位、九二不当位（得中）、六三必不当位**；**坤在上 → 六四当位、六五不当位（得中居尊）、上六当位**。<br>**逐爻核对**：初九（阳居阳位）当位 ✓｜九二（阳居阴位）不当位但得中 ✓｜六三（阴居阳位）不当位 ✓｜六四（阴居阴位）当位 ✓｜六五（阴居阳位）不当位但得中居尊 ✓｜上六（阴居阴位）当位 ✓。<br>**⚠️ 六三是全卦唯一乘刚之爻**（六三直接压在九二这个阳爻之上）。**而它也正是全卦唯一被判"无攸利"的爻——这不是巧合，见六三专项。** |
| **领域定义** | **居上临下，而且势头正在往上长**。① 刚被提上管理岗，要面对原来的同事；② 团队在扩张、你带的人在变多；③ 从"自己干"转成"看着别人干"；④ 家长面对逐渐长大的孩子（你还在上位，但已不能全管）；⑤ 平台方／甲方面对入驻者、供应商；⑥ 势头正好，你在判断"这波能持续多久"（**卦辞那句"至于八月有凶"就是给这一条的**）。<br>凡是"我在上面，要往下看、往下管、往下给"，都落在临卦。 |
| **不归本卦的情况** | ① 是**下面的人在看你**、你靠示范影响人 → **观卦**（20）——**这是本卦最重要的一条分界，见末节**；② 是你要选择跟谁站在一起 → **比卦**（8）；③ 是靠愉悦聚人、担心自己在讨好 → **兑卦**（58）；④ 是你在教、对方在学 → **蒙卦**（4）：**蒙讲教学关系本身的双向责任，临讲"我在上位该怎么往下看"**；⑤ 是有人跟随你、你手里聚起了人 → **随卦**（17）九四。 |
| **"临"字本义** | 从"人俯视"取象——**居高处向下看、监临、莅临**。**序卦传另训为"大"**（"临者，大也"）。<br>**两义必须合读：临之所以是"大"，因为它写的是势头在长（刚浸而长）；临之所以是"临"，因为长起来之后你就站到了上面，必须往下看。** |
| **卦辞原文** | 临：元亨利贞。至于八月有凶。 |
| **⚠️ 卦辞的关键结构（四德齐备，却带一个期限）** | **元、亨、利、贞四德全给**——全书明写完整"元亨利贞"的卦极少（本库已有的乾 1、屯 3、随 17 属此类），**《周易》对"居上临下、势头渐长"这件事评价极高**。<br>**但紧接着是"至于八月有凶"——一个明确的期限警告。**<br>**⚠️ 这是全书极罕见的写法：在卦辞里给出具体的时间刻度。**（本库现有的时间刻度都在爻辞里：震六二"七日得"、坎上六"三岁不得"、巽九五／蛊卦辞"三日"。**卦辞级别的期限，本库到此仅见临卦一处。**）<br>**彖传给的理由是四个字："消不久也"——（阳的）消退不会太久就来。**<br>**合读结论（本卦定性）：临卦的好是有保质期的。四德齐备说明这条路完全走得通；"至于八月有凶"说明它不会一直通。** |
| **卦辞现代解** | **元亨利贞**——**根本地通、守正则利**：势头在长的时候，路是全开的。<br>**至于八月有凶**——**到了那个节点会转凶。** 面向未来的推测统一见 `知识卡00` 第七节与宪法 RULE-007；**卦气配月属汉代注家之说、非经文，不把经文刻度换算为现实日期**。此处取它的方法论含义：<br>**"势头在长"这个状态本身就包含它的终点。所以临卦所有的动作都必须在"还在长"的时候做完——尤其是六四的"至临"（亲自到位）和六五的"知临"（用人用中）。等到"八月"，做什么都晚了。** |
| **彖传** | 临，刚浸而长。说而顺，刚中而应，大亨以正，天之道也。至于八月有凶，消不久也。 |
| **⚠️ 彖传要点（三条）** | ① **"刚浸而长"**——**刚（阳）是"浸"着长上来的**，"浸"是渐渐地、一点一点地。**这个字定了本卦的节奏：临不是骤然登上高位，是渐渐长上去的。所以它有时间做准备，也因此没有理由急。**<br>② **"说而顺"**——**下兑（悦）上坤（顺）**：**下面是悦，上面是顺。** ⚠️ **注意方向：在临卦里，"悦"是在下的那个（你所临的对象是悦的），"顺"是在上的那个（你自己是顺的）。这正好是"居上临下"的正确姿态：让下面高兴，自己保持顺。**<br>③ **"刚中而应"**——**九二刚中，与六五相应**。**这是全卦唯一的一对相应关系**（同本库师九二↔六五、蒙九二↔六五的结构），**也解释了为什么九二是全卦判词最重的一爻。** |
| **大象传（行动纲领）** | 泽上有地，临。君子以教思无穷，容保民无疆。 |
| **⚠️ "教思无穷，容保民无疆"解（本卦最高原则）** | **教思无穷**——"教"是教化，"思"是用心思虑，"无穷"是没有穷尽：**教化的用心没有尽头**。<br>**容保民无疆**——"容"是容纳，"保"是保护，"无疆"是没有边界：**容纳与保护民众，不设界限**。<br>**⚠️ 这条纲领的全部分量在于它排除了什么。**<br>**居上临下，最顺手的四件事是：管、查、考、罚。而大象传给的两个动作是"教"和"容保"——一个都没沾。**<br>**本库口径（可直接给读者的一句话）：居上临下的唯一合法内容是"教"与"保"，不是"管"与"查"。你在上面，是为了让下面的人长起来和不受伤，不是为了看住他们。**<br>**⚠️ 与师卦的一处呼应**：师卦大象传"**容民畜众**"——平时把力量蓄在民间。**两卦共用一个"容"字，且都是坤在上（地在上）。合读：师的"容"是为了战时能动员，临的"容"是为了长期能保。** |
| **总铁律** | ① **临的对象是所有人，不是自己人**（初九、九二"咸临"，"咸"＝皆）；② **不许用甜话临下**——"甘临，无攸利"，象传"位不当也"（六三）；③ **临必须"至"（亲自到）**，不能只"看"（六四）；④ **居尊者用"知"，不用"察"**（六五"知临"）；⑤ **临到最后要"敦"（厚）**，且心志要在内（上六）；⑥ **所有动作都要在"还在长"的时候做完**（卦辞"至于八月有凶"）。 |

## 二、爻级字段

> ⚠️ **本卦六爻是全书分类最工整的几卦之一，五个爻各给了"临"的一种形态**：**咸临（初九、九二）→ 甘临（六三）→ 至临（六四）→ 知临（六五）→ 敦临（上六）**。判词从"贞吉"一路到"无不利"，中间掉到"无攸利"，最后回到"吉，无咎"。**读本卦可以直接当作"居上临下的五种形态分类表"用**（速查表见第三节）。

### 初九 · 咸临（临之始）

| 字段 | 内容 |
|---|---|
| **爻辞** | 咸临，贞吉。 |
| **象传** | 咸临贞吉，志行正也。 |
| **位属性** | 阳爻居阳位，**当位**（兑在下 → 初必当位）；居全卦最下——**是彖传"刚浸而长"的那个起点，也是离下面最近的一爻** |
| **判词 → 行动语义** | **贞吉** → **普遍地临，不分亲疏；且必须守正** |
| **关键词解** | **咸**＝**皆、都、普遍**（一说通"感"，以感应而临；**两读并存，本库取"皆"为主、"感"为辅：普遍地临，靠的是感应而不是命令**）。**咸临**＝**对所有人一视同仁地临**。 |
| **⚠️ 象传"志行正也"是本爻的全部理由** | **"心志的施行是正的。"**<br>**注意象传没有说"因为你当位所以吉"，它说的是"志行正"——吉的原因在动机与施行上，不在位置上。**<br>**这与卦辞"元亨利贞"里那个"贞"完全对应：临的第一步，靠的是标准正，不是权力大。** |
| **⚠️ "咸"（普遍）为什么是临的第一动作** | **初九在全卦最下，离被临的对象最近**——**它是那个刚刚从"自己人"里被提上来的人。**<br>**这个位置最大的诱惑就是"先照顾原来一起的那几个"。爻辞用一个"咸"字把这条堵死了：临的第一天就必须是普遍的。**<br>**本库口径：临一旦从"自己人"开始，就再也回不到"咸"了——因为标准一旦开过口子，就是六三的"甘临"。** |
| **识别信号** | ① 你刚获得往下看／往下管的位置；② 你原来和这批人是平级或更低；③ 有人已经在期待你"照顾一下老关系"；④ 你倾向于"先把身边几个搞定，再管其他人"。 |
| **该做** | **① 第一批规则对所有人同时生效，一个例外都不开；② 把标准公开（这是"贞"的具体形态）；③ 用感应而不是命令——先让人看到你按标准做事。** |
| **不该做** | 从自己人开始。**也不要靠位置压人——象传给的理由是"志行正"，不是"位当"。** |
| **与兑初九"和兑，吉"的呼应（两个兑在下的初九）** | **兑初九"和兑，吉"，象传"行未疑也"——平和自然地让人愉悦，不针对特定对象、不带目的，所以经得起怀疑。**<br>**临初九"咸临，贞吉"，象传"志行正也"——普遍地临，不分亲疏。**<br>**两爻同为兑在下的初九、同为当位、同判吉，且要求完全一致：不针对特定的人。合读结论：凡是兑在下的卦，最下面那一爻的合格标准都是"无偏、无私、无可疑"。** |

### 九二 · 咸临（⚠️ 全卦判词最重之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 咸临，吉，无不利。 |
| **象传** | 咸临吉无不利，未顺命也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**（下兑之中）；**与六五相应**——彖传"刚中而应"指的就是它。**是全卦唯一有应援的爻** |
| **判词 → 行动语义** | **吉 ＋ 无不利**（按本库吉凶序：**元吉 ＞ 无不利／大吉 ＞ 吉**，**"无不利"约等于大吉，仅次于元吉**） → **以刚中之德普遍地临，并且不把"上面怎么说"当成唯一依据** |
| **⚠️ 判词密度的意义** | **本爻同时给了"吉"和"无不利"，是全卦判词最重的一爻，也是本库现有各卦中少数达到"无不利"这一档的爻**（对照巽九五"贞吉·悔亡·无不利·吉"）。<br>**而它不当位。**<br>**这是本库通则"⚠️ 得中可救不当位"在临卦里的形态：九二阳居阴位（名分不正），但它得中、且与六五相应——有实权、能办事、上面认它。** |
| **⚠️ 象传"未顺命也"的读法（⚠️ 释义有分歧，本库取合读）** | **原文四字："未顺命也。"** 历代主要有两读：<br>**① "未（不）一味顺从命令"**——九二有刚中之德，它的临不是照着上面的指令做的，而是按自己的判断做的；<br>**② "未顺"作"非因顺从而得"**——它的吉不是靠听话换来的。<br>**⚠️ 两读的落点其实完全一致，本库取合读：九二之所以能到"无不利"，恰恰因为它不是靠唯命是从得来的。**<br>**⚠️ 合规口径提醒：这一条不是授权你抗命。** 它的准确含义是——**你所在的这个"办事枢纽"位置，价值来自你的刚中之德（判断力＋不偏），不来自你的服从度。所以你要以"什么是对的"为依据行事，并把判断如实上报，而不是把"上面怎么说"当成唯一依据。** |
| **识别信号** | ① 你是实际办事、实际管人的那个枢纽（得中）；② 你的名分不完全正（不当位：代管、空降、职级不匹配、老资格但无头衔）；③ 上面认你、和你相应（六五）；④ 你面前有"按上面说的办"和"按该怎么办去办"两条路；⑤ 你倾向于选前者，因为那样最安全。 |
| **该做** | **① 保持"咸"（普遍、不偏）；② 以刚中之德下判断，并把判断如实讲给上面（这是"未顺命"的正解）；③ 用足与六五的相应关系。** |
| **不该做** | 用服从代替判断。**在临卦里，一个只会执行的九二拿不到"无不利"这个判词。** |
| **⚠️ 与师九二的对照（两个不当位而得中的九二，两种授权来源）** | **师九二"在师中吉，无咎，王三锡命"，象传"承天宠也"——统帅居中主事，靠的是君王三次任命的授权。**<br>**临九二"咸临，吉，无不利"，象传"未顺命也"——靠的是不唯命是从。**<br>**⚠️ 两爻结构完全同构（阳居阴位、不当位、得中、与六五相应、都是全卦办事枢纽），授权来源却正好相反：师九二的合法性来自上面给的命，临九二的合法性来自它不只听命。**<br>**分辨依据（极实用）：师卦是"组织化对抗"，必须指挥权集中、多头指挥必凶——所以九二靠授权；临卦是"居上临下、势头渐长"，需要的是不偏的判断——所以九二靠刚中。**<br>**本库通则可补一条：同一个结构位置在不同领域里的正确动作可以完全相反；判断依据是这一卦的领域，不是这一爻的位置。** |

### 六三 · 甘临（⚠️ 全卦唯一的负面判词）

| 字段 | 内容 |
|---|---|
| **爻辞** | 甘临，无攸利。既忧之，无咎。 |
| **象传** | 甘临，位不当也。既忧之，咎不长也。 |
| **位属性** | 阴爻居阳位，**不当位**（**象传直接点名"位不当也"**）；**乘于九二之上——乘刚**（全卦唯一乘刚之爻）；居下兑之顶；本库通则"**三多凶**" |
| **判词 → 行动语义** | **无攸利 → 既忧之 → 无咎**（**先判负，再给爻内解药**） → **停止用甜话临下；一旦意识到并为此忧惧，就无灾** |
| **关键词解** | **甘**＝甜、甘美，此处指**甜言蜜语、和颜悦色的哄**。**甘临**＝**用甜话、用讨好的方式去临下面的人**。<br>**无攸利**＝没有任何益处（按本库口径，同蒙六三"无攸利"，**双方皆输**）。<br>**既忧之**＝**已经为此忧惧了**（"既"＝已经）。**咎不长也**＝**灾不会长久**。 |

#### ⚠️ 六三专项：本库"兑在下＝讨好陷阱"这条通则的第二个实证

| 对照项 | **兑六三** · 来兑 | **临六三** · 甘临 |
|---|---|---|
| 爻辞 | 来兑，**凶** | 甘临，**无攸利**。既忧之，无咎 |
| 位属性 | 阴居阳位·**不当位**·下兑之顶·三多凶 | 阴居阳位·**不当位**·**乘刚**·下兑之顶·三多凶 |
| **象传理由** | **位不当也** | **位不当也** |
| 动作方向 | **"来"＝自外向内**，上门去讨好（**向上／向外**） | **"甘"＝以甜临下**，用好话哄（**向下**） |
| 判词 | **凶**（全卦唯一） | **无攸利**（全卦唯一的负面判词） |
| 有无爻内解药 | **无**（解药在别的爻：回到九二"孚兑"） | **有**——"**既忧之，无咎**" |

> **⚠️ 三条结论，都是本卡的实质增量**：
> **① 两爻的象传是完全相同的四个字——"位不当也"。** 本库通则"**兑在下＝易落入讨好的陷阱**"此前只有兑卦本身一个实例（兑卦卡曾预告"履、临、归妹、损、节、睽、中孚皆属此类，读到时要格外小心"）。**临六三是这条通则的第二个实证，而且是象传原文级别的实证，不是推演。**
> **② 陷阱位是同一个（兑之第三爻），但形态可以是向上的也可以是向下的**：**兑六三是往上讨好（来兑），临六三是往下讨好（甘临）。** **合起来的通则：讨好与方向无关，与位置有关——它是"用姿态去补位置的亏空"，而无论你补的是上面的亏空还是下面的亏空，象传给的理由都只有"位不当也"。**
> **③ 判词轻重的差别，来自你在上还是在下**：**兑六三在下位向上讨好，判"凶"，且爻内无解；临六三在上位向下讨好，判"无攸利"，并给了解药"既忧之"。** **推演结论：讨好下面的人还有救（因为你毕竟在上位，收回来即可），讨好上面的人没有救（因为你连位置都不正，姿态是你唯一的本钱）。**

| 字段 | 内容 |
|---|---|
| **⚠️ "既忧之，无咎"是本卦最实用的一条解药** | **象传"咎不长也"——灾不会长久。**<br>**注意这个解药有多轻：它不要求你补救、不要求你道歉、不要求你换做法，只要求"忧之"——真正为此不安。**<br>**为什么这么轻就够了？因为"甘临"的病根是自欺：用甜话哄下面的人，同时告诉自己"这是在搞好关系"。一旦你真的开始为它不安，自欺就破了，做法自然会变。**<br>**本库口径：这是全书对"意识到"这个动作给出的最高评价之一——在临六三，光是"意识到并且难受"就足以免咎。** |
| **识别信号（诊断清单）** | ① 你在上位，但你对下面的人主要靠好话、许诺、和气来维持；② 你不敢提标准、不敢批评、不敢说"这样不行"；③ 你下面顶着一股硬力量（一个你不敢动的老资格、一批你不敢得罪的人）——**这就是乘刚**；④ 你的位置本身名分不足（新来的、代管的、资历不够）；⑤ 你心里其实知道这样不对（**⚠️ 有这一条，就已经在"既忧之"的门口了**）。 |
| **该做** | **① 承认并保持这份不安（既忧之）——不要把它压下去；② 把维持关系的方式从"甜话"换成"标准"：一次只做一件——公开一条谁都适用的标准，并自己先照做；③ 回到初九、九二的"咸临"（普遍、不偏）。** |
| **不该做** | 加大甜度。**也不要反过来突然变严——那是从"甘临"跳到用权力压人，与大象传"教思无穷，容保民无疆"完全相反。** |
| **与蒙六三的呼应** | **蒙六三"勿用取女，见金夫，不有躬，无攸利"，象传"行不顺也"——施教者见钱眼开、丢了师道尊严，双方皆输。**<br>**临六三"甘临，无攸利"，象传"位不当也"——居上者用甜话哄下面的人。**<br>**两爻同判"无攸利"，病根相同：在上位的人放弃了自己那份"刚"，去换对方的好感。差别是蒙六三没有爻内解药（要重新原筮），临六三有（既忧之）。** |

### 六四 · 至临（位当）

| 字段 | 内容 |
|---|---|
| **爻辞** | 至临，无咎。 |
| **象传** | 至临无咎，位当也。 |
| **位属性** | 阴爻居阴位，**当位**（坤在上 → 四必当位）；已入上坤（顺）；本库通则"**四多惧**" |
| **判词 → 行动语义** | **无咎**（按本库口径：**无灾，不等于吉利**） → **亲自到位，到具体的人和事跟前去** |
| **关键词解** | **至**＝**到、亲至、到达**（**不是"极致"，是"到场"**）。**至临**＝**到了跟前的临**。 |
| **⚠️ 象传"位当也"与六三"位不当也"正面对照** | **全卦只有两爻的象传是以"位"作理由的，而且正好是相邻的两爻，一正一反**：<br>**六三"甘临，位不当也"｜六四"至临无咎，位当也"。**<br>**⚠️ 这一组是本库"当位／不当位"这条基础规则最干净的一处经文实证：同一个卦、相邻两爻，象传直接用"位当"与"位不当"解释判词的正负。** |
| **⚠️ "至"是本卦最实用的一个字** | **临这个动作有一个天然的懒惰形态：站在上面看。**<br>**六四把它纠正为"至"——走到跟前去。**<br>**本库口径（一句话）：临的正确形态是"到"，不是"看"。 隔一层看，你看到的是汇报；到跟前，你看到的是事情。**<br>**注意判词只给"无咎"，不给吉**：**亲自到场只是免灾的底线动作，不是功劳。** |
| **识别信号** | ① 你在上下之间的层级上（中层、四位）；② 你主要通过汇报、报表、转述了解下面的情况；③ 你"多惧"——怕问细了显得不信任，怕下去了显得越级；④ 你已经有一段时间没有亲自接触过一线的人和事。 |
| **该做** | **亲自到具体的人和事跟前去**——不是巡视，是坐下来把一件具体的事从头看一遍。 |
| **不该做** | 隔着层级听汇报就下判断。**在临卦里，这不是尊重层级，这是失掉"至"。** |
| **⚠️ 与蒙六四"困蒙，吝"的对照（同一爻位，"远实"与"至"）** | **蒙六四"困蒙，吝"，象传"独远实也"——学不明白也不出去找人，因为远离了"实"（远离了九二、上九那两个阳爻）。**<br>**临六四"至临，无咎"，象传"位当也"——亲自到跟前，也就是"近于实"。**<br>**⚠️ 两个六四正好构成一对：同在"多惧"之位，远实则"吝"（路越走越窄），至则"无咎"。**<br>**合读结论（可入库为通则）：四位（多惧之位）的通用解法是缩短与"实"的距离——本库此前已有两条四位解法（艮六四"止诸躬"缩小范围、巽六四"田获三品"交出成果），临六四补上第三条：亲自到场。** |

### 六五 · 知临（卦主·居尊）

| 字段 | 内容 |
|---|---|
| **爻辞** | 知临，大君之宜，吉。 |
| **象传** | 大君之宜，行中之谓也。 |
| **位属性** | 阴爻居阳位，**不当位**（坤在上 → 五必不当位），但**得中**且居尊位；**与九二相应**（彖传"刚中而应"）——**全卦卦主** |
| **判词 → 行动语义** | **吉** → **居尊临下，用"知"（明智）和"中"（中道），不用"察"（亲自查）** |
| **关键词解** | **知**＝**通"智"，明智**（一说读本字"知晓"；**两读义近，本库取"智"**）。**知临**＝**以明智去临**。<br>**大君**＝最高在位者。**宜**＝所应当的、合宜的做法。**大君之宜**＝**这才是最高在位者该有的做法**。<br>**象传"行中之谓也"**＝**这说的就是"行中道"**。 |
| **⚠️ 本爻的核心：象传把"知"直接解释成"中"** | **爻辞说"知"，象传说"行中"——《周易》在这里给"明智"下了一个非常具体的定义：明智就是走中道。**<br>**这句话在临卦里有极强的针对性。** 居尊者面对下面一大片人，最想做的是"我要都看清楚"。**而六五不当位（它其实看不清，也不该都看清）、只是得中。所以它的"知"不是"看得多"，是"处理得中"。**<br>**本库口径（一句话）：居尊位者的明智不是看得清，是把握得住分寸。看不清是这个位置的常态；六五的答案是用中道弥补视野，不是用勤奋弥补视野。** |
| **⚠️ 与六四"至临"的分工（本卦最需要分清的一条）** | **六四要"至"（亲自到场），六五要"知"（用中道）——两个动作方向相反，而两爻相邻。**<br>**为什么？因为位置不同：六四在中层，它的下面是具体的事，所以必须到；六五在尊位，它的下面是一整片，到不了，也不该到——它一到，六四就没法办事了。**<br>**⚠️ 这是本库对"该不该亲自下去"这个高频困境的正解：看你在四位还是五位。四位必须至，五位必须知。** |
| **识别信号** | ① 你在最终拍板的位置上；② 下面的事你不可能都亲眼看到；③ 你不当位（名分未必完全正，或你本身不是技术出身、不懂具体业务）；④ 你有一个刚中之才在办事（九二）；⑤ 你倾向于"我得亲自把这些都摸清楚"。 |
| **该做** | **① 把具体的"至"交给六四那一层；② 自己只做两件事：用对人（与九二相应）＋把握分寸（行中）；③ 记住卦辞的期限——趁"还在长"的时候把人和分寸定下来。** |
| **不该做** | 亲自去查每件事。**在临卦里，居尊者的勤奋会挤掉下面所有人的空间，而且它替代不了"中"。** |
| **⚠️ 本库"居尊位者必须放弃一样特权"专题的第七例** | 本库索引已列五例，加上蛊六五共六例：**乾九五**（放弃独断，去求贤）、**坤六五**（放弃权柄，守臣节）、**蒙六五**（放弃架子，存赤子之心）、**离六五**（放弃坚强，哭得出来）、**艮六五**（放弃说话的自由，言有序）、**蛊六五**（放弃用权，改用誉与德）。<br>**临六五补上第七种：放弃"亲自查清"的特权，改用知与中。**<br>**七例完全同构——居尊位者必须放弃的，恰恰是这一卦里最能立刻见效、最让人安心的那一样。** |
| **与师六五、蒙六五的对照（三个不当位而得中居尊的六五）** | **师六五"长子帅师，弟子舆尸，贞凶"——它唯一的动作是"选谁"，用对人则无咎、用错人则凶**；**蒙六五"童蒙，吉"，象传"顺以巽也"——居尊而放下身段去求教**；**临六五"知临，大君之宜，吉"——居尊而用中道，不用亲察。**<br>**三爻结构完全相同（阴居阳位、不当位、得中、居尊、皆与九二相应），动作依次是：选人（师）、求教（蒙）、行中（临）。** <br>**⚠️ 合读结论：本库现有的四个"六五"（师、蒙、艮、临）加上蛊六五，五个居尊者没有一个是靠权力解决问题的。这已经足够立为通则：在《周易》里，尊位提供的是选择权与分寸权，不是执行权。** |

### 上六 · 敦临（⚠️ 与艮上九"敦艮"是全书唯二的"敦"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 敦临，吉，无咎。 |
| **象传** | 敦临之吉，志在内也。 |
| **位属性** | 阴爻居阴位，**当位**（坤在上 → 上必当位）；居全卦之终、离下面的二阳最远——**却判"吉，无咎"** |
| **判词 → 行动语义** | **吉 ＋ 无咎** → **把"临"做得厚重笃实；且心志始终指向下面** |
| **关键词解** | **敦**＝**厚、笃实、敦厚**（与本库艮上九"敦艮"同字）。**敦临**＝**把居上临下这件事做到厚重的程度**。<br>**象传"志在内也"**＝**心志在"内"**（**"内"指下卦，即最下面那两个阳爻——也就是最基层**）。 |
| **⚠️ 本爻是全卦的收尾，也是"上爻"通则的又一个正面实例** | **上六居全卦最高、最远、最末，按本库六爻周期"上＝物极必反"，本该是最危险的一爻。**<br>**它却拿到"吉，无咎"。理由在象传里，只有四个字："志在内也"。**<br>**站在最高的位置上，心还在最下面——这就是"敦临"。** |

#### ⚠️ 上六专项：全书唯二的"敦"字爻辞，都在上爻，都判吉

| 对照项 | **艮上九** · 敦艮 | **临上六** · 敦临 |
|---|---|---|
| 爻辞 | 敦艮，**吉** | 敦临，**吉，无咎** |
| 位属性 | 阳居阴位·**不当位**·居终 | 阴居阴位·**当位**·居终 |
| 象传理由 | **以厚终也** | **志在内也** |
| 所"敦"的对象 | **止**（把收手做厚） | **临**（把居上临下做厚） |
| 在本卦中的地位 | **八纯卦六个上爻里唯一的"吉"** | **全卦收尾，判词与九二并列为最好之一** |

> **⚠️ 结论（建议补入索引第五节"上＝物极必反"那一条）**：
> **本库现行口径写的是"上爻之凶不来自'到顶'本身，只来自'到顶而不知止'"。临上六提供了这条通则的正面补充：上爻要拿到"吉"，靠的是"敦"（厚）。**
> **全书只有两处"敦"字爻辞（艮上九、临上六），都出现在第六位，都判"吉"。这不可能是偶然——"敦"是《周易》给"到顶位置"设定的质量标准。**
> **而两爻给出的"厚"的具体形态互补**：
> **艮上九的厚＝不留尾巴、不留后手、不留万一（以厚终也）——厚在收手的彻底上；**
> **临上六的厚＝居最高位而心志仍在最下面（志在内也）——厚在不脱离基层上。**
> **合起来一句：到顶之后要么把事做绝（敦艮），要么把根扎住（敦临）。薄，才是上爻真正的危险。**

| 字段 | 内容 |
|---|---|
| **识别信号** | ① 你已在最高、最远的位置上（组织顶层、退到二线、名义上的最高长辈）；② 你和一线之间隔了好几层；③ 你的动作已经很少，主要是"在那里"；④ 你在判断自己还该不该关心下面的事。 |
| **该做** | **① 把心志明确放在最基层（志在内）——你关心的、问的、记得住的，是最下面那批人的事；② 把"厚"做出来：稳定、不反复、说过的话长期有效；③ 不必增加动作——上六的价值不在做事，在"厚"。** |
| **不该做** | 用增加干预来证明自己还在。**上六当位、居终，它的合格标准是"敦"（厚），不是"动"。一动，就把六五的"知"和六四的"至"全打乱了。** |
| **⚠️ 与比上六"比之无首，凶"的对照（两个当位的上六，一吉一凶）** | **比上六"比之无首，凶"，象传"无所终也"——当位，但观望太久、已过九五，没有可归附的核心，所以凶。**<br>**临上六"敦临，吉，无咎"，象传"志在内也"——当位，居终，心志有明确的指向，所以吉。**<br>**⚠️ 两爻位属性完全相同（阴居阴位、当位、居全卦之终、都已过五位），判词一凶一吉。差别只有一条：心里有没有一个明确的指向。**<br>**比上六"无首"＝心里没有对象；临上六"志在内"＝心志指向最下面。**<br>**本库通则可补一条：居终之爻的吉凶，不看它做什么，看它的"志"有没有着落。** |
| **与随上六的对照（同为上六，两种"到极处"）** | **随上六"拘系之，乃从维之"，象传"上穷也"——把跟随关系绑到不能解，无判词，只判"穷"**；**临上六"敦临，吉，无咎"，象传"志在内也"——把居上临下做厚，判吉。**<br>**差别在动作落在谁身上：随上六把绳子绑到别人身上（穷），临上六把心志放到别人那里（吉）。** |

| 六四 | 中层·靠汇报 | 至临 | 已很久没亲自接触一线 | **当位**·四多惧 | **无咎**·亲自到场 |
| 六五 | 居尊（**卦主**） | 知临 | 下面的事你不可能都看到 | 不当位但**得中居尊** | **吉**·用知与中·不亲察 |
| 上六 | 最高最远 | 敦临 | 隔了好几层，在想还该不该管 | **当位**·居终 | **吉·无咎**·敦（厚）·志在内 |

**临卦三句话**：
1. **居上临下的唯一合法内容是"教"与"保"，不是"管"与"查"**（大象传"教思无穷，容保民无疆"）。**而临的第一动作必须是"咸"（普遍）——一旦从自己人开始，就再也回不来了。**
2. **四位必须"至"，五位必须"知"**（六四、六五）。**中层的懒惰是不到场，高层的过错是亲自查。这两个动作方向相反，位置决定选哪个。**
3. **临的好是有保质期的**（卦辞"至于八月有凶"，彖传"消不久也"）。**四德齐备说明这条路完全走得通，期限警告说明它不会一直通——所有动作都要在"还在长"的时候做完。**

**本卦最反直觉的三条**：
- **九二不当位，却拿到全卦最重的判词（吉·无不利，仅次于元吉）；而象传给的理由是"未顺命也"。** **在这一卦里，办事枢纽的价值来自判断力，不来自服从度。**（⚠️ 与师九二"王三锡命"正好相反——**同一个结构位置在不同领域里的正确动作可以完全相反。**）
- **六三"甘临"的象传与兑六三"来兑"的象传是完全相同的四个字："位不当也"。** **但一个判"凶"且无解，一个判"无攸利"却给了解药——"既忧之，无咎"。** **《周易》对"讨好下面的人"留了后门：光是真心为此不安，就足以免咎。**
- **上六在最高、最远、最末的位置上，判词却是"吉，无咎"。** 理由只有四个字："**志在内也**"——**站在最高处而心还在最下面。** 这与艮上九"敦艮，吉"构成全书唯二的"敦"字爻辞，**两处都在上爻，都判吉。**

## 四、⚠️ 本卡对全库的意义

### 1. 临 ↔ 观：本批最重要的一对（完整对照表）

**临（19）与观（20）在序卦上相邻，在结构上是二阳位置的上下颠倒，在义理上是"看"这个动作的两个方向。两卡必须合读，单看一卦必失其义**（与本库泰／否同理）。

| 对照项 | **临 19**（上坤下兑） | **观 20**（上巽下坤） |
|---|---|---|
| **卦象** | **二阳在最下**（初九、九二），四阴在上——彖传"**刚浸而长**" | **二阳在最上**（九五、上九），四阴在下——彖传"**大观在上**" |
| **⚠️ 看的方向** | **你去看下面的人** | **下面的人看你** |
| **卦辞性格** | **元亨利贞四德齐备 ＋ 一个期限**（"至于八月有凶"）：路全开，但有保质期 | **"盥而不荐，有孚颙若"——不含元亨利贞，也不含任何吉凶判词**：什么都不给，只给一个画面 |
| **纲领动作** | **君子**以教思无穷，容保民无疆 → **容纳、保护、教化**（把人护住） | **先王**以省方观民设教 → **巡视、观察、设教**（⚠️ 主体是"先王"，制度层面） |
| **乘刚** | **六三一爻乘刚**（＝全卦唯一负面判词所在） | **全卦无一爻乘刚** |

> **完整对照表（另含卦名训义、彖传机制、卦主与判词分布、"上位"两种定义）在 `知识卡20-观卦.md` 第四节第 1 条，本卡不重复。**

> **⚠️ 合读结论（本批最有价值的一条）**：
> **临与观是"上位者"这个身份的两个半边，缺一个就残。**
> **临告诉你：你在上面，要往下走、往下看、把人护住（至临、容保民无疆），而且要趁势头还在长的时候做完（八月有凶）。**
> **观告诉你：与此同时，下面的人一直在看你，而你影响他们的真正途径不是你的动作，是你的样子（盥而不荐，有孚颙若；下观而化也）。**
> **两卦的判词分布把这层意思说得更透：临卦的九二能到"无不利"（因为它在办事），观卦位置最好的九五只有"无咎"（因为它只被看）。**
> **一句话记住：临是你能做的，观是你躲不开的。**

### 2. 印证本库"兑在下＝讨好陷阱"通则（象传原文级别的第二实证）

本库兑卦卡在末节曾预告：
> **"兑在下 → 只有初九当位，六三必不当位：'来兑，凶'这个陷阱只在兑居下卦时出现（履、临、归妹、损、节、睽、中孚皆属此类）。"**

**临六三"甘临"正是这个预告的第一次兑现，而且是象传原文级别的兑现——两卦六三的象传是完全相同的四个字："位不当也"。**

| | **兑六三** | **临六三** |
|---|---|---|
| 动作 | **来兑**（上门讨好，向上／向外） | **甘临**（用甜话哄，向下） |
| 象传 | **位不当也** | **位不当也** |
| 判词 | **凶**（爻内无解药） | **无攸利** → **既忧之，无咎**（有解药） |

> **⚠️ 由此得到的通则（建议补入索引）**：
> **① 讨好这个陷阱与方向无关，只与位置有关。** 无论你讨好的是上面还是下面，象传给的理由都只有"位不当也"——**它的本质是用姿态去补位置的亏空。**
> **② 但判词的轻重与你在上还是在下有关**：**在下位向上讨好判"凶"且无解（兑六三）；在上位向下讨好判"无攸利"但可救（临六三）。** 因为**在上位的人还有位置可以退回去，在下位的人姿态就是全部本钱。**
> **③ 临六三还补上一个乘刚的细节**：**它是全卦唯一乘刚之爻（乘九二），也是全卦唯一负面判词所在。** 这也补正了本库"乘刚来源＝震"的口径——**兑（阳阳阴）内部同样制造一个乘刚：兑在下则六三必乘刚，兑在上则上六必乘刚。**（随上六乘九五可互证。**建议回补兑卦卡六三、上六的乘刚属性。**）

### 3. 补上"该不该亲自下去"这个高频困境的正解

本库路由表长期有一类问题没有归属：**"我该不该亲自去查／亲自去做／亲自下一线？"**
**临卦六四与六五相邻两爻给出的答案是相反的，而且分界极其清楚**：

| 你在哪一位 | 指令 | 经文 | 理由 |
|---|---|---|---|
| **四位**（中层） | **必须"至"（亲自到场）** | 六四"至临，无咎" | 象传"位当也"；对照蒙六四"独远实也"（远实则吝） |
| **五位**（居尊） | **必须"知"（用中道，不亲察）** | 六五"知临，大君之宜，吉" | 象传"行中之谓也" |

> **一句话结论：中层的失职是不到场，高层的过错是亲自查。**
> **这条与本库已有的两条"四位解法"合起来，四位（多惧之位）共有三个合格动作**：**艮六四"止诸躬"（缩小范围）、巽六四"田获三品"（交出成果）、临六四"至临"（亲自到场）。**

### 4. "敦"＝上爻的质量标准（新通则）

**全书只有两处"敦"字爻辞：艮上九"敦艮，吉"、临上六"敦临，吉，无咎"。两处都在第六位，都判"吉"。**

> **建议补入索引第五节"⚠️ '上＝物极必反'需加限定"那一条**：
> **现有口径**："反的是'不知止的极'，不是'到顶'本身。过刚则悔，过柔则凶，知止则吉，无内容则白过。"
> **补充**：**"上爻要拿到吉，靠的是'敦'（厚）。"**
> **两种厚的形态互补**：**艮上九的厚是"以厚终也"（收手要彻底，不留尾巴）；临上六的厚是"志在内也"（居最高位而心志仍在最基层）。**
> **反过来说，上爻真正的危险是"薄"**：**兑上六"引兑"之所以"未光"，正是因为它薄——只剩下"引"（牵引）这个动作，没有内容。**

### 5. 三个"六五／九五"的补充与"尊位"专题的收口

**本卦为本库两个待办专题各补一例**：

| 专题 | 本卦贡献 |
|---|---|
| **居尊位者必须放弃一样特权**（已 6 例） | **临六五＝放弃"亲自查清"的特权，改用知与中**（第七例）。前六例：乾九五放弃独断、坤六五放弃权柄、蒙六五放弃架子、离六五放弃坚强、艮六五放弃说话的自由、蛊六五放弃用权。 |
| **不当位而得中居尊的六五**（师、蒙、艮、蛊、临五例） | **五个居尊者没有一个靠权力解决问题**：师六五选人、蒙六五求教、艮六五闭嘴、蛊六五用誉、临六五行中。**⚠️ 可直接立为通则：在《周易》里，尊位提供的是选择权与分寸权，不是执行权。** |

### 6. 一处结构位置的重要反例：九二

**师九二与临九二结构完全同构**（阳居阴位、不当位、得中、与六五相应、全卦办事枢纽），**授权来源却完全相反**：

| | **师九二** | **临九二** |
|---|---|---|
| 爻辞 | 在师中吉，无咎，**王三锡命** | 咸临，吉，**无不利** |
| 象传 | **承天宠也**（君王三次任命） | **未顺命也**（不是靠听话得来的） |
| 合法性来源 | **上面给的授权** | **自己的刚中之德** |

> **⚠️ 结论（建议补入索引第五节）**：**同一个结构位置在不同领域里的正确动作可以完全相反。判断依据是这一卦的领域，不是这一爻的位置。**
> **师卦是"组织化对抗"——指挥权必须集中，多头指挥必凶，所以九二靠授权；临卦是"居上临下、势头渐长"——需要的是不偏的判断，所以九二靠刚中。**
> **这条通则对产品极重要：位属性只能给出"风险高低"，不能给出"该做什么"。该做什么必须先定域。**

### 7. 序卦链 18→19→20 与本卦打开的新格

> 序卦传："**蛊者，事也。有事而后可大，故受之以临。临者，大也。**"——**治完了事才能大起来。**
> 序卦传："**临者，大也。物大然后可观，故受之以观。**"——**大起来了，然后才被人看。**

**17→18→19→20 是一条极完整的因果链**：
> **随（跟着走）→ 蛊（跟着走会积下一堆事）→ 临（治完事才能大，大了就站到了上面）→ 观（站上去之后，你就成了被看的那个）。**

**本卦打开的新格**：按本库兑卦卡展开表，**临 19 属"兑在下"一族**（与已有的履 10 同族，且是这一族"讨好陷阱"的第二个实证）；按坤的结构律，它属"坤在上"一族（与师 7、比 8 的坤同侧）。
> **优先建议**：**观 20（上巽下坤）**——**本卡的对卦，两卡必须合读**（已在本批同批完成）。
> 其次是 **萃 45（上兑下坤）**——**临的兑坤上下颠倒**：临是"泽上有地"（地在上俯临），萃是"泽上于地"（水聚在地上）。**萃讲"聚"，与本库比卦（归附）、随卦（跟随）构成完整的"人怎么聚起来"三卦组**，且它是"兑在上"一族，可与临的"兑在下"直接对照，把这条通则彻底验完。
