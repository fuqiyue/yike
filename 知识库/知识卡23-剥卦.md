# 知识卡 23 · 剥卦（山地剥）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："贲者，饰也。致饰然后通则尽矣，故受之以剥。剥者，烂也。"——上一卦（贲 22）把形式做到了极致；**"致饰然后通则尽矣"——文饰做到头，可通的路也就走完了。装点到无可再装点，就开始烂、开始剥。**
> ⚠️ **版本待核**：序卦传"致饰然后通则尽矣"一句的断句各本略异（一作"致饰然后通，通则尽矣"），文意一致，此处照录通行本。
> **⚠️⚠️ 本卦与复卦（24）是全库最重要的一对，必须合读。** 剥＝阴长阳消到只剩上九一阳（层层剥落、势不可挡的衰败）；复＝一阳来复于最下（转机的起点）。**两卦互为反卦（把剥整个倒过来就是复），而序卦传把这条转换写成了四个字："穷上反下"。剥卦上九"硕果不食"保留的那一颗种子，正是复卦初九"不远复"。**（详见第四节）

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 剥 · 第二十三卦 |
| **卦象** | 上艮（山／止）下坤（地／顺），称"山地剥"。大象传作"**山附于地**"——**山本该高耸，现在却是"附于地"（贴伏在地上）：被剥到只剩一层贴着地面的形状。**<br>**五阴在下、一阳独存于上九**——**阴自下而上一层层长，把阳一路顶到最顶端，只剩最后一爻。**<br>**按本库第 4 节结构律，本卦的当位分布是全确定的**：**坤在下 → 六二当位（且得中）、初六与六三不当位**；**艮在上 → 六四当位、六五与上九不当位**。**六爻只有两爻当位（六二、六四），与师卦（7）、噬嗑卦（21）同为"2 当位"的低当位卦。**<br>**⚠️ 一个必须注意的结构事实：本卦无一处乘刚。** 全卦唯一的阳在最顶（上九），**它上面没有爻可以压它，下面五阴也没有一个是压在阳上的**。按本库通则（"艮把阳放在最上往下压，其内部不制造乘刚"＋坤全阴），**这个结果是必然的**。<br>**这条结构事实解释了剥卦痛苦的性质：剥卦的难，不是"被顶"（那是震／屯／噬嗑的六二），而是"被抽空"。没有人在顶你，是脚下的东西在一层一层消失。** |
| **⚠️ 六爻应位的结构事实（本卦最关键的一条，决定了六三为什么特殊）** | 《周易》的应位是"初应四、二应五、三应上"，**须一阴一阳方为正应**。本卦：<br>**初六 ↔ 六四：皆阴，不应。**<br>**六二 ↔ 六五：皆阴，不应**（这就是六二象传"**未有与也**"的结构原因——**没有援助**）。<br>**六三 ↔ 上九：一阴一阳，是全卦唯一的正应。**<br>**结论：五个阴爻中，只有六三与那唯一的阳有联系。所以它也是五阴中唯一判"无咎"的一爻**（象传"失上下也"——它离开了上下的群阴）。**在剥卦里，你的处境好坏取决于一件事：你还和"那一点阳"连着没有。** |
| **领域定义** | **系统性、渐进性、不可逆的衰败**。① 行业整体下行，公司连续裁员、业务线一条条关停；② 家道中落——资产、人脉、名声被一件件事耗掉；③ 身体机能的渐进衰退、慢性病一级一级加重；④ 组织里正直能干的人一个个走掉，最后只剩一两个；⑤ 一段关系的缓慢死亡（不是吵架，是一点点冷掉）；⑥ 个人信用、专业口碑被一次次小事磨没。<br>凡是"**它不是突然崩的，是一层一层剥下来的，而且我挡不住**"，都落在剥卦。 |
| **不归本卦的情况** | ① **突发的一下**（还没反应过来）→ **震卦（51）**（震是冲击型，"七日得"；**剥是滞留型，且不可逆**）；② **已经陷进去出不来** → **坎卦（29）**（坎是被困，剥是被消）；③ **要判断大势是由通转塞** → **否卦（12）**（否讲天地不交的格局判断，剥讲已经开始掉的过程）；④ **你有能力继续但决定主动停** → **艮卦（52）**；⑤ **冲突升级、要组织力量去打** → **师卦（7）**。<br>**剥卦特指"由下而上、一层一层、你挡不住的剥落"。它的关键词不是'险'也不是'塞'，是'消'。** |
| **"剥"字本义** | **剥落、剥蚀、剖裂**。序卦传给了另一个定义："**剥者，烂也**"——**烂：从里往外的腐坏。** 彖传给的定义最技术："**剥，剥也，柔变刚也**"——**"柔变刚"：阴一层层把阳替换掉。**<br>**三个定义合起来就是本卦的全部机制：外面在剥（剥落）、里面在烂（腐坏）、本质是替换（柔变刚）。** |
| **卦辞原文** | 剥：不利有攸往。 |
| **⚠️⚠️ 卦辞的关键结构（本库目前最"吝啬"的卦辞）** | **本库已完成各卦中，最吝啬的卦辞记录一直由师卦与艮卦保持**：师卦"贞，丈人吉，无咎"（**无元无亨无利，只有贞**）；艮卦"…无咎"（**无元无亨无利无贞，只给一个无咎**）。<br>**剥卦刷新了这个记录：它连"无咎"都不给。**<br>> **剥卦的卦辞里没有任何一个判词，只有一条禁令：不利有攸往。**<br>**这是全库唯一一个卦辞"通篇只有一句禁令、别无他语"的卦。**<br>⚠️ **本轮校准（与夬卡 43 第四节对齐）**：若把标准放宽为"一个判词都不给、只给一条禁令"，则**恰好两卦——剥「不利有攸往」与姤 44「勿用取女」**（姤卦辞另有「女壮」一句描述，非判词）。**两卦都在"阴在长"的那一段上；而它们的错卦（夬 43、复 24）都给了「利有攸往」。** 天道对这一卦的全部交代就是四个字：**别往前走。**<br>**⚠️ 但请注意它禁的是什么**：**禁的是"往"（有所前往、有所作为、往外扩张），不是禁"做事"。** 大象传随即给了一个必须做的动作（厚下安宅），彖传给了三个动作（顺、止、观）。**所以剥卦的正确读法不是"什么都别干"，而是"停止一切向外的动作，把力气全部转到向下加固上"。** |
| **卦辞现代解** | **不利有攸往**——**在剥落期，任何"往前一步"的动作都不利**：不要新开业务线、不要借新债去搏、不要在这个时候跳到更高的台阶、不要用一次大动作试图翻盘。<br>**理由彖传写得很清楚："小人长也"——不是你不够努力，是消耗你的那股力量正在生长期。在对方的生长期里主动出击，是把自己的最后一点存量送出去。** |
| **彖传** | 剥，剥也，柔变刚也。不利有攸往，小人长也。顺而止之，观象也。君子尚消息盈虚，天行也。 |
| **⚠️ 彖传要点（三条，本卦的全部方法论）** | ① **"不利有攸往，小人长也"**——**禁止前往的原因，是消耗方正在生长。** 本库口径提醒：**"小人长"是一个关于"势"的判断，不是关于"人品"的判断**。它说的是"剥落这股力量此刻处在上升段"，**在上升段里硬顶，损失的是你**。<br>② **"顺而止之，观象也"**（**本卦最实用的一句**）——**下坤是"顺"，上艮是"止"。合起来的动作是三个：顺（不硬抗）＋止（把它止住）＋观（看清形势）。**<br>**⚠️ 注意"顺而止之"这个语序：先顺，后止。不是先止后顺。** 意思是：**你不能正面挡住剥落（挡不住），只能顺着它的方向走，在顺的过程中找到可以止住它的那个点。** 而"观象也"三个字点明：**这一卦要求的第一个动作是"看"，不是"动"。**<br>③ **"君子尚消息盈虚，天行也"**（**全库"周期律"的经文原点之一**）——**"消"是阳的消退，"息"是阳的生长；"盈虚"是满与空。君子"尚"（推崇、看重）这件事，因为它是"天行"（天道的运行）。**<br>**这一句是全库第一次由经文直接说出："衰败与生长的交替本身就是天道"。** 它和复卦彖传"**七日来复，天行也**"是同一个"天行也"，**两句合起来就是《周易》给周期律下的定义**（详见第四节）。 |
| **大象传（行动纲领）** | 山附于地，剥。上以厚下安宅。 |
| **⚠️⚠️ "厚下安宅"解（本卦最高层原则）** | **注意主语是"上以"——不是"君子以"，也不是"先王以"。** 这是《周易》大象传中极罕见的主语，**"上"指在上位者、当家的那个人**。<br>**为什么剥卦要专门指定"上"？** 因为**剥落是自下而上的**（初六剥床脚 → 六二剥床身 → 六四剥到肌肤），**而在上位者往往最后才感觉到**。**大象传把这条纲领直接交给"上"，就是在说：底下已经在掉了，最该动的是你，而不是底下那些正在掉的人。**<br>**厚下**＝**把下面加厚**（下＝基础、底层、民、现金流、家底、身体的基本盘）。**安宅**＝**使居所安稳**（宅＝安身之所、根据地、最后不能丢的那一块）。<br>**⚠️ 这条纲领最狠的地方在于它的方向与剥落方向正相反**：<br>> **剥是从下往上剥的，所以补也必须从下往上补。**<br>**山之所以"附于地"（塌成一片贴着地面），是因为底下被剥空了。此时唯一有效的动作不是把山垒回去（往上补），是把地加厚（往下补）。**<br>**落到现代最直接的一句：衰败期不要去救那个最显眼的、掉得最厉害的项目（那是"山"），要去加厚最下面那一层——现金、健康、最核心的两三个人、住的地方。** |
| **总铁律** | ① **不许往**（卦辞）——剥落期任何向外扩张的动作都是把存量送出去；② **先顺后止，且第一动作是"观"**（彖传"顺而止之，观象也"）——挡不住就别正面挡；③ **补必须从下往上补**（大象传"厚下安宅"）——剥从下起，补也从下起；④ **保住那一点阳**（上九"硕果不食"）——**全卦真正的任务只有这一条：把最后那颗种子留住，别吃了它**；⑤ **不许灭"贞"**（初六、六二皆判"蔑贞凶"）——**衰败期把底线也一起放弃，才是这一卦里唯一的"凶"的来源**。 |

## 二、爻级字段

**⚠️ 先读这一段，本卦六爻是一条极清晰的"剥落进程表"：**

| 爻 | 剥到哪里 | 判词 | 关键 |
|---|---|---|---|
| **初六** | **床足**（床腿） | **蔑贞凶** | 剥落从最下、最看不见处开始 |
| **六二** | **床辨**（床身与腿的交接） | **蔑贞凶** | 剥到承重的连接处，且**无援**（未有与也） |
| **六三** | —（不言剥床） | **无咎** | **全卦唯一与那一阳有正应的爻**（失上下也） |
| **六四** | **床肤**（床面／人的肌肤） | **凶** | **切近灾也**——已经剥到人身上 |
| **六五** | —（不言剥床） | **无不利** | **贯鱼**：把散乱的阴组织起来，顺承那一阳 |
| **上九** | **硕果不食**（唯一的阳） | 两种结局并列 | **君子得舆／小人剥庐**——种子留住还是连屋子都拆了 |

**⚠️ 两个必须先注意的事实：**
1. **"剥床"这个意象只出现在初六、六二、六四三爻，而这三爻正是全卦三个"凶"。** 六三、六五、上九都不说"剥床"——**它们讲的不是被剥，是在剥落中怎么活。**
2. **本卦六爻中有三个"凶"（初六、六二、六四），这是本库已完成各卦中"凶"最密的一卦**（对照：师卦 2 处、坎卦 2 处、离卦 2 处）。**而剥卦的三个凶全部集中在前四爻，即剥落进行期。**

### 初六 · 剥床以足

| 字段 | 内容 |
|---|---|
| **爻辞** | 剥床以足，蔑贞凶。 |
| **象传** | 剥床以足，以灭下也。 |
| **位属性** | 阴爻居阳位，**不当位**；居全卦最下——**剥落的起点**；**与六四不应（皆阴），无援** |
| **判词 → 行动语义** | **凶** → **在最下、最不显眼处已经开始掉了；此时守住底线，别跟着一起放弃** |
| **关键词解** | **床**＝安身之具（**全卦用"床"来比喻你的安身立命之所**）。**足**＝床腿，**最下、最承重、最不被注意的部分**。**蔑**＝通"灭"，消灭、无。**蔑贞**＝**正道／底线被灭掉**。**灭下**＝从下面开始灭。 |
| **⚠️ 本爻的核心：凶的原因是"蔑贞"，不是"剥床"** | 这一爻要极小心读。爻辞是两截：**"剥床以足"是描述现象（床腿在掉），"蔑贞凶"是判词及其原因。**<br>**《周易》没有说"床腿掉了所以凶"——它说的是"底线被灭掉了，所以凶"。**<br>**这是全卦最重要的分辨**：**剥落本身是天行（彖传"消息盈虚，天行也"），不判凶；跟着剥落一起把自己的"贞"也放弃掉，才判凶。**<br>**落到现代：公司开始掉业务，这不凶；因为公司在掉，你开始不守规矩、开始糊弄、开始做以前不肯做的事——这才是"蔑贞凶"。** |
| **识别信号** | ① 最基础的那一层开始有掉的迹象——现金流、体检指标、最核心那两三个人的状态、家里最基本的开支；② 现象很小、在最下面，几乎没人提；③ **你或你周围的人开始出现"反正都这样了"的松动**（这是"蔑贞"的第一个征兆）。 |
| **该做** | ① **把"贞"单独拎出来锁死**：写下三条不管情况多坏都不会做的事，并且立刻执行；② **按大象传"厚下"办**——**把资源往最下那一层收**（现金、健康、住处、核心几个人）；③ 记录并盯住那个"足"上的指标，别让它掉出视野。 |
| **不该做** | ① 用一个大动作去翻盘（卦辞已明令"不利有攸往"）；② 觉得"这么小的事不至于"。 |
| **与坤初六"履霜坚冰至"的直接呼应（本库最该并读的两个初六）** | **坤初六"履霜，坚冰至"，象传"阴始凝也。驯致其道，至坚冰也"——阴的力量在最开端萌生，见微知著、防微。**<br>**剥初六"剥床以足…以灭下也"——阴已经开始把最下面那一层灭掉。**<br>**两爻是同一个进程的两个时点：坤初六是"霜刚落，还只是征兆"；剥初六是"已经开始掉了，但掉在最下面"。**<br>**⚠️ 而且两卦的下卦都是坤（纯阴）。坤卦讲的"驯致其道，至坚冰也"（顺着这条路走下去，一定到坚冰），在剥卦这里就是那条已经走成的路。**<br>> **合读的结论：坤初六是最早的预警，剥初六是预警已经落地。到了剥初六，"防微"的窗口已经关了，动作从"察"变成"厚下"。** |

### 六二 · 剥床以辨（⚠️ 当位得中却判凶）

| 字段 | 内容 |
|---|---|
| **爻辞** | 剥床以辨，蔑贞凶。 |
| **象传** | 剥床以辨，未有与也。 |
| **位属性** | 阴爻居阴位，**当位且得中**——**按本库通则，这本该是最好的位置之一**；**但与六五皆阴，不应，无正应**——象传直接点明"**未有与也**" |
| **判词 → 行动语义** | **凶**（与初六同判） → **剥到承重的连接处了，而且你没有援助；此时更要守住底线** |
| **关键词解** | **辨**＝床身与床腿之间的分隔／连接部位（一说即床干、床板与足之交接处）。**剥床以辨**＝**剥落已经上升到承重的连接处**。**与**＝援助、同伴、应与（"未有与"即无人相应、无外援）。 |
| **⚠️ 本爻是全库"当位得中却判凶"的关键实例（口径必须记住）** | 本库通则一直强调：**当位＝名正言顺，得中＝可救不当位**。**六二在本卦当位又得中，条件全对，判词却是"凶"。**<br>**象传给了唯一的原因："未有与也"——没有援助。**<br>**结构上为什么没有？因为六二的应位是六五，而六五也是阴——同性不应。全卦五阴，只有六三应得上上九那一阳。**<br>> **可入库的口径（重要）**：**"当位得中"能保证的是"你没做错"，不能保证"你不受损"。当整个环境里没有阳（没有可援之力、没有可依之正、没有人接得住你）时，当位得中也只是一个人站得很正地被剥掉。**<br>**这与震六二形成一组极干净的对照**：**震六二当位得中而"厉"，原因是"乘刚也"（有阳在下顶你）；剥六二当位得中而"凶"，原因是"未有与也"（根本没有阳）。**<br>**一个是被阳打，一个是没有阳可依。后者更重——判词从"厉"跌到"凶"。** |
| **识别信号** | ① 剥落已经从最边缘上升到承重结构（不是可选项在掉，是必需项在掉：核心客户、主营收入、关键人、基本体能）；② **你环顾四周，发现没有人能真正帮你**——上面接不住，同级都在自保，下面在观望；③ 你自己的位置、名分、做事方式都是正的、挑不出错的（当位得中）；④ 你开始怀疑"我这么规矩到底有什么用"。 |
| **该做** | ① **接受"未有与"这个事实，停止求援**——把用来找援助的力气全部转到"厚下"上；② **继续守"贞"**：本爻的凶与初六同源，来自"蔑贞"；**在没有援助的时候放弃底线，是这一卦里最快的死法**；③ **按彖传"观象"办——先看清整个盘子在往哪儿走，再决定一个动作，而不是慌乱地试。** |
| **不该做** | ① 把大量时间用在找靠山、找接盘、找同盟上（**"未有与也"是象传给的结构判断，不是运气不好**）；② 因为"我明明是对的"而生怨——**这一爻的教导正是：对，不等于不受损。** |
| **与师六四、艮六二的对照** | **师六四"师左次，无咎"，象传"未失常也"——有实力者主动后撤，退就是赢**；**艮六二"艮其腓，不拯其随，其心不快"，象传"未退听也"——止住了自己，救不了上面的人，只落一个心不快**；**剥六二"未有与也"——连一个可救可劝的对象都没有。**<br>**三爻按"外部还有多少可依"排序：师六四有兵可撤，艮六二有人可劝（虽然不听），剥六二什么都没有。而三者的动作恰好也依次收缩：撤 → 止己 → 厚下。** |

### 六三 · 剥之（⚠️ 五阴中唯一无咎的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 剥之，无咎。 |
| **象传** | 剥之无咎，失上下也。 |
| **位属性** | 阴爻居阳位，**不当位**；失中；居下坤之顶；**但与上九一阴一阳，是全卦唯一的正应**；本库通则"**三多凶**"，**而本爻是全卦五阴中唯一不判凶的** |
| **判词 → 行动语义** | **无咎**（按本库口径：无灾，不等于吉利） → **脱离正在剥落的那一群，去连上那唯一还在的阳** |
| **关键词解** | **剥之**＝二字极简（对照初六、六二、六四都说"剥床以某"）。**本爻不说剥床，说明它已经不在"被剥的床"里了。** **失上下**＝**离开了上下（即上下的群阴）**——"失"在此不是损失，是**脱离、不与之同群**。 |
| **⚠️ 本爻是全卦最实用的一爻，也是最反直觉的一爻** | **不当位、失中、居三多凶之位、身处剥落之中——按本库任何一条通则，它都该是凶。判词偏偏是"无咎"。**<br>**象传给的原因干净得不需要解释："失上下也"——它离开了上下那一群阴。**<br>**结构上讲，六三是五个阴爻里唯一"应"得上上九那一阳的**（三应上）。**所以它的"无咎"不来自它的位置（位置很差），来自它的连接对象。**<br>> **这一爻给出的是剥卦里唯一一条个人层面的活路**：<br>> **在系统性衰败中，决定你结局的不是你在系统里的位置正不正，而是你还和"那一点还没被剥掉的阳"连着没有。**<br>**"上下"在这里是双关：既指上下的群阴（同僚、同群、大势），也指上下两个方向的裹挟。"失上下"就是主动从那股正在往下掉的群体动能里退出来。**<br>**⚠️ 注意《周易》给的分寸：它只判"无咎"，不判吉。** 意思是：**你脱离了那一群，所以你不会被一起剥掉；但你并没有因此得到好处，衰败还在继续。** |
| **识别信号** | ① 你身处一个正在整体下滑的组织／行业／关系里；② 你周围的人在同一个方向上一起往下走，且彼此裹挟（大家都这么干、都这么想、都这么消耗）；③ 你能识别出这个系统里"还没坏的那一点"是什么／是谁；④ 你正在纠结"要不要跟大家保持一致"。 |
| **该做** | ① **从那个群体动能里退出来**——不再参与共同的抱怨、共同的糊弄、共同的赌一把；② **把连接建到"那一点阳"上**：那个还在认真做事的人、那条还在赚钱的业务、那个还没坏的习惯、那个还守正的圈子。**明确、具体、只一个也行**；③ **接受"无咎"的分量**——这是免灾，不是翻盘。 |
| **不该做** | ① 为了"合群"留在下滑的动能里（**"失上下也"是本爻全部的解药，不失上下就没有无咎**）；② 把脱离群体做成公开的对抗、批判、割席——**爻辞只有两个字"剥之"，动作是极安静的。** |
| **与讼六三、震六三、噬嗑六三的四爻对照（四个不当位的"三"）** | **讼六三"食旧德，贞厉终吉"（从上吉也）——守本分、功归上**；**震六三"震苏苏，震行无眚"（位不当也）——跟着震动走**；**噬嗑六三"噬腊肉，遇毒，小吝无咎"（位不当也）——先补名分再办**；**剥六三"剥之，无咎"（失上下也）——脱离群体、连上那一点阳。**<br>**四个"三"全部不当位，四种处方，共同点只有一个：都不是靠"把位置摆正"来解决的（三爻的位置摆不正）。** 差别在于**各自领域里"可依之物"是什么**：讼靠旧德，震靠动能，噬嗑靠名分，**剥靠那唯一的一点阳。** |

### 六四 · 剥床以肤

| 字段 | 内容 |
|---|---|
| **爻辞** | 剥床以肤，凶。 |
| **象传** | 剥床以肤，切近灾也。 |
| **位属性** | 阴爻居阴位，**当位**；**刚入上艮**；本库通则"**四多惧**"；与初六不应（皆阴），**无援** |
| **判词 → 行动语义** | **凶** → **已经剥到人身上了；此时不许有任何向外的动作** |
| **关键词解** | **肤**＝床面／褥席（一说即人的肌肤）。**剥床以肤**＝剥落已经到了床面这一层——**再往上就是躺在床上的那个人**。**切近**＝紧贴着、马上就到。**切近灾也**＝**灾已经贴到身上了。** |
| **⚠️ 本爻是剥落进程的最后一站，也是全卦三个凶中最重的一个** | 剥落三级：**足（床腿，初六）→ 辨（承重连接，六二）→ 肤（床面，六四）**。<br>**注意初六、六二的判词都是"蔑贞凶"——凶的原因是"灭了贞"；而六四的判词只有一个字"凶"，象传只说"切近灾也"。**<br>> **这个差别很重要：前两爻的凶还挂着一个原因（你放弃了底线），说明还有可控的部分；六四的凶不给原因，只报距离——灾已经贴到皮肤上了。**<br>**这是剥卦对"拖"的最终定价：拖到"肤"，就没有"因为什么"可谈了，只有"多近"。** |
| **⚠️ 本爻当位而凶（与六二同型，是本库"当位不保平安"的第二个实例）** | **六四阴居阴位，当位**；但**上无援（初六亦阴，不应）**，且**已入上艮（被止住、动不了）**。<br>**它与六二合起来给出一条口径**：<br>> **在剥卦这种"环境里没有阳"的处境中，"当位"完全不构成保护。全卦两个当位的爻（六二、六四）都判了凶，而不当位的六三反而无咎——因为它连上了阳。**<br>**这是全库对"当位"这条通则最强的一次限定：当位是"你自己站得正"，它不能替代"你身处的系统里还有没有正的东西"。** |
| **识别信号** | ① 剥落已经到你身上了——不是公司在裁，是裁到你这一层；不是行业在缩，是你的收入在缩；不是指标异常，是症状出现了；② 你已经动不了了（上艮＝被止住：没有资源、没有窗口、没有下一步）；③ 你身边没有可以接住你的人；④ **有人在此刻劝你"最后搏一把"。** |
| **该做** | ① **绝对不动**（卦辞"不利有攸往"在这一爻上是最硬的）；② **把"宅"守住**——**大象传"安宅"在这一爻是唯一的动作：住处、健康、最基本的现金、最核心的一两个人，其余全部放弃**；③ **主动往六五、上九的方向读**：全卦的出路不在剥落进程里，在六五（把散乱的力量组织起来）和上九（保住那颗种子）。 |
| **不该做** | ① 搏最后一把（**"切近灾也"的意思是你已经没有失败的余量了**）；② 继续把资源投在正在剥落的那一层（**要"厚下"，不是"补山"**）。 |
| **与坎上六、离九四的对照** | **坎上六"系用徽纆，三岁不得，凶"——被绑着长期出不来**；**离九四"焚如死如弃如"，象传"无所容也"——烧尽，连停都来不及**；**剥六四"剥床以肤，凶"，象传"切近灾也"——灾已贴身，但还没到。**<br>**三者都是重爻，剥六四是三者中唯一"灾还没落"的**：**离九四已经烧完，坎上六已经被绑住，剥六四是"贴到了，还差一层"。** 所以它是三者中唯一还有动作可做的——**而那个动作只有两个字：安宅。** |

### 六五 · 贯鱼（⚠️ 全卦判词最高的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 贯鱼，以宫人宠，无不利。 |
| **象传** | 以宫人宠，终无尤也。 |
| **位属性** | 阴爻居阳位，**不当位**（艮在上则五、上皆不当位），但**得中**且居尊位——**全卦卦主，是五阴之长，也是唯一紧邻那一点阳的阴爻** |
| **判词 → 行动语义** | **无不利**（按本库吉凶序：**元吉 ＞ 无不利／大吉 ＞ 吉**——**这是本卦唯一的高位判词，约等于大吉**） → **把散乱的剥落之力组织成有次序的序列，顺承那唯一还在的阳** |
| **关键词解** | **贯鱼**＝**用绳把鱼一条条串起来**（"贯"是穿、串）——**从散乱变成有次序的序列**。**宫人**＝宫中女官／侍御之人。**以宫人宠**＝**像宫人受宠那样，各依其序、各得其位地承接恩宠**（宫人之制的要点就是"有次序"）。**尤**＝过失、怨咎。 |
| **⚠️ 本爻是剥卦真正的解法所在（也是全卦最容易被跳过的一爻）** | **一个六爻中有三个"凶"的衰败之卦，第五爻却给了接近大吉的"无不利"。** 这不是矛盾，是《周易》在告诉你剥卦的正确动作是什么：<br>**六五是五个阴（剥落之力）的领头者，同时是唯一贴着上九那一阳的阴。它的动作有两个：**<br>**① "贯"——把散乱的阴串成有次序的序列。** 剥落之所以势不可挡，一半原因是它是散的、无序的、各处同时在掉。**六五做的事是给它排序：哪个先掉、哪个后掉、哪个绝不能掉。**<br>**② "以宫人宠"——各依其序地顺承上面那一阳。** 不是消灭剥落之力（消灭不了，彖传说"小人长也"），**是让它有序地服从于那唯一还在的正面力量。**<br>> **译成现代管理语言，这是衰败期最高级的一个动作：**
> **你止不住业务在掉、人在走、钱在少。你能做的是给这个下降过程排一个序——列出关停顺序、削减顺序、放弃顺序，并让所有资源按序服务于那个还活着的核心。**
> **无序的收缩会把核心一起带走；有序的收缩能把核心保下来。这就是"贯鱼"与"无不利"的因果。**<br>**象传只加了三个字的保证："终无尤也"——最终不会有过失。注意它同样不承诺"翻盘"：剥卦不给翻盘，只给"无尤"。** |
| **识别信号** | ① 你是这个下降局面里拍板的那个人；② 你的名分其实不足（不当位：临时受命、代理、或者这个烂摊子本来不是你造成的）；③ 局面在多处同时往下掉，你在四处救火，而且救不过来；④ 你能说清"这个盘子里唯一还不能碰的是什么"（那就是上九那颗硕果）。 |
| **该做** | ① **排序，而不是全救**：把所有正在掉的东西列出来，明确关停／削减／放弃的先后，写下来并公布；② **指定那一个不许碰的核心**（人、业务、现金底线、身体的某项指标），**所有排序都以保它为准**；③ **让每一项收缩都"各依其序"地服务于那个核心（以宫人宠）**——**不允许出现"为了救 A 把核心 B 挪用了"的情况。** |
| **不该做** | ① 四处救火、平均用力（**那就是"鱼没有被贯起来"**）；② 用一次大动作试图逆转（卦辞"不利有攸往"）；③ 借这个局面立威、清算——**六五不当位，动作越大越把不足照亮**（与噬嗑六五、贲六五完全同理）。 |
| **本库"六五／九五"专题的第八例** | 已有七例：**乾九五**（放弃独断）、**坤六五**（放弃权柄）、**蒙六五**（放弃架子）、**离六五**（放弃坚强）、**艮六五**（放弃说话的自由）、**噬嗑六五**（放弃罚个够的痛快）、**贲六五**（放弃排场）。**剥六五补上第八种：放弃"全都要救"的执念——只保一颗种子，其余按序放手。**<br>**⚠️ 而且它是这八例里判词第二高的（无不利，仅次于坤六五的元吉）。这说明一件事：在最坏的局面里，"主动放弃"这个动作的价值最高。** |

### 上九 · 硕果不食（⚠️ 全卦落点，也是通向复卦的那颗种子）

| 字段 | 内容 |
|---|---|
| **爻辞** | 硕果不食，君子得舆，小人剥庐。 |
| **象传** | 君子得舆，民所载也。小人剥庐，终不可用也。 |
| **位属性** | 阳爻居阴位，**不当位**；**全卦唯一的阳爻**，居全卦之终——**被五阴一路顶到最顶端，是"剩下的最后一点阳"**；**是上艮那一阳（按艮卦口径，它是"止"的力量本身所在）** |
| **判词 → 行动语义** | **两种结局并列**（君子得舆 / 小人剥庐） → **看你把这最后一颗大果当成种子留着，还是当成粮食吃掉** |
| **关键词解** | **硕果**＝**树上最大的那颗果实**。**不食**＝**没有被吃掉**（**这三个字是全卦的落点**）。**舆**＝车舆，**引申为被承载、被拥戴**。**庐**＝屋舍、寄身之所。**剥庐**＝**连自己住的屋子都拆掉了**。 |
| **⚠️⚠️ "硕果不食"是全库"周期律"的经文原点（本卡最重要的一条）** | 五阴一路剥上来，把阳顶到最顶端，只剩这一爻。**《周易》没有让它也被剥掉，而是给了一个极具体的意象：树上最高处那颗最大的果实，没有被吃。**<br>**为什么最高处的果实往往不被吃？因为摘不到。这就是剥卦留给下一卦的全部资本。**<br>**而"不食"三个字才是关键：一颗被吃掉的果实是粮食（当期消耗掉了），一颗没被吃掉的果实是种子（能进入下一轮）。**<br>> **序卦传把这个转换写死了："物不可以终尽剥，穷上反下，故受之以复。"**
> **"穷上反下"——剥卦这一阳穷尽于最上（上九），转过来就落到最下（复卦初九）。把剥卦整个倒过来，就是复卦。**
> **所以：剥上九"硕果不食"保留的那颗种子，就是复卦初九"不远复，无祗悔，元吉"。这不是比喻，是同一个阳爻在反卦中的同一个位置。**（完整链条见第四节） |
| **⚠️ "君子得舆／小人剥庐"是两种结局并列（本卦的最终分岔）** | 这是全库第三个"同一爻两种结局并列"的例子（另两个是**师六五**"长子帅师／弟子舆尸"、**离九三**"鼓缶而歌／大耋之嗟"）。<br>**君子得舆——象传"民所载也"**：**君子在这一爻做的事是把那颗果留住**，所以他被下面的众人承载（车舆之象）。**注意这个因果：不是他去争取拥戴，是他保住了种子，所以众人愿意载他。**<br>**小人剥庐——象传"终不可用也"**：**小人在这一爻做的事是把果也吃掉**，剥到最后连自己的房子都拆了。**"庐"是最后的安身之所——本卦大象传的"安宅"就是它。剥庐＝把大象传唯一的纲领亲手违反。** 象传的判决是四个字：**终不可用**——**这个人从此不能再用了。**<br>> **两种结局的分岔点只有一个动作：吃不吃那颗果。**
> **落到现代：衰败到最后，手里只剩一件东西（一笔救命钱、一个核心团队成员、一项还在赚钱的业务、一副还撑得住的身体）。留着它，你会被人承载；把它也变现掉，你连住的地方都没有了。** |
| **识别信号** | ① 剥落已经走到尽头，你手里只剩一件真正有价值的东西；② 有充分正当的理由把它也用掉（"用它可以救活现在这个局面"）；③ 你已经看不到下一轮，所以觉得留着没用；④ 身边有人在算"把这个也卖了还能撑几个月"。 |
| **该做** | ① **明确指认那颗"硕果"是什么，并把它写下来、锁死、设为不可动用**；② **接受"这一轮已经结束"这个事实**——种子的用处不在这一轮，在下一轮；③ **保住"庐"**（大象传"安宅"）：**住处、基本生活、最后的安身之所，绝不动**。 |
| **不该做** | ① 用那颗果去救这一轮（**这就是"食"，也是"剥庐"的开始**）；② 因为看不到下一轮就认为种子无价值——**剥卦上九的全部意义，就是替一个你还看不见的下一轮做准备。** |
| **与艮上九、乾上九的三爻对照（三个上爻）** | **乾上九"亢龙有悔"——盈极不知止，乾卦唯一的纯凶之爻**；**艮上九"敦艮，吉"，象传"以厚终也"——主动止到极处，八纯卦上爻里唯一的吉**；**剥上九"硕果不食"——不给判词，只给两种结局，让你自己选。**<br>**三者的共同点：都在"到顶"这个位置；差别在于到顶时手里还有什么。乾上九手里是满（所以要止），艮上九手里是止本身（所以吉），剥上九手里只剩一颗果（所以只问你吃不吃）。**<br>> **本库"上爻限定"通则再进一层**：**"上＝物极必反"，反的是"不知止的极"（艮卡）；而剥上九补上另一种极——"被剥到极"。到这种极的人，考题不是"要不要止"，是"要不要把最后一点存量也消费掉"。** |

## 三、剥卦定位速查表

| 爻 | 剥到哪 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | **足**（床腿） | 剥床以足 | 最下那一层开始掉，几乎没人提 | 不当位·**无应** | **蔑贞凶**·锁死底线·厚下 |
| 六二 | **辨**（承重连接） | 剥床以辨 | 必需项在掉，且四顾无人能帮你 | **当位·得中**·**未有与** | **蔑贞凶**·停止求援·继续守贞 |
| 六三 | —（脱离） | 剥之 | 周围人一起往下走，你在纠结要不要合群 | 不当位·**唯一有正应** | **无咎**·失上下·连上那一点阳 |
| 六四 | **肤**（贴身） | 剥床以肤 | 已经剥到你身上，且有人劝你搏一把 | 当位·**无应**·四多惧 | **凶**·切近灾·绝对不动·安宅 |
| 六五 | —（组织） | 贯鱼·以宫人宠 | 你在拍板，多处同时掉，救不过来 | 不当位但**得中居尊** | **无不利**·排序收缩·只保核心 |
| 上九 | **硕果**（唯一的阳） | 硕果不食 | 只剩一件真东西，有理由把它也用掉 | 不当位·**全卦唯一阳** | **君子得舆／小人剥庐**·别吃那颗果 |

**剥卦三句话**：
1. **剥落本身不凶，跟着剥落一起放弃底线才凶。** 初六、六二判的都是"**蔑贞**凶"——**凶的原因写在"蔑贞"三个字上，不在"剥床"三个字上。** 剥落是天行（彖传"消息盈虚，天行也"）。
2. **补必须从下往上补。** 大象传"**上以厚下安宅**"——**剥是从床腿开始剥的，所以救也必须从最底层开始加厚**。衰败期不要去救那个掉得最厉害、最显眼的东西（那是"山"），要去加厚最下面那一层（现金、健康、住处、核心的两三个人）。
3. **全卦真正的任务只有一条：别吃那颗果。** 上九"**硕果不食**"——**留着它，你被人承载（君子得舆）；把它也吃掉，连住的地方都没了（小人剥庐），而且"终不可用也"。**

**本卦最反直觉的四条**：
- **卦辞里没有任何判词，只有一句禁令："不利有攸往"。** 这是本库唯一一个连"无咎"都不给的卦辞——**比师卦（只有"贞"）、艮卦（只有"无咎"）更吝啬**。但它禁的是"往"，不是"做"：彖传给了三个动作（顺、止、观），大象传给了一个动作（厚下安宅）。
- **当位得中的六二判"凶"，不当位失中的六三判"无咎"。** 差别只有一个：**六三是五阴里唯一应得上那一点阳的**（象传"失上下也"）。**在系统性衰败中，"你站得正不正"让位于"你还和那点阳连着没有"。**
- **一个有三个"凶"的衰败之卦，第五爻给了接近大吉的"无不利"。** 因为六五做的是**"贯鱼"——给下降过程排一个序**。**无序的收缩会把核心一起带走，有序的收缩能把核心保下来。**
- **本卦没有一处乘刚。** 全卦唯一的阳在最顶端，谁也压不到它，它也顶不到谁。**这条结构事实定义了剥卦痛苦的性质：不是"被顶"（震／屯／噬嗑六二那种），是"被抽空"。** 没有人在顶你，是脚下的东西在一层一层消失。

## 四、本卦对全库的意义

### 1. 与复卦（24）合成全库"周期律"的经文依据（本批最重要的增量）

**这两卦不是"相似"，是同一个卦的两个方向。三条经文把这条链锁死了：**

| 环节 | 经文 | 说的是什么 |
|---|---|---|
| **① 衰败是天道，不是你的错** | **剥彖传："君子尚消息盈虚，天行也。"** | **"消"（阳退）与"息"（阳长）、"盈"与"虚"的交替，本身就是天行。** 君子"尚"（看重）它，而不是抗拒它。 |
| **② 剥到尽头必转，转法是"穷上反下"** | **序卦传："物不可以终尽剥，穷上反下，故受之以复。"** | **剥卦那一阳穷尽于最上（上九），转过来就落到最下（复初九）。把剥整个倒过来就是复——两卦互为反卦。** |
| **③ 回复也是天道，且有节奏** | **复彖传："反复其道，七日来复，天行也。"** | 同一个"**天行也**"。**衰与复被判为同一条天道的两段。** |
| **④ 那个转过来的东西，是一颗没被吃掉的果** | **剥上九"硕果不食" → 复初九"不远复，无祗悔，元吉"** | **同一个阳爻，在反卦里的同一个身份：剥卦把它留下来（不食），复卦把它用起来（不远复）。** |

> **可直接入库为本库第一条"周期通则"**：
> **· 剥＝阴长阳消到只剩最上一爻，其任务是"保住种子"（硕果不食）；复＝一阳来复于最下，其任务是"及早回头"（不远复）。**
> **· 两卦互为反卦，序卦传的"穷上反下"就是这个反转本身。**
> **· 因此：剥卦的正确读法不是"我完了"，是"我这一轮结束了，现在要做的是把种子留下"。而复卦的正确读法不是"我起来了"，是"那颗种子刚落地，极其脆弱，此时必须封闭休养"。**
> **· ⚠️ 合规提醒：这条通则解释经文之间的结构关系；面向未来的推测统一见 `知识卡00` 第七节与宪法 RULE-007，本卡不另立预测政策。经文给的是"必转"的结构判断，不是现实时间表，经文刻度不得换算成现实日期。**

**⚠️ 关于"七日来复"的时间尺度（版本与来源标注）**：汉代以后注家多以**卦气／十二消息卦**说解之——把十二卦配十二月：**复（十一月，冬至所在）、临、泰、大壮、夬、乾、姤、遯、否、观、剥（九月）、坤（十月）**；一阴始生于姤，历遯、否、观、剥、坤而至复，为"七"。另一种解法是就爻位数：**阳穷于剥之上九，历坤卦六爻纯阴，至复初九阳复，正是第七位。** **两说皆为后世注家之说，非经文本身；卦气配月须声明为汉代注家之说，不能把经文刻度换算成现实日期。面向未来的推测边界统一见 `知识卡00` 第七节与宪法 RULE-007。**

### 2. 对"当位"通则的最强限定（剥卦是全库唯一的完整反例）

本库通则：**同性＝当位（名正言顺、风险低），异性＝不当位（名不正、风险高）；二五得中，得中可救不当位。**

**剥卦六爻把这条通则整个翻过来了：**

| 爻 | 位属性 | 有无正应 | 判词 |
|---|---|---|---|
| 初六 | 不当位 | **无** | 凶 |
| **六二** | **当位＋得中** | **无**（象传"未有与也"） | **凶** |
| **六三** | **不当位＋失中** | **有**（应上九） | **无咎** |
| **六四** | **当位** | **无** | **凶** |
| 六五 | 不当位·得中居尊 | 无 | **无不利**（靠"贯鱼"这个动作救的） |
| 上九 | 不当位 | 有（应六三） | 两种结局并列 |

> **可入库的口径修正（重要）**：
> **"当位"保证的是"你没做错"，不保证"你不受损"。**
> **当整个系统里没有阳可依时（剥卦五阴一阳），当位得中也只是一个人站得很正地被剥掉（六二、六四皆凶）；而不当位失中的六三，只因为它应得上那一点阳，就拿到了无咎。**
> **落到诊断上：在剥卦领域的问题里，第一个要问的不是"我的位置正不正"，是"这个系统里还有没有阳，我和它连着没有"。**

**并列对照（三个"当位得中却受损"的六二）**：

| 卦 | 六二 | 位属性 | 受损原因（象传原文） | 判词 |
|---|---|---|---|---|
| 屯 3 | 屯如邅如…十年乃字 | 当位得中 | "六二之难，**乘刚也**" | 难 |
| 震 51 | 震来厉，亿丧贝 | 当位得中 | "震来厉，**乘刚也**" | **厉** |
| **剥 23** | **剥床以辨** | **当位得中** | "剥床以辨，**未有与也**" | **凶** |

> **一句话记住三者的差别**：**屯／震六二是"有阳在下顶你"（乘刚，被打）；剥六二是"根本没有阳"（未有与，无可依）。后者更重——判词从"厉"直接跌到"凶"。**

### 3. 大象传主语第三种："上以"

本批四卦一次性补齐了《周易》大象传三种主语中的三种（详见知识卡 21 第四节）：

| 主语 | 层级 | 本批出处 | 本库已有 |
|---|---|---|---|
| **君子以** | 修身层（人人可做） | **贲 22**："君子以明庶政，无敢折狱" | 乾、坤、屯、需、讼、师…（多数卦） |
| **上以** | **在位者层（当家的那个人）** | **剥 23**："**上以**厚下安宅" | **无（本卦是本库第一例）** |
| **先王以** | 制度层（最高立法者） | **噬嗑 21**"先王以明罚敕法"、**复 24**"先王以至日闭关…" | 比 8"先王以建万国，亲诸侯" |

> **"上以"为什么只在剥卦出现（这不是偶然）**：**剥落是自下而上的，而在上位者往往最后才感觉到。** 大象传把这条纲领单独指定给"上"，就是在说：**底下已经在掉了，最该改变动作的是你，不是那些正在掉的人。**
> **用法**：读到"上以"，要先确认自己是不是那个"上"。**如果不是，这条纲领对你的形态是"提醒你的上位者去厚下"，而不是"你自己去厚下整个盘子"**（后者会掉进艮六二"不拯其随，其心不快"——你救不了不肯退听的人）。

剥是**艮卡第三节"艮在上"栏**列出的待补卦之一。**本卦完成后，"艮在上"栏（被压住不许动）已有蒙 4、贲 22、剥 23、艮 52 四张**。

| 与剥直接成组的卦 | 关系 | 优先度 |
|---|---|---|

> **优先建议**：**谦 15（上坤下艮）**。理由：① 它恰是剥的上下颠倒——**同样两个三画卦，剥是"山塌在地上"（山附于地，被剥空），谦是"地在山上"（地中有山，把高的藏在低的下面）。一个是被动剥落，一个是主动藏高**，两卦并读，"高与低"这条轴就完整了；② 艮卡已把它列为首选（"本库已有坤卦与履卦，谦卦正是这两张卡之间缺失的一环"），**本卡与之独立地得出同一结论**；③ 它是路由表"该不该抢功／要不要出头"这类高频问题的正解所在。
