# 知识卡 25 · 无妄卦（天雷无妄）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："复则不妄矣，故受之以无妄。"——从最低点一阳来复、重新回到正道上（复卦 24），人就不会再虚妄妄为，所以接之以无妄。
> **本组四卦（25 无妄 → 26 大畜 → 27 颐 → 28 大过）在序卦传里是一条不断的链**："复则不妄矣，故受之以无妄。**有无妄，然后可畜**，故受之以大畜。**物畜然后可养**，故受之以颐。颐者，养也。**不养则不可动**，故受之以大过。"——**而大过之后紧接着就是本库已有的坎卦（"物不可以终过，故受之以坎"）。四卦合起来正好把"复 → 坎"之间的整段补上。**
> ⚠️ **本卦是全库唯一直接给"无辜受灾"命名的卦**：六三"**无妄之灾**"、九五"**无妄之疾**"。**《周易》在这里明确承认：有些灾祸与你的对错无关。**
> ⚠️ **本卦还是继乾卦之后第二个"元亨利贞"四德齐全的卦**，但它多挂了一个一票否决条款（见卦辞）。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 无妄 · 第二十五卦 |
| **卦象** | 上乾（天／健）下震（雷／动），称"天雷无妄"。**雷动于下、天健于上——动而合于天**。<br>按本库结构律逐项核对：**震在下 → 初九当位、六二当位、六三不当位**（底子是正的，动是从正道上发起的）；**乾在上 → 九五当位得中，九四、上九不当位**。<br>**全卦唯一的乘刚是六二**（震把阳放在最下往上顶，震在下则六二必乘刚）。<br>彖传"**刚自外来而为主于内**"——初九这个刚爻来做了内卦之主：**本卦的动力在最底下、在你自己身上，不是被外面推着动。** |
| **领域定义** | **动机的纯度，以及"不是你的错"的那一类事。**<br>① 你要做一件事，心里却夹带着一个不敢说出口的图谋（升职、报复、证明自己、顺便捞一笔）；<br>② 事情出了，你反复自查，确实找不到自己的错；<br>③ 你被别人的行为牵连——同事捅了篓子、合作方跑路、上游断供、家人惹了事，责任却落到你头上；<br>④ 出现了一个找不到原因、也没有恶化趋势的症状（团队情绪、指标波动、关系里一阵莫名的冷淡、舆情的一次无源头起伏），你正想"做点什么"；<br>⑤ 你想跳过必要的过程直接拿结果，或在心里已经把回报预支了；<br>⑥ 一件事已经做到没有新东西可做，你还想再推一把。<br>凡是"**我这么做到底图什么**"和"**这事凭什么是我倒霉**"，都落在无妄卦。 |
| **不归本卦的情况** | 已经陷在一串坏事里出不来、需要脱险方法 → **坎卦**（29，求小得、勿加深）；冲击刚砸下来那一刻、且有实际财物损失 → **震卦**（51，认赔、勿逐、七日得）；你有能力继续但决定停下 → **艮卦**（52）；在强势等级结构里求安全通行 → **履卦**（10）。<br>**无妄卦特指"动机是否纯正"与"灾是否与我有关"这两个判断本身，它不负责教你怎么脱险。** |
| **"无妄"二字本义** | **妄**＝虚妄、乱、不合实际的期待与不合正道的作为。**无妄＝不妄为、不妄求、不虚妄。**<br>它在本卦里有两层引申，**而本卦最独特的地方是这两层同时成立**：<br>① **主动层**——我的动作里没有夹带虚妄（初九、六二、九四、上九）；<br>② **被动层**——发生在我身上的事没有"妄"（原因）可归，即"无妄之灾""无妄之疾"（六三、九五）。<br>**换句话说：你可以完全无妄，而灾照样来。** |
| **卦辞原文** | 无妄：元亨，利贞。其匪正有眚，不利有攸往。 |
| **⚠️ 卦辞的关键结构** | **元、亨、利、贞四德齐全**——本库现有 18 卦里，只有**乾卦**（"元，亨，利，贞"）达到过这个密度；师卦只有"贞"，艮卦只有"无咎"，巽卦只给"小亨"，坎卦连"亨"都带前提（"维心亨"）。<br>**但无妄比乾卦多了一样东西：一个否定条款。**"其匪正有眚，不利有攸往"。<br>**结论：这是全书结构最锋利的一条卦辞——先把最高的许诺给足，再挂一个一票否决的条件。四德不是奖励，是"以正"的自动结果；一旦不正，四德当场作废，并且连"往"都不许。** |
| **卦辞现代解** | **元亨**——启动得开、通得开，力度是最高一档。<br>**利贞**——有益，且必须守正。<br>**其匪正有眚**——"匪"通非，"**眚**"是由行为带出来的过失之灾（与"灾"略有分工：眚偏由内／由行，灾偏由外）。**只要你不在正道上，就有眚。**<br>**不利有攸往**——此时不宜有所前往。<br>**合起来：动机纯正，则元亨利贞；动机一有夹带，四德立刻作废，而且不许你动。** |
| **彖传** | 无妄，刚自外来而为主于内，动而健，刚中而应，大亨以正，天之命也。其匪正有眚，不利有攸往，无妄之往何之矣？天命不佑，行矣哉？ |
| **彖传要点** | ① **刚自外来而为主于内**——初九那个刚爻来到内卦做主。**动力必须发自你内部**，被外面推着动的不算"无妄"。<br>② **动而健**——下震动、上乾健：**动了之后要撑得住**，不是一动就散。<br>③ **大亨以正，天之命也**——"元亨"的唯一条件是"以正"，**而这是天命，不是可以谈判的交易**。<br>④ **"无妄之往何之矣？天命不佑，行矣哉？"**——**连续两个反问**，是全书语气最重的彖传之一：不正而往，你能往到哪里去？天命都不帮你，还走什么？ |
| **大象传（行动纲领）** | 天下雷行，物与无妄。先王以茂对时育万物。 |
| **⚠️ 注意主语是"先王"，不是"君子"** | 六十四卦大象传绝大多数以"**君子**"为主语（乾"君子以自强不息"、艮"君子以思不出其位"、兑"君子以朋友讲习"）。**无妄用的是"先王"**（同类只有比、豫、观、噬嗑、涣等少数几卦）。<br>**这意味着无妄的行动纲领不在个人修养层面，而在"立制度、顺天时、养万物"的层面。** |
| **"茂对时育万物"解** | **茂**＝盛大、勉力；**对时**＝顺应天时、与时节相对；**育万物**＝养育万物。全句：**盛大地顺应时节去养育万物。**<br>**这是本卦最高层的原则，而它的形态出人意料：无妄的正面动作不是"管住自己不要乱来"，而是"把力气全部投到顺天时、养他人上"。**<br>**深意：一个人之所以会"妄"，通常是因为他的动作是为自己找结果。当动作的对象变成"对时育万物"（顺着规律去养别人），"妄"就没有落脚处了。** 这与六二"未富也"（不为求富而耕）是同一条道理的两个层级。 |
| **总铁律** | ① **动机一旦夹带，四德全部作废**（卦辞"其匪正有眚，不利有攸往"）；② **做事不预设收获，反而可行**（六二"不耕获…则利有攸往"，象传"未富也"）；③ **有些灾与你的对错无关**（六三"无妄之灾"）——**不要把它当成自己德行有亏的证据**；④ **有些问题不治自愈，而且药"不可试"**（九五）；⑤ **走到尽头就不要再行，动机纯正也不能救**（上九"行有眚，无攸利"，象传"穷之灾也"）。 |

## 二、爻级字段

### 初九 · 无妄，往吉

| 字段 | 内容 |
|---|---|
| **爻辞** | 无妄，往吉。 |
| **象传** | 无妄之往，得志也。 |
| **位属性** | 阳爻居阳位，**当位**；居下震之最下——**震动之始**，即彖传"刚自外来而为主于内"的那个刚爻，**是全卦动力之源**。 |
| **判词 → 行动语义** | **吉** → **动机不夹带，就直接往前**。 |
| **关键词解** | **无妄**＝没有虚妄（此处指动机、意图无夹带）。**往**＝前往、行动。象传"**得志也**"＝心志得以实现。 |
| **⚠️ 本爻是本库唯一"起步即可直接前往"的初爻** | 已有各卦的初爻都在加限定：**乾初九"潜龙勿用"**——要先潜；**震初九"震来虩虩"**——要先怕；**坎初六"入于坎窞，凶"**——不能往深；**艮初六"艮其趾"**——要在趾上止；**小畜初九"复自道"**——要先回到自己的道上；**师初六"师出以律"**——要先立纪律。<br>**只有无妄初九是"往吉"：不必潜、不必怕、不必止、不必先立什么。** 条件只有两个字：**无妄**。 |
| **识别信号** | ① 你要做的事刚起步；② 你能清楚说出你为什么做它，且这个理由不需要藏着；③ 你没有在这件事上给自己预留一个"顺便得到的好处"。 |
| **该做** | 直接开始。**把"我图什么"当成开工前唯一要过的那道关**——过了就走，不必再加别的准备动作。 |
| **不该做** | 给一个纯粹的动机再补上一个功利的理由（"顺便还能……"）。**在无妄卦里，"顺便"就是"妄"的入口。** |
| **⚠️ 与上九对照（本卦自带的"同辞异断"）** | **初九"无妄，往吉"／上九"无妄，行有眚，无攸利"。**<br>同样以"无妄"开头，同样是"往／行"，**一个吉、一个眚**。象传把差别写得更清楚：初九"**得志也**"，上九"**穷之灾也**"。<br>**差别只有时位：初九是发端，上九已穷。**<br>**结论：动机纯正是必要条件，不是充分条件——还要看你处在这件事的哪一段。**（本库第三组"同辞异断"教材，前两组是巽卦九二／上九"巽在床下"，颐卦六二／六四"颠颐"。） |

### 六二 · 不耕获（⚠️ 乘刚而不受损的第一例）

| 字段 | 内容 |
|---|---|
| **爻辞** | 不耕获，不菑畬，则利有攸往。 |
| **象传** | 不耕获，未富也。 |
| **位属性** | 阴爻居阴位，**当位且得中**；**乘于初九之上——乘刚**（震在下必然，见本库通则）。 |
| **判词 → 行动语义** | **利有攸往**（按本库口径：利＝可行·有益）→ **不预设收获地做本分事，就可以往**。 |
| **关键词解** | **菑**＝初开垦之田（开荒第一年的生田）；**畬**＝已耕熟之田。<br>本库取主流义理读法：**不为了收获而耕、不为了得熟田而开荒**——耕就是耕，做就是做，**不把结果预先绑在动作上**。象传"**未富也**"＝**本来就不是为了致富**。<br>⚠️ 另有一读将此句解为"不耕而获、不菑而畬"（即不劳而获），但与下句"则利有攸往"（判为可行）语义不合，**故本库取前读**。 |
| **⚠️ 本爻是本库"乘刚"规则下最重要的新例** | 本库已有三例"**震在下之六二**"，结构完全相同（阴爻当位、得中、乘于初九之上）：<br>**屯六二**——"女子贞不字，十年乃字"，象传"六二之难，**乘刚也**"；<br>**震六二**——"震来厉，亿丧贝"，象传"震来厉，**乘刚也**"；<br>**颐六二**——"颠颐，拂经，于丘颐，**征凶**"，象传"行失类也"（见 27 卡）。<br>**无妄六二结构与三者完全同构，却是四者中唯一没有受损的：判词是"利有攸往"。**<br>**差别只在象传那三个字："未富也"——它不求获，所以下面顶上来的那股刚劲没有东西可以从它手里夺走。**<br>**结论（可入库为通则）：乘刚的第三个破解方式＝不预设收获。**（前两个是艮六四"止诸躬"、巽六四"田获三品"。） |
| **识别信号** | ① 你在实际干活的枢纽位置上（得中），位置也正当；② 你下面／背后有一股强劲的力量在顶你、催你（乘刚）；③ 你已经开始在心里计算这件事能给你带来什么。 |
| **该做** | **把动作和结果解绑**——只对"这件事该怎么做对"负责，不对"我能从中得到什么"下注。这是无妄卦在执行层最实用的一条。 |
| **不该做** | 在乘刚的压力下去抢一个确定的收获。**屯六二被画饼、震六二丢财货，都是在"想要拿到"这件事上被咬的。** |

### 六三 · 无妄之灾（⚠️ 全库唯一直接命名"无辜受灾"的爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 无妄之灾，或系之牛，行人之得，邑人之灾。 |
| **象传** | 无妄之灾，行有眚也。　⚠️ **版本待核**（另有异文作"行人得牛，邑人灾也"；本库依主口径取前者） |
| **位属性** | 阴爻居阳位，**不当位**；**失中**；居下震之顶（本库通则"**三多凶**"）。 |
| **判词 → 行动语义** | **无吉凶判词，只陈述一个事实："灾"** → **把"这是不是我的错"与"这是不是我要处理的事"分开**。 |
| **关键词解** | **或**＝有人（不知何人）；**系之牛**＝把牛系在那里；**行人**＝过路的人；**得**＝把牛牵走了；**邑人**＝本邑的居民。<br>**全句：有人把牛系在那儿，过路人顺手把牛牵走了，结果是本地人挨了这个灾**（被怀疑、被追责、被索赔）。<br>**眚**＝由"行"带出来的过失之灾（与卦辞"其匪正有眚"同字，但来源相反：卦辞的眚出自你自己不正，本爻的眚出自别人的行）。 |

#### ⚠️ 专项：《周易》承认有些灾祸与你的对错无关

**1. 灾的两个当事人都不是你。**
系牛的是"**或**"（不知何人），牵牛的是"**行人**"（过路人）。**你的身份只有一个："邑人"——住在这儿的人。** 全书四百多条爻辞里，**这是唯一一条把"我什么都没做，灾却落在我头上"直接写成完整场景的爻**。

**2. 《周易》没有判你有咎，也没有判你凶。**
六三既没有"凶"，也没有"厉"，也没有"无咎"——**它只给了"灾"这一个字**，然后用象传补一句"**行有眚也**"：这个眚是由别人的"行"带出来的。
按本库判词口径，**这是需要单独记的一档：它不属于"元吉→凶"十级吉凶中的任何一级，而是一个事实声明。**《周易》在这里既不奖你也不罚你，**它只是承认这件事发生了，并且指出原因不在你身上。**

**3. 但结构解释了"为什么是你"。**
六三**不当位**（名分不足）、**失中**（没有定盘星）、**居下卦之顶**（最显眼的位置）。
**灾不是你造成的，但你的位置决定了你是承受者。**
**这是《周易》对"为什么倒霉的是我"给出的唯一结构性回答：不是因为你坏，是因为你站在一个名分不足却又很显眼的地方。**

| 字段 | 内容 |
|---|---|
| **识别信号（诊断清单）** | ① 出事了，你反复自查，确实找不到自己的错；② 直接责任人是别人（同事、合作方、上游、家人），甚至根本找不到人；③ 你的名分本来就有一样不足（资历／授权／归属／合同有一项模糊），而你恰恰是最显眼的那个；④ **你开始怀疑"是不是我人品有问题才总遇到这种事"**。 |
| **该做** | ① **先把两件事分开**——"这是我的错吗"（多数情况：不是）与"这是我要处理的事吗"（多数情况：是）；<br>② **把链条上的事实固定下来**——谁把牛系在那儿、谁牵走的。**澄清链条比自证清白有效得多**；<br>③ **把六三真正属于你的那部分补上**：名分不足是可以补的（把权责、归属、合同写清），**这是这一爻里唯一可以改善的变量**。 |
| **不该做** | **把无妄之灾当成自己德行有亏的证据。** 这是本爻最大的陷阱：一旦你接受"灾＝我错了"，你就会去做一个真正错误的补救动作——**那就直接掉进九五的"乱吃药"。** |
| **⚠️ 与震六二、坎初六的三角对照（本库对"灾"的分类）** | **坎初六**象传"**失道凶也**"——**凶的原因是失道，这确实是你的错**；<br>**震六二**象传"**乘刚也**"——**你没做错，但冲击来自你下面这个结构位置**；<br>**无妄六三**象传"**行有眚也**"——**你没做错，冲击也不来自结构，就是别人的行为溅到了你身上。**<br>**三爻合起来是一份完整的分类：失道之灾（改路）、乘刚之灾（认赔、上高地、勿逐）、无妄之灾（澄清链条、不自责）。**<br>**误判第一类为第三类，会让人不肯改路；误判第三类为第一类，会让人乱吃药。** |

### 九四 · 可贞

| 字段 | 内容 |
|---|---|
| **爻辞** | 可贞，无咎。 |
| **象传** | 可贞无咎，固有之也。 |
| **位属性** | 阳爻居阴位，**不当位**；已入上乾，紧邻九五尊位，本库通则"**四多惧**"。 |
| **判词 → 行动语义** | **无咎**（按本库口径：无灾，**不等于吉利**）→ **只守住已有的，不新增**。 |
| **关键词解** | **"可"字是限定词**——可以守持，言外之意是**只可守，不可进**。象传"**固有之也**"＝**固守其所本有**。 |
| **本爻的全部重量在那个"可"字** | 全卦只有这一爻用了"可"。**它没有说"贞吉"，只说"可贞，无咎"——守正在这里不带来好处，只带来"没有灾"。**<br>原因是位置：九四不当位、又紧贴尊位，**在这个位置上任何新增的动作都会被读成"妄"**。 |
| **识别信号** | ① 你已经进到接近核心的位置，但名分不完全正；② 你手上已经有一份东西（职责、资源、客户、成果）；③ 你正想在这个位置上再做一件"证明自己"的事。 |
| **该做** | **盘点已有，守住已有。** 把这一段的目标定成"不丢"，不要定成"再拿"。 |
| **不该做** | 在四位上开新战场。 |
| **四个"四爻"的对照（缩小作为范围的四种方式）** | **坤六四"括囊，无咎无誉"——闭口**；**艮六四"艮其身"象传"止诸躬也"——只管自己**；**无妄九四"可贞"象传"固有之也"——只守既有**。**三者都在多惧之位，给出的都是"缩小作为范围"。**<br>**唯一的例外是巽六四"田获三品"象传"有功也"——那是四位里唯一被要求交付成果的爻**，而它的前提是**当位**。**无妄九四不当位，所以只到"无咎"。** |

### 九五 · 无妄之疾（⚠️ 位置最好的一爻，却被告知什么都不要做）

| 字段 | 内容 |
|---|---|
| **爻辞** | 无妄之疾，勿药有喜。 |
| **象传** | 无妄之药，不可试也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位——**全卦位置最好的一爻**。 |
| **判词 → 行动语义** | **有喜**（正面陈述，但注意：不是"吉"）→ **不下药，等它自己好**。 |
| **关键词解** | **疾**＝病。**勿药**＝不要用药。**有喜**＝有可喜之事（病自愈）。象传"**不可试也**"＝**连试一次都不行**。 |

#### ⚠️ 专项："勿药有喜"——本库动作量级的最低点

**1. 为什么位置最好的人被告知什么都不要做？**
因为"无妄之疾"是**无因之疾**——它不是你做错什么招来的，所以**根本不存在一味"对症"的药**。
**给无因之病下药，药本身就成了新的"妄"**：你会因为"必须有所作为"的压力，而亲手制造一个真实的问题。

**2. 象传的力度是全书少见的。**
不是"少用药"、不是"慎用药"，是"**不可试也**"——《周易》极少下这种绝对禁令。
对照本库已有的两种"勿"：**乾初九"勿用"是蓄力型不动**（核心在潜）；**坎六三"勿用"是止损型停手**（象传"终无功也"）。
**无妄九五的"勿药"是第三种不动：不是蓄力，不是止损，是不干扰。**

**3. 与坎、震构成"不可控冲击"三卦组（本卦最实用的一条）**

| 卦 | 冲击性质 | 经文依据 | 动作量级 |
|---|---|---|---|
| **坎 29** | 持续消耗的困局，**你已在其中** | 卦辞"**行有尚**"、九二"**求小得**"、上六"三岁不得，凶" | **要动**——小步、持续；不动会固化成牢笼 |
| **震 51** | 一次性冲击，**已有实际损失** | 六二"**亿丧贝，跻于九陵，勿逐，七日得**" | **不追**——认赔、上高地、按住手，七日会回 |
| **无妄 25** | **无因之症状，且无恶化机制** | 九五"**无妄之疾，勿药有喜**"，象传"不可试也" | **零动作**——不治，不试药 |

> **三卦的动作量级依次递减到零。判别依据只有两条：能不能找到原因，以及有没有持续恶化的机制。**
> - 找得到原因、且在恶化 → **坎**（要动，求小得）
> - 找不到原因、但已有实际损失 → **震**（不追，等七日）
> - 找不到原因、也没有恶化 → **无妄**（不治，勿药）

**4. ⚠️ 适用边界（必须写清）**
这一爻的前提是"**无妄**"——**确认无因，且确认没有恶化机制**。
**若能找到原因，或情况正在持续变差，那就不是"无妄之疾"**，此时"勿药"是错的，该走的是坎九二"求小得"。
**"勿药有喜"绝不是"任何问题都不用管"的授权。**
另：本库定位为传统智慧决策参考框架，**此处"疾／药"是比喻，不涉及任何医疗判断或建议；身体上的问题请循医学途径处理。**

| 字段 | 内容 |
|---|---|
| **识别信号** | ① 出现了一个症状（团队情绪莫名低落、某项指标异常波动、关系里一阵说不清的冷淡、舆情的一次无源头起伏）；② 你和别人都找不到归因；③ **它没有在持续变差**；④ 你在拍板位置上，正感到"必须做点什么"的压力。 |
| **该做** | **设一个有期限的观察期，只做记录与观察。** 并且**把"什么都不做"当成一个正式宣布的决定**，而不是让别人以为你在拖延。 |
| **不该做** | 为了"有所作为"而改组、发文、加规则、开大会、逐个约谈。**这些全都是"药"，而象传说的是"不可试也"。** |
| **三个尊位的动作量对照** | **坎九五"坎不盈，祗既平，无咎"——水位一平就收手**；**震六五"亿无丧，有事"——只守住那件不能停的本职**；**无妄九五"勿药有喜"——连守都不必守，不动即可。**<br>**三个尊位的动作依次递减，无妄九五是本库动作量最小的尊位爻。** |

### 上九 · 行有眚

| 字段 | 内容 |
|---|---|
| **爻辞** | 无妄，行有眚，无攸利。 |
| **象传** | 无妄之行，穷之灾也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终。 |
| **判词 → 行动语义** | **无攸利**（没有任何有利之处）→ **此时不可行**。 |
| **关键词解** | **行有眚**＝有所行动就有灾。**无攸利**＝无所往而有利。象传"**穷之灾也**"＝**这是"穷"（走到尽头）带来的灾，不是"妄"带来的灾**。 |
| **⚠️ 本爻是卦辞警告的落地，但换了来源** | 卦辞说"**其匪正有眚**，不利有攸往"——**眚的原因是不正**。<br>**而上九爻辞的第一个词仍然是"无妄"**（动机依然干净），眚照样来，象传给的原因是"**穷**"。<br>**结论：动机纯正救不了你在尽头之后的行动。这是本卦对"无妄"两个字最重要的限定。** |
| **识别信号** | ① 这件事已经做到没有新东西可做了；② **你的动机依然干净，所以你觉得"再推一把应该没问题"**；③ 你找不到新的资源、新的对手、新的市场，只能重复过去做过的动作。 |
| **该做** | **停。** 把"我的动机是对的"和"这件事还有没有余地"当成两个独立问题分别判断。 |
| **不该做** | 拿动机纯正当继续的理由。 |
| **与乾上九、艮上九的三角对照** | **乾上九"亢龙有悔"——到顶而不知止，过刚则悔**；<br>**艮上九"敦艮，吉"——到顶而主动止到极处，知止则吉**；<br>**无妄上九"行有眚，无攸利"——到顶而动机仍然纯正，却依然不许行。**<br>**无妄上九补上了第三种情形：上爻的禁令不看你的品德，只看这件事还有没有余地。** |

**无妄卦三句话**：
1. **四德齐全，但挂了一票否决。** 卦辞给足"元亨利贞"，紧接着一句"其匪正有眚，不利有攸往"——**动机一有夹带，四德当场作废。**
2. **《周易》承认有些灾与你无关。** 六三"无妄之灾"——牛是别人系的、别人牵的，灾落在你头上；象传只说"行有眚也"，**没有判你有咎。不要把它当成自己德行有亏的证据。**
3. **有些问题不治自愈，而且药"不可试"。** 九五是全卦最尊最正的一爻，得到的指令却是"什么都不要做"——**因为无因之病没有对症的药，下药本身就是新的"妄"。**

**本卦最反直觉的两条**：
- **位置最好的九五，动作量最小（勿药）；位置最差的六三，反而是全卦唯一被明确免责的爻（不是你的错）。** 无妄卦把"位置好不好"和"该做多少"彻底脱钩了。
- **六二当位、得中、乘刚，与屯六二／震六二／颐六二结构完全相同，却是四者中唯一不受损的。** 差别只在象传三个字："**未富也**"——**它不求获，所以下面顶上来的刚劲没有东西可以从它手里夺走。**

## 四、⚠️ 本卡对全库的意义

### 1. 补齐本库对"灾"的分类学——而无妄一卦独供两类

本库此前只有两类"灾"的机制（失道、乘刚）。无妄卦一次补上两类，**分类至此闭合**：

| 灾的类型 | 出处 | 象传 | 是不是你的错 | 正确动作 |
|---|---|---|---|---|
| **失道之灾** | 坎初六"入于坎窞，凶" | **失道凶也** | **是**——路径错了 | 停止追加，承认前面全错，回到道上 |
| **乘刚之灾** | 震六二"亿丧贝" | **乘刚也** | **不是**——冲击来自你下面的结构位置 | 认赔、上高地、勿逐，等七日 |
| **无妄之灾** | **无妄六三** | **行有眚也** | **不是**——是别人的行为溅到你身上 | 澄清链条、补名分、**不自责** |
| **穷之灾** | **无妄上九"行有眚，无攸利"** | **穷之灾也** | **不是品德问题**——是这件事已经没有余地 | 停止行动，不拿动机纯正当理由 |

> **这张表可直接进索引，作为"我倒霉了，先分清是哪一种"的一级分诊。**
> **误判成本极高**：把失道之灾当无妄之灾，人就不肯改路（掉进坎初六）；把无妄之灾当失道之灾，人就会乱吃药（掉进九五被禁止的动作）。

### 2. "不可控冲击"三卦组：坎 → 震 → 无妄，动作量级递减到零

| 卦 | 结构 | 卦辞／关键爻 | 时间刻度 | 动作量级 |
|---|---|---|---|---|
| **坎 29** | 上坎下坎（重险） | "行有尚"、九二"求小得" | **三岁不得**（滞留会固化） | **持续小动** |
| **震 51** | 上震下震（洊雷） | 六二"勿逐，七日得" | **七日得**（短周期可回） | **按住不追** |
| **无妄 25** | 上乾下震 | 九五"勿药有喜"，象"不可试也" | **无刻度**（自愈） | **零动作** |

> **合读结论（可入索引跨卦衔接）：《周易》处理"不是你造成的坏事"，只有三档动作——小动、不追、不治。选错档位比选错方向更常见。**
> 判别只看两条：**① 找不找得到原因；② 有没有持续恶化的机制。**

### 3. 卦辞判词密度表：无妄是乾之外唯一四德齐全的卦，且唯一带否决条款

### 4. 结构增量：震在下之六二的第四例，以及"乘刚的第三个破解"

本库通则说"**震在下则六二必乘刚**"。四个实例现在齐了，**而它们的结局差异极大**：

| 卦 | 卦象 | 六二爻辞 | 象传 | 结局 |
|---|---|---|---|---|
| **屯 3** | 上坎下震 | 女子贞不字，**十年乃字** | 六二之难，**乘刚也** | 难，但十年后返常 |
| **震 51** | 上震下震 | **亿丧贝**，跻于九陵，勿逐 | 震来厉，**乘刚也** | **厉·大损** |
| **颐 27** | 上艮下震 | 颠颐，拂经，于丘颐，**征凶** | 行失类也 | **征凶** |
| **无妄 25** | 上乾下震 | 不耕获，不菑畬，**则利有攸往** | **未富也** | **利·唯一不受损** |

> **四爻位属性完全相同（阴居阴位、当位、得中、乘于初九之上），结局从"大损"到"可行"横跨四档。**
> **唯一的变量是"它想不想拿到东西"**：屯六二被求婚的画饼吸引、震六二丢的是财货、颐六二是去求养（求食于人），**只有无妄六二"未富也"——它压根不预设收获。**
> **可入库为通则：乘刚的第三个破解方式＝不预设收获。**
> （破解一：艮六四"止诸躬"，把范围收回到自己这一身；破解二：巽六四"田获三品"，交付可分配的实际成果；**破解三：无妄六二"未富也"，不把结果绑在动作上。** 三者的共同点是**都放弃了一样东西**：范围、姿态、预期。）
