# 知识卡 26 · 大畜卦（山天大畜）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："有无妄，然后可畜，故受之以大畜。"——先做到"无妄"（动机无虚妄），然后才蓄得住东西，所以接之以大畜。
> ⚠️ **本卡必须与小畜卦（9）合读**。两卦下卦同为乾（同一股刚健之力），**差别只在"谁来畜它"**：小畜是巽（风）以柔畜刚，大畜是艮（山）以止畜健。**这一条差别决定了两卦的全部结局**（详见第四节第 1 条，这是本卡最重要的内容）。
> ⚠️ **本卡还提供全库唯一一个"上爻得亨"的爻**：上九"何天之衢，亨"，象传"道大行也"。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 大畜 · 第二十六卦 |
| **卦象** | 上艮（山／止）下乾（天／健），称"山天大畜"。**大象传写作"天在山中"——整个天被装进山里**，这是六十四卦大象里最不可思议的一个意象。<br>按本库结构律逐项核对：**乾在下 → 初九当位、九二不当位（得中）、九三当位**；**艮在上 → 六四当位、六五不当位（得中）、上九不当位**。<br>**全卦唯一的乘刚是六四**（乘于九三之上）——**注意：这个乘刚不来自震**，而来自"下卦以阳终、上卦以阴始"的交界，是本库"乘刚来源"的一条结构增量（见第四节第 3 条）。<br>**上九是艮的那个阳爻（艮＝阴阴阳，阳在最上）——它就是全卦"止"的力量本身所在**，这解释了它为什么不当位却得"亨"。 |
| **领域定义** | **大规模的积累与涵养，以及"以止养健"。**<br>① 你有很强的实力与干劲，却被一个更大的结构压着不许发（组织流程、行业周期、上级、家庭责任、监管）；<br>② 你在为一件需要巨大储备的事做准备（"利涉大川"），而准备期长得看不到头；<br>③ 你在做系统性的知识与经验积累——读史、复盘、拜访前辈、建自己的方法论（大象传"多识前言往行"）；<br>④ 你在建组织的能力底座：人才储备、干部培养、"养贤"（卦辞"不家食"）；<br>⑤ 你要制服一股很难制的力量（一个强势的人、一条失控的业务、自己的某个欲望），正在考虑硬碰还是别的办法；<br>⑥ 你有本事，却只在养活自己和自己这一家（卦辞"不家食"正是针对这个）。<br>凡是"**我在攒，而且攒的是大东西**"，都落在大畜卦。 |
| **不归本卦的情况** | 力量本来就不足、只能小规模积累且蓄而不得发 → **小畜卦**（9，"密云不雨"，天花板就写在"小"字上）；完全没有根基、要从零扎根 → **屯卦**（3）；你有能力继续但决定不再继续 → **艮卦**（52，止是终点，不是为了后面发）；险还在前方、底子已刚健、只需等待时机 → **需卦**（5）。<br>**大畜卦特指"很大的力量（乾）被很大的约束（艮）蓄住，而且这个蓄是有用的、有出口的"。** |
| **"大畜"训解** | **畜**＝三义并存：**积蓄**（攒）、**畜养**（养）、**畜止**（约束）。**本卦三义全用**：初九、九二是"止"，九三是"养兵演练"，六四、六五是"止而养"，上九是"畜足而通"。<br>**"大"不是形容词，是结构结论**：彖传"**能止健，大正也**"——**被止住的对象是"健"（乾，天下最刚健的力量），所以能止住它的那个"止"必然与它同量级。** 对照小畜之"小"：巽卦辞本身只给"小亨"（见 57 卡），**畜者的量级决定了"畜"的量级。** |
| **卦辞原文** | 大畜：利贞。不家食，吉。利涉大川。 |
| **⚠️ 卦辞的关键结构** | **无元、无亨**——只有"利贞"，加两个具体许诺。<br>**而"亨"字被放到了上九**（"何天之衢，**亨**"）。**这是本库第一个"卦辞不给亨、末爻才给亨"的卦。**<br>**对照小畜：卦辞一上来就给"亨"，却在上九给"君子征凶"。**<br>**两卦的"亨"字位置正好相反——这就是"小"与"大"的全部差别：小畜的通路在开头（然后越走越窄），大畜的通路在结尾（所以前面必须忍）。** |
| **卦辞现代解** | **利贞**——有益，但必须守正。**注意它没有"元"（现在不许你启动）、没有"亨"（现在还不通）。**<br>**不家食，吉**——"家食"＝在家靠自己那点产出吃饭；"**不家食**"＝**不靠自家吃饭，而食禄于公**。彖传直接释为"**养贤也**"。<br>　　对个人：**有本事的人不该只养活自己和自己这一家，应当进入一个更大的平台，被供养，并承担与之相称的公共责任。**<br>　　对组织：**你要把有本事的人养起来（养贤）——这是"大畜"能够成立的前提条件。**<br>**利涉大川**——适宜渡大河，即**可以去做需要跨越重大险阻的大事**（与需卦卦辞同语，彖传"往有功也"）。<br>**⚠️ 注意语序：利贞（守正）→ 不家食吉（被供养、担公责）→ 利涉大川（做大事）。这是大畜的三级台阶，顺序不可跳。** |
| **彖传** | 大畜，刚健笃实辉光，其德刚上而尚贤。能止健，大正也。不家食吉，养贤也。利涉大川，应乎天也。 |
| **彖传要点** | ① **刚健笃实辉光**——下乾刚健、上艮笃实，两者相积才有"辉光"。**注意"笃实"两个字：艮（山）在本卦的性格不是"压制"，是"厚重可靠"。**<br>② **其德刚上而尚贤**——那个刚爻（上九）在最上面，而且崇尚贤者。这与卦辞"不家食（养贤）"是一回事。<br>③ **⚠️ "能止健，大正也"（全卦纲领）**——**能够止住"健"，这才是大的正道。** 这七个字是"大畜"之所以为"大"的全部理由。<br>④ **养贤也 / 应乎天也**——"不家食吉"之所以吉，实质是"养贤"；"利涉大川"之所以可行，是因为它"应乎天"（下卦本身就是乾＝天）。 |
| **大象传（行动纲领）** | 天在山中，大畜。君子以多识前言往行，以畜其德。 |
| **"天在山中"解** | **整座山把整个天蓄住了。** 这个意象与小畜的"**风行天上**"正好相反：**风在天上飘过，什么都留不住；山把天装进去了。** 同一个"畜"字，一个留不住，一个装得下。 |
| **⚠️ "多识前言往行，以畜其德"解（本卦最实用的一句）** | **多了解前人说过的话、做过的事，用它来积蓄自己的德。**<br>**这是全书对"如何积累"给出的唯一一条具体方法，而且它指定了材料：前言（前人的言论）与往行（过去的行事）。**<br>**深意：大畜要攒的不是资源、不是钱、不是人脉，是"识"——把别人已经付过学费的经验，变成自己的判断力。** 这是唯一一种可以在被约束期无限积累、且不受外部条件卡住的东西。<br>**对照小畜"懿文德"（修养美好的文采与德行）：小畜是打磨自己已有的，大畜是把别人的经验装进来。这就是"小"与"大"在方法上的差别。** |
| **总铁律** | ① **起步不可犯难，见险就止**（初九"有厉，利已"，象传"不犯灾也"）；② **走不动就主动卸车，绝不硬走**（九二"舆说輹"，象传"中无尤也"）；③ **约束要下在最早、最小、最不痛的地方**（六四"童牛之牿，元吉"）；④ **对付已经长成的强横力量，去它暴烈之根，不斗它的牙**（六五"豮豕之牙，元吉"）；⑤ **积累的材料是"前言往行"，不是资源**（大象传）；⑥ **蓄足则通——大畜的顶不是物极必反，是路开了**（上九"何天之衢，亨"，象传"道大行也"）。 |

## 二、爻级字段

### 初九 · 有厉，利已

| 字段 | 内容 |
|---|---|
| **爻辞** | 有厉，利已。 |
| **象传** | 有厉利已，不犯灾也。 |
| **位属性** | 阳爻居阳位，**当位**；居下乾之最下——刚健之始，力量最生猛，而距上面那座山最远。 |
| **判词 → 行动语义** | **厉**（按本库口径：**警告，非判死**）＋ **利已** → **见险就止，不要往上冲**。 |
| **关键词解** | **厉**＝危、告警。**已**＝停止（"利已"＝适宜停下来）。象传"**不犯灾也**"＝**不去触犯那个灾**。 |
| **本爻的分量** | 初九当位、纯阳之始、正是最有劲的时候，**爻辞第一句却是"有厉"**。原因很直接：**它上面顶着整座山——大畜的约束是全卦性的，从第一爻起就在。**<br>**"利已"是本卦成本最低的一个动作**：与艮初六"艮其趾"同构（止在最前端，代价近乎零）。**但有一个关键差别：艮初六不当位而象传判"未失正也"；大畜初九当位却仍要"已"——说明这里的止不是因为你不对，而是因为时候没到。** |
| **识别信号** | ① 你刚有劲、刚想动；② 前面明显有一个你现在处理不了的阻力（一个人、一道流程、一个周期）；③ 你在想"先冲一下试试"。 |
| **该做** | **停。** 把这段时间整体转到大象传的"多识前言往行"上去——**积累是这一爻唯一的正业。** |
| **不该做** | 试探性地冲一下。**象传只给了四个字"不犯灾也"——意思是：这个灾是可以完全避开的，前提是你别去碰它。** |
| **与乾初九、艮初六的三角对照** | **乾初九"潜龙勿用"——蓄力型不动，是为了后面动**；**艮初六"艮其趾，无咎，利永贞"——在零成本处止住，且要长期守住这个决定**；**大畜初九"有厉，利已"——见险即止，但这是暂时的**（因为全卦的走向是上九的"亨"）。<br>**三者的差别在"止多久"：乾是等时机，艮是永远，大畜是等蓄足。** |

### 九二 · 舆说輹（⚠️ 与小畜九三"舆说辐"的同象异断）

| 字段 | 内容 |
|---|---|
| **爻辞** | 舆说輹。　⚠️ **版本待核**（"輹"字或作"輻/辐"；通行本大畜九二作"輹"、小畜九三作"辐"，两处应分开记） |
| **象传** | 舆说輹，中无尤也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**——下乾之中，是实际干活的枢纽。 |
| **判词 → 行动语义** | **无吉凶判词，象传给"无尤"** → **主动把车卸下来，不硬走**。 |
| **关键词解** | **舆**＝车厢；**说**通"脱"；**輹**＝车轴上缚住车厢的伏兔（车与轴的连接件）。**舆说輹＝车厢与车轴脱开了，车走不动了。**<br>**尤**＝过失、可责之处。象传"**中无尤也**"＝**因为得中，所以没有过失。** |

#### ⚠️ 专项：与小畜九三的同象异断（本卦最有价值的一条跨卦对照）

| 对照项 | **小畜 9 · 九三** | **大畜 26 · 九二** |
|---|---|---|
| 爻辞 | **舆说辐**，夫妻反目 | **舆说輹** |
| 卦象 | 上巽下乾（以柔畜刚） | 上艮下乾（以止畜健） |
| 位属性 | 阳居阳位，**当位**，居下卦之顶 | 阳居阴位，**不当位**，但**得中** |
| 象传 | **不能正室也**（连内部关系都摆不平） | **中无尤也**（没有过失） |
| 车为什么坏 | **被六四顶坏的**——硬冲畜止者，撞得最狠 | **自己卸下来的**——走不动就不走 |
| 结果 | **崩盘**（车毁、班子裂、夫妻反目） | **无尤** |

> **结论：同一个"车坏了"的意象，一个是被撞坏的，一个是主动卸下的。**
> **《周易》评价的不是"车能不能走"，是"车为什么停"。**
> 小畜九三当位、刚健、最不甘心被压，所以硬顶，结果"不能正室"；**大畜九二不当位，但它得中——得中让它有资格说"这一段路我不走了"，所以"无尤"。**
> **这也是本库通则"⚠️ 得中可救不当位"在大畜卦的实例。**

| 字段 | 内容 |
|---|---|
| **识别信号** | ① 你在实际干活的枢纽位置上（得中）；② 你已经明显推不动了（资源不到、审批不下、人心不齐）；③ 周围在等你表态"到底还走不走"。 |
| **该做** | **主动、公开地把车卸下来**——宣布这一段停下，说清停的理由与恢复的条件。**"主动"三个字是"无尤"的全部来源。** |
| **不该做** | 拖着不停（把"走不动"熬成"车毁"）；或者硬顶——**那就直接变成小畜九三。** |

### 九三 · 良马逐

| 字段 | 内容 |
|---|---|
| **爻辞** | 良马逐，利艰贞。曰闲舆卫，利有攸往。　⚠️ **版本待核**（"曰"字一作"日"，读作"日日演练舆卫"，义相通） |
| **象传** | 利有攸往，上合志也。 |
| **位属性** | 阳爻居阳位，**当位**；居下乾之顶（本库通则"**三多凶**"）；**下乾三阳至此并进**。 |
| **判词 → 行动语义** | **利艰贞 ＋ 利有攸往** → **可以动了，但只能以"艰贞＋预先演练"的方式动**。 |
| **关键词解** | **良马逐**＝好马奔驰追逐——三阳并进之象。**利艰贞**＝适宜在艰难中守正（**"艰"字是限定：这条路本来就是难的**）。**闲**＝闲习、演练；**舆卫**＝车马与护卫。**闲舆卫**＝**反复演练车马与防卫**。 |
| **⚠️ 本爻是全卦第一个"可以动"的爻，而它把动的条件写全了** | ① **利艰贞**——先接受"这一段是艰难的"，并在艰难里守正；<br>② **闲舆卫**——**在出发之前把车马与护卫演练好**，不是等路上出事再学；<br>③ 然后才是"**利有攸往**"。<br>**顺序是：艰贞 → 演练 → 才可以往。**<br>**这与师初六"师出以律，否臧凶"、巽九五"先庚三日，后庚三日"是同一条纪律：真正的准备动作发生在开始之前。** |
| **⚠️ 象传"上合志也"——与小畜六四同文（本库第二处）** | **小畜六四"血去惕出，无咎"，象传"上合志也"**——那是一个**柔爻**，靠与九五合志才免灾，**合法性来自上面**。<br>**大畜九三"利有攸往"，象传也是"上合志也"**——但这是一个**刚爻**，它与上九（艮之阳、全卦所"尚"的那个贤）志同。<br>**结论：同一句"上合志也"，柔爻用它换生存，刚爻用它换通行权。**<br>**判别问题：你向上合志，是为了获得庇护，还是为了获得方向？** |
| **识别信号** | ① 你和同侧的人进入了齐头并进的状态（良马逐）；② 路是通的，但明显是难的；③ 你在考虑"边走边补"。 |
| **该做** | 先接受"艰"，把守正当成前提；**出发前把"舆卫"（后勤、风控、备份方案、护卫人员）演练到位**；确认你与上面的方向一致（上合志）。 |
| **不该做** | 把"良马逐"当成"路好走"。**三多凶之位上唯一的保险就是"艰贞"两个字。** |

### 六四 · 童牛之牿（⚠️ 元吉，且是"乘刚"的第四个破解）

| 字段 | 内容 |
|---|---|
| **爻辞** | 童牛之牿，元吉。 |
| **象传** | 六四元吉，有喜也。 |
| **位属性** | 阴爻居阴位，**当位**；**乘于九三之上——乘刚**；已入上艮，本库通则"**四多惧**"。 |
| **判词 → 行动语义** | **元吉**（本库吉凶序最高一档）→ **在最早、最小、最不痛的地方下约束**。 |
| **关键词解** | **童牛**＝小牛，**角还没长成**。**牿**＝绑在牛角上的横木，防它顶人。**童牛之牿＝趁小牛角还没长出来，就先给它上了横木。** |
| **⚠️ 本爻是本库第一个"元吉"级别的乘刚爻** | 按本库判词表，**元吉＝成·根本性圆满，且"通常带附加条件，必须指出条件是什么"**。<br>**六四的条件就写在"童"字上：约束的时机必须早到"角还没长出来"。**<br>本库已有两例乘刚破解，**都只到"无咎／悔亡"级**：<br>　**艮六四"艮其身"象传"止诸躬也"**——当位·乘刚·**无咎**（把范围收回到自己这一身）；<br>　**巽六四"悔亡，田获三品"象传"有功也"**——当位·乘刚·**悔亡·有功**（交付可分配的实际成果）。<br>**大畜六四同样当位、同样乘刚（下面顶着九三那匹"良马"），却直接到"元吉"。**<br>**差别：艮六四是收缩自己，巽六四是交付成果，大畜六四是抢在事情长大之前就把它约束住。**<br>**结论（可入库为通则）：乘刚的第四个破解方式＝在那股力量还小的时候就给它加约束（"童"）。这是四种破解里唯一能到"元吉"的。** |
| **识别信号** | ① 你在中层（多惧之位），下面顶着一股正在变强的力量——一个能干但难管的人、一条正在膨胀的业务、自己的一个欲望；② **它现在还小、还好管**；③ 你在想"等它真出问题再说"。 |
| **该做** | **现在就上"牿"——趁小、趁没长角、趁代价还接近于零。** 具体形态：先把边界写清、先定上限、先约定退出机制、先把话说明白。 |
| **不该做** | 等它长大再管。**对照艮九三"艮其限，列其夤，厉"——拖到"腰"上再止，就要撕裂脊背。"童牛之牿"是同一条道理的正面版本：止的代价与止的时机成反比。** |
| **与小畜六四的对照** | **小畜六四也是那个唯一的柔爻、也当位、也判"无咎"，但它的凭仗是象传"上合志也"（靠九五的支持）**；**大畜六四靠的是"时机"（童）。**<br>**一个靠关系，一个靠早——所以一个"无咎"，一个"元吉"。** |

### 六五 · 豮豕之牙（卦主，⚠️ 第二个元吉）

| 字段 | 内容 |
|---|---|
| **爻辞** | 豮豕之牙，元吉。 |
| **象传** | 六五元吉，有庆也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位——全卦卦主。 |
| **判词 → 行动语义** | **元吉** → **不去斗它的牙，去掉它暴烈的根**。 |
| **关键词解** | **豮**（fén）＝阉过的猪；**豕**＝猪（此处指野猪之类）；**牙**＝獠牙。**豮豕之牙＝已经去势的豕的獠牙——牙还在，但那股暴烈的劲没有了。** |
| **⚠️ 本爻是全卦最高明的一条方法（居尊者的专门指令）** | **野猪最危险的是牙，但去锯它的牙是没用的**——它会拼命，而且牙会长回来。<br>爻辞给出的方案是那个"**豮**"字：**去掉给它提供暴烈的那个源头。**<br>**结论：制服一股强横的力量，不要在它最锋利的地方与它硬碰；要找到给它供能的那个根，把根处理掉。牙可以留着。**<br>**这也是六五唯一可行的路子**：它是阴柔之才、**不当位**，**根本没有力量去斗牙**；但它**得中居尊**，**有资格去处理"根"。** |
| **⚠️ 六四 → 六五 是本卦最重要的一组递进** | \|　\| **六四 童牛之牿** \| **六五 豮豕之牙** \|<br>\| 对象 \| **还小的**（童牛，角未成） \| **已经长成的**（豕，牙已在） \|<br>\| 手段 \| **加约束**（牿，从外面拦住） \| **去根源**（豮，从里面卸掉） \|<br>\| 位属性 \| 当位·乘刚·四多惧 \| 不当位·**得中居尊** \|<br>\| 象传 \| **有喜也** \| **有庆也** \|<br>\| 判词 \| **元吉** \| **元吉** \|<br>**两爻都是元吉，但对象与手段完全不同：能趁早就"牿"（六四），错过了就只能"豮"（六五）。**<br>**象传两个词也有分工：喜是自家之喜（一件事管住了），庆是及众之庆（整个局面安了）。** 按本库口径，**"有庆"的覆盖面大于"有喜"**——对照履上九"元吉在上，**大有庆也**"、颐上九"由颐厉吉，**大有庆也**"。 |
| **识别信号** | ① 你在拍板位置上；② 有一股力量已经长成了，硬碰你碰不过（一个强势的人、一块已经做大的业务、一种已成风气的行为）；③ 你正在考虑硬性处置（换人、砍业务、发禁令）。 |
| **该做** | **找"豮"的位置**——那股暴烈是靠什么供养的？（利益结构、考核指标、信息垄断、某个人的背书、某条路径依赖。）**处理供养，不处理獠牙。** |
| **不该做** | 正面锯牙。**这与兑九四"介疾有喜"（只隔断病处，不动整片和气）、离上九"获匪其丑"（只斩首恶、不牵连从众）是同一路方法：切口要小而准。** |
| **本库"六五／九五"专题的第六例** | 已有五例：**乾九五**（居尊而求贤）、**坤六五**（有君之权而守臣节）、**蒙六五**（居尊而不失赤子之心）、**离六五**（居尊而痛哭）、**艮六五**（居尊而闭嘴）。**大畜六五补上第六种：居尊而不硬碰。**<br>**六者完全同构——居尊位者必须主动放弃一样特权**：乾放弃独断，坤放弃权柄，蒙放弃架子，离放弃坚强，艮放弃说话的自由，**大畜放弃正面较量。** |

### 上九 · 何天之衢（⚠️ 全库唯一"上爻得亨"的爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 何天之衢，亨。 |
| **象传** | 何天之衢，道大行也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终；**是艮的那个阳爻**（艮＝阴阴阳，阳在最上）——**它就是全卦"止"的力量本身所在**。 |
| **判词 → 行动语义** | **亨** → **蓄足了，路开了；此时才是"往"的时候**。 |
| **关键词解** | **衢**＝四通八达的大路。**何**：一说通"荷"（承担、负荷），一说为感叹词。**两读皆通且互补**——"**荷**天之衢"＝承担起天之大道；"**何**天之衢"＝何等宽阔的天之大路。<br>象传"**道大行也**"＝**道得以大大地施行**。 |

#### ⚠️ 专项：本卦对本库"上爻"通则的最大修正

本库通则（索引第五节）：**"上＝物极必反"，而反的是"不知止的极"——过刚则悔，过柔则凶，知止则吉，无内容则白过。**
**大畜上九补上了第五种，也是唯一一种"正向突破"：蓄足则通。**

| 卦 | 上爻 | 爻辞 | 判词 | 机制 |
|---|---|---|---|---|
| 乾 1 | 上九 | 亢龙有悔 | **悔** | 过刚不知止 |
| 坤 2 | 上六 | 龙战于野，其血玄黄 | **凶** | 盈极不知止 |
| 巽 57 | 上九 | 巽在床下，丧其资斧 | **贞凶** | 过柔而丧决断 |
| 兑 58 | 上六 | 引兑 | **无判词·未光** | 没有新内容，白过 |
| **小畜 9** | 上九 | 既雨既处…**君子征凶** | **凶** | **蓄满即动，逆势** |
| 艮 52 | 上九 | 敦艮 | **吉** | 主动止到极处，以厚终 |
| 履 10 | 上九 | 视履考祥，其旋 | **元吉** | 复盘后进入循环 |
| **大畜 26** | 上九 | **何天之衢** | **亨·道大行也** | **⚠️ 蓄足则通——路本身打开了** |

> **⚠️ 这是全库唯一一个"上爻得亨"的爻。** 艮上九的"吉"是把"止"这件事做圆满了；履上九的"元吉"是靠"旋"（循环）避开了"穷"；**只有大畜上九给的是"亨"——一个卦辞级别的判词，出现在最后一爻。**
> **合读结论：上爻不必然是终点。当一整卦的德就是"积累"时，走到最后是路开了，而不是路尽了。**

**⚠️ 结构解释：为什么好事落在这个上九？**
上九是**艮的那个阳爻**。按本库结构律"**艮在上 → 四当位、五上不当**"，**这个上九必然不当位**。**但本库现有的"艮在上"诸卦，上爻全部善终**：

| 卦 | 卦象 | 上爻爻辞 | 结果 |
|---|---|---|---|
| **艮 52** | 上艮下艮 | 敦艮 | **吉**（以厚终也） |
| **蒙 4** | 上艮下坎 | 击蒙，不利为寇，利御寇 | 有条件可行（非凶） |
| **大畜 26** | 上艮下乾 | 何天之衢 | **亨**（道大行也） |
| **颐 27** | 上艮下震 | 由颐，厉吉，利涉大川 | **厉吉**（大有庆也） |

> **可入库为通则：艮在上的上爻虽必然不当位，却是全书最安全的上爻位置。** 因为**它本身就是"止"的力量所在——到顶而知止，所以不受"物极必反"的处罚。**
> 这与艮卡的结论完全一致：**"上爻之凶从不来自到顶本身，只来自到顶而不知止。"** 大畜上九把它推进了一步：**不但不受罚，还能得"亨"。**

| 字段 | 内容 |
|---|---|
| **识别信号** | ① 你已经积累了很长时间，而且积累的是"识"（判断力）而不只是资源；② 之前压着你的那个约束松了，或者你已经不再需要绕开它；③ **你开始看到的不是一条路，而是很多条路（衢）。** |
| **该做** | **往。** 此时才是卦辞"利涉大川"真正兑现的时候。**并且要"荷"起来**——象传说的是"道大行也"，**这条路是给"道"走的，不是给你个人走的。** |
| **不该做** | 把上九当成"终于可以为自己收割了"。**"何天之衢"的两种读法都不指向个人收益：一是承担天道，二是感叹路之宽。** 一旦读成收割，就掉回小畜上九的"君子征凶"。 |

## 三、大畜卦定位速查表

| 爻 | 角色 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | 蓄之始 | 有厉，利已 | 刚有劲想动，前面有处理不了的阻力 | **当位**·乾之始 | **厉**·**利已**·不犯灾 |

**大畜卦三句话**：
1. **"能止健，大正也"**（彖传）——**这一卦之所以叫"大"，是因为它止住的对象是"健"（天下最刚健的力量），所以那个"止"必然同量级。** 与小畜之"小"（巽只给"小亨"）的差别就在这里。
2. **积累的材料是"前言往行"，不是资源**（大象传"多识前言往行，以畜其德"）。**这是被约束期唯一不受外部条件卡住的积累。**
3. **约束要下得早**：趁小就"牿"（六四元吉），错过了只能"豮"（六五元吉）——**两个元吉，都不在"硬碰"这条路上。**

**本卦最反直觉的两条**：
- **卦辞不给"亨"，"亨"字在最后一爻**（上九"何天之衢，亨"）。**而小畜正好相反：卦辞给"亨"，上九却"君子征凶"。** **同一个"畜"字，通路一个在开头、一个在结尾——这就是"小"与"大"的全部差别。**
- **六四当位而乘刚，本该受损，却是本库第一个"元吉"级的乘刚爻。** 破解不是收缩（艮六四）、不是交付成果（巽六四），而是**"童"——抢在那股力量长大之前**。

## 四、⚠️ 本卡对全库的意义

### 1. ⚠️ 大畜 ↔ 小畜：本库"畜"字的完整解（本卡最重要的一条）

| 对照项 | **小畜 9（风天小畜）** | **大畜 26（山天大畜）** |
|---|---|---|
| 卦象 | 上**巽**下乾 | 上**艮**下乾 |
| 下卦（被畜者） | **乾（健）** | **乾（健）**——完全相同 |
| 畜者是谁 | **巽（风）**：一阴（六四）畜五阳 | **艮（山）**：以整座山止住天 |
| 畜者本身的天花板 | **巽卦辞只给"小亨"**（57 卡已证：彖传"柔皆顺乎刚，是以小亨"） | **艮＝止**；彖传"**能止健，大正也**"——止得住"健"的力量必与健同量级 |
| 意象 | **风行天上**（风飘过天，什么都留不住） | **天在山中**（整个天被装进山里） |
| 卦辞 | **亨**。密云不雨，自我西郊 | 利贞。不家食，吉。**利涉大川** |
| **"亨"在哪里** | **在卦辞**——一上来就通 | **在上九**——最后一爻才通 |
| 卦辞的意象判断 | **密云不雨——现在成不了事** | **利涉大川——可以去做跨越重大险阻的大事** |
| 积累的方法 | **懿文德**（打磨自己已有的文采德行） | **多识前言往行**（把前人的经验装进来） |
| 元吉 | **无** | **两个**（六四"有喜"、六五"有庆"） |
| 关键柔爻的凭仗 | 六四"血去惕出"，象传"**上合志也**"——**合法性来自上级支持** | 六四"童牛之牿"，元吉——**凭仗是"时机（童）"** |
| 上爻 | 上九"既雨既处…**君子征凶**"（象传"德积载也"＋"有所疑也"） | 上九"何天之衢，**亨**"（象传"**道大行也**"） |
| 全卦走向 | **先通后凶**：卦辞给亨，蓄满反而征凶 | **先不通后大通**：卦辞不给亨，蓄足则道大行 |

> **⚠️ 结论一（机制）：两卦下卦完全相同——同一股刚健之力；差别只在"谁来畜它"。**
> **小畜用"柔"去畜**——以一阴压五阳，靠"上合志也"才勉强无咎，九三一硬顶就"舆说辐、夫妻反目"，所以只能"密云不雨"，而且**蓄满之时最凶**（"月几望，君子征凶"）。
> **大畜用"止"去畜**——艮是山，"止"是与刚健同量级的德（彖传"能止健，大正也"），所以能"利涉大川"，而且**蓄足之时路反而开了**（"何天之衢，亨"）。
> **一句话记住：以柔畜刚只能密云不雨；以止畜健才能利涉大川。**

> **⚠️ 结论二（可直接入索引的判别法）：两卦"亨"字位置的对照，是全库最干净的一个结构证明。**
> **"小"与"大"不是程度差别，是机制差别**：
> - **小畜的通路在开头**（卦辞就给亨），所以后面越走越窄，蓄满即凶——**它的"畜"是被动的、不牢固的约束**；
> - **大畜的通路在结尾**（卦辞不给亨），所以前面必须忍，蓄足则通——**它的"畜"是主动的、有出口的积累**。
> **用户自查一句话：你现在的"攒"，是攒到最后能开路（大畜），还是攒到最后只能忍着不动（小畜）？** 判别依据就是**畜者的量级**：压住你的那个东西，是一阵风，还是一座山？

### 2. 上爻通则的第五档："蓄足则通"，以及"艮在上的上爻最安全"

- **第五档已补入**（详见上九专项表）：**过刚则悔（乾）｜过柔则凶（巽）｜知止则吉（艮）｜无内容则白过（兑）｜蓄满即动则凶（小畜）｜复盘入循环则元吉（履）｜⚠️ 蓄足则通（大畜）。**
- **新通则建议**：**艮在上的上爻虽必然不当位，却是全书最安全的上爻位置**（艮 52 吉、蒙 4 有条件可行、大畜 26 亨、颐 27 厉吉大有庆）。**机制：艮的阳爻在最上，它本身就是"止"的力量，所以"到顶"对它不构成"不知止"。**

### 3. "乘刚"的两条结构增量

**增量一：乘刚的第四个破解方式**

| 破解 | 出处 | 位属性 | 动作 | 判词 |
|---|---|---|---|---|
| ① 缩范围 | **艮六四"止诸躬也"** | 当位·乘刚 | 只管自己这一身 | **无咎** |
| ② 出成果 | **巽六四"田获三品"·有功也** | 当位·乘刚 | 交付可分配的实绩 | **悔亡** |
| ③ 不求获 | **无妄六二"未富也"** | 当位·得中·乘刚 | 不把结果绑在动作上 | **利有攸往** |
| ④ **趁小止** | **大畜六四"童牛之牿"** | 当位·乘刚·四多惧 | **在它还小时就加约束** | **⚠️ 元吉** |

> **四者的共同点：都放弃了一样东西**——范围、姿态、预期、时间上的从容。**而"趁小止"是唯一能到"元吉"的，因为它是四者中唯一在压力形成之前动手的。**
> **反例仍是震六二"亿丧贝"**（当位·得中·乘刚而大损）——**它既没缩范围、也没出成果、也在求获，还等到冲击砸下来才动。**

**增量二：乘刚还有第二个来源——上下卦交界的"阳终阴始"**

本库通则说"**乘刚的来源＝震**（震把阳放在最下往上顶）"，并说"**艮内部不制造乘刚**"。**这两句都对，但不完整**：
- **大畜没有震**，六四却乘刚——因为**下卦乾以阳爻收尾（九三），上卦艮以阴爻开头（六四）**。
- 同理，**艮六四乘九三、巽六四乘九三**，都产生在上下卦交界处。
> **修正后的完整口径：乘刚＝任何阴爻直接压在阳爻之上。它有两个来源——① 三画卦内部（震：阳在最下；兑：阴在最上压阳；坎、离：阴压阳），② 上下卦交界（下卦以阳终、上卦以阴始）。**
> **巽（阴在最下）与艮（阳在最上）是唯一两个内部不制造乘刚的非纯阴之卦**——这一条原判断成立，只需补上"但它们仍可能在交界处产生乘刚"。

### 4. 大畜与本库现有卦的三条衔接

| 衔接 | 机制 |
|---|---|
| **大畜 ↔ 小畜 9** | **同下卦、异上卦，"亨"字位置相反**——本库"小／大"之别的结构原型（见第 1 条） |
| **大畜 ↔ 艮 52** | **艮卡说"止"是终点（敦艮，以厚终）；大畜说"止"是手段（能止健，然后何天之衢）。** 同一个艮，一个止到不再动，一个止到能大动。**判别：你的"止"有没有出口。** |
| **大畜 ↔ 需 5** | **两卦卦辞都有"利涉大川"。需卦是"险在前方、底子刚健，所以等"（彖传"往有功也"）；大畜是"约束在上方、底子刚健，所以攒"。** **同样的"利涉大川"，需卦靠"待时"兑现，大畜靠"畜德"兑现。** 合起来是本库对"大事之前该干什么"的完整答案：**该等的等（需），该攒的攒（大畜），而攒的材料是"前言往行"。** |
