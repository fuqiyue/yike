# 知识卡 27 · 颐卦（山雷颐）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："物畜然后可养，故受之以颐。颐者，养也。"——东西积蓄起来了（大畜 26），然后才谈得上"养"，所以接之以颐。
> ⚠️ **本卦是全库"养"的专卦**，六爻走的是一条完整路径：**被养 → 自养 → 养人**。
> ⚠️ **本卡提供本库第二组"同辞异断"教材**：**六二与六四爻辞都以"颠颐"开头，一个"征凶"，一个"吉"。**（第一组是巽卦九二／上九"巽在床下"。）
> ⚠️ **本卡还提供本库最长的时间刻度**：六三"**十年勿用**"（象传"道大悖也"）。

---

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 颐 · 第二十七卦 |
| **卦象** | 上艮（山／止）下震（雷／动），称"山雷颐"。**山下有雷**——雷动于下、山止于上。<br>**六爻之形正是一张口**：初九、上九两阳如上下唇齿，中间四阴如口中之空——**这就是"颐"（下巴／口腔）的取象**，全书取"人身器官"为象最直白的一卦（另一处是艮卦的趾腓限身辅）。<br>按本库结构律逐项核对：**震在下 → 初九当位、六二当位、六三不当位**；**艮在上 → 六四当位、六五不当位（得中）、上九不当位**。<br>**全卦唯一的乘刚是六二**（乘于初九之上，震在下必然）。<br>**⚠️ 结构含义：下三爻属震（动而求食，是"求养者"）；上三爻属艮（止而在上，是"养人者"）。** 彖传"**观其所养**／**观其自养**"这两句，正是对这上下两半的分工描述。 |
| **领域定义** | **谁养谁：供养关系、生计来源、以及"养"的三个层次（养身、养德、养人）。**<br>① 你靠什么吃饭——靠自己的本事，还是靠一个平台／一个人／一份关系；<br>② 你正在考虑要不要去求人（求资源、求机会、求收留），或者已经在求；<br>③ 你带团队、带孩子、带学生——你是那个"养人"的人；<br>④ 你在做身心的调养：作息、饮食、情绪、体力的恢复（大象传"节饮食"）；<br>⑤ 你在积累德行与见识，但还没到可以给别人的程度（"自养"阶段）；<br>⑥ 你手里有一份本事没在用，同时盯着别人碗里的东西（初九"舍尔灵龟，观我朵颐"）；<br>⑦ 家庭赡养、代际供养、"谁该养谁"的分歧。<br>凡是"**这一口饭从哪来 / 该给谁**"，都落在颐卦。 |
| **不归本卦的情况** | 还在攒、还没到分配使用的阶段 → **大畜卦**（26，"畜"是攒，"颐"是养）；是在选择依附谁、跟谁站在一起 → **比卦**（8，"原筮，元永贞"，重点在择主与时间窗口）；是被压住不许动、要不要停 → **艮卦**（52）；是要不要切断一段正在消耗你的供养 → **兑九五"孚于剥，有厉"＋兑九四"介疾"**。<br>**颐卦特指"养"这个动作本身：谁在养、养得正不正、以及你处在被养还是养人的哪一段。** |
| **"颐"字本义** | **颐**＝下巴、面颊，引申为**口腔与咀嚼**，再引申为**养**（口是取食之处，故"颐"＝养）。<br>本卦"养"字含三层，**由浅入深**：**养身**（饮食、体力）→ **养德**（见识、品性）→ **养人**（供养、培育他人）。<br>**⚠️ 注意"颐"不是"吃"，是"咀嚼与消化"**——它强调的是**把外来的东西转成自己的东西**这个过程。这解释了为什么初九"观我朵颐"（看着别人嚼）是凶：**看别人咀嚼，你自己一口没进。** |
| **卦辞原文** | 颐：贞吉。观颐，自求口实。 |
| **⚠️ 卦辞的关键结构** | **无元、无亨、无利，只有"贞吉"。**<br>比师卦（只有"贞"）多了一个"吉"，比艮卦（只有"无咎"）好一档，但**依然是全书最吝啬的一类卦辞**。<br>**彖传直接把它释死了："颐，贞吉，养正则吉也。"——"养"这件事，天道只认一个条件：正。**<br>**养对了就吉，养错了就"贞凶"（六三）、"征凶"（六二）。这一卦不给你任何额外许诺，只给一个开关：正不正。** |
| **卦辞现代解** | **贞吉**——守正则吉；**言外之意：不正则不吉，而本卦的"不正"有专名，叫"拂经"（违背常道）与"颠颐"（颠倒地求养）。**<br>**观颐**——观察"养"：**看别人是怎么养的、看这份供养从哪来、看这个供养关系正不正。** 彖传释为"**观其所养也**"。<br>**自求口实**（全卦最重要的四个字）——"口实"＝口中之食。**自己去求得口中的食物。** 彖传释为"**观其自养也**"。<br>**⚠️ 卦辞把两个动作并列摆出来：观颐（看别人怎么养）＋自求口实（自己动手挣）。而全卦六爻的吉凶，基本就是按这两个动作的比例排出来的**——只"观"不"自求"的是初九（凶），只"自求"而求错方向的是六二六三（征凶／贞凶），既能自养又能养人的是上九（厉吉·大有庆）。 |
| **彖传** | 颐，贞吉，养正则吉也。观颐，观其所养也；自求口实，观其自养也。天地养万物，圣人养贤以及万民，颐之时大矣哉！ |
| **彖传要点** | ① **"养正则吉也"**——**全卦唯一的条件句**。不是"养则吉"，是"养**正**则吉"。<br>② **"观其所养也"／"观其自养也"**——把卦辞两句分别对应到**他养**与**自养**两个维度。**这是本卦的诊断坐标：先问"是谁在养我"，再问"我自己能养自己多少"。**<br>③ **"天地养万物，圣人养贤以及万民"**——**养的最高形态是链式的：养贤，然后由贤去养万民。** 这一句与大畜卦辞"不家食吉"（彖传"养贤也"）直接接续，**两卦在"养贤"这一点上是同一条线。**<br>④ **"颐之时大矣哉"**——与坎卦"险之时用大矣哉"、大过卦"大过之时大矣哉"同一句式。**《周易》用这个句式的地方，都是在说"这件事的时机判断比手段更重要"。** |
| **大象传（行动纲领）** | 山下有雷，颐。君子以慎言语，节饮食。 |
| **⚠️ "慎言语，节饮食"解（本卦最实用的一条，也最容易被当成陈词滥调）** | 山下有雷：**动在下（雷）而止在上（山）——口的形态正是这样：下颌动、上颌不动。**<br>**所以君子的对应动作，是把"口"的两个方向都管住：言语是"出"，饮食是"入"。**<br>**⚠️ 这是六十四卦大象传中唯一一条同时管"进"和"出"的纲领**，而它选的载体正是本卦的取象——口。<br>**落到现代（这一条必须写实，否则就成了空话）**：<br>　**"节饮食"的现代形态＝管住输入。** 信息流、短视频、群消息、行业八卦、劣质内容、酒局、以及"顺手接下来的活"——**这些都是"食"。颐卦的立场很明确：你吃进来什么，就长成什么。输入不节制，"自养"就无从谈起。**<br>　**"慎言语"的现代形态＝管住输出。** 表态、承诺、评论、转发、对不属于你的事发意见——**每一次输出都在消耗你"被养"的资格与"养人"的信用。**<br>**深意：颐卦认为"养"的第一现场不是你挣了多少，是你的口在进什么、出什么。这两件事都不需要外部条件，是唯一从第一天就能自己做主的部分。** |
| **⚠️ 与艮六五"艮其辅"的呼应** | **艮六五"艮其辅，言有序，悔亡"——管住嘴（说话）**，那是**居尊位者**的专门指令。<br>**颐卦大象传"慎言语，节饮食"——把"口"的两个功能一起管住**，是**全卦所有人**的纲领。<br>**两处合读：艮管"出"的一半（且只对居尊者说），颐管"进出"两半（对所有人说）。** |
| **总铁律** | ① **先看自己有什么（灵龟），再看别人碗里（朵颐）——顺序颠倒就凶**（初九）；② **求养必须循"经"（常道）**，"拂经""颠颐"皆有凶（六二、六三、六五）；③ **六三"十年勿用"是本库最长的封禁**——养错了方向，代价按十年计；④ **居尊而受养者要"居贞"，且"不可涉大川"**（六五）——受人养的时候不能有大动作；⑤ **养人者必须先承担"厉"**（上九"厉吉"）——**养人不是好处，是风险**；⑥ **口的进出（饮食／言语）是唯一从第一天就能自己做主的部分**（大象传）。 |

## 二、爻级字段

> **本卦六爻的分工极清晰**：**初九、六二、六三属震（下），是"求养者"，三爻全部为负；六四、六五、上九属艮（上），是"养人者／受养而能施者"，三爻全部转正。**
> **这个分水岭正好落在上下卦之交——本库"艮在上／震在下"两条结构律在本卦同时生效。**

### 初九 · 舍尔灵龟（⚠️ 本卦最重的一句自查）

| 字段 | 内容 |
|---|---|
| **爻辞** | 舍尔灵龟，观我朵颐，凶。 |
| **象传** | 观我朵颐，亦不足贵也。 |
| **位属性** | 阳爻居阳位，**当位**；居下震之始——**是全卦下面那片"唇齿"的阳爻，本身有实力**。 |
| **判词 → 行动语义** | **凶**（本库吉凶序最坏一档）→ **把自己那份本事拿出来用，别盯着别人的碗**。 |
| **关键词解** | **舍**＝舍弃、放着不用。**尔**＝你。**灵龟**＝灵异的龟——古人以龟卜、以龟为长寿灵物，**此处指"你自己身上那份可以据以自养的本事／禀赋"**（龟能不食而寿，正是"自养"的象征）。<br>**朵颐**＝鼓动腮颐、大口咀嚼之貌。**观我朵颐**＝**看着别人（我）在那儿大口吃。**<br>全句：**放着你自己那只灵龟不用，却盯着别人咀嚼——凶。** |
| **⚠️ 本爻为什么"当位"却"凶"（全卦最需要解释的一处）** | 初九**阳爻当位**，按本库通则是"名正言顺、风险低"，**而它却是全卦唯一的"凶"。**<br>**原因不在位置，在动作。** 象传给的评语是"**亦不足贵也**"——**不值得看重**。这五个字的分量很特殊：**《周易》没有说他做错了什么事，而是说他"不足贵"——他把自己变得不值钱了。**<br>**结构上更刺眼：初九是全卦仅有的两个阳爻之一（另一个是上九），本来正是"能养人"的那一类；它却去做"求养"的动作。** 有本事的人去乞食，**凶的不是乞食这件事，是他自愿放弃了自己的量级。** |
| **识别信号（诊断清单）** | ① **你手上有一样确实能用的本事／资源／作品，但你没在用它**；② 你在持续关注别人怎么拿到好处（谁又融资了、谁又升了、谁的号又起来了）；③ 你的时间大量花在"看"上，产出接近于零；④ 你在等一个人／一个平台来"给"你机会，而不是拿你的东西去换。 |
| **该做** | **把"灵龟"拿出来用**——不管它多小、多不成熟。**卦辞的指令写得很清楚：自求口实。** 先用自己的东西挣到第一口，再谈别的。 |
| **不该做** | 继续"观我朵颐"。**注意：本爻的凶没有爻内解药**（象传只给了一句评价），**解药在卦辞"自求口实"和上九"由颐"**。 |
| **与小畜初九、乾初九的三角对照** | **乾初九"潜龙勿用"——有本事而藏着，是对的（因为在攒）**；<br>**小畜初九"复自道，何其咎，吉"——被压制时回到自己的正道上，吉**；<br>**颐初九"舍尔灵龟，观我朵颐，凶"——有本事而不用，反去看别人吃，凶。**<br>**三个初爻，三种"有本事却没在用"：藏着待时是吉（乾），回到自己道上是吉（小畜），放着去羡慕别人是凶（颐）。**<br>**判别只有一条：你的注意力在自己身上，还是在别人碗里。** |

### 六二 · 颠颐（⚠️ 与六四同辞异断之一）

| 字段 | 内容 |
|---|---|
| **爻辞** | 颠颐，拂经，于丘颐，征凶。 |
| **象传** | 六二征凶，行失类也。 |
| **位属性** | 阴爻居阴位，**当位且得中**——按常理条件极好；**但乘于初九之上，是乘刚**（震在下必然）。 |
| **判词 → 行动语义** | **征凶**（有所行动则凶）→ **不要向下、也不要向上去求这口饭**。 |
| **关键词解** | **颠**＝颠倒。**颠颐**＝**颠倒地求养**——本该向上求养（阴柔求于阳刚在上者），它却向**下**求于初九。<br>**拂**＝违背。**经**＝常道、常理。**拂经**＝**违背了常道**。<br>**丘**＝高处（指上九）。**于丘颐**＝**转而向高处（上九）求养**。<br>**征**＝有所行动、出行。全句：**向下求养是颠倒的、违背常道；转向高处去求，一动就凶。** |
| **⚠️ 象传"行失类也"是本爻的全部重量** | "**类**"＝同类。**六二是阴爻，它向下求初九（阳）、向上求上九（阳），两个方向都不是它的"类"。**<br>**深意：求养失败的原因不是对方不给，是"你去求的对象与你不是一路人"。** 六二当位、得中，条件本来极好——**它错的不是姿态，是方向。**<br>**现代形态：向一个与你根本不同类的对象求资源（价值观不同、量级不同、目标不同），无论姿态多低、条件多好，都是"行失类"。** |
| **⚠️ 本爻是"震在下之六二"的第四例，也是四例中第二差的** | 本库四例结构完全相同（阴爻当位、得中、乘于初九之上）：<br>**屯六二**"十年乃字"（象传"乘刚也""反常也"）——难，但十年后返常；<br>**震六二**"亿丧贝"（象传"乘刚也"）——**厉·大损**；<br>**颐六二**"征凶"（象传"行失类也"）——**凶**；<br>**无妄六二**"则利有攸往"（象传"未富也"）——**唯一不受损**。<br>**四爻位属性完全一致，结局横跨四档，唯一的变量是"它想不想拿到东西、向谁拿"。**<br>**颐六二是四者中最差的：因为它不但在求，还求错了对象（失类）。** 而无妄六二最好，因为它"未富也"——压根不求。 |
| **识别信号** | ① 你的位置、资历、条件其实都不错（当位得中）；② 你却在向人要资源／要收留／要机会；③ **你要的对象与你不是一路人**——量级、目标、价值观有一样根本不同；④ 你已经试过一个方向（向下），不成，正准备转向另一个方向（向上）。 |
| **该做** | **停止"征"（不要再换方向去求）**。回到卦辞"自求口实"，并按初九的教训把自己的"灵龟"拿出来。**六二的解药不是换对象，是换动作。** |
| **不该做** | 换一个更高的对象再求一次（"于丘颐"）。**爻辞把这个动作和"征凶"直接绑在一起了。** |

### 六三 · 拂颐（⚠️ 本库最长的时间刻度：十年勿用）

| 字段 | 内容 |
|---|---|
| **爻辞** | 拂颐，贞凶，十年勿用，无攸利。 |
| **象传** | 十年勿用，道大悖也。 |
| **位属性** | 阴爻居阳位，**不当位**；**失中**；居下震之顶（本库通则"**三多凶**"）。 |
| **判词 → 行动语义** | **贞凶 ＋ 十年勿用 ＋ 无攸利**（**全卦判词最重之爻**）→ **此爻不可入；已在此处，唯一动作是彻底换路** |
| **关键词解** | **拂颐**＝违背了"养"的道理（比六二的"拂经"更进一层：六二违背的是常道，六三违背的是"颐"本身）。<br>**贞凶**（按本库口径：**守正也凶——问题不在品德，在处境与选择的根本错位**）。<br>**十年勿用**＝十年之内不可有所作为。**无攸利**＝没有任何有利之处。<br>象传"**道大悖也**"＝**道理上大大地违背了**（"悖"是逆、乱）。 |
| **⚠️ 专项：本库时间刻度表至此补齐** | 《周易》给出明确时间刻度的地方极少，本库已收两处，颐卦补上第三、第四处：<br>\|　卦爻　\|　刻度　\|　象传／性质　\|　含义　\|<br>\| **震六二** \| **七日得** \| 乘刚也 \| **冲击型**：损失是短周期的、会回来的 \|<br>\| **屯六二** \| **十年乃字** \| **反常也**（返回常态） \| **等待型**：难，但一个完整周期过后自然成 \|<br>\| **坎上六** \| **三岁不得，凶** \| **失道**·凶三岁也 \| **滞留型**：不动的时长本身会固化成牢笼 \|<br>\| **颐六三** \| **十年勿用，无攸利** \| **道大悖也** \| **⚠️ 悖道型**：方向根本错了，一整个周期不可用 \|<br>**⚠️ 关键区分：屯六二的"十年"与颐六三的"十年"是同一个刻度、相反的含义。**<br>**屯六二"十年乃字"——十年后会成（象传"反常也"，返回常态）；颐六三"十年勿用"——十年内不可用（象传"道大悖也"，方向大错）。**<br>**同一个"十"（数之终，代表一整个完整周期），一个是"等到"，一个是"封禁"。判别依据就在象传：是"反常"（会回到正常）还是"大悖"（本来就错得离谱）。**<br>**结论（可入库为通则）：时间刻度的长度对应错误的深度——七日是丢东西，三岁是失道加滞留，十年是"道大悖"。** |
| **⚠️ 为什么是"贞凶"而不只是"凶"** | 按本库判词表，"**贞凶**"比"凶"更需要解释：**守正也凶，说明问题不在品德，在处境与选择的根本错位。**<br>六三**不当位、失中、居三多凶之位**，而它做的事是"拂颐"——**它在"养"这件事上从根上走反了**。所以即使它态度端正、老实守分，也救不了。<br>**本库现有"贞凶"三例：屯九五"大贞凶"（刚有积累就大举扩张）、师六五"弟子舆尸，贞凶"（用错了人）、巽上九"丧其资斧，贞凶"（居高位而一味卑顺）。颐六三补上第四例：在"养"上根本走反。**<br>**四例的共同点：都是"方向性错误"，而不是"程度性错误"。这也解释了为什么它们的解药都不在爻内。** |
| **识别信号（诊断清单）** | ① 你在"靠什么活着"这件事上做了一个根本性的选择，而它明显不对（靠一个不可持续的来源、靠伤害自己的方式、靠一个注定要断的关系）；② 你态度很端正、很努力，情况却没有变好；③ **时间已经过去很久，而你的"自养"能力没有任何增长**；④ 你在想"再坚持坚持"。 |
| **该做** | **承认"道大悖"——不是努力不够，是路错了。** 彻底换掉供养来源／换掉"养"的方式，并且**接受这需要一个完整周期（十年之数）来重建**。 |
| **不该做** | 在原路上加大投入。**对照坎初六"入于坎窞"象传"失道凶也"——同样是"路错了还往下走"。区别是坎初六还有"停止加深"这个爻内动作，颐六三连这个都没有：爻辞直接封了"十年勿用，无攸利"。** |
| **与坎六三的对照（两个六三，两条禁令）** | **坎六三"勿用"（象传"终无功也"）——进退皆险，动了也白动，所以停手，这是"止损型勿用"**；<br>**颐六三"十年勿用"（象传"道大悖也"）——不是白动，是方向反了，且带了一个刻度。**<br>**按本库口径：坎六三是"此刻无解"，颐六三是"这条路整个作废"。后者更重。** |

### 六四 · 颠颐，吉（⚠️ 与六二同辞异断之二）

| 字段 | 内容 |
|---|---|
| **爻辞** | 颠颐，吉。虎视眈眈，其欲逐逐，无咎。 |
| **象传** | 颠颐之吉，上施光也。 |
| **位属性** | 阴爻居阴位，**当位**；已入上艮——**从本爻起全卦转正**；本库通则"**四多惧**"。 |
| **判词 → 行动语义** | **吉 ＋ 无咎** → **在位者向下取养，但要取得专注、持续、正大，并且把所得施下去**。 |
| **关键词解** | **颠颐**＝与六二完全相同的两个字——**颠倒地求养**（六四为阴，向下求于初九之阳）。<br>**虎视眈眈**＝像老虎那样目光下视、专注凝定（"眈眈"是垂目专注之貌）。**注意：这里不是凶相，是"专注而有威"**。<br>**其欲逐逐**＝所求接连不断（"逐逐"＝相继不绝）——**求得持续，不是一次性伸手。**<br>象传"**上施光也**"＝**把上面的光施下去**（"施"是施予，"光"是光明、恩泽）。 |

#### ⚠️ 专项：六二"颠颐，征凶" ↔ 六四"颠颐，吉"（本库第二组"同辞异断"教材）

| 对照项 | **六二 · 颠颐** | **六四 · 颠颐** |
|---|---|---|
| 相同部分 | **颠颐**（都是向下求养于初九） | **颠颐**（同） |
| 位属性 | 当位·**得中**·**乘刚**·在震（下） | 当位·**不得中**·不乘刚·在艮（上） |
| 补充动作 | **拂经，于丘颐**（违常道，又转向高处求） | **虎视眈眈，其欲逐逐**（专注、持续、正大） |
| 象传理由 | **行失类也**（求的对象不是同类） | **上施光也**（把所得施予下面） |
| 判词 | **征凶** | **吉·无咎** |

> **⚠️ 结论（可直接入库为通则）：同一个"向下求养"的动作，一个凶一个吉，差别有两条，而且都不在动作本身：**
> **① 求的方式**——六二是"拂经"（违常道）＋"于丘颐"（换个更高的对象再求一次，即到处伸手）；六四是"虎视眈眈，其欲逐逐"（**盯准一个方向，专注、持续、公开地取**）。
> **② 求来干什么**——六二求来是为了自己吃（所以"失类"）；**六四求来是为了"上施光"（转手施予下面的人），所以吉。**
> **判别问题（用户可直接自查）：你伸手要的东西，最终停在你这儿，还是会流向别人？**
>
> **这与巽卦"巽在床下"（九二吉／上九贞凶）是同一条方法论的两次出现**：**判断一个"低姿态／伸手"动作的吉凶，从来不看动作本身，看做这个动作的人在什么位置、手上还有什么、以及要来做什么。**

| 字段 | 内容 |
|---|---|
| **识别信号** | ① 你在一个有责任的位置上（当位、在上卦），但资源不在你手里；② 你必须向下／向外去取资源（向执行层要人、向合作方要支持、向下级借力）；③ 你在纠结"这样伸手是不是显得没本事"（四多惧）。 |
| **该做** | ① **公开、专注、持续地取**——"虎视眈眈"是正大，不是偷偷摸摸；"其欲逐逐"是持续，不是一次性透支人情；<br>② **⚠️ 最关键：把取来的东西"上施光"**——明确让出成果、把好处给到提供资源的那一方和你下面的人。**这一条是"吉"的全部来源。** |
| **不该做** | 到处伸手（那是六二的"于丘颐"）；或者取来自己独占（那就取消了"上施光"，吉的理由就没了）。 |
| **与巽六四、小畜六四的对照（三个当位的"四"）** | **小畜六四"血去惕出，无咎"（上合志也）——靠上级支持免灾**；**巽六四"悔亡，田获三品"（有功也）——靠交付可分配的成果站住**；**颐六四"颠颐，吉"（上施光也）——靠把所得转施下去得吉。**<br>**三爻都在多惧之位、都当位，判词依次上升：无咎 → 悔亡 → 吉。**<br>**规律很清楚：四位上的价值高低，取决于你手里的东西流向哪里。** 流向自己＝勉强无咎；分配给各方＝悔亡有功；**转施给下面＝吉。** |

### 六五 · 拂经，居贞吉（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 拂经，居贞吉，不可涉大川。 |
| **象传** | 居贞之吉，顺以从上也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位——全卦卦主。 |
| **判词 → 行动语义** | **吉（带条件："居贞"）＋ 不可涉大川** → **安居守正则吉，但绝不可有大动作**。 |
| **关键词解** | **拂经**＝违背常道（与六二同词）。**为什么居尊位反而"拂经"？** 因为**六五自己是阴柔，养不了天下，反而要靠上九来养**——**居尊位而受人养，这在常道上是颠倒的。**<br>**居贞**＝安居守正（"居"是不动、安处）。**不可涉大川**＝不可去做跨越重大险阻的大事。<br>象传"**顺以从上也**"＝**顺从并跟随上面那一位**（上九）。 |
| **⚠️ 本爻是本库"居尊者"专题里最特殊的一例：居尊而承认自己养不了** | 六五**不当位**（阴居阳位），**得中居尊**。它的处境是：**名义上最高，实际上要靠上九提供供养与判断。**<br>**《周易》对这种处境的处理极其干脆——不批评它，但给了两条硬约束：**<br>**① "居贞"：安居守正，不折腾。吉是有条件的，条件就是"居"（不动）。**<br>**② "不可涉大川"：不许有大动作。**<br>**深意：受人供养的时候，你的判断力不完全属于你自己，所以此时任何"大川级"的决定都不该由你发起。**<br>本库"六五／九五"专题至此七例：**乾九五**（居尊而求贤）、**坤六五**（有君之权而守臣节）、**蒙六五**（居尊而不失赤子之心）、**离六五**（居尊而痛哭）、**艮六五**（居尊而闭嘴）、**大畜六五**（居尊而不硬碰）、**颐六五（居尊而承认自己养不了，顺从能养者）**。<br>**七者完全同构——居尊位者必须主动放弃一样特权。颐六五放弃的是"自己拍大事"的权力。** |
| **⚠️ "不可涉大川" ↔ 上九"利涉大川"（同卦之内的直接对立）** | **本卦六五"不可涉大川"，上九"利涉大川"——相邻两爻，同一件事，一个禁、一个许。**<br>**差别只有一条：六五是被养的那个，上九是养人的那个。**<br>**结论（可入库为通则）：能不能"涉大川"，不取决于你的位置有多高，取决于你是被养者还是养人者。**<br>**跨卦并读**：大畜卦辞"**利涉大川**"（彖传"应乎天也"）、需卦卦辞"**利涉大川**"（彖传"往有功也"）——**两卦的共同前提都是"下卦刚健（乾）、自己有本钱"。而颐六五之所以不可涉，正因为它自己没有本钱（阴柔、要靠人养）。** |
| **识别信号** | ① 你在名义上最高／最被认可的位置上；② **但你现在的资源、判断、甚至日常运转，实际上依赖某一个人／一个渠道**；③ 你正在考虑做一件大事（融资、转型、扩张、重大人事）。 |
| **该做** | **居贞**——把这一段的目标定成"稳住、不出错、把关系维持好"；**并且如实承认那个"从上"的依赖关系**（象传"顺以从上也"，这里没有贬义）。 |
| **不该做** | 在被供养期发起"大川级"的动作。**也不要因为"我是最高的那个"就掩盖依赖关系——爻辞第一个词就是"拂经"，《周易》已经把这件事说出来了，你不必替它掩饰。** |

### 上九 · 由颐（⚠️ 全卦最好之爻，养人者）

| 字段 | 内容 |
|---|---|
| **爻辞** | 由颐，厉吉，利涉大川。 |
| **象传** | 由颐厉吉，大有庆也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终；**是艮的那个阳爻**（艮＝阴阴阳，阳在最上）；**也是全卦上面那片"唇齿"**。 |
| **判词 → 行动语义** | **厉吉**（厉＝警告非判死；吉＝进／成）**＋ 利涉大川** → **成为那个养人的人；先承担风险，然后才吉** |
| **关键词解** | **由**＝经由、依赖、由之而来。**由颐**＝**天下由他而得养**——**他是那个供养的源头。**<br>**厉吉**＝**有危险，但吉**（两个判词并列，顺序是"厉"在前）。**利涉大川**＝可以去做跨越重大险阻的大事。<br>象传"**大有庆也**"＝**有大的、及于众人的喜庆**（对照六四"有喜"是自家之喜、大畜六五"有庆"是及众之庆，"**大有庆**"是覆盖面最大的一档，本库另一处是履上九"元吉在上，大有庆也"）。 |
| **⚠️ 专项："厉"字在前——养人不是好处，是风险** | **本爻是全卦最好的一爻，判词却以"厉"开头。** 这个顺序不能忽略：<br>**《周易》没有说"养人则吉"，它说的是"厉吉"——先有危险，然后才是吉。**<br>**为什么？** 因为上九此时承担的是**全卦所有人的口粮**：六五要靠它（"顺以从上也"），六四要靠它转施（"上施光也"），下三爻的求养最终都指向它。**一个人成为供养的源头，就同时成了所有风险的汇集点。**<br>**这与本库现有的两条判断完全一致**：<br>　**师卦九二**——一阳统五阴，是"丈人"，**卦辞对战争不许诺任何好处，只给"贞"**；<br>　**小畜九五"富以其邻"象传"不独富也"**——核心位置者必须分享。<br>**颐上九把这条线推到最后一步：不只是"必须分享"，而是"你就是那个源头，并且要先承担风险"。** |
| **⚠️ 本爻不当位却是全卦最好的一爻——"义理可救位"的第三例** | 阳居阴位本是名不正言不顺。**但上九是艮的那个阳爻，是全卦唯一有能力"养"的力量所在，德与卦完全相合，所以象传不谈位，只谈"大有庆"。**<br>**本库同类：艮上九"敦艮，吉"（不当位而吉，因为它就是"止"的力量本身）、大畜上九"何天之衢，亨"（不当位而亨，因为它就是"畜足"的那个刚）。**<br>**三例合看，是同一条结构规律：艮的阳爻居上，虽必然不当位，却因"德与卦合"而得善终。**（详见第四节第 3 条。） |
| **识别信号** | ① 你已经是那个"别人靠你吃饭"的人（团队、家庭、学生、下游合作方）；② 你手上有可持续的产出能力，不是一次性资源；③ **你已经感到风险在向你集中**（所有问题最后都是你的问题）；④ 你正在考虑一件需要跨越重大险阻的事。 |
| **该做** | ① **接受"厉"**——把风险集中当成这个位置的固定成本，不当成异常；<br>② **正式承担"由颐"的角色**：让供养关系清楚、可持续、可预期，而不是靠临时救济；<br>③ **此时才可以"涉大川"**——**养人者是本卦唯一被授权做大事的爻。** |
| **不该做** | 在没有"由颐"的能力时抢这个位置（那是六二六三的下场）；或者做了源头却不承认风险（"厉"字在前，是提前告知，不是意外）。 |
| **与初九的首尾对照（本卦的完整弧线）** | **初九"舍尔灵龟，观我朵颐，凶"——有本事而不用，去看别人吃**；<br>**上九"由颐，厉吉，利涉大川"——成为别人吃饭的源头。**<br>**两爻都是阳爻，都是这张"口"的唇齿，一在最下、一在最上。**<br>**同样有本事，一个去羡慕别人的碗（凶），一个成为所有人的碗（大有庆）。这就是颐卦全部的落差。** |

| 六四 | **受养而能施** | 颠颐，吉 | 有责任没资源，必须向下取 | **当位**·四多惧 | **吉·无咎**·专注持续取＋**上施光** |
| 六五 | **居尊受养（卦主）** | 居贞吉 | 名义最高，实际依赖某一个来源 | 不当位但**得中居尊** | **吉（须居贞）·不可涉大川** |
| 上九 | **养人** | 由颐 | 别人靠你吃饭，风险都汇到你这儿 | 不当位**却最好** | **厉吉·利涉大川**·大有庆 |

**颐卦三句话**：
1. **"养正则吉"**（彖传）——**这一卦没有元、没有亨、没有利，只有一个"贞吉"：养对了就吉，养错了就贞凶。开关只有"正"这一个。**
2. **路径是"被养 → 自养 → 养人"，而分水岭在上下卦之交**：下三爻（震，求养者）全部为负，上三爻（艮，养人者）全部转正。**卦辞给的动作就是过这道关的方法：观颐（看清供养关系）＋自求口实（自己动手挣）。**
3. **口的进出是唯一从第一天就能自己做主的部分**（大象传"慎言语，节饮食"）——**"节饮食"＝管住输入（信息、内容、顺手接下的活）；"慎言语"＝管住输出（表态、承诺、评论）。**

**本卦最反直觉的三条**：
- **初九当位、有本事，却是全卦唯一的"凶"。** 象传的评语不是"有咎"，是"**亦不足贵也**"——**《周易》没说他做错事，说的是他把自己变得不值钱了。**
- **六二与六四爻辞都以"颠颐"开头，一个"征凶"，一个"吉"。** 差别不在动作，在**求的方式**（专注一处 vs 到处伸手）和**求来干什么**（自己吃 vs 上施光）。
- **相邻两爻，六五"不可涉大川"、上九"利涉大川"。** **能不能做大事，不取决于位置多高，取决于你是被养者还是养人者。**

## 四、⚠️ 本卡对全库的意义

### 1. 本库第二组"同辞异断"教材，判别法与第一组完全一致

| | **第一组：巽 57** | **第二组：颐 27** |
|---|---|---|
| 相同爻辞 | **巽在床下**（九二／上九） | **颠颐**（六二／六四） |
| 吉的那一爻 | **九二**"用史巫纷若，**吉，无咎**"（象传"得中也"） | **六四**"虎视眈眈，其欲逐逐，**吉·无咎**"（象传"上施光也"） |
| 凶的那一爻 | **上九**"丧其资斧，**贞凶**"（象传"上穷也"） | **六二**"拂经，于丘颐，**征凶**"（象传"行失类也"） |
| 差别所在 | **是否还握着决断权（斧）** | **求的对象是否同类；求来是否转施出去** |

> **合并后的通则（可直接入索引）：**
> **判断一个"低姿态／伸手求人"的动作是吉是凶，从来不看动作本身，看三件事——**
> **① 你在什么位置（得中？上穷？）；② 你手上还握着什么（决断权？可施之物？）；③ 你求来的东西流向哪里（自己吃？转施出去？）。**
> **这条通则可以直接做成产品里的三问式自查。**

### 2. 时间刻度表补齐——并区分出"等到"与"封禁"两种"十年"

| 卦爻 | 刻度 | 象传 | 性质 | 现代读法 |
|---|---|---|---|---|
| **震六二** | **七日得** | 乘刚也 | **冲击型** | 一次性损失，短周期会回，别追 |
| **屯六二** | **十年乃字** | **反常也**（返回常态） | **等待型** | 一个完整周期后自然成，别被中途的画饼骗走 |
| **坎上六** | **三岁不得，凶** | 上六失道，凶三岁也 | **滞留型** | 不动的时长本身会固化成牢笼 |
| **颐六三** | **十年勿用，无攸利** | **道大悖也** | **⚠️ 悖道型** | 方向从根上反了，整条路作废，须重建一个周期 |

> **⚠️ 关键区分（本卡最实用的一条增量）：屯六二与颐六三用的是同一个"十年"（"十"是数之终，代表一整个完整周期），含义正相反。**
> **屯六二"十年乃字"是"等得到"（象传"反常也"）；颐六三"十年勿用"是"封禁"（象传"道大悖也"）。**
> **判别只看象传一句：是"反常"（会回到正常）还是"大悖"（本来就错得离谱）。**
> **结论：时间刻度的长度＝错误的深度。七日是丢东西，三岁是失道加滞留，十年是道大悖。**

### 3. "艮的阳爻居上"＝全书最安全的上爻位置（结构律，四例齐备）

| 卦 | 卦象 | 上爻 | 判词 | 象传 | 机制 |
|---|---|---|---|---|---|
| **艮 52** | 上艮下艮 | 敦艮 | **吉** | 以厚终也 | 它就是"止"的力量本身 |
| **蒙 4** | 上艮下坎 | 击蒙，不利为寇，利御寇 | 有条件可行 | — | 施教者的最后手段，有边界 |
| **大畜 26** | 上艮下乾 | 何天之衢 | **亨** | **道大行也** | 它就是"畜足"的那个刚 |
| **颐 27** | 上艮下震 | 由颐，厉吉，利涉大川 | **厉吉** | **大有庆也** | 它就是"养"的源头 |

> **通则：艮在上时，上爻按结构律必然不当位（阳居阴位），却在本库四例中全部善终。**
> **机制统一：艮把阳放在最上，所以这个上爻本身就是本卦之德的载体——止之卦它是"止"，畜之卦它是"畜足"，养之卦它是"养源"。位不正，而德与卦完全相合，故象传不谈位。**
> **这是本库"义理可救位"最集中的一处证据，也把艮卡的结论推进了一步：不知止才受罚；而如果你就是那个"止"本身，到顶反而是圆满。**

### 4. 颐卦与本库的三条衔接

| 衔接 | 机制 |
|---|---|
| **颐 ↔ 大畜 26** | 序卦直接相承（"物畜然后可养"）。**大畜卦辞"不家食吉"，彖传释为"养贤也"；颐彖传"圣人养贤以及万民"。两卦是同一条"养贤"线的上下游：大畜讲"要把贤者养起来"，颐讲"养起来之后这条链怎么传下去"。** |
| **颐 ↔ 艮 52** | **艮六五"艮其辅，言有序"管住"出"（且只对居尊者说）；颐大象传"慎言语，节饮食"把"进"与"出"一起管住（对所有人说）。** 合起来是本库对"口"的完整纪律：**定之前多想（比卦"原筮"），定之后少说（艮六五），而进什么出什么每天都要节制（颐）。** |
| **颐 ↔ 震 51 / 屯 3 / 无妄 25** | **"震在下之六二"四例至此齐备**（屯、震、颐、无妄），四爻位属性完全相同而结局横跨四档。**唯一变量是"想不想拿到东西、向谁拿"：颐六二在求且求错对象（最差），无妄六二"未富也"压根不求（最好）。** 这组四爻可直接做成产品里"乘刚"这一诊断的对照训练题。 |
