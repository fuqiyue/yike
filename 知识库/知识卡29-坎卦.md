# 知识卡 29 · 坎卦（习坎 / 水）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："物不可以终过，故受之以坎。坎者，陷也。"——过头了必然陷落。
> **本卦是八纯卦之一（上坎下坎），也是本库通则"坎在上／在下"的总源头。** 蒙、讼、师三卦坎在下，屯、需、比三卦坎在上——读完本卡，那六卦的险境性质差异才真正立得住（见末节对照表）。

---

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 坎（习坎）· 第二十九卦 · **八纯卦之一** |
| **卦象** | 上坎下坎，**重险**。一阳陷于二阴之中（九二、九五各被上下阴爻夹住）——"陷"之象。**卦名特加"习"字**：习＝重、叠，习坎＝**险上加险** |
| **领域定义** | **极端困境与连续打击**。重大挫折接连发生、系统性风险、深陷债务／官司／疾病／信任崩塌、看不到出口的持续消耗。凡是"不是一件坏事，是一串坏事，而且我已经在里面了"，都落在坎卦。 |
| **不归本卦的情况** | 险还在前方、尚未入 → **需卦**（上坎，待时）；险在前方但起步是"动"、还有根可扎 → **屯卦**（上坎下震）；单一对手的私人冲突 → **讼卦**。 |
| **"坎"字本义** | 坑、陷、险。说卦传"坎为水"——**水的三个性质是本卦全部义理的根**：① 必下行（就下）；② 必守信（盈科而后进，走多少算多少）；③ 无形而不可夺（可堵不可灭）。 |
| **卦辞原文** | 习坎：有孚，维心亨，行有尚。 |
| **⚠️ 卦辞的关键特征** | **无元、无利、无贞；连"亨"都带前提——"维心亨"。** 这是全书最苛刻的一条通路：**重险之中，唯一通的东西是"心"，外面没有一条路是通的。** |
| **卦辞现代解** | **有孚**——必须有真实的诚信与内在确信，这是险中唯一的凭据。<br>**维心亨**——"维"是唯、只有：**只有心是通的**。险境里改变不了外部条件，能守住的只有"心不乱、信不失"。<br>**行有尚**——"尚"是嘉尚、值得：**仍然要行动，而且行动本身就值得肯定**。<br>合起来九个字：**心不乱、信不失、脚不停。** |
| **彖传** | 习坎，重险也。水流而不盈，行险而不失其信。维心亨，乃以刚中也。行有尚，往有功也。天险不可升也，地险山川丘陵也，王公设险以守其国，险之时用大矣哉。 |
| **彖传要点（本卦最重要）** | ① **水流而不盈**——水流过而不满溢，**走多少算多少，绝不虚报**。② **行险而不失其信**——险中最容易丢的是"信"，而水从不丢。③ **乃以刚中也**——心之所以能通，靠的是九二九五的"刚中"，即**内在那个刚硬的核**。④ **险之时用大矣哉**——险不只是灾：**王公设险以守其国**，险是可以被"用"的。这是全卦唯一的翻转视角。 |
| **大象传（行动纲领）** | 水洊至，习坎。君子以常德行习教事。 |
| **"常德行，习教事"解** | 洊＝相继而至。**水一波接一波来——外部打击不会停。** 君子的对策不是硬抗，是"常"与"习"：**把德行做成常态，把该学该教的事反复练。险中唯一能积累的东西，是日常功课。** |
| **总铁律** | ① **绝不加深**——初六、六三两次警告"入于坎窞"，都是往更深处走；② **只求小得**（九二），此时任何大目标都是幻觉；③ **水位一平就收**（九五"祗既平，无咎"），不要等"彻底好起来"；④ **三年是死线**（上六"三岁不得，凶"）——**困在里面不动的时长本身会杀死你**。 |

## 二、爻级字段

### 初六 · 入于坎窞

| 字段 | 内容 |
|---|---|
| **爻辞** | 习坎，入于坎窞，凶。 |
| **象传** | 习坎入坎，失道凶也。 |
| **位属性** | 阴爻居阳位，**不当位**；居重险之最下——**全卦最深处**。 |
| **判词 → 行动语义** | **凶** → **此爻不可入；已在此处，唯一动作是"不再往下"**。 |
| **关键词解** | **窞**＝坑中之坑、洞中之洞。"入于坎窞"＝**已经在坑里，还在往更深的坑里走**。 |
| **⚠️ 象传给了原因** | "**失道凶也**"——**凶不是因为坑深，是因为失道。** 走错了路才掉进去；掉进去之后**仍按原来的逻辑继续走**，就是"入窞"。 |
| **识别信号** | ① 事情已经很糟，你的对策是"加倍投入把它扳回来"；② 借新债还旧债、追加投资摊薄成本、为挽回关系做更大让步；③ 你在说"已经到这一步了，只能往前"。 |
| **该做** | **停止追加。** 承认"失道"——不是运气不好，是路径错了。回到"道"上，代价哪怕是承认前面全错。 |
| **不该做** | 沉没成本思维。**这一爻凶的全部原因就是"往深处走"。** |
| **与屯卦初九的关键区别** | 屯卦是**上坎下震**——险在前方，起步是"动"，初九阳爻**当位**，还有根可扎，所以是"磐桓，利居贞"；**坎卦是下坎——起步就已经在险中**，初六不当位、上下皆坎，无根可扎。**同是开局遇险，屯有生机，坎无。** 本库通则说"坎在下卦→刚起步遇险极凶，很多人物理销号或心理销号"，指的正是这一爻的性质。 |

### 九二 · 求小得（下坎卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 坎有险，求小得。 |
| **象传** | 求小得，未出中也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**；**下坎唯一阳爻**——下卦卦主。 |
| **判词 → 行动语义** | **无判词，只给方法** → **降低目标，只求小得**。 |
| **爻义** | **坎有险**——先承认险在，不自欺。**求小得**——只谋求小的、确定能拿到的收获。 |
| **⚠️ 本爻是全卦的操作核心** | 象传"**未出中也**"——**你还没出险，仍在坎中**。所以"小得"不是保守，**是唯一现实的量级**。险中求大，必然变成初六、六三的"入于坎窞"。 |
| **本库规则的应用** | **"得中可救不当位"**——九二不当位（名不正言不顺），但得中，所以还有余地、还能动。对比初六与六三：**不当位又不得中，直接凶。** |
| **识别信号** | ① 你在困境中，但还能动、还剩一点资源；② 周围（或你自己）在期待一个"翻盘"；③ 你能列出几件小事是确定做得成的。 |
| **该做** | **把目标切到最小可完成单元。** 今天能还上一笔小账、能修好一段关系、能交付一件小活——就做这个。**用"小得"来维持卦辞里的"孚"（可信）与"心亨"（不乱）。** |
| **不该做** | 谋求一次性解决。也**不要因为"只能做小事"就干脆不动**——卦辞明写"行有尚"。 |
| **与需卦九二的对照** | 需九二"需于沙，小有言，终吉"是**险在前方时的等待**；坎九二是**险在身上时的小步求生**。都落在"小"字上，但一个是慎，一个是活。 |

### 六三 · 险且枕

| 字段 | 内容 |
|---|---|
| **爻辞** | 来之坎坎，险且枕，入于坎窞，勿用。 |
| **象传** | 来之坎坎，终无功也。 |
| **位属性** | 阴爻居阳位，**不当位**且失中；居下坎之顶、正对上坎——**进退都是坎**。**且乘于九二之上，是乘刚**——险中还被下面顶着。 |
| **判词 → 行动语义** | **勿用** → **全面停手**。 |
| **关键词解** | **来之坎坎**——"来"（退）也是坎，"之"（往）也是坎，**进退皆险**。**险且枕**——"枕"是枕靠、停滞不安：险境上还压着一层。**勿用**——不要有任何作为。 |
| **⚠️ 与乾初九"勿用"的根本区别（必须分清）** | 乾初九"潜龙勿用"是**蓄力型勿用**，核心在"潜"，是有前途的等待；**坎六三"勿用"是止损型勿用**，象传"**终无功也**"——明确告诉你**此时无论怎么动都不会有成果**。**前者是攒，后者是停。** |
| **识别信号** | ① 无论选哪个方向，你都能看到明确的坏结果；② 你已经很累（枕），却还在逼自己做决定；③ 你在两个坏选项之间来回反复。 |
| **该做** | **承认此时无解，停止决策。** 守住卦辞里的"心"——人不动，但功课不停（大象传"常德行习教事"）。 |
| **不该做** | 硬选一个方向。在"终无功也"的判断下，任何选择都只是消耗。 |
| **与屯六三的对照** | 屯六三"往吝穷也"是**越走越窄**（吝），还有一条窄路；坎六三是**白费**（无功），连窄路都没有。按本库吉凶序：**吝 ＞ 终无功。** |

### 六四 · 纳约自牖（全卦转机之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 樽酒簋贰，用缶，纳约自牖，终无咎。 |
| **象传** | 樽酒簋贰，刚柔际也。 |
| **位属性** | 阴爻居阴位，**当位**；已入上坎——本库通则"**坎在上卦 → 六四、九五、上六全部当位、全有转机**"，**从本爻起全卦转向**。 |
| **判词 → 行动语义** | 终无咎 → **极简、走侧门、先把关系接上**。 |
| **关键词解** | **樽酒簋贰**＝一樽酒、两簋饭，**极薄的礼**。**用缶**＝用瓦罐盛，**最粗的器**。**纳约自牖**＝从窗子把简约之物递进去（"牖"是窗，"约"是简约）——**不走正门，走窗口**。 |
| **⚠️ 本爻是全卦的转机** | 险境中的破局方式**不是隆重，是"极简 ＋ 侧门"**。象传"**刚柔际也**"——六四（柔）与九五（刚）相接，**关键就在于把这层关系接上**。困境里真正救命的，是**一条能通到关键人、且不讲排场的沟通渠道**。 |
| **识别信号** | ① 你在困境中需要外部支持；② 你拿不出"体面"的对接资源；③ 正规渠道走不通，或走得通但太慢。 |
| **该做** | 用最小的成本、最不正式的渠道，**先把关系接上**。**险中一句真诚的话，胜过一个办不到的大礼。** |
| **不该做** | 因为拿不出体面的东西就干脆不去接触；或反过来超出能力搞排场——**险中打肿脸充胖子，直接坏掉"孚"**。 |
| **与比卦的呼应** | 比卦（上坎下坤）讲归附联合，卦辞"原筮，元永贞"讲审慎择主、"后夫凶"讲时间窗口。**坎六四是同一件事在险境中的最小实现**：没时间也没资源去从容审慎，那就先从窗口递进去，把线接上。 |

### 九五 · 坎不盈（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 坎不盈，祗既平，无咎。 |
| **象传** | 坎不盈，中未大也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位；**上坎唯一阳爻**——全卦卦主。 |
| **判词 → 行动语义** | 无咎 → **水位刚平就收手，不求满**。 |
| **关键词解** | **坎不盈**＝坑没被填满、水没有溢出。**祗**＝仅、只是（"祗既平"＝只是刚刚齐平）。全句：**坑还没满，只是刚刚齐平，这就无咎了。** |
| **⚠️ 本爻是全卦最反直觉的一条** | **全卦最高、最正、最中的一爻，判词只有"无咎"**——不是吉，更不是元吉。象传"**中未大也**"：你居中得正，但成就并不大。**坎卦明确告诉你：度过重险的最好结果，就是"没事了"。** 要求更多，就是在险中求盈——而水的本性是"流而不盈"。 |
| **该做** | **承认"平"就是终点。** 水位齐平——债还清了、病稳住了、关系不再恶化——**立刻收手，转出坎卦**。 |
| **不该做** | 等"彻底好起来"再收；或把刚脱险当成新起点、马上加杠杆。**"不盈"是天道给的上限，不是你努力不够。** |
| **四个"五"的对照（尊位差异）** | 需九五"酒食贞吉"——上岸后的分享与节制；师六五——选对人然后放手；讼九五"元吉"——中正折中、案结事了；**坎九五"无咎"——水平即止、不求满**。**同为尊位，坎是唯一连"吉"字都没有的，因为它的处境最差。** |
| **与乾上九的呼应** | 乾上九"亢龙有悔"是**盈极不知止**；坎九五"不盈"是**天道直接封住了"盈"这条路**——险中根本不给你盈的机会，**这反而是一种保护**。 |

### 上六 · 系用徽纆

| 字段 | 内容 |
|---|---|
| **爻辞** | 系用徽纆，置于丛棘，三岁不得，凶。 |
| **象传** | 上六失道，凶三岁也。 |
| **位属性** | 阴爻居阴位，**当位**；居全卦之终——**但当位不救，仍是凶**。；**且乘于九五之上，是乘刚**。 |
| **判词 → 行动语义** | **凶** → **此爻不可入；核心变量是"时间"**。 |
| **关键词解** | **徽纆**＝绑人的绳索（徽是三股绳，纆是两股绳）。**丛棘**＝荆棘丛，古代囚禁之地。**三岁不得**＝三年脱不出来。 |
| **⚠️ 本爻是全卦最重的警告** | 与初六首尾呼应——**象传都用了"失道"二字**。但上六多给了一个量：**时间**。"**凶三岁也**"——把自己捆住、置于荆棘、长期不动，**这个状态本身会固化成牢笼**。**险境真正的杀伤力不在冲击强度，在滞留时长。** |
| **识别信号** | ① 你已经习惯了这个困境，不再尝试了；② 你把处境解释成"命"或"就这样了"；③ **捆住你的绳子有一部分是你自己系的**——爻辞是被动式（"系用徽纆"），但象传判的是"失道"。 |
| **该做** | **立即回到九二"求小得"**——用最小的行动打破滞留。卦辞"**行有尚**"针对的就是这一爻：**行动本身就值得肯定，因为不动才是致命的。** |
| **不该做** | 等外部条件自己变好。**"三岁"是《周易》在这里给出的一个明确刻度。** |
| **⚠️ "当位却凶"的稀有案例** | 本库通则说当位＝名正言顺、风险低。**上六是重要反例**：当位也救不了"失道 ＋ 长期不动"。**位置正，但方向错、时间久，照样凶。** |

## 三、坎卦定位速查表

| 爻 | 处境 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | 刚陷入 | 入于坎窞 | 事情糟了，你在加倍投入 | 不当位·重险最下 | **凶**·失道·停止加深 |
| 九二 | 困中有余力 | 求小得 | 还能动，但想一次翻盘 | 不当位但**得中** | **只求小得**·未出中 |
| 六三 | 进退皆险 | 险且枕 | 每个方向都是坏结果 | 不当位·失中·两坎之间 | **勿用**·终无功·停手 |
| 六四 | 转机初现 | 纳约自牖 | 需要外援，但没资源讲排场 | **当位**·入上坎 | **终无咎**·极简走侧门 |
| 九五 | 将出险（**卦主**） | 坎不盈 | 水位刚刚齐平 | **当位·得中·居尊** | **无咎**·平即止·不求满 |
| 上六 | 长期滞留 | 系用徽纆 | 已经习惯了，不再尝试 | 当位**却凶** | **凶三岁**·必须动起来 |

**坎卦三句话**：
1. 陷进去之后，唯一致命的动作是**往更深处走**（初六、六三）。
2. 唯一有效的动作是**求小得**（九二）——外面没有一条路是通的，通的只有心（维心亨）。
3. 出险的最好结果是**无咎**，不是吉（九五）；而**不动满三年，是凶**（上六）。

**本卦最反直觉的三条**：
- **九五全卦最尊最正，判词只是"无咎"。** 度过重险，"没事了"就是满分。
- **上六当位，却是全卦最重的凶。** 位置对不代表方向对；**滞留时间会自己长成牢笼**。
- 彖传"**险之时用大矣哉**"——王公设险以守其国。**险不只是要躲的东西，你自己也可以设险自守。** 这是坎卦留给已经出险的人的最后一层。

## 四、⚠️ 本卡对全库的意义：坎在上／在下总源对照表

本库通则说"同一个险，在不同阶段完全是两种性质"。**其机制是纯结构性的、可验证的**：坎的三爻由下而上是**阴、阳、阴**——

- **坎在下卦**（占初、二、三位）→ 阴居阳位、阳居阴位、阴居阳位 → **三爻必然全部不当位**。
- **坎在上卦**（占四、五、上位）→ 阴居阴位、阳居阳位、阴居阴位 → **三爻必然全部当位**。

| 卦 | 卦象 | 坎的位置 | 当位爻 | 险的性质 |
|---|---|---|---|---|
| **蒙**（4） | 上艮下坎 | **下** | 仅六四 | 起步即险，且被"止"压住——故须"童蒙求我" |
| **讼**（6） | 上乾下坎 | **下** | 仅九五 | 起步即险，全卦仅裁决者当位——故"中吉终凶" |
| **师**（7） | 上坤下坎 | **下** | 六四、上六 | 起步即险，不得已而战——故卦辞只给"贞" |
| **坎**（29） | 上坎下坎 | **上下皆是** | 六四、九五、上六 | **重险**：前三爻全不当位（凶／勿用），后三爻全当位（转机） |
| **屯**（3） | 上坎下震 | **上** | 5 爻（仅六三不当位） | 险在前方，起步是"动"——故可扎根、可小试错 |
| **需**（5） | 上坎下乾 | **上** | 5 爻（仅九二不当位） | 险在前方，底子刚健——故"老天极度支持安身养命" |
| **比**（8） | 上坎下坤 | **上** | 4 爻 | 险在前方，底子柔顺——故须审慎择主、且有时间窗口 |

**结论（可直接用于第三步"定势"）**：
> **坎在下 → 你已经在险里，本库口径是"求小得、勿加深"。**
> **坎在上 → 险还在前方，本库口径是"扎根／待时／择主"。**
> **习坎（29）是唯一上下皆坎的卦，因此它同时是这两句话的完整版本——前三爻教你怎么不死，后三爻教你怎么出来。**
