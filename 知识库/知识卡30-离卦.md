# 知识卡 30 · 离卦（离 / 火）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："陷必有所丽，故受之以离。离者，丽也。"——陷落之后必然要有所附着。
> **本卦是八纯卦之一（上离下离），也是坎卦（29）的错卦**：坎是一阳陷于二阴（陷、险、暗），**离是一阴丽于二阳（丽、明、亮）**。坎讲"怎么不死"，**离讲"怎么不被烧掉"**。
> ⚠️ **离在本库现有 12 张卡中一次都没出现过**（01–12 只涉及乾、坤、震、坎、艮、巽、兑）。**本卡是纯新增地基**，一次打开 15 个卦（见末节）。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 离 · 第三十卦 · **八纯卦之一** |
| **卦象** | 上离下离，**重明**。一阴丽于二阳之中（六二、六五各被上下阳爻夹持）——"附丽"之象。**明两作**：两重光明相继而起 |
| **⚠️ "离"字的双义（本卦全部义理的根）** | **"离"同时是"火／光明"和"丽／附着"两个意思，而且必须合起来读**：**火不能自己烧，必须附在薪柴上才能燃**。所以本卦的核心命题是——**你的光不是你自己的，是附在某个东西上的；附着物决定了你能亮多久、会不会烧起来。** |
| **领域定义** | **光明、名声、影响力、专业展现，以及"依附什么而发光"**。出名、被看见、成为标杆、以专业能力立身、做内容做教育做传播、进入高光期；也包括**依附于某个平台／组织／人而获得光亮**。凡是"我被照亮了／我在发光／我靠什么发光"，都落在离卦。 |
| **不归本卦的情况** | 有实力但被压住、蓄而未发 → **小畜卦**；在强势结构中求安全通行 → **履卦**；已是顺境全通 → **泰卦**。**离卦特指"亮起来了"这件事本身的经营。** |
| **卦辞原文** | 离：利贞，亨。畜牝牛，吉。 |
| **⚠️ 卦辞的关键特征** | **有利、有贞、有亨，却无"元"**；而且它给了一个极具体、看似不相干的指令：**"畜牝牛"**。**全书用"养一头母牛"来定一卦之要的，只有这里。** |
| **卦辞现代解** | **利贞**——**先贞后利**：光明这件事必须走正道，正才有益。注意语序是"利贞，亨"——**不正，则连"亨"都不给**。<br>**畜牝牛，吉**——"牝牛"是母牛，**柔顺之至**。火性躁烈、上炎、易失控；**所以要专门"畜养"一份极柔顺的德性来压住它**。<br>**这是本卦最实用的一条**：**越是发光的时候，越要养一份笨、慢、顺、能承载的东西在身上**——与坤卦"厚德载物"是同一味药。 |
| **彖传** | 离，丽也。日月丽乎天，百谷草木丽乎土，重明以丽乎正，乃化成天下。柔丽乎中正，故亨，是以畜牝牛吉也。 |
| **彖传要点（本卦最重要）** | ① **日月丽乎天，百谷草木丽乎土**——**连日月都得附着在天上，草木都得附着在土里。没有不依附而独存的光明。** ② **重明以丽乎正，乃化成天下**——**光明必须附着于"正"**，才能化育天下；附着于不正，光越大祸越大。③ **柔丽乎中正，故亨**——之所以能"亨"，是因为那一阴（柔）附着在了中正之位（六二得中且当位）。**结论：亨的原因不是火大，是柔而得中。** |
| **大象传（行动纲领）** | 明两作，离。大人以继明照于四方。 |
| **"继明照于四方"解** | **"继"是本卦纲领上的关键字**：明两作＝一重光明接着一重光明。**光明不是一次性的爆发，是要"继"的**——今天的光要接得上昨天的光。**大人的责任不是亮一次，是持续亮，并且照到四方（不能只照自己）。** |
| **总铁律** | ① **光必须有所附着，且必须附于"中正"**（六二"黄离，元吉"）——附错了地方，光就变成"焚"（九四）；② **火性躁，必须"畜牝牛"**，用极顺之德压住烈性；③ **高光一定会西斜**（九三"日昃之离"），**提前接受它，才不至于晚年只剩悲叹**；④ **到顶时只除首恶、绝不扩大**（上九"获匪其丑"）——这是全书少见的"上爻无咎"。 |

## 二、爻级字段

### 初九 · 履错然，敬之

| 字段 | 内容 |
|---|---|
| **爻辞** | 履错然，敬之，无咎。 |
| **象传** | 履错之敬，以辟咎也。 |
| **位属性** | 阳爻居阳位，**当位**；居明之初——**光刚亮起来** |
| **判词 → 行动语义** | 无咎 → **保持敬慎，别被刚亮的光晃了脚** |
| **关键词解** | **履错然**＝步履交错杂乱。刚开始发光，事情多、机会多、脚步乱。**敬之**＝对此保持敬慎。**辟咎**＝"辟"通避——**敬慎是用来"避"灾的，不是用来求吉的**。 |
| **⚠️ 本爻的要点** | 象传只承诺"**以辟咎也**"——**敬慎只能免灾，不能带来好处**。这与本库判词表口径一致：**无咎 ≠ 吉利**。刚被看见的时候，你能拿到的最好结果就是"没出事"。 |
| **识别信号** | ① 你刚开始被注意到、被邀请、被推荐；② 机会一下多起来，节奏乱了；③ 你开始同时答应好几件事。 |
| **该做** | **把步子放慢、把承诺收紧。** 只答应做得到的；对每一个新来的机会都先敬慎再判断。 |
| **不该做** | 把"刚被看见"当成"已经成了"。**初九当位、有明德，但错在脚乱**——这一爻的风险全部来自自己的节奏。 |
| **与乾初九、履卦的对照** | 乾初九"潜龙勿用"是**还没被看见时的蓄力**；**离初九是已经被看见了、但光还很小**，所以不是"勿用"，是"敬之"。而**履卦（上乾下兑）讲的是在强者旁边怎么走**，离初九讲的是**自己脚下怎么走**——一个是外部危险，一个是自身失序。 |

### 六二 · 黄离，元吉（下离卦主，全卦最吉之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 黄离，元吉。 |
| **象传** | 黄离元吉，得中道也。 |
| **位属性** | 阴爻居阴位，**当位且得中**；**下离唯一阴爻**——下卦卦主，即彖传"柔丽乎中正"所指之爻；**且乘于初九之上，是乘刚**——柔中之吉是"顶着压力"得来的。 |
| **判词 → 行动语义** | **元吉** → **附着于中道，光明得其正位** |
| **关键词解** | **黄**＝五色之中，**中央之色**（五行土居中），在《周易》里是"中"的符号（对比坤六五"黄裳元吉"）。**黄离**＝**附着于中道的光明**。 |
| **⚠️ 这是全书极少的"元吉"之一，但附加条件写得极清楚** | 按本库判词表：**元吉＝成·根本性圆满，但必须满足附加条件**。此处的条件象传只给了四个字：**"得中道也"**。**不是因为你光大，是因为你居中不偏。** 光大而不中，就是九四的"焚如、死如、弃如"。 |
| **与坤六五"黄裳元吉"的对照（重要）** | 两处都是"黄"＋"元吉"，都在讲"中"，但位置不同：**坤六五是居尊位者以臣自处**（有其权而守其节）；**离六二是有光明者以中自守**（有其明而不炫）。**本库"元吉必有附加条件"的口径，在这两爻上完全一致。** |
| **识别信号** | ① 你的专业能力／名声已经立住了；② 你处在"干事的核心与基层枢纽"位置（本库通则：二爻）；③ 你没有偏向任何一极，说话做事都在中间。 |
| **该做** | **守住"中"**。不站极端、不做最响的那个、不为了关注度偏移。**这一爻的全部价值就在"不偏"。** |
| **不该做** | 用已经立住的光去博更大的关注。**离卦的"元吉"只在中位上成立，一偏即失。** |
| **与需卦、师卦二爻的呼应** | 需九二"需于沙"是**险前的慎**；师九二"在师中吉"是**险中的统**；**离六二"黄离"是明中的中**。三个二爻共同印证本库通则"**二多誉**"——但誉的来源都是"得中"，不是"能力大"。 |

### 九三 · 日昃之离

| 字段 | 内容 |
|---|---|
| **爻辞** | 日昃之离，不鼓缶而歌，则大耋之嗟，凶。 |
| **象传** | 日昃之离，何可久也。 |
| **位属性** | 阳爻居阳位，**当位**；居下离之顶——**日已西斜**；本库通则"**三多凶**" |
| **判词 → 行动语义** | **凶（有条件的凶）** → **接受高光已过、安然自处；不接受则凶** |
| **关键词解** | **日昃**＝太阳西斜（过了正午）。**鼓缶而歌**＝敲着瓦罐唱歌，**极朴素的自得其乐**。**大耋**＝高龄（八十曰耋）。**嗟**＝叹息。全句：**光明已经西斜，此时若不能敲着瓦罐自在地唱歌，就只剩老人的悲叹，凶。** |
| **⚠️ 本爻是全卦最扎人的一条** | 象传"**何可久也**"——**没有任何光明可以长久**。而爻辞给出的解药竟然是**"鼓缶而歌"**：不是再拼一次，不是转型，是**用最朴素的方式安然接受**。**凶与不凶，全在你能不能"歌"。** |
| **本爻的因果结构（要点）** | 爻辞把两条路并列写出：**鼓缶而歌 → 不凶；大耋之嗟 → 凶。** 这一爻的"凶"**不是命定的，是选出来的**——**高光过去本身不凶，不接受它才凶。** |
| **识别信号** | ① 你最好的阶段已经过去，你自己知道；② 你还在用巅峰期的标准要求现在；③ 你开始频繁提"当年"，或者对新起来的人有情绪。 |
| **该做** | **主动降规格、过朴素日子、自己找乐**（鼓缶而歌）；把"继明"的任务交出去（大象传"继明"——光要接得上，但不一定由你亮）。 |
| **不该做** | 硬撑巅峰、和后来者较劲、把"日昃"解释成暂时低谷。 |
| **与乾九三、乾上九的三角对照（重要）** | **乾九三**"终日乾乾夕惕若，厉，无咎"——**上升期的抉择点，惕则无咎**；**乾上九**"亢龙有悔"——**盈极不知止，唯一纯凶**；**离九三是第三种**：**没有盈极，只是自然西斜**。乾上九的解药是"止"，**离九三的解药是"歌"**——**一个是收手，一个是认命而自适。** |

### 九四 · 突如其来如

| 字段 | 内容 |
|---|---|
| **爻辞** | 突如其来如，焚如，死如，弃如。 |
| **象传** | 突如其来如，无所容也。 |
| **位属性** | 阳爻居阴位，**不当位**；刚入上离——**两重火的交接处，全卦最烈之点**；本库通则"**四多惧**" |
| **判词 → 行动语义** | **无判词，但四个"如"字就是判词** → **此爻不可入** |
| **关键词解** | 四个"如"是连续的意象：**突如其来如**（突然爆发而来）→ **焚如**（烧起来）→ **死如**（烧死）→ **弃如**（被抛弃）。**从爆发到被弃，一气写完，中间没有任何转机。** |
| **⚠️ 本爻是全书最恐怖的爻辞之一** | 象传"**无所容也**"——**没有容身之处**。为什么？因为**火本要"丽"（附着）才能燃，而九四不当位、又处两火交接**：**它附不住任何东西，只能纯烧**。**烧完就没了，这就是"无所容"。** |
| **触发条件** | ① 阳刚居阴位＝**名不正言不顺却居高位发光**；② 处于新旧两重光明的交界——**上一段的光还没落，你的光已经猛地起来**。**这两条凑在一起，就是"突如其来"。** |
| **识别信号（诊断清单）** | ① 你以极快的速度爆红／爆火／被推到台前；② 你的位置名不正（资历、授权、资格有一样不足）；③ 你上面还有一个正在发光的人，或一段还没结束的旧秩序。 |
| **该做** | **立刻降温、找附着。** 把爆发出来的光挂回到一个正当的载体上——组织、师承、授权、规矩，任何一个都行。**核心是给自己找到"丽"（附着物），因为纯烧必尽。** |
| **不该做** | 趁势再加火。**这一爻里"势"就是燃料，加势等于加柴。** |
| **与乾九四、坎六三的对照** | **乾九四**"或跃在渊，无咎"——**不当位不得中，但仍有唯一通路，跃则无咎**；**坎六三**"勿用，终无功"——**无路，但停手可保命**；**离九四"焚如死如弃如"——不当位、不得中、且处最烈处，连"停"都来不及**。本库三大险爻里，**离九四是唯一没有给出爻内解药的**：解药只能在爻外——**不要用这种方式亮起来。** |

### 六五 · 出涕沱若（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 出涕沱若，戚嗟若，吉。 |
| **象传** | 六五之吉，离王公也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位；**上离唯一阴爻**——全卦卦主；**且乘于九四之上，是乘刚**——这正是"出涕沱若"的结构由来。 |
| **判词 → 行动语义** | **吉** → **居尊位而知忧惧、能哭得出来，是吉** |
| **关键词解** | **出涕沱若**＝眼泪滂沱而下（"沱"是水盛之貌，"若"是语尾助词）。**戚嗟若**＝忧伤叹息。**然后判词是"吉"。** |
| **⚠️ 本爻是全卦、乃至全书最反直觉的一爻** | **一个居尊位的人在痛哭忧叹，判词却是"吉"。** 为什么？象传给的理由是"**离王公也**"——他附丽于王公之正位。**结合九四刚刚"焚如死如弃如"来读就通了：紧接大火之后居尊位，还能哭得出来、还知道怕，说明他没有被权位和光明烧掉知觉。** **在离卦里，能忧惧就是最大的吉。** |
| **本库"六五／九五"专题的第四例（重要）** | 本库通则已有三例：**乾九五**（居尊而利见大人）、**坤六五**（有君之权而守臣节）、**蒙六五**（居尊而不失赤子之心）。**离六五补上第四种，也是最锋利的一种：居尊而痛哭。** 四者指向完全同一件事——**居尊位者必须保留一样"往下"的东西**：乾是求贤，坤是守节，蒙是童心，**离是眼泪**。 |
| **识别信号** | ① 你在高位、在高光中；② 你刚经历（或正看着）一场惨烈的燃烧（九四）；③ 你感到害怕、难受、想哭，并且怀疑这是不是软弱。 |
| **该做** | **允许自己怕、允许自己哭。** 把这份忧惧当成决策输入，不当成缺陷。**同时守住"得中"——不当位靠得中救**（本库通则）。 |
| **不该做** | 用"我在这个位置上不能示弱"把忧惧压掉。**压掉忧惧，就从六五掉回九四。** |

### 上九 · 王用出征

| 字段 | 内容 |
|---|---|
| **爻辞** | 王用出征，有嘉折首，获匪其丑，无咎。 |
| **象传** | 王用出征，以正邦也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终——**但判词是"无咎"** |
| **判词 → 行动语义** | 无咎 → **用明察只除首恶，绝不扩大打击面** |
| **关键词解** | **有嘉**＝有可嘉之功。**折首**＝斩其首恶（"首"是为首者）。**获匪其丑**——**"丑"是类、众、党羽，"匪"通非**：**俘获的不是他的那些从众**。全句：**出征只斩为首的，不牵连跟从的众人。** |
| **⚠️ 本爻是"上爻"里罕见的善终，原因写得很明确** | 本库通则说：**乾上九、坤上六是各自全卦唯一的纯凶之爻，皆因盈极不知止**；坎上六亦凶（三岁不得）。**离上九却是"无咎"**——理由是象传的"**以正邦也**"：**他到顶之后做的事不是为自己扩张，是为国家立正。** 而且手段极其克制：**只折首，不获丑。** |
| **为什么"离"卦到顶反而无咎（本卦的收束）** | 离是光明、是明察。**光明到了极处，其正当用法是"看清楚谁该负责"，而不是"照亮所有人来审"。** 上九不当位，本该有咎；**是"折首而不获丑"这个动作把它救了下来。** |
| **识别信号** | ① 你的影响力／权威已到顶点；② 出了大事，需要有人负责；③ 你手里有足够的力量把打击面扩到很大。 |
| **该做** | **精准问责：只处理为首者，明确不追究跟从者。** 对外把边界说清楚（"获匪其丑"要让所有人看见）。 |
| **不该做** | 借势清算、扩大范围、连坐。**扩大打击面 → 你就从"以正邦"变成"焚如"，掉回九四。** |
| **与师上六的呼应（同一件事的两半）** | 师上六"大君有命，开国承家，**小人勿用**"——**战后赏，但择人**；**离上九"有嘉折首，获匪其丑"——战后罚，但限人。** **两爻合起来是完整的收尾原则：赏要公而择人，罚要准而限人。** |

## 三、离卦定位速查表

| 爻 | 处境 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | 刚被看见 | 履错然 | 机会一下变多，节奏乱了 | **当位** | **无咎**·敬慎·只能辟咎 |
| 六二 | 立住了（**下卦主**） | 黄离 | 能力名声已立，且不偏不倚 | **当位·得中** | **元吉**（条件：得中道） |
| 九三 | 高光已过 | 日昃之离 | 最好的阶段过去了，你自己知道 | 当位·三多凶 | **歌则安，嗟则凶** |
| 九四 | 暴烈爆发 | 焚如死如弃如 | 爆红但名不正，且旧秩序未落 | **不当位**·两火之交 | **无所容**·不可入·必须找附着 |
| 六五 | 居尊在高光（**卦主**） | 出涕沱若 | 在高位，且怕得想哭 | 不当位但**得中居尊** | **吉**·忧惧即是吉 |
| 上九 | 到顶问责 | 王用出征 | 影响力到顶，出事要有人负责 | 不当位 | **无咎**·只折首·不获丑 |

**离卦三句话**：
1. **光不是你自己的，是附在别的东西上的**（丽）——所以第一件事是看清你附着于什么，且必须附于"中正"（六二）。
2. **火会烧掉附着它的人**：附错了、烧太快、名不正，就是"焚如死如弃如"（九四）。**发光期唯一的解药是"畜牝牛"——养一份笨、慢、顺、能承载的东西在身上。**
3. **光一定会西斜**（九三）。**能敲着瓦罐唱歌，就不凶；居尊位还哭得出来，就是吉**（六五）。

**本卦最反直觉的三条**：
- **六五在痛哭，判词是"吉"。** 在离卦里，**保住忧惧的能力就是保住命**——因为它证明你没被自己的光烧掉知觉。
- **九三的凶不是命定的，是选出来的。** 高光过去本身不凶，**不接受它才凶**。
- **上九到顶却"无咎"，是八纯卦里少见的善终。** 原因只有一条：**到顶后做的事是"正邦"，不是扩张；是"折首"，不是"获丑"。**

## 四、⚠️ 本卡对全库的意义：离在上／在下结构律（与坎完全相反）

坎的三爻由下而上是**阴、阳、阴**，离的三爻由下而上是**阳、阴、阳**——两者互为错卦，因此**当位规律也完全相反**：

| | 占初、二、三位（下卦） | 占四、五、上位（上卦） |
|---|---|---|
| **坎**（阴阳阴） | **三爻全部不当位** | **三爻全部当位** |
| **离**（阳阴阳） | **三爻全部当位** | **三爻全部不当位** |

**离卦本身正是这条律的完整演示**：初九、六二、九三全当位（无咎 → **元吉** → 有解药的凶）；九四、六五、上九全不当位（**焚如死如弃如** → 靠得中救回的吉 → 靠正确动作救回的无咎）。

**结论（可直接用于第三步"定势"）**：
> **离在下卦 → 明德在内、名正言顺**，这份光是你自己长出来的，稳。
> **离在上卦 → 光明在外、名不正言不顺**，这份光是位置／舞台给你的，**全靠"得中"和"做对动作"来救**。
> 与坎律合起来记：**坎在下是"你已在险中"，离在上是"光在你身外"——这两种情形都全爻不当位，都最危险。**
