# 知识卡 31 · 咸卦（泽山咸）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传（下篇开篇）："有天地然后有万物，有万物然后有男女，有男女然后有夫妇，有夫妇然后有父子，有父子然后有君臣，有君臣然后有上下，有上下然后礼义有所错。夫妇之道不可以不久也，故受之以恒。"——**咸是《周易》下经之首**。序卦传下篇不从上一卦（离 30）接续，而是**重起一条谱系：天地 → 万物 → 男女 → 夫妇**；"夫妇"之位即咸卦，然后才转入恒卦。⚠️ 注意：**此段序卦传原文中并未直接出现"咸"字**（咸以"夫妇"隐指），下一句才明写"故受之以恒"。
> **本卦与恒卦（32）是一对，且是结构上的倒转（覆卦）**：咸卦六爻自下往上为"阴阴阳阳阳阴"，整卦上下颠倒即得恒卦。**咸讲关系如何建立（感应），恒讲关系如何维持（恒久）。两卦必须合读。**
> ⚠️ **本卡最有价值的部分**：**咸卦六爻是一条完整的人体上行序列——拇 → 腓 → 股 →（九四：心）→ 脢 → 辅颊舌**，与艮卦（52）的**趾 → 腓 → 限 → 身 → 辅 → 敦**构成本库唯一的一组"同构身体序列"。**逐位对照见第四节，那是本卡的核心增量。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 咸 · 第三十一卦 · **下经之首** |
| **卦象** | 上兑（泽/悦）下艮（山/止），称"泽山咸"。**山在下而泽在上**——山是实的、止的，其上却有一池水。<br>按本库第 4 节结构律，本卦是**"艮在下 ＋ 兑在上"的叠加**：<br>**艮在下 → 初六不当位、六二当位得中、九三当位**（艮在下＝止在内，自己收手）；<br>**兑在上 → 九四不当位、九五当位得中、上六当位**（兑在上＝悦在外，位较正）。<br>⚠️ **这两条结构律在本卦被彖传原文直接确认了四个字："止而说"**——先艮之止，后兑之悦。这是本库结构律第一次拿到经文级的背书。 |
| **领域定义** | **关系与信任如何被建立**（不是维持，维持归恒卦）。双向选择的场合：相亲与恋爱初期、面试与被面试、拿下一个不能强推的客户、新团队破冰、去说服一个不受你管的人、想让某个重要的人主动愿意配合你、争取一次合作但对方还没有理由答应你。凡是"**我需要对方真心愿意，而我不能强迫，也不能只靠讲道理**"，都落在咸卦。 |
| **不归本卦的情况** | ① 关系已经建立，问题是怎么让它久 → **恒卦（32）**；② 日常的团队氛围与愉悦沟通本身 → **兑卦（58）**；③ 要选择跟谁站在一起、择主结盟 → **比卦（8）**；④ 要用柔顺一点点渗透去改变一个人 → **巽卦（57）**。**咸卦特指"从零到有感应"这一段，而且是双向的。** |
| **"咸"字本义** | **咸＝感**（彖传第一句就定死："咸，感也"）。"咸"字本义是"皆、都、全"，在本卦取其**"两方同时"**之义：**不是我感动你，也不是你感动我，是"二气感应以相与"（彖传）——双向同时发生。**<br>**这是咸卦与巽卦（渗透）、兑卦（悦人）最根本的分界：巽兑是单向动作，咸是双向状态。** |
| **卦辞原文** | 咸：亨，利贞，取女吉。 |
| **⚠️ 卦辞的关键结构** | **有"亨"、有"利贞"、有一个具体事项的吉断（取女吉），唯独无"元"。**<br>**缺"元"的意义**：按本库口径，"元"＝敢于启动、去做去拼（善之长）。**咸卦不给"元"——因为感应不是你能"启动"的东西。** 你能做的只有"亨"（让路通）与"利贞"（走正道），**启动权不在你手上，在双方之间。**<br>**多了什么**：多了"取女吉"这个**具体事项的吉断**，这在六十四卦卦辞里很少见。它是《周易》给"感应成立"提供的验证场景——**双向自愿的结合**。（本库按"关系建立"读，不作性别或婚俗上的规范主张。） |
| **卦辞现代解** | **亨**——这条路是通的，感应是真实可行的机制，不是玄谈。<br>**利贞**——但必须走正道：**感而不正，"亨"立刻作废**（与兑卦"亨，利贞"同构）。<br>**取女吉**——落到最具体的场景：**当双向自愿真的成立，结果是吉。** 反过来说：**凡是需要单方面用力才能维持的"感应"，都不在这一卦的许诺范围内。** |
| **彖传** | 咸，感也。柔上而刚下，二气感应以相与。止而说，男下女，是以亨利贞，取女吉也。天地感而万物化生，圣人感人心而天下和平。观其所感，而天地万物之情可见矣。 |
| **⚠️ 彖传要点（本卦全部机制都在这三句里）** | ① **"柔上而刚下"**——柔（兑）在上，刚（艮）在下。**这句话与恒卦彖传"刚上而柔下"正好互为镜像**（详见第四节）。<br>② **"止而说，男下女"（本卦最实用的六个字）**——**下艮止、上兑悦：自己先止住，对方才会愉悦。** 而"男下女"＝少男（艮）居于少女（兑）之下，**即强的一方主动把位置放低。**<br>**结论：建立感应的三个动作是——① 止（不主动进逼）；② 下（把位置放低）；③ 让对方悦。** 顺序不可颠倒：**没有"止"和"下"，"悦"就变成兑六三的"来兑，凶"（讨好）。**<br>③ **"观其所感，而天地万物之情可见矣"**——看一个人被什么打动，就能看见他的实情。**这一句可以直接当诊断工具用：判断一个人（包括自己），不看他说什么，看他对什么有感应。** |
| **大象传（行动纲领）** | 山上有泽，咸。君子以虚受人。 |
| **⚠️ "虚受人"解（本卦最高层原则）** | 山是实的，泽是虚的、是水；**山能承住一池水，是因为山上有一个凹处**。<br>**"虚受人"＝先把自己心里腾空，才装得下别人。**<br>**这是咸卦对"感应"给出的唯一前置条件，也是全卦六爻问题的总病根**：<br>**六二先动（不虚，急）｜九三随人（不虚，被填满了别人的节奏）｜九四憧憧（不虚，塞满了自己的推测）｜九五感在脢（不虚，麻木）｜上六滕口说（不虚，塞满了自己的话）。**<br>**六爻里有五爻都是"没腾空"的不同形态。** |
| **总铁律** | ① **感应的前置条件是"虚受人"**——先腾空，再谈感（大象传）；② **机制是"止而说，男下女"**——先止、先放低，对方才悦（彖传）；③ **"利贞"是硬约束**——感而不正，卦辞的"亨"作废；④ **感得越低越实，越高越虚**：止在拇上尚可，升到辅颊舌就只剩"滕口说"（初六 ↔ 上六）；⑤ **六二"凶，居吉"是全卦最短的一条禁令**——**动则凶，不动则吉**；⑥ **位置最好的九五只得"无悔"**——在咸卦里，位正当保不住任何东西，能不能"感"才算数。 |

## 二、爻级字段

> ⚠️ **本卦六爻是一条自下而上的人体序列**：**拇（大脚趾）→ 腓（小腿）→ 股（大腿）→［九四＝心］→ 脢（背脊肉，古注定为"心之上、口之下"）→ 辅颊舌（口）**。
> **"感在哪个部位"＝"感应停在哪个层次"。** 六爻中**唯一不写身体部位的是九四**——因为感的器官本身就是心，无法"咸其心"，所以爻辞直接写心的状态："憧憧往来"。**而九五"脢"的古注定位（心之上、口之下）反过来把九四钉死在"心"这一层。**

### 初六 · 咸其拇

| 字段 | 内容 |
|---|---|
| **爻辞** | 咸其拇。 |
| **象传** | 咸其拇，志在外也。 |
| **位属性** | 阴爻居阳位，**不当位**；居全卦最下（艮在下 → 初不当位）；与九四相应 |
| **判词 → 行动语义** | **无判词，仅象传给出一个心理状态** → **《周易》承认你已经动心了，但既不判你有咎，也不授权你行动** |
| **关键词解** | **拇**＝大脚趾（**与艮初六的"趾"是同一部位**）。**志在外**＝心志已经向外去了（向上应的九四）。**全爻只有三个字，没有任何动作，也没有任何判词。** |
| **⚠️ 本爻的全部信息量就在"没有判词"这件事上** | 按本库判词表最下面那一档：**"无判词 ＋ 只给心理状态"＝《周易》承认你的难受（或心动），但不判你有咎，也不授权你越位。**<br>**咸初六正是这一档最干净的样本**：感应刚起，动作还只到大脚趾这个最前端、最微小的部位，**心却已经跑到外面去了。** 爻辞对此不奖不罚，只如实记录。 |
| **识别信号** | ① 你对某个人／某个机会刚有了"想接近"的念头；② 你还没有任何实际动作，但注意力已经过去了；③ 你很想马上让对方知道，或者做一个"小小的试探"。 |
| **该做** | **承认"志在外"，同时把动作停在拇上。** 感应尚在最初，**此时不需要任何表示**——大象传的"虚受人"在这一爻的形态就是：**先让这份心动待着，不去处理它。** |
| **不该做** | 把"动心"当成"该行动"。**在咸卦里，动心与该动是两件事，本爻把它们之间那道缝写得很清楚。** |
| **⚠️ 与艮初六的对照（身体序列第一位）** | **艮初六"艮其趾，无咎，利永贞"，象传"未失正也"**——**同一个部位、同一个爻位、同样不当位**，艮卦判"无咎＋利永贞"，理由是**"它止得足够早"（止的代价与止的时机成反比）**。<br>**咸初六却什么判词都没有。**<br>**差别在卦德**：**艮在这个位置要你"别动"，所以早止有功（无咎）；咸在这个位置只是"起了感应"，还谈不上功过，所以不判。**<br>**合读结论：同一个脚趾，止之则无咎，感之则只是"志在外"。** |
| **与乾初九、大壮初九的三角对照** | **乾初九"潜龙勿用"——蓄力型不动（有明确指令）**；**大壮初九"壮于趾，征凶"——力量刚起就用在最前端，凶**；**咸初六"咸其拇"——只有心动，无指令无判词。** 三卦的初爻都落在"最下、最前端"，**一个是攒、一个是禁、一个是不置评。** |

### 六二 · 咸其腓（⚠️ 全卦唯一的"凶"，也是全卦最短的禁令）

| 字段 | 内容 |
|---|---|
| **爻辞** | 咸其腓，凶，居吉。 |
| **象传** | 虽凶居吉，顺不害也。 |
| **位属性** | 阴爻居阴位，**当位且得中**（艮在下 → 二当位）；与九五相应——**条件是全卦最好的一批** |
| **判词 → 行动语义** | **凶 ＋ 居吉（同一爻内两个相反的断语）** → **动则凶，不动则吉** |
| **关键词解** | **腓**＝小腿，**走路的主要发力处**（与艮六二的"腓"是同一部位）。**居**＝安居、待在原处不动。**顺**＝顺其位、顺其时，不躁动。 |
| **⚠️ 本爻是全卦唯一的"凶"，而"凶"只落在一个字上** | **爻辞把凶与吉写在同一句里，中间只隔一个"居"字。**<br>象传把理由压缩成三个字：**"顺不害也"**——**顺着待下去就不受害。**<br>**结论：这一爻的凶不来自对象、不来自条件、不来自位置（它当位、得中、有应，条件极好）。凶只来自"你自己先迈了腿"。**<br>**这是全库最干净的一条"动即凶"**：腓一动就是走，走就是主动去追；**而咸卦的机制是"止而说"（彖传）——你一追，"止"就没了，感应的地基就塌了。** |
| **识别信号（诊断清单）** | ① 你已经有明确的感应对象，而且对方是有回应的（六二↔九五有应）；② 你的条件其实不差，位置也正当；③ 你正准备迈出主动的一步——发一条消息、上一次门、表一次白、追一次报价、递一次方案；④ 你的理由是"总得有人先动"。 |
| **该做** | **居。** 原地不动，让感应自己走完剩下的路。**象传给的理由只有一个字："顺"。**<br>操作化：**把"我该做什么"换成"我该不做什么"**——不加频次、不加力度、不追进度。 |
| **不该做** | 主动发力去追。**注意："凶"落在"咸其腓"（动）上，不落在感应本身。** 也不要反过来把"居"理解成冷淡或博弈——**"居"是不动，不是撤回。** |
| **⚠️ 与艮六二的逐位对照（本卡最重要的一组，必须合读）** | | 

| 对照项 | **艮六二** | **咸六二** |
|---|---|---|
| 爻辞 | 艮其**腓**，不拯其随，其心不快 | 咸其**腓**，凶，居吉 |
| 部位 | 腓（小腿） | 腓（小腿） |
| 位属性 | **当位·得中** | **当位·得中** |
| 判词 | **无判词**，只给心理状态 | **凶 ／ 居吉** |
| 象传 | **未退听也**（上面那个人不肯退让、不听劝） | **顺不害也**（顺着待下去就不受害） |
| 病根 | **在别人身上**——你止住了自己，救不了你跟随的人 | **在自己身上**——你自己先动了 |
| 解药 | 止住自己，接受"心不快"，不越位 | **居**（不动） |

| 字段 | 内容 |
|---|---|
| **⚠️ 这一组对照的结论** | **同一个"腓"、同一个爻位、同样当位得中，两卦的病完全相反：艮六二的困难来自外部（未退听），咸六二的凶来自内部（先动）。**<br>**但两爻的解药是同一个动作——不动。** 艮六二的不动叫"止住自己"，咸六二的不动叫"居"。<br>**可入库为通则：二爻当位得中，条件最好，因此它的风险从不来自条件不足，只来自"忍不住"。** |

### 九三 · 咸其股

| 字段 | 内容 |
|---|---|
| **爻辞** | 咸其股，执其随，往吝。 |
| **象传** | 咸其股，亦不处也。志在随人，所执下也。 |
| **位属性** | 阳爻居阳位，**当位**（艮在下 → 三当位）；居下艮之顶；**是下卦唯一的阳爻**——本该是"止"的力量所在；本库通则"**三多凶**"；与上六相应 |
| **判词 → 行动语义** | **往吝**（按本库口径：**路越走越窄，趋势极差**） → **停止"跟着别人走"这个动作** |
| **关键词解** | **股**＝大腿（在腓之上，本该是**带动**小腿的部位）。**执**＝执守、抓住不放。**随**＝随从、跟着走（一说指它下面的初六、六二，即"它所跟随的那些人／那些低层次的东西"）。**处**＝安处、留在原地。 |
| **⚠️ 象传的两句话是本爻全部的重量** | ① **"亦不处也"**——**它"也"不肯安处**。这个"亦"字极重：**六二已经动了（咸其腓），九三跟着一起动。** 本该带动腿的股，反而被腿带着走。<br>② **"志在随人，所执下也"**——**心志在于跟随别人，而它执守的是"下面"（低层次的东西）。**<br>**结论：九三是全卦唯一有"止"的力量的爻（下艮的那个阳），它却把这份刚用来跟随。这就是"往吝"——不是它做错了某一件事，是它的方向从根上是"随"。** |
| **识别信号（诊断清单）** | ① 在这段关系／这件事里，你其实是有主导能力的（有资源、有判断、位置也正当）；② 但你的节奏完全由对方决定——对方动你就动，对方冷你就慌；③ 你抓住不放的是一些低层次的东西：即时回应、面子、对方的认可、一点小便宜；④ 你已经这样走了一段时间，且感觉余地在变小。 |
| **该做** | **"处"**——象传把病写成"不处"，那么药就是"处"：**停在自己的位置上，按自己的判断走。** 把执守的对象从"下"（别人的反应）换成自己的方向。 |
| **不该做** | 继续跟。**"吝"是趋势判词，它不说你现在有多糟，它说你正在走窄。** 也不要反向过度——从"随人"跳到"逼人"，那是六二的"凶"。 |
| **⚠️ 与巽九三、恒九三的三方对照（"当位而吝"的三例）** | **巽九三"频巽，吝"，象传"志穷也"**——当位之刚却一再退让，退到心志困穷；<br>**恒九三"不恒其德，或承之羞，贞吝"，象传"无所容也"**——当位之刚而德不能持续，落到无处容身；<br>**咸九三"咸其股，执其随，往吝"，象传"所执下也"**——当位之刚而志在随人，执守的都是低的东西。<br>**三个九三，全部当位（阳居阳位），全部判"吝"，象传全部指向"穷／无所容／下"。**<br>**共同病根：当位之才用错了自己的刚。** 巽用刚去退让，恒的刚接不上，咸的刚拿去跟随。<br>⚠️ 说明：这是**三例同构**，本库尚不足以断为通则（其他"巽在下"诸卦的九三判词并不一致），**但三例已足以作为诊断线索：当位而心里发虚，先查是不是"把刚用在了不该用的方向"。** |
| **与艮九三的对照（身体序列第三位）** | **艮九三"艮其限，列其夤，厉"**——止在腰（限）上，把上下身硬生生截断，撕裂脊背。<br>**咸九三"咸其股…往吝"**——感在大腿上，跟着腿一起动。<br>**两爻的部位相邻（股在限之下），判词一"厉"一"吝"**：**艮九三是"决定对了但切口错了"，咸九三是"方向从根上错了"。**<br>⚠️ **按本库吉凶序（…悔 ＞ 吝 ＞ 厉 ＞ 凶）厉在吝之后，即厉重于吝**——本卡此处原写作"吝更靠后、更差"，方向写反了，已更正。<br>⚠️ **但索引对两者的释义是"厉＝警告，非判死"与"吝＝路越走越窄，趋势极差"：一个度量当下危险度，一个度量趋势，不是同一个维度**，故不宜据此判定"跟错方向"与"用错方法"哪个更难挽回。**可确定的只是：艮九三给的是急性警告，咸九三给的是趋势恶化。** |

### 上六 · 咸其辅、颊、舌

| 字段 | 内容 |

| **⚠️ 与艮六五"艮其辅"的对照（身体序列第五、六位，本组最有价值的一段）** | **艮六五"艮其辅，言有序，悔亡"，象传"以中正也"**——**管住嘴，说话有次序，把本该有的悔消掉了。**<br>**咸上六"咸其辅、颊、舌"，象传"滕口说也"**——**不但没管住，还把辅、颊、舌三样器官全用上了，结果只有"嘴上说说"。**<br>**同一个"辅"字：艮卦止住它得"悔亡"，咸卦感到它得"滕口说"。**<br>**而且咸上六比艮六五多用了两个器官（颊、舌）——器官越多，内容越少。** 这是《周易》一处极冷的笔法。 |
| **⚠️ 本爻是"感应到顶"的形态（与艮上九的正面对照）** | **艮上九"敦艮，吉"，象传"以厚终也"**——**止到极处，是卦德的圆满完成，是八纯卦六个上爻里唯一的"吉"。**<br>**咸上六"辅颊舌，滕口说"**——**感到极处，是卦德的空转。**<br>**为什么一个能圆满、一个只能空转？**<br>**因为"止"可以做厚（敦＝厚、笃实），"感"不能靠嘴做厚。** 感应沿身体一路上行，到了最高、最外、最轻的器官（口舌），**能做的只剩"说"**——而说不构成感。<br>**这正好呼应兑卦大象传"丽泽"（两泽互相润泽）的判据：单向输出不构成互相润泽，所以"未光"、所以"滕口说"。** |
| **识别信号（诊断清单）** | ① 这段关系／这件事你已经谈了很多轮、说了很多话；② 实际发生的进展很少，或者一直停在"下次再约"；③ 你对外的表述（发的动态、给别人的说法、写的方案）比内部的实情热闹得多；④ 你已经说不清双方现在共同在做什么。 |
| **该做** | **停止表述，回到两个动作**：**六二的"居"**（不再往前推）＋**大象传的"虚受人"**（把"说"换成"受"）。**给这段关系一个共同的内容，而不是一次新的表述**——这与兑上六"引兑"的解药（回到"朋友讲习"，给关系一个新的共同内容）完全同源。 |
| **不该做** | 再说一轮、再解释一次、再表一次态。**本爻既不凶也不吉，代价只有时间与信用——但信用是会被"滕口说"耗完的。** |
| **与兑上六"引兑"的呼应（同为上卦兑之终）** | **兑上六"引兑"，象传"未光也"**——悦到尽头，只能靠牵引延长；**咸上六"咸其辅颊舌"，象传"滕口说也"**——感到尽头，只能靠嘴。<br>**两爻都是"兑在上"的最上一爻，都无判词，都是"没有新内容了"。** 而两处的解药也一致：**给关系一个新的共同内容。** |

| **初六** | **拇**（大脚趾） | 刚动心，动作只到最前端 | **无判词** | 志在外也（心已向外，不奖不罚） |
| **六二** | **腓**（小腿） | 要迈步去追 | **凶 ／ 居吉** | 顺不害也（**动则凶，居则吉**） |
| **九三** | **股**（大腿） | 跟着对方的节奏走 | **往吝** | 亦不处也·所执下也（志在随人） |
| **九四** | **［心］**（不写部位） | 心里来回推演 | **贞吉·悔亡** | 未感害也 **／** 未光大也（**爻内分裂**） |
| **九五** | **脢**（背脊，心之上口之下） | 位最正却感不到 | **无悔** | 志末也（心只到末梢） |
| **上六** | **辅、颊、舌**（口） | 只剩嘴上说 | **无判词** | 滕口说也（**器官越多，内容越少**） |

### 全爻速查

| 爻 | 角色 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | 刚动心者 | 咸其拇 | 有了念头，还没动作 | 不当位·有应 | **无判词**·承认心动·停在拇上 |
| 六二 | 想主动者 | 咸其腓 | 条件很好，正想迈第一步 | **当位·得中·有应** | **凶／居吉**·唯一动作是"不动" |
| 九三 | 跟随者 | 咸其股 | 有主导力却跟着对方节奏 | 当位·三多凶 | **往吝**·停止"随"·回到"处" |
| 九四 | 摇荡的心 | 憧憧往来 | 反复推演对方在想什么 | 不当位·四多惧 | **贞吉悔亡／未光大**·做贞的一半，停憧的一半 |
| 九五 | 居尊者 | 咸其脢 | 位置最正，却说不出对方的实情 | **当位·得中·居尊** | **无悔**·虚受人·别满足于"不出错" |
| 上六 | 只会说的人 | 咸其辅颊舌 | 谈了很多，进展很少 | 当位·**乘刚** | **无判词·滕口说**·把"说"换成"受" |

**咸卦三句话**：
1. **感应的前置条件是"虚受人"**（大象传）——**先腾空，再谈感。** 六爻里有五爻的病都是"心里没腾空"的不同形态：急（六二）、被填满别人的节奏（九三）、塞满自己的推测（九四）、麻木（九五）、塞满自己的话（上六）。
2. **机制是"止而说，男下女"**（彖传）——**自己先止住、把位置放低，对方才会悦。** 三个动作顺序不可颠倒；少了"止"和"下"，"悦"就变成兑六三的"来兑，凶"（讨好）。
3. **感得越低越实，越高越虚。** 从拇到辅颊舌，位置一路上升，**内容一路变轻**：到九五"脢"只剩"无悔"，到上六"辅颊舌"只剩"滕口说"。

**本卦最反直觉的三条**：
- **六二当位、得中、有应，条件全卦最好，判词却是"凶"——而"凶"只落在一个动作上：迈腿。** 隔一个"居"字就是"吉"。**在咸卦里，最好的条件配上最自然的冲动，就是最差的结果。**
- **九五当位得中居尊，只得"无悔"，象传还判"志末也"。** 而**同一个"背"，在艮卦卦辞里（艮其背）是最高境界，在咸九五（咸其脢）是感不到。** **部位没有固定吉凶，卦德决定它的吉凶。**
- **九四同一爻里有两个方向的评价**：爻辞给"贞吉、悔亡"，象传对"憧憧往来"单判"未光大也"。**《周易》会把一个人做对的部分和白费的部分分开算账——所以你不必先解决焦虑再去做事。**

## 四、⚠️ 本卡对全库的意义

### 1. 咸／艮身体序列逐位对照（本卡最核心的增量）

《周易》里只有两卦通篇以人体部位自下而上组织六爻：**艮卦（52）与咸卦（31）**。两卦的下卦都是艮，序列起点都在脚，**但卦德相反（艮＝止，咸＝感），所以同一部位的判词几乎处处相反。**

| 位 | **艮 52（止）** | 判词 | **咸 31（感）** | 判词 | 同部位的分野 |
|---|---|---|---|---|---|
| **初** | 艮其**趾** | **无咎·利永贞**<br>（未失正也） | 咸其**拇** | **无判词**<br>（志在外也） | 同为大脚趾。**止得早＝零成本有功；感刚起＝不奖不罚** |
| **二** | 艮其**腓** | **无判词，其心不快**<br>（未退听也） | 咸其**腓** | **凶／居吉**<br>（顺不害也） | 同为小腿，同当位得中。**艮的病在外（别人不听）；咸的凶在内（自己先动）。解药同为"不动"** |
| **三** | 艮其**限**（腰） | **厉**<br>（危熏心也） | 咸其**股**（大腿） | **往吝**<br>（所执下也） | 部位相邻。**艮＝决定对了但切口错（厉＝急性警告）；咸＝方向从根上错（吝＝趋势恶化）。⚠️ 两者度量不同维度，不作排序** |
| **四** | 艮其**身**（整个人） | **无咎**<br>（止诸躬也） | **［心］**憧憧往来 | **贞吉·悔亡／未光大** | ⚠️ **两卦在此分道**：艮升级为"整个自己"（有解药：止诸躬）；咸落到"心"（无部位可写，因为心即感本身） |
| **五** | 艮其**辅**（嘴） | **悔亡**<br>（以中正也） | 咸其**脢**（背脊） | **无悔**<br>（志末也） | **艮管住嘴＝挽回；咸感在背＝感不到。艮卦辞"艮其背"是最高境界，咸"咸其脢"却只是不及格边缘** |
| **上** | **敦**艮（厚） | **吉**<br>（以厚终也） | 咸其**辅、颊、舌**（口） | **无判词**<br>（滕口说也） | ⚠️ **两卦的收尾完全相反**：艮离开身体、升到"厚"这个质量词，得吉；咸升到最外最轻的器官，只剩说 |

**三条从这张表读出来的结论（建议入库）**：

> **① 身体部位在《周易》里没有固定吉凶，吉凶由卦德决定。**
> 最硬的证据是"背"：**艮卦辞"艮其背，不获其身…无咎"是全卦最高境界**（止在自己看不见的地方＝不带自我表演地止）；**咸九五"咸其脢"（脢即背脊之肉）却只得"无悔"，并被判"志末也"。** 因为**艮要的是"不觉"，咸要的是"能觉"。**

> **② 两条序列各有一处"不写部位"的空缺，而空缺的位置正是各自卦德的极点。**
> **艮的空缺在上（"敦"是质量词，不是部位）——因为"止"可以做厚，所以卦德在最上一位圆满完成（吉）。**
> **咸的空缺在四（"心"无法被"咸"，因为心就是感本身）——因为感的器官就是心，所以卦德在中间那一位无处落笔（只能写状态：憧憧往来）。**
> **合读：一卦的空缺在哪儿，就说明这一卦的"底"在哪儿。**

> **③ 序列方向决定了两卦的结局相反。**
> **艮：越往上，止得越彻底（趾→身→辅→敦），所以上爻最好（吉）。**
> **咸：越往上，感得越虚（拇→腓→股→心→脢→口），所以上爻最轻（滕口说）。**
> **同一条人体阶梯，一卦向上是升华，一卦向上是空转。** 差别只在：**"止"是一个可以做到彻底的动作，"感"不是——感的深浅在关系里，不在你身上升多高。**

**顺带一条延伸**：**大壮初九"壮于趾，征凶"** 把这条脚趾对照扩到三卦——**同一个脚趾，止之则无咎（艮初六），感之则志在外（咸初六），壮之则征凶（大壮初九）。** 三卦的最下一爻用同一个部位，写出了三种完全不同的初始动作评价。

### 2. 咸／恒是一对倒转卦，且两卦彖传恰好互为镜像

**结构核对（机械可验）**：
- **咸**六爻自下往上：**阴 阴 阳 阳 阳 阴**
- 整卦上下颠倒：**阴 阳 阳 阳 阴 阴** ＝ **恒**（上震下巽）✓
- **两卦互为覆卦（倒转卦）**，这正是序卦传把它们排在一起的结构原因。

**而两卦彖传的第一句，恰好是一对反话**：

| | **咸 31** | **恒 32** |
|---|---|---|
| 彖传首句 | **柔上而刚下** | **刚上而柔下** |
| 结构 | 兑（柔）在上，艮（刚）在下 | 震（刚）在上，巽（柔）在下 |
| 机制 | **止而说，男下女**——强的一方主动放低 | **巽而动**——先顺后动，各归其位 |
| 卦德 | 感（建立） | 久（维持） |
| 一句话 | **建立关系靠"放低"** | **维持关系靠"归位"** |

> **合读结论（本组最有价值的一条对照，且完全出自两卦彖传原文）**：
> **《周易》把"关系"拆成了两个方向相反的动作——**
> **建立时，强者必须下来（柔上而刚下，男下女）；维持时，各自必须归位（刚上而柔下）。**
> **用建立的方式去维持（一直放低），就是恒九三"不恒其德…无所容也"；用维持的方式去建立（一上来就摆位置），就是咸卦根本进不了门。**

**另外一条结构事实**：**咸与恒都是"全应"卦**——三对应爻（初↔四、二↔五、三↔上）全部一阴一阳，无一失应。恒卦彖传直接写出来了："**刚柔皆应**"；咸卦彖传的说法是"**二气感应以相与**"。

> **这与八纯卦正好相反。** 艮卦彖传"**上下敌应，不相与也**"对全部八纯卦成立（纯卦上下相同，故每对应爻必然同性相斥，全卦无援）。
> **所以：八纯卦＝全卦无一援（只能靠自己）；咸恒＝全卦无一失应（讲的就是"相与"）。**
> **一个卦讲不讲"关系"，从应爻结构上就能看出来。**（对照本库已有的泰 11／否 12 也是全应卦——它们讲的是"通"与"不通"，同样是关系型的卦。）

### 3. ⚠️ 对规格第 3 节"未光"档的一条限定（建议补入索引）

**原档**：「无判词 ＋ 象传"未光也"｜**不在吉凶十级之内**：既不害人也不成事，代价只有时间与声望」。

**咸九四要求给它加一条限定**：

| 型 | 样本 | 爻辞 | 判词 | 象传 |
|---|---|---|---|---|
| **整爻未光**（原档不变） | 震 51 九四 | 震遂泥（三字） | **全无** | 未光**也** |
| **整爻未光**（原档不变） | 兑 58 上六 | 引兑（两字） | **全无** | 未光**也** |
| **爻内分裂**（新增） | **咸 31 九四** | 贞吉，悔亡。憧憧往来，朋从尔思 | **贞吉·悔亡** | 贞吉悔亡，**未感害也**／憧憧往来，**未光大也** |

> **限定条文**：**"未光"可以只针对爻中的一个具体动作，而不针对整爻。** 判断时先看象传是否把爻辞切开分判——**若切开了，就要分开算账。**
> **用字也有区别**：整爻未光型作"**未光也**"（三字），咸九四作"**未光大也**"（四字）。
> **实操价值**：这条限定把"未光"从一个整体判决改成了一个可定位的诊断——**它告诉你"哪一部分"在白费，而不是"你在白费"。** 咸九四的具体读法就是：**守正的动作照做（贞吉、悔亡是确定收益），心里那些来回推演停掉（未光大）。**

### 4. ⚠️ 新增结构事实：乘刚的第二个来源是兑

规格第 4 节现有条文：「**乘刚的来源＝震**。震把阳放在最下往上顶，所以震在下则六二必乘刚，震在上则六五必乘刚。**艮把阳放在最上往下压，其内部不制造乘刚。**」

**这条对震与艮的判断完全成立，但它没有覆盖兑。** 机械核对如下：

| 三画卦 | 自下往上 | 内部是否有"阴直压阳" | 结果 |
|---|---|---|---|
| **震** | **阳** 阴 阴 | 有（中阴压初阳） | **在下 → 六二乘刚；在上 → 六五乘刚** |
| **兑** | 阳 阳 **阴** | 有（**顶阴压中阳**） | **在下 → 六三乘刚；在上 → 上六乘刚** |
| **艮** | 阴 阴 **阳** | 无（阳在最顶，其上无爻可乘） | 内部不制造乘刚 ✓ |
| **巽** | **阴** 阳 阳 | 无（阴在最下，其下无阳） | 内部不制造乘刚 |

> **结论（建议补入规格第 4 节）**：**制造乘刚的三画卦有两个——震与兑。**
> **震制造的是"底部型乘刚"（六二／六五：阳在最下往上顶）；兑制造的是"顶部型乘刚"（六三／上六：阴在最上往下压着阳）。**
> **本卦的实例**：**咸上六直接压在九五之上——上六乘刚。** 而上六恰恰是全卦最空的一爻（"滕口说也"）。
> **回溯本库已有卡片**：**兑卦（58）本身即上兑下兑，故六三乘九二、上六乘九五，全卦有两处乘刚**——兑卡未记这一点。**而兑六三正是全卦唯一的"凶"（来兑），上六正是全卦唯一的"无判词"（引兑）。** 兑卦两个最差的爻，恰好就是它两个乘刚的爻。**这为兑卡"六三讨好陷阱"那条判断补了一层结构理由：六三不只是不当位，它还在乘刚。**
> **回溯履卦（10）**：履＝上乾下兑，**兑在下 → 六三乘九二**。而履六三正是全卦唯一的凶爻（"咥人，凶"）。**履卡已从"位不当"解释了这一爻，本条为它补上第二个结构原因。**

### 5. 咸卦在全库中补上的缺口

| 缺口 | 咸卦补的内容 |
|---|---|
| **兑卦（58）与艮卦（52）之间没有连接** | **咸＝上兑下艮**，是这两张纯卦卡的直接叠加。彖传"**止而说**"四个字把本库两条结构律（艮在下＝止在内自己收手；兑在上＝悦在外位较正）**第一次拿经文钉了下来**。 |
| **兑卡指出"来兑（讨好）是凶"，但没说"不讨好该怎么办"** | **咸卦彖传给了答案："止而说，男下女"——放低位置不等于讨好。** 差别是：**"男下女"是主动把位置放低（结构性的、一次性的）；"来兑"是持续单向输出好处（行为性的、无止境的）。** 两卦合读，本库对"如何让一个不受我管的人真心愿意"这个高频问题才算给全：**放低位置 → 自己先止 → 让对方悦 → 但绝不讨好、绝不追（咸六二"凶，居吉"）。** |
| **本库有"如何维持"（无）、"如何退出"（艮）、"如何在强者面前行走"（履），但没有"如何开始一段关系"** | **咸卦是本库第一张专讲"关系建立"的卡**，且它给出的方法与直觉完全相反：**主要动作是"不动"（六二"居吉"）与"腾空"（大象传"虚受人"）。** |
| **路由表缺一条高频困境** | **"我很想主动，但怕一动就毁了"**——这是咸六二的原文处境，也是本库现有各卦都答不了的一问。**咸六二给的答案短到不能再短：凶，居吉。** |

### 6. 本卡打开的下一步（优先建议）

> **首选：恒 32（上震下巽）**——**与本卦是倒转对，必须合读**（本批已同步产出）。
> 其次：**损 41（上艮下兑）**——它正是咸卦的**上下卦交换**（咸＝上兑下艮，损＝上艮下兑）。**咸是"艮在下＋兑在上"（自己先止，对方愉悦）；损是"兑在下＋艮在上"（自己愉悦，却被压住不许动）。** 两卦合读，可以把兑／艮这一对反卦在复合卦里的两种叠加方式一次读完。
> 第三：**中孚 61（上巽下兑）**——卦名即"孚"（诚信）。本库已有三处"孚"（需卦、坎卦、兑九二）与两处"孚"的警告（兑九五"孚于剥"、大壮初九"其孚穷也"），**中孚是这条线索的正卦，是本库"诚信"专题唯一缺失的一环。**
