# 知识卡 32 · 恒卦（雷风恒 · 亦作恆）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："夫妇之道不可以不久也，故受之以恒。恒者，久也。"——**咸卦讲"夫妇之道"如何建立（感应），而《周易》紧接着说：这条道"不可以不久"，所以必须有一卦专讲"久"。**
> **本卦与咸卦（31）是一对，且是结构上的倒转（覆卦）**：咸卦六爻自下往上"阴阴阳阳阳阴"，整卦上下颠倒即得恒卦"阴阳阳阳阴阴"。**咸讲关系如何建立，恒讲关系如何维持。两卦必须合读。**
> ⚠️ **两卦彖传的第一句恰好是一对反话**：**咸"柔上而刚下"（强者主动放低）／恒"刚上而柔下"（各归其位）。建立靠放低，维持靠归位。**（详见第四节）
> ⚠️ **本卦的六爻结构极值得注意**：**讲"久"的卦，六爻里有四爻在讲"久"的失败形态**（初六浚恒 · 九三不恒 · 九四久非其位 · 上六振恒），**只有九二一爻给出正解，六五给的是有条件的正解。**《周易》对"恒久"的态度，与它对战争（师卦）、对止（艮卦）一样吝啬。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 恒 · 第三十二卦（字亦作**恆**） |
| **卦象** | 上震（雷/动）下巽（风/顺入），称"雷风恒"。**雷与风相随而起、彼此助长**（彖传"雷风相与"）——**一动一顺，互为对方的条件，所以能持续。**<br>按本库第 4 节结构律，本卦是**"巽在下 ＋ 震在上"的叠加**：<br>**巽在下 → 初六不当位、九二不当位（得中）、九三当位**（巽在下＝柔在底下，最易犯犹豫与滥让）；<br>**震在上 → 九四不当位、六五不当位（得中居尊）、上六当位**（震在上＝动在头顶，自己做不了主）。<br>**⚠️ 六爻里有四爻不当位（初、二、四、五），是本组四卦中当位最差的一卦**——一个讲"恒久"的卦，结构上却极不稳定。<br>**⚠️ 乘刚**：按规格通则"震在上则六五必乘刚"——**本卦六五直压九四之上，六五乘刚，验证通过。** |
| **领域定义** | **已经开始的事与关系，如何让它久**。长期伴侣关系的维护、把一件事做十年、守住一个手艺或品牌、维持一支老团队、一个长期习惯（健身/写作/读书）、任期内保持政策一致、一段"看不到反馈但必须继续"的投入期、家族事业的守成。凡是"**这件事我已经在里面了，问题不是要不要做，是怎么让它不断掉**"，都落在恒卦。 |
| **不归本卦的情况** | ① 关系还没建立，要让对方愿意 → **咸卦（31）**；② 在纠结该不该停手、该不该收 → **艮卦（52）**；③ 在纠结该不该退出、该不该离场 → **遯卦（33）**；④ 已经陷在里面出不来、是被困不是要久 → **坎卦（29）**；⑤ 要靠反复申明去推动一次变革 → **巽卦（57）**。<br>**⚠️ 恒卦与坎卦最容易混，分界极重要**：**恒＝你要它久，且你可以不要（有退出权）；坎＝你不要它，但出不去（无退出权）。** 判错方向的代价极大：**在坎卦里"守恒"就是坎上六的"三岁不得，凶"。** |
| **"恒"字本义** | **久**（彖传第一句："恒，久也"）。字形从"心"从"亘"，**"亘"是连绵不断**——**恒是"心的连续性"，不是"事的不变"。**<br>**这一点被大象传定死了："立不易方"**——**不改的是"方"（方向、原则、所守），不是具体做法。**<br>**所以本卦最容易被误读的地方是：把"恒"理解成"不变"。** 彖传恰恰说"**四时变化而能久成**"——**四季一直在变，才能长久地成就万物。变是恒的手段，不是恒的敌人。** |
| **卦辞原文** | 恒：亨，无咎，利贞，利有攸往。 |
| **⚠️ 卦辞的关键结构** | **给了四项：亨、无咎、利贞、利有攸往；唯独没有"元"。**<br>**这是全书判词最密集的卦辞之一**（对照：师卦"只有贞"、艮卦"只有无咎"、大壮"只有利贞"）。**《周易》对"恒久"这条路给得很足——通（亨）、没灾（无咎）、守正有益（利贞）、还鼓励你往前走（利有攸往）。**<br>**⚠️ 但缺"元"这件事恰恰是本卦的性格。** 按本库口径，"元"＝敢于启动、去做去拼（善之长）。**恒卦不给"元"，因为恒不是启动，是延续。**<br>**而彖传把这个缺口自己补上了："利有攸往，终则有始也。"**——**恒卦的"往"不是开创新局，是在一个终点上接出新的起点。** 这与履上九"其旋元吉"、乾用九"群龙无首"（进入循环，而非到达顶点）**完全同源**：<br>**"元"是第一次开始；恒卦给的是第二次以及以后的每一次开始。** |
| **卦辞现代解** | **亨**——这条路通，长久本身是可以达成的，不是幻想。<br>**无咎**——按本库口径，"无咎"是"没有灾"，常是"善补过才没灾"。**放在恒卦：久不会自动带来好处，但它能让你不出灾。**<br>**利贞**——必须走正道。**⚠️ 这是本卦最硬的一条：久而不正，就是九三"不恒其德"与上六"振恒"。**<br>**利有攸往**——**恒不是原地不动。** 彖传解释为"终则有始也"：**每一段做完，接上下一段，这才叫久。** |
| **彖传** | 恒，久也。刚上而柔下，雷风相与，巽而动，刚柔皆应，恒。恒亨无咎利贞，久于其道也。天地之道，恒久而不已也。利有攸往，终则有始也。日月得天而能久照，四时变化而能久成，圣人久于其道而天下化成。观其所恒，而天地万物之情可见矣。 |
| **⚠️ 彖传要点（本卦机制全在这四句）** | ① **"刚上而柔下"**——**与咸卦彖传"柔上而刚下"正好互为镜像。****咸要"男下女"（强者主动放低）才能建立；恒要"刚上柔下"（各归其位）才能维持。**（详见第四节）<br>② **"巽而动"（本卦最实用的三个字）**——**下巽（顺）在前，上震（动）在后：先顺，后动。****恒久的机制不是硬撑，是"顺着来才动"。** 顺序不可颠倒：**先动后顺，就是上六的"振恒，凶"（在上面先摇起来）。**<br>③ **"刚柔皆应"**——三对应爻（初六↔九四、九二↔六五、九三↔上六）**全部一阴一阳，全卦无一失应**。**这是"恒"在结构上的根据：能久，是因为每一层都有对面的人接着。**（与八纯卦"上下敌应，不相与也"正相反，详见第四节）<br>④ **"久于其道也"／"四时变化而能久成"**——**久的不是事，是"道"；四季一直在变，才能长久地成就。** |
| **大象传（行动纲领）** | 雷风，恒。君子以立不易方。 |
| **⚠️ "立不易方"解（本卦最高层原则）** | **立**＝立身、站定；**易**＝改变；**方**＝方所、方向、所守之则（**与坤六二"直方大"的那个"方"同源：有棱角、有规矩**）。<br>**"立不易方"＝站定之后，不改变自己的"方"。**<br>**这五个字给了"恒久"一个可操作的定义：不是不变，是"方"不变。**<br>**该变的：做法、节奏、路径、合作对象、具体目标（彖传"四时变化而能久成"）。**<br>**不该变的：方向、原则、所守的那条线（大象传"不易方"）。**<br>**⚠️ 本卦六爻的失败形态，全部可以用这一句来诊断**：<br>**初六"浚恒"＝方还没立就往深挖｜九三"不恒其德"＝方时有时无｜九四"田无禽"＝方立错了地方（久非其位）｜六五"从妇凶"＝该自己定方的人跟着别人的方走｜上六"振恒"＝在最高处把方摇动了。** |
| **总铁律** | ① **恒的操作定义是"立不易方"**——事可以变，方不能易（大象传）；② **顺序是"巽而动"**——先顺后动，不可颠倒（彖传）；③ **不要一开始就求深**（初六"浚恒，贞凶"）——久是攒出来的，不是一次挖出来的；④ **正解只有一个："能久中"**（九二"悔亡"，象传）；⑤ **德不能断断续续**（九三"不恒其德…无所容也"）——**间断的德比没有德更没有容身之处**；⑥ **不要长久待在不属于自己的位置上**（九四"田无禽…久非其位"）；⑦ **该守成者守，该决断者不可一味跟从**（六五"妇人吉，夫子凶"）；⑧ **居上位而动摇不定，是恒的反面**（上六"振恒，凶…大无功也"）。 |

## 二、爻级字段

> ⚠️ **本卦六爻可以直接读成"恒之三失 ＋ 恒之二得 ＋ 一个位置警告"**：
> **三失**：**浚**（求之太深太急，初六）｜**不恒**（德不能持续，九三）｜**振**（居上而动摇，上六）。
> **二得**：**能久中**（九二）｜**恒其德，贞**（六五，但结果视职分而分吉凶）。
> **一个位置警告**：**久非其位**（九四"田无禽"）。
> **速查表见第三节。**

### 初六 · 浚恒（⚠️ 恒之失其一：求之太深太急）

| 字段 | 内容 |
|---|---|
| **爻辞** | 浚恒，贞凶，无攸利。 |
| **象传** | 浚恒之凶，始求深也。 |
| **位属性** | 阴爻居阳位，**不当位**（巽在下 → 初不当位）；居全卦最下——**柔之极，且是"久"的起点**；与九四相应 |
| **判词 → 行动语义** | **贞凶 ＋ 无攸利**（按本库口径：**贞凶＝守正也凶，问题不在品德，在处境与选择的根本错位**；**无攸利＝没有任何好处可图**） → **此爻不可入；把深度降下来** |
| **关键词解** | **浚**（jùn）＝深挖、疏浚（如"浚河"）。**浚恒**＝**一上来就把"恒"往深处挖**——刚开始就要求终身的深度、彻底的承诺、不可动摇的关系。**始求深**＝**开头就求深。** |
| **⚠️ 本爻是全卦最重的判词，而象传只用四个字给了理由** | **"始求深也"**——**病不在"求深"，在"始"。**<br>**同一个"深"，放在后面是九二的"能久中"，放在最开头就是"贞凶"。**<br>**为什么这么重？** 因为**"贞凶"意味着连守正都救不了你**：初六在最下、不当位、柔弱无力，**它唯一能做的是慢慢来；而它偏偏要一次到底。** 这不是品德问题（它可能非常诚恳、非常认真），**是"处境与选择的根本错位"——用最弱的位置去要最深的结果。**<br>**再加"无攸利"三个字：《周易》连一点余地都没留。** |
| **⚠️ 与巽初六的对照（巽在下的两个初爻）** | 本库巽卡指出：**"巽在下 → 柔在最底下，容易犯'进退'（犹豫）与'频巽'（一再退让）两个病。"**<br>**巽初六"进退，利武人之贞"——柔在底下的病是犹豫，药是借一份刚硬。**<br>**恒初六"浚恒，贞凶，无攸利"——柔在底下的病却是反的：不是不敢动，是一动就要动到底。**<br>**同一个结构位置，两卦的病形态相反，但根是同一个：柔在最底下，对自己的分量没有判断。**<br>**巽是"不敢用"，恒是"一次用尽"。** 而两卦给的药方向一致：**给自己一个刻度**——巽给的是"武人之贞"（一条硬线），恒给的是"始"（先别求深）。 |
| **识别信号（诊断清单）** | ① 一段关系／一件事刚开始，你就想把它锁定成长期的（要承诺、要合同、要"以后都这样"）；② 你的理由是"早点定下来才安心"；③ 你正在为一件刚起步的事投入远超它当前阶段的资源、感情、时间；④ 对方（或这件事本身）还没有到那个深度，你已经到了。 |
| **该做** | **把深度降到与阶段匹配。** 具体：**只做这个阶段该做的那一件事**，不预支后面的承诺与投入。**参照咸卦初六"咸其拇"——感应刚起时，正确动作是把作为停在最前端那一点上。** |
| **不该做** | 用"我很认真"为理由继续加深。**"贞凶"说的正是这个：认真（贞）在这里救不了你。** |
| **与屯卦、坎卦初爻的三角对照** | **屯卦是草创（本库已有），坎初六"入于坎窞，凶"——已经陷进去还往深走**；**恒初六"浚恒，贞凶"——刚开始就往深挖**。<br>**两爻的动作完全一样（往深处去），判词也一样重。** 区别：**坎初六是在险中加深，恒初六是在开头加深。**<br>**合起来是一条通则线索：《周易》对"往深处"这个动作，在初爻位置上从不给好话。** 而**艮初六"艮其趾，无咎，利永贞"** 给出了初爻唯一被明确嘉许的动作：**在最微处止住。** |

### 九二 · 悔亡（⚠️ 全卦唯一的正解，也是全卦最短的爻辞）

| 字段 | 内容 |
|---|---|
| **爻辞** | 悔亡。 |
| **象传** | 九二悔亡，能久中也。 |
| **位属性** | 阳爻居阴位，**不当位**（巽在下 → 二不当位），**但得中**；与六五相应 |
| **判词 → 行动语义** | **悔亡**（按本库吉凶序：无咎 ＞ **悔亡** ＞ 悔；**"挽回级"——本该有的悔恨消失了，不是得到好处**） → **长久地守在中道上，不加别的动作** |
| **关键词解** | **爻辞只有两个字，是本卦最短、也是全书最短的爻辞之一**（对照大壮九二"贞吉"、震九四"震遂泥"）。<br>**能久中**＝**能够长久地居中**（中＝中道、不偏不倚，也指它得中这个位置）。 |
| **⚠️ 本爻是全卦唯一不讲"失"的爻，而它的全部内容在象传三个字里** | **爻辞不说做什么，只给结果（悔亡）；象传补上原因："能久中也"。**<br>**注意"能"字与"久"字**：<br>**"中"不难，"久中"难。** 一时的不偏不倚谁都做得到；**在同一件事上十年不偏，才是这一爻。**<br>**而《周易》给这件事的回报是"悔亡"，不是"吉"。** 这一点必须讲清楚：**按本库口径，"悔亡"是挽回级——它不给你额外的好处，只是把你本该有的悔恨抹掉了。**<br>**这就是恒卦对长期主义最诚实的一句话：长久地做对，回报不是收益，是"没有遗憾"。** |
| **本爻不当位却是正解的原因（"得中可救不当位"的又一实例）** | 阳爻居阴位，**名不正言不顺**；但它**得中**。<br>按本库通则"**⚠️ 得中可救不当位**"——**九二在恒卦里的价值恰恰在于"刚而处柔位"**：<br>**它有刚（阳），所以能持续；它在柔位（不当位），所以不硬撑、不逞强。**<br>**对照本卦九三：九三当位（阳居阳），刚而在刚位，反而"不恒其德"、判"贞吝"。****一个不当位的九二是全卦正解，一个当位的九三是全卦的病例——这在恒卦里不是偶然，而是"过刚不能久"的直接体现。** |
| **识别信号** | ① 你已经在这件事／这段关系里待了相当一段时间；② 你的名分、条件不完全匹配（不当位）——不是最有资格的那个，但事情实际靠你在维持；③ 你没有惊人的动作，也没有明显的偏移；④ 你偶尔怀疑"我这样一直下去有什么意义"。 |
| **该做** | **什么都不加，继续居中。** 具体化"久中"的三条刻度：**① 节奏不变（频率、投入量稳定）；② 立场不偏（不因一时冷热而改判断）；③ 不在中途改标准。** |
| **不该做** | 为了"证明自己在坚持"而加动作（加投入、加宣示、加深度）。**加动作就掉到初六的"浚"或九三的"不恒"。** |
| **与巽九二、履九二、大壮九二的四方对照（"不当位而得中"的四例）** | | 

| 卦 | 九二爻辞 | 判词 | 象传 | 得中的具体形态 |
|---|---|---|---|---|
| **恒 32** | 悔亡（两字） | **悔亡** | **能久中也** | **在时间上不偏**——久 |
| **大壮 34** | 贞吉（两字） | **贞吉** | 以中也 | **在力量上不满**——刚而处柔位 |

| 字段 | 内容 |
|---|---|
| **四方对照的结论** | **四个九二全部"阳居阴位、不当位、得中"，判词全部靠"中"来救，象传全部只给"中"这一个理由。**<br>**这是本库通则"得中可救不当位"目前最整齐的一组证据。**<br>**而四卦给"中"的内容各不相同：恒＝时间上的中，大壮＝力量上的中，履＝心态上的中，巽＝姿态上的中。**<br>**合读结论：所谓"得中"不是一个位置属性，是"在这一卦最容易失衡的那个维度上不失衡"。** |

### 九三 · 不恒其德（⚠️ 恒之失其二：德不能持续）

| 字段 | 内容 |
|---|---|
| **爻辞** | 不恒其德，或承之羞，贞吝。 |
| **象传** | 不恒其德，无所容也。 |
| **位属性** | 阳爻居阳位，**当位**（巽在下 → 三当位）；居下巽之顶；本库通则"**三多凶**"；与上六相应 |
| **判词 → 行动语义** | **贞吝**（按本库口径：**吝＝路越走越窄，趋势极差**；加"贞"字则连守正也走窄） → **不要把"德"做成断断续续的** |
| **关键词解** | **不恒其德**＝**不能长久地守住自己的德**（时好时坏、时严时松、时热时冷）。**或**＝或许、常常。**承之羞**＝**承受随之而来的羞辱**（"承"是接受、担着）。**无所容**＝**没有容身之处、没有人容得下你。** |
| **⚠️ 象传四个字是全书最狠的诊断之一："无所容也"** | **不是"有咎"，不是"凶"，是"没有地方容你"。**<br>**为什么这么重？**<br>**因为"德"是别人用来预测你的唯一依据。** 一个德一贯很差的人，别人知道怎么防他；**一个德时有时无的人，别人无法与他建立任何长期安排——所以"无所容"。**<br>**这也解释了"或承之羞"：羞辱不是别人施加的惩罚，是"不可预测"这件事的自然结果。**<br>**可入库为通则：《周易》评价一个人，看的是"德的连续性"，不只是"德的高度"。间断的德，比一贯的平庸更难安置。** |
| **为什么当位反而"吝"** | **九三是阳爻居阳位，刚健当位之才，且是下巽三爻中唯一当位的那一爻**——条件不差。<br>**但它居下巽之顶（三多凶），刚性最盛而位置最"正"，最容易觉得"我本来就是对的，所以不必一贯"。**<br>**本库通则"三多凶"在本爻的具体形态是：在最该稳住的位置上摇摆。**<br>**对照本卦九二：不当位而得中，判"悔亡"（正解）；九三当位而不得中，判"贞吝"（病例）。** |
| **⚠️ 与巽九三的对照（同一个结构位置，同一个判词，两卦同构）** | **巽卦下卦是巽，恒卦下卦也是巽——两个九三是完全相同的结构位置（阳居阳位、当位、居下巽之顶）。** |

| 字段 | 内容 |
|---|---|
| **⚠️ 这一组对照的价值** | **同一个三画卦（巽）落在同一个位置（下卦之顶），两卦的九三判词都是"吝"，象传都指向"穷／无所容"。**<br>**这是本库结构律最干净的一次交叉验证。**<br>⚠️ **但必须谨慎，不可断为通则**：其余"巽在下"诸卦的九三判词并不一致（如大过九三判"凶"、姤九三判"厉"）。**所以这只是两例同构，本库应记为"诊断线索"而非"结构律"**：<br>**线索内容：巽在下的九三，是一个高风险的"当位而虚"位——当位给了它资格，下巽给了它软性，两者合起来最容易走窄。查它的方法是问一句"我在这个位置上，有没有一件事是一贯的？"** |

| **识别信号（诊断清单）** | ① 你的原则和标准，在不同的人、不同的时候、不同的心情下不一样；② 你自己也说不清"我到底守的是什么"；③ 你已经因为前后不一而尴尬过、被人当面提过（或承之羞）；④ 你发现愿意跟你做长期安排的人在变少（无所容）。 |

| **不该做** | 用一次更大的表态来弥补前面的不一贯。**"贞吝"里的"吝"是趋势判词——它说的不是你现在有多糟，是你正在走窄；而再一次的表态只会把窄的速度加快。** |
| **与蒙卦"蒙以养正"、师上六"小人勿用"的呼应** | 本库已反复出现同一条铁律：**绝不能把权位／本领／诚信交给无德之人**（蒙、师上六、比卦"原筮"、兑九五"孚于剥"）。<br>**恒九三是这条铁律的内向版本：这一次要防的是自己。****"无所容也"给出的是他人视角的结论——一个德不连续的人，在别人的长期安排里没有位置。** |

### 九四 · 田无禽（⚠️ 位置警告：久非其位）

| 字段 | 内容 |
|---|---|
| **爻辞** | 田无禽。 |
| **象传** | 久非其位，安得禽也。 |
| **位属性** | 阳爻居阴位，**不当位**（震在上 → 四不当位）；**是上震的那个阳爻**，处上下卦之交；本库通则"**四多惧**"；与初六相应 |
| **判词 → 行动语义** | **无判词，仅三字爻辞** → **不是灾，是白费；先查"位"，不要先查"努力"** |
| **关键词解** | **田**＝田猎、打猎。**禽**＝猎物。**田无禽**＝**打了一天猎，什么也没打到。****安得禽也**＝**怎么可能打到猎物呢？**（反问句，语气极重） |
| **⚠️ 象传是全书对"白费"最直接的一次归因** | **象传没有责备这一爻不努力，它只问了一个位置问题："久非其位，安得禽也。"**<br>**"久非其位"＝长久地待在不属于自己的位置上。**<br>**结论极清晰：打不到猎物的原因不是技术、不是运气、不是猎场没有猎物，是你长期站在了没有猎物的位置上。**<br>**这是恒卦最容易被跳过、也最实用的一爻**：<br>**它把"恒"的一个致命误用点出来了——把"久"用在了错的位置上。** 前面九三讲"德不能久"，**这一爻讲"错的位置不能久"。** 两者合起来：**该久的不久，不该久的却久，是恒卦全部失败的两个方向。** |
| **⚠️ 三个"震在上的九四"对照（本卡最有价值的结构发现之一）** | **震在上时，九四必然是震的那个阳爻，且必然不当位。** 本库现有三例： | 

| 卦 | 下卦 | 九四爻辞 | 判词 | 象传 | 性质 |
|---|---|---|---|---|---|
| **震 51** | 震（雷） | 震遂泥 | **无** | **未光也** | **陷住**——想动，每一步都黏住 |
| **恒 32** | 巽（风） | 田无禽 | **无** | **久非其位，安得禽也** | **空猎**——动了，一无所获 |
| **大壮 34** | 乾（天） | 藩决不羸，贞吉悔亡 | **贞吉·悔亡** | **尚往也** | **冲开**——势到，藩自己开了 |

| 字段 | 内容 |
|---|---|
| **⚠️ 三例对照的结论（建议入库为通则）** | **同一个"震在上的九四"，三卦三种结果，差别完全由下卦决定：**<br>**下面是震（泥沼、余震未消）→ 陷住（遂泥，未光）；**<br>**下面是巽（柔在底、无所凭借）→ 空猎（田无禽）；**<br>**下面是乾（四阳同升、势已成）→ 冲开（藩决不羸，贞吉悔亡）。**<br>**通则：九四能不能动，不看九四自己，看下卦给了它什么。**<br>**这条通则的实操价值极高**：**"四多惧"这个位置的问题，从来不在四这一位上，在你脚下三爻的构成上。** 所以四位的诊断动作应该是**向下看，不是向前看**。 |
| **识别信号（诊断清单）** | ① 你在这件事上已经投入很久，动作也不少，但产出接近于零；② 你的第一反应是"再努力一点"或"再等等"；③ 你的位置本来就不太对——名分、资格、职权、赛道有一样长期不匹配；④ 你从来没有认真问过"这个位置上有没有猎物"。 |
| **该做** | **换位置，或者停止在这个位置上继续投入。**<br>**具体动作：把"我做得够不够"这个问题，换成象传的那个问题——"这个位置上有猎物吗？"**<br>**如果答案是没有，那么继续"恒"就是在把"久"这个优点用成缺点。** |
| **不该做** | 加大投入、延长时间。**注意本爻没有判词——《周易》连"凶"都不给它，因为它不是灾难，是白费。** 而白费的东西加倍投入，只会变成白费更多。 |
| **与震九四、兑上六的呼应（"白费"家族）** | 本库"未光／白费"一档现有：**震九四"遂泥，未光也"（陷住）、兑上六"引兑，未光也"（没内容）、咸九四"憧憧往来，未光大也"（爻内分裂）。**<br>**恒九四"田无禽"是这一族的第四个成员，而且它是其中唯一给出明确归因的**——**象传直接指出原因是"位"。**<br>**所以在这一族里，恒九四是那个"可诊断"的样本：其余三爻告诉你"你在白费"，恒九四告诉你"为什么"。** |

### 六五 · 恒其德（⚠️ 乘刚，且同爻两断）

| 字段 | 内容 |
|---|---|
| **爻辞** | 恒其德，贞。妇人吉，夫子凶。 |
| **象传** | 妇人贞吉，从一也；夫子制义，从妇凶也。 |
| **位属性** | 阴爻居阳位，**不当位**（震在上 → 五不当位），但**得中**且居尊位；**直压九四之上——乘刚**（验证规格"震在上则六五必乘刚"）；与九二相应 |
| **判词 → 行动语义** | **吉 ／ 凶（同一爻内两断，按职分而分）** → **该守成者守到底则吉；该做判断的人一味跟从则凶** |
| **关键词解** | **恒其德，贞**＝长久地守其德而端正。**妇人／夫子**＝**《周易》此处用两种职分来分判同一个动作**——象传自己给了定义：**"妇人…从一也"（守成者：从一而终）；"夫子制义"（制义者：负责裁断是非、定夺义理的人）。**<br>⚠️ **本库按职分读，不按性别读**：象传的分界线不在身份上，在**"你这个位置的职责是守，还是断"**。 |
| **⚠️ 本爻是本卦最需要小心读的一爻，象传把机制写得极清楚** | **同一个动作"恒其德"（一贯地守），落到两种职分上，一吉一凶：**<br>**① 职责是"守"的人（从一）——恒其德就是把本职做到底，所以"贞吉"。**<br>**② 职责是"断"的人（制义）——恒其德若变成"一贯地跟从"，就是"从妇凶也"：他放弃了自己唯一不能放弃的职能。**<br>**结论："恒"这件事本身没有吉凶，它的吉凶由"你这个位置该恒什么"决定。**<br>**该守的人恒其守，是吉；该断的人恒其从，是凶。** |
| **⚠️ 与巽上九"丧其资斧，贞凶"完全同一机制（本库第二例）** | **巽上九"巽在床下，丧其资斧，贞凶"，象传"上穷也／正乎凶也"**——本库巽卡的结论是：**"一个已在高位的人，其职责就是决断（斧）；他若一味卑顺，就是在放弃自己唯一不可放弃的职能。正因为他'守正'（老实、恭顺、不争），才更逃不掉这个凶。"**<br>**恒六五"夫子…从妇凶也"是同一条判断的第二次出现，而且这一次《周易》把职分的名字写出来了："制义"。**<br>**合读结论（可入库为通则）：**<br>**居高位而放弃裁断，是《周易》判"凶"最稳定的一种情形；且它专门针对"品德没问题"的人——两处都强调守正（贞凶／从妇凶），说明问题不在品德，在职分错位。** |
| **乘刚的处理（本爻是"六五乘刚"的第二例）** | 按规格，**震在上则六五必乘刚**。本库现有的六五乘刚案例是**震六五**（"亿无丧，有事"，靠"其事在中"守住本职）。<br>**恒六五是第二例，它的处境是：下面顶着九四（那个"田无禽"的阳爻），自己不当位，只靠得中居尊。**<br>**它的破解方式是"恒其德，贞"——用"一贯"来对抗下面的顶迫。**<br>**但《周易》立刻加了限定：这个方法只对"该守的人"有效；对"该断的人"，一贯的跟从就是凶。**（三例六五乘刚的完整对照见第四节） |
| **识别信号（诊断清单）** | ① 你在拍板或被指望拍板的位置上，但名分／条件不完全匹配（不当位）；② 下面有强劲的力量在顶你（乘刚）；③ 你的处理方式是"保持一贯、不改变、跟着既定方向走"；④ **关键自查：你这个位置的职责，是"守住"还是"裁断"？** |
| **该做** | **先确定职分，再决定恒什么。**<br>**若职责是守成（从一）**：把本职一贯做到底，不因下面的顶迫而改动作——**这条路是"贞吉"。**<br>**若职责是裁断（制义）**：**必须自己下判断。** 可以一贯地守原则，**但不能一贯地跟从**。**参照巽上九的解药："把斧拿回来——在自己职责范围内做出至少一个明确的决断。"** |
| **不该做** | 以"我一直都是这样"为理由回避该做的判断。**这正是"从妇凶也"四个字。** |
| **本库"五爻专题"的新一例** | 已有十一例（乾九五利见大人、坤六五守臣节、蒙六五赤子之心、离六五痛哭、艮六五闭嘴、师六五选人放手、震六五守本职、巽九五申命、履九五位正当反厉、兑九五收回孚、咸九五感不到）。<br>**恒六五补上第十二种：居尊而必须自己判断。** 它要放弃的特权是——**"保持一贯"这个特权。** |

### 上六 · 振恒（⚠️ 恒之失其三：居上而动摇）

| 字段 | 内容 |
|---|---|
| **爻辞** | 振恒，凶。 |
| **象传** | 振恒在上，大无功也。 |
| **位属性** | 阴爻居阴位，**当位**（震在上 → 上当位）；居全卦之终、上震之顶——**动之极**；与九三相应 |
| **判词 → 行动语义** | **凶**（按本库口径：**周易所有结局中最坏的，别不当回事**） → **此爻不可入；居上位者停止摇动** |
| **关键词解** | **振**＝振动、摇动、抖动（一说振奋过度而不能安）。**振恒**＝**把"恒"摇动了**——在最高处，把本该稳定的东西不断晃动。**在上**＝居于最上位。**大无功**＝**毫无成果。** |
| **⚠️ 本爻当位却判"凶"，理由全在"在上"两个字** | 上六**当位**（阴居阴位），本该不差；**判词却是本卦最重的"凶"，而且象传追加"大无功也"（完全没有成果）。**<br>**象传给的理由只有两个字："在上"。**<br>**为什么"在上"就致命？**<br>**因为恒卦的德是"久"，而"久"的载体是稳定；居上位者的每一次摇动，会沿着整个结构传下去。** 下面五爻各自的偏差只影响自己，**上六的摇动影响全卦——所以它的代价从"吝""厉"直接跳到"凶"。**<br>**再对照卦德的顺序（彖传"巽而动"：先顺后动）：上六在最上面先动起来，正是把顺序颠倒了。** |
| **⚠️ 与师六三"大无功也"的呼应（全书两处"大无功也"）** | **师六三"师或舆尸，凶"，象传"大无功也"**——本库师卡的解读：**"不仅败，而且毫无战果"；病根是"无能力却抢了指挥权"（才不配位）。**<br>**恒上六"振恒，凶"，象传"振恒在上，大无功也"**——病根是**"居上位而动摇不定"。**<br>**两处"大无功也"都判"凶"，都在"位置与作为错配"上：师六三是无能力者占了位置，恒上六是居上位者做了不该做的动作。**<br>**合读结论：《周易》说"大无功"时，从不是在批评能力，是在批评"这个位置上做了这个动作"。** |
| **⚠️ 与巽上九、艮上九、乾上九、兑上六的五方对照（"到顶之后"的五种走法）** | |

**恒卦三句话**：
1. **"恒"不是不变，是"方"不变**（大象传"立不易方"；彖传"四时变化而能久成"）。**该变的是做法、节奏、路径；不该变的是方向、原则、那条线。** 把两者搞反，就是本卦六爻的全部病例。
2. **顺序是"巽而动"——先顺后动**（彖传）。**颠倒过来（在最上面先摇起来）就是上六"振恒，凶"。**
3. **长久地做对，回报不是收益，是"没有遗憾"**（九二"悔亡"，按本库口径是挽回级，不是得利级）。**《周易》对恒久这条路给了亨、无咎、利贞、利有攸往，却唯独不给"元"——因为恒不是启动，是"终则有始"。**

**本卦最反直觉的四条**：
- **一个专讲"久"的卦，六爻里有四爻在讲"久"的失败形态**（浚、不恒、久非其位、振），**只有九二一爻是无条件的正解，而它的爻辞只有两个字（"悔亡"）。**
- **不当位的九二是全卦正解，当位的九三是全卦最典型的病例。** 因为**恒卦最怕的不是位置不正，是过刚不能久**——九二刚而处柔位（不硬撑），九三刚而在刚位（摇摆而自以为对）。
- **初六"浚恒"判"贞凶，无攸利"，而它做的事是"一开始就求深"。** 病不在"深"，在"始"——**同一个深度，放在后面是九二的"能久中"，放在最开头就是全卦最重的判词。**
- **九四"田无禽"没有任何判词，但它的象传是全卦最实用的一句："久非其位，安得禽也。"** **打不到猎物的原因不是你不努力，是这个位置上没有猎物。** 而《周易》对此不判凶——**它不是灾，是白费。**

## 四、⚠️ 本卡对全库的意义

### 1. 咸／恒是一对倒转卦，且两卦彖传互为镜像——本库第一组"关系双卦"

**结构核对（机械可验）**：
- **咸 31**（上兑下艮）六爻自下往上：**阴 阴 阳 阳 阳 阴**
- 整卦上下颠倒：**阴 阳 阳 阳 阴 阴** ＝ **恒 32**（上震下巽）✓
- **两卦互为覆卦（倒转卦）**——这正是序卦传把它们排在一起、并且用一句话（"夫妇之道不可以不久也"）串起来的结构原因。

**而两卦彖传的第一句，恰好是一对反话**：

| | **咸 31（建立）** | **恒 32（维持）** |
|---|---|---|
| 彖传首句 | **柔上而刚下** | **刚上而柔下** |
| 结构 | 兑（柔）在上，艮（刚）在下 | 震（刚）在上，巽（柔）在下 |
| 机制 | **止而说，男下女**——**强的一方主动放低** | **巽而动**——**先顺后动，各归其位** |
| 卦辞 | 亨，利贞，**取女吉**（无元） | 亨，无咎，利贞，**利有攸往**（无元） |
| 大象传 | **虚受人**（先腾空） | **立不易方**（把方钉住） |
| 卦德 | 感 | 久 |
| 一句话 | **建立关系靠"放低"** | **维持关系靠"归位"** |

> **⚠️ 合读结论（本组最有价值的一条对照，且完全出自两卦彖传原文）**：
> **《周易》把"关系"拆成了两个方向相反的动作。**
> **建立时，强者必须下来（柔上而刚下，男下女）；维持时，各自必须归位（刚上而柔下）。**
> **用建立的方式去维持** ——一直放低、一直迁就、一直靠感应撑着—— **就是恒九三"不恒其德…无所容也"与巽九三"频巽…志穷也"。**
> **用维持的方式去建立** ——一上来就摆位置、讲规则、要承诺—— **就是恒初六"浚恒，贞凶"，而且连咸卦的门都进不去。**
> **两卦合读，本库对"关系"这个领域才算给全了：咸管从零到有，恒管从有到久，而两者的方法是反的。**

**另一条结构事实：咸与恒都是"全应"卦。**
三对应爻（初↔四、二↔五、三↔上）全部一阴一阳，无一失应。**恒卦彖传直接写出来了："刚柔皆应"**；咸卦彖传的说法是"二气感应以相与"。

> **这与八纯卦正好相反。** 艮卦彖传"**上下敌应，不相与也**"对全部八纯卦成立（纯卦上下相同，每对应爻必然同性相斥）。
> **所以：八纯卦＝全卦无一援（八条纲领全是"对自己下的指令"）；咸恒＝全卦无一失应（每一层都有对面的人接着）。**
> **一个卦讲不讲"关系"，从应爻结构上就能读出来。** 本库已有的泰 11／否 12 也是全应卦——它们讲"通"与"不通"，同样是关系型的卦。
> **可入库为一条读卦通则：先数应爻。三对全应＝这一卦讲"相与"；三对全不应＝这一卦讲"自处"。**

### 2. ⚠️ 新增通则：三个"震在上的九四"，结果完全由下卦决定

**震在上时，九四必然是震的那个阳爻，且必然不当位**（规格第 4 节：震在上 → 四五不当、上当位）。本库现有三例，恰好在本批凑齐：

| 卦 | 卦象 | 下卦 | 九四爻辞 | 判词 | 象传 | 结果 |
|---|---|---|---|---|---|---|
| **震 51** | 上震下震 | **震**（雷·余震未消） | 震遂泥 | **无** | 未光也 | **陷住**——想动，每步都黏住 |
| **恒 32** | 上震下巽 | **巽**（风·柔在底） | 田无禽 | **无** | **久非其位，安得禽也** | **空猎**——动了，一无所获 |
| **大壮 34** | 上震下乾 | **乾**（天·四阳同升） | 藩决不羸，贞吉悔亡 | **贞吉·悔亡** | 尚往也 | **冲开**——势到，藩自己开了 |

> **⚠️ 通则（建议补入索引第五节）**：
> **"四多惧"这个位置的吉凶，不由四位本身决定，由下卦（初二三爻）给它什么决定。**
> **脚下是泥沼（震）→ 陷住｜脚下是柔（巽）→ 空猎｜脚下是四阳之势（乾）→ 冲开。**
> **实操推论：处在四位时，正确的诊断动作是"向下看"，不是"向前看"。** 问的不是"我该不该往前"，而是"我脚下这三爻给了我什么"。
> **这条通则同时解释了本库震卡的一个悬置问题**：震九四"遂泥"为什么那么憋屈？——**因为它的下卦也是震，脚下是刚过去的一波余震。** 换成乾（大壮），同一个位置就是"藩决不羸，贞吉悔亡"。

### 4. 本卦补上的机制缺口

| 缺口 | 恒卦补的内容 |

| **本库有"该不该开始"（乾/屯）、"该不该停"（艮）、"该不该退"（遯），但没有"怎么让它久"** | **恒卦是本库第一张专讲"长期维持"的卡**，而且它给的答案与直觉相反：**六爻里四爻在讲失败形态，唯一的正解（九二）只得"悔亡"——挽回级，不是得利级。** |

| **"该久的不久 / 不该久的却久"这一对错误没有归口** | **恒九三（该久的不久：德不连续）与恒九四（不该久的却久：久非其位）在同一卦里成对出现**，这是本库唯一一处把这两种相反错误并置的地方。**诊断顺序应该是：先用九四查"位置对不对"，再用九三查"德连不连续"。** 顺序颠倒会让人在错的位置上努力做一贯的人。 |

### 5. 本卡打开的下一步（优先建议）

> **首选：蛊 18（上艮下巽）**——本库巽卡已指出："蛊卦卦辞'先甲三日，后甲三日'与巽九五'先庚三日，后庚三日'是全书唯一的一对姊妹句（**甲＝始事，庚＝更事**），两卦合读才完整。"
> **而恒卦为蛊卦补上了第二个理由**：**蛊＝积弊、烂摊子，讲的正是"久"出了问题之后怎么整治。** 恒九三"不恒其德"、九四"久非其位"、上六"振恒"三种"恒之失"积累下来，**结果就是蛊。** 恒 → 蛊 是本库目前最自然的一条因果衔接。
> 其次：**益 42（上巽下震）**——它是**恒卦的上下卦交换**（恒＝上震下巽，益＝上巽下震）。巽卡已指出"巽在上→六四、九五皆当位，是巽最好的位置"。**恒（巽在下，柔在底，四爻不当位）与益（巽在上，位最正）合读，可以把巽/震这一对在复合卦里的两种叠加方式一次读完。**
> 第三：**大过 28（上兑下巽）**——卦名即"过"。**恒讲"久"的正道，大过讲"过度"**，两卦下卦同为巽，是"巽在下"两个病（犹豫、滥让）的另一种发展方向。
