# 知识卡 33 · 遯卦（天山遯 · 亦作遁）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："恒者，久也。物不可以久居其所，故受之以遯。遯者，退也。"——**"久"（恒 32）之后紧接着的不是更久，是"不可以久居其所"。《周易》自己给"恒"划了边界：可以久于其道，不可以久居其位。**
> **本卦与大壮卦（34）是一对，且是结构上的倒转（覆卦）**：遯卦六爻自下往上"阴阴阳阳阳阳"，整卦上下颠倒即得大壮"阳阳阳阳阴阴"。**遯＝退避，大壮＝壮盛。这一对是"什么时候该退、什么时候该进"的直接对照，合读表见第四节。**
> ⚠️ **本卡最重要的一条**：**上九"肥遯，无不利"是本库目前"退避"类判词的最高等级**（按吉凶序仅次于元吉）。**与艮上九"敦艮，吉"、乾上九"亢龙有悔"三方对照，可以把规格第 3 节"上爻限定"那条通则钉死。**（详见上九与第四节）

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 遯 · 第三十三卦（字亦作**遁**） |
| **卦象** | 上乾（天/健）下艮（山/止），称"天山遯"。**天在上而山止于下**——山虽高，天却一直在上面远去，**山追不上天**，这就是"远离"之象（大象传"天下有山"）。<br>按本库第 4 节结构律，本卦是**"艮在下 ＋ 乾在上"的叠加**：<br>**艮在下 → 初六不当位、六二当位得中、九三当位**（艮在下＝止在内，自己收手）；<br>**乾在上 → 九四不当位、九五当位得中居尊、上九不当位**。<br>**⚠️ 本卦无一处乘刚**（无阴爻居阳爻之上）：艮在下不制造乘刚，乾无阴爻。**这是本组四卦中唯一完全没有乘刚的一卦**——退避这件事，压力不来自下面顶你，来自大势本身在变。<br>**⚠️ 阴阳消长**：下面两爻是阴，上面四爻是阳，**阴自下而生、正在往上长**——彖传"**浸而长也**"说的就是这个。 |
| **领域定义** | **该退避时如何退**。从一个正在慢慢变坏的组织／关系／行业里撤出；离职与转行；退出一个合作或项目；与某个持续消耗你的人保持距离；不再参与一场自己改变不了的局面；在还没到最坏之前提前离场；从一个位置上下来并交接干净。凡是"**这里正在慢慢变坏，而我改变不了它**"，都落在遯卦。 |
| **不归本卦的情况** | ① **主动停手但不离场** → **艮卦（52）**（艮＝停在原地不再往前；遯＝离开这个场）；② **已经陷进去出不来、没有退出权** → **坎卦（29）**；③ **别人出事而自己按住不动** → **震上六**（"征凶…畏邻戒也"）；④ **冲突已经组织化、要打** → **师卦（7）**；⑤ **自己有实力、正在上升期** → **大壮卦（34）**。<br>**⚠️ 遯与艮的分界是本卡最需要说清的一条**：**艮卦特指"你有能力继续，但你决定不继续"（止）；遯卦特指"你有能力留下，但你决定不留下"（退）。** 一个是停手，一个是离场。**艮上九"敦艮，吉"是厚厚地停住；遯上九"肥遯，无不利"是宽绰地走开。** |
| **"遯"字本义** | **退**（序卦传直接给了定义："遯者，退也"）。字从"辵"（走），从"豚"——**本义是逃、隐去、避开。**<br>**⚠️ 但本卦最容易被误读的地方是把"遯"当成逃跑或认输。** 彖传把它定死了：**"遯，亨，遯而亨也"——退这个动作本身就是通。** 而且彖传给了本卦一句全书最高级的赞叹句式：**"遯之时义大矣哉！"**<br>**《周易》对"退"的评价，比对"进"（大壮）的评价高得多**：大壮卦辞只有"利贞"两字，遯卦辞却有"亨"。（详见第四节的对照表） |
| **卦辞原文** | 遯：亨，小利贞。 |
| **⚠️ 卦辞的关键结构** | **有"亨"，有"利贞"，但"利贞"前面加了一个"小"字；无元。**<br>**① 有"亨"这件事本身就反直觉**：退避居然是"通"的。彖传立刻解释："**遯而亨也**"——**不是退了之后就通了，是"退"这个动作本身构成通。**<br>**② 为什么"利贞"要加"小"？** 彖传给了理由："**小利贞，浸而长也**"——**阴（那个正在变坏的东西）正在慢慢生长。****大势在往坏的方向走，所以你守正能得到的好处只能是"小"的。**<br>**③ 与巽卦"小亨"的分别（很重要）**：巽卦是"**小**亨"（路通得小）；遯卦是"亨，**小**利贞"（**路是全通的，只是守正的收益小**）。**两个"小"落的位置完全不同：巽的天花板在"通"上，遯的天花板在"利"上。**<br>**结论：遯卦告诉你——退这条路完全通得开，但不要指望靠退拿到好处。** |
| **卦辞现代解** | **亨**——退这条路是通的，而且是当下唯一通的那条。<br>**小利贞**——**你仍然必须守正（贞），但要接受收益是有限的（小）**：因为大势正在"浸而长"地变坏，你能保住的只是自己，保不住局面。<br>**深意：遯卦不许诺你"退了之后会更好"，它只许诺"退这个动作是通的"。** 想在遯卦里拿到"元"（开创）或"大利"，是把遯当成了大壮。 |
| **彖传** | 遯，亨，遯而亨也。刚当位而应，与时行也。小利贞，浸而长也。遯之时义大矣哉。 |
| **⚠️ 彖传要点（本卦机制全在这四句）** | ① **"遯而亨也"**——**退本身就是通。** 这是本卦的定性句。<br>② **"刚当位而应，与时行也"**——**九五刚而当位（阳居阳位、得中居尊），且与六二相应**（机械核对：六二阴 ↔ 九五阳，相应 ✓）。**所以遯卦不是全盘崩坏，最高位上还有一个正当的、有呼应的人**——这就是九五"嘉遯"能"贞吉"的结构根据。<br>**"与时行也"＝依时而行**——**与艮卦彖传"时止则止，时行则行，动静不失其时"完全同源。****遯判断的也是"时"，不是偏好。**<br>③ **"小利贞，浸而长也"（本卦最实用的五个字）**——**"浸"是浸润、渐渐、一点一点。****遯卦的处境是"坏的东西正在慢慢长大"，不是突然爆发。**<br>**⚠️ 这一句是遯卦与震卦最重要的分界**：**震＝突然砸下来（"震来虩虩"，冲击型，七日得）；遯＝慢慢渗上来（"浸而长"，渐变型）。** 判错方向的代价极大：**震卦的正解是按住不动等七日，遯卦的正解是趁早离场。**<br>④ **"遯之时义大矣哉"**——《周易》用最高级的赞叹句式收尾。**"时义"两字并举：退的价值全在"时"上，退早了叫先见，退晚了叫溃败（初六"遯尾，厉"）。** |
| **大象传（行动纲领）** | 天下有山，遯。君子以远小人，不恶而严。 |
| **⚠️ "远小人，不恶而严"解（本卦最高层原则，也是全卦最实用的一句）** | **天在山之上，且一直往上远去；山虽然高、虽然想追，也追不上——所以"远"。**<br>**"远小人"**＝**主动拉开距离**（不是斗、不是揭发、不是改造）。<br>**"不恶而严"（本卦精髓四字）**＝**不表现出厌恶，但保持严正。**<br>**⚠️ 这是遯卦对"退避的正确形态"给出的唯一定义，而它同时排除了两种常见做法**：<br>**① 排除"恶"**——不撕破脸、不控诉、不把退变成一场清算。因为一旦"恶"，你就还在场内（对方成了你的对手，你就没退成）。<br>**② 排除"不严"**——不含糊、不留人情后门、不搞"表面还是朋友，实际慢慢淡"。**界限必须分明。**<br>**合起来：态度上不带情绪，边界上一寸不让。**<br>**这与兑九五"孚于剥，有厉"（把诚信从正在剥损你的对象那里收回来）、兑九四"介疾有喜"（只隔断病处，不动整片和气）是同一条方法在三卦的表达：精准切断，不做整体清算。** |
| **总铁律** | ① **退判断的是"时"**（彖传"与时行也"，同艮卦"时止则止，时行则行"）——**退早了是先见，退晚了是溃败**；② **处境是"浸而长"**（渐变，不是突变）——**所以不会有一个明显的信号提醒你走，你必须自己定时点**；③ **正确形态是"不恶而严"**（大象传）——不带情绪，边界分明；④ **越早越好、越远越好**：初六（最晚）"厉"，上九（最远）"无不利"；⑤ **有牵挂就退不掉**（九三"系遯"），此时唯一的合法动作是**把范围缩到最小**（"畜臣妾吉，不可大事也"）；⑥ **卦辞只给"小利贞"**——**不要指望退能带来好处，它只带来"通"。** |

## 二、爻级字段

> ⚠️ **本卦六爻是一条"退的质量阶梯"**，且它的排序方式与其他卦不同：
> **不是按时间先后排，是按"退得干净的程度"排**——
> **遯尾（落在最后，厉）→ 执之用黄牛之革（把决心捆死）→ 系遯（有牵挂，退不掉，厉）→ 好遯（心里乐意地退，君子吉）→ 嘉遯（退得体面，贞吉）→ 肥遯（退得宽绰无牵，无不利）。**
> **判词从"厉"一路升到"无不利"，位置越高、越远，结果越好。这与绝大多数卦"上爻物极必反"的走势完全相反**（原因见第四节）。

### 初六 · 遯尾

| 字段 | 内容 |
|---|---|
| **爻辞** | 遯尾，厉，勿用有攸往。 |
| **象传** | 遯尾之厉，不往何灾也。 |
| **位属性** | 阴爻居阳位，**不当位**（艮在下 → 初不当位）；居全卦最下——**退的队列里最后那一个**；与九四相应 |
| **判词 → 行动语义** | **厉**（按本库口径：**警告，非判死**）**＋ 勿用有攸往**（明确禁令） → **不要再往前动；停在原地就没有灾** |
| **关键词解** | **尾**＝末尾、最后。**遯尾**＝**退在最后面**（撤退时排在队尾，是最危险的位置）。**勿用有攸往**＝**不要有任何前往的动作**（"攸往"＝所往，同小畜、恒卦辞用法）。 |
| **⚠️ 象传把解药直接写出来了："不往何灾也"** | **"不往，哪来的灾？"**——**这是全书最省力的一条解药：什么都不做就解决了。**<br>**为什么？** 因为初六的问题不是"它做错了什么"，是**"它已经错过了时间"**：该走的人都走了，它还在最后。**此时任何"补一步"的动作都会把它暴露在最危险的位置上。**<br>**结论：遯卦初爻的病是"太晚"，而太晚的解药不是"赶紧追"，是"就地停住"。** |
| **⚠️ 与大壮初九的正面对照（一对倒转卦的两个初爻，病症正好相反）** | **大壮初九"壮于趾，征凶，有孚"，象传"其孚穷也"**——**力量刚起来就用在最前端（趾），前进则凶。**<br>**遯初六"遯尾，厉，勿用有攸往"，象传"不往何灾也"**——**退的时候落在最后（尾），前进则有灾。**<br>**⚠️ 一个讲"尾"，一个讲"趾"；一个怕太晚，一个怕太早。**<br>**而两爻的禁令一模一样：都是"别往前"（征凶／勿用有攸往）。**<br>**合读结论（本组最漂亮的一处对称，且完全出自经文用字）：退卦的初爻病在"太晚"，进卦的初爻病在"太早"；但无论太早还是太晚，《周易》给初爻的指令都是同一个——不要动。** |
| **与艮初六的对照（同为"艮在下"的初爻，一好一坏）** | **艮初六"艮其趾，无咎，利永贞"，象传"未失正也"**——本库艮卡的结论是：**"止的代价与止的时机成反比。在'趾'上止，几乎无成本。"**<br>**遯初六却是"厉"。** 为什么同一个结构位置差这么多？<br>**因为两卦的初爻测量的是不同的东西**：**艮初六测"止的早晚"（它止得最早，所以最好）；遯初六测"退的队列"（它排在最后，所以最差）。**<br>**合读结论：同一个"最下面那一爻"，在艮卦是"最早"，在遯卦是"最晚"。读卦时必须先问这一卦的六爻是按什么维度排的。** |
| **识别信号（诊断清单）** | ① 该走的人已经走了一批，你还在；② 你是最后知道消息、或最后行动的那一个；③ 你想"再补一步"把已经出去的损失捞回来（再谈一次、再交一次方案、再投一笔）；④ 你还在等一个明确的信号告诉你该走——**而"浸而长"的处境是不会给你这个信号的。** |
| **该做** | **停住，不要再有任何前往的动作。** 具体：**停止新增投入、停止新的承诺、停止争取。** 然后按六二的方法把决心固定下来。 |
| **不该做** | 追着往前补救。**"勿用有攸往"是明确禁令，而"不往何灾也"说明这条禁令一执行，灾就没了——这是全卦成本最低的一次自救。** |
| **与震上六的呼应（两处"别动"）** | **震上六"震不于其躬，于其邻，无咎"，象传"畏邻戒也"**——雷打在邻居家，正确动作是按住不动、以邻为戒。<br>**遯初六"勿用有攸往…不往何灾也"**——退的队列里落在最后，正确动作是按住不动。<br>**两处都是"不动即无灾"，但触发条件不同：震上六是灾在别人身上（你还没被卷进来）；遯初六是灾正在浸上来（你已经在场内、且落在最后）。** |

### 六二 · 执之用黄牛之革

| 字段 | 内容 |
|---|---|
| **爻辞** | 执之用黄牛之革，莫之胜说。 |
| **象传** | 执用黄牛，固志也。 |
| **位属性** | 阴爻居阴位，**当位且得中**（艮在下 → 二当位）；**与九五相应**——即彖传"刚当位而应"里那个"应" |
| **判词 → 行动语义** | **无吉凶判词，只给一个动作** → **给心志加一道解不开的硬约束** |
| **关键词解** | **执**＝捆绑、系住。**黄牛之革**＝黄牛皮，**古人取其最坚韧**。**莫之胜说**——**"说"通"脱"**：**没有什么能把它解脱开。****固志**＝**使心志坚固。** |
| **⚠️ 本爻是全卦唯一"不谈走不走、只谈心志"的一爻** | 全卦五爻都在谈"退"的形态（尾、系、好、嘉、肥），**只有六二一爻不提退，只讲一个动作：把自己捆死。**<br>**为什么这一爻要这么做？** 因为六二是**全卦条件最好的柔爻**：当位、得中、且与九五（那个"嘉遯贞吉"的最高位）相应。**条件好，就意味着诱因多——上面有人呼应你、下面还有位置留给你、留下来是有道理的。**<br>**所以《周易》对这一爻不下吉凶，只给一根黄牛皮：先把心志钉住，再谈别的。** |
| **⚠️ 与巽初六"武人之贞"的对照（同一味药，象传用词都同源）** | **巽初六"进退，利武人之贞"，象传"进退，志疑也。利武人之贞，志治也。"**——本库巽卡的结论是：**"柔顺的第一个代价不是被欺负，是自己没主意。而《周易》给的药不是'更顺'，是反向的一味刚。"**<br>**遯六二"执之用黄牛之革"，象传"固志也"。**<br>**⚠️ 两处的象传都落在"志"字上：巽初六是"志疑"→"志治"（治理心志），遯六二是"固志"（坚固心志）。**<br>**两爻给的药也完全同类：都不是道理，是一道外部的硬约束。** 巽初六借的是"武人之贞"（一条不可退让的硬线），遯六二用的是"黄牛之革"（一条解不开的绑绳）。<br>**合读结论（可入库为通则）：《周易》处理"心志摇摆"从不用说服，只用约束。凡象传出现"志疑／固志／志治／正志"字样的爻，解法都是"给自己加一道外部硬线"，不是"想通"。**（本卦九五象传"以正志也"是第三例） |
| **识别信号（诊断清单）** | ① 你已经判断出应该退（或应该守住不动），但每隔几天就动摇一次；② 拉你回头的东西是"有人还需要你"、"上面对你不错"、"再等等也许会变好"——**注意这正是六二与九五相应的处境**；③ 你已经反复宣布过决定，又反复推翻；④ 你在靠意志力硬撑这个决定。 |
| **该做** | **加一道"黄牛之革"级别的硬约束——标准是"莫之胜说"（自己也解不开）。**<br>**具体形态**：把决定写下来并告知第三方；设一个不可撤回的时间点；把退路提前处置掉（交还权限、结清账、把接手人定下来）。**关键是这道约束必须不由你当时的心情来执行。** |
| **不该做** | 靠"我想清楚了"来维持决心。**本爻不给吉凶判词，等于说：《周易》在这一爻不评价你的结果，只检查你有没有把志固住。** |
| **与咸六二的对照（同为当位得中的六二，动作方向相反）** | **咸六二"咸其腓，凶，居吉"，象传"顺不害也"**——**当位得中，条件最好，唯一的动作是"居"（不动）。**<br>**遯六二"执之用黄牛之革"，象传"固志也"**——**当位得中，条件最好，唯一的动作是"把志捆死"。**<br>**两爻同位、同属性、都不许"顺着感觉走"。** 差别在于：**咸六二要防的是"忍不住迈腿"（外向的动作），遯六二要防的是"忍不住回头"（内向的动摇）。**<br>**合读通则：二爻当位得中，条件最好，所以它的风险从不来自条件不足，只来自"忍不住"。** |

### 九三 · 系遯（⚠️ 全卦唯一"想退而退不掉"的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 系遯，有疾厉，畜臣妾吉。 |
| **象传** | 系遯之厉，有疾困也。畜臣妾吉，不可大事也。 |
| **位属性** | 阳爻居阳位，**当位**（艮在下 → 三当位）；**是下艮唯一的阳爻**（本该是"止"的力量所在）；居下卦之顶；本库通则"**三多凶**"；与上九**不相应**（九三阳 ↔ 上九阳，同性相斥）——**全卦唯一失应的一爻** |
| **判词 → 行动语义** | **厉**（警告）**＋ 畜臣妾吉**（有条件、有范围限定的吉） → **退不掉的时候，把范围缩到最小，明确放弃大事** |
| **关键词解** | **系**＝牵系、缠住、绑住。**系遯**＝**想退，却被牵系住**（有放不下的人、事、承诺）。**有疾厉**＝有疾患而危（"疾"既可读作实际的身心出问题，也可读作"病害"）。**畜臣妾**＝养育、照料家中的近人与琐务——**代指范围极小的、具体的、眼前的事。** |
| **⚠️ 象传两句把病和药分开写了** | ① **"有疾困也"**——**有疾而困**。九三**当位、有刚、是下卦唯一的阳**，条件不差，**但它被上下都缠着**：下面是初六六二两个阴（牵挂），上面是三个阳（挡路），**而且它是全卦唯一没有应爻的那一爻**。**所以它不是不想走，是走不动，走不动就"困"，困久了就"疾"。**<br>② **"不可大事也"**——**这是明确禁令，也是本爻的全部处方：不能做大事。**<br>**"畜臣妾吉"不是让你去做小事以求安慰，是《周易》给你划定了一个能力范围：在这个被牵系的状态下，你只在"手边最小的一圈"里有效，超出这一圈就是"厉"。** |
| **⚠️ 与艮六四"止诸躬也"是同一条策略（本库第二例）** | **艮六四"艮其身，无咎"，象传"止诸躬也"**——本库艮卡的结论是：**"乘刚带来的压迫感无法消除，但只要把范围收回到'自己这一身'，就不构成灾。"**<br>**遯九三"畜臣妾吉…不可大事也"**——**被牵系的处境无法消除，但只要把范围收到"手边最小的一圈"，就是吉。**<br>**⚠️ 两爻的机制完全相同：处境不可解，但范围可以收；收到位就不构成灾。**<br>**合读结论（可入库为通则）：《周易》处理"动不了"这类困境，从不给"如何脱身"的办法，只给"如何缩小作战面"的办法。** 已有三例：**艮六四"止诸躬"（收到自己这一身）｜巽六四"田获三品"（收到一个可交付的成果）｜遯九三"畜臣妾"（收到手边最小的一圈）。** |
| **识别信号（诊断清单）** | ① 你已经判断该退，但有人或有事牵住你——家人、下属、老客户、未完的承诺、一份没到期的合同；② 你的身心已经开始出问题（有疾）：睡不好、拖延、无名的疲惫；③ 你还想"在退出之前把那件大事办完"；④ 你发现越想两头都顾，两头都在恶化。 |
| **该做** | **明确放弃大事，把动作缩到"眼前最小的一圈"。**<br>**具体三条**：**① 写下"我这段时间只负责这几件具体的事"（越具体越好）；② 把大事正式交出去或正式搁置，且告知相关方；③ 把"退"的时间点往后放，但把"退"的范围现在就锁死。**<br>**注意"畜臣妾吉"里那个"吉"字**——**缩小范围在本爻不是退让，是唯一被判"吉"的动作。** |
| **不该做** | 一边被牵系一边还要办大事。**"不可大事也"是象传的明确禁令，而"有疾困也"已经告知代价会落在你身上。** |
| **与师六四的对照（两种"不打这一仗"）** | **师六四"师左次，无咎"，象传"未失常也"**——**有实力者的主动战略后撤，退驻扎营，不打这一仗；"未失常"＝退不是失败，是没有违背常理。**<br>**遯九三"系遯，有疾厉"**——**想退而被牵住，退不成。**<br>**两爻的差别是"从容"与"被困"**：师六四是**有得选**（所以"无咎"），遯九三是**没得选**（所以"厉"）。<br>**合读结论：退的质量取决于你是否还有选择权。而选择权是在更早的时候攒的——这就是遯卦"越早越好"的结构原因。** |

### 九四 · 好遯

| 字段 | 内容 |
|---|---|
| **爻辞** | 好遯，君子吉，小人否。 |
| **象传** | 君子好遯，小人否也。 |
| **位属性** | 阳爻居阴位，**不当位**（乾在上 → 四不当位）；已入上乾；本库通则"**四多惧**"；与初六相应 |
| **判词 → 行动语义** | **吉 ／ 否（同一爻内两断，按人而分）** → **在你心里还乐意退的时候就退** |
| **关键词解** | **好**（hào）＝喜好、乐意。**好遯**＝**心里是乐意退的，不是被迫退的**（一说读 hǎo，"退得好"，义可相通）。**否**（pǐ）＝不然、不行、闭塞——**做不到，或者做了也不通。** |
| **⚠️ 本爻的全部信息量在"好"这一个字上** | 全卦五种退法（尾、系、好、嘉、肥），**只有这一爻描写的是"心情"**。<br>**"好遯"＝退的时候心里没有不舍。**<br>**而爻辞立刻说明它的稀缺性：君子做得到（吉），小人做不到（否）。**<br>**⚠️ 关键推论：本爻讲的不是"该不该退"，是"退的窗口期"。**<br>**"心里还乐意退"这个状态是有时限的——一旦变成"舍不得"，就掉到九三的"系遯"（被牵系，有疾厉）。**<br>**所以九四是遯卦全部时间性的落点：退的最佳时点不是形势最坏的时候，是你还不心疼的时候。** |
| **与师六五"长子帅师／弟子舆尸"的句式同构** | **师六五"长子帅师，弟子舆尸，贞凶"，象传"使不当也"**——**同一个动作（带兵），用对人则无咎，用错人则凶。**<br>**遯九四"好遯，君子吉，小人否"，象传"君子好遯，小人否也"**——**同一个动作（退），君子做了吉，小人做不到。**<br>**⚠️ 两爻是本库目前唯一的一对"同一动作、因人而两断"的爻**（本批的恒六五"妇人吉，夫子凶"是第三例）。<br>**合读结论：《周易》在少数几处会把判词的分歧归到"人"而不是"位"或"时"。凡遇此类爻，诊断的第一问不是"我该怎么做"，而是"我是不是做得到这件事的那种人"。** |
| **识别信号（诊断清单）** | ① 你有条件退（还没有被牵住、还有交接的余地）；② **更关键：你现在心里其实是愿意退的**——你不觉得退是损失，也不需要谁来说服你；③ 你的位置不完全正当（不当位）——名分、资格、归属感有一样已经不匹配了；④ 周围有人绝不肯退，并且在质疑你为什么要走。 |
| **该做** | **趁"还乐意"的时候就退。**<br>**具体：把"我什么时候会开始舍不得"当成截止线，在那之前完成退出。** 而不是把"形势什么时候变得足够坏"当成截止线——**因为"浸而长"的坏是没有明显节点的（彖传）。** |
| **不该做** | 等到"舍不得"或"被逼"再退。**那就不再是九四的"好遯"，而是九三的"系遯"（有疾厉）或初六的"遯尾"（厉）。** 本卦的三个"不好"的爻（初六、九三）与三个"好"的爻（九四、九五、上九）之间，分界线就是这个"好"字。 |
| **与乾九四、履九四的对照（三个"四多惧"的处理）** | **乾九四"或跃在渊，无咎"，象传"进无咎也"**——前是尊位后是深渊，**只能进**；**履九四"履虎尾，愬愬，终吉"**——紧邻最高权力，**怕就是安全带**；**遯九四"好遯，君子吉"**——**能走就走，且趁乐意时走。**<br>**三卦的九四都不当位、都在"多惧"之位，出路却是三个方向：跃过去、怕着走、走开。****差别在上面那一爻是什么**：乾九四上面是九五（在位者，不死不休），履九四上面是九五（帝位，须极度戒慎），**遯九四上面是"正在远去的天"（乾在上，本卦的势就是往外走）——所以它可以走。** |

### 九五 · 嘉遯（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 嘉遯，贞吉。 |
| **象传** | 嘉遯贞吉，以正志也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位（乾在上 → 五当位得中）；**与六二相应**——即彖传"**刚当位而应**"所指；**全卦卦主** |
| **判词 → 行动语义** | **贞吉** → **在最高位上主动退场，且把退办成一件体面、有交代的事** |
| **关键词解** | **嘉**＝美善、嘉美、值得称许（如"嘉宾""嘉礼"）。**嘉遯**＝**退得美善、退得体面、退得让人称许。****正志**＝**端正心志。** |
| **⚠️ 本爻是彖传"刚当位而应，与时行也"的落点** | 彖传说全卦有一处"刚当位而应"，**指的就是九五**：**它当位、得中、居尊，还与六二相应——条件是全卦最好的一爻。**<br>**⚠️ 而一个条件最好的人，在遯卦里的正确动作依然是"退"。** 这是本卦对全库最有冲击力的一条：<br>**《周易》不是让"混不下去的人"退，它专门给"位置最正、最有资格留下的那个人"写了一条退法——而且判"贞吉"。**<br>**因为遯卦的处境是"浸而长"（大势在坏），而九五改变不了大势（它只有一个人当位）。****能力最强者在错的大势里，唯一能做好的事就是退得漂亮。** |
| **⚠️ 象传"以正志也"是本爻唯一的条件（也是"嘉"的全部内容）** | **"嘉"不是排场，是"志正"。**<br>**"正志"排除了三种常见的退法**：<br>**① 赌气走**（志在怨）——那不叫嘉，叫"恶"（违背大象传"不恶而严"）；<br>**② 被赶走**（志被动）——那是初六的"遯尾"；<br>**③ 悄悄消失**（无志）——那既不"嘉"，也没有"严"。<br>**"正志"＝先把自己为什么退这件事想端正，然后按这个理由把退办成一件完整的事：交接清楚、话说明白、不带情绪、不留话柄。**<br>**⚠️ 注意本卦第三次出现"志"字**（六二"固志"、九五"正志"，加上巽初六"志治"这条外部呼应）——**遯卦对"志"的要求贯穿全卦：先固志（六二），再正志（九五），最后无所疑（上九）。这是一条完整的心志三段递进。** |
| **识别信号（诊断清单）** | ① 你在最高位、或最有资格留下的位置上（当位、得中、有人呼应）；② 局面正在"浸而长"地变坏，而你确认自己改变不了它；③ 你有能力体面地安排交接；④ 有人在劝你"你最不该走"——**这句话是对的（你确实最有资格留），但它不是理由。** |
| **该做** | **先"正志"，再退。**<br>**具体三条**：**① 把退的真实理由写清楚（对自己），确认里面没有怨、没有赌气；② 把交接办完整（这就是"嘉"）；③ 按大象传"不恶而严"处理关系——不控诉任何人，但边界一次说清。** |
| **不该做** | 因为"我最有资格留下"而留下。**也不要把退变成一次表态或一次清算——那就从"嘉"掉回"恶"。** |
| **⚠️ 本库"五爻专题"的新一例（第十三例）** | 已有：乾九五（居尊而利见大人）、坤六五（有君之权而守臣节）、蒙六五（居尊而不失赤子之心）、离六五（居尊而痛哭）、艮六五（居尊而闭嘴）、师六五（选对人然后放手）、震六五（只守本职）、巽九五（前后各留三日申命）、履九五（位正当反而厉）、兑九五（把孚收回来）、咸九五（居尊而感不到）、恒六五（居尊而必须自己判断）。<br>**遯九五补上第十三种：居尊而主动退场。****它要放弃的特权是——"我最有资格留下"这个特权。**<br>**⚠️ 而在这十三例里，遯九五是唯一一个"位置条件完美（当位·得中·有应），判词也好（贞吉），动作却是离开"的。** 其余十二例都是"如何在位置上自处"。 |

### 上九 · 肥遯（⚠️ 全卦最好的一爻，也是本库上爻排序的关键样本）

| 字段 | 内容 |
|---|---|
| **爻辞** | 肥遯，无不利。 |
| **象传** | 肥遯无不利，无所疑也。 |
| **位属性** | 阳爻居阴位，**不当位**（乾在上 → 上不当位）；居全卦之终、距下面那两个正在生长的阴爻**最远**；与九三**不相应**（同性）——**无应，也无牵** |
| **判词 → 行动语义** | **无不利**（按本库吉凶序：**元吉 ＞ 无不利／大吉 ＞ 吉 ＞ 利 ＞ 无咎…**；**"无不利"＝守本心·顺遂，约等于大吉**） → **退到最远、退到毫无牵系与疑虑** |
| **关键词解** | **肥**＝宽裕、饶足、宽绰（一说"肥"通"飞"，高飞远去；两读义相通，都指"远而无所滞"）。**肥遯**＝**宽绰从容地远退，没有一处黏滞。****无所疑**＝**毫无疑虑、毫无牵挂。** |
| **⚠️ 本爻不当位却是全卦最好的一爻——理由与艮上九完全同构** | 阳居阴位，本是"名不正言不顺"；**但遯卦的德就是"退"，而上九退得最远、最彻底、最无牵挂——所以它是这一卦之德的圆满完成。**<br>**本库艮卡已经给过这条通则的第一例**：艮上九"敦艮，吉"不当位而吉，**"位不正，而德与卦完全相合，所以象传不谈位，只谈'厚'"——这是本库"义理可救位"的实例。**<br>**遯上九是第二例，而且更极端：它拿到的是"无不利"，比艮上九的"吉"还高一档。**<br>**⚠️ 为什么遯上九比艮上九更高？**<br>**因为"止"是停在原地不再往前（还在场内），"退"是离场（不在场内）。****上九距离那两个正在"浸而长"的阴爻最远，而且它与九三不相应——无应即无牵。** 结构上，它是全卦唯一一个**既走得最远、又没有任何绳子拴着**的位置。 |
| **⚠️ 象传"无所疑也"是本爻唯一的质量标准** | **不是"退得多远"，是"心里还有没有疑"。**<br>**对照艮上九的标准是"厚"（以厚终也），遯上九的标准是"无疑"。**<br>**两个标准合起来，就是《周易》给"结束一件事"定的两条验收线**：<br>**① 厚**——不留尾巴、不留后手、不留"万一"（艮上九）；<br>**② 无疑**——不需要向任何人（包括自己）证明当初的决定是对的（遯上九）。<br>**⚠️ 而"无所疑"这条标准最实用的地方是：它是可自查的。** 你只要还在反复复盘"当初走对了没有"、还在关注那边现在怎么样了、还在准备一套说法解释自己为什么走——**那就还没到"肥遯"，还有疑。** |

#### ⚠️ 专项：遯上九 ／ 艮上九 ／ 乾上九 三方对照——"上爻限定"这条通则的决定性证据

**遯卦三句话**：
1. **退判断的是"时"，不是心情**（彖传"与时行也"，与艮卦"时止则止，时行则行"同源）。**而遯卦的时间性落在九四那一个字上——"好"：退的最佳时点不是形势最坏的时候，是你还不心疼的时候。**
2. **处境是"浸而长"（彖传）——坏是一点一点渗上来的，不会有明显信号提醒你走。** 所以退必须自己定时点；等信号，就变成初六的"遯尾，厉"。
3. **正确形态是"不恶而严"（大象传）——态度上不带情绪，边界上一寸不让。** 一旦"恶"（撕破脸、控诉、清算），你就还在场内，等于没退成。

**本卦最反直觉的四条**：
- **卦辞给"亨"（退本身就是通），而它的倒转卦大壮（进）只给"利贞"，连"亨"都没有。** **《周易》对"退"的评价高于对"进"的评价**——彖传还专门给了一句最高级的赞叹："遯之时义大矣哉！"
- **九五当位、得中、居尊、有应，条件全卦最好，而它的正确动作是"退"，判词是"贞吉"。** **《周易》不是让混不下去的人退，它专门给"最有资格留下的那个人"写了一条退法。**
- **上九不当位，却是全卦最好的一爻（无不利），比艮上九"敦艮，吉"还高一档。** **因为退＝止 ＋ 离场：止住的人还在场内，退走的人连场都不在了。**
- **六爻里判词最差的两爻（初六"厉"、九三"厉"）都在下卦（艮），最好的三爻（九四吉、九五贞吉、上九无不利）都在上卦（乾）。** **在遯卦里，越往上、越往外、离那两个正在生长的阴爻越远，结果越好——这与"上爻物极必反"的常规走势完全相反**（原因见第四节）。

## 四、⚠️ 本卡对全库的意义

### 1. ⚠️ 遯／大壮：什么时候该退、什么时候该进（本组必须写成的一张表）

**结构核对（机械可验）**：
- **遯 33**（上乾下艮）六爻自下往上：**阴 阴 阳 阳 阳 阳**
- 整卦上下颠倒：**阳 阳 阳 阳 阴 阴** ＝ **大壮 34**（上震下乾）✓
- **两卦互为覆卦（倒转卦）**，且序卦传把它们直接串起来："**物不可以久居其所，故受之以遯**"→"**物不可以终遯，故受之以大壮**"。

| 判别项 | **遯 33（退）** | **大壮 34（进）** |
|---|---|---|
| **卦象** | 上乾（天）下艮（山）——天在上不断远去，山追不上 | 上震（雷）下乾（天）——雷响在天上，四阳自下同升 |
| **阴阳形势** | **二阴在下，正在往上长**（彖传"**浸而长也**"） | **四阳在下，正在往上升**（彖传"**大者壮也，刚以动**"） |
| **大势方向** | **坏的东西在慢慢长大，且是渐变的** | **好的力量在整体上升，且已成势** |
| **你能否改变大势** | **不能**（九五这个最有资格的人也只能退） | **能推进，但不能靠蛮力**（九三撞藩伤角，九四靠势冲开） |
| **卦辞** | **亨，小利贞** | **利贞** |
| **卦辞给了什么／缺了什么** | **给"亨"**（退本身就是通）；**"利贞"前加"小"**（大势在坏，收益有限） | **只有"利贞"两字，无元无亨**——**壮盛不许诺通达，唯一的利来自"正"** |
| **彖传定性** | **遯而亨也 / 与时行也 / 遯之时义大矣哉** | **大者壮也 / 刚以动，故壮 / 大者正也** |
| **大象传（唯一的纲领）** | **远小人，不恶而严**——**拉开距离，不带情绪，边界分明** | **非礼弗履**——**给自己划一条"不走"的路** |
| **最好的爻** | **上九"肥遯，无不利"**（退到最远，无所疑） | **九四"藩决不羸，贞吉悔亡"**（势到，藩自己开了） |
| **最危险的爻** | **初六"遯尾，厉"**（该走时落在最后）／**九三"系遯，有疾厉"**（被牵住退不掉） | **九三"小人用壮…贞厉"**（有力量而逞强）／**上六"不能退，不能遂，无攸利"**（撞完卡死） |
| **初爻的病** | **太晚**（遯**尾**，落在队尾） | **太早**（壮于**趾**，力量刚起就用在最前端） |
| **失败的典型形态** | **系**（牵挂放不下） | **触藩**（撞硬障碍） |
| **时间／质量的关键** | **越早越好、越远越好**（初六最晚→厉；上九最远→无不利） | **越正越好**（力量不能替代正当性；九三当位而"贞厉"，九四不当位而"贞吉"） |
| **判别一句话** | **"我改变不了它，而它正在慢慢变坏"** | **"我有力量了，问题是往哪用、能不能用"** |

> **⚠️ 这一对最重要的结论（也是本组四卦最有价值的一条）：序卦传把退与进串成了一条时间链，而不是两个选项。**
> **"恒者，久也。物不可以久居其所，故受之以遯。遯者，退也。"→"物不可以终遯，故受之以大壮。"**
> **《周易》的逻辑是：久（恒 32）→ 不可以久居其所 → 退（遯 33）→ 不可以终退 → 壮（大壮 34）。**
> **所以"我该退还是该进"这个问题本身就问错了。正确的问题是："我在这条链上的哪一段？"**
> **判别的依据是彖传给的两个词：如果你看到的是"浸而长"（坏在渐渐上来），你在遯；如果你看到的是"刚以动"（自己的力量已经成势），你在大壮。**

> **⚠️ 第二条结论：《周易》给退的评价高于给进的评价。**
> **遯卦辞有"亨"，大壮卦辞连"亨"都没有（只有"利贞"）；遯彖传有"遯之时义大矣哉"这句最高级的赞叹，大壮彖传只说"大者正也"。**
> **这与本库已有的口径完全一致**：师卦（战争）"只有贞"，讼卦"终凶"——**《周易》一贯不鼓励扩张与对抗，而对"退""止""不动"给出的评价远比直觉高。**

### 2. ⚠️ 遯／艮的分界：本库"该停"与"该退"两卦的定域切线

本库已有艮卡（52）专讲"止"，遯卡是它最容易混的邻居。**分界必须写清，否则路由会错**：

| | **艮 52（止）** | **遯 33（退）** |
|---|---|---|
| 定义 | **你有能力继续，但你决定不继续** | **你有能力留下，但你决定不留下** |
| 动作 | **停在原地不再往前**（还在场内） | **离开这个场**（不在场内） |
| 判断依据 | **时**（彖传"时止则止，时行则行"） | **时**（彖传"与时行也"）——**两卦同源** |
| 卦辞 | **只给"无咎"**（最吝啬） | **亨，小利贞**（给了"亨"） |
| 最高层纲领 | **思不出其位**（连念头都不越界） | **远小人，不恶而严**（拉开距离，边界分明） |
| 上爻 | **敦艮，吉**（以厚终也）——**标准是"厚"** | **肥遯，无不利**（无所疑也）——**标准是"无疑"** |
| 最痛的一爻 | **九三"艮其限，列其夤，厉"**（止的位置错了，在承重处硬切） | **九三"系遯，有疾厉"**（被牵系，退不掉） |
| 处理"动不了"的方法 | **六四"止诸躬也"**（收回到自己这一身） | **九三"畜臣妾吉，不可大事也"**（收到手边最小的一圈） |

> **⚠️ 路由用法**：**问一句"你还打算待在这个场里吗？"**
> **打算待，但不往前 → 艮。**
> **不打算待 → 遯。**
> **想待但出不去（没有退出权）→ 坎。**
> **⚠️ 而两卦的九三与四位处理方式高度同构（都是"缩小范围"），说明它们共享一个底层机制：艮在下的卦，第三爻是"想收手而收不干净"的高风险位，解法一律是缩小作战面，不是脱身。** 这为规格第 4 节的"艮在下＝止在内、自己收手"补上了具体形态。

### 3. ⚠️ 本卦为规格第 3 节"上爻限定"提供的决定性证据

**规格原文**：「⚠️ **上爻限定**：反的是"不知止的极"，不是"到顶"本身。过刚则悔，过柔则凶，知止则吉，无内容则白过。」

**遯上九／艮上九／乾上九三爻的位属性完全相同（第六位、阳爻、阳居阴位不当位、各卦之顶），判词横跨三档（悔／吉／无不利），唯一的变量是"到顶之后做了什么"。**

> **⚠️ 建议把这条通则修订为**：
> **"上爻限定：反的是'不知止的极'，不是'到顶'本身。**
> **还在顶点上使劲的三种走法：过刚则悔（乾上九）、过柔则凶（巽上九）、过动则凶（恒上六）。**
> **不再停留在顶点的三种走法：知止则吉（艮上九"敦艮"，标准是厚）、知退则无不利（遯上九"肥遯"，标准是无疑）、入循环则元吉（履上九"其旋"，标准是复盘后重来）。**
> **另有一档：无内容则白过（兑上六"引兑"，未光）。"**
>
> **这条修订的核心增量是把"知止则吉"扩成三级递进：止（吉）＜ 退（无不利）＜ 循环（元吉）。**
> **三者的差别是"离开顶点的彻底程度"**：**止＝不再往前但人还在；退＝人也走开；循环＝把终点接成新的起点，所以根本没有"顶点"这回事。**
> **这与本库已有的判断完全咬合**：履卡已提炼"**《周易》给出的终极解药从来不是'到达顶点'，而是'进入循环'**"（乾用九 ＋ 履上九）。**遯上九与艮上九补上了这条阶梯中间的两级。**

### 4. 本卦补上的机制缺口

| 缺口 | 遯卦补的内容 |
|---|---|
| **本库有"止"（艮）、"久困"（坎）、"按住不动"（震上六），但没有"离场"** | **遯卦是本库第一张专讲"退出"的卡**，并且它给退定了两条验收线：**事上"不留尾巴"（借艮上九的"厚"）、心上"无所疑"（上九）。** |
| **"渐变型危机"这个处境在本库无处归口** | 本库现有的危机卦全是"突变"或"已陷"：**震＝突然砸下来（七日得）、坎＝已陷且长期（三岁不得）、屯＝草创维艰。**<br>**遯卦彖传"浸而长也"补上了第三种：慢慢渗上来。** 而它的应对方式与前两种完全不同：**震要按住不动等七日，坎要"维心亨"求小得，遯要趁早离场。** **判错型别，代价极大。** |
| **"义理可救位"这条通则只有一个孤例** | 艮卡提出：艮上九不当位而吉，**"位不正，而德与卦完全相合，所以象传不谈位，只谈'厚'"。**<br>**遯上九是第二例，而且更强（无不利 ＞ 吉）。两例合起来，"义理可救位"可以从"实例"升格为通则：当一爻的动作与本卦卦德完全相合时，象传会绕过位属性，直接给德下判词。** |
| **"心志摇摆"这类问题缺一套统一解法** | **遯卦贯穿全卦的"志"三段（六二"固志"→ 九五"正志"→ 上九"无所疑"），加上巽初六"志治也"，构成本库第一条完整的"心志处理链"**：<br>**先固志（加外部硬约束）→ 再正志（把理由端正）→ 最后无疑（清掉复盘与辩护的冲动）。**<br>**⚠️ 而这四处的共同点是：《周易》从不用"想通"来处理摇摆，只用"约束"。** |
| **路由表缺两条高频困境** | ① **"这里在慢慢变坏，但还没坏到必须走的程度"**——这正是遯卦"浸而长"的原文处境，本库现有各卦都答不了。**遯九四给的答案是一个时点判据："趁你心里还乐意走的时候走。"**<br>② **"我明明是最有资格留下的人，凭什么我走"**——**遯九五"嘉遯，贞吉"就是给这个人写的。** |

### 5. 本卡打开的下一步（优先建议）

> **首选：大壮 34（上震下乾）**——**与本卦是倒转对，必须合读**（本批已同步产出）。
> 其次：**否 12（上乾下坤）· 本库已有，建议重读**——**否＝天地不交、上下不通，是"大势已坏"的定局态；遯＝大势正在坏（浸而长），是"定局之前"的动态。** 本库已有泰否卡，**读完遯卡之后，泰否那张卡的"否"半边就多了一个时间维度：遯是否的前夜。** 这条衔接不需要新卡，只需在索引里补一行。
> 第三：**大畜 26（上艮下乾）**——它是**遯卦的上下卦交换**（遯＝上乾下艮，大畜＝上艮下乾）。艮卡已给出结构律"**艮在上＝被压住不许动**"；**遯（艮在下，自己收手）与大畜（艮在上，被压住蓄而不发）合读，可以把艮在复合卦里的两种叠加方式一次读完。** 且大畜与本库已有的小畜（9）构成"大／小"一对，是现有卡片最近的一个缺口。
> 第四：**谦 15（上坤下艮）**——艮卡已把它列为首选建议（"已有实力者如何自处"）。**遯卡为它补上第二个理由：遯讲"退出这个场"，谦讲"留在场内但把自己放低"——两卦是"有实力者"的两条不同出路，合读才完整。**
