# 知识卡 34 · 大壮卦（雷天大壮）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："遯者，退也。物不可以终遯，故受之以大壮。"——**不可能一直退下去，所以退之后接"壮"。《周易》给"退"也划了边界：可以退，不可以终退。**
> **本卦与遯卦（33）是一对，且是结构上的倒转（覆卦）**：遯卦六爻自下往上"阴阴阳阳阳阳"，整卦上下颠倒即得大壮"阳阳阳阳阴阴"。**遯＝退避，大壮＝壮盛。这一对是"什么时候该退、什么时候该进"的直接对照，合读表见遯卡第四节第 1 条。**
> ⚠️ **本卡两条最重要的线索**：
> **① 卦辞只有"利贞"两字（无元、无亨），而大象传给壮盛之时定了唯一一条约束——"非礼弗履"。**这条纲领里用的正是**履卦（10）**的那个"履"字：**履讲"怎么走"，大壮讲"有力量时哪条路不走"。**
> **② 九三"小人用壮，君子用罔，贞厉"与九四"藩决不羸，贞吉悔亡"是全卦核心对照**——**同一道篱笆，九三撞它伤了角，九四把它冲开了。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 大壮 · 第三十四卦 |
| **卦象** | 上震（雷/动）下乾（天/健），称"雷天大壮"。**雷本在天下响，此卦却是"雷在天上"**（大象传"雷在天上，大壮"）——**声势极大，位置极高。**<br>**四阳自下而上、连成一片，两阴退居最上**——**阳（大者）已成压倒之势**，故彖传曰"**大者壮也**"；下乾健、上震动，故"**刚以动，故壮**"。<br>按本库第 4 节结构律，本卦是**"乾在下 ＋ 震在上"的叠加**：<br>**乾在下 → 初九当位、九二不当位（得中）、九三当位**；<br>**震在上 → 九四不当位、六五不当位（得中居尊）、上六当位**。<br>**⚠️ 乘刚**：按规格通则"震在上则六五必乘刚"——**六五直压九四之上，六五乘刚，验证通过。** 而六五恰恰是那个"丧羊"的爻。 |
| **领域定义** | **有实力时如何行动**。势头正盛、团队正强、拿到大笔资源、刚升上高位、连胜期、掌握了压倒性优势、行业风口上、自己成了那个说得上话的人。凡是"**我现在有力量了，问题是往哪用、能不能用、用到什么程度**"，都落在大壮卦。 |
| **不归本卦的情况** | ① 力量还没起来、在纠结要不要冒头 → **乾卦（1）初九、九二**；② 大势在慢慢变坏、该不该离场 → **遯卦（33）**；③ 该不该停手、该不该收 → **艮卦（52）**；④ **力量不足，要在远比自己强大的结构里安全通行 → 履卦（10）**；⑤ 没有强制力、只能柔性渗透 → **巽卦（57）**；⑥ 已经组织化要打一场硬仗 → **师卦（7）**。<br>**⚠️ 大壮与履卦的分界是本卡最需要说清的一条**：**履＝你弱，对方强（履虎尾）；大壮＝你强（大者壮也）。****同一件事"怎么处世"，力量方向一反，方法就完全不同**（详见第四节）。<br>**⚠️ 大壮与乾卦的分界**：**乾是主导者从无名到衰落的完整生命周期（一条抛物线）；大壮只截取其中"力量已成势"的那一段，并且只讲一件事——这股力量该怎么受约束。** |
| **"大壮"字义** | **"大"＝阳、大者**（《周易》以阳为大、阴为小）；**"壮"＝盛、强健。**<br>**⚠️ 但彖传立刻把"大"重新定义了一遍："大壮利贞，大者正也。"**<br>**——"大"的本质不是"壮"，是"正"。**<br>**这是本卦最容易被跳过、也最关键的一次训解**：**不正就不叫"大"，只叫"壮"。** 而卦名把"大"放在"壮"前面，说明**"正"是"盛"的前提，不是它的装饰。**<br>**九三"小人用壮，君子用罔"就是这句话在爻上的落实：小人拿"壮"当依据，君子当它不存在。** |
| **卦辞原文** | 大壮：利贞。 |
| **⚠️ 卦辞的关键结构（本卦性格全在这里）** | **只有"利贞"两个字。无元、无亨、无别的许诺。**<br>**这是全书最吝啬的几条卦辞之一。** 与本库已有各卦对照： | 

| 卦 | 卦辞 | 给了什么 | 本库口径 |
|---|---|---|---|
| **乾 1** | 元，亨，利，贞 | **四德全给** | 主导者之路，四个指标齐备 |
| **兑 58** | 亨，利贞 | 亨 ＋ 利贞 | 承认愉悦是真正通得开的路 |
| **恒 32** | 亨，无咎，利贞，利有攸往 | 四项（缺元） | 恒久给得很足，但不是启动 |
| **遯 33** | 亨，小利贞 | 亨 ＋ 小利贞 | **退本身就是通**，但收益有限 |
| **师 7** | 贞，丈人吉，无咎 | **只有贞** | 天道对战争不许诺好处 |
| **艮 52** | （艮其背…）无咎 | **只有无咎** | 止不许诺好处，只说不会有灾 |
| **⚠️ 大壮 34** | **利贞** | **只有利贞** | **壮盛不许诺通达，唯一的利来自"正"** |

| 字段 | 内容 |
|---|---|
| **⚠️ "只有利贞"的含义（本卦最反直觉的一条）** | **缺"元"**——按本库口径，元＝敢于启动、去做去拼。**壮盛之时，《周易》不给"元"：不鼓励你借着势头再开新局。**<br>**缺"亨"**——亨＝懂规律、顺人性，让人才资源汇聚。**《周易》不给"亨"：有力量不等于路会通。** 这一条极重要——**它把"壮"和"通"彻底分开了。**<br>**只给"利贞"**——**你唯一能从这股力量里拿到好处的方式，是守正。**<br>**⚠️ 对比它的倒转卦遯（退）：遯卦有"亨"，大壮（进）连"亨"都没有。****《周易》对"退"的评价高于对"进"的评价**——这与师卦"只有贞"、讼卦"终凶"是同一个态度。 |
| **卦辞现代解** | **利**——有益、可行；**贞**——正。合起来：**在你最强的时候，能给你带来实际好处的只有一件事：正当。**<br>**深意：大壮卦不讨论"怎么把力量用大"，它默认你的力量已经足够大了（四阳同升）。它讨论的唯一问题是"怎么不让这股力量伤到你自己"——而答案是"正"。** |
| **彖传** | 大壮，大者壮也。刚以动，故壮。大壮利贞，大者正也。正大而天地之情可见矣。 |
| **⚠️ 彖传要点（全书最短的彖传之一，四句每句都是定性）** | ① **"大者壮也"**——**壮的是"大者"（阳、正大之物），不是"力气"。**<br>② **"刚以动，故壮"**——**下乾之刚 ＋ 上震之动 ＝ 壮。** 注意顺序：**先有刚（实力），后有动（行动）；壮是这两者的结果，不是原因。**<br>③ **"大壮利贞，大者正也"（本卦纲领句）**——**"大"就是"正"。****不正的盛，不配称"大"。**<br>④ **"正大而天地之情可见矣"**——**正而且大，天地的实情就显现了。**（对照咸卦彖传"观其所感，而天地万物之情可见矣"、恒卦"观其所恒…"——**咸看"所感"、恒看"所恒"、大壮看"正大"，这是《周易》三处相同句式的收尾**。） |
| **大象传（行动纲领）** | 雷在天上，大壮。君子以非礼弗履。 |
| **⚠️ "非礼弗履"解（本卦最高层原则，也是全卦唯一的约束）** | **雷响到天上去了——声势已经大到极处。** 而君子在这种时候的动作，《周易》只给了四个字：**非礼弗履。**<br>**"非礼"＝不合于礼的（礼＝分际、规矩、该有的边界）；"弗履"＝不去踩、不去走。**<br>**⚠️ 全句：不合于礼的路，一步都不走。**<br>**⚠️ 三条必须讲清的点**：<br>**① 它是一条"不做"的纲领，不是"做"的纲领。** 大象传对壮盛者提的唯一要求是划一条禁行线。**因为壮盛者不缺力量、不缺办法、不缺理由——他缺的是"不走"的理由。**<br>**② 它不是"低调"、不是"节省"、不是"收敛"。** 那些都是减少力量的使用量；**"非礼弗履"不管用量，只管方向：可以全力走，但只走合礼的路。**<br>**③ ⚠️ 它用的正是履卦（10）的那个"履"字。** 履卦大象传是"**辩上下，定民志**"（位分清楚），讲弱者如何在强势结构中安全行走；**大壮大象传"非礼弗履"，讲强者如何给自己设禁行线。****同一个"履"（走），两卦从力量的两端各写了一半。**（详见第四节） |
| **总铁律** | ① **卦辞只给"利贞"**——壮盛不许诺通达，唯一的利来自"正"（彖传"大者正也"）；② **唯一的约束是"非礼弗履"**（大象传）——**给自己划一条不走的路**；③ **不可"用壮"**（九三）——**有力量的人最大的风险是拿"我有力量"当决策依据**；④ **趾上不可壮**（初九"壮于趾，征凶"）——力量刚起来就用在最前端必凶；⑤ **藩要靠势冲开，不能靠角去撞**（九三"羸其角"／九四"藩决不羸"）；⑥ **顶不住的时候要"丧羊"**（六五）——**主动放掉那个正在顶你的东西才无悔**；⑦ **卡死了就认艰**（上六"无攸利，艰则吉"）——不要再撞，也不要找巧路。 |

## 二、爻级字段

> ⚠️ **本卦六爻是一条"力量与阻碍"的完整剧本，核心意象是"羝羊触藩"（公羊撞篱笆）**：
> **趾（力量刚起，不可用）→ 中（守正即可）→ 撞（羸其角，贞厉）→ 冲开（藩决不羸，贞吉悔亡）→ 放羊（丧羊于易，无悔）→ 卡死（不能退不能遂，艰则吉）。**
> ⚠️ **"羝羊触藩"四个字在九三与上六两处重复出现，判词却完全不同**——**这是全书第二组"同辞异断"教材**（第一组是巽卦九二／上九的"巽在床下"，见巽卡）。对照表见上六一节。

### 初九 · 壮于趾

| 字段 | 内容 |
|---|---|
| **爻辞** | 壮于趾，征凶，有孚。 |
| **象传** | 壮于趾，其孚穷也。 |
| **位属性** | 阳爻居阳位，**当位**（乾在下 → 初当位）；居全卦最下——**力量的最前端、最开始**；与九四**不相应**（同性相斥） |
| **判词 → 行动语义** | **征凶**（前进则凶） → **力量刚起来的时候，不要用在最前端** |
| **关键词解** | **壮于趾**＝**强壮表现在脚趾上**（趾＝动作的最前端、最开始）。**征**＝出行、有所行动、往前进。**有孚**＝有诚信、有所确信（此处指**"他自己是确信的"**）。**其孚穷也**＝**他那份确信会走到困穷。** |
| **⚠️ 象传"其孚穷也"是本爻最狠的一句** | **爻辞给了"有孚"（他有诚信、有确信），象传立刻说这份确信会"穷"。**<br>**这不是说他不诚实，而是说：**<br>**他的确信是真的，但确信不能替代时机。**<br>**当位（阳居阳位）＋有孚（内心笃定）＋力量刚起 —— 三个条件凑在一起，恰恰是最容易冲出去的组合，而《周易》判"征凶"。**<br>**结论：本爻的凶不来自能力不足，也不来自品德，来自"位置太低而动作太前"。** |
| **⚠️ 与遯初六的正面对照（一对倒转卦的两个初爻，病症正相反）** | **遯初六"遯尾，厉，勿用有攸往"，象传"不往何灾也"**——**退的时候落在最后（尾），前进则有灾。**<br>**大壮初九"壮于趾，征凶，有孚"，象传"其孚穷也"**——**进的时候力量刚起就用在最前端（趾），前进则凶。**<br>**⚠️ 一个讲"尾"，一个讲"趾"；一个怕太晚，一个怕太早。**<br>**而两爻的禁令完全一样：别往前（勿用有攸往／征凶）。**<br>**合读结论（本组最漂亮的一处对称，且完全出自经文用字）：退卦的初爻病在"太晚"，进卦的初爻病在"太早"；但无论太早还是太晚，《周易》给初爻的指令都是同一个——不要动。** |
| **⚠️ "脚趾"三卦对照（本组的一条延伸发现）** | **艮初六"艮其趾，无咎，利永贞"，象传"未失正也"**——**止在趾上，零成本，是艮卦最省力的一爻。**<br>**咸初六"咸其拇"（拇＝大脚趾），象传"志在外也"**——**感在拇上，无判词，不奖不罚。**<br>**大壮初九"壮于趾，征凶"，象传"其孚穷也"**——**壮在趾上，凶。**<br>**⚠️ 同一个脚趾，止之则无咎，感之则志在外，壮之则征凶。**<br>**结论（与咸卡第四节同源）：身体部位在《周易》里没有固定吉凶，吉凶由卦德与动作决定。** |
| **识别信号（诊断清单）** | ① 你刚有了一点实力、一点势头、一笔资源、一个名分；② 你最想做的就是马上往前走一步把它证明出来；③ 你内心非常确信自己是对的（有孚）——而且这份确信很真诚；④ 你的理由是"趁热打铁"、"窗口期不等人"。 |
| **该做** | **不动。把"壮"留在下面，不让它出现在最前端。**<br>**具体：把这股新起的力量用在加厚底盘上（能力、现金、人、口碑），不用在"往前一步"上。** 参照乾初九"潜龙勿用"——**核心在"潜"不在"勿"。** |
| **不该做** | 用刚起来的力量抢先走一步。**⚠️ 象传"其孚穷也"给出的代价很特别：不是损失钱或位置，是"你的自信本身会被耗尽"。** 一次过早的前冲，代价是以后你不再相信自己的判断。 |
| **与乾初九、乾九二的对照** | **乾初九"潜龙勿用"——没人知道你，也没资源，指令是守·蓄力**；**乾九二"见龙在田，利见大人"——所有人都看到你了，指令是进，但必须借力。**<br>**大壮初九的处境在两者之间：力量已经有了（不是潜龙），但还在最下面（不是见龙）。**<br>**而《周易》在这里给的不是"借力"，是"别动"。** 差别在卦境：**乾卦讲的是一条上升路径（所以九二要往上找大人）；大壮讲的是一股已成的势（所以初九只要等这股势自己升上去，不必自己往前跑）。** |

### 九二 · 贞吉

| 字段 | 内容 |
|---|---|
| **爻辞** | 贞吉。 |
| **象传** | 九二贞吉，以中也。 |
| **位属性** | 阳爻居阴位，**不当位**（乾在下 → 二不当位），**但得中**；与六五相应 |
| **判词 → 行动语义** | **贞吉** → **守正，什么都不加** |
| **关键词解** | **爻辞只有两个字，是全卦最短、也是全书最短的爻辞之一**（对照恒九二"悔亡"、震九四"震遂泥"）。**以中**＝**因为它得中。** |
| **⚠️ 本爻是全卦最省事的一爻，而理由只有两个字："以中"** | **在一个阳刚过盛的卦里（四阳同升），九二的价值恰恰在于"不满"**：<br>**它有刚（阳爻），所以有实力；它居阴位（不当位），所以不硬、不逞强、不自以为名正言顺。**<br>**⚠️ 对照本卦九三：九三当位（阳居阳位），刚而在刚位，判"贞厉"（警告）。**<br>**一个不当位的九二判"贞吉"，一个当位的九三判"贞厉"——在大壮卦里这不是偶然，是"过刚必危"的直接体现。**<br>**结论：在盛壮之卦里，"位置不那么正"反而是一种保护。** |
| **本爻是"得中可救不当位"的又一实例** | 按本库通则"**⚠️ 得中可救不当位**"——九二阳居阴位、名不正言不顺，**但得中**，象传就只给这一个理由。<br>**⚠️ 本库现有四个"不当位而得中的九二"，判词全部靠"中"来救，且四卦给"中"的内容各不相同**： | 

| 卦 | 九二爻辞 | 判词 | 象传 | 得中的具体形态 |
|---|---|---|---|---|
| **大壮 34** | 贞吉（两字） | **贞吉** | **以中也** | **在力量上不满**——刚而处柔位 |
| **恒 32** | 悔亡（两字） | **悔亡** | 能久中也 | **在时间上不偏**——久 |
| **履 10** | 履道坦坦，幽人贞吉 | **贞吉** | 中不自乱也 | **在心态上有余量**——不自乱 |
| **巽 57** | 巽在床下，用史巫纷若，吉，无咎 | **吉·无咎** | 得中也 | **在姿态上能放到最低**——低姿态＋高频沟通 |

| 字段 | 内容 |
|---|---|
| **四方对照的结论** | **四个九二全部"阳居阴位、不当位、得中"，象传全部只给"中"这一个理由。**<br>**这是本库通则"得中可救不当位"目前最整齐的一组证据。**<br>**而所谓"得中"不是一个位置属性，是"在这一卦最容易失衡的那个维度上不失衡"。** 大壮最容易失衡的维度是**力量**，所以大壮的"中"＝力量上不满。 |

### 九三 · 小人用壮，君子用罔（⚠️ 本卦核心之一）

| 字段 | 内容 |

| **爻辞** | 小人用壮，君子用罔，贞厉。羝羊触藩，羸其角。 |

| **⚠️ 本爻是全卦的核心警告，"用壮"与"用罔"的分野是全书最锋利的一处对照** | **同样有力量，两种用法**：<br>**小人"用壮"——把"我强"当成行动的理由**：我撞得过去、我扛得住、我有资源、他们拿我没办法。<br>**君子"用罔"——把"我强"当成不存在**：这件事该不该做，按理、按分际判断，**与我强不强无关。**<br>**⚠️ 这就是大象传"非礼弗履"在爻上的落实**：**"礼"是判断依据，"壮"不是。**<br>**而"用壮"的结果，爻辞用一个画面写完了：公羊去撞篱笆，撞坏的是自己的角。**<br>**⚠️ 注意"羸其角"这三个字的准确性：篱笆没坏，坏的是角——而角正是这只羊赖以为"壮"的那个东西。****用壮的代价，是把你之所以强的那个东西损掉。** |
| **⚠️ 为什么当位反而"贞厉"（本爻结构上最重要的一点）** | **九三阳居阳位、当位；居下乾之顶；是四阳里力量最满、名分最正的那一爻。条件几乎是全卦最好的。**<br>**判词却是"贞厉"——连守正也危。**<br>**⚠️ 这与履九五完全同构。** 本库履卡指出：**履九五"夬履，贞厉"，象传"位正当也"——"正因为你位置太正当了！位置越正当，越容易变得刚决独断；越刚决独断，越危险。权力的正当性本身就是过度自信的来源。"**<br>**大壮九三是这条判断的第二例，而且这一次《周易》把病名直接写出来了："用壮"。** |

### 六五 · 丧羊于易（⚠️ 乘刚，且是"乘刚"的第五种解法）

| 字段 | 内容 |
|---|---|
| **爻辞** | 丧羊于易，无悔。 |
| **象传** | 丧羊于易，位不当也。 |
| **位属性** | 阴爻居阳位，**不当位**（震在上 → 五不当位；**象传直接点名"位不当也"**），但**得中**且居尊位；**直压九四之上——乘刚**（验证规格"震在上则六五必乘刚"）；与九二相应 |
| **判词 → 行动语义** | **无悔**（"没有悔"级，与"悔亡"同档，**不是得利级**） → **主动放掉那只要去撞藩的羊** |
| **关键词解** | **丧**＝失去、放掉。**羊**＝**即前面那只"羝羊"**（那股要去撞藩的刚猛力量）。**易**＝二读并存：① **通"埸"（yì），田界、疆界**——在边界处丧羊；② **平易之地**——在平坦无险处丧羊。<br>⚠️ **两读义可相通，都指"不是在险处丢的，是在边界／平地上放掉的"**——**即"不是被抢走，是自己放的"。**（此为训解上的两说，非经文异文。） |
| **⚠️ 本爻是全卦唯一"主动放弃力量"的一爻** | **六五居尊位，但它不当位（象传专门点名），而且乘刚——下面顶着九四那股刚刚冲开篱笆、正在往上升的力量。**<br>**它挡不住，也不该挡。**<br>**所以爻辞给的动作是"丧羊"：把那只羊放掉。**<br>**⚠️ 而判词是"无悔"——不是"吉"，是"没有悔"。****含义极准确：放掉是唯一不留悔的选项，但它本身不带来任何好处。**<br>**这与本卦卦辞"只有利贞"完全一致：壮盛之卦里，居尊者的最好结果就是"不留悔"。** |
| **⚠️ 象传"位不当也"该怎么读** | 有两层，本库取合读：<br>**① 位不当，所以挡不住**——阴居阳位，力量与位置不匹配，硬挡就是与九四对撞。<br>**② 正因为位不当，所以"丧羊"才是对的**——**如果它当位（有力量匹配尊位），那么按住这股力量可能是它的职责；但它不当位，就不该承担这个职责。**<br>**⚠️ 这与兑九五、履九五的象传"位正当也"正好相反**：那两爻是"位正当反而危"（正当性带来过度自信）；**六五是"位不当所以要放手"（不匹配就不要硬接）。**<br>**合读结论：象传的"位当／位不当"从不是评价好坏，是在解释"这个位置该不该接这件事"。** |
| **⚠️ 本爻是"乘刚"的第五种解法（本库至此凑齐五解）** | 规格第 4 节：**"乘刚的破解：① 艮六四'止诸躬'——把范围收回到自己这一身；② 巽六四'田获三品'——交付可分配的实际成果。"** 本批把样本补到五个： |

|---|---|
| **⚠️ 五解合读的通则（建议入库）** | **乘刚带来的顶迫感无法消除（它来自你下面，与你的对错无关），而五个解法里没有一个是"顶回去"。**<br>**它们分别是：缩小范围、交出成果、守住本职、辨明职分、主动放手。**<br>**通则：乘刚只能"处理自己"，不能"处理下面那个刚"。**<br>**而大壮六五是五解中最彻底的一种——前四种都还在"保住某样东西"，只有"丧羊"是直接放弃。** |
| **识别信号（诊断清单）** | ① 你在拍板位置上，但你的条件与这个位置不完全匹配（不当位）；② 下面有强劲上升的力量在顶你（乘刚）——可能是一个人、一支团队、一股趋势；③ 你手上有一件"要去撞的事"（那只羊）：一个正在推进的强硬动作、一个准备硬碰的对手、一个想强推的方案；④ 你在犹豫是按住它、还是跟着它一起撞。 |
| **该做** | **放掉。在边界处（易／埸）把那只羊放走。**<br>**具体：主动放弃那个强硬动作，或者把它交给下面那股力量去做（不再由你按着）。**<br>**⚠️ "无悔"的准确含义是：放掉不会带来好处，但它是唯一不留悔的选项。** 不要期待放手之后有奖赏。 |
| **不该做** | **两个方向都不行**：**① 按住它**（位不当，按不住，会变成与九四对撞）；**② 跟着它一起撞**（那就是九三的"羸其角"，或上六的"不能退不能遂"）。 |
| **本库"五爻专题"的新一例（第十四例）** | 已有十三例（乾九五利见大人、坤六五守臣节、蒙六五赤子之心、离六五痛哭、艮六五闭嘴、师六五选人放手、震六五守本职、巽九五申命、履九五位正当反厉、兑九五收回孚、咸九五感不到、恒六五必须自己判断、遯九五主动退场）。<br>**大壮六五补上第十四种：居尊而主动放弃力量。****它要放弃的特权是——"我可以按住这件事"这个特权。** |

### 上六 · 羝羊触藩（⚠️ 全书第二组"同辞异断"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 羝羊触藩，不能退，不能遂，无攸利，艰则吉。 |
| **象传** | 不能退，不能遂，咎也。艰则吉，咎不长也。 |
| **位属性** | 阴爻居阴位，**当位**（震在上 → 上当位）；居全卦之终、上震之顶；与九三相应——**而九三正是那个"羝羊触藩，羸其角"的爻** |
| **判词 → 行动语义** | **无攸利 ＋ 艰则吉**（先断没有好处，再给一个有条件的吉） → **认下这段艰难，把动作降到最低** |
| **关键词解** | **羝羊触藩**＝公羊撞篱笆（**与九三完全相同的四个字**）。**遂**＝进、达成、往前通过。**不能退，不能遂**＝**退不回来，也过不去——卡死。****无攸利**＝没有任何好处可图。**艰**＝艰难；**艰则吉**＝**处在艰难中（安于艰难、以艰难自处）则吉。****咎不长也**＝**这个过咎不会长久。** |
| **⚠️ 象传把"咎"与"吉"分开归因，是本爻全部的重量** | ① **"不能退，不能遂，咎也"**——**卡死这件事本身，是"咎"（过失）。** 象传不客气：**这个局面是你自己撞出来的。**<br>② **"艰则吉，咎不长也"**——**但如果你能安于艰难，这个咎不会长久。**<br>**⚠️ 结论：本爻的"吉"不来自脱身，来自"承受"。****它是全书少见的一条"以受苦得吉"的爻**，而且《周易》把话说得很实在：**没有好处（无攸利），只有一个承诺——不会一直这样（咎不长也）。** |

#### ⚠️ 专项：九三 ↔ 上六 对照——全书第二组"同辞异断"教材

> **第一组是巽卦九二／上九的"巽在床下"**（见巽卡：同样四个字，一个"吉，无咎"，一个"贞凶"，差别在"得中"与"上穷"）。
> **本卦提供第二组："羝羊触藩"四个字在九三与上六重复出现。**

| 对照项 | **九三** · 羝羊触藩 | **上六** · 羝羊触藩 |
|---|---|---|
| 爻辞相同部分 | **羝羊触藩** | **羝羊触藩** |
| 后续 | **羸其角**（角被缠住） | **不能退，不能遂**（卡死） |
| 位属性 | 阳居阳位·**当位**·下乾之顶·**刚盛** | 阴居阴位·**当位**·上震之顶·**柔而在最上** |
| 阶段 | **正在撞**（力量最满时的动作） | **撞完了**（力量已尽后的结果） |
| 判词 | **贞厉** | **无攸利 ＋ 艰则吉** |
| 象传 | 小人用壮，**君子罔也** | **咎也** ／ **咎不长也** |
| 解法 | **用罔**——把"我有力量"从依据里删掉（**还来得及不撞**） | **认艰**——安于艰难，等它过去（**已经撞了，只能受着**） |

| 字段 | 内容 |
|---|---|
| **⚠️ 这一组对照的结论（可入库为通则）** | **同一个动作（羝羊触藩），在力量最满时是"贞厉"（还有警告的余地），在力量用尽后是"无攸利 ＋ 艰则吉"（只剩承受）。**<br>**差别不在动作，在你处在这个动作的哪一段。**<br>**⚠️ 而两爻正好相应（九三阳 ↔ 上六阴），结构上是同一件事的首尾**：九三是那只羊开始撞，上六是那只羊卡在篱笆上。**《周易》把一个完整的错误从起点写到终点，并且分别给了两种不同的药：起点的药是"别撞"，终点的药是"认艰"。**<br>**这与巽卦那组"同辞异断"的通则同源**：巽卡的结论是"**判断一个'退让／示弱'动作的吉凶，不看动作本身，看做这个动作的人是否还握着决断权**"；**本卡补上第二条判据：不看动作本身，看你处在这个动作的哪一段。** |
| **⚠️ 与遯上九、艮上九、乾上九的对照（"到顶之后"的又一种走法）** | 规格第 3 节"上爻限定"：**"反的是'不知止的极'，不是'到顶'本身。过刚则悔，过柔则凶，知止则吉，无内容则白过。"**<br>**本库上爻按吉凶序**：**履上九元吉（进入循环）＞ 遯上九无不利（离场）＞ 艮上九吉（知止）＞ 离上九无咎（不扩大）＞ 震上六征凶/无咎（畏邻戒）＞ ⚠️ 大壮上六无攸利/艰则吉（承受）＞ 兑上六未光（无内容）＞ 乾上九悔（过刚）＞ 巽上九贞凶（过柔）＞ 恒上六凶（过动）＞ 坤/坎上六凶（不知止/失道）。**<br>**⚠️ 大壮上六在这条序列里的位置很特别：它是唯一一个"已经犯了错、但仍能得吉"的上爻。**<br>**它的"吉"不来自做对了什么，来自"艰则"这个条件——承受。而象传给的理由是时间："咎不长也"。**<br>**建议入库的一条补充：上爻除了"离开顶点"（履、遯、艮）与"还在顶点上使劲"（乾、巽、恒、坤、坎）这两类，还有第三类——"已经撞在顶点上了"（大壮上六）。这一类的唯一出路不是动作，是时间。** |
| **识别信号（诊断清单）** | ① 你已经撞过了——那件强硬的事已经做了，且没有成功；② 现在退不回来（面子、成本、已公开的承诺），也过不去（对方没让、条件没变）；③ 你正在找一个巧办法脱身（换个说法、绕一圈、找人说和、再加一次力）；④ 你觉得这段难受不该由你承受。 |
| **该做** | **认艰。**<br>**具体三条**：**① 明确承认这是自己撞出来的（象传"咎也"，不要向外归因）；② 把动作降到最低——不再加力、不再找巧路、不再解释；③ 按时间等，"咎不长也"是《周易》给的承诺。**<br>**参照艮六四"止诸躬"与遯九三"畜臣妾吉，不可大事也"——卡住的时候，正确动作一律是缩小作战面。** |
| **不该做** | 再撞一次（回到九三"羸其角"）；或找巧路绕过去。**"无攸利"四个字已经明说：这个局面里没有任何好处可图，所以任何"想捞回来"的动作都是在延长它。** |

### ⚠️ 核心表：力量与那道"藩"的六个阶段

### 全爻速查

| 爻 | 角色 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | 刚有力量的人 | 壮于趾 | 刚有点势头，最想马上证明它 | 当位·最下 | **征凶**·不动·把壮留在下面 |
| 九二 | 办事枢纽 | 贞吉 | 有实力，名分不匹配，眼下无事必做 | 不当位但**得中** | **贞吉**·守正·一个动作都不加 |
| 九三 | 力量最满者 | 小人用壮 | 有资格、有力量，面前有道规矩想撞 | **当位**·三多凶 | **贞厉**·用罔·改问"合不合礼" |
| 九四 | 势已成者 | 藩决不羸 | 有势，阻碍已在松动，不需硬撞 | 不当位·四多惧 | **贞吉·悔亡**·顺势往·不亲自撞 |
| 六五 | 居尊者（**乘刚**） | 丧羊于易 | 下面在顶你，你手上有件想硬推的事 | 不当位·**得中居尊·乘刚** | **无悔**·放掉那只羊 |
| 上六 | 已经撞过的人 | 羝羊触藩 | 退不回也过不去，正在找巧路脱身 | 当位·卦终 | **无攸利·艰则吉**·认艰·等"咎不长" |

**大壮卦三句话**：
1. **卦辞只有"利贞"两字，无元无亨。****壮盛不许诺通达——有力量不等于路会通。** 唯一能从这股力量里拿到的好处是"正"（彖传"大者正也"：**不正就不叫"大"，只叫"壮"**）。
2. **壮盛之时唯一的约束是"非礼弗履"**（大象传）——**给自己划一条不走的路。** 它不管你用多少力，只管你走哪条路；因为**壮盛者不缺力量、不缺办法、不缺理由，缺的是"不走"的理由。**
3. **藩是被势冲开的，不是被角撞开的**（九三"羸其角"／九四"藩决不羸"）。**九三用壮所以伤角，九四顺势所以通过——而九三当位、九四不当位。在大壮卦里，位置太正是危险的来源。**

**本卦最反直觉的四条**：
- **卦辞比它的倒转卦遯（退）还要吝啬**：遯有"亨"，大壮连"亨"都没有。**《周易》对"退"的评价高于对"进"的评价**（同师卦"只有贞"、讼卦"终凶"的一贯态度）。
- **九二不当位判"贞吉"，九三当位判"贞厉"；九四不当位判"贞吉＋悔亡"，六五不当位却只判"无悔"。****在这一卦里，位置越正越危险**——因为位置的正当性会变成"用壮"的理由（与履九五"位正当也"却"贞厉"完全同构）。
- **全卦判词最密集的一爻（九四"贞吉＋悔亡"）出现在一个只给"利贞"两字的卦里。** 这说明**"利贞"锁的是方法，不是上限**：不用壮、只顺势，在这一卦里也能拿到最好的结果。（与巽卡"'小'锁的是方法，不是上限"机制完全一致。）
- **上六"羝羊触藩"与九三"羝羊触藩"是同样四个字，判词却完全不同。** 差别不在动作，**在你处在这个动作的哪一段**：正在撞（还来得及不撞，判"贞厉"），撞完卡住（只能承受，判"无攸利，艰则吉"）。

## 四、⚠️ 本卡对全库的意义

### 1. ⚠️ 遯／大壮：什么时候该退、什么时候该进（本组必须写成的一张表）

**结构核对（机械可验）**：
- **遯 33**（上乾下艮）六爻自下往上：**阴 阴 阳 阳 阳 阳**
- 整卦上下颠倒：**阳 阳 阳 阳 阴 阴** ＝ **大壮 34**（上震下乾）✓
- **两卦互为覆卦（倒转卦）**，且序卦传把它们直接串起来："**物不可以久居其所，故受之以遯**"→"**物不可以终遯，故受之以大壮**"。

| 判别项 | **遯 33（退）** | **大壮 34（进）** |
|---|---|---|
| **卦象** | 上乾（天）下艮（山）——天在上不断远去，山追不上 | 上震（雷）下乾（天）——雷响在天上，四阳自下同升 |
| **阴阳形势** | **二阴在下，正在往上长**（彖传"**浸而长也**"） | **四阳在下，正在往上升**（彖传"**大者壮也，刚以动**"） |
| **大势方向** | **坏的东西在慢慢长大，而且是渐变的** | **好的力量在整体上升，而且已成势** |
| **你能否改变大势** | **不能**（连九五这个最有资格的人也只能退） | **能推进，但不能靠蛮力** |
| **卦辞** | **亨，小利贞** | **利贞** |
| **卦辞给／缺** | **给"亨"**（退本身就是通）；"利贞"前加"小"（大势在坏，收益有限） | **只有"利贞"，无元无亨**（壮盛不许诺通达） |
| **彖传定性** | 遯而亨也 / **与时行也** / 遯之时义大矣哉 | 大者壮也 / 刚以动，故壮 / **大者正也** |
| **大象传（唯一纲领）** | **远小人，不恶而严**——拉开距离，不带情绪，边界分明 | **非礼弗履**——给自己划一条"不走"的路 |
| **最好的爻** | **上九"肥遯，无不利"**（退到最远，无所疑） | **九四"藩决不羸，贞吉悔亡"**（势到，藩自己开了） |
| **最危险的爻** | **初六"遯尾，厉"**（该走时落在最后）／**九三"系遯，有疾厉"**（被牵住退不掉） | **九三"用壮…贞厉"**（有力量而逞强）／**上六"无攸利"**（撞完卡死） |
| **初爻的病** | **太晚**（遯**尾**，落在队尾） | **太早**（壮于**趾**，力量刚起就用在最前端） |
| **初爻的指令** | **勿用有攸往**（不往何灾也） | **征凶**（其孚穷也）——**⚠️ 两卦初爻的指令完全相同：不要动** |
| **失败的典型形态** | **系**（牵挂放不下） | **触藩**（撞硬障碍） |
| **卡住时的解法** | **畜臣妾吉，不可大事也**（缩到手边最小一圈） | **艰则吉，咎不长也**（认艰，等时间） |
| **关键变量** | **时**（越早越好、越远越好） | **正**（力量不能替代正当性） |
| **判别一句话** | **"我改变不了它，而它正在慢慢变坏"** | **"我有力量了，问题是往哪用、能不能用"** |

> **⚠️ 这一对最重要的结论（本组四卦最有价值的一条）：序卦传把退与进串成了一条时间链，而不是两个选项。**
> **恒（32，久）→ "物不可以久居其所" → 遯（33，退）→ "物不可以终遯" → 大壮（34，壮）。**
> **所以"我该退还是该进"这个问题本身就问错了。正确的问题是："我在这条链上的哪一段？"**
> **判别依据是两卦彖传各给的一个词**：
> **看到"浸而长"（坏在渐渐渗上来、你改变不了）→ 你在遯，动作是趁早离场；**
> **看到"刚以动"（自己的力量已经成势、阻碍在松动）→ 你在大壮，动作是顺势而往、非礼弗履。**
> **⚠️ 而两卦的初爻给了同一条指令：无论你判成哪一卦，最下面那一爻都是"不要动"。**

### 2. ⚠️ 大壮／履：同一个"履"字，从力量的两端各写一半

**⚠️ 这条对照的经文根据极硬：大壮大象传"君子以非礼弗履"里的"履"，就是履卦（10）的那个"履"。**

| | **履 10（天泽履）** | **大壮 34（雷天大壮）** |
|---|---|---|
| 卦象 | 上乾（天）**下兑**（泽·悦） | **上震**（雷）下乾（天） |
| 力量对比 | **你弱，对方强**（一阴在五阳之中，柔履刚） | **你强**（四阳同升，大者壮也） |
| 核心意象 | **履虎尾**（踩在猛虎尾巴上） | **羝羊触藩**（公羊撞篱笆） |
| 卦辞 | **履虎尾，不咥人，亨**（只有亨） | **利贞**（只有利贞） |
| 大象传 | **辩上下，定民志**——**位分清楚** | **非礼弗履**——**给自己划禁行线** |
| 讲的问题 | **怎么走**（在等级结构中安全通行） | **哪条路不走**（有力量时的自我约束） |
| 安全来自 | **说而应乎乾 ＋ 位分清楚**（彖传） | **正**（彖传"大者正也"） |
| 三爻的病 | **六三"眇能视，跛能履…咥人，凶"**——**才不配位而志刚**（没能力却硬走） | **九三"小人用壮…贞厉"**——**才盛而无礼**（有能力却逞强） |
| "位正当"的作用 | **九五"夬履，贞厉"，象传"位正当也"**——**正当性是过度自信的来源** | **九三当位而"贞厉"**——**同一机制**（位置太正 → 用壮） |
| 最好的爻 | **上九"视履考祥，其旋元吉"**（复盘后重新开始） | **九四"藩决不羸，贞吉悔亡"**（顺势而往） |

> **⚠️ 合读结论（本卡对全库的第二条增量）**：
> **《周易》把"处世"（履）这件事按力量方向拆成了两卦，而且用了同一个字。**
> **弱的时候（履）：安全靠"说而应"（以和悦顺应）＋"辩上下"（位分清楚）；最危险的是"眇而自以为明、跛而自以为行"（履六三）。**
> **强的时候（大壮）：安全靠"正"（大者正也）＋"非礼弗履"（自设禁行线）；最危险的是"用壮"（拿力量当依据，九三）。**
> **两卦合起来，本库对"处世"这个领域才算给全：弱者的功课是自知，强者的功课是自限。**
> **⚠️ 而两卦最锋利的一处交叉是：履六三（凶）与大壮九三（贞厉）是同一个病的两端。** 按本库吉凶序 **凶 重于 厉**——**《周易》认为"没能力而硬走"比"有能力而逞强"更致命；但后者的解药更难，因为它要你主动放弃一个真实存在的优势（用罔）。**

### 3. ⚠️ 本卦印证并修正的三条通则

**① "震在上的九四"三例齐备，通则可入库。**

| 卦 | 下卦 | 九四 | 判词 | 结果 |
|---|---|---|---|---|
| 震 51 | 震（泥沼） | 震遂泥 | 无 | 陷住（未光） |
| 恒 32 | 巽（柔在底） | 田无禽 | 无 | 空猎（久非其位） |
| **大壮 34** | **乾（四阳同升）** | **藩决不羸** | **贞吉·悔亡** | **冲开（尚往）** |

> **通则："四多惧"这个位置的吉凶不由四位本身决定，由下卦给它什么决定。** 处在四位时，正确的诊断动作是**向下看，不是向前看**。

**② "六五乘刚"三例齐备，加上两例六四，"乘刚"至此有五种解法。**

> **艮六四"止诸躬"（缩范围）｜巽六四"田获三品"（交成果）｜震六五"其事在中"（守本职）｜恒六五"先辨职分"｜⚠️ 大壮六五"丧羊"（主动放手）。**
> **五解无一是"顶回去"。通则：乘刚只能"处理自己"，不能"处理下面那个刚"。** 而"丧羊"是五解中最彻底的一种——**前四种都还在保住某样东西，只有它是直接放弃。**

**③ "位正当反而危"三例齐备（履九五、兑九五、大壮九三），可升为通则。**

> **三爻全部当位，判词全部是"厉"档，病名分别是"夬"（刚决）、"孚于剥"（给错人）、"用壮"（拿力量当依据）。**
> **通则：位置的正当性不提供安全，它提供的是过度自信的来源。**
> **诊断问句：当"我完全有资格这么做"成为你最主要的理由时，你已经在"厉"里了。**

**④ 上爻分类需要加第三类。**

> 原有两类：**离开顶点**（履上九元吉·循环／遯上九无不利·离场／艮上九吉·知止）；**还在顶点上使劲**（乾上九悔·过刚／巽上九贞凶·过柔／恒上六凶·过动／坤坎上六凶·不知止）。
> **⚠️ 大壮上六是第三类："已经撞在顶点上了"**——退不回也过不去。**它的唯一出路不是动作，是时间（"艰则吉，咎不长也"）。**
> **这是本库唯一一条"以承受得吉"的上爻。**

### 4. 本卦补上的机制缺口

| 缺口 | 大壮卦补的内容 |
|---|---|
| **本库有"力量还没起来怎么办"（乾初九/九二、屯、蒙），但没有"力量已经起来了怎么办"** | 乾卡的九五（飞龙）讲的是**鼎盛期如何持续纳新**，上九（亢龙）讲的是**盛极之后如何退舍**；**中间那一段"力量刚成势、正要往前推"的处境，本库此前没有专卦。****大壮补上的正是这一段**，而且它给的唯一约束是"非礼弗履"。 |
| **"有力量的人该受什么约束"这一问只有零散答案** | 已有：**乾用九"群龙无首"**（不居首、不独尊）、**履九五"夬履，贞厉"**（勿刚决）、**兑九五"孚于剥"**（别给错人）。<br>**大壮大象传"非礼弗履"给了本库第一条完整、可执行的强者纪律**：**不管用量，只管方向——划出一条不走的路。** |
| **"用壮"这个病名此前无处归口** | 本库路由表的高频困境里有一类是"我明明有能力/有资源/有理由，为什么推不动"。**大壮九三给了病名（用壮）与解药（用罔），并且给了明确的代价预告（羸其角——坏的是你赖以为壮的那个东西）。** |
| **"同辞异断"只有一组教材** | 巽卡提供了第一组（九二／上九"巽在床下"，判据是"是否还握着决断权"）。<br>**大壮九三／上六"羝羊触藩"是第二组，判据不同：不看动作本身，看你处在这个动作的哪一段（正在撞／已撞完）。** 两组合读，本库"同辞异断"的读法就有了两条独立判据。 |
| **路由表缺两条高频困境** | ① **"我有实力，也完全有资格，为什么一动就出事"**——大壮九三"用壮…贞厉"，解药是"用罔"。<br>② **"我已经硬推过一次，现在退不回也过不去"**——大壮上六"不能退，不能遂，无攸利，艰则吉"，解药是认艰＋等时间。 |

### 5. 本卡打开的下一步（优先建议）

> **首选：无妄 25（上乾下震）**——它是**大壮的上下卦交换**（大壮＝上震下乾，无妄＝上乾下震）。震卡已给出结构律"**震在上＝动在头顶（自己做不了主）／震在下＝底子是正的，动是从正道上发起的**"。**大壮（震在上）与无妄（震在下）合读，可以把震在复合卦里的两种叠加方式一次读完。** 且"无妄"卦名即"不妄动"，**与大壮"非礼弗履"是同一条纪律的两种表述**（一个从"不妄"说，一个从"不履"说），衔接极自然。
> 其次：**夬 43（上兑下乾）**——**夬＝决，五阳决一阴，是大壮再往前一步的形势**（大壮四阳，夬五阳）。**而"夬"字正是履九五"夬履，贞厉"里的那个字**——本库履卡已把"夬"标为需要防范的动作，**夬卦是这个动作的正卦**，且它与大壮同为"阳盛"之卦，是本库"力量过盛"这条线最自然的续接。
> 第三：**豫 16（上震下坤）**——震卡已把它列为首选建议（卦辞"利建侯行师"直接衔接师卦 7）。**大壮为它补上第二个理由：豫＝上震下坤（动在头顶而下面全柔），大壮＝上震下乾（动在头顶而下面全刚）。两卦是"震在上"的两个极端，合读可以验证"下卦决定四位"这条新通则。**
> 第四：**大畜 26（上艮下乾）**——**与本卦下卦相同（乾在下），上卦一个是震（动）一个是艮（止）**：**大壮＝有力量而要往（非礼弗履），大畜＝有力量而被止住（蓄而不发）。** 这一对是"有实力者"的进／蓄两条路，且大畜与本库已有的小畜（9）构成"大／小"一对。
