# 知识卡 35 · 晋卦（火地晋）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："物不可以终壮，故受之以晋。晋者，进也。"——大壮（34）之后不能永远停在"壮"的状态；力量壮了就要往上走，于是进入晋卦。
> **本卦与明夷（36）互为反卦，是本组的核心一对**：晋＝上离下坤（**明出地上**），明夷＝上坤下离（**明入地中**）。**同样是离与坤两个三画卦，上下一换，一卦讲晋升，一卦讲埋没。** 这是本库"离在上／在下结构律"的第二组干净实证（详见末节）。
> ⚠️ **本卦的结构性事实**：**六爻中只有六二一爻当位**（坤在下 → 二当位、初三不当；离在上 → 三爻全不当位）。**当位率与讼卦（6）、睽卦（38）并列全库最低档。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 晋 · 第三十五卦 |
| **卦象** | 上离（火／明）下坤（地／顺），称"火地晋"。**明出地上**——太阳从地面升起来。<br>按本库结构律：**坤在下 → 六二当位，初六、六三不当位**；**离在上 → 九四、六五、上九三爻全部不当位**。**合起来：全卦只有六二一爻当位。**<br>⚠️ **"离在上＝光在你身外（名不正）"**（本库六条最危险位置之一）——**晋卦的结构本身就在说：晋升期你的光是位置给的，不是自己长出来的。** 这一点彖传写得更直白："顺而丽乎大明"。 |
| **领域定义** | **晋升、上行、被提拔、被赏识、进入更高一层的秩序**。<br>① 你正在被往上放（提名、试用、代理、内部竞聘、被推荐）；② 你已经上了一级，正在适应"离决策层更近"的位置；③ 你手上多了资源和上行沟通的频次，但名分还没完全落地；④ 你在权衡这一步的得失是否公平（给我的够不够、他为什么比我多）；⑤ 你想往上但被顶回来过一次或几次；⑥ 你上行已到顶，力量还在，不知道往哪里用。<br>**凡是"我正在往上走，或者刚被放上去"，都落在晋卦。** |
| **不归本卦的情况** | 是"亮起来、被看见"这件事本身的经营 → **离（30）**（离管光，晋管位）；有实力但被压住、蓄而未发 → **小畜（9）**；要选择跟谁站在一起才有上升机会 → **比（8）**；**能力被压制、上升通道被截断、发亮会招祸 → 明夷（36）**（**晋的反面，同组必须合读**）。 |
| **"晋"字本义** | 说文："晋，进也。日出万物进。"从日从臸——**日出而万物向上**。<br>⚠️ **关键区分：晋是"往上走"，不是"变强"。** 变强是上一卦大壮，往上走才是晋。**很多人误把"我更强了"当成"我该上了"——晋卦的动力机制恰恰不是刚强（见彖传"柔进而上行"）。** |
| **卦辞原文** | 晋：康侯用锡马蕃庶，昼日三接。 |
| **⚠️ 卦辞的关键结构** | **元、亨、利、贞四德一个都没有。**<br>本库师卦卡已指出："师卦无元无亨无利、只有'贞'，是六卦以来最吝啬的卦辞之一"——**晋卦更进一步：连"贞"都没有。**<br>**它换成了一个极具体的场景：受赏很多、一天被接见三次。**<br>**这是全书最"现象化"的卦辞之一，含义要读准：《周易》对"晋升"不做任何品质承诺**——不说它是通的（无亨），不说它有益（无利），不说守正就够（无贞）。**它只告诉你晋升长什么样，然后把全部风险下移到六爻里去**（九四"鼫鼠，贞厉"、上九"贞吝"）。<br>**换句话说：晋升本身不带道德属性，它既不是奖赏也不是保障。** |
| **卦辞现代解** | **康侯**＝安定邦国之侯（"康"训安、大）。⚠️ 一说指周初康叔封，人物指认有争议，本库取"安定邦国的侯"这一通解，不作史实断言。<br>**用锡马蕃庶**——"锡"通赐，"蕃庶"＝众多。**被赏赐了很多马匹**：马是行动力与位移能力，**赏赐是晋升最直观的形态——资源真的到你手上了。**<br>**昼日三接**——**一天之内被接见三次。**<br>**⚠️ 落到现代，这两句给出了判断"是不是真晋升"的两个硬指标**：① **资源配给是否增加**（锡马蕃庶）；② **上行沟通频次是否增加**（昼日三接）。**只有头衔而这两样都没变，那不是晋，是被挂起来。** |
| **彖传** | 晋，进也。明出地上，顺而丽乎大明，柔进而上行。是以康侯用锡马蕃庶，昼日三接也。 |
| **彖传要点** | ① **顺而丽乎大明**——下坤是顺、上离是大明：**你的上行方式是"以顺附丽于上面那个大光明"。**<br>直接呼应离卦彖传"日月丽乎天，百谷草木丽乎土"——**晋卦的"丽"（附着物）就是上面那位。这是"离在上＝光在身外"最正的解释：晋升期你的光是借来的，而借来的光必须靠"顺"来维持。**<br>② **柔进而上行**——**往上走的是那个柔爻（六五居尊位），不是刚爻。**<br>**这一句是全卦最重要的定性：晋卦的上行动力是柔顺，不是刚强。** 它直接解释了九四为什么"贞厉"——**九四是全卦唯一一个用阳刚去占位置的爻，它在逆着这一卦的动力机制走。** |
| **大象传（行动纲领）** | 明出地上，晋。君子以自昭明德。 |
| **"自昭明德"解** | **"自"字是本卦纲领的全部重量。** 明出地上——**光是从地里自己升起来的，不是别人点的**。所以君子的动作是"**自**昭明德"：**自己去昭显自己的德。**<br>**⚠️ 与离卦纲领的分工（必须合读）**：**离卦"继明照于四方"——已经亮了，任务是"继"（接得上）和"照四方"（不能只照自己）**；**晋卦"自昭明德"——刚要亮，任务是"自"（自己把它显出来）。**<br>**⚠️ 关键分寸**：**"自昭明德"昭的是"明德"，不是"自己"。** 上行期把德显出来是本分；**把自己吹出来，就是九四的"鼫鼠"。** 一字之差，一卦之内最好与最坏。 |
| **总铁律** | ① **晋升期的判词以"悔亡"为骨，不是"吉"**（六三、六五都带"悔亡"）——按本库口径"**悔亡＝本该有的悔恨消失了，不是得到好处**"：**晋升的常态收益是免悔，不是得利**；② **不要用刚去抢位置**（九四"晋如鼫鼠，贞厉"，象传"位不当也"）；③ **起步阶段没人信你是正常的**（初六"罔孚"，象传"未受命也"）——**药是"裕"（宽绰从容），不是去争取信任**；④ **居尊位后要关掉得失的算法**（六五"失得勿恤"）；⑤ **上行到顶只能对内用力，且要接受"贞吝"**（上九"维用伐邑"）。 |

## 二、爻级字段

### 初六 · 晋如摧如

| 字段 | 内容 |
|---|---|
| **爻辞** | 晋如，摧如，贞吉。罔孚，裕无咎。 |
| **象传** | 晋如摧如，独行正也。裕无咎，未受命也。 |
| **位属性** | 阴爻居阳位，**不当位**；居下坤之底——**上行之始，位最低** |
| **判词 → 行动语义** | 贞吉 ＋ 无咎 → **守正而独行；没人信你的时候用"宽绰"自处，不去争取信任** |
| **关键词解** | **晋如**＝要往上进的样子。**摧如**＝被摧折退回的样子（"摧"＝折、退）。**两个"如"字并列：想进，却被顶回来。**<br>**罔孚**＝没有得到信任（"罔"＝无，"孚"＝信）。**裕**＝宽绰、从容、把节奏放宽。 |
| **⚠️ 象传两句都是解药** | "**独行正也**"——**没有人跟着你，你一个人守正地走。** 这是本爻"贞吉"的全部理由：**吉不是因为你进得动，是因为进不动的时候你还是正的。**<br>"**未受命也**"——**你还没有接到任命。** 这四个字把"罔孚"的原因说得干干净净：**不是你人品有问题，是你还没有名分。** **在没有名分的时候要求别人信任你，是一个错位的要求。** |
| **识别信号** | ① 你想往上走，且已经动了，但被顶回来一次或几次；② 你感到"没人信我""大家都在观望"；③ 你还没有正式任命或授权，却已在承担那个位置的期待。 |
| **该做** | **"裕"——把节奏放宽。** 继续独立地做正确的事；**先把"取得信任"这个目标撤掉**，因为你确实"未受命"。 |
| **不该做** | 为了取得信任而加大表现、找人表态、四处解释。**罔孚的解药不是"孚"，是"裕"。** |
| **与巽初六"进退"的对照** | **巽初六"进退，志疑也"——柔在最底下，病是自己犹豫，药是"武人之贞"（借一份刚）**；**晋初六"晋如摧如"——柔在最底下，病是外面顶你，药是"裕"（宽绰）。**<br>**两爻位属性完全同构（阴居阳位、不当位、居全卦最下），药却相反。合起来是一条通则：柔居下位时，自己没主意用"刚"治，外面不认用"宽"治。** |

### 六二 · 受兹介福（全卦唯一当位之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 晋如，愁如，贞吉。受兹介福，于其王母。 |
| **象传** | 受兹介福，以中正也。 |
| **位属性** | 阴爻居阴位，**当位且得中**；**是全卦六爻中唯一当位的一爻**；处下坤之中 |
| **判词 → 行动语义** | 贞吉 → **守正而忧；福来自"中正"，不来自额外动作** |
| **关键词解** | **愁如**＝忧愁的样子。**介福**＝大福（"介"训大）。**王母**＝上面那位尊长（一说祖母，一说指六五）。⚠️ "王母"所指有异说，本库取"来自上面那位柔顺尊长"的通解。 |
| **⚠️ 本爻的两个要点** | ① **它是全卦唯一当位的爻，而它的心理状态是"愁"。**<br>上行期最正的那个位置上，坐着一个在发愁的人。**这与离六五"出涕沱若，吉"是同一个机制：在往上走的时候，忧惧本身是资格的证明**——它说明你还知道这个位置的重量。<br>② **象传把福的来源写死了："以中正也"。**<br>**不是因为你会来事，不是因为你争到了，是因为你居中且当位。** 这与离六二"黄离元吉，得中道也"完全同构——**本库通则再次成立：福的来源永远是"中正"，不是"能力大"。** |
| **识别信号** | ① 你在上行通道里，而且位置是正的（该有的名分、资历都在）；② 你反而在发愁——怕站不住、怕不够格、怕上面变卦；③ 你拿到了一份来自上面尊长的实质性好处（提名、背书、资源倾斜）。 |
| **该做** | 接受这份"介福"，同时**把"愁"保留住**。守中守正，不做额外动作。 |
| **不该做** | 因为发愁而去补动作（表忠心、加码表现、提前谢恩）。**你的福是"中正"给的，任何偏移都在削它。** |
| **与需九二、师九二、离六二的四"二"对照** | **需九二"需于沙，小有言，终吉"（险前之慎）｜师九二"在师中吉"（险中之统）｜离六二"黄离，元吉"（明中之中）｜晋六二"晋如愁如，贞吉"（升中之忧）。**<br>**四个二爻共同印证本库通则"二多誉"，且誉的来源全部是"得中"、没有一个是"能力大"。**<br>**晋六二的独特处：它是四个里唯一带明确负面情绪（愁）的，而判词依旧是"贞吉"。** |

### 六三 · 众允

| 字段 | 内容 |
|---|---|
| **爻辞** | 众允，悔亡。 |
| **象传** | 众允之志，上行也。 |
| **位属性** | 阴爻居阳位，**不当位**且失中；居下坤之顶；本库通则"**三多凶**"，**而本爻是本组四卦里第一个"三位无凶"之爻** |
| **判词 → 行动语义** | 悔亡 → **众人认同了你，但那只够把"不当位"带来的悔抵掉** |
| **关键词解** | **允**＝信、认可、许可。**众允**＝众人都认同你。<br>**⚠️ 与初六"罔孚"连成一条线**：从"没人信"（初六）到"众人信"（六三）——**晋卦把人望的积累过程写在了下卦的两端。** |
| **⚠️ 本爻的关键：为什么只给"悔亡"而不给"吉"** | 按本库口径，**悔亡＝本该有的悔恨消失了，不是得到好处**。六三不当位、失中、又处"三多凶"之位，**本该有悔；是"众允"这件事把悔抵掉的。**<br>**换句话说：众人的认同不能给你好处，只能免掉你不当位带来的那份悔。** **这是《周易》对"人望"最冷静的一次定价。**<br>象传"**上行也**"——**众人认同的是你"要往上走"这个志向，不是你已经到了。** |
| **识别信号** | ① 大家都认你、都说你该上；② 但你的名分、资历、位置其实还不正（不当位）；③ 你开始把"大家都支持我"当成已经成了。 |
| **该做** | **把"众允"当成免悔的资源，不当成资本。** 继续上行，但不宣称已成，不动用众望去换东西。 |
| **不该做** | 用"众望所归"去越位、去逼上面表态。**从六三越位，落点就是九四的"鼫鼠"。** |
| **与坤六三"含章"的对照（同一爻位、同一位属性）** | **坤六三"含章可贞，或从王事，无成有终"——手上有功勋，要内敛、要归功于上**；**晋六三"众允，悔亡"——手上有众望，要压住不动用。**<br>**两爻同为阴居阳位、同处下卦之顶。合读得一条通则：三位（下卦之顶）的通用纪律是"手上有东西，但不能动用"。** 坤管的是功，晋管的是望。 |

### 九四 · 晋如鼫鼠（全卦唯一负面判词）

| 字段 | 内容 |
|---|---|
| **爻辞** | 晋如鼫鼠，贞厉。 |
| **象传** | 鼫鼠贞厉，位不当也。 |
| **位属性** | 阳爻居阴位，**不当位**（**象传直接点名"位不当也"**）；**刚入上离——离在上则三爻全不当位，九四是第一个**；本库通则"**四多惧**" |
| **判词 → 行动语义** | **贞厉**（按本库口径：**厉＝警告，非判死**；而"贞厉"＝**守正也危，问题不在品德，在处境与选择的错位**） → **立刻改掉这个位置的占法** |
| **关键词解** | **鼫鼠**——两说并存，⚠️ 训解有异议：① 硕鼠、田鼠，**贪食而多惧、昼伏夜出**；② 五技鼠（**能飞不能上屋、能缘不能穷木、能游不能渡谷、能穴不能掩身、能走不能先人——五样都会，一样都不成**）。<br>**本库两说并存，因为两说指向的病症完全相同：又贪又怕，样样沾边、样样不成。** |
| **⚠️ 本爻是全卦风险的总出口** | 九四是**全卦唯一一个用阳刚去占位置的爻**（上九虽也是阳，但已在卦终、无位可争）。<br>**在一个彖传明写"柔进而上行"的卦里，用刚去往上顶，就是逆着这一卦的动力机制走。** 所以判词不是"凶"（它没做伤天害理的事），是"厉"（危）——**而且是"贞厉"：你就算完全守规矩，这个位置的占法本身也是危的。**<br>象传的理由只有四个字：**"位不当也"**——**与兑六三"来兑之凶，位不当也"完全同一个句式。** 本库通则：**不当位＝名不正言不顺；姿态补不了位置，力气也补不了位置。** |
| **触发条件** | ① 你在上行通道的中段，已经离决策层很近（四位）；② 你的名分不足（阳居阴位）；③ 你的应对方式是"多占几样、都沾一点、谁都不得罪、也谁都不放弃"。 |
| **识别信号（诊断清单）** | ① 你同时抓着好几条线（几个项目、几个山头、几个人），每条都不深；② 你对失去任何一条都害怕（贪）；③ 你主要靠"离得近"和信息差吃饭，在别人的地盘上取食；④ 你说不清自己"到底靠哪一样立得住"。 |
| **该做** | **砍到一样。** 选一条真正属于你的线，把其余的放掉——**把"五技"换成"一技"。** 这是"鼫鼠"唯一的解法，而且解药就在爻内（减法）。 |
| **不该做** | 靠"我很守规矩"硬撑。**"贞厉"这两个字已经把这条路挡掉了：品德救不了错位。** |
| **与离九四、兑六三的三角对照（重要）** | **离九四"焚如，死如，弃如"，象传"无所容也"——爆发式发光而名不正，纯烧必尽**；<br>**兑六三"来兑，凶"，象传"位不当也"——用讨好去补位置的亏空**；<br>**晋九四"鼫鼠，贞厉"，象传"位不当也"——用多占去补位置的亏空。**<br>**三爻是同一条病的三种形态：位置不正时，人会分别用"加火""讨好""多占"去补，三条都不通。**<br>**差别只在剂量与解药位置**：离九四已无爻内解药（本库判定），兑六三的解药在别的爻（九二"孚兑"），**晋九四的解药在爻内——减到一样。** |

### 六五 · 失得勿恤（卦主，全卦最好之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 悔亡，失得勿恤，往吉，无不利。 |
| **象传** | 失得勿恤，往有庆也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位；**乘九四之刚**（按本库第 2 节机械定义：阴爻直接压在阳爻之上）；**是彖传"柔进而上行"所指之爻——全卦卦主** |
| **判词 → 行动语义** | **悔亡 ＋ 往吉 ＋ 无不利**（**全卦判词最密集之爻**；按本库吉凶序：**无不利 ＞ 吉 ＞ …… ＞ 悔亡**） → **关掉得失的算法，往前走** |
| **关键词解** | **失得**＝得失（此处倒言）。**恤**＝忧、顾念、计较。**失得勿恤＝不要去计较得失。** **往吉**＝前往则吉。**无不利**＝按本库口径约等于大吉，仅次于元吉。 |
| **⚠️ 本爻是晋卦的全部答案** | **一个既不当位、又乘刚的爻，拿到了全卦最密集的好判词。** 原因就在爻辞正中间那四个字：**"失得勿恤"。**<br>**晋卦是升迁卦，而升迁期最大的消耗恰恰是算得失**——这次给我的够不够、他凭什么比我多、这一步是不是亏了。**六五给的指令是：把这套算法整个关掉。** 关掉之后，判词是"往吉，无不利"。<br>象传"**往有庆也**"——**好处在"往"（继续前进）里，不在"算"里。** |
| **⚠️ 本库"得中可救不当位"通则的又一实证（且是条件最差的一例）** | 已有诸例：**师九二**（不当位·得中·中吉）、**巽九二**（不当位·得中·吉无咎）、**震六五**（不当位·得中·亿无丧）、**离六五**（不当位·得中·吉）。<br>**晋六五是这一组里位置条件最差的一个：既不当位、又乘刚，而判词最好（无不利）。**<br>**原因值得记下：它给出的不是一个姿态，是一条心法（勿恤失得）。** 姿态补不了位置（兑六三、晋九四已证），**但心法可以。** |
| **识别信号** | ① 你已经上到尊位／关键位置，但名分上有一处不正（空降、代理、资历不足、非嫡系）；② 你下面顶着一个强硬的人或力量（乘刚）；③ 你在反复计算这一步的得失是否公平。 |
| **该做** | **停止计算得失，把注意力全部转到"往"上**——下一步要做成什么。**这是本卦唯一被象传承诺"有庆"的动作。** |
| **不该做** | 为了把得失算平而停下来讨价还价。**在晋卦里，停下来算账，就是把"无不利"主动换成"悔亡"。** |
| **与坤六五、离六五的三"五"对照** | **坤六五"黄裳，元吉"——有君之权而守臣节（放下名分）**；**离六五"出涕沱若，吉"——居尊而保住忧惧（放下体面）**；**晋六五"失得勿恤，无不利"——居尊而放下账本（放下得失）。**<br>**三个柔居尊位之爻，各要求放下一样东西。** 本库"居尊位者必须保留一样'往下'的东西"这条通则，在晋卦里的具体内容是：**不算账。** |

### 上九 · 晋其角

| 字段 | 内容 |
|---|---|
| **爻辞** | 晋其角，维用伐邑，厉吉无咎，贞吝。 |
| **象传** | 维用伐邑，道未光也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终——**上行已到"角"上** |
| **判词 → 行动语义** | **厉 → 吉 → 无咎 → 贞吝**（四个判词连排，是全书判词序列最奇特的爻之一） → **到顶后只能对内整治，且必须接受趋势已在收窄** |
| **关键词解** | **角**＝兽角，**身体最高、最硬、最前端的部分**。**晋其角**＝上行到了角上——**再往前没有了，而且这个位置又高又硬又尖。**<br>**维用**＝只可用于（"维"＝唯）。**伐邑**＝征伐自己的城邑——**打的是自己内部，不是外敌。** |
| **⚠️ 判词序列怎么读（本爻最需要拆的地方）** | **厉**——到顶且不当位，本就危；<br>**吉，无咎**——**但如果用"伐邑"这个动作，则吉且免灾**；<br>**贞吝**——**然而即使你做得完全正当，路依然是越走越窄的**（本库口径：**吝＝路越走越窄，趋势极差**）。<br>**四个判词连起来是一句完整的话：到顶之后，向内整治是唯一可行的动作；这个动作能让你免灾，但不能让你继续变好。**<br>象传把这层说得极准：**"道未光也"——道路不能光大。**<br>按本库判词表，"未光"是最轻的一档负面（震九四"遂泥"、兑上六"引兑"），**但晋上九是"未光"＋"贞吝"叠加：不只是白过，是在收窄。** |
| **为什么"伐邑"是唯一动作** | 上九已在"角"上——**对外再进，无处可进。** 此时力量只剩一个正当出口：**处理自己内部积下来的问题（伐邑）。**<br>**⚠️ 与离上九的对照（同为阳爻居上位、同用兵象）**：**离上九"王用出征，有嘉折首，获匪其丑，无咎"——对外出征，只斩首恶、不牵连从众，象传"以正邦也"**；**晋上九"维用伐邑…贞吝"——只能对内整治，而且趋势仍在收窄。**<br>**差别的结构原因很清楚：离上九头上有"明"（上下皆离，光是自己的），所以它敢对外；晋上九的明是借来的（离在上，光在身外），所以它只能对内。** |
| **识别信号** | ① 你的上行已经到顶，再往上没有位置了；② 你手上还有力量，还想用；③ 你面前有两个用法：向外开新战场，或向内整理自己这一摊。 |
| **该做** | **向内整治**——处理自己团队／自己这一摊里积下来的问题。**并且预先接受"贞吝"：这件事必须做，但不要指望它带来新的上升。** |
| **不该做** | ① 向外扩张、开新战场；② 反过来，因为"贞吝"就干脆什么都不做——**"厉吉无咎"是明确给出的：做了才免灾。** |

## 三、晋卦定位速查表

| 爻 | 处境 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | 想上而被顶回 | 晋如摧如 | 想往上走，被顶回来过，且没人信你 | 不当位 | **贞吉·无咎**·独行正·**用"裕"** |
| 六二 | 位最正（**唯一当位**） | 受兹介福 | 名分是正的，你却在发愁 | **当位·得中** | **贞吉**·福来自中正·不加动作 |
| 六三 | 众望在身 | 众允 | 大家都说你该上，但名分还不正 | 不当位·三多凶 | **悔亡**·众望只够免悔·不可动用 |
| 九四 | 用刚抢位 | 晋如鼫鼠 | 同时抓好几条线，每条都不深 | **不当位**·四多惧 | **贞厉**·位不当·**砍到一样** |
| 六五 | 居尊（**卦主**） | 失得勿恤 | 上到关键位置，却在反复算得失 | 不当位·**得中居尊**·乘刚 | **无不利**·关掉算法·**往有庆** |
| 上九 | 到顶（角上） | 维用伐邑 | 再往上没位置了，力量还在 | 不当位·卦终 | **厉吉无咎·贞吝**·只可对内 |

**晋卦三句话**：
1. **晋是"往上走"，不是"变强"**（说文"日出万物进"）。上行的动力是"柔进而上行"——**用刚去抢位置就是"鼫鼠，贞厉"。**
2. **晋升期的常态收益是"免悔"，不是"得利"**（六三、六五皆"悔亡"）。**卦辞连元亨利贞一个字都不给：《周易》对晋升不做任何品质承诺，它只告诉你晋升长什么样（锡马蕃庶、昼日三接）。**
3. **纲领是"自昭明德"**（大象传）——**自己把德显出来，但昭的是"明德"不是"自己"。** 到顶之后只剩一个动作：**向内整治（伐邑），并接受"道未光也"。**

**本卦最反直觉的三条**：
- **全卦唯一当位的六二，心理状态是"愁"。** 而全卦判词最好的六五，位置最差（不当位＋乘刚）。**位置正的在发愁，位置不正的"无不利"——差别只在一条心法：勿恤失得。**
- **卦辞里元亨利贞四德全缺，比师卦（只剩"贞"）更吝啬。** **《周易》不认为"被提拔"本身是一件好事或坏事。**
- **上九连给四个判词：厉、吉、无咎、贞吝。** **到顶之后，你能拿到的最好结果是"做了就免灾，但路还是在窄"。** 这是全书对"到顶"最不留情面的一次描写。

## 四、⚠️ 本卡对全库的意义

### 1. 晋／明夷＝"离在上／在下结构律"的第二组干净实证

本库离卦卡（30）已立下这条律：**离（阳阴阳）在下则三爻全当位，在上则三爻全不当位**，并点出三对最值得优先做的反卦：**同人 13／大有 14、晋 35／明夷 36、既济 63／未济 64**。

**晋与明夷是同一对三画卦（离＋坤）的上下互换，因此是这条律最干净的一次逐爻验证：**

| 爻位 | **晋 35**（上离下坤） | 当位？ | **明夷 36**（上坤下离） | 当位？ |
|---|---|---|---|---|
| 上（阴位） | 上九（阳） | **不当位** | 上六（阴） | **当位** |
| 五（阳位） | 六五（阴） | **不当位** | 六五（阴） | **不当位** |
| 四（阴位） | 九四（阳） | **不当位** | 六四（阴） | **当位** |
| 三（阳位） | 六三（阴） | **不当位** | 九三（阳） | **当位** |
| 二（阴位） | 六二（阴） | **当位·得中** | 六二（阴） | **当位·得中** |
| 初（阳位） | 初六（阴） | **不当位** | 初九（阳） | **当位** |
| **合计** | | **1 爻当位** | | **5 爻当位** |

> **离在上（晋）→ 四五上三爻全不当位**：加上坤在下只给六二一个当位，**全卦仅 1 爻当位**。
> **离在下（明夷）→ 初二三三爻全当位**：加上坤在上给六四、上六当位，**全卦 5 爻当位，只有六五不当位**。
> **这条律至此已有两组独立验证**：离卦本身（30，上下皆离，两律同时成立）＋ 晋／明夷这一对。**与 13 同人／14 大有那一组并列时，可预判：同人（上乾下离）下三爻全当位，大有（上离下乾）上三爻全不当位。**

### 2. ⚠️ 但本组同时给出全库最重要的一条反例：当位率与吉凶不成正比

**这是晋／明夷合读才能得到的结论，也是这一组卡真正的增量：**

| | **晋 35** | **明夷 36** |
|---|---|---|
| 当位爻数 | **1 / 6**（最低档） | **5 / 6**（最高档） |
| 卦义 | 晋升、上行 | 光被埋没、贤者受难 |
| 卦辞 | 四德全缺（连"贞"都没有） | 利艰贞（**无亨**） |
| 判词最好之爻 | 六五"**无不利**"（约等于大吉） | 六二"**吉**"（全卦唯一的吉） |
| 全卦判词总体 | 悔亡为骨，一处"无不利" | 几乎没有吉字，多为无判词 |

> **一个只有 1 爻当位的卦（晋），出了一个"无不利"；一个有 5 爻当位的卦（明夷），全卦只有一个"吉"字。**
> **结论（建议补入索引"位属性判断规则"）**：**当位描述的是"你在这件事里名正不正"，它不描述"这件事整体是好是坏"。**
> **卦义由上下两卦的关系（明出地上／明入地中）决定，当位只决定"在这个卦义之下，哪一爻站得住"。**
> **实务用法**：读一张卡时，**先看上下卦关系定"这是个什么局"，再看当位定"你在这个局里正不正"。** 两层不能混。

### 3. 本卦补上的领域缺口：全库此前没有"晋升"这一格

本库乾卦（1）讲上升，但那是**主导者自身的成长曲线**（潜现惕跃飞亢），是"成龙之路"；**晋卦讲的是完全不同的一件事：在一个既有结构里被别人往上放。**

| | 乾 1 | 晋 35 |
|---|---|---|
| 上升的性质 | **自己长上去** | **被放上去**（顺而丽乎大明） |
| 动力 | 刚健（自强不息） | **柔顺**（柔进而上行） |
| 关键抉择爻 | **九三 → 九四**（"或跃在渊"，不进则死） | **九四**（"鼫鼠，贞厉"，用刚抢位则危） |
| 到顶 | 上九"亢龙有悔"（不知止） | 上九"维用伐邑，贞吝"（只能对内） |
| 纲领 | 自强不息 | **自昭明德** |

> **两个"九四"的对照最有价值**：**乾九四"或跃在渊，无咎"——不当位不得中，但仍有唯一通路，跃则无咎**；**晋九四"晋如鼫鼠，贞厉"——同样不当位，但这一卦的动力是柔，所以用刚去跃就是"贞厉"。**
> **合起来一条通则：同样是"离决策层一步之遥"，该不该用刚去跃，取决于这一卦的动力机制是刚还是柔。** 乾是刚（必须跃），晋是柔（不可抢）。

### 4. 一条对全库"乘刚"口径的机械补充

本库现有口径：**"乘刚的来源＝震"**（震把阳放在最下往上顶，故震在下则六二必乘刚，震在上则六五必乘刚；艮把阳放在最上往下压，其内部不制造乘刚）。

按本库第 2 节给出的机械定义（**阴爻直接压在阳爻之上则该阴爻乘刚，逐爻检查**），**离与兑同样在其内部制造乘刚**：

| 三画卦 | 自下往上 | 内部是否有"阴直接在阳之上" | 结论 |
|---|---|---|---|
| **震** | 阳 阴 阴 | 有（二在初之上） | 在下→六二乘刚；在上→六五乘刚 |
| **离** | 阳 阴 阳 | **有（二在初之上）** | **在下→六二乘刚；在上→六五乘刚** |
| **兑** | 阳 阳 阴 | **有（三在二之上）** | **在下→六三乘刚；在上→上六乘刚** |
| **艮** | 阴 阴 阳 | 无（阳在最顶） | 内部不制造乘刚 |
| 乾／坤／坎／巽 | — | 坎、巽亦各有一处，此处不展开 | — |

> **本卡涉及的两处**：**晋六五乘九四**（离在上）、**明夷六二乘初九**（离在下）。**⚠️ 建议把"乘刚来源"这一条从"＝震"扩写为"凡三画卦内部有阴爻直接压在阳爻之上者皆制造乘刚，震是其中最典型、且象传直接写出'乘刚也'的一个"。**
> **注意这不推翻原口径**：震之所以被单列，是因为**震六二的小象直接写了"乘刚也"三个字**（本库唯一一处经文明证），且震在下时那个阳在全卦最底、顶迫最强。

### 5. 本卡打开的卦与优先建议

**坤在下的一组**（二当位、初三不当）：**比 8**（已有）、**师 7**（已有）、**晋 35**（本卡）、**豫 16、观 20、升 46、复 24、明夷之反**……
**离在上的一组**（三爻全不当位）：**晋 35**（本卡）、**大有 14、噬嗑 21、旅 56、鼎 50、睽 38**（本组）、**未济 64**。

> **优先建议**：**大有 14（上离下乾）**——**与晋卦并列可完成"离在上"这一律的第三次验证**，且它是本库"盛大"这一格的空位；**其次是鼎 50（上离下巽）**——与本组家人卦（上巽下离）恰为反卦，可与晋／明夷这一对形成"离＋巽"的第二组反卦对照。

| **晋上九 ↔ 离上九** | **同为阳爻居上位、同用兵象**：离可对外（明是自己的），**晋只能对内（明是借来的）** |
| **晋 ↔ 乾** | **两条上升路的分工**：乾是自己长上去（刚），晋是被放上去（柔）。**两个九四正好相反：乾必须跃，晋不可抢** |
