# 知识卡 36 · 明夷卦（地火明夷）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："进必有所伤，故受之以明夷。夷者，伤也。"——晋卦（35）一路上行，**进到极处必有所伤**，于是转入明夷。
> **本卦是晋卦（35）的反卦，两卦是本组的核心一对**：晋＝上离下坤（**明出地上**，晋升），明夷＝上坤下离（**明入地中**，光被埋没）。**同样是离与坤，上下一换，一卦讲被往上放，一卦讲被压在下面。**
> ⚠️ **本卦是全库唯一直接讲"才能被压制、身处黑暗环境"的卦。**
> ⚠️ **本卦最重要的结构性事实（也是本卡对全库最大的贡献）**：**明夷六爻中五爻当位（只有六五不当位），却几乎拿不到一个吉字。** **这是全库"当位不保证吉"这条通则最极端的一例——自己位置正，救不了环境黑。**（详见末节）

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 明夷 · 第三十六卦 |
| **卦象** | 上坤（地／顺）下离（火／明），称"地火明夷"。**明入地中**——光明沉到地底下去了。<br>按本库结构律：**离在下 → 初九、六二、九三三爻全部当位**（明德在内、名正言顺）；**坤在上 → 六四、上六当位，六五不当位**。**全卦只有六五一爻不当位。**<br>**⚠️ 这个"当位率极高"必须与卦义一起读，否则会完全读反**：**离在下＝你的明是自己长出来的、是正的**；**坤在上＝上面压着厚厚三层土**。<br>**所以明夷的处境不是"你不行"，是"你行，但上面盖着东西"。** 这一条是本卦全部义理的起点。 |
| **领域定义** | **能力被压制、光被埋没、身处黑暗环境**。具体：<br>① 你的专业能力明显高于当前位置允许你发挥的范围，而且这不是暂时的；<br>② **汇报线被截断**——你的成果到不了能决策的人那里，或被中间层截留、改写、署名；<br>③ 直接上级的能力或意愿低于你，而他决定你的评价；<br>④ 组织／行业风气在变坏：讲真话的人在被清理，讲假话的人在上升；<br>⑤ 你身处一个"说对了会得罪人"的场合，**正确本身成了风险**；<br>⑥ 家族／团体内部出现了不能提的事，你知情，但发声的代价极高。<br>**凡是"我行，但这个环境不容我发挥，而且发亮会招祸"，都落在明夷卦。** |
| **不归本卦的情况** | 有实力但只是**时机未到、被柔性约束**，环境本身不敌你 → **小畜（9）**（"密云不雨"，雨还会来）；<br>已在**连续打击**之中，问题是"怎么活下来" → **坎（29）**（**坎讲脱险，明夷讲藏光**）；<br>是**大势整体闭塞、天地不交** → **否（12）**（**否是全局判断，明夷是"你的明"被埋**）；<br>冲突已经开打／已组织化 → **讼（6）／师（7）**；<br>你的光**还亮着、只是刚亮**，风险来自自己的节奏 → **离（30）**。 |
| **"明夷"二字本义** | **明**＝光明、明德、才智；**夷**＝伤（序卦传直接训"夷者，伤也"），又有**平、灭、低下**之义。**明夷＝光明被伤、被削平、被压到地下。**<br>**⚠️ "夷"字的双读，本卦两义都用**：作动词是"伤害光明"（**外部在打压**），作名词是"受伤的光明"（**你自己的处境**）。**卦名说的是处境，爻辞说的是应对。** |
| **卦辞原文** | 明夷：利艰贞。 |
| **⚠️ 卦辞的关键结构** | **无元、无亨；只有"利"和"贞"，而且两者之间被硬插进一个"艰"字。**<br>**① "无亨"是本卦最冷的一处。** 亨＝通。**《周易》明确不承诺明夷之时是通的。** 你不会因为守正就被看见——**这一点必须先接受，再谈别的。** 本卦读者最容易崩掉的地方，就是"我明明是对的，为什么还没被看见"——**卦辞已经回答了：这一卦不给"亨"。**<br>**② 与师卦对照**：本库师卦卡指出"师卦无元无亨无利、只有'贞'——天道对战争不许诺任何好处"。**明夷是另一种吝啬：它给了"利"，但把"艰"写进了条件里——益处只存在于"艰难地守正"这个动作里，不在别处。**<br>**③ 卦辞层用"艰"字极罕见。** 全书另一处著名的"艰贞"在**泰九三"艰贞无咎"**（本库已有）。**两处对照：泰九三是"顺境将要转"的艰，明夷是"环境本来就黑"的艰。** |
| **卦辞现代解** | **利**——这条路是有益的，**但益处不是外部回报，是你自己不被毁掉。**<br>**艰**——必须承认这是艰难的、而且会持续艰难。**任何"忍一忍就过去了"的预期都不成立**（上六给出的时间尺度是"初登于天，后入于地"——那是一整个升降周期）。<br>**贞**——守正。<br>**三个字连起来：在承认艰难的前提下守正，才有益。** 顺序不可颠倒：**先承认艰，再谈守正；不承认艰而守正，撑不过六四。** |
| **彖传** | 明入地中，明夷。内文明而外柔顺，以蒙大难，文王以之。利艰贞，晦其明也。内难而能正其志，箕子以之。 |
| **⚠️ 彖传要点（本卦纲领的一半在这里）** | ① **内文明而外柔顺**——**里面是明的（离在下），外面是顺的（坤在上）。** 这就是明夷的标准姿态：**内在保持清明，外在保持柔顺，两样都不能缺。**<br>**与兑卦彖传"刚中而柔外"是同一句法的两种内容**：**兑是内刚外柔（用于悦），明夷是内明外顺（用于藏）。** 本库由此可提一条通则：**《周易》凡讲"外柔"，必先规定"内"是什么；纯柔在全书没有一处是德。**<br>② **以蒙大难**——"蒙"是承受、蒙受。**这条路不承诺你避开大难，只承诺你能承受它。**<br>③ **利艰贞，晦其明也**——**⚠️ 彖传自己把"艰贞"翻译成了"晦其明"：所谓"艰难地守正"，具体动作就是把自己的明收暗。** **这是全卦最关键的一次自注，也是大象传"用晦而明"的直接来源。**<br>④ **内难而能正其志**——**难在里面（内难）时，能端正自己的心志。** 注意与"以蒙大难"的分工：**大难在外，用"柔顺"承受；难在内部，用"正志"顶住。**<br>⑤ 两个人物：**文王以之**（外有大难，以柔顺蒙之）、**箕子以之**（内有难，以正志守之）。⚠️ 人物为彖传原文所举，本库照录，不作史实断言。 |
| **大象传（行动纲领）** | 明入地中，明夷。君子以莅众，用晦而明。 |
| **⚠️⚠️ "用晦而明"解（本卦全部实操的核心）** | **莅众**＝临民、管理众人、面对一群人。**用晦而明**＝**用"晦"（把光收暗）的方式来达成"明"。**<br>**逐层拆开：**<br>**① "晦"是手段，"明"是目的。** **不是让你变糊涂，是把光收起来当工具用。** 收光不是放弃能力，**是不让能力成为攻击你的理由。**<br>**② 在黑暗的环境里，发亮＝暴露。** 你的明在明夷之时**不是资产，是靶子**。这一条是本卦与离卦最根本的分歧点。<br>**③ "莅众"点明了场景：这是管理者的纲领。** 面对一群人时，把什么都看穿、什么都点破、什么都要求清楚——**在明夷之时，这会把整个局面点燃。** 所以要"用晦"：**该知道的都知道，但不都说出来；该管的都管，但不都揪出来。**<br>**④ 落到现代的四条操作**：<br>· **不做全知的姿态**——不让人觉得"什么都瞒不过他"；<br>· **不在公开场合展示你比别人清楚多少**；<br>· **把判断转成行动，不要转成言论**（做出来，不说出来）；<br>· **对已经看破的事，保留"我还没看破"的余地**——这是给对方的退路，也是给自己的。 |
| **⚠️ 与离卦"继明照于四方"的正反对照（本卡最重要的一组对照）** | **离 30（上离下离·重明）：光亮在最高处，纲领"继明照于四方"——光要接得上，而且必须照到别人；违反则光断（九三"何可久也"）或纯烧（九四"焚如"）。**<br>**明夷 36（上坤下离·明入地中）：光埋在地底下，纲领"用晦而明"——光要收起来，只留自己看得见；违反（光露）则是上六"后入于地"。**<br>（完整对照表见末节第 3 条）<br>**⚠️ 两条纲领是同一件事的两个环境参数：环境亮的时候，光要外放且不能断；环境黑的时候，光要内收且不能灭。**<br>**《周易》从来没有给"要不要发光"一个绝对答案，它给的是"先看你在哪一卦里"。** 这是本库最重要的方法论示范之一。<br>**⚠️ 同时这也是对离卦那句名言的一次校正**：离卦卡说"**光不是你自己的，是附在别的东西上的**"（离在上／丽于天）；**而明夷的光恰恰是自己的**（离在下，下三爻全当位）——**正因为是自己的，才必须自己收好：没有别人替你收。** |
| **总铁律** | ① **"用晦而明"是唯一纲领**——在黑暗里收自己的光，**不是熄灭它**（大象传）；<br>② **接受"无亨"**——明夷之时不承诺通达，**不要用"我守正了怎么还没被看见"来动摇自己**（卦辞）；<br>③ **内明外顺**（彖传）——里面清楚、外面柔顺，缺一样都不成；<br>④ **该走就走，而且走得难看是正常的**（初九"垂其翼""三日不食""主人有言"）；<br>⑤ **受伤后先救腿，不救面子**（六二"用拯马壮"）；<br>⑥ **拿到主导权后绝不可急于清算**（九三"不可疾贞"）；<br>⑦ **进对方内部只为"获心意"，摸清就走**（六四"于出门庭"）；<br>⑧ **最重的一爻是上六：登得越高，掉得越彻底，而原因只有一个字——"失则"。** |

## 二、爻级字段

### 初九 · 明夷于飞

| 字段 | 内容 |
|---|---|
| **爻辞** | 明夷于飞，垂其翼。君子于行，三日不食。有攸往，主人有言。 |
| **象传** | 明夷于飞，垂其翼，义不食也。 ⚠️ 象传前半照录爻辞，仅末尾加"义不食也"四字 |
| **位属性** | 阳爻居阳位，**当位**；居下离之初——**明德在内、位置最正，却处全卦最下** |
| **判词 → 行动语义** | **无吉凶判词**（按本库口径：**无判词＋只给处境与代价＝《周易》承认你的难受，但不判你有咎，也不授权你越位**） → **该走就走，接受狼狈** |
| **关键词解** | **于飞**＝正在飞（要离开）。**垂其翼**＝翅膀是垂着的——**受了伤还要飞，飞得不好看。**<br>**君子于行**＝君子在路上（出走、离开）。**三日不食**＝三天没有进食。<br>**主人有言**＝所投奔的那位主人（新的接纳方）对你有闲话、有非议。 |
| **⚠️ 本爻的要点（全卦最容易被跳过的一条）** | **初九是全卦位置最正的爻之一（阳居阳位、明德在内），它的处境却是"垂翼、三日不食、主人有言"。**<br>**也就是说：明夷之时，走是对的，但走的代价一分都不会减。** 你会飞得难看（垂翼）、会有一段没饭吃（三日不食）、还会被新接纳你的人说闲话（主人有言）。<br>象传"**义不食也**"——**这个"不食"是义所当然的**：按道义，此时就该不吃那个环境给的食。**"三日不食"不是失败的证据，是选择的成本。**<br>**⚠️ 这三样是爻辞明写的、必然发生的项，不是意外。** 预算到了，就不会因为它们而回头。 |
| **识别信号** | ① 你已经判断这个环境不容你，而且不会变；② 你打算离开，但走得不体面（没有下家、要放弃在手的东西、会被说不够意思）；③ 你担心"新地方会不会看不起我这段经历"（主人有言）。 |
| **该做** | **走，并且预算好那"三日"**——一段没有收入／没有位置／被议论的空档期。**把"垂翼"当正常，不要为了飞得好看而多留。** |
| **不该做** | ① 为了体面退场而拖延；② 因为"新东家会有闲话"而不走。**"主人有言"是必然项，不是变量。** |
| **与讼九二"归而逋"的对照（重要）** | **讼九二"不克讼，归而逋，其邑人三百户，无眚"——弱势方火速撤退到最无威胁的地方，判词是"无眚"（免灾）**；**明夷初九"于飞，垂其翼"——同样是走，《周易》连"无眚"都不给，只给一句"义不食也"。**<br>**差别在退的对象**：**讼卦是从一场冲突里退出（冲突有边界，退到边界外就安全了）；明夷是从整个环境里退出（没有一块安全地可退）。**<br>**所以讼九二能拿到"无眚"，明夷初九只能拿到"义"。** **这一条要写给所有准备"裸辞式离开"的人：明夷的走没有安全保障，只有正当性。** |

### 六二 · 夷于左股（全卦唯一的"吉"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 明夷，夷于左股，用拯马壮，吉。 |
| **象传** | 六二之吉，顺以则也。 |
| **位属性** | 阴爻居阴位，**当位且得中**；**乘初九之刚**（阴爻直接压在阳爻之上）；处下离之中——**明德在内的最正之位** |
| **判词 → 行动语义** | **吉**（**全卦唯一的"吉"字**） → **伤已经成了事实，立刻去救行动力** |
| **关键词解** | **夷于左股**＝左腿受了伤（"股"＝大腿）。<br>**⚠️ 为什么是"左"**：古以右为用、为前，**左为次、为辅**——**伤在左股＝伤得不轻，但没伤在要命／主用的地方。**（本卦六四"入于左腹"也用"左"，同为"非正面"之义。）<br>**用拯**＝用来拯救、用来自救（"拯"＝救、举起）。**马壮**＝马是壮的。<br>**全句：左腿伤了，但有一匹壮马可以用来自救，吉。** |
| **⚠️ 本爻是全卦唯一的"吉"，理由写在象传里** | "**顺以则也**"——**顺，而且有法则。**<br>按本库口径，这与家人六二"顺以巽也"、师彖传"行险而顺"同源：**顺不是软，是"有则地顺"。《周易》凡讲顺，必带一个限定词。**<br>**本爻的实操极其清楚，而且顺序不可换**：**受伤了（伤已成事实，不可挽回）→ 不去处理伤口、不去追究是谁伤的 → 直接补上"壮马"（恢复移动能力）。** |
| **⚠️ "马"在本库中的固定语义（三卦一致）** | **晋卦卦辞"锡马蕃庶"——资源与行动力到手（晋升的硬指标）**；**坤卦卦辞"利牝马之贞"——顺而能行**；**明夷六二"用拯马壮"——被打伤之后先恢复移动能力。**<br>**结论：马＝位移与行动的能力。** **明夷六二说的是：在黑暗环境里被打伤之后，第一件要买的东西是"腿"，不是"药"。** |
| **识别信号** | ① 你已经被这个环境实实在在伤到了（被降职、被抢功、被穿小鞋、被排除在关键信息之外）；② 伤在"辅助面"而不是根本面——**你还能干活，只是使不上全力**；③ 你的第一反应是想弄清"是谁干的""为什么是我"。 |
| **该做** | **立刻补"壮马"**——恢复自己的移动能力：可迁移的技能、外部的关系、独立的收入来源、随时能走的准备。**这是本卦唯一被判"吉"的动作。** |
| **不该做** | 把力气花在追责和申诉上。**⚠️ 明夷之时没有裁决者**（对比讼卦九五"讼元吉，以中正也"——讼卦有一个当位得中的裁决位，**明夷卦没有**）。**在没有裁决者的局里追责，只会让你的"明"暴露得更彻底。** |
| **与震六二"亿丧贝"的对照（两个乘刚的六二）** | **震六二：当位、得中、乘刚，判词"厉"，动作是"跻于九陵，勿逐，七日得"——认赔、上高地、不去追**；<br>**明夷六二：当位、得中、乘刚，判词"吉"，动作是"用拯马壮"——认伤、补腿。**<br>**两爻结构完全同构，动作也同构（都不去追、都先恢复自己的能力）。差别在时间尺度**：**震是一次性冲击（"七日得"，有期限），明夷是持续的黑暗（无期限）**——**所以震只要"勿逐"就够了，明夷还必须"拯"（主动补一样东西）。** |

### 九三 · 得其大首

| 字段 | 内容 |
|---|---|
| **爻辞** | 明夷于南狩，得其大首，不可疾贞。 |
| **象传** | 南狩之志，乃大得也。 |
| **位属性** | 阳爻居阳位，**当位**；居下离之顶——**明之极，也是"明"与"地"（坤）的交界**；本库通则"**三多凶**"，**而本爻是本组四卦里第二个"三位无凶"之爻**（另一为晋六三） |
| **判词 → 行动语义** | **不可疾贞**（无吉凶判词，只给一条禁令） → **拿到了主导权，但绝不可急** |
| **关键词解** | **南狩**＝向南方行猎、征讨。**南为明之方位**（离为火、为南）——**向南出猎＝朝着光明的方向去征讨。**<br>**大首**＝为首的那一个、首恶。**得其大首**＝拿住了首要的那一个。<br>**疾**＝急、快。**不可疾贞**＝**不可以急着去"正"它**（"贞"在此作动词：正、匡正）。 |
| **⚠️ 本爻是明夷卦里唯一一个"转守为攻"的爻，而《周易》立刻给它上了刹车** | **爻辞承认成果**（得其大首）、**象传承认志向**（"南狩之志，乃大得也"——大有所得），**但爻辞的最后四个字是"不可疾贞"。**<br>**为什么不可疾**：九三虽当位、虽已到明之极，**但它上面压着整个坤（三层土）**——**你拿住了首恶，不等于你改变了环境。** 此时若立刻大举匡正，**就是用一个爻的力量去顶三个爻的土。**<br>**⚠️ 与离上九是同一条方法的两个时点**：**离上九"王用出征，有嘉折首，获匪其丑，无咎"——环境明的时候问责（象传"以正邦也"）**；**明夷九三"得其大首，不可疾贞"——环境暗的时候问责。** **同样只取"大首"，但明夷多了一句"不可疾"。** |
| **识别信号** | ① 你在黑暗环境里终于抓到了主动权（掌握了关键证据、拿到了关键位置、扳倒了那个具体的人）；② 你的支持者在推动你"一次性把它清干净"；③ 你觉得机会窗口很短，必须快。 |
| **该做** | **只处理"大首"那一个，然后停下来。** 把节奏放到最慢——**"不可疾"是本爻唯一的指令，而且经文没有给例外条款。** |
| **不该做** | 借势扩大、连带清算、公开宣示胜利。**在明夷之时，扩大打击面等于把自己的"明"全部暴露给上面那三层土。** |
| **与师六五、离上九、兑九四的四角对照（本库"精准处理"通则的完成）** | **师六五"长子帅师，弟子舆尸"——人要对**；<br>**离上九"有嘉折首，获匪其丑"——只罚首恶，切口要小**；<br>**兑九四"介疾有喜"——只隔断病处，不动整片和气**；<br>**明夷九三"得其大首，不可疾贞"——只取首恶，且不许快。**<br>**四爻合起来是本库"精准处理"通则的完整版：人要对（师）、切口要小（离、兑）、速度要慢（明夷）。** **明夷补上的正是"速度"这一维——而它只在环境黑的时候才成为硬约束。** |

### 六四 · 入于左腹

| 字段 | 内容 |
|---|---|
| **爻辞** | 入于左腹，获明夷之心，于出门庭。 ⚠️ **版本待核**：本爻爻辞异文较多，另有作"明夷，夷于左腹"者；本库照录通行本 |
| **象传** | 入于左腹，获心意也。 ⚠️ 象传近乎复述爻辞 |
| **位属性** | 阴爻居阴位，**当位**；**乘九三之刚**；**已入上坤——从"明"进入"地"，这是全卦的黑暗分界线**；本库通则"**四多惧**" |
| **判词 → 行动语义** | **无吉凶判词** → **深入内部摸清对方心意，然后出去** |
| **关键词解** | **入于左腹**＝进入到左腹（深处、内里）。**"左"仍是"非正面、辅侧"之义**——**不是正面进攻，是从侧后进入内部。**<br>**获明夷之心**＝**取得了"明夷"（那个伤害光明的一方，或整个黑暗局面）的真实心意**。<br>**于出门庭**＝然后从门庭出去（"于"＝乃、于是）。 |
| **⚠️ 本爻是本卦最"技术性"的一爻，也是"乘刚"的第三种破解** | 本库通则：**乘刚的压迫无法消除，但可以不构成灾**，此前已收两种破解：**艮六四"止诸躬"（把范围收回到自己这一身）**、**巽六四"田获三品"（交付可分配的实际成果）**。<br>**明夷六四给出第三种：入于左腹 → 获心意 → 于出门庭（进去、摸清、出来）。**<br>**三种破解的共同点：都不是去对抗下面那个阳刚，而是改变自己的作用范围。** 艮是缩小范围，巽是把范围转成成果，**明夷是把范围从"对抗"改成"获取信息"。**<br>**⚠️ 爻辞的动作顺序不可颠倒**：先"入"、再"获"、最后"出"。**"于出门庭"这四个字是本爻的安全阀：进去是为了出来，不是为了留下。** **摸清了就走；留下来，你就成了黑暗的一部分。** |
| **识别信号** | ① 你已经进入上坤——环境明确地黑了，光在你上面被土盖住；② 你有机会靠近核心、了解真实意图（被叫去参与、被透露、被拉进小圈子）；③ 你在犹豫要不要"进去看看"。 |
| **该做** | **可以进去，但必须带着"出来"的计划进去。** 目标只有一个：**弄清对方真实的心意**（象传"获心意也"）。拿到之后立刻"出门庭"。 |
| **不该做** | ① 进去之后留下来分好处；② 反过来，因为"不想脏手"而完全不去了解对方心意——**明夷之时最危险的一种人，是"什么都不知道地正直着"。** |
| **与坤六四"括囊"的对照（同一爻位、同是坤的当位之爻）** | **坤六四"括囊，无咎无誉"——扎紧口袋、闭嘴、不表态，象传"慎不害也"**；**明夷六四"入于左腹，获明夷之心"——不是闭嘴，是进去听。**<br>**⚠️ 两爻合读才完整：明夷之时，嘴要"括囊"（不说），耳朵要"入左腹"（要知道）。**<br>**只括囊不入腹，是安全但盲的；只入腹不括囊，是知情但暴露的。** **本库四位（多惧之位）的通用配方由此补齐：少说 ＋ 多知 ＋ 能出来。** |

### 六五 · 箕子之明夷（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 箕子之明夷，利贞。 |
| **象传** | 箕子之明夷，利用晦也。 ⚠️ 象传前半照录爻辞，仅末尾加"利用晦也"四字 |
| **位属性** | 阴爻居阳位，**不当位**（**全卦六爻中唯一不当位的一爻**），但**得中**且居尊位——**全卦卦主** |
| **判词 → 行动语义** | **利贞** → **在黑暗中守正并收起自己的光，这是唯一有益的做法** |
| **关键词解** | **箕子**＝彖传所举之人（"内难而能正其志，箕子以之"）。**本卦用他命名这一爻的处境：身在核心、身处内难、走不了、也不能亮。** ⚠️ 人物为经文原文所举，本库照录，不作史实断言。<br>**利贞**＝守正才有益（与卦辞"利艰贞"同一口径，**这里省掉了"艰"字——因为六五这个位置本身就是"艰"**）。 |
| **⚠️ 象传是全卦的落锤："利用晦也"** | **大象传给的是"用晦而明"（一条纲领），六五的小象给的是"利用晦"（一条利害判定）。**<br>**《周易》在卦主这一爻上，把"用晦"从方法升格成了判断：在这个位置上，收光是有益的。**<br>**⚠️ 注意六五是全卦唯一不当位的爻。** 按本库通则"**得中可救不当位**"——六五靠"得中"站住；**而它"得中"的具体内容就是"晦"：不偏向发光，也不偏向熄灭。** **"晦"在这里正是那个"中"。** |
| **⚠️ 本爻为什么是全卦最难的位置（本卦最重要的一条辨析）** | **初九可以走（于飞），六二可以补腿（拯马壮），六四可以进出（于出门庭）——只有六五走不了。**<br>**它在尊位、在核心、在"内难"之中：位置太高，走了就是天下大事；位置又不当，亮了就是引火。** **所以它唯一的动作就是"晦"。**<br>**⚠️ 这同时解释了本卦最大的一个悖论：为什么全卦当位率高达五分之六，却只有一个"吉"字？——因为全卦最关键的那个位置（尊位），恰恰是唯一不当位的那一爻。** **五个当位的爻都不在能定局的位置上。** |
| **识别信号** | ① 你在核心位置上（家族核心、组织核心、专业圈子的核心），走不了也不该走；② 环境已经黑了，而你比大多数人更清楚它有多黑；③ 你反复在两个极端之间摆动：要么把话全说出来，要么彻底躺平装傻。 |
| **该做** | **"晦"——第三条路。** 该知道的继续知道、该做的继续做，**但不显示自己知道多少**。把清明留在里面（内文明），把柔顺放在外面（外柔顺）。 |
| **不该做** | ① 把"晦"做成"装傻"——**装傻是把明灭了，不是收了；灭了就再也拿不出来**；<br>② 把"守正"做成"公开表态"——**明夷之时公开表态，就是上六的"初登于天"。** |
| **与坤六五、离六五、晋六五的对照（本库柔居尊位专题）** | **坤六五"黄裳，元吉"——有君之权而守臣节（放下名分）**；<br>**离六五"出涕沱若，吉"——居尊而保住忧惧（放下体面）**；<br>**晋六五"失得勿恤，无不利"——居尊而关掉算法（放下得失）**；<br>**明夷六五"箕子之明夷，利贞"——居尊而收起自己的光（放下"被理解"）。**<br>**四个柔居尊位之爻，各要求放下一样东西；而明夷六五要放下的这一样最难：不是名、不是利、不是脸面，是"被人知道我是对的"。** |

### 上六 · 初登于天，后入于地（全卦最重之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 不明晦，初登于天，后入于地。 |
| **象传** | 初登于天，照四国也。后入于地，失则也。 |
| **位属性** | 阴爻居阴位，**当位**；居全卦之终，**也是上坤之顶——黑暗的最深处** |
| **判词 → 行动语义** | **无吉凶判词**，但**象传"失则也"就是判词** → **此爻不可入** |
| **关键词解** | **不明晦**＝不明而晦（该明的不明，只剩晦暗）；一说读作"不明，晦"——**光明彻底没有了，只剩黑。**<br>**初登于天**＝起初登上了天（升到最高、照临天下）。**后入于地**＝后来落进了地里（沉到最底、不见天日）。<br>**象传两句分注**："**照四国也**"——**当初他登天的时候，是照亮四方之国的**（"四国"＝四方诸国）；"**失则也**"——**掉下去的原因是"失则"：失去了法度、法则。** |

#### ⚠️ 专项分析：本爻是全卦最重的一爻

**① 它是全书写"升降全程"写得最完整的一爻。**
**六个字走完一整条抛物线**：**初登于天**（最高）→ **后入于地**（最低）。**《周易》没有给它任何吉凶判词，因为不需要：这条曲线本身就是判词。**

**② 象传把因果切得极干净。**
登天时"**照四国**"——**说明他不是庸人，他真的亮过，而且亮到照遍四方**；
掉下去时"**失则**"——**说明掉下去的原因不是他不亮，是他丢了法度。**
**合起来是一句极重的话：把光照到最大的那个人，如果丢了法度，就会掉到最黑的地方去。亮得越大，掉得越深。**

**③ 它是整卦的成因说明（这一层最容易被漏掉）。**
明夷卦讲的是"明被埋在地下"。**上六告诉你，那个被埋在地下的"明"，最初是登过天的。**
**换句话说：明夷之世不是天生就黑的。是那个曾经照四国的人失了则、落了地，天下才黑的。**
**这一条对读者的用法**：**当你身处明夷（能力被压制）时，压着你的那个黑暗，往上追溯往往是某个曾经很亮的人／某套曾经很好的制度"失则"的结果。** **理解这一点，是从"这世界怎么这样"转到"是哪一条则被丢了"的关键一步。**

**④ 与乾上九、坤上六并读（本库上爻专题最重的一组）。**

| 上爻 | 爻辞 | 坏在哪 | 位属性 |
|---|---|---|---|
| **乾上九** | 亢龙有悔 | **过刚不知止** | 不当位 |
| **坤上六** | 龙战于野，其血玄黄 | **由顺变逆，要去夺** | 当位但穷极 |
| **明夷上六** | 不明晦，初登于天，后入于地 | **曾照四国而"失则"** | **当位** |

> **三条上爻是三种"到顶之后"的坏法：乾是不肯下来，坤是要去抢，明夷是丢了规矩。**
> **按本库上爻限定（"反的是不知止的极，不是到顶本身"）——明夷上六补上了第三种：不是不知止，是知止而失则。** **它掉下去的时候是当位的、也没有在夺（不像坤上六），它只是把法度丢了。**

**⑤ 对读者最直接的一条：本爻是"当位"的。**
**阴居阴位，位置完全正当，判词却是全卦最坏的图景。**
**这是本库"当位不保证吉"这条通则最极端的一例**（此前最强的例子是震六二当位得中而"亿丧贝"）。**明夷上六比它更极端：当位、居全卦终点、而且曾经照四国。**
> **合起来的通则（建议入索引）**：**当位保的是"名正言顺"，不保"结局好"。** **决定结局的是三样：卦义（环境）、是否得中（枢纽）、以及有没有丢掉那条"则"。**

| 字段 | 内容 |
|---|---|
| **识别信号** | ① 你（或你所在的组织／行业）曾经处在明确的高位，照过很多人；② 现在正在往下走，而且是持续的、成体系的下行；③ 有一样东西被丢掉了，而且大家都心里有数是什么——某条规矩、某条底线、某个不该破的例（**失则**）。 |
| **该做** | **把"失了哪一条则"找出来，先把那一条补回去。** 象传只给了一个原因，就只有一个解法。**不要先去修外面的黑，先去修丢掉的那条则。** |
| **不该做** | ① 用"当初我照过四国"来解释现在的处境；② 归因于时运、人心、大势——**象传写的是"失则也"，不是"时也""命也"。** |

## 三、明夷卦定位速查表

| 爻 | 处境 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | 判断要走 | 明夷于飞 | 已断定环境不容你，但走得不体面 | **当位** | **无判词**·走·预算"三日"·垂翼是正常的 |
| 六二 | 已被打伤 | 夷于左股 | 被实实在在伤到了，还能干活但使不上全力 | **当位·得中**·乘刚 | **吉（全卦唯一）**·**先补腿不补药** |
| 九三 | 拿到主动权 | 得其大首 | 终于抓住了那个人／那个证据 | **当位**·三多凶 | **不可疾贞**·只取首恶·**必须慢** |
| 六四 | 进入黑暗内部 | 入于左腹 | 有机会靠近核心、了解真实意图 | **当位**·乘刚 | **无判词**·进去→获心意→**出门庭** |
| 六五 | 核心走不了（**卦主**） | 箕子之明夷 | 在核心位置上，比谁都清楚它多黑 | **不当位（唯一）·得中居尊** | **利贞**·**用晦**（不是装傻） |
| 上六 | 曾照四国而坠 | 初登于天，后入于地 | 曾经在高位照过人，现在成体系下行 | **当位**·卦终 | **不可入**·**失则也**·先补那条则 |

**明夷卦三句话**：
1. **明夷的处境不是"你不行"，是"你行，但上面盖着东西"**（离在下三爻全当位，坤在上压着）。**所以卦辞不给"亨"——不要用"我守正了怎么还没被看见"来动摇自己。**
2. **纲领只有四个字："用晦而明"**（大象传）。**在黑暗里要收敛自己的光——收，不是灭。** **"晦"是手段，"明"是目的**；该知道的都知道，但不都说出来。
3. **六爻给出一条完整的行动序列**：**能走就走（初九）→ 走不了就先补腿（六二）→ 拿到主动权也不许急（九三）→ 要进内部但必须出来（六四）→ 走不了又不能亮，就"晦"（六五）→ 最深的黑，是有人丢了那条则（上六）。**

**本卦最反直觉的四条**：
- **五爻当位，却只有一个"吉"字。** **自己位置正，救不了环境黑。**（全库最强的一条反例，详见末节）
- **全卦唯一不当位的那一爻（六五），是卦主，也是全卦的答案所在。** **因为它是唯一在"能定局的位置"上的爻。**
- **被打伤之后，第一件事是"补腿"（用拯马壮），不是"上药"，更不是"追责"。** 明夷之时**没有裁决者可找**（对比讼九五）。
- **上六当位，却是全卦最坏的图景；而它坏掉的原因不是不知止，是"失则"。** **登天照四国的人也会掉进地里——只要他丢了法度。**

## 四、⚠️ 本卡对全库的意义

### 1. 填上全库最大的一个处境缺口：能力被压制

本库已完成 18 卦覆盖的处境是：主导（乾）、辅佐（坤）、草创（屯）、教育（蒙）、取利（需）、争讼（讼）、对抗（师）、结盟（比）、积累（小畜）、处世（履）、顺逆（泰否）、险难（坎）、光明（离）、冲击（震）、止（艮）、渗透（巽）、愉悦（兑）。

**其中没有一卦直接处理这个高频困境：我有能力，但这个环境不让我用，而且用出来还会招祸。**

| 相近的卦 | 差别 |
|---|---|
| **小畜 9** | "密云不雨"——**有实力被柔性约束，雨还会来**；明夷是**上面压着土，且不承诺"亨"** |
| **坎 29** | 连续打击、已在险中，问题是**怎么活下来**；明夷不一定有生存危险，问题是**怎么不发光而又不熄灭** |
| **否 12** | **全局闭塞**（天地不交），是大势判断；明夷是**你个人的明被埋**，环境可以整体不错而你被埋 |
| **艮 52** | **你有能力继续，但你自己决定不继续**（主动止）；明夷是**你想继续，但不许你亮**（被动晦） |

> **⚠️ 明夷与艮的分界是本卦最需要写进路由表的一条**：**"我决定不干了" → 艮（52）；"我想干，但不让我亮" → 明夷（36）。** 前者是自主的止，后者是被迫的晦。

### 2. ⚠️ 本卡对全库最重要的贡献：一条反例——当位率与吉凶不成正比

**晋（35）与明夷（36）是同一对三画卦上下互换，因此可以做一次严格的对照实验：**

| 爻位 | **晋 35**（上离下坤） | **明夷 36**（上坤下离） |
|---|---|---|
| 上 | 上九 · **不当位** | 上六 · **当位** |
| 五 | 六五 · **不当位**（得中·卦主） | 六五 · **不当位**（得中·卦主） |
| 四 | 九四 · **不当位** | 六四 · **当位** |
| 三 | 六三 · **不当位** | 九三 · **当位** |
| 二 | 六二 · **当位·得中** | 六二 · **当位·得中** |
| 初 | 初六 · **不当位** | 初九 · **当位** |
| **当位合计** | **1 / 6**（全库最低档，与讼 6、睽 38 并列） | **5 / 6**（全库最高档，与需 5、家人 37 并列） |
| **判词最好之爻** | 六五"**无不利**"（约等于大吉） | 六二"**吉**"（**全卦唯一的吉**） |
| **卦义** | **晋升、上行** | **光被埋没、贤者受难** |

> **一个只有 1 爻当位的卦出了"无不利"；一个有 5 爻当位的卦全卦只有一个"吉"字。**
> **结论（建议补入索引第五节"位属性判断规则"）**：
> **① 当位描述的是"你在这件事里名正不正"，它不描述"这件事整体是好是坏"。**
> **② 卦义由上下两卦的关系（明出地上／明入地中）决定；当位只决定"在这个既定卦义之下，哪一爻站得住"。**
> **③ 实务顺序：先看上下卦关系定"这是个什么局"，再看当位定"你在这个局里正不正"。两层不能混。**
> **④ 明夷是这条通则最锋利的样本：五爻当位而无吉，说明"自己正"这件事在明夷之时只能免咎，不能改局。** 这也正是卦辞为什么给"利贞"却不给"亨"。

### 3. "用晦而明"与"继明照于四方"：本库第一组"同一件事、相反指令"的纲领对

| | **离 30** | **明夷 36** |
|---|---|---|
| 结构 | 离在上下（重明） | **离在下（明在内）**，坤在上压之 |
| 纲领 | **继明照于四方** | **用晦而明** |
| 光的指令 | 外放、不能断、必须照到别人 | **内收、只留自己看得见、绝不能灭** |
| 主体 | **大人**以继明 | **君子**以莅众 |
| 失手的样子 | 光断（九三"何可久也"）／纯烧（九四"焚如"） | 光露（上六"后入于地"） |

> **这是本库第一次出现两条大象传纲领在同一件事上给出相反指令。**
> **它给全库立下一条读法：纲领不是道德律，是"环境参数 → 动作"的映射。** 问"要不要发光"是问错了问题；**要先问"我现在在哪一卦"。**
> **本组的家人卦（37）与离卦之间还有第二例**：**离六五要"忧"（出涕沱若，吉），家人九五要"勿恤"（不必忧虑，吉）。** 同为居尊位，指令相反，差别在环境（外部高光 vs 家内）。

### 4. 乘刚破解的第三式，以及四位（多惧之位）配方的补齐

| 卦 | 六四 | 动作 | 判词 | 破解机制 |
|---|---|---|---|---|
| **艮 52** | 艮其身 | **止诸躬**——把范围收回到自己这一身 | **无咎** | 缩小范围 |
| **巽 57** | 田获三品 | **获**——交付可分配的实际成果 | **悔亡·有功** | 转成成果 |
| **明夷 36** | 入于左腹 | **获心意 → 于出门庭**——进去摸清，然后出来 | **无判词** | **改为获取信息** |
| **家人 37** | 富家 | **富**——把自己这一摊做厚 | **大吉** | 做厚基础（见家人卡） |

> **四种破解的共同点：都不是去对抗下面那个阳刚，而是改变自己的作用范围。**
> **同时，明夷六四与坤六四合读，补齐了本库"四位"的通用配方**：**坤六四"括囊，无咎无誉"（少说）＋ 明夷六四"入于左腹，获心意"（多知）＋"于出门庭"（能出来）。** **少说、多知、能出来——这是四位（近君、多惧）三条缺一不可的纪律。**

### 5. 一条新增的口径建议：象传"失则也"

本库判词表现有十级（元吉…凶）＋两条补充（无判词＋未光也；无判词＋只给心理状态）。**明夷上六提供了第三条补充：**

> **⚠️ 无判词 ＋ 象传给出"失则也"**：**《周易》不下吉凶，而是直接指出成因——"你丢了一条法度"。**
> **这一档的行动语义极明确：解法只有一个，把那条则找回来。** 它比"未光也"重（未光只是白过），**但比"凶"轻（它给了唯一且明确的解法）。**
> **同类可比**：兑上六"未光也"（没有新内容）｜震九四"未光也"（陷泥动不了）｜**明夷上六"失则也"（丢了法度）**。

### 6. 与已完成各卡的衔接一览

| 衔接 | 机制 |
|---|---|
| **明夷 ↔ 晋** | **同一对三画卦上下互换。晋＝明出地上（1 爻当位·无不利），明夷＝明入地中（5 爻当位·仅一吉）。当位率与吉凶不成正比的最强反例** |
| **明夷 ↔ 离** | **"用晦而明" vs "继明照于四方"——本库第一组相反指令的纲领对。** 且明夷的光是自己的（离在下全当位），**正因为是自己的才必须自己收好** |
| **明夷初九 ↔ 讼九二** | **两种"走"**：讼卦从一场冲突里退出（有边界，"无眚"）；**明夷从整个环境里退出（无安全地，只给"义"）** |
| **明夷六二 ↔ 震六二** | **两个当位得中而乘刚的六二**：震"勿逐，七日得"（一次性冲击）；**明夷"用拯马壮"（持续黑暗，必须主动补一样东西）** |
| **明夷九三 ↔ 离上九／兑九四／师六五** | **"精准处理"通则的完整版**：人要对（师）、切口要小（离、兑）、**速度要慢（明夷）** |
| **明夷六四 ↔ 坤六四** | **四位配方**：括囊（少说）＋ 入左腹（多知）＋ 出门庭（能出来） |
| **明夷六四 ↔ 艮六四／巽六四** | **乘刚破解的第三式**：改为"获取信息"而非对抗 |
| **明夷六五 ↔ 坤六五／离六五／晋六五** | **柔居尊位专题**：放下名分／体面／得失／**"被理解"** |
| **明夷上六 ↔ 乾上九／坤上六** | **三种"到顶之后"的坏法**：不肯下来（乾）／要去抢（坤）／**丢了法度（明夷）** |
| **明夷 ↔ 艮** | ⚠️ **路由分界**：我决定不干了 → 艮；**我想干但不让我亮 → 明夷** |
| **明夷 ↔ 家人** | 序卦传"**夷于外者必反其家**"——**在外面受了伤的人回到家里**。这是明夷之后唯一的去处，也是家人卦在序卦中的位置 |
