# 知识卡 38 · 睽卦（火泽睽）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："家道穷必乖，故受之以睽。睽者，乖也。"——**家道走到尽头必然背离**，于是转入睽卦。
> **⚠️ 序卦传把睽的成因写死了：睽不是从陌生人之间开始的，是从"家道穷"开始的——关系破裂发生在原本最亲近的人之间。** 这一条决定了本卦的全部语气。
> ⚠️ **本卦是全库唯一直接讲"关系破裂与修复"的卦。**
> ⚠️ **本卦的结构性事实**：上离下兑——**兑在下则初九当位、九二不当位（得中）、六三必不当位；离在上则三爻全不当位。全卦只有初九一爻当位。**
> ⚠️ **与讼卦（6）的结构对照是本卡最锋利的一条**：**讼卦六爻只有九五（裁决者，当位得中居尊）一爻当位；睽卦六爻只有初九（最底层）一爻当位——睽卦里没有裁决者。**（详见末节）

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 睽 · 第三十八卦 |
| **卦象** | 上离（火／明）下兑（泽／悦），称"火泽睽"。**上火下泽**——**火性上炎，泽性下流，两者背向而行。**<br>按本库结构律：**兑在下 → 初九当位、九二不当位（但得中）、六三必不当位**；**离在上 → 九四、六五、上九三爻全部不当位**。**合起来：全卦只有初九一爻当位。**<br>**⚠️ 与讼卦是同一种"背道而驰"的卦象**：**讼是"天与水违行"（天往西、水往东），睽是"上火下泽"（火往上、泽往下）。这是全书唯一两个把"方向相反"直接写进大象传的卦。**<br>**但两者的相反方式不同**：**讼是两个力互相顶（对撞），睽是两个力各走各的（不相及）。** 这个差别是本卦与讼卦全部分野的根。 |
| **领域定义** | **关系的背离、对立与修复**。<br>① 曾经很亲近的人现在说不到一块去（伴侣、父母子女、多年老友、创业合伙人）；<br>② 团队里两派人看同一件事得出完全相反的结论，且**互相认为对方有问题**；<br>③ 你和某个人之间**已经开始互相猜测动机**（他为什么这么说、他是不是在针对我）；<br>④ **沟通已经无效**——你说的每句话都被对方读成另一个意思；<br>⑤ 一个组织内部分裂成两块，**还没有公开对抗，但已经不合作**；<br>⑥ 你被孤立了，而且你怀疑背后有人在串联（"睽孤"）。<br>**凡是"我们还没打起来，但已经看不到一块去了"，都落在睽卦。** |
| **不归本卦的情况** | **已经开打、要争要诉** → **讼（6）**（**睽是还没打起来的对立；一动手就出睽入讼**）；<br>已经组织化对抗、要拉人打硬仗 → **师（7）**；<br>关系**还没坏透、还能坐下来立规矩** → **家人（37）**（**序卦：家道穷才到睽**）；<br>是要选择**跟谁站在一起** → **比（8）**；<br>关系尚好，只是要经营愉悦底色 → **兑（58）**。 |
| **"睽"字本义** | **说文："睽，目不相听也。"**——**两只眼睛不朝同一个方向看。** 序卦传直接训"**乖**"（背、违、不合）。<br>**⚠️ 引申到本卦最关键的一层：睽不是"吵架"，是"视线不交"。** **你们看的不是同一件事，所以说什么都对不上。** 这解释了为什么睽的痛苦不是"被打"，而是"你说什么他都不接"。 |
| **卦辞原文** | 睽：小事吉。 |
| **⚠️ 卦辞的关键结构** | **元、亨、利、贞四德全缺，只给三个字："小事吉"。**<br>**这是全书唯一一条把"能成什么规格的事"直接写进卦辞的卦。**<br>**⚠️ 与巽卦"小亨"的分工必须分清**：**巽卦"小亨"限的是"通的程度"（能通，但只能小通）；睽卦"小事吉"限的是"事的规格"（大事一件都不要动，小事反而是吉的）。**<br>**含义极明确：在关系背离的状态下，把所有事情的规格降下来。** 不要在睽之时做重大决定、重大投入、重大表态、重大清算。<br>**⚠️ 但请注意它给的是"吉"**——**《周易》没有说睽是凶的。** 它说的是：**规格降下来，就是吉的。** **这是全书对"对立状态"最宽的一句话，也是本卦全部希望的来源**（彖传更进一步："睽之时用大矣哉！"）。 |
| **卦辞现代解** | **在关系已经背离的时候，把所有事情的规格降到"小事"**——**小额、小范围、可撤回、不必表态、不涉及原则、不需要对方认同你的动机。**<br>**在这个规格上，事情是能办成的（吉）；一旦升格，就会触发六三的"见舆曳，其牛掣"（处处被拖住）和上九的"载鬼一车"（猜疑生幻象）。**<br>**⚠️ 这一条是本卦最容易执行、也最容易被跳过的一条**：绝大多数关系破裂的加速，都是因为有人在睽之时坚持要办一件大事（要一个说法、定一个规矩、分一次家、开一次"把话说清楚"的会）。 |
| **彖传** | 睽，火动而上，泽动而下；二女同居，其志不同行。说而丽乎明，柔进而上行，得中而应乎刚，是以小事吉。天地睽而其事同也，男女睽而其志通也，万物睽而其事类也；睽之时用大矣哉！ |
| **⚠️ 彖传要点（本卦最重要的思想都在这里）** | ① **火动而上，泽动而下**——**两者不是互相攻击，是各走各的方向。**<br>**这是"睽"与"讼"的根本差别：讼是两个力互相顶，睽是两个力互不相干。** **睽的痛苦不是被打，是"你说什么他都不接"。**<br>② **二女同居，其志不同行**——**离为中女、兑为少女**（说卦传），**两个同类住在一起，志向却不同路。**<br>**⚠️ 这一句极重要，它给出了睽的两个前提**：**睽发生在"同居"的人之间**（同一个屋檐下、同一个团队、同一个家），**而且发生在"同类"之间**（不是异类相斥，是同类不同志）。<br>**与兑卦大象传"丽泽"对照**：**同样是两个相近的东西挨在一起——兑是"互相润泽"，睽是"其志不同行"。** **同一个相邻结构，两种完全不同的结果。**<br>③ **说而丽乎明**——**以悦（兑）附丽于明（离）。**<br>**⚠️ 注意这与履卦彖传"说而应乎乾"是同一个句式。** 本库履卦卡与兑卦卡已联读得出："**履卦'老虎不咬你'的机制就是兑（悦）；以悦相应可以，上门讨好（来兑）是凶。**"<br>**睽卦这里的"说而丽乎明"是同一味药在对立场景里的用法：在背离的关系里，你能动的不是"讲道理"（明在上、是对方那一边的），是"先把气氛放和"（悦在下、是你这一边的）。**<br>④ **得中而应乎刚**——**六五得中而应九二之刚**：**这是全卦唯一一组阴阳相应，也是"小事吉"的结构来源**，更是九二"遇主于巷"与六五"厥宗噬肤"这一条修复通路的依据。<br>⑤ **⚠️⚠️ 天地睽而其事同也，男女睽而其志通也，万物睽而其事类也；睽之时用大矣哉！**<br>**这是全书对"差异"最高的一次肯定**：<br>**天与地是背离的（一上一下），但它们做的是同一件事；男与女是背离的，但心志是通的；万物各不相同，但事理同类。**<br>**"睽之时用大矣哉"——背离这个时机，它的用处大得很。**<br>**➡️ 本库转译（本卦最重要的一条义理）**：**《周易》不认为"看不到一块去"本身是坏的。** 它认为**差异是结构性的、永久的、而且有大用**；**坏的是把"差异"当成"敌意"。**<br>**睽卦全部的病，都发生在"把不同解释成针对"这一步上。** **上九的"载鬼一车"就是这一步走到极处的样子。** |
| **大象传（行动纲领）** | 上火下泽，睽。君子以同而异。 |
| **⚠️ "同而异"解（本卦最高层原则）** | **四个字，两个方向，而且两个都是要求："同"是要求，"异"也是要求。**<br>**① "同"——在大处、在共同利益、在必须一致的地方保持一致。**<br>**② "异"——在小处、在方法、在偏好、在看法上允许不同，并且不去消除它。**<br>**合起来：君子在"同"上求同，在"异"上留异——这不是折中，是分层。**<br>**⚠️ 这条纲领的关键是它的顺序：是"同而异"，先同后异。**<br>**在关系已经背离的时候，如果不先确认"我们在哪一点上是一致的"，任何"我允许你不同"都会被对方读成"你不在乎我"。** 顺序颠倒了，这条纲领就完全失效。<br>**➡️ 落到现代的三步**：<br>**① 把"我们共同要的东西"明确说出来**（同）——孩子好、公司活着、这个家不散；<br>**② 把分歧的范围明确圈小**（异只在这几件事上，不蔓延）；<br>**③ 在圈定的范围里，不再试图说服对方。**<br>**第三步是最难也最关键的：睽卦的解法里没有"说服"这个动作。** |
| **总铁律** | ① **睽之时只做小事**（卦辞"小事吉"）——**降规格是唯一的通行证**；<br>② **丢了的东西不要去追**（初九"丧马勿逐，自复"）；<br>③ **该见的"恶人"要去见**（初九"见恶人，无咎"，象传"以辟咎也"）——**不为和好，为避灾**；<br>④ **修复关系要走非正式渠道**（九二"遇主于巷"，象传"未失道也"）；<br>⑤ **孤立时要找一个够格的人双向交心**（九四"遇元夫，交孚"）；<br>⑥ **有人开了口子就认下并往前走，不要计较开的方式**（六五"厥宗噬肤，往无咎"）；<br>⑦ **⚠️ 猜疑到极处会生幻象，此时的解药不是证据，是"遇雨"**（上九——见专项分析）；<br>⑧ **差异是永久的、有大用的；敌意是自己加上去的**（彖传）。 |

## 二、爻级字段

### 初九 · 丧马勿逐（全卦唯一当位之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 悔亡。丧马勿逐，自复。见恶人，无咎。 |
| **象传** | 见恶人，以辟咎也。 ⚠️ 小象只解释了后半句（"见恶人"），未及"丧马勿逐" |
| **位属性** | 阳爻居阳位，**当位**；**是全卦六爻中唯一当位的一爻**；居下兑之底——本库通则"**兑在下＝易落入讨好的陷阱**"，**而初九正是兑在下唯一当位的那一爻，也是本卦唯一的立足点** |
| **判词 → 行动语义** | **悔亡 ＋ 无咎** → **不追已经丢掉的，去见不想见的** |
| **关键词解** | **丧马**＝丢了马。**⚠️ "马"在本库中是固定语义：行动力与位移能力**（对照晋卦辞"锡马蕃庶"＝资源与行动力到手；明夷六二"用拯马壮"＝受伤后先补腿）。<br>**勿逐**＝不要去追。**自复**＝它自己会回来。<br>**恶人**＝**你所厌恶的人、与你不合的那一方**——**⚠️ 不是"坏人"。这是本爻最容易误读的一个词，读错了整条指令就反了。**<br>**辟咎**＝"辟"通避，**避开灾祸**（与离初九"以辟咎也"同句）。 |
| **⚠️ 本爻给了睽卦最开头的两个动作，一正一反** | **【动作一】"丧马勿逐，自复"——不要去追。**<br>**睽之初，你会先丢东西**：丢掉一部分默契、一部分信任、一部分本来该有的支持（**丧马**＝失去了原来那份"能动起来"的关系资源）。<br>**《周易》的指令是"勿逐"，理由是"自复"（它自己会回来）。**<br>**⚠️ 为什么不能追**：在关系背离的状态下，**"去追"这个动作本身会被对方读成施压。** 追得越紧，越回不来。**这与震六二"勿逐，七日得"是完全同一个机制**（本库已有）：**冲击型的损失，追它等于加深它。**<br>**【动作二】"见恶人，无咎"——要去见。**<br>**这是本爻更反直觉的一半：在关系已经背离的时候，要主动去见那个你不想见的人。**<br>**象传给的理由极其冷静："以辟咎也"——是为了避灾。**<br>**不是为了和好，不是为了讲清楚，就是为了避灾。** 按本库口径，**无咎＝无灾，不等于吉利**——**见了不会变好，但不见会出事。**<br>**⚠️ 机制**：睽之时，**不见面 → 只能靠猜 → 猜疑积累 → 上九的"载鬼一车"。** **"见恶人"是整卦对猜疑最早、最便宜的一道拦截。** 越早做，成本越低。 |
| **识别信号** | ① 一段亲近关系刚开始背离，你已经感到"有些东西没了"；② 你想去把它追回来（要解释、要挽回、要一个说法）；③ 有一个人你很不想见，而且你正在避开他。 |
| **该做** | **① 停止追讨（勿逐）；② 主动安排一次和"恶人"的见面——不带议题、不求结论，就是见到。** 这是全卦成本最低的动作，也是唯一在最底层就能做的事。 |
| **不该做** | ① 追讨已经丢掉的默契与信任；② **靠中间人传话来代替见面**——**在睽卦里，传话是"载鬼一车"的燃料**（每一手转述都会被两边各加一层解释）。 |
| **⚠️ 与兑六三"来兑，凶"的辨析（本爻最需要划清的边界）** | **兑六三"来兑，凶"——主动去讨好、上门逢迎，象传理由"位不当也"，本库判为"用姿态补位置的亏空，而姿态补不了位置"**；<br>**睽初九"见恶人"——同样是主动往对方那里去，判词却是"无咎"，象传理由是"以辟咎也"。**<br>**⚠️ 两个动作外形相同，判词一凶一无咎，差别有两条：**<br>**① 位属性**——**兑六三不当位（没有正当立场），睽初九当位（有正当立场）**；<br>**② 目的**——**"来兑"要的是"他高兴"，"见恶人"要的是"事不坏"。**<br>**➡️ 合起来的通则（建议入库）：主动接触本身没有吉凶。看两件事——你去的时候位置正不正，以及你要的是"他高兴"还是"事不坏"。** |

### 九二 · 遇主于巷

| 字段 | 内容 |
|---|---|
| **爻辞** | 遇主于巷，无咎。 |
| **象传** | 遇主于巷，未失道也。 ⚠️ 象传近乎复述爻辞 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**（下兑之中）；**与六五相应**——**是彖传"得中而应乎刚"里的那个"刚"，也是全卦唯一一组阴阳正应** |
| **判词 → 行动语义** | 无咎 → **换一个非正式的场合，把那条断了的线接上** |
| **关键词解** | **遇**＝**不期而遇**（**不是"约见"——这个字很重要**）。<br>**主**＝所要见的那位主事者，**此处指与它相应的六五**。<br>**巷**＝**里巷、小路、非正式的场所**（不是朝堂、不是正式会议、不是"专门找你谈谈"）。<br>**未失道**＝没有偏离正道。 |
| **⚠️ 本爻是全卦最实用的一条方法** | **九二和六五是全卦唯一一组相应的爻**——**也就是说：在这个"几乎没有一爻当位"的背离结构里，只有一条线是通的，就是九二 ↔ 六五。**<br>**而这条线的接法不是走正门，是"于巷"。**<br>**⚠️ 为什么必须"于巷"**：睽之时，**正式渠道已经被"睽"污染了**——公开场合的每一句话都会被解读成立场、被记录、被传播、被第三方引用。**要接上一条断了的线，只能在非正式的、低压力的、可否认的场合。**<br>**⚠️ 象传特意加了一句"未失道也"**——**《周易》知道读者会怀疑"私下里见是不是不够磊落"，所以直接给了背书：走小路去遇见，没有偏离正道。** 这句背书本身就是本爻最珍贵的部分。<br>按本库口径，**无咎＝无灾，不等于吉利**：**"遇主于巷"不会解决问题，它只是把线接上，让后面的事（六五的"往无咎"）有可能发生。** |
| **识别信号** | ① 你和关键的那个人（上级、伴侣、合伙人、父母）之间的正式沟通已经完全无效；② **每次正式沟通之后关系更差**；③ 你处在"事情实际要靠你办"的枢纽位置，但名分不足（不当位却得中）。 |
| **该做** | **创造一次非正式的相遇**——顺路、饭桌、走廊、共同的第三方场合、一起做一件不相干的小事。**不谈结论，不带方案，只把人际那条线接上。** |
| **不该做** | ① 继续用正式渠道（发长信息、提交报告、开专门的会、请人评理）去解决睽；② 因为"私下沟通显得不磊落"而拒绝走"巷"——**象传已经把这条顾虑挡掉了。** |
| **与巽九二"巽在床下，用史巫纷若"的对照** | **巽九二不当位但得中，动作是"把姿态放到最低、把沟通次数加到最多"，判词"吉，无咎"**；<br>**睽九二不当位但得中，动作是"换一个非正式的场合去遇见"，判词"无咎"。**<br>**两爻结构完全同构**（都是不当位·得中·居下卦之中·要推动一个自己没有强制力的对象）；**差别在调的参数**：**巽调的是"频次与姿态"，睽调的是"场合"。**<br>**➡️ 合起来是本库"没有强制力时怎么推事"的完整两招：改频次（巽），改场合（睽）。** |

### 六三 · 见舆曳

| 字段 | 内容 |
|---|---|
| **爻辞** | 见舆曳，其牛掣，其人天且劓，无初有终。 |
| **象传** | 见舆曳，位不当也。无初有终，遇刚也。 |
| **位属性** | 阴爻居阳位，**不当位**（**象传直接点名"位不当也"**）；**乘九二之刚**；居下兑之顶——**本库结构律"兑在下则六三必不当位"**；本库通则"**三多凶**" |
| **判词 → 行动语义** | **无初有终** → **开头完全不成，但结尾有——而且成因是"遇刚"，不是"忍够"** |
| **关键词解** | **舆曳**＝车子被向后拖住（"曳"＝拖）。**牛掣**＝拉车的牛被牵制住（"掣"＝牵、拽）。<br>**天**＝**通"而"，指剃去头发的刑罚**（一说"天"为额上刺字之刑）；**劓**＝**割鼻之刑**。**天且劓＝又被去发、又被割鼻**——**受了双重的、加在脸面上的伤害。** ⚠️ "天"字训解有异说（剃发／刺额），本库并存；**两说所指相同：加于面部、无法遮掩的公开羞辱。**<br>**无初有终**＝开始没有，最后有（**与巽九五"无初有终"同辞**）。 |
| **⚠️ 本爻是全卦最狼狈的一爻，也是"睽"的痛感最真实的一爻** | **三个意象层层加码**：**车被拖住（走不了）→ 牛被牵住（连拉车的力气都被制住）→ 人被伤在脸上（羞辱是公开的、遮不住的）。**<br>象传只给了四个字的原因：**"位不当也"**——**与兑六三"来兑之凶，位不当也"、晋九四"鼫鼠贞厉，位不当也"完全同一个句式。** 本库通则：**不当位＝名不正言不顺；姿态补不了位置，力气也补不了位置。** |
| **⚠️ 但本爻有救，救在最后四个字："无初有终"，而象传给了理由："遇刚也"** | **"遇刚"指的就是它上面的九四**（六三上承九四之阳）。<br>**也就是说：六三自己走不动（车和牛都被制住了），但它会遇到那个刚爻，然后就有"终"。**<br>**➡️ 本库转译**：**在睽之时，如果你正处在"处处被拖住、还被公开羞辱"的位置上，经文的判断不是"你完了"，而是"开头一定不成，但你会遇到一个能把车拉动的人"。**<br>**你要做的不是自己再使一次力，是等到并接住那个"刚"。**<br>**⚠️ 同辞对照（本库已有）**：**巽九五"无初有终"——居尊者做柔性变革，前期没动静是正常的（时间维度）**；**睽六三"无初有终"——被困者遇到刚爻才动得了（外力维度）。**<br>**同样四个字，一个靠等时间，一个靠等人。** |
| **识别信号（诊断清单）** | ① 你在这件事上处处被拖住，每推一步都有反向的力（舆曳、牛掣）；② 你不仅办不成事，还在人前丢了脸（天且劓）；③ 你的位置本来就名分不足（不当位）；④ 你的第一反应是"我再加把劲""我要把这个脸挣回来"。 |
| **该做** | **停止自己发力，去找那个"刚"**——那个有位置、有决断力、能把车拉动的人。**并且接受"无初"：开头这一段是注定不成的，这不是你的能力问题。** |
| **不该做** | ① 为了把脸面挣回来而加大动作——**"天且劓"是已经发生的事实，挣不回来，只会加深**；<br>② 把"无初有终"读成"忍忍就好了"——**它的机制是"遇刚"，不是"忍够"。** 光忍不遇，还是"无初"。 |
| **与讼六三、屯六二的三角对照** | **讼六三"食旧德，贞厉，终吉"——不当位失中，守本分、功归上，则终吉**；<br>**屯六二"当位得中但乘刚，十年乃字"，象传"六二之难，乘刚也"——什么都没做错，只是生态位难受**；<br>**睽六三"不当位、乘刚、且被公开羞辱，无初有终"。**<br>**三爻共同点：都处在"个人努力无效"的位置上，而经文都不判它有咎。**<br>**差别在解法：讼六三守本分（低调），屯六二等时间（十年乃字），睽六三等人（遇刚）。** |

### 九四 · 睽孤，遇元夫

| 字段 | 内容 |
|---|---|
| **爻辞** | 睽孤，遇元夫，交孚，厉无咎。 |
| **象传** | 交孚无咎，志行也。 |
| **位属性** | 阳爻居阴位，**不当位**；**刚入上离——离在上则三爻全不当位，九四是第一个**；本库通则"**四多惧**" |
| **判词 → 行动语义** | **厉 → 无咎**（按本库口径：**厉＝警告，非判死**） → **孤立之中找到一个够格的人，双向交付诚信，则免灾** |
| **关键词解** | **睽孤**＝**在睽之中被孤立、孤单**（**"睽孤"三字在本卦出现两次：九四与上九——见上九专项对照**）。<br>**元夫**＝那个"元"（首、善、大）的男子，即**一个够格的、可以对等相待的人**（一说指与它相应之位的初九）。<br>**交孚**＝**互相交付诚信**（**"交"是双向的**，与家人九五象传"交相爱"、兑卦"丽泽"同一结构）。 |
| **⚠️ 本爻是全卦第一次给出"孤"的解药** | **"睽孤"是本卦对读者处境最精准的一个词**：**关系背离到一定程度，人的主要感受不是愤怒，是孤。**<br>**你不再有人可以核对判断——于是所有判断都只能靠自己猜。这就是上九"载鬼一车"的前一步。**<br>**解药是"遇元夫，交孚"：找到一个够格的人，双向地交付诚信。**<br>**⚠️ 三个字都是硬性限定条件，缺一不可：**<br>**"元"**——**必须是够格的人**。对照**兑九五"孚于剥，有厉"**：**诚信给错对象，位置再正（当位·得中·居尊）也有危**。**孤立中的人最容易在这一条上出错。**<br>**"交"**——**必须是双向的**。**单向交付＝兑六三"来兑"，凶**；单向倾诉不构成"交孚"。<br>**"孚"**——**交付的必须是诚信（真实的判断与处境），不是好处。**<br>象传"**志行也**"——**心志得以行。** **"孤"的实质是"你的判断没有出口"，而"交孚"打开的正是这个出口。**<br>**⚠️ 判词"厉无咎"的读法**：**先"厉"（这仍然是危险的处境），后"无咎"（做了这个动作则免灾）。** **《周易》没有说"遇元夫"能解决睽，只说它能让你不出灾。** |
| **识别信号** | ① 你在这件事上已经孤立——**没有一个人能跟你核对判断**；② 你开始越来越多地靠推测去理解别人的动机；③ 你身边有一两个够格但你还没有真正交心的人。 |
| **该做** | **找一个够格的人，把真实的判断和处境说给他听，并且听他的。**<br>**⚠️ 注意"交"字：你必须也接住他给你的东西（包括他不同意你的部分），否则那只是倾诉，不是交孚。** |
| **不该做** | ① 在孤立中独自加大推测；② **把心交给一个不够格的人**——**"元"字是硬条件，违反它会直接掉进兑九五"孚于剥，有厉"。** 孤立中的人最容易抓住任何一个愿意听的人，**而这一条正是经文提前挡掉的。** |
| **⚠️ 与离九四的对照（同一爻位、同是"离在上"的第一爻，判词天差地别）** | **离九四"突如其来如，焚如，死如，弃如"，象传"无所容也"——不当位又处两重火的交界，附不住任何东西，纯烧必尽。本库判定：三大险爻里唯一没有爻内解药的一爻。**<br>**睽九四同样不当位、同样是"离在上"的第一爻，却给了爻内解药（遇元夫，交孚），判词只到"厉无咎"。**<br>**⚠️ 差别的结构原因在下卦**：**离九四下面是另一重火（越烧越旺，无处可附）；睽九四下面是兑（悦）——它还有一个"能让人愉悦地接近"的底子，所以它遇得到"元夫"。**<br>**➡️ 这是本库"上卦相同、下卦不同则判词分野"的最好一例，可直接入库为读卦方法：同一个爻位的吉凶，往往由另一半卦决定。** |
| **与履九四的呼应（两处"志行也"）** | **履九四"履虎尾，愬愬，终吉"，象传"志行也"——极度戒惧，所以志向反而能推行**；**睽九四"交孚无咎"，象传"志行也"——把判断交出去，所以心志得以行。**<br>**两处"志行"的共同点：都不是靠加大力度，一个靠"怕"，一个靠"交"。** |

### 六五 · 厥宗噬肤（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 悔亡，厥宗噬肤，往无咎。 |
| **象传** | 厥宗噬肤，往有庆也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位；**乘九四之刚**；**与九二相应**——**是彖传"得中而应乎刚"里的那个"中"，也是"小事吉"的结构来源。全卦卦主。** |
| **判词 → 行动语义** | **悔亡 ＋ 往无咎**，象传更给"**往有庆也**" → **同宗的人已经把最容易的那一口咬开了，你只管往前走** |
| **关键词解** | **厥宗**＝他的同宗、同族之人，**此处指与它相应的九二**。<br>**噬肤**＝咬开肌肤——**"肤"是最容易咬开的那一层**（对照噬嗑卦六二"噬肤"）。<br>**厥宗噬肤**＝**同宗的那个人已经把最容易的那一口咬开了**，即**已经有人替你把最初的口子打开了**。<br>**往**＝前往、继续走。 |
| **⚠️ 本爻是睽卦的答案所在** | **六五不当位、又乘刚，条件不好；但它得中、居尊、且与九二相应。**<br>按本库通则"**得中可救不当位**"——**而它"得中"的具体内容，是"它手上有一条通着的关系线"**（九二"遇主于巷"接上的正是这条线）。<br>**⚠️ 九二与六五必须合读，这是全卦唯一的一条通路：**<br>**下面的九二从"巷"（非正式渠道）来遇你** → 判词"无咎"，象传"未失道也"；<br>**上面的六五看到"厥宗噬肤"（口子已经开了）** → 判词"往无咎"，象传加一句"**往有庆也**"。<br>**➡️ 合起来是一套完整的修复流程：下面的人换个场合把线接上（九二），上面的人认下这个口子并继续往前走（六五）。**<br>**⚠️ 这与师卦"九二↔六五"、蒙卦"九二↔六五"完全同构——是本库第三个"九二执行、六五认账"的结构。** 差别只在内容：**师是授权带兵，蒙是施教受教，睽是修复关系。** |
| **识别信号** | ① 你在这段关系里处于"要拍板的一方"（长辈、上级、主动权在你手上的那一个）；② 你的名分并不完全正（不当位），下面还顶着强硬的力量（乘刚）；③ **已经有人开了口子**——递了话、找了机会、给了台阶、做了一件不必做的小事。 |
| **该做** | **认下那个口子，然后"往"（继续走下去）。**<br>**⚠️ 不要因为"口子开得不够正式""开的方式我不满意""他还没道歉"而退回去。** **象传承诺的是"往有庆"——好处全部在"往"这个动作里。** |
| **不该做** | ① 要求对方用更正式、更体面的方式重新来一次；② 在"谁先低头"上继续僵持。<br>**⚠️ 注意"噬肤"的字面意思就是"最容易的那一口"——它本来就不够、本来就轻，但它是全卦唯一的开口。** 嫌它轻而不接，全卦就没有第二个机会。 |
| **与晋六五的对照（两个"往"）** | **晋六五"失得勿恤，往吉，无不利"——放下得失的算账，往前走**；**睽六五"厥宗噬肤，往无咎"——认下别人开的口子，往前走。**<br>**⚠️ 两爻的位属性完全相同：柔居尊位、不当位、得中、乘刚，而且都以"往"为解药。**<br>**差别只在放下的东西：晋六五要放下的是"账"，睽六五要放下的是"面子"。**<br>**➡️ 合起来一条通则（本组两卦共同给出）：柔居尊位而不当位、又乘刚的人，解药永远是"往"——而"往"的前提是先放下一样东西。** |

### 上九 · 睽孤，载鬼一车（⚠️ 全卦最重之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 睽孤，见豕负涂，载鬼一车。先张之弧，后说之弧，匪寇婚媾。往遇雨则吉。 |
| **象传** | 遇雨之吉，群疑亡也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终——**睽之极，也就是猜疑之极** |
| **判词 → 行动语义** | **往遇雨则吉**（有条件的吉） → **把弓放下，然后等误会自然消解；不要去自证** |
| **关键词解** | **睽孤**＝孤立（**与九四同辞**）。<br>**豕负涂**＝**猪背上驮着泥**（"涂"＝泥）——**又脏又不成样子的东西。**<br>**载鬼一车**＝**一整车的鬼。**<br>**张之弧**＝拉开弓（"弧"＝木弓）。**说之弧**＝**"说"通"脱"，把弓放下**（与蒙卦"用说桎梏"同一个通假）。<br>**匪寇婚媾**＝**不是强盗，是来结亲的**（"匪"通非；"婚媾"＝婚配、结亲）。<br>**遇雨**＝遇到下雨。<br>**群疑亡也**＝**一群疑虑消散了**（"亡"＝消失、自行散去）。 |

#### ⚠️⚠️ 专项分析：本爻是《周易》里意象最奇特的一爻

**① 爻辞是一段完整的心理过程，不是一串占卜术语。**

六个短句严格按时间顺序排列：

> **孤立（睽孤）→ 看见脏东西（见豕负涂）→ 看见一车鬼（载鬼一车）→ 拉弓（先张之弧）→ 放下弓（后说之弧）→ 发现来的是亲家（匪寇婚媾）→ 遇雨（往遇雨则吉）**

**这是全书唯一一段完整写出"猜疑如何生成、又如何解除"的文字。** 它不是在描述超自然现象，**它在描述一个孤立的人眼里的世界。**

**② "载鬼一车"是幻象——而且经文自己明确告诉你它是幻象。**

**证据就在爻辞里：他"先张之弧"（以为是强盗，拉弓要打），"后说之弧"（把弓放下），然后发现"匪寇婚媾"——来的根本不是强盗，是来结亲的。**

**也就是说：那一车鬼是他自己看出来的。**

**➡️ 孤立（睽孤）到极处，人会把靠近自己的一切都读成威胁**：脏的（豕负涂）、鬼的（载鬼一车）、来抢的（寇）。**而事实是"婚媾"——对方是来结亲的。**
**这一条是全卦最重的诊断：在睽之极，你对情势的判断本身已经不可信了。**

**③ ⚠️ 本爻最重要的一条：猜疑的解药不是证据，是"遇雨"。**

**爻辞给出的唯一"吉"的条件是"往遇雨则吉"，而象传给的机制是"群疑亡也"。**

**⚠️ 注意"遇"字：不是"求雨"、不是"造雨"，是"遇雨"——遇到下雨。**
**雨在《周易》里是"阴阳和合、气交而通"之象**（对照小畜卦"密云不雨"——气未和，所以雨下不来）。**雨是等来的，不是做出来的。**

**➡️ 本库转译（本卦的核心，也是本卡最该被记住的一段）：**

**在猜疑达到"载鬼一车"这个程度之后，你已经无法用证据说服自己或对方了。**
**因为猜疑的机制是"孤"（判断没有出口），不是"缺乏信息"。** 新的信息进来，**会被同一套机制重新解释成一条新的鬼。** 你拿出证据，他读出"你早就准备好了证据"；你解释动机，他读出"你在编"。**每一次自证，都在给那辆车再装一个鬼。**

**所以经文给的不是"去查清楚"，是"往"（继续往前走）＋"遇雨"（等到那个气交而通的时刻）。**

**⚠️ 落到现代，三条禁令与一条动作：**
- **① 不要在猜疑最盛的时候要求对方给交代、给证据、给解释**——那一车鬼不是证据能搬走的；
- **② 不要在这个时候自证清白**——你的每一条自证都会被读成一条新的鬼；
- **③ 不要找第三方来"评理"**——**引入裁决者就把睽升格成了讼**（见末节），而讼卦的判词是"中吉终凶"；
- **④ 该做的只有"往"**：**把自己的事继续做下去，把最低限度的接触保持住**（初九"见恶人"），**然后等。**
**等到一个外部条件发生变化——一件共同要办的事、一次共同的难、一段足够长的时间过去——"群疑"会自己散掉。** **象传用的字是"亡"（自行消失），不是"破"（被人打破）。这个用字差别是整爻的关键。**

**④ "先张之弧，后说之弧"是全爻最珍贵的六个字。**

**他确实拉过弓。** **猜疑到极处，人一定会有一次要动手的冲动**——这是《周易》承认的、正常的。
**而经文没有责怪他拉弓，它记下的是他"后说之弧"（把弓放下了）。**

**本爻之所以能"吉"，第一步就是这个"说弧"的动作。**
**⚠️ 如果那一箭射出去了，就不再是睽卦了——是讼卦、是师卦。**

**⑤ "睽孤"在九四与上九各出现一次：本卦的"同辞异断"教材**

| 对照项 | **九四** · 睽孤 | **上九** · 睽孤 |
|---|---|---|
| 处境 | 孤，但还在往上走的路上 | **孤到极处，已在卦终** |
| **看见了什么** | **元夫**（一个够格的人） | **豕负涂、载鬼一车**（脏东西和鬼） |
| 动作 | **交孚**（互相交付诚信） | **先张之弧，后说之弧**（差点动手，放下了） |
| 判词 | **厉，无咎** | **往遇雨则吉** |
| 象传机制 | **志行也**（判断有了出口） | **群疑亡也**（疑虑自行消散） |
| 解药的性质 | **可以主动做**（去找人交心） | **只能被动等**（遇雨） |

> **⚠️ 同一个"孤"字：九四看见的是人，上九看见的是鬼。差别只有一条——九四还有一个可以"交孚"的对象，上九已经没有了。**
> **➡️ 结论（可直接入库为通则）：孤立的第一阶段要主动找人交心（九四"遇元夫，交孚"）；一旦错过、孤到看见鬼的程度，就只剩两个动作——把弓放下，然后等雨。**
> **这条通则的实用价值极高：它告诉读者"解药是有时效的"。** 九四阶段的解药是主动的、便宜的；**上九阶段的解药是被动的、只能等的。所以要在九四就动手。**

| 字段 | 内容 |
|---|---|
| **识别信号（诊断清单）** | ① 你已经在这段关系里彻底孤立，**没有一个人可以核对你的判断**；② 你开始把对方所有的行为都解释成针对你的——**包括那些善意的行为**（"他现在对我好，肯定是有目的"）；③ 你在脑子里演练过至少一次"动手"（撕破脸、发那条消息、把事情捅出去、找共同的人评理）；④ **你觉得只要拿到证据、把话说清楚，一切就能澄清。**<br>**⚠️ 第 ④ 条是本爻最关键的识别信号——它本身就是"载鬼一车"的症状之一。** |
| **该做** | **① 把弓放下（说之弧）**——不发那条消息、不撕破脸、不捅出去；<br>**② 停止自证与取证**；<br>**③ "往"**——把自己该做的事继续做，把最低限度的接触保持住（初九"见恶人"）；<br>**④ 等"雨"**——等一个外部条件的变化，让"群疑"自己散掉。 |
| **不该做** | ① **射出那一箭**——**一射就从睽卦掉进讼卦；本库讼卦口径：中吉终凶，官司没有真正的赢家**；<br>② **用证据去解决猜疑**——**"群疑"是"亡"的（自行消散），不是"破"的**；<br>③ 找第三方评理——**睽卦里没有裁决者可找**（见末节）。 |

## 三、睽卦定位速查表

| 爻 | 处境 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | 刚开始背离（**唯一当位**） | 丧马勿逐·见恶人 | 感到有些东西没了，且在避开某个人 | **当位** | **悔亡·无咎**·**不追** ＋ **去见** |
| 九二 | 正式渠道已失效 | 遇主于巷 | 每次正式沟通之后关系更差 | 不当位但**得中**·应六五 | **无咎**·**换场合**·未失道 |
| 六三 | 处处被拖住且丢脸 | 见舆曳 | 每推一步都有反向的力，还在人前丢了脸 | **不当位**·乘刚·三多凶 | **无初有终**·停止发力·**等"刚"** |
| 九四 | 孤立（还能主动） | 睽孤·遇元夫 | 没有人可以跟你核对判断 | 不当位·四多惧 | **厉·无咎**·**找够格的人交孚（双向）** |
| 六五 | 拍板方（**卦主**） | 厥宗噬肤 | 已经有人递了话、给了台阶 | 不当位·**得中居尊**·乘刚·应九二 | **往无咎·往有庆**·**认下口子就走** |
| 上九 | 猜疑之极 | 载鬼一车 | 把对方一切行为都读成针对，且想动手 | 不当位·卦终 | **往遇雨则吉**·**放下弓·停止自证·等** |

**睽卦三句话**：
1. **睽不是吵架，是"目不相听"——两只眼睛不朝同一个方向看**（说文）。**所以睽的痛苦不是被打，是"你说什么他都不接"。** 对策的第一条是降规格：**卦辞只给三个字"小事吉"——大事一件都不要动。**
2. **纲领是"同而异"**（大象传），**而且顺序不可颠倒：先把"我们共同要的东西"确认下来（同），再把分歧圈小并允许它存在（异）。** **睽卦的解法里没有"说服"这个动作。**
3. **修复只有一条通路：九二从"巷"里把线接上 → 六五认下这个口子并往前走。** **而猜疑一旦到了"载鬼一车"，解药就不再是证据，是"放下弓 ＋ 等雨"**（上九，象传"群疑亡也"）。

**本卦最反直觉的四条**：
- **⚠️ 猜疑的解药不是证据，是"遇雨"。** **象传用的字是"群疑亡也"——疑虑是自行消散的，不是被打破的。** **在"载鬼一车"这个程度上，每一条自证都会被读成一条新的鬼。**
- **"见恶人，无咎"——在关系已经背离的时候，要主动去见那个你最不想见的人。** **而理由不是"为了和好"，象传写得极冷静："以辟咎也"（为了避灾）。** 不见面 → 只能靠猜 → 就是上九。
- **彖传对"差异"给了全书最高的肯定："天地睽而其事同也……睽之时用大矣哉！"** **《周易》不认为"看不到一块去"是坏事；坏的是把"不同"解释成"针对"。**
- **全卦唯一当位的一爻是初九（最底层），而不是九五那个尊位。** **这意味着睽卦里没有裁决者——所以"找人评理"这条路从结构上就不存在。**

## 四、⚠️ 本卡对全库的意义

### 1. ⚠️ 睽 vs 讼：全库最锋利的一组结构对照——"睽卦里没有裁决者"

本库讼卦卡立下的核心判断是：**"整个讼卦六爻唯一当位得中的就是象征裁决者的九五"**，而讼卦的解法是卦辞明写的"**利见大人**"——**引入一个双方都认的第三方来折中。**

**睽卦的当位分布恰好把这条路堵死了：**

| | **讼 6** | **睽 38** |
|---|---|---|
| 卦象 | 上乾下坎（**天与水违行**） | 上离下兑（**上火下泽**） |
| 相反的方式 | **两个力互相顶**（对撞） | **两个力各走各的**（不相及） |
| **唯一当位之爻** | **九五**——裁决者，**且当位得中居尊** | **初九**——**最底层，且不得中** |
| 卦辞 | 有孚窒惕，**中吉终凶，利见大人**，不利涉大川 | **小事吉** |
| 大象传纲领 | **作事谋始**（从开头就把规则说清） | **同而异**（大处求同，小处留异） |
| 解法 | **利见大人**——引入第三方裁决，"案结事了" | **无第三方可引**；只有九二↔六五一条内部线 |
| 全卦最好判词 | 九五"**元吉**"（裁决者） | 六五"**往无咎**"／象传"往有庆" |

> **⚠️ 讼卦的解法是"利见大人"（找一个双方都认的第三方来折中）；而睽卦的卦辞里没有"利见大人"，六爻里也没有一个当位得中的尊位——睽之时没有裁决者可找。**
>
> **这正是"睽是还没打起来的对立"的结构原因**：**睽是"其志不同行"（志向不同路），不是"利有所争"。** **没有形成可裁决的争点，裁决机制就根本用不上**——你去找人评理，人家也只能说"你们俩谁都没错，就是想法不一样"。
>
> **睽之时能用的只有三样，全部是内部动作**：**① 降规格（小事吉）；② 保持接触（初九"见恶人"）；③ 换场合（九二"遇主于巷"）。**
>
> **⚠️ 反过来说，这条对照给出一个极实用的警告：如果你在"睽"的处境里去找裁决者（评理、投诉、请领导定、闹到明面上），就等于把睽升格成讼——而讼卦的判词是"中吉终凶"，本库口径是"官司没有真正的赢家"。**
> **睽是讼的上游。而讼卦"作事谋始"这条预防原则，落到关系层面就是睽卦初九的"见恶人"与九二的"遇主于巷"——趁早、趁小、走非正式渠道。**

### 2. 本卦补上了全库缺失的一个机制：猜疑

本库已完成 18 卦里没有一卦处理"猜疑"这个机制。而它在实际困境中出现的频率极高，且**它有一个独特的性质：它对信息免疫。**

| 卦 | 处理的机制 | 解法的性质 |
|---|---|---|
| **讼 6** | **争点**（利有所争） | 引入第三方折中（**外部裁决**） |
| **师 7** | **对抗**（已组织化） | 立纪律、选对人（**内部治理**） |
| **坎 29** | **险**（连续打击） | "维心亨"、只做小事（**心与节奏**） |
| **震 51** | **冲击**（突发） | 认赔、勿逐、七日得（**等时间**） |
| **睽 38** | **猜疑**（志不同行 → 载鬼一车） | **放下弓 ＋ 遇雨（等外部条件变化，让"群疑"自行消散）** |

> **⚠️ 猜疑的独特性（本卡最有价值的一条机制发现）**：**它的成因是"孤"（判断没有出口），不是"信息不足"。** **所以补充信息不能解决它——新信息会被同一套机制重新解释成新的威胁。**
> **这直接推出一条可直接用于诊断的规则：当用户描述的困境里出现"我要拿到证据""我要把话说清楚"这类诉求，而对方已经开始把他的一切行为读成针对时，本库不应支持"取证／自证"路线，而应引向睽上九的两个动作：放下弓，然后往。**
> **同时给出解药的时效性**：**九四阶段（还有人可以交心）解药是主动的、便宜的；上九阶段（已看见鬼）解药是被动的、只能等。所以要在九四就动手。**

### 3. "同而异"：本库第一条明确处理"差异"的纲领，以及关系类纲领的汇总

| 卦 | 纲领 | 核心要求 | 是否要求双向 |
|---|---|---|---|
| **兑 58** | 大象传"**朋友讲习**"（丽泽·互相润泽） | 一起把事情想明白 | **必须双向**（"来兑"单向讨好 → **凶**） |
| **家人 37** | 大象传"**言有物而行有恒**"；九五小象"**交相爱**" | 说话有内容、标准要稳定；互相爱 | **必须双向**（"交"字） |
| **睽 38** | 大象传"**同而异**" | **大处求同，小处留异，且不试图消除差异** | **同是双向的，异是各自的** |
| **讼 6** | 大象传"**作事谋始**" | 从开头就把规则、边界说清 | 双向（规则约束双方） |

> **➡️ 四条合起来，本库"关系类纲领"已成体系**：
> **关系好的时候一起做事（兑·朋友讲习）→ 有了共同生活就把规矩和责任分明（家人·言有物行有恒 ＋ 交相爱）→ 开始背离就分层（睽·同而异）→ 已成争点就从开头立规则并及早止讼（讼·作事谋始）。**
> **⚠️ 而四条共享一条底线：《周易》讲关系，凡单向者皆不成立。** 兑六三"来兑，凶"（单向讨好）、家人九五"交相爱"（双向）、睽九四"交孚"（双向）——**三处经文，同一条通则。**

### 4. 兑在下的第二个样本：验证"兑在下则六三必不当位"

本库兑卦卡已立下这条律：**"兑在下 → 只有初九当位，六三必不当位：'来兑，凶'这个陷阱只在兑居下卦时出现"**，并点名"本库已有的履卦正属此类——所以读履卦时，六三那一爻要格外小心"。

**睽卦是本库第二个"兑在下"的样本，可以做一次验证：**

| 卦 | 卦象 | 六三爻辞 | 判词 | 象传理由 |
|---|---|---|---|---|
| **履 10** | 上乾**下兑** | 眇能视，跛能履，履虎尾，**咥人** | **凶**（全卦唯一凶爻） | 不足以有明也／不足以与行也／**位不当也**／志刚也 |
| **兑 58** | 上兑**下兑** | 来兑 | **凶**（全卦唯一凶爻） | **位不当也** |
| **睽 38** | 上离**下兑** | 见舆曳，其牛掣，其人天且劓 | **无初有终**（无吉凶判词，但意象最狼狈） | **位不当也**／遇刚也 |

> **⚠️ 三卦的六三全部不当位，三条象传全部出现"位不当也"四个字，三爻的处境全部很难看。这条律至此得到三次独立验证。**
> **➡️ 可直接补入索引的读卦法：凡遇"兑在下"的卦（履、临、归妹、损、节、睽、中孚），六三是全卦第一个要看的危险点，且它必不当位。**
> **睽六三的独特之处**：**它是三者里唯一被给了出路的（"无初有终，遇刚也"）。** 履六三和兑六三都是"凶"且解药在爻外；**睽六三虽最狼狈，但经文明确告诉它"会遇到一个能拉动你的人"。** 原因可能在上卦：**履上有乾（虎，只会咬）、兑上还是兑（同类，无援）、而睽上有离（明，还能被看见）。**

### 5. 一条对"离在上"结构律的第三次验证

本组四卦中有三卦含离，**其中晋（35）与睽（38）都是"离在上"：**

| 卦 | 卦象 | 四 | 五 | 上 | 全卦当位数 |
|---|---|---|---|---|---|
| **晋 35** | 上离**下坤** | 九四 **不当位** | 六五 **不当位**（得中） | 上九 **不当位** | **1**（六二） |
| **睽 38** | 上离**下兑** | 九四 **不当位** | 六五 **不当位**（得中） | 上九 **不当位** | **1**（初九） |
| **明夷 36** | **下离**上坤 | — | — | — | **5**（唯六五不当位） |

> **"离在上则四五上三爻全不当位"这条律，在晋与睽两卦得到完全一致的验证**（加上离卦本身与明夷的反向验证，本库这条律已有四次实证）。
> **⚠️ 但两卦的唯一当位爻落点不同，导致性格完全不同**：**晋的当位爻在六二（下卦枢纽，"受兹介福，以中正也"）；睽的当位爻在初九（最底层，只能做"不追"和"去见"这两件小事）。**
> **这再次印证家人卡提出的通则：不要只数"几爻当位"，要看"当位的那一爻落在哪个位置"。** **落在二／五（枢纽）则全卦有主心骨；落在初（最底）则全卦只能从最小的动作起手——这正是卦辞"小事吉"的结构来源。**

### 6. 与已完成各卡的衔接一览

| 衔接 | 机制 |
|---|---|
| **家人 → 睽** | 序卦传"**家道穷必乖**"——**睽发生在原本最亲近的人之间。家人是还能立规矩的阶段，睽是已经背离的阶段** |
| **⚠️ 睽 ↔ 讼** | **睽是讼的上游。讼唯一当位之爻是九五（裁决者），睽唯一当位之爻是初九（最底层）——睽卦里没有裁决者，所以"找人评理"会把睽升格成讼（中吉终凶）** |
| **睽 ↔ 兑** | **上离下兑："说而丽乎明"与履卦"说而应乎乾"同句式——在背离的关系里，你能动的是"悦"（气氛），不是"明"（道理）**；且**兑在下则六三必不当位**在此第三次验证 |
| **睽 ↔ 履** | **两卦同为"兑在下"**；履彖传"说而应乎乾"、睽彖传"说而丽乎明"——**同一味药（悦）用在两种强势结构里** |
| **睽初九 ↔ 兑六三** | **主动接触的分界**：**兑六三"来兑"要的是"他高兴"（凶）；睽初九"见恶人"要的是"事不坏"（无咎）。位置正不正 ＋ 要的是什么，决定吉凶** |
| **睽初九 ↔ 震六二** | **两处"勿逐"**：震"勿逐，七日得"（冲击型损失，追它等于加深）；**睽"丧马勿逐，自复"（背离型损失，追它会被读成施压）** |
| **睽九二 ↔ 巽九二** | **没有强制力时怎么推事的两招**：巽改"频次与姿态"（申命、纷若），**睽改"场合"（于巷）** |
| **睽六三 ↔ 巽九五** | **两处"无初有终"**：巽九五靠**等时间**（柔性渗透前期无动静是正常的）；**睽六三靠等人（"遇刚也"）** |
| **睽九四 ↔ 离九四** | ⚠️ **同一爻位、同是"离在上"的第一爻，判词天差地别**：离九四"焚如死如弃如"（无爻内解药），**睽九四"厉无咎"（有解药）。差别在下卦——离下是火，睽下是兑（悦）。这是"同一爻位的吉凶由另一半卦决定"的最好一例** |
| **睽九四 ↔ 兑九五** | **"元夫"这个限定条件的来源**：兑九五"孚于剥，有厉"——**诚信给错对象，当位得中居尊也有危。孤立中的人最容易犯这一条** |
| **睽九四 ↔ 履九四** | **两处"志行也"**：履靠"怕"（愬愬），**睽靠"交"（交孚）——都不是靠加大力度** |
| **睽六五 ↔ 晋六五** | **位属性完全相同**（柔居尊·不当位·得中·乘刚），**解药都是"往"**；差别在放下什么：晋放下"账"，**睽放下"面子"** |
| **睽六五↔九二 ↔ 师／蒙的六五↔九二** | **本库第三个"九二执行、六五认账"结构**：师是授权带兵，蒙是施教受教，**睽是修复关系** |
| **睽上九 ↔ 小畜"密云不雨"** | **"雨"＝阴阳和合、气交而通之象**。小畜是"气未和所以雨下不来"，**睽上九是"遇雨则吉"——雨是等来的，不是造出来的** |
| **睽 ↔ 革 49** | **上兑下离＝革，正是睽（上离下兑）的反卦**。本组尚未成卡，可与睽并读：**同一对三画卦上下互换，一为"背离"，一为"变革"** |
