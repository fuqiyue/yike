# 知识卡 39 · 蹇卦（水山蹇）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："乖必有难，故受之以蹇。蹇者，难也。"——上一卦（睽 38）讲"乖"（离心、背反、看法分裂）；**人心一乖，事情必然走不动，于是进入蹇。** 蹇不是被打击，是**走不动**。
> **本卦与解卦（40）是一对，且是结构上的倒转（覆卦）**：蹇六爻自下往上"阴阴阳｜阴阳阴"，整卦上下颠倒即得解卦"阴阳阴｜阳阴阴"。**蹇讲被堵死，解讲解开。两卦必须合读。**
> ⚠️ **本卦是本库坎卡（29）"坎在上"那条通则的第四个样本，也是最极端的一个**：坎卡指出"坎在上 → 险还在前方，口径是扎根／待时／择主"。**蹇是唯一一个"险在前方，而自己脚下还被艮压着不许动"的卦**——两头同时堵死。详见第四节。
> ⚠️ **本卦是全书唯一一处彖传直接用"当位"二字为整卦下判的卦**："**当位贞吉，以正邦也。**" **本库第 4 节结构律由此第二次拿到经文级背书**（第一次是咸卦彖传"止而说"）。
> ⚠️ **本卦是全库"困境中唯一动作是修自己"的经文正源**：大象传"山上有水，蹇。君子以反身修德。"

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 蹇 · 第三十九卦 |
| **卦象** | 上坎（水／险）下艮（山／止），称"水山蹇"。**山上还有水**——前面是险，脚下是山，**险在前而自己又动不了**。<br>**六爻自下而上：阴、阴、阳｜阴、阳、阴。**<br>**按本库第 4 节结构律逐爻核定**：**艮在下 → 初六不当位、六二当位得中、九三当位**；**坎在上 → 六四、九五、上六三爻全部当位**。<br>**⚠️ 合计五爻当位（六二、九三、六四、九五、上六），只有初六一爻不当位——这是本库目前当位数最高的卦。**<br>**⚠️ 而彖传亲自把这件事写出来了："当位贞吉，以正邦也。"**<br>**⚠️ 逐爻核查乘刚**：**六四直乘九三之上——乘刚**；**上六直乘九五之上——乘刚**（按咸卡新增的结构事实，坎的顶阴压中阳，**坎在上则上六必乘刚**）。六二乘于初六之上，同性不构成乘刚。**全卦两处乘刚，都在上坎。**<br>**⚠️ 应爻核查**：初六↔六四（阴／阴，**不应**）；六二↔九五（阴／阳，**应**）；九三↔上六（阳／阴，**应**）。**二应一不应，而唯一失应的一对正是全卦唯一不当位的那一爻（初六）所在。** |
| **⚠️ "上坎下艮"的定势含义（本卦全部义理的根）** | 本库两条现成的结构律，在本卦第一次正面撞在一起：<br>**① 坎在上＝险还在前方**（坎卡第四节：屯／需／比皆属此类，口径是"扎根／待时／择主"）；<br>**② 艮在下＝止在内，是你自己这边的"止"**（谦卡：艮在下的"止"是主动放进去的，不是别人加的）。<br>**两条叠起来就是蹇的处境：前面明确有险（坎），而你自己内部又是"止"（艮）——一头是不能进，一头是走不动。**<br>**⚠️ 这就是"蹇"字的全部含义：不是被打倒，是跛足、迈不开腿。**<br>**而彖传把这个结构直接读成了一句褒语**：**"见险而能止，知矣哉！"——看见险而能停住，这是智慧。** 也就是说：**《周易》不把"下艮"当成蹇的病，它把"下艮"当成蹇唯一的本钱。** |
| **领域定义** | **前有明确阻碍、自己又动不了的僵局**。① 项目／审批／官司卡在一个环节上，你已经知道往前是坑，但停在这儿也出不来；② 事业或职业方向已经看清此路不通，但转不了身（有房贷、有团队、有家人、有合约）；③ 一段关系已经明显走不下去，双方都不动，谁先动谁吃亏；④ 组织内部改革，方案是对的，但推不下去，越推阻力越大；⑤ 长期病痛、长期照护、长期债务——**不是在恶化（那是坎），是在"卡住"**；⑥ 你已经很努力，但每一次向前的动作都换回同样的挫折，且**外部条件短期内不可能改变**。<br>**凡是"前面走不通，脚下也挪不动，而我又必须在这里待着"，都落在蹇卦。** |
| **不归本卦的情况** | ① **已经陷在里面、还在往深处走** → **坎卦（29）**。**分界线极重要：坎是"你已经在坑里"（坎在下／重险），蹇是"坑在你前面，而你被自己的山挡在这边"（坎在上）。** 用坎卡的口径说：**坎在下＝求小得、勿加深；坎在上＝待时、择主、扎根。**<br>② **险还在前方，但你脚下是"动"** → **屯卦（3，上坎下震）**。屯有根可扎、可以小试错；**蹇脚下是艮（止），连"动"这个选项都没有。**<br>③ **险还在前方，底子刚健** → **需卦（5，上坎下乾）**；**底子柔顺、要择主** → **比卦（8，上坎下坤）**。<br>④ **你有能力继续，只是决定不继续** → **艮卦（52）**。**艮是主动止，蹇是想动而动不了。**<br>⑤ **已经在往外走、正在脱身** → **解卦（40）**。**蹇与解是同一件事的两头，判别只问一句："我现在是在被堵着，还是已经在出来了？"** |
| **"蹇"字本义** | **跛、行走艰难**。《说文》"蹇，跛也"，本义是腿脚不利索、迈不开步。彖传第一句直接定死："**蹇，难也，险在前也。**"<br>**⚠️ "蹇"的重点在"腿"，不在"敌"。** 它描述的不是外部有多凶，是**你自己的行进能力受限**。这就解释了为什么全卦的解药是"**反身修德**"（大象传）——**腿的问题只能在自己身上治。** |
| **卦辞原文** | 蹇：利西南，不利东北；利见大人，贞吉。 |
| **⚠️ 卦辞的关键结构** | **无元、无亨。** 有的只是三样东西：**一个方位许可（利西南）＋一个方位禁令（不利东北）＋一个求助指令（利见大人）＋一个条件性吉断（贞吉）。**<br>**① 无"亨"是本卦最重的一条缺失。** 对照：**坎卦（29）卦辞是"有孚，维心亨"——重险之中至少还给了一个"心亨"；蹇卦连这个都没有。** **《周易》对"走不动"这件事的态度是：此时没有任何一条路是通的，包括心里那条。**<br>**② 但蹇给了"贞吉"，而坎全卦卦辞里没有一个"吉"字。** **两卦刚好互补：坎给你"心通"但不给"吉"（在里面只能不死）；蹇不给"通"但给"吉"（走不动，可是守正就有好结果）。**<br>**③ ⚠️ 全书唯一一组"方位禁令"级的卦辞（本卦与解卦共有"利西南"）。** 按本库乾卡的八卦方位表：**坤＝西南，艮＝东北。**<br>**"利西南"＝往坤（地、顺、平易、众人）那边去；"不利东北"＝不要往艮（山、止、险阻）那边去。**<br>**⚠️ 而本卦的下卦正是艮。** 也就是说：**卦辞禁止你往自己内部那座山里钻。** 彖传把理由写死了：**"不利东北，其道穷也"——那个方向是死路。**<br>**结论（本卦最实用的一条）：蹇的正确方向是"往平地上去、往人多的地方去"，而不是"往自己心里那座山上去"。** |
| **卦辞现代解** | **利西南**——**往开阔、平顺、有人的方向去**。落到现代：**把问题拿到人群里，去找平坦好走的那条路，而不是继续在险处硬碰。**<br>**不利东北**——**不要往险阻、闭塞、只有你自己的方向去**。落到现代：**不要独自钻进去；不要用"再想想""再忍忍""我一个人扛"来处理蹇。**<br>**利见大人**——**适宜去见有位有德的人**（与乾九二、乾九五、蒙卦、巽卦卦辞同字）。**⚠️ 这三个字在本卦被写了两次（卦辞＋上六爻辞），是全卦唯一被重复的指令。**<br>**贞吉**——**守正则吉**。彖传给了它的结构理由：**"当位贞吉，以正邦也"——全卦五爻当位，所以"守住位置上该做的事"这条路是真的通的。** |
| **彖传** | 蹇，难也，险在前也。见险而能止，知矣哉！蹇利西南，往得中也；不利东北，其道穷也。利见大人，往有功也。当位贞吉，以正邦也。蹇之时用大矣哉！ |
| **⚠️ 彖传要点（本卦机制全在这五句里）** | ① **"蹇，难也，险在前也"**——**定性：险在前方。** 这一句直接把蹇钉在"坎在上"这条律上。<br>② **"见险而能止，知矣哉！"（本卦最重要的一句）**——**看见险而能停住，这是智慧。** **《周易》在这里把"下艮"（止）从蹇的病因翻成了蹇的本钱**：**你之所以还没死，就是因为你停住了。** 这也是"蹇"这个卦名不带贬义的原因。<br>③ **"蹇利西南，往得中也；不利东北，其道穷也"**——**方位有了理由：往西南能"得中"（走到平顺得中的地方），往东北则"道穷"（无路可走）。**<br>④ **"利见大人，往有功也"**——**去见大人这件事，是本卦唯一被许了"有功"的动作。** 注意：**彖传对"往"字的态度在这里出现了唯一一次反转**——爻辞里四处"往蹇"（往则难），**唯独"往见大人"是"往有功"**。<br>⑤ **"当位贞吉，以正邦也"（⚠️ 全书唯一一处彖传拿"当位"给整卦下判）**——**因为全卦五爻当位，所以"贞"这条路能"吉"，而且能"正邦"（把局面扶正）。**<br>**⚠️ 这是本库第 4 节结构律第二次拿到经文级背书**（第一次是咸卦彖传"止而说"直接对应"艮在下＋兑在上"）。**它的意义远超本卦：它证明"当位"在《周易》自己的话语系统里就是一个真实存在的判据。**<br>⑥ **"蹇之时用大矣哉！"**——与坎卦彖传"**险之时用大矣哉**"完全同一句式。**《周易》全书用"……之时用大矣哉"这个格式的极少，而坎与蹇两处并列：险可以用，难也可以用。** |
| **大象传（行动纲领）** | 山上有水，蹇。君子以反身修德。 |
| **⚠️ "反身修德"解（本卦最高层原则，也是全库"困境自处"的经文正源）** | **反身**＝反过来看自己这一身（"反"是返、回头；"身"是自己）。**修德**＝修治自己的德。<br>**为什么山上有水就要"反身"？** 山已经很高，上面又有水——**前面的路被自己的高度和前方的险共同封住了。此时向外的每一个方向都不通，唯一还剩下的方向是"向内"。**<br>**⚠️ 这五个字给出的不是安慰，是一条极硬的操作纪律**：<br>**在蹇的处境里，你唯一被授权的动作是"修自己"。** 不是修局面、不是修对方、不是修条件——**因为那些恰恰是"往蹇"（爻辞四次警告）。**<br>**⚠️ 本库同类纲领的横向对照（这是全库"困境中做什么"的完整谱系，四条纲领指向同一个方向）**：<br>**坎 29「常德行习教事」**——险中唯一能积累的是日常功课（**做**）；<br>**震 51「恐惧修省」**——震动降临时把恐惧直接换成查自己（**查**）；<br>**艮 52「思不出其位」**——连念头都不越出自己的位置（**收**）；<br>**蹇 39「反身修德」**——走不动的时候，把方向整个转回自身（**转**）。<br>**⚠️ 四条合读得出一条本库口径**：**《周易》给困境的行动纲领，无一条是"改变外部"，四条全部是"对自己下的指令"。而蹇卦是四条里最彻底的一条——它不是"顺便也修自己"，它是"除了修自己没有别的可做"。** |
| **总铁律** | ① **往必蹇。** 四爻（初六、九三、六四、上六）都以"往蹇"开头——**《周易》在同一卦里用四次重复告诉你：这个局面里，向前的动作没有一次是对的。**<br>② **来必有得，且回报递增。** 与四个"往蹇"配对的是"来誉 → 来反 → 来连 → 来硕"——**返回的收益一路加码**（详见第三节的方向判定表）。<br>③ **唯一被许"有功"的"往"是"往见大人"**（彖传"利见大人，往有功也"）。**卦辞与上六重复此令，是全卦唯一被说两次的指令。**<br>④ **唯一必须硬着头皮往前的人是六二**（"王臣蹇蹇"）——**因为职责在身，且它的回报只是"终无咎"。**<br>⑤ **九五"大蹇"不是失败，"朋来"是全卦的转机**——**居尊位者在最大的难里，得到的不是能力，是人。**<br>⑥ **绝不往"东北"（自己内部那座山）钻**——彖传判"其道穷也"。**"反身修德"是转向自己，不是把自己关起来；这两件事必须分清。** |

## 二、爻级字段

> ⚠️ **先读这一段，否则六爻会读乱：本卦是全书结构最整齐的一卦之一。**
> **六爻里有四爻（初六、九三、六四、上六）都用同一个句式：「往蹇，来×」。**
> **"往"是向前、向外、去推进；"来"是返回、退回、回到自己这边。**
> **四处的"往"全部是"蹇"（难），四处的"来"全部是正面，而且回报逐级升高：**
> **誉（声誉）→ 反（返回本位）→ 连（连结、得到同伴）→ 硕（硕大、丰厚）。**
> **另两爻不在这条序列里，各有专门职能**：**六二**（王臣蹇蹇——职责在身，必须往）与**九五**（大蹇朋来——最大的难，也是转机）。
> **方向判定总表见第三节。**

### 初六 · 往蹇来誉

| 字段 | 内容 |
|---|---|
| **爻辞** | 往蹇，来誉。 |
| **象传** | 往蹇来誉，宜待也。 |
| **位属性** | 阴爻居阳位，**不当位**（艮在下之律：初不当位）——**全卦唯一不当位的一爻**；居全卦最下；与六四同性，**是全卦唯一失应的一对**。 |
| **判词 → 行动语义** | **无吉凶判词，只给方向对比（往／来）＋象传一个动作** → **此时不要动，等；等本身就是这一爻的"誉"** |
| **关键词解** | **往**＝向前去、向外去。**蹇**＝难。**来**＝返回、退回。**誉**＝声誉、被称许。<br>**⚠️ 全爻只有四个字，是本卦最短的爻辞，也是《周易》里"以方向代判词"最干净的一例：它不说吉凶，只说"哪个方向是难的"。**<br>**象传**：**宜待也**——**适宜等待。** |
| **⚠️ 本爻的核心：为什么"不动"能换来"誉"** | 初六**不当位、在最下、又是全卦唯一失应的爻**——**按本库通则，这是条件最差的一爻**（不当位＋无援）。<br>**但《周易》既不判它凶，也不判它咎，反而给了一个"誉"。** 理由全在象传两个字：**"宜待"。**<br>**在一个"往必蹇"的局面里，"不往"就是最正确的动作；而在全卦最下、最没有资格动的位置上做出这个正确动作，就换到了"誉"。**<br>**⚠️ 结论（可直接用于自查）：蹇卦的第一课是——条件最差的人，因为最有理由不动，所以最容易做对。** |
| **识别信号** | ① 局面刚开始卡住，你在最下面、最没有资源和授权的位置上；② 你能清楚看到往前那条路是难的；③ 周围有人在推你"总得做点什么"，或者你自己急着表现；④ 你手上没有任何一件"往前"的事是有把握的。 |
| **该做** | **待。** 具体化"宜待"的三条刻度：**① 不申请、不请战、不主动接前面那件难事；② 把这段时间用在大象传的"反身修德"上（补短板、补功课）；③ 明确告诉相关的人"我现在等一个条件"，而不是消失。**<br>**⚠️ 第三条很重要——"誉"是别人给的，所以"待"必须是可见的等待，不是失联。** |
| **不该做** | 为了证明自己在努力而往前走一步。**在蹇卦里，"往"不换来失败，换来的是"蹇"（更走不动）。** |
| **⚠️ 与艮初六、坎初六、谦初六的四角对照（本库"最下一爻"专题）** | **艮初六**"艮其趾，无咎，利永贞"，象传"未失正也"——**在脚趾刚要迈出时止住，零成本**；<br>**坎初六**"习坎，入于坎窞，凶"，象传"失道凶也"——**已在坑里还往深走，凶**；<br>**谦初六**"谦谦君子，用涉大川，吉"，象传"卑以自牧也"——**谦到极处，反而可涉大川**；<br>**蹇初六"往蹇，来誉"，象传"宜待也"——险在前方，最下位者的正解是等。**<br>**四个初爻全部不当位（谦初六、艮初六、坎初六、蹇初六）**，判词依次是 **无咎／凶／吉／（无判词但得"誉"）**。<br>**⚠️ 差别只在一件事：这一爻面对的"前面"是什么，以及它有没有动。** **艮的前面是自己要迈的一步（止住即无咎）；坎的前面是更深的坑（往则凶）；谦的前面是大川（管好自己就能涉）；蹇的前面是险（等则有誉）。**<br>**合读结论：初爻的吉凶几乎完全由"要不要动"决定，而不由条件决定——四爻条件都差（全部不当位），结果横跨凶到吉。** |

### 六二 · 王臣蹇蹇（⚠️ 全卦唯一必须往前的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 王臣蹇蹇，终无咎。 |
| **象传** | 王臣蹇蹇，终无咎也。 ⚠️ **象传近乎复述爻辞**，只在末尾加一个"也"字，未给额外解释。 |
| **位属性** | 阴爻居阴位，**当位且得中**（艮在下之律：二当位）；**与九五相应**——**全卦最正、且有援的一爻**；本库通则"**二多誉**"。 |
| **判词 → 行动语义** | **终无咎**（按本库口径：**无灾，不等于吉利**；加"终"字＝**最后才无咎，过程中不是**） → **职责在身，明知是难也要往；但要接受"最好的结果只是没灾"** |
| **关键词解** | **王臣**＝君王的臣子——**有职分、有委任、事情压在你头上的人**。**蹇蹇**＝叠字，**难上加难、一步一步地艰难前行**（对照坎卦"来之坎坎"的叠字用法）。**终**＝最终、到最后。**无咎**＝没有灾。<br>**⚠️ "蹇蹇"这个叠字是本爻的全部重量所在：它不是"遇到了难"，是"在难里一直走"。** |
| **⚠️ 本爻是全卦唯一的例外，也是最容易被读错的一爻** | 全卦四次警告"往蹇"（往则难），**唯独六二不说"往"也不说"来"，它直接描述一个人在难里往前挪。**<br>**为什么它可以违反全卦的"往必蹇"？** 因为它是"**王臣**"——**它有职分。** 六二当位、得中、与九五（那个"大蹇"的君位）相应；**九五在最大的难里，六二是唯一能上去的人。**<br>**⚠️ 而《周易》对这份忠诚给的回报极其克制："终无咎"。**<br>**按本库判词口径，"无咎"是"没有灾，不等于吉利"，而这里还加了一个"终"字——意思是：过程中不会好，只有到最后才谈得上"没灾"。**<br>**⚠️ 这是本库"职责型行动"最诚实的一条口径**：**当一件事是你的职分时，《周易》要你去做，但它不许诺你任何好处，只保证你最后不会有咎。**（对照师卦卦辞"贞，丈人吉，无咎"——同样是"无元无亨无利"的吝啬态度。） |
| **⚠️ 象传近乎复述爻辞，这个"不解释"本身有信息** | 本卦六爻里，**只有六二的小象传没有给出任何新内容**（其余五爻的象传都追加了理由：宜待、内喜之、当位实、以中节、志在内）。<br>**按本库口径记为"⚠️ 象传近乎复述爻辞"**，同时可读出一层：**这一爻没有可讲的方法。它不是一个策略问题，是一个身份问题——你是"王臣"，就得往里走，没有别的操作空间。** |
| **识别信号（诊断清单）** | ① 局面卡住了，而处理它明确是你的职责（不是你想不想）；② 你的位置是正的、条件是全局里最好的一批（当位得中）；③ 上面那个人（老板、家里的主事者、真正担责的人）正处在最大的难里（九五"大蹇"）；④ 你已经在里面走了一段，且每一步都比上一步更难（蹇蹇）；⑤ 你开始期待"扛过去会有回报"。 |
| **该做** | **① 承认这是职分，不是选择——所以不必再纠结"值不值得"；② 一步一步往里走（蹇蹇），不追求一次解决；③ ⚠️ 把预期调到"终无咎"这个刻度上——不指望表彰、不指望翻身、不指望被记得。**<br>**参照噬嗑九四"吉＋未光也"的口径：有些事你必须做，做成了也不会给你带来光荣。本爻更狠一档——它连"吉"都不给。** |
| **不该做** | ① 用"这不该我管"退出（你当位、得中、有应，全卦只有你上得去）；② 反过来，指望这份忠诚换来收益。**"终无咎"三个字已经把天花板写死了。** |
| **⚠️ 与艮六二、咸六二的三方对照（三个当位得中的六二，三种结局）** | 本库咸卡已给出一条通则："**二爻当位得中，条件最好，因此它的风险从不来自条件不足，只来自'忍不住'。**" **蹇六二给这条通则补上了第三种、也是唯一的例外情形**： | 

| 卦 | 六二爻辞 | 判词 | 象传 | 病／职在哪 | 动作 |
|---|---|---|---|---|---|
| **艮 52** | 艮其腓，不拯其随，其心不快 | **无判词，只给心理状态** | 未退听也 | **病在外**（上面的人不听劝） | **止住自己，接受心不快** |
| **咸 31** | 咸其腓，凶，居吉 | **凶／居吉** | 顺不害也 | **病在内**（自己先动了） | **居**（不动） |
| **蹇 39** | 王臣蹇蹇，终无咎 | **终无咎** | （复述） | **不是病，是职分** | **往**（唯一被要求往前的六二） |

| 字段 | 内容 |
|---|---|
| **⚠️ 三方对照的结论（建议入库）** | **三个六二全部当位得中，前两个的正确动作都是"不动"，蹇六二是唯一被要求"动"的。**<br>**差别不在条件（三者条件相同），在有没有"职分"**：<br>**艮六二想去管别人的事（越位）→ 不许动；咸六二想去追自己想要的（求取）→ 不许动；蹇六二被委任了这件事（王臣）→ 必须动。**<br>**⚠️ 可入库为通则：判断"该不该动"的第一个问题不是"我能不能"，是"这件事是不是我的职分"。是职分则动，且不许议价；不是职分则不动，哪怕条件再好。** |

### 九三 · 往蹇来反

| 字段 | 内容 |
|---|---|
| **爻辞** | 往蹇，来反。 |
| **象传** | 往蹇来反，内喜之也。 |
| **位属性** | 阳爻居阳位，**当位**（艮在下之律：三当位）；**是下艮唯一的阳爻**——**即艮之"止"的力量本身所在**；居下艮之顶、正对上坎；本库通则"**三多凶**"——**但本爻不凶**；与上六相应。 |
| **判词 → 行动语义** | **无吉凶判词，只给方向** → **回来。而且回来是有人接的** |
| **关键词解** | **反**＝返、回到本位（与"来"同向，但比"来"更重：**"来"是往回走，"反"是回到原来该在的地方**）。<br>**象传**：**内喜之也**——**内部的人为此高兴**（"内"指下卦，即初六、六二；"之"指九三返回这件事）。 |
| **⚠️ 本爻是"三多凶"的又一个例外，理由干净** | 本库已有的"三爻多凶"实例（师六三舆尸、履六三咥人、比六三匪人、否六三包羞）共同病根是"**才不配位而志刚**"；而**谦九三"劳谦"是明确反例（当位＋有实功＋志不刚）。**<br>**蹇九三补上第三种不凶的方式：当位之刚，而且它做的事正好就是本卦之德。**<br>**九三是下艮的那个阳爻——它就是"止"的力量本身。** 彖传说"**见险而能止，知矣哉**"，**而"能止"这件事，在爻上就是九三。** 所以它一"来反"（回到本位），下面两个阴爻立刻"喜之"。<br>**⚠️ 这与艮上九"敦艮，吉"是同一条机制：位不必最正，但爻德与卦德相合，位就不构成障碍。** 本库把这条记作"**义理可救位**"，蹇九三是它在"三位"上的实例。 |
| **⚠️ "来反"与"来誉"的区别（必须分清）** | **初六"来誉"——它本来就在最下，"来"只是不动，所以收获是别人的评价（誉）。**<br>**九三"来反"——它是下卦唯一有力量的那个阳，"来"是真的从险的边缘退回本位，所以收获是内部的支持（内喜之）。**<br>**⚠️ 结论：在蹇卦里，越有力量的人回撤，收益越具体。** 初六回撤只换来一句好话；九三回撤换来的是整个下卦的拥护。<br>**这一条直接回答了蹇卦最常见的一个心理障碍："我要是退回来，下面的人会不会看不起我？"——象传的回答是三个字：内喜之。** |
| **识别信号（诊断清单）** | ① 你是这一摊里实际有能力、有资源、最能顶事的那个人；② 你的位置是正的（当位），下面的人靠你；③ 你正站在最前沿，再往前一步就是明确的险（下艮之顶，正对上坎）；④ 你觉得自己一退，下面的人会失望、局面会崩；⑤ 你已经试过往前，每次都换回更大的阻力。 |
| **该做** | **反——回到自己的本位上去。** 具体三条：**① 把已经伸出去的那只手收回来（停掉最前沿那个推不动的动作）；② 明确回到本职范围内，把本职做实（这正是大象传"反身修德"在九三的形态）；③ 把"我退回来了"这件事对下面的人讲清楚**——**因为你的收益（内喜之）正是来自内部，不说清就拿不到。** |
| **不该做** | 因为"下面人看着"而硬往前顶一步。**九三是全卦唯一有力量往前顶的爻，所以这个诱惑也只有它有。** 而爻辞的判决只有两个字：**往蹇。** |
| **与咸九三、艮九三的对照（同为下艮／艮系的九三）** | **艮九三**"艮其限，列其夤，厉"，象传"危熏心也"——**止在腰上，把上下身硬生生截断，撕裂脊背**；<br>**咸九三**"咸其股，执其随，往吝"，象传"所执下也"——**下艮唯一的阳，却把刚用来跟随别人**；<br>**蹇九三"往蹇，来反"，象传"内喜之也"——下艮唯一的阳，把刚用来"止住并返回"，下面的人拥护他。**<br>**⚠️ 三个九三，下卦全部是艮（艮／艮／艮），同为"止"的力量所在，结果一"厉"一"吝"一"内喜"。**<br>**差别在于这份"止"用在了哪里**：**艮九三止在承重结构上（切口错）；咸九三根本没在止，在随（方向错）；蹇九三止住自己并退回本位（位置对、方向对）。**<br>**合读结论：下艮的那个九三是"止"的开关。它是全卦最有力量的位置，也因此是最容易把力量用错的位置。** |

### 六四 · 往蹇来连

| 字段 | 内容 |
|---|---|
| **爻辞** | 往蹇，来连。 |
| **象传** | 往蹇来连，当位实也。 |
| **位属性** | 阴爻居阴位，**当位**（坎在上之律：四当位）；**直乘九三之上——乘刚**；本库通则"**四多惧**"；与初六同性，**失应**（全卦唯一失应的一对）；已入上坎——**按坎卡通则，坎在上则六四、九五、上六全部当位、全有转机，从本爻起全卦转向**。 |
| **判词 → 行动语义** | **无吉凶判词，只给方向** → **回来，并与人连成一片** |
| **关键词解** | **连**＝连结、联合、相连（一说"连"通"辇"，缓行之貌；本库取"连结"义，因它与象传"当位实"及九五"朋来"连成一条线）。<br>**象传**：**当位实也**——**位置正当而且是实在的**（"实"＝实在、有实内容，与"虚"相对）。 |
| **⚠️ 象传"当位实也"是本卦结构层面最重要的一句** | **全书小象传里直接用"当位"二字的极少，本爻是其中之一，而它所在的卦的彖传也用了"当位"（"当位贞吉"）——一卦之内彖传与象传两次用"当位"，全书仅此一处。**<br>**"当位实也"给出的信息**：**六四虽然乘刚（下面顶着九三这个下艮之阳）、虽然失应（初六与它同性，没人接），但它"当位"而且"实"——所以它有资格去"连"。**<br>**⚠️ 这一句同时给"乘刚"补上了一个新的破解方式。** 本库现有的乘刚破解（截至恒卡）共五式：**艮六四"止诸躬"（收缩范围）／巽六四"田获三品"（交付成果）／谦六四"撝谦"（推行规矩）／震六五"其事在中"（守住本职）／恒六五"先辨职分"／大壮六五"丧羊"（主动放手）。**<br>**蹇六四补上一式：**"**来连**"——**横向连结**。<br>**它与前几式的区别是方向**：**前面五式都是"处理自己"（缩范围、交成果、推规矩、守本职、辨职分、放手），蹇六四是"处理关系"——不往前顶，而是横过来把人连起来。**<br>**⚠️ 可入库：乘刚的第七式＝横向连结。它成立的条件由象传写明——"当位实也"，即你的位置是正的、手上是有实内容的。位不正或手上是空的，"连"就变成拉帮结派。** |
| **⚠️ 为什么六四失应，却是全卦"连"的那一爻** | **六四与初六同性，是全卦唯一失应的一对**——**按常理它最孤立。**<br>**而它偏偏是唯一说"连"的爻。** 这个反差不是矛盾，是因果：**正因为向下（初六）接不上，它才必须横向去连。**<br>**⚠️ 这与坎六四"纳约自牖，终无咎"（极简＋走侧门，把关系接上）是同一个位置、同一个动作。** 坎卡把六四称为"全卦转机之爻"，理由是象传"刚柔际也"（六四与九五相接）。<br>**两卦合读：坎在上的六四，都是靠"接上关系"来转机的——一个是从窗口把礼递进去（坎），一个是横过来把人连起来（蹇）。** |
| **识别信号** | ① 局面已经卡了一段时间，你在中层／执行层，名分是正的（当位）；② 下面有强劲的力量在顶你（乘刚——九三那个"最能顶事的人"就在你脚下）；③ 你向下找不到接得上的人（失应），指望不上原来那条线；④ 你手上其实有实在的东西（当位实）：一份数据、一个渠道、一段关系、一块能交付的活；⑤ 你正在考虑要不要单独往前推一把。 |
| **该做** | **来连——把力量横向连起来。** 具体三条：**① 停掉单独向前推的动作（往蹇）；② 把你手上那个"实"拿出来做连结的凭据（不是姿态，是实物）；③ 主动去连九三（下面那个能顶事的人）与九五（上面正在大难里的那个人）——⚠️ 本爻的"连"是往上下两头连，不是往外拉山头。** |
| **不该做** | ① 独自往前推（往蹇）；② 因为"上面还没发话"而按着不动——**六四是坎在上转机的起点，它一动，才有九五的"朋来"。**<br>③ 把"连"做成结党。**象传给的资格是"当位实也"——位正、手上有实货。这两条丢了，"连"立刻变质。** |
| **与谦六四、坎六四的三方对照（三个乘刚的六四）** | **谦六四**"无不利，撝谦"，象传"不违则也"——**乘的是那个"万民服"的卦主，解法是把谦推行成规矩，判词"无不利"**；<br>**坎六四**"樽酒簋贰，用缶，纳约自牖，终无咎"，象传"刚柔际也"——**险中用极简＋侧门把关系接上，判词"终无咎"**；<br>**蹇六四"往蹇，来连"，象传"当位实也"——难中横向连结，无判词。**<br>**⚠️ 三爻都当位、都乘刚、都在"四多惧"之位，动作依次是：推行规矩 → 接上一条线 → 连成一片。**<br>**判词依次是"无不利 ／ 终无咎 ／ 无判词"。** **注意判词是递减的，而这与卦的处境完全对应：谦是无凶之卦，坎是重险，蹇是走不动。同一个动作在不同处境里能换到的东西不一样——但动作本身的方向是一致的：不往前，往旁边。** |

### 九五 · 大蹇朋来（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 大蹇，朋来。 |
| **象传** | 大蹇朋来，以中节也。 |

| **⚠️ 上六当位却仍乘刚，而这一次乘刚不构成灾** | **按咸卡新增的结构事实，坎的顶阴压中阳，所以坎在上则上六必乘刚。** 本卦上六直乘九五之上。<br>**但它是全卦唯一的"吉"。** 原因在爻辞后半句：**"利见大人"，象传"以从贵也"。**<br>**⚠️ 这是本库"乘刚破解"的第八式，也是最特殊的一式：从。**<br>**前七式（止诸躬／田获三品／撝谦／其事在中／辨职分／丧羊／来连）都是"自己做点什么"；蹇上六是"跟从下面那个刚"。**<br>**它把"被下面顶着"这件事整个翻了过来：不去抵挡九五的刚，而是承认它尊贵、跟从它。**<br>**⚠️ 可入库为通则：乘刚的最后一式是"从"——当下面那个阳是"贵"（有位有德）时，乘刚的压迫感可以直接转成依附的通路。**<br>**这也解释了为什么"利见大人"在本卦被说两次：卦辞说一次是给全卦定方向，上六再说一次是因为它就是那个"最需要人、也最有条件去从"的位置。** |

### ⚠️ 核心表：往／来方向判定（本卡最实用的一张表）

**本卦六爻里有四爻用同一句式"往蹇，来×"。这四爻组成了全书最系统的一组"方向判定"：**

| 爻 | 爻辞 | 「往」的判定 | 「来」的回报 | 象传给的理由 | 回报量级 |
|---|---|---|---|---|---|
| **初六** | 往蹇，来誉 | **蹇** | **誉**（一句好话） | **宜待也**（该等） | 最小 |
| **九三** | 往蹇，来反 | **蹇** | **反**（回到本位） | **内喜之也**（下面人拥护） | ↑ |
| **六四** | 往蹇，来连 | **蹇** | **连**（连成一片） | **当位实也**（位正手上有实货） | ↑ |
| **上六** | 往蹇，来硕，**吉** | **蹇** | **硕**（硕大） | **志在内也**（心志转向内） | **最大 ＋ 全卦唯一的吉** |

> **⚠️ 三条从这张表读出来的结论**：
> **① 「往」在本卦出现四次，四次全部是「蹇」。** **《周易》用四次重复表态：这个局面里向前的动作没有一次是对的。** 全卦唯一被许"有功"的"往"，是彖传的"利见大人，往有功也"——**往人那里去，不是往事那里去。**
> **② 「来」的回报随位置升高而递增：誉 → 反 → 连 → 硕。** **越靠上、往前代价越高的人，回撤的收益越大。**
> **③ 「来」的本质不是身体退回，是「志在内」**（上六象传）。**所以"来"不等于放弃——初六来了得"誉"，九三来了得"内喜"，六四来了得"连"，上六来了得"硕"＋"吉"。四处没有一处是损失。**

**蹇卦三句话**：
1. **蹇不是被打倒，是走不动**（"蹇，跛也"）。**而《周易》不把"停住"当病，它把"停住"当本钱**——彖传"**见险而能止，知矣哉！**"
2. **往必蹇，来必得。** 四爻四次"往蹇"，四次"来"的回报一路递增（誉→反→连→硕）。**唯一被许"有功"的"往"是"往见大人"；唯一必须往前的人是有职分的六二（而它最好的结果只是"终无咎"）。**
3. **唯一的行动纲领是"反身修德"**（大象传）。**走不动的时候，唯一还通的方向是向内——而上六把这件事说穿了：所谓"来"，就是"志在内也"。**

**本卦最反直觉的四条**：
- **⚠️ 全卦五爻当位（本库当位数最高的卦），而它是一个"难"卦。** 彖传自己写着"当位贞吉"。**这是本库对"当位＝顺遂"这个误解最硬的一次纠正：当位保证的是"守正这条路是通的"，不保证事情走得动。** 而它的倒转卦解（40）只有一爻当位，反而是"解脱"——**详见第四节。**
- **全卦唯一的"吉"不给最正的九五，也不给最忠的六二，给了最外围的上六。** **九五当位得中居尊，只有"大蹇，朋来"，连判词都没有；六二当位得中有应，只有"终无咎"；上六在最外面，把心志转回来（志在内），得"吉"＋"硕"。**
- **九五什么动作都没做，却得到了全卦唯一的援军。** 象传只给四个字："**以中节也**"。**在最大的难里，能把人吸引过来的不是办法，是"不偏"（中）与"有度"（节）。**
- **全卦唯一不当位的初六，判词最轻但最干净：不动即得"誉"。** **条件最差的人因为最有理由不动，所以在蹇卦里最容易做对。**

**⚠️ 这不是巧合，而是一条可以两行证明的定理**：

> **位属性规则**：初、三、五＝阳位；二、四、上＝阴位。
> **覆卦规则**：整卦上下颠倒，则原第 *i* 位的爻落到第 *7−i* 位。
> **而 *i* 与 *7−i* 必然一奇一偶**（1↔6、2↔5、3↔4）——**也就是必然一阳位一阴位。**
> **所以：任何一爻，倒转之后所处位置的阴阳属性必然翻转。原来当位的，倒过来必然不当位；原来不当位的，倒过来必然当位。**
> **推论一：一对覆卦的当位数必然相加为 6，逐爻互补，无一例外。**
> **推论二：本库此前记录的三组"4↔2"不是这三对卦的性格，而是"一卦有 4 爻当位"这件事的必然结果。**

**⚠️ 这条定理对本库的实际价值极大，因为它把"当位数"这个指标的性质彻底改写了**：

- **改写前**（本库谦卡的口径）：谦 4 当位＝全卦无凶；豫 2 当位＝开局即凶。**结论是"当位数决定吉凶"。**
- **改写后**：**当位数在一对覆卦里是零和的——一卦多当位，必然意味着它的倒转卦少当位。所以"当位数高"本身不含吉凶信息，它只说明"这一卦的爻更多地落在了与自己阴阳相符的位上"。**
- **⚠️ 而蹇／解这一对就是这条改写的最强证据**（见下一节）。

> **建议补入索引第五节的一句**：**"当位数"不是吉凶指标，是结构指标。它高，说明这一卦的爻多数处在"名正言顺"的位置上；但一卦是难还是顺，由卦德与爻辞决定，不由当位数决定。**

### 2. ⚠️ 蹇（5 当位）是"难"，解（1 当位）是"解脱"——本库"当位≠顺遂"最硬的一次证明

| | **蹇 39（水山蹇）** | **解 40（雷水解）** |
|---|---|---|
| **卦象** | 上坎下艮 | 上震下坎 |
| **六爻（自下往上）** | 阴 阴 阳 ｜ 阴 阳 阴 | 阴 阳 阴 ｜ 阳 阴 阴 |
| **当位爻** | **六二、九三、六四、九五、上六（5 爻）** | **上六（1 爻）** |
| **不当位爻** | 初六（1 爻） | **初六、九二、六三、九四、六五（5 爻）** |
| **卦德** | **难**（彖传"蹇，难也"） | **缓／解**（序卦传"解者，缓也"） |
| **卦辞** | 利西南，不利东北；利见大人，**贞吉**（**无亨**） | 利西南，无所往，其来复吉。有攸往，**夙吉** |
| **爻中判词** | 誉／**终无咎**／反／连／（无）／**吉** | **无咎**／**贞吉**／**贞凶**／（无）／**吉**／**无不利** |
| **最高判词** | **吉**（上六，一处） | **无不利**（上六）＋**吉**（六五）＋**贞吉**（九二） |
| **一句话** | **位最正，却走不动** | **位最不正，却出得来** |

> **⚠️ 结论（建议直接补入索引，与"坎在上／在下"通则并列）**：
> **蹇是本库当位数最高的卦（5／6），它的卦德是"难"；解是本库当位数最低的卦之一（1／6），它的卦德是"解脱"，而且它的正面判词比蹇多、比蹇重。**
> **两卦互为覆卦，六爻的阴阳一个没变，只是倒过来读。**
> **所以：位置的"正"与处境的"顺"是两件完全不同的事。**
> **⚠️ 这条结论修正了本库谦卡第 2 节那条推论（"当位数决定吉凶"）——谦／豫那一组的差异不是来自当位数本身，而是来自"唯一那个阳爻在第三位还是第四位"（谦卡第 3 节已经把真正的机制写对了：阳爻上移一位，把乘刚从可解的六四推到无解的六五）。**
> **换句话说：真正起作用的是"关键爻落在哪一位"，不是"有几爻当位"。**

### 3. 蹇是"坎在上"的第四个样本，也是最极端的一个（与 29 坎卡直接联动）

本库坎卡第四节给出的总对照表，本卡为它补上第四行：

| 卦 | 卦象 | 下卦是什么 | 险的性质 | 本库口径 |
|---|---|---|---|---|
| **屯 3** | 上坎**下震** | **动** | 险在前方，起步是"动" | **扎根**、可小试错（九五"小贞吉，大贞凶"） |
| **需 5** | 上坎**下乾** | **刚健** | 险在前方，底子刚健 | **待时**、安身养命 |
| **比 8** | 上坎**下坤** | **顺** | 险在前方，底子柔顺 | **择主**、且有时间窗口（"后夫凶"） |
| **蹇 39** | 上坎**下艮** | **止** | **险在前方，而自己内部是"止"——两头堵死** | **反身修德**、往必蹇来必得、利见大人 |

> **⚠️ 本卡给坎卡通则补的一条关键限定**：
> **坎卡的口径是"坎在上 → 险还在前方，所以扎根／待时／择主"。这三条都预设了"你还能动"（屯能扎根、需能待、比能择）。**
> **蹇是这条通则的边界情形：下卦是艮（止），所以"扎根／待时／择主"里的前两条都做不了——你连"动起来去扎根"都不行。**
> **蹇剩下的唯一一条是第三条的变体：「利见大人」（去找人）＋「反身修德」（修自己）。**
> **⚠️ 于是"坎在上"这条通则的完整形态是：险在前方时，你能做什么，完全由你脚下那个三画卦决定——**
> **脚下是震（动）→ 扎根；脚下是乾（刚）→ 待时；脚下是坤（顺）→ 择主；脚下是艮（止）→ 修己＋见大人。**
> **这与恒卡第 2 节给出的通则（"'四多惧'的吉凶由下卦决定，四位的诊断动作是向下看"）是同一条规律在卦级上的表现：诊断动作永远是向下看，不是向前看。**

**⚠️ 同时，蹇与坎构成了本库"险"的两端对照，这一组必须并读**：

| | **坎 29（重险）** | **蹇 39（走不动）** |
|---|---|---|
| **坎的位置** | 上下皆坎 | **只在上**（险在前方） |
| **你在哪** | **已经在里面** | **还没进去，被自己的山挡在这边** |
| **卦辞给了什么** | **有孚，维心亨**（只有心是通的）；**无一个"吉"字** | **贞吉**（守正则吉）；**无一个"亨"字** |
| **纲领** | **常德行习教事**（把日常功课做成常态） | **反身修德**（把方向整个转回自身） |
| **唯一有效动作** | **求小得**（九二）——降低量级 | **来**（四爻）——返回；**见大人**（卦辞＋上六） |
| **致命动作** | **入于坎窞**（往深处走） | **往**（往前推） |
| **时间刻度** | **三岁不得，凶**（上六）——滞留会固化成牢笼 | 无时间刻度；**回报刻度在"来"的幅度上**（誉→反→连→硕） |
| **一句话** | **在里面，只求不死** | **在外面，只许转身** |

> **⚠️ 这组对照给出的路由判据（可直接入库）**：
> **用户困境里最需要区分的一句话是——"你是已经在坑里，还是被堵在坑前面？"**
> **已经在里面（坎在下／重险）→ 坎卦：求小得、勿加深、别滞留三年。**
> **还在外面而动不了（坎在上＋艮在下）→ 蹇卦：别往前、往回来、修自己、去见人。**
> **误路由的代价：拿坎卦的"求小得"去指导蹇卦的人，他会继续往前做小动作，而本卦四次判"往蹇"；拿蹇卦的"反身修德"去指导坎卦的人，他会停下来修身而错过"行有尚"与"三岁"这条死线。**

### 4. 蹇 ↔ 蒙（4）：同两个三画卦的另一种叠法（交卦对照）

**蹇＝上坎下艮；蒙＝上艮下坎。两卦由同样的两个三画卦（坎、艮）构成，只是上下互换。** 本库蒙卡已有，两卡可直接对撞：

| | **蒙 4（山水蒙）** | **蹇 39（水山蹇）** |
|---|---|---|
| **卦象** | **上艮下坎** | **上坎下艮** |
| **结构含义** | **坎在下＝起步即险；艮在上＝被压住不许动** | **艮在下＝止在内（自己这边）；坎在上＝险在前方** |
| **当位分布** | **坎在下 → 初二三全不当位；艮在上 → 仅六四当位** ＝ **1 爻当位** | **艮在下 → 二三当位；坎在上 → 四五上全当位** ＝ **5 爻当位** |
| **卦德** | **蒙昧、需要开蒙** | **难、走不动** |
| **险与止的关系** | **险在脚下，止在头顶**——你已经在险里，上面还有人压着你不许动 | **止在脚下，险在头顶**——你自己停住了，险还在前面 |
| **唯一通路** | **九二 ↔ 六五**（刚中的施教者 ↔ 童蒙的求教者）——**全卦唯一的吉配** | **九五 ↔ 六二**（大蹇而朋来的君 ↔ 王臣蹇蹇的臣）——**全卦唯一的吉配** |
| **对外求助的指令** | **童蒙求我**（求教者必须主动来求） | **利见大人**（卦辞＋上六，全卦唯一被重复的指令） |
| **一句话** | **你在险里被压着，只能靠"求"** | **你在险前停住了，只能靠"来"与"见"** |

> **⚠️ 合读结论（这是本卡最精妙的一处对照）**：
> **同样的坎与艮，谁在上谁在下，决定了"险"和"止"分别属于谁——**
> **蒙：险是你已经踩进去的（坎在下），止是别人压给你的（艮在上）。所以蒙卦的解药是向上求（童蒙求我），且它的当位数是本库最低的 1／6。**
> **蹇：止是你自己主动放的（艮在下），险是还没碰到的（坎在上）。所以蹇卦的解药是向内转（反身修德）＋向外见人（利见大人），且它的当位数是本库最高的 5／6。**
> **⚠️ 而两卦的通路结构完全同构：都只有九二／九五这一对相应爻是活的，其余四爻各自受困。**
> **可入库为一条读卦法：当一个卦只有一对应爻是活的时候，全卦的解法就压在那一对上——不必去救别的爻。**

**⚠️ 顺带补上坎卡末节的一个悬置**：坎卡曾指出"蒙卦（上艮下坎）＝坎在下（起步即险）＋艮在上（被压住），所以只有九二↔六五这一条通路"。**本卡完成了它的镜像：蹇卦（上坎下艮）＝艮在下（止在自己这边）＋坎在上（险在前方），所以有五爻当位、四爻讲"来"，而唯一的通路仍然只有一对（六二↔九五）。两卡合读，坎／艮这一对反卦在复合卦里的两种叠加方式就读完了。**

### 5. "反身修德"补上本库"困境自处"纲领谱的最后一条

《周易》大象传给困境开的行动纲领，本库现有四条，**它们的共同点是：没有一条指向"改变外部"**。

| 卦 | 大象传 | 纲领 | 动作类型 | 处境 |
|---|---|---|---|---|
| **坎 29** | 水洊至，习坎 | **常德行习教事** | **做**（把日常功课做成常态） | 已在重险中，打击一波接一波 |
| **震 51** | 洊雷，震 | **恐惧修省** | **查**（把恐惧直接换成查自己） | 突发冲击刚砸下来 |
| **艮 52** | 兼山，艮 | **思不出其位** | **收**（连念头都不越出自己的位置） | 该停下来的时候 |
| **蹇 39** | 山上有水，蹇 | **反身修德** | **转**（把方向整个转回自身） | **前有险、自己又动不了** |

> **⚠️ 四条合读得出的口径（建议入库）**：
> **《周易》处理困境的全部纲领都是"对自己下的指令"，无一条是"改变对方或条件"。**
> **而蹇卦是四条里最彻底的一条**：**坎、震、艮三卦的纲领是"在做别的事的同时也修自己"，蹇卦的纲领是"除了修自己，没有别的可做"**——因为它的六爻已经用四次"往蹇"把所有向外的动作判死了。
> **⚠️ 由此可给蹇卦一个在全库中的独特定位：它是本库唯一一张"外部完全无解"的卡。** 其余各卦总还有一个外向动作（坎有"求小得"、震有"立则"、艮有"换切口"、需有"待"、比有"择主"），**蹇卦的向外动作只剩一个，而且不是做事，是见人（利见大人）。**

### 7. 本卡打开的下一步（优先建议）

> **首选：解 40（上震下坎）**——**与本卦是覆卦对，必须合读**（本批已同步产出）。**蹇讲堵死，解讲解开；蹇 5 当位而难，解 1 当位而解脱，是本库"当位≠顺遂"最硬的一对样本。**
> **⚠️ 必须回读：睽 38（上离下兑）**——本库已有此卡。序卦传"**乖必有难，故受之以蹇**"，**睽是蹇的直接病因**：**人心先"乖"（离心、看法分裂），事情才"蹇"（走不动）。** 建议在索引里把 **睽 38 → 蹇 39 → 解 40** 记成一条完整因果链：**离心 → 走不动 → 解开**。而"解"之后紧接"损"（41），**因为解开必有所失**（序卦传"缓必有所失，故受之以损"）。**这条四卦链是下经中段最连贯的一段，本批把它的后三环补齐。**
> 其次：**井 48（上坎下巽）** 与 **节 60（上坎下兑）**——**这是"坎在上"一族在本库仅剩的两个缺口**（坎在上已有：屯 3、需 5、比 8、既济 63、蹇 39）。**井讲"险在上而下有源"（巽在下，柔在底往下渗成井），节讲"险在上而下是悦"（兑在下，愉悦必须有节度）。** 补上这两卦，坎卡第四节那张"坎在上／在下"总表就满了。
> 第三：**小过 62（上震下艮）** 与 **旅 56（上离下艮）**——**"艮在下"一族仅剩的两个缺口**（艮在下已有：谦 15、咸 31、遯 33、渐 53、艮 52、蹇 39）。**小过是"止在内而动在头顶"，恰是蹇的震化版本（前面不是险而是动）；旅是"止在内而明在身外"。** 三卦合读可把"艮在下＝止在自己这边"这条结构律的不同展开方式读全。
