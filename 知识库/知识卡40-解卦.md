# 知识卡 40 · 解卦（雷水解）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传/系辞传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："物不可以终难，故受之以解。解者，缓也。"——**难不可能一直难下去，所以接之以解。** 注意序卦传给"解"的训解是"**缓**"（松开、缓下来），不是"胜"、不是"成"。
> **本卦与蹇卦（39）是一对，且是结构上的倒转（覆卦）**：蹇六爻自下往上"阴阴阳｜阴阳阴"，整卦上下颠倒即得解卦"阴阳阴｜阳阴阴"。**蹇讲被堵死，解讲解开。两卦必须合读。**
> ⚠️ **本卦是本库"当位≠顺遂"最强的一个样本**：**全卦六爻只有上六一爻当位（1／6，本库当位数最低的卦之一），却是"解脱"之卦，判词密度还高于蹇。** 而它的覆卦蹇有五爻当位，卦德是"难"。**详见第四节第 1、2 条。**
> ⚠️ **本卦同时踩在本库"六条最危险位置"里的两条上**：**坎在下＝你已在险中｜震在上＝动在头顶（你做不了主）。** 两条最难的结构叠在一起，卦名却是"解"——**这不是矛盾，是机制**（彖传"险以动，动而免乎险"）。**这条反例要求修订"震在上"那条通则，见第四节第 3 条。**
> ⚠️ **本卦六三是《周易》里唯一一条爻辞本身就写着"乘"字的爻**（"负且乘"），**而系辞上传专门为它写了一整段解释**。**本库"乘刚"专题的正源在此。**
> ⚠️ **本卦大象传"君子以赦过宥罪"是全库"追责的终点"那条判断的唯一经文依据**，必须与师上六"小人勿用"、噬嗑"明罚敕法"三方对读（第四节第 5 条）。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 解 · 第四十卦 |
| **卦象** | 上震（雷／动）下坎（水／险），称"雷水解"。**大象传直接叫它"雷雨作"**——**雷响了，雨下来了，凝住的东西开始松动。**<br>**六爻自下而上：阴、阳、阴｜阳、阴、阴。**<br>**按本库第 4 节结构律逐爻核定**：**坎在下 → 初六、九二、六三三爻全部不当位**（九二得中）；**震在上 → 九四不当位、六五不当位（得中居尊）、上六当位**。<br>**⚠️ 合计只有上六一爻当位，其余五爻全部不当位——这是本库当位数最低的卦之一（与蒙 4 并列 1／6）。**<br>**⚠️ 而九四的小象传亲自把这件事写出来了："解而拇，未当位也。"**<br>**⚠️ 逐爻核查乘刚**：**六三直乘九二之上——乘刚**（涣卡已立："坎在下时，六三乘九二之刚构成一次乘刚"；困卦六三的小象传更直接写出"乘刚也"）；**六五直乘九四之上——乘刚**（规格通则："震在上则六五必乘刚"，验证通过）。**上六乘于六五之上，同性，不构成乘刚。全卦两处乘刚。**<br>**⚠️ 应爻核查**：初六↔九四（阴／阳，**应**）；九二↔六五（阳／阴，**应**）；六三↔上六（阴／阴，**不应**）。**二应一不应，而唯一失应的一对正好包含全卦唯一的"凶"（六三）与全卦最高判词（上六）。** |
| **⚠️ "上震下坎"的定势含义（本卦最需要讲清的一条）** | 本库"六条最危险的位置"里，有两条同时落在本卦身上：<br>**① 坎在下＝你已在险中**（本库口径：求小得、勿加深）；<br>**② 震在上＝动在头顶，你做不了主**（本库口径：三者中最难的位置之一）。<br>**按常理，这应该是一个极凶的卦。可它叫"解"，而且六爻判词是：无咎／贞吉／贞凶／（无判词）／吉／无不利。**<br>**⚠️ 彖传把机制写得极干净，只有七个字："险以动，动而免乎险。"**<br>**下坎是"你在险里"，上震是"动"——而正因为那个"动"在你头顶、不由你发起，它才能把你从险里带出来。**<br>**⚠️ 这就是本卦对结构律的修订（详见第四节第 3 条）**：**"震在上＝动在头顶（你做不了主）"这条通则，只在"你需要自己做主"的时候是坏事；当你需要的恰恰是"被松开"的时候，"动在头顶"就是唯一的出路。**<br>**大象传给了这件事最直白的形象："雷雨作"——雷不是你打的，雨不是你下的。彖传更进一步："天地解而雷雨作。"** **解是天地先解开了，然后雷雨才作；不是雷雨作了才解开。** |
| **领域定义** | **困局松动、脱身、以及"解开之后怎么收尾"**。① 官司／审计／调查结束了，或明确将要结束；② 债务重组通过、资金到账、项目被救活；③ 长期病痛好转、长期照护关系结束；④ 团队风波平息、组织动荡告一段落；⑤ 一段消耗性的关系终于解绑（离职成功、合作终止、婚姻结束）；⑥ 你终于从一个卡了很久的位置上出来了；⑦ **⚠️ 以及最容易被忽略的一类：事情已经解开，但你还在处理"谁该负责"这件事。**<br>**凡是"这件事正在松开／已经松开，接下来该怎么办"，都落在解卦。** |
| **不归本卦的情况** | ① **还在险里出不来、还在往深处走** → **坎卦（29）**。**分界线只问一句："松动了没有？"没松动就是坎，松动了才是解。**<br>② **前面有险、自己又动不了** → **蹇卦（39）**。**蹇是"往必蹇"（不能往），解是"有攸往，夙吉"（可以往，而且要快）。这一条判反了代价极大：在蹇卦里往前是"蹇"，在解卦里不往前是错过时机。**<br>③ **不是被困，是"没有"——资源、通路、人全部枯竭** → **困卦（47）**。<br>④ **队形被吹散了、人心离散** → **涣卦（59）**。<br>⑤ **你手里有处置权，要不要罚、罚多重** → **噬嗑卦（21）**。**⚠️ 这一条是本卦最容易误路由的方向**：**解卦的大象传是"赦过宥罪"（放下追责），噬嗑的大象传是"明罚敕法"（把罚则挂出来）。拿解卦去指导执法者会变成放纵，拿噬嗑去指导已经解开的局面会变成翻旧账。**（详见第四节第 5 条。）<br>⑥ **突发冲击刚砸下来、你还没反应过来** → **震卦（51）**。**震是"雷来了"，解是"雷雨作完了，东西开始松"。** |
| **"解"字本义** | **解开、松开、分开**。《说文》"解，判也"，本义是**用刀把骨肉分开**（"解牛"），引申为**解结、松绑、消散**。<br>**⚠️ 但序卦传给的训解不是"解开"，是"缓"**："解者，缓也。"<br>**这个字的选择极重要：它把"解"的分量定死了——解不是胜利，不是圆满，是"松下来了"。**<br>**对照本库判词口径**：**"解"这件事在吉凶谱上的位置，接近"悔亡"（挽回级）而不是"元吉"（圆满级）。** 而本卦爻辞正好印证：**初六只给"无咎"，九二"贞吉"，六五"吉"，最高的"无不利"要等到上六把那只隼射下来。** |
| **卦辞原文** | 解：利西南，无所往，其来复吉。有攸往，夙吉。 |
| **⚠️ 卦辞的关键结构** | **无元、无亨、无利（"利西南"是方位限定，不是判词性的"利"）、无贞。全部内容是一个方位 ＋ 两种情形的分别处置。**<br>**① ⚠️ 这是《周易》里罕见的"分情形卦辞"**：<br>**「无所往，其来复吉」**——**如果没有地方可去，那就回来，回来则吉**（彖传："乃得中也"）；<br>**「有攸往，夙吉」**——**如果有地方可去，那就要早，早则吉**（彖传："往有功也"）。<br>**两句是一组条件判断，不是并列的建议。所以读本卦第一件事是自问："我现在有没有一个明确的去处？"**<br>**② ⚠️ "夙"字是本卦最具操作性的一个字。** **夙＝早、天刚亮的时候。** **"夙吉"＝早则吉，言外之意就是晚则不吉。**<br>**解卦对时间的态度与蹇卦正好相反**：**蹇卦四次判"往蹇"（不许往）；解卦说"有攸往，夙吉"（要往，而且要快）。** **同一个"往"字，一卦禁止、一卦催促——判别依据只有一个：局面松没松。**<br>**③ 与蹇卦共有"利西南"**——**全书只有蹇、解两卦的卦辞出现"利西南"，而这两卦正是一对覆卦。** 按本库乾卡方位表：**坤＝西南。** 彖传给了理由：**"解利西南，往得众也"——往西南（坤／地／众）去，是为了"得众"。**<br>**⚠️ 两卦的"利西南"含义不同**：**蹇卦的"利西南"是与"不利东北"成对的方向禁令（别往自己那座山里钻）；解卦的"利西南"没有配套禁令，它是纯正面的——往人多、平易、宽阔的地方去，把人聚起来。**<br>**合读：难的时候往西南是为了不死（蹇"往得中也"），解的时候往西南是为了聚人（解"往得众也"）。** |
| **卦辞现代解** | **利西南**——**往开阔、平易、有人的方向去，目的是"得众"（把人重新聚起来）。** 落到现代：**危机松动之后的第一件事不是复盘追责，是把人聚回来。**<br>**无所往，其来复吉**——**如果眼下没有明确的新去处，就回来，回到本位、回到常态。** 彖传"乃得中也"：**回来才回到中道。**<br>**有攸往，夙吉**——**如果确实有一个明确的去处（一个已经看清的机会、一件必须马上办的事），那就要早，越早越好。** 彖传"往有功也"：**这个"往"是有功的。**<br>**⚠️ 合起来是一条极清晰的决策树**：**先问有没有明确去处 → 没有就回到常态（别乱动）→ 有就立刻动（别拖）。** **本卦不允许的只有一种状态：有去处却拖着，或没去处却乱动。** |
| **彖传** | 解，险以动，动而免乎险，解。解利西南，往得众也；其来复吉，乃得中也。有攸往夙吉，往有功也。天地解而雷雨作，雷雨作而百果草木皆甲坼，解之时大矣哉！ |
| **⚠️ 彖传要点（本卦机制全在这四句里）** | ① **"险以动，动而免乎险，解"（本卦的全部机制，只有九个字）**——**下面是险，上面是动；因为动，所以免于险。**<br>**⚠️ 注意语序："险以动"是"处在险中而动"，"动而免乎险"是"因为动才脱险"。** **《周易》在这里给了脱险的唯一机制：动。** 而它与坎卦的口径并不矛盾——**坎卦（重险）说"行有尚"（行动本身就值得肯定），坎九二说"求小得"（用小动作活着）。解卦是那个"动"终于奏效的时刻。**<br>② **"其来复吉，乃得中也"／"有攸往夙吉，往有功也"**——**两种情形分别给了理由：回来是为了"得中"（回到中道），往前是为了"有功"（做成事）。**<br>③ **"天地解而雷雨作，雷雨作而百果草木皆甲坼"（本卦最美也最重要的一句）**——**天地先解开，然后雷雨才作；雷雨一作，所有的果实草木外壳都裂开了。**<br>**"甲坼"（jiǎ chè）＝外壳裂开**（"甲"是种子的硬壳，"坼"是裂）。<br>**⚠️ 这一句给出了"解"的真实形象：不是打赢了什么，是外面那层硬壳自己裂开了。** **而裂开的原因在"天地解"——大势先松，然后才有雷雨，然后才有草木发芽。**<br>**⚠️ 由此得出本卦最反直觉的一条：解不是你解开的。** 你能做的只有三件事：**看准它松了（判断）、该走就快走（夙）、该回就回来（来复）。**<br>④ **"解之时大矣哉！"**——与坎卦"**险之时用大矣哉**"、蹇卦"**蹇之时用大矣哉**"同一句式。**⚠️ 注意区别：坎、蹇两卦用的是"时用"（时机的用处），解卦用的是"时"（时机本身）。** **险与难都还有"可用"的余地（王公设险以守其国、见险而能止），而解只有"时"——它是一个窗口，用不用只看你抓不抓得住。这正是"夙吉"的理由。** |
| **大象传（行动纲领）** | 雷雨作，解。君子以赦过宥罪。 |
| **⚠️ "赦过宥罪"解（本卦最高层原则，也是全库"追责的终点"唯一的经文依据）** | **赦**＝赦免、免除。**过**＝过失（无心之失）。**宥**＝宽减、从宽（不是免除，是减等）。**罪**＝罪行（有心之恶）。<br>**⚠️ 注意这四个字是两组、两个不同的力度**：**"过"是赦（完全免除），"罪"是宥（从宽处理）。** **《周易》在这里分得极细：无心之失一笔勾销，有心之恶减等处理——但不是不处理。**<br>**为什么"雷雨作"就要"赦过宥罪"？** 雷雨是天地的大动，一作而万物皆得舒解；**君子对应的动作，就是把压在人身上的追究也松开。**<br>**⚠️ 这条纲领的操作含义（本卦最实用的一条）**：**局面解开的那一刻，你必须主动结束追责。** **因为"解"的载体是人，而追责会把刚松开的东西重新绑紧。**<br>**⚠️ 但它有一条极重要的边界，且这条边界是本卦自己写出来的**：<br>**六五象传"君子有解，小人退也"——小人要退。**<br>**上六"公用射隼，于高墉之上，获之"——那只隼要射下来。**<br>**⚠️ 三者合读得出本卦最精确的一条口径（本卡最重要的贡献之一）**：<br>> **赦过宥罪 ＝ 放下"追究"，不等于恢复"授权"。**
> **过可以赦、罪可以宥（不再追打），但位子要退（小人退也），首恶要除（射隼获之）。**
> **换成一句话：不再算旧账，但不再给权力。**<br>**⚠️ 这一条把本卦与师上六"小人勿用，必乱邦也"完全打通了，两处没有任何矛盾**（详见第四节第 5 条）。 |
| **总铁律** | ① **解不是你解开的**（彖传"天地解而雷雨作"）——**你的动作只有判断、快走、回位三件。**<br>② **先问有没有明确去处**：没有就"来复"（回到常态），有就"夙"（立刻动）。**本卦唯一不允许的是拖着或乱动。**<br>③ **"夙吉"是硬指令**——**解的窗口是有时限的**（彖传只说"解之时"，不说"时用"）。<br>④ **⚠️ 解开之后必须"赦过宥罪"**（大象传）——**主动结束追责，因为追责会把松开的重新绑紧。**<br>⑤ **但"赦"的同时必须"退"与"射"**：**小人退其位（六五象传），首恶射其身（上六）。放下追究 ≠ 恢复授权。**<br>⑥ **必须"解而拇"**（九四）——**把粘在自己身上最低处那个牵累解掉，"朋"才会来。**<br>⑦ **⚠️ 全卦唯一的凶在六三"负且乘"**：**背着东西还坐在车上（德薄而位尊），是自己把强盗招来的**（系辞传"盗之招也"，象传"自我致戎，又谁咎也"）。 |

## 二、爻级字段

> ⚠️ **先读这一段：本卦六爻是一条极清晰的"解的五个动作 ＋ 一个反例"。**
> **初六「无咎」**——刚松开，什么都不用做（全书最短的爻辞之一）。
> **九二「田获三狐，得黄矢」**——把那三只狐狸打掉，拿到中正的凭据。
> **⚠️ 六三「负且乘，致寇至」**——**全卦唯一的凶，也是全卦唯一的反例**：德不配位，自己招祸。
> **九四「解而拇」**——解掉粘在自己身上那个牵累。
> **六五「君子维有解」**——居尊者亲自解开，小人自己退。
> **上六「公用射隼」**——把墙头上那只鹰射下来，收尾（全卦最高判词"无不利"）。
> **⚠️ 注意五个正面动作的对象一路升级：狐（九二）→ 拇（九四）→ 小人（六五）→ 隼（上六）。从"猎物"到"自己身上的东西"到"人"到"首恶"，越往上越具体、越往上判词越高。**

### 初六 · 无咎（⚠️ 全书最短的爻辞之一）

| 字段 | 内容 |
|---|---|
| **爻辞** | 无咎。 |
| **象传** | 刚柔之际，义无咎也。 |
| **位属性** | 阴爻居阳位，**不当位**（坎在下之律：三爻全不当位）；居全卦最下、坎险之底；**与九四相应**；上承九二之刚。 |
| **判词 → 行动语义** | **无咎**（按本库口径：**无灾，不等于吉利**） → **刚松开的时候，什么都不用做；不做就是对的** |
| **关键词解** | **⚠️ 全爻只有两个字，而且这两个字就是判词本身——爻辞里没有任何内容、没有任何意象、没有任何动作。**<br>**象传**：**刚柔之际，义无咎也**——**处在刚与柔交接的地方，按义理就该无咎**（"际"是交接处；"义"是理当、按道理）。 |
| **⚠️ 本爻是《周易》"纯判词爻辞"家族的第三个成员（本库现已凑齐三例）** | 《周易》里有极少数爻辞**通篇只有一个判词、别无他字**。本库现有三例，**三例的象传都只给一个理由，而三个理由全部指向"位置关系"**： | 

| 卦·爻 | 爻辞 | 判词 | 象传 | 象传给的唯一理由 |
|---|---|---|---|---|
| **大壮 34 九二** | 贞吉 | **贞吉** | 九二贞吉，**以中也** | **得中** |
| **恒 32 九二** | 悔亡 | **悔亡** | 九二悔亡，**能久中也** | **久中** |
| **解 40 初六** | 无咎 | **无咎** | **刚柔之际**，义无咎也 | **处在刚柔交接处** |

| 字段 | 内容 |
|---|---|
| **⚠️ 三例对照的结论（建议入库）** | **当《周易》把一条爻辞压缩到只剩判词时，它的意思是"这一爻没有动作可做"，而象传会告诉你"你不需要动作的原因"。**<br>**三个理由都是结构性的：得中（大壮）、久中（恒）、刚柔之际（解）。**<br>**⚠️ 换成人话：这三爻的好处不是你挣来的，是你所处的位置本身给的。所以最正确的动作是不加动作。**<br>**⚠️ 而解初六是三者中最极端的一个**：**大壮九二与恒九二至少还"得中"（是全卦的枢纽），解初六不当位、失中、在坎险最底——按本库通则这是条件最差的一批。可它依然"无咎"。**<br>**理由就是象传那四个字："刚柔之际"——它上面紧接着九二这个阳爻，正处在刚柔交接的位置上。局面松动的力量正好从这里过。** |
| **⚠️ 与蹇初六的正面对照（一对覆卦的两个初爻）** | **蹇初六"往蹇，来誉"，象传"宜待也"——不当位、失应，正解是"等"，回报是"誉"。**<br>**解初六"无咎"，象传"刚柔之际，义无咎也"——不当位、有应（应九四），正解是"什么都不做"，回报是"无咎"。**<br>**⚠️ 两爻都不当位、都在最下、正解都是"不动"，但性质完全不同**：<br>**蹇初六的"不动"是主动的等待（宜待——有一个明确的等待对象和时间）；解初六的"不动"是彻底的无事（爻辞连内容都没有）。**<br>**合读结论：难的开头要"等"，解的开头要"空"。** **⚠️ 落到实操上是同一句话的两半：局面刚卡住的时候不要急着动；局面刚松开的时候也不要急着动。** |
| **识别信号** | ① 长期的困局刚刚出现松动的迹象；② 你在最底层、最没有资源和话语权的位置上；③ 你上面紧接着有一个正在发力、靠得住的人或结构（九二）；④ 你的第一反应是"我得赶紧做点什么，把这个机会抓住"；⑤ 你已经在盘算怎么"趁这个机会"给自己争一点东西。 |
| **该做** | **什么都不做。** 具体三条：**① 不申请、不表态、不抢功、不站队；② 让上面那个正在发力的人（九二）把事做完；③ 把这段时间用来把自己的本职恢复到常态。**<br>**⚠️ 本爻的价值全在"义无咎也"这三个字上——按道理你就该没事。任何多出来的动作都是在这个"理当无咎"上加风险。** |
| **不该做** | 趁松动期为自己抢东西。**参照本卦六三"负且乘，致寇至"：解卦里唯一的凶，就是在局面刚松的时候占了不该占的位置。** |

### 九二 · 田获三狐，得黄矢

| 字段 | 内容 |
|---|---|
| **爻辞** | 田获三狐，得黄矢，贞吉。 |
| **象传** | 九二贞吉，得中道也。 |
| **位属性** | 阳爻居阴位，**不当位**（坎在下之律：三爻全不当位），**但得中**——**下坎唯一的阳爻**，是下半卦的实际发力点；**与六五相应**；本库通则"**二多誉**"。 |
| **判词 → 行动语义** | **贞吉** → **把该清掉的那几个东西清掉，并且拿到中正的凭据** |
| **关键词解** | **田**＝田猎。**三狐**＝三只狐狸——**狐是狡兽，古注多以"狐"喻邪媚小人；"三"是数之多，泛指那几个搅事的**。**黄矢**＝黄色的箭。**黄**＝中央之色（对照坤六五"黄裳元吉"、离六二"黄离元吉"、噬嗑六五"得黄金"）；**矢**＝箭，**是硬的、直的、能作证的实物**（对照噬嗑九四"得金矢"）。<br>**⚠️ "得黄矢"＝拿到了中正而刚直的凭据。** 它不是战利品，是**能拿出来说话的东西**。<br>**象传**：**得中道也**——**因为它走在中道上。** |
| **⚠️ 本爻是全卦的实际操作核心，而它的力量全部来自"得中"** | 九二**不当位**（阳居阴位，名不正言不顺），**在坎险之中**（下卦是坎，它是那个陷在两阴之间的阳）。**按本库通则，这是"你已经在险里"的标准位置。**<br>**但它得中。** 而象传对"贞吉"只给了三个字的理由：**"得中道也"。**<br>**⚠️ 这是本库通则"得中可救不当位"在本卦的实例，而且它给"得中"填上了一个新的具体内容：在解卦里，"得中"表现为"清理的范围是准的"。**<br>**"三狐"是有数的——不是"扫荡一切"，是那三只。** **"黄矢"是中正的——不是随便抓一个证据，是拿得出手的那一个。**<br>**⚠️ 结论：解局面的时候，"中"不是态度温和，是范围精确。** |
| **⚠️ 本库"田猎三爻"的完整对照（本卡新增的一组）** | 《周易》里以"田"（田猎）起首的爻共三处，**本批凑齐**： | 

| 卦·爻 | 爻辞 | 判词 | 象传 | 位属性 | 结果 |
|---|---|---|---|---|---|
| **巽 57 六四** | **田获三品** | **悔亡** | **有功也** | 当位·乘刚 | **猎到，而且正好覆盖三个必须交付的方向**（干豆／宾客／充君之庖） |
| **解 40 九二** | **田获三狐**，得黄矢 | **贞吉** | **得中道也** | 不当位但**得中** | **猎到，而且拿到中正的凭据** |
| **恒 32 九四** | **田无禽** | **无判词** | **久非其位，安得禽也** | 不当位·四多惧 | **空猎**——这个位置上根本没有猎物 |

| 字段 | 内容 |
|---|---|
| **⚠️ 三例对照的结论（建议入库）** | **同一个"田猎"意象，三种结果，而三处象传的归因完全不同：巽六四归因于"功"（成果的分配设计），解九二归因于"中"（范围与凭据的精确），恒九四归因于"位"（这个位置上没有猎物）。**<br>**⚠️ 由此可得一条诊断顺序：当你在"打猎"（清理、追讨、争取一个具体成果）却打不到时，按这三卦的顺序自查——**<br>**① 先查"位"（恒九四）：这个位置上有猎物吗？没有就换位置，别加投入。**<br>**② 再查"中"（解九二）：我的范围准吗？凭据拿得出手吗？**<br>**③ 最后查"功"（巽六四）：猎到之后，能不能分配给该给的三个方向？**<br>**⚠️ 顺序不可颠倒——在没有猎物的位置上把范围调得再精确也没用。** |
| **识别信号** | ① 局面正在松动，而你是实际在处理这件事的人（下坎唯一的阳）；② 你自己也还在险里（坎在下），不是站在岸上指挥；③ 你的名分不完全够（不当位），但事情靠你办（得中）；④ 你面前有几个明确的搅事对象（三狐），也有机会拿到硬证据（黄矢）；⑤ 你有一种"干脆一次清干净"的冲动。 |
| **该做** | **① 把范围锁死在"三狐"上**——列出具体是哪几个人／哪几件事，写下来，不扩大；**② 拿到"黄矢"**——把处理的依据做成能拿出手、能复核的东西（不是口头判断，是可查的记录）；**③ 守住"中道"**——不因为自己也在险中而失衡，不因为名分不足而急于立威。 |
| **不该做** | ① 扩大清理范围（"三狐"是有数的）；② 靠印象和情绪处理（"黄矢"要求硬凭据）；③ 因为自己不当位就不动手——**本爻是全卦唯一有力量清场的爻，它不动，六五就没有"有解"的基础。** |
| **⚠️ 与噬嗑九四／六五的对照（"矢"与"金"的两处）** | **噬嗑九四"噬干胏，得金矢，利艰贞，吉"，象传"未光也"**——**执法者咬最硬的一口，拿到无法辩驳的硬证据，但这件事不给你光荣**；<br>**噬嗑六五"噬干肉，得黄金，贞厉，无咎"，象传"得当也"**——**用刑的最高位，所得是"中正而贵重"，唯一标准是"当"**；<br>**解九二"田获三狐，得黄矢，贞吉"，象传"得中道也"**——**解局面的枢纽，把该清的清掉，所得是"中正而刚直的凭据"。**<br>**⚠️ 三处的"金／黄／矢"是同一套语汇：矢＝硬凭据，黄／金＝中正。**<br>**⚠️ 而判词差异极有信息量：噬嗑九四"吉＋未光也"，噬嗑六五"贞厉＋无咎"，解九二"贞吉"。**<br>**同样是拿到中正的硬凭据，为什么解九二的判词最干净？因为噬嗑是"用刑"（处置同类，天道不给荣耀），解卦是"解开"（清掉障碍以恢复常态）。**<br>**⚠️ 结论：同一个动作，服务于"罚"则不光荣，服务于"解"则贞吉。判别依据是你的目的——是要让他付出代价，还是要让局面松开。** |

### 六三 · 负且乘（⚠️ 全卦唯一的凶；系辞传专门为它写了一段）

| 字段 | 内容 |
|---|---|
| **爻辞** | 负且乘，致寇至，贞凶。 |
| **象传** | 负且乘，亦可丑也，自我致戎，又谁咎也。 |
| **位属性** | 阴爻居阳位，**不当位**（坎在下之律：三爻全不当位）；失中；**直乘九二之上——乘刚**（坎在下则六三乘刚；困卦六三的小象传直书"乘刚也"）；居下坎之顶；**与上六同性，失应**——**全卦唯一失应的一对**；本库通则"**三多凶**"。 |
| **判词 → 行动语义** | **贞凶**（按本库口径：**守正也凶——问题不在品德，在处境与选择的根本错位**） → **此爻不可入；已在此处，唯一动作是把不该占的位置交出去** |
| **关键词解** | **负**＝背着东西（用背扛，**是役夫、下人干的活**）。**乘**＝坐车（**乘车是君子的待遇**）。**负且乘**＝**背上扛着包袱，人却坐在车上**——**⚠️ 一个身份错位到自相矛盾的形象。**<br>**致寇至**＝**招来了强盗**（"致"是招致，主动引来）。**戎**＝兵、兵祸。**丑**＝可耻、难看。<br>**⚠️ 象传两句都极重**：**"亦可丑也"——这事也太难看了；"自我致戎，又谁咎也"——兵祸是我自己招来的，还能怪谁？** |
| **⚠️⚠️ 系辞上传专门为本爻写了一整段（本卡最重要的经文材料）** | 系辞上传（与"劳谦君子"、"亢龙有悔"同章）：<br>> **"《易》曰：'负且乘，致寇至。'子曰：'负也者，小人之事也；乘也者，君子之器也。小人而乘君子之器，盗思夺之矣。上慢下暴，盗思伐之矣。慢藏诲盗，冶容诲淫。《易》曰"负且乘，致寇至"，盗之招也。'"**<br>**逐句训解（这是全书对"位不配德"最完整的一段论述）**：<br>**负也者，小人之事也**——背东西是下人干的活；<br>**乘也者，君子之器也**——车是君子用的东西；<br>**小人而乘君子之器，盗思夺之矣**——**德不够的人坐上了配不上的位置，强盗就会想来夺它**；<br>**上慢下暴，盗思伐之矣**——**上面轻慢、下面残暴，强盗就会想来打**；<br>**慢藏诲盗，冶容诲淫**——**收藏得随便，等于在教人来偷；打扮得妖艳，等于在招人来犯**（"诲"是教）；<br>**盗之招也**——**这是自己把强盗招来的。**<br>**⚠️ 系辞传在这里给出的是全书最硬的一条因果判断：祸不是别人给的，是位置与德行不匹配这件事本身发出的邀请。**<br>**⚠️ 而本库师卦、蒙卦、比卦、兑卦反复出现的那条铁律（"绝不能把权位／本领／诚信交给无德之人"）在这里第一次拿到了它的反面版本**：**从"不要给他"变成"你自己不要拿"。** |
| **⚠️ 本爻是本库"乘刚"专题的正源（全书唯一一条爻辞里就写着"乘"字的爻）** | 本库"乘刚"这条通则，此前全部依靠**小象传**的记载（屯六二"乘刚也"、震六二"乘刚也"、噬嗑六二"乘刚也"、豫六五"乘刚也"、困六三"乘刚也"）。<br>**⚠️ 解六三是唯一一处"乘"字出现在爻辞正文里的爻**，而且系辞传专门解释了这个"乘"字（"乘也者，君子之器也"）。<br>**⚠️ 由此可以给本库的"乘刚"补上一层本义**：<br>> **"乘"的本义是"坐车"——即占据一个原本属于更有分量者的位置。**
> **所以"乘刚"（阴爻压在阳爻之上）在《周易》的语汇里不只是一个位置关系，它带着一层价值判断：柔坐在刚的上面，就像小人坐上了君子的车。**
> **⚠️ 这解释了为什么本库五个乘刚的解法里没有一个是"顶回去"——因为乘刚者的问题从来不是力量不足，是"这个位置本来不该是我的"。**<br>**⚠️ 同时它也解释了乘刚的两种命运**：**接受这个错位并缩小自己（艮六四"止诸躬"、大壮六五"丧羊"、蹇上六"以从贵"）→ 可解；不接受、继续坐着（解六三"负且乘"）→ 贞凶。** |
| **⚠️ 为什么是"贞凶"而不是"凶"** | 按本库判词表：**"贞凶＝守正也凶，问题不在品德，在处境与选择的根本错位。"**<br>**本爻正是这条口径最标准的样本，而且它是全书唯一一处把"错位"直接画成图像的爻**：**背上背着东西（说明你的真实身份是要出力的），人却坐在车上（说明你占的位置是不出力的）。**<br>**⚠️ "贞"救不了它的原因写得很清楚：你可以非常勤勉（负）、非常端正，但只要你还坐在那辆车上，"盗"就会来。因为招祸的不是你的品德，是那个错位本身。**<br>**⚠️ 对照本库现有的"贞凶"家族**：**师六五"弟子舆尸，贞凶"（用错了人）／巽上九"丧其资斧，贞凶"（到顶而一味顺，放弃了决断）／恒初六"浚恒，贞凶"（开头就求深）／恒六五"从妇凶"（该断的人一味跟从）。**<br>**⚠️ 五处"贞凶"的共同点：全部是"职分与动作错配"，而且全部发生在品德没问题的人身上。** **解六三给这一族补上最直白的一种：职分与位置错配。** |
| **识别信号（诊断清单）** | ① 局面正在松动，而你在这轮松动里拿到了一个位置（升职、接手、被推举、分到一块地盘）；② **⚠️ 你自己心里清楚这个位置的分量超过你现在的分量**（你还在"负"，却已经在"乘"）；③ 你的处理方式是更加勤勉——加倍出力，想用辛劳把位置坐实；④ 已经开始有人来"夺"了：有人质疑你的资格、翻你的旧账、争这个位置；⑤ 你的解释是"他们嫉妒"、"是他们的问题"。<br>**⚠️ 第⑤条是确诊指标。象传的回答只有六个字："自我致戎，又谁咎也。"** |
| **该做** | **把不该占的那部分交出去。** 具体三条：**① 明确区分"我该做的事"与"我占的位置"——前者留下，后者交还；② 如果位置不能交，就把它减到与自己分量相称的程度（缩小职权范围、公开自己的边界、把超出能力的部分明确移交）；③ 停止用"更努力"来弥补——系辞传已经把这条路封死了："负也者，小人之事也"，你越负，越证明你不该乘。**<br>**⚠️ 参照系辞传的"慢藏诲盗"：把超出自己分量的东西摊在外面，就是在邀请人来夺。所以还有一个动作是"藏"——不炫耀、不张扬这个位置。** |
| **不该做** | ① 用勤勉抵位置（越负越难看）；② 把来夺的人当敌人处理（象传判"又谁咎也"——你没有资格怪别人）；③ 继续往上争，想用更高的位置压住质疑。**⚠️ "贞凶"的意思就是：这条路上没有一个动作能救你，除了下车。** |
| **⚠️ 与本库其他"下卦之顶·三多凶"诸爻的对照** | **师六三"师或舆尸，凶"（大无功也）——无能力却抢了指挥权**；**履六三"眇能视，跛能履，履虎尾，咥人，凶"（志刚也）——才不配位而志刚**；**比六三"比之匪人"（不亦伤乎）——归附错了对象**；**否六三"包羞"（位不当也）——位不当而受羞**；**困六三"困于石，据于蒺藜…凶"（乘刚也）——困卦唯一的凶，象传直书乘刚**；**解六三"负且乘，致寇至，贞凶"（自我致戎）——位不配德，自己招祸。**<br>**⚠️ 六个"三爻"，全部不当位，全部指向同一个病根："才／德不配位"。**<br>**⚠️ 而解六三是六者中说得最透的一个，因为它有系辞传的专门解释，而且它把病根从"能力不足"精确到了"位置错了"：**<br>> **师六三是"能力不够却抢了位置"（还有救——把指挥权交还九二）；**
> **解六三是"身份与位置根本不是一回事"（贞凶——只能下车）。**
> **两者的区别在于：前者可以通过让位解决，后者必须通过"承认我本来是负的那个人"来解决。** |

### 九四 · 解而拇

### 六五 · 君子维有解（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 君子维有解，吉；有孚于小人。 |
| **象传** | 君子有解，小人退也。 |
| **位属性** | 阴爻居阳位，**不当位**（震在上之律：五不当位），**但得中**且居尊位——**全卦卦主**；**直乘九四之上——乘刚**（震在上则六五必乘刚，验证通过）；**与九二相应**（九二正是那个"田获三狐、得黄矢"的人）。 |
| **判词 → 行动语义** | **吉** → **居尊位者亲自把它解开；解开之后小人自己退，连他们也验证了你的诚信** |
| **关键词解** | **维**＝① 通"唯"，**唯有**；② 系、维系。**本库取"唯有"为主义、兼取"维系"之意**：**君子唯有"解"这一件事可做**（一说：君子把那个维系着的结解开）。<br>**有孚于小人**＝**在小人那里也有了诚信**——两层可读：① **连小人也信服你**；② **你的诚信在小人身上得到了验证**（因为他们自己退了）。**本库取合读。**<br>**象传**：**小人退也**——**小人退去了。** |
| **⚠️ 本爻是全卦的枢纽，也是"赦过宥罪"这条纲领的边界所在（本卡最重要的一爻）** | **大象传说"赦过宥罪"（放下追责），而六五象传说"小人退也"（小人要退）。这两句放在一起，才是解卦完整的态度。**<br>**⚠️ 注意象传的语法："小人退也"——不是"退小人"，是"小人退"。** **君子做的动作只有一个字："解"；小人的退是这个动作的自然结果，不是君子额外去清算的结果。**<br>**⚠️ 这是本卦最精确、也最容易被读丢的一层**：<br>> **君子的动作：解（把那个结解开）。**
> **小人的反应：退（自己走）。**
> **君子不做的动作：追、罚、清算（大象传已经明令"赦过宥罪"）。**<br>**⚠️ 为什么"解"就能让小人退？** 因为**小人依附的是那个"结"，不是你**。**结一解开，依附就失去了着力点。** 而如果你不解结、只去打小人，结还在，新的小人还会来。<br>**⚠️ 这条口径可以直接用在组织管理上：想让搅事的人离开，正确动作不是处理人，是解开那个让他有价值的结构（那个含糊的授权、那条不清的利益线、那个没人敢碰的旧安排）。** |
| **⚠️ "有孚于小人"的读法（本爻最难的三个字）** | 按本库"孚"专题（需卦"有孚"、坎卦"有孚，维心亨"、兑九二"孚兑"、兑九五"孚于剥，有厉"），**"孚"是诚信、内在的真实。**<br>**⚠️ 而这里出现了一个刺眼的组合：把"孚"用在"小人"身上。** 兑九五刚刚警告过：**"孚于剥，有厉"——把诚信给了该剥落的对象，位置再正当也有危。**<br>**两处如何不冲突？** 分别在"给"与"验"：<br>> **兑九五是"孚于剥"——主动把诚信投给正在剥损你的对象（继续供血）→ 有厉。**
> **解六五是"有孚于小人"——你的诚信在小人那里得到了验证（他们自己退了，说明你这次解得干净）→ 吉。**<br>**⚠️ 判别标准很实用：你是在"给他信任"，还是"让他看清你不再给了"？** **前者是危，后者是吉。**<br>**⚠️ 落到动作上：解卦不要求你与小人翻脸（那违背"赦过宥罪"），它要求你把结解开，让他自己判断——而这份让他能自己判断的清楚，就是"有孚于小人"。** |
| **⚠️ 本爻是"六五乘刚"的第四例（本库该专题至此四例齐备）** | 规格第 4 节：**震在上则六五必乘刚。** 本库现有四例： |

| **本库"五爻专题"的新一例** | 已有十三例（乾九五利见大人、坤六五守臣节、蒙六五赤子之心、离六五痛哭、艮六五闭嘴、师六五选人放手、震六五守本职、巽九五申命、履九五位正当反厉、兑九五收回孚、咸九五感不到、恒六五必须自己判断、蹇九五承认大蹇）。<br>**⚠️ 解六五补上第十四种：居尊而只做"解"这一件事。** 它要主动放弃的特权是——**"清算"这个特权。**<br>**⚠️ 因为爻辞用了一个"维"（唯有）字：君子唯有"解"可做。居尊者在这个时刻手里有全部的追究权力，而《周易》只许他用其中最小的一项。** |
| **识别信号（若你是六五）** | ① 局面已经松开或正在松开，而你是最终拍板的人；② 你的名分不完全够（不当位），靠的是居中与众人认可；③ 下面顶着一个正在发力的强者（乘刚——九四）；④ 局面里有明显搅事、投机、依附而不出力的人；⑤ **⚠️ 你现在手上有完整的清算能力，而且很多人在等你清算**；⑥ 你在纠结"不处理他们，别人会觉得我软"。 |
| **该做** | **① 只做"解"这一件事**——把那个让他们有依附价值的结构解开（含糊的授权、不清的利益线、没人敢碰的旧安排），**写清楚、公开、一次做完**；<br>**② 执行大象传"赦过宥罪"**——**过一笔勾销，罪从宽处理，明确宣布不再追究旧账**；<br>**③ 让"退"自己发生**——不点名、不逼退、不做姿态；**④ 与九二对接**——**九二已经"田获三狐、得黄矢"（范围锁定、凭据在手），你的"解"要建立在它的那份凭据上，而不是建立在你的判断上。** |
| **不该做** | ① 借这次松动做一轮清算（那会把刚解开的重新绑上，而且会掉到六三"自我致戎"的因果里）；② 为了显得强硬而扩大处理范围（九二已经把范围锁在"三狐"上）；③ 反过来，为了显得宽厚而把位置继续留给他们——**⚠️ "小人退也"是象传写明的必要结果。赦过不等于留任。** |

### 上六 · 公用射隼（⚠️ 全卦最高判词，也是全卦唯一当位的爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 公用射隼，于高墉之上，获之，无不利。 |
| **象传** | 公用射隼，以解悖也。 |
| **位属性** | 阴爻居阴位，**当位**（震在上之律：上当位）——**全卦唯一当位的一爻**；居全卦之终、上震之顶；**与六三同性，失应**（全卦唯一失应的一对，另一头正是那个"负且乘"的六三）；**乘于六五之上，同性，不构成乘刚。** |
| **判词 → 行动语义** | **无不利**（按本库吉凶序：**元吉 ＞ 无不利／大吉 ＞ 吉 ＞ 利 ＞ 无咎**——**约等于大吉，是全卦最高判词**） → **把墙头上那只鹰射下来，事情才算真的解完** |
| **关键词解** | **公**＝公侯、有位者（对照大有九三"公用享于天子"、益六三"告公用圭"、益六四"告公从"）。**射**＝用箭射。**隼**（sǔn）＝**鹰隼，猛禽**——**是会俯冲下来抓东西的那种鸟**。**高墉**＝**高墙**（"墉"是城墙）。**获之**＝把它拿下了。<br>**悖**＝违逆、乖悖、不顺（与睽卦的"乖"同族）。**以解悖也**＝**用来解开那个乖悖。**<br>**⚠️ 意象要读准：隼停在高墙上——它不在天上，不在远处，就在你自家城墙的顶上，随时会扑下来。** |
| **⚠️ 本爻是全卦的收尾，而它给"解"补上了最后一步：除首恶** | **全卦五个正面动作的对象一路升级：狐（九二，几只搅事的）→ 拇（九四，粘在自己身上的旧牵累）→ 小人（六五，依附者，让他自己退）→ 隼（上六，那只会俯冲的猛禽，必须射下来）。**<br>**⚠️ 隼与狐、与小人都不一样**：**狐是狡（骗人的）、小人是附（依附的）、隼是猛（会主动扑下来伤人的）。**<br>**所以对隼的处理也不一样：狐是"获"（清掉）、小人是"退"（自己走）、隼是"射"（必须动手，而且要射死）。**<br>**⚠️ 这就是"赦过宥罪"那条纲领的最后一道边界：可以赦、可以宥、可以让他自己退，但对那只会俯冲的猛禽必须射。**<br>**⚠️ 而象传给的理由极准："以解悖也"——射它不是为了报复，是为了"解悖"（把那个乖悖解开）。** **动作是"射"，目的仍然是"解"。**<br>**⚠️ 结论（本爻最重要的一条）：解卦到最后动了武，但它的动机始终没有变成惩罚。这与噬嗑卦"利用狱"的分野极清楚——噬嗑的目的是"合"（咬开障碍以求合），解的目的是"解"（射掉首恶以求松开）。两卦都不以惩罚为目的。** |
| **⚠️ 本库"精准打击"专题的第四例（这一族的方法完全一致）** | **离上九**"王用出征，有嘉折首，**获匪其丑**"，判**无咎**——**只斩首恶，不牵连从众**；<br>**兑九四**"商兑未宁，**介疾有喜**"，判**有喜**——**只隔断病处，不动整片和气**；<br>**噬嗑六二**"噬肤灭鼻"（本库口径：**要提前把不追究的部分明说出来**）；<br>**解上六"公用射隼，于高墉之上，获之，无不利"，象传"以解悖也"——只射那一只，判词是四者中最高的"无不利"。**<br>**⚠️ 四例的方法完全一致：切口要小而准。而解上六的判词最高，原因在于它的目的最干净——它不是为了罚（噬嗑）、不是为了正邦（离）、不是为了保住和气（兑），它只是为了"解悖"。**<br>**⚠️ 可入库为通则：精准打击的判词高低，与打击力度无关，与目的纯度有关。** |
| **⚠️ "上爻用兵必须向内"通则的第三个样本（且是唯一给"无不利"的）** | 谦卡已立此通则：**凡上爻涉及用兵，打击方向必须是"向内"；向外扩张就是"不知止"。** 本库现有三例： |

> **解上六：一支箭，一只隼，一堵墙（最具体）→ 无不利。**<br>**⚠️ 实操推论：到了收尾阶段，"我要整肃内部"这种表述是不够的；必须能说出"具体是哪一个"。说不出来，就不要动手。** |

| **识别信号** | ① 整件事基本已经解开，你在收尾阶段、在最外围／最上位；② 但还有一个明确的、具体的、会主动伤人的对象没有处理（不是抱怨的人，不是有意见的人，是那个会扑下来的）；③ 这个对象就在你自己的范围内（高墉之上——不是外面，是你自家墙头）；④ 你倾向于"都过去了，就算了吧"；⑤ 或者反过来，你倾向于借这一箭把一批人都清一遍。 |
| **该做** | **① 把目标锁到一个**——说出具体是谁／是哪一件事，说不出就不动手；**② 动手，而且要"获之"**（拿下，不留半途）；**③ 守住"以解悖也"这个动机**——**这一箭是为了让局面顺过来，不是为了让谁付代价**；**④ 射完就收，不扩大**（参照离上九"获匪其丑"）。 |
| **不该做** | ① 以"赦过宥罪"为理由放过那只隼——**大象传管的是"过"与"罪"（已经发生的），上六管的是"悖"（正在违逆、还会扑下来的）。两者不是一回事。**<br>② 借这一箭扩大打击面（那就从"无不利"掉到离九四的"焚如"）；③ 只表态不动手（"获之"两个字要求结果）。 |

## 三、解卦定位速查表

### ⚠️ 核心表：解的五个动作 ＋ 一个反例（对象一路升级）

| 爻 | 动作 | 对象 | 对象的性质 | 判词 | 象传机制 |
|---|---|---|---|---|---|
| **初六** | **不动** | — | — | **无咎** | 刚柔之际，义无咎也（**理当无咎，别加动作**） |
| **九二** | **获** | **三狐** | **狡**——骗人、搅事的那几个 | **贞吉** | 得中道也（**范围准、凭据硬**） |
| **⚠️ 六三** | **（反例）** | **自己占的那个位置** | **错位**——负而乘 | **贞凶** | 自我致戎，又谁咎也（**祸是自己招的**） |
| **九四** | **解** | **拇** | **黏**——粘在自己身上的旧牵累 | **无判词** | 未当位也（**位不正，只能先卸载**） |
| **六五** | **解（结）** | **小人** | **附**——依附而不出力的 | **吉** | 小人退也（**解结，让他自己退**） |
| **上六** | **射** | **隼** | **猛**——会主动扑下来伤人的 | **无不利** | 以解悖也（**只射那一只，为解悖不为报复**） |

> **⚠️ 三条从这张表读出来的结论**：
> **① 对象性质决定处理方式，不能混用**：**狡者获（清掉）｜黏者解（松开）｜附者退（让他自己走）｜猛者射（必须动手）。** 用错方式的代价：**对附者动手＝违背"赦过宥罪"，会把解开的重新绑上；对猛者宽宥＝隼还在墙头上。**
> **② 判词随对象具体化而升高**：无咎 → 贞吉 →（凶）→ 无判词 → 吉 → 无不利。**越到后面，动作越具体、目标越单一、判词越高。**
> **③ 唯一的凶不在"处理别人"上，在"自己占了不该占的位置"上**（六三）。**解卦的风险不是解得不干净，是趁着松动给自己捞了一个坐不住的位置。**

### 全爻速查

| 爻 | 角色 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | 最下位者 | 无咎 | 刚出现松动，你想赶紧抓住机会做点什么 | 不当位·坎在下·**有应** | **无咎**·什么都不做·"义无咎也" |
| 九二 | **实际操作者** | 田获三狐 | 你在处理这件事，自己也还在险里 | 不当位但**得中** | **贞吉**·范围锁死·拿到硬凭据 |
| **六三** | **⚠️ 位不配德者** | 负且乘 | 松动期你拿到一个坐不住的位置，还想用勤勉坐实 | **不当位·失中·乘刚·失应** | **贞凶**·不可入·**下车** |
| 九四 | 有力量的推动者 | 解而拇 | 你身上拖着一个旧牵累，新伙伴一直没真靠过来 | 不当位（**象传点名**）·四多惧 | **无判词**·解掉牵累·朋至斯孚 |
| 六五 | **卦主·居尊** | 君子维有解 | 你手上有完整的清算权，很多人等你清算 | 不当位但**得中居尊**·**乘刚** | **吉**·只做"解"·**赦过宥罪**·小人自退 |
| 上六 | 收尾者 | 公用射隼 | 基本解完了，但墙头上还有一只会扑下来的 | **当位**（全卦唯一）·失应 | **无不利**·射那一只·以解悖也 |

**解卦三句话**：
1. **解不是你解开的**（彖传"**天地解而雷雨作**"）。**大势先松，雷雨才作，草木外壳才裂（甲坼）。** 你能做的只有三件事：**判断它松了没有、该走就快走（夙吉）、没处去就回本位（其来复吉）。**
2. **解开之后必须"赦过宥罪"**（大象传）——**主动结束追责，因为追责会把刚松开的东西重新绑紧。** **但"赦"有边界，且边界是本卦自己写的：小人要退位（六五"小人退也"），首恶要射下（上六"射隼获之"）。**⚠️ **放下追究 ≠ 恢复授权。**
3. **⚠️ 解卦唯一的凶不在"解得不够"，在"趁着松动坐上了坐不住的位置"**（六三"负且乘，致寇至，贞凶"）。**系辞传把话说到了底："盗之招也"——强盗是你自己招来的。**

**本卦最反直觉的四条**：
- **⚠️ 全卦只有一爻当位（1／6，本库最低之一），而它是"解脱"之卦；它的覆卦蹇卦五爻当位，卦德是"难"。** **六爻的阴阳一个没变，只是倒过来读。这是本库"当位≠顺遂"最硬的一对样本。**
- **⚠️ 本卦同时踩在本库"六条最危险位置"的两条上（坎在下＋震在上），却叫"解"。** 因为彖传的九个字：**"险以动，动而免乎险"**——**"动在头顶、你做不了主"这件事，在你需要被松开的时候恰恰是唯一的出路。**
- **⚠️ 九五的位置在本卦并不特殊，全卦最高判词给了上六。** 而上六是全卦唯一当位的爻——**但它的"无不利"不来自当位，来自它做的事：一支箭、一只隼、一堵墙（目标最具体）。**
- **⚠️ 九四要解掉的"拇"，正是它自己的应爻（初六）。** **在《周易》里"相应"通常是好事，本爻是本库第一处明确要求"解掉自己的应爻"的地方**——而回报是"朋至斯孚"：**旧牵累不腾开，新关系就永远立不起来。**

| 大象传 | **反身修德**（转向自己） | **赦过宥罪**（放下追究） |
| 「往」的判定 | **四爻判"往蹇"**——往则难 | **"有攸往，夙吉"**——往则要快 |
| 判词谱 | 誉／终无咎／反／连／（无）／**吉** | 无咎／**贞吉**／**贞凶**／（无）／**吉**／**无不利** |
| 最高判词 | **吉**（一处） | **无不利**（高于吉） |
| 唯一的凶 | **无** | **贞凶**（六三） |
| 一句话 | **位最正，却走不动** | **位最不正，却出得来** |

> **⚠️ 结论（建议直接补入索引第五节，与"坎在上／在下"通则并列）**：
> **① "当位数"是结构指标，不是吉凶指标。** 它高，只说明这一卦的爻多数落在与自己阴阳相符的位上；一卦是难还是顺，由卦德与爻辞决定。
> **② 一对覆卦的当位数必然相加为 6，且逐爻互补**（证明见蹇卡）。**所以本库此前记录的三组"4↔2"（同人／大有、谦／豫、咸／恒）不是那三对卦的性格，而是数学必然。**
> **③ ⚠️ 与此对照，覆卦的"应爻结构"完全不变。** 机械核对：覆卦把第 *i* 位换到第 *7−i* 位，**而应爻的三对（初↔四、二↔五、三↔上）在这个映射下作为集合被保留**（(1,4)↔(3,6)、(2,5)↔(2,5)）；两爻的阴阳都不变，所以每一对的"应／不应"状态也不变。
> **实证：蹇是二应一不应（失应的是初六↔六四）；解也是二应一不应（失应的是六三↔上六）。**
> **⚠️ 由此得出一条可入库的读卦法：一对覆卦之间，"当位"全部翻转，"应"完全保留。**
> **所以判断一对覆卦的性格差异，要看应爻结构里那对"不应"落在了哪儿，而不是数当位。**
> **本例：蹇的失应落在初／四（开头没人接，所以"宜待"）；解的失应落在三／上（招祸的和收拾祸的接不上，所以六三"贞凶"、上六必须"射隼"）。**

### 2. 解是"坎在下"的第六个样本，本库该族至此六卦齐备

坎卡第四节的总表原有六行（蒙、讼、师、坎、屯、需、比），此后困卡、涣卡各补一行。**本卡把"坎在下"这一族补齐**：

| 卦 | 卦象 | 上卦是什么 | 险的性质 | 本库口径 |
|---|---|---|---|---|
| **蒙 4** | **下坎**上艮 | **艮（止）** | 起步即险，且被压住不许动 | **童蒙求我**——只能向上求（全卦仅 1 爻当位） |
| **讼 6** | **下坎**上乾 | **乾（刚）** | 起步即险，对面是绝对强者 | **作事谋始**——中吉终凶，全卦仅九五当位 |
| **师 7** | **下坎**上坤 | **坤（顺）** | 起步即险，不得已而战 | **容民畜众**——卦辞只给"贞" |
| **困 47** | **下坎**上兑 | **兑（悦）** | 起步即险，且要对人保持和顺 | **险以说**——不只承受，还要悦（困卡语） |
| **涣 59** | **下坎**上巽 | **巽（入）** | 起步即险，队形还散了 | **以顺而入**——收拾散局靠"渗"不靠"抓" |
| **解 40** | **下坎**上震 | **震（动）** | **起步即险，而头顶正在动** | **⚠️ 险以动，动而免乎险**——**唯一一个"险在下而能出来"的** |

> **⚠️ 本卡给"坎在下"这条通则补的关键限定**：
> **坎卡的原口径是"坎在下 → 你已经在险里，求小得、勿加深"。这条口径对蒙、讼、师、困、涣全部成立（五卦的下三爻判词都压得极低）。**
> **⚠️ 而解卦是唯一的例外，原因完全在上卦：只有解卦的上卦是震（动）。**
> **蒙的上面是艮（压住）、讼的上面是乾（更强）、师的上面是坤（顺）、困的上面是兑（要和悦）、涣的上面是巽（慢渗）——五者都没有把人拔出来的力量。**
> **只有震有：雷雨一作，硬壳自己就裂了（彖传"甲坼"）。**
> **⚠️ 由此得一条完整口径（建议入库）：坎在下时，你能不能出来，完全由上卦决定。**
> **上艮 → 出不来，只能求（蒙）｜上乾 → 出不来，只能及早止损（讼）｜上坤 → 出不来，只能顺着打（师）｜上兑 → 出不来，还要对人和悦（困）｜上巽 → 慢慢渗出来（涣）｜⚠️ 上震 → 能出来，而且不是靠你（解）。**
> **这与恒卡的"四位向下看"通则合成一条总纲：下卦决定你能不能动，上卦决定你能不能出去。**

**⚠️ 顺带一条经文核实修正（建议同步到索引与涣卡）**：
**涣卡第四节末尾有一句"也是'坎在下'七卦之一（坎在下：屯 3、需 5、蹇 39、井 48、涣 59、解 40、未济 64 等）"。**
**⚠️ 该列表有误。** 机械核对：**屯 3（上坎下震）、需 5（上坎下乾）、蹇 39（上坎下艮）、井 48（上坎下巽）四卦都是坎在上，不是坎在下。**<br>**⚠️ 涣卡该处已于本轮修订**（涣卡第 291 行已改为正确名单，并注明判据指向知识卡65）。
**"坎在下"的正确名单是八卦**：**蒙 4（上艮）、讼 6（上乾）、师 7（上坤）、解 40（上震）、困 47（上兑）、涣 59（上巽）、未济 64（上离）、坎 29（上坎，两律同时成立）。**
**"坎在上"的正确名单是八卦**：**屯 3（下震）、需 5（下乾）、比 8（下坤）、蹇 39（下艮）、井 48（下巽）、节 60（下兑）、既济 63（下离）、坎 29（下坎）。**

### 3. ⚠️ 对"震在上＝动在头顶（你做不了主）"这条通则的重要修订

本库六大危险位置里有一条：**"震在上＝动在头顶（你做不了主）"**（震卡第四节立，艮卡、巽卡、兑卡、索引第五节均转录）。

**⚠️ 解卦是这条通则的第一个明确反例，而且反得很彻底**：

| | 震在上，且是坏事 | 震在上，且是好事 |
|---|---|---|
| **样本** | **震 51**（上震下震：余震不断，九四"遂泥"）<br>**恒 32**（上震下巽：上六"振恒，凶"，居上而摇动）<br>**豫 16**（上震下坤：九四不当位而为卦主，六五"贞疾"无解） | **⚠️ 解 40**（上震下坎：**"险以动，动而免乎险"**）<br>**大壮 34**（上震下乾：九四"藩决不羸，贞吉悔亡"——势到，藩自己开了） |
| **共同结构** | 九四必不当位、六五必不当位且乘刚、上六当位 | 同 |
| **差别** | **你需要自己做主，而动在头顶** | **⚠️ 你需要的恰恰是"被松开／被推着走"** |

> **⚠️ 修订后的完整口径（建议替换索引第五节的原表述）**：
> **"震在上＝动在头顶，你做不了主。"**
> **⚠️ 这句话是中性的结构描述，不是负面判词。它的吉凶取决于你此刻需要的是什么：**
> **① 若你需要自己拍板、需要稳定（恒、豫）→ 动在头顶是灾：你的方向被别人摇动，六五乘刚且无解（豫六五"贞疾，恒不死"）。**
> **② ⚠️ 若你需要的是被松开、被推出去（解）→ 动在头顶是唯一的出路：解不是你解开的（"天地解而雷雨作"），正因为那个动不由你发起，它才能把你从险里带出来。**
> **③ 若你自己也有势（大壮下乾）→ 动在头顶与你的势合流，藩自己就开了。**
> **⚠️ 实操判据：先问"我现在缺的是主导权，还是缺一个外力？"缺主导权，震在上是灾；缺外力，震在上是救。**

**⚠️ 这条修订的价值在于它同时救回了另一条通则的准确性**：本库原来把"六条最危险的位置"当成负面清单直接用于"定势"。**解卦证明这份清单必须加一句总限定：**
> **这六条描述的是"结构上的困难"，不是"结局上的坏"。困难是不是坏，取决于卦德要你做什么。**
> **最干净的证据就是解卦：它同时踩了两条（坎在下＋震在上），六爻只有一爻当位，而它是"解脱"之卦，判词谱高于它那个五爻当位的覆卦。**

### 4. ⚠️ 蹇／解这一对为本库"当位"判据提供了唯一的经文级三重背书

**全书传文（彖传＋小象传）直接使用"当位／未当位"字样的地方极少。而蹇、解这一对覆卦之内出现了三次——全书仅此一对**：

| 出处 | 原文 | 它在说什么 | 与本库结构律核对 |
|---|---|---|---|
| **蹇 39 彖传** | **当位贞吉**，以正邦也 | **为整卦下判**：因为当位，所以"贞"能"吉"，还能正邦 | **蹇 5 爻当位（艮在下→二三当位；坎在上→四五上全当位）** ✓ |
| **蹇 39 六四 小象** | 往蹇来连，**当位实也** | **为单爻下判**：这一爻位置正当且有实内容，所以有资格去"连" | **坎在上→四当位** ✓ |
| **解 40 九四 小象** | 解而拇，**未当位也** | **为单爻下判**：这一爻位置不正，所以只能先卸载 | **震在上→四不当位** ✓ |

> **⚠️ 结论（建议补入规格第 4 节的开头）**：
> **本库"当位"这个判据不是后人加的解释框架，它是《周易》传文自己在用的语言。**
> **蹇卦彖传用它给整卦下判（"当位贞吉"），蹇六四小象用它给单爻下判（"当位实也"），解九四小象用它下反向的判（"未当位也"）——三处与本库第 4 节的机械推导结果完全一致，无一例外。**
> **⚠️ 这一条与咸卡的发现（咸彖传"止而说"直接对应"艮在下＋兑在上"）、困卡的发现（困卦六三"乘刚也"、九四"未当位也"与机械推导完全一致）合成本库最重要的一条方法论背书：**
> **爻位／当位／乘刚这套分析不是外加的框架，是经文自己在用的语言；本库的机械规则只是把它系统化了。**

**⚠️ 但必须同时守住蹇／解这一对给出的限定**：**传文用"当位"来解释"为什么这一爻能做这件事"，从不用它来许诺"这一爻会顺"。** 蹇卦五爻当位而全卦讲"难"，就是这条限定最硬的证据。

### 5. ⚠️ "赦过宥罪"补上本库司法／追责链条的最后一环（三卦对读）

本库此前的司法与追责主线是两卦：**讼 6（当事人视角：该不该争）与噬嗑 21（执法者视角：该不该罚、罚多重）**。噬嗑卡明确写道："**'司法'在本库不是一个领域，是两个。**"

**⚠️ 解卦补上第三个，也是这条链条的终点：追责什么时候必须停。**

| | **讼 6（天水讼）** | **噬嗑 21（火雷噬嗑）** | **解 40（雷水解）** |
|---|---|---|---|
| **你是谁** | **当事人**（在争） | **执法者**（在罚） | **⚠️ 局面解开之后的决策者**（在收尾） |
| **卦象** | 上乾下坎 | 上离下震 | 上震下坎 |
| **卦辞** | 有孚窒惕，**中吉终凶**，利见大人，不利涉大川 | **亨。利用狱** | 利西南，无所往其来复吉，**有攸往夙吉** |
| **大象传（主语）** | **君子以**作事谋始 | **先王以**明罚敕法 | **君子以**赦过宥罪 |
| **纲领的时点** | **事前**（起头就把边界谈清） | **事前**（动手前把罚则挂出来） | **⚠️ 事后**（局面解开的那一刻） |
| **核心动作** | **谋始**——把边界写在开头 | **明罚敕法**——先立标准再咬 | **⚠️ 赦过宥罪**——过赦免、罪从宽 |
| **最高位在做什么** | 九五**元吉**：中正裁决、案结事了 | 六五**贞厉·无咎**：只求一个"当" | 六五**吉**：**只做"解"，让小人自己退** |
| **一句话** | **你赢了也是输** | **你办成了也不光荣** | **⚠️ 你解开了，就必须停手** |

> **⚠️ 三卦合读得出的完整链条（建议补入索引路由表）**：
> **争（讼）→ 罚（噬嗑）→ ⚠️ 停（解）。**
> **本库此前只有前两段，所以路由表回答不了一个极高频的困境："事情已经过去了，我还该不该追究？"**
> **解卦大象传"赦过宥罪"是这个问题唯一的经文答案，而且它把力度分了两档：过（无心之失）＝赦（一笔勾销）；罪（有心之恶）＝宥（从宽，但仍处理）。**

**⚠️ 而这条链条与本库那条反复出现的铁律如何不冲突？——这是本卡必须解决的一个疑点。**

本库已有一条最硬的铁律，出现过至少五次：
**蒙卦"蒙以养正"（绝不能把一身本领交给无德之人）／师上六"小人勿用，必乱邦也"（赏错了人，赢了的仗也会输掉）／比卦"原筮，元永贞"（归附前必须反复审断对象）／兑九五"孚于剥，有厉"（诚信给错人，位正当也有危）／恒九三"不恒其德…无所容也"（德不连续的人，别人的长期安排里没有他的位置）。**

**⚠️ 而解卦说"赦过宥罪"。表面看，这与"小人勿用"直接冲突。**

**⚠️ 冲突是假的，而且解卦自己就把话说完了**：

| 层面 | 解卦怎么说 | 出处 |
|---|---|---|
| **追究** | **停止**——过赦免、罪从宽 | **大象传"赦过宥罪"** |
| **位子** | **必须退**——而且是他自己退 | **六五象传"小人退也"** |
| **首恶** | **必须除**——一支箭，一只隼 | **上六"公用射隼…获之，无不利"** |

> **⚠️ 由此得出本卡最重要的一条口径（建议直接入库为通则）**：
> ### **放下追究 ≠ 恢复授权。**
> **"赦过宥罪"管的是"要不要继续算账"——答案是不要，因为算账会把刚松开的重新绑紧。**
> **"小人勿用"管的是"要不要继续给他权力"——答案是不给，因为"必乱邦也"。**
> **⚠️ 两句话管的是两件事，所以可以同时成立，而且必须同时执行：不再算旧账（解），但不再给位子（师）。**
> **⚠️ 缺任何一半都会出事：只赦不退 → 隼还在高墉上（上六未射）；只退不赦 → 追责没完，"解"被自己取消掉（掉回噬嗑，甚至掉到六三"自我致戎"）。**

**⚠️ 与噬嗑用刑序列的精确分工**：
噬嗑卡立了一条铁律：**"刑要止在'止其行'，不要走到'灭其耳'"**（初九"灭趾，不行也"是最经济的刑；上九"灭耳，聪不明也"是全卦唯一的凶）。
**⚠️ 解卦给这条序列补上了它的出口**：**噬嗑管"从哪里开始罚"，解管"到哪里停下"。**
> **噬嗑初九：在最微处施最轻之刑（把路截住）。**
> **噬嗑九四：咬最硬的一口，拿到金矢（艰贞则吉，但未光）。**
> **噬嗑六五：只求一个"当"（贞厉，无咎）。**
> **⚠️ 解 40 大象传：局面一解开，赦过宥罪——罚的序列在这里终止。**
> **⚠️ 解上六：唯一的例外是那只会俯冲的隼——射之，而且动机仍是"解悖"，不是罚。**

### 6. 本卦对"乘刚"、"贞凶"、"纯判词爻辞"三个专题的补充

| 专题 | 本卡补的内容 |
|---|---|
| **⚠️ 乘刚（本库此专题的正源）** | **解六三是全书唯一一条爻辞正文里就写着"乘"字的爻**（"负且乘"），**而系辞上传专门解释了这个"乘"字："乘也者，君子之器也；小人而乘君子之器，盗思夺之矣。"**<br>**⚠️ 由此给本库"乘刚"补上本义层**：**"乘"＝坐车＝占据一个原本属于更有分量者的位置。所以"乘刚"不只是位置关系，它自带价值判断。**<br>**⚠️ 这解释了为什么本库现有的乘刚解法（收缩范围／交付成果／推行规矩／守住本职／辨明职分／主动放手／横向连结／跟从／解开）没有一个是"顶回去"——乘刚者的问题从来不是力量不足，是"这个位置本来不该是我的"。**<br>**⚠️ 并且它给出了乘刚的两种命运：承认错位并缩小自己 → 可解；不承认、继续坐着 → 解六三"贞凶"。**<br>**⚠️ 解六五补上"六五乘刚"的第四个解法：解（把结解开，让依附者自己退），且它是四例中判词最高的（吉）。** |
| **⚠️ "贞凶"家族的第五例，也是最直白的一例** | 现有四例：**师六五"弟子舆尸，贞凶"（用错了人）／巽上九"丧其资斧，贞凶"（到顶而一味顺）／恒初六"浚恒，贞凶"（开头就求深）／恒六五"从妇凶"（该断的人一味跟从）。**<br>**解六三"负且乘，致寇至，贞凶"补上第五例，而且它是唯一一个把"错位"直接画成图像的**：**背上背着东西，人却坐在车上。**<br>**⚠️ 五例的共同点（可入库为通则）："贞凶"专门针对品德没问题的人。五处全部是"职分与动作／位置错配"，而不是德行有亏。所以看到"贞凶"，第一诊断动作是查职分与位置，不是查品德。** |
| **⚠️ "纯判词爻辞"家族至此三例齐备** | **大壮 34 九二"贞吉"（象传"以中也"）／恒 32 九二"悔亡"（象传"能久中也"）／解 40 初六"无咎"（象传"刚柔之际，义无咎也"）。**<br>**⚠️ 通则：当《周易》把一条爻辞压缩到只剩一个判词时，它的意思是"这一爻没有动作可做"；而象传会告诉你不需要动作的原因，三处理由全部是结构性的（得中／久中／刚柔之际）。**<br>**⚠️ 实操：读到这种爻，正确反应是"把手放下"，而不是"去找一个动作"。** |
