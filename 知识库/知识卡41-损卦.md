# 知识卡 41 · 损卦（山泽损）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："缓必有所失，故受之以损。"——上一卦（解 40）讲"缓"（松开、解脱）；**东西一松开，必然有所失落，于是进入损。** ⚠️ **注意这条因果：损不是失败带来的，是"解开"带来的。** 局面一松，原来绑在一起的东西就要少掉一些。
> **本卦与益卦（42）是一对，且是结构上的倒转（覆卦）**：损六爻自下往上"阳阳阴｜阴阴阳"，整卦上下颠倒即得益卦"阳阴阴｜阴阳阳"。**损讲减，益讲增。两卦必须合读，而且它们的彖传是一对反话**（损"损下益上"／益"损上益下"，详见第四节第 1 条）。
> ⚠️ **本卦最容易被误读的地方，大象传一句话就堵死了**："山下有泽，损。**君子以惩忿窒欲**。"——**损的第一对象是自己的忿与欲，不是别人、不是预算、不是人手。** 全库"减"这个动作的正当起点在此（第四节第 6 条）。
> ⚠️ **本卦是"损到什么程度该停"唯一的经文依据**：**六三"三人行，则损一人"（减到成对就停）＋ 九二／上九两处"弗损益之"（同一句四个字，两种判词）。** 详见第四节第 3 条。
> ⚠️ **本卦是"兑在下 → 六三必不当位且乘刚"这条律的第四次验证，也是唯一一次例外**：**前三例（履六三、兑六三、睽六三）的小象传全部写着"位不当也"且结局极差；损六三的小象传偏偏不提位，改说"三则疑也"，而且全爻没有判词。** 详见第四节第 4 条。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 损 · 第四十一卦 |
| **卦象** | 上艮（山／止）下兑（泽／悦），称"山泽损"。**山下有泽**——**泽在山下，水往下渗，山上的土被一点点冲减下去；也可以读成：泽越深，山就显得越高（损下而益上）。**<br>**六爻自下而上：阳、阳、阴｜阴、阴、阳。**<br>**按本库第 4 节结构律逐爻核定**：**兑在下 → 初九当位、九二不当位（得中）、六三必不当位**；**艮在上 → 六四当位、六五不当位（得中居尊）、上九不当位**。<br>**⚠️ 合计只有初九、六四两爻当位（2／6）。**（公式核对：当位数 ＝ 3 ＋ d(下卦) − d(上卦)，d 值 离 3｜乾震艮 2｜坤巽兑 1｜坎 0 → **3＋1−2＝2** ✓）<br>**⚠️ 逐爻核查乘刚**：**六三直乘九二之上——乘刚**（兑在下则六三必乘刚，见咸卡第四节新增的结构事实；随卡已把机械规则写全："震、离、坎、兑四卦各内造一个乘刚"）。**六四乘于六三之上，同性；上九在六五之上，是阳，不构成乘刚。全卦只有一处乘刚。**<br>**⚠️ 应爻核查**：初九↔六四（阳／阴，**应**）；九二↔六五（阳／阴，**应**）；六三↔上九（阴／阳，**应**）。**⚠️ 三对全应——损卦是"全应卦"。** |
| **⚠️ "全应"这件事是本卦的定性（本库读卦法的又一次验证）** | 恒卡立过一条读卦通则：**"先数应爻。三对全应＝这一卦讲'相与'；三对全不应＝这一卦讲'自处'。"**（八纯卦全不应，靠自己；咸、恒、泰、否全应，讲关系。）<br>**⚠️ 损卦与益卦都是全应卦，逐对可验。**<br>**这一条直接给出了损／益的领域定性：损与益从头到尾讲的都是"两方之间的给与取"，不是一个人的收支。**<br>**⚠️ 所以本卦所有"减"的动作都有一个对象在另一头**：初九减了给上面（"已事遄往"）、六三是被减掉的那一个、六五是受益的那一个、上九是本该继续拿却停手的那一个。**读损卦第一件事是先问："我这一减，是减给谁？"** |
| **⚠️ "上艮下兑"的定势含义** | 本库两条现成的结构律叠在本卦：<br>**① 兑在下＝易落入讨好的陷阱**（兑卡第四节："'来兑，凶'这个陷阱只在兑居下卦时出现"；且**兑在下则六三必不当位**）；<br>**② 艮在上＝被压住不许动**（艮卡：有人在上面压着你）。<br>**⚠️ 两条叠起来正是"损"的处境：自己这边是"悦"（想让人满意、想维持关系），上面又压着一座山（不许动、必须承受）——于是只剩下一条路：减自己。**<br>**⚠️ 而这正是大象传"惩忿窒欲"的结构理由**：**下兑（悦／欲）是要被"窒"的那个东西，上艮（止）是那个"窒"的动作。** **山压在泽上，把泛滥的水面按住——这就是"窒欲"的字面画面。**<br>**⚠️ 由此可以给"兑在下＝讨好陷阱"这条律补一条正面用法**：**兑在下的那份"悦"，用来向外讨好是六三的"来兑，凶"（兑 58）；用来向内自省、承认"我这里有过多的欲"，就是损卦的"窒欲"。同一个下兑，向外是陷阱，向内是本卦的起点。** |
| **领域定义** | **主动做减法**。① 削减预算、砍项目、关业务线、裁掉不产出的部分；② 降低自己的开支、欲望、生活标准（主动降级）；③ 精简团队、精简流程、精简产品功能；④ 从一个多人的局面里减掉一个人（合伙人退出、团队缩编、朋友圈收缩）；⑤ 上供、进献、把自己的资源交给上面／整体（交税、上缴、给公司让利、给家里出钱）；⑥ **⚠️ 以及本卦真正的起点：减自己的脾气与贪欲**（大象传"惩忿窒欲"）。<br>**凡是"我要主动去掉一些东西"，都落在损卦。** |
| **不归本卦的情况** | ① **要增、要给、要投入** → **益卦（42）**。**这一对必须先分清方向，判据见第四节第 1 条与益卡的"何时减／何时增"对照表。**<br>② **要主动停下来、退出、不再继续** → **艮卦（52）**。**⚠️ 分界线很实用：艮是"不干了"（停止这件事），损是"还干，但规模减小"（减少投入）。** 判错的代价：该艮的做成损，会一直减到没有还在做；该损的做成艮，会把还有价值的整条线砍掉。<br>③ **已经有实力，要摆位置、要分配** → **谦卦（15）**。**⚠️ 谦与损最容易混**：**谦的大象传是"裒多益寡，称物平施"（减多的补少的，横向公平分配）；损的彖传是"损下益上，其道上行"（下面减，给上面）。** **谦是横着分，损是竖着交。**<br>④ **不是主动减，是被剥落、被一层层削掉** → **剥卦（23）**。**损是你自己动手，剥是别人／大势在剥你。**<br>⑤ **资源已经枯竭、无可再减** → **困卦（47）**。<br>⑥ **顺境中要治理、要修剪** → **泰卦（11）**（大象传"财成天地之道，辅相天地之宜"）。**⚠️ 而损卦在传统卦变里正是从泰卦来的**（详见第四节第 5 条）。 |
| **"损"字本义** | **减少、亏损、损害**。《说文》"损，减也"。<br>**⚠️ 但本卦的"损"是一个及物动词，而且是主动语态：是"我去损某样东西"，不是"我被损了"。** 全卦六爻的"损"字全部如此：**"酌损之"（初九，斟酌着减它）、"弗损益之"（九二、上九，不减它而是增它）、"则损一人"（六三，减掉一个人）、"损其疾"（六四，减掉那个病）。**<br>**⚠️ 六处"损"字，五处带宾语。这是本卦最重要的一条读法：损必须有明确的对象。** **说"我要节省一点"不算损卦；说"我要砍掉这三项"才是。** |
| **卦辞原文** | 损：有孚，元吉，无咎，可贞，利有攸往。曷之用？二簋可用享。 |
| **⚠️ 卦辞的关键结构** | **⚠️ 判词极其丰厚：元吉、无咎、可贞、利有攸往——四项，而且带头的是全书最高判词"元吉"。**（对照：**师卦只给"贞"｜艮卦只给"无咎"｜蹇卦无亨｜坎卦只给"维心亨"**。）<br>**① 唯独没有"亨"。** 按本库口径这很好理解：**"亨"是通达；而"损"这个动作本身不制造通达，它只是把多余的去掉。通不通要看减完之后的事。**<br>**② ⚠️ "元吉"挂着一个前提，而且前提写在最前面："有孚"。** 按本库判词口径：**"元吉通常带附加条件，必须指出条件是什么。"** **本卦的条件就是两个字：有孚（有真实的诚信）。**<br>**彖传把这个挂钩写得更死："损而有孚，元吉。"——不是"损，元吉"，是"损而有孚，元吉"。**<br>**⚠️ 落到实操：减法要想拿到"元吉"，唯一的门槛是"你减得是真的、说得是真的"。** **虚减（账面上减、对外宣布减而实际没减）、偷减（不告诉对方就减）都不"有孚"，"元吉"立刻作废，只剩一个动作本身。**<br>**③ ⚠️ "曷之用？二簋可用享"是全书极罕见的一处自问自答。**<br>**曷**＝何、什么。**曷之用**＝**（那么）用什么来行祭呢？** **簋**（guǐ）＝盛食物的礼器。**二簋**＝**只用两簋**（正常祭礼的规格远高于此）。**享**＝祭献。<br>**⚠️ 全句：那用什么祭呢？两簋就可以拿去祭了。**<br>**这是《周易》给"减到什么程度"的第一个刻度，而且它选的场景是最不该省的那个——祭祀。** **连祭天祭祖都可以只用两簋，那还有什么不能减？**<br>**⚠️ 但彖传立刻加了限定，而且这条限定是全卦最重要的一句："二簋应有时。"——两簋是有时候才可以的。** 详见彖传要点。 |
| **卦辞现代解** | **有孚**——**减必须是真减、明减**。真实的数字、真实的告知、真实的自己也在减。**这是"元吉"唯一的门槛。**<br>**元吉**——根本性的圆满（**附条件：有孚**）。<br>**无咎**——没有灾。<br>**可贞**——**"可以守持"**：注意不是"利贞"（守正有益），是"可贞"（这条路守得住）。**语气比"利贞"更收，符合"损"的性格：它不许诺好处，只说这条路站得住。**<br>**利有攸往**——**减完之后适宜往前走**。**⚠️ 这四个字很重要：损不是终点，减完是要动的。** 与益卦卦辞的"利有攸往"完全同文——**一对反向的卦，卦辞末尾给了同一句话：减完要走，增完也要走。**<br>**曷之用？二簋可用享**——**规格可以降到最低，只要那份诚（孚）在。** 落到现代：**该给的心意不能少，该花的排场可以砍到底。** |
| **彖传** | 损，损下益上，其道上行。损而有孚，元吉，无咎，可贞，利有攸往。曷之用？二簋可用享。二簋应有时，损刚益柔有时。损益盈虚，与时偕行。 |
| **⚠️ 彖传要点（本卦机制全在这四句里，最后一句是全库级的）** | ① **"损下益上，其道上行"**——**减下面，给上面；它的路是往上走的。**<br>**⚠️ 注意《周易》在这里的措辞极其中性，既不赞成也不反对。** **而它的覆卦益卦，彖传说的是"损上益下，民说无疆；自上下下，其道大光"——同样的句式，一个只说"其道上行"，一个说"其道大光"。**<br>**⚠️ 一个"上行"、一个"大光"，《周易》的偏好已经说完了**（详见第四节第 1 条）。<br>② **"损而有孚，元吉"**——**"元吉"的条件是"有孚"，不是"损"。**<br>③ **⚠️ "二簋应有时，损刚益柔有时"（本卦最实用的一句）**——**两簋是"有时"才行的；损刚益柔也是"有时"才行的。**<br>**"应有时"＝要看时候。** **《周易》先给了"二簋可用享"这个极端刻度，紧接着自己收回一半：这个刻度只在某些时候成立。**<br>**⚠️ 这一句是对"极简主义"的直接限定：把规格降到最低是一种时机性的动作，不是一条永远正确的原则。** **平时用二簋是俭，该用大礼时用二簋就是失礼。**<br>④ **⚠️⚠️ "损益盈虚，与时偕行"（全库级的一句）**——**减、增、满、空，都跟着时机一起走。**<br>**⚠️ 而益卦彖传的结句是"凡益之道，与时偕行"——同样的四个字。**<br>**⚠️ 这是《周易》对"该减还是该增"这个问题给出的唯一答案，而且它把答案给在了两卦的同一个位置上：不是看你想不想，不是看东西多不多，是看时。** 详见第四节第 1 条。 |
| **大象传（行动纲领）** | 山下有泽，损。君子以惩忿窒欲。 |
| **⚠️ "惩忿窒欲"解（本卦最高层原则，也是本卦最容易被跳过的一条）** | **惩**＝惩戒、克制、把它压下去。**忿**＝忿怒、火气。**窒**＝堵塞、塞住。**欲**＝欲望、贪求。<br>**⚠️ 全句：君子用它来克制自己的火气、塞住自己的贪欲。**<br>**⚠️ 这是本卦全部义理里最关键的一处，因为它规定了"损"的第一个对象**：<br>> **一个讲"减"的卦，它的行动纲领没有一个字提到钱、人、项目、资源。它只说两样东西：忿与欲。**
> **⚠️ 结论：损的第一对象是自己的忿与欲，不是别人，也不是预算。**<br>**⚠️ 为什么必须先减这两样？因为它们正是让"减"这个动作变形的两个东西**：<br>**带着"忿"去减 → 减法变成清算**（"我早就想砍掉这块了"）；<br>**带着"欲"去减 → 减法变成算计**（减别人的、留自己的，即彖传的"损下益上"被用私了）。<br>**⚠️ 结构上的理由也很干净**：**下兑是"悦／欲"，上艮是"止"。山压在泽上，正是用"止"去按住那片泛滥的水面。忿与欲都在下面（在你自己这一边），要止的东西也在下面。**<br>**⚠️ 本库同族纲领对照（"对自己下的指令"这一族至此五条）**：<br>**坎 29「常德行习教事」（做）｜震 51「恐惧修省」（查）｜艮 52「思不出其位」（收）｜蹇 39「反身修德」（转）｜⚠️ 损 41「惩忿窒欲」（减）。**<br>**⚠️ 五条纲领没有一条指向外部。而损卦补上的是最具体的一条：它点名了要减的两样东西。** |
| **总铁律** | ① **减必须有明确对象**（六处"损"字五处带宾语）——**"我要节省一点"不是损卦，"我要砍掉这三项"才是。**<br>② **第一个减的对象是自己的忿与欲**（大象传）。**带着火气减＝清算；带着贪欲减＝算计。**<br>③ **"元吉"的门槛只有一个："有孚"**（卦辞＋彖传）——**真减、明减、自己也在减。**<br>④ **⚠️ 减到成对就停**（六三"三人行，则损一人"，象传"一人行，三则疑也"）——**目标数是"二"，不是"最少"，更不是"一"。**<br>⑤ **⚠️ 到顶就要反过来给**（上九"弗损益之"，象传"大得志也"）——**损卦自己在最上一爻取消了"损下益上"。**<br>⑥ **减要快，而且要斟酌着减**（初九"已事遄往…酌损之"）——**遄（快）与酌（斟酌）是同一爻里的两个要求。**<br>⑦ **⚠️ 减的额度与时机绑定，不与数量绑定**（彖传"二簋应有时，损刚益柔有时。损益盈虚，与时偕行"）。 |

## 二、爻级字段

> ⚠️ **先读这一段：本卦六爻是一条极完整的"减法作业流程"，而且六爻分成两半。**
> **下三爻（初九、九二、六三）属下兑，是"被减的那一方"**——**初九主动减（酌损之）、九二不必再减（弗损益之，但征凶）、六三是被减掉的那一个（三人行则损一人）。**
> **上三爻（六四、六五、上九）属上艮，是"受益的那一方"**——**六四减掉自己的病（损其疾）、六五坐着受益（或益之十朋之龟，元吉）、上九到顶而停手并反过来给（弗损益之，大得志也）。**
> **⚠️ 而全卦最重要的一组是九二 ↔ 上九：同样四个字"弗损益之"，一个挂着"征凶"，一个给了"无咎·贞吉·利有攸往"。这是全书继巽卦"巽在床下"之后第二好的"同辞异断"教材（第四节第 3 条）。**

### 初九 · 已事遄往

| 字段 | 内容 |
|---|---|
| **爻辞** | 已事遄往，无咎，酌损之。 |
| **象传** | 已事遄往，尚合志也。 |
| **位属性** | 阳爻居阳位，**当位**（兑在下之律：初当位）——**全卦仅两爻当位，这是其中之一**；居全卦最下；**与六四相应**。 |
| **判词 → 行动语义** | **无咎**（按本库口径：**无灾，不等于吉利**） → **手上的事一了结就赶快去，而且要斟酌着减，不要一次减光** |
| **关键词解** | **已**＝已毕、完成（"已事"＝把自己的事办完）。一说"已"通"祀"，则"已事"为祭祀之事；**本库取"事毕"义为主**。**遄**（chuán）＝**快、迅速**。**已事遄往**＝**自己的事一办完就赶快前往**（往上、往六四那边去）。<br>**酌**＝斟酌、量着来（"酌"的本义是舀酒，引申为有分寸地取用）。**酌损之**＝**斟酌着减它。**<br>**象传**：**尚合志也**——**还要与（上面那一方的）心志相合**（"尚"＝还要、崇尚；"合志"＝心志相合，指与六四相应）。 |
| **⚠️ 本爻是全卦的操作起点，而它一开口就给了两个互相制约的要求** | **"遄"（快）与"酌"（斟酌）在同一条爻辞里。**<br>**⚠️ 这不是矛盾，是本卦对减法的完整要求**：<br>> **时间上要快（遄）——该减就立刻减，拖着减是最贵的减。**
> **额度上要有分寸（酌）——一次减多少要量着来，不能减光。**<br>**⚠️ 而"酌"这个字非常重要，因为它是全卦第一次给"减多少"设限。** 后面六三给了具体的数（三人减一人），上九给了终点（到顶就停），**而初九给的是原则：每一次都要斟酌。**<br>**⚠️ 再加象传那三个字"尚合志也"——减之前还要与对方心志相合。** **也就是说：减不是自己算好了就动手，要先对齐。这正是卦辞"有孚"在初爻的落实。** |
| **⚠️ 与蹇初六、解初六的对照（本组三卦的三个初爻，三条完全不同的指令）** | **蹇初六"往蹇，来誉"，象传"宜待也"——险在前方而自己动不了，正解是"等"；**<br>**解初六"无咎"，象传"刚柔之际，义无咎也"——局面刚松，正解是"什么都不做"；**<br>**损初九"已事遄往，无咎，酌损之"，象传"尚合志也"——⚠️ 正解是"赶快去做"。**<br>**⚠️ 三个初爻，一个等、一个空、一个快。而三卦是序卦传上连着的三卦（39 → 40 → 41）。**<br>**⚠️ 差别的唯一依据是卦德**：**蹇是"走不动"（所以等）｜解是"正在松开"（所以别插手）｜损是"该减了"（所以快减）。**<br>**⚠️ 而结构上也对得上：蹇初六不当位且失应（最没资格动）｜解初六不当位但有应（不必动）｜损初九当位且有应（有资格动，也有人接）。**<br>**合读结论：初爻该不该动，看两件事——位正不正，以及上面有没有人接（应）。两条都有，就"遄往"；缺一条，就等或空。** |
| **识别信号** | ① 你已经确定要减、要交、要上缴、要削减（方向已定）；② 你在最下面／最基层，是实际出这份东西的人；③ 你自己手上的本职刚好告一段落（已事）；④ 上面有一个明确的接收方，而且你们的目标是一致的（合志）；⑤ 你倾向于"再拖一拖"，或者反过来倾向于"一次减到底，图个干净"。 |
| **该做** | **① 快去（遄）**——事一了结立刻执行，不要留在"准备减"的状态里；**② 量着减（酌）**——**这一次减多少要有一个明确的额度，并且留有余地；③ 先对齐（合志）**——**动手前跟接收那一方把目标说明白，这是卦辞"有孚"的第一步。** |
| **不该做** | ① 拖着不减（"遄"字就是针对这个的）；② 一次减光图个痛快（"酌"字就是针对这个的）；③ 不打招呼就减——**那违背象传"尚合志也"，也破掉"有孚"，"元吉"随之作废。** |

### 九二 · 弗损益之（⚠️ 与上九"同辞异断"的一半）

| 字段 | 内容 |
|---|---|
| **爻辞** | 利贞，征凶，弗损益之。 |
| **象传** | 九二利贞，中以为志也。 |
| **位属性** | 阳爻居阴位，**不当位**（兑在下之律：二不当位），**但得中**——下兑之中；**与六五相应**（六五正是那个"或益之十朋之龟，元吉"的受益者）；本库通则"**二多誉**"。 |
| **判词 → 行动语义** | **利贞 ＋ 征凶**（**同一爻内一正一反**） → **守住正道是有益的；但主动往前去（再自减以奉上）则凶。你不必再减了，你要做的是"益之"** |
| **关键词解** | **利贞**＝守正有益。**征**＝征行、主动前往（对照大壮初九"壮于趾，征凶"、颐六二"征凶"、震上六"征凶"）。**征凶**＝主动前往则凶。<br>**⚠️ 弗损益之**＝**不减损它，而是增益它**（"弗"＝不；"之"指所对的一方，即六五）。**一说：不用"减损"的方式去增益它。两读相通，本库取合读。**<br>**象传**：**中以为志也**——**把"中"当成自己的心志**（"中"＝居中不偏；"以为志"＝作为志向）。 |
| **⚠️ 本爻是本卦第一个"停"的信号，而且它给了理由** | **在一个讲"损"的卦里，第二爻就说"弗损"（不要减）。**<br>**为什么？象传只给了五个字："中以为志也"。**<br>**⚠️ 九二不当位（名分不正），但它得中——它是下兑的枢纽，是实际在出力、在承担的那一个。**<br>**⚠️ 按本库通则"得中可救不当位"，而在损卦里，"得中"的具体内容就是："不再往下减自己"。**<br>**因为再减下去，那个"中"就没了——枢纽自己空了，整件事就塌了。**<br>**⚠️ 结论（本爻最实用的一条）：减法有一条底线，就是不能把"中"减掉。** **落到实操：不能减掉那个让事情还能运转的核心（核心人员、核心现金流、核心产能、你自己的健康）。**<br>**⚠️ 而"征凶"两个字把这条底线写成了禁令：不是"少减一点"，是"不要主动去减"。** |
| **⚠️ "征凶"为什么这么重（本爻最容易读丢的一层）** | **本卦下三爻是"被减的那一方"。九二作为这一方的枢纽，最容易犯的错是"主动表现"——主动上缴、主动加码、主动说"我再让一点"。**<br>**⚠️ 而《周易》对这个动作的判词是"凶"，全库最重的一档。**<br>**⚠️ 这与兑卦六三"来兑，凶"（主动上门讨好）在机制上完全同源，而且它们的下卦都是兑**：<br>> **兑六三"来兑，凶"（象传"位不当也"）——用姿态去补位置的亏空，主动单向输出。**
> **损九二"征凶"——在该被减的位置上主动加码去奉上。**
> **⚠️ 两者都是"主动往上／往外多给一点"，都判凶。而兑卡的结论是"姿态补不了位置"；损九二补上第二句：加码补不了额度。**<br>**⚠️ 落到实操：当组织在向你要减让时，主动多让一档不会换来好处。判词是"凶"，不是"吝"、不是"厉"。** |
| **识别信号（诊断清单）** | ① 大方向是"你这一块要减、要让、要上缴"；② 你是这一块实际的枢纽，事情靠你在运转（得中）；③ 你的名分不完全够（不当位），你想用姿态弥补；④ **⚠️ 你正准备主动多让一档，或主动去表个态**；⑤ 你的理由是"反正要减，不如我主动点，显得好看"。 |
| **该做** | **① 守住"中"（利贞 ＋ 中以为志）**——**把"哪些东西不能减"写下来，作为不可退让的底线**（参照巽初六"利武人之贞"：给自己一条硬线）；<br>**② 按住不动（不征）**——**减多少由那个额度决定，不由你的姿态决定**；<br>**③ 把动作从"损"换成"益"（弗损益之）**——**⚠️ 你能给上面的最好的东西不是再减一刀，是把手上这块做得更好。** |
| **不该做** | ① 主动加码上缴（**征凶**）；② 用"我很配合"的姿态去换评价（掉到兑六三"来兑，凶"）；③ 反过来，用"我要守住中"为理由一点都不减——**注意爻辞给的是"弗损益之"（不减而增），不是"不给"。** |
| **⚠️ 与上九的对照（先立此桩，完整对照见上九与第四节第 3 条）** | **九二与上九的爻辞里都有"弗损益之"这四个字，判词却完全不同**：<br>**九二："利贞，征凶，弗损益之"——挂着一个"征凶"。**<br>**上九："弗损益之，无咎，贞吉，利有攸往，得臣无家"——判词最丰厚。**<br>**⚠️ 差别在位置：九二在"被减的那一方"（弗损是守住底线，所以配一条禁令"征凶"）；上九在"受益的那一方"（弗损是停止索取并反过来给，所以配最好的判词）。**<br>**⚠️ 同一个动作，在给的一方是"底线"，在拿的一方是"美德"。** |

### 六三 · 三人行则损一人（⚠️ "减到什么程度该停"的经文依据）

| 字段 | 内容 |
|---|---|
| **爻辞** | 三人行，则损一人。 |
| **象传** | 一人行，三则疑也。 |
| **位属性** | 阴爻居阳位，**不当位**（兑在下之律：**三必不当位**，本库"兑在下＝讨好陷阱位"）；失中；**直乘九二之上——乘刚**（兑在下则六三必乘刚）；居下兑之顶；**与上九相应**；本库通则"**三多凶**"。 |
| **判词 → 行动语义** | **⚠️ 无吉凶判词**（爻辞只有六个字，是一句纯粹的事实陈述） → **三个人一起走，就要减掉一个；这是"减到什么程度"的刻度，不是对你的评判** |
| **关键词解** | **三人行，则损一人**＝**三个人同行，就要减去一个人。**<br>**象传**：**一人行，三则疑也**——**（减到）一个人走；三个（在一起）就会互相猜疑。**<br>**⚠️ 象传的语法要读准：它把爻辞倒过来说了。爻辞说"三人行则损一人"（结果），象传说"三则疑也"（原因）——为什么要减掉一个？因为三个就会生疑。** |
| **⚠️ 本爻是全卦最重要的一爻，因为它给"减多少"给出了唯一的数字刻度** | **⚠️ 全卦讲了六爻的"减"，只有这一爻给了具体的数：从三减到二。**<br>**⚠️ 请注意它没有说的话**：<br>> **它没说"减到最少"。**
> **它没说"减到一"。**
> **它说的是"三人行，则损一人"——从三个减成两个，然后停。**<br>**⚠️ 而象传给了这个数字唯一的理由："三则疑也"——三个人在一起就会互相猜疑。**<br>**⚠️ 这是《周易》对"多"给出的定义：多不是数量上的多，是"开始互相猜疑"。** **两个人可以相与（一对一，责任与信任都是清楚的）；三个人就会有两两组合，就会有人觉得自己被排除在外，于是生疑。**<br>**⚠️ 结论（本卦最实用的一条，可直接入库）**：<br>> **损的目标数是"成对"，不是"最少"。**
> **判断"该不该再减一个"的标准不是成本，是"还有没有猜疑"。**
> **没有猜疑了，就停手——再减下去就伤到"中"了（九二"征凶"）。**<br>**⚠️ 落到实操：三个合伙人变两个、三层汇报变两层、三个方案留两个、三个负责人定一个主一个备——这些都是"损一人"。而两个再减成一个，本爻没有授权。** |
| **⚠️ 本爻是"兑在下 → 六三必不当位"这条律的第四例，也是唯一一次例外（本卡的一条结构发现）** | 本库现有三例，**三条小象传全部写着"位不当也"，而且结局全部极差**： | 

| 卦·爻 | 爻辞 | 判词 | 小象传 | 性质 |
|---|---|---|---|---|
| **履 10 六三** | 眇能视，跛能履，履虎尾，咥人，凶 | **凶** | 咥人之凶，**位不当也**；武人为于大君，志刚也 | 才不配位而志刚 |
| **兑 58 六三** | 来兑，凶 | **凶** | 来兑之凶，**位不当也** | 主动讨好，用姿态补位置 |
| **睽 38 六三** | 见舆尸，其牛掣，其人天且劓，无初有终 | （**无初有终**） | 见舆尸，**位不当也** | 离心之世，位不当而受伤 |
| **⚠️ 损 41 六三** | **三人行，则损一人** | **⚠️ 无判词** | **一人行，三则疑也**（**⚠️ 完全不提位**） | **⚠️ 它就是那个该被减掉的人——而这不是过错** |

| 字段 | 内容 |
|---|---|
| **⚠️ 四例对照的结论（建议入库为通则的一条限定）** | **⚠️ 前三例的小象传都点名"位不当也"，损六三的小象传却完全不提位，改说"三则疑也"，而且全爻不给判词。**<br>**为什么？因为在损卦里，"六三该被减掉"正是这一卦要做的事。**<br>**⚠️ 六三在结构上是：下兑之顶、不当位、乘刚、失中——按本库通则这是"最该被处理"的位置。而损卦的卦德就是"减"。所以卦德与它的处境完全相合，它的"不当位"不再是过错，而是这一卦的作业对象。**<br>**⚠️ 由此得出一条对"兑在下＝讨好陷阱"这条律的重要限定（建议补入规格第 4 节）**：<br>> **"兑在下则六三必不当位"是结构事实，但它是不是"陷阱"，由卦德决定。**
> **当卦德要求"求悦、上行、争取"时（履、兑、睽），六三的不当位就是陷阱，判凶。**
> **⚠️ 当卦德本身就是"减"时（损），六三的不当位反而是这一卦的落点——《周易》连判词都不给它，因为它没有做错什么，它只是那个要被减掉的。**<br>**⚠️ 这与咸卡给出的通则完全同构："身体部位在《周易》里没有固定吉凶，吉凶由卦德决定。" 本条把它推广到爻位：位属性没有固定吉凶，吉凶由卦德决定。** |
| **⚠️ 本爻同时是全卦唯一的乘刚，而它也不受判罚** | 本库"乘刚"专题现有九种破解（收缩范围／交付成果／推行规矩／不预设收获／下附于仁／守住本职／辨明职分／主动放手／横向连结／跟从／解开结）。<br>**⚠️ 损六三不属于任何一种，因为它不需要破解——它是被减掉的那一个。**<br>**⚠️ 这给"乘刚"补上一条例外情形（建议入库）**：<br>> **当卦德就是"减损"时，乘刚者的正确出路不是破解，是"成为被减的那一个"。**
> **⚠️ 判据：看这一卦要你留下还是要你走。要你留下，就用九种破解之一；要你走，就走得干净——损六三没有判词，说明《周易》既不奖它也不罚它。**<br>**⚠️ 落到实操：一个组织在缩编，而你正处在"当位不正、上面顶着强人、又不在核心"的位置上——本爻的意思是，这个位置本来就是缩编的落点，走不是你的失败。** |
| **识别信号（诊断清单）** | ① 一个局面里现在有三方／三个人／三层／三个方案；② 你能感到已经开始有猜疑：有人觉得另外两个走得近、有人觉得自己被绕过、信息开始分叉；③ 事情推不动的原因说不清楚，但每一次沟通都要三方对齐；④ **⚠️ 或者：你就是这三个里位置最不正、最靠边、上面还压着一个强人的那一个**。 |
| **该做** | **① 减到两个。** 明确保留哪两方，并把去掉的那一方**明确地、有交代地去掉**（参照解卦"赦过宥罪"：解除关系但不追究）；<br>**② 用"疑"作判据，不用"成本"作判据**——**象传给的标准是"三则疑也"。还有猜疑就减，没有猜疑就停；**<br>**③ 减完就停在"二"**——**再往下减就碰到九二的"征凶"（把"中"减掉了）。**<br>**④ ⚠️ 如果你就是那一个：走得干净。** 本爻不给判词，也就是《周易》不判你有咎；**而你的应爻是上九（那个"弗损益之，大得志也"的人）——第四节第 3 条会说明这条应的意义。** |
| **不该做** | ① 为了"公平"把三方都保留（象传已判"三则疑也"）；② 一路减到一个（本爻只授权减到二；再减就是九二"征凶"）；③ 减得不明不白（破"有孚"，"元吉"作废）。 |

### 六四 · 损其疾

| 字段 | 内容 |
|---|---|
| **爻辞** | 损其疾，使遄有喜，无咎。 |
| **象传** | 损其疾，亦可喜也。 |
| **位属性** | 阴爻居阴位，**当位**（艮在上之律：四当位）——**全卦仅两爻当位，这是其中之一**；已入上艮；**与初九相应**（初九正是那个"已事遄往"的人）；本库通则"**四多惧**"。**⚠️ 注意：六四乘于六三之上，同性，不构成乘刚。** |
| **判词 → 行动语义** | **无咎 ＋ 有喜** → **减掉那个"病"，而且要快；减掉它是可喜的** |
| **关键词解** | **疾**＝病、毛病、病害（对照兑九四"介疾有喜"——同一个"疾"字，同一个"有喜"）。**损其疾**＝**减掉那个病处。**<br>**遄**＝快（**与初九"遄往"同字**）。**使遄有喜**＝**让它快一点，就有可喜之事。**<br>**象传**：**亦可喜也**——**这也是可喜的。**（"亦"字有味道：减东西本来不像是好事，但这一减"也"是可喜的。） |
| **⚠️ 本爻是全卦唯一一处把"减"直接判成"喜"的爻** | **全卦判词谱：无咎（初九）／利贞·征凶（九二）／无判词（六三）／⚠️ 无咎·有喜（六四）／元吉（六五）／无咎·贞吉·利有攸往（上九）。**<br>**⚠️ "有喜"只出现在六四，而它减的东西是"疾"（病）。**<br>**⚠️ 结论（本爻最重要的一条）：损卦里唯一无条件可喜的减法，是减掉病的那一部分。** **其余的减都只到"无咎"，或者要挂条件（有孚→元吉）。**<br>**⚠️ 落到实操：这一爻给"该减什么"排了序——**<br>> **第一顺位减"疾"（有病的那部分）→ 有喜；**
> **其次减"多"（多出来的、造成猜疑的）→ 无判词，是本分（六三）；**
> **绝不减"中"（让事情还能运转的核心）→ 减了就是征凶（九二）。**<br>**⚠️ 这三档合起来就是本卦的"减法优先级表"，见第三节。** |
| **⚠️ 与兑九四"介疾有喜"的对照（全书两处"疾…有喜"，且都在九四／六四位）** | **兑 58 九四"商兑未宁，介疾有喜"——在"该不该迁就"上反复权衡，把那个病处隔断开，就有喜；**<br>**损 41 六四"损其疾，使遄有喜，无咎"——把那个病减掉，而且要快，就有喜。**<br>**⚠️ 两爻的动作是同一个（处理"疾"），差别在两点**：<br>> **① 手法：兑九四是"介"（隔断——只把它隔开，不动整片和气）；损六四是"损"（减掉——直接去除）。**
> **② 速度：兑九四之前有一段"商兑未宁"（反复权衡、睡不好）；损六四要求"遄"（快）。**<br>**⚠️ 差别的原因在卦德与位属性**：**兑卦的德是"悦"，所以处理病处必须小心不破坏整片和气，而且九四不当位（只能隔，不能割）；损卦的德是"减"，所以可以直接割，而且六四当位（有资格动手）。**<br>**⚠️ 合读结论（可入库）：处理"病处"有两种手法——不当位者只能"介"（隔断），当位者可以"损"（切除）。判断用哪一种，先看自己的位正不正。** |
| **⚠️ "遄"字在本卦出现两次，而且是一对相应爻** | **初九"已事遄往"（当位，在最下，是给的那一方）／六四"使遄有喜"（当位，在四位，是受的那一方）。**<br>**⚠️ 而初九与六四正是相应的一对，也正是全卦唯一的两个当位之爻。**<br>**⚠️ 这不是巧合，它构成了本卦的主轴**：<br>> **全卦只有两爻当位，而这两爻相应，而这两爻的爻辞里都有一个"遄"（快）。**
> **⚠️ 结论：损卦里位置最正的那条通道，其唯一的共同要求是"快"。**<br>**⚠️ 落到实操：减法最贵的成本是时间。方向定了就快执行（初九"遄往"），病看出来了就快切掉（六四"使遄"）——而这两件事恰好是这一卦里唯一"名正言顺"的两个动作。** |
| **识别信号** | ① 你在中层／执行层，位置是正的（当位）；② 局面里有一块明确是"病"的——持续亏损的业务、明显不产出的环节、一个已经坏掉的流程、一段消耗性的关系、一个自己身上的坏习惯；③ 你已经看清它是病，不是暂时的困难；④ 你在拖，理由通常是"再观察一下"、"等这一季过完"；⑤ 你四周都在看你（四多惧）。 |
| **该做** | **① 明确指认"疾"**——**写清楚是哪一块，以及凭什么判定它是病（不是暂时困难）；② 快（遄）**——**爻辞把"喜"直接挂在"遄"上：使遄有喜。慢，就没有那个喜；③ 只切病处，不扩大**（参照兑九四"介疾"、离上九"获匪其丑"、解上六"射隼"——本库"精准打击"专题）。 |
| **不该做** | ① 拖（"使遄"两个字是本爻唯一的条件）；② 借切病处做一轮整体清算（那会伤到九二那个"中"）；③ 因为"四多惧"、四周都在看而不动手——**⚠️ 本爻当位，是全卦最有资格动手的两个位置之一。** |

| **象传** | 六五元吉，自上祐也。 |
| **位属性** | 阴爻居阳位，**不当位**（艮在上之律：五不当位），**但得中**且居尊位——**全卦卦主**；**与九二相应**（九二正是那个"弗损益之"的枢纽）。**⚠️ 六五乘于六四之上，同性，不构成乘刚。** |

|---|---|
| **⚠️ 这一组对照的结论（本卡最重要的一条）** | **⚠️ 同样一份"十朋之龟"的厚礼，同样"推不掉"，两卦给的判词与归因完全不同**：<br>> **损六五在尊位收到它 → 元吉，象传说"自上祐也"（来自上面）。**
> **益六二在下位收到它 → 永贞吉·吉，象传说"自外来也"（来自外面）。**<br>**⚠️ 差别的机制很清楚：损卦是"损下益上"，所以六五（在上）收到的东西是下面交上来的，而《周易》偏偏不说"自下来"，说"自上祐也"——它把这份所得的来源归给了更上面（上九／上天），不归给六五自己的位置。**<br>**⚠️ 益卦是"损上益下"，所以六二（在下）收到的东西是上面给下来的，象传说"自外来也"——它明确指出这不是你挣的。**<br>**⚠️ 两处合读得出一条本库口径（建议入库）**：<br>> **《周易》给"白得的厚礼"配的判词很高（元吉／永贞吉），但两处的小象传都在做同一件事：把来源指向你之外。**
> **"自上祐也"与"自外来也"，说的是同一句话——这不是你的功劳。**
> **⚠️ 所以这两爻的行动语义不是"你很成功"，是"你受了馈赠，别当成业绩"。**<br>**⚠️ 落到实操：拿到一笔超出自己贡献的资源（一次意外的授权、一笔白来的预算、一个被硬塞给你的机会），正确动作是：接下来（弗克违，推不掉也不该推），但在账上把它记成"外来"而不是"我挣的"。记错了，就掉到解六三的"负且乘"（德薄而位尊，盗思夺之）。** |
| **⚠️ 为什么本爻能拿"元吉"，而卦辞的"元吉"是有条件的** | **卦辞："有孚，元吉"——彖传把它写成"损而有孚，元吉"，条件是"有孚"。**<br>**⚠️ 六五的"元吉"没有再挂条件，但象传给了它一个替代品："自上祐也"。**<br>**⚠️ 也就是说：六五的元吉不是它挣来的，是"上面佑助"的结果。这与卦辞的"有孚→元吉"并不冲突，而是同一件事的两端**：<br>> **下面的人有孚（真减、明减）→ 上面才可能得到"十朋之龟"级的东西 → 元吉。**
> **⚠️ 而六五与九二相应，九二的动作正是"弗损益之"（不再自减，而是把手上这块做得更好）。所以六五这份厚礼的实际来路，就是九二把事情做好了。**<br>**⚠️ 结论：损卦的"元吉"是一条完整的链——下面真诚地减并把事做好（九二"中以为志"）→ 上面得到厚报（六五"元吉"）→ 而上面必须承认这是"自上祐"，不是自己的本事。链条上任何一环把功劳记到自己头上，"元吉"就断了。** |
| **⚠️ 六五不当位，却是全卦最高判词所在（本卦"当位≠吉凶"的内部实例）** | **⚠️ 全卦只有初九、六四当位，而它们的判词是"无咎"与"无咎·有喜"；不当位的六五拿到"元吉"，不当位的上九拿到"无咎·贞吉·利有攸往"。**<br>**⚠️ 也就是说：本卦判词最高的两爻都不当位。** 这与本组蹇／解那一对给出的结论完全一致（**位置只提供缓冲，不提供保障；判词由这一爻做了什么决定**），**而损卦是在一卦内部就把这件事演完了。** |
| **本库"五爻专题"的新一例** | 已有十四例（乾九五利见大人、坤六五守臣节、蒙六五赤子之心、离六五痛哭、艮六五闭嘴、师六五选人放手、震六五守本职、巽九五申命、履九五位正当反厉、兑九五收回孚、咸九五感不到、恒六五必须自己判断、蹇九五承认大蹇、解六五只做"解"）。<br>**⚠️ 损六五补上第十五种：居尊而承认自己所得是白来的。** 它要主动放弃的特权是——**"把下面交上来的东西记成自己的成绩"这个特权。** |
| **识别信号（若你是六五）** | ① 你在上位／受益的一方，下面正在为你减让（缩编、让利、上缴、加班）；② 你收到了明显超出自己贡献的东西——一笔厚资源、一次高评价、一个大机会；③ 你推不掉，也不该推（弗克违）；④ **⚠️ 你开始把它解释成自己的判断正确、自己的领导有方**；⑤ 你的名分其实并不完全够（不当位）。 |

### 上九 · 弗损益之（⚠️ 损卦自己取消了"损下益上"）

> **而这个时候由位置决定：走到最上（拿得最多的那一位），就必须停止索取并开始给出。**
> **⚠️ 三条刻度合起来才完整：**
> **① 单次额度——"酌"（初九，每次都要斟酌）；**
> **② 目标数量——"损一人"（六三，减到成对就停，判据是"还有没有猜疑"）；**
> **③ ⚠️ 整体终点——"弗损益之"（上九，到顶就反过来给）。**<br>**⚠️ 而这条终点还有一个结构上的印证：上九与六三相应。上九正对着的，就是那个被减掉的人。所以"弗损益之"不是抽象的慷慨，是对着那个为你付出过的人。** |
| **⚠️⚠️ 九二 ↔ 上九："同辞异断"教材（本库第二例，第一例是巽卦"巽在床下"）** | 巽卡给出了本库第一例"同辞异断"：**巽九二与上九爻辞里都有"巽在床下"四个字，一个"吉，无咎"，一个"贞凶"，差别在"得中"与"上穷"。** **损卦给出第二例，而且方向正好相反**： |

| 字段 | 内容 |
|---|---|
| **⚠️ 这一组对照的结论（建议入库为通则）** | **⚠️ 同一个动作"弗损益之"，在给的一方是"底线"（配禁令：征凶），在拿的一方是"美德"（配最高判词群）。**<br>> **⚠️ 通则：一个"我不再减了"的动作，其吉凶完全取决于说这句话的人是给方还是拿方。**
> **给方说"我不再减了"——这是守住底线，正当，但不许再主动往前（征凶）。**
> **拿方说"我不再减你了"——这是停止索取并反过来给，判词最高（无咎·贞吉·利有攸往·大得志）。**<br>**⚠️ 与巽卦那一例合读，本库"同辞异断"至此有两组，而两组的判据不同**：<br>**巽卦（巽在床下）的判据是"得中／上穷"——同一个位置属性维度上的差别；**<br>**⚠️ 损卦（弗损益之）的判据是"在给的一方／在拿的一方"——立场维度上的差别。**<br>**⚠️ 由此可给本库读卦法补一条：读一句爻辞之前，先确定说这句话的人在这一卦的哪一方。同一句话，立场一换，判词可以从"凶"跳到"贞吉"。** |
| **⚠️ 上爻走法的第八种（本库"到顶之后"专题）** | 本库现有七种（恒卡整理六种 ＋ 蹇卡补第七种）：**知止则吉（艮上九"敦艮"）｜转向内则吉（蹇上六"来硕"）｜不扩大则无咎（离上九"获匪其丑"）｜无内容则白过（兑上六"引兑"）｜过刚则悔（乾上九"亢龙"）｜过柔则凶（巽上九"丧其资斧"）｜过动则凶（恒上六"振恒"）。**<br>**⚠️ 损上九补上第八种：到顶而反过来给，则判词最密集（无咎·贞吉·利有攸往，象传"大得志也"）。**<br>**⚠️ 修订后的完整口径（建议入库）**：<br>> **到顶之后有八种走法——知止则吉｜转向内则吉｜⚠️ 反过来给则大得志｜不扩大则无咎｜无内容则白过｜过刚则悔｜过柔则凶｜过动则凶。**
> **⚠️ 而三种正面走法（艮上九"止"、蹇上六"转向内"、损上九"反过来给"）有一个共同点：都不再向外索取。** **这与本库另一条上爻通则（"凡上爻涉及用兵，方向必须向内"——泰上六、谦上六、解上六）完全同源。**
> **⚠️ 合成一条总纲：上爻的安全动作只有一个方向——停止向外拿。停手（艮）、转身（蹇）、给出去（损），是这一个方向的三种强度。** |
| **⚠️ "得臣无家"与本库"核心须分享"标签** | 本库该标签现有出处：**需九五"酒食"、师上六"正功"、小畜九五"富以其邻"、泰九二"朋亡"、泰六四"不富，以其邻"、大有九三"公用享于天子"、谦六五"不富以其邻"＋谦大象传"裒多益寡，称物平施"。**<br>**⚠️ 损上九"得臣无家"补上这条标签最高的一处**：**前面各处讲的是"把多的分给旁边的人"，损上九讲的是"到了顶，连'私家'的界限都不再有"。**<br>**⚠️ 而它拿到的回报也是这条标签里最高的：象传"大得志也"。** **本库口径可以补一句：分享的层级越高，回报越不是物质的——需九五得"贞吉"，谦六五得"无不利"，损上九得"大得志"。** |
| **识别信号（若你是上九）** | ① 你在整条链的最上端，是这一轮"减"的最终受益者；② 下面已经为你减了不止一轮；③ 你还有继续索取的空间和正当理由（预算还能压、人还能减、条件还能提）；④ **⚠️ 你正对着的那个人／那一块，就是这一轮被减掉的**（上九↔六三）；⑤ 你在考虑"再压一轮"。 |
| **该做** | **① 停止索取（弗损）**——**明确宣布这一轮到此为止；② 反过来给（益之）**——**把拿到的一部分明确地还给下面，尤其还给被减掉的那一方（六三）；③ 拆掉"私家"的界限（得臣无家）**——**不再把资源按"我的／不是我的"划分。** |
| **不该做** | ① 再压一轮（**本爻是全卦判词最密集的一爻，而它的全部内容就是"不再压"**）；② 只口头表示而不实际给回（破"有孚"）；③ 把"给回去"做成恩赐——**象传是"大得志也"（你的心志实现了），不是"他们该感谢你"。** |

## 三、损卦定位速查表

### ⚠️ 核心表一：减法优先级（本卦最实用的一张表）

**本卦对"该减什么"排了严格的顺序，判词自己就是排序依据：**

| 顺位 | 减什么 | 出处 | 判词 | 机制 |
|---|---|---|---|---|
| **⚠️ 第 0 位（前置）** | **自己的忿与欲** | **大象传"惩忿窒欲"** | （纲领，无判词） | **不先减这两样，后面每一步都会变形：带忿则成清算，带欲则成算计** |
| **第 1 位** | **疾**（有病的那部分） | **六四"损其疾，使遄有喜"** | **无咎 ＋ 有喜** | **⚠️ 全卦唯一无条件可喜的减法；条件是"遄"（快）** |
| **第 2 位** | **多**（造成猜疑的那一个） | **六三"三人行，则损一人"** | **无判词** | **⚠️ 判据是"三则疑也"——有猜疑就减，减到成对就停** |
| **⚠️ 禁止减** | **中**（让事情还能运转的核心） | **九二"利贞，征凶，弗损益之"** | **⚠️ 征凶** | **象传"中以为志也"——把"中"减掉，整件事就塌了** |
| **⚠️ 终点** | **停止减，反过来给** | **上九"弗损益之"** | **无咎 ＋ 贞吉 ＋ 利有攸往** | **象传"大得志也"——到顶就必须反向** |

### ⚠️ 核心表二：三条"减多少"的刻度

| 刻度 | 出处 | 内容 |
|---|---|---|
| **单次额度** | **初九"酌损之"** | **每一次都要斟酌着来，不能一次减光**（同爻还要求"遄"——快） |
| **目标数量** | **六三"三人行，则损一人"** | **⚠️ 目标数是"成对"（二），不是"最少"，不是"一"。判据是猜疑（三则疑也）** |
| **规格下限** | **卦辞"二簋可用享"** | **规格可以降到最低（连祭祀都只用两簋）。⚠️ 但彖传立刻限定："二簋应有时"——这是时机性的，不是永恒原则** |
| **整体终点** | **上九"弗损益之"** | **⚠️ 走到最上（拿得最多的位置），就停止索取并反过来给** |
| **⚠️ 总判据** | **彖传"损益盈虚，与时偕行"** | **⚠️ 减、增、满、空，全部跟着时机走——不看你想不想，不看东西多不多，看时** |

### 全爻速查

| 爻 | 在哪一方 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | **给方**（下兑） | 已事遄往 | 方向已定，你是实际出这份东西的人 | **当位**·有应 | **无咎**·**遄**（快去）＋**酌**（量着减）·先合志 |
| 九二 | **给方·枢纽** | 弗损益之 | 你想主动多让一档，显得配合 | 不当位但**得中** | **利贞·⚠️ 征凶**·守住"中"·别加码 |
| 六三 | **给方·被减者** | 三人行则损一人 | 三方在一起，已经开始互相猜疑 | **不当位·失中·乘刚** | **⚠️ 无判词**·减到成对·判据是"疑" |
| 六四 | **受方**（上艮） | 损其疾 | 有一块明确是病，你在拖 | **当位**·有应 | **无咎·⚠️ 有喜**·快切病处 |
| 六五 | **受方·卦主** | 或益之十朋之龟 | 收到明显超出自己贡献的厚礼 | 不当位但**得中居尊** | **⚠️ 元吉**·接下来·但记成"自上祐"不是业绩 |
| 上九 | **受方·终端** | 弗损益之 | 你在最上端，还能再压一轮 | 不当位·卦终 | **无咎·贞吉·利有攸往**·⚠️ 停止索取·反过来给 |

**损卦三句话**：
1. **⚠️ 损的第一对象是自己的忿与欲，不是别人**（大象传"**惩忿窒欲**"）。**一个讲"减"的卦，行动纲领里没有一个字提到钱、人、项目——只有忿与欲。因为带着火气减就成了清算，带着贪欲减就成了算计。**
2. **减有三条刻度，缺一条就会减错**：**每次要"酌"（初九）｜减到成对就停，判据是猜疑（六三"三则疑也"）｜绝不能减掉那个"中"（九二"征凶"）。** **而唯一无条件可喜的减法是减掉"疾"（六四"损其疾，使遄有喜"）。**
3. **⚠️ 损卦在自己的最后一爻取消了自己**：**整卦是"损下益上"（彖传），而上九说"弗损益之"——到顶就停止索取、反过来给，判词是全卦最密集的（无咎·贞吉·利有攸往），象传"大得志也"。**

**本卦最反直觉的四条**：
- **⚠️ 全卦只有两爻当位（2／6），而判词最高的两爻（六五"元吉"、上九"无咎·贞吉·利有攸往"）都不当位；两个当位的爻（初九、六四）判词只到"无咎"。** **本卦在一卦内部就把"当位≠吉凶"演完了。**
- **⚠️ 一个讲"减"的卦，卦辞判词却极其丰厚：元吉、无咎、可贞、利有攸往（四项，带头是全书最高的"元吉"）。** **唯独没有"亨"——减这个动作本身不制造通达。而"元吉"挂着唯一一个条件："有孚"（真减、明减）。**
- **⚠️ 同样四个字"弗损益之"，九二配的是"征凶"，上九配的是"无咎·贞吉·利有攸往"。** **差别不在位置属性，在立场：给方说"我不再减了"是守底线（不许再主动往前）；拿方说"我不再减你了"是美德（判词最高）。**
- **⚠️ 六三是"兑在下→六三必不当位"这条律的第四例，却是唯一一例小象传不提"位不当也"的。** **前三例（履、兑、睽）全部点名位不当且结局极差；损六三不给判词、不提位，只说"三则疑也"——因为在损卦里，"该被减掉"正是这一卦要做的事。位属性没有固定吉凶，卦德决定它的吉凶。**

## 四、⚠️ 本卡对全库的意义

### 1. ⚠️ 损／益是一对倒转卦，两卦彖传是一对反话（本库第二组"彖传镜像"）

**结构核对（机械可验）**：
- **损 41**（上艮下兑）六爻自下往上：**阳 阳 阴 ｜ 阴 阴 阳**
- 整卦上下颠倒：**阳 阴 阴 ｜ 阴 阳 阳** ＝ **益 42**（上巽下震）✓
- **两卦互为覆卦**——这正是序卦传把它们排在一起的结构原因（"损而不已必益，故受之以益"）。

**⚠️ 而两卦彖传的第一句，恰好是一对反话，且第二句就分出了褒贬**：

| | **损 41（减）** | **益 42（增）** |
|---|---|---|
| **彖传首句** | **损下益上，其道上行** | **损上益下，民说无疆；自上下下，其道大光** |
| **⚠️ 对这条"道"的评价** | **⚠️ 只说"上行"**（中性描述，不加褒贬） | **⚠️ 说"大光"，还加"民说无疆"**（明确的褒） |
| 结构 | 兑（悦）在下，艮（止）在上 | 震（动）在下，巽（顺）在上 |
| **当位数** | **2／6**（初九、六四） | **4／6**（初九、六二、六四、九五） |
| **卦辞** | **有孚，元吉，无咎，可贞，利有攸往。曷之用？二簋可用享**（**判词四项，含元吉**） | **利有攸往，利涉大川**（**判词两项，无元吉**） |
| **大象传** | **惩忿窒欲**（**减自己的忿与欲**） | **见善则迁，有过则改**（**改自己的行为**） |
| **彖传结句** | **⚠️ 损益盈虚，与时偕行** | **⚠️ 凡益之道，与时偕行** |
| **一句话** | **减，是往上交** | **增，是往下给** |

> **⚠️ 合读结论一（完全出自两卦彖传原文，是本组最有价值的一条）**：
> **《周易》对"损"与"益"这两个动作本身没有偏好，它偏好的是方向。**
> **同样是"损"这个字——"损下益上"只得一句"其道上行"（中性）；"损上益下"得到"民说无疆／其道大光"（明确的褒）。**
> **⚠️ 所以本库对这一对的口径应该是：不要问"该减还是该增"，要问"这一减一增的方向是往上还是往下"。**
> **往下（上面减、下面得）＝大光；往上（下面减、上面得）＝只是"上行"，需要额外的条件（有孚）才能拿到元吉。**

> **⚠️ 合读结论二（本组最反直觉的一条）**：
> **⚠️ 损只有 2 爻当位，益有 4 爻当位——"减"在结构上位位不正，"增"在结构上多半是正的。**
> **⚠️ 但绝不可据此反推吉凶：损的卦辞给了"元吉、无咎、可贞、利有攸往"四项，益的卦辞只给"利有攸往、利涉大川"两项，而且没有元吉。**
> **⚠️ 也就是说：当位数少的那一卦，卦辞判词反而更足。**
> **这与本组前一对（蹇 5 当位而"难"／解 1 当位而"解脱"）是同一条结论的第二次实证，只是方向相反——蹇是"当位多而处境差"，损是"当位少而判词足"。**
> **⚠️ 两对四卦合起来，本库"当位数不是吉凶指标"这条修订就再无争议了。**

> **⚠️ 合读结论三（两卦彖传的同一个结句）**：
> **损彖传结句："损益盈虚，与时偕行。"｜益彖传结句："凡益之道，与时偕行。"**
> **⚠️ 《周易》把同样的四个字放在这一对卦的同一个位置上——这是它对"该减还是该增"给出的唯一答案：与时偕行。**
> **⚠️ 而损卦彖传在这句之前还多铺了两层："二簋应有时，损刚益柔有时。"——连"减到什么规格"、"减刚补柔"都是"有时"的。**
> **⚠️ 结论：损益的判据不是数量（东西多不多），不是意愿（想不想），是时机。这就把"该减该增"从一个价值判断变成了一个时机判断。具体的操作化对照表见益卡第四节第 1 条。**

### 2. 覆卦当位互补定理的公式化证明（蹇卡的定理在此获得一条更强的形式）

蹇卡第四节第 1 条已用位属性奇偶性证明了：**一对覆卦的当位数必然相加为 6，且逐爻互补。** **本卡补上一个更好用的形式，它同时把定理的证明变成一行**：

> **⚠️ 当位数公式**：
> ### **当位数 ＝ 3 ＋ d(下卦) − d(上卦)**
> **其中 d(X) ＝ 该三画卦落在下卦位置时的当位爻数**：
> **离 ＝ 3｜乾、震、艮 ＝ 2｜坤、巽、兑 ＝ 1｜坎 ＝ 0**

**公式的来历（机械可验）**：下卦占初（阳位）、二（阴位）、三（阳位）；上卦占四（阴位）、五（阳位）、上（阴位）——**两组位的阴阳序列正好互补。** 所以同一个三画卦落在上卦时的当位数必然是 **3 − d**。总数 ＝ d(下) ＋ [3 − d(上)] ＝ **3 ＋ d(下) − d(上)**。

**本组四卦验算**：

| 卦 | 下卦 | d(下) | 上卦 | d(上) | 公式 | 实际当位爻 | ✓ |
|---|---|---|---|---|---|---|---|
| **蹇 39** | 艮 | 2 | 坎 | 0 | 3＋2−0 ＝ **5** | 六二、九三、六四、九五、上六 | ✓ |
| **解 40** | 坎 | 0 | 震 | 2 | 3＋0−2 ＝ **1** | 上六 | ✓ |
| **损 41** | 兑 | 1 | 艮 | 2 | 3＋1−2 ＝ **2** | 初九、六四 | ✓ |
| **益 42** | 震 | 2 | 巽 | 1 | 3＋2−1 ＝ **4** | 初九、六二、六四、九五 | ✓ |

> **⚠️ 而定理的一行证明**：**d 在三画卦的上下倒转下是不变的**——机械核对：**离↔离（3）｜乾↔乾（2）｜震↔艮（2↔2）｜坤↔坤（1）｜巽↔兑（1↔1）｜坎↔坎（0）。**
> **一卦的覆卦，其下卦 ＝ 原上卦倒转、上卦 ＝ 原下卦倒转。** 所以覆卦的当位数 ＝ 3 ＋ d(上) − d(下) ＝ **6 −** 原卦当位数。**∎**
> **⚠️ 附带一条可直接用于校验的结论：当位数只能取 0–6，而且它完全由上下两个三画卦决定，与爻辞无关。所以"当位数"这个指标在本库里应当只用于结构核对（防止爻名写错），不用于吉凶判断。**
> **⚠️ 本组四卦的当位数分别是 5、1、2、4，判词最好的是解（无不利）与损（元吉），最差的是解六三（贞凶）——完全没有相关性。**

### 3. ⚠️ "损到什么程度该停"——本库唯一的经文答案（本卡的核心增量）

**本库此前有"该不该停"（艮 52）、"该不该退"（遯 33）、"怎么让它久"（恒 32），但没有"减到什么程度该停"。损卦是唯一给出刻度的卦，而且它给了三个层次的刻度，出处全部在爻上：**

| 层次 | 出处 | 刻度 | 判据 | 违反的代价 |
|---|---|---|---|---|
| **单次** | **初九"酌损之"** | **每次都要斟酌，不能一次减光** | 无量化判据，靠"酌" | 一次减光 → 直接碰到九二的"中" |
| **⚠️ 数量** | **六三"三人行，则损一人"**<br>象传"**一人行，三则疑也**" | **⚠️ 减到"成对"（二）就停** | **⚠️ 猜疑**（还有猜疑就减，没有就停） | 减过头 → 九二"**征凶**" |
| **规格** | **卦辞"曷之用？二簋可用享"**<br>彖传"**二簋应有时**" | **规格可降到最低（连祭祀都只用两簋）** | **⚠️ 时**（"应有时"——这是时机性的，不是永恒原则） | 该用大礼时用二簋 → 失礼 |
| **⚠️ 底线** | **九二"利贞，征凶"**<br>象传"**中以为志也**" | **⚠️ 绝不减那个"中"（让事情还能运转的核心）** | 事情还转不转得动 | **凶**（全库最重一档） |
| **⚠️ 终点** | **上九"弗损益之"**<br>象传"**大得志也**" | **⚠️ 走到最上（拿最多的位置），停止索取并反过来给** | 位置（到顶即是终点） | 再压一轮 → 失掉全卦最密集的判词群 |

> **⚠️ 三条最重要的口径（建议直接入库）**：
> **① 损的目标数是"成对"，不是"最少"。** 六三只授权从三减到二（"三人行，则损一人"），**象传给的判据是猜疑（"三则疑也"）而不是成本。** **两个再减成一个，本卦没有授权；那已经是九二的"征凶"。**
> **② ⚠️ 减法有一条不可碰的底线："中"。** 九二得中而《周易》判"征凶"，象传只给五个字"中以为志也"——**把那个让事情还能运转的核心减掉，是全库最重的判词。落到实操：核心人员、核心现金流、核心产能、自己的健康。**
> **③ ⚠️ 损的终点由位置决定，不由数量决定。** **走到"拿得最多"的那一位（上九），就必须停止索取并反过来给。** 而《周易》给这个反转配的是全卦最密集的判词（无咎·贞吉·利有攸往）＋象传"大得志也"。

**⚠️ 而"弗损益之"这四个字在九二与上九两处出现、判词完全不同，是本库第二组"同辞异断"教材**（第一组是巽卦"巽在床下"，九二"吉，无咎"／上九"贞凶"）：

| 组 | 相同的字 | 判据维度 | 结论 |
|---|---|---|---|
| **巽 57**（九二／上九） | **巽在床下** | **位属性**（得中／上穷） | **低姿态在枢纽位置上是方法，在到顶位置上是失能** |
| **⚠️ 损 41**（九二／上九） | **弗损益之** | **⚠️ 立场**（给方／拿方） | **⚠️ "我不再减了"在给方是守底线（配禁令"征凶"），在拿方是美德（配最高判词群）** |

> **⚠️ 由此给本库读卦法补一条（建议入库）**：
> **读一句爻辞之前，先确定说这句话的人在这一卦的哪一方（给方还是拿方、治人还是受治、求教还是施教）。**
> **同一句话，立场一换，判词可以从"凶"跳到"贞吉"。**
> **⚠️ 本库已有的分方读法样本至此三例：蒙 4（下卦施教者／上卦求教者）、噬嗑 21（初上受刑者／中四用刑者）、⚠️ 损 41（下兑给方／上艮受方）。** **建议在索引里把"先分方"列为读卦第一步，与"先数应爻"并列。**

### 4. 对"兑在下＝讨好陷阱"这条结构律的重要限定

规格第 4 节现有条文：**"兑在下 → 初当位、二不当（得中）、三必不当位"**，并列在六条最危险位置里：**"兑在下＝易落入讨好的陷阱。"**

**⚠️ 本库现有四个"兑在下的六三"，而损六三是唯一的例外**（完整对照表见本卡六三爻）：

| 卦 | 六三爻辞 | 判词 | 小象传 | 卦德要求六三做什么 |
|---|---|---|---|---|
| **履 10** | 履虎尾，咥人，凶 | **凶** | **位不当也**·志刚也 | 在强者旁安全通行 → 它却志刚 |
| **兑 58** | 来兑，凶 | **凶** | **位不当也** | 让人愉悦 → 它却上门讨好 |
| **睽 38** | 见舆尸…其人天且劓 | 无初有终 | **位不当也** | 处离心之世 → 它位不当而受伤 |
| **⚠️ 损 41** | **三人行，则损一人** | **⚠️ 无判词** | **⚠️ 一人行，三则疑也**（不提位） | **⚠️ 减 → 它就是被减掉的那一个** |

> **⚠️ 限定条文（建议补入规格第 4 节）**：
> **"兑在下则六三必不当位"是结构事实；但"不当位"是不是"陷阱"，由卦德决定。**
> **⚠️ 当卦德要求六三去求、去悦、去争、去通行时（履、兑、睽），它的不当位就是陷阱——三处小象传全部点名"位不当也"，结局全部极差。**
> **⚠️ 当卦德本身就是"减损"时（损），六三的不当位反而正是这一卦的落点——小象传连位都不提，判词一个字也不给。**
> **⚠️ 这与咸卡的通则完全同构（"身体部位没有固定吉凶，吉凶由卦德决定"），本条把它从"部位"推广到"爻位"：**
> ### **位属性没有固定吉凶，卦德决定它的吉凶。**

**⚠️ 同时给"乘刚"专题补一条例外情形**：本库现有九种乘刚破解（收缩范围／交付成果／推行规矩／不预设收获／下附于仁／守住本职／辨明职分／主动放手／横向连结／跟从／解开结）。
**⚠️ 损六三是全卦唯一的乘刚，而它不需要任何破解——因为它是被减掉的那一个。**
> **⚠️ 新增条文：当卦德就是"减损"时，乘刚者的出路不是破解，是"成为被减的那一个"，而且这不构成咎（损六三无判词）。**
> **⚠️ 判据：先看这一卦要你留下还是要你走。要你留 → 用九种破解之一；要你走 → 走干净。**

### 5. 损 ↔ 咸（31）：交卦对照；损 ← 泰（11）：卦变来路

**⚠️ 咸卡末节点名了这个缺口**："其次：**损 41（上艮下兑）**——它正是咸卦的**上下卦交换**（咸＝上兑下艮，损＝上艮下兑）。**咸是'艮在下＋兑在上'（自己先止，对方愉悦）；损是'兑在下＋艮在上'（自己愉悦，却被压住不许动）。** 两卦合读，可以把兑／艮这一对反卦在复合卦里的两种叠加方式一次读完。"**本卡补上这一环。**

| | **咸 31（泽山咸）** | **损 41（山泽损）** |
|---|---|---|
| **卦象** | **上兑下艮** | **上艮下兑** |
| **结构含义** | **艮在下＝止在内（自己先止）；兑在上＝悦在外（位较正）** | **兑在下＝悦／欲在内（讨好陷阱位）；艮在上＝被压住不许动** |
| **当位数** | **4／6**（公式：3＋d艮2−d兑1＝4） | **2／6**（公式：3＋d兑1−d艮2＝2） |
| **彖传首句** | **柔上而刚下**——"**止而说，男下女**" | **损下益上，其道上行** |
| **卦德** | **感**（关系如何建立） | **减**（如何做减法） |
| **大象传** | **虚受人**（先把自己腾空） | **⚠️ 惩忿窒欲**（减自己的忿与欲） |
| **那份"悦／欲"用在哪** | **⚠️ 向外**——让对方悦（但绝不讨好，六二"凶，居吉"） | **⚠️ 向内**——承认"我这里有过多的欲"，然后窒住它 |
| **一句话** | **先止住自己，让对方愉悦** | **先按住自己的欲，然后减自己** |

> **⚠️ 合读结论（本卡对咸卡那个缺口的回答）**：
> **兑与艮这一对，在复合卦里的两种叠法给出了两个完全不同的动作，而它们共享同一个前置条件——先处理自己。**
> **咸（艮在下）：止在自己这边，所以先"止"、先"虚受人"（腾空），然后对方才会悦。**
> **⚠️ 损（兑在下）：欲在自己这边，上面又有山压着，所以先"惩忿窒欲"（按住），然后才有资格去减。**
> **⚠️ 两卦的大象传"虚受人"与"惩忿窒欲"是同一味药的两个剂型：一个是腾空以容人，一个是按住以能减。**
> **⚠️ 并且它们同时给"兑在下＝讨好陷阱"这条律补上了正面用法：那份"悦／欲"向外用是陷阱（兑六三"来兑，凶"），向内用（承认它、按住它）就是损卦的起点。**

**⚠️ 另一条来路：损与泰（11）的卦变关系（义理层·通行解，标注待校）**

按传统卦变的通行读法（⚠️ **此为义理层推演，非经文原文，本库标为"一说"**）：
- **泰 11**（上坤下乾）六爻：**阳 阳 阳 ｜ 阴 阴 阴**
- **把泰的九三与上六互换** → **阳 阳 阴 ｜ 阴 阴 阳** ＝ **损 41** ✓（机械可验）
- **这正是彖传"损下益上"的字面实现：下卦的那个阳（九三）交到了上位。**

**同理，益卦来自否卦**：
- **否 12**（上乾下坤）六爻：**阴 阴 阴 ｜ 阳 阳 阳**
- **把否的九四与初六互换** → **阳 阴 阴 ｜ 阴 阳 阳** ＝ **益 42** ✓
- **这正是益卦彖传"损上益下，自上下下"的字面实现。**

> **⚠️ 这条来路给损／益补上了一层极有价值的时机含义（本库泰否卡已有，可直接衔接）**：
> **⚠️ 损从泰来——"减"这个动作发生在顺境里。** 泰卦大象传"**财成天地之道，辅相天地之宜**"（本库泰否卡的解读是"顺境中的正确动作是裁和辅，顺境不是躺平期，是治理期"）。**损卦就是那个"裁"的具体化：顺境中主动减掉多的、病的。**
> **⚠️ 益从否来——"增"这个动作发生在逆境里。** 否卦大象传"**君子以俭德辟难**"（本库口径："逆境中的正确动作不是奋起对抗，而是俭以辟难"）。**而益卦补上了否卦缺的另一半：逆境里除了自己收敛，还要"损上益下"——上面主动往下给。**
> **⚠️ 合成一条可入库的口径：顺境要减（损自泰来），逆境要增（益自否来）。**
> **⚠️ 这与直觉正好相反（直觉是顺境加投入、逆境砍成本），也正是本组四卦最有实操价值的一条。完整的判据表见益卡第四节第 1 条。**
> **⚠️ 标注：卦变是义理层的通行读法，本库据两卦彖传"损下益上"／"损上益下，自上下下"采信其结构对应（机械可验），但不将它作为经文级依据。**

### 6. "惩忿窒欲"补上本库"对自己下的指令"这一族的第五条

《周易》大象传里那些**只对自己下指令、完全不指向外部**的纲领，本库现有四条，**本卡补上第五条，也是最具体的一条**：

| 卦 | 大象传 | 纲领 | 动作类型 | 要处理的对象 |
|---|---|---|---|---|
| **坎 29** | 水洊至，习坎 | **常德行习教事** | **做** | 日常功课 |
| **震 51** | 洊雷，震 | **恐惧修省** | **查** | 自己的过失 |
| **艮 52** | 兼山，艮 | **思不出其位** | **收** | 越界的念头 |
| **蹇 39** | 山上有水，蹇 | **反身修德** | **转** | 整个方向（转回自身） |
| **⚠️ 损 41** | 山下有泽，损 | **⚠️ 惩忿窒欲** | **⚠️ 减** | **⚠️ 忿与欲（点名的两样）** |

> **⚠️ 五条合读得出的口径（建议入库）**：
> **《周易》给"处境不好时该做什么"的全部纲领，无一条指向外部；而它们的具体程度是递增的——从"做功课"（坎）到"查自己"（震）到"收念头"（艮）到"转方向"（蹇），最后到损卦**点名两样东西**：忿与欲。**
> **⚠️ 而损卦点这两样，是因为它们正是让"减"这个动作变形的两个东西：带忿则减法变清算，带欲则减法变算计（减别人的、留自己的）。**
> **⚠️ 实操推论：凡是要动手做减法（裁员、砍预算、砍项目、缩编、断关系），第一个自查项不是"减哪些"，是"我现在有没有火气、有没有私心"。这两样在，就先别动手——因为损卦六爻里唯一的"凶"（九二"征凶"）与唯一被减掉的那一个（六三），都是在这两样东西上出的事。**

**⚠️ 顺带一条与谦卦（15）的分界（这两卦最容易混，必须写清）**：

| | **谦 15（地山谦）** | **损 41（山泽损）** |
|---|---|---|
| **纲领** | **裒多益寡，称物平施** | **惩忿窒欲** |
| **减什么** | **多出来的那部分资源**（钱、机会、曝光、话语权、功劳） | **⚠️ 自己的忿与欲**（前置）＋ **疾**（第一顺位）＋ **多**（第二顺位） |
| **给谁** | **⚠️ 横着给**——补到少的那一边，公平分配（平施） | **⚠️ 竖着交**——往上交（彖传"损下益上，其道上行"） |
| **你的处境** | **你已经有了实力与功劳**（九三"劳谦"，卦主） | **你在被要求减让的那一方**（下兑三爻） |
| **判词谱** | **全卦无凶**（吉／贞吉／吉／无不利／无不利／利） | **有一个"征凶"（九二）；卦辞含元吉** |
| **一句话** | **有了之后怎么分** | **该减的时候怎么减** |

> **⚠️ 分界问诊题（建议补入索引路由表）**：**"你现在是要把多出来的分给旁边的人，还是要把自己这块整体缩小？"**
> **分给旁边 → 谦（裒多益寡，横向平施）｜整体缩小并往上交 → 损（惩忿窒欲，竖向上行）。**
> **⚠️ 误路由的代价：拿谦卦去指导损卦的人，他会把该减的东西横向分掉而总量没减；拿损卦去指导谦卦的人，他会把本该分给同侧的东西全部上交，而谦卦要的是"平施"。**
