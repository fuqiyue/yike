# 知识卡 47 · 困卦（泽水困）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传/系辞传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："升而不已必困，故受之以困。"——一直往上走而不知停，必然走到"困"。⚠️ 上一卦升（46）本库尚未成卡，但这句话本身已经给出了困卦最重要的来路：**困不一定是从失败来的，更常是从"一路顺着往上、停不下来"来的。**
> 杂卦传："井通而困相遇也。"——困与井（48）是紧挨着的一对：**困是"通不了"，井是"通了"。**
> ⚠️ **本卦是本批四卦中最重要的一张，也是本库"极端处境"这一域的最后一块缺口。** 坎卦（29）讲的是**险**，困卦讲的是**穷**——**险是有东西要过，穷是资源耗尽、动不了。** 这条分界必须先立住，本卡才读得对（见第四节第 1 条）。
> ⚠️ **本卦有一句全书极罕见的卦辞："有言不信"。** 《周易》在这里直接否定了一种行动方式——**在困境中说话（解释、自证、申辩）是无效的。** 这是全卦落到现代最锋利的一条（见第四节第 2 条）。
> ⚠️ **系辞下传把困列入"九卦三陈"**："困，德之辨也……困以寡怨。" 本库已成卡的履（10）、谦（15）、恒（32）、巽（57）都在这个序列里，**井（48）紧接其后**。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 困 · 第四十七卦 |
| **卦象** | 上兑（泽／悦）下坎（水／险），称"泽水困"。<br>**大象传写作"泽无水"——这是全卦全部义理的源头。** 泽（蓄水的洼地）在上，水（坎）却在下：**水从泽底漏下去了，泽还在，水没了。** 不是没有容器，是容器空了。<br>**⚠️ 这个意象与坎卦（29）的"水洊至"（一波接一波来）正好相反**：坎是水太多把你淹了，**困是水漏光了把你干在那里**。<br>按本库结构律逐爻核对：<br>· **坎在下 → 初六、九二、六三三爻全部不当位**（规格第 4 节"六条最危险的位置"之首：**坎在下＝你已在险中**）；<br>· **兑在上 → 九四不当位、九五当位得中、上六当位**。<br>**全卦六爻只有九五、上六两爻当位，是本批四卦中当位最少者之二。**<br>**⚠️ 乘刚两处，且都被象传直接点名**：**六三乘九二**（象传"**据于蒺藜，乘刚也**"——经文自己写出了"乘刚"二字）；**上六乘九五**。<br>**⚠️ 九四不当位也被象传直接点名**（"**虽不当位，有与也**"）。**困卦是本库第一个由小象传两次直接证实爻位分析的卦**，其结构增量见第四节第 4 条。 |
| **领域定义** | **资源耗尽、动不了，而且说什么都没人信。** 具体：<br>① **现金流断了**——不是"有风险"，是账上真的没有了；每一个动作都需要钱，而钱不在；<br>② **失势之后**——降职、去职、被边缘化、公司缩编，你还在，但你调不动任何资源；<br>③ **长期消耗型处境**——慢性病、照护责任、长期债务、诉讼拖尾：不是一次打击，是能量被持续抽干；<br>④ **上面有资源但不给你**——你被卡在审批、预算、编制、名分上（九四"困于金车"、九五"困于赤绂"）；<br>⑤ **解释权丧失**——你越澄清越像掩饰，越自证越显得心虚（卦辞"有言不信"）；<br>⑥ **关系走到"无话可说"**——最亲近的人也不理解你，回家等于没有回家（六三"入于其宫，不见其妻"）。<br>凡是"**我不是不知道该怎么做，是我做不了——手上什么都没有了，而且我说的话没人当真**"，都落在困卦。 |
| **不归本卦的情况** | ① **险在身上、还有余力，问题是"怎么不往更深处走"** → **坎（29）**。⚠️ **这是最容易混、也最关键的一条分界**：**坎是险（有一道关要过，你还有力气），困是穷（没有关，只有没有——你连过关的力气都没有了）。** 坎九二的处方是"求小得"（还能动），**困卦的处方是"致命遂志"（先别动，先把心立住）**。<br>② **险还在前方、尚未入** → **需（5）**（待时）。<br>③ **你有能力，但环境黑、发亮招祸** → **明夷（36）**。⚠️ **明夷是"有光不许发"，困是"油已经烧完"。** 明夷的动作是**收光**（用晦而明），困的动作是**闭口**（有言不信）。两者都是"少露"，但一个藏能力，一个省能量。<br>④ **大势整体闭塞、天地不交** → **否（12）**。**否是全局判断，困是你个人的资源账户见底**——大势很好而你个人困住，是常态。<br>⑤ **只是暂时被柔性约束，雨还会来** → **小畜（9）**。<br>⑥ **有实力却被大结构压住不许发** → **大畜（26）**。**大畜是"被蓄住"（有出口，在攒），困是"被漏空"（没有出口，在减）。** |
| **"困"字本义** | 字形从"木"在"囗"中——**树长在围墙里，根还在，但长不开。** 训为窘、穷、乏、极。<br>**⚠️ 三层含义在本卦全部用到**：<br>· **穷**（资源用尽）——大象传"泽无水"；<br>· **围**（被限死）——六三"困于石，据于蒺藜"，上六"困于葛藟"；<br>· **辨**（被逼出真面目）——系辞传"**困，德之辨也**"。<br>**第三层是本卦最深的一层：困的功能不只是折磨你，是"辨"——把你是什么人辨出来。** 顺境里德行看不出来，因为不需要付代价。 |
| **卦辞原文** | 困：亨，贞，大人吉，无咎，有言不信。 |
| **⚠️ 卦辞的关键结构（本卦性格全在这里）** | **有"亨"、有"贞"，无"元"、无"利"，而末尾多出一句全书极罕见的否定句"有言不信"。**<br>**① "亨"字在这里被彖传当场重新定义。** 彖传说："**困而不失其所亨**"——**不是"困境是通的"，是"困住了，但你本来通的那个东西没有丢"。** ⚠️ **这与坎卦"维心亨"（只有心是通的）是同一种句法**：**《周易》在极端处境里从不承诺外部通达，只承诺"内里那一样东西还在"。**<br>**② 无"元"——不许你在困中启动新局。** 这一条落到现代极其实用：**困境中最常见的错误，就是想靠一个新项目、新方向、新平台把自己救出来。** 卦辞没给"元"。<br>**③ 无"利"——天道不许诺困境会给你带来好处。** 与师卦（7）"只有贞"、大有（14）"只有元亨"是同一种吝啬。**困的收益只有一样，写在系辞里："困，德之辨也"——你会更清楚自己是谁。这不是好处，这是代价换来的结果。**<br>**④ "大人吉"——与师卦"丈人吉"同一句法。** 彖传释为"**以刚中也**"：**吉不属于所有困住的人，属于那个内核刚硬且守中的人。** 困卦不是普惠的。<br>**⑤ ⚠️ "有言不信"是全卦最重的一句，也是《周易》卦辞层唯一一次直接否定"说话"这个动作。** 详见下一格。 |
| **⚠️⚠️ "有言不信"专解（本卡最重要的一格）** | **字面**：你说的话，别人不信。<br>**彖传的自注**："**有言不信，尚口乃穷也**"——⚠️ **"尚口乃穷"四个字是《周易》给出的因果判断：崇尚口舌，正是"穷"的来源。** 注意"穷"字：**困卦的本义是穷，而彖传说，让你更穷的那个动作就是"尚口"。**<br>**为什么困境中说话无效——三层机制：**<br>**① 信用是有账户的，而困境正是账户的低点。** 别人相信你，靠的不是这句话本身，是你过去兑现过的记录加上你当下的势。**失势时，同一句话的可信度会打折，而这个折扣与话的内容无关。**<br>**② 你在困中说的话，几乎必然是"关于自己"的话。** 解释、澄清、申辩、诉苦——**这些话的共同点是"要求对方改变对你的判断"，而这正是低信用时最贵的请求。**<br>**③ 说话消耗你唯一还剩的东西：时间与心力。** 泽无水，每一滴都要算。**在自证上花掉的能量，是从"贞"上扣的。**<br>**⚠️ 所以困卦的唯一有效动作不是解释，是"贞"。** 卦辞的语序就是答案：**亨（内里还在）→ 贞（守住正）→ 大人吉（内核刚中者才吉）→ 无咎（不落灾）→ 有言不信（别说话）。** 把"有言不信"放在最后，是**先给通路、再给底线、最后关掉那扇你最想推的门**。<br>**落到现代的四条操作**：<br>· **不做全网／全组织范围的澄清**；把说明只给"必须知道、且有权处理"的那一两个人；<br>· **把要说的话换成可验证的动作**——交一次货、还一笔钱、按时出现一次，比一万字长文有用；<br>· **接受"被误解要持续一段时间"是这一卦的常态**，不把它当成新的紧急事件；<br>· **⚠️ 唯一例外在九五："利用祭祀"**——**允许你把话说给不会评判你的对象**（祭祀之诚、日记、独处的自我复核）。**《周易》没有让你憋着，它是让你换收信人。** |
| **卦辞现代解** | **亨**——你本来通的那样东西还在（能力、信誉的底、一段关系、一个手艺），**困住的是流量，不是资产**。<br>**贞**——唯一有效的动作：把标准守住，不因为穷而降低底线。<br>**大人吉**——**内核刚硬、居中不偏的人，在这一卦里才有"吉"**；不是所有人都有。<br>**无咎**——**最好的结果是"没有落下灾祸"，不是翻盘**（与坎九五"无咎"同一量级）。<br>**有言不信**——**别解释。** |
| **彖传** | 困，刚掩也。险以说，困而不失其所亨，其唯君子乎。贞大人吉，以刚中也。有言不信，尚口乃穷也。 |
| **彖传要点** | ① **⚠️ 刚掩也**——"掩"是遮盖、掩蔽。**刚被柔掩住了**：本卦九二被初六、六三夹住，九四九五被上六压着。**"困"的结构定义就是这三个字：不是刚不够，是刚被盖住了。** 这一条落到现代：**困住你的往往不是能力不足，是能力发不出去。**<br>② **⚠️ 险以说**——下坎是险、上兑是悦（说＝悦）。**险在下面，而上面还得"悦"。** 这是本卦最难的姿态：**身在险中，表面还要和顺**。⚠️ **与师卦彖传"行险而顺"（坎下坤上）是同一句法的第二个版本**：师是"以顺的方式行险"，**困是"在险中还要保持悦"**——比师更难，因为"悦"要面对人。<br>③ **困而不失其所亨，其唯君子乎**——⚠️ **"其唯君子乎"是一句带感叹的限定：能做到的只有君子。** 彖传在这里承认了难度。<br>④ **以刚中也**——"大人吉"的全部理由是九二、九五的**刚中**。**刚（有内核）＋中（不偏激）。缺一样，卦辞的"吉"就不属于你。**<br>⑤ **尚口乃穷也**——见上格专解。 |
| **大象传（行动纲领）** | 泽无水，困。君子以致命遂志。 |
| **⚠️ "致命遂志"解（全卦最高原则）** | **致命**——"致"是送达、交付、极尽；"命"是性命，也是命运、天命。**"致命"＝把性命交付出去，即"把生死这一层放下、认下"。**<br>**遂志**——"遂"是达成、贯彻；"志"是心之所向。**"遂志"＝把自己的志向贯彻下去。**<br>**⚠️ 四个字连读的机制是一次交换：把"命"这一层交出去，换取"志"这一层的自由。**<br>**为什么在困卦是这个纲领——因为困的杀伤方式是"要价"。** 困境不断地跟你要东西：面子、安全感、体面、退路、时间。**只要你还有一样东西不肯给，它就还能拿它来逼你。** "致命"是把最后一样（命）也先放到台面上认了，**于是困境再没有可以要的东西，你的志才动得起来。**<br>**⚠️ 与坎卦纲领的分工（必须对照读）**：坎"**常德行习教事**"——**险中唯一能积累的是日常功课**（讲的是"做什么"）；困"**致命遂志**"——**穷中唯一要处理的是心里那笔账**（讲的是"先放下什么"）。**坎给你一份日课，困先给你一次结算。**<br>**落到现代的三条操作**：<br>· **先把最坏结果写下来并认下**（破产、离职、关系结束、病治不好）——不是悲观，是**把"怕"从每天的决策里拿掉**；<br>· **然后只保留一件"志"的事**，每天做一点，哪怕极小；<br>· **⚠️ 不要用"致命"去合理化冒险**。"致命"是心理上的放下，**不是行为上的赌命**——九二、上六都写着"征"（主动出击）的后果，见爻辞。 |
| **总铁律** | ① **闭口**——"有言不信""尚口乃穷"，**解释是本卦最贵的动作**（卦辞、彖传）；<br>② **不启新局**——卦辞无"元"；**困中所有"靠一个新东西翻盘"的方案都在初六"入于幽谷"的射程内**；<br>③ **不要主动出击**——九二明写"**征凶**"；<br>④ **不硬顶硬物**——六三"困于石，据于蒺藜"，系辞传的判语是"**非所困而困焉，名必辱；非所据而据焉，身必危**"；<br>⑤ **慢是对的**——九四"**来徐徐**"、九五"**乃徐有说**"，**本卦两次用"徐"字，是全书最集中的"慢"的授权**；<br>⑥ **把话说给不评判你的对象**——九二"利用亨祀"、九五"利用祭祀"，**本卦两次以祭祀为出口**；<br>⑦ **困到尽头必须动**——上六"**征吉**"是全卦唯一的"吉"字出击，**与九二的"征凶"正好相反：动与不动，取决于你在第几爻**（见第三节速查表与第四节第 3 条）。 |

## 二、爻级字段

### 初六 · 入于幽谷

| 字段 | 内容 |
|---|---|
| **爻辞** | 臀困于株木，入于幽谷，三岁不觌。 |
| **象传** | 入于幽谷，幽不明也。 |
| **位属性** | 阴爻居阳位，**不当位**；失中；**居坎险之最下、全卦最深处**。按本库结构律，坎在下 → 本爻必然不当位。 |
| **判词 → 行动语义** | **无吉凶判词，只给状态与时限（三岁不觌）** → **按本库口径，这是"《周易》承认你的难受，但不判你有咎"的一种；但它给了一个量：时间。行动指令是"承认自己看不清，不要在暗中做判断"。** |
| **关键词解** | **臀困于株木**——"株木"是砍剩的树桩。**坐在树桩上，坐不安稳也站不起来**：一个既不能歇又不能走的姿势。⚠️ 注意《周易》选的是"臀"——**受困的是你坐的地方，也就是你的立足点本身。**<br>**幽谷**——幽深的山谷，**不见光**。<br>**三岁不觌**——"觌"是见。**三年见不到（人／光／出路）。** |
| **⚠️ 象传给了原因** | "**幽不明也**"——⚠️ **象传把重点从"困"转到了"不明"：这一爻真正的问题不是处境深，是你看不清。** 落到现代：**刚陷进去的时候，你对局面的判断几乎全是错的**——不知道谁还会帮你、不知道这事会持续多久、不知道自己还剩多少。**在"幽不明"的状态下做的重大决定，多半要重做一次。** |
| **⚠️ "三岁"是本库第二次出现的时间刻度** | 坎卦上六"**三岁不得，凶**"——**滞留三年，凶**。困初六"**三岁不觌**"——**三年见不到**。<br>**两处对照的差别很重要**：**坎上六是"你不动，于是被困成牢笼"，判凶；困初六只是陈述"这段暗期有长度"，不判凶。**<br>**结论（本库口径）**：**"三岁"在《周易》里是"一个完整周期"的刻度，不是命运判决。** 在困初六，它的作用是**校准预期**：**这一段是按年算的，不是按周算的。** 按周算预期的人，会在第三个月崩掉。 |
| **识别信号** | ① 你刚失去主要的资源来源（收入、职位、平台、支持者），且还没找到替代；② 你现在的姿势"既歇不了也走不了"——不敢休息，也没有方向；③ 你发现自己**对局面的信息严重不足**，但仍在被迫每天做判断；④ 你在心里给这事定的期限是"一两个月"。 |
| **该做** | ① **承认"幽不明"**——把"我现在看不清"当成一项已知条件写下来；② **把预期从"月"改成"年"**，据此重排开销与承诺；③ **只做可逆的动作**（可退租、可撤回、可续期），把不可逆的决定推后；④ **保住那个"株木"**——哪怕坐得不舒服，先不要离开唯一还能落脚的地方。 |
| **不该做** | **在暗中赌大方向。** 也不要为了摆脱"坐不安稳"而随便找一个新方向冲出去——**那是往幽谷更深处走**。 |
| **与坎卦初六的对照（必读）** | 坎初六"**习坎，入于坎窞，凶**"，象传"**失道凶也**"；困初六"**入于幽谷**"，象传"**幽不明也**"。<br>**同是"入于……"的开局最深爻，同是不当位，判词却完全不同**：<br>· **坎初六判"凶"，原因是"失道"——你的路径错了，还在加倍走**；<br>· **困初六不判凶，原因是"不明"——你的路径未必错，只是看不见。**<br>**⚠️ 这就是"险"与"穷"在第一爻上的分别**：**险中最危险的动作是"加深"（做多了）；穷中最危险的动作是"在看不清时定方向"（判断错了）。** 一个要你停手，一个要你先睁眼。 |

### 九二 · 困于酒食（下卦刚中）

| 字段 | 内容 |
|---|---|
| **爻辞** | 困于酒食，朱绂方来，利用亨祀，征凶，无咎。 |
| **象传** | 困于酒食，中有庆也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**；**下坎唯一阳爻**，被初六、六三上下夹住——彖传"**刚掩也**"的第一处实例。**它就是彖传"以刚中也"所指的两爻之一。** |
| **判词 → 行动语义** | **征凶，无咎**（同爻两判） → **不动则无咎，主动出击则凶。行动指令：以诚敬自守，等"朱绂"到，绝不主动征伐。** |
| **关键词解** | **困于酒食**——⚠️ **此句两读，本库并列，且以象传定取向**：<br>· **读法 A（乏）**：困于酒食的匮乏——连吃喝都成问题。<br>· **读法 B（累）**：困于酒食的应酬——被宴饮、人情、场面缠住，动不了。<br>**象传说"中有庆也"（居中而有可庆之事），倾向于 B 或"虽困而实有余庆"**：⚠️ **所以本爻不是最穷的一爻，它是"看起来还过得去、其实动不了"的一爻。**<br>**朱绂方来**——"绂"是系印绶的丝带，引申为官服、使者、任命。朱（红）为贵。**朱绂方来＝有名分、有援助、有机会正在来的路上。**<br>**利用亨祀**——"亨"读作"享"。**宜于举行享祭：以诚敬奉献的方式自处。**<br>**征凶**——**主动出征则凶。** |
| **⚠️ 本爻是全卦的操作核心** | **它把困卦最反直觉的一条写全了："朱绂方来"与"征凶"同时出现。**<br>**援助正在来的路上，而你此时出击就是凶。** 为什么——**因为"方来"意味着它还没到，你手上的资源仍然是空的。** 在资源到位之前发起的行动，用的是"预期"而不是"实有"，**而困卦的底色是"泽无水"：没有的东西不能当有的用。**<br>**落到现代**：融资已过会但钱没打款、offer 已口头但合同没签、领导说"回头给你安排"但文件没下——**这三种状态都是"朱绂方来"。此时对外承诺、对内加码、提前扩张，就是"征"。**<br>**⚠️ 本库口径提醒**：**"无咎"不等于吉**（规格第 3 节）。**九二得中、有援将至，最好的结果也只是"无咎"**——这与坎九五"无咎"、困卦辞"无咎"是同一量级。**困卦全六爻只有一个"吉"字（上六"征吉"）和一个"终吉"（九四）。** |
| **识别信号** | ① 你在困中，但表面看还过得去，甚至还有饭局、还有人找你；② 有一个明确的好消息"正在路上"，但还没落地；③ 你很想趁这个消息先动起来——先招人、先签约、先宣布；④ 你的时间被大量低效社交占满，而真正的问题一件没解决。 |
| **该做** | ① **等它到账再动**——把"朱绂"到位的客观标志写清楚（钱到账／合同签字／文件下发），**以此为唯一启动线**；② **"利用亨祀"落到现代＝把姿态放在"诚敬地做本分"上**：把手上确定该做的事做干净，不做姿态性动作；③ 主动**削减酒食**——把被应酬占掉的时间收回来。 |
| **不该做** | **凭"方来"出击**（征凶）。也不要因为"还过得去"就否认自己在困中——**"困于酒食"正是最容易被自己否认的一爻。** |
| **与坎卦九二"求小得"的对照** | **两爻结构完全同构**：都是下卦唯一阳爻、都不当位而得中、都是本卦下半的操作核心。**但处方相反**：<br>· **坎九二"求小得"——要你动，只是把目标切小**（象传"未出中也"）；<br>· **困九二"征凶"——要你不动，等资源到位**（象传"中有庆也"）。<br>**⚠️ 这一组对照是"险"与"穷"分界的最强证据**：**险中你还有力气，所以"小步走"是对的；穷中你没有力气，"小步走"也会把最后一点耗掉，所以要等。** 同一个位置、同一个结构，**只因为一个是水太多、一个是水漏光，指令就完全反转。** |

### 六三 · 困于石，据于蒺藜

#### ⚠️ 本爻是全卦最重的一爻，且是《周易》全书唯一被系辞传专门加注的困卦爻

| 字段 | 内容 |
|---|---|
| **爻辞** | 困于石，据于蒺藜，入于其宫，不见其妻，凶。 |
| **象传** | 据于蒺藜，乘刚也。入于其宫不见其妻，不祥也。 |
| **位属性** | 阴爻居阳位，**不当位**且失中；**居下坎之顶**（险之极），**乘九二之刚**。<br>⚠️ **本爻是本库最重要的一条经文级结构证据：小象传直接写出"乘刚也"三个字。** 本库"乘刚"这一分析工具，在这里得到了经文自身的确认（详见第四节第 4 条）。 |
| **判词 → 行动语义** | **凶** → **按本库口径，"凶"是《周易》所有结局中最坏的。行动语义：此爻不可入；已在此处，唯一动作是从"石"和"蒺藜"上撤下来。** |
| **关键词解** | **困于石**——被石头挡住。**石是硬的、不动的、你顶不过的东西。**<br>**据于蒺藜**——"据"是凭靠、扶着、坐上去；"蒺藜"是带刺的野生植物。**你伸手去扶的、去坐的，是一丛刺。** ⚠️ **注意"据"是主动动作：石头是它挡你，蒺藜是你自己去靠的。**<br>**入于其宫，不见其妻**——回到自己家里，见不到妻子。**最后一个可以退回去的地方也空了。**<br>**⚠️ 与大象传"泽无水"同构**：**宫在，人不在；泽在，水不在。** 本卦反复讲的就是这一件事——**形式还在，内容没了。** |
| **⚠️ 象传的两句判语** | ① "**据于蒺藜，乘刚也**"——**你之所以扶到刺，是因为你压在刚的上面。** 六三是阴柔，下面顶着九二的阳刚：**你想借力的那个东西，正在往上顶你。** 落到现代：**弱势时去依靠一个比你强、且利益不一致的人／机构，那不是靠山，是蒺藜。**<br>② "**入于其宫不见其妻，不祥也**"——"不祥"是全书用得极少的重词。**它不再讲吉凶得失，讲的是"这个状态本身不对"。** |
| **⚠️⚠️ 系辞下传对本爻的专门解释（经文级，务必逐字读）** | 系辞下传引本爻后云：<br>"**非所困而困焉，名必辱；非所据而据焉，身必危。既辱且危，死期将至，妻其可得见邪？**"<br>**逐句落地：**<br>· **非所困而困焉，名必辱**——**在不该跟它较劲的地方较劲，名声一定受损。** "困于石"就是这种：**石头本来不是你的对手，是你自己选它当对手的。** 现代形态：**跟平台规则较劲、跟制度较劲、跟一个根本不会改主意的人反复争论、在评论区跟所有人辩到底。**<br>· **非所据而据焉，身必危**——**去依靠不该依靠的东西，人身一定危险。** 现代形态：**借高息钱周转、把身家押在一个单一强势合作方身上、为了求助而交出核心资产或个人担保。**<br>· **既辱且危**——**⚠️ 注意这两个错误是叠加的**：先在硬东西上耗掉名声（辱），再为了续命去抓刺（危）。**困境中的崩溃，几乎都是这个两步组合。**<br>· **妻其可得见邪**——所以最后连家也空了。**这不是诅咒，是链条的终点：名辱→身危→众叛。**<br>**⚠️ 系辞传在这段之前先给了正面公式**："**君子安其身而后动，易其心而后语，定其交而后求。**"<br>**这三句正是六三的解药，而且是本库"困境中如何求助"的最佳操作定义**：<br>· **安其身而后动**——**先把自己安顿住，再动**（对应"致命遂志"）；<br>· **易其心而后语**——"易"是平和；**先把心平了，再说话**（对应"有言不信"：不是永远不说，是**心不平时不说**）；<br>· **定其交而后求**——**⚠️ 先把关系确定下来，再提请求。** 这一句直接破"据于蒺藜"：**不要向一段还没有确定的关系伸手求救。** |
| **识别信号（诊断清单）** | ① 你正在跟一个**明显不会改变的东西**较劲（规则、制度、判决、一个铁了心的人），而且已经投进去大量时间与声望；② 你为了周转，正在考虑或已经动用了**有刺的资源**——高成本借贷、附带苛刻条件的援助、需要交出核心权益的合作；③ **你回到家（或独处）时也得不到支持**，最亲近的人已经不理解你在做什么；④ 你同时在"顶硬东西"和"抓刺"这两件事上——**⚠️ 这两项同时成立，就是本爻。** |
| **该做** | ① **立刻从"石"上撤下来**——公开或私下停止那场较劲，接受"这一局不争了"；② **立刻停止"据蒺藜"**——不再新增任何带刺条件的资源；已经有的，按"止损优先于面子"重排；③ **回到系辞的三句公式**：先安身（保住基本生活与健康）、再平心（心不平不说话）、再定交（先修关系，后提请求）；④ **把"不见其妻"当成第一优先级**处理——**关系不是你翻盘之后再修的东西，它是你翻盘的条件。** |
| **不该做** | **在这一爻里继续"努力"。** ⚠️ **本爻的凶不来自懈怠，来自用力的方向**——顶石头、抓刺，都是很努力的动作。 |
| **与坎卦六三的对照** | **两爻位置完全同构**（阴居三位、不当位、失中、居下坎之顶），**但结局与处方不同**：<br>· **坎六三"来之坎坎，险且枕，入于坎窞，勿用"**，象传"**终无功也**"——**进退都是险，判"勿用"：全面停手，动也没用。**<br>· **困六三"困于石，据于蒺藜……凶"**，象传"**乘刚也**""**不祥也**"——**不是"动了没用"，是"你动的方式在制造伤害"。**<br>**⚠️ 差别的实操意义**：**坎六三要你"停"，困六三要你"改换对象"**——从石头上下来、从刺上放手，**然后仍然要去做"安身、平心、定交"这三件事**。**困六三不是无解爻，它的解药写在系辞里，只是不在爻内。** |
| **与讼卦的呼应** | 讼卦（6）的整体口径是"**中吉终凶**"——冲突死磕到底必凶。**困六三是"死磕"在极端匮乏状态下的样子**：讼卦你至少还有资源打官司，**困六三是你已经没有资源，还在跟石头较劲。** 同一个错误，代价高一个量级。 |

### 九四 · 来徐徐

| 字段 | 内容 |
|---|---|
| **爻辞** | 来徐徐，困于金车，有言，终吉。 |
| **象传** | 来徐徐，志在下也。虽不当位，有与也。 |
| **位属性** | 阳爻居阴位，**不当位**；失中；**已入上兑**。按本库结构律，兑在上 → 九四必然不当位。<br>⚠️ **本爻的小象传直接写出"虽不当位"四字**——**这是本库爻位分析的第二处经文级确证。** |
| **判词 → 行动语义** | **终吉** → **慢慢来、被阻也不改方向，最终得吉。行动语义：把节奏放到最慢，坚持要去的那个方向。** |
| **关键词解** | **来徐徐**——"来"是往下、返回（下行为来）；"徐徐"是缓慢、从容。**缓缓地往下来。**<br>**困于金车**——"金车"是贵重的车。⚠️ **两读并存**：① **被金车所阻**（有一个体面而强大的东西挡在中间）；② **困在金车里**（坐着好车却动不了——有名分、有排场，却调不动实际资源）。**本库取"两义并存"，因为九四正是"位不当而有位"的爻：有名分、无正位。**<br>**有言**——⚠️ **注意与卦辞"有言不信"的呼应**：**这里会有议论、会有人说话**（对你的非议，或你想开口）。**爻辞把"有言"放在"终吉"之前**：**议论是过程中必然出现的一段，不是结局。**<br>**终吉**——**最终得吉。**⚠️ **"终"字是限定：吉在后面，不在现在。** |
| **⚠️ 象传两句都是关键** | ① "**来徐徐，志在下也**"——**慢，是因为志在下面。** 九四的方向是往下去（照本卦通行解，是要去应下面的初六）。**"志在下"落到现代：你要救的、要接的、要负责的那个对象在你下面（下属、家人、更弱的一方、你自己的根本盘），而不是在上面。**<br>**⚠️ 这与九五"志未得也"形成一组**：**九四知道自己志在哪儿，只是慢；九五则是"志未得"。位置更高的那个，反而更不得志。**<br>② "**虽不当位，有与也**"——**位置虽然不正当，但有相与者（有人配合、有伙伴）。**<br>**⚠️ 这是本库通则的一条重要补充**：规格第 3、4 节口径是"不当位＝名不正言不顺"，并有"**得中可救不当位**"一条。**九四既不当位又不得中，本该最差；但象传给出了第三条救法："有与"——有人跟你在一起。**<br>**本库由此可提一条新律**：**不当位的三种救法——① 得中（坎九二、困九二）；② 有与（困九四）；③ 居中主事而不越位（师九二）。第二条是本卡的增量：在极端匮乏中，"有人和你一起"本身就是一种正当性来源。** |
| **识别信号** | ① 你想去帮／去接一个比你更弱的对象（下属、家人、老客户、自己的基本盘），但你自己也困着；② 中间挡着一个**体面而强硬的障碍**——一道流程、一个更有资源的第三方、一份"看起来很好"的安排；③ 你有名分、有头衔、有场面，**但调不动实际资源**（困于金车的第二读）；④ 已经开始有人议论你了（有言）。 |
| **该做** | ① **慢**——"徐徐"是本爻明写的方法，不是妥协。**在困卦里，慢等于省水。**<br>② **认下"有言"这一段**——议论会来，按卦辞处理（不解释），按本爻处理（不改方向）；<br>③ **⚠️ 把"有与"当成资产来经营**——**你唯一的正当性来源是"还有人跟你一起"**，所以：先保住同行的人，再谈进度；<br>④ 方向不改（志在下），速度可改。 |
| **不该做** | ① **加速**——为了摆脱议论而抢时间，会正好撞上"金车"；② **改方向**——把"志在下"改成"志在上"（转头去讨好上面），**会同时丢掉"有与"和"终吉"**；③ 靠头衔和排场撑场面（金车之困的来源）。 |
| **与坎卦六四"纳约自牖"的对照** | **两爻都是本卦下半转上半的转机爻，处方也是同一族**：<br>· **坎六四"樽酒簋贰，用缶，纳约自牖，终无咎"**——**极简 ＋ 走侧门，先把关系接上**（象传"刚柔际也"）；<br>· **困九四"来徐徐……终吉"**——**放慢 ＋ 不改方向，守住"有与"**（象传"有与也"）。<br>**⚠️ 两者的共同点是"降规格"**：坎六四降的是**礼的规格**，困九四降的是**速度的规格**。**极端处境里的转机，从来不是靠加大投入拿到的，是靠把某一项规格降下来腾出空间。**<br>**且注意判词的差别**：**坎六四只能"终无咎"，困九四能"终吉"。** 在整卦更苦的困卦里出现了更好的判词——**因为困九四有"有与"，而坎六四是孤身走窗口。** |

### 九五 · 劓刖，困于赤绂（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 劓刖，困于赤绂，乃徐有说，利用祭祀。 |
| **象传** | 劓刖，志未得也。乃徐有说，以中直也。利用祭祀，受福也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位；**上兑之中**；**被上六乘刚**（上六压在其上）。<br>**它是彖传"以刚中也"所指的第二爻，也是卦辞"大人吉"所指之爻——本卦卦主。** |
| **判词 → 行动语义** | **无吉凶判词，只给过程（乃徐有说）与方法（利用祭祀）** → **按本库口径，这属于"无判词＋只给方法"。行动语义：承认此刻志未得，把节奏放慢，用诚敬之事守住内核，等"说"（解脱）自己慢慢出来。** |
| **关键词解** | **劓刖**——"劓"是割鼻，"刖"是断足，**都是古代肉刑**。⚠️ **两个字合起来是"上下俱伤"之象**：**鼻在上、足在下**——**上面（名声、体面、话语权）被伤，下面（立足点、行动能力）也被伤。** ⚠️ 版本待核：此二字亦有作"臲卼"（不安）者，本库照通行本作"劓刖"。<br>**困于赤绂**——"赤绂"与九二"朱绂"同类而更贵，**指高位的服饰、名分**。**困于赤绂＝被自己的高位困住。**<br>**乃徐有说**——"说"读作"脱"（解脱），亦可读"悦"。⚠️ **本库取"两义并存"**：**慢慢地才有解脱，也才有喜悦。** 注意"**乃**"和"**徐**"两个字：**不是马上，也不是快。**<br>**利用祭祀**——**宜于祭祀。** 与九二"利用亨祀"呼应，**是本卦第二次把出口指向祭祀。** |
| **⚠️ 本爻是全卦最反直觉的一条** | **全卦最高、最正、最中、居尊位的一爻，判词里没有"吉"字。** 只有"乃徐有说"（慢慢会解脱）和"利用祭祀"（宜于诚敬），加上象传一句"**志未得也**"。<br>**⚠️ 这与坎九五"坎不盈，祗既平，无咎"（象传"中未大也"）是同一现象的第二例**：<br>· **坎九五：当位得中居尊，判词只有"无咎"**，因为**险中不给你"盈"**；<br>· **困九五：当位得中居尊，连"无咎"都没给**，只给"慢慢会解脱"，因为**穷中不给你"得志"**。<br>**⚠️ 本库口径的重要一条**：**当位得中居尊，只保证"你是对的那个人"，不保证"你此刻能成事"。** 明夷卦（36）已用"五爻当位却拿不到吉"证过一次；**困九五把它推到极处：连尊位卦主也只能等。** |
| **⚠️ "困于赤绂"：位高反而更困** | **九二"困于酒食"是低位之困（吃喝应酬），九五"困于赤绂"是高位之困（名分体面）。** 两爻同为刚中，**困的东西恰好相反**：<br>· 低位的人被**生计与人情**困住；<br>· 高位的人被**名分与责任**困住——**位置越高，可以放弃的东西越少，动作空间越小。**<br>**落到现代**：一把手在组织出问题时往往是最不能动的人——**他一动，市场、员工、上级、客户四方全部读出信号**。**"劓刖"（上下俱伤）正是这种处境：讲话有风险，行动有风险。** |
| **⚠️ 象传"以中直也"与"受福也"** | ① "**乃徐有说，以中直也**"——**能慢慢脱困，靠的是"中"（不偏）与"直"（不弯）。** ⚠️ **注意《周易》给的不是"术"，是两个品质。** 在"劓刖"这种上下俱伤的处境里，**能拿来用的只有你还没变形的那一部分。**<br>② "**利用祭祀，受福也**"——**祭祀之所以有益，是因为"受福"。**<br>**⚠️ 本库合规口径**：**本条不作任何祈福灵验的断言。** 本库把"祭祀"读作一个**结构性动作**：**把话与心交付给一个不会评判你、不会转述你、也不与你争利的对象。** 对现代读者，它对应的是：**独处的自我复核、写给自己看的记录、对一套长期价值的重新确认、有仪式感的静默。** **它的功能是把"有言不信"造成的憋闷排掉，而不把它排到会伤害你的地方去。** |
| **识别信号** | ① 你是这件事上位置最高、最"该有办法"的人，**而你恰恰最动不了**；② 你同时在两头受损：**说话被解读（鼻），行动被掣肘（足）**；③ 你的名分、头衔、责任本身构成了约束（困于赤绂）；④ 你心里有一个"本该已经实现"的目标没实现（志未得），并因此持续消耗。 |
| **该做** | ① **接受"徐"**——把时间表整体拉长，**明确告诉自己"解脱是慢慢来的"**；② **守住"中直"**——不偏袒任何一方、不为脱困而弯标准，**这是本爻唯一的凭据**；③ **建立"祭祀"式的出口**——固定时间、固定形式、不对外的自我交付（记录、复核、静处）；④ 把"志未得"从耻辱改记为**当前状态**。 |
| **不该做** | ① **为了快而破"中直"**——本爻能脱困的全部理由就是中直；② **把憋闷排到会评判你的人身上**——那是回到"有言不信"；③ 用高位强推一个此刻推不动的方案（劓刖已经说明上下都有伤口）。 |
| **与师卦六五、讼卦九五、坎卦九五的四"五"对照** | · **师六五**（不当位·得中·居尊）——职责是"**选对人然后放手**"，无咎／贞凶两结局；<br>· **讼九五**（当位·得中·居尊）——职责是"**中正裁决、案结事了**"，**元吉**；<br>· **坎九五**（当位·得中·居尊）——职责是"**水平即止、不求满**"，**无咎**；<br>· **困九五**（当位·得中·居尊）——职责是"**守中直、待徐说、以祭祀自持**"，**无判词**。<br>**⚠️ 四个尊位排下来，判词等级严格随处境递降：元吉 ＞ 无咎／贞凶 ＞ 无咎 ＞ 无判词。** **这条序列是本库"处境决定尊位能兑现多少"的最清楚证明：位置一样，能拿到的完全不一样。** |

### 上六 · 困于葛藟

| 字段 | 内容 |
|---|---|
| **爻辞** | 困于葛藟，于臲卼，曰动悔有悔，征吉。 |
| **象传** | 困于葛藟，未当也。动悔有悔，吉行也。 |
| **位属性** | 阴爻居阴位，**当位**；居全卦之终；**乘九五之刚**（兑在上，上六必乘刚）。<br>⚠️ **象传却说"未当也"**——**本库读作"所处未当"（困之极处本身不是个正当的位置），不是"爻位不当"**：按结构律，阴居上位是当位，此处不可误读为位不当。标注供后续校核。 |
| **判词 → 行动语义** | **征吉** → **主动出击，得吉。行动语义：困到极处，唯一的出路是动；且必须接受"动了会后悔"这件事。** ⚠️ **这是全卦唯一的"吉"字判词，也与九二"征凶"正好相反——请务必与九二对读。** |
| **关键词解** | **葛藟**——葛与藟都是藤类蔓生植物。**被藤缠住**：⚠️ **注意这与六三"石"和"蒺藜"的差别——藤是软的、缠人的、不致命的。** 落到现代：**不是有一个硬障碍挡着你，是无数细小的牵扯把你缠住了**（人情、旧承诺、零碎义务、习惯、别人的期待）。<br>**臲卼**——不安、动摇不定的样子。**坐立不安。**<br>**曰动悔有悔**——⚠️ **本句是全书句读最难处之一，两读并存**：<br>· **读法 A**：（自己）说"动了会后悔"，于是果然生出悔——**因为怕悔而不动，最后还是悔。**<br>· **读法 B**：说"动会后悔"，但有这份悔意（即知悔改）——**所以"征吉"。**<br>**⚠️ 本库取两读并存，因为两读指向同一个行动结论**：**"动会后悔"这个念头本身，是这一爻要破的东西。** 象传"**动悔有悔，吉行也**"把话说定了：**这个"行"是吉的。**<br>**征吉**——**主动前往、出击，吉。** |
| **⚠️ 本爻是全卦的出口，机制必须写清** | **困到极处，缠住你的东西已经不是硬的（石），而是软的（藟）。** 而软的东西的特点是：**它不阻止你动，它只让你不想动。**<br>**"曰动悔有悔"精确描述了这个心理机制**：**你先在心里预演一遍"动了会后悔"，然后就不动了；而不动的结果，是照样后悔。** ⚠️ **《周易》在这里没有承诺"动了不会后悔"，它说的是"动，吉"。** **两件事同时成立：会有悔，且是吉的。**<br>**落到现代的三条**：<br>· **困久了之后，最大的敌人是"想象出来的后果"**——你能列出十条动起来的坏结果，一条都没试过；<br>· **牵扯型束缚必须一根一根剪**，不能等一次性解决（藤没有主干）；<br>· **⚠️ 接受"动了会有一部分损失"是本爻的入场费**——不愿付这笔费的人，会一直留在上六。 |
| **⚠️ "征凶"（九二）与"征吉"（上六）：本卦最重要的一组反转** | **同一个"征"字，同一卦之内，一处凶一处吉。** 差别只有一样：**位置（时机）。**<br>· **九二"征凶"**——**援助正在来的路上（朱绂方来），此时出击是拿"预期"当"实有"**，故凶；<br>· **上六"征吉"**——**已困到极处，缠的是软藤，等不来任何东西了**，故吉。<br>**⚠️ 本库口径（可直接用于"定势"）**：<br>> **困卦不问"该不该动"，只问"你在第几爻"。**<br>> **有东西在来的路上 → 不动（九二）。**<br>> **什么都不会来了 → 必须动（上六）。**<br>**判断标准很硬：写下"我在等什么"。写不出具体对象与时间的，就是上六。** |
| **识别信号** | ① 你已经困了很久，**缠住你的不是一个大障碍，是一堆小牵扯**；② 你坐立不安（臲卼）却什么都没做；③ **你能非常流畅地说出"动了会有什么坏结果"，但从没试过**；④ 你等的那个东西，已经说不出具体是什么、什么时候来。 |
| **该做** | ① **动**——**本爻明写"征吉"，这是全卦唯一的出击授权**；② **一根一根剪藤**：把牵扯列成清单，按"最容易解除且最占心力"排序，逐项了结；③ **预先给"悔"留预算**——**接受动起来会损失一部分东西（关系、面子、一笔钱），把它当入场费而不是失败**；④ 回到大象传"**致命遂志**"：把最坏结果认下，"志"才动得起来。 |
| **不该做** | ① **继续等**；② 追求"一次性、无损失地脱困"——**"有悔"是本爻明写的条件**；③ ⚠️ **把"征吉"读成"可以乱来"**：本爻的"征"是**从缠绕中走出去**，不是回头去顶六三的石头，也不是去抓蒺藜。 |
| **与坎卦上六的对照（本卡最重要的一组尾爻对照）** | · **坎上六"系用徽纆，置于丛棘，三岁不得，凶"**，象传"**上六失道，凶三岁也**"——**当位却凶，因为"失道 ＋ 长期不动"**；<br>· **困上六"困于葛藟……征吉"**，象传"**动悔有悔，吉行也**"——**当位而吉，因为"动"**。<br>**⚠️ 两爻的处境几乎一样：都是被缠住（徽纆／葛藟）、都在最上、都当位。差别只有一个动作——坎上六不动，困上六动。**<br>**结论（本库口径）**：**极端处境的最后一爻，吉凶不由位置决定，由"动不动"决定。** 坎卦已经把不动的代价标好了价（凶三岁）；**困卦把动的收益也标好了（征吉），并且诚实地告诉你附带成本（有悔）。** **这两爻合起来，是本库对"长期困境如何收尾"给出的完整答案。** |
| **与巽卦上九的对照** | 巽上九"**丧其资斧，贞凶**"——**居高位还一味卑顺，丢掉了断决之力**。**困上六恰是反面：柔在最上，却拿回了"征"这个决断。** ⚠️ **同为柔顺之极的尾爻，一个丢了斧子判贞凶，一个动起来判吉。** 差别在于：**巽上九是在还有余地时放弃决断，困上六是在没有余地时重新决断。** |

## 三、困卦定位速查表

| 爻 | 处境 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | 刚陷入 | 入于幽谷 | 资源刚断，且你看不清局面 | 不当位·险之最下 | **无判词·"三岁"校准预期**·先睁眼，只做可逆动作 |
| 九二 | 表面还过得去 | 困于酒食 | 好消息在路上，但还没到 | 不当位但**得中**·刚被掩 | **征凶／无咎**·等它到账再动 |
| 六三 | 两头出错 | 困于石·据蒺藜 | 既在顶硬东西，又在抓有刺的资源 | 不当位·失中·**乘刚**（象传明言） | **凶**·从石上下来、从刺上放手 |
| 九四 | 转机初现 | 来徐徐 | 想去接下面的人，中间挡着体面的障碍 | 不当位（象传明言）但**有与** | **终吉**·放慢、不改方向、保住同行者 |
| 九五 | 高位之困（**卦主**） | 劓刖·困于赤绂 | 你最该有办法，却最动不了 | **当位·得中·居尊** | **无判词**·守中直·徐有说·以祭祀自持 |
| 上六 | 困之极 | 困于葛藟 | 缠住你的是一堆小牵扯，而你只在预演后悔 | 当位（象传"未当也"＝所处未当）·**乘刚** | **征吉**·必须动，并接受"有悔" |

**困卦三句话**：
1. **困不是险，是穷**——险是有一道关要过，穷是资源耗尽动不了。所以处方不是"求小得"（坎），是先"致命遂志"：**把最坏结果认下，换回志的自由。**
2. **困境中最贵的动作是说话**——"有言不信""尚口乃穷"。**唯一有效的不是解释，是"贞"**；憋不住的部分，交给"祭祀"式的出口，不要交给会评判你的人。
3. **动还是不动，只看你在第几爻**——**有东西在来的路上就不动（九二征凶），什么都不会来了就必须动（上六征吉）。** 判断标准：**写下"我在等什么"，写不出具体对象与日期的，就是上六。**

**本卦最反直觉的三条**：
- **卦辞给了"亨"，彖传却把它改释为"困而不失其所亨"**——**不是处境通，是你本来通的那样东西没丢。** 困卦不承诺出路，只承诺你还在。
- **九五当位、得中、居尊、是卦主，判词里连"无咎"都没有**，象传只说"志未得也"。**位置全对，救不了处境全空。**
- **同一个"征"字，九二判凶、上六判吉。** 《周易》在同一卦里给出相反指令，**证明它给的从来不是规则，是"先看你在哪一爻"。**

## 四、本卦对全库的意义

### 1. ⚠️ 补上全库最后一块极端处境缺口：把"险"与"穷"分开

本库此前处理极端处境的主力是**坎（29）**及坎在下的蒙（4）、讼（6）、师（7）。但这一族全部是**"险"**：**有一道具体的关横在那里，你有力气，问题是怎么过、怎么不陷更深。** 困卦补上的是另一种：**"穷"——没有关，只有"没有"。**

| | **坎 29（险）** | **困 47（穷）** |
|---|---|---|
| 卦象 | 上坎下坎，**水洊至**（一波接一波来） | 上兑下坎，**泽无水**（水漏光了） |
| 处境的本质 | **东西太多**（打击、风险、债务不断加码） | **东西没有**（资源、名分、可信度见底） |
| 卦辞唯一的通路 | **维心亨**——只有心是通的 | **困而不失其所亨**——本来通的没丢 |
| 纲领 | **常德行习教事**——险中唯一能积累的是日课 | **致命遂志**——穷中先做一次心里的结算 |
| 下半的核心处方 | **求小得**（九二）——**要动，把目标切小** | **征凶**（九二）——**不要动，等资源到位** |
| 最后一爻 | **不动 → 凶三岁**（上六） | **动 → 征吉**（上六） |
| 尊位判词 | **无咎**（九五，"中未大也"） | **无判词**（九五，"志未得也"） |
| 主要杀伤方式 | **加深**（沉没成本、加倍投入） | **尚口**（解释、自证）＋ **据蒺藜**（抓有刺的资源） |

> **定域路由的一句话判据（可直接用）**：
> **问"我还有力气吗"。**
> **有力气、但前面有关 → 坎（29）：求小得，勿加深。**
> **没力气、前面没关只有空 → 困（47）：致命遂志，闭口守贞，看清自己在第几爻再决定动不动。**

⚠️ 附带一条修正：本库坎卦卡末节的总表按"坎在上／在下"列了蒙、讼、师、屯、需、比六卦。**困卦是该表新增的一行，且是唯一一个"坎在下而上卦为兑"的**——**上兑（悦）意味着：这一卦的险不只要承受，还要对着人保持和顺**（彖传"险以说"）。**这比师卦的"行险而顺"更难：顺可以对事，悦必须对人。**

### 2. ⚠️ "有言不信"：全库第一条"沟通禁令"，以及它与三条现有纲领的关系

《周易》卦辞层直接否定一个具体动作的地方极少，**"有言不信"是最明确的一处**，且彖传补了因果："**尚口乃穷也**"。本库由此新增一条口径：

> **失势期的沟通律**：**信用不是由内容决定的，是由"账户余额 × 当下势位"决定的。** 同一句话，在困卦里的可信度会被打折，而**折扣与话的对错无关**。因此困卦中：
> **① 不做广域澄清**；**② 把说明只给"必须知道且有权处理"的人**；**③ 把要说的话尽量换成可验证的动作**；**④ 心不平时不说话**（系辞"易其心而后语"）；**⑤ 憋闷交给不评判你的对象**（九二"利用亨祀"、九五"利用祭祀"）。

**与三条已有纲领并列，可以看出《周易》对"露不露"给的是一张四格表**：

| 卦 | 环境 | 你有什么 | 纲领 | 对"表达"的指令 |
|---|---|---|---|---|
| **离 30** | 亮 | 有光 | **继明照于四方** | **必须照出去，而且不能断** |
| **大有 14** | 亮而多 | 东西多 | **遏恶扬善** | **必须辨、必须表态处置** |
| **明夷 36** | 黑 | 有光 | **用晦而明** | **把光收起来，只留自己看见** |
| **困 47** | 穷 | 光还在但没油 | **致命遂志** | **闭口；把话换成动作，把憋闷交给祭祀** |

⚠️ **明夷与困必须分清，这是本条最实用的部分**：
- **明夷"用晦而明"是"藏能力"**——你亮就招祸，收光是为了不当靶子；
- **困"有言不信"是"省能量、认现实"**——你说了也没人信，闭口是因为**说话不产生效果，只消耗你唯一还剩的东西**。

**一句话**：**明夷不许你亮，困不许你说。** 前者的风险来自别人的恶意，后者的无效来自你自己的势位。

### 3. ⚠️ "征凶／征吉"同卦反转：本库第一条"同一动作、按爻位反转"的实证

规格第 3 节给了判词的吉凶排序与语义，但此前没有一卦在**同一个动词**上同时给出正反两判。**困卦九二"征凶"与上六"征吉"是全库最干净的一例**（且都不是模糊表述，两爻各自的象传都作了支持：九二"中有庆也"、上六"吉行也"）。

**它证明的是本库方法论的核心**：
> **《周易》给的不是行为规则，是"先定位、再行动"。** 同一个"征"，在有援将至时是凶（因为你在用预期当实有），在无援可待时是吉（因为不动只会继续耗）。
> **所以任何"要不要动手"的问题，在本库里都必须先回答"我在第几爻"。**

**可直接落地的定位问句（本卡贡献）**：**"写下我在等什么，以及它什么时候到。"**
- 写得出对象与日期 → **九二**：等，不动。
- 写不出 → **上六**：动，并给"悔"留预算。

### 4. ⚠️ 结构增量：本卦由小象传两次确证爻位分析，并补出"乘刚"的第二个来源

**这是本卡对全库结构工具的最硬贡献。**

**（1）经文级确证。** 规格第 2、4 节的爻位与乘刚分析，此前是本库自建的分析工具。**困卦的小象传直接用了它的两个术语**：
- **六三象传："据于蒺藜，乘刚也。"**——**"乘刚"二字出自经文。**
- **九四象传："虽不当位，有与也。"**——**"不当位"三字出自经文。**

而按本库结构律机械推导：**坎在下 → 六三必不当位且乘九二之刚**；**兑在上 → 九四必不当位**。**推导结果与经文自述完全一致。** 结论：**本库的爻位／乘刚分析不是外加的解释框架，是经文自己在用的语言。**

**（2）"乘刚来源"的补充。** 规格第 4 节说"**乘刚的来源＝震**：震在下则六二必乘刚，震在上则六五必乘刚"，并指出"艮把阳放在最上往下压，其内部不制造乘刚"。**困卦显示这条规则不完整**——按各三画卦内部"阴在阳之上"的位置机械枚举：

| 三画卦 | 自下往上 | 内部是否有阴压阳 | 在下卦制造的乘刚 | 在上卦制造的乘刚 |
|---|---|---|---|---|
| 乾 阳阳阳 | — | 无 | — | — |
| 坤 阴阴阴 | — | 无 | — | — |
| 艮 阴阴阳 | 阳在最上 | 无 | — | — |
| 巽 阴阳阳 | 阴在最下 | 无 | — | — |
| **震 阳阴阴** | 二阴压初阳 | **有（在第 2 位）** | **六二乘刚** | **六五乘刚** |
| **离 阳阴阳** | 二阴压初阳 | **有（在第 2 位）** | **六二乘刚** | **六五乘刚** |
| **坎 阴阳阴** | 三阴压二阳 | **有（在第 3 位）** | **六三乘刚** | **上六乘刚** |
| **兑 阳阳阴** | 三阴压二阳 | **有（在第 3 位）** | **六三乘刚** | **上六乘刚** |

> **修正后的口径（建议入库）**：
> **乘刚有三个来源**——
> **① 得中位的乘刚，来自震与离**（阴在三画卦第 2 位）：在下 → 六二乘刚；在上 → 六五乘刚。
> **② 三／上位的乘刚，来自坎与兑**（阴在三画卦第 3 位）：在下 → 六三乘刚；在上 → 上六乘刚。
> **③ 交界处的乘刚**：下卦以阳终（乾／艮／巽／离）而上卦以阴始（坤／艮／坎／巽）→ **六四乘刚**（大畜卡已提出此条，本卡确认其为独立第三源）。

**（3）用这条修正回读困卦，结果极其整齐。** 困＝**上兑下坎**，**恰好把第②源用了两次**：
- **坎在下 → 六三乘刚**：那是全卦唯一判"凶"的爻（困于石、据于蒺藜），**象传给的理由就是"乘刚也"**；
- **兑在上 → 上六乘刚**：那是全卦最缠人的一爻（困于葛藟）。

**即：困卦两个乘刚爻，正好是全卦两个"被缠住"的爻。** 而**它们的处理方式完全不同**——**六三判凶（乘的是硬的：石与刺，必须撤），上六判征吉（乘的是软的：藤，必须动）。** 这为本库"乘刚的破解"清单补了第三条：

> **乘刚的三种破解**：① **艮六四"止诸躬"**——把范围收回到自己这一身；② **巽六四"田获三品"**——交付可分配的实际成果；③ **困上六"征吉"**——**当乘的是"软的牵扯"时，唯一破法是动起来，并预先接受"有悔"。**
