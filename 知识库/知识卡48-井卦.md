# 知识卡 48 · 井卦（水风井）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传/系辞传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："困乎上者必反下，故受之以井。"——在上面困住了，**必然要返回到下面**，所以接之以井。⚠️ **这句话是本卡的钥匙**：困（47）的出路不是继续往上找，是**往下回到那个"养人而不迁移"的东西**——那就是井。
> 杂卦传："井通而困相遇也。"——**井是"通"，困是"通不了"。** 两卦紧挨着，是一组正反。
> ⚠️ **本卦是全库唯一直接讲"可迁移资产与不可迁移资产"的卦**，纲领句就是卦辞第一句"**改邑不改井**"——**城可以搬，井搬不走**（见第四节第 1 条）。
> ⚠️ **本卦与鼎（50）是全库唯一两个"以器物为主体贯穿六爻"的卦**，且两卦下卦同为巽（木），大象传只差一个字：**井＝"木上有水"，鼎＝"木上有火"**（见第四节第 5 条）。
> ⚠️ **系辞下传"九卦三陈"**："井，德之地也……**井以辨义**。" **困辨的是"德"（你是什么人），井辨的是"义"（怎么分才对）。** 本库已成卡的履（10）、谦（15）、恒（32）、困（47）、巽（57）同在此序列。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 井 · 第四十八卦 |
| **卦象** | 上坎（水／险）下巽（风／木／入），称"水风井"。<br>**⚠️ 此处的巽必须取"木"义，不取"风"义**：大象传写"**木上有水**"，彖传写"**巽乎水而上水**"——**木器（汲水的桶与绳）伸到水里去，再把水提上来。这就是"井"。**<br>**所以井卦的核心动作是一个方向："上水"（把下面的水提到上面来）。** 全卦六爻的吉凶，几乎都可以用"这一爻是在上水，还是在往下漏"来解释（见九二）。<br>按本库结构律逐爻核对：<br>· **巽在下 → 初六不当位、九二不当位（得中）、九三当位**（规格第 4 节"六条最危险的位置"之一：**巽在下＝柔在底下，易犯犹豫与滥让**）；<br>· **坎在上 → 六四、九五、上六三爻全部当位**（本库通则："坎在上卦 → 后三爻全部当位、全有转机"）。<br>**全卦四爻当位（三、四、五、上），只有初、二不当位——而这两爻恰好就是井"不成井"的两爻**（井泥不食、瓮敝漏）。**结构与卦义严丝合缝。**<br>**⚠️ 乘刚两处**：**六四乘九三**（交界乘刚：下卦以阳终、上卦以阴始）；**上六乘九五**（坎在上必然）。<br>**⚠️ 注意上六乘刚而判"元吉"**——这是本库"乘刚"工具的一个重要案例（见第四节第 4 条）。 |
| **领域定义** | **可持续供养他人的那样东西：它是什么、怎么修、怎么被人用上。** 具体：<br>① **组织变动中的"核心能力"辨识**——公司搬迁、改名、重组、被并购、换赛道：**什么跟着走，什么留在原地，什么根本不受影响**；<br>② **你自己的"不可迁移资产"清点**——手艺、判断力、口碑、一套方法、一群真正信你的人：**换公司换城市换行业之后还剩下的那些**；<br>③ **有能力却没人来用**（九三"井渫不食"）——你准备好了、水是干净的，**但通道没建起来，没人知道**；<br>④ **基础设施与公共品的建设与维护**——平台、文档、流程、社区、家族的规矩：**不出成果但没有它就不成立的那一层**（六四"井甃"）；<br>⑤ **核心能力被用错方向**（九二"井谷射鲋"）——**拿最强的本事去做边角小事，同时承载工具还在漏**；<br>⑥ **成果要不要开放共享**（上六"井收勿幕"）——你手上有好东西，**盖起来独占，还是敞开给人用**。<br>凡是"**这件东西能养人，而且不该跟着我搬走**"，都落在井卦。 |
| **不归本卦的情况** | ① **在积蓄大量储备、且被结构压住不许发** → **大畜（26）**。⚠️ **大畜是"攒"（存量在增加），井是"养"（存量恒定而流量不断）。** 卦辞已写明差别：**井"无丧无得"——它不增不减。**<br>② **东西已经多到需要分辨管理** → **大有（14）**。**大有讲"多"，井讲"不竭"。** 一个是量，一个是可持续性。<br>③ **能力被压制、环境黑、发亮招祸** → **明夷（36）**。⚠️ **这是与九三最容易混的一条，必须分清**：**明夷是"亮了会招祸"，井九三是"亮了没人看见"。** 前者收光，后者求明（见九三专项）。<br>④ **资源已经耗尽、动不了** → **困（47）**。**困是"泽无水"（没有了），井是"井养而不穷"（有，而且不会没有）。** 序卦传给的路径是**困 → 井**：**困到极处，要回来找那口井。**<br>⑤ **要除旧、要改制度** → **革（49）**。序卦传下一句就是"**井道不可不革**"：**井讲怎么把这口井修好用好，革讲这口井本身该不该换。**<br>⑥ **要建立新的承载体系** → **鼎（50）**。**井是取（把下面的提上来），鼎是烹（把生的变成熟的）。** |
| **"井"字本义** | 字形象井栏（四木交叉）与井口。本义即水井。<br>**⚠️ 三层含义在本卦全部用到**：<br>· **不迁移**——井是唯一挖好之后绝对搬不走的生产设施（卦辞"改邑不改井"）；<br>· **不排他且不耗竭**——一口井供全村，来的人越多它也不少（卦辞"无丧无得，往来井井"；彖传"**井养而不穷也**"）；<br>· **必须有人维护、也必须有人来取**——**井会淤（初六）、会漏（九二）、会闲置（九三）、要砌壁（六四）。⚠️ 井不是自然物，是"人造的公共品"。** 这一层决定了大象传为什么讲"劳民劝相"。<br>**系辞传的定义最重**："**井，德之地也**"——**地是根基、是立足之处。德要有一块地站着，那块地就是井。** |
| **卦辞原文** | 井：改邑不改井，无丧无得，往来井井。汔至，亦未繘井，羸其瓶，凶。 |
| **⚠️⚠️ 卦辞的关键结构（本卦性格全在这里，且是全库一条新记录）** | **元、亨、利、贞——四个字一个都没有出现。**<br>**⚠️ 在本库已成卡的诸卦中，井是唯一一个卦辞里四德一字不见的卦。** 对照：师（7）只给"贞"、大有（14）只给"元亨"、大畜（26）只给"利贞"、明夷（36）只给"利艰贞"、困（47）给"亨贞"——**它们再吝啬，也至少给一个。井一个都不给。**<br>**⚠️ 而且卦辞以"凶"字收尾**（"羸其瓶，凶"）。<br>**这两条合起来说明了什么——井卦的性格是：**<br>**① 它不是一个"处境卦"，是一个"对象卦"。** 元亨利贞是对**你**的许诺与要求；**而井卦讲的主体不是你，是那口井**。**井的好坏不用吉凶来判，用状态来判**（泥／漏／渫／甃／洌／收）。**所以四德无处可放。** 这一条是本卡对全库分类学的增量（见第四节第 5 条）。<br>**② 它把唯一的判词留给了一个具体的失败方式。** 不是"井不好会凶"，是"**瓶破了会凶**"——**凶不在资源侧，在器具侧。** 详见下格。<br>**③ 卦辞的三段结构是"定义 → 性质 → 唯一警告"**：**改邑不改井**（定义：它是什么）→ **无丧无得，往来井井**（性质：它怎么运作）→ **汔至，亦未繘井，羸其瓶，凶**（警告：唯一会出事的地方）。 |
| **⚠️⚠️ "改邑不改井"专解（本卦最高纲领之一）** | **邑**＝城邑、聚落，**人聚起来的那个组织形式**；**井**＝水源与取水设施。<br>**字面**：**城可以搬，井不能搬。**<br>**⚠️ 彖传给的理由是结构性的**："**改邑不改井，乃以刚中也**"——**井之所以不改，是因为它有"刚中"**（九二、九五两个阳爻各居下上卦之中）。**井的不可迁移性，来自它内部那个刚硬且居中的核。**<br>**落到现代——这是本卦最实用的一节。把手上的东西按"能不能跟着搬"分成两类：**<br>| | **邑（可迁移／可更换）** | **井（不可迁移／搬不走也拿不走）** |<br>|---|---|---|<br>| 组织 | 办公地址、公司名、组织架构、职级体系、汇报线、KPI 表 | **真正能交付的那几个人、跑得通的工艺、客户对你的信任、沉淀下来的判断标准** |<br>| 个人 | 头衔、名片、工位、所在平台、履历上的公司名 | **手艺、判断力、口碑、一套自己的方法、真正信你的那几个人** |<br>| 家庭／家族 | 房子、地点、生活方式 | **规矩、处事的底线、彼此之间的信任** |<br>**⚠️ 两条硬判据（本卡贡献，可直接用）**：<br>**① "拿走测试"**——**把"邑"整个拿掉（换公司、换城市、失去头衔、平台关掉），还剩下什么？剩下的就是你的井。**<br>**② "带走测试"**——**你离职时能带走的，恰恰不是井。** ⚠️ 这是最容易反过来理解的一点：**井不能搬走，意味着"组织的井"你带不走，"你的井"组织也拿不走。** 双向都成立。<br>**⚠️ 由此得出一条极重要的现代结论**：<br>> **组织搬了、改名了、重组了，井还在不在，不看公告，看两件事：那个"刚中"（能定事、能扛事、居中不偏的核心）还在不在；以及有没有人在继续"上水"（把能力真的交付出去）。**<br>> **核心一散，改多少次名字都是"邑"在动，井已经废了（初六"旧井无禽"）。** |
| **⚠️ "无丧无得，往来井井"解** | **无丧无得**——**不减少，也不增加。** 井里的水，多打不见少，少打不见多。<br>**⚠️ 这是《周易》对"能力型资产"的精确刻画，与"物质型资产"完全不同**：**钱花了就少，井用了不少。** 落到现代：**你的判断力、手艺、方法论，用得越多不但不减，反而更清（对照九三"渫"＝淘净）；而它闲置不用，反而会淤（初六"井泥"）。**<br>**⚠️ 与大畜（26）的分界就在这里**：**大畜是"攒"，卦辞讲"利涉大川"，上九"何天之衢，亨"——它有一个蓄满之后放出去的时点；井没有那个时点，它一直在那儿，不增不减。**<br>**往来井井**——来来往往的人都来打水，**井还是井**（"井井"是井然、依旧是井之貌）。<br>**⚠️ 这一句是"非排他性"的经文表述**：**用的人多，不影响它对每一个人的可用性。** 落到现代：**文档、工具、方法、开源的东西、一套好规矩，都具有"往来井井"的性质；而工位、名额、预算不具有。** **凡具有"往来井井"性质的东西，上六的"勿幕"（不要盖住）才成立。** |
| **⚠️⚠️ "汔至，亦未繘井，羸其瓶，凶"专解（全卦唯一的凶，也是最锋利的一条）** | **汔**＝几乎、将近。**繘**＝井绳；此处作动词，**用绳把水汲上来**。**羸**＝损坏、翻覆（一说"累"，系挂不牢）。**瓶**＝汲水的陶瓶。<br>**字面**：**已经快到了，却还没把水提上来，瓶子先破了——凶。**<br>**彖传两句注**："**汔至亦未繘井，未有功也**"（等于白干）；"**羸其瓶，是以凶也**"（**凶的原因就是瓶破**）。<br>**⚠️ 这条警告的结构极特殊，必须拆清**：<br>· **水有**（井里不缺）；<br>· **路走完了**（"汔至"——就差最后一步）；<br>· **人到了**；<br>· **唯一坏掉的是器具**（瓶）；<br>· **结果：凶，而且"未有功"（前面全部白费）。**<br>**⚠️ 也就是说：井卦把全卦唯一的"凶"，放在了"最后一米的载具失效"上。** 不是资源不够，不是能力不行，不是时机不对——**是你用来交付的那个东西坏了。**<br>**落到现代的五种"羸其瓶"**：<br>· **交付载具**：产品做出来了，但发布流程／渠道／合同在最后一刻崩了；<br>· **人的载具**：项目临门，核心的人病倒、离职、崩溃——**⚠️ 你自己的身体和精神状态就是"瓶"**；<br>· **信誉的载具**：能力全在，但因为一次失约，客户不接你的水了；<br>· **组织的载具**：能力在个人身上，没有沉淀成流程，人一走全漏（呼应九二"瓮敝漏"）；<br>· **收尾的载具**：九成的活干完了，**剩下一成是最枯燥的收尾，于是没做**——彖传判"未有功也"。<br>**⚠️ 与大畜九二"舆说輹"的关键对照（本卡最重要的一组器具对照）**：<br>· **大畜九二"舆说輹"**（车子脱了轴），象传"**中无尤也**"——**判无咎，因为那是"主动卸车、不硬走"**；<br>· **井卦辞"羸其瓶"**，彖传"**是以凶也**"——**判凶，因为那是"在最后一步被动损毁"**。<br>**⚠️ 同是"器具失效"，一个无尤一个凶，差别只在"你是主动卸的，还是它自己坏的"。** 本库由此可提一条口径：<br>> **器具（瓶／舆／载具）必须在"用它之前"检查和更换。主动卸车是无咎的，走到最后一米才发现瓶破，是凶的。** |
| **卦辞现代解** | **改邑不改井**——**分清什么会变、什么不会变**；把力气放在不会变的那一半。<br>**无丧无得**——**这类资产不因使用而减少**，所以吝啬地藏着它没有意义。<br>**往来井井**——**它可以被很多人同时用，且不因此变差。**<br>**汔至，亦未繘井，羸其瓶，凶**——**⚠️ 先检查你的桶。** 在动手之前，把交付链条上最脆的那一环（人的状态、流程、渠道、合同、工具）修好或换掉。**这一卦真正会出事的地方只有这一处。** |
| **彖传** | 巽乎水而上水，井。井养而不穷也。改邑不改井，乃以刚中也。汔至亦未繘井，未有功也。羸其瓶，是以凶也。 |
| **彖传要点** | ① **⚠️ 巽乎水而上水**——"巽"此处作动词：**(木器)入到水里去，然后把水提上来。** **"上水"是本卦唯一被认可的方向。** 落到现代：**井卦所有正确的动作都是"把下面的东西提到上面、提给人用"；凡是方向朝下的（自己往下钻、往下漏、拿它做小事），都是九二"井谷射鲋"。**<br>② **⚠️ 井养而不穷也**——**井的功能是"养"，而且"不穷"（不会竭尽）。** 这七个字是井卦全部价值的定义：**它不是让你赢，是让你和别人都活得下去，而且长期。**<br>**与困（47）对读**：困的本义就是"穷"，彖传说"**尚口乃穷也**"；**井直接说"不穷"。序卦传"困乎上者必反下"——从"穷"出来的路，就是回到"不穷"的那个东西上。**<br>③ **改邑不改井，乃以刚中也**——见上格专解。**不可迁移性来自"刚中"。**<br>④ **未有功也 / 是以凶也**——**"未有功"是本库吉凶序里比"吝"更重的一档（规格第 3 节："终无功——白费"）。** 井卦把它用在"最后一米没做完"上。 |
| **大象传（行动纲领）** | 木上有水，井。君子以劳民劝相。 |
| **⚠️ "劳民劝相"解（全卦最高原则）** | **劳**＝慰劳、慰勉（不是"使之劳"）；**民**＝众人；**劝**＝劝勉、鼓励；**相**＝互助、相帮。<br>**"劳民劝相"＝慰勉众人，并鼓励他们互相帮助。**<br>**⚠️ 这是本库唯一一条"纲领的作用对象不是君子自己、也不是君子对民，而是民与民之间"的大象传。** 逐条对照可见其特殊：<br>| 卦 | 纲领 | 作用方向 |<br>|---|---|---|<br>| 坎 29 | 常德行习教事 | **君子对自己**（修自己的日课） |<br>| 明夷 36 | 莅众，用晦而明 | **君子对众**（怎么面对一群人） |<br>| 师 7 | 容民畜众 | **君子蓄养民**（自上而下） |<br>| **井 48** | **劳民劝相** | **⚠️ 君子促成民与民互助（横向）** |<br>**为什么井卦是这个纲领——因为井是公共品，它的性质决定了治理方式**：<br>· **一口井供全村，谁都能用（往来井井）**；<br>· **但它会淤、会漏、井壁会塌，必须有人维护**；<br>· **⚠️ 而维护的收益是所有人的，成本是维护者的。** 这就是公共品的根本难题。<br>**《周易》给的解法不是"君子亲自去修"，是"劝相"——让用井的人互相帮、共同维护。**<br>**落到现代的四条操作**：<br>· **建公共品时，同时建维护的规矩**——谁淘井、多久淘一次、坏了谁报；<br>· **不要把自己做成那口井的唯一维护者**——你一走，它就是"旧井无禽"（初六）；<br>· **管理者的核心动作是"劝相"（促成横向互助），不是"独自供给"**；<br>· **"劳"字不可略**：**先慰勉，再要求。** 让人白维护公共品，维护不了两轮。<br>**⚠️ 系辞传的配套句是"井以辨义"**：**公共资源怎么用、谁多用谁少用、维护成本怎么摊——这些正是"义"（分配正当性）问题，而井是最能把人的"义"辨出来的地方。** 九二"井谷射鲋"（把公共井当私人渔场）是不义的样子；**上六"井收勿幕"（打上水来不盖井口）是义的样子。** |
| **总铁律** | ① **先分清邑与井**——力气放在搬不走的那一半（卦辞"改邑不改井"）；<br>② **唯一的方向是"上水"**——把下面的提上来、交出去；**凡方向朝下即错**（彖传"巽乎水而上水"，九二"井谷射鲋"反证）；<br>③ **⚠️ 动手之前先检查瓶**——全卦唯一的凶在"最后一米载具失效"（卦辞"羸其瓶，凶"）；<br>④ **闲置的能力会淤**——初六"井泥不食"；**用得多反而更清**——九三"渫"；<br>⑤ **不被用的时候要"求明"，不是等**——九三象传"**求王明**"（⚠️ 象传比爻辞多了一个"求"字）；<br>⑥ **修基础设施只得"无咎"，但没有它就没有九五**——六四"井甃，无咎"；<br>⑦ **最高判词给"开放"，不给"品质"**——九五"井洌，寒泉食"无判词，**上六"勿幕"才是元吉**（见第四节第 3 条）。 |

## 二、爻级字段

### 初六 · 井泥不食

| 字段 | 内容 |
|---|---|
| **爻辞** | 井泥不食，旧井无禽。 |
| **象传** | 井泥不食，下也。旧井无禽，时舍也。 |
| **位属性** | 阴爻居阳位，**不当位**；失中；**居巽之最下、全卦最底**。按本库结构律，巽在下 → 初六必然不当位（规格第 4 节："**巽在下＝柔在底下，易犯犹豫与滥让**"）。 |
| **判词 → 行动语义** | **无吉凶判词，只给状态** → **按本库口径，这是"《周易》陈述事实而不判你有咎"的一种。行动语义：认定这口井已经废了——要么淘（去九三），要么别再指望它。** |
| **关键词解** | **井泥**——井底淤满了泥。**不是没水，是水被泥搅浑了、井道被堵了。**<br>**不食**——不能饮用。<br>**旧井**——废弃已久的老井。<br>**无禽**——**连鸟兽都不来。** ⚠️ **这四个字极狠：不是人不来，是连不挑的动物都不来了。** |
| **⚠️ 象传两句都给了原因** | ① "**井泥不食，下也**"——**因为它在最下面。** 双重含义：**位置最低（泥在井底沉着）＋地位最低（无人在意）。**<br>② "**旧井无禽，时舍也**"——⚠️ **"时舍"＝为时代所舍弃。** **注意《周易》没有说"这口井不好"，说的是"时舍"：它可能曾经很好，只是时代已经不在这儿打水了。**<br>**落到现代**：**一门手艺、一套流程、一个产品线、一个部门被"时舍"，往往不是因为它变差了，是因为需求搬走了（邑改了）。** ⚠️ **这一条与卦辞"改邑不改井"形成一个尖锐的反面**：**如果"邑"搬走了而井还在原地，那这口井就成了"旧井"。** 井的不可迁移性是它的优势，**也是它唯一的致命风险。** |
| **⚠️ "闲置即淤"：本爻最实用的一层** | **卦辞说井"无丧无得"（不增不减），初六说井会"泥"。** 两句不矛盾——**水量不减，但井道会淤。**<br>**落到现代**：**能力本身不会因为使用而减少（无丧无得），但会因为长期不用而"淤"**：手艺生疏、判断迟钝、人脉断线、方法论过时。**"泥"不是水的问题，是通道的问题。**<br>**⚠️ 所以本爻的解药方向已经写在九三**："**渫**"（淘净）。**初六 → 九三是同一件事的两端：淤了，就淘。** |
| **识别信号** | ① 你有一样确实有价值的东西，**但已经很久没人来用了**；② 不只是"客户少"，是**连最低门槛的人也不找你**（无禽）；③ 你倾向于解释成"时代变了"——⚠️ **象传同意你（"时舍也"），但这不构成不作为的理由**；④ 你手上这口井**从来没有淘过**（没有系统更新过内容、方法、对外的说明）。 |
| **该做** | ① **先判定这是"淤"还是"时舍"**——**淤（通道堵了、内容旧了）就去淘（九三）；真被时舍（需求整体消失）就承认，转去看革（49）**；② **⚠️ 淘井的具体动作**：把这套能力重新做一遍、重新写一遍、对着今天的需求校一遍——**"渫"是动词，不是心态**；③ 把"无禽"当成数据看，不当成羞辱看。 |
| **不该做** | ① **在泥井边等人来**——象传"时舍也"已经说了，时代不会自己回来；② 因为"无丧无得"就以为能力不会退化——**水不减，井道会淤。** |
| **与坎卦初六、困卦初六的三初对照** | · **坎初六"入于坎窞，凶"**，象传"**失道凶也**"——**路径错了还在加倍走**；<br>· **困初六"入于幽谷，三岁不觌"**，象传"**幽不明也**"——**看不清，别在暗中定方向**；<br>· **井初六"井泥不食，旧井无禽"**，象传"**时舍也**"——**东西还在，但没人来了。**<br>**⚠️ 三个"最下爻"排下来，是三种不同的坏开局**：**坎＝方向错，困＝看不清，井＝没人要。** 处方也不同：**坎要停手，困要睁眼，井要淘井（或承认时舍）。** |

### 九二 · 井谷射鲋

| 字段 | 内容 |
|---|---|
| **爻辞** | 井谷射鲋，瓮敝漏。 |
| **象传** | 井谷射鲋，无与也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**；**下卦（巽）唯一的刚中之爻**——它是彖传"改邑不改井，乃以刚中也"所指的两爻之一。 |
| **判词 → 行动语义** | **无吉凶判词，只给状态（一个用错方向的动作 ＋ 一个坏掉的器具）** → **行动语义：立刻纠正方向（要上水，不要向下）；立刻换器具。** |
| **关键词解** | **井谷**——井壁的旁穴、井中低洼处。**总之是井里"下面"的那一块。**<br>**射鲋**——"鲋"是小鱼（一说蛤蟆）。**射取小鱼。** ⚠️ **这是一个用途完全错位的动作：井是给人喝水的，不是抓小鱼的。**<br>**瓮敝漏**——"瓮"是汲水的陶器；"敝"是破旧；**瓮破了，漏水。**<br>**⚠️ 两句合起来是本卦最完整的一次"错"**：**方向错（向下）＋ 器具坏（漏）。** |
| **⚠️ 本爻是全卦最刺眼的一处：刚中之爻却一无所成** | **九二是下卦唯一的阳爻、得中、且是彖传点名的"刚中"之一——本该是好爻，结果是全卦最难看的两爻之一。** 原因只有一个：**方向。**<br>**彖传定义井的动作是"巽乎水而上水"——把水往上提。** **九二做的是往下（井谷）取小东西（鲋）。** **有水、有力、有位（得中），方向反了，全部作废。**<br>**⚠️ 落到现代的三种"井谷射鲋"（本卡最实用的一节）**：<br>· **把最强的能力用在最小的事上**——顶级工程师整年在改文案格式，资深医生整天在填表；**能力没浪费在偷懒上，浪费在方向朝下上**；<br>· **把公共资源私用**——把团队的井、平台的井、公司的井拿来"射鲋"（做自己的小副业、刷自己的数据、办自己的人情）。**⚠️ 这正是系辞"井以辨义"要辨的东西**；<br>· **只做取用不做上水**——从井里舀水自己喝，**从不把水提上来给别人**。 |
| **⚠️ 象传"无与也"** | "**无与**"＝**没有相与者，没有人配合、没有人跟你在一起。**<br>**⚠️ 与困卦九四"虽不当位，有与也"正好互为反面**：**困九四不当位又不得中，却因为"有与"而"终吉"；井九二得中、刚中，却"无与"而一无所成。**<br>**本库由此可确认一条口径（与困卦卡呼应）**：<br>> **"有与／无与"是独立于"当位／得中"的第三个变量，而且在实际结果上权重很高。**<br>> **有与可以救不当位（困九四终吉）；无与可以废掉刚中（井九二无成）。**<br>**为什么九二"无与"——因为它在"射鲋"。** **⚠️ 方向朝下的人，没有人会跟他一起走。** 你把井当渔场，别人自然不来这儿打水（也就回到初六"无禽"）。 |
| **识别信号** | ① 你（或你的团队）**能力明显强于正在做的事**；② 你在用一个共享的资源做只对自己有利的小事；③ **你的承载工具正在漏**——人才留不住、流程不沉淀、渠道有损耗、交付总差一口气（瓮敝漏）；④ **周围没有人跟你一起做这件事**（无与）——**⚠️ 这是最好用的一条自查：如果一件事你怎么都拉不到同行者，先检查它的方向，不要先检查别人的态度。** |
| **该做** | ① **把方向调成"上水"**——问一句"我这个动作，是把东西提上来给人用，还是往下捞给自己"；② **换瓮**——把漏损点找出来修掉（把能力沉淀成文档／流程／可交接的东西，这正是六四"井甃"的活）；③ 把最强的能力对准最需要它的地方。 |
| **不该做** | ① **在"射鲋"上追求效率**——方向错的时候提高效率只是漏得更快；② 用"我得中、我刚中、我是核心"来解释为什么没人配合——**象传把原因归给了动作（射鲋），不是别人。** |
| **与困卦九二的对照（两个"下卦刚中"）** | · **困九二"困于酒食，朱绂方来，利用亨祀，征凶，无咎"**，象传"**中有庆也**"——**刚中而被掩，处方是"等"**；<br>· **井九二"井谷射鲋，瓮敝漏"**，象传"**无与也**"——**刚中而方向错，处方是"改方向、换器具"**。<br>**⚠️ 两爻位置完全同构（阳居二位、不当位、得中、下卦唯一或核心阳爻），处方完全不同**：**困九二的问题在时机（东西还没到），井九二的问题在方向（东西在，你用反了）。**<br>**判据一句话**：**问"我缺的是时间，还是方向？"** 缺时间 → 困九二，等；**方向反了 → 井九二，现在就改，等一万年也不会自己对。** |

### 九三 · 井渫不食

#### ⚠️ 本爻是全库讲"有能力而不被用"的第二处，必须与明夷（36）对读

| 字段 | 内容 |
|---|---|
| **爻辞** | 井渫不食，为我心恻，可用汲，王明，并受其福。 |
| **象传** | 井渫不食，行恻也。求王明，受福也。 |
| **位属性** | 阳爻居阳位，**当位**；失中；**居巽之顶、下卦之极**，正对上坎。按本库结构律，巽在下 → 九三必然当位。<br>⚠️ **本爻是全卦第一个当位之爻，也是"井"第一次真正合格的一爻。** |
| **判词 → 行动语义** | **⚠️ 无吉凶判词，只给心理状态（心恻）＋事实（可用汲）＋条件性结果（王明，并受其福）** → **按本库口径（规格第 3 节末条）："《周易》承认你的难受，但不判你有咎，也不授权你越位。" 行动语义：你的委屈是被承认的；而唯一的动作是象传那个字——"求"。** |
| **关键词解** | **渫**——**淘去污泥、使之洁净。** ⚠️ **注意这个字与初六"泥"正好相对：初六是淤，九三是已经淘干净了。** 淘井是苦活、脏活、看不见成果的活。<br>**不食**——**却没有人来喝。**<br>**为我心恻**——"恻"是悲伤、痛惜。**这使我心里难受。** ⚠️ **《周易》极少直接写情绪，这是最明确的一处之一。**<br>**可用汲**——**它是可以汲取饮用的**（一个客观陈述：**水没问题，你没问题**）。<br>**王明，并受其福**——**若君王明察（有识别能力的决策者看见了），则（井与人）一同受福。** ⚠️ "并"是"一同"：**不是你受益，是双方受益——被看见这件事，对看见的那一方也是收益。** |
| **⚠️⚠️ 象传比爻辞多了一个字："求"** | **爻辞写"王明"，象传写"求王明"。**<br>**⚠️ 这一个字是本爻全部的操作内容：不是"等王明察"，是"去求王明察"。**<br>**为什么这一个字这么重要——因为"井渫不食"的处境有一个天然的心理陷阱**：<br>· 你已经付出了最苦的成本（淘井）；<br>· 水的质量客观没问题（可用汲）；<br>· **于是你会觉得"接下来该由别人来发现我"。**<br>**⚠️ 象传否掉了这一点。它说：求。**<br>**而"求"字同时也解释了为什么本爻没有吉凶判词**：**《周易》不判你，因为你没做错什么；但它也不替你把人叫来。** 这正是规格第 3 节"无判词＋只给心理状态"那一条的标准形态。<br>**⚠️ 落到现代的"求王明"四条操作（注意都不是"自我推销"）**：<br>· **让水可被验证**——把能力做成别人能自己试用、自己检查的形式（样品、试用、公开的作品、可复现的方法）。**"可用汲"要看得见，不能只是你知道**；<br>· **⚠️ 找"明"的人，不是找"大"的人**——爻辞的条件是"王**明**"（有识别能力），不是"王大"。**向没有识别能力的人推销，是白费；这也是与九二"无与"的呼应**；<br>· **说"并受其福"，不说"我很委屈"**——**你的诉求要写成"这对你也有用"，不能写成"我被埋没了"**（⚠️ 呼应困卦"有言不信"：讲自己没人信，讲对方的收益才有人听）；<br>· **把"求"做成可重复的动作**，不是一次性的表态：淘井要反复，求明也要反复。 |
| **⚠️⚠️ 与明夷（36）的分界（本卡最重要的一组对照）** | **两卦讲的是同一个现象——"我行，但我没被用"——处方完全相反。**<br>| | **明夷 36（地火明夷）** | **井 48 九三** |<br>|---|---|---|<br>| 卦象 | 上坤下离，**明入地中** | 上坎下巽，**木上有水** |<br>| 为什么不被用 | **环境是黑的：发亮会招祸**（讲真话的人在被清理） | **环境不黑：只是没人来打水**（通道没建，没人知道） |<br>| 纲领 | **用晦而明**——**把光收起来** | **求王明**——**去把有识别力的人找来** |<br>| 卦辞 | 利艰贞（**无亨**：不承诺被看见） | 无四德（**不判你**，只给"凶"在瓶破处） |<br>| 情绪的处理 | 彖传"以蒙大难"——**承受** | 爻辞"为我心恻"——**承认，但不许停在这儿** |<br>| 违反的后果 | 露光 → 上六"后入于地" | 不求 → 停在"不食"，井继续闲置直至变回初六的"泥" |<br>**⚠️ 分界判据（一句话，可直接用）**：<br>> **问："如果我现在被看见了，会怎样？"**<br>> **会有麻烦（得罪人、被清理、被抢功、正确本身成了风险）→ 明夷：用晦而明，收光。**<br>> **不会有麻烦，只是没人知道 → 井九三：求王明，去建通道。**<br>**⚠️ 最容易犯的错误是把"井九三"当成"明夷"来处理**：**用"环境不好、我不便出头"来解释一个其实只是"没人知道"的处境**——**那不是用晦而明，那是让井继续淤。** 反向的错误同样致命：**在真正的明夷环境里去"求王明"，等于自己举手当靶子。**<br>**⚠️ 附一条结构印证**：**明夷是"离在下、下三爻全当位"，井是"巽在下、九三当位"——两处不被用的能力都是"自己长出来的、正的"。** 区别在上面盖的是什么：**明夷上面是坤（三层土，压死），井上面是坎（在上，三爻全当位，全是通路）。** **能不能求，看你头上是土还是水。** |
| **识别信号** | ① 你已经把该做的苦活做完了（淘井：整理、打磨、验证、补齐），**东西确实可用**；② **没人来用**，而且不是因为你不好；③ **你心里难受，且这份难受里有"凭什么要我去开口"的成分**——⚠️ **这一条是本爻的确诊指标**；④ 被看见对对方也有好处（并受其福），你却从没这么讲过；⑤ **你头上不是"土"**：说出来不会招祸，只是没人问。 |
| **该做** | ① **"求"**——主动去找那个有识别能力的人，并且反复找；② 把"可用汲"做成可验证形态（能试、能查、能复现）；③ 把诉求改写成对方的收益（并受其福）；④ **允许自己难受，但不允许难受代替动作**（象传"行恻也"——"行"字在前）。 |
| **不该做** | ① **等**——**这一爻没有"等"的授权，象传给的是"求"**；② 用"环境不好"给自己免责（那是明夷，不是井九三）；③ 向没有识别能力的人反复推销（王须"明"）；④ 把诉求说成委屈（呼应困卦"有言不信"）。 |
| **与大有九三、大畜的呼应** | 大有九三"**公用亨于天子**"——**把手上的东西全部献给上，象传"小人弗克"**；**井九三是它的前一步：你连"献"的通道都还没有，所以先"求王明"。** 而**大畜"不家食，吉"**（彖传"养贤也"）**正是"王明"的组织侧写法**：**井九三是贤者在求明，大畜"养贤"是明者在求贤。⚠️ 两卦是同一件事的两端——本库由此可给出一条完整口径：贤者要"求王明"（不能等），组织要"不家食、养贤"（不能只让人自己养自己）。** |

### 六四 · 井甃

| 字段 | 内容 |
|---|---|
| **爻辞** | 井甃，无咎。 |
| **象传** | 井甃无咎，修井也。 |
| **位属性** | 阴爻居阴位，**当位**；**已入上坎**——本库通则："坎在上卦 → 六四、九五、上六全部当位、全有转机"，**从本爻起全卦转向**。<br>**⚠️ 乘刚**：六四乘九三之刚（交界乘刚：下卦以阳终、上卦以阴始）。 |
| **判词 → 行动语义** | **无咎** → **按本库口径，"无咎"是"无灾，不等于吉利"。行动语义：这一阶段不出成果，只做结构性修缮——而这正是对的。** |
| **关键词解** | **甃**——**用砖石砌井壁。** 目的是**防止井壁坍塌、防止泥沙重新灌入**（即防止退回初六的"泥"）。<br>⚠️ **注意"甃"不产水**：**砌井壁一滴水都提不上来，但没有它，九五的"寒泉食"不可能存在。** |
| **⚠️ 本爻是全卦最容易被跳过、也最不可跳过的一爻** | **判词只有"无咎"，象传只有"修井也"三个字**——**《周易》在这里给了一个极其朴素的评价：这是本分，不是功劳。**<br>**⚠️ 但把六爻序列排开就看得很清楚**：<br>**初六（泥／废）→ 九二（漏／方向错）→ 九三（渫／净了但没人用）→ 六四（甃／砌壁）→ 九五（洌／可饮）→ 上六（收勿幕／元吉）。**<br>**九三"渫"是清理内容，六四"甃"是加固结构。** **只淘不砌的井，会再淤一次。**<br>**落到现代——六四是全卦最像"没成绩"的阶段，具体是这些活**：<br>· 把只在人脑子里的能力，**写成文档、做成流程、变成可交接的东西**（⚠️ 这正是修九二那个"敝漏之瓮"）；<br>· 把临时方案换成正式方案；补测试、补规范、补合同条款；<br>· 把家族／团队的口头默契，变成明确的规矩；<br>· 把个人的健康、作息、财务缓冲修好——**⚠️ 你自己就是那个"瓶"，卦辞的凶就在这儿。**<br>**⚠️ 六四是唯一能在事前防住"羸其瓶，凶"的一爻。** 卦辞把凶放在"汔至（快到了）"的位置，**而防住它的动作在六四（还没开始取水的时候）。** |
| **⚠️ 交界乘刚的行为学（本卡结构增量）** | **六四乘九三之刚，属"交界乘刚"（大畜卡已确立此为独立的乘刚来源）。** 把本库已有的交界乘刚六四排在一起：<br>· **大畜六四"童牛之牿，元吉"**（上艮下乾）——动作是**下约束**（在牛角还小的时候套上木牿），**元吉**；<br>· **井六四"井甃，无咎"**（上坎下巽）——动作是**做修缮**（砌井壁），**无咎**。<br>**⚠️ 两爻的共同点极清楚：都不取用，都只处理结构。**<br>**本库由此可提一条口径**：<br>> **六四乘刚（下面顶着一个刚爻）时，正确动作不是"取用"或"压制"，而是"处理结构"——约束（大畜）或修缮（井）。** 因为**下面那个刚是你的力量来源，不是你的敌人**：九三"渫"完的井，正是六四要砌的那口井。<br>**这也补上了规格第 4 节"乘刚的破解"清单**（原有：艮六四"止诸躬"收回到自己这一身；巽六四"田获三品"交付可分配的实际成果）——**第五条：井六四"甃"，即"不取用，先加固"。** |
| **识别信号** | ① 你刚把某样东西清理好、验证好（走完九三），**正想立刻拿去用／拿去变现**；② 你手上这套东西**只存在于你一个人身上**，没有沉淀；③ 上一轮出过"漏"的问题（人走了、流程断了、交付掉链子），而你没有修，只是绕过去了；④ 你在为一件更大的事做准备，**而准备工作本身没有任何可展示的成果**。 |
| **该做** | ① **砌壁**——把最脆的那一环加固：文档化、流程化、补合同、补缓冲、修身体；② **接受"无咎"就是这一阶段的满分**——不要求这一阶段出成绩；③ **按"瓶"的清单逐项检查**（人、流程、渠道、信誉、工具），这是唯一能防住卦辞之凶的窗口。 |
| **不该做** | ① **跳过六四直接去取水**——这就是卦辞"汔至，亦未繘井，羸其瓶，凶"的完整剧本；② 因为"看不出成果"而中断修缮；③ 把六四的活当成可以外包给任何人的杂活——**井壁塌了，水就没了。** |
| **与坎卦六四"纳约自牖"的对照** | **两爻结构完全同构**（阴居四位、当位、坎在上的第一爻、全卦转机之爻），**动作方向也一致：都是"降规格换空间"**。<br>· **坎六四"樽酒簋贰，用缶，纳约自牖，终无咎"**——**降礼的规格**，从窗口把关系接上（象传"刚柔际也"）；<br>· **井六四"井甃，无咎"**——**降成果的规格**，只修不取（象传"修井也"）。<br>**⚠️ 两者判词都只是"无咎"级。** 本库口径由此更清楚：**坎在上的第一爻（六四）是转机的入口，而转机的入口从不给"吉"——它只给"没事"，因为它的功能是"止住恶化、把底修好"，不是"拿到好处"。** |

### 九五 · 井洌，寒泉食（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 井洌，寒泉食。 |
| **象传** | 寒泉之食，中正也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位；**上坎之中**——它是彖传"乃以刚中也"所指的第二爻，**全卦卦主**（"井"之所以为井的那个核）。 |
| **判词 → 行动语义** | **⚠️ 无吉凶判词，只给状态** → **行动语义：井已经成了——水清、水寒、可以喝。此爻的动作是"保持中正"，不是"再进一步"。** |
| **关键词解** | **洌**——**清洁、清澄。**<br>**寒泉**——**清冷的泉水。** ⚠️ **"寒"是好评**：井水凉，说明水源深、活水、不是表层积水。<br>**食**——**可供饮用。** ⚠️ **注意主语：是"（人）食"，不是"井食"。九五的成立需要有人来喝。** |
| **⚠️⚠️ 本爻是全卦最反直觉的一条：卦主无判词** | **全卦最高、最正、最中、居尊位、且是彖传点名的"刚中"——判词一个字都没有**，只有"井洌，寒泉食"这一句纯粹的状态描述，和象传三个字"**中正也**"。<br>**⚠️ 为什么——因为井的价值不在它自己好，在有人来喝。**<br>**九五做到了"品质最优"，而《周易》把"元吉"留给了上六的"勿幕"（真的敞开给人用）。**<br>> **⚠️ 这是本卡对全库最重要的一条价值判断（详见第四节第 3 条）：**
> **《周易》在井卦里明确地把"最高判词"给了"开放"那一爻，没有给"品质最好"那一爻。**<br>**落到现代**：**把东西做到最好，只是"中正"（本分做到了）；把它交出去、让人真的用上，才是"大成"。** 一个只有作者自己知道有多好的东西，在井卦里停在九五。<br>**⚠️ 五个尊位的判词序列（本库累计）**：<br>· **讼九五**——**元吉**（中正裁决、案结事了）；<br>· **师六五**——**无咎／贞凶**（选对人则无咎，选错则凶）；<br>· **坎九五**——**无咎**（水平即止，"中未大也"）；<br>· **井九五**——**无判词，只给状态**（"中正也"）；<br>· **困九五**——**无判词，只给过程与方法**（"志未得也"）。<br>**⚠️ 但井九五与困九五的"无判词"性质完全不同**：**困九五是"位置全对而处境全空，所以拿不到判词"；井九五是"位置全对且事已办成，判词被留给了下一爻"。** **前者是不能，后者是未完。** |
| **⚠️ 象传"中正也"的分量** | 象传给"寒泉之食"的唯一理由是"**中正**"——**当位（正）＋得中（中）。**<br>**⚠️ 这是本库"当位且得中"这一最优位属性的一次纯粹兑现**：**它兑现成的不是吉，是"水是清的、凉的、能喝的"。** 换言之：<br>> **"中正"在《周易》里兑现的形态，是"你产出的东西干净可靠"，不是"你得到好处"。** |
| **识别信号** | ① 你手上的东西**确实做到了很高的品质**，自己也清楚；② 该修的都修了（走完六四），该淘的都淘了（走完九三）；③ **你正在等这份品质自动带来回报**——⚠️ **本爻没有这个许诺**；④ 知道它有多好的人，还很少。 |
| **该做** | ① **守住"中正"**——不为了扩散而降品质，也不为了品质而无限期推迟开放；② **⚠️ 立刻走向上六**：**主动把井口打开、告诉别人可以来打水**。**九五的完成度只能靠上六来兑现**；③ 保住"寒"——保住那个深层活水的来源（持续更新、持续验证），不要变成表层积水。 |
| **不该做** | ① **停在九五自我欣赏**——**这是本卦最体面的一种失败**；② 反过来，为了让更多人用而把水掺浑（丢掉"洌"与"中正"）。 |
| **与坎卦九五、离卦六二的对照** | · **坎九五"坎不盈，祗既平，无咎"**（象传"中未大也"）——**险中的最好结果是"没事了"**；<br>· **井九五"井洌，寒泉食"**（象传"中正也"）——**养中的最好结果是"水是好的"**；<br>· **离六二"黄离，元吉"**（附于中正而得元吉）——**明中的最好结果是"附对了地方"**。<br>**⚠️ 三处都指向"中正"，兑现形态各异：坎兑现为"平安"，井兑现为"可靠"，离兑现为"元吉"。** 本库口径：**"中正"是条件，不是结果；结果由卦（处境）决定。** |

### 上六 · 井收勿幕

#### ⚠️ 本爻是本库目前上爻判词的最高一条（元吉），必须与"上爻限定"一起读

| 字段 | 内容 |
|---|---|
| **爻辞** | 井收勿幕，有孚元吉。 |
| **象传** | 元吉在上，大成也。 |
| **位属性** | 阴爻居阴位，**当位**；居全卦之终；**乘九五之刚**（坎在上必然）。<br>⚠️ **乘刚而得元吉——这是本库"乘刚"分析的一个关键案例**（见下"乘刚的第四种破解"）。 |
| **判词 → 行动语义** | **元吉** → **按本库口径，"元吉＝成·根本性圆满，且通常带附加条件，必须指出条件是什么"。⚠️ 本爻的条件写得极清楚：勿幕 ＋ 有孚。行动语义：把井口敞开，让所有人来打水，并且保持可信。** |
| **关键词解** | **收**——⚠️ **两读并存，结论一致**：① **汲取完成**（水已经提上来了）；② **井上的汲水设施**（辘轳、井栏、井绳一类）。<br>**幕**——**覆盖、盖上。**<br>**勿幕**——**不要盖住井口。** ⚠️ **盖井口是极自然的动作**（防脏、防人乱用、防出事、"这是我家的井"），**而《周易》在这里明确禁止它。**<br>**有孚**——**有诚信、可被信任。**<br>**元吉**——**根本性的圆满。** |
| **⚠️⚠️ "勿幕"专解（本爻全部价值所在）** | **井已经修好了（六四）、水已经最好了（九五）、也已经打上来了（收）。到这一步，唯一还剩的选择是：盖，还是不盖。**<br>**⚠️ "幕"的三种现代形态（都很正当，也都很致命）**：<br>· **独占**——"这套方法是我的核心竞争力，不能给别人"；<br>· **管控**——"开放了会被滥用、会出问题、会不好管"，于是加权限、加审批、加门槛；<br>· **拖延**——"再完善一点就开放"，然后永远差一点。<br>**⚠️ 为什么"勿幕"能换来全卦唯一的元吉——三层机制：**<br>**① 井的性质决定了盖井没有收益。** 卦辞已写明"**无丧无得，往来井井**"：**井不因多人取用而减少。** **所以"幕"保护不了任何东西，它只是把井废掉。** ⚠️ **这一条是判据：只有具备"往来井井"性质的东西（方法、文档、工具、规矩、开放的知识）才适用"勿幕"；名额、预算、工位这类排他性资源不适用。**<br>**② 盖上的井会变回"旧井"。** **初六"旧井无禽"是本爻的反面结局**：**没人来的井会淤。⚠️ 井卦六爻首尾对照最狠的一点是：初六的"泥"，往往是上六选择了"幕"的若干年后的样子。**<br>**③ "有孚"是"勿幕"的配套条件。** **敞开而不可信，井会被搞坏；可信而不敞开，井会被废掉。** **两者必须同时成立，元吉才成立。**<br>**⚠️ 落到现代的四条操作**：<br>· **把成果的取用门槛降到最低**（能自助就不要审批，能公开就不要申请）；<br>· **同时把"孚"建起来**——**说明怎么用、用坏了谁负责、更新由谁维护**（⚠️ 这就是大象传"劳民劝相"：敞开之后要靠使用者互相维护）；<br>· **不因为"怕被滥用"而盖井，改为"把规矩写清楚"**；<br>· **⚠️ 不要把"勿幕"做成一次性的发布**——井是天天要人来打水的，**敞开是一个持续状态，不是一个动作。** |
| **⚠️ 象传"元吉在上，大成也"** | "**元吉在上**"——**元吉出现在最上一爻**（象传自己点出这件事的罕见）；"**大成也**"——**大功告成。**<br>**⚠️ "大成"在《周易》里是极重的评价**，而它给的对象是"**把井敞开**"，不是"把井修好"。 |
| **⚠️⚠️ 与规格"上爻限定"的关系（本卡对全库通则的增量）** | 规格第 3 节的上爻限定是：**"反的是'不知止的极'，不是'到顶'本身。过刚则悔，过柔则凶，知止则吉，无内容则白过。"**<br>**井上六不属于以上任何一种。** 它既不过刚，也不过柔；它做的不是"止"，是"**开**"。<br>**把本库已成卡的上爻排开对照**：<br>| 卦 | 上爻 | 判词 | 上爻做了什么 |<br>|---|---|---|---|<br>| 乾 1 | 亢龙有悔 | **悔** | **过刚不知止** |<br>| 坎 29 | 系用徽纆，三岁不得 | **凶** | **不动，滞留成牢笼** |<br>| 巽 57 | 丧其资斧 | **贞凶** | **过柔，丢掉断决之力** |<br>| 离 30 | 获匪其丑 | **无咎** | **知止：只除首恶、不扩大** |<br>| 师 7 | 大君有命，小人勿用 | （正功） | **知止：赏公而择人** |<br>| 大畜 26 | 何天之衢 | **亨** | **蓄足而通：路开了** |<br>| 困 47 | 困于葛藟…征吉 | **吉** | **动起来，破除缠绕** |<br>| **井 48** | **井收勿幕** | **⚠️ 元吉** | **⚠️ 开放：把成果交给别人用** |<br>> **⚠️ 增量口径（建议入库）：上爻的第五种结局——"交出去"。**
> **除了"过刚则悔／过柔则凶／知止则吉／无内容则白过"之外，还有一种：把到手的成果敞开给人用（勿幕），且保持可信（有孚）。这一种在本库中拿到了上爻的最高判词——元吉。**
> **它比"知止"更进一步：知止是不再拿，勿幕是把已经拿到的放开。** |
| **⚠️ 乘刚的第四种破解** | 规格第 4 节原有两条破解（艮六四"止诸躬"、巽六四"田获三品"），困卦卡增补第三条（困上六"征吉"：软缠绕要动起来）。**井上六是第四条**：<br>> **④ 井上六"井收勿幕"——当你乘于刚之上（坐在别人的力量之上）时，把这份力量的产出敞开给所有人用。**<br>**机制**：**上六乘九五之刚，意味着它坐在整口井（九五＝刚中之核）的上面——它是井口。** **井口的正当性只有一种：敞开。** **一旦盖上，它就从"井口"变成"塞子"，乘刚立刻变成压制。**<br>**⚠️ 这是全库对"乘刚"最正面的一次处理**：**乘刚不必然是坏事；坐在别人的力量之上而把出口打开的，得元吉。** |
| **识别信号** | ① 你手上有一样已经做好、且"用的人多也不会变少"的东西；② 你正在犹豫要不要设门槛（权限、审批、收费、只给内部）；③ 你的理由是"怕被滥用／怕不好管／再完善一点"；④ **你其实还没有把"怎么用、坏了谁负责、谁来维护"写清楚**——⚠️ **这一条才是真问题，而它的解法是"有孚"，不是"幕"。** |
| **该做** | ① **勿幕**——把取用门槛降到最低；② **有孚**——同时把使用说明、责任与维护机制建起来（大象传"劳民劝相"）；③ **把敞开做成常态**，不是一次发布；④ **⚠️ 先做"往来井井"判定**：这东西是否真的"多人用不减少"？是，才适用勿幕。 |
| **不该做** | ① **盖井**——**这是本卦唯一一个会把前面五爻全部作废的动作**（终点回到初六"旧井无禽"）；② 敞开而不建规矩（丢掉"有孚"，井会被搞坏）；③ 把排他性资源（名额、预算）当井来"勿幕"——**那不是勿幕，那是不负责。** |
| **与大畜上九、大有上九的三上对照** | · **大畜上九"何天之衢，亨"**，象传"**道大行也**"——**蓄足则通：约束解除，路自己开了**；<br>· **大有上九"自天佑之，吉无不利"**——**把功归天，不居功**；<br>· **井上六"井收勿幕，有孚元吉"**，象传"**大成也**"——**把成果敞开给人用。**<br>**⚠️ 三爻是"顶点的三种正确姿态"**：**大畜是"等到路开"，大有是"把功归上"，井是"把水给人"。** **判词依次为 亨 ＜ 吉无不利 ＜ 元吉。**<br>**本库口径**：**顶点的判词高低，与"你把多少东西让出去"正相关。** 大畜让的是时间，大有让的是功劳，**井让的是资源本身——所以它最高。** |

**井卦三句话**：
1. **先分清"邑"与"井"**——城可以搬，井搬不走。**把"邑"整个拿掉之后还剩下的，才是你真正的资产**；而彖传说井之所以不改，是"**乃以刚中也**"：**核心一散，改多少次名字都只是邑在动，井已经废了。**
2. **唯一的方向是"上水"，唯一的凶在"瓶破"**。方向朝下（井谷射鲋）废掉刚中；而全卦唯一的"凶"不在资源侧，在器具侧——**汔至而瓶羸，前面全白干（彖传"未有功也"）。所以动手之前先检查桶，六四是唯一的窗口。**
3. **有能力而不被用，先问头上是土还是水**。**是土（发亮招祸）→ 明夷，用晦而明；是水（只是没人知道）→ 井九三，象传给的是一个字："求"。**

**本卦最反直觉的三条**：
- **卦辞里元亨利贞四个字一个都没有，却以"凶"字收尾。** **因为井卦的主体不是你，是那口井**——井的好坏不用吉凶判，用状态判（泥／漏／渫／甃／洌／收）。
- **卦主九五"井洌，寒泉食"没有任何判词，全卦唯一的元吉给了上六"井收勿幕"。** **《周易》把最高评价给了"开放"，不给"品质最好"。** 一个只有作者自己知道有多好的东西，在井卦里只能停在九五。
- **九三是当位之爻、水已淘净、"可用汲"，《周易》却不判它吉，只承认它"心恻"，然后由象传补上一个字："求"。** **它承认你的委屈，但它不替你把人叫来。**

## 四、本卦对全库的意义

### 1. ⚠️ 全库唯一的"资产可迁移性"框架："改邑不改井"

本库此前处理"你有什么"的卦有三个层次：**小畜（9）＝有实力但被压住（小规模蓄）**、**大畜（26）＝大规模积累与涵养（在攒，有出口）**、**大有（14）＝东西已经多到需要分辨管理（在分）**。**它们都是"量"的框架。井卦补上的是"性质"的框架：同样的东西，哪一部分搬得走，哪一部分搬不走。**

| 卦 | 关注 | 关键句 | 时间形态 |
|---|---|---|---|
| 小畜 9 | **蓄不住** | 密云不雨 | 有天花板 |
| 大畜 26 | **在攒** | 天在山中；不家食，吉 | 有一个"蓄足而通"的时点（上九"何天之衢，亨"） |
| 大有 14 | **在分** | 遏恶扬善 | 高点，会西斜 |
| **井 48** | **⚠️ 不增不减、不可迁移、不可耗竭** | **改邑不改井；无丧无得；井养而不穷** | **⚠️ 没有时点——它一直在那儿** |

**两条可直接使用的判据（本卡贡献）**：
- **"拿走测试"**：**把"邑"整个拿掉（换公司、换城市、失去头衔、平台关停），还剩什么？剩下的就是井。**
- **"带走测试"**：**你离职能带走的，恰恰不是井。** ⚠️ 双向成立：**组织的井你带不走，你的井组织也拿不走。**

而彖传给的机制是结构性的、可验证的：**"改邑不改井，乃以刚中也"——井的不可迁移性来自九二、九五这两个刚中之爻。** 落到现代：**组织重组之后井还在不在，不看公告，看"那个能定事、能扛事、居中不偏的核心还在不在"，以及"有没有人在继续上水（真的把能力交付出去）"。**

⚠️ 同时井卦诚实地写出了这项优势的反面：**初六"旧井无禽"，象传"时舍也"——邑搬走了而井留在原地，井就成了旧井。不可迁移既是井的价值，也是它唯一的致命风险。**

---

### 2. ⚠️ "有能力而不被用"的第二处，与明夷（36）构成本库第二组"同现象、反指令"

本库已经有过一组"同一件事、相反指令"的纲领对（明夷"用晦而明" vs 离"继明照于四方"，见明夷卡）。**井九三与明夷构成第二组，而且比第一组更常用**，因为它处理的是现代读者最高频的一个困扰：**"我明明可以，为什么没人用我。"**

> **⚠️ 分界判据（一句话）**：**问"如果我现在被看见了，会怎样？"**
> **会有麻烦 → 明夷（36）：用晦而明，收光。**
> **不会有麻烦，只是没人知道 → 井（48）九三：求王明，去建通道。**

**结构上也能验证**：两处"不被用的能力"都是自己长出来的、正的（**明夷离在下，下三爻全当位；井巽在下，九三当位**）。**差别在头上盖的是什么**：
- **明夷上面是坤——三层土，压死的**，所以只能"晦"；
- **井上面是坎（在上）——三爻全部当位，全是通路**，所以可以"求"。

**⚠️ "能不能求，看你头上是土还是水"，这是本库把结构律直接用成实操判据的一次典型示范。**

**⚠️ 两个方向的误用都很常见，且代价都高**：
- **把"井九三"误判为"明夷"**——用"环境不好、我不便出头"解释一个其实只是"没人知道"的处境。**那不是用晦而明，那是让井继续淤，终点是初六。**
- **把"明夷"误判为"井九三"**——在真正黑的环境里去"求王明"，等于举手当靶子。

**另外，井九三与大畜"不家食（养贤）"是同一件事的两端**，本库由此可给出一条完整口径：
> **贤者要"求王明"（不能等着被发现）；组织要"不家食、养贤"（不能只让人自己养自己）。两边都动，"并受其福"才成立。**

---

### 3. ⚠️ 最重要的价值判断：《周易》把最高判词给了"开放"，不给"品质"

**这是井卦对全库最锋利的一条贡献，而它是纯经文层的事实，不需要推演：**

- **九五**（当位·得中·居尊·刚中·卦主）："**井洌，寒泉食**"——**无任何吉凶判词**，象传只给"中正也"；
- **上六**（当位·乘刚·卦末）："**井收勿幕，有孚元吉**"——**元吉**，象传"**大成也**"。

**井已经是最好的井了（九五），而"大成"不在那里，在下一步：把井口打开（上六）。**

> **口径（建议入库，可直接用于"定势"）**：
> **在井卦（供养型资产）中，"把东西做到最好"只兑现为"中正"（本分做到了）；"让别人真的用上"才兑现为"元吉·大成"。**
> **反过来：一个只有作者自己知道有多好的东西，在井卦里停在九五——它不算失败，但它没有完成。**

这条判断同时给了本库"上爻"通则一个增量。规格第 3 节的上爻限定原有四种结局（**过刚则悔／过柔则凶／知止则吉／无内容则白过**），**井上六是第五种：把到手的成果交出去（勿幕）。它在本库中拿到了上爻的最高判词。**

**并且它给了"元吉"这个判词一次教科书式的条件标注**（规格要求"元吉通常带附加条件，必须指出条件是什么"）：**条件是"勿幕（敞开）＋ 有孚（可信）"——缺一个，元吉不成立**。敞开而不可信，井会被搞坏；可信而不敞开，井会被废掉。

---

### 4. ⚠️ 结构增量：坎在上通则的第八个实证，以及"乘刚"工具的两条补充

**（1）"坎在上 → 后三爻全当位、全有转机"的第八个实证。** 坎卦卡末节列了七卦（蒙、讼、师、坎、屯、需、比），**困（47）是第八行（坎在下），井（48）是第九行（坎在上）**。井卦的实证极干净：
- **六四"井甃，无咎"**（当位·修井）→ **九五"井洌，寒泉食"**（当位得中·成）→ **上六"井收勿幕，有孚元吉"**（当位·大成）。
- **三爻依次是"修 → 成 → 共享"，判词依次是 无咎 → 无判词（中正）→ 元吉。** **这是本库"坎在上三爻全有转机"最完整、最好看的一次兑现。**

而**前两爻（初六泥、九二漏）正是全卦唯一的两个不当位之爻**，且都是"井不成井"的状态——**巽在下（柔在底下）的病，在井卦里表现为"底部淤塞与漏损"**：初六被时代舍弃（滥让的极端形态：连争取都没有），九二"无与"（犹豫与方向不明的后果）。**结构与卦义严丝合缝。**

**（2）"交界乘刚"的行为学（新）。** 大畜卡已确立"交界乘刚"（下卦以阳终、上卦以阴始 → 六四乘刚）为独立的第三个乘刚来源。**井六四是第二个实例，两例合起来给出了行为规律**：

| 卦 | 交界乘刚之爻 | 动作 | 判词 |
|---|---|---|---|
| 大畜 26 | 六四乘九三 | **童牛之牿**——在最早最小处下约束 | **元吉** |
| **井 48** | 六四乘九三 | **井甃**——砌井壁，只修不取 | **无咎** |

> **口径（建议入库）**：**六四乘刚时，正确动作不是"取用"也不是"压制"，而是"处理结构"——约束（大畜）或修缮（井）。** 因为**下面那个刚是你的力量来源，不是你的敌人**：九三"渫"完的那口井，正是六四要砌的那口井。

**（3）"乘刚的破解"清单补到五条。** 规格第 4 节原有两条，困卡增一条，本卡增一条：
1. **艮六四"止诸躬"**——把范围收回到自己这一身；
2. **巽六四"田获三品"**——交付可分配的实际成果；
3. **困上六"征吉"**（困卡）——乘的是软缠绕时，唯一破法是动起来，并预先接受"有悔"；
4. **井六四"井甃"**（本卡）——**不取用，先加固**；
5. **井上六"井收勿幕"**（本卡）——**⚠️ 坐在别人的力量之上时，把这份力量的产出敞开给所有人用。**

⚠️ **第 5 条是全库对"乘刚"最正面的一次处理**：**乘刚不必然是坏事。上六乘九五，意味着它坐在整口井（刚中之核）的上面——它就是井口。井口的正当性只有一种：敞开。一旦盖上，井口就变成塞子，乘刚立刻变成压制。**

### 5. ⚠️ 分类学增量：本库第一对"以器物为主体"的卦（井 48 ／ 鼎 50）

**井卦的六爻主语不是人，是井**（泥／漏／渫／甃／洌／收）。**这解释了本卡开头那个记录：卦辞里元亨利贞一个都没有——因为四德是对"你"的许诺与要求，而这一卦讲的对象是那口井。**

**鼎（50）与它完全同构**：鼎的六爻主语也是鼎（颠趾／有实／耳革／折足／黄耳金铉／玉铉）。**而两卦的关系近到不可思议：**

| | **井 48** | **鼎 50** |
|---|---|---|
| 卦象 | 上坎（水）下**巽（木）** | 上离（火）下**巽（木）** |
| 大象传 | **木上有水**，井 | **木上有火**，鼎 |
| 器物 | **汲器**（桶、绳、瓶、瓮） | **烹器**（鼎、足、耳、铉） |
| 功能 | **取**：把下面的提上来 | **烹**：把生的变成熟的 |
| 彖传的功能定义 | **井养而不穷也** | **亨（烹）以养圣贤**（大亨以养圣贤） |
| 唯一的凶在哪里 | **卦辞"羸其瓶"**——汲器坏了 | **九四"鼎折足，覆公餗"**——承载超限 |
| 器物的失效方式 | **淤、漏、瓶破** | **颠趾、耳革、折足** |
| 最好的一爻 | **上六"勿幕"（元吉·大成）** | **上九"玉铉"（大吉·无不利）** |

**⚠️ 两卦的大象传只差一个字（水／火），下卦同为巽（木），彖传的功能定义都用"养"字。** 本库由此可提一条结论：

> **《周易》处理"可持续供养他人的能力"时，用的是两个器物：井与鼎。**
> **井管"取得"（把深处的东西提上来，且不可迁移、不会耗竭）；鼎管"转化与承载"（把原料变成成品，且承载有上限）。**
> **两卦共同的教训也一致：⚠️ 出事的从来不是资源侧，是器具侧。** 井是"水有而瓶破"（卦辞之凶），鼎是"食有而足折"（九四之凶）。

**这也给了序卦传一个机制解释**：**井（48）→ 革（49）→ 鼎（50）**——"**井道不可不革**"（这口井本身该不该换），"**革物者莫若鼎**"（换了之后要有新的承载器）。**井与鼎中间夹着一个革，正是"同一个巽（木）在下，把上面的水换成火"的那一步。**

### 6. 与已成卡各卦的衔接一览

| 衔接 | 机制一句话 |
|---|---|
| **井 ↔ 困（47）** | **序卦传"困乎上者必反下，故受之以井"＋杂卦传"井通而困相遇"**：困是"穷"（泽无水），井是"不穷"（井养而不穷）；**从困出来的路，就是回到那个不会枯的东西上** |
| **井 ↔ 明夷（36）** | **本库第二组"同现象、反指令"**：明夷"用晦而明"（收光，怕招祸）／井九三"求王明"（去建通道，只是没人知道）。**判据：头上是土还是水** |
| **井 ↔ 大畜（26）** | **"攒"与"养"的分界**：大畜有蓄足而通的时点（上九得亨），井无时点、不增不减；**且大畜"养贤"与井九三"求王明"是同一件事的两端** |
| **井 ↔ 大有（14）** | **"多"与"不竭"**：大有讲量与分配（遏恶扬善），井讲可持续与非排他（往来井井） |
| **井 ↔ 坎（29）** | **坎在上通则的第九行**：六四修、九五成、上六大成，三爻全当位全有转机；**且六四与坎六四同为"降规格换空间"的转机爻，判词同为无咎级** |
| **井 ↔ 师（7）** | **两条"民"字纲领**：师"容民畜众"（自上而下蓄养以备战）／井"劳民劝相"（**横向促成互助以维护公共品**）。⚠️ 井是本库唯一一条作用于"民与民之间"的纲领 |
| **井 ↔ 巽（57）** | **巽在下的病在井卦的具体形态**：初六被"时舍"（滥让到连争取都没有）、九二"无与"（方向不明而无人相随）；**且此处巽取"木"义而非"风"义，是本库第一次明确区分** |
| **井 ↔ 履（10）、谦（15）、恒（32）、困（47）** | **系辞"九卦三陈"同族**："**井，德之地也……井以辨义**"。⚠️ **困辨"德"（你是什么人），井辨"义"（怎么分才对）**；九二"井谷射鲋"是不义之样，上六"勿幕"是义之样 |
| **井 ↔ 革（49）、鼎（50）** | **序卦链"井 → 革 → 鼎"**：井讲这口井怎么修好用好，革讲它该不该换，鼎讲换了之后靠什么承载；**井与鼎是本库唯一一对"以器物为主体"的卦，大象传只差一个字** |
