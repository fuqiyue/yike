# 知识卡 49 · 革卦（泽火革）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："井道不可不革，故受之以革。"——⚠️ **这句话给了革卦最准确的入口**：井（48）讲的是"把这口井修好、用好、敞开"；**而井道走到尽头，会遇到一个井卦回答不了的问题——这口井本身还该不该是这口井。** 那就进入革。
> ⚠️ **革（49）与鼎（50）是全库唯一一对直接讲组织变革的卦，必须合读**：**革＝除旧（上兑下离，泽中有火），鼎＝立新（上离下巽，木上有火）。** 序卦传下一句紧接着说"**革物者莫若鼎**"——**革之后必须有鼎，否则只有拆没有立。**
> ⚠️ **本卦最重要的结构性事实（也是本卡对全库最大的贡献）**：**革卦六爻中五爻当位，唯一不当位的是九四——而九四正是"有孚改命"、真正动手改的那一爻。** **《周易》把变革的实际动作，放在了全卦唯一一个"位置不正当"的地方，其唯一凭据是"有孚"。**（详见第四节第 2 条）
> ⚠️ **本卦"孚"字出现四次**（卦辞"乃孚"、九三"有孚"、九四"有孚改命"、九五"未占有孚"）——**是全库"孚"字密度最高的卦。变革的全部难点不在"改什么"，在"什么时候有人信"。**

---

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 革 · 第四十九卦 |
| **卦象** | 上兑（泽／悦／少女）下离（火／明／中女），称"泽火革"。<br>**大象传写作"泽中有火"——火在水里。** ⚠️ **这是一个"不可共存"的意象，而"不可共存"就是革卦的结构定义。** 彖传给了两句注：<br>· "**水火相息**"——水与火相灭（"息"亦有生长义，本库取"相灭"为主）：**两者放在一处，必有一方要变。**<br>· "**二女同居，其志不相得**"——兑为少女、离为中女，**两个人同处一室而心志不合。**<br>**⚠️ 所以"革"不是因为有人想改，是因为现状里装了两样不能共处的东西。** 落到现代：**新老业务共用一套考核、两种文化装在一个组织里、旧流程配新工具——不是有人闹事，是结构本身在互相灭。**<br>按本库结构律逐爻核对：<br>· **离在下 → 初九、六二、九三三爻全部当位**（明德在内、名正言顺。⚠️ 注意规格第 4 节列的危险位置是"**离在上**＝光在你身外"，**离在下不在危险清单里**）；<br>· **兑在上 → 九四不当位、九五当位得中、上六当位**。<br>**⚠️ 全卦五爻当位，只有九四一爻不当位——而九四是"改命"那一爻。** 这是全卦最重要的结构事实。<br>**⚠️ 乘刚两处**：**六二乘初九**（离在下必然）、**上六乘九五**（兑在上必然）。**且六二判"征吉"——是本库又一个"乘刚而吉"的案例**（见第四节第 4 条）。 |
| **领域定义** | **除旧：把已经不能共存的旧制度、旧做法、旧结构改掉。** 具体：<br>① **组织改制**——改组织架构、改考核方式、改分配规则、改决策流程、砍掉一条业务线；<br>② **换赛道／换模式**——原来的活法还能撑一阵，但你已经看清它撑不到终点；<br>③ **人事与权责的重排**——不是换个人，是**改变"谁说了算"这件事本身**（九四"改命"）；<br>④ **家庭／家族的规矩变更**——赡养方式、财务安排、过节方式、谁做主，这些多年不动的东西要动；<br>⑤ **自己的重大习惯与身份变更**——戒断一件事、离开一个行业、结束一段长期关系：**⚠️ 革卦要求"大人虎变"，即变化必须是可见的、根本的，不是内心决定了就算**；<br>⑥ **变革推不动**——你已经确信要改，方案也对，**但没人相信必须改**（这正是卦辞"巳日乃孚"要处理的全部内容）。<br>凡是"**必须把现在这一套换掉，而难点是让人相信这件事该现在做**"，都落在革卦。 |
| **不归本卦的情况** | ① **要建立新的承载体系、要把新东西真的运起来** → **鼎（50）**。⚠️ **革与鼎是一对，必须分清动作**：**革是"拆"（除旧），鼎是"立"（立新）。** **只革不鼎＝拆完没有承载器，最后是鼎九四"折足覆餗"；只鼎不革＝新东西装在旧结构里，回到彖传"二女同居，其志不相得"。**<br>② **这口井怎么修好、用好、敞开** → **井（48）**。序卦传"井道不可不革"：**井处理"用"，革处理"换"。** 先问"淘一淘还能用吗"（井九三"渫"）——**还能用就不要革。**<br>③ **蓄力等待、时机未到而力量在攒** → **大畜（26）／需（5）**。**大畜是"攒到蓄足而通"，革是"等到那一天动手拆"。** 革不许你在等的时候攒——初九明写"**不可以有为也**"。<br>④ **冲突已经组织化、要打** → **师（7）**。**师是对外打，革是对内改。** 革的姿态是彖传"**文明以说**"（讲清道理 ＋ 让人心悦），不是对抗。<br>⑤ **资源耗尽、动不了** → **困（47）**。**困中不许启新局（卦辞无"元"）；革卦辞四德齐全，是明确许可你启动的卦——但前面挂着"巳日乃孚"这道闸门。**<br>⑥ **只是要修一修、改进一下** → 不必用革。**⚠️ 彖传的门槛很高："水火相息""其志不相得"——只有当两样东西已经不能共存时才是革。** 够不上这个门槛的，是井六四的"甃"（修）。 |
| **"革"字本义** | **本义是"去毛的兽皮"，即皮革。** 由"处理生皮使之变成革"引申为**改变、变更、除旧**。<br>**⚠️ 本卦把这个字的两层意思同时用上，而且用成了一次对照（全书最精巧的一处字义反用）**：<br>· **卦名"革"＝变革**（改掉）；<br>· **初九"巩用黄牛之革"＝用黄牛皮把自己捆住**（不动）。<br>**同一个"革"字，卦名是"变"，初九是"不变的束缚"。⚠️ 《周易》用这个双关说了一件事：变革的第一步是先把自己绑住。**<br>**另一层含义在九三**："**革言三就**"——**这里的"革"是"变革的主张"**，即**方案／议案**。**所以革卦的"革"是三个东西：改变（卦名）、束缚（初九）、方案（九三）。** |
| **卦辞原文** | 革：巳日乃孚，元亨，利贞，悔亡。 |
| **⚠️ 版本说明** | **"巳日"⚠️ 版本待核**：通行本多作"**己日**"（己为十干之第六，居十干之中，取"时已过中、成熟"之义），亦有作"**巳日**"者（巳为十二支之第六）。**本卡依核定采"巳日"。⚠️ 两读的义理指向完全一致：都是"到了那个特定的日子才有人信"，即时机成熟是信任的前提。** 六二"巳日乃革之"同此。 |
| **⚠️⚠️ 卦辞的关键结构（本卦性格全在这里）** | **① 元、亨、利、贞四德齐全**——**这是《周易》对一件事最完整的许诺**（对照师 7 只给"贞"、大有 14 只给"元亨"、大畜 26 只给"利贞"、明夷 36 只给"利艰贞"、困 47 给"亨贞"、井 48 一个都不给）。<br>**⚠️ 这一条必须先说清，因为它决定了本卦的基调**：**《周易》对"变革"这件事本身是完全肯定的。** 彖传更进一步："**天地革而四时成**"——**四季就是天地在变革。变革不是破坏秩序，变革是秩序的产生方式。**<br>**② 但四德前面挂了一道闸门："巳日乃孚"。** ⚠️ **注意语序：不是"元亨利贞，巳日乃孚"，是"巳日乃孚，元亨利贞"。** **闸门在最前面：到了那一天、有人信了，四德才生效。**<br>**⚠️ 这是全库最重要的一条"条件前置"结构**：<br>> **变革的四德不是无条件给的。时机未到、无人相信之时，"元亨利贞"一个都不成立。**<br>**③ 末尾多一个"悔亡"。** 按本库口径（规格第 3 节）：**"悔亡"＝挽回级：本该有的悔恨消失了，不是得到好处。**<br>**⚠️ 这句话的含义极其诚实：《周易》承认任何变革都天然带"悔"。** 彖传的注是"**革而当，其悔乃亡**"——**变革做得恰当，那个悔才消失。**<br>**⚠️ 所以革卦对变革的完整态度是：值得做（四德齐全）＋ 必然带悔（悔亡）＋ 必须等到有人信（巳日乃孚）。** 三条缺一不可。<br>**④ 而卦辞的"悔亡"具体在九四兑现**（九四爻辞第一句就是"悔亡"）——**卦辞层的许诺，落到爻位上有一个确定的地址。** |
| **⚠️⚠️ "巳日乃孚"专解（全卦时序的总闸门）** | **字面**：到了"巳日"那一天，才会有人相信。<br>**彖传的自注**："**巳日乃孚，革而信之**"——**到了那一天，把它改了，人们才信它。** ⚠️ **注意彖传的语序：先"革"，后"信"。不是"信了才革"，是"到了那一天革，人才信"。** 这与九四"**有孚改命**"（先有孚再改命）合起来，构成一个两级结构（见下"孚的阶梯"）。<br>**⚠️ 为什么"信"这么重要——因为变革与其他所有动作有一个根本差别**：<br>· 别的事，你做对了就有结果；<br>· **变革的对象是"大家共同遵守的那一套"，所以它的成败不取决于方案对不对，取决于有多少人愿意按新的那一套行动。** **一个没人信的正确方案，在革卦里等于零。**<br>**⚠️ 所以"巳日"是什么——不是历法上的某一天，是"人心成熟的那一刻"。** 它的可观察标志（本卡贡献，可用于自查）：<br>· **不再只有你一个人说"这样下去不行"**——⚠️ **这是最硬的一条**；<br>· **旧办法刚刚公开失效过一次**（数据出来了、周期到了、出了一件掩盖不住的事）；<br>· **原来最反对改的人，开始说"确实得想想办法"**；<br>· **⚠️ 反向指标：如果你需要花大力气去说服别人"有问题"，那就还没到巳日**——此时的正确动作是初九（把自己绑住）。<br>**⚠️ 与困卦"有言不信"的呼应（本库两条"信"的律条）**：<br>· **困 47"有言不信，尚口乃穷"——失势时说什么都没人信，所以不要说**；<br>· **革 49"巳日乃孚"——时机未到时改什么都没人信，所以不要改**。<br>**两条合起来是一条通则**：**"被相信"不是内容问题，是"势位 × 时机"问题。** 困卦教你在低位闭口，**革卦教你在时机未到时不动手。** |
| **卦辞现代解** | **巳日乃孚**——**先等到那一天**：等到"必须改"这件事不再只是你的判断，而是多数人的共识。<br>**元**——这是一次**开创性的、根本层面的**变动（不是微调）。**亨**——它是通的。**利**——它有益。**贞**——但必须守正。<br>**悔亡**——**⚠️ 不要期待"毫无遗憾地完成变革"。** 你能拿到的最好结果是"**那个本来会有的悔，消失了**"——**条件是彖传说的"革而当"。** |
| **彖传** | 革，水火相息，二女同居，其志不相得，曰革。巳日乃孚，革而信之。文明以说，大亨以正。革而当，其悔乃亡。天地革而四时成，汤武革命，顺乎天而应乎人，革之时大矣哉。 |
| **⚠️ 彖传要点（本卦纲领的一半在这里）** | ① **水火相息，二女同居，其志不相得，曰革**——⚠️ **这是彖传给出的"革"的定义，也是本卦的入场门槛**：**只有当结构里装了两样不能共存的东西时，才叫革。** 够不上这个门槛的，是"修"（井六四"甃"），不是"革"。<br>**⚠️ 与咸卦（31）的对照（极佳的一组）**：**咸＝上兑（少女）下艮（少男）**，彖传"**二气感应以相与**"——**其志相得，故为"感"**；**革＝上兑（少女）下离（中女）**，彖传"**其志不相得**"——**故为"革"**。<br>**同一个上兑，下面换一卦：换成少男则相感，换成中女则相革。⚠️ 这是本库"卦素组合决定卦义"最直观的一次示范：不是"兑"决定的，是"和谁在一起"决定的。**<br>② **⚠️ 文明以说**——下离＝文明（讲得清楚、辨得明白），上兑＝说（悦，让人心里舒服）。**⚠️ 这是革卦的标准姿态：底下要把道理讲透，上面要让人心悦。** **不是靠强推，不是靠权力压。**<br>**与本库已有的两条同素语序对照**：**同人 13"文明以健"**（明在内、力在外：先看清再使劲）／**大有 14"刚健而文明"**（力在内、明在外：先有实力再照亮）／**革 49"文明以说"**（**明在内、悦在外：先讲清楚，再让人接受**）。**⚠️ 同一个离，配的东西不同，作业顺序就不同——这是本库方法论的又一次实证。**<br>**并且它印证本库那条通则（⚠️ 该律已由"必"降为"多"，见鼎卦 50 卡第四节第 5 条）**："**凡卦中有离，纲领多与'辨／明'有关**"——革卦的"辨"落在大象传"治历**明**时"与彖传"**文明**以说"上：**把"为什么必须改"与"什么时候改"都辨清楚。**<br>③ **大亨以正**——大通而以正道行之，即卦辞"亨"与"贞"的合并说明。<br>④ **⚠️ 革而当，其悔乃亡**——**变革做得"当"，那个悔才消失。** ⚠️ **关键在"当"字怎么读**：<br>**它不能读作"位置当"——因为全卦唯一不当位的九四，恰恰就是"改命"并拿到"悔亡…吉"的那一爻。**<br>**所以"当"只能读作"时机与分寸恰当"**：**巳日到了（时）＋ 三就成议了（序）＋ 有孚了（信）＋ 该止的时候止了（上六居贞）。** **这四项做到，就是"革而当"。**（这条推论的完整论证见第四节第 2 条。）<br>⑤ **⚠️ 天地革而四时成**——**天地的变革产生了四季。** 这是《周易》对变革最高层的辩护：**变革不是秩序的反面，是秩序的产生方式。** ⚠️ **也是大象传"治历明时"的直接来源**：四时既是天地之革的产物，人对它的记录与公示就是历法。<br>⑥ **汤武革命，顺乎天而应乎人**——⚠️ **"革命"一词出自此处。** 彖传给的条件是两条：**顺乎天（合于大势）＋ 应乎人（合于人心）。** ⚠️ **人物为彖传原文所举，本库照录，不作史实断言，亦不引申为任何现实层面的判断。**<br>⑦ **⚠️ 革之时大矣哉**——**与坎卦彖传"险之时用大矣哉"是同一句法。** **全卦的落点是一个"时"字。** |
| **大象传（行动纲领）** | 泽中有火，革。君子以治历明时。 |
| **⚠️⚠️ "治历明时"解（全卦最高原则，也是全书最"技术性"的一条纲领）** | **治历**＝制定、修订历法；**明时**＝使时令明确、让节气清楚可知。<br>**⚠️ 第一个问题：为什么"变革"的行动纲领是"制历法"？** 这条纲领初看极不相称，**但它是全书最精准的一条**。三层机制：<br>**① 因为革卦的全部难点是"时"（彖传落点"革之时大矣哉"），而历法就是把"时"变成可公开查证的东西。** 卦辞说"巳日乃孚"——**若"巳日"只在你心里，别人无法确认它到了；写进历法，所有人都能自己看。**<br>**② 因为历法一旦颁布，"什么时候该做什么"就不再依赖个人判断，而有了公共标准——⚠️ 这正是"孚"（信任）的来源。** **人们相信的不是你，是那个可核对的时间表。**<br>**③ 因为"天地革而四时成"**：**四时是天地之革的成果，历法是人对这个成果的记录。** **能把"变"记录成"可预期的节律"，变就不再是动乱。**<br>**⚠️ 落到现代——这一条解释了大多数组织变革失败的真正原因**：<br>> **变革失败很少是因为方案错，多数是因为"时间不明"。** 员工不知道下一步什么时候来、要多久、什么时候结束，**于是每个人自己编一个版本，谣言填满空白，信任先崩掉。方案再好也推不动，因为"孚"没有了。**<br>**四条操作**：<br>· **把变革做成公开的时间表**——分几个阶段、每阶段起止、每阶段做什么、什么时候能看到结果；<br>· **让人能自己查到"现在到哪一步了"**——⚠️ **可核对性就是"孚"**；<br>· **⚠️ 按预告的时间发生**——**变革正当性的一半来自"说了这一天动，就这一天动"**（呼应六二"巳日乃革之"）。**改期一次，孚掉一半**；<br>· **给出终点**——**告诉人们什么时候结束**（呼应上六"居贞吉"：革是有终点的，不是永久动员）。 |
| **总铁律** | ① **时机未到就把自己绑住，一件事都不做**（初九"巩用黄牛之革"，象传"**不可以有为也**"）；<br>② **窗口只有一个，就是"巳日"**（六二"巳日乃革之，**征吉**"）——**过了这个窗口，"征"就变成凶**（九三、上六都是"征凶"）；<br>③ **方案必须"三就"才有孚**（九三"革言三就，有孚"）——**程序不是拖延，程序是信任的来源**；<br>④ **⚠️ 改命必须在有孚之后**（九四"**有孚改命**"）：**语序不可颠倒，不是改完了再去争取信任**；<br>⑤ **领导者自己必须先变，而且要变得看得见**（九五"大人虎变"，象传"**其文炳也**"）；<br>⑥ **⚠️ 接受三层分化并及时收手**（上六"君子豹变，小人革面。**征凶，居贞吉**"）——**要求全员真心转变，就是"征凶"**；<br>⑦ **必须有鼎**（序卦传"革物者莫若鼎"）——**只拆不立，最后是鼎九四"折足覆餗"**。 |

## 二、爻级字段

### 初九 · 巩用黄牛之革

| 字段 | 内容 |
|---|---|
| **爻辞** | 巩用黄牛之革。 |
| **象传** | 巩用黄牛，不可以有为也。 |
| **位属性** | 阳爻居阳位，**当位**；失中；**居离之最下**。按本库结构律，离在下 → 初九必然当位。 |
| **判词 → 行动语义** | **⚠️ 无吉凶判词，只给一个动作** → **行动语义：把自己捆紧，一件事都不做。** ⚠️ **象传把话说到最硬："不可以有为也"——不是"少做"，是"不可以有为"。** |
| **关键词解** | **巩**——**固、捆紧、加固。**<br>**黄牛之革**——**黄牛皮。** ⚠️ **两个字都有讲究**：<br>· **黄**＝中色，在《周易》里固定代表**中道**（离六二"黄离，元吉"、坤六五"黄裳，元吉"、鼎六五"黄耳"）；<br>· **牛**＝最驯顺而有力的畜（对照离卦辞"畜牝牛，吉"——用极顺之德压住烈性；对照大畜六四"童牛之牿"——给小牛套上木牿）；<br>· **革（皮）**＝最坚韧的束缚材料。<br>**合起来：用最坚韧、且合于中道的东西，把自己牢牢固住。** |
| **⚠️ 全书最精巧的一次字义反用** | **卦名是"革"（变），初九用"革"（皮）把自己绑住（不变）。**<br>**⚠️ 《周易》用这个双关说了一件事：变革的第一个动作，是反方向的——先把自己绑住。**<br>**为什么——因为看清"必须改"的人，天然有一股要立刻动手的冲动，而这股冲动出现的时间，永远早于"巳日"。** 卦辞已经说了"巳日乃孚"：**在有人相信之前动手，方案再对也没有孚，等于零。** |
| **⚠️ 本库"不动"三型（本卡增量）** | 本库此前有两型"勿用"（坎卦卡已分清）。**革初九是第三型**：<br>| 型 | 代表爻 | 性质 | 核心字 |<br>|---|---|---|---|<br>| **蓄力型** | 乾初九"潜龙勿用" | 有前途的等待，在攒力 | **潜** |<br>| **止损型** | 坎六三"勿用"（象传"终无功也"） | 此时怎么动都无成果，要停手 | **停** |<br>| **⚠️ 约束型** | **革初九"巩用黄牛之革"**（象传"不可以有为也"） | **⚠️ 力已备、判断已清，纯粹因为时机未到而主动自缚** | **⚠️ 缚** |<br>**⚠️ 第三型与前两型的关键差别：它不是"没准备好"，也不是"动了没用"，是"准备好了、动了也会有用，但现在动会毁掉'孚'"。** **这是最难忍的一种不动，因为你手上什么都齐了。** |
| **识别信号** | ① **你已经很清楚必须改，而且方案基本成型**；② ⚠️ **但"必须改"这件事，目前基本只有你在说**；③ 你正想做一件"先动一小步"的事——**发个信号、搞个试点、找几个人先透露、在会上先提一句**；④ 你在跟自己说"总要有人先开口"。<br>**⚠️ 第③项是本爻的确诊指标：所有"先动一小步"，在革卦初九都属于"有为"。** |
| **该做** | ① **把方案做完，但不发**——**做和发是两件事，初九只允许做**；② **⚠️ 把自己的情绪绑住**——"巩"的对象首先是自己的急迫感；③ **去建立"巳日"的观测指标**（见卦级"巳日乃孚"专解的四条标志），**把判断从"我觉得该改了"换成"可观察的事实"**；④ 等。 |
| **不该做** | ① **任何形式的"先动一步"**——象传"不可以有为也"没有留余地；② 用"试点"、"小范围"、"只是提一下"给自己开口子；③ 反过来，也不要把"绑住"理解成放弃——**卦辞四德齐全，革是被完全肯定的，只是不在现在。** |
| **与大畜六四"童牛之牿"的对照（同族意象，方向相反）** | **两爻都用"牛 ＋ 束具"这一组意象，动作方向正好相反**：<br>· **大畜六四"童牛之牿，元吉"**——**给小牛套上木牿：约束别人，且在最早最小、最不痛的地方下手**，故**元吉**；<br>· **革初九"巩用黄牛之革"**（象传"不可以有为也"）——**用黄牛皮把自己捆住：约束自己**，且**无判词**。<br>**⚠️ 同一族手法，一个对外、一个对内**。本库口径：**大畜的约束是"以止养健"（约束是为了后面能发），革初九的约束是"以缚待时"（约束是为了不毁掉孚）。** |
| **与大畜初九、需卦的对照** | **大畜初九"有厉，利已"**（象传"不犯灾也"）——**见险就止，是"因为前面有危险而止"**；**需卦（5）是"险在前方、底子刚健，待时"**；**革初九是"前面没有危险，也不缺力，纯粹因为人心未熟而自缚"。⚠️ 三种"不动"的理由完全不同：一个怕灾，一个待时，一个待信。** |

### 六二 · 巳日乃革之

#### ⚠️ 本爻是全卦唯一的行动窗口

| 字段 | 内容 |
|---|---|
| **爻辞** | 巳日乃革之，征吉，无咎。 |
| **象传** | 巳日革之，行有嘉也。 |
| **位属性** | 阴爻居阴位，**当位且得中**；**居离之中**；**乘初九之刚**（离在下必然）。<br>⚠️ **当位 ＋ 得中 ＋ 乘刚，且判"征吉"——这是本库最好的一组位属性组合之一。** |
| **判词 → 行动语义** | **征吉，无咎** → **⚠️ 主动出击，吉；且无灾。行动语义：就在这一天动手，并且公开地动。** ⚠️ **这是全卦唯一的"征吉"，也是全卦唯一的"吉"字出击授权。** |
| **关键词解** | **巳日**——见卦级版本说明。**那个时机成熟的日子。**<br>**乃**——⚠️ **全卦时序的枢纽字：才、这才。** **"巳日乃革之"＝到了那一天，这才去改它。** **在此之前不改，在此之后不等。**<br>**革之**——**改它。** ⚠️ 注意有宾语"之"：**动手对象是明确的那一件事，不是笼统的"变革"。**<br>**征吉**——**主动前往、发动，吉。**<br>**无咎**——**并且不会落下灾祸。** |
| **⚠️ 革卦三个"征"字：一吉两凶（全卦时序最硬的证据）** | **革卦六爻中出现了三次"征"，判断是"一吉两凶"，而吉的那个在最前面**：<br>| 爻 | 判词 | 位置 |<br>|---|---|---|<br>| **六二** | **征吉** | ⚠️ **唯一的窗口** |<br>| **九三** | **征凶**，贞厉 | 窗口刚过 |<br>| **上六** | **征凶**，居贞吉 | 收尾阶段 |<br>> **⚠️ 口径（可直接用于"定势"）：革卦不问"该不该动手"，只问"是不是巳日"。是，则征吉；早了（初九）不许有为，晚了（九三、上六）征凶。**<br>**⚠️ 与困卦（47）的"征"字反转对照**：困卦是**九二征凶 / 上六征吉**（前面不动、最后要动）；**革卦是六二征吉 / 九三、上六征凶（中间动、前后都不动）**。<br>**两卦合起来给出本库一条通则**：<br>> **同一个"征"字在《周易》里从不自带吉凶，它的吉凶完全由"你在第几爻"决定。**
> **困卦的窗口在最后（等无可等就必须动），革卦的窗口在中间（早了没人信，晚了错过时机）。** |
| **⚠️ 乘刚在本爻是推力，不是压迫** | **六二乘初九之刚——而初九正是"巩用黄牛之革"（把自己绑住的那股力量）。**<br>**⚠️ 意象极妙：变革的发动，正是踩在前一阶段的自我约束之上。** 初九攒下的那份"没有乱动"，成了六二"征吉"的底座。<br>**本库口径的一条重要补充**：**"乘刚"本身是中性的结构事实，它的性质由卦决定**——<br>· **在困卦是被顶迫**（六三"据于蒺藜，乘刚也"→ 凶）；<br>· **在革卦是被推动**（六二乘初九 → 征吉）；<br>· **在井卦是被托举**（上六乘九五 → 勿幕而元吉）。<br>**⚠️ 结论：不要一看到"乘刚"就判为不利。要问"你脚下那个刚，是在顶你，还是在托你"。** |
| **识别信号** | ① **"这样下去不行"已经不只是你在说**（⚠️ 最硬的一条）；② **有一个明确的外部触发刚刚发生**——数据出来了、周期到了、上级换了、出了一件掩盖不住的事、旧办法公开失效了一次；③ 你的方案在初九阶段已经做完了；④ **原来最反对的人开始说"确实得想想办法"**。 |
| **该做** | ① **就在这一天动**——**不要再等一轮**；② **公开地动**——呼应大象传"治历明时"：**动手要有明确的时间点，并让人知道**；③ 对象要明确（"革**之**"），一次只改讲得清的那一件；④ **同时准备走九三的"三就"**——征吉不等于一次就成，见下爻。 |
| **不该做** | ① **再等一个"更好的时机"**——⚠️ **过了六二，下一爻就是"征凶，贞厉"**；② 悄悄地动（那会让人自己去猜，回到"孚"的流失）；③ 一次改一堆事。 |
| **与师卦初六"师出以律"的对照** | **师初六"师出以律，否臧凶"**，象传"**失律凶也**"——**开打之前必须先立纪律，否则无论结果好坏都是凶**；**革六二是同一位置上的另一件事：开动之前必须先到"巳日"。**<br>**⚠️ 两卦对"发动"的前置条件要求不同**：**师要"律"（内部秩序），革要"时"（外部人心）。** 而两者的违反代价都是"凶"。**本库由此可提一条：《周易》从不允许"直接开始"——发动之前必有一道前置闸门，师是律，革是时，井是修（六四"甃"），鼎是清（初六"出否"）。** |

### 九三 · 革言三就

| 字段 | 内容 |
|---|---|
| **爻辞** | 征凶，贞厉。革言三就，有孚。 |
| **象传** | 革言三就，又何之矣。 |
| **位属性** | 阳爻居阳位，**当位**；失中；**居离之顶、下卦之极**（离在下 → 九三必然当位）。 |
| **判词 → 行动语义** | **⚠️ 征凶 ＋ 贞厉 ＋（出路）有孚** → **行动语义：不许强推（征凶）；即使你完全守正，这个位置本身也危险（贞厉）；唯一的出路是走完"三就"这道程序。** |
| **⚠️ 判词组合专解："贞厉"** | 按本库判词口径（规格第 3 节）：**"贞凶"＝守正也凶，问题不在品德，在处境与选择的根本错位**；**"厉"＝警告，非判死**。<br>**⚠️ "贞厉"＝两者的合成，是"贞凶"的减一级形态**：<br>> **"贞厉"＝你的品德与立场都没问题，但这个位置本身有危险，所以守正也不能免除警告。**<br>**这一条落到现代极其重要**：**九三是变革里最容易崩掉的位置——你完全正确、完全正当、并且刚刚拿到了六二的"征吉"，于是你以为可以一路推下去。⚠️ 《周易》在这里说：不行，而且你的"对"救不了你。**<br>⚠️ **"贞厉"这一判词组合未见于本库现有口径表，建议入库**（见本卡报告）。 |
| **关键词解** | **征凶**——**强行推进则凶。**<br>**贞厉**——见上格。<br>**革言**——⚠️ **"言"是议论、主张、方案。"革言"＝变革的议案。**<br>**三就**——"就"是**成、成就、告成**。**"三就"＝三次成议、三度审议告成。**<br>**有孚**——**这样才会有人信。**<br>**⚠️ 全句的逻辑链：不许硬推（征凶）→ 你的正当性不足以豁免风险（贞厉）→ 走三就（程序）→ 才有孚（信任）。** |
| **⚠️⚠️ "革言三就"专解：本卦最实用的一条程序法** | **⚠️ 这一爻回答了革卦最难的问题：孚从哪儿来？**<br>**卦辞给了一个来源："巳日"（时机）。九三给了第二个来源："三就"（程序）。**<br>> **⚠️ 孚的公式（本卡贡献）：孚 ＝ 时机（巳日）× 程序（三就）。**
> **时机对而程序缺 → 九三"征凶"（人心到了，你却一言而决，于是没人服）。**
> **程序全而时机未到 → 初九"不可以有为"（走了一堆流程，没人觉得有必要改）。**
> **⚠️ 两者是乘法关系，任一项为零，孚就是零。**<br>**"三就"落到现代的三条操作**：<br>· **⚠️ 不要一次会就定**——**至少三轮：提出 → 反馈修改 → 定稿确认**，而且**每一轮都要留下可查的记录**（呼应大象传"治历明时"：可核对性就是孚）；<br>· **每一轮必须真的改动方案**——**⚠️ "三就"是三次"成"，不是三次宣讲。走形式的三轮，孚不会长出来**；<br>· **把反对意见写进方案里**——**这是让反对者变成"有孚"的唯一办法**（呼应彖传"文明以说"：讲清楚 ＋ 让人心悦）。<br>**⚠️ 最需要破除的错误认知**：**"再讨论就是拖延"。** 在革卦里，**讨论不是拖延的反面，是孚的来源**；跳过它的代价是"征凶"。 |
| **⚠️ 象传"又何之矣"** | **字面：还能往哪儿去呢。** ⚠️ **两读并存**：<br>· **读法 A**：**三就之后，程序已尽，不必再往前推**（"还能往哪儿去"＝已经到位了）；<br>· **读法 B**：**三就之后你还想去哪**（反问：不要再进了）。<br>**⚠️ 两读的行动结论一致：程序走完就够了，不要在程序之外再加动作。** 本库取此为主。 |
| **识别信号** | ① 你确信方案对，**而且你确实是守正的、动机干净的**；② 你刚经历过六二那种"终于可以动了"的窗口，**现在想一路推下去**；③ **方案还没有经过反复审议、还没有形成书面共识**；④ ⚠️ **你正在心里说"再讨论就是拖延""这么明显的事还要开几次会"**；⑤ 你已经感到阻力，且倾向于用权力压过去。 |
| **该做** | ① **⚠️ 停下"推"的动作，转去走"三就"**——把提出、修改、定稿三轮真的走完，留下记录；② **每一轮都真改方案，把反对意见吸收进去**；③ 用"文明以说"的姿态（讲清道理 ＋ 让人心悦），不用权力；④ **接受"贞厉"**：知道自己对，但也知道这个位置本身危险，所以更要走程序。 |
| **不该做** | ① **用"我是对的"代替程序**（→ 征凶）；② **用"我守正"来自我安慰**（→ 贞厉：守正不免除危险）；③ 走形式的三轮；④ 在三就之外再加动作（象传"又何之矣"）。 |
| **与讼卦、师卦的对照** | · **讼卦（6）整体口径"中吉终凶"**——**冲突死磕到底必凶**。**⚠️ 革九三"征凶"是同一个错误在变革场景里的形态：你不是在跟人打官司，你是在跟"共识还没形成"这件事死磕。**<br>· **师卦（7）初六"师出以律"**——**动之前必须有形式（纪律）**；**革九三"革言三就"——推进之中必须有形式（程序）。⚠️ 差别在阶段：师的形式在开打前，革的形式在开动后、改命前。** |
| **与明夷九三的对照** | 明夷九三的口径是"**拿到主导权后绝不可急于清算**"（"不可疾贞"）。**⚠️ 革九三是同一条律的另一面：拿到发动窗口后绝不可急于推行。** **两处都是三爻、都是"刚刚得势"、都被明确警告"不要快"。** 本库由此可强化"三多凶"这一系辞通则的具体内容：**⚠️ 三爻之凶，多数不是来自敌人，是来自"刚刚有了势就想一次做完"。** |

### 九四 · 有孚改命

#### ⚠️⚠️ 本爻是全卦唯一不当位之爻，也是全卦真正动手改的那一爻——本卡最重要的结构发现

| 字段 | 内容 |
|---|---|
| **爻辞** | 悔亡，有孚改命，吉。 |
| **象传** | 改命之吉，信志也。 |
| **位属性** | 阳爻居阴位，**⚠️ 不当位**；失中；**已入上兑**。按本库结构律，兑在上 → 九四必然不当位。<br>**⚠️ 全卦六爻只有这一爻不当位。** |
| **判词 → 行动语义** | **⚠️ 悔亡 ＋ 吉（同爻双判）** → **行动语义：先把那份本该有的悔消掉，然后得吉。前置条件写在动作里：有孚，才改命。** |
| **⚠️ 判词组合专解："悔亡…吉"** | 按本库口径，**"悔亡"是挽回级——本该有的悔恨消失了，不是得到好处**；**"吉"是进／成**。<br>**⚠️ 本爻把两者写在同一爻，构成一个两段式结果**：<br>> **第一段"悔亡"——变革天然带的那份悔（卦辞已经预告了"悔亡"）在这一爻被消掉；**
> **第二段"吉"——消掉之后才谈得上吉。**<br>**⚠️ 并且卦辞层的"悔亡"在此兑现：卦辞许诺的东西，落到爻位上有确定地址。** 本库由此可提一条读法：**卦辞里的判词，往往在某一爻上有对应的落点；找到那个落点，就找到了这一卦的操作核心。**<br>⚠️ **"悔亡…吉"这一判词组合未见于本库现有口径表，建议入库**（见本卡报告）。 |
| **关键词解** | **悔亡**——见上格。<br>**⚠️ 有孚改命**——**有了信任，然后改命。**<br>· **孚**＝诚信、被相信；<br>· **命**＝命令、政令、名分、天命。**"改命"＝更改现行的命令与名分秩序**，即**制度性的、正式的变更**（不是做法上的调整）。<br>**⚠️ 语序绝对不可颠倒：有孚 → 改命。不是"改了命再去争取信任"。** 这与彖传"**巳日乃孚，革而信之**"（到了那天革，人才信）合起来是一个两级结构：**时机层面是"革而后信"（到点就动，信任随之而来）；制度层面是"有孚而后改命"（正式改制必须建立在已有的信任之上）。** **⚠️ 两句不矛盾：先在六二动手做（革而信之），孚长出来之后，才在九四改制度（有孚改命）。**<br>**吉**——**吉。** |
| **⚠️ 象传"信志也"** | "**信志**"＝**（人们）相信他的志向。**<br>**⚠️ 注意象传给"改命之吉"的理由不是"他位置对"、不是"他方案好"，而是"人们信他的志"。** **这正是本爻不当位却得吉的全部解释。** |
| **⚠️⚠️ 本卦最重要的结构发现（本卡对全库的核心贡献）** | **事实层（纯经文与结构，无需推演）**：<br>· **革卦六爻五爻当位，唯一不当位的是九四**（由"兑在上 → 九四不当位"机械推出）；<br>· **而九四正是"有孚改命"——全卦真正动手改制度的那一爻**；<br>· **它的判词是"悔亡…吉"，凭据是"有孚"，象传的理由是"信志也"。**<br>**⚠️ 机制解释（这是本卡的推演，标明为义理层）**：<br>> **"当位"的含义是"符合现有的名分秩序"。**
> **而"改命"的定义就是"改变现有的名分秩序"。**
> **⚠️ 所以"改命"这个动作在结构上不可能"当位"——它一旦当位，就不是改命了。**<br>**由此得出本卡最重要的一条口径**：<br>> **⚠️ 变革的正当性不来自位置，来自信任。**
> **《周易》把变革的实际动作放在唯一一个"位置不正当"的地方，然后告诉你：只要"有孚"，它就"悔亡…吉"。**<br>**⚠️ 这同时解答了彖传"革而当，其悔乃亡"中"当"字怎么读的问题**：**"当"不可能是"位置当"（因为改命那爻位置不当），只能是"时机与分寸当"**——即**巳日到了（时）＋ 三就成议了（序）＋ 有孚了（信）＋ 该止时止了（上六居贞）**。**这四项就是"革而当"的操作定义。**<br>**⚠️ 落到现代，这一条极其解压**：<br>· **推动变革的人，往往不是最"名正言顺"的那个**——不是一把手、权限不够、这事本不在你职责范围内、你是空降的、你是被临时抽调的；<br>· **《周易》没有把这当成障碍。** 它把"改命"就放在这个位置上，并且给了吉；<br>· **它只提一个条件：有孚。** **所以位置不够时，要补的不是权限，是信任。** |
| **⚠️ "不当位的四种救法"（本库累计，本卡补第三条）** | | 救法 | 代表爻 | 结果 |<br>|---|---|---|<br>| ① **得中** | 坎九二"求小得"、困九二"无咎" | 还能动、还有余地 |<br>| ② **有与**（有人和你一起） | 困九四"虽不当位，**有与也**" | **终吉** |<br>| ③ **⚠️ 有孚**（人们信你的志） | **革九四"有孚改命"，象传"信志也"** | **⚠️ 悔亡…吉** |<br>| ④ **居中主事而不越位** | 师九二"在师中吉" | 中吉·无咎 |<br>**⚠️ 而②③两条都出现在"兑在上的九四"这个固定席位上**（困 47 与革 49 上卦皆兑，九四必不当位）：<br>· **困九四靠"有与"得终吉**；<br>· **革九四靠"有孚"得吉**。<br>> **⚠️ 口径（建议入库）：兑在上的九四是本库"靠人际资源救不当位"的固定席位。** 结构上它注定名不正，**而它的两条出路都不是位置性的：一条是"还有人跟你一起"，一条是"人们信你的志"。** |
| **识别信号** | ① **巳日到了、三就走完了、确实有人信你了**——⚠️ **三项都成立**；② 现在要做的是**正式的、制度性的变更**（发文、改架构、改考核、改分配、改决策权）；③ **⚠️ 你的位置未必名正言顺**——权限不足、不是一把手、这事本不在你职责内；④ 你正因为第③项而犹豫。 |
| **该做** | ① **⚠️ 就在"有孚"的窗口里改命**——**孚是有保质期的，三就之后不改，孚会流失**；② **把"改命"做成正式的、明确的、书面的**（"命"是命令，必须落到文件、公告、制度里，不能停在口头共识）；③ 同时给出时间表与终点（大象传"治历明时"）；④ **⚠️ 接受"悔亡"就是最好的结果**——不要指望这次变革让所有人满意。 |
| **不该做** | ① **在"有孚"之前改命**（→ 退回九三"征凶"）；② **⚠️ 因为"我位置不够"而不改**——**本爻明写不当位而吉，位置不是理由**；③ 只在口头上改而不落到制度（那是上六的"革面"，不是"改命"）。 |
| **与师卦九二、坤卦六五的对照** | **师九二"在师中吉，无咎，王三锡命"**——**阳居阴位、不当位而得中，是卦主；师卦卡的解释是"统帅本不该居君位，他的价值在于得中：有实权、能决断、却不越位"。**<br>**⚠️ 革九四与它构成一组重要区别**：**师九二不当位而"不越位"（守住自己不是最终拍板者）；革九四不当位而"改命"（恰恰就是要动那个名分秩序）。**<br>**差别在于卦**：**师卦的任务是打赢，所以名分秩序不能乱；革卦的任务就是改那个秩序，所以"越位"正是它的工作内容。⚠️ 而它唯一的合法性来源是"有孚"——这也解释了为什么革卦"孚"字出现四次。** |

### 九五 · 大人虎变（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 大人虎变，未占有孚。 |
| **象传** | 大人虎变，其文炳也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位；**上兑之中**——**全卦卦主**。 |
| **判词 → 行动语义** | **⚠️ 无吉凶判词，只给状态与一句极特殊的断语（未占有孚）** → **行动语义：领导者自己彻底改变，而且要改得看得见。** |
| **关键词解** | **大人**——有位有德者、领导者（与卦辞"大人吉"式用法同族；对照师卦"丈人"、困卦"大人"）。<br>**虎变**——**像虎那样变化。** ⚠️ **取象在虎的斑纹：大而鲜明、一望即知。** 象传"**其文炳也**"——"炳"是光明显赫。**所以"虎变"的重点不只是"变得彻底"，更是"变得看得见"。**<br>**⚠️ 未占有孚**——**还没有占问，就已经有孚了。**<br>· **"占"**＝占问、卜问，即**通过某种手段去求证、去取得凭据**；<br>· **"未占有孚"＝不需要任何证明手段，人们已经相信了。** |
| **⚠️⚠️ "未占有孚"专解（全书最特殊的一句，也与本库定位直接相关）** | **《周易》在这里说了一句极罕见的话：不用占了。**<br>**⚠️ 它给出的机制是因果性的，而且就在同一爻里**：<br>> **因为"大人虎变"（领导者自己变了，而且变得所有人都看得见），所以"未占有孚"（不需要任何证明，人们就已经相信）。**<br>**⚠️ 落到现代——这是变革中最不可替代、也最常被跳过的一件事**：<br>· 文件可以发、口号可以喊、KPI 可以改、组织图可以重画——**这些在上六叫"小人革面"**；<br>· **只有一把手自己的行为可见地改变，才是"虎变"**：他自己的时间怎么花、自己先放弃了什么、自己第一个按新规则被约束、自己公开承认了旧做法的错；<br>· **⚠️ 而"未占有孚"说的正是它的效果：一把手真的变了，别人不需要看任何证明材料就信了。反过来，一把手没变，你做多少沟通、多少宣讲、多少数据，都补不上这个缺口。**<br>**⚠️ 与本库定位的关系（合规层面的一条重要说明）**：**历史旧立场曾以"未占有孚"支持起卦与预测禁令；现行合规口径统一见 `知识卡00` 第七节及宪法 RULE-041／RULE-007。** 本爻仍提醒使用者关注可见的事实与已经建立的信任，不得以占测或推测推翻定域定位。 |
| **⚠️ 虎变 / 豹变 / 革面：变革深度的三层**（本爻与上六合读） | | 层 | 谁 | 变什么 | 象传 |<br>|---|---|---|---|<br>| **虎变** | **大人（领导者）** | **根本改变，且鲜明可见** | **其文炳也**（大而显赫） |<br>| **豹变** | **君子（真正跟随的贤者）** | **真实改变，细密渐成** | **其文蔚也**（细而茂密） |<br>| **革面** | **小人** | **只改表面** | **顺以从君也**（顺从而已） |<br>**⚠️ 这三层是本卦对"变革能到多深"最诚实的回答，详见上六。** |
| **⚠️ 尊位职责清单（本库累计，本卡新增一条）** | · **讼九五**（元吉）——**中正裁决、案结事了**；<br>· **师六五**（无咎／贞凶）——**选对人，然后放手**；<br>· **坎九五**（无咎）——**水位一平就收，不求满**；<br>· **井九五**（无判词）——**守中正，并立刻走向开放**；<br>· **困九五**（无判词）——**守中直、待徐说、以祭祀自持**；<br>· **⚠️ 革九五**（无判词，"未占有孚"）——**⚠️ 自己先变，而且要变得看得见。**<br>**⚠️ 六个尊位排下来，只有革九五的职责是"改变自己"。** 其余五个都是"处理外部"（裁决、选人、止步、开放、自持）。**本库由此可提一条：变革是唯一一种"领导者必须先改变自己才能推动"的事。** |
| **⚠️ 与明夷"用晦而明"的正反对照** | · **明夷 36 六五**，象传"**利用晦也**"——**在黑暗环境里，把光收起来是有益的**；<br>· **革 49 九五**，象传"**其文炳也**"——**在变革之时，要把纹彩显赫地打出来。**<br>**⚠️ 同为第五爻、同为关键位置，一个要藏，一个要显。** 差别只在卦（环境）：<br>> **明夷的环境是黑的，你亮就成靶子；革的环境是"必须有人相信改变正在发生"，你不亮就没有孚。**<br>**这是本库"《周易》从不给'要不要发光'一个绝对答案，它给的是'先看你在哪一卦里'"这条方法论的第三次实证**（前两次：离 30 ↔ 明夷 36；井 48 九三 ↔ 明夷 36）。 |
| **识别信号** | ① 你是这场变革里位置最高的人；② 制度已经改了（九四走完），**现在要让它真的运起来**；③ **你正在考虑靠沟通、宣讲、培训、考核来推动**；④ ⚠️ **而你自己的行为、时间分配、被约束的方式，还完全是旧的那一套**。 |
| **该做** | ① **⚠️ 自己先变，并且让人看见**：自己第一个按新规则受约束、公开承认旧做法的问题、改变自己的时间与注意力分配、放弃一项自己的旧特权；② **让变化是"炳"的**——鲜明、具体、可指认，不是"我的观念变了"；③ 相信"未占有孚"的机制：**你变了，别人不需要证明材料。** |
| **不该做** | ① **让别人变而自己不变**——**这是变革失败最常见的单一原因，且它在上六直接落成"小人革面"**；② 用沟通量代替自身改变；③ 反过来，也不要把"虎变"做成表演——**"孚"是被观察出来的，不是被展示出来的**（呼应兑卦铁律"悦必须刚中而柔外，内核必须刚"）。 |

| **爻辞** | 君子豹变，小人革面。征凶，居贞吉。 |
| **象传** | 君子豹变，其文蔚也。小人革面，顺以从君也。 |
| **位属性** | 阴爻居阴位，**当位**；居全卦之终；**乘九五之刚**（兑在上必然）。 |
| **判词 → 行动语义** | **⚠️ 征凶 ＋ 居贞吉（同爻双判，取决于动还是居）** → **行动语义：不可再推进（征凶）；停下来、守住已改成的局面，则吉（居贞吉）。** ⚠️ **这是规格第 3 节"上爻限定"里"知止则吉"的标准例证。** |
| **关键词解** | **君子豹变**——**君子也随之变化，如豹纹渐渐成形。** 象传"**其文蔚也**"——"蔚"是茂密、细密。⚠️ **与九五"炳"（大而显赫）相对：豹纹细密，是"真实但不张扬、渐次形成"的改变。**<br>**小人革面**——**小人只改变面容（表面）。** 象传"**顺以从君也**"——**他们只是顺从而跟着君上罢了。**<br>**征凶**——**再往前推进则凶。**<br>**居贞吉**——**安居、守正，则吉。** |
| **⚠️⚠️ 本爻是全卦最反直觉、也最实用的一条** | **《周易》在变革的最后一爻，明确地把人分成了三层，并且——⚠️ 它没有判"小人革面"为凶，也没有要求你把他们变成"虎变"。**<br>**象传给"小人革面"的评语是中性的："顺以从君也"（顺从而跟着走）。**<br>> **⚠️ 口径（本卡最重要的实操结论）：变革的成功标准不是"所有人都真心转变"，而是"大人虎变、君子豹变、小人革面"这三层同时成立。**
> **⚠️ 要求全员虎变，就是"征凶"。**<br>**为什么"革面"是合格结果——三层机制**：<br>**① 变革要的是"新规则被遵守"，不是"所有人内心认同"。** **只要行为跟上了（革面 ＋ 顺以从君），系统就跑得起来。**<br>**② 强求内心认同，一定会走向甄别与清算**——**而甄别谁"真心"是不可能完成的任务，它只会制造表演。⚠️ 这正是"征凶"。**<br>**③ 变革必须有终点。** 大象传"治历明时"包含了"什么时候结束"这一项；**上六"居贞"就是那个终点。** 一场没有终点的变革，会把"革"变成永久动员，最后连"革面"都保不住。<br>**⚠️ 落到现代的三条**：<br>· **⚠️ 结束变革，并公开宣布结束**；<br>· **只考核行为，不考核态度**；<br>· **接受组织里有一部分人只是"跟着走"，并把这当成正常，不当成隐患。** |
| **⚠️ 与离卦上九"获匪其丑"的对照（本卡最佳的一组上爻对照）** | · **离 30 上九"……获匪其丑"**，本库离卦卡的口径是"**到顶时只除首恶、绝不扩大**"，且这是"全书少见的上爻无咎"；<br>· **革 49 上六"小人革面。征凶，居贞吉"**——**到顶时只到"革面"为止，不深究人心。**<br>**⚠️ 两爻是同一条律的两次出现：《周易》在两个"必须处理人"的卦的最后一爻，都明确地要求"收手、不扩大"。**<br>**本库口径**：**凡涉及处理人的收尾（除恶、变革），到顶时的正确动作是划一条明确的界线并停在那儿。扩大化在这两卦里都被明确判为错。** |
| **⚠️ 与师卦上六"小人勿用"的关键区分（必须分清，否则会读反）** | · **师 7 上六"大君有命，开国承家，**小人勿用**"**，象传"**小人勿用，必乱邦也**"——**绝不能把权位交给无德之人**；<br>· **革 49 上六"**小人革面**"**，象传"**顺以从君也**"——**可以接受他们只改表面。**<br>**⚠️ 两条不矛盾，而且必须同时成立**：<br>> **"不给权位"（师上六）≠ "要求真心转变"（革上六所否定的）。**
> **⚠️ 正确的组合是：接受他们只是革面（不强求人心），同时绝不把权位交给他们（不误置人事）。**<br>**⚠️ 只取一半都会出事**：**只要求真心转变 → 革上六"征凶"（清算扩大化）；只接受革面而把权位也给了 → 师上六"必乱邦也"。** **本库由此可给出变革收尾的完整口径：宽于人心，严于人事。** |
| **⚠️ 与规格"上爻限定"的关系** | 规格第 3 节：**"上爻反的是'不知止的极'，不是'到顶'本身。过刚则悔，过柔则凶，知止则吉，无内容则白过。"**<br>**⚠️ 革上六是"知止则吉"最干净的一个例证**：**它把两种结局并排写在同一爻里——"征凶"（不知止）与"居贞吉"（知止）。**<br>**并且与本批的两个上爻构成一组**：<br>· **困 47 上六"征吉"**——**困到极处必须动**；<br>· **井 48 上六"勿幕…元吉"**——**成到极处必须交出去**；<br>· **⚠️ 革 49 上六"征凶，居贞吉"**——**改到极处必须停。**<br>**⚠️ 三个上爻给出三种不同的终点动作：动、交、停。** **本库口径：上爻的正确动作由卦决定，没有一个通用的"到顶怎么办"。** |
| **识别信号** | ① 制度已经改完、领导者也变了（九四、九五走完）；② **你发现有一部分人只是表面配合**；③ **你正想再推一轮"把思想统一了"、"把不认同的人清一清"**——⚠️ **这就是"征"**；④ 变革已经进行了很久，**而你没有宣布过它什么时候结束**。 |
| **该做** | ① **停**（居）——**并且公开宣布变革结束**；② **守住已经改成的那一套**（贞）——把新规则做成日常，不再当成运动；③ **接受三层分化**：虎变、豹变、革面各安其位；④ **只考核行为，不考核态度**；⑤ ⚠️ **同时守住师卦那一半：不把权位交给"革面"的人。** |
| **不该做** | ① **再推一轮去统一思想或清理人**（→ 征凶）；② 要求所有人真心认同；③ 让变革无限延长（那会耗尽"孚"）。 |
| **与困卦上六、巽卦上九的对照** | · **困 47 上六"征吉"**——**柔在最上，拿回决断，动起来**；<br>· **巽 57 上九"丧其资斧，**贞凶**"**——**居高位还一味卑顺，丢掉断决之力**；<br>· **革 49 上六"征凶，居贞吉"**——**柔在最上，主动放弃继续推进的决断，反而吉。**<br>**⚠️ 三爻合读得出一条**：**"是否该继续用力"没有通则。巽上九错在该断而不断，革上六对在不该断而不断，困上六对在必须动时动了。判据始终是卦（处境），不是姿态。** |

| 爻 | 阶段 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |

**革卦三句话**：
1. **变革本身是被完全肯定的（四德齐全，"天地革而四时成"），但四德前面挂着一道闸门："巳日乃孚"。** 时机未到、无人相信之时，元亨利贞一个都不成立——**此时唯一正确的动作是初九：把自己绑住，一件事都不做。**
2. **孚 ＝ 时机（巳日）× 程序（三就）**，两者是乘法关系，任一项为零则孚为零。**时机对而跳过程序 → 九三"征凶，贞厉"（你对，但你的对救不了你）；程序全而时机未到 → 初九"不可以有为"。**
3. **变革的正当性不来自位置，来自信任**——**全卦唯一不当位的九四，正是"有孚改命"那一爻**，象传给的理由是"信志也"。**位置不够时，要补的不是权限，是孚。**

**本卦最反直觉的三条**：
- **卦名是"革"（变），而初九用"革"（皮）把自己捆住。** 变革的第一个动作是反方向的：**先把自己绑住，因为想动手的冲动出现的时间永远早于"巳日"。**
- **五爻当位，唯一不当位的九四恰恰就是动手改的那一爻。** **因为"当位"意味着符合现有秩序，而"改命"的定义就是改变现有秩序——它一旦当位，就不是改命了。**
- **⚠️ 变革的成功标准不是"所有人都真心转变"，是"大人虎变、君子豹变、小人革面"三层同时成立。要求全员虎变，就是"征凶"。** 而与师卦合读得出完整口径：**宽于人心，严于人事。**

## 四、本卦对全库的意义

### 1. ⚠️ 革 ／ 鼎：全库唯一一对直接讲组织变革的卦，而它们的结构对照是全库最漂亮的一组

**序卦传把这一对绑得极紧**："井道不可不革，故受之以革"→"**革物者莫若鼎**，故受之以鼎"。**革是除旧，鼎是立新。** 而**两卦的爻位结构，恰好把这个分工做了一次完美的印证**（下表为机械推导，可逐爻复核）：

| | **革 49（除旧）** | **鼎 50（立新）** |
|---|---|---|
| 卦象 | 上兑（泽）下离（火）——**泽中有火** | 上离（火）下巽（木）——**木上有火** |
| 结构律 | **离在下 → 初二三全当位**；**兑在上 → 四不当、五当位得中、上当位** | **巽在下 → 初二不当（二得中）、三当位**；**离在上 → 四五上全不当位** |
| **当位数** | **⚠️ 五爻当位，仅九四不当** | **⚠️ 仅九三一爻当位** |
| 那个例外之爻 | **九四"有孚改命"——真正动手改的那一爻** | **九三"鼎耳革，其行塞"——唯一提不起来的那一爻** |
| 卦辞四德 | **元亨利贞齐全**（前置"巳日乃孚"） | **元吉，亨**（⚠️ 版本待核，见鼎卡） |
| 主体 | 人（大人虎变、君子豹变、小人革面） | **器**（颠趾、有实、耳革、折足、黄耳金铉、玉铉） |
| 核心风险 | **无孚而改**（九三征凶、贞厉） | **承载超限**（九四"鼎折足，覆公餗，凶"） |
| 上爻 | **征凶，居贞吉**（知止则吉） | **玉铉，大吉，无不利**（刚柔节也） |

**⚠️ 这组对照最深的一层（本卡的推演，标为义理层）**：

> **革卦五爻当位——因为"除旧"是在现有秩序里做的事，你必须站得正、名分要够，唯一"不正"的那一下就是动手改的那一刻（九四）。**
> **鼎卦只有一爻当位——因为"立新"本身就还没有名分：新东西刚立起来的时候，它在旧秩序里全都是"不当位"的。**
> **⚠️ 而鼎卦的判词却极好（元吉、亨、上九大吉无不利）——这说明《周易》认为：新事物的价值不在"名正"，在"能不能承载"。**

**落到现代的一条组合口径**：
> **改的时候要讲名分（革：五爻当位，姿态是"文明以说"），立的时候不要等名分（鼎：一爻当位，判词却最好）。**
> **只革不鼎 → 拆完没有承载器，终点是鼎九四"折足覆餗"。**
> **只鼎不革 → 新东西装在旧结构里，回到革彖传"二女同居，其志不相得"。**

### 2. ⚠️ 变革时序表（本卡的核心交付物）

**革卦六爻是全库唯一一条完整的"变革阶段序列"，而它的每一步都有经文层的判词与象传背书。** 下表可直接作为操作清单使用：

| 阶段 | 爻 | 经文 | 象传 | 判词 | ⚠️ 这一步唯一要做的事 | ⚠️ 这一步最常犯的错 | 孚的状态 |
|---|---|---|---|---|---|---|---|
| **0 · 自缚** | 初九 | 巩用黄牛之革 | **不可以有为也** | 无 | **把方案做完但不发；绑住自己的急迫感；建立"巳日"的观测指标** | **"先动一小步"**（试点、放风、会上先提一句） | **无孚**（只有你在说） |
| **1 · 发动** | 六二 | **巳日**乃革之 | **行有嘉也** | **征吉·无咎** | **就在这一天动，且公开地动；对象只取讲得清的那一件** | **再等一个"更好的时机"**（过了就是征凶） | **孚开始生成**（彖传"革而信之"） |

| **5 · 收尾** | 上六 | 君子豹变，小人革面。**征凶，居贞吉** | 其文蔚也 / **顺以从君也** | **征凶／居贞吉** | **停，并公开宣布变革结束；只考核行为不考核态度；接受三层分化** | **再推一轮"统一思想／清理不认同的人"** | **孚已兑现为新常态** |

**⚠️ 三条贯穿全表的口径**：

**① 唯一的行动窗口是阶段 1（六二）。** 革卦三个"征"字，**一吉两凶**，吉的那个在最前面（六二征吉；九三、上六征凶）。**早了不许有为（初九），晚了就是凶。**

**② 孚 ＝ 时机 × 程序，且必须在改命之前到位。** **两个来源缺一不可：卦辞给"巳日"（时机），九三给"三就"（程序）；九四才允许"有孚改命"。**

**③ 收尾的标准是"三层"，不是"全员"。** **大人虎变（炳）、君子豹变（蔚）、小人革面（顺以从君）——三层同时成立即为成功。** 与师卦上六合读：**宽于人心，严于人事。**

### 3. ⚠️ "被相信"是一个独立变量：困（47）与革（49）的两条"信"律

本批四卦里，**困与革各给了一条关于"信任"的硬律，合起来构成本库一条新通则**：

| 卦 | 经文 | 机制 | 处方 |
|---|---|---|---|
| **困 47** | **有言不信**；彖传"**尚口乃穷也**" | **失势时，同一句话的可信度被打折，折扣与内容无关** | **闭口；把话换成可验证的动作** |
| **革 49** | **巳日乃孚**；彖传"**革而信之**" | **时机未到时，方案再对也无人相信** | **自缚待时；等"巳日"** |

> **⚠️ 通则（建议入库）："被相信"不是内容问题，是"势位 × 时机"的函数。**
> **势位低 → 困：不要说（有言不信）。**
> **时机未到 → 革：不要改（巳日乃孚）。**
> **⚠️ 两卦都不否认你是对的；它们否认的是"对"能够单独产生效果。**

**而革卦进一步给出了"孚"的生产方式**，这是困卦没有的：**巳日（时机）× 三就（程序）→ 有孚 → 改命**。**加上九五"大人虎变 → 未占有孚"（自身可见的改变是最强的孚源），革卦是全库唯一一张"信任生成图"。**

### 4. ⚠️ 结构增量：三条

**（1）"不动"的第三型：约束型（本卡新增）。** 本库原有两型（乾初九蓄力型"潜"、坎六三止损型"停"）。**革初九是第三型："缚"——力已备、判断已清，纯粹因为时机未到而主动自缚**（象传"不可以有为也"）。**⚠️ 它是三型中最难执行的一种，因为你手上什么都齐了。**

**（2）"不当位的第三种救法：有孚"（本卡新增）。** 累计四种：**① 得中**（坎九二、困九二）；**② 有与**（困九四"虽不当位，有与也"→ 终吉）；**③ ⚠️ 有孚**（革九四"有孚改命"，象传"信志也"→ 悔亡…吉）；**④ 居中主事而不越位**（师九二）。

**⚠️ 而②③同在"兑在上的九四"这个席位上**（困、革上卦皆兑，九四必不当位）：
> **口径（建议入库）：兑在上的九四是本库"靠人际资源救不当位"的固定席位。** 它结构上注定名不正，两条出路都不是位置性的——**"还有人跟你一起"（有与）与"人们信你的志"（有孚）。**

**（3）"乘刚"的性质由卦决定（本卡修正一条读法）。** 革六二**乘初九之刚而判"征吉"**，是又一个"乘刚而吉"的案例。把本批三例排开：

| 卦 | 乘刚之爻 | 脚下那个刚是什么 | 结果 |
|---|---|---|---|
| 困 47 | 六三乘九二（象传"**乘刚也**"） | **顶你的硬物**（石与蒺藜） | **凶** |
| **革 49** | **六二乘初九** | **⚠️ 托你的自我约束**（巩用黄牛之革） | **⚠️ 征吉** |
| 井 48 | 上六乘九五 | **托你的整口井**（刚中之核） | **元吉**（条件：勿幕、有孚） |

> **⚠️ 口径（建议入库）：不要一看到"乘刚"就判为不利。要问一句"脚下那个刚，是在顶你还是在托你"。**
> **顶你 → 撤（困六三）。托你 → 用（革六二发动、井上六敞开）。**

### 5. 与已成卡各卦的衔接一览

| 衔接 | 机制一句话 |
|---|---|
| **革 ↔ 鼎（50）** | **全库唯一直接讲组织变革的一对**：革除旧／鼎立新；**革五爻当位（除旧要名分），鼎仅一爻当位（立新没有名分）**；只革不鼎→鼎九四折足，只鼎不革→革彖传"二女同居" |
| **革 ↔ 井（48）** | **序卦"井道不可不革"**：井处理"用"（还能淘就不要革），革处理"换"（彖传门槛：水火相息、其志不相得） |
| **革 ↔ 困（47）** | **两条"信"律**：困"有言不信"（势位低不要说）／革"巳日乃孚"（时机未到不要改）；**且两卦"征"字都在同卦内反转，证明"征"不自带吉凶** |
| **革 ↔ 咸（31）** | **同一个上兑，下卦一换就分成两卦**：咸（下艮·少男）彖传"二气感应以相与"＝**其志相得**；革（下离·中女）彖传"**其志不相得**"。**卦义不由单一卦素决定，由组合决定** |
| **革 ↔ 明夷（36）** | **第五爻的正反指令**：明夷六五象传"**利用晦也**"（收光）／革九五象传"**其文炳也**"（显赫）。**同为关键位，一藏一显，差别只在环境**；且明夷九三"不可疾贞"与革九三"征凶"是同一条"刚得势不可急"的律 |
| **革 ↔ 离（30）** | **"文明以说"是含离之卦彖传"文明"语序的第三种**（同人"文明以健"／大有"刚健而文明"／革"文明以说"）——⚠️ 这是彖传语序的观察，**与大有卡那条已废止的"离＝辨"律无关**（见大有卡该行）；**且离上九"只除首恶绝不扩大"与革上六"只到革面不深究"是同一条收尾律** |
| **革 ↔ 师（7）** | **变革收尾的完整口径**：革上六"小人革面"（宽于人心）＋ 师上六"小人勿用，必乱邦也"（严于人事）。**只取一半都会出事**；且师九二"不越位"与革九四"改命"是"不当位"的两种相反用法 |
| **革 ↔ 大畜（26）** | **同族的"牛＋束具"意象，方向相反**：大畜六四"童牛之牿"（约束别人，元吉）／革初九"巩用黄牛之革"（约束自己，无判词）；**且大畜是"以止养健"（为了后面发），革初九是"以缚待时"（为了不毁孚）** |
| **革 ↔ 兑（58）** | **上兑决定革的姿态**：彖传"**文明以说**"——**变革要让人心悦，不能靠压**。而兑卦铁律"悦必须刚中而柔外，内核必须刚"正是革九五"大人虎变"的底：**⚠️ 让人悦，不等于让人舒服；核心必须自己先硬起来改** |
