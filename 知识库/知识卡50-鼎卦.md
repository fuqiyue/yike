# 知识卡 50 · 鼎卦（火风鼎）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传/系辞传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传（入）："**革物者莫若鼎**，故受之以鼎。"——**要把东西真正变过来，没有比鼎更管用的**，所以革（49）之后接鼎。
> 序卦传（出）："主器者莫若长子，故受之以震。"——**主管这件重器的，莫过于长子**，所以鼎之后接震（51，本库已成卡）。⚠️ **这一进一出把鼎的位置说得极准：革负责"拆"，鼎负责"立"，震负责"谁来主"。**
> ⚠️ **本卦与革（49）是全库唯一一对直接讲组织变革的卦，必须合读**：**革＝除旧，鼎＝立新。**
> ⚠️⚠️ **本卦最重要的结构性事实（也是本卡对全库最大的贡献）**：**鼎卦六爻中只有九三一爻当位——是本库当位最少的卦；而革卦五爻当位。5 : 1 的反差，正是"破旧"与"立新"的结构差异。** **这解释了为什么鼎卦的主线是"折足覆餗"的风险，而不是意气风发。**（详见第四节第 1 条）
> ⚠️ **本卦是全库唯一一卦，彖传开篇直接说它是个"象"**："**鼎，象也。**" 全卦义理都从器物形制推出：趾、实、耳、足、铉，六爻各就其位。
> ⚠️ **系辞下传对九四有专门解说**："德薄而位尊，知小而谋大，力少而任重，鲜不及矣……**言不胜其任也**。" 这是全书对"承担不起"最完整的一次判语。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 鼎 · 第五十卦 |
| **卦象** | 上离（火／明）下巽（风／木／入），称"火风鼎"。<br>**大象传写作"木上有火"——木在下、火在上，这就是灶。** ⚠️ **此处巽必须取"木"义**：彖传"**以木巽火，亨饪也**"——**把木送进火里，用来烹煮。**<br>**⚠️ 注意一个关键区别：离在鼎卦里是"火"（热源），不是"明"（光源）。** 这一条决定了鼎卦的纲领为什么不谈"辨"（见第四节第 5 条）。<br>**六爻自下而上：阴、阳、阳｜阳、阴、阳。**<br>按本库结构律逐爻核对：<br>· **巽在下 → 初六不当位、九二不当位（得中）、九三当位**（规格第 4 节危险位置之一：**巽在下＝柔在底下，易犯犹豫与滥让**）；<br>· **离在上 → 九四、六五、上九三爻全部不当位**（规格第 4 节危险位置之一：**离在上＝光在你身外，名不正**）。<br>**⚠️ 全卦仅九三一爻当位——本库当位最少的卦。** 用本库已核定的机械公式复核：**当位数 ＝ 3 ＋ d(下卦) − d(上卦)**，其中 **d＝离 3｜乾 震 艮 2｜坤 巽 兑 1｜坎 0**。**鼎＝3 ＋ 1(巽) − 3(离) ＝ 1** ✓（革＝3 ＋ 3 − 1 ＝ 5 ✓）。<br>**⚠️ 乘刚一处：六五乘九四**（离在上必然）。**而九四正是"折足"那一爻——耳与铉恰好压在断掉的足之上**，这个结构关系是六五全部义理的来源（见六五）。 |
| **⚠️ 鼎的形制与六爻的对应（本卦的读法总纲）** | 彖传说"**鼎，象也**"，所以先把器物摆清楚。**鼎＝三足、圆腹、两耳，耳中横穿"铉"以供提举。** 六爻自下而上正好是一具鼎：<br>| 爻 | 部件 | 经文 | 状态 |<br>|---|---|---|---|<br>| 初六 | **趾（足底）** | 鼎**颠趾**，出否 | **主动倒过来，倒空陈货** |<br>| 九二 | **腹（容量）** | 鼎**有实** | **装满了** |<br>| 九三 | **耳（提举处）** | 鼎**耳革**，其行塞 | **⚠️ 把手坏了，提不起来** |<br>| 九四 | **足（承重）** | 鼎**折足**，覆公餗 | **⚠️ 承重断裂，全部倾覆** |<br>| 六五 | **耳 ＋ 铉** | 鼎**黄耳金铉** | **提举系统完好且居中** |<br>| 上九 | **铉（最上的横杠）** | 鼎**玉铉** | **刚柔有节** |<br>**⚠️ 三条一望即明的读法（全卦的骨架）**：<br>**① 全卦讲的是同一件事的两半：能不能"装"（腹与足＝承载），能不能"提"（耳与铉＝交接）。**<br>**② 出事的地方全在器具，不在食物**：食物一直是好的（九三"雉膏"、九四"公餗"），**坏掉的是耳与足**。<br>**③ ⚠️ "足"出现了两次，且性质相反**：**初六"颠趾"是主动把鼎倒过来（无咎），九四"折足"是被动断裂（凶）。** **同一个部件，主动倾倒无咎，被动断裂是凶**——这是本批四卦一条通则的实例（见第四节第 6 条）。 |
| **领域定义** | **立新：把新的东西真正立起来、装得住、提得动。** 具体：<br>① **新业务／新团队／新制度刚立起来，要让它真的跑起来**——不是还要不要做的问题，是**靠什么承载**的问题；<br>② **你被托付了一件超出现有能力或资源的事**——⚠️ **这是本卦的核心场景，系辞判语"力少而任重"直接对准它**；<br>③ **把原料变成成品的转化环节**——想法→交付、研发→产品、新人→骨干（彖传"**亨饪**"＝烹煮，"**大亨以养圣贤**"）；<br>④ **交接与提举**——一件事由谁负责、通过什么把手交出去、别人能不能接手（九三"耳革"、六五"金铉"）；<br>⑤ **承载力的评估与调整**——人、钱、时间够不够扛这个担子；不够时怎么减载（九四）；<br>⑥ **清理旧存货以装新东西**（初六"出否"）——新东西要用旧容器（旧团队、旧预算、旧代码、旧客户名单）时的第一步；<br>⑦ **组织的"重器"确立**——什么是这个组织不可动摇的那一件（鼎为国之重器，大象传"**正位凝命**"）。<br>凡是"**新的东西已经该立了，问题是它能不能被装住、被提起来、被交出去**"，都落在鼎卦。 |
| **不归本卦的情况** | ① **要除旧、要改制度** → **革（49）**。⚠️ **必须分清动作**：**革是拆，鼎是立。** **只革不鼎 → 拆完没有承载器，终点就是本卦九四"折足覆餗"；只鼎不革 → 新东西装在旧结构里，回到革彖传"二女同居，其志不相得"。**<br>② **取用与共享既有的、不会枯的资源** → **井（48）**。**井是"取"（把下面的提上来），鼎是"烹"（把生的变成熟的）。** 井不增不减，**鼎有明确的容量上限与承重上限**。<br>③ **在积蓄、涵养，还没到动手做大事的时候** → **大畜（26）**。⚠️ **大畜是鼎九四的预防措施**：大畜卦辞的三级台阶"**利贞 → 不家食吉 → 利涉大川**"顺序不可跳，**跳级就是鼎九四**（见九四专项）。<br>④ **东西已经多到需要分辨与分配** → **大有（14）**。**大有讲"多了怎么办"（减损自己），鼎讲"新东西怎么承载"。** ⚠️ **但两卦九四是同一个席位，答案互补**（见第四节第 3 条）。<br>⑤ **资源耗尽、动不了** → **困（47）**。**困中不许启新局（卦辞无"元"）；鼎卦辞给"元"，是明确许可启动的卦。**<br>⑥ **谁来主这件重器** → **震（51）**。序卦传"主器者莫若长子，故受之以震"：**鼎负责把器立起来，震负责谁来主它。** |
| **"鼎"字本义** | **本义是三足两耳的烹器**，用于烹饪与祭祀；因祭祀之用而成为**国之重器**，进而引申为**政权、名位、承载**。<br>**⚠️ 三层含义在本卦全部用到**：<br>· **烹器（转化）**——彖传"以木巽火，**亨饪**也"：把生的变成熟的，这是鼎的功能；<br>· **重器（名位）**——大象传"**正位凝命**"：鼎所在之处即名位所在，鼎不可轻动；<br>· **⚠️ 承载（有上限）**——九四"**折足覆餗**"：**鼎的一切都建立在"足撑得住"这个前提上。这是全卦唯一的凶。**<br>**⚠️ 与"革"字的对照**：**革（皮）是柔而韧的，鼎（金）是刚而重的。** **除旧用柔韧（革彖传"文明以说"），立新用重器（鼎大象传"正位凝命"）。** |
| **卦辞原文** | 鼎：元吉，亨。 |
| **⚠️ 版本说明** | **"元吉，亨"⚠️ 版本待核**：通行本作"元吉，亨"，**但彖传结句作"是以元亨"**，因此历来有以"吉"字为衍文、当读作"**鼎：元亨**"者。**本卡照通行本录"元吉，亨"，并在义理上以彖传"元亨"为准**（两读的差别不影响本卦任何一条操作口径）。 |
| **⚠️⚠️ 卦辞的关键结构（与全卦结构互证）** | **有"元"、有"亨"（并"吉"），⚠️ 无"利"、无"贞"。**<br>**① 有"元"——这是一次开创级的启动。** 对照困（47）卦辞**无元**（困中不许启新局）：**鼎是明确许可你启动的卦。**<br>**② 有"亨"——它是通的。** 彖传给的理由是"**柔进而上行，得中而应乎刚**"（六五柔居尊而得中）。<br>**③ ⚠️ 缺"利"——天道不许诺"立新"会给你带来好处。** 与大有（14，只给"元亨"）完全同型。<br>**④ ⚠️ 缺"贞"——天道也不承认新东西自动正当。**<br>**⚠️ 而这一条与全卦结构严丝合缝，是本卡最漂亮的一次互证**：<br>> **卦辞不给"贞"（不承认新事物自动正当）；而结构上，鼎卦六爻只有一爻当位（几乎没有一处"正"）。**
> **⚠️ 经文层的沉默与结构层的事实，说的是同一件事：新立起来的东西，在旧秩序里本来就没有名分。**<br>**⑤ 于是大象传立刻补上"正位凝命"——"正"字自己出现在纲领里。**<br>**⚠️ 这是本库第二例"卦辞缺德、大象传补"**：<br>· **大有 14**：卦辞"元亨"缺利贞 → 大象传"**遏恶扬善，顺天休命**"补上正当性与利的归属；<br>· **⚠️ 鼎 50**：卦辞"元吉，亨"缺利贞 → 大象传"**正位凝命**"补上"正"。<br>**⚠️ 而鼎卦还多给了一条路：卦辞缺的"利贞"二字，原封不动出现在卦主六五的爻辞里——"鼎黄耳金铉，利贞"。** **卦辞缺的两德，落在卦主那一爻上。** 本库由此可提一条读法：**卦辞里缺的字，往往在大象传或卦主爻里被补回来；找到它被补在哪儿，就找到了这一卦的操作重心。** |
| **卦辞现代解** | **元**——这是一次**根本性的、开创级的**立新（不是修补）。<br>**吉／亨**——它是通的，值得做。<br>**⚠️ 然后就没有了。** 没有告诉你会得利（**立新不许诺好处**），没有告诉你它是正当的（**新东西的正当性要靠"正位凝命"自己去挣**）。 |
| **彖传** | 鼎，象也。以木巽火，亨饪也。圣人亨以享上帝，而大亨以养圣贤。巽而耳目聪明，柔进而上行，得中而应乎刚，是以元亨。 |
| **⚠️ 彖传要点** | ① **⚠️ 鼎，象也**——**全书唯一一处彖传开篇即说"这一卦是个象"。** **鼎卦的全部义理从器物形制推出**，所以读鼎卦必须先把趾、腹、耳、足、铉摆清楚（见上表）。<br>② **以木巽火，亨饪也**——**把木送进火里，这是烹煮。** ⚠️ **"亨"读"烹"。鼎的功能是转化：生的变熟的、原料变成品。** **这也确定了离在本卦取"火"义（热源）而非"明"义（光源）。**<br>③ **⚠️ 圣人亨以享上帝，而大亨以养圣贤**——**小烹用于祭天，大烹用于养贤。**<br>**⚠️ "养"字把本库三卦串起来了**：**大畜 26"不家食，吉"（彖传"**养贤**也"）／井 48"井**养**而不穷也"／鼎 50"大亨以**养**圣贤"。**<br>**三卦分工极清楚**：**大畜管"养贤的资源与资格"（先畜其德、被供养、才做大事）；井管"取（不竭的水源）"；鼎管"转化（把生的煮成能养人的）"。** ⚠️ **一条完整的链：畜（攒）→ 井（取）→ 鼎（烹）→ 养人。**<br>④ **⚠️ 巽而耳目聪明**——**因为顺（巽），所以耳目聪明。** ⚠️ **注意"耳"字在这里第二次出现（鼎有耳，人有耳目）**：<br>**鼎的"耳"是被提举的接口，人的"耳目"是接收反馈的通道。** **合起来是一条：新事物能不能被提起来，取决于它有没有"耳"（可被把握的接口）＋ 你有没有"耳目聪明"（听得见反馈）。** **⚠️ 而"聪明"的前提是"巽"（顺）——不顺则听不见。**<br>⑤ **⚠️ 柔进而上行，得中而应乎刚，是以元亨**——**"元亨"的理由是六五：柔向上走到尊位、得中、并与刚相应。**<br>**⚠️ 与大有彖传同一句法**：大有"**柔得尊位大中，而上下应之，曰大有**"；鼎"**柔进而上行，得中而应乎刚，是以元亨**"。<br>**本库口径由此得到第二例实证**：**《周易》凡讲"大局面能够成立"，核心多是"柔居尊而得中"。核心一硬，"应"就没有了。**（大有卡已立此条，鼎卦为第二例。） |
| **大象传（行动纲领）** | 木上有火，鼎。君子以正位凝命。 |
| **⚠️⚠️ "正位凝命"解（全卦最高原则）** | **正位**＝端正它的位置；**凝命**＝"凝"是凝固、聚结、使之定而不散，"命"是所受之命（使命、名分、委任）。**"凝命"＝把所受的使命凝定下来，不再摇摆。**<br>**⚠️ 为什么鼎的纲领是这四个字——三层机制**：<br>**① 物理层：鼎是重器，重器最怕不稳。** 三足不正则倾，鼎倾则"覆公餗"。**所以"正位"首先是一句关于稳定的物理要求。**<br>**② 结构层：鼎卦六爻只有一爻当位——它是全库最"不正"的卦。** ⚠️ **正因为结构上几乎无一处正，纲领才必须以"正位"开头：这不是描述，是命令。**<br>**③ 名分层：新立的东西"命"是散的。** 它归谁、算什么、边界在哪、要多久——**这些不明确，热情撑不过两个季度。所以要"凝"：把使命固定下来。**<br>**⚠️ 落到现代的四条操作（本卦最实用的一节）**：<br>· **⚠️ 新东西立起来的第一件事是把位置摆正**：它在组织里算什么、归谁管、和谁并列、边界在哪、谁有权决定它的存废。**位置不清的新业务，早晚是九四"折足"。**<br>· **⚠️ 把使命"凝"住**：**一句话说清它是干什么的，然后不再改。** **"凝"的反面是"每季度换一个定位"——那不是灵活，那是命散了。**<br>· **不要靠热情支撑新事物，要靠"位"与"命"支撑。** **热情会耗尽，位与命是结构性的。**<br>· **⚠️ 三足要正（义理层推演，取鼎之形制）**：**新事物至少要有三条腿撑着——负责人、资源、真实需求（或：人、钱、客户）。缺一条就是"折足"，而且不是"慢一点"，是"覆"。**<br>**⚠️ 这条纲领不含"辨"字，是本库一条通则的重要例外**（见第四节第 5 条）。 |
| **总铁律** | ① **先倒空再装**（初六"鼎颠趾，出否"，象传"**未悖也**"——把鼎倒过来并不违常理）；<br>② **⚠️ 装满了就要更慎**（九二"鼎有实"，象传"**慎所之也**"）——**九二不慎，直通九四"覆公餗"**；<br>③ **⚠️ 必须有"耳"**（九三"鼎耳革，其行塞"）——**没有可交接的把手，东西再好也"不食"**；<br>④ **⚠️ 承重不足必须减载**（九四"鼎折足，覆公餗，**凶**"；系辞"**言不胜其任也**"）——**这是全卦唯一的凶**；<br>⑤ **救鼎不在足，在耳与铉**（六五"黄耳金铉"压在九四折足之上）；<br>⑥ **"实"的实质是"中"，不是量**（六五象传"**中以为实也**"）；<br>⑦ **⚠️ 到顶的答案是"节"，不是更硬也不是放软**（上九"玉铉，大吉，无不利"，象传"**刚柔节也**"）；<br>⑧ **必须有革在前**（序卦传"革物者莫若鼎"）——**没除旧就立新，等于把新东西装进没倒空的鼎**。 |

| 字段 | 内容 |

| **爻辞** | 鼎颠趾，出否，得妾以其子，无咎。 |
| **象传** | 鼎颠趾，未悖也。出否，以从贵也。 |
| **位属性** | 阴爻居阳位，**不当位**；失中；**居巽之最下、全卦最底**。按本库结构律，巽在下 → 初六必然不当位（规格第 4 节："巽在下＝柔在底下，易犯犹豫与滥让"）。 |
| **判词 → 行动语义** | **无咎** → **按本库口径，"无咎"＝无灾，不等于吉利，常是"善补过才没灾"。行动语义：把鼎倒过来，把陈货倒干净；并且接纳来源不体面但真正有用的东西。** |
| **关键词解** | **颠趾**——"颠"是倒转、倾覆；"趾"是鼎足。**把鼎足朝上倒过来**，即**整个鼎翻过来。**<br>**出否**——"否"读 pǐ，**恶物、腐败污秽之物**。**把里面的陈腐之物倒出来。**<br>**得妾以其子**——**得到妾，是因为她有子。** ⚠️ **经文以古代家庭制度取象，本库照录，不作价值判断。** 义理层读法见下。<br>**无咎**——**没有灾祸。** |
| **⚠️ 本爻最反直觉的一点：把鼎倒过来，象传说"未悖也"** | **鼎是重器，把重器整个倒过来，是最不敬、最不稳、最难看的动作。** ⚠️ **而象传偏偏说"未悖也"——并不违背常理。**<br>**理由在下一句："出否，以从贵也"——倒空是为了趋从"贵"（迎接好的、新的）。**<br>> **⚠️ 口径：立新的第一个动作是难看的。** **倒空这件事没有体面的做法，而《周易》明确为它背书："未悖也"。**<br>**落到现代**：**新业务要用旧的容器（旧团队、旧预算、旧客户名单、旧代码库、旧品牌）时，第一件事是把里面的陈货倒出去**——裁撤、下架、清库、断掉旧承诺、公开承认旧做法作废。**这个动作一定会被说成"折腾""不稳重""动摇根基"。⚠️ 象传替它挡了这一句。**<br>**⚠️ 与革初九的对照（本卦入口 vs 上一卦入口）**：**革初九"巩用黄牛之革"（象传"不可以有为也"）——除旧的第一步是"绑住不动"；鼎初六"鼎颠趾，出否"——立新的第一步是"倒空"。** **⚠️ 一个从"什么都不做"开始，一个从"先清空"开始。两卦的入口姿态正好相反，因为一个在等人心，一个在腾地方。** |
| **⚠️ "得妾以其子"的义理层读法** | **⚠️ 本库不采信也不复述任何以出身论人的价值判断，仅取其结构含义。**<br>**结构含义**：**从一个地位不高、不被看重的来源，得到了真正有价值的东西（"子"＝后继、成果）。** 象传的落点是"**以从贵也**"——**⚠️ "贵"不在来源，在能不能出成果。**<br>**落到现代（极实用）**：**新事物的关键资源，往往来自组织里最不被看重的地方**——边缘团队、小客户、被淘汰的老项目、非正式渠道、一个职级很低但真懂的人。**倒空旧货（出否）之后，装进来的往往就是这类东西。**<br>**⚠️ 而这一条同时是一条警告：如果你还在按"来源是否体面"筛选资源，鼎就装不满。** |
| **识别信号** | ① 你要立一件新的东西，**而它要用一个已经装着旧东西的容器**（旧团队、旧预算、旧品牌、旧系统）；② **你打算在旧存货上直接加新东西**（不清库就上新）；③ 你已经知道该倒掉什么，**但那个动作会很难看、会被说成折腾**；④ 手边有一个来源不体面但确实有用的资源，**你因为"来源"在犹豫**。 |
| **该做** | ① **倒空**——先"出否"，再装；② **接受这个动作难看**（象传"未悖也"已经为它背书）；③ **按"能不能出成果"筛资源，不按来源筛**（象传"以从贵也"）；④ **一次倒干净**，不要留一半陈货。 |
| **不该做** | ① **不出否就装**——**旧货与新货混在一鼎里，就是革彖传"二女同居，其志不相得"**；② 因为怕难看而只做局部清理；③ 因为出身／来源而拒绝真正有用的资源。 |
| **与井卦初六的对照（本卡最佳的一组初爻对照）** | **两卦下卦同为巽，初六位属性完全同构（阴居阳位、不当位、失中、巽之最下），而且两爻讲的都是"容器里有脏东西"**：<br>· **井 48 初六"井泥不食，旧井无禽"**，象传"**时舍也**"——**淤了，而且没有淘：无判词，被时代舍弃**；<br>· **鼎 50 初六"鼎颠趾，出否"**，象传"**未悖也**""**以从贵也**"——**主动倒空了：无咎。**<br>**⚠️ 同一个位置、同一种问题，一个停在那儿，一个动手倒了。判词的差别（无判词·时舍 → 无咎）全部来自那个动作。**<br>**本库口径**：**容器脏了不是问题，不倒才是问题。** |

### 九二 · 鼎有实

| 字段 | 内容 |
|---|---|
| **爻辞** | 鼎有实，我仇有疾，不我能即，吉。 |
| **象传** | 鼎有实，慎所之也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**；**居巽之中**——下卦的核心之爻。 |
| **判词 → 行动语义** | **吉** → **进／成。⚠️ 这是全卦唯一一个单纯的"吉"字（九三是"终吉"，上九是"大吉"）。行动语义：内容已经装进去了，此时唯一要做的是"慎所之"。** |
| **关键词解** | **鼎有实**——**鼎里有实在的东西**（装满了、有内容了）。<br>**我仇有疾**——"仇"＝**匹、对**（配偶、对应者，亦可作"仇敌"）；"疾"＝**病、毛病、间隙**。**与我相对的那一方有毛病。** ⚠️ **两读并存**：① **仇＝初六**（阴阳相匹），初六不当位而在下，故"有疾"，牵累不到九二；② **仇＝对手**，对手有病，来不了。**本库并列，以"会牵累你的那一方靠不过来"为主读。**<br>**不我能即**——"即"＝**接近、靠近**。**（它）不能靠近我。**<br>**吉**——**吉。** |
| **⚠️ 本爻的要点全在象传："慎所之也"** | **⚠️ 爻辞给了"吉"，象传却完全不谈吉，只给一个字：慎。**<br>"**慎所之**"＝**慎重于所往，对下一步去哪儿要格外小心。**<br>**⚠️ 为什么装满了反而要更慎——因为"翻"的代价变了**：<br>> **空鼎摔了不过是个空鼎；满鼎一翻，就是九四的"覆公餗"。**<br>**⚠️ 这是九二与九四之间一条直接的因果链，而且是经文自己排的：《周易》把"慎"的警告放在"有实"这一爻上，把"覆"的结果放在两爻之后。**<br>**落到现代**：**新业务刚有了内容、刚跑通、刚拿到第一批客户——这一刻最危险的不是没东西，是"有东西了所以想加速"。** 加速的方向如果超出承载力，两步之后就是折足。<br>**⚠️ "我仇有疾，不我能即"落到现代**：**这一阶段的运气成分是"会拖累你的那一方，正好靠不过来"**——竞争对手自顾不暇、旧的牵扯暂时没找上门、以前那个总要插一手的人正忙别的。**《周易》把这写成"吉"的一部分，同时提醒你：这只是"暂时靠不过来"，所以要趁这个窗口"慎所之"，把路走对。** |
| **识别信号** | ① **新东西刚跑通、刚有了实在的内容**；② **你正想趁势加速、扩张、加码**；③ 会拖累你的那一方（对手、旧包袱、爱插手的人）**暂时没顾上你**；④ ⚠️ **你还没有确认下一步的路"撑不撑得住"**。 |
| **该做** | ① **⚠️ 慎所之**——**每走一步之前，先确认承载力（人、钱、时间）能不能撑住这一步**；② **趁"仇有疾"的窗口把路走对，而不是把量做大**；③ **守住"实"**——不要为了扩张把内容掺薄；④ 提前去做九三的活（把"耳"做出来）。 |
| **不该做** | ① **因为有内容了就加速**——**这是通向九四"折足覆餗"的标准路径**；② 让有毛病、有间隙的一方参与承载（"不我能即"是好事，不要主动请回来）；③ 把"暂时没人来拖累"当成"从此没有阻力"。 |
| **⚠️ 与大有九二的对照（同为二位"装载"之爻，一给信心一给警告）** | · **大有 14 九二"大车以载，有攸往，无咎"**，象传"**积中不败也**"——**用大车装载，因为"积中"所以不会倒**；<br>· **鼎 50 九二"鼎有实……吉"**，象传"**慎所之也**"——**装满了，所以要慎于所往。**<br>**⚠️ 两爻位属性完全同构（阳居二位、不当位、得中、本卦装载之爻），判语方向相反：一个说"不败"，一个说"要慎"。**<br>**差别在下卦（承载器的材质）**：<br>> **大有下乾（天／健）——车是刚健的，所以"积中不败"；**
> **⚠️ 鼎下巽（木）——鼎足是木上之器、三足细而高，所以"慎所之"。**<br>**本库口径**：**"能装多少"要看承载器是什么做的。** 同样装满，**乾造的车可以放心走，巽木架起来的鼎必须小心走。** |

### 九三 · 鼎耳革，其行塞

#### ⚠️ 本爻是全卦唯一当位之爻，却是"提不起来"的一爻——本卦最深的一个悖论

| 字段 | 内容 |
|---|---|
| **爻辞** | 鼎耳革，其行塞，雉膏不食，方雨亏悔，终吉。 |
| **象传** | 鼎耳革，失其义也。 |
| **位属性** | 阳爻居阳位，**当位**；失中；**居巽之顶、下卦之极**。按本库结构律，巽在下 → 九三必然当位。<br>**⚠️ 全卦六爻只有这一爻当位。** |
| **判词 → 行动语义** | **终吉**（前置"亏悔"） → **最终得吉，但必须经过一段"悔在减少"的过程。行动语义：耳坏了就不要硬提；先把耳修好，同时等"雨"。** |
| **关键词解** | **鼎耳革**——**鼎的耳发生了变化（坏了、脱落了、形制变了）。** ⚠️ **注意"革"字——上一卦的卦名出现在这里，而在这里它是一个故障**（见下专项）。<br>**其行塞**——"塞"是堵塞、不通。**因为耳坏了，铉穿不进去，鼎提不起来，所以走不动。**<br>**雉膏不食**——"雉"是野鸡，"膏"是肥美之肉。**鼎里是美味，却吃不到。** ⚠️ **食物没问题，器具有问题。**<br>**方雨亏悔**——"方"＝将要、正当；"雨"＝降雨，取**阴阳和洽**之象；"亏"＝减损。**⚠️ 等到阴阳和洽（雨降）之时，悔就减少了。** **注意：是"亏悔"（减少悔），不是"无悔"。**<br>**终吉**——**最终得吉。** |
| **⚠️⚠️ 本爻的核心悖论：唯一当位的爻，偏偏动不了** | **事实层**：**鼎卦六爻只有九三当位（名正言顺），而它是"其行塞"（走不动）的那一爻。**<br>**机制（义理层）**：**"耳"是鼎唯一能被提起来的地方。耳一坏，鼎再正、再满、再好，也提不起来。**<br>> **⚠️ 口径（本爻最重要的一条）：新事物失败最隐蔽的一种方式，不是它不好，是它"没有把手"——没有任何人能把它提起来、接过去、交出去。**<br>**⚠️ 落到现代的四种"鼎耳革"（极实用）**：<br>· **只有创始那几个人知道怎么运作**——文档没有、流程在人脑子里；<br>· **客户／上级只认某一个人**——那个人不在，整件事就停；<br>· **交接接口坏了**——想交出去，没人接得住，或接了也提不动；<br>· **对外说不清它是什么**——**⚠️ "说不清"就是没有耳：别人无从下手把它拿起来。**<br>**结果就是"雉膏不食"：东西是好东西，但没人吃得到。**<br>**⚠️ 象传的判语极重："失其义也"**——**失去了它应有的功用与义理。** **一口提不起来的鼎，已经不是鼎了。** |
| **⚠️⚠️ 与井卦九三的对照（本卡最强的一组结构发现）** | **⚠️ 井（48）与鼎（50）下卦同为巽，因此两卦的九三位属性完全同构（阳居三位、当位、失中、巽之顶）。而两爻的爻辞都用了"不食"二字**：<br>| | **井 48 九三** | **鼎 50 九三** |<br>|---|---|---|<br>| 爻辞 | **井渫不食**，为我心恻，可用汲，王明，并受其福 | **鼎耳革，其行塞，雉膏不食**，方雨亏悔，终吉 |<br>| 东西的状态 | **水已淘净，客观可饮** | **雉膏是美味，客观可食** |<br>| 为什么"不食" | **⚠️ 没人来（外部通道未建）** | **⚠️ 提不起来（内部把手坏了）** |<br>| 象传 | 行恻也；**求王明**，受福也 | **失其义也** |<br>| 解药 | **⚠️ "求"**——主动去找有识别力的人 | **⚠️ 修耳 ＋ 待雨**——把接口做出来，等阴阳和洽 |<br>| 上卦（头上是什么） | **坎（水）**——三爻全当位，全是通路 | **离（火）**——三爻全不当位 |<br>| 判词 | 无判词（承认心恻，不判有咎） | **终吉**（要先经过"亏悔"） |<br>> **⚠️ 口径（建议入库）：巽在下的九三，是本库"有好东西而不被用"的固定席位。**
> **两卦都用"不食"二字，但病灶不同：井病在"没人来"，鼎病在"提不起来"。**<br>**⚠️ 而这给本库的"不被用"判据补上了第三条。** 累计三条（三卦对照）：<br>| 你头上是什么 | 卦 | 病灶 | 处方 |<br>|---|---|---|---|<br>| **土**（上坤，压死） | **明夷 36** | **发亮会招祸** | **用晦而明**（收光） |<br>| **水**（上坎，全通路） | **井 48 九三** | **只是没人知道** | **求王明**（去建通道） |<br>| **⚠️ 火**（上离，全不当位） | **⚠️ 鼎 50 九三** | **⚠️ 提不起来／交不出去** | **⚠️ 修耳 ＋ 待雨**（做接口，等条件和洽） |<br>**⚠️ 一句话判据：头上是土就收光，是水就去求，是火就先做把手、并等雨。** |
| **⚠️ "鼎耳革"：一个字在两卦里的正反用法** | **⚠️ "革"是上一卦的卦名，而它在鼎卦里唯一的一次出现是负面的（耳坏了）。**<br>· **革 49**：**"革"是要做的事**（卦辞四德齐全，"天地革而四时成"）；<br>· **鼎 50 九三**：**"耳革"（耳变了）是要修的病**（象传"失其义也"）。<br>> **⚠️ 口径：除旧阶段的美德，到了立新阶段会变成故障。**
> **变（革）用在制度上是"改命"，用在接口上就是"耳革"——⚠️ 新事物最不该反复变的，恰恰是别人抓它的那个把手。**<br>**落到现代**：**变革期可以改一切，但一旦进入"立新"，就必须把"别人怎么找到你、怎么接手你、你归谁管"这几件事固定下来**——这正是大象传"**凝命**"的具体内容。**接口反复变，等于永远提不起来。** |
| **⚠️ "方雨亏悔"的实操含义** | "**雨**"取**阴阳和洽**之象：**上下、内外、供需两边的意愿对上了。**<br>**落到现代**：**等到有人愿意接手、等到需求侧与供给侧对上、等到上下的意愿一致。**<br>**⚠️ 两条限定必须说清**：<br>· **⚠️ 经文只承诺"亏悔"（悔减少），不承诺"无悔"**——**这一段的损失是真实发生的（雉膏确实凉了一段时间）**；<br>· **⚠️ 但结局是"终吉"**——**只要不硬提、把耳修好，最终是吉的。**<br>**⚠️ "等雨"不是被动等待，因为它和"修耳"是同时进行的两件事**：**等的是外部条件，修的是内部接口。只等不修，雨来了你还是提不起来。** |
| **识别信号** | ① **东西确实好、位置也正**（你走完了九二，内容装满了）；② **⚠️ 但它动不了、交不出去、没人接得住**；③ 只有你（或极少数人）知道它怎么运作；④ 对外说不清它是什么；⑤ **你正想"硬提一把"**——⚠️ **这一条是最危险的信号，硬提直通九四"折足"。** |
| **该做** | ① **⚠️ 修耳**——把可交接的接口做出来：文档化、流程化、培养能接手的人、把对外的说法固定下来（呼应大象传"凝命"、井六四"甃"）；② **等雨**——等外部意愿对上，接受这一段有"悔"；③ **把"耳"固定下来之后不再改**（"耳革"就是接口反复变）。 |
| **不该做** | ① **⚠️ 硬提**——**耳坏了硬提，鼎会从足上断（→ 九四"折足覆餗"）。这是本卦最短的一条死路**；② 因为"我位置是正的、东西是好的"就认为不必修接口（⚠️ **本爻恰恰是"当位而行塞"**）；③ 只等不修。 |
| **与井六四"井甃"的呼应** | **井六四"井甃，无咎"**，象传"**修井也**"——**只修不取，砌井壁**；**鼎九三的解药也是修（修耳）。**<br>**⚠️ 本库口径由此更清楚：井与鼎两卦，在"东西已经好了但还不能用"的关口，给的都是同一个动作——修结构。** **而两卦都把这个动作的判词压到最低（无咎／终吉），因为它不出成果。** |

### 九四 · 鼎折足，覆公餗

#### ⚠️⚠️ 全卦唯一的凶，也是全书对"承担不起"最完整的一次判语

| 字段 | 内容 |
|---|---|
| **爻辞** | 鼎折足，覆公餗，凶。 |
| **象传** | 覆公餗，信如何也。 |
| **位属性** | 阳爻居阴位，**不当位**；失中；**已入上离**。按本库结构律，离在上 → 九四必然不当位（规格第 4 节危险位置之一："离在上＝光在你身外，名不正"）。 |
| **判词 → 行动语义** | **凶** → **按本库口径，"凶"是《周易》所有结局中最坏的，别不当回事。行动语义：此爻不可入；已在此处，唯一动作是立刻改变"载重 ÷ 承载力"这个比值。** |
| **关键词解** | **折足**——**鼎足断了。** ⚠️ **足是唯一承重的部件。**<br>**覆公餗**——"覆"是倾覆、翻倒；"公"指公家、所奉之上；"餗"是**鼎中的食物**（粥、八珍一类）。**把进献给公的那一鼎食物全翻了。**<br>**⚠️ 注意"公"字：翻掉的不是你自己的饭，是别人托付给你的东西。** 这决定了象传的落点。<br>**凶**——**凶。** |
| **⚠️ 象传"信如何也"** | **字面：（这样）所受的信托该怎么办呢。**<br>**⚠️ 象传的重点不在"食物洒了"，在"你被托付的那份信任怎么办"。** "信"＝**信托、所受之托**。<br>**落到现代**：**承担不起的真正代价不是这件事失败，是"别人托付你"这件事从此不成立了。** ⚠️ **这也是它与井卦"羸其瓶"的差别：瓶破是"未有功也"（白干），折足是"信如何也"（信托崩了）。** |
| **⚠️⚠️ 系辞下传专解（经文级，务必逐字读）** | 系辞下传云：<br>"**子曰：德薄而位尊，知小而谋大，力少而任重，鲜不及矣。**《易》曰：'鼎折足，覆公餗，凶。'**言不胜其任也。**"<br>⚠️ **版本待核**："力少"亦有作"**力小**"者，义同。<br>**⚠️ 系辞给了一句总结："言不胜其任也"——这一爻讲的就是"承担不起所受的任"。** 这是全书对本爻唯一的、也是最权威的一次定性。<br>**⚠️ 三项错配（本卡把它做成诊断表，可直接自查）**：<br>| 系辞判语 | 含义 | 现代形态 | 对应鼎的部件 |<br>|---|---|---|---|<br>| **德薄而位尊** | 德行不足而位置高 | 靠资源、关系、资历、融资坐上了那个位置 | **位不正**（违大象传"正位"） |<br>| **知小而谋大** | 见识不足而图谋大 | 没做过就要做十倍；只见过一种情况就定长期方案 | **装得太满**（九二"有实"而不慎） |<br>| **⚠️ 力少而任重** | 承载力不足而担子重 | 人不够、钱不够、时间不够，却把担子接了 | **⚠️ 足**（本爻"折足"） |<br>| **鲜不及矣** | **很少有不遭祸的** | ⚠️ 这是概率判断，与"凶"配套 | — |<br>**⚠️ 三项的共同结构是"错配"：不是你不好，是你的某一项与担子的量级不匹配。** 而**《周易》把"凶"给了这个错配，不是给你的人品。** |
| **⚠️⚠️ 与大有九四"匪其彭"的对照（本卡最重要的结构发现之一）** | **⚠️ 大有（14）＝上离下乾，鼎（50）＝上离下巽——两卦上卦同为离，所以按结构律，两卦的九四必然都不当位。而这两个九四讲的是同一件事的正反两面**：<br>| | **大有 14 九四** | **鼎 50 九四** |<br>|---|---|---|<br>| 爻辞 | **匪其彭**，无咎 | **鼎折足，覆公餗，凶** |<br>| 动作 | **⚠️ 不要盛满（减载）** | **⚠️ 超载（足断）** |<br>| 判词 | **无咎** | **凶** |<br>| 位属性 | 阳居四位·不当位（离在上必然） | 阳居四位·不当位（离在上必然） |<br>> **⚠️ 口径（建议入库）：离在上的九四，是本库"载重"的固定席位。**
> **它结构上必然不当位（名不正），因此不能靠位置扛事；它唯一正确的动作是"减载"（大有"匪其彭"），超载则"折足覆餗"（鼎九四）。**<br>**⚠️ 而本库大有卡的第②条铁律正是这条的总纲**："**大有所有好结果都来自减损自己**"。**鼎九四是它的反面教材，而且是全书最重的那一个。** |
| **⚠️⚠️ 与大畜（26）的对照：大畜是鼎九四的预防措施** | **⚠️ 系辞三项错配里，前两项（德薄、知小）恰好就是大畜卦要解决的东西**：<br>· **"德薄"** ← 大畜大象传"**多识前言往行，以畜其德**"（**畜其德**治德薄）；<br>· **"知小"** ← 同一句（**多识前言往行**治知小：把别人付过学费的经验变成自己的判断力）；<br>· **"力少而任重"** ← **⚠️ 大畜卦辞的三级台阶治它**："**利贞 → 不家食吉 → 利涉大川**"，本库大畜卡明确标注"**顺序不可跳**"。<br>> **⚠️ 结论（本卡最实用的一条组合口径）：**
> **鼎九四"折足覆餗"，本质上就是"跳过了大畜"。**
> **大畜说：先守正（利贞）→ 再被供养、承担公责（不家食吉）→ 最后才去做需要跨越重大险阻的大事（利涉大川）。**
> **⚠️ 谁在没走完前两级的时候直接去"涉大川"，谁就是鼎九四。** |
| **⚠️ 与困六三的对照（系辞两段合读）** | **系辞下传另有一段解困六三**："**非所困而困焉，名必辱；非所据而据焉，身必危。**"<br>**⚠️ 两段合读，是《周易》对"力与位错配"的两种形态**：<br>· **困六三 —— 靠错了东西**（"据于蒺藜"：去依靠不该依靠的资源）→ **身必危**；<br>· **⚠️ 鼎九四 —— 担错了分量**（"力少而任重"）→ **不胜其任**。<br>**本库口径**：**一个是"抓错了"，一个是"接多了"。⚠️ 两者在现代场景里常常同时出现：担子接多了，于是去抓有刺的资源来补——这正是困六三"既辱且危"的两步组合。** |
| **识别信号（诊断清单）** | ① **⚠️ 你接下的担子明显超出现有的人、钱、时间**，而你打算靠加班、意志、"先干起来再说"补上；② 你坐上这个位置靠的是资源／关系／资历／融资，**而不是这件事本身要求的能力**（德薄而位尊）；③ 你没做过这种规模的事，**却把目标定在没做过的十倍上**（知小而谋大）；④ **你正在硬提一口耳已经坏了的鼎**（从九三硬撑过来）；⑤ **⚠️ 你翻掉的将是别人托付给你的东西**（公餗），不是你自己的。 |
| **该做** | **⚠️ 只有三个动作，且都是改变"载重 ÷ 承载力"这个比值**：<br>① **减载**——把担子砍小（大有九四"匪其彭"）；<br>② **加足**——补人、补钱、补时间，把承载力真的加上去；<br>③ **⚠️ 把担子的一部分交出去**——**这需要"耳"（九三）与"铉"（六五）**：**能交出去的前提是有可交接的把手。**<br>**⚠️ 没有第四种动作。** 意志、承诺、加班、"熬过这一阵"都不改变这个比值。 |
| **不该做** | ① **靠意志硬扛**（力少而任重）；② **靠位置压过去**（德薄而位尊）；③ **把目标再加大以求一次解决**（知小而谋大）；④ ⚠️ **隐瞒承载不足**——**象传的落点是"信如何也"：⚠️ 提前说"扛不住"损伤的是面子，翻了之后损伤的是"别人还能不能托付你"。** |
| **与井卦辞"羸其瓶"的对照** | · **井 48 卦辞"汔至，亦未繘井，**羸其瓶，凶**"**，彖传"**未有功也**""**是以凶也**"——**最后一米，汲器坏了：前面全白干**；<br>· **鼎 50 九四"鼎折足，覆公餗，凶"**，象传"**信如何也**"——**承重断裂，托付之物尽覆：信托崩了。**<br>**⚠️ 两卦唯一的"凶"都在器具侧，不在资源侧**（井里有水、鼎里有餗）。<br>**差别在损失的性质**：**井是"白干"（未有功），鼎是"失信"（信如何）。** **本库口径：器具失效有两种代价——你自己的功白费，和别人对你的托付作废。后者更重。** |

### 六五 · 鼎黄耳金铉（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 鼎黄耳金铉，利贞。 |
| **象传** | 鼎黄耳，中以为实也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位；**上离之中**；**⚠️ 乘九四之刚**（离在上必然）。<br>**它是彖传"柔进而上行，得中而应乎刚，是以元亨"所指之爻——全卦卦主。** |
| **判词 → 行动语义** | **利贞** → **按本库口径，"利"＝可行·有益；"贞"＝守正。行动语义：这条路有益，但必须守正。** <br>**⚠️ 而这两个字正是卦辞里缺的两个字**（卦辞"元吉，亨"无利贞）——**卦辞缺的两德，落在卦主这一爻上。** |
| **关键词解** | **黄**——**中色**，在《周易》里固定代表**中道**（坤六五"黄裳，元吉"、离六二"黄离，元吉"、革初九"黄牛之革"）。<br>**耳**——鼎的提举处。<br>**金**——**坚固的金属。**<br>**铉**——**穿过鼎耳、用以举鼎的横杠。**<br>**"黄耳金铉"＝居中的耳，配上金属的铉——⚠️ 提举系统完好，而且合于中道。** |
| **⚠️ 象传"中以为实也"：一个"实"字的两种内容** | **⚠️ 九二说"鼎有实"（鼎里装的是实物），六五象传说"中以为实"（它装的实质是"中"）。**<br>**⚠️ 同一个"实"字，一个是货，一个是德。**<br>> **⚠️ 口径：承载体系的实质内容，不是它装了多少，是它是否居中。**<br>**落到现代**：**一个新事物真正的"内容"不是它的规模、收入、人数（那是九二的"实"），是它有没有一个不偏的核（六五的"实"）。** **规模是可以掺水的，"中"不行。** |
| **⚠️⚠️ 六五乘九四之刚：本爻全部义理的来源** | **结构事实**：**六五乘九四之刚（离在上必然），而九四正是"鼎折足，覆公餗"那一爻。**<br>**⚠️ 意象因此极其精确：耳与铉（六五），恰好压在断掉的足（九四）之上。**<br>**机制（义理层）**：<br>> **足断了，救这口鼎的唯一希望就在上面——只要"耳"还在、"铉"还能穿进去，鼎就还能被提起来、挪走、修好。**<br>> **⚠️ 口径（本爻最重要的一条）：承载出问题时，解法不在下面，在上面。足已经断了，"再加固足"是不存在的动作；能救它的是"有没有一个合格的把手，让别人把整件事提起来"。**<br>**⚠️ 落到现代（极实用）**：**项目扛不住了，救它的不是让原班人马再加班（修足），而是——**<br>· **有没有一个能把整件事"提起来"的接口**：清晰的现状、可交接的资料、明确的边界；<br>· **有没有一个能提它的人**：一个能接手、能协调、能对上负责的角色（这就是"金铉"）；<br>· **⚠️ 而这个把手必须"黄"（居中）**：**它不能偏向任何一方，否则提起来就会歪，歪了还是覆。**<br>**⚠️ 这也正是九三"鼎耳革"的反面**：**九三耳坏 → 其行塞（动不了）；六五黄耳金铉 → 可提、可行、可救。** **两爻合读是一条完整的因果：接口坏了就动不了，接口好了连断足的鼎都能救。** |
| **⚠️ 与大有六五的对照（两个"柔居尊"的卦主）** | · **大有 14 六五**（全卦唯一阴爻，柔得尊位大中）——彖传"**柔得尊位大中，而上下应之，曰大有**"；<br>· **鼎 50 六五**（柔居尊得中）——彖传"**柔进而上行，得中而应乎刚，是以元亨**"。<br>**⚠️ 两卦上卦同为离，两个卦主都是柔居尊位而得中，两处彖传都把"大局面能成立"归因于此。**<br>**本库口径（大有卡已立，鼎卦为第二例实证）**：<br>> **《周易》凡讲"大局面能够成立"，核心多是"柔居尊而得中"。核心一硬，"上下应之"／"应乎刚"立刻消失。**<br>**⚠️ 而鼎卦给这条通则补了一个具体的功能解释：核心之所以要柔，是因为它的功能是"耳"（被提举的接口），不是"足"（承重）。** **耳的作用是让别人能抓住你、提起你、和你对接；⚠️ 用耳去承重，耳就会"革"（坏掉）。** |
| **识别信号** | ① 你处在这件事最高、最关键的位置上；② **下面已经出现了承载问题**（人扛不住、资源断了、进度崩了）；③ **你的第一反应是"再加固下面"**——加人加压加班；④ ⚠️ **而这件事目前没有一个能让别人提起来的把手**（没有清晰现状、没有可交接资料、没有能接手的人）。 |
| **该做** | ① **⚠️ 做"金铉"**——建立一个可靠的提举接口：现状清晰、边界明确、有一个能接手并对上负责的角色；② **让这个把手"黄"（居中）**——不偏向任何一方；③ **以"中"为实**（象传）：不偏、不满、不独占；④ **守正（利贞）**——⚠️ **卦辞缺的两德在这一爻，所以这一爻是全卦"正当性"的唯一来源。** |
| **不该做** | ① **⚠️ 用"耳"去承重**——耳是提的，不是扛的；② 在足已断时继续加固足；③ **核心变硬**——**核心一硬，彖传的"应乎刚"就没了，"元亨"随之失效**（呼应兑卦铁律：外柔可以，但内核必须刚且得中；⚠️ **鼎六五是它的镜像：核心居尊者必须柔且得中，刚在它上下**）。 |

### 上九 · 鼎玉铉

#### ⚠️⚠️ 本爻不当位，却是本库上爻判词第二高的一爻——也是规格"过刚则悔／过柔则凶"那两句的正解

| 字段 | 内容 |
|---|---|
| **爻辞** | 鼎玉铉，大吉，无不利。 |
| **象传** | 玉铉在上，刚柔节也。 |
| **位属性** | 阳爻居阴位，**⚠️ 不当位**；居全卦之终；**上离之顶**。按本库结构律，离在上 → 上九必然不当位。 |
| **判词 → 行动语义** | **大吉，无不利**（双判叠加） → **按本库吉凶排序：元吉 ＞ 无不利／大吉 ＞ 吉。⚠️ 本爻两个判词叠加，是本库上爻判词的第二高（仅次于井上六"元吉"）。行动语义：在最上面做那根"刚柔有节"的横杠。** |
| **关键词解** | **玉铉**——**玉制的举鼎横杠。**<br>**⚠️ 全爻的重量全在"玉"这个字上**：**玉的物性是"坚硬而温润"——既刚又不燥、既硬又不割手。** 对照六五的"**金**铉"：**金是纯刚、是硬。**<br>**⚠️ 从金到玉，变的不是功能（都是提举），是质地。** |
| **⚠️ 象传"玉铉在上，刚柔节也"** | "**节**"＝**节制、调节、适度、有节度。**<br>**⚠️ 象传没有说"刚柔并用"，也没有说"刚柔各半"，说的是"刚柔节"——刚与柔被调到了恰当的程度。**<br>> **⚠️ 口径（本爻最重要的一条）：承载体系的最高形态，不是最坚固的，是"刚柔有节"的。**<br>**落到现代三条**：<br>· **最强的接口不是最硬的规则，是"有原则且有弹性"的规则**——硬到不可谈判的规则会被绕过去，软到可以随时谈的规则等于没有；<br>· **最好的负责人不是最强硬的那个，是"能定事也能松手"的那个**；<br>· **⚠️ "节"是动词性的**：**不是把刚柔配成一个固定比例，是按需要调节。** |
| **⚠️⚠️ 本爻是规格"上爻限定"那两句的正解（本卡对全库通则的最重要增量）** | **规格第 3 节的上爻限定原文**："**反的是'不知止的极'，不是'到顶'本身。过刚则悔，过柔则凶，知止则吉，无内容则白过。**"<br>**⚠️ 而这两句各有一个标准例证，且它们与鼎上九的位属性完全同构**：<br>| 卦 | 上爻 | 位属性 | 经文 | 判词 | 性质 |<br>|---|---|---|---|---|---|<br>| **乾 1** | 上九 | **阳居阴位·不当位**（乾在上必然） | **亢龙有悔** | **悔** | **⚠️ 过刚，不知止** |<br>| **巽 57** | 上九 | **阳居阴位·不当位**（巽在上必然） | **丧其资斧，贞凶** | **贞凶** | **⚠️ 过柔，丢掉断决之力** |<br>| **⚠️ 鼎 50** | 上九 | **阳居阴位·不当位**（离在上必然） | **玉铉** | **⚠️ 大吉，无不利** | **⚠️ 刚柔有节** |<br>**⚠️ 三爻的位属性完全相同：都是阳爻居上位、都不当位。判词从"悔"到"贞凶"到"大吉，无不利"。**<br>> **⚠️ 结论（本卡最强的一条）：《周易》在"阳爻居最上、不当位"这个完全相同的位置上，给出了三个截然不同的结局，差别只有一个字——"节"。**
> **⚠️ 过刚 → 悔（乾上九）；过柔 → 贞凶（巽上九）；刚柔有节 → 大吉，无不利（鼎上九）。**
> **⚠️ 也就是说：规格里"过刚则悔，过柔则凶"这两句是问题，鼎上九"刚柔节也"是答案。**<br>**⚠️ 建议入库：上爻的第六种结局——"节"。** 累计六种：**过刚则悔（乾）／过柔则凶（巽）／知止则吉（离、革）／无内容则白过／交出去则元吉（井上六，本批）／⚠️ 刚柔有节则大吉无不利（鼎上九，本批）。** |
| **⚠️ 本爻是"当位不决定吉凶"最强的一例之一** | **上九不当位，且居"离在上→三爻全不当位"的最末，却拿到"大吉，无不利"。**<br>**⚠️ 与明夷（36）恰好构成一对反证**：<br>· **明夷五爻当位，却几乎拿不到一个吉字**（明夷卡已立："自己位置正，救不了环境黑"）；<br>· **⚠️ 鼎仅一爻当位，判词却极好**（卦辞元吉亨、九二吉、九三终吉、六五利贞、上九大吉无不利，全卦只有一个凶）。<br>> **⚠️ 口径（建议入库）：当位率与吉凶不相关。**
> **明夷证明"当位救不了坏环境"，鼎证明"不当位不妨碍好结果"。**
> **⚠️ 结构（当位）解释的是"你名分正不正"，不是"事成不成"。鼎卦的价值判据不是"正"，是"能不能承载、能不能提起来"。** |
| **识别信号** | ① 这件事已经立起来了、也能被提起来了（走完六五）；② 你在最上面的位置上；③ ⚠️ **你正在两种冲动之间**：**要么觉得到顶了该更硬（把规则钉死、把话说绝）**，**要么觉得该放软（都听下面的、不再拍板）**；④ 你需要给出的是一个长期能用的接口，而不是一次决定。 |
| **该做** | ① **做那根玉铉**：**在最上面既定得住、又不僵**——原则不动，方式可调；② **⚠️ 把"节"落到具体机制上**：哪些是不可谈判的（刚），哪些是可以按情况调的（柔），并且明确写出来；③ 保持"温润"——**在最上面的人，硬度要够，但不能割手。** |
| **不该做** | ① **⚠️ 以为到顶就该更硬**——那是乾上九"亢龙有悔"；② **⚠️ 以为到顶就该放软**——那是巽上九"丧其资斧，贞凶"；③ **把"节"做成和稀泥**——"节"是调节，不是没有立场（玉是硬的）。 |
| **与井上六、革上六的三上对照（本批四卦的三个终点）** | · **井 48 上六"井收勿幕，有孚元吉"**（象传"大成也"）——**⚠️ 交出去**：把成果敞开给人用；<br>· **革 49 上六"君子豹变，小人革面。征凶，居贞吉"**——**⚠️ 停下来**：宽于人心，严于人事；<br>· **困 47 上六"困于葛藟……征吉"**——**⚠️ 动起来**：破除软缠绕；<br>· **⚠️ 鼎 50 上九"鼎玉铉，大吉，无不利"**（象传"刚柔节也"）——**⚠️ 调到有节**。<br>**⚠️ 四个上爻给出四种不同的终点动作：交、停、动、节。**<br>**本库口径**：**上爻的正确动作完全由卦决定，不存在一个通用的"到顶怎么办"。** |

**鼎卦三句话**：
1. **鼎卦讲的是同一件事的两半：能不能"装"（腹与足＝承载），能不能"提"（耳与铉＝交接）。** **⚠️ 而全卦出事的地方全在器具，不在食物**——雉膏是美味、公餗是好东西，**坏掉的是耳和足**。
2. **⚠️ 全卦唯一的凶在九四"折足覆餗"，系辞的定性是"言不胜其任也"**：德薄而位尊、知小而谋大、**力少而任重**。**它的解法只有三条——减载、加足、交出去一部分；意志、承诺、加班都不改变"载重 ÷ 承载力"这个比值。**
3. **⚠️ 新事物失败最隐蔽的一种方式，不是它不好，是它"没有把手"**（九三"鼎耳革，其行塞，雉膏不食"）。**东西再好，没人提得起来、接得住、说得清，就是"失其义也"。**

**本卦最反直觉的四条**：
- **⚠️ 全卦六爻只有九三一爻当位，而九三恰恰是"其行塞"（动不了）的那一爻。** **因为"耳"是鼎唯一能被提起来的地方——位置再正，把手坏了就提不起来。**
- **⚠️ 卦辞不给"贞"，结构上也几乎没有一处"正"（仅 1 爻当位）；而鼎卦的判词却极好，全卦只有一个凶。** **《周易》在这里说得很清楚：新事物的价值不在"名正"，在"能不能承载"。**
- **⚠️ 六五（耳与铉）正好乘在九四（折了的足）之上。** **所以承载出问题时，解法不在下面——足已经断了，能救它的是"上面有没有一个合格的把手让别人把它提起来"。**
- **⚠️ 上九不当位，判词却是"大吉，无不利"，象传只给三个字："刚柔节也"。** **而乾上九（同一位属性）过刚得"悔"，巽上九（同一位属性）过柔得"贞凶"。⚠️ 同一个位置、三种结局，差别只有一个"节"字。**

## 四、本卦对全库的意义

### 1. ⚠️⚠️ 革 5 : 鼎 1——"破旧"与"立新"的结构反差（本卡最核心的贡献）

用本库已核定的机械公式复核（**当位数 ＝ 3 ＋ d(下卦) − d(上卦)**，**d＝离 3｜乾 震 艮 2｜坤 巽 兑 1｜坎 0**）：

| | **革 49（破旧）** | **鼎 50（立新）** |
|---|---|---|
| 卦象 | 上兑（泽）下离（火）——**泽中有火** | 上离（火）下巽（木）——**木上有火** |
| 公式 | **3 ＋ 3(离) − 1(兑) ＝ 5** | **3 ＋ 1(巽) − 3(离) ＝ 1** |
| **当位数** | **⚠️ 5 爻当位**（仅九四不当） | **⚠️ 1 爻当位**（仅九三当位） |
| 那个例外之爻 | **九四"有孚改命"——真正动手改的那一爻** | **九三"鼎耳革，其行塞"——提不起来的那一爻** |
| 乘刚 | 六二（乘初九）、上六（乘九五） | **六五（乘九四）** |
| 卦辞 | **元亨利贞四德齐全**（前置闸门"巳日乃孚"）＋悔亡 | **元吉，亨**（⚠️ **缺利贞**） |
| 主体 | **人**（大人虎变／君子豹变／小人革面） | **器**（趾／实／耳／足／铉） |
| 唯一的凶／最重的警告 | 九三"**征凶，贞厉**"（无孚而推） | 九四"**折足覆餗，凶**"（承载超限） |
| 上爻 | **征凶，居贞吉**（知止） | **大吉，无不利**（刚柔有节） |

**⚠️ 这组 5 : 1 的反差不是巧合，它正是两卦分工的结构表达（此段为义理层推演）**：

> **⚠️ 革卦五爻当位——因为"破旧"是在现有秩序里做的事：你必须站得正、名分要够、程序要全（"革言三就"），姿态还要"文明以说"。**
> **它唯一"不正"的那一下，就是动手改的那一刻（九四"有孚改命"）——因为"改命"的定义就是改变现有的名分秩序，它一旦当位就不是改命了。**
>
> **⚠️ 鼎卦只有一爻当位——因为"立新"本身还没有名分：新东西刚立起来的时候，它在旧秩序里全都是"不当位"的。**
> **⚠️ 而这正解释了为什么鼎卦的主线是"折足覆餗"的风险，而不是意气风发：**
> **一个在旧秩序里没有名分的东西，撑住它的不可能是"位"，只能是"承载力"。** **所以鼎卦从头到尾在算一件事——足够不够粗、耳牢不牢、装了多少、谁能提起来。**

**⚠️ 卦辞层与结构层在此完全互证**：**鼎卦辞缺"贞"（天道不承认新东西自动正当）↔ 结构上几乎无一处"正"。** **于是大象传立刻补上"正位凝命"——"正"字必须由你自己去做，这不是描述，是命令。**

**落到现代的一条组合口径（本批四卦最实用的产物之一）**：
> **⚠️ 改的时候要讲名分，立的时候不要等名分。**
> **革：五爻当位——除旧必须站得正、程序要全、姿态要"文明以说"。**
> **鼎：一爻当位——立新在名分上本来就是不正的，别等它变正，去把足做粗、把耳做牢。**
> **⚠️ 只革不鼎 → 拆完没有承载器，终点是鼎九四"折足覆餗"。**
> **⚠️ 只鼎不革 → 新东西装在没倒空的鼎里，回到革彖传"二女同居，其志不相得"。**

### 2. ⚠️ 井 48 ／ 鼎 50：本库唯一一对"以器物为主体"的卦，以及"巽在下的九三"这一固定席位

**两卦下卦同为巽（木），大象传只差一个字**：**井＝"木上有水"，鼎＝"木上有火"。** 井卡已列出完整对照表，这里只补本卡新增的两条：

**（1）⚠️ "巽在下的九三"是本库"有好东西而不被用"的固定席位。** 井、鼎下卦同为巽，故两卦九三必然同为"阳居三位·当位·失中·巽之顶"。**而两爻的爻辞都出现了"不食"二字**：

| | **井 48 九三** | **鼎 50 九三** |
|---|---|---|
| 经文 | **井渫不食**，为我心恻，可用汲，王明，并受其福 | 鼎耳革，其行塞，**雉膏不食**，方雨亏悔，终吉 |
| 病灶 | **没人来**（外部通道未建） | **提不起来**（内部把手坏了） |
| 象传 | **求王明**，受福也 | **失其义也** |
| 解药 | **"求"**——去找有识别力的人 | **修耳 ＋ 待雨**——做接口、等条件和洽 |
| 头上是什么 | **坎（水）**：上三爻全当位，全是通路 | **离（火）**：上三爻全不当位 |

**（2）⚠️ "不被用"判据补到三条（本库累计）**：

| 你头上是什么 | 卦 | 病灶 | 处方 |
|---|---|---|---|
| **土**（上坤，压死） | **明夷 36** | 发亮会招祸 | **用晦而明**（收光） |
| **水**（上坎，全通路） | **井 48 九三** | 只是没人知道 | **求王明**（去建通道） |
| **⚠️ 火**（上离，全不当位） | **⚠️ 鼎 50 九三** | **提不起来／交不出去** | **⚠️ 修耳 ＋ 待雨** |

> **⚠️ 一句话判据：头上是土就收光，是水就去求，是火就先做把手、并等雨。**

**（3）⚠️ "革"字在两卦中的正反用法。** **"革"是上一卦的卦名，而它在鼎卦唯一的一次出现是负面的（九三"鼎耳革"＝耳坏了）。**
> **⚠️ 口径：除旧阶段的美德，到了立新阶段会变成故障。变（革）用在制度上是"改命"（革九四，吉），用在接口上就是"耳革"（鼎九三，行塞）。**
> **⚠️ 新事物最不该反复变的，恰恰是别人抓它的那个把手——这正是大象传"凝命"的具体内容。**

### 3. ⚠️ "九四席位学"：本库两个必然不当位的九四，两套完全不同的救法

**结构事实**：按结构律，**上卦为离 → 九四必不当位**；**上卦为兑 → 九四也必不当位**。本库已成卡中恰好各有两卦，**而它们的救法分成清清楚楚的两族**：

| 上卦 | 卦 | 九四经文 | 判词 | ⚠️ 救法 |
|---|---|---|---|---|
| **离** | **大有 14** | **匪其彭**，无咎 | 无咎 | **⚠️ 减载**（不要盛满） |
| **离** | **⚠️ 鼎 50** | **鼎折足，覆公餗** | **凶** | **⚠️ 超载的反面教材** |
| **兑** | **困 47** | 来徐徐，困于金车，有言，终吉（象传"虽不当位，**有与也**"） | 终吉 | **⚠️ 有与**（还有人跟你一起） |
| **兑** | **革 49** | 悔亡，**有孚**改命，吉（象传"信志也"） | 悔亡…吉 | **⚠️ 有孚**（人们信你的志） |

> **⚠️ 口径（建议入库）：**
> **① 离在上的九四＝"载重"席位。** 它名不正，所以不能靠位置扛事；**唯一正确的动作是减载（大有"匪其彭"），超载则"折足覆餗"（鼎）。**
> **② 兑在上的九四＝"人际"席位。** 它名不正，所以两条出路都不是位置性的：**"还有人跟你一起"（困"有与"）与"人们信你的志"（革"有孚"）。**
> **⚠️ 合起来一句：九四不当位时，要么减少你扛的量（离在上），要么增加信你的人（兑在上）。没有"靠名分把它扛过去"这条路。**

**并且"不当位的救法"清单由此补到四条**（本批贡献两条）：**① 得中**（坎九二、困九二）；**② 有与**（困九四）；**③ 有孚**（革九四）；**④ 居中主事而不越位**（师九二）。

### 4. ⚠️ 上爻通则的完成：规格"过刚则悔，过柔则凶"两句，在鼎上九得到答案

**规格第 3 节的上爻限定说"过刚则悔，过柔则凶，知止则吉，无内容则白过"。⚠️ 而这两句的标准例证，与鼎上九的位属性完全相同——都是"阳爻居上位·不当位"**：

| 卦 | 上爻 | 经文 | 判词 | 性质 |
|---|---|---|---|---|
| **乾 1** | 上九 | 亢龙有悔 | **悔** | **过刚，不知止** |
| **巽 57** | 上九 | 丧其资斧，贞凶 | **贞凶** | **过柔，丢掉断决之力** |
| **⚠️ 鼎 50** | 上九 | **鼎玉铉** | **⚠️ 大吉，无不利** | **⚠️ 刚柔有节**（象传"刚柔节也"） |

> **⚠️ 结论：同一个位置（阳爻居上、不当位），三种结局，差别只有一个字——"节"。**
> **规格里"过刚则悔，过柔则凶"这两句是问题，鼎上九"刚柔节也"是答案。**

**⚠️ 上爻结局清单由此补到六种**（本批贡献两种）：
1. **过刚则悔**（乾上九）；
2. **过柔则凶**（巽上九）；
3. **知止则吉**（离上九"只除首恶不扩大"；革上六"征凶，居贞吉"）；
4. **无内容则白过**；
5. **⚠️ 交出去则元吉**（井上六"井收勿幕，有孚元吉"，象传"大成也"）；
6. **⚠️ 刚柔有节则大吉无不利**（鼎上九"玉铉"，象传"刚柔节也"）。

**本批四卦的四个上爻，正好给出四种不同的终点动作**：**井＝交，革＝停，困＝动，鼎＝节。**
> **⚠️ 口径：不存在一个通用的"到顶怎么办"。上爻的正确动作完全由卦（处境）决定。**

**⚠️ 另附一条重要反证：鼎卦证明"当位率与吉凶不相关"。** 明夷（36）**五爻当位却几乎拿不到一个吉字**（"自己位置正，救不了环境黑"）；**鼎（50）仅一爻当位，判词却极好**（元吉亨／吉／终吉／利贞／大吉无不利，全卦只有一个凶）。
> **⚠️ 结构（当位）解释的是"你名分正不正"，不是"事成不成"。**

### 5. ⚠️ 通则修正：「凡卦有离，纲领必与"辨"有关」**已整条废止**（本节原结论"由必降为多"亦不成立，见节末更新）

**本库原有一律（大有卡提出）**："**凡卦中有离，纲领必与'辨'有关；离在下＝先辨后同，离在上＝先有后辨。**" 其依据是同人"**类族辨物**"、大有"**遏恶扬善**"、大有九四象传"明辨晳也"。

**⚠️ 该律已出现明确例外，须降级**：

| 卦 | 卦象 | 大象传（纲领） | 是否涉"辨" |
|---|---|---|---|
| 同人 13 | 上乾下离 | 类族**辨**物 | ✓ |
| 大有 14 | 上离下乾 | 遏恶扬善，顺天休命（分辨并处置） | ✓ |
| 离 30 | 上离下离 | 继**明**照于四方 | ✓（明） |
| 明夷 36 | 上坤下离 | 用晦而**明** | ✓（明） |
| 革 49 | 上兑下离 | 治历**明**时 | ✓（明时＝分辨时令） |
| **既济 63** | 上坎下离 | **思患而豫防之** | **⚠️ ✗（第一个明确例外）** |
| **⚠️ 鼎 50** | 上离下巽 | **正位凝命** | **⚠️ ✗（第二个例外）** |

> **⚠️ 本节原结论"凡卦中有离，纲领『多』与辨／明有关"已被推翻。** 旅卡（56）核过全库 14 个含离样本，**纲领含"辨"者只有 2 卦（同人 13、未济 64），2/14 连"多"都撑不住，故该律整条废止。** 但本节下面那条"何时例外"的判据是对的，且已成为替换条文的一半：

**⚠️ 并且例外是有规律的，可以预测（本卡的机制补充）**：

> **判据：看这一卦里的"离"取"火"义还是"明"义。**
> **· 离取"明"（光源／视觉）→ 纲领必与"辨／明"有关**（同人、大有、离、明夷、革）；
> **· ⚠️ 离取"火"（热源／功用）→ 纲领与"辨"无关**（鼎、既济）。

**两个例外都能被这条判据解释**：
- **⚠️ 鼎 50**：彖传明写"**以木巽火，亨饪也**"——**离在这里是灶火，是用来煮东西的热源，不是用来看东西的光。** 所以纲领谈的是器物的稳定与名分（"**正位凝命**"），不谈分辨。
- **既济 63**：**上坎下离，水在火上，火是用来煮水的功用**，所以纲领谈的是防患（"**思患而豫防之**"），不谈分辨。

**⚠️ 一条可供后续卦卡检验的推论**：**未济（64）＝上离下坎，火在水上、不相为用，此时离回到"明"义——按本判据，其纲领应当涉"辨"。经文作"君子以慎辨物居方"，含"辨"字。⚠️ 未济尚未成卡，此条待该卡核定。**

### 6. ⚠️ 器具通则：主动倒空／卸载＝无咎，被动断裂＝凶

**本批四卦加上大畜，一共出现了五次"器具事件"，而《周易》的态度完全一致**：

| 卦·爻 | 器具事件 | 主动还是被动 | 判词 | 象／彖传 |
|---|---|---|---|---|
| **大畜 26 九二** | **舆说輹**（车脱了轴） | **⚠️ 主动卸车、不硬走** | **无咎** | **中无尤也** |
| **⚠️ 鼎 50 初六** | **鼎颠趾，出否**（把鼎倒过来） | **⚠️ 主动倒空** | **无咎** | **未悖也**／以从贵也 |
| **井 48 九二** | **瓮敝漏**（汲器破了在漏） | **被动损耗（未处理）** | 无判词 | **无与也** |
| **⚠️ 井 48 卦辞** | **羸其瓶**（最后一米瓶破了） | **⚠️ 被动损毁** | **凶** | **未有功也**／是以凶也 |
| **⚠️ 鼎 50 九四** | **鼎折足，覆公餗**（承重断裂） | **⚠️ 被动断裂** | **凶** | **信如何也** |

> **⚠️ 口径（建议入库）：**
> **① 器具必须在"用它之前"检查与更换。主动卸载／主动倒空是"无咎"的（大畜九二、鼎初六）；走到最后一米才发现器具坏了，是"凶"的（井卦辞、鼎九四）。**
> **② ⚠️ 两卦唯一的凶都在器具侧，不在资源侧**——井里有水、鼎里有餗，**坏的是瓶和足**。
> **③ 两种凶的代价不同：井"羸其瓶"是"未有功也"（你自己白干）；鼎"折足覆餗"是"信如何也"（别人对你的托付作废）。⚠️ 后者更重。**

**⚠️ 而"检查器具"的窗口在本库中有明确地址**：**井六四"井甃"（只修不取）与鼎九三"修耳"——两卦都把这个动作的判词压到最低（无咎／终吉），因为它不出成果；但跳过它，就是那两个"凶"。**

### 7. 与已成卡各卦的衔接一览

| 衔接 | 机制一句话 |
|---|---|
| **鼎 ↔ 革（49）** | **全库唯一直接讲组织变革的一对**：革除旧／鼎立新；**当位数 5 : 1**——**破旧位位都正（要名分、要程序），立新几乎无一处正（要承载力，不要等名分）**；只革不鼎→鼎九四折足，只鼎不革→革彖传"二女同居" |
| **鼎 ↔ 井（48）** | **本库唯一一对"以器物为主体"的卦**，大象传只差一字（木上有水／木上有火）；**巽在下的九三是"有好东西而不被用"的固定席位**（两爻都用"不食"）；**两卦唯一的凶都在器具侧** |
| **鼎 ↔ 大畜（26）** | **⚠️ 大畜是鼎九四的预防措施**：系辞三错配中"德薄""知小"由大畜"多识前言往行，以畜其德"治，"力少而任重"由大畜三级台阶（利贞→不家食吉→利涉大川，顺序不可跳）治。**跳级就是折足** |
| **鼎 ↔ 大有（14）** | **离在上的九四是"载重"席位**：大有"匪其彭"（减载·无咎）／鼎"折足覆餗"（超载·凶）；**且两卦卦主同为柔居尊得中，彖传同一句法，同为"卦辞缺德、大象传补"** |
| **鼎 ↔ 困（47）** | **系辞两段合读**：困六三"非所据而据焉，身必危"（靠错了）／鼎九四"力少而任重…不胜其任"（担多了）。**现代常同时发生：担子接多了，于是去抓有刺的资源来补** |
| **鼎 ↔ 明夷（36）** | **"当位率与吉凶不相关"的一对反证**：明夷五爻当位而几无吉（位正救不了环境黑）／鼎仅一爻当位而判词极好（新事物不靠名分靠承载） |
| **鼎 ↔ 乾（1）、巽（57）** | **三个"阳爻居上位·不当位"的上爻**：乾"亢龙有悔"（过刚）／巽"丧其资斧，贞凶"（过柔）／**鼎"玉铉，大吉，无不利"（刚柔节也）。⚠️ 规格"过刚则悔，过柔则凶"两句的答案就是鼎上九的"节"** |
| **鼎 ↔ 兑（58）** | **卦主的镜像**：兑铁律"悦必须刚中而柔外，内核必须刚"／**鼎六五是柔居尊而刚在上下（彖传"得中而应乎刚"）。⚠️ 核心居尊者要柔，因为它的功能是"耳"（被提举的接口），不是"足"（承重）——用耳承重，耳就会"革"** |
| **鼎 ↔ 震（51）** | **序卦传出口"主器者莫若长子，故受之以震"**：鼎负责把器立起来，**震负责"谁来主这件重器"**。本库震卡可由此接上 |
| **鼎 ↔ 离（30）** | **⚠️ 通则修正的来源**：鼎大象传"正位凝命"不含"辨"，与既济"思患而豫防之"同为例外。**判据：离取"明"义则纲领涉辨，取"火"义（热源／功用）则不涉** |
