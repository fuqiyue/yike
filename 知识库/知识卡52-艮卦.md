# 知识卡 52 · 艮卦（艮 / 山）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："物不可以终动，止之，故受之以艮。艮者，止也。"——不可能一直动下去，所以要止。
> **本卦是八纯卦之一（上艮下艮），是震卦（51）的反卦**：震＝动，艮＝止。**两卦必须合读。**
> ⚠️ **本卡是本库一条核心通则的关键反证**：索引通则说"**乾上九／坤上六是各自全卦唯一的纯凶之爻，皆因盈极不知止**"。**艮卦上九"敦艮，吉"——是八纯卦上爻里最好的结果。知止者，居上位反吉。**（详见上九与末节）

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 艮 · 第五十二卦 · **八纯卦之一** |
| **卦象** | 上艮下艮，**兼山**（两山并立）。**一阳止于二阴之上**——阳气升到顶被止住，故为"止"、为"山"、为"少子" |
| **⚠️ 与震的结构互补（一句话记住两卦）** | **震把阳放在最下面，往上顶 → 动；艮把阳放在最上面，往下压 → 止。** 同样是"一阳二阴"，位置一换，一卦讲怎么应对突变，一卦讲怎么停下来。 |
| **领域定义** | **该停下来的时候如何停**。收手、退出、封盘、戒断、划边界、不越界、闭嘴、放弃一个机会、结束一段关系、从一个位置上下来。也包括**"守住自己那一份、不操别人的心"**（大象传"思不出其位"）。凡是"我要不要停／怎么停／停在哪儿"，都落在艮卦。 |
| **不归本卦的情况** | 是被困住出不来，不是主动停 → **坎卦**；是被震了一下要不要动 → **震卦**；是想止住别人／以柔制刚 → **小畜卦**。**艮卦特指"你有能力继续，但你决定不继续"。** |
| **"艮"字义** | 止。**注意本卦最容易被误读的地方：艮不是消极、不是躺平。** 彖传第一句就把它定死了：**"时止则止，时行则行"——艮判断的是"时"，不是偏好。** |
| **卦辞原文** | 艮：艮其背，不获其身，行其庭，不见其人，无咎。 |
| **⚠️ 卦辞的关键特征** | **无元、无亨、无利、无贞，只给了一个"无咎"**——**和师卦一样吝啬**。止这件事，天道不许诺任何好处，只告诉你**这样做不会有灾**。 |
| **卦辞现代解** | **艮其背**——止在"背"上。**背是自己看不见、也不主动的部位**：止要止在你看不见自己的地方，即**不带自我表演地止**。<br>**不获其身**——止到看不见自己这个"身"。**没有"我在忍""我在牺牲"的念头，才算真止。**<br>**行其庭，不见其人**——走过庭院，不见人影。**止到这个程度，外界的干扰、比较、看法都进不来。**<br>**无咎**——如此则无灾。 |
| **彖传** | 艮，止也。时止则止，时行则行，动静不失其时，其道光明。艮其止，止其所也。上下敌应，不相与也，是以不获其身，行其庭不见其人，无咎也。 |
| **⚠️ 彖传要点（本卦纲领，全书名句）** | ① **"时止则止，时行则行，动静不失其时，其道光明"**——**艮卦的最高原则不是"止"，是"不失其时"。** 该动而不动，与该止而不止，是同一个错。<br>② **"艮其止，止其所也"**——止要**止在该止的地方**（"所"是位置）。**止错了位置，就是九三的"列其夤"（撕裂脊背）。**<br>③ **"上下敌应，不相与也"**——上下卦每一对应爻同性相斥，**全卦无一爻有应援**。这就是"不见其人"的结构原因：**艮卦是一个没有外援的处境**（此为八纯卦共性，见末节）。 |
| **大象传（行动纲领）** | 兼山，艮。君子以思不出其位。 |
| **⚠️ "思不出其位"解（本卦最实用的一句）** | 两山并立，各在其位、互不侵越。**"思"都不越出自己的位置**——**不是行为不越界，是连念头都不越界**。<br>**这是艮卦给出的边界纪律，也是"止"在日常里的具体形态**：不操不属于你位置的心，不替别人做决定，不在自己没有责任的事上耗神。 |
| **总铁律** | ① **艮判断的是"时"**，该行则行、该止则止（彖传）；② **止要止得早、止在微处**——止于"趾"代价最小（初六）；③ **绝不能止在"限"（腰）**——硬把上下截断会撕裂（九三"厉"）；④ **居尊位者最难止的是嘴**（六五"艮其辅，言有序"）；⑤ **止到极处是"敦艮，吉"**——因为"以厚终也"（上九）。 |

## 二、爻级字段
（**本卦六爻按人体自下而上排列：趾 → 腓 → 限 → 身 → 辅 → 敦**。这是《周易》里最系统的一组身体隐喻，**"止在哪个部位"就是"止在哪个层次"**。）

### 初六 · 艮其趾

| 字段 | 内容 |
|---|---|
| **爻辞** | 艮其趾，无咎，利永贞。 |
| **象传** | 艮其趾，未失正也。 |
| **位属性** | 阴爻居阳位，**不当位**；居全卦最下——**最早、最微处** |
| **判词 → 行动语义** | 无咎 ＋ 利永贞 → **在脚趾刚要迈出去时就止住** |
| **关键词解** | **趾**＝脚趾，**动作的最前端、最开始**。**艮其趾**＝**在还没真正走出去的时候止住**。**利永贞**＝适宜长久守持此正道。 |
| **⚠️ 本爻的核心（成本最低的止）** | 初六**不当位**，本该"名不正言不顺、风险高"，**但象传判了"未失正也"（并没有失正）**——**理由只有一个：它止得足够早。**<br>**结论：止的代价与止的时机成反比。在"趾"上止，几乎无成本；拖到"限"（腰）上再止，就要撕裂脊背（九三）。** |
| **识别信号** | ① 一件事你刚有念头、刚要迈第一步；② 你隐约知道这事不对，但还没有付出任何成本；③ 周围还没有人知道你打算做。 |
| **该做** | **现在就停，并且长期守住这个决定（利永贞）。** 不必解释、不必宣布——**趾上的止是零成本的**。 |
| **不该做** | 想"先走两步看看"。**在艮卦里，"先走两步"就是把止的位置从趾推到腰。** |
| **与乾初九、坎初六的三角对照** | **乾初九"潜龙勿用"——蓄力型不动，是为了后面动**；**坎初六"入于坎窞，凶"——已经陷进去还往深走**；**艮初六"艮其趾"——在还能零成本退出时退出。** 三者都在"最下面那一爻"，**但一个是攒、一个是陷、一个是退。** |

### 六二 · 艮其腓（辅佐者的困境）

| 字段 | 内容 |
|---|---|
| **爻辞** | 艮其腓，不拯其随，其心不快。 |
| **象传** | 不拯其随，未退听也。 |
| **位属性** | 阴爻居阴位，**当位且得中**——条件本该很好；**但判词只给了"心不快"** |
| **判词 → 行动语义** | **无吉凶判词，只给了一个心理状态** → **你止住了自己，但救不了你跟随的人** |
| **关键词解** | **腓**＝小腿（走路的主要发力处）。**艮其腓**＝止住小腿，**自己不走了**。**不拯其随**——"随"指其所跟随者（上面的九三）：**救不了他**。**其心不快**＝心里不痛快。 |
| **⚠️ 象传给出了原因，也是本爻全部的重量** | "**未退听也**"——**上面那个人不肯退让、不肯听。**<br>**所以六二的憋屈不是它自己的问题**：它当位、得中、自己已经止住了；**问题在于它跟随的人不听劝，而它没有力量拉住他。** |
| **本爻是"辅佐者视角的艮"（与坤卦直接呼应）** | 坤卦讲辅佐者之路——**守臣节、不抢权**；**艮六二讲的是辅佐者在"该止"这件事上的极限：你能止住自己，止不住你的主帅。** 而《周易》在这里**没有给你任何越位的授权**：爻辞只承认"其心不快"，**它承认你的难受，但不允许你去替他做决定**（这正是大象传"思不出其位"）。 |
| **识别信号** | ① 你已经决定不再往前，并且做到了；② 你上面的人（老板、合伙人、家人、主导者）正在往危险方向走；③ 你劝过，他不听；④ 你心里非常难受，开始想"要不要直接替他做了"。 |
| **该做** | **止住自己，说清你的判断，然后接受"心不快"。** 把这份不快当成正常代价，不当成必须解决的问题。 |
| **不该做** | 越位替他决定；或反过来，因为救不了他就跟着一起走。**"不拯其随"是事实陈述，不是失败判定——爻辞并未判你有咎。** |
| **与坤六三"无成有终"的呼应** | 坤六三（及讼六三）"无成有终"＝**不居功、功归于上**；**艮六二则是它的反面情形：过归于上，你也担不了。** 两爻合起来是辅佐者的完整边界：**功不抢，过也不越位去替他挡。** |

### 九三 · 艮其限（本卦最痛的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 艮其限，列其夤，厉。 |
| **象传** | 艮其限，危熏心也。 |
| **位属性** | 阳爻居阳位，**当位**；居下艮之顶、上下两艮之交——**正是"限"（界）所在**；本库通则"**三多凶**" |
| **判词 → 行动语义** | **厉**（按本库口径：**警告，非判死**） → **不要在"腰"上硬切** |
| **关键词解** | **限**＝腰，**人体上下身的分界**。**列**通裂，**夤**＝夹脊之肉。**列其夤**＝**脊背的肉被撕裂开**。**熏**＝烧灼。 |
| **⚠️ 本爻是全卦最重要的警告** | 止在脚趾（初六）是零成本；**止在腰上，是把一个人的上半身和下半身硬生生截断——所以"列其夤"（撕裂）、"危熏心"（危险烧到心里）。**<br>**这一爻讲的不是"该不该止"，是"止的位置错了"。** 对应彖传那句：**"艮其止，止其所也"——止必须止在该止的地方。** |
| **什么叫"止在腰上"（现代形态）** | ① 事情已经推进到一半，上下游都已投入，此时硬性叫停；② 在一个组织的中层强行切断上下的连接；③ 戒断一件已经深度嵌进生活的事，用一刀切的方式；④ 一段关系已经彼此嵌合，用单方面断联的方式结束。**特征都是：切口选在"承重结构"上。** |
| **识别信号** | ① 你已经投入很深，但决定要停；② 你的停会同时切断上游和下游；③ 你能感到强烈的生理性焦虑（危熏心）。 |
| **该做** | **换切口。** 不在承重处切——**先止"趾"（不再新增）、再止"身"（管住自己整体，六四）、最后止"辅"（不再对外表态，六五）**。**本卦已经给了四个可选的切口，腰是唯一不能选的那个。** |
| **不该做** | 一刀两断。**"厉"是警告不是判死，说明还有救；但如果按"列其夤"继续，就会掉到"危熏心"。** |
| **与乾九三的对照（两个"三"的分野）** | **乾九三"终日乾乾夕惕若，厉，无咎"——上升期的抉择点，惕则无咎，还能往上跨一步**；**艮九三"列其夤，厉"——没有"无咎"，只有"厉"。** **同为九三、同为当位、同判"厉"，乾九三给了出路（惕），艮九三只给了警告。** 差别在于：**乾是要不要再进，艮是已经决定退、但退法错了。** |

### 六四 · 艮其身

| 字段 | 内容 |
|---|---|
| **爻辞** | 艮其身，无咎。 |
| **象传** | 艮其身，止诸躬也。 |
| **位属性** | 阴爻居阴位，**当位**；**乘于九三之上——乘刚**；本库通则"**四多惧**" |
| **判词 → 行动语义** | 无咎 → **从"止住某个部位"升级为"止住整个自己"** |
| **关键词解** | **身**＝全身、整个人（与前三爻的趾、腓、限不同，这是第一次不再是局部）。**止诸躬**＝**止于自己身上**（"躬"是自身）。 |
| **⚠️ 本爻是全卦的转折，也是"乘刚"的解药** | 本库通则：**乘刚＝阴爻居阳爻之上，天然被下方阳刚逼迫冲击**（震六二、屯六二皆因此受损）。**但艮六四同样乘刚，判词却是"无咎"。**<br>**原因就在象传那三个字："止诸躬也"——它只管自己。**<br>**结论：乘刚带来的压迫感无法消除，但只要把范围收回到"自己这一身"，就不构成灾。** 这是本库"乘刚"规则下第一个明确的破解方式。 |
| **识别信号** | ① 你下面／周围有强劲的力量在顶你（乘刚）；② 你已经过了九三那个最痛的切口期；③ 你还在纠结要不要去管别人、去纠正局面。 |
| **该做** | **把边界画在自己身上。** 我不做什么、我到此为止——**只对"我"下指令，不对局面下指令。** |
| **不该做** | 试图"止住整件事""止住所有人"。**六四能做到的只是"止诸躬"，超出这一身就不是它的位置**（大象传"思不出其位"）。 |
| **与坤六四"无咎无誉"的呼应** | 坤六四"括囊，无咎无誉"——**慎、闭口，此处不引人注目正是好事**；**艮六四"止诸躬"——把作为收回到自身。** **两爻是同一种智慧在两卦的表达：在四位（多惧之位），最好的作为是缩小作为范围。** |

### 六五 · 艮其辅（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 艮其辅，言有序，悔亡。 |
| **象传** | 艮其辅，以中正也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位——全卦卦主 |
| **判词 → 行动语义** | **悔亡**（按本库吉凶序：无咎 ＞ **悔亡** ＞ 悔） → **止住嘴，且说话要有次序** |
| **关键词解** | **辅**＝面颊、牙床，**代指口舌／说话**。**艮其辅**＝**管住嘴**。**言有序**＝说话有条理、有先后、有分寸。**悔亡**＝原本会有的悔恨消失了。 |
| **⚠️ 本爻是艮卦对居尊位者的专门指令** | 全卦六爻里，**只有六五讲的不是身体动作，是"说话"**。**因为居尊位的人最难止住的不是手脚，是嘴**：一句话就能改变局面、就能越界、就能把已经止住的事重新搅动。<br>**"艮其辅"不是不说话，是"言有序"——该说的说，按次序说，不多一句。** |
| **本爻为什么只给"悔亡"而不是"吉"** | 按本库判词表，**悔亡＝原本该有的悔恨没有了**——**它是一个"挽回"级别的判词，不是"得利"级别。** 意思很明确：**居尊位者管住嘴，能挽回的只是本来会犯的错，不会因此额外得到好处。** |
| **本库"六五／九五"专题的第五例** | 已有四例：**乾九五**（居尊而利见大人）、**坤六五**（有君之权而守臣节）、**蒙六五**（居尊而不失赤子之心）、**离六五**（居尊而痛哭）。**艮六五补上第五种：居尊而闭嘴。**<br>**五者完全同构——居尊位者必须主动放弃一样特权**：乾放弃独断（去求贤），坤放弃权柄，蒙放弃架子，离放弃坚强，**艮放弃说话的自由。** |
| **识别信号** | ① 你在拍板的位置上；② 事情已经决定要停／要收；③ 你很想再解释一次、再表个态、再补一句。 |
| **该做** | **闭嘴，或者按次序只说必要的那几句。** 决定停了，就不再对外反复论证。 |
| **不该做** | 反复解释、发长文、私下补充说明。**每一句多出来的话都会把"止"重新变成"动"。** |
| **与坤六四、比卦的呼应** | 坤六四"括囊"是**辅佐者的闭口**；**艮六五是决策者的闭口。** 而比卦（8）卦辞"**原筮**"（反复审慎判断）讲的是**决定之前要多想**——**合起来是完整的口径：定之前多想，定之后少说。** |

### 上九 · 敦艮（⚠️ 八纯卦上爻里最好的结果）

| 字段 | 内容 |
|---|---|
| **爻辞** | 敦艮，吉。 |
| **象传** | 敦艮之吉，以厚终也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终——**却是"吉"** |
| **判词 → 行动语义** | **吉** → **厚重地、彻底地止住，善终** |
| **关键词解** | **敦**＝厚、笃实、敦厚。**敦艮**＝**把"止"做到厚重笃实的程度**。**以厚终**＝以厚重收尾。 |
| **⚠️ 本爻是本库一条核心通则的关键反证（本卡最重要的一条）** | 本库索引通则写着：<br>> **乾上九／坤上六——各自全卦唯一的纯凶之爻，皆因盈极不知止。**<br>而八纯卦的上爻依次是：**乾上九"亢龙有悔"（悔）、坤上六"龙战于野"（凶）、坎上六"三岁不得"（凶）、离上九"获匪其丑"（无咎）、震上六"征凶…无咎"（有条件的无咎）、艮上九"敦艮"（吉）。**<br>**艮上九是其中唯一的"吉"。原因干净得不需要解释：这一卦的德就是"止"，所以止到极处，正是这一卦之德的圆满完成。**<br>**结论（可直接入库为通则）：上爻之凶从不来自"到顶"本身，只来自"到顶而不知止"。知止者，居上位反吉。** |
| **本爻为什么不当位却吉** | 阳居阴位本是名不正言不顺。**但艮卦的上九是"一阳止于二阴之上"的那个阳——它就是全卦"止"的力量本身所在。** 位不正，而**德与卦完全相合**，所以象传不谈位，只谈"厚"。**这也是本库"义理可救位"的一个实例。** |
| **识别信号** | ① 你已经完成了退出／收手／结束；② 你没有留后门、没有反复、没有对外反复解释；③ 你对这个决定不再感到需要辩护。 |
| **该做** | **把止做厚**——不留尾巴、不留后手、不留"万一"。**厚，是"止"唯一的质量标准。** |
| **不该做** | 半止半留。**"敦"字的反面就是薄——止得薄，就会在别处漏回来。** |
| **与乾上九的正面对照（全书最值得并读的两爻）** | **乾上九"亢龙有悔"：能力到顶、位置到顶，却不肯止，所以是乾卦唯一的纯凶之爻。**<br>**艮上九"敦艮，吉"：位置到顶，主动止到极处，是艮卦最好的一爻。**<br>**同样在第六位、同样是阳爻、同样到顶——一个悔，一个吉。差别只有一个字：止。** |

## 三、艮卦定位速查表

| 爻 | 止在哪 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | **趾**（脚趾） | 艮其趾 | 刚有念头，还没付出成本 | 不当位但**未失正** | **无咎·利永贞**·零成本止 |
| 六二 | **腓**（小腿） | 艮其腓 | 自己止住了，但上面的人不听 | **当位·得中** | **其心不快**·止己·不越位 |
| 九三 | **限**（腰） | 艮其限 | 投入很深，想一刀两断 | 当位·两艮之交 | **厉·列其夤**·换切口 |
| 六四 | **身**（整个人） | 艮其身 | 下面有力量在顶你，你想去管局面 | 当位·**乘刚** | **无咎**·止诸躬·只管自己 |
| 六五 | **辅**（嘴） | 艮其辅 | 已经决定停，却很想再解释一句 | 不当位但**得中居尊** | **悔亡**·闭嘴·言有序 |
| 上九 | **敦**（厚） | 敦艮 | 已经完成退出，不再需要辩护 | 不当位**却吉** | **吉**·以厚终·不留尾巴 |

**艮卦三句话**：
1. **艮判断的是"时"，不是偏好**——"时止则止，时行则行，动静不失其时，其道光明"（彖传）。**该动不动和该止不止，是同一个错。**
2. **止的代价与止的时机成反比**：止在"趾"上零成本（初六），拖到"腰"上就要撕裂脊背（九三）。**止的位置比止的决心重要。**
3. **止到极处是吉**（上九"敦艮"）。**唯一的质量标准是"厚"——不留尾巴、不留后手、不留万一。**

**本卦最反直觉的三条**：
- **上九不当位，却是八纯卦六个上爻里唯一的"吉"。** 与乾上九"亢龙有悔"正面对照：**同在第六位、同是阳爻、同样到顶，一个悔一个吉，差别只有"止"这一个字。**
- **六二当位又得中，判词却只有"其心不快"。** 因为它的困难不来自自己——**上面的人不肯退听，而《周易》不给你越位去替他决定的授权**（大象传"思不出其位"）。
- **六四同样乘刚，却"无咎"**（对比震六二乘刚而"亿丧贝"）。**解药是"止诸躬"——把范围收回到自己这一身。这是本库"乘刚"规则下第一个明确的破解方式。**

## 四、⚠️ 本卡对全库的意义

### 1. 新增通则：上爻之凶不来自"到顶"，只来自"到顶而不知止"

| 纯卦 | 上爻 | 爻辞 | 判词 | 机制 |
|---|---|---|---|---|
| **乾 1** | 上九 | 亢龙有悔 | **悔** | 盈极不知止 |
| **坤 2** | 上六 | 龙战于野，其血玄黄 | **凶** | 盈极不知止 |
| **坎 29** | 上六 | 系用徽纆…三岁不得 | **凶** | 失道且久困不动 |
| **离 30** | 上九 | 王用出征…获匪其丑 | **无咎** | 到顶而"正邦"、不扩大 |
| **震 51** | 上六 | 震索索…征凶…无咎 | **征凶／无咎** | 不动＋畏邻戒，则无咎 |
| **艮 52** | 上九 | 敦艮 | **吉** | **主动止到极处，以厚终** |

> **可直接补入索引第五节"位属性判断规则"**：**"上＝物极必反"这一条需要加一个限定——反的是"不知止的极"。** 六个纯卦的上爻按"是否知止"排序，结果与吉凶序完全一致。

### 2. 震／艮结构互补律

| | 阳爻位置 | 内部是否制造"乘刚" | 卦德 |
|---|---|---|---|
| **震**（阳阴阴） | **在最下**，往上顶 | **是**——震在下则六二乘刚，震在上则六五乘刚 | 动 |
| **艮**（阴阴阳） | **在最上**，往下压 | **否**——阳在本卦最顶，其上无爻可乘 | 止 |

> **艮的当位分布**：**艮在下 → 初六不当位、六二当位、九三当位**；**艮在上 → 六四当位、六五不当位、上九不当位**。
> 与已有三律合记：**坎在下＝已在险中；离在上＝光在身外；震在上＝动在头顶；艮在上＝止在头顶（有人在上面压着你不许动）。**
