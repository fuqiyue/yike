# 知识卡 53 · 渐卦（风山渐）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："艮者，止也。物不可以终止，故受之以渐。渐者，进也。"——**艮卦（52）教的是"怎么停"，但天下没有停到底的事**，所以停完之后必须重新往前走，而重新往前走的唯一合法方式叫"渐"。**注意这条转接的分量：渐不是"止"的反面，渐是"止"的延续——它的下卦就是艮。**
> **本卦与归妹卦（54）是一对，且是结构上的倒转（覆卦）**：渐六爻自下往上为"阴阴阳阴阳阳"，整卦上下颠倒即得归妹（"阳阳阴阳阴阴"＝上震下兑）。**两卦讲的是同一件事（女归／结合）的两种走法，卦辞的判断却完全相反：渐"女归吉"，归妹"征凶，无攸利"。必须合读。**
> ⚠️ **本卡最有价值的部分**：**渐六爻是全书最干净的一条上行台阶序列——鸿渐于干 → 磐 → 陆 → 木 → 陵 → 陆**，且它与乾卦（01）的六龙序列（潜→见→惕→跃→飞→亢）构成本库唯一的一组"上行序列正面对照"。**乾以"亢"终，渐以"吉"终，差别只在一个字：止。逐级清单与逐位对照见第二节开头与第四节。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 渐 · 第五十三卦 |
| **卦象** | 上巽（风／木／顺入）下艮（山／止），称"风山渐"。**大象传取的是"山上有木"**（巽兼风与木二象）——**山已经很高了，山上还长着树，树是一年一寸长上去的：这就是"渐"的全部图像。**<br>**按本库第 4 节结构律，本卦的当位分布是全确定的**：<br>**艮在下 → 初六不当位、六二当位得中、九三当位**；<br>**巽在上 → 六四当位、九五当位得中、上九不当位**。<br>**⚠️ 结果：六爻四当位（二、三、四、五连续四爻全部当位），而且二、五两个中位全部"当位＋得中"。这是本库已完成各卦中当位结构最好的一卦之一。**<br>**这条结构事实直接解释了卦德**：一条"每一级都站得住"的阶梯，才可能"渐"。**换句话说：渐不是心态，是结构条件——阶梯本身必须是稳的。**<br>**⚠️ 彖传把这个结构钉死了两次**：一次是"**进得位，往有功也**"（往前走能站住位置，所以有功），一次是"**止而巽，动不穷也**"（下艮止、上巽顺）。 |
| **领域定义** | **必须一级一级来、跳级即毁的上行过程**。① 进入一个新的圈子／行业／单位，从边缘走到核心；② 一段关系从认识走到定下来（订婚、合伙、长期合约）；③ 资质、职称、执照、学位这类"必须逐级考"的路径；④ 把一个小业务养成主业（不靠融资、不靠一次爆红）；⑤ 组织内的正常晋升序列；⑥ 长期习惯的建立与身体、技艺的养成。**凡是"我知道方向，问题只是节奏"，都落在渐卦。** |
| **不归本卦的情况** | ① 已经跳级了、已经不理想地结合了，问题是"怎么过下去" → **归妹卦（54）**；② 该不该停下来、怎么停 → **艮卦（52）**；③ 要靠柔顺一点点渗透去改变一个人 → **巽卦（57）**；④ 关系从零到有感应的那一段 → **咸卦（31）**；⑤ 起步阶段根基不稳、方向都还不明 → **屯卦（03）**。**渐卦的前提是：方向已定、阶梯已在、你只是想快一点。** |
| **"渐"字本义** | **渐＝浸、渍，水一点点浸润过去**；序卦传直接训为"**进也**"，彖传首句训为"**之进也**"——**渐是"进"的一种，是"慢慢地进"这个特定形态。**<br>**注意《周易》没有把"渐"和"进"分成两个词，它只是给"进"加了一个速率限制。** 这一点很重要：**渐卦不劝你不进，它只规定进的步长。**<br>**卦名与下卦的关系**：渐的"慢"不是从上卦巽（顺）来的，是从下卦艮（止）来的——**内部有一个止的机制，外部才显得顺；所以"渐"的操作定义是：每走一级，先在这一级停住。** |
| **卦辞原文** | 渐：女归吉，利贞。 |
| **⚠️ 卦辞的关键结构** | **无"元"、无"亨"；有"利贞"；并且额外多了一个具体事项的吉断——"女归吉"，而且它排在最前面。**<br>**缺"元"（敢于启动、去做去拼）**：渐卦不给你启动的爆发力，**因为渐的第一步本来就不需要爆发力**。<br>**缺"亨"（路自然通、资源自然聚）**：**渐卦不许诺路是通的。** 这一点极关键——**你按台阶走，不代表台阶会为你加速；"利贞"只保证走正道有益，不保证顺畅。**<br>**多了"女归吉"**：与咸卦（31）卦辞"取女吉"同型（都用一个婚嫁场景做验证案例），**但位置不同——咸卦把它放在"亨，利贞"之后当补充，渐卦把它放在最前面当定义。**<br>**⚠️ 为什么把它放最前面？因为古礼中"女归"是全部社会活动里唯一一件"步骤本身就是内容"的事（纳采、问名、纳吉、纳征、请期、亲迎，六步不可颠倒）。《周易》要给"渐"下定义，找不到比它更精确的例子。**<br>**⚠️ 与归妹卦辞的正面冲突（本卦最重要的一条对照）**：**同样是"女归"这件事，渐卦断"吉"，归妹卦断"征凶，无攸利"。《周易》对同一件事给出两个相反的卦辞级判断，差别只在一个变量——是否循序。** |
| **卦辞现代解** | **女归吉**——**按完整程序、一步不省地走完的结合，是吉的。** 落到现代：把入职、合伙、长期合约、资质获取这类事的"手续"当成内容而不是障碍。<br>**利贞**——**走正道有益。** 注意这里只说"利"（可行、有益），不说"吉"。**在渐卦，"守正"的收益是稳定，不是加速。** |
| **彖传** | 渐之进也。女归吉也。进得位，往有功也。进以正，可以正邦也。其位刚得中也。止而巽，动不穷也。 ⚠️ 版本待核（"可以正邦也"一句，另有版本作"利贞也"；"其位刚得中也"断句各家略异） |
| **⚠️ 彖传要点（本卦的全部机制都在最后六个字里）** | ① **"进得位，往有功也"**——**往前走能站住位置，所以往前有功。** 这正是上表算出来的结构事实（二三四五连续四爻当位）。**反过来读更有用：如果你往前一步就站不住位置，那就不是渐，别走。**<br>② **"进以正，可以正邦也"**——**按正当程序上行，其效果能一直外溢到把整个局面弄正。** 注意它不说"可以成事"，说"可以正邦"：**渐的价值不在你到了哪儿，在你把路走成了什么样。** 这一句是上九"其羽可用为仪"的伏笔。<br>③ **"止而巽，动不穷也"（全卦最重的六个字）**——**下艮是"止"，上巽是"巽"（顺、入）；因为内有止，所以动起来不会穷。**<br>**⚠️ "动不穷也"这四个字与乾卦上九象传"盈不可久也"是一对正面反话**：乾是纯阳无止，所以"盈不可久"；渐是内有止，所以"动不穷"。**《周易》在此明说：让运动能持续的不是动力，是内部的止。**（详见第四节） |
| **⚠️ 一条结构律的第三次经文背书** | 本库规格第 4 节的条文"**艮在下＝止在内，自己收手**"，已在咸卦（31）彖传拿到"**止而说**"的背书；**本卦彖传作"止而巽"，旅卦（56）彖传作"止而丽乎明"。**<br>**三卦（咸 31、渐 53、旅 56）全部是"艮在下"，三卦彖传全部以"止而□"起句，句式完全一致。**<br>**结论：这已经不是三个巧合，而是《周易》自己对"艮在下"这个结构的固定读法。** 详见第四节。 |
| **大象传（行动纲领）** | 山上有木，渐。君子以居贤德善俗。 ⚠️ 版本待核（另有版本断作"君子以居贤善俗"） |
| **⚠️ "居贤德善俗"解（本卦最高层原则）** | **"居"＝安居、积蓄、日久而居之（不是"当"，是"住在里面"）。"贤德"＝贤良之德。"善俗"＝使风俗变好。**<br>**全句：君子把贤德一点点积住，让风气一点点变好。**<br>**⚠️ 这一条纲领的关键在于它给的两个动作都是"不可加速"的**：德不能一夜积成，俗不能一天改掉。**山上的树没有别的长法。**<br>**操作含义（渐卦最高层的三句话）**：<br>① **你能控制的只有"每天加一寸"这个动作本身，不能控制它什么时候显效**；<br>② **"善俗"是外部效果，它一定滞后于"居贤德"这个内部动作**——**所以在渐卦里，看不到效果是正常的，不是失败信号**（九五"妇三岁不孕"就是这一条的爻级形态）；<br>③ **纲领里没有任何一个字与"速度"有关，也没有任何一个字与"结果"有关。** |
| **总铁律** | ① **每走一级，先在这一级停住**（下卦艮）——**渐的操作定义就是"进一步，止一下"**；<br>② **看不到效果是渐卦的常态**（九五"妇三岁不孕，终莫之胜，吉"）——**空窗期本身不是坏消息，换赛道才是**；<br>③ **唯一的凶在九三，凶的内容是"该止的那一级没止住"**（"夫征不复"）——**渐卦的全部风险集中在一格**；<br>④ **不许诺"亨"**（卦辞）——**按台阶走不等于路会为你加速**；<br>⑤ **落点不是"到顶"，是"成为法度"**（上九"其羽可用为仪"、彖传"可以正邦")——**渐卦的收成是你走出来的那条路，不是你站到的那个位置。** |

## 二、爻级字段

> ⚠️ **本卦六爻是一条水鸟上岸的完整台阶序列**：**干（水边的岸）→ 磐（大石）→ 陆（平地）→ 木（树上）→ 陵（丘陵高地）→ 陆（高平之地）**。
> **"鸿"＝大雁（鸿雁），水鸟；"渐"在爻辞里就是"一级一级往上迁"这个动作。**
> **⚠️ 关键前提：鸿是水鸟。它离水越远，越不在自己的元素里。** 这一条决定了整个序列的吉凶逻辑——**不是"越高越好"，而是"每一级都得有落脚点"。** 九三（完全离水的平地，无水无掩护）是唯一的凶，六四（树上，水鸟根本不该栖木）靠"或得其桷"才勉强无咎。

### ⚠️ 核心清单：每一级台阶该做什么

| 级 | 落点 | 这一级的地形性质 | **这一级唯一该做的一件事** | 判词 |
|---|---|---|---|---|
| **初六** | **干**（水边的岸） | 离水最近，随时能退回去；但已经上岸了，会被看见 | **忍受被质疑。** "小子厉，有言"——被年轻人轻视、被议论，是入场费。**不解释、不反击、也不退回水里。** | **无咎** |
| **六二** | **磐**（大石） | 第一块真正能站住的实地（当位·得中） | **把吃饭这件事做稳，而且"不素饱"。** 建立可持续的现金流／基本盘，并且确保它是你干出来的，不是白拿的。 | **吉** |
| **九三** | **陆**（平地） | **已完全离水，无水、无掩护、无退路**（艮之顶＝该止之地） | **停在这里巩固，绝不继续往前征。** 对外只做一件事：**"御寇"（防守），不主动出击。** | **凶** ／ **利御寇** |
| **六四** | **木**（树上） | **水鸟根本不该待的地方**，本无处落脚（乘刚） | **找到"桷"——一根能落脚的平枝。** 在不属于你的场合里，**找一个具体、可栖、够窄的支点**（一个明确的职责、一个具体的交付物），不要试图整体适应。 | **无咎** |
| **九五** | **陵**（丘陵高地） | 高而稳，视野开阔（当位·得中·居尊） | **接受"三岁不孕"的空窗期，不换赛道。** 高位上最难的一关是长时间没有产出，**而爻辞说"终莫之胜"——没人能压过你。** | **吉** |
| **上九** | **陆**（高平之地） | 到顶（⚠️ 与九三同字，见下） | **把自己的"羽"交出去当"仪"。** 不再往上，转而把自己走过的路变成别人的标准／样板／规程。 | **吉** |

> ⚠️ **关于九三与上九同为"陆"字的著名异文**：**通行本九三、上九爻辞皆作"鸿渐于陆"。** 因鸿雁不可能从"木"（六四）、"陵"（九五）再退回平地，自程颐、胡瑗以下多有主张上九当作"**逵**"（音同"陸"之古读，义为云路、天路）者。**本卡照录通行本"陆"字**，并把这处异文本身当成一条信息：**同一个"陆"，在九三是凶（离水太远而无所归），在上九是吉（走完全程而成法度）。若通行本无误，则《周易》正是要用同一个地名说明——地方没变，你变了。**
> ⚠️ 版本待核：上九"陆"字之异文（"逵"）。

### 初六 · 鸿渐于干

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸿渐于干，小子厉，有言，无咎。 |
| **象传** | 小子之厉，义无咎也。 |
| **位属性** | 阴爻居阳位，**不当位**（艮在下 → 初不当位）；居全卦最下；不得中 |
| **判词 → 行动语义** | **厉（警告，非判死） ＋ 无咎** → **被质疑是正常的，忍住就没有灾** |
| **关键词解** | **干**（gān）＝水涯、岸边（一说通"岸"）——**刚上岸的第一步，离水最近**。**小子**＝年幼者、见识浅者。**厉**＝危、有压力。**有言**＝有议论、有闲话（本库已有的"有言"用例：明夷初九"主人有言"）。**义无咎也**＝**按道理是没有灾的**（"义"＝理当、按道理）。 |
| **⚠️ 象传多了一个字，全爻的重量都在这个字上** | 爻辞说"无咎"，象传说"**义**无咎也"——**多了一个"义"字。**<br>**按本库口径，"无咎"常是"善补过才没灾"；但"义无咎"是另一档：不是你补过补得好，而是"按道理本来就不该有灾"。**<br>**含义：初六被"小子"轻视、被人议论，这件事本身不是你的过失，你不需要为它做任何补救动作。**<br>**这一条极实用——它把"入场时被质疑"从"我做错了什么"改判为"这一级台阶的固有属性"。** |
| **识别信号（诊断清单）** | ① 你刚进入一个新的圈子／单位／行业，位置在最边缘；② 已经有人（往往是资历比你浅、或位置比你低的人）公开表示不服、看不上、或觉得你不该来；③ 你身后有议论，而且这些议论你听得见；④ 你正在两种冲动之间摆动：**要么正面解释／证明自己，要么干脆退回原来的地方。** |
| **该做** | **① 什么都不做，把这一轮议论过去。** 象传已经判了"义无咎"——**这不需要处理。**<br>**② 保持离水近。** 初六在"干"上，随时能退回水里——**在这一级上不要烧掉退路、不要押上全部身家。**<br>**③ 把注意力放到下一级台阶的"磐"上**：找那块能真正站住的实地（六二的"饮食衎衎"）。 |
| **不该做** | ① **不要解释、不要正面回应"小子"**——回应等于承认这是一件需要处理的事；② **不要为了止住议论而加速**（跳到九三就是凶）；③ **不要退回水里**——退回去这一级还得重走。 |
| **与需卦初九、明夷初九的三方对照** | **需初九"需于郊，利用恒，无咎"，象传"不犯难行也"**——在最远处等着，不冒险前进；<br>**明夷初九"明夷于飞，垂其翼。君子于行，三日不食，主人有言"**——该走就走，且走得难看、还被主人说闲话；<br>**渐初六"鸿渐于干，小子厉，有言，无咎"，象传"义无咎也"**——刚上岸就被议论，按道理无灾。<br>**三个初爻都出现了"外界的负面反应"，处理方式一致：不辩解。**<br>**但三者的性质不同**：需初九是**还没开始**（不犯难行）；明夷初九是**正在撤离**（于行）；**渐初六是刚刚开始，且《周易》专门用"义"字告诉你这不是你的过错。** |

### 六二 · 鸿渐于磐（⚠️ 全卦条件最好的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸿渐于磐，饮食衎衎，吉。 |
| **象传** | 饮食衎衎，不素饱也。 |
| **位属性** | 阴爻居阴位，**当位且得中**（艮在下 → 二当位得中）；与九五相应——**位置条件全卦第一** |
| **判词 → 行动语义** | **吉** → **把基本盘做稳、做实，并确保它是你挣来的** |
| **关键词解** | **磐**（pán）＝大石、磐石——**第一块真正能站住的实地**。**衎衎**（kàn kàn）＝和乐、从容自得之貌。**饮食衎衎**＝吃喝从容和乐。**素**＝空、白（如"素餐"＝白吃饭）；**不素饱**＝**不是白吃饱的**。 |
| **⚠️ 象传给了本卦最实用的一条自查标准："不素饱也"** | **爻辞只写了一个安逸的画面（吃喝从容），象传立刻加了一条限定：不是白吃的。**<br>**这五个字把"六二很舒服"和"六二很稳"区分开了**：<br>**同样是"饮食衎衎"，如果是白拿的（素饱），它就不是磐石，是别人的桌子。**<br>**⚠️ 自查题（可直接用）：你现在的基本盘，如果去掉某一个人的关照、某一个平台的流量、某一层关系，还剩多少？**<br>**剩下的那部分才是"磐"。** |
| **识别信号（诊断清单）** | ① 你在新的地方站住了：有稳定的活干、有可预期的收入、被当成"这儿的人"；② 你不再需要每天证明自己该不该在这儿；③ 你开始有余力和从容感（衎衎）；④ **同时你心里有一个隐约的问题：这份稳当，有多少是我自己挣的？**<br>⑤ **典型的下一步冲动：既然站住了，就该往前推一大步了。** |
| **该做** | **① 先答完"不素饱"这道题。** 把基本盘里"靠人给的"和"靠自己挣的"分开列出来，**把靠自己那部分做厚。**<br>**② 享受这一级。** 六二是全卦条件最好的一爻（当位、得中、有应），**判词就是干净的"吉"，没有任何附加条件——本库里这种爻不多，在这一级上不需要提防什么。**<br>**③ 但绝不因为"很稳"就跨到九三。** 九三是全卦唯一的凶，**而通向它的诱因恰恰是六二的舒服。** |
| **不该做** | ① 把"舒服"当成"稳"（素饱之病）；② 用这块磐石去换一个更高的位置——**九三就在上面一格，且是凶**；③ 反过来，也不要因为"怕九三"就永远待在六二**不再往上**：渐卦的落点在上九，六二只是第二级。 |
| **与需卦九五、小畜九五的对照（"饮食"与"不独富"）** | **需九五"需于酒食，贞吉"**——上岸之后以酒食待人，守正则吉；<br>**小畜九五"有孚挛如，富以其邻"**，本库读为"**不独富**"——有了积蓄要带上邻居；<br>**渐六二"饮食衎衎"，象传"不素饱也"**——**吃得从容，但不能是白吃的。**<br>**三处都写"吃"，管的却是三件事**：**需九五管"吃的时候分给谁"，小畜九五管"富了带谁"，渐六二管"这口饭是谁挣的"。**<br>**合读：本库"饮食"这一组的完整口径是——① 来源要正（渐六二）；② 有了要分（小畜九五）；③ 分的时候要节制（需九五）。** |

### 九三 · 鸿渐于陆（⚠️ 全卦唯一的凶，也是全卦唯一的风险格）

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸿渐于陆，夫征不复，妇孕不育，凶。利御寇。 |
| **象传** | 夫征不复，离群丑也。妇孕不育，失其道也。利用御寇，顺相保也。 |
| **位属性** | 阳爻居阳位，**当位**（艮在下 → 三当位）；**居下艮之顶——按本库口径这正是"该止之地"**；不得中；本库通则"**三多凶**"；**是下卦唯一的阳爻，即"止"的力量本身所在** |
| **判词 → 行动语义** | **凶**（周易所有结局中最坏的） ／ **利御寇**（可行·有益） → **停止前进，转为防守** |
| **关键词解** | **陆**＝平地、陆地——**完全离水了**。**夫征不复**＝丈夫出征而不回来（"征"＝远行、出征、主动进取）。**妇孕不育**＝妇人怀孕而不能生养。**御寇**＝抵御外来的侵犯。**离群丑**＝离开了自己的同类（"丑"＝类、群类；"群丑"＝同类之群，非贬义）。**顺相保**＝顺着（各安其位）互相保全。 |

#### ⚠️ 专项：为什么全卦的凶只有这一格，而且落在一个"当位"的爻上

| 核实项 | 结论 |
|---|---|
| 九三的位属性好不好？ | **好。阳爻居阳位，当位。** 它是下卦唯一的阳爻，**是"艮"这个止之卦的那个阳，即"止"的力量本身。** |
| 那凶从哪来？ | **不从位来，从动作来。** 爻辞里的动作词是"**征**"（出征、往前推）。**九三站在艮之顶——按本库口径这是"该止之地"；它却"征"了。**<br>**所以：渐九三的凶＝该止的那一级没有止住。** |
| 象传怎么解释？ | 两条理由，一条比一条硬：<br>**① "离群丑也"——离开了自己的同类。** 鸿是水鸟，"陆"是完全离水的平地：**没有水、没有掩护、没有同类。**<br>**② "失其道也"——失掉了它的道。** 注意这四个字管的是"妇孕不育"：**怀上了却生不出来——投入已经发生，产出不会到来。** |
| 这一爻有解药吗？ | **有半条：利御寇。** 象传给的机制是"**顺相保也**"——**各守其位、互相保全。**<br>**即：这一格不许进攻，只许防守；防守是"利"的（有益、可行）。** |

| 字段 | 内容 |
|---|---|
| **⚠️ "夫征不复，妇孕不育"是一组极精确的现代诊断** | **《周易》在这里用两句话写了同一件事的两半**：<br>**"夫征不复"＝往外投出去的那一部分（人、钱、时间、精力）不回来了**；<br>**"妇孕不育"＝已经在孕育的那一部分，生不出来。**<br>**合起来：外部投入沉没 ＋ 内部产出流产。这就是"跳级"的标准账面。**<br>**而两句话的共同原因只有一个：位置离你的水太远了。**<br>**现代原型**：跳到一个自己没有根基、没有同类、没有支援的位置上——**新行业里没有一个同行朋友，新公司里没有一个能替你说话的人，新业务里没有一样是你原来会的。** 在这种位置上，**投出去的收不回来，做起来的交付不出去。** |
| **识别信号（诊断清单）** | ① **你刚刚（或正准备）跨过一级或几级**：位置、层级、领域、地域，至少有一样跳了；② **环境里没有你的同类**——没人跟你一个背景、一个专业、一个来路（"离群丑"）；③ **已经有投入出去而收不回来**：垫的钱、派出去的人、答应了的交付、说出去的话；④ **手上有一件"怀上了但生不出来"的事**：立了项做不完、招了人带不动、签了约交不了；⑤ **你的判断是"再往前一点就打通了"。** |
| **该做** | **① 立刻停止"征"。** 这一格的动作只有一个方向被许可：**守。**<br>**② 转为"御寇"，且只做御寇。** 具体化：**只处理"别人打进来"的事（守住已有客户、已有职责、已有边界、已有现金），不处理"我要打出去"的事。**<br>**③ 执行象传的"顺相保"——回到同类里去。** 找回你的"群丑"：原来的同行、原来的专业圈、原来能替你说话的人。**"离群丑"是病名，"相保"是药。**<br>**④ 承认"妇孕不育"这笔账。** 已经流产的项目要销账，**不要再往里追投——那是"夫征"的另一种形式。** |
| **不该做** | ① **不要用"再推一把就通了"来解释**——爻辞已经把结果写成"不复"和"不育"；② **不要因为自己"当位"（名分是正的、资格是够的）就觉得安全**——**九三是当位的，还是凶**；③ 不要主动出击去挣回沉没成本（"征"）；④ 不要一凶就全撤——**"利御寇"说明这一格是可以守住的，撤等于把六二那块磐石也丢了。** |
| **⚠️ 与乾卦九四的正面对照（本卡最重要的一组跨卦）** | **乾九四"或跃在渊，无咎"，象传"进无咎也"**——本库读为"**不进则死，只能进**"，是乾卦风险最高的一爻，且**不可长留**。<br>**渐九三"鸿渐于陆…凶。利御寇"，象传"离群丑也／失其道也／顺相保也"**——**只能守，不能进。**<br>**两爻是本库最干净的一对反向指令**：<br>**同样是"上行序列里的那道生死关口"，乾卦的答案是"只能进"，渐卦的答案是"只能守"。**<br>**差别的机械原因**：**乾是纯阳无止，九四之下没有任何"止"的结构，所以停下来就被吃掉，只能赌一把往上跃；渐的下卦就是艮（止），九三本身就是那个"止"的阳爻，所以它的正确动作是行使自己的卦德——止。**<br>**⚠️ 由此得出一条可入库的通则：一个上行序列的关口该"进"还是该"守"，不看你有多少实力，看这个序列内部有没有"止"的结构。有止则守，无止则只能进。** |
| **与师卦六三、否卦六三的对照（"三多凶"三例）** | **师六三"师或舆尸，凶"，象传"大无功也"**——无实力者抢了指挥权；<br>**否六三"包羞"，象传"位不当也"**——闭塞之世，位不当而受辱；<br>**渐九三"鸿渐于陆…凶"，象传"离群丑也"**——**有实力、且当位，却离开了自己的同类。**<br>**⚠️ 这是本库"三多凶"组里第一个"当位而凶"的样本。** 前两例都可以用"位不当"解释，**渐九三不能——它当位。**<br>**结论：三爻之凶有两种来源——一种是"你不该在这个位置上"（师六三、否六三），一种是"你在正确的位置上做了错误的动作"（渐九三）。后者的解药在你手上，前者不在。** |

### 六四 · 鸿渐于木（⚠️ 全卦唯一的乘刚）

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸿渐于木，或得其桷，无咎。 |
| **象传** | 或得其桷，顺以巽也。 |
| **位属性** | 阴爻居阴位，**当位**（巽在上 → 四当位）；本库通则"**四多惧**"；**⚠️ 六四直接压在九三之上——乘刚，且是全卦唯一的一处乘刚**（交界型：下艮之顶为阳、上巽之底为阴） |
| **判词 → 行动语义** | **无咎** → **在不属于你的场合里，找一个具体、够窄的落脚点** |
| **关键词解** | **木**＝树、树上——**⚠️ 鸿是水鸟，蹼足，本不能栖木**。**或**＝或许、偶然（表示不确定，不是必然能得到）。**桷**（jué）＝方形的椽子，此处指**树上那种平直、能落脚的枝干**。**顺以巽也**＝顺从而巽入（"巽"既是上卦之名，又训"顺、入、谦退"）。 |
| **⚠️ 本爻的全部机制：一个"不该在这儿的人"如何无咎** | **六四的处境是全卦最尴尬的**：<br>**① 它在"木"上——水鸟栖树，根本不是自己的元素；**<br>**② 它乘刚——直接压在九三这个阳爻上，被下方的阳刚顶迫；**<br>**③ 它在"四多惧"的位置上。**<br>**但它得了"无咎"。凭什么？凭两个字："桷"和"巽"。**<br>**"桷"是一根平的枝**——**在整棵不适合你的树上，找到一处恰好能落脚的地方。** 注意爻辞用了"**或**"字：**不保证有，需要找。**<br>**"顺以巽也"是象传给的方法**——**顺着、退让着、往里嵌进去，而不是改造那棵树。**<br>**⚠️ 这正好命中本库规格第 4 节关于乘刚的破解条文**：「乘刚的破解：① 艮六四"止诸躬"——把范围收回到自己这一身；② 巽六四"田获三品"——交付可分配的实际成果。」<br>**渐六四是第三种破解：找一个具体的落脚点（桷），并以"巽"（顺入）的方式待在上面。** 三者是同一个策略的三个剂型——**都是把范围缩到一个具体、可控、够窄的东西上。** |
| **识别信号（诊断清单）** | ① 你在一个客观上不适合你的位置／场合／团队里（专业不对口、风格不合、来路不同）；② 下面有一股实实在在的力量在顶你——具体的人、既成的事实、原有的规矩（乘刚）；③ 你既不能走（走了这一级还得重走），也不能整体适应；④ 你正在两种冲动之间：**要么改造整棵树（推翻现有规矩），要么整体假装自己适合（全面伪装）。** |
| **该做** | **① 找"桷"，一根就够。** 具体化：**在这个不适合你的场合里，找出一件"只有你能干、且他们确实需要"的具体事**——一个职责、一个交付物、一份数据、一门手艺。**把自己完全放在这一件事上。**<br>**② 用"巽"的姿态待着**（顺、退、嵌入），**不改造、不评论、不推翻。**<br>**③ 接受"或"字。** 桷不是一定有的，**找不到就先不落脚（继续悬着），也不要随便踩一根撑不住的枝。** |
| **不该做** | ① **不要整体适应**——水鸟变不成雀鸟，"或得其桷"只要求你找到一处落脚点，不要求你成为树上的动物；② **不要因为乘刚的顶迫而向下发力**（跟九三较劲），六四的方向是"顺以巽"，不是往下压；③ 不要把"无咎"当成"吉"——**按本库口径，无咎只是没灾，六四这一级的任务就是"平安通过"。** |
| **⚠️ 与艮六四、巽六四的三方对照（"乘刚破解"三例，本库现已齐全）** | | 

| 爻 | 爻辞 | 判词 | 象传 | 破解的动作 | 破解的类型 |
|---|---|---|---|---|---|
| **艮 52 六四** | 艮其身 | **无咎** | 止诸躬也 | **把范围收回到自己这一身** | 收缩到"自身" |
| **巽 57 六四** | 田获三品 | **无咎** | 有功也 | **交付可分配的实际成果** | 收缩到"成果" |
| **渐 53 六四** | 鸿渐于木，或得其桷 | **无咎** | 顺以巽也 | **找一根能落脚的平枝** | 收缩到"一个支点" |

| 字段 | 内容 |
|---|---|
| **⚠️ 三例对照的结论（建议入库）** | **三个六四全部乘刚，全部得"无咎"，全部靠"把范围缩小到一个具体的东西上"来破解。**<br>**而且三者的收缩对象恰好构成一条完整的梯度：自身（艮）→ 成果（巽）→ 支点（渐）。**<br>**可提炼为一条通则：乘刚（被下方的既成力量顶迫）不能靠向下压制破解，只能靠"缩小自己的作用面"破解——把责任范围、交付范围、立足范围三者之一收窄到一个别人无法争议的点上。**<br>**⚠️ 反面样本**：本库尚未出现"乘刚而向下反压"得吉的爻。**注意渐六四的上卦正是巽——它的破解方式（顺以巽也）与巽六四同源，这不是巧合。** |

### 九五 · 鸿渐于陵（⚠️ 全卦最需要耐心的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸿渐于陵，妇三岁不孕，终莫之胜，吉。 |
| **象传** | 终莫之胜，吉，得所愿也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位（巽在上 → 五当位得中）；与六二相应——**位置条件与六二同为全卦最好** |
| **判词 → 行动语义** | **吉**（附带一个漫长的条件） → **接受空窗期，不换赛道** |
| **关键词解** | **陵**＝丘陵、高地（比"陆"更高，且是能栖息的高处）。**三岁不孕**＝三年没有怀上（"三岁"在《周易》中常表"长久"，非确指三年；对照丰上六"三岁不觌"、既济九三"三年克之"）。**终莫之胜**＝**最终没有什么／没有谁能胜过它**（"莫之胜"＝没有能压过它的）。**得所愿**＝得到了所愿求的。 |
| **⚠️ 本爻是大象传"居贤德善俗"的爻级形态** | **九五的位置条件是全卦最好的（当位、得中、居尊、有应），判词也是"吉"。但爻辞在"吉"之前塞进了一句极冷的话："妇三岁不孕。"**<br>**这句话的功能是给"吉"标注价格：这一级的吉，价格是一段很长的、看不到产出的时间。**<br>**⚠️ 而象传的处理方式很值得注意：它完全没有解释"三岁不孕"，只把后半句拿出来重申一遍——"终莫之胜，吉，得所愿也。"**<br>**《周易》在这里的态度是：空窗期不需要解释，也不需要处理；它就是这一级的地形。**<br>**这正是大象传"居贤德善俗"的机制——德要"居"（住进去、积住），俗要"善"（一点点变好），两者都必然滞后。九五就是滞后期本身。** |
| **⚠️ "终莫之胜"三个层次的读法** | ① **最直接的一层**：最终没有谁能压过你。**九五当位得中居尊，且下有六二正应——它的结构是全卦最硬的，只是慢。**<br>② **对"三岁不孕"的回应**：**空窗期不构成失败**，因为"胜负"不在这三年里结算。<br>③ **⚠️ 最有价值的一层（与彖传呼应）**：彖传说"**动不穷也**"——**渐的运动不会穷尽。"终莫之胜"就是"动不穷"在九五的形态：只要那个一寸一寸的动作还在，就没有东西能把你压过去。** |
| **识别信号（诊断清单）** | ① 你已经到了高位／进入了核心／拿到了资格，位置和名分都是正的；② **但已经有很长一段时间没有可交付的成果、没有新的进展、没有外部认可**（三岁不孕）；③ 周围（或你自己）开始怀疑这条路是不是错了；④ 有一个更快的替代方案在诱惑你：换赛道、换行业、换打法、换一个能立刻出成绩的位置；⑤ 你的基本盘其实没有动摇——**收入、职责、关系都在，只是"没有新的"。** |
| **该做** | **① 什么都不换。** 九五的任务不是产出，是**待住**。<br>**② 把"三岁不孕"写进预算。** 明确地给自己一个"不问产出"的期限，**并把这段时间的评价标准从"出了什么"改成"每天有没有加那一寸"**（大象传"居贤德"）。<br>**③ 维持与六二的连接。** 六二是你的正应，也是那块磐石——**高位上的空窗期，靠基本盘养着，不靠新故事养着。**<br>**④ 记住"终莫之胜"是给这一爻的判语，不是给你的安慰**：它说的是结构上没人压得过你，**前提是你还在这条序列上。换赛道就等于退出这个结论的适用范围。** |
| **不该做** | ① **不要为了结束空窗期而制造成果**（临时立项、买增长、包装数据）——那是把九五降回九三的"征"；② 不要把"三岁不孕"读成"这条路错了"；③ 不要因为焦虑而向下抢六四、六二的活干（越位）；④ **也不要把"终莫之胜"当成可以躺着**——"莫之胜"的主语是那只还在渐的鸿。 |
| **⚠️ 与全库"五爻专题"的对照（居尊者的第 N 种功课）** | 本库已有：**乾九五**（居尊而利见大人／持续纳新）、**坤六五**（有君之权而守臣节）、**蒙六五**（居尊而不失赤子之心）、**离六五**（居尊而痛哭）、**艮六五**（居尊而闭嘴）、**师六五**（选对人然后放手）、**震六五**（只守本职）、**巽九五**（前后各留三日申命）、**履九五**（位正当反而厉）、**兑九五**（把孚收回来）、**咸九五**（居尊而感不到）、**泰六五**（居尊而主动下嫁，元吉）、**否九五**（居尊而"其亡其亡"）。<br>**渐九五补上新的一种：居尊而长期没有产出。** 而它要主动放弃的特权是——**"我在这个位置上，就得不断有新东西拿出来"这个执念。**<br>**⚠️ 注意它与否九五的分工**：**否九五在最坏的时候要"其亡其亡"（时刻念着要完了）；渐九五在最好的位置上要接受"三岁不孕"（时刻接受没动静）。** 一个是逆境里的警惕，一个是顺境里的耐心，**《周易》给尊位安排的两副药，方向正好相反。** |

| **⚠️ 象传"不可乱也"是全卦的封印** | **象传没有夸奖上九，它下了一条禁令：不可乱。**<br>**乱什么？——乱这个次序。**<br>**全卦六爻是一条严格的台阶（干→磐→陆→木→陵→陆），上九走完了全程，所以它的"羽"才配当法度；而这条法度的内容恰恰就是"次序不可打乱"。**<br>**⚠️ 于是渐卦形成一个完美的闭环：卦德是"循序"，最高一爻的价值是"成为法度"，而这条法度的内容就是"循序"本身。**<br>**这也是渐卦对九三那个凶的最终解释：九三之凶（跳级）与上九之吉（成为法度），是同一条规则的两面。** |
| **识别信号（诊断清单）** | ① 你已经走完了一条完整的路径，位置、资历、成绩都在；② 你面前已经没有下一级台阶了（或有，但代价与收益明显不成比例）；③ 开始有人来问你"当初是怎么走的"；④ 你有两种冲动在拉扯：**要么再往上冲一格（但上九已经不当位了），要么就此收着、什么也不留。** |
| **该做** | **① 把"羽"交出去。** 具体化：**把你走这条路的完整步骤显性化——写下来、教出去、变成规程／课程／带出来的人。**<br>**② 守住"不可乱也"。** 你交出去的不只是经验，**是"次序"**：**明确告诉后来者哪一级不能跳（尤其是九三那一级）。**<br>**③ 停在这里。** 上九已经不当位——**渐卦允许你走到顶，但不允许你在顶上继续"渐"。** |

**渐卦三句话**：
1. **渐不是慢，是"进一步、止一下"。** 慢的来源是下卦艮（止），不是上卦巽（顺）——**内部有止的机制，外部才显得顺**（彖传"止而巽，动不穷也"）。
2. **全卦的风险只有一格：九三。** 内容是"该止的那一级没止住"，账面是"夫征不复（投出去的收不回）＋妇孕不育（做起来的交付不出）"。**这一格当位、有实力，照样凶。**
3. **落点不是到顶，是成为法度。** 上九的价值不在它站到了哪儿，在"其羽可用为仪"——**你走通的次序变成了别人的标准，而这条标准的内容就是"不可乱"。**

**本卦最反直觉的三条**：
- **全卦唯一的凶落在一个"当位"的爻上（九三，阳居阳位）。** 本库"三多凶"的前两个样本（师六三、否六三）都可以用"位不当"解释，**渐九三不能。结论：在正确的位置上做错误的动作，一样凶——而这种凶的解药在你手上。**
- **九五位置条件全卦最好，爻辞却塞进"妇三岁不孕"。** 而象传对这句话完全不作解释，只重申"吉"。**《周易》的态度是：高位上的长期空窗不需要被解释，它就是这一级的地形。**
- **渐的上爻是吉，乾的上爻是悔——而两者位属性完全相同（阳居阴位、不当位、不得中）。** 差别只在：**渐把"止"分摊到了每一级，走到顶时止已用完六次；乾从头到尾没有止，所以只能盈到不可久。**

## 四、⚠️ 本卦对全库的意义

### 1. 乾／渐：本库唯一的一组"上行序列正面对照"

《周易》里以一条连贯意象贯穿六爻的卦极少。已完成卡中有三条：**艮 52 的身体序列（趾→腓→限→身→辅→敦）、咸 31 的身体序列（拇→腓→股→［心］→脢→辅颊舌）**，以及**乾 01 的六龙序列（潜→见→惕→跃→飞→亢）**。**渐 53 的鸿雁序列（干→磐→陆→木→陵→陆）是第四条，而它是唯一一条与乾的六龙可以逐位对齐的上行序列**——两者都在讲"一个人怎么一级一级往上走"。

逐位对照见上一节的表。**从表里读出来的三条结论：**

> **① 关口的位置不同，而且指令相反。**
> **乾的关口在九四**（"或跃在渊"，本库判为"不进则死、只能进、不可长留"）；**渐的关口在九三**（"凶。利御寇"，只能守）。
> **关口往下移了一格，而且答案从"只能进"翻成了"只能守"。**
> **机械原因**：**乾是纯阳，九四之下没有任何"止"的结构，停在那儿就被吃掉，所以只能赌一把；渐的下卦就是艮，九三本身就是那个"止"的阳爻，它的正确动作是行使自己的卦德。**
> **⚠️ 可入库通则：上行序列的关口该"进"还是该"守"，不看实力多少，看序列内部有没有"止"的结构。有止则守，无止则只能进。**

> **② 结局相反，而位属性完全相同。**
> 乾上九与渐上九**都是阳爻居阴位、都不当位、都不得中**，一个"有悔"（盈不可久也），一个"吉"（其羽可用为仪，不可乱也）。
> **彖传与象传在这里正面对话**：渐彖传"**动不穷也**" ／ 乾上九象传"**盈不可久也**"。
> **《周易》在此明说：让运动能持续的不是动力，是内部的止。**
> **⚠️ 对规格第 3 节"上爻限定"补一条：一个卦的上爻能得吉还是只能得代价，取决于这个卦有没有把"止"内置在序列里。内置了（艮、渐），上爻是收成；没内置（乾），上爻只能是代价。**

> **③ 渐比乾"温和"，代价是渐不许诺"元亨"。**
> **六爻判词密度对比**：乾六爻无一"吉"字（勿用／利见大人／厉无咎／无咎／利见大人／有悔，"吉"只出现在用九"群龙无首"）；**渐六爻有三个"吉"（六二、九五、上九）。**
> 但**乾卦辞是"元亨利贞"四德俱全，渐卦辞只有"女归吉，利贞"——无元、无亨。**
> **合读：乾给你四德，但六爻一路凶险且必以亢终；渐不给你启动力与通达，但给你三个吉和一个能收成的顶。**
> **⚠️ 这是《周易》一次极清楚的定价：爆发力与稳定结局，是两笔不同的买卖。**

### 2. ⚠️ 新增结构律：覆卦（倒转卦）的当位分布必然完全互补

**渐（53）与归妹（54）是一对覆卦**，机械核对：

- **渐**六爻自下往上：**阴 阴 阳 阴 阳 阳**（下艮上巽）
- 整卦上下颠倒：**阳 阳 阴 阳 阴 阴** ＝ **归妹**（下兑上震）✓

**而两卦的当位分布是这样的：**

| | 初 | 二 | 三 | 四 | 五 | 上 | 当位数 |
|---|---|---|---|---|---|---|---|
| **渐 53** | 不当 | **当·中** | **当** | **当** | **当·中** | 不当 | **4** |
| **归妹 54** | **当** | 不当·中 | 不当 | 不当 | 不当·中 | **当** | **2** |

**4 ＋ 2 ＝ 6。逐位完全互补，一处不差。**

> **⚠️ 这不是巧合，而是可机械证明的必然：**
> **爻位的阴阳由位序奇偶决定（初三五为阳位，二四上为阴位）。倒转后，第 i 位变成第 7−i 位，而 i 与 7−i 的奇偶必然相反；同时那一爻本身的阴阳不变。**
> **所以：原卦每一个"当位"的爻，在覆卦里必然"不当位"，反之亦然。**
> **推论 A：任何一对覆卦的当位数之和恒为 6。**
> **推论 B：得中（二、五）在倒转下互换（二↔五），所以"得中"保留，但"当位"翻转——于是一对覆卦里，必然一卦的两个中位全部当位，另一卦的两个中位全部不当位。**

**用本库已有卡回溯验证：**

| 覆卦对 | 当位数 | 两个中位 |
|---|---|---|
| **咸 31（上兑下艮）** | **4** | 六二当位得中、九五当位得中 |
| **恒 32（上震下巽）** | **2** | 九二不当位得中、六五不当位得中 |
| **渐 53（上巽下艮）** | **4** | 六二当位得中、九五当位得中 |
| **归妹 54（上震下兑）** | **2** | 九二不当位得中、六五不当位得中 |
| **丰 55（上震下离）** | **4** | 六二当位得中、六五不当位得中 ⚠️ 见下 |
| **旅 56（上离下艮）** | **2** | 六二当位得中、六五不当位得中 ⚠️ 见下 |

> ⚠️ **丰／旅这一对需要特别注意，它正好暴露了推论 B 的适用条件**：丰六二当位得中、丰六五不当位得中；旅六二当位得中、旅六五不当位得中。**看起来推论 B 失效了？没有——因为丰的"二"倒转后变成旅的"五"，丰的"五"倒转后变成旅的"二"。** 逐位核对：**丰二（当）↔ 旅五（不当）✓；丰五（不当）↔ 旅二（当）✓。** 完全成立。**推论 B 的准确表述应是：一对覆卦中，一卦的二爻当位则另一卦的五爻不当位，一卦的五爻当位则另一卦的二爻不当位。**（咸／恒、渐／归妹恰好是"两中位同当／同不当"的类型，丰／旅是"交叉"的类型。）

> **⚠️ 这条结构律的实操价值（这才是重点）**：
> **它说明"当位多"和"当位少"从来不是运气，而是一对卦被设计出来的分工。**
> **渐是"该慢慢来"的那一卦——四当位、两中位全当位，阶梯每一级都站得住，所以《周易》许诺"进得位，往有功也"。**
> **归妹是"已经将错就错了"的那一卦——只有两当位、两中位全不当位，所以彖传直接把卦辞的凶归因于结构："征凶，位不当也。无攸利，柔乘刚也。"**
> **两卦是同一个卦形的正反两面：把一条"每级都站得住的阶梯"上下颠倒，就得到一个"每个中位都站不住的处境"。**
> **这为本库"渐／归妹"这一对提供了最硬的结构根据：不是两个题目，是同一个卦形的两种朝向。**

### 3. "艮在下"的第三次经文背书：彖传"止而□"的固定句式

本库规格第 4 节有一条：「**艮在上＝被压住不许动**」「**艮在下**」→ 咸卡已从彖传"止而说"拿到背书。**加上本卦与旅卦，这个句式已经出现三次，且三卦全部是"艮在下"：**

| 卦 | 卦象 | 彖传原句 | 上卦之德 | 全句给出的机制 |
|---|---|---|---|---|
| **咸 31** | 上兑下艮 | **止而说** | 兑＝悦 | 自己先止住，对方才会愉悦 |
| **渐 53** | 上巽下艮 | **止而巽，动不穷也** | 巽＝顺／入 | 内有止，所以动起来不会穷 |
| **旅 56** | 上离下艮 | **止而丽乎明** | 离＝明／丽 | 止住自己，附丽于外面的光明 |

> **⚠️ 结论（建议补入规格第 4 节）**：**"艮在下"这个结构，《周易》自己有固定读法，句式是"止而＋上卦之德"。**
> **含义：艮在下不是"你被卡住了"，是"你的内部先止住，然后才能与外部那个德发生关系"。**
> **三卦给出三种外部之德，对应三种关系**：**止而悦（咸：建立关系）｜止而顺入（渐：一级一级上行）｜止而附丽于明（旅：在别人的地盘上借光）。**
> **而"止"这个动作在三卦里完全相同——先收自己的手。**
> **反向的价值更大**：**如果你的处境里"止"这一步没做，那么无论上卦是什么德，都不成立**——咸就变成"来兑"（讨好，凶），渐就变成"夫征不复"（跳级，凶），旅就变成"旅琐琐"（计较小事，取灾）。**三卦的凶，全部是"没止住"的三种形态。**

### 4. 渐卦补上的三个缺口

| 缺口 | 渐卦补的内容 |
|---|---|
| **本库有"怎么停"（艮 52），没有"停完之后怎么重新走"** | **序卦传的转接说得极直白："物不可以终止，故受之以渐。"** 而渐的答案不是"重新加速"，是**把"止"改造成节奏**——下卦仍然是艮。**渐＝把一次性的止，改成每一级都止一下。** |
| **本库的上行路径只有乾（01）一条，而乾必以"亢"终，对绝大多数人不适用** | **渐提供了第二条上行路径，且它是可以吉终的。** 代价是无元、无亨（不许诺爆发力与通达）、且中间有一格硬凶（九三）。**本库从此可以在"我想往上走"这个高频困境上给两条路，而不是一条。** |
| **"乘刚破解"只有两例（艮六四、巽六四），不足以立通则** | **渐六四补上第三例（或得其桷，顺以巽也），三例的收缩对象构成完整梯度：自身 → 成果 → 支点。** 可提炼通则：**乘刚只能靠"缩小自己的作用面"破解，不能靠向下反压。**（本库至今没有一例"乘刚而向下反压"得吉的爻。） |
| **路由表缺两条高频困境** | ① **"我知道该怎么做，问题只是想快一点"**——这是渐卦的标准入口，本库现有各卦都答不了；<br>② **"我在最好的位置上，但已经很久没出成绩了"**——**渐九五给的答案是"妇三岁不孕，终莫之胜，吉"：接受空窗，绝不换赛道。** 而象传对空窗期不作任何解释——**这本身就是答案。** |
