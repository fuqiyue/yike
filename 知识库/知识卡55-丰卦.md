# 知识卡 55 · 丰卦（雷火丰）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："得其所归者必大，故受之以丰。丰者，大也。"——**归妹（54）讲的是"有所归"，一旦归定、结构成立，接着必然做大**，所以转入丰。**注意这条转接的冷酷：《周易》认为"大"不是努力挣来的，而是"归定"之后自然发生的后果。**
> **⚠️ 下一条转接更狠**：**"穷大者必失其居，故受之以旅。"**——**把"大"做到穷尽的人，必然失去他的住处。** 而丰卦最后一爻正是"**丰其屋**"（把房子盖到极大）。**《周易》用序卦传把丰上六与旅卦直接扣在了一起：房子盖到最大的那一刻，你就成了没有住处的人。**
> **本卦与旅卦（56）是一对覆卦（上下颠倒）**：丰六爻自下往上"阳阴阳阳阴阴"，整卦颠倒即得旅"阴阴阳阳阴阳"（上离下艮）。**丰＝丰大，旅＝客居；一个是"房子越来越大"，一个是"没有自己的房子"。必须合读。**
> ⚠️ **本卡的三个重点**：
> **① 彖传"日中则昃，月盈则食"是全书对"巅峰即转折"最直白的一句**，且它紧接在卦辞"勿忧，宜日中"之后——**卦辞叫你别忧、要像正午的太阳，彖传立刻说正午之后就是偏斜。**
> **② 上六"丰其屋，蔀其家，窥其户，阖其无人，三岁不觌，凶"是全库讲"巅峰的危险"最狠的一爻**：房子越盖越大，家里却没人了。**逐条对照乾上九、泰上六见第四节。**
> **③ 本卡新增一条结构事实：乘刚的第三个来源是离。** 咸卡（31）已把"乘刚的来源"从震扩到兑，**本卦把它补齐为一条完整的机械律**（见第四节）。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 丰 · 第五十五卦 |
| **卦象** | 上震（雷／动／威）下离（火／电／明），称"雷火丰"。**大象传取的是"雷电皆至"**——**⚠️ 请注意这四个字**：噬嗑卦（21，上离下震）的大象传是"**雷电**"两个字，**本卦是同样的两个字加上"皆至"。** 同样的雷与电，噬嗑是分着来，丰是**一起到**。**"皆至"就是"丰"（大）在取象上的定义：不是某一样特别强，是几样同时到位。**<br>**按本库第 4 节结构律，本卦的当位分布是全确定的，且本卡逐爻验证如下**：<br>**离在下 → 三爻全当位**：初九（阳居阳位）✓、六二（阴居阴位，且得中）✓、九三（阳居阳位）✓；<br>**震在上 → 四五不当、上当位**：九四（阳居阴位，不当）✓、六五（阴居阳位，不当，但得中）✓、上六（阴居阴位，当位）✓。<br>**⚠️ 结果：六爻四当位（初、二、三、上），下卦三爻全部当位。**<br>**这是本库"离在下 → 三爻全当位"这条结构律的又一个样本**（已有样本：离 30 的下卦、贲 22、明夷 36；反向样本：噬嗑 21 与大有 14 的离在上 → 三爻全不当位，本批的旅 56 亦然）。<br>**⚠️ 乘刚两处**：**六二乘初九**（离在下的底部型乘刚，**本卡新增的结构来源**）、**六五乘九四**（震在上的底部型乘刚，规格第 4 节原有条文）。 |
| **⚠️ 结构与卦德的对应（本卦最重要的一次结构解释）** | **下卦三爻全部当位、上卦只有一爻当位——这个分布本身就是"丰"的图像：**<br>**底盘（离，你的能力与见识）三层全部站得住，所以能做大；上层（震，动与权势）却只有最顶上一爻站得住，所以做大之后的位置全都不正。**<br>**⚠️ 落到现代：丰卦的处境是"我的本事和判断力都对得上（下三爻当位），但我坐上去之后的这些位子都不太对（九四、六五不当位）"。**<br>**这就解释了为什么丰卦的爻辞里"蔀"（遮蔽）出现三次，而且全部在上半段之后——遮蔽不是从底盘来的，是从"位置越坐越不正"来的。** |
| **领域定义** | **巅峰期本身，以及巅峰期的具体作业**。① 公司／团队最好的那一两年（增长最快、声量最大、人最多）；② 个人影响力、收入、话语权同时到位的时期；③ 一个项目最风光的阶段（资源全给、人人看好）；④ 家庭最富足的阶段（房子最大、开销最大）；⑤ 一个人同时握有判断力与执行权的短暂窗口（离＝明，震＝动，两者"皆至"）。<br>**⚠️ 凡是"我现在处在最好的时候，而我隐约觉得不对劲"，都落在丰卦。**<br>**⚠️ 特别地，凡是"要清旧账、断积压的是非、执行早该执行的处罚"，也落在丰卦——这是大象传指定的动作。** |
| **不归本卦的情况** | ① 上下通达、氛围好，但重点是"怎么维护这条通道" → **泰卦（11）**；② 已经到顶且已开始衰，重点是"怎么退、怎么舍" → **乾上九 / 剥卦（23）**；③ 有明察之力但没有执行权，只能立规矩 → **噬嗑卦（21）**；④ 有明察之力但被明令禁止判人 → **贲卦（22）**；⑤ **没有自己的地盘、寄居在别人处** → **旅卦（56，本卦之覆）**。<br>**⚠️ 与泰卦的分界最要紧**：**泰问的是"上下通不通"，丰问的是"你还看得见吗、家里还有人吗"。** 一个组织可以完全"通"而同时正在"蔀"。 |
| **"丰"字本义** | **丰＝大、盛大、丰满**（彖传第一句就训："丰，大也"）。字形取草木繁盛、器皿盈满之象。<br>**⚠️ 但本卦的用法极特别：爻辞里"丰"字四见，全部是动词——"丰其蔀"（六二）、"丰其沛"（九三）、"丰其蔀"（九四）、"丰其屋"（上六）。**<br>**"丰其X"＝把X做大。而《周易》让它做大的四样东西是什么？蔀（遮蔽物）、沛（帷幔）、蔀（遮蔽物）、屋（房子）。**<br>**⚠️ 四次"丰其"，三次丰的是遮蔽物，一次丰的是房子。没有一次丰的是"明"。**<br>**这就是丰卦对"做大"的定义：做大的从来不是你看得见的能力，是挡在你和世界之间的那一层。** |
| **卦辞原文** | 丰：亨，王假之，勿忧，宜日中。 |
| **⚠️ 卦辞的关键结构** | **只有"亨"；无元、无利、无贞。然后给了一个人物（王假之）、一条禁令（勿忧）、一条条件（宜日中）。**<br>**缺"元"**：丰不需要启动力——**按序卦传，"大"是"得其所归"之后自然来的，不是你发动的。**<br>**缺"利"**：**丰不许诺好处。** 这一点极重要：**你到了最盛的时候，《周易》不说你会得利。**<br>**⚠️ 缺"贞"（最关键的一处缺失）**：**丰卦通篇没有"贞"字。**<br>**对照师卦（07）：师卦辞只有一个"贞"，本库读为"天道对战争不许诺任何好处，只给一条师出有名的底线"。**<br>**⚠️ 丰卦恰好相反：只有"亨"（路是通的）而没有"贞"（没给守正的许诺，也没提守正的要求）。**<br>**含义：巅峰期的问题不在"你正不正"。你完全可以是正的、能干的、当位的（下三爻全当位），照样走到上六的"阖其无人"。丰卦的危险与品德无关，与结构和时间有关。**<br>**多了"勿忧"**：**一条明确的禁令——不要忧虑。**<br>**多了"宜日中"**：**一条时间条件——应当在正午。而"正午"只有一瞬。** |
| **⚠️ 卦辞与彖传的正面对撞（本卦全部张力的来源）** | **卦辞："勿忧，宜日中。"**（别忧虑，要像正午的太阳）<br>**彖传紧接着："日中则昃，月盈则食。"**（正午之后就偏斜，满月之后就亏食）<br>**⚠️ 《周易》在同一卦的卦辞与彖传里，先叫你别忧、要做正午的太阳，再告诉你正午之后必然偏斜。**<br>**唯一自洽的读法是：**<br>**"勿忧"管的是"丰"这件事本身——它是真的、是"亨"的，不要疑心它、不要因为它太好而不安、也不要为了保住它而缩手。**<br>**"宜日中"管的是"你只有这一瞬"——正午的意义不是"最高"，是"能照到所有地方"（彖传自注："宜照天下也"）。**<br>**⚠️ 合起来就是丰卦的作业指令：不要忧虑它会过去（那是必然的，忧虑没用）；要在它还在的这一瞬，把光照到所有该照的地方。**<br>**这解释了大象传为什么给的是"折狱致刑"——趁着还看得见（离＝明）、还动得了（震＝威），把积压的是非全部结清。** |
| **卦辞现代解** | **亨**——这条路是通的，你现在的盛大是真实的，不是虚的。<br>**王假之**——"假"（gé）＝至、到达；**最高决策者亲自到场／亲自达成**。落到现代：**这个盛大是"顶格"的，它需要也配得上最高层级的亲自介入。**<br>**勿忧**——**不要忧虑。** 具体：**不要因为"太顺了心里发慌"而缩手，也不要为了保住它而提前收缩。**<br>**宜日中**——**应当像正午一样，把光照到所有地方**（彖传："宜照天下也"）。**而正午只有一瞬，所以这是一条时间指令，不是一条状态描述。** |
| **彖传** | 丰，大也。明以动，故丰。王假之，尚大也。勿忧宜日中，宜照天下也。日中则昃，月盈则食，天地盈虚，与时消息，而况于人乎？况于鬼神乎？ ⚠️ 版本待核（末二句"而况于人乎？况于鬼神乎？"各本文字略异） |
| **⚠️ 彖传要点（本卦的机制全在这三处）** | ① **"明以动，故丰"（丰的生成公式）**——**下离是"明"（看得清），上震是"动"（动得了）；明在前、动在后，所以能大。**<br>**⚠️ 这是本库"上下卦读法"句式的又一个样本**：咸"止而说"、渐"止而巽"、恒"巽而动"、旅"止而丽乎明"、**丰"明以动"**。<br>**丰的公式最短也最实用：看得清 ＋ 动得了 ＝ 做得大。**<br>**反过来读更有用：只要这两样里少一样，"丰"就不成立。而丰卦六爻的全部麻烦，就是"明"这一半被"蔀"（遮蔽）掉了——三次"丰其蔀"、三次"日中见斗／见沬"，全是"明"的失效。**<br>**⚠️ 所以：丰卦不会因为你"动不了"而衰，只会因为你"看不见"而衰。**<br>② **"勿忧宜日中，宜照天下也"**——**彖传自己给"宜日中"下了定义：正午的意义是"照天下"（照到所有地方），不是"站在最高处"。**<br>**这一句把整卦的落点从"高度"改成了"覆盖面"。落到现代：巅峰期该做的不是继续往上，是把光打到每一个还黑着的角落——积压的问题、被忽略的人、没人愿意碰的旧账。**<br>③ **⚠️ "日中则昃，月盈则食，天地盈虚，与时消息"（全书对"巅峰即转折"最直白的一句）**——**太阳到了正午就开始偏斜（昃），月亮圆满了就开始亏食；天地都在盈与虚之间，随着时间一消一长。**<br>**⚠️ 请注意它的精确之处：转折点不在"太阳落山"，在"正午"那一刻。盛与衰之间没有平台期，最高点本身就是转折点。**<br>**"而况于人乎？况于鬼神乎？"——连天地鬼神都逃不掉，何况人。这是《周易》少见的、把话说尽的语气。** |
| **大象传（行动纲领）** | 雷电皆至，丰。君子以折狱致刑。 |
| **⚠️ "折狱致刑"解（本卦最高层原则，也是全库最出人意料的一条纲领）** | **折狱**＝断案、判决讼案（"折"＝断、裁断）。**致刑**＝施行刑罚（"致"＝施、加）。<br>**⚠️ 为什么一个讲"盛大"的卦，行动纲领是"断案与执刑"？**<br>**因为这是唯一一个"明"与"威"同时在手的时刻**——**下离是明（看得清、断得准），上震是威（打得响、执行得动），大象传说"雷电皆至"（两样一起到）。**<br>**⚠️ 断案需要"明"，执刑需要"威"。绝大多数时候你只有一样：**<br>**只有明而无威 → 贲卦（22，上艮下离）："明庶政，无敢折狱"——只能处理小事，不许判人；**<br>**只有威而明在外 → 噬嗑卦（21，上离下震）："先王以明罚敕法"——只能事先把罚则挂出来，属于制度层；**<br>**明与威皆至 → 丰卦："君子以折狱致刑"——可以断，也可以执行。**<br>**⚠️ 结论（丰卦最实用的一条）：巅峰期正确的动作不是扩张，是清账。** 具体化：**把积压的是非断掉、把早该处理的人和事处理掉、把一直没人愿意碰的旧账结掉。**<br>**⚠️ 理由是时间性的：这些事只能在"雷电皆至"的窗口里做，而彖传已经说了这个窗口就是"日中"——一瞬。窗口过去以后，你就只剩明或者只剩威，两样都不够。**<br>**⚠️ 而这一条纲领恰恰是上六那个凶的解药**：上六的病是"丰其屋"（把房子盖大）；大象传的药是"折狱致刑"（把账清掉）。**同样的巅峰期，一种用法是盖房子，一种用法是清账；前者的结局是"阖其无人，凶"。** |
| **总铁律** | ① **丰的公式是"明以动"**（彖传）——**看得清 ＋ 动得了；两样缺一样，丰就不成立**；<br>② **"丰"与"蔀"同步生长**（六二、九四、上六三次"蔀"）——**你做大的从来不是明，是挡在你和世界之间的那一层**；<br>③ **转折点在"日中"本身，不在日落**（彖传"日中则昃"）——**盛与衰之间没有平台期**；<br>④ **巅峰期的动作是清账，不是扩张**（大象传"折狱致刑"）——**因为"明与威皆至"只有这一瞬**；<br>⑤ **唯一逆转"蔀"的动作是"来章"**（六五）——**把有光的人招进来**；<br>⑥ **一开始就要守住"旬"（均等）**（初九"虽旬无咎，过旬灾也"）——**超过均等就有灾**；<br>⑦ **最重的一爻是上六：房子盖到最大，家里没人了。** 而它是**当位**的——**正当性不能替代内容。** |

## 二、爻级字段

> ⚠️ **本卦六爻是一条"遮蔽逐级加厚、最后把人自己遮没"的序列，而中间被六五打断了一次。**
> **"丰其"四见（六二蔀、九三沛、九四蔀、上六屋）｜"蔀"三见（六二、九四、上六）｜"日中见星"三见（六二见斗、九三见沬、九四见斗）。**
> **⚠️ "日中见斗／见沬"是全书最精确的一个意象：正午时分看见了星星——不是天黑了，是你和光之间多了一层东西。而看见的星越小（斗＝北斗大星 → 沬＝小星），说明天越黑、遮得越厚。**
> **序列**：**初九（守均等）→ 六二（蔀·见斗，用孚破）→ 九三（沛·见沬，最暗，不可大事）→ 九四（蔀·见斗，遇夷主则吉）→ 六五（来章·招光，唯一的逆转）→ 上六（丰其屋·阖其无人，凶）。**

### 初九 · 遇其配主

| 字段 | 内容 |
|---|---|
| **爻辞** | 遇其配主，虽旬无咎，往有尚。 |
| **象传** | 虽旬无咎，过旬灾也。 |
| **位属性** | 阳爻居阳位，**当位**（离在下 → 三爻全当位）；居全卦最下；不得中；与九四敌应（同性）——**⚠️ 而爻辞里的"配主"通行解正指九四** |
| **判词 → 行动语义** | **无咎**（有条件） ／ **往有尚** → **与对等的那一方保持均等，不要超过** |
| **关键词解** | **配主**＝与自己相配的那个"主"（对等的一方；通行解指九四，与初九同为阳爻，故为"配"而非"应"）。**旬**＝**均、等同**（一说训"十日"，即一个周期）。**虽旬无咎**＝**虽然彼此均等，也没有灾**。**往有尚**＝前往有嘉尚、值得称许（"尚"＝嘉、崇）。**过旬灾也**＝**超过了均等，就有灾。** |
| **⚠️ 象传给了本卦第一条铁律，而且是唯一一条带"灾"字的** | **爻辞说"虽旬无咎"，象传立刻补上反面："过旬灾也。"**<br>**⚠️ 全卦六爻只有这一处出现"灾"字，而它管的事是"要不要超过对等的那一方"。**<br>**读法：在"丰"（做大）刚开始的时候，你遇到了一个和你势均力敌的人（配主）。**<br>**"虽旬无咎"——保持均等，没有灾。这个"虽"字很有意思：它承认"均等"让人不舒服（你会觉得应该分出高下），但《周易》说这样没有灾。**<br>**"过旬灾也"——一旦你要超过他，就有灾。**<br>**⚠️ 为什么？因为丰卦的公式是"明以动"，而"明"最先失效的地方就是"我要压过他"这个念头。** 你一旦开始比，注意力就从"照天下"（彖传）转到了"照过他"，**遮蔽（蔀）就是从这里开始长的。** |
| **⚠️ 与乾用九"群龙无首"的呼应** | **乾用九"见群龙无首，吉"，象传"天德不可为首也"**——本库读为：**不把自己放在唯一至高的主宰位置；各在其位、各尽其能、互不争强。**<br>**丰初九"虽旬无咎，过旬灾也"**——**保持均等则无灾，超过均等则有灾。**<br>**⚠️ 两处讲的是同一件事，但位置完全不同**：**乾用九是对整卦的升华（写在六爻之外，是给九五和上九的校验项）；丰初九把它放在了最下面一爻——做大的第一步。**<br>**合读结论：本库"不独尊"这条线索至此有了两端——乾用九告诉你到顶之后要"无首"，丰初九告诉你一开始就不要"过旬"。** |
| **识别信号（诊断清单）** | ① 你正处在一段快速做大的开头：资源开始进来、事情开始有声量；② 环境里有一个和你分量相当的人／团队／对手（配主）——同级、同期、同赛道；③ 你已经开始把"我要不要压过他"当成一个真问题；④ 你的判断是"这个阶段必须分出高下，否则将来不好办"；⑤ 你能明确说出"如果我超过他会有什么好处"，但说不出"如果我们保持均等会有什么坏处"。 |
| **该做** | **① 保持"旬"（均等）。** 具体化：**不去争排名、不去抢同一个位置的独占权、不去做"把他挤掉"的动作。**<br>**② 往前走（"往有尚"）。** 注意爻辞是允许你进取的——**它禁止的不是"往"，是"过旬"。** 往你自己的方向走，不往他的位置上走。<br>**③ 把注意力放回"照天下"**（彖传）——**在这个阶段该看的是还有哪些地方没照到，不是那个人有多高。** |
| **不该做** | ① 不要在做大的开头处理高下问题——**"过旬灾也"是全卦唯一的"灾"字**；② 不要因为"必须保持均等"就不动（爻辞明说"往有尚"）；③ 不要把"配主"当对手看——**"配"是相配，不是相敌。** |

### 六二 · 丰其蔀（⚠️ 全卦第一次"蔀"，也是唯一给出解药的遮蔽爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 丰其蔀，日中见斗，往得疑疾。有孚发若，吉。 |
| **象传** | 有孚发若，信以发志也。 |
| **位属性** | 阴爻居阴位，**当位且得中**（离在下 → 二当位得中）；与六五敌应（同性）；**⚠️ 六二直接压在初九之上——乘刚**（离在下的底部型乘刚，**本卡新增的结构来源，详见第四节**） |
| **判词 → 行动语义** | **吉**（附一个明确的条件：有孚发若） → **用诚信把局面打开，不要往前推进** |
| **关键词解** | **蔀**（bù）＝**覆盖物、遮蔽物**（一说指草席之类的遮蔽；一说指"蔀"为日食之蔽）。**丰其蔀**＝**把遮蔽物做大／遮蔽变得很厚**。**日中见斗**＝**正午时分看见了北斗星**（斗＝北斗，大星）。**疑疾**＝猜疑之病、被猜忌。**孚**＝诚信（本库"孚"字专题：需卦、坎卦、兑九二、兑九五"孚于剥"、大壮初九"其孚穷也"）。**发若**＝启发、发动的样子（"若"为语助）。**信以发志**＝**用诚信去启发（对方的）心志。** |
| **⚠️ "丰其蔀，日中见斗"是全书最好的一个"看不见"的意象** | **六二的条件是全卦最好的一批（当位、得中，且在离＝明的中心）。它本该是最亮的一爻。**<br>**⚠️ 但爻辞说它"丰其蔀"（遮蔽变厚）、"日中见斗"（正午看见星星）。**<br>**这不是天黑了——正午的太阳一直在那里。是你和太阳之间多了一层东西。**<br>**⚠️ 落到现代的原型（极精确）**：**在组织最盛的时候，你处在中层的核心位置（当位得中），本该是信息最灵通的地方，结果你发现自己反而看不清了**——**汇报被层层加工、真话到不了你这儿、你听到的都是筛过的。这就是"丰其蔀"：组织越大，你和事实之间的层数越多。**<br>**而"日中见斗"精确地描述了这种状态的诡异感：环境明明是最好的时候，你却在看星星导航。** |
| **⚠️ "往得疑疾"：这一爻明确禁止前进** | **"往"＝前往、往前推进。"得疑疾"＝招来猜疑之病。**<br>**⚠️ 为什么在遮蔽状态下前进会招猜疑？因为你看不清，别人也看不清你。** 在信息被遮蔽的环境里，任何主动的推进都会被解读成别有用心。<br>**所以六二的正确动作不是"冲破遮蔽"，而是绕过它——用"孚"（诚信）。** |
| **⚠️ 解药："有孚发若"，而象传把它翻译成"信以发志也"** | **爻辞给的动作是"有孚发若"（怀着诚信去启发），象传给的机制是"信以发志也"（用诚信去启发心志）。**<br>**⚠️ 这是全卦唯一一处给出"破蔀"办法的地方，而办法不是"更努力地看"，是"让对方愿意告诉你"。**<br>**逻辑：遮蔽（蔀）是信息问题，而信息问题不能靠增加观察强度解决——层数还在。唯一的破法是让层里的人主动把真话交出来，而让人交真话的东西只有"孚"。**<br>**⚠️ 操作化（丰六二最实用的三条）**：<br>**① 不带评价地听一次。** 不追问、不反驳、不当场处理——**"发志"是让对方把心里的话发出来，任何评价都会把它按回去。**<br>**② 先给孚，不要先要信息。** 具体：**先明确告诉对方一件真实的、对你不利的事**（你的顾虑、你的失误、你不确定的地方）。<br>**③ 不要"往"。** 在拿到真实信息之前，不做任何推进动作（"往得疑疾"）。 |
| **识别信号（诊断清单）** | ① 组织／项目正处在最盛的阶段，你在核心位置上；② **你已经明确感觉到"我拿到的信息不是真的"**——汇报太漂亮、坏消息总是晚到、没人跟你说难听话；③ 你正准备主动推进一件事来"打开局面"；④ 你已经察觉到有人在猜疑你的动机（疑疾），或者你在猜疑别人的；⑤ **⚠️ 关键信号：你在用"经验和直觉"判断而不是用事实判断——这就是"日中见斗"（正午靠星星导航）。** |
| **该做** | ① **停止"往"**；② **给孚，然后听**（"有孚发若"）；③ **把"我看不见"这件事本身当成要处理的第一个问题**，而不是当成背景条件。 |
| **不该做** | ① 不要靠加大观察强度破蔀（多开会、多要报表、多做汇报要求）——**那是在加层，不是在减层**；② 不要在遮蔽中推进（往得疑疾）；③ 不要因为"我当位得中"就相信自己看得清——**六二正是当位得中的那一爻，它照样"日中见斗"。** |
| **⚠️ 与兑九二、需卦"孚"的对照（本库"孚"字专题）** | **兑 58 九二"孚兑，吉，悔亡"，象传"信志也"**——**以诚信而悦，吉**；<br>**兑 58 九五"孚于剥，有厉"**——**把诚信给了该剥落之人，即使位置完全正当，也有厉**；<br>**丰 55 六二"有孚发若，吉"，象传"信以发志也"**——**用诚信去启发对方的心志，吉。**<br>**⚠️ 兑九二象传作"信志也"（三字），丰六二象传作"信以发志也"（五字）——多了"以"和"发"两个字。**<br>**差别很实在：兑九二是"我以诚信待你"（状态）；丰六二是"我用诚信去把你的话引出来"（动作，有目的）。**<br>**合读：本库"孚"字的完整口径是——① 孚是悦的正确形态之一（兑九二）；② 孚不能给错人（兑九五"孚于剥"）；③ **孚在信息被遮蔽时是唯一的破法（丰六二）。**<br>**⚠️ 第三条是本卡新增的，也是"孚"第一次被用作"工具"而不是"品德"。** |

### 九三 · 丰其沛（⚠️ 全卦最暗的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 丰其沛，日中见沬，遇其夷主，无咎。 ⚠️ 版本待核（"沛"一作"旆"；"沬"一作"沫"） |
| **象传** | 丰其沛，不可大事也。遇其夷主，吉行也。 |
| **位属性** | 阳爻居阳位，**当位**（离在下 → 三当位）；不得中；居下离之顶；本库通则"**三多凶**"；与上六相应<br>⚠️ **不乘刚**（其下为六二，阴爻） |
| **判词 → 行动语义** | **无咎**（并附一条禁令：不可大事） → **不做大事，只与对等者同行** |
| **关键词解** | **沛**＝**帷幔、旗幔**（异文作"旆"，即大旗的垂幔）——**比"蔀"更大、更密的遮蔽物**。**沬**（mèi）＝**小星**（异文作"沫"）。**日中见沬**＝**正午看见了小星星。****夷主**＝**平等的主**（"夷"＝平；一说"夷主"即与自己平等相处的一方，与初九"配主"同类）。**不可大事**＝**不可以做大事。****吉行**＝行动是吉的、这条路走得通。 |
| **⚠️ 从"见斗"到"见沬"：《周易》用星星的大小标了遮蔽的厚度** | **六二"日中见斗"——正午看见北斗（大星）；**<br>**九三"日中见沬"——正午看见小星。**<br>**⚠️ 能看见的星越小，说明天越黑。所以九三比六二遮得更厚——而爻辞的用字也对上了：六二丰的是"蔀"（覆盖物），九三丰的是"沛"（帷幔，更大更密）。**<br>**⚠️ 这是一条极精细的经文设计：《周易》用两组词（蔀／沛、斗／沬）平行地标出了同一件事的两个刻度。**<br>**而象传给出的后果也随之加重：六二只是"往得疑疾"（前进会招猜疑），九三是"不可大事也"（大事根本不能做）。** |
| **⚠️ "不可大事也"是本卦对巅峰期的一条硬限制** | **九三是下离（明）的顶端、是本卦"明"的最后一爻，位置当位、力量是阳刚。它本该是最能干大事的一爻。**<br>**⚠️ 象传偏偏说"不可大事也"。**<br>**理由只能是遮蔽：明已经被"沛"厚厚地挡住了，而丰卦的公式是"明以动"（彖传）——明失效了，"动"就不再产生"丰"，只产生风险。**<br>**⚠️ 落到现代：在你判断力最强、位置最当位、最想干一票大的时候，如果你手上的信息是被过滤过的，那么"不可大事"——不是你不行，是你看不见。** |
| **⚠️ 解药："遇其夷主"，象传判"吉行也"** | **九三的解药与初九同源：找一个"对等的人"。**<br>**初九的是"配主"（相配的主），九三的是"夷主"（平等的主），九四的也是"夷主"。**<br>**⚠️ 全卦三次出现"对等的一方"（初九配主、九三夷主、九四夷主），而三次的结果分别是"无咎／无咎／吉"。**<br>**这是丰卦给出的第二条破蔀之法：既然你自己看不见，就找一个和你平等、不需要向你汇报、也不怕你的人。**<br>**⚠️ 关键在"夷"（平）字：不是找上级（他有自己的蔀），不是找下属（下属的话正是蔀的一部分），是找一个平等的人。**<br>**落到现代：在巅峰期，你唯一还能听到真话的渠道是同级／外部／没有利害关系的对等者。** |
| **识别信号（诊断清单）** | ① 你的能力和位置都在最好的状态（当位、阳刚、居下卦之顶）；② 你手上正有一件"大事"想做（大扩张、大并购、大改组、大押注）；③ **但你已经无法独立核实关键信息**——所有关键数据都经过别人的手；④ 你身边听到的意见高度一致；⑤ **⚠️ 关键信号：你已经很久没有和一个"不怕你、也不需要你"的人认真谈过这件事。** |
| **该做** | **① 不做大事。** 象传的"不可大事也"是这一爻唯一的禁令，也是最重的一条。**把大事拆成小事，或者推迟。**<br>**② 找"夷主"——一个真正对等的人，把这件事完整讲给他听。** 具体化：**同级同行、已经离开的老同事、外部顾问、不在你利益链上的朋友。** 判据只有一个：**他没有理由讨好你，也没有理由怕你。**<br>**③ 承认"见沬"这个事实**——你现在看到的是小星，不是太阳。 |
| **不该做** | ① 不要用"我判断力一向很准"来抵消"不可大事也"——**九三正是判断力最好的那一爻**；② 不要找上级或下属来核实（他们各有各的蔀）；③ 不要因为"不可大事"就什么都不做——**"遇其夷主"是被判为"吉行也"的，这一爻是有事可做的。** |
| **⚠️ 与咸九三、巽九三、恒九三的四方对照（"当位而受限"的四例）** | 咸卡（31）已列三例："**巽九三"频巽，吝"（志穷也）｜恒九三"不恒其德…贞吝"（无所容也）｜咸九三"咸其股，执其随，往吝"（所执下也）**"，三例全部当位、全部判"吝"，共同病根是"**当位之才用错了自己的刚**"。<br>**⚠️ 丰九三是这一组的第四例，但它不一样**：<br>**判词不是"吝"，是"无咎"；象传不是"志穷／无所容／所执下"，是"不可大事也"。**<br>**差别在于病根不同**：**前三例的病在"用错方向"（刚用去退让／断续／跟随）；丰九三的病在"看不见"（明被遮蔽）。**<br>**⚠️ 由此可以给那条诊断线索加一个分支：当位而事情做不动时，先分两种——**<br>**① 方向错了（刚用错了地方）→ 判"吝"，路越走越窄，解药是换方向；**<br>**② 信息不够（明被遮住了）→ 判"无咎＋不可大事"，解药是找对等的人核实。**<br>**两者的处理完全不同，误判的代价很大：把"看不见"当成"方向错"，就会去改方向；把"方向错"当成"看不见"，就会去找更多信息。** |

### 九四 · 丰其蔀（⚠️ 全卦位置最差的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 丰其蔀，日中见斗，遇其夷主，吉。 |
| **象传** | 丰其蔀，位不当也。日中见斗，幽不明也。遇其夷主，吉行也。 |
| **位属性** | 阳爻居阴位，**不当位**（震在上 → 四不当位）；不得中；本库通则"**四多惧**"；与初九敌应（同性）<br>⚠️ **不乘刚**（其下为九三，阳爻）；**但六五乘在它头上**（见下爻） |
| **判词 → 行动语义** | **吉**（条件：遇其夷主） → **承认自己在暗处，去找对等的人** |
| **关键词解** | **蔀 / 日中见斗**＝与六二同（遮蔽物、正午见北斗）。**夷主**＝平等的主（与九三同）。**位不当**＝位置不正当。**幽不明**＝**幽暗而不明亮**（"幽"＝暗）。 |
| **⚠️ 本爻是全卦象传信息量最大的一爻：三句话，三个判定** | **象传把爻辞切成三段，逐段下判——这是本库遇到的少数几处"三段分判"：**<br>**① "丰其蔀，位不当也"——遮蔽变厚的原因是位置不正当。**<br>**⚠️ 这一句极重要：六二也"丰其蔀"，象传没解释原因；九四同样"丰其蔀"，象传直接归因于"位不当"。**<br>**《周易》在此明说：遮蔽的来源之一是你坐的位置不对。**<br>**② "日中见斗，幽不明也"——正午看见星星，是因为幽暗而不明。**<br>**⚠️ 注意它不说"外面黑"，说的是"幽不明"（这个状态本身就是暗的）。对照六二：六二当位得中，它的"见斗"是被外面的层挡住；九四不当位，它的"见斗"是自己所处的位置本来就是暗的。**<br>**③ "遇其夷主，吉行也"——去找对等的人，这条路走得通。**<br>**⚠️ 与九三象传的后半句一字不差（"遇其夷主，吉行也"），说明这是《周易》在丰卦里反复给的同一味药。** |
| **⚠️ 九四与六二的对照：同样的"丰其蔀，日中见斗"，判词一个"吉"一个"吉"，机制完全不同** | | 

| 对照项 | **六二**（离在下） | **九四**（震在上） |
|---|---|---|
| 爻辞前半 | 丰其蔀，日中见斗 | 丰其蔀，日中见斗（**完全相同**） |
| 位属性 | **当位·得中**·乘刚 | **不当位**·四多惧 |
| 遮蔽的原因 | 象传未解释（在明的中心却被外层挡住） | **象传明判"位不当也"** |
| 暗的性质 | 外面加了层 | **"幽不明也"——所处的位置本身就是暗的** |
| 前进的后果 | **往得疑疾**（禁止前进） | 未提 |
| 解药 | **有孚发若**（用诚信让对方开口） | **遇其夷主**（去找对等的人） |
| 判词 | **吉** | **吉** |

| 字段 | 内容 |
|---|---|
| **⚠️ 这一组对照的结论（本卦最实用的一条诊断分流）** | **同样是"我在最盛的时候却看不清"，《周易》分了两种病因和两种药：**<br>**① 你的位置是对的，但信息被层层过滤（六二）→ 药是"孚"：让人愿意跟你说真话。**<br>**② 你的位置本身就不对（九四）→ 药是"夷主"：找一个位置之外的对等者。**<br>**⚠️ 分流的判据很实在：问自己"我这个位子该不该由我坐？"**<br>**该我坐而看不清 → 是信息问题，用孚破（六二）。**<br>**本来就不该我坐（临时顶上、破格提拔、名不正、职责重叠）→ 是位置问题，位置问题不能靠信息解决，只能靠外部对等者校准（九四）。**<br>**⚠️ 而两爻的判词都是"吉"——这说明在丰卦里，"看不清"本身不是败局，只要你用对了药。** |
| **识别信号（诊断清单）** | ① 你在一个盛大的组织／项目里，位置比较高但名分不正：临时负责、兼着、破格上来的、职责与别人重叠；② 你能感觉到"这个位置本身就是雾"——你不确定自己该管什么、该向谁交代、谁该听你的；③ 你是"四多惧"的典型状态：投入很大，位置很虚；④ 你上面有一个人压着你（六五乘刚），而你自己压不住下面的九三；⑤ 你正在考虑把位置坐实（要授权、要名分、要编制）。 |
| **该做** | **① 承认"位不当"，并且不把它当成要立刻解决的问题**——**⚠️ 注意：象传把它当成原因说明，不当成任务。九四的药不是"把位置搞正"，是"遇其夷主"。**<br>**② 去找"夷主"。** 与九三的动作完全相同：**找一个和你对等、不怕你也不需要你的人，把你的判断完整讲给他听。**<br>**③ 接受"幽不明"是这个位置的固有属性**，所以**在这个位置上不要相信自己的直觉判断，要相信外部校准。** |
| **不该做** | ① 不要用"把位置坐实"来解决看不清——**位置坐实需要时间，而丰卦的窗口只有"日中"一瞬**；② 不要向上（六五）或向下（九三）求证——**上面压着你，下面被你压着，两边给的都不是真话**；③ 不要因为"位不当"就自我否定——**判词是"吉"。** |

### 六五 · 来章（⚠️ 全卦唯一逆转"蔀"的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 来章，有庆誉，吉。 |
| **象传** | 六五之吉，有庆也。 |
| **位属性** | 阴爻居阳位，**不当位**，但**得中**且居尊位（震在上 → 五不当位而得中）；与六二敌应（同性）；**⚠️ 六五直接压在九四之上——乘刚**（规格第 4 节："**震在上则六五必乘刚**"） |
| **判词 → 行动语义** | **吉** → **把有光的人招进来** |
| **关键词解** | **来**＝**使之来、招来**（使动用法）。**章**＝**文采、彰明、光华**；引申为**有才华、能发光的人或事**（与"彰"同源）。**来章**＝**把"章"招来**。**庆**＝福庆、可庆之事。**誉**＝声誉。**有庆誉**＝有福庆也有声誉。 |
| **⚠️ 本爻是全卦的转折点，而它的动作只有两个字** | **前面四爻，"丰"的对象全是遮蔽物：蔀（六二）、沛（九三）、蔀（九四）。**<br>**⚠️ 六五第一次不"丰"任何东西，它"来"——把光招进来。**<br>**这是全卦唯一逆转"蔀"的动作，而且它极短：来章。**<br>**⚠️ 为什么解药落在六五（尊位）身上？因为前面三爻的遮蔽，都不是它们自己能解的：**<br>**六二当位得中而"日中见斗"（层不在它手里）；九三当位而"不可大事"（信息不在它手里）；九四不当位而"幽不明"（位置不在它手里）。**<br>**⚠️ 只有六五能"来章"——只有居尊者能决定让谁进来。** 这与师卦六五完全同构：**师六五自己不上战场，"它唯一的动作就是选谁，而这个选择决定全卦成败"。**<br>**丰六五也一样：它自己不发光（阴爻），它的动作是"让发光的人来"。** |
| **⚠️ 与乾九五"利见大人"的强呼应（本卡最重要的一组跨卦）** | **乾 01 九五"飞龙在天，利见大人"，象传"大人造也"**——本库读为：**"不再是求人提携，而是自己成为大人的同时，大量发掘人才共襄盛举"**；该做是"**不断吸纳新人、补充燃料**"，不该做是"**自满、独占、自毁长城；消灭所有大人、断绝新鲜血液**"。<br>**丰 55 六五"来章，有庆誉，吉"**——**把有光的人招进来。**<br>**⚠️ 两爻是同一条指令的两种写法，而且都在"五"这个尊位上，都是巅峰期。**<br>**⚠️ 但差别很关键：乾九五是阳爻当位得中（它自己就是光），所以它"利见大人"是锦上添花；丰六五是阴爻不当位（它自己不发光），所以"来章"是它唯一的活路。**<br>**合读结论：巅峰期的居尊者，无论自己亮不亮，动作都是同一个——把外面的光引进来。** |
| **⚠️ 与上六的因果关系（本卦最重要的一处爻间关系）** | **六五"来章"（招光进来）→ 吉。**<br>**上六"阖其无人"（门关着，里面没有人）→ 凶。**<br>**⚠️ 这两爻是紧挨着的，而它们的内容正好相反：一个是把人招进来，一个是里面一个人也没有。**<br>**《周易》把丰卦最后的分岔点放在了这里：巅峰期结束时你手上有没有人，取决于你在六五这一爻做没做"来章"。**<br>**⚠️ 而这条因果与乾卦完全一致：乾上九"亢龙有悔"的识别信号之一正是"外部不再有新鲜血液涌入"，而乾九五的该做正是"不断吸纳新人"。**<br>**两卦合读，本库可以下一条相当硬的通则：**<br>**「巅峰期的唯一保命动作是持续引入外部的光（人、观点、信息）；停止引入，上爻必坏。」**<br>**样本：乾九五（纳新）→ 乾上九（血液断绝，有悔）｜丰六五（来章）→ 丰上六（阖其无人，凶）。** |
| **识别信号（诊断清单）** | ① 你在一个盛大的局面里居于最高或次高位；② 你的名分其实不完全正（不当位），下面还有一股强力顶着你（乘刚：一个强势的九四）；③ 你自己不是那个"最会发光的人"，你的价值在于能决定谁进来；④ 你手上有名额、有预算、有邀请权、有推荐权；⑤ **⚠️ 关键信号：你已经很久没有引入过一个"比现有人更亮"的人——最近进来的都是听话的、熟悉的、好管的。** |
| **该做** | **① "来章"——引入比现有人更亮的人。** 具体化：**招一个比你现有团队最强者更强的人；请一个会当面反对你的顾问；引入一个外部的、不属于你体系的评审者。**<br>**② 用"庆誉"而不是"权"去招。** 爻辞的收益写作"有庆誉"（福庆与声誉）——**在丰卦，居尊者能给的最好东西是"让人有光可发"，不是位子。**<br>**③ 用"来章"替代"丰其蔀"。** 这是六五对整卦的责任：**前面三爻都在被遮蔽，只有你能让层变薄——办法是把新的光源放进来，不是去撤那些层。** |
| **不该做** | ① 不要只招"好管的人"——**那正是上六"阖其无人"的成因**；② 不要因为"我不当位"就不敢招比自己亮的人——**六五的判词是干净的"吉"，而它恰恰不当位**；③ 不要用位子去换忠诚（对照师上六"小人勿用，必乱邦也"）。 |
| **⚠️ 与本库"五爻专题"的对照** | 本库已有：乾九五（纳新）、坤六五（守臣节）、蒙六五（赤子之心）、离六五（居尊而痛哭）、艮六五（居尊而闭嘴）、师六五（选对人然后放手）、震六五（只守本职）、巽九五（前后各留三日申命）、履九五（位正当反而厉）、兑九五（把孚收回来）、咸九五（居尊而感不到）、泰六五（居尊而下嫁，元吉）、否九五（居尊而"其亡其亡"）、渐九五（居尊而长期无产出）、归妹六五（居尊而主动降格）。<br>**丰六五补上新的一种：居尊而把光招进来。**<br>**⚠️ 它与师六五是同一类型（尊位唯一的动作是"选谁"），但对象不同：师六五选的是"带兵的人"（能不能打），丰六五选的是"发光的人"（能不能照亮）。**<br>**⚠️ 而它与咸九五恰好互补：咸九五的病是"居尊而感不到"，药是"虚受人"（先腾空）；丰六五的病是"居尊而看不见"，药是"来章"（引外光）。一个向内腾空，一个向外引光。** |

### 上六 · 丰其屋（⚠️ 全库讲"巅峰的危险"最狠的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 丰其屋，蔀其家，窥其户，阖其无人，三岁不觌，凶。 |
| **象传** | 丰其屋，天际翔也。窥其户，阖其无人，自藏也。 |
| **位属性** | 阴爻居阴位，**当位**（震在上 → 上当位）；居全卦之终；与九三相应<br>⚠️ **不乘刚**（其下为六五，阴爻） |
| **判词 → 行动语义** | **凶**（周易所有结局中最坏的） → **此爻不可入；解药在六五（来章）与大象传（折狱致刑）** |
| **关键词解** | **丰其屋**＝把房子盖得极大。**蔀其家**＝**把家遮蔽起来**（"蔀"第三次出现，而这一次遮的是"家"本身）。**窥**＝从缝隙里往里看。**户**＝门。**阖**（hé）＝**闭、关**。**阖其无人**＝**门关着，里面没有人。****三岁**＝很长时间（对照渐九五"妇三岁不孕"）。**觌**（dí）＝**见**。**三岁不觌**＝**很长时间见不到（人）。****天际翔**＝**在天边飞翔**（形容屋宇高峻，直入天际）。**自藏**＝**自己把自己藏起来。** |

#### ⚠️ 专项：这一爻为什么是全库讲"巅峰的危险"最狠的一句

| 核实项 | 结论 |
|---|---|
| 它写了几个动作？ | **五个，而且是一条完整的镜头推移**：<br>**① 丰其屋**（房子越盖越大）→ **② 蔀其家**（家被遮住了）→ **③ 窥其户**（有人从门缝往里看）→ **④ 阖其无人**（门关着，里面一个人也没有）→ **⑤ 三岁不觌**（很长时间见不到人）。<br>**⚠️ 请注意视角的转换：前两句是从里面写（我在盖房子、我把家遮起来），后三句是从外面写（有人来看、门关着、很久没见）。** |
| 它凶在哪里？ | **不在房子坏了——房子好得不能再好（"天际翔也"，高到天边）。**<br>**凶在"无人"。**<br>**⚠️ 全卦的"丰"到这里达到顶点（屋是六爻里最大的一个"丰其"对象），而内容归零。** |
| 象传怎么判？ | **两句，一句比一句冷**：<br>**① "丰其屋，天际翔也"——象传没有批评盖房子，它只是形容：这房子高得像在天边飞。这是一句纯粹的客观描述，而客观描述在这里就是最重的判词。**<br>**② "窥其户，阖其无人，自藏也"——⚠️ 关键在最后三个字："自藏也"。**<br>**不是别人不来，是他自己把自己藏起来了。** |
| 那"凶"的责任在谁？ | **⚠️ 在他自己。"自藏"是主动的。**<br>**这是本爻最狠的一点：《周易》没有说"盛极而衰是天道，怪不得你"，它说"自藏也"——你自己关的门。** |
| 位属性给了保护吗？ | **没有。上六是当位的（阴爻居阴位）。**<br>**⚠️ 正当性不能替代内容——这与归妹上六（同为当位、同为凶、同为"形式在内容空"）完全一致。** |

| 字段 | 内容 |
|---|---|
| **⚠️ "丰其屋，蔀其家"六个字是全卦机制的最终揭示** | **前面"丰其蔀"（六二、九四）说的是"遮蔽物变大"，你还可以理解为外部的层。**<br>**上六把因果彻底写明了：丰其屋 → 蔀其家。**<br>**⚠️ 房子越大，家越被遮住。 不是两件事，是一件事的两面。**<br>**"屋"是外在的规模（房子、编制、体量、排面、声量）；"家"是里面真实的人和关系。**<br>**规模的增长本身就是对内容的遮蔽——这就是丰卦从头到尾在说的那件事，而它到最后一爻才把因果链完整地摆出来。**<br>**⚠️ 落到现代（原型极常见）**：<br>**公司总部越盖越气派，而能做决定的人一个也见不到；团队编制越扩越大，而没有一个人真正对结果负责；一个人的头衔越来越多，而没有一件事是他亲手做的；家里房子越换越大，而一年没有一次全家一起吃饭。**<br>**"窥其户，阖其无人"——有人来找你，门关着，里面没人。**<br>**"三岁不觌"——很长时间见不到你。** |
| **识别信号（诊断清单）** | ① 你（或你的组织）的外在规模处在历史最高：体量、编制、排面、声量、资产；② **有人想找你／找这个组织，但找不到能说话的人**——层级太多、流程太长、负责人永远在别处；③ **你自己已经很久没有直接见过关键的人**：一线的人、客户、合作方、家里人；④ 门是你自己关的（自藏）——你为了效率／为了专注／为了减少干扰，主动切断了直接接触；⑤ **⚠️ 最强的信号：你能列出一长串"规模指标"的增长，却说不出最近一次真实的、面对面的、有内容的接触是什么时候。** |
| **该做** | **⚠️ 按本库口径，"凶"级爻的正确读法是"不要走到这里"；这一爻的解药不在爻内，在两个地方：**<br>**① 六五的"来章"——把人招进来。** 上六是"阖其无人"，六五是"来章"；**这一爻的病，正是上一爻没做的那个动作。**<br>**② 大象传的"折狱致刑"——把巅峰期的力气从"盖房子"转到"清账"。** 大象传给的是丰卦唯一的正面纲领，**而它指定的动作恰恰不是扩张。**<br>**若已经在上六，唯一还能做的动作是：**<br>**③ 开门。** 具体化：**恢复至少一条直接接触的通道，且是你自己去接触，不是让人来找你**——**因为"自藏"是主动的，所以解除它也只能是主动的。** |

**丰卦三句话**：
1. **丰的公式是"明以动"（彖传），而丰卦从头到尾在坏的都是"明"这一半。** 六爻里"蔀"三见、"日中见星"三见——**你做大的从来不是能力，是挡在你和世界之间的那一层。** 上六把因果写全了：**丰其屋 → 蔀其家。**

**本卦最反直觉的四条**：
- **卦辞通篇没有"贞"字。** 对照师卦（只有"贞"），丰卦是"只有亨、没有贞"。**含义：巅峰期的危险与你正不正无关。** 下卦三爻（初九、六二、九三）全部当位，六二还当位得中——**它们照样"日中见斗""不可大事"。**
- **全卦唯一的"灾"字在最下面一爻**（初九"过旬灾也"），**内容是"不要超过和你对等的那个人"。** 危险不在顶上开始，在你第一次想分出高下的时候开始。
- **六二当位得中，处在"明"的正中心，偏偏"日中见斗"。** **位置越好、越靠核心，被过滤的信息越多。** 而解药不是"更努力地看"，是"孚"——让人愿意告诉你。

### 1. ⚠️ 补齐一条机械律：制造"乘刚"的三画卦是四个，分两型

规格第 4 节原有条文：「**乘刚的来源＝震**。震把阳放在最下往上顶，所以震在下则六二必乘刚，震在上则六五必乘刚。**艮把阳放在最上往下压，其内部不制造乘刚。**」
咸卡（31）已补充：「**制造乘刚的三画卦有两个——震与兑**。」

**本卦六二乘初九（离在下）暴露了第三个来源。逐卦机械核对如下（判据：三画卦内部有没有"阴爻直接压在阳爻之上"）：**

> **⚠️ 完整条文（建议整体替换规格第 4 节的"乘刚的来源"一条）**：
> **① 判据：一个三画卦制造内部乘刚，当且仅当它内部有一个阴爻直接压在一个阳爻之上。**
> **② 制造乘刚的三画卦有四个，分两型**：
> **底部型（震、离）**——阳在最下往上顶，**在下卦则六二乘刚，在上卦则六五乘刚**；
> **顶部型（坎、兑）**——阴在最上往下压，**在下卦则六三乘刚，在上卦则上六乘刚**。
> **③ 不制造乘刚的有四个：乾、坤（无对立爻）、艮（阳在顶，其上无爻）、巽（阴在底，其下无阳）。**
> **④ 另有一个原条文未涉及的来源：交界型乘刚**——**下卦最上一爻为阳、上卦最下一爻为阴时，六四乘九三。** 下卦顶为阳的是乾、艮、巽；上卦底为阴的是坤、艮、坎、巽。**本批的渐卦（53，下艮上巽）就是一个实例（六四乘九三，且是该卦唯一的乘刚）。**

**本卦的两处乘刚正好一型一例**：**六二乘初九**（离在下，底部型）、**六五乘九四**（震在上，底部型）。而**六二的判词是"吉"，六五的判词也是"吉"**——

> **⚠️ 一条重要的限定（防止把"乘刚"读成凶兆）**：**乘刚本身不是判词。** 本库已有的乘刚样本里，**兑六三"凶"、履六三"凶"、咸上六"无判词"、归妹六三"无判词"、归妹六五"吉"、丰六二"吉"、丰六五"吉"、渐六四"无咎"**。
> **结论：乘刚是一个处境描述（被下方的既成力量顶迫），它加大难度，不决定结果。** 决定结果的是这一爻做了什么——**而本库已有的三例"乘刚而得吉／无咎"（丰六二用孚、丰六五来章、渐六四得桷）都符合同一条规律：把作用面缩小，或者把外部的东西引进来，都不向下反压。**

### 2. ⚠️ 丰／噬嗑：同样两个三画卦的两种叠法，大象传给出两种司法权限

**丰（55，上震下离）与噬嗑（21，上离下震）是震与离的上下交换。两卦的大象传都是讲刑狱的，而权限完全不同：**

| | **噬嗑 21**（上离下震） | **丰 55**（上震下离） |
|---|---|---|
| 大象传取象 | **雷电**（两字） | **雷电皆至**（四字，多"皆至"） |
| 大象传主语 | **先王以**（制度层） | **君子以**（修身／在位者层） |
| 指定动作 | **明罚敕法**（把罚则事先挂出来、整饬法度） | **折狱致刑**（断案、施行刑罚） |
| 时态 | **事前**（罚之前必须先做完的事） | **当下**（趁窗口把积案结掉） |
| 结构 | 离在上 → **三爻全不当位**；震在下 → 初二当位、三不当（**2 当位**） | 离在下 → **三爻全当位**；震在上 → 四五不当、上当位（**4 当位**） |
| 彖传的机制句 | 颐中有物（有东西横在口中，必须咬掉） | **明以动，故丰**（看得清 ＋ 动得了） |

> **⚠️ 两条结论**：
> **① "雷电"这个取象由震与离共同构成，所以两卦共用它；而"皆至"两个字是丰卦独有的，它正是"丰"（大）的定义——不是某一样特别强，是几样同时到位。**
> **② 权限的差别由"明"在哪一半决定，但决定动作的是另一半。**
> **噬嗑的离在上（明在外，本库读为"名不正"）、震在下（动在自己手里）→ 只能"事前立法"，而且主语升到"先王以"（制度层）。**
> **丰的离在下（明在内，三爻全当位，判断力最实）、震在上（威在头顶）→ 可以"当场断案并执行"，主语是"君子以"。**
> **⚠️ 这印证并细化了规格第 4 节的两条**：**"离在上＝光在你身外（名不正）"**（所以噬嗑只能立规矩，不能判人）；**"离在下＝三爻全当位"**（所以丰的判断力是全卦最实的部分，可以断案）。
> **⚠️ 实操含义：一个人能不能"下判决"（处理人、定是非、执行处罚），取决于"明"在他自己身上还是在他身外。明在内可断，明在外只能立规矩。**（本库"明与狱"的四卦分级见旅卡 56 第四节，那里给出完整的四级表。）

### 3. ⚠️ "巅峰期"专题：本库三卦合读

**丰卦是本库第一张专讲"巅峰期本身"的卡。此前处理巅峰的资源分散在两处：**

| | **泰 11（顺境）** | **乾 01 九五→上九（鼎盛→亢）** | **丰 55（丰大）** |

| 关注的变量 | **交不交**（上下是否真实沟通） | **纳不纳新**（外部血液是否涌入） | **看不看得见 / 门里还有人吗** |
| 盛期纲领 | **裁成天地之道，辅相天地之宜**（顺境是治理期） | **利见大人**（持续纳新） | **折狱致刑**（清账） |
| 警告出现的位置 | **九三**（还很顺的时候）："无平不陂，无往不复" | **上九**："亢龙有悔·盈不可久也" | **彖传**（卦级）："日中则昃，月盈则食" |
| 崩塌的形态 | **城复于隍**（秩序垮了，政令乱） | **势尽而坠**（用尽了） | **阖其无人**（外在完好，人没了） |
| 崩塌后的出路 | **有**："自邑告命，贞吉" | **有**（若能退）：自谦、自亏、自舍 | **爻内没有**（解药在六五"来章"与大象传） |

> **⚠️ 三卦合读得出的三条**：
> **① 警告的位置一路提前。** 泰卦把警告放在九三（顺境还很顺的时候）；乾卦放在上九（已经亢了）；**丰卦放到了彖传——卦级，也就是"你还没开始读爻，先告诉你最高点就是转折点"。**
> **⚠️ 这说明《周易》认为"丰"（做大）比"泰"（通达）更危险：泰还允许你在九三才醒，丰在一开始就把话说尽了（"而况于人乎？况于鬼神乎？"）。**
> **② 三卦的盛期作业都不是扩张。** 泰是治理（裁、辅），乾九五是纳新，丰是清账（折狱致刑）＋引光（来章）。**本库由此可以下一条相当硬的通则：《周易》从不把"最好的时候"当成扩张的时候。**
> **③ 三种崩塌形态里，丰上六是唯一"外在毫无破损"的一种，也是唯一没有爻内出路的一种。**
> **原因在象传的三个字："自藏也"——主体已经不在场了，所以没有人可以执行任何解药。**
> **⚠️ 由此可为本库补一条诊断题（外部视角，本库此前完全没有）：「别人来找你（或找你的组织），找得到能说话的人吗？」**
> **这一题比"你感觉顺不顺""你还在进新东西吗"更难自欺，因为它的答案不在你手上。**

### 4. 丰卦补上的缺口

| 缺口 | 丰卦补的内容 |
|---|---|
| **本库有"顺境"（泰）与"鼎盛"（乾九五），但没有"盛大本身的机制"** | **丰给出机制："明以动，故丰"（彖传）＋"丰其X"四见（三次丰的是遮蔽物）。**<br>**核心发现：规模的增长本身就是对内容的遮蔽（丰其屋 → 蔀其家）。这在本库此前完全没有对应物。** |
| **本库讲"看不清"只有明夷（36，环境黑）与归妹（54，视野残缺）两种** | **丰补上第三种，也是最反直觉的一种：环境最亮的时候看不清（日中见斗）。**<br>**三者的药完全不同**：**明夷用晦（收光）｜归妹用剩下的那半只眼（眇能视）｜丰用孚（让人告诉你）与夷主（找对等者核实）。** |
| **"孚"在本库一直是品德（诚信）** | **丰六二第一次把"孚"用作工具**："有孚发若"，象传"信以发志也"——**孚是在信息被遮蔽时唯一的破法。** |
| **"乘刚"的来源条文不完整（只到震、兑）** | **本卡补齐为四个来源、两型，加交界型，并给出机械判据**（见本节第 1 条）。**同时给出限定：乘刚是处境，不是判词。** |
| **路由表缺三条高频困境** | ① **"现在是我最好的时候，但我心里不安"**——**丰卦辞给的是"勿忧"，彖传给的是"日中则昃"：不要为它会过去而忧，要在这一瞬把光照全。**<br>② **"位置越高，我拿到的信息越假"**——**丰六二"日中见斗"，药是"有孚发若"；丰九三"不可大事也"，药是"遇其夷主"。**<br>③ **"我们的规模一直在涨，但好像什么都推不动了"**——**丰上六"丰其屋，蔀其家…阖其无人"，且这一爻是当位的。** |
