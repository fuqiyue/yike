# 知识卡 56 · 旅卦（火山旅）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："穷大者必失其居，故受之以旅。"——**把"大"做到穷尽的人，必然失去他的住处。** 而丰卦（55）最后一爻正是"**丰其屋，蔀其家…阖其无人**"（房子盖到天边，里面一个人也没有）。**《周易》用序卦传把两卦扣死：房子盖到最大的那一刻，你就成了没有住处的人。**
> **本卦与丰卦（55）是一对覆卦（上下颠倒）**：丰六爻自下往上"阳阴阳阳阴阴"，整卦颠倒即得旅"阴阴阳阳阴阳"。**丰＝房子越盖越大，旅＝没有自己的房子。必须合读，逐爻并列表见第四节第 1 条。**
> ⚠️ **本卡的四个重点**：
> **① "离在下 vs 离在上"这条结构律的完整实证**：丰的离在下 → 初二三**全部当位**（4 当位）；旅的离在上 → 四五上**全部不当位**（2 当位）。**同样的两个三画卦，只是上下换了个位置，能站住的爻数就从 4 掉到 2。**
> **② 旅卦六爻没有一个"吉"字。** 全卦唯一的"吉"在卦辞里，而且带着限定："**旅贞吉**"——不是"贞吉"，是"以客居之身守正才吉"。
> **③ 本卦两处象传用了同一个罕见句式："以旅与下，其义丧也"（九三）、"以旅在上，其义焚也"（上九）**——**"其义……也"＝按道理就该如此。这是《周易》给客居身份下的两条禁令，而且不留任何余地。**
> **④ 彖传"止而丽乎明"是"离在上＝光在你身外"这条结构律的经文原文表述；彖传"顺乎刚"则是本库"乘刚破解"第一次拿到卦级的经文依据。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 旅 · 第五十六卦 |
| **卦象** | 上离（火／明）下艮（山／止），称"火山旅"。**大象传取"山上有火"**——**⚠️ 关键在于这两样东西的动静不同：山是止的（艮＝止），火是行的。山不动，而火在山上一路烧过去、烧过就走、不驻留。**<br>**这就是"旅"（行旅、客居）的全部图像：你脚下的地方（山）不属于你、也不会跟着你动；你自己（火）只是在它上面经过。**<br>**⚠️ 而这一条直接决定了大象传为什么落在"不留狱"上——"不留"是火在山上的本性**（见下文纲领解）。<br>**按本库第 4 节结构律，本卦的当位分布是全确定的，本卡逐爻验证如下**：<br>**艮在下 → 初不当、二三当位**：初六（阴居阳位，**不当位**）✓、六二（阴居阴位，**当位且得中**）✓、九三（阳居阳位，**当位**）✓；<br>**离在上 → 三爻全不当位**：九四（阳居阴位，**不当**）✓、六五（阴居阳位，**不当**，但得中）✓、上九（阳居阴位，**不当**）✓。<br>**⚠️ 结果：六爻只有两爻当位（六二、九三），而且全部集中在下卦；上卦三爻无一当位。**<br>**⚠️ 乘刚一处**：**六五乘九四**（离在上的底部型乘刚，见丰卡第四节第 1 条补齐的机械律："**离在上则六五必乘刚**"）。 |
| **⚠️ 结构与卦德的对应（本卦最核心的一次结构解释）** | **旅卦的处境是两条"最危险的位置"叠出来的，而规格第 4 节把这两条都列了名：**<br>**① "离在上＝光在你身外（名不正）"**——**你的合法性、名分、能见度都不在你身上，在上面那个不属于你的光里。** 这就是为什么九四"**未得位也**"、六五要靠"**上逮**"（向上通达）才拿到"誉命"。<br>**② 艮在下＝止在内**——**⚠️ 这里需要一条精确的区分。** 规格第 4 节的"六条最危险的位置"里写的是"**艮在上＝被压住不许动**"（有人在你头顶压着你）。**旅卦是艮在下，不是艮在上，所以它的"动不了"是另一种：不是被上面压住，而是自己脚下没有根。**<br>**山在下，是你所处的那块地方——它是止的、不动的、也不是你的。你不能带走它，也不能改变它。**<br>**⚠️ 两条合起来，正是"客居"的精确定义：脚下的地方不动也不属于你（艮在下），头上的光和名分不属于你（离在上）。你唯一能做的是"丽"（附着）——而这正是彖传的原话："止而丽乎明"。** |
| **领域定义** | **在别人的地盘上生活或做事，且没有产权**。① **外派、驻场、常驻客户现场**；② **跳槽／调岗后的头几个月**（人、规矩、关系网都不是你的）；③ **寄人篱下**：住在亲戚家、借住、依附于某个平台或大树下做事；④ **异地**：异地工作、异地求学、异地婚姻中的那一方；⑤ **加盟、挂靠、代理、外包驻场**——名义上合作，实际上在对方屋里；⑥ **并购后作为被并方留下来的人**；⑦ **任何"我在这里，但这里不是我的"的处境。**<br>**⚠️ 凡是"我在别人的地方，拿不到名分，也带不走什么"，都落在旅卦。** |
| **不归本卦的情况** | ① 有自己的地盘，问题是"盛大之后怎么办" → **丰卦（55，本卦之覆）**；② 已经归定、身份已成立，问题是"怎么在里面过下去" → **归妹卦（54）**；③ 环境黑、需要藏起自己的光 → **明夷卦（36）**；④ 该停下来、怎么停 → **艮卦（52）**；⑤ 有明察之力却被禁止判人 → **贲卦（22）**；⑥ 上下不通、正事做不动 → **否卦（12）**。<br>**⚠️ 与明夷的分界最要紧**：**明夷是"我有光，但环境不许我亮"（药是"用晦而明"，收光）；旅是"光根本不在我身上"（药是"丽乎明"，附着于外面的光）。** 一个是收，一个是附——**用明夷的姿态过旅卦，会把自己藏到没人知道你在；用旅卦的姿态过明夷，会把自己交给不该交的光。** |
| **"旅"字本义** | **旅＝行、行旅、出行在外**（引申为军旅之"旅"，但本卦取"行旅／客居"义）。<br>**⚠️ 爻辞里"旅"字五见，而且每一次都是身份限定语，不是动作**：**"旅琐琐"（初六）、"旅即次"（六二）、"旅焚其次"（九三）、"旅于处"（九四）、"旅人先笑后号咷"（上九）**，加上两处象传的"**以旅**与下"、"**以旅**在上"。<br>**含义：《周易》在这一卦里反复提醒你的是身份，不是动作。同一个动作，"以旅"去做和"以主人"去做，评价完全不同——这正是九三与上九两处"其义……也"的根据。** |
| **卦辞原文** | 旅：小亨，旅贞吉。 |
| **⚠️ 卦辞的关键结构** | **不是"亨"，是"小亨"；不是"贞吉"，是"旅贞吉"。无元、无利。**<br>**① 缺"元"、缺"利"**：客居既没有启动权（元），也没有可分的好处（利）。<br>**② "小亨"而非"亨"（⚠️ 与丰卦最尖锐的对照）**：**丰卦辞是"亨"，旅卦辞是"小亨"。**<br>**两卦是覆卦——同一个卦形上下颠倒一次，"亨"就降格成"小亨"。** 这是本库覆卦对里最直观的一次卦辞级降格。<br>**"小亨"的含义**：**路是通的，但只通小的。** 落到现代：**客居可以过得好，但过不成大的——不要在客居的位置上图谋大事。**<br>**⚠️ 本库另一处"小亨"是巽卦（57，"小亨，利有攸往，利见大人"）。对照之下旅卦更苛刻：巽在"小亨"之后还给了两个"利"，旅卦一个也没给，只给了一个带条件的"吉"。**<br>**③ ⚠️ "旅贞吉"三个字是全卦最精细的一处（本卦最重要的一条读法）**：<br>**它不是"贞吉"（守正则吉），是"旅贞吉"——前面加了一个身份限定词。**<br>**含义：你要守的不是一般意义上的"正"，是"客居之正"。**<br>**⚠️ 这一点极关键，因为它解释了九三为什么"贞厉"：九三是当位的、也守着正，但它守的是"主人之正"（对下面的人行主人的权），而不是"旅之正"。所以它虽然"贞"，却"厉"。**<br>**⚠️ 结论：在旅卦里，"守正"这件事本身要按身份重新定义。同一件正确的事，主人做是对的，客人做就是错的。** |
| **卦辞现代解** | **小亨**——**这条路通，但只通小的。** 具体：**客居期间可以做成事、可以过得体面，但不要图大**（对照九三"焚其次"与上九"焚其巢"，两处的凶都来自把客居当成主场）。<br>**旅贞吉**——**以客居的身份守客居的正，则吉。** 具体：**先弄清"以我现在的身份，什么是正的"，再去守它。** |
| **彖传** | 旅，小亨，柔得中乎外而顺乎刚，止而丽乎明，是以小亨，旅贞吉也。旅之时义大矣哉！ |
| **⚠️ 彖传要点（本卦全部机制都在这三句里，且每一句都对上一条结构律）** | ① **"柔得中乎外而顺乎刚"**——**柔（六五，阴爻）在外卦（上卦）得了中位，而它顺从刚。**<br>**⚠️ 这句话在结构上极准确，也极有信息量：六五正是全卦唯一的乘刚爻（它压在九四这个阳爻上）。按常理，乘刚的爻处于"被下方阳刚顶迫"的状态；而彖传偏偏说它"顺乎刚"。**<br>**⚠️ 这是本库"乘刚破解"第一次拿到卦级的经文依据。** 规格第 4 节原有的破解是两条爻级样本（艮六四"止诸躬"、巽六四"田获三品"），渐卡（53）补了第三条（渐六四"或得其桷"）。**旅卦彖传把它上升成了一条原则：顺乎刚。**<br>**而六五的爻辞正是这条原则的执行："射雉，一矢亡，终以誉命"，象传"上逮也"——它不与下面的九四争，而是向上通达到上九。**<br>**⚠️ 落到现代：你压着的那股力量（既成事实、强势的下属、原有的规矩）不要去较劲，顺着它，同时把关系往上接。**<br>② **⚠️ "止而丽乎明"（"离在上"这条结构律的经文原文）**——**下艮是"止"，上离是"明"；"丽"＝附丽、依附、附着。**<br>**"止而丽乎明"＝先止住自己，然后附着于外面的那个光。**<br>**⚠️ 规格第 4 节写的是"离在上＝光在你身外（名不正）"，而彖传给出的是同一件事的正面表述：既然光在你身外，你能做的就是"丽"（附着于它），不是自己发光。**<br>**⚠️ 这一条是客居的核心技术，也是它与明夷的分界**：**明夷有自己的光（离在下），所以要"用晦"（收起来）；旅的光在外面（离在上），所以只能"丽"（附上去）。**<br>**⚠️ 而这也是"艮在下"彖传句式的第三次出现**：**咸 31"止而说"、渐 53"止而巽"、旅 56"止而丽乎明"。三卦全部是艮在下，三卦彖传全部以"止而□"起句。**（详见第四节第 4 条）<br>③ **"旅之时义大矣哉！"**——**⚠️ 《周易》的彖传只在少数几卦末尾下这种感叹式的总评。**<br>**"时"＝时机、"义"＝分寸与该当之理。"旅之时义大矣哉"＝客居这件事的时机与分寸，太重要了。**<br>**含义：客居的一切都不是常态，而是"一段时间"。你做得对不对，全看你有没有把它当成一段时间来处理。**<br>**⚠️ 而九三与上九的凶，恰恰都是把"一段时间"当成了"从此以后"：九三把旅舍当家（所以烧了它也伤自己），上九把窝当成永久的位置（所以"其义焚也"）。** |
| **大象传（行动纲领）** | 山上有火，旅。君子以明慎用刑而不留狱。 |
| **⚠️ "明慎用刑而不留狱"解（本卦最高层原则）** | **明**＝明察（离＝明）；**慎**＝谨慎（艮＝止）；**用刑**＝施用刑罚；**不留狱**＝**不积压案件、不让案子留在手上**（"留"＝滞留、积压）。<br>**全句：明察而谨慎地用刑，并且不把案子积压下来。**<br>**⚠️ 为什么一个讲"客居"的卦，行动纲领是司法？——因为取象就是这么来的。**<br>**"山上有火"：山是止的、火是行的。火在山上烧过就走，不驻留。**<br>**⚠️ 所以这条纲领的灵魂不在"用刑"，在"不留"——"不留"是火在山上的本性，也是客居者的本分。**<br>**⚠️ 三层操作含义（这是本卦最实用的一段）**：<br>**① "明慎"＝看清楚、且不敢造次。** 离给你"明"（你看得清），艮给你"慎"（但你要止住手）。**客居者的判断力往往是全场最清醒的——因为你是新来的、是外人、没有既得利益。但"明"不授权你出手。**<br>**② "用刑"＝该处理的还是要处理。** 注意它没有像贲卦那样说"无敢折狱"——**旅卦是允许处置的**，只是必须"明慎"。<br>**③ ⚠️ "不留狱"＝处理完就交出去、不攒在自己手上。** 这是客居者的保命条款：**你可以断，但不能把案子（以及案子带来的恩怨、人情、把柄）留在自己身上。因为你要走，而留下来的东西会替你留在这里。**<br>**⚠️ 而这条纲领恰恰是九三与上九的解药**：**九三"焚其次、丧其童仆"是把恩怨留成了火；上九"鸟焚其巢"是把位置留成了窝。两处的病都是"留"，而纲领的最后三个字就是"不留狱"。** |
| **总铁律** | ① **守正要按身份重新定义**（卦辞"旅**贞**吉"，不是"贞吉"）——**同一件正确的事，主人做是对的，客人做就是错的**；<br>② **只通小的**（"小亨"）——**客居期间不图大事**；<br>③ **机制是"止而丽乎明"**（彖传）——**先止住自己，再附着于外面的光；不要自己发光，也不要像明夷那样把光藏起来**；<br>④ **对你压着的那股力量要"顺"，不要争**（彖传"顺乎刚"，六五"上逮也"）；<br>⑤ **纲领的灵魂是"不留"**（大象传"不留狱"）——**可以断、可以处置，但不能把案子和恩怨留在自己身上**；<br>⑥ **客居要守住三样东西：住处、钱、帮手**（六二"即次、怀其资、得童仆贞"）——**九三丢了两样，九四只剩一样半**；<br>⑦ **两条禁令，且《周易》判为"理当如此"**：**不许以客居之身处置下面的人（九三"以旅与下，其义丧也"）；不许以客居之身坐到最上面（上九"以旅在上，其义焚也"）**；<br>⑧ **全卦六爻没有一个"吉"字。** 唯一的"吉"在卦辞，且带条件。 |

## 二、爻级字段

> ⚠️ **本卦六爻是一条"客居的资产逐步流失"的序列，中间被六五扭转了一次。**
> **三样资产**：**次**（落脚的住处）、**资**（钱）、**童仆**（当地的帮手）。
> **"次"三见**：六二**即**其次（住下）→ 九三**焚**其次（烧了）→ 九四只剩"**处**"（一个落脚点，连"次"都不是了）。
> **"童仆"两见**：六二**得**童仆贞 → 九三**丧**其童仆。
> **"焚"两见**：九三焚其**次**（临时住处）→ 上九焚其**巢**（窝）。**⚠️ 烧的东西从"临时的"升级成"自己的"，而两次都是自己烧的。**
> **⚠️ 序列**：**初六（一进门就计较小事，自取灾）→ 六二（三样齐备，全卦最好的一爻）→ 九三（烧了住处、丢了帮手，贞厉）→ 九四（只剩一个落脚点和钱，心里不快）→ 六五（用一支箭换来誉命，唯一的上行）→ 上九（烧了自己的窝，先笑后哭，凶）。**

### 初六 · 旅琐琐（⚠️ 全卦唯一的"灾"字）

| 字段 | 内容 |
|---|---|
| **爻辞** | 旅琐琐，斯其所取灾。 |
| **象传** | 旅琐琐，志穷灾也。 |
| **位属性** | 阴爻居阳位，**不当位**（艮在下 → 初不当位）；居全卦最下；不得中 |
| **判词 → 行动语义** | **取灾**（自取灾祸，全卦唯一的"灾"字） → **停止计较细碎的事** |
| **关键词解** | **琐琐**（suǒ suǒ）＝**细小、猥琐、计较细碎**（重言，强调其小）。**斯**＝乃、这就是。**取灾**＝**自己招来的灾**（"取"是主动的，不是被动遇上）。**志穷**＝**心志困穷、志向被憋住了。** |
| **⚠️ 本爻的全部重量在两个字上："取"与"穷"** | **① "取"字**：爻辞不说"有灾"，说"**取**灾"——**灾不是环境给你的，是你自己拿来的。**<br>**⚠️ 在一个"名不正、脚下没根"的处境里（离在上、艮在下），《周易》第一件事居然是告诉你：接下来的麻烦是你自己招的。** 这话很硬，但它是本卦最有用的一条：**客居的头一关不是环境，是你自己的注意力。**<br>**② "穷"字（象传给的病根）**：**"志穷灾也"——志向困穷了，所以有灾。**<br>**⚠️ 因果顺序要读准：不是"琐琐所以志穷"，是"志穷所以琐琐"。** 心里的目标被憋住了、没处使了，注意力就自动落到最细碎的地方去。<br>**⚠️ 落到现代（原型极常见）**：**刚外派／刚入职／刚借住，你的正事还没铺开（志穷），于是全部注意力落到座位在哪、报销标准、称呼、谁先跟谁打招呼、别人有我没有、上次那句话什么意思。**<br>**而这些恰恰是客居者最没有资格计较的东西——因为按定义，这里的规矩不是为你定的。** |
| **识别信号（诊断清单）** | ① 你刚到一个不属于你的地方（新单位、新城市、客户现场、亲戚家）；② **你的正事还没真正开始**——职责没落地、资源没到位、你也不清楚该干什么（志穷）；③ **你最近想得最多的，都是小事**：待遇的差别、称呼、座位、谁没通知你、报销、谁对你的态度；④ 你已经为其中一两件小事表达过不满，或者正准备表达；⑤ **⚠️ 关键信号：你能清楚列出"这里对我不公平"的五条，却说不出"我来这里要做成的一件事"是什么。** |
| **该做** | **① 先补"志"，再谈"琐"。** 象传把病根定在"志穷"，所以药也在那里：**明确写下"我在这段客居里要做成的一件事"（一件，不是三件）。** 志一立起来，琐琐会自动退场。<br>**② 主动放弃计较的资格。** 具体化：**列出五件你觉得不公平的小事，然后全部划掉，并明确告诉自己"这些不是我的项目"。**<br>**③ 把注意力转到六二的三样东西上**：**住处（安顿好）、钱（管好自己的现金）、帮手（找到一个可靠的本地人）。** 这三样才是客居真正的资产。 |
| **不该做** | ① **不要在进门阶段处理公平问题**——**"取灾"是全卦唯一的"灾"字，而它就挂在这件事上**；② 不要把"我在维护自己的边界"当成理由——**客居阶段的边界不是靠计较来划的，是靠交付来划的**；③ 不要因为"志穷"就放弃立志（那是把初六过成一直的初六）。 |
| **⚠️ 与丰初九的对照（覆卦对的两个"灾"，都在初爻）** | **丰 55 初九"遇其配主，虽旬无咎，往有尚"，象传"虽旬无咎，过旬灾也"**——**保持均等则无灾，想超过对等的那一方就有灾。**<br>**旅 56 初六"旅琐琐，斯其所取灾"，象传"志穷灾也"**——**计较细碎就是自取灾。**<br>**⚠️ 两卦是覆卦，而两卦唯一的"灾"字都出现在初爻，而且病根是同一个：注意力放错了地方。**<br>**丰初九：注意力从"照天下"（彖传）转到了"照过他"——想比高下。**<br>**旅初六：注意力从"站住脚"转到了"计较细碎"——想比公平。**<br>**⚠️ 合读结论（可入库）：一件事刚开始时，《周易》两次用"灾"这个字，两次都不是在警告能力不足或环境凶险，而是在警告"你开始跟人比了"。**<br>**在"盛大"的开头，比的是高下（丰）；在"客居"的开头，比的是待遇（旅）。两种比法都判"灾"。** |

### 六二 · 旅即次（⚠️ 全卦最好的一爻，也是客居的标准配置）

| 字段 | 内容 |
|---|---|
| **爻辞** | 旅即次，怀其资，得童仆贞。 |
| **象传** | 得童仆贞，终无尤也。 |
| **位属性** | 阴爻居阴位，**当位且得中**（艮在下 → 二当位得中）；与六五敌应（同性）<br>⚠️ **不乘刚**（其下为初六，阴爻） |
| **判词 → 行动语义** | **无判词，象传给"终无尤也"** → **⚠️ 全卦条件最好的一爻，也只拿到"最终没有过咎"** |
| **关键词解** | **即**＝到达、就（"即次"＝到了旅舍并住下）。**次**＝**旅舍、临时的驻处**（军旅之"次"亦指驻扎地；⚠️ **注意它本义就是临时的**）。**怀**＝揣着、带在身上（"怀其资"＝钱在自己手里）。**资**＝资财、路费。**童仆**＝仆役、随从，此处指**在当地为你做事的人**。**贞**＝忠贞、可靠（**⚠️ 这个"贞"是修饰童仆的，不是判词**）。**尤**＝过失、怨咎。 |
| **⚠️ 本爻是《周易》给客居者开的一张配置清单：三样，且只有三样** | **① 次——一个落脚的住处**（临时的，但是确定的）；<br>**② 资——钱在自己手上**（"怀"字很实在：不是"有钱"，是钱在你身上）；<br>**③ 童仆贞——有可靠的当地帮手。**<br>**⚠️ 三样齐备，象传给的评语是"终无尤也"（最终没有过咎）。**<br>**⚠️ 请注意这个评语有多克制：六二是全卦唯一"当位且得中"的爻，条件是全卦第一，判词却只是"无尤"——连"无咎"都没写，更没有"吉"。**<br>**这正是"小亨"在爻级上的形态：客居做到最好，也就是"没有过咎"。**<br>**⚠️ 由此可以下一条很实用的判断：如果你在客居里期待的是"吉"（大成、被认可、翻身），那你期待的东西不在这一卦的许诺范围内。旅卦能给的最高结果是"终无尤"。** |
| **⚠️ 为什么三样里《周易》只表扬了"童仆贞"** | **爻辞列了三样，象传却只挑出第三样重复了一遍："得童仆贞，终无尤也。"**<br>**⚠️ 含义：住处和钱是条件，人才是结果。**<br>**"次"是别人给的（你租的、公司安排的、亲戚腾的），"资"是你自己带来的，只有"童仆贞"是你在这里赢得的——它是唯一一样"客居期间新长出来的资产"。**<br>**⚠️ 而它的形态也很值得注意：不是"得童仆"，是"得童仆**贞**"——得到的是他们的**忠贞可靠**，不是得到他们这些人。** 客居者拿不到人的所有权，只能拿到人的可靠。<br>**⚠️ 落到现代：外派／新岗位／寄居的头几个月，唯一真正值得投入的是"让当地至少几个人成为可靠的自己人"。这件事的收益是"终无尤"——它是你后面所有麻烦的保险。**<br>**⚠️ 反证在九三：九三"丧其童仆"，象传的理由是"以旅与下，其义丧也"——弄丢了帮手，是"理当"的。可见《周易》认为这三样里最容易丢、也最要命的就是它。** |
| **识别信号（诊断清单）** | ① 你在这个不属于你的地方已经安顿下来了：住处有了、钱是自己管的、活也铺开了；② 你不再需要为吃住和身份焦虑（已经过了初六）；③ 已经有一两个当地的人开始真心帮你、给你说实话；④ **你正在考虑下一步："既然站住了，是不是可以推动些什么了？"**<br>⑤ **⚠️ 关键信号：你开始把这里当成"我的地方"来想事情。** |
| **该做** | **① 把三样东西各自坐实。** 具体化：**住处（生活稳定、不折腾）｜钱（自己的现金流独立于这里，不要把身家押进来）｜帮手（明确知道谁是可靠的，并且持续投入这段关系）。**<br>**② 重点投在"童仆贞"上。** 象传只表扬了这一样。**具体动作：给他们真实的好处、替他们担一次事、不在他们面前摆客人的架子。**<br>**③ 把期望值定在"终无尤"。** 这一爻不给吉，**所以正确的自我评价标准是"这段客居有没有留下过咎"，不是"有没有做出成绩"。**<br>**④ ⚠️ 不要从这里往前推。** **六二的下一爻是九三——全卦最坏的一爻之一（贞厉），而且它坏在"把客居当主场"。** |
| **不该做** | ① **不要把身家押进来**（"怀其资"＝钱在自己手上，这是明确的指令）；② 不要开始行使主人的权力（那是九三"以旅与下"）；③ 不要因为"只是无尤"而觉得这一爻不值得——**在旅卦里，"终无尤也"就是最好的结果。** |
| **⚠️ 与丰六二的对照（覆卦对的两个六二，同样当位得中，判词天差地别）** | **丰 55 六二"丰其蔀，日中见斗，往得疑疾。有孚发若，吉"**——**当位得中而"日中见斗"（看不清），但给了"吉"。**<br>**旅 56 六二"旅即次，怀其资，得童仆贞"，象传"终无尤也"**——**当位得中、三样齐备，只给"无尤"。**<br>**⚠️ 两爻位属性完全相同（阴爻居阴位、当位、得中），一个得"吉"，一个只得"无尤"。**<br>**差别不在爻，在卦：丰卦辞是"亨"，旅卦辞是"小亨"。**<br>**⚠️ 结论：卦辞的"亨"与"小亨"，是会一路传导到爻级判词上的。同样站得最稳的那一爻，在"亨"的卦里能得吉，在"小亨"的卦里只能得无尤。**<br>**这为本库"卦境决定动作上限"这条通则（泰否卡第 2 条、归妹卡第 4 节第 4 条）又添一个样本，而且这一个是在覆卦对内部完成的——变量只有一个。** |

### 九三 · 旅焚其次（⚠️ 全卦最重的一条禁令）

| 字段 | 内容 |
|---|---|
| **爻辞** | 旅焚其次，丧其童仆，贞厉。 |
| **象传** | 旅焚其次，亦以伤矣。以旅与下，其义丧也。 |
| **位属性** | 阳爻居阳位，**当位**（艮在下 → 三当位）；不得中；**居下艮之顶——按本库口径这正是"该止之地"**；本库通则"**三多凶**"；与上九敌应（同性）<br>⚠️ **不乘刚**（其下为六二，阴爻） |
| **判词 → 行动语义** | **贞厉**（守正也危；按本库口径"厉"是警告，非判死） → **停止对下面的人行使主人的权力** |
| **关键词解** | **焚**＝烧。**焚其次**＝**把自己的旅舍烧了**（"次"即六二那个落脚处）。**丧**＝丧失、弄丢。**贞厉**＝**守正也有危**（对照本库口径："贞凶＝守正也凶，问题不在品德，在处境与选择的根本错位"；**贞厉是同一逻辑的较轻一档**）。**亦以伤矣**＝**也已经伤到自己了。****以旅与下**＝**以客居的身份去对待（处置）下面的人**（"与"＝相与、对待）。**其义丧也**＝**按道理就该丢掉。** |

#### ⚠️ 专项：一个"当位"的爻为什么判"贞厉"，而且象传说"理当如此"

| 核实项 | 结论 |
|---|---|
| 九三的位属性好不好？ | **好。阳爻居阳位，当位。** 它是下卦艮唯一的阳爻，**即"止"的力量本身所在**，也是**下艮之顶＝该止之地**。 |
| 那"厉"从哪来？ | **不从位来，从身份来。**<br>**象传给的理由是六个字："以旅与下"——以客居的身份去处置下面的人。**<br>**⚠️ 九三是当位的、也是有力量的（阳刚）、也确实"贞"（守正）。它做的事在主人看来完全正当：管一管下面的人。**<br>**但它是客。** |
| 为什么爻辞用"贞厉"而不是"厉"？ | **因为它确实守正。**<br>**⚠️ "贞厉"这个组合的意思正是：你的品德和做法都没问题，问题在于你的身份与这个做法根本不匹配。**<br>**这正是卦辞"旅**贞**吉"那个身份限定词的反面：卦辞要你守"旅之正"，九三守的是"主人之正"。同一个"贞"，身份错了就从"吉"翻成"厉"。** |
| 象传的"其义丧也"有多重？ | **极重。"义"＝理当、按道理。**<br>**《周易》没有说"你运气不好"、"下面的人不识好人心"，它说：以客居之身处置下面的人，丢掉他们是**应当的**。**<br>**⚠️ 这是本卦不留余地的一处——它把责任完全放在身份的误判上。** |
| 它丢了什么？ | **六二三样资产里的两样：次（住处，被自己烧了）与童仆（帮手，丢了）。**<br>**⚠️ 只剩"资"（钱）。而九四正好接着说："得其资斧，我心不快"——钱还在，人不快。** |

| 字段 | 内容 |
|---|---|
| **⚠️ "焚其次"是自己烧的（本爻最容易读漏的一点）** | **爻辞是"旅焚其次"——主语是"旅"（客居者），动作是"焚"。不是失火，是他自己烧的。**<br>**⚠️ 而"次"是什么？是六二辛苦"即"（到达并住下）的那个落脚处。**<br>**落到现代：你把自己在这里的立足之地亲手毁掉了。** 具体形态：**跟房东／接待方／原有的负责人翻脸；在寄居的地方发一次脾气；对客户现场的人行使了你没有的权力；作为新来的人处理了一个"早该处理"的老人。**<br>**⚠️ 这些动作在道理上往往都站得住（所以是"贞"），而它们的共同后果是：你把自己借住的那间房子点了。**<br>**象传的评语只有四个字："亦以伤矣"——也已经伤到自己了。烧的是别人给你的房子，伤的是你自己。** |
| **识别信号（诊断清单）** | ① 你在这里已经站住了（过了六二），并且开始有实际的影响力；② **你手上有一件"明显不对、早就该处理"的事，涉及这里的某个人或某个惯例**；③ **你的判断是对的**——你能清楚说明它为什么不对（这正是危险信号：离＝明，你确实看得清）；④ 你已经处理了，或者正准备处理；⑤ **⚠️ 最强的信号：你想处理这件事的理由是"这不合规矩"，而不是"这在我职责范围内"。** |
| **该做** | **① 立刻止住。** **九三居艮之顶——这是"该止之地"，而它手里握着的正是"止"的那份阳刚力量。**<br>**② 把"我看得清"和"我有资格处理"分开。** 大象传给的顺序是"**明慎**"——**先明（看清），再慎（止住手）。看清不等于授权。**<br>**③ 如果这件事真的必须处理，交给主人去处理。** 具体化：**把事实交上去，不带处置意见；让有产权的人下手。** 这正是大象传"**不留狱**"的真意——**你可以断，但不能把案子和恩怨留在自己身上。**<br>**④ 保住"童仆"。** 象传把最重的话留给了这一条（"其义丧也"）。**在客居里，人比对错值钱。** |
| **不该做** | ① **不要以客居之身处置下面的人**——这是本卦最重的一条禁令，且象传判为"理当"；② 不要用"我是对的"来抵消"贞厉"——**"贞厉"的意思正是"你是对的，但还是危"**；③ 不要因为"焚其次"就整体撤走——**"厉"是警告不是判死，六二那三样里"资"还在，九四还有路。** |
| **⚠️ 与咸九三、渐九三的三方对照（本卡最重要的一组结构发现）** | **⚠️ 本库现有三个"艮在下"的卦：咸 31（上兑下艮）、渐 53（上巽下艮）、旅 56（上离下艮）。三卦的九三全部当位，判词全部是负面的，而且全部是各自卦里最坏或次坏的一爻。**

| 卦 | 九三爻辞 | 判词 | 象传 | 位属性 | "该止而未止"的具体形态 |
|---|---|---|---|---|---|
| **咸 31** | 咸其股，执其随，往吝 | **往吝** | 亦不处也 · **所执下也** | 阳·**当位** | **该止而跟着别人走**（志在随人） |
| **渐 53** | 鸿渐于陆，夫征不复，妇孕不育，凶。利御寇 | **凶** | **离群丑也** · 失其道也 | 阳·**当位** | **该止而往前征**（跳级，离开同类） |
| **旅 56** | 旅焚其次，丧其童仆，贞厉 | **贞厉** | 亦以伤矣 · **以旅与下，其义丧也** | 阳·**当位** | **该止而行主人之权**（身份误判） |

| 字段 | 内容 |
|---|---|
| **⚠️ 三例对照的三条结论（建议入库，本批最有价值的一条结构发现）** | **① "艮在下"的卦，九三是那个"当位却最危险"的位置。**<br>**机械原因很清楚：艮＝阴阴阳，它把唯一的阳放在最上面。所以"艮在下"时，九三必然是阳居阳位（当位），而且它是下卦唯一的阳——它就是"止"这个力量本身，同时它又处在下卦之顶，即该止之地。**<br>**⚠️ 于是这一爻构成一个陷阱：它有力量（阳）、有名分（当位）、有位置（卦之半），而它的卦德要求它不动。**<br>**② 三爻的病根完全相同：手里握着"止"的力量，却没有用。** 咸九三拿它去跟随，渐九三拿它去前征，旅九三拿它去行权。<br>**⚠️ 三者都不是"能力不足"，也不是"位置不对"——本库"三多凶"的另两个样本（师六三、否六三）都可以用"位不当"解释，这三个不能。**<br>**③ 判词的轻重与"动的方向"对应，且完全符合本库吉凶序（吝 ＞ 厉 ＞ 凶，越往后越差）**：<br>**咸九三"往吝"（最轻）——它只是跟着别人走，方向错但没有毁掉什么；**<br>**旅九三"贞厉"（中）——它毁掉了自己的落脚处和帮手，但"厉"是警告，还有路；**<br>**渐九三"凶"（最重）——它离开了同类、投入收不回、产出生不出，且是全卦唯一的凶。**<br>**⚠️ 合读的实操价值：只要你的处境里含"艮在下"（内部有一个"止"的机制），那么"卦之过半、你刚站稳、你有力量、你看得清、你想动一下"这个组合就是最危险的时刻。三卦给出的答案完全一致：不动。**<br>⚠️ **一条口径校勘（顺带报出）**：咸卡（31）在九三一节写有"按本库吉凶序 **吝 ＞ 厉**（吝更靠后、更差）"，**但规格第 3 节的排序是从最好到最坏"…悔 ＞ 吝 ＞ 厉 ＞ 凶"，即"吝"优于"厉"。咸卡的文字说明与规格方向相反，**已于本轮修订**（咸卡 98、236 两处已改正为"厉重于吝"，并加注"厉＝急性警告／吝＝趋势恶化，两者度量不同维度，不作排序"）。** 本卡按规格方向使用。 |

### 九四 · 旅于处

| 字段 | 内容 |
|---|---|
| **爻辞** | 旅于处，得其资斧，我心不快。 |
| **象传** | 旅于处，未得位也。得其资斧，心未快也。 |
| **位属性** | 阳爻居阴位，**不当位**（离在上 → 三爻全不当位）；不得中；本库通则"**四多惧**"；与初六相应<br>⚠️ **不乘刚**（其下为九三，阳爻）；**但六五乘在它头上** |
| **判词 → 行动语义** | **无判词，只给一个心理状态** → **按本库口径：《周易》承认你的难受，但不判你有咎，也不授权你越位** |
| **关键词解** | **处**＝**处所、一个待着的地方**（⚠️ **比"次"低一档**：六二是"次"＝旅舍，九四只是"处"＝一个能待的地方）。**资斧**＝**资财与斧**（一说"资斧"即路费；一说"斧"是防身与开路的工具）。**我心不快**＝**我心里不痛快**（⚠️ **第一人称，全卦唯一一处"我"**）。**未得位**＝**没有得到位置。** |
| **⚠️ 本爻的全部信息在"未得位也"这四个字上** | **九四把六二那三样资产的账结清了**：<br>**"次"（旅舍）已经在九三被烧了 → 九四只剩"处"（一个能待的地方）；**<br>**"童仆"（帮手）在九三丢了 → 九四没有提到人；**<br>**"资"（钱）还在，而且还多了个"斧" → "得其资斧"。**<br>**⚠️ 于是九四的处境是：钱有了，工具有了，地方有了，人没了，位置没有。而它的反应是"我心不快"。**<br>**象传把原因说得极其直白："**未得位也**"——**没有得到位置。**<br>**⚠️ 这正是规格第 4 节"离在上＝光在你身外（名不正）"这条结构律最干净的一次爻级实证：九四是离的最下一爻，它不当位，而象传给出的唯一解释就是"未得位"。** |
| **⚠️ "我心不快"：全卦唯一的第一人称，也是《周易》对客居最体贴的一句** | **六爻里只有这一处出现"我"。爻辞没有判它有咎，也没有安慰它，只是如实记下："我心不快。"**<br>**象传重复了一遍，还把它说得更准："**心未快也**"——心还没有痛快。**<br>**⚠️ 按本库口径，这属于最轻的一档：「无判词 ＋ 只给心理状态｜《周易》承认你的难受，但不判你有咎，也不授权你越位。」**<br>**⚠️ 落到现代（这是客居最典型的一种状态，也最容易被误处理）**：<br>**外派／新岗位到了中段，钱到位了、待遇不错、事也能干（得其资斧），住的地方也有了（旅于处），但你就是不痛快——因为你没有位置：没有名分、没有归属、没有人把你算成"我们的人"。**<br>**⚠️ 关键在于《周易》怎么处理它：它不说这不快是错的（不判咎），也不说你该去把位置要来（不授权）。它只是承认。**<br>**这一条极重要，因为"不快"最常见的误处理正是去要位置——而"要位置"在旅卦里就是上九"鸟焚其巢"的开头。** |
| **识别信号（诊断清单）** | ① 你在这个不属于你的地方已经过了中段；② **物质条件是够的**：钱、待遇、工具、住处都不缺（得其资斧、旅于处）；③ **但你没有位置**：没编制、没名分、不在核心名单里、别人介绍你时要解释一句；④ 你的帮手比之前少了（或者你和当地人的关系不如刚来时）；⑤ **⚠️ 关键信号：你说不清自己为什么不痛快，因为条件明明都不差——而答案就是象传那四个字："未得位也"。** |
| **该做** | **① 承认"不快"，并且不处理它。** 象传只说"心未快也"，没给任何动作。**这一爻的正确做法是让这份不快待着。**<br>**② 把"不快"的原因归对位置。** 具体化：**明确告诉自己"我不快不是因为待遇、不是因为谁对我不好，是因为我没有位置——而在旅卦里，位置本来就不属于我"。** 归因归对了，不快就不会转成怨。<br>**③ 守住"资斧"。** 钱和工具是九四手上唯一完整的东西，**也是你将来能带走的唯一东西。**<br>**④ 把动作留到六五。** 下一爻（六五）才是这一卦唯一的上行通道，而它的方式是"射雉，一矢亡"——**用一个小的、具体的、可见的投入去换"誉命"，不是去要位置。** |
| **不该做** | ① **不要去要位置**（要编制、要名分、要一个正式的头衔）——**"未得位"是这个身份的固有属性，不是待办事项；而强求位置的终点是上九"以旅在上，其义焚也"**；② 不要用加倍投入来换不快的消失（那会把身家押进来，违背六二"怀其资"）；③ **不要把"不快"说给这里的人听**——客居者的不快在主人听来就是不满。 |
| **⚠️ 与咸九四、震九四的三方对照（本库"无判词"家族的三种形态）** | **震 51 九四"震遂泥"，无判词，象传"未光也"**——本库读为**整爻白费**：有能力想动，陷在泥里动不了；<br>**咸 31 九四"贞吉，悔亡。憧憧往来，朋从尔思"，象传"未感害也／未光大也"**——**爻内分裂**：守正的一半算数，来回推演的一半白费；<br>**旅 56 九四"旅于处，得其资斧，我心不快"，象传"未得位也／心未快也"**——**⚠️ 第三种形态：有实际所得，但没有位置，所以不快；《周易》只记录，不判、不劝。**<br>**⚠️ 三个九四都在"四多惧"的位置上、都不当位，而《周易》给的处理方式分三档**：<br>**震九四判"白费"（未光也）｜咸九四把对的部分和白费的部分分开算账｜旅九四既不判白费也不判有咎，只是承认。**<br>**⚠️ 差别的根据在"有没有实际所得"**：**震九四陷在泥里，什么也没得到；咸九四得到了"贞吉、悔亡"；旅九四得到了"资斧"（实物）。**<br>**⚠️ 合读结论（可入库）：《周易》不把"心里不痛快"算成损失。只要有实际所得，不快就只是不快——它既不构成咎，也不需要被解决。**<br>**这对本库"情绪如何入账"这个问题给出了明确口径，而旅九四是其中唯一带第一人称的样本。** |

### 六五 · 射雉（⚠️ 全卦唯一的上行通道）

| 字段 | 内容 |
|---|---|
| **爻辞** | 射雉，一矢亡，终以誉命。 |
| **象传** | 终以誉命，上逮也。 |
| **位属性** | 阴爻居阳位，**不当位**（离在上 → 五不当位），但**得中**且居尊位；与六二敌应（同性）；**⚠️ 六五直接压在九四之上——乘刚，且是全卦唯一的一处乘刚**（离在上的底部型乘刚）<br>**⚠️ 彖传"柔得中乎外而顺乎刚"指的正是这一爻** |
| **判词 → 行动语义** | **无吉凶判词，但给了实际所得："终以誉命"** → **付一个小的、看得见的代价，换取声誉与任命** |
| **关键词解** | **射雉**＝射野鸡（**雉羽华美，古为文饰之物；离为雉，取"文明"之象**）。**一矢亡**＝**丢了一支箭**（"亡"＝失、损失）。**终**＝最终。**誉**＝声誉。**命**＝**任命、爵命**（⚠️ **不是产权，是授权**）。**上逮**＝**向上通达、往上够着了**（"逮"＝及、达到）。 |
| **⚠️ 本爻是全卦唯一往上走的一爻，而它的成本只有"一支箭"** | **前四爻是一路流失：初六取灾 → 六二三样齐备 → 九三丢了两样 → 九四只剩钱和一个落脚处、且心里不快。**<br>**⚠️ 六五第一次出现"所得"，而且是往上的所得："誉"（声誉）与"命"（任命）。**<br>**而它付出的成本被写得极小、也极具体：**一支箭**。**<br>**⚠️ 这个配比是本爻全部的智慧所在**：<br>**① 成本必须是"看得见的损失"。** 不是零成本——**"一矢亡"明确写了损失。客居者要往上走，必须让人看见你付出了自己的东西。**<br>**② 成本必须是小的。** 一支箭，不是一头牛（对照上九"丧牛于易"——那才是丢了根本）。<br>**③ 目标必须是具体的。** 射的是"雉"（一只具体的野鸡），不是一片天。**客居者不能立大志、只能立准的靶。**<br>**④ ⚠️ 所得只能是"誉命"，不能是产权。** **在别人的地盘上，你能积累的只有声誉和授权，不可能积累所有权。** 认清这一条，你就不会去做九三（行权）和上九（占位）那两件事。 |
| **⚠️ "上逮也"：本库"乘刚破解"的第四条，也是第一条来自卦级原则的** | **六五是全卦唯一的乘刚爻（压在九四这个阳爻上）。按常理它被下方顶迫。**<br>**⚠️ 而彖传给的原则是"顺乎刚"，象传给的动作是"上逮"（向上通达）。**<br>**⚠️ 两句合起来就是一条完整的破解：不与你所乘的那个刚较劲，顺着它，同时把关系往上接（上逮，接到上九）。**<br>**本库"乘刚破解"至此有四条，全部同源**：

| 样本 | 动作 | 破解的类型 |
|---|---|---|
| **艮 52 六四**"艮其身"（止诸躬也） | 把范围收回到自己这一身 | 收缩到**自身** |
| **巽 57 六四**"田获三品"（有功也） | 交付可分配的实际成果 | 收缩到**成果** |
| **渐 53 六四**"或得其桷"（顺以巽也） | 找一根能落脚的平枝 | 收缩到**一个支点** |
| **旅 56 六五**"射雉，一矢亡"（**上逮也**） | **付一支箭的代价，把关系往上接** | **改变方向：不向下，向上** |

| 字段 | 内容 |
|---|---|
| **⚠️ 第四条与前三条的分野（重要）** | **前三条都是"缩小自己的作用面"（收缩到自身／成果／支点）；旅六五是第四种，也是唯一一种"改变方向"的：不去处理下面那个刚，而是往上接。**<br>**⚠️ 而它有卦级的经文背书——彖传"柔得中乎外而顺乎刚"。这是本库"乘刚"这个概念第一次不是靠爻例归纳，而是有一条彖传原则可引。**<br>**⚠️ 可入库为通则（补入规格第 4 节"乘刚的破解"）**：<br>**乘刚有四种破解，共同点是"绝不向下反压"**：**① 收缩到自身；② 收缩到成果；③ 收缩到一个支点；④ 顺它，并把关系往上接（旅彖传"顺乎刚"、旅六五象传"上逮也"）。**<br>**本库至今没有一例"乘刚而向下反压"得吉的爻。** |
| **识别信号（诊断清单）** | ① 你在这个不属于你的地方已经过了中段，物质条件够了但没有位置（过了九四）；② 你下面（或平级）有一股强势的力量压着你的空间：一个资深的本地人、一套既成的规矩、一个不服你的团队（乘刚）；③ 你正在考虑怎么打开局面，而选项通常是两个：**要么把下面那股力量压下去，要么把位置要过来**；④ 你手上有一件可以做成、且做成了大家都看得见的具体小事；⑤ **⚠️ 关键信号：你能说出一件"我愿意为它付出自己的东西、而且别人会看见"的具体事。** |
| **该做** | **① 选一只"雉"——一个具体、不大、做成了大家都看得见的靶。** 不要选战略级的大目标（"小亨"）。<br>**② 明确付出"一支箭"——一个可见的、属于你自己的代价。** 具体化：**自掏一次费用、让出一次署名、加一次别人不愿意加的班、担一次不该你担的责任。** **⚠️ 关键是"别人看得见你损失了什么"——这是客居者建立信任的唯一方式，因为你没有产权可以质押。**<br>**③ "上逮"——把关系往上接，不向下争。** 具体化：**让上面的人知道这件事是你做的（不是抢功，是让授权者看见）；不与下面那股力量正面处理。**<br>**④ 把所得定位在"誉命"上。** **你要的是声誉与授权，不是名分与产权。** 认清这一点，就不会走向上九。 |
| **不该做** | ① **不要向下压制那股顶着你的力量**（本库四条破解全部禁止向下反压）；② 不要选大目标（"小亨"是卦级限制）；③ 不要零成本地要声誉——**"一矢亡"是明写的，没有损失就没有"誉"**；④ **不要把"誉命"当成"位置"。** 拿到誉命之后继续往上，就是上九。 |
| **⚠️ 与本库"五爻专题"的对照** | 本库已有：乾九五（纳新）、坤六五（守臣节）、蒙六五（赤子之心）、离六五（居尊而痛哭）、艮六五（居尊而闭嘴）、师六五（选对人然后放手）、震六五（只守本职）、巽九五（前后各留三日申命）、履九五（位正当反而厉）、兑九五（把孚收回来）、咸九五（居尊而感不到）、泰六五（居尊而下嫁，元吉）、否九五（居尊而"其亡其亡"）、渐九五（居尊而长期无产出）、归妹六五（居尊而主动降格）、丰六五（居尊而把光招进来）。<br>**旅六五补上新的一种：不在自己地盘上的"五"——它拿不到产权，只能拿"誉命"。**<br>**⚠️ 它是这一组里唯一一个"居中位而不居自己家"的样本，也是唯一一个明确写出"要付一个可见成本"的样本。**<br>**⚠️ 与丰六五（覆卦对的另一个五）的对照很有意思**：**丰六五"来章"（把光招进来，因为它有屋可招）；旅六五"射雉"（把箭射出去，因为它没有屋，只能拿自己的东西去换）。**<br>**同为覆卦对的中位：有产权的用"招"，没产权的用"付"。** |

### 上九 · 鸟焚其巢（⚠️ 全卦唯一的凶，也是本卦最不留情的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸟焚其巢，旅人先笑后号咷。丧牛于易，凶。 |
| **象传** | 以旅在上，其义焚也。丧牛于易，终莫之闻也。 |
| **位属性** | 阳爻居阴位，**不当位**（离在上 → 上不当位）；不得中；居全卦之终；与九三敌应（同性）<br>⚠️ **不乘刚**（其下为六五，阴爻） |
| **判词 → 行动语义** | **凶**（周易所有结局中最坏的） → **此爻不可入；解药在六五（射雉／上逮）与大象传（不留狱）** |
| **关键词解** | **巢**＝鸟窝（**⚠️ 比"次"高一档：次是旅舍，巢是自己筑的窝**）。**号咷**（háo táo）＝大哭。**先笑后号咷**＝先是笑，后来大哭。**丧牛**＝丢了牛（**牛在《周易》中取坤之象，为"顺"之德；对照离卦卦辞"畜牝牛，吉"**）。**易**＝**疆界、边邑**（一说读"轻易"，即"轻易地丢了"；两解皆通，本卡并录）。**其义焚也**＝**按道理就该被烧。****终莫之闻也**＝**最终没有人听说（他的事）。** |

#### ⚠️ 专项：这一爻为什么是本卦最狠的一句

| 核实项 | 结论 |
|---|---|
| 它写了几层？ | **四层，一层比一层深**：<br>**① 鸟焚其巢**——窝被烧了（**而且是自己筑的窝，不再是借住的旅舍**）；<br>**② 先笑后号咷**——情绪的完整抛物线：先得意，后大哭；<br>**③ 丧牛于易**——**把"顺"这个根本的德，在边界上（或者轻易地）丢了**；<br>**④ 终莫之闻也**——**最后连声音都没人听见。** |
| 象传怎么判责任？ | **⚠️ 六个字，不留余地："以旅在上，其义焚也。"**<br>**以客居的身份坐到最上面，被烧是**应当的**。**<br>**"义"＝理当。《周易》没有说他运气不好、没有说主人排外，它说：按道理就该这样。** |
| 与九三的象传是什么关系？ | **⚠️ 同一个罕见句式，本卦独有的一对**：<br>**九三"**以旅**与下，**其义**丧也"**——以客居之身处置下面的人，丢掉他们是应当的；<br>**上九"**以旅**在上，**其义**焚也"**——以客居之身坐到最上面，被烧是应当的。<br>**⚠️ 两条合起来，就是客居身份的两条禁令：不许向下行权（九三），不许向上占位（上九）。而《周易》两次都用"其义……也"下判——不是警告，是"理当如此"。** |
| "丧牛于易"丢的是什么？ | **牛在《周易》中是"顺"之德的象**（离卦卦辞"畜牝牛，吉"——本库离卡即以"畜养柔顺"读之）。<br>**⚠️ 而"顺"正是彖传给旅卦的核心指令："柔得中乎外而**顺**乎刚"。**<br>**所以"丧牛"＝**把这一卦唯一的活路丢了**。上九坐到最上面，就不再"顺乎刚"了——于是它丢的不是一头牲畜，是旅卦的卦德本身。** |
| "终莫之闻也"有多重？ | **⚠️ 极重，而且方式很特别：它不是"身败名裂"，是"没人听说"。**<br>**对照六五"终以誉命"——六五最终得到的是"誉"（声誉）；上九最终是"莫之闻"（没有声誉，连负面的都没有）。**<br>**⚠️ 两爻紧挨着，一个"终以誉命"，一个"终莫之闻"。《周易》把客居者的两种结局并排放在了最后两爻。** |

| 字段 | 内容 |
|---|---|
| **⚠️ "先笑后号咷"：客居者最典型的一条时间曲线** | **爻辞没有写他做了什么，只写了他的情绪顺序：先笑，后大哭。**<br>**⚠️ "笑"在前面，说明这件事一开始是成功的——他真的坐上去了，而且高兴。**<br>**⚠️ 落到现代（原型极常见）**：**外派的人被扶正了、并购后被留下来的人当上了负责人、借住的亲戚成了这个家实际做主的人、驻场的乙方接管了甲方的团队。一开始所有人都笑。**<br>**然后"鸟焚其巢"：那个位置本身把他烧了——他没有根，坐在最高处，所有人的力量都从下面顶上来（而他已经不"顺乎刚"了）。**<br>**⚠️ 而"丧牛于易"给出了机制：他是在"易"（边界上）丢了牛。边界正是客居者的身份线。**<br>**他一跨过那条线（从客变成主），就把"顺"丢了；而"顺"是他唯一的立足点。** |

| **不该做** | ① 不要在客居中接受最高位置——**象传判"其义焚也"（理当被烧）**；② **不要在"先笑"的阶段以为已经过关**——爻辞把笑写在最前面，正是为了告诉你笑不是结果；③ 不要丢"顺"（丧牛）——**顺是旅卦唯一的立足点，彖传原话是"顺乎刚"**；④ 不要指望被理解——**"终莫之闻也"说明这一爻的结局是无人听说，不是众人指责。** |

**旅卦三句话**：
1. **守正要按身份重新定义。** 卦辞不是"贞吉"，是"**旅**贞吉"。**同一件正确的事，主人做是对的，客人做就是错的**——这就是九三为什么当位、守正，却判"贞厉"。
2. **机制是"止而丽乎明，顺乎刚"（彖传）。** **先止住自己（艮在下：脚下的地方不是你的），再附着于外面的光（离在上：名分不在你身上），并顺从你压着的那股力量（六五乘刚而"上逮"）。** 客居者不自己发光，也不像明夷那样藏光——只能"丽"。
3. **纲领的灵魂是"不留"（大象传"不留狱"）。** **火在山上，烧过就走。** 而全卦两处"焚"（九三焚其次、上九焚其巢）的病根都是"想留"：把旅舍当家，把窝当位置。

**本卦最反直觉的四条**：
- **六爻没有一个"吉"字。** 全卦唯一的"吉"在卦辞的"旅贞吉"里，还带着身份限定。**而条件最好的六二（唯一当位得中）只拿到"终无尤也"。⚠️ 如果你在客居里期待"吉"，那不在这一卦的许诺范围内。**
- **九三当位、守正、判断也对，判词却是"贞厉"，象传还说"其义丧也"（理当丢掉）。** **《周易》在这里把责任完全放在身份误判上——不是你错了，是你不是这里的人。**
- **九四"我心不快"是全卦唯一的第一人称，而《周易》既不判它有咎，也不给它任何动作。** 象传只补了四个字："**未得位也**"。**不快的原因是没有位置，而位置本来就不属于客居者——所以这份不快不需要被解决。**
- **上九是"先笑后号咷"，笑在前面。** **《周易》特意把成功写在前面，就是要告诉你："坐上去了"不是过关的信号，是被烧的开始。** 而它给的判据是六个字：**"以旅在上，其义焚也。"**

## 四、⚠️ 本卦对全库的意义

### 1. ⚠️ 丰／旅逐爻并列：本库"离在下 vs 离在上"这条结构律的完整实证

**丰（55，上震下离）与旅（56，上离下艮）……⚠️ 严格地说，这一对的变量不止一个**：丰＝震＋离，旅＝离＋艮。**但它们是覆卦（丰上下颠倒即得旅），而且"离"这个三画卦在两卦里恰好一个在下、一个在上。所以就"离的三爻能不能站住"这一点，两卦构成一次干净的对照。**

**机械核对**：
- **丰**六爻自下往上：**阳 阴 阳 ｜ 阳 阴 阴**（下离，上震）
- 整卦上下颠倒：**阴 阴 阳 ｜ 阳 阴 阳** ＝ **旅**（下艮，上离）✓

> **⚠️ 结论一（结构律的直接实证）**：
> **离＝阳阴阳，而下卦的位序是"阳阴阳"、上卦的位序是"阴阳阴"。**
> **所以离落在下卦时，三爻的阴阳与位序完全同步 → 初、二、三全部当位（丰）；**
> **落在上卦时，三爻的阴阳与位序完全相反 → 四、五、上全部不当位（旅）。**
> **⚠️ 这不是概率，是恒等式。规格第 4 节的条文"离：在下 → 三爻全当位；在上 → 三爻全不当位"在本对卦上得到最干净的一次并列验证：同一个三画卦，位置换一下，三个当位就变成三个不当位。**
> **同时它满足渐卡（53）第四节第 2 条那条覆卦律：一对覆卦的当位数之和恒为 6（4 ＋ 2 ＝ 6 ✓）。**

> **⚠️ 但必须立刻加一条限定，否则会把这条相关性用错**：**本批另一对覆卦（渐 53 ／ 归妹 54）不服从这个规律。** 渐 4 当位、3 个吉；**归妹只有 2 当位，却也有 2 个吉（初九"征吉"、六五"吉"）。**
> **为什么？因为归妹那两个吉都是"靠降低自己换来的"**：初九"归妹以娣"（认下次要身份）、六五"其君之袂不如其娣之袂良"（主动降格）。**结构差，但还有"往下降"的空间可用。**
> **⚠️ 而旅卦一个吉也没有，正因为客居者本来就在最低处，没有"再降"的余地可用——他能做的只有"顺"和"付"。**
> **⚠️ 合读结论（建议入库，这是本批对结构律最重要的一条限定）：当位数不能换算成吉凶。它只告诉你"这一卦有多少爻站得住"；一卦能不能拿到吉，还要看它有没有可用的"降"的余地。结构差而有降的余地（归妹）仍可得吉；结构差而已在最低处（旅）就只剩"无尤"。**

### 2. ⚠️ "明与狱"四卦分级：同一个"离"配四种另一半，给出四种司法指令

**贲卡（22）第四节曾把噬嗑与贲对照，并明确留下一个指引：「顺带打开第三卦：旅 56（上离下艮）＝贲的上下颠倒……三卦合读，《周易》对'明'与'狱'的关系给了一组完整的分级。」**
**本批产出的丰（55）与旅（56）把这一组补成了四卦。⚠️ 而且这四卦恰好是"离＋震"与"离＋艮"两组各自的上下两种叠法：**

| 卦 | 卦象 | 离在哪 | 另一半 | 大象传取象 | 主语 | **对"断案／用刑"的指令** | 指令的性质 | 当位数 |
|---|---|---|---|---|---|---|---|---|
| **噬嗑 21** | 上离下震 | **上**（光在身外） | **震＝威／动**（在下，动在自己手里） | **雷电** | **先王以**（制度层） | **明罚敕法** | **只能事前立法**：把罚则明白地挂出来、整饬法度 | 2 |
| **丰 55** | 上震下离 | **下**（明德在内，三爻全当位） | **震＝威**（在上） | **雷电皆至** | **君子以** | **折狱致刑** | **可以当场断，并且执行** | 4 |
| **贲 22** | 上艮下离 | **下**（明在内，三爻全当位） | **艮＝止**（在上，止在头顶） | **山下有火** | **君子以** | **明庶政，无敢折狱** | **明令禁止断案**：只能办明白小事 | 4 |
| **旅 56** | 上离下艮 | **上**（光在身外） | **艮＝止**（在下，止在自己） | **山上有火** | **君子以** | **明慎用刑而不留狱** | **可以用刑，但必须明慎，且不许积压** | 2 |

> **⚠️ 从这张表读出来的四条结论**：
>
> **① 同一个"离"，配不同的另一半，对同一件事（该不该断案）给出四种完全不同的指令：只能立法（噬嗑）／可以断并执行（丰）／绝不许断（贲）／可以断但要慎而不留（旅）。**
> **《周易》没有一条关于"断案"的普遍规则——它只有四条按结构分派的授权。**
>
> **② "离"提供的是"明"（看得清），但决定这份明能拿去做什么的，是另一半三画卦。**
> **配震（威）→ 可以动手**（噬嗑立法、丰断案执刑）；
> **配艮（止）→ 必须收手**（贲不许断、旅慎而不留）。
> **⚠️ 落到现代最实用的一句：你看得清，不等于你有权处置。授权来自你手上有没有"威"（执行力与地位），不来自你有多明白。**
>
> **③ 而"离在下／在上"决定的是权限的层级与稳固程度。**
> **离在下（丰、贲）＝明德在内、三爻全当位 → 主语都是"君子以"，指令都很具体（折狱致刑／明庶政）；**
> **离在上（噬嗑、旅）＝光在身外、三爻全不当位 → 噬嗑被推到"先王以"（只有最高立法者能做），旅被限定成"明慎……不留"（能做但要提防）。**
> **⚠️ 这印证了规格第 4 节"离在上＝光在你身外（名不正）"：名不正的时候，你要么把动作升到制度层（噬嗑），要么把动作压到"不留"（旅）——两条都是在回避"以个人名义处置个人"。**
>
> **④ ⚠️ 四卦的指令恰好构成一条从严到宽的完整量表，可直接当作产品里的"我有资格处理这件事吗"决策树**：
> **我看得清这件事不对 →**
> **· 我头上有"止"（上面压着，不许我动）→ 贲：不许断，只办明白小事（无敢折狱）。**
> **· 我脚下有"止"（我是客、没有根）→ 旅：可以处理，但必须明慎，而且处理完就交出去、不留在自己手上（明慎用刑而不留狱）。**
> **· 我有"威"但名分在别人手上 → 噬嗑：不要处理个案，去把规则事先立明白（明罚敕法）。**
> **· 我"明"与"威"皆至（一瞬）→ 丰：现在断，现在执行，把积案清掉（折狱致刑）。**

### 3. ⚠️ 例外记录：「凡卦有离，纲领必与'辨'有关」这条一律不成立，建议废止并替换

**本库原有一条一律：「凡卦有离，纲领（大象传）必与'辨'有关」，并已把既济（63）"思患而豫防之"记为第一个明确例外。**
**⚠️ 本卡按要求核对了旅、丰两卦，并顺带把本库全部含"离"的卡逐条核了一遍。结果是：这条一律远不止一个例外，它在绝大多数样本上都不成立。**

**⚠️ 先回答直接的问题**：
- **旅 56 大象传"山上有火，旅。君子以明慎用刑而不留狱"——不含"辨"。**（含"明"与"慎"。）

> **含"辨"的只有 2 卦：同人 13（类族辨物）与未济 64（慎辨物居方）。**
> **不含"辨"的有 12 卦。**
> **⚠️ 也就是说：这条一律在 14 个可核样本中只成立 2 例（约 14%）。既济 63 不是"第一个例外"，它是第十几个——大有、噬嗑、贲、离、晋、明夷、家人、睽、革都早已是例外，只是此前没有被逐条核过。**
>
> **⚠️ 建议（不是从"必"降为"多"，而是废止并替换）**：
> **原条文"凡卦有离，纲领必与'辨'有关"应当**删去**——"多"这个程度词也撑不住，因为 2/14 不构成"多"。**
> **建议替换为下面这条，它在 14 个样本中成立 12 例，且能解释剩下 2 例为什么例外**：
>
> > **【替换条文】离提供"明"（看得清）；含离之卦的纲领，其核心动词几乎都是"明的某一种用法"——照（离 30）、昭（晋 35）、明罚（噬嗑 21）、明庶政（贲 22）、明慎（旅 56）、明时（革 49）、晦（明夷 36，收明）、辨（同人 13、未济 64，用明分类）、同而异（睽 38，分辨同异）、遏恶扬善（大有 14，分辨后取舍）。**
> > **"辨"只是这些用法之一，而且是少数（2/14）。**
> > **⚠️ 而"这份明拿去做什么"由另一半三画卦决定**（配震则动手、配艮则收手，见本节第 2 条的四卦分级）。
> > **真正的例外有两个：家人 37"言有物而行有恒"与既济 63"思患而豫防之"——两卦的纲领都不涉及"明"的任何用法。**
> > **⚠️ 一个边界样本：丰 55"折狱致刑"字面不含"明"字，但"折狱"本身就是明察之事，且彖传明写"明以动，故丰"。可记为"义含而字不含"。**
>
> **⚠️ 顺带一条更稳的规律（本节第 2 条已论证，此处只作索引）**：**含离之卦的纲领动词，可以按"另一半是哪个三画卦"两两配对预测**——**离＋震 → 罚／断刑（噬嗑、丰）｜离＋艮 → 禁断／慎断（贲、旅）｜离＋乾 → 分类与取舍（同人、大有）｜离＋坤 → 昭明德／用晦（晋、明夷）｜离＋坎 → 防患／慎辨居方（既济、未济）｜离＋兑 → 辨同异／明时（睽、革）。**
> **⚠️ 每一对里两卦的上下位置正好相反，而纲领属于同一族。这条比"辨"那条一律有解释力得多，建议作为新条文入库。**

### 4. "艮在下"的三条经文与三个危险的九三（本批最重要的结构发现）

**本库现有三个"艮在下"的卦：咸 31（上兑下艮）、渐 53（上巽下艮）、旅 56（上离下艮）。三卦给出两条整齐的规律：**

**① 三卦彖传全部以"止而□"起句，句式完全一致：**

| 卦 | 卦象 | 彖传原句 | 上卦之德 | 全句机制 |
|---|---|---|---|---|
| **咸 31** | 上兑下艮 | **止而说** | 兑＝悦 | 自己先止住，对方才会愉悦 |
| **渐 53** | 上巽下艮 | **止而巽，动不穷也** | 巽＝顺／入 | 内有止，所以动起来不会穷 |
| **旅 56** | 上离下艮 | **止而丽乎明** | 离＝明 | 止住自己，附丽于外面的光 |

> **⚠️ 结论（建议补入规格第 4 节）**：**"艮在下"这个结构，《周易》自己有固定读法，句式是"止而＋上卦之德"。**
> **含义：艮在下不是"你被卡住了"，是"你的内部先止住，然后才能与外部那个德发生关系"。**
> **⚠️ 而三卦的凶／厉，全部是"没止住"的三种形态**：咸变成"来兑"式的追（六二"凶，居吉"）、渐变成"夫征不复"（九三凶）、旅变成"焚其次"（九三贞厉）。

**② ⚠️ 三卦的九三全部当位，判词全部负面，且全部是各自卦里最坏或次坏的一爻**（完整对照表见本卡九三一节）：
**咸九三"往吝"（所执下也）｜渐九三"凶"（离群丑也）｜旅九三"贞厉"（其义丧也）。**

> **⚠️ 机械原因**：**艮＝阴阴阳，唯一的阳在最上。所以"艮在下"时，九三必然是阳居阳位（当位），而且它是下卦唯一的阳——它就是"止"这个力量本身，同时又处在下卦之顶，即该止之地。**
> **⚠️ 于是这一爻构成一个固定的陷阱：有力量（阳）、有名分（当位）、到了卦之过半，而卦德要求它不动。**
> **⚠️ 三爻的病根完全相同：手里握着"止"的力量却没有用它。** 咸拿去跟随，渐拿去前征，旅拿去行权。
> **⚠️ 实操价值极高：只要你的处境里含"艮在下"（内部有一个止的机制），那么"我刚站稳、我有力量、我看得清、我想动一下"这个组合就是最危险的时刻。三卦的答案完全一致——不动。**
> **⚠️ 这也补上了本库"三多凶"专题的一个空白**：此前的样本（师六三、否六三、归妹六三）都可以用"位不当"解释；**咸／渐／旅这三个九三全部当位，说明"三多凶"另有一条独立的来源——当位而不行卦德。**

### 5. 旅卦补上的缺口

| 缺口 | 旅卦补的内容 |
|---|---|
| **本库路由表在"离乡、外派、寄居、在别人的地盘上做事"这一大类上完全空缺**（贲卡 22 已明确点出这是"高频困境"） | **旅卦是本库第一张、也是唯一一张专讲"客居"的卡。** 它的定位极清楚：**脚下的地方不属于你（艮在下），头上的名分不属于你（离在上），所以你只能"止而丽乎明"。** |
| **"明与狱"分级只有三卦（噬嗑、贲，加丰卡新增的一卦）** | **旅补齐第四卦，四卦构成一条从严到宽的完整量表，可直接做成"我有资格处理这件事吗"的决策树**（本节第 2 条）。 |
| **"守正"在本库一直是无条件的** | **⚠️ 旅卦辞"旅贞吉"第一次给"贞"加了身份限定词，而九三"贞厉"给出了反证：守正而身份错，一样危。**<br>**这是本库第一次出现"守正需要先问身份"的口径，建议作为一条独立通则入库。** |
| **"乘刚破解"三条都是"缩小作用面"型，且都是爻级归纳** | **旅补上第四条，且是唯一"改变方向"型（顺它，把关系往上接），并且有卦级彖传背书（"顺乎刚"）。** |
| **"情绪如何入账"没有明确口径** | **旅九四"我心不快"是全书少见的第一人称，而《周易》既不判咎也不给动作，象传只补"未得位也"。**<br>**口径：只要有实际所得（资斧），不快就只是不快——不构成咎，也不需要被解决。** |
| **上爻通则缺一条统一解释** | **本批四个上爻（渐吉、归妹凶、丰凶、旅凶）给出：上爻吉凶不由当位决定，由"这个卦有没有把'止'内置在上行过程里"决定**（本卡上九一节）。 |
| **原有"离＝辨"一律不成立** | **本卡逐条核了 14 个样本（2 例成立、12 例不成立），建议废止该条并替换为"离提供明、另一半决定明的用法"**（本节第 3 条）。 |
