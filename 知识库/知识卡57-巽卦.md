# 知识卡 57 · 巽卦（巽 / 风）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："旅而无所容，故受之以巽。巽者，入也。"——漂泊在外无处容身，所以要"入"。
> **本卦是八纯卦之一（上巽下巽），是兑卦（58）的反卦、震卦（51）的错卦。**
> ⚠️ **本卡是本库现有小畜卦（9）那个"小"字的源头**：小畜＝上巽下乾，其天花板之所以是"小"，根子在**巽卦卦辞本身就只给"小亨"**（详见卦级字段与末节）。
> ⚠️ **本卡还提供全书最好的"同辞异断"教材**：**九二与上九爻辞里都有"巽在床下"四个字，一个"吉，无咎"，一个"贞凶"。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 巽 · 第五十七卦 · **八纯卦之一** |
| **卦象** | 上巽下巽，**随风**（风接着风）。**一阴伏于二阳之下**——柔在下而承二刚，故为"顺"、为"入"、为"风"、为"长女" |
| **⚠️ "巽"字的双义（本卦全部义理的根）** | 序卦传定为"**入**"，说卦传定为"**顺**"。**两义必须合读：巽的力量方式是"以顺而入"——不靠强度，靠无处不至。**<br>**风的性质就是本卦的方法论**：① **无形**（看不见，但到处都在）；② **无阻**（缝隙再小也进得去）；③ **必须持续**（风一停，什么都没留下）。 |
| **领域定义** | **渗透式影响与软性推动**。说服、教化、推行制度／政令、改变风气、影响一个不受你管的人、在没有强制力的情况下推动事情；也包括**"顺从"这件事本身的分寸**。凡是"我没有权力硬推，只能一点一点让它渗进去"，都落在巽卦。 |
| **不归本卦的情况** | 你有实力但被压住、蓄而未发 → **小畜卦**（结构上是巽压乾，但重点在"畜"）；在强势结构中求自身安全 → **履卦**；靠愉悦沟通聚人 → **兑卦**。**巽卦特指"用柔顺去渗透和改变"这个动作。** |
| **卦辞原文** | 巽：小亨，利有攸往，利见大人。 |
| **⚠️ 卦辞的关键特征（本卦定性）** | **不是"亨"，是"小亨"。** 全书六十四卦里明写"小亨"的极少。**《周易》一上来就给这条路定了天花板：以柔顺渗透的方式做事，能通，但只能小通。**<br>**这与本库小畜卦卡的判断完全一致**："**小**字定性了本卦的天花板：这种积累是有限的、这种约束是不牢固的"——**其源头就在这里。** |
| **卦辞现代解** | **小亨**——路通，但成就有限；**不要用巽的方法去追求大的、快的、结构性的结果**。<br>**利有攸往**——适宜有所前往：**柔顺不是不动，是要往外走、往里渗**。<br>**利见大人**——**适宜见大人**。这三个字是本卦的关键补充：**柔顺渗透这条路，单靠自己只能"小亨"；要突破这个上限，必须借助"大人"（有位有德者）的力量。**（对照乾九二、乾九五、蒙六五皆有"利见大人"之义。） |
| **彖传** | 重巽以申命，柔皆顺乎刚，是以小亨，利有攸往，利见大人。 |
| **彖传要点** | ① **重巽以申命**——**两重风相随，所以要"申命"（反复申明命令）**。风一次吹不透，就吹第二次、第三次。**这是本卦最实用的一条方法：柔性推动的关键不是力度，是次数。**<br>② **柔皆顺乎刚**——全卦两个阴爻（初六、六四）都顺从于上面的阳刚。**"是以小亨"——正因为全是柔顺刚，所以只能小通。《周易》把"小"的原因说得很直白：一味顺，就大不了。** |
| **大象传（行动纲领）** | 随风，巽。君子以申命行事。 |
| **⚠️ "申命行事"解（顺序不可颠倒）** | **先"申命"，后"行事"。** 反复申明在前，动手在后。<br>**这是艮卦"思不出其位"之外，八纯卦里第二条纯粹的管理纪律**：**任何要靠别人配合才能成的事，通知一次就动手，等于没通知。** 具体刻度见九五的"先庚三日，后庚三日"。 |
| **总铁律** | ① **巽只给"小亨"**——柔顺渗透的天花板就是小，认这个上限；要破限，须"利见大人"；② **顺的第一个病是犹豫**（初六"进退"），解药是借一份"武人之贞"；③ **顺的第二个病是一味地顺**（九三"频巽，吝"）——会把路走窄、心志走穷；④ **顺的正确用法是拿到可分配的实际成果**（六四"田获三品"），不是讨好；⑤ **变更任何规矩，前后各留三天反复申明**（九五"先庚三日，后庚三日"）；⑥ **居高位还一味卑顺，会丢掉断决之力**（上九"丧其资斧，贞凶"）。 |

## 二、爻级字段

### 初六 · 进退（顺的第一个病：犹豫）

| 字段 | 内容 |
|---|---|
| **爻辞** | 进退，利武人之贞。 |
| **象传** | 进退，志疑也。利武人之贞，志治也。 |
| **位属性** | 阴爻居阳位，**不当位**；居全卦最下——**柔之极，顺之始** |
| **判词 → 行动语义** | **无吉凶判词，只给病症与药** → **借一份刚硬来定住心志** |
| **关键词解** | **进退**＝进也不定、退也不定，**犹豫不决**（爻辞只有两个字，就把"过分柔顺"的第一个后果写完了）。**武人之贞**＝武人那样的刚正守持。 |
| **⚠️ 象传把病因和药效都点明了** | "**志疑也**"——**心志疑惑**，这是"进退"的病因；"**志治也**"——**心志得到治理**，这是药效。<br>**结论：柔顺的第一个代价不是被欺负，是自己没主意。** 而《周易》给的药不是"更顺"，是**反向的一味刚**。 |
| **识别信号** | ① 事情需要你表态，你反复在两个选项间移动；② 你的犹豫来自"怕得罪人""想两边都照顾"；③ 你已经拖了一段时间，且拖延本身在消耗信用。 |
| **该做** | **借"武人之贞"**——给自己设一条不可退让的硬线（时间线、底线条件、一个不再商量的原则），**用刚硬把心志钉住**。 |
| **不该做** | 继续用柔顺处理犹豫。**在巽卦里，"再顺一点"治不了"没主意"。** |
| **与坤卦六二的对照（重要）** | 坤卦是辅佐者纲领，六二"直方大"——**柔顺者的正道是"直（正直）、方（有棱角）、大（能承载）"。** **注意"方"字：连最柔顺的坤卦都要求一份棱角。** 巽初六的"武人之贞"与坤六二的"方"是同一味药——**纯柔不是德，纯柔是病。** |

### 九二 · 巽在床下（吉）

| 字段 | 内容 |
|---|---|
| **爻辞** | 巽在床下，用史巫纷若，吉，无咎。 |
| **象传** | 纷若之吉，得中也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**——下巽之中 |
| **判词 → 行动语义** | **吉，无咎** → **退到极低处，用反复诚敬的方式反复沟通** |
| **关键词解** | **巽在床下**＝卑顺到床底下去，**姿态低到极处**。**史巫**＝祝史与巫祝，**古代专职沟通神人的人**，其特征是仪式繁复、态度极诚。**纷若**＝繁多、反复之貌。 |
| **⚠️ 本爻的核心：为什么极度卑顺在这里是吉的** | 象传只给了两个字的理由：**"得中也"**。<br>**九二不当位（阳居阴位，名不正言不顺），但它得中。** 按本库通则"**⚠️ 得中可救不当位**"——**得中让它的极度卑顺成为一种手段，而不是一种沦落。**<br>而"**用史巫纷若**"点明了这份卑顺的正确形态：**不是低头认输，是像祝史巫祝那样反复地、诚敬地、不厌其烦地沟通**——**这正是彖传"重巽以申命"在爻上的落实。** |
| **识别信号** | ① 你要推动的事，对方比你强势得多，你没有任何强制力；② 你在这件事上位置不正（不是你的职权范围）；③ 但你处在核心枢纽位置，事情实际要靠你办（得中）。 |
| **该做** | **把姿态放到最低，把沟通次数加到最多。** 不谈条件、不摆道理，反复、诚恳、具体地讲同一件事。 |
| **不该做** | 因为"姿态太低了没面子"而改用硬的。**本爻的吉，全部来自"低姿态 ＋ 高频次"这个组合。** |
| **⚠️ 与上九的对照（本卦最重要的一组，必须合读）** | **上九爻辞里也有"巽在床下"四个字，判词却是"贞凶"。**<br>**同样的动作，一个吉，一个凶。差别只有一条：九二"得中"，上九"上穷"。**<br>**结论（可直接入库为通则）：低姿态本身无吉凶。它在枢纽位置上是方法（吉），在到顶位置上是失能（凶）。**（详见上九） |

### 九三 · 频巽（顺的第二个病：一味地顺）

| 字段 | 内容 |
|---|---|
| **爻辞** | 频巽，吝。 |
| **象传** | 频巽之吝，志穷也。 |
| **位属性** | 阳爻居阳位，**当位**；居下巽之顶；本库通则"**三多凶**" |
| **判词 → 行动语义** | **吝**（按本库口径：**路越走越窄，趋势极差**） → **停止无原则的一再退让** |
| **关键词解** | **频**＝频繁、一再、屡屡（一说通"顿"，皱眉之貌，义亦相通）。**频巽**＝**反复地卑顺、没完没了地退让**。 |
| **⚠️ 本爻与九二的分界（本卦最需要分清的一条）** | **九二"巽在床下…纷若"是吉的，九三"频巽"是吝的——两者都是"反复地顺"，为什么一吉一吝？**<br>**九二的反复，是同一件事反复沟通（申命）——次数用在"讲清楚"上。**<br>**九三的反复，是一次次让步（频巽）——次数用在"退"上。**<br>**申命可以反复，退让不能反复。** 象传判"**志穷也**"（心志困穷）：**每退一次，自己的余地就少一分，退到最后心志就穷了。** |
| **为什么当位却"吝"** | 九三是**阳爻居阳位、刚健当位之才**。**它本该有刚，却在做"一再卑顺"的事——违背了自己的本性和位置。** 本库通则"三多凶"在此处的具体形态是：**在该硬的位置上软，路只会越走越窄。** |
| **识别信号** | ① 你已经让了不止一次，每次都想"这是最后一次"；② 每次让完，对方的要求都会再抬一点；③ 你开始感到"没什么可给的了"（志穷）。 |
| **该做** | **停止退让，回到初六的药：立一条"武人之贞"的硬线。** 把反复的次数从"退"转到"讲"（九二的申命）。 |
| **不该做** | 再让一次。**"吝"是趋势判词——它不说你现在有多糟，它说你正在走窄。** |
| **与屯六三、蒙六四的呼应** | 本库判词表已收两条"吝"：**屯六三"往吝穷也"**、**蒙六四／上九**。**三处"吝"的共同点是"路窄且心志穷"**。**巽九三的独特处在于：它的窄是自己一次次让出来的。** |

### 六四 · 田获三品（顺的正确用法）

| 字段 | 内容 |
|---|---|
| **爻辞** | 悔亡，田获三品。 |
| **象传** | 田获三品，有功也。 |
| **位属性** | 阴爻居阴位，**当位**；**乘于九三之上——乘刚**；本库通则"**四多惧**" |
| **判词 → 行动语义** | **悔亡** ＋ **有功** → **柔顺者要拿出实实在在、可分配的成果** |
| **关键词解** | **田**＝田猎。**三品**＝所获分为三类用途（古注：**干豆（祭祀）、宾客（待客）、充君之庖（供养）**）——**不只是"猎到很多"，而是"猎到的东西正好覆盖三个必须交付的方向"。** |
| **⚠️ 本爻是全卦唯一被象传明判"有功"的爻** | 全卦其余五爻讲的都是姿态、心志、分寸；**只有六四讲"结果"。**<br>**这是巽卦最重要的正面指令：柔顺的价值不由态度证明，由成果证明；而且成果必须是"三品"——能分配、能覆盖各方所需的那种。**<br>**换句话说：顺不是讨好，顺是"我用柔的方式，把各方要的东西都拿到手并分好"。** |
| **"悔亡"的含义** | 按本库吉凶序：**无咎 ＞ 悔亡 ＞ 悔**。**悔亡＝本来该有的悔恨消失了。** 六四当位却乘刚（下面顶着九三这个刚爻），本该有悔；**是"田获三品"这个实绩把悔消掉的。** |
| **识别信号** | ① 你处在执行层／中层，用柔性方式在推事；② 你下面（或旁边）有强硬的力量在顶你（乘刚）；③ 你手上有机会做出一个实际成果。 |
| **该做** | **交付成果，并且主动把成果分给三个方向**——上面要的、同侧要的、下面要的。**"三品"的重点是分配设计，不只是产出。** |
| **不该做** | 用态度和辛苦来证明自己。**在四位（多惧之位）靠姿态活着，是撑不住的；靠"有功"才撑得住。** |
| **与小畜六四的对照（同一爻位，同一个巽）** | 小畜卦（上巽下乾）的**六四正是那"一阴畜五阳"的关键爻**——以一柔制五刚，所以只能"小畜"、只能"密云不雨"。**巽六四同样是巽的那个柔爻，但它不去"畜"（约束别人），而是去"获"（做出成果）。**<br>**结论：同一个柔爻，用来压制别人只能"密云不雨"；用来产出成果就能"有功"。** 这是本库小畜卡与本卡之间最有价值的一条互补。 |

### 九五 · 先庚三日（卦主，全卦最好之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 贞吉，悔亡，无不利。无初有终。先庚三日，后庚三日，吉。 |
| **象传** | 贞吉，位正中也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位——全卦卦主 |
| **判词 → 行动语义** | **贞吉 ＋ 悔亡 ＋ 无不利 ＋ 吉**（全卦判词最密集之爻） → **变更任何规矩，前后各留三天反复申明** |
| **⚠️ 判词密度的意义** | 按本库吉凶序：**元吉 ＞ 无不利／大吉 ＞ 吉 ＞ 利 ＞ 无咎 ＞ 悔亡**。**本爻一口气给了"无不利"（约等于大吉）＋"贞吉"＋"悔亡"＋"吉"。**<br>**在一个卦辞只给"小亨"的卦里，出现这样一个判词密集的九五——说明"巽"这条路的上限不是被能力锁住的，是被方法锁住的：方法对了（申命），柔顺也能到"无不利"。** |
| **"无初有终"解** | **开头没有，结尾有。** 柔性渗透的必然形态：**一开始看不见效果，效果全部出现在后段。**<br>**这是巽卦给所有做长期渗透工作的人的一句承诺，也是一个提醒：前期的"没动静"是正常的，不是失败信号。** |
| **⚠️ "先庚三日，后庚三日"解（全书最具操作性的一条指令）** | **"庚"在古义中通"更"，即变更、更改。**（对照蛊卦"先甲三日，后甲三日"，"甲"是开始——**始事用甲，更事用庚**。）<br>**全句：在变更之日的前三天、后三天，都要反复申明。**<br>**这就是彖传"重巽以申命"、大象传"申命行事"的具体刻度**：<br>**① 变更前三天**——反复讲清楚"要改什么、为什么改、什么时候生效"；<br>**② 变更后三天**——反复确认"改到了没有、有谁没跟上、哪里卡住"。<br>**中间那一天（庚日）才是真正动手的一天，它只占全过程的七分之一。** |
| **识别信号** | ① 你在拍板位置上，要改一个规矩／流程／政策／习惯；② 这件事需要很多人配合，你没法靠强制推到底；③ 你倾向于"通知一下就执行"。 |
| **该做** | **把"通知"扩成前后各三天的申命窗口。** 前三天讲，后三天追。**并接受"无初有终"——前期不会有反馈。** |
| **不该做** | 一次通知即执行。**在巽卦里，这不是效率，这是让整件事回到"小亨"甚至失败。** |
| **与师卦初六的呼应（两条"开工前"纪律）** | **师初六"师出以律，否臧凶"——组织化对抗，开打前必须先立纪律，"边打边理"是死路。**<br>**巽九五"先庚三日"——柔性变革，动手前必须先反复申明。**<br>**两卦一刚一柔，给出的却是同一条纪律：真正的准备动作发生在开始之前。** |

### 上九 · 巽在床下（贞凶）

| 字段 | 内容 |
|---|---|
| **爻辞** | 巽在床下，丧其资斧，贞凶。 |
| **象传** | 巽在床下，上穷也。丧其资斧，正乎凶也。 |
| **位属性** | 阳爻居阴位，**不当位**；居全卦之终——**且象传判"上穷也"（到顶而穷）** |
| **判词 → 行动语义** | **贞凶**（**即使守正也凶**，同屯九五"大贞凶"、师六五"弟子舆尸，贞凶"之重） → **此爻不可入** |
| **关键词解** | **巽在床下**——与九二**完全相同**的四个字。**丧其资斧**——"资"是赖以为生的资财，"斧"是工具、**也是断决之具**：**丢掉了本钱，也丢掉了下判断、做决断的能力。** |
| **识别信号** | ① 你已在高位／到顶位置；② 你的应对方式是一味退让、不表态、不拍板、把决定权让出去；③ 你开始发现自己既没有资源可调，也没有人再来问你意见（丧其资斧）。 |
| **该做** | **把"斧"拿回来——在自己职责范围内做出至少一个明确的决断。** 姿态可以低，**决断权不能让。** |
| **不该做** | 继续以"我很谦和""我不专断"为由回避决断。 |

#### ⚠️ 九二 ↔ 上九 对照：全书最好的"同辞异断"教材

| 对照项 | **九二** · 巽在床下 | **上九** · 巽在床下 |
|---|---|---|
| 爻辞相同部分 | 巽在床下 | 巽在床下 |
| 位属性 | 不当位，**但得中** | 不当位，**且上穷** |
| 补充动作 | **用史巫纷若**（反复诚敬沟通） | **丧其资斧**（丢掉本钱与决断力） |
| 象传理由 | **得中也** | **上穷也** / **正乎凶也** |
| 判词 | **吉，无咎** | **贞凶** |

| 字段 | 内容 |
|---|---|
| **⚠️ 结论（可直接入库为通则）** | **同一个"低姿态"动作，在枢纽位置（得中）上是方法，在到顶位置（上穷）上是失能。**<br>**九二低头，是为了把话讲进去；上九低头，是因为已经没有别的可做。** 前者手里还有"斧"（判断力），后者把斧丢了。<br>**这条通则可推广到全库：判断一个"退让／示弱"动作的吉凶，不看动作本身，看做这个动作的人是否还握着决断权。** |
| **为什么"贞凶"** | 按本库判词表，**"贞凶"是很重的判词**——**守正也凶，说明问题不在品德，在处境与选择的根本错位。** 一个已在高位的人，**其职责就是决断（斧）**；他若一味卑顺，就是**在放弃自己唯一不可放弃的职能**。**正因为他"守正"（老实、恭顺、不争），才更逃不掉这个凶。** |
| **与乾上九、艮上九的三角对照** | **乾上九"亢龙有悔"——到顶而不知止，因"过刚"而悔**；**艮上九"敦艮，吉"——到顶而主动止，因"知止"而吉**；**巽上九"贞凶"——到顶而一味顺，因"过柔"而凶。**<br>**三个上爻把"到顶之后"的三种可能走完了：过刚则悔，过柔则凶，知止则吉。** |

## 三、巽卦定位速查表

| 爻 | 处境 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | 柔之极 | 进退 | 反复犹豫，怕得罪人 | 不当位 | **借武人之贞**·立硬线定志 |
| 九二 | 枢纽位·无强制力 | 巽在床下 | 对方强势得多，但事要靠你办 | 不当位但**得中** | **吉·无咎**·低姿态＋高频沟通 |
| 九三 | 该硬处发软 | 频巽 | 已经让了不止一次，每次都想是最后一次 | 当位·三多凶 | **吝·志穷**·停止退让 |
| 六四 | 执行层·被顶着 | 田获三品 | 下面有硬力量顶你，你手上有个机会 | 当位·**乘刚** | **悔亡·有功**·交付可分配的成果 |
| 九五 | 居尊变革（**卦主**） | 先庚三日 | 要改一个规矩，且必须靠人配合 | **当位·得中·居尊** | **无不利**·前后各留三日申命·无初有终 |
| 上九 | 到顶仍一味顺 | 丧其资斧 | 在高位却不肯拍板，也没人再问你 | 不当位·**上穷** | **贞凶**·把决断权拿回来 |

**巽卦三句话**：
1. **柔顺渗透的天花板就是"小亨"**（卦辞）。认这个上限；要突破，只有两条路：**"利见大人"（借力）** 与 **九五的"申命"（方法）**。
2. **顺有两个病**：**犹豫**（初六"进退"，药是"武人之贞"）与**一味地顺**（九三"频巽，吝"）。**申命可以反复，退让不能反复。**
3. **顺的价值由成果证明，不由态度证明**（六四"田获三品，有功"）。**而变更任何规矩，前三天讲、后三天追，中间那一天才动手**（九五）。

**本卦最反直觉的三条**：
- **"巽在床下"四个字，九二是"吉，无咎"，上九是"贞凶"。** **差别只在得中与上穷——低姿态在枢纽位置上是方法，在到顶位置上是失能。判断退让的吉凶，看做这个动作的人是否还握着决断权。**
- **一个卦辞只给"小亨"的卦，九五却是全卦判词最密集的爻（无不利／贞吉／悔亡／吉）。** 说明**"小"锁的是方法，不是上限**：方法对了（申命），柔顺也能到"无不利"。
- **同一个柔爻，用来"畜"（压制别人）只能密云不雨（小畜六四）；用来"获"（做出成果）就能有功（巽六四）。**

## 四、⚠️ 本卡对全库的意义

### 1. 补齐小畜卦（9）的源头

本库小畜卡的判断——"**'小'字定性了本卦的天花板：这种积累是有限的、这种约束是不牢固的**"——**其结构来源在此**：

| | 小畜 9 | 巽 57 |
|---|---|---|
| 卦象 | 上巽下乾 | 上巽下巽 |
| 卦辞 | **亨**，密云不雨，自我西郊 | **小亨**，利有攸往，利见大人 |
| 关键柔爻 | **六四**（一阴畜五阳） | **六四**（田获三品，有功） |
| 该柔爻的用法 | **畜**（约束五阳）→ 密云不雨 | **获**（产出成果）→ 有功 |

> **合读结论**：**巽的柔用来"压"，成不了事（小畜）；用来"渗"和"产"，才有功（巽六四）。** 本库小畜卡讲"以柔制刚"，**巽卡补上的是"以柔成事"——同一个工具的两种用法，效果完全不同。**

### 2. 巽在上／在下结构律

| | 占初、二、三位（下卦） | 占四、五、上位（上卦） |
|---|---|---|
| **巽**（阴阳阳） | 初六不当位、九二不当位（**得中**）、九三**当位** | 六四**当位**、九五**当位**（**得中**）、上九不当位 |

> **巽在上 → 六四、九五皆当位，九五更是当位得中居尊**：**这是巽最好的位置**（小畜、观、益、渐、涣、家人、中孚皆属此类）。
> **巽在下 → 初、二皆不当位，只有九三当位**：**柔在最底下，容易犯"进退"（犹豫）与"频巽"（一再退让）两个病**（姤、升、恒、蛊、井、鼎、大过皆属此类）。
> 与已有各律合记：**坎在下＝已在险中；离在上＝光在身外；震在上＝动在头顶；艮在上＝被压住不许动；巽在下＝柔在底下，最易犹豫与滥让。**
