# 知识卡 58 · 兑卦（兑 / 泽）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："入而后说之，故受之以兑。兑者，说也。"（**"说"读作悦**）——渗进去了，然后才能让人愉悦。
> **本卦是八纯卦之一（上兑下兑），是巽卦（57）的反卦、艮卦（52）的错卦。**
> ⚠️ **本卡补上本库履卦（10）彖传里那个"说"字的来源**：履卦彖传"**说而应乎乾**"——**履卦之所以"履虎尾而不咥人"，机制就是下卦的兑（悦）**。读完本卡，履卦"极险的处境里也有安全的走法"这句话才有了具体内容（见末节）。

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 兑 · 第五十八卦 · **八纯卦之一** |
| **卦象** | 上兑下兑，**丽泽**（两泽相连、互相润泽）。**一阴现于二阳之上**——刚在内而柔在外，故为"悦"、为"泽"、为"口"、为"少女" |
| **⚠️ 与巽的结构互补** | **巽是一阴伏于二阳之下（柔在内，顺而入）；兑是一阴现于二阳之上（柔在外，悦而通）。** 同样是"一阴二阳"，**巽把柔藏起来往里渗，兑把柔露出来让人愉悦。** |
| **领域定义** | **愉悦、和顺沟通、聚人与团队氛围**。让人愿意跟你共事、把话说得让人听得进去、经营团队士气、社交与人情往来、谈判中的气氛营造；也包括**"取悦"的边界在哪里**。凡是"这件事要靠人心愿意，而不是靠规则强制"，都落在兑卦。 |
| **不归本卦的情况** | 是要选择跟谁站在一起 → **比卦**（择主与结盟）；是要在强势结构中安全通行 → **履卦**；是要用柔顺渗透去改变别人 → **巽卦**。**兑卦特指"让人愉悦"这个动作本身，以及它的五种形态（见爻级字段）。** |
| **"兑"字义** | 说（悦）、泽、口。**注意本卦的立场：《周易》对"愉悦"的评价极高，但把条件写得极死。** |
| **卦辞原文** | 兑：亨，利贞。 |
| **⚠️ 卦辞的关键特征** | **全书最短的卦辞之一，只有四个字：亨，利贞。**<br>**注意语序是"亨，利贞"**——先给"亨"（通），再给"利贞"（正才有益）。**它不像巽卦那样只给"小亨"，而是直接给"亨"：《周易》承认愉悦是一条真正通得开的路。**<br>**但"利贞"是紧跟着的限定：悦必须走正道，否则"亨"立刻作废。** |
| **彖传** | 兑，说也。刚中而柔外，说以利贞，是以顺乎天而应乎人。说以先民，民忘其劳；说以犯难，民忘其死；说之大，民劝矣哉。 |
| **⚠️ 彖传要点（本卦纲领，两条都极重要）** | ① **"刚中而柔外"（本卦最实用的五个字）**——**里面刚硬得中，外面柔和悦人。**<br>指的是九二、九五两个阳爻得中（刚中），六三、上六两个阴爻在外（柔外）。**这句话把"悦"的正确形态一次说完了：悦是外表的事，内核必须是刚的。外柔而内也柔，就是六三的"来兑，凶"。**<br>② **"说以先民，民忘其劳；说以犯难，民忘其死"**——**用愉悦带头，人们会忘记劳苦；用愉悦去赴难，人们会忘记生死。**<br>**这是《周易》对"人心愉悦"给出的最高评价**，也是全书唯一一处把某种情绪的力量描述到"民忘其死"的程度。**"说之大，民劝矣哉"——悦的力量之大，能让民众自己互相勉励。** |
| **大象传（行动纲领）** | 丽泽，兑。君子以朋友讲习。 |
| **⚠️ "朋友讲习"解（全书最温暖也最容易被跳过的一条纲领）** | 两泽相连、水互相润泽——**所以君子的对应动作是"和朋友一起讲论、切磋、学习"。**<br>**这是六十四卦大象传中唯一明确以"朋友"为主体的一条**，而且它对"悦"的最高形态给了一个出人意料的答案：**不是娱乐、不是宴饮、不是社交，是"讲习"——一起把事情想明白。**<br>**结论：兑卦认为，人最深的愉悦来自互相润泽的智力交流；这也解释了为什么"来兑"（讨好）反而是凶——讨好是单向输出，不构成"丽泽"（互相润泽）。** |
| **总铁律** | ① **悦必须"刚中而柔外"**——外柔可以，内核必须刚且得中（彖传）；② **悦的正确形态只有两种**：**和兑**（和顺，初九）与**孚兑**（诚信，九二）；③ **主动去讨好求悦是凶**（六三"来兑，凶"），象传的理由是"位不当"；④ **诚信不能给该剥落之人**（九五"孚于剥，有厉"）——**即使你位置完全正当**；⑤ **悦的最高形态是"朋友讲习"**，不是娱乐（大象传）。 |

## 二、爻级字段

> ⚠️ **本卦六爻结构极清晰，是全书分类最工整的一卦**：**五个爻各给了"兑"的一种形态——和兑、孚兑、来兑、商兑、引兑**，判词从"吉"一路到"凶"再到"未光"。**读本卦可以直接当作"愉悦的五种形态分类表"用**（速查表见第三节）。

### 初九 · 和兑（吉）

| 字段 | 内容 |
|---|---|
| **爻辞** | 和兑，吉。 |
| **象传** | 和兑之吉，行未疑也。 |
| **位属性** | 阳爻居阳位，**当位**；居全卦最下——**悦之始，且是最纯净的一种** |
| **判词 → 行动语义** | **吉** → **和顺地愉悦，不带目的** |
| **关键词解** | **和**＝和顺、平和、无所偏党。**和兑**＝**平和自然地让人愉悦**，没有讨好、没有算计、没有针对特定的人。 |
| **⚠️ 象传给的理由是本爻的全部重量** | "**行未疑也**"——**他的行为里没有可疑之处**。<br>**这是"和兑"之所以吉的唯一原因：不是因为它效果好，是因为它经得起怀疑。** 一旦让人觉得"你对我这么好是想干什么"，和兑就不成立了。 |
| **识别信号** | ① 你和人相处是舒服的，且不针对特定对象；② 你没有在这段关系里图什么具体的东西；③ 别人不会揣测你的动机。 |
| **该做** | 保持无目的的和顺。**这一爻不需要额外动作——它的价值在于"没有可疑之处"，任何附加目的都会破坏它。** |
| **不该做** | 把已经建立的和顺关系拿去兑换具体好处。**一兑换，就掉到六三的"来兑"。** |
| **与比卦的辨析** | 比卦（8）讲**归附与结盟**，卦辞明确要"原筮，元永贞"（反复审慎地择对象）；**兑初九的"和兑"恰恰相反——它不择对象、不谈条件。** **两者不冲突，分工不同：兑管日常关系的底色，比管关键时刻站到谁那一边。** |

### 九二 · 孚兑（吉，悔亡）

| 字段 | 内容 |
|---|---|
| **爻辞** | 孚兑，吉，悔亡。 |
| **象传** | 孚兑之吉，信志也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**——下兑之中，即彖传"刚中"之一 |
| **判词 → 行动语义** | **吉 ＋ 悔亡** → **以诚信让人愉悦** |
| **关键词解** | **孚**＝诚信、内在的真实（本库需卦卦辞"有孚"、坎卦卦辞"有孚"同字）。**孚兑**＝**建立在诚信之上的愉悦**。 |
| **⚠️ 本爻与初九的分工** | **初九"和兑"是态度层面的（和顺、无可疑）；九二"孚兑"是内容层面的（说真话、守承诺）。**<br>象传"**信志也**"——**心志是可信的**。<br>**两爻合起来就是彖传的"刚中而柔外"**：**九二是那个"刚中"（内核诚信得中），初九是那个"柔外"的日常形态。** |
| **本爻不当位却吉的原因** | 阳居阴位，名不正言不顺；**但它得中。** 按本库通则"**⚠️ 得中可救不当位**"——**在兑卦里，"得中"具体表现为"诚信"：不管你位置正不正，说真话的人站得住。** |
| **"悔亡"的意义** | 按本库吉凶序：**吉 ＞ 无咎 ＞ 悔亡**。本爻同时给了"吉"和"悔亡"——**既得吉，又把本该有的悔消掉了。** 不当位本会带来悔，**诚信把它抵掉了。** |
| **识别信号** | ① 你在关系里处于"办事的枢纽"位置（得中）；② 你的位置名分不完全正（不当位）；③ 你面临"要不要说实话／要不要承认做不到"的选择。 |
| **该做** | **说真话，包括说"我做不到"。** 用诚信而不是用姿态去维持关系。 |
| **不该做** | 用善意的模糊话维持气氛。**在兑卦里，模糊话是"引兑"（上六）的开端——不害人，但成不了事。** |
| **与需卦、坎卦"有孚"的呼应（三处"孚"的对照）** | **需卦卦辞"有孚"——资源争取期，诚信是取利的前提**；**坎卦卦辞"有孚，维心亨"——重险之中，诚信是唯一的凭据**；**兑九二"孚兑"——愉悦关系中，诚信是愉悦的地基。**<br>**三卦领域完全不同（取利／脱险／聚人），却都把"孚"放在最前面。这是本库跨卦最强的一条共识。** |

### 六三 · 来兑（凶）

| 字段 | 内容 |
|---|---|
| **爻辞** | 来兑，凶。 |
| **象传** | 来兑之凶，位不当也。 |
| **位属性** | 阴爻居阳位，**不当位**（**象传直接点名"位不当也"**）；居下兑之顶；本库通则"**三多凶**"；**且乘于九二之上，是乘刚**——"来兑"的冲动来自下面顶上来的刚。 |
| **判词 → 行动语义** | **凶** → **此爻不可入** |
| **关键词解** | **"来"是自外向内、主动招引。****来兑**＝**主动去求人愉悦、上门去讨好**。<br>与初九"和兑"（自然的和顺）、九二"孚兑"（诚信的愉悦）相比，**六三是唯一"主动往对方那里去"的悦——也就是讨好、逢迎、巴结。** |
| **⚠️ 本爻是全卦唯一的"凶"，而且是本卦全部禁令的所在** | 象传给的理由只有四个字：**"位不当也"**。<br>**为什么讨好一定"位不当"？因为讨好这个动作本身就宣告了"我的位置不足以让你自愿愉悦"。** 它是**用姿态去补位置的亏空**，而按本库通则，不当位＝名不正言不顺、风险高。**姿态补不了位置。**<br>**再对照大象传"丽泽"（互相润泽）：讨好是单向输出，不构成互相润泽，所以它连兑卦的门都进不来。** |
| **识别信号（诊断清单）** | ① 你在主动、持续地对某个人／某个群体输出好处、好话、好脸；② 对方并没有同等回应，你也不觉得对等；③ 你的位置本来就名分不足（资历、授权、话语权有一样欠缺）；④ 你心里清楚这是"为了让他高兴"，不是"因为我愿意"。 |
| **该做** | **立刻停止单向输出，回到九二的"孚兑"**——把关系的基础从"让他高兴"换成"我说的话是真的"。**姿态的亏空只能用诚信补，不能用更多姿态补。** |
| **不该做** | 加大讨好力度。**这一爻是全卦唯一的"凶"，且没有给爻内解药——解药只在别的爻（九二）。** |
| **与巽九三"频巽，吝"的对照（两个"三"的分野）** | **巽九三"频巽，吝"——一再退让，路越走越窄，判词是"吝"（趋势极差）**；**兑六三"来兑，凶"——主动讨好，判词直接是"凶"。**<br>**按本库吉凶序，凶重于吝。** 差别在哪？**巽九三是当位之才做了软事（还有回头的余地）；兑六三是不当位者做了讨好的事（连位置都不正，所以直接凶）。**<br>**合起来的通则：退让伤趋势，讨好伤根本。** |
| **与讼卦、师卦的呼应** | 讼卦"作事谋始"、师卦"师出以律"讲的都是**开头就要立正**。**兑六三反过来给出了"开头就立歪"的样本**：**一段用讨好开局的关系，位置从第一天起就不正。** |

### 九四 · 商兑未宁

| 字段 | 内容 |
|---|---|
| **爻辞** | 商兑未宁，介疾有喜。 |
| **象传** | 九四商兑未宁，介疾有喜。 |
| **位属性** | 阳爻居阴位，**不当位**；处上下两兑之交；本库通则"**四多惧**" |
| **判词 → 行动语义** | 未宁（不安）→ **有喜** → **在"要不要悦"上纠结时，把那个毛病隔断，就有喜** |
| **关键词解** | **商**＝商量、权衡、斟酌。**商兑未宁**＝**在"该不该让他愉悦／该不该迁就"这件事上反复权衡，心里不安宁**。<br>**介**＝隔绝、界断，也有"坚定守节"之义。**疾**＝毛病、病害。**介疾**＝**把那个毛病隔断开**。**有喜**＝有可喜之事。 |
| **⚠️ 本爻的象传是全书少见的"原文重述"** | 兑卦九四的小象几乎完全重复爻辞，**没有给出额外解释**——按本库"待校"口径，此处需注意版本差异。**但这个"不解释"本身也有信息：这一爻的动作已经写在爻辞里了，无须再释——纠结（商兑未宁）之后，动作就是"介疾"（切断病处）。** |
| **本爻的处境** | 九四不当位、又在两重"悦"的交界上：**下面是已经建立起来的一片和气（下兑），上面是新的一片（上兑）**。**它必须决定：这片和气里有哪些是病的（疾），要不要切。**<br>**"未宁"是准确的心理描写——切了会得罪人，不切会烂掉。** |
| **识别信号** | ① 团队／关系里气氛很好，但你知道其中有一块是有问题的（有人在和稀泥、有人在用人情换资源、有个不能提的话题）；② 你反复权衡要不要动它，睡不好（未宁）；③ 你担心一动就破坏整体气氛。 |
| **该做** | **"介疾"——只隔断那个病处，不动整片和气。** 精准切除，不做整体清算。**爻辞承诺的是"有喜"：切对了会带来可喜的结果。** |
| **不该做** | 因为怕破坏气氛而一直"商兑未宁"。**纠结本身没有判词，也就是说它既不吉也不凶——它只是耗着。** |
| **与离上九"获匪其丑"的呼应（同一种精准）** | **离上九"有嘉折首，获匪其丑"——只斩首恶，不牵连从众**；**兑九四"介疾有喜"——只隔断病处，不动整片和气。**<br>**两爻是同一条方法在两个领域的表达：处理问题时，切口要小而准。扩大范围，离卦会变成"焚如"，兑卦会毁掉整个"丽泽"。** |

### 九五 · 孚于剥（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 孚于剥，有厉。 |
| **象传** | 孚于剥，位正当也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位——全卦卦主，即彖传"刚中"之另一 |
| **判词 → 行动语义** | **有厉**（按本库口径：**警告，非判死**） → **别把诚信给该剥落的人** |
| **关键词解** | **孚**＝诚信（与九二同字）。**剥**＝剥落、消损、侵蚀（《周易》另有剥卦 23，卦义即"剥落"）。**孚于剥**＝**把诚信施加于正在剥损你的对象／已经该剥落的人事**。 |
| **⚠️ 本爻是全卦最需要小心读的一爻** | **它是全卦位置最好的一爻——当位、得中、居尊，象传还特别强调"位正当也"。可是判词是"有厉"（危）。**<br>**这个组合传递的信息极明确：位置完全正当，也不能保证不出危险；出危险的原因不在位置，在你把"孚"（诚信）给了错误的对象。**<br>**同一个"孚"字，在九二是"吉，悔亡"，在九五是"有厉"——差别只在给谁。** |
| **象传"位正当也"该怎么读** | 有两层可读，本库取合读：① **位置正当，所以这个"厉"不至于成凶**（当位提供了缓冲）；② **正因为位置正当（居尊、有德、讲信用），才特别容易把诚信给到不该给的人**——**居尊者的诚信是稀缺资源，谁都想要。** |
| **⚠️ 与本库现有三卦的强呼应（同一条铁律的第四次出现）** | **蒙卦"蒙以养正"**——**绝不能将一身本领交给无德之人**；<br>**师上六"小人勿用，必乱邦也"**——**赏错了人，赢了的仗也会输掉**；<br>**比卦卦辞"原筮，元永贞"**——**归附之前必须反复审断对象是否为"正源"**；<br>**兑九五"孚于剥，有厉"**——**诚信给错了对象，居尊当位也有危。**<br>**四处指向完全同一件事：《周易》反复警告的不是"你不够好"，是"你把好东西给了不该给的人"。** |
| **识别信号** | ① 你在被信任、被依赖的位置上（当位得中居尊）；② 有人正在持续消耗你的信用、资源、耐心，而没有回报；③ 你倾向于"再信他一次""不能不讲信用"。 |
| **该做** | **把"孚"收回来。** 讲信用是对人，不是对所有人：**对正在剥损你的对象，守信用就是继续供血。** 用九四的"介疾"处理它——精准隔断，不做整体清算。 |
| **不该做** | 以"我一向讲信用"为由继续给。**"有厉"是警告，说明还来得及；若继续，就会掉到比卦"后夫凶"那种被清算的位置。** |

### 上六 · 引兑（⚠️ 全卦唯一无判词之爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 引兑。 |
| **象传** | 上六引兑，未光也。 |
| **位属性** | 阴爻居阴位，**当位**；居全卦之终；**且乘于九五之上，是乘刚**。 |
| **判词 → 行动语义** | **无判词，仅象传"未光也"** → **不害人，但成不了事** |
| **关键词解** | **引**＝牵引、延长、引诱。**引兑**＝**把愉悦拉长、把人引来让自己愉悦**。<br>**全卦最短的爻辞，只有两个字，且是全卦唯一没有吉凶判词的爻。** |
| **⚠️ "无判词"本身就是判词（本库口径）** | 按本库判词表，从"元吉"到"凶"共十级，**上六一级都没占**。**《周易》既不判它吉，也不判它凶——只给了象传三个字："未光也"（不能光大）。**<br>**这是一种"白过"的状态：你没做错什么，也没成就什么。** |
| **本爻为什么"未光"** | 上六当位，本该不错；**但它居兑之终，只剩"延长愉悦"这一件事可做。**<br>**悦到了尽头还想再拉长，就只能靠"引"（牵引、引诱），而不再有新的内容。** 对照大象传"**丽泽**"（两泽互相润泽）——**"引"是单方面拉扯，不是互相润泽，所以不能光大。** |
| **识别信号** | ① 一段关系／一个团队的高兴劲已经过去，你在想办法把气氛再撑一会儿；② 你开始靠组织活动、找话题、请客、发福利来维持愉悦；③ 你说不出这段关系现在还在共同做什么。 |
| **该做** | **回到大象传的"朋友讲习"——给这段关系一个新的共同内容（一起把一件事想明白、学明白、做明白）。** 悦要靠内容续命，不能靠"引"。 |
| **不该做** | 靠加大娱乐和人情投入延长愉悦。**它不会带来凶，只会带来"未光"——时间白花。** |
| **与震九四"遂泥"的呼应（全书两处"未光也"）** | **震九四"震遂泥"象传"未光也"——有能力想动，但陷在泥里动不了**；**兑上六"引兑"象传"未光也"——想维持愉悦，但没有新内容可给。**<br>**两处的共同点：都无吉凶判词，损失都只是时间与声望。** 按本库吉凶序，**"未光"是最轻的一档负面结果——它的唯一代价是白过。** |
| **与乾上九、艮上九、巽上九的四角对照** | **乾上九"亢龙有悔"——过刚不知止，悔**；**巽上九"贞凶"——过柔而丧决断，凶**；**艮上九"敦艮，吉"——主动止到极处，吉**；**兑上六"引兑，未光"——不刚不柔，只是没内容了。**<br>**四个上爻把"到顶之后"走完了：过刚则悔，过柔则凶，知止则吉，无内容则白过。** |

## 三、兑卦定位速查表

### ⚠️ 核心表：愉悦的五种形态（本卡最实用的一张表）

| 形态 | 爻 | 含义 | 判词 | 机制 |
|---|---|---|---|---|
| **和兑** | 初九 | 平和自然、不针对人、无目的 | **吉** | 行未疑也（经得起怀疑） |
| **孚兑** | 九二 | 建立在诚信上、说真话 | **吉·悔亡** | 信志也（心志可信） |
| **来兑** | 六三 | **主动讨好、上门逢迎** | **凶** | 位不当也（用姿态补位置的亏空） |
| **商兑** | 九四 | 在"该不该迁就"上反复权衡 | 未宁 → **有喜** | 介疾（只隔断病处） |
| **引兑** | 上六 | 靠牵引和活动延长愉悦 | **无判词** | 未光也（没有新内容，白过） |
| *（九五不是一种"兑"，而是对"孚"的警告）* | 九五 | 把诚信给了该剥落之人 | **有厉** | 位正当也（位正也挡不住给错人） |

### 全爻速查

| 爻 | 处境 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | 关系底色 | 和兑 | 相处舒服，且不图什么 | **当位** | **吉**·保持无目的的和顺 |
| 九二 | 办事枢纽 | 孚兑 | 名分不足，但事靠你办 | 不当位但**得中** | **吉·悔亡**·说真话，含"我做不到" |
| 六三 | 单向讨好 | 来兑 | 持续对某人输出好处好话，对方不对等 | **不当位**·三多凶 | **凶**·立即停止·回到孚兑 |
| 九四 | 和气里有病处 | 商兑未宁 | 气氛好，但有一块明显是烂的 | 不当位·两兑之交 | **介疾有喜**·只切病处 |
| 九五 | 被信任者（**卦主**） | 孚于剥 | 有人在持续消耗你的信用，你还想再信一次 | **当位·得中·居尊** | **有厉**·把孚收回来 |
| 上六 | 悦已到尽头 | 引兑 | 高兴劲过了，你在想办法撑气氛 | 当位 | **未光**·给关系一个新内容 |

**兑卦三句话**：
1. **"刚中而柔外"**（彖传）——**悦是外表的事，内核必须是刚的、得中的。** 外柔而内也柔，就是六三的"来兑，凶"。
2. **悦只有两种正确形态：和兑（无可疑）与孚兑（说真话）。** **讨好（来兑）是唯一的凶，因为它是用姿态去补位置的亏空，而姿态补不了位置。**
3. **悦的最高形态是"朋友讲习"**（大象传）——**一起把事情想明白。** 靠娱乐和人情延长的愉悦（引兑）不害人，但"未光"，只是白过。

**本卦最反直觉的三条**：
- **九五是全卦位置最好的一爻（当位、得中、居尊，象传还强调"位正当也"），判词却是"有厉"。** **同一个"孚"字，九二给对了人是"吉"，九五给错了人是"厉"——出危险的原因从来不在位置，在给谁。**
- **上六是全卦唯一没有吉凶判词的爻。** 《周易》对它既不奖也不罚，只说"未光"。**这提示本库判词表下方还需要一档："无判词 ＋ 未光"＝不害人也不成事，代价是时间。**
- **《周易》对愉悦的评价极高**——"说以先民，民忘其劳；说以犯难，民忘其死"（彖传）。**但它把力气全花在划边界上：全卦六爻，两爻讲怎么悦，四爻讲什么不算悦。**

## 四、⚠️ 本卡对全库的意义

### 1. 补上履卦（10）"说而应乎乾"的机制

本库履卦卡指出：履卦"**极险的处境里也有安全的走法**"，其彖传是"**履，柔履刚也。说而应乎乾，是以履虎尾，不咥人，亨**"。
**那个"说"就是兑**——**履卦＝上乾下兑，即"以兑之悦去应乾之刚"。**

| | 履 10 | 兑 58 |
|---|---|---|
| 卦象 | 上乾（天／刚）**下兑（泽／悦）** | 上兑下兑 |
| 处境 | 履虎尾 | 丽泽 |
| 机制 | **说而应乎乾** → 不咥人 | 刚中而柔外 → 亨 |

> **合读结论（这是本卡最有价值的一条互补）**：**履卦"老虎不咬你"的原因，不是运气，是"兑"——你以愉悦而非对抗的方式去应对那个刚强者。**
> **而兑卦六三"来兑，凶"正好给出了这个方法的边界**：**应乎乾（以悦相待）是对的，来兑（上门讨好）是凶的。**
> **两卦合起来，本库对"如何与远比自己强大的对象相处"这个高频问题才算给全了答案：以悦相应，但绝不讨好。**

### 2. 兑在上／在下结构律

| | 占初、二、三位（下卦） | 占四、五、上位（上卦） |
|---|---|---|
| **兑**（阳阳阴） | 初九**当位**、九二不当位（**得中**）、六三不当位 | 九四不当位、九五**当位**（**得中**）、上六**当位** |

> **兑在上 → 九五当位得中居尊、上六当位**：**悦在外、在上，位置较正**（夬、萃、随、咸、困、革、大过皆属此类）。
> **兑在下 → 只有初九当位，六三必不当位**：**"来兑，凶"这个陷阱只在兑居下卦时出现**（履、临、归妹、损、节、睽、中孚皆属此类）。**本库已有的履卦正属此类——所以读履卦时，六三那一爻要格外小心。**
> 八纯卦结构律至此全部齐备，合记如下：
> **坎在下＝已在险中｜离在上＝光在身外｜震在上＝动在头顶｜艮在上＝被压住不许动｜巽在下＝柔在底下易犹豫滥让｜兑在下＝易落入讨好的陷阱。**

### 3. 八纯卦的共性：上下敌应，全卦无援

艮卦彖传的一句话对**全部八个纯卦**都成立：**"上下敌应，不相与也。"**

**因为纯卦上下两卦相同，所以初↔四、二↔五、三↔上 每一对应爻必然同性相斥，全卦没有一对"相应"。**

> **这解释了八纯卦为什么都特别硬**：**它们描述的都是"没有外援、只能靠自己那点东西"的处境**——
> 乾靠自强不息，坤靠厚德载物，坎靠"维心亨"，离靠"畜牝牛"，震靠"恐惧修省"，艮靠"思不出其位"，巽靠"申命"，**兑靠"朋友讲习"**。
> **八条纲领全部是"对自己下的指令"，没有一条依赖别人。这是八纯卦作为全书地基的真正含义。**
