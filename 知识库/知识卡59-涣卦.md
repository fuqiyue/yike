# 知识卡 59 · 涣卦（风水涣）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："兑者，说也。说而后散之，故受之以涣。涣者，离也。"——**兑卦的愉悦聚起了人，而愉悦之后必然涌向离散**：一团和气到了尽头（兑上六"引兑，未光"），人就开始各奔各的。涣卦接管的正是"这个群已经散了"这件事。
> **本卦与节卦（60）是覆卦对**：涣（上巽下坎）整个倒过来看就是节（上坎下兑）。**序卦传把这一对的关系写得极清楚："物不可以终离，故受之以节。"——涣讲怎么处理已经散的，节讲怎么不再散。两卦必须合读。**
> ⚠️ **本卡填的是同人卦（13）留下的一个机制缺口**：同人六二"同人于宗"被判"**吝道也**"（范围太窄则路窄），**但同人卦没有给出"人已经在宗里了，怎么办"的动作。涣六四"涣其群，元吉"就是那个动作。**（详见末节）

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 涣 · 第五十九卦 |
| **卦象** | 上巽（风/入）下坎（水/险），称"**风水涣**"。**风行水上，水波涣然而散**——聚在一起的东西被吹开了。<br>**按本库第 4 节结构律，本卦的当位分布是完全确定的**：**坎在下 → 初、二、三三爻全不当位**（初六、九二、六三）；**巽在上 → 四、五当位，上不当位**（六四、九五当位，上九不当）。<br>**这个分布本身就是卦义**：**下半截（初二三）没有一个位置是正的——涣散的根源在下面，不在上面。而上半截六四、九五都正，九五更是当位得中居尊，正是"巽在上＝巽最好的位置"。所以涣卦的解药全部在上半截。** |
| **⚠️ 卦象的三层读法** | ① **风行水上**——外力吹散内部（外部环境变了，队形自己就散了）；<br>② **坎在下＝已在险中**（本库六大危险位置之一）——**涣不是从平地开始散的，是在险境里散的**；<br>③ **巽在上＝以顺而入**——**收拾散局的方法是"渗"，不是"抓"**。风散得开，也只有风进得去。 |
| **领域定义** | **已经发生的离散，以及如何在离散中重建凝聚**。① 团队人心散了、核心成员开始各找出路；② 组织重组、部门被拆、项目组解散；③ 一个圈子/社群从活跃走向沉寂，群里没人说话了；④ 家族、合伙关系、长期朋友群的自然疏离；⑤ **你自己内部的涣散**：注意力散、目标散、精力被切成碎片；⑥ 你身处一个小团体里，而这个小团体正在妨碍更大的事。<br>凡是"**本来在一起的，现在正在散开**"，都落在涣卦。 |
| **不归本卦的情况** | ① **要把人接到一个方向上、要凝聚共识** → **同人卦（13）**。**同人是"接通"，涣是"散开"，两者动作相反，但涣六四正是同人的前置动作**（见末节）。<br>② **要把人聚起来、结成组织** → **萃卦（45）**。**⚠️ 全书只有涣、萃两卦的卦辞里有"王假有庙"，而这两卦一散一聚**——见末节专项。<br>③ **冲突已升级、要组织力量去打** → **师卦（7）**。<br>④ **只是在险中出不来，还没散** → **坎卦（29）**。**坎讲脱险，涣讲散局；涣的下卦就是坎，所以涣是"险 ＋ 散"的叠加态。** |
| **"涣"字本义** | 从水，本义是**水流盛大而四散**（《说文》"涣，流散也"）。序卦传直接训为"**离**"。<br>**引申两义，本卦全部用到**：① **消极义——涣散、溃散、离心**（卦名的底色）；② **积极义——涣然、散开、疏通**（如"涣然冰释"）。<br>**⚠️ 本卦最关键的语言事实：全卦六爻，"涣"字出现五次（九二、六三、六四、九五、上九），而其中四次是"涣其X"的主动句式——涣其躬、涣其群、涣王居、涣其血。**<br>**也就是说：涣卦并不教你"如何不散"，它教你"散什么"。** 卦名是被动的（局面散了），爻辞全是主动的（你去散掉某样东西）。**这是本卦最需要先立住的一条口径。** |
| **卦辞原文** | 涣：亨。王假有庙，利涉大川，利贞。 |
| **⚠️ 卦辞的关键结构** | **有亨、有利（两个"利"）、有贞，独缺"元"。**<br>**缺"元"的含义**：**涣不是开创，是善后。** 它不给你从无到有的那一下——散局是既成事实，你只能在残局上重建。**（对照本库同人卦，同样缺"元"，理由同类：都是处理"已经存在的人"。）**<br>**"亨"放在最前面，而且是不带条件的"亨"**：这一点极重要。**坎卦卦辞只敢给"维心亨"（唯有心是通的），巽卦只给"小亨"；而涣直接给"亨"。**<br>**《周易》对"散"的评价并不低——散得对，路是通的。** 但"亨"后面立刻跟了三个限定条件：**王假有庙、利涉大川、利贞**，缺一不可。 |
| **卦辞现代解** | **王假有庙**——"**假**"＝至、格（到达、来到，非"虚假"）；"**有庙**"＝宗庙。**王亲自来到宗庙**。彖传释为"**王乃在中也**"。<br>　　**这是全卦的第一动作，也是最容易被现代读者跳过的一条**：**人心散了的时候，第一件事不是开会、不是留人、不是加激励，是把所有人重新带到一个"高于所有人的共同东西"面前。** 宗庙是那个东西的古代形态——**它高于每一个具体的人，包括王自己**。现代对应：**共同的使命、共同的祖辈/来处、共同签过的那份东西、共同承认的事实、一次所有人都到场的正式仪式。**<br>　　**⚠️ 注意大象传的主语是"先王"不是"君子"**（见下）——**这说明"立庙"是建制级动作，不是个人修养。**<br>**利涉大川**——适宜渡大河，即**可以去做需要跨越重大险阻的大事**。彖传归因于"**乘木有功也**"——**巽为木，坎为水：木在水上就是舟。**<br>　　**这是全卦最反直觉的一句：一个正在涣散的局面，卦辞却说"可以去干大事"。理由不在人多，在"有舟"——散开的水面上，只要有一条船（一个共同的载体），就能过河。**（对照本库：需卦"利涉大川"靠**往有功**、同人靠**乾行**、大畜靠**应乎天**、谦初六靠**卑以自牧**——**涣靠"乘木"，即靠一个共同的载体。这是本库第五种"涉大川资格"。**）<br>**利贞**——有益，但必须守正。**散是可以的，散得偏私就不行。** |
| **彖传** | 涣，刚来而不穷，柔得位而上同。王假有庙，王乃在中也。利涉大川，乘木有功也。 |
| **⚠️ 彖传要点（三句都要用）** | ① **"刚来而不穷"**——那个阳刚（九二）来到下卦之中，所以不至于困穷。**下卦是坎（险），若下卦全无刚，就是纯粹的溃散；九二这一个刚爻居中，是散局里唯一的支点。**（这正是九二"奔其机"的结构来源。）<br>② **"柔得位而上同"（本卦最实用的五个字）**——那个柔爻（六四）**得位**（六四当位），**而且"上同"（向上与九五同）**。<br>　　**"上同"是涣卦全部积极动作的总纲：散掉横向的小连结，去承接上面那个更高的中心。** 六四"涣其群，元吉"就是它的落实。**没有"上同"，"涣其群"就只是溃散；有了"上同"，它才是元吉。**<br>③ **"王乃在中也"**——王来到宗庙，是**王处于"中"的位置上**。**注意它不说"王在上"，说"王在中"：涣散之时，中心不能悬在上面，必须在人心之中。** |
| **大象传（行动纲领）** | 风行水上，涣。先王以享于帝立庙。 |
| **⚠️ "先王以享于帝立庙"解（注意主语）** | **六十四卦大象传绝大多数以"君子以……"开头（54 卦），主语为"先王"的共 7 卦**（⚠️ 本轮更正：原记"五卦"，漏噬嗑 21、复 24）：**比 8（建万国，亲诸侯）、豫 16（作乐崇德）、观 20（省方观民设教）、噬嗑 21（明罚敕法）、复 24（至日闭关，商旅不行）、无妄 25（茂对时育万物）、涣 59（享于帝立庙）**。<br>**主语从"君子"换成"先王"，含义是明确的：这不是一条个人修养的指令，是一条建制指令——它需要公共身份和公共权力才做得出来。**<br>**为什么涣卦的纲领必须是建制级的？** 因为**一个已经散掉的群体，任何个人都无法靠自身的品德把它拉回来**。风一起，水波必散；要让散开的水重新有方向，只能给它一个共同的岸。**"享于帝"（祭天）＋"立庙"（建宗庙）＝把一个高于所有在场者的东西建起来，并且当众把它做实。**<br>**现代落地（三步，顺序不可换）**：<br>**① 找到那个"帝"**——比所有人都高的、不属于任何人的共同事实（使命、创始那件事、共同的用户、共同承担过的一次危机）；<br>**② "立庙"——把它做成可反复回到的实体**：一份写下来的东西、一个固定的会、一个纪念、一套所有人都认的口径。**庙的要点是"可以再来"**，不是"讲一次"；<br>**③ "王假"——最高位的人必须亲自到场**。彖传"王乃在中也"：**这件事不能授权，不能派代表。** |
| **总铁律** | ① **涣卦不教你"不散"，只教你"散什么"**——全卦四个"涣其X"（躬、群、王居、血），**每一个都是散掉自己这边的东西**；<br>② **第一动作是"王假有庙"**——先立一个高于所有人的共同物，并且最高位者亲自到场；<br>③ **"涣其群，元吉"的条件是"上同"**（彖传）——**散掉小圈子必须同时归入一个更大的中心，否则就只是溃散**；<br>④ **散局之时，号令一出不可收回**（九五"涣汗其大号"）——**这一条与巽九五"先庚三日、后庚三日"的反复申明恰好相反，是本库最需要分清的一对**（见九五）；<br>⑤ **散到最后要把"害"也散掉，然后远离**（上九"涣其血，去逖出"，象传"远害也"）；<br>⑥ **"利涉大川"靠的是"乘木"（一个共同的载体），不是靠人多。** |

## 二、爻级字段

> ⚠️ **本卦六爻的结构极其规整，读法上先立一条**：**初六、九二是"自保"（先别跟着散）；六三、六四、九五、上九是四个"涣其X"（主动散掉某样东西）。** 分界线正好在下卦坎（险）与上卦巽（入）之间。

### 初六 · 用拯马壮

| 字段 | 内容 |
|---|---|
| **爻辞** | 用拯马壮，吉。 |
| **象传** | 初六之吉，顺也。 |
| **位属性** | 阴爻居阳位，**不当位**（坎在下，三爻全不当位）；居全卦最下——**涣之始，且已在坎险最底**；上承九二之刚。 |
| **判词 → 行动语义** | **吉** → **借一份现成的强力，先把自己拔出来** |
| **关键词解** | **拯**＝拯救、举起、拔出（一说"拯"通"升"，义亦相通）。**马壮**＝强壮的马。**用拯马壮**＝**用强壮的马来把（自己/局面）拉出来**。<br>**注意爻辞没有说"你要变强"，说的是"用马"——马是外物，是可以借的。** |
| **⚠️ 象传只给一个字的理由："顺也"** | "**顺**"＝顺承。**初六阴柔无力，它的"吉"不来自自己的力量，来自它顺承九二（那匹"壮马"，即彖传"刚来而不穷"的那个刚爻）。**<br>**这一爻定下了涣卦最开始的姿态：局面散了，你在最下面、最险处、位置还不正——此时不要指望自己发力，要找到那个还立得住的刚，顺上去。** |
| **识别信号** | ① 你所在的团队/关系正在明显松散，你处在最没有话语权的位置；② 你自己的处境本来就已经很险（坎在下），不是从舒适位置开始的；③ 你身边还有一个仍然靠得住、还在正常运转的人或结构（九二）；④ 你的第一反应是"我得自己扛住"。 |
| **该做** | **① 立刻识别出那匹"壮马"**——散局里还没散的那一块（一个仍在正常运转的项目、一位仍然靠得住的上级或同侧、一条还有效的规则）；**② 顺上去，把自己接到它上面。** 不谈条件、不摆姿态，象传给的就是"顺"。 |
| **不该做** | 在最下、最险、位置不正的时候试图靠自己稳住大局。**也不要在这个阶段去"救别人"——初六连自己都要靠马拯。** |
| **与巽初六"利武人之贞"的对照（两个"借刚"）** | **巽初六"进退，利武人之贞"——柔在最底下犯犹豫，药是"借一份武人的刚正"（借的是内心的刚，给自己立一条硬线）**；<br>**涣初六"用拯马壮，吉"——柔在最底下又在险中，药是"借一匹现成的壮马"（借的是外部的刚，把自己接上去）。**<br>**两爻位置完全相同（皆为阴爻居初、皆不当位、皆在柔之极），药方也同类——都是"向刚借力"；差别在借内还是借外。**<br>**合成一条通则（可入库）：柔在最底下的第一动作永远是"借一份刚"。巽卦借的是决心，涣卦借的是外力。** |
| **与坎九二"求小得"的对照** | 坎卦（29）铁律之一是"**只求小得**，此时任何大目标都是幻觉"。**涣初六同样在坎险之中，但它的动作不是"求小得"（自己去取一点），而是"用拯马壮"（借力被拉出来）。**<br>**差别在于：坎卦是纯险（上下皆坎），外面没有任何东西可借；涣卦的上卦是巽，且有九二这个刚爻——所以涣卦允许"借"。** **一句话：纯险中只能自己求小得，险而有援时第一件事是借力。** |

### 九二 · 涣奔其机

| 字段 | 内容 |
|---|---|
| **爻辞** | 涣奔其机，悔亡。 |
| **象传** | 涣奔其机，得愿也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**——下坎之中，**即彖传"刚来而不穷"的那个刚爻**；下有初六来顺，上被六三所乘（六三乘九二之刚）。 |
| **判词 → 行动语义** | **悔亡**（按本库口径：**本该有的悔恨消失了，不是得到好处**） → **在散局中先给自己找一个能凭靠的支点** |
| **关键词解** | **机**＝**几**，即案几、几案，**古人凭靠、依托之具**（一说"机"作机会解，本库取"几案"之义，因它与"奔"字搭配更顺，且与象传"得愿"呼应）。<br>**涣奔其机**＝**在涣散之际，奔向那个可以凭靠的几案**——**找到一个能坐下来、能靠住的落脚点。** |
| **⚠️ 本爻是全卦的结构支点，但判词只有"悔亡"** | **九二是全卦下半截唯一的阳爻，彖传专门为它写了一句"刚来而不穷"——它是散局中唯一没有被吹散的那个东西。**<br>**可是它的判词只有"悔亡"，不是"吉"。为什么？**<br>**因为九二不当位（阳居阴位，名不正）、又身在坎险之中、上面还被六三乘着。它能做到的极限就是"不倒"。**<br>**按本库口径，"悔亡"＝本该有的悔消掉了。九二本该有悔（位不正、在险中、被乘刚），是"奔其机"这个动作把悔消掉的——它没有得到任何额外的好处，它只是没有跟着散。**<br>**这恰恰是涣卦最实用的一条：在一个正在散的局面里，"守住不散"本身就已经是全部的成绩，不要再要求更多。** |
| **象传"得愿也"该怎么读** | "**得愿**"＝所愿得偿。**九二的"愿"是什么？不是升迁、不是扩张，是"有个地方可以靠"。**<br>**《周易》承认这个愿望是正当的，并且判它已经实现了。** 在涣卦的语境里，**"我终于有个能靠住的地方了"就是一个完整的胜利。** |
| **识别信号** | ① 组织/关系在散，而你是实际上还在办事、还被大家默认为枢纽的那个人（得中）；② 但你的名分不足（不当位）——头衔、授权、资历有一项不够；③ 上面有人压着你、消耗你（乘刚）；④ 你正在焦虑"我该做点大事把局面救回来"。 |
| **该做** | **先给自己找到"机"（几案）——一个具体、有边界、能坐得住的支点。** 现代形态：**把自己的职责范围明确成一件事、一个可交付物、一块自己说了算的地盘。** 支点必须是"能凭靠"的，也就是**不依赖别人配合就能立住的东西**。 |
| **不该做** | 在散局中去做"救全局"的大动作。**九二连位置都不正，救全局是九五的事（"涣汗其大号，涣王居"）。** 也不要因为"我是枢纽"而承担全部——**它的判词只有"悔亡"，天道没有许诺你更多。** |
| **与坎九二"求小得"的呼应（同为坎之中）** | **坎九二"坎有险，求小得"——在重险的正中，唯一有效的动作是求一点小的所得。**<br>**涣九二"涣奔其机，悔亡"——在险而散的正中，唯一有效的动作是找一张能靠的几。**<br>**两爻同为坎卦之中的阳爻，动作同类：都把目标压到最小。** 差别是：**坎九二要的是"得"（取一点东西），涣九二要的是"靠"（有个位置）。因为涣的问题不是缺东西，是缺落点。** |
| **与师九二"在师中吉"的对照（同为一卦之中的关键阳爻）** | **师九二是全卦唯一阳爻、五阴所归，判"中吉，无咎"，还有"王三锡命"（被授权）**；<br>**涣九二同样是下卦唯一的刚、同样得中，却只给"悔亡"，没有任何授权。**<br>**差别的全部在于卦德：师卦是"组织起来去打"，所以它的中枢被授权、被嘉奖；涣卦是"局面正在散"，它的中枢连名分都拿不到，只能自己找张几坐下。**<br>**合读结论：同一个"得中而不当位"的枢纽位置，在聚势之卦里是被授权的统帅，在散势之卦里只是一个自己找地方坐稳的人。位置不决定分量，卦时决定分量。** |

### 六三 · 涣其躬（⚠️ 全卦第一个"涣其X"，也是"三多凶"的一个反例）

| 字段 | 内容 |
|---|---|
| **爻辞** | 涣其躬，无悔。 |
| **象传** | 涣其躬，志在外也。 |
| **位属性** | 阴爻居阳位，**不当位**（坎在下，三爻全不当位）；**乘于九二之上——乘刚**；居下坎之顶（险之极）；本库通则"**三多凶**"。 |
| **判词 → 行动语义** | **无悔** → **把"自己"这一层散掉，心志放到外面去** |
| **关键词解** | **躬**＝自身、身体，引申为**自我、己私**。**涣其躬**＝**散掉自己**——不再把自身的得失、面子、位置当成要保的东西。 |
| **⚠️ 判词"无悔"是本库判词表尚未收录的一档（建议入库）** | 本库判词表已有"**悔亡**"（本该有的悔消失了）与"**悔**"（退·止·舍），**但没有"无悔"。**<br>**三者必须分清**：<br>　**悔**＝有悔恨，指令是退/止/舍；<br>　**悔亡**＝**本该有的悔被某个动作消掉了**（是挽回级，如九二"奔其机"）；<br>　**无悔**＝**本来就不会有悔**（不是挽回，是从一开始就没有可悔的东西）。<br>**为什么六三是"无悔"而不是"无咎"或"吉"？**<br>**因为"涣其躬"这个动作不产生外部成果——它不保证事情办成（所以不给吉、不给无咎），它保证的是你自己心里不会留下悔。** 你把"自己"这一层放下了，事情成不成都不再构成你的悔恨。<br>**这是《周易》里少见的、纯粹内向的一条判词。** |
| **⚠️ 本爻是"三多凶"通则的一个清晰反例，且原因可以说清** | **本库通则"三多凶"在已完成各卦中反复兑现**：师六三"舆尸，凶"、兑六三"来兑，凶"、巽九三"频巽，吝"、同人九三"伏戎"。<br>**而涣六三不当位、乘刚、居险之顶、占三位——四项负面条件全齐，判词却只有一个温和的"无悔"。**<br>**原因只有一条：它做的事恰好就是本卦的卦德。**<br>**涣卦的卦德是"散"。六三散的是"躬"（自己）——在一个以"散"为德的卦里，散掉自己就是最正的动作，所以位置再不正也伤不到它。**<br>**⚠️ 合成通则（可入库，与艮上九、大有上九是同一条）：位属性的凶险只在"你做的事与卦德相违"时才兑现。做的事正是卦德本身，四重不当位也压不出凶来。** |
| **象传"志在外也"该怎么读** | "**志在外**"＝**心志在外面，不在自己身上**。<br>**这五个字是"涣其躬"的操作定义**：**不是要你自我否定、自我损害，是要你把注意力的落点从"我怎么样"移到"外面那件事怎么样"。**<br>**同时它也是六三的合理性来源**：六三上无所应、下乘九二，**它在这个位置上唯一能做的就是不再保自己**。 |
| **识别信号** | ① 局面正在散，而你处在最尴尬的位置——不当位、上面顶着人、又在险处最高点；② 你发现自己大部分精力花在"保住我的面子/位置/说法"上；③ 你有一件明确在外面的事（真正要办成的那件事）被这份自我保护挤到了后面；④ 你能感觉到"如果我不那么在乎自己怎么样，这事其实好办"。 |
| **该做** | **主动散掉"躬"这一层**：**① 放弃在这件事上的署名权/面子诉求；② 把话说成"这件事需要怎样"，不说成"我需要怎样"；③ 把心志明确地放到外面那件事上（志在外）。** |
| **不该做** | 在这个位置上争位置。**六三不当位、乘刚、在险顶——它没有一项条件支持它去争。**<br>也不要把"涣其躬"误读成自我牺牲式的付出：**爻辞给的是"无悔"，不是"吉"，它不承诺回报；它承诺的只是你心里干净。** |
| **与谦初六"卑以自牧"的对照** | **谦初六"谦谦君子，用涉大川，吉"，象传"卑以自牧也"——因为管住了自己、没有可乘之隙，所以险境里没有东西能拿住他。**<br>**涣六三"涣其躬"，象传"志在外也"——因为不再保自己，所以在险顶被乘刚也无悔。**<br>**两爻是同一条机制的两种表述：把"自己"这个把手撤掉，别人就没有地方可以抓你。** 差别是：**谦初六收在里面（自牧），涣六三放到外面（志在外）**；一个是"管住"，一个是"移开"。 |
| **与坤六三"无成有终"的呼应** | **坤六三"无成有终"——不居功、功归于上，本库口径是"不是没干成"**；**涣六三"涣其躬"——不保自己，志向在外。**<br>**两爻合起来是本库"不据己"这条纪律的一对：功不归自己（坤），身也不保自己（涣）。** |

### 六四 · 涣其群（⚠️ 全卦唯一"元吉"，本卡最重要的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 涣其群，元吉。 |
| **象传** | 涣其群，元吉，光大也。 |
| **位属性** | 阴爻居阴位，**当位**（巽在上，四、五当位）；**已入上卦巽**；上承九五（尊位之刚）；下临六三（同为阴，**不乘刚**）；本库通则"**四多惧**"。<br>**⚠️ 它正是彖传"柔得位而上同"所指的那个柔爻——"得位"指六四当位，"上同"指它向上与九五同。** |
| **判词 → 行动语义** | **元吉**（本库吉凶序最高一档：**成·根本性圆满**） → **主动打散自己那个小圈子** |
| **关键词解** | **群**＝群党、朋党、小团体。**⚠️ 注意是"其群"——是他自己的那一伙，不是别人的。**<br>**涣其群**＝**把自己所在/所领的那个小圈子散掉。** |
| **⚠️ 为什么"打散自己的小圈子"能得到全卦唯一的"元吉"** | 按本库口径，**"元吉"通常带附加条件，必须指出条件是什么**。**六四的元吉有三个条件，全部写在结构和彖传里，缺一不可**：<br>**① 当位**——六四阴爻居阴位，是它唯一"正"的资本。**它散群不是因为混不下去，是因为它站得正。**<br>**② 上同**（彖传"柔得位而**上同**"）——**散掉横向的小连结，是为了向上接到九五那个更高的中心去。** ⚠️ **这是最关键的一条：没有"上同"，"涣其群"就只是溃散，不是元吉。**<br>**③ 散的是"其群"（自己的）**——**它散掉的是自己手里的那份人脉资本，不是去拆别人的台。**<br>**三条齐备，象传才给"光大也"——散掉小的，才能光大。** |
| **⚠️ 象传"光大也"是本爻的全部理由** | **"光大"＝光明而广大。** 这三个字给出了"涣其群"的因果链：<br>**小圈子的存在方式是"暗"和"小"——它必须有内外之别才成立，而这个内外之别本身就是它的天花板。**<br>**把它散掉，你失去的是一小块确定的东西，得到的是"光"（公开）与"大"（范围）。**<br>**这与本库同人卦的判断完全咬合**：同人六二"同人于宗"，象传判"**吝道也**"——**同的范围越窄，路越走越窄。** **涣六四正是那条窄路的出口。** |
| **⚠️ 现代落地（这一爻最容易被读成漂亮话，所以要给具体动作）** | **"其群"在现代的常见形态**：<br>　① 公司里跟着你的那几个人（"我的人"）；② 一个只对内开放的小群/饭局/信息渠道；③ 你和某几位形成的默认同盟（开会前先通气）；④ 学术/行业里互相引用互相站台的小圈；⑤ 家族内部的一支。<br>**"涣其群"的具体动作（三条，与三个条件一一对应）**：<br>**① 把信息渠道打开**——原来只在小群里说的，改到公开渠道说（对应"光"）；<br>**② 把人交回体制**——明确告诉他们最终对谁负责、共同服务的目标是什么（对应"上同"）；<br>**③ 自己先退出那个身份**——不再以"我们这拨人"的口气说话（对应"散其群"而非"散别人的群"）。<br>**⚠️ 反面测试**：**如果散了群之后，没有一个更高的中心接住这些人，那不是"涣其群"，那是"溃散"。** 此时应先做卦辞的"王假有庙"（立起共同物），再散群。**顺序不可颠倒。** |
| **识别信号** | ① 你手上有一个真实存在、对你有利的小圈子；② 这个小圈子正在妨碍一件更大的事（信息不通、别人进不来、决策绕道）；③ 你的位置本身是正的（当位）——你并不需要靠这个圈子活着；④ 上面有一个更高、更公的中心是你认的（九五）；⑤ 你舍不得散，理由通常是"这些人是跟着我的"。 |
| **该做** | **散。而且要三条一起做：公开信息（光）、把人交回更高的中心（上同）、自己先退出这个身份。** |
| **不该做** | ① **只散不同**——把圈子散了却没有接到更高的中心上，那是溃散；② **散别人的群**——爻辞是"涣**其**群"，动作对象是自己那一份；③ 在自己位置不正、还要靠这个圈子活着的时候去散（那不是六四，那是六三的处境，六三的动作是"涣其躬"）。 |
| **与同人六二"同人于宗，吝"的合读（⚠️ 本卡最重要的一条跨卦对照）** | **同人卡的判断是**：卦辞标准为"同人**于野**"（范围放到最大），而六二"同人**于宗**"（只与本宗求同）被象传直判"**吝道也**"——**同的对象越窄，路越走越窄。**<br>**但同人卦只诊断，没有给出治疗动作**：**已经在"宗"里的人该怎么办？**<br>**涣六四给出了那个动作，而且判词是全卦唯一的"元吉"：涣其群。**<br>**合读结论（可直接入库为通则）：要把"同"的范围扩大，第一个动作不是往外拉人，是先把自己已有的小圈子散掉。** 同人卦的"于野"是目标，涣卦的"涣其群"是通往它的第一步。**这也解释了为什么这两卦的卦辞都缺"元"却在爻里出现"元吉"——它们处理的是同一件事的两端。** |
| **与巽六四"田获三品"的对照（同为巽之柔爻）** | **巽六四"悔亡，田获三品"，象传"有功也"——巽的柔爻在四位，用来"获"（做出可分配的成果）就有功**；<br>**涣六四"涣其群，元吉"，象传"光大也"——涣的柔爻在四位，用来"散"（散掉自己的小圈子）就元吉。**<br>**两爻同为"巽在上"的六四、同为当位、同处"四多惧"之位，动作却相反：一个是把东西聚拢来分给三方，一个是把已经聚起来的人散掉。**<br>**统一的机制是"上同"：巽六四把成果分出去（横向交付），涣六四把人交上去（纵向归公）——两者都是"不把资源攥在自己手里"。** **本库小畜六四"以一柔畜五阳"是这一机制的反例，结果只能"密云不雨"。三个六四合读：柔爻在四位，攥住则不雨，分出去则有功，交上去则元吉。** |

### 九五 · 涣汗其大号（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 涣汗其大号，涣王居，无咎。 |
| **象传** | 王居无咎，正位也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位——**全卦卦主**；**巽在上，九五是巽最好的位置**（本库巽卦卡结构律：巽在上则四、五当位，九五更是当位得中居尊）。 |
| **判词 → 行动语义** | **无咎**（按本库口径：**无灾，不等于吉利**） → **发一道不可收回的号令，并散掉自己的居积** |
| **关键词解** | **汗**＝汗水。**⚠️ "涣汗"是全书最精确的一个比喻：汗一旦出来，就绝不会再回到身体里去。**<br>**大号**＝重大的号令、诏令。**涣汗其大号**＝**发布如汗出不返的重大号令**——**一出口就不再收回、不再商量、不再修改。**<br>**王居**＝王者的居积/所据守之处（"居"兼有"居积"与"居所"两义，本库取合读）。**涣王居**＝**把王自己的那份居积/据守也散出去。** |
| **⚠️ 本爻两个动作，一对外一对己，必须成对读** | **① 对外——"涣汗其大号"：给出一个不可撤回的号令。**<br>　散局的本质是"没有共同方向"。此时**任何"再看看""大家商量商量"都在加深涣散**，因为它把不确定性又发回给了每个人。**必须有一个点是确定的、不再变的。**<br>**② 对己——"涣王居"：散掉自己的那份居积。**<br>　**这是号令能立得住的唯一条件。** 你要求所有人散掉小圈子（六四"涣其群"），**自己的那一份必须先散、而且要当众散。** 王不散王居，"大号"就只是命令别人。<br>**两个动作合起来才换到"无咎"。** |
| **⚠️ 为什么卦主、当位、得中、居尊，判词却只有"无咎"** | **这是本卡最需要解释的一处**（对照本库：兑九五当位得中居尊而判"有厉"；随九五当位得中居尊而判"吉"）。<br>**理由是卦时**：**涣卦处理的是残局。** 在一个已经散掉的局面里，**最高位者能拿到的最好结果就是"没有灾"——把局面稳住、不再继续散，就是全部的成功。**<br>**同时"无咎"按本库口径常是"善补过才没灾"**：**九五的两个动作（不收回的号令 ＋ 散掉自己的居积）都是补过性质的，它在补的正是"局面为什么会散"这件事。**<br>**⚠️ 象传只给了三个字的理由："正位也。"** **不是"吉在其中"，不是"有功"——只是"位置正"。** 在涣卦里，**最高位者守住"位正"这一件事，就已经是全卦的天花板。** |
| **识别信号** | ① 你是拍板的人，且位置是正的（当位得中居尊）；② 局面已经在散——人心浮动、开始有人各找出路；③ 你倾向于"先安抚、慢慢来、再观察一下"；④ 你手上有一份别人都知道的居积（特权、预算、信息、一块自己保留的地盘）。 |
| **该做** | **① 先做卦辞的"王假有庙"**——把那个高于所有人的共同物立起来，并亲自到场；<br>**② 发出一道不可撤回的大号令**——范围小一点没关系，但必须是"从此不再改"的；<br>**③ 同时、当众散掉自己的那份居积（涣王居）**。**顺序上第③条最好与第②条同时宣布——它是号令的抵押品。** |
| **不该做** | ① 只发号令不散自己的居积（那道号令立不住）；② 发一道留有余地的号令（在涣卦里，"余地"就是继续散的空间）；③ 把这件事授权给别人去宣布——卦辞是"**王假**有庙"，彖传是"**王乃在中**也"，**这件事不能派代表。** |
| **与师六五"长子帅师"的对照（同为尊位，动作不同）** | **师六五的唯一动作是"选谁"（用长子则无咎，用弟子则贞凶）**；**涣九五的动作是"说定 ＋ 散己"。**<br>**两者的共同点是：尊位的动作都极少，而且一旦做错就直接决定全卦。** 差别是：**师卦的胜负在"用人"，涣卦的胜负在"有没有一个不再变的锚点，以及你自己有没有先交出东西"。** |

#### ⚠️ 涣九五 ↔ 巽九五：本库最需要分清的一对号令纪律

**两爻同为九五、同为当位得中居尊、同处"巽在上"的最佳位置，给出的号令纪律却完全相反。**

|---|---|---|

| 判词 | 贞吉·悔亡·无不利·吉（全卦最密集） | **无咎** |

| 字段 | 内容 |
|---|---|
| **⚠️ 分界线（这是合读的全部价值）** | **巽卦的对象是"还在的、只是没听懂的人"——所以要反复讲，讲的次数就是关键（彖传"重巽以申命"）。**<br>**涣卦的对象是"已经在散的人"——对他们反复讲，等于反复告诉他们"这事还没定"，只会加速散。此时需要的不是次数，是一个不再变的锚点。** |

| **⚠️ 最危险的两种错配** | **① 在涣的时段用巽的方法**（局面已散还在反复商量）→ 每一次"再讨论"都在证明"还没定"，散得更快；<br>**② 在巽的时段用涣的方法**（风气未变就下不可撤回的死命令）→ 按巽卦口径，这会让整件事回到"小亨"甚至失败。<br>**结论（可入库为通则）：号令该反复还是该一次说定，不看你的位置有多高，看对面的人"是还在但没懂"，还是"已经在走"。** |

### 上九 · 涣其血（⚠️ 四卦上爻中唯一无灾的一爻）

| 字段 | 内容 |
|---|---|
| **爻辞** | 涣其血，去逖出，无咎。 |
| **象传** | 涣其血，远害也。 |
| **位属性** | 阳爻居阴位，**不当位**（巽在上，上爻必不当位）；居全卦之终。 |
| **判词 → 行动语义** | **无咎** → **把那份伤害本身散掉，然后走远** |
| **关键词解** | **血**＝血，此处指**伤害、流血之事、忧患**（一说"血"通"恤"，忧也；两读都指向"伤"，本库取合读）。<br>**去**＝离去。**逖**＝远（同"逷"、"逿"，远也）。**去逖出**＝**远远地离开、走出去**。 |
| **⚠️ 本爻是涣卦的圆满，也是本库"上爻"通则的又一个正例** | 本库通则（艮卦卡所立）：**"上＝物极必反"要加限定——反的是"不知止的极"，不是"到顶"本身。** 已有正例：**艮上九"敦艮，吉"（止到极处正是艮德的圆满）、大有上九"自天佑之，吉"（把功归天正是大有之德的圆满）。**<br>**涣上九补上第三个正例：涣到极处，散的对象已经不是人、不是群、不是自己的居积，而是"血"（那份伤害本身）——把伤害也散掉，然后远离。这正是涣德的圆满完成，所以不当位也"无咎"。**<br>**⚠️ 而它在本组四卦里的地位更醒目**：**涣、节、中孚、小过四卦的上爻分别是"无咎／贞凶／贞凶／凶（是谓灾眚）"——只有涣上九全身而退，唯一的原因是它做的事正是本卦之德。** |
| **象传"远害也"是全卦最后一条指令** | **"远害"＝远离祸害。** 注意《周易》在这里给的不是"化解"、不是"和解"、不是"报复"，是**"散掉它，然后走远"**。<br>**这与"涣"字的动作是一致的：涣不是把东西修好，是把东西散开。到了最后，连"受过的伤"这件事也不留着——散掉，走开。** |
| **⚠️ "涣其血"与"涣其群"、"涣其躬"构成本卦的三层递进** | **六三"涣其躬"——散掉自己（我的面子与位置）→ 无悔（心里干净）**；<br>**六四"涣其群"——散掉自己的小圈子（我的人脉资本）→ 元吉（光大）**；<br>**九五"涣王居"——散掉自己的居积（我的特权与据守）→ 无咎（位正）**；<br>**上九"涣其血"——散掉自己的伤（我受过的委屈与损失）→ 无咎（远害）。**<br>**⚠️ 四个"涣其X"排成一条完整的递进：面子 → 圈子 → 特权 → 伤口。**<br>**这四样东西的共同点是：它们都是"你的"，而且都是散局中最难放手的四样。涣卦的全部内容就是按这个顺序把它们一件件放掉。**<br>**⚠️ 最后一件（伤口）之所以放在最后，因为它最隐蔽：面子、圈子、特权都是别人看得见的，"我受过的伤"只有自己知道，也最容易被留着当理由。** |
| **识别信号** | ① 散局已经过去，事情基本定了；② 你身上留着这一程的伤——损失、被辜负、被误解、某个人的名字；③ 你发现自己在反复讲述这段经历（"当初就是他……"）；④ 你还在原地，虽然事情已经结束。 |
| **该做** | **① 散掉"血"**——不再把这段伤害作为身份、理由、谈资；**② 去逖出**——**物理性地离开**：换环境、换项目、换城市、换社交圈。**象传给的是"远害也"，"远"是一个距离词，它要求的是真的走远，不是心里放下。** |
| **不该做** | 留在原地消化。**上九不当位，它在这个位置上已经没有可做的事了；"无咎"是它走开才拿到的。** 也不要在这个阶段回头清算——**清算是噬嗑（21）、师上六（正功）的事，不是涣卦的事。** |
| **与坎上六"三岁不得，凶"的对照（⚠️ 一对极强的反差）** | **坎上六"系用徽纆，置于丛棘，三岁不得，凶"——本库坎卦铁律之一是"三年是死线：困在里面不动的时长本身会杀死你"。**<br>**涣上九"涣其血，去逖出，无咎"——散掉伤害、远远走开，就无灾。**<br>**两爻都是"险局的最末端"，一个凶、一个无咎，差别只有一个动作：走没走。**<br>**合读结论（可入库为通则）：险局的终点不由局面决定，由你是否离开决定。坎上六是"不得出"（凶），涣上九是"去逖出"（无咎）。** |
| **与兑上六"引兑，未光"的对照（两个"散局的尾巴"）** | **兑上六"引兑"，象传"未光也"——一团和气到了尽头还想拉长，不害人但白过**；<br>**涣上九"涣其血，去逖出"，象传"远害也"——散局到了尽头，把伤散掉走远，无咎。**<br>**⚠️ 而序卦传正是把这两爻接在一起的："说而后散之，故受之以涣。"**<br>**合读结论：兑上六是"想留住已经没有内容的关系"（未光，白过）；涣上九是"承认它散了，把伤也散掉，走开"（无咎）。同一个关系的终点，抓着是白过，放手并离开是无灾。这是兑、涣两卦衔接处最实用的一条。** |

## 三、涣卦定位速查表

### ⚠️ 核心表：四个"涣其X"——散局中要放掉的四样东西

| 顺序 | 爻 | 散什么 | 现代形态 | 判词 | 象传给的理由 |
|---|---|---|---|---|---|
| 1 | **六三** | **躬**（自己） | 面子、署名权、"我怎么样" | **无悔** | 志在外也 |
| 2 | **六四** | **群**（小圈子） | "我的人"、只对内的信息渠道、默认同盟 | **元吉** | **光大也** |
| 3 | **九五** | **王居**（居积） | 特权、保留地盘、不公开的预算与信息 | **无咎** | 正位也 |
| 4 | **上九** | **血**（伤口） | 损失、委屈、被辜负的那段经历 | **无咎** | **远害也** |

> **四样东西的共同点：它们全部是"你的"，而且是散局中最难放手的四样。**
> **顺序不可乱**：**先放面子（否则争位置），再放圈子（否则挡住公），再放特权（否则号令立不住），最后放伤口（否则走不掉）。**

### 全爻速查

| 爻 | 角色 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初六 | 最弱者·险底 | 用拯马壮 | 局面在散，你最没话语权，且自己也在险中 | **不当位**·坎在下 | **吉**·借一份现成的强力，顺上去 |
| 九二 | 散局枢纽 | 涣奔其机 | 事实上还靠你办，但名分不足、上面还压着你 | 不当位但**得中** | **悔亡**·先找一张能靠的几，守住不散 |

| 六四 | 有小圈子的当位者 | **涣其群** | 你手上有个真实有利的小圈子，它挡着更大的事 | **当位**·上承九五 | **元吉**·散群＋上同＋公开 |
| 九五 | 最高决策者（**卦主**） | 涣汗其大号 | 你要拍板，而局面已经在散 | **当位·得中·居尊** | **无咎**·一出不返的号令 ＋ 散掉自己的居积 |
| 上九 | 散局之末 | **涣其血** | 事情已过，你还留着那份伤，也还在原地 | 不当位·卦终 | **无咎**·散掉伤，**走远** |

**涣卦三句话**：
1. **涣卦不教你"不散"，只教你"散什么"。** 全卦四个"涣其X"，**散的全部是自己这边的东西**：面子、圈子、特权、伤口。
2. **散局的第一动作是"王假有庙"**（卦辞）——**先立一个高于所有人的共同物，最高位者亲自到场**。**大象传的主语是"先王"不是"君子"：这是建制级动作，个人品德救不回一个散掉的群体。**
3. **"涣其群，元吉"的条件是"上同"**（彖传）——**散掉小圈子必须同时归入一个更大的中心。只散不同，就只是溃散。**

**本卦最反直觉的三条**：
- **"打散自己的小圈子"得到了全卦唯一的"元吉"（六四），而"守住枢纽不倒"只得到"悔亡"（九二）。** **《周易》在散局里的排序是：主动放掉自己的资本 ＞ 守住自己的位置。**
- **卦主九五当位、得中、居尊，判词只有"无咎"，象传只给三个字"正位也"。** **在残局里，最高位者的天花板就是"没有灾"。**
- **同为九五、同为"巽在上"的最佳位置，巽九五要"前三天讲、后三天追"（反复申明），涣九五要"如汗不返"（一出不收回）。** **号令该反复还是该一次说定，不看你的位置，看局面是"还在的人没听懂"还是"人已经在散"。**

## 四、⚠️ 本卡对全库的意义

### 1. 填上同人卦（13）的机制缺口：想"于野"，先"涣其群"

本库同人卡的核心判断是：**卦辞标准为"同人于野"（范围放到最大、最不偏私），而六二"同人于宗"被象传直判"吝道也"——同的对象越窄，路越走越窄。**
**但同人卦通篇只诊断，不给动作**：已经身在"宗"里的人，第一步该做什么？

| | 同人 13（上乾下离） | 涣 59（上巽下坎） |
|---|---|---|
| 卦辞缺的字 | **缺"元"** | **缺"元"** |
| 目标 | **同人于野**（范围最大） | **王假有庙**（立共同物） |
| 对"小圈子"的处理 | 六二"同人于宗" → **吝道也**（只诊断） | 六四"涣其群" → **元吉·光大也**（给动作） |
| 涉大川的资格 | **乾行也**（靠刚健） | **乘木有功也**（靠共同载体） |
| 关键动作 | 类族辨物（辨清了再同） | **涣其群 ＋ 上同** |

> **合读结论（可直接入库为通则）**：**要扩大"同"的范围，第一个动作不是往外拉人，是先把自己已有的小圈子散掉。**
> **同人卦的"于野"是目标，涣卦的"涣其群"是通往它的第一步；而"上同"（彖传）是这一步的安全绳——没有更高的中心接住，散群就只是溃散。**
> **两卦的卦辞都缺"元"，正因为它们处理的是同一件事的两端：都不是从无到有，都是在"已经存在的人"身上做手术。**

### 2. 涣 ↔ 萃（45）：全书唯二的"王假有庙"，一散一聚

**《周易》六十四卦中，卦辞出现"王假有庙"的只有两卦**：
- **萃 45（上兑下坤）**：萃：亨。王假有庙，利见大人，亨，利贞。用大牲吉，利有攸往。
- **涣 59（上巽下坎）**：涣：亨。王假有庙，利涉大川，利贞。

> **而这两卦的卦名恰好是反义：萃＝聚，涣＝散。**
> **⚠️ 合读结论（本卡最有价值的一条增量）：《周易》认为"聚"与"散"不是两件事，是同一件事的两个方向——而两者的枢纽是同一个动作："王假有庙"，即建立并当众确认一个高于所有人的共同物。**
> **推论**：**判断一个群体的问题是"该聚"还是"该散"，往往不需要判断——因为下一步的动作是一样的：先把那个共同物立起来。** 立起来之后，**该聚的自然聚（萃），该散的小圈子自然可以放心地散（涣六四），因为有东西接住了。**
> （**萃卦 45 已落盘，其卦辞经核为"萃：亨。王假有庙。利见大人，亨，利贞。用大牲吉，利有攸往"——"王假有庙"确在卦辞，本条通则的两半证据齐备。** 两卦构成本库最完整的一对"聚散"专题，建议在索引中并列。）

### 3. 涣 ↔ 节（60）：覆卦对，也是本库第一对"善后 ＋ 防复发"

**涣（上巽下坎）整个倒过来看，就是节（上坎下兑）——两卦是覆卦。** 序卦传把这一对的关系写得极明确：
> **"说而后散之，故受之以涣。涣者，离也。物不可以终离，故受之以节。"**

| | 涣 59 | 节 60 |
|---|---|---|
| 卦象 | 上巽下坎（**坎在下＝已在险中**） | 上坎下兑（**坎在上＝三爻全当位**） |
| 处理的时段 | **已经散了** | **不要再散** |
| 核心方法 | **王假有庙**（立共同物） | **制数度，议德行**（立可执行的量度） |
| 卦辞 | 亨。王假有庙，利涉大川，利贞 | 亨。**苦节不可贞** |
| 失败形态 | 只散不同 → 溃散 | **节到自苦 → 上六"苦节，贞凶"** |

> **合读结论**：**涣给的是"散了怎么收"（一个高于所有人的共同点，加四次主动放手）；节给的是"怎么不再散"（把共同点翻译成可执行的度量）。**
> **⚠️ 而节卦立刻补了一个反向警告："苦节不可贞"——量度定得过狠，会把人重新逼散。** **所以这一对必须合读：涣教你立共同物，节教你把它做成能长期执行的刻度，并且明确告诉你刻度不能过。**

### 4. 结构律的印证与一条补充

**本卦对本库第 4 节结构律是一次完整印证，六爻全部对齐，无一例外：**

| | 占初、二、三位（下卦） | 占四、五、上位（上卦） |
|---|---|---|
| **坎**（阴阳阴） | **三爻全不当位** → 涣：初六、九二、六三全不当位 ✓ | 三爻全当位 |
| **巽**（阴阳阳） | 初二不当（二得中）、三当位 | **四五当位、上不当** → 涣：六四、九五当位，上九不当 ✓ |

> **本卦印证了"巽在上＝巽最好的位置"这一条**：**六四拿到全卦唯一的"元吉"，九五是当位得中居尊的卦主**——**巽卦卡的判断（"巽在上 → 六四、九五皆当位，九五更是当位得中居尊，这是巽最好的位置"）在涣卦得到最强的一次兑现。**
> **同时印证了"坎在下＝你已在险中"**：**下三爻不但全不当位，判词也全部压得极低——吉（但靠借力）、悔亡、无悔。三个爻没有一个是靠自己站起来的。**

**⚠️ 一条对"乘刚"通则的补充（建议入库）**：
本库第 4 节已立"**乘刚的来源＝震**"（震把阳放在最下往上顶）。**涣卦提示这条表述需要补一句：坎在下时，六三乘九二之刚，也构成一次乘刚。**

- **震**（阳阴阴）：在下则六二乘刚，在上则六五乘刚；
- **坎**（阴阳阴）：**在下则六三乘刚，在上则上六乘刚**；
- **离**（阳阴阳）：在下则六二乘刚，在上则六五乘刚；
- **兑**（阳阳阴）：在下则六三乘刚，在上则上六乘刚；
- **艮**（阴阴阳）、**巽**（阴阳阳）：**内部不制造乘刚**（阳都在阴之上/阴都在阳之下）。

> **这条补充不改变原通则的结论（震确实是"乘刚"意象最典型的来源，因为它的阳在最底往上顶），只是把机械判据补全，避免逐爻检查时漏掉坎、离、兑三卦内部的乘刚。**
> **涣卦本身的乘刚只有一处：六三乘九二。而这一处正好落在"涣其躬"上——被下面的刚顶着，它的解法恰恰是"不保自己"（志在外也），这与本库已有的两个乘刚破解法（艮六四"止诸躬"＝把范围收回自己这一身；巽六四"田获三品"＝交付可分配的成果）合成第三种：涣六三"涣其躬"＝把自己这一层撤掉。**
> **三种破解法合读：艮是"收进来"，巽是"交出去"，涣是"撤掉它"。**

### 5. 判词表的一条新增（建议入库）

**涣六三"涣其躬，无悔"提供了本库判词表尚未收录的一档："无悔"。**

| 判词 | 本库口径 | 与"无悔"的差别 |
|---|---|---|
| **无咎** | 无灾，**不等于吉利**；常是"善补过才没灾" | **无咎是对外的**：外部没有可以责你的地方 |
| **悔亡** | **挽回级**：本该有的悔恨消失了，**不是得到好处** | **悔亡是有过程的**：先有该悔的处境，被某个动作抵消 |
| **⚠️ 无悔（新增）** | **对内无憾**：这件事你心里不会留下悔恨，**但不承诺任何外部成果** | **无悔是无过程的**：从一开始就没有可悔的东西 |

> **涣六三是最干净的样本**：它不当位、乘刚、居险顶、占三位——四项负面条件全齐，**却只判"无悔"，既不判凶（因为它做的事正是卦德），也不许诺吉或无咎（因为"涣其躬"不产生外部成果）。**
> **建议在判词表中把"无悔"放在"无咎"与"悔亡"之间，并注明：它是《周易》少见的纯内向判词——只保证你心里干净，不保证事情办成。**

### 6. 本卡打开的卦

**涣是"巽在上"八卦之一**（巽在上：小畜 9、家人 37、益 42、观 20、渐 53、**涣 59**、巽 57、中孚 61）；**也是"坎在下"八卦之一**。<br>⚠️ **本行原列的坎在下名单有误（屯 3、需 5、蹇 39、井 48 四卦实为坎在**上**），已更正如下**：<br>**坎在下八卦**＝蒙 4、讼 6、师 7、解 40、困 47、**涣 59**、未济 64、坎 29；<br>**坎在上八卦**＝屯 3、需 5、比 8、蹇 39、井 48、节 60、既济 63、坎 29。<br>（判据：下卦决定初二三爻，上卦决定四五上爻；坎在下则三爻全不当位，坎在上则三爻全当位——见知识卡65。）

> **优先建议**：**萃 45（上兑下坤）**——**与本卦构成全书唯一一对"王假有庙"，一聚一散，是本库"聚散"专题的另一半，缺它则本卡第 2 节的通则只有一半证据。**
> 其次是 **井 48（上坎下巽）**——**它与涣的上下卦恰好互换**（涣＝上巽下坎，井＝上坎下巽）。**涣是"风行水上而散"，井是"水在木上而养"：同样的两个三画卦，颠倒一次，一个讲散、一个讲长久的供养。** 这是本库检验"上下互换"这条读法的最好一对样本。
