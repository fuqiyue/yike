# 知识卡 61 · 中孚卦（风泽中孚）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："节而信之，故受之以中孚。"——**节卦（60）把刻度定下来了，接着必须让人相信它**。**⚠️ 这个衔接极重要：制度定完了不会自动生效，它需要"孚"（诚信）才能被执行。中孚卦接管的正是"制度与人之间那道信任"。**
> **本卦与小过卦（62）是错卦对**（每一爻阴阳完全相反），**而且两卦都是全书八个"倒过来还是自己"的不易卦之一**（乾、坤、坎、离、颐、大过、中孚、小过）。**两卦必须合读。**
> ⚠️ **本卡的核心是第四节第 1 条：全库"孚"字系列的汇总表。** 本库此前已在需、讼、比、小畜、泰、大有、随、坎、兑、观、革、睽、未济十三卦中反复遇到"孚"字，**但从未把它们放在一起看过。中孚卦是这个字的本卦，本卡把它汇总成两张表，并从表里提出六条通则——这是本卡最有价值的增量。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 中孚 · 第六十一卦 · **八不易卦之一**（倒过来还是自己） |
| **卦象** | 上巽（风/入）下兑（泽/悦），称"**风泽中孚**"。**泽上有风**——风行泽上，水面无处不被吹动，**象征诚信之感应无所不至**。<br>**⚠️ 全卦六爻的阴阳排列是：阳 阳 阴 阴 阳 阳（自下往上）——四阳夹二阴，二阴正在中间（六三、六四）。这个"中虚"之象是卦名的直接来源，也是全卦全部意象的源头**（见下条）。<br>**按本库第 4 节结构律，本卦的当位分布是完全确定的**：**兑在下 → 初九当位、九二不当位（但得中）、六三必不当位**；**巽在上 → 六四、九五当位，上九不当位**。<br>**⚠️ "巽在上"是巽最好的位置**（巽卦卡原话：**"巽在上 → 六四、九五皆当位，九五更是当位得中居尊，这是巽最好的位置"**）——**本卦六四"无咎"、九五"无咎"、上九"贞凶"，正是这条结构律的标准兑现：四五都正、上必不正。** |
| **⚠️ "中虚"之象：三个意象共用一个结构（本卦最要紧的一条）** | **二阴居中、四阳在外——这个结构在《周易》里同时被读作三样东西，而三样都在本卦经文里出现：**<br>**① 鸟卵。** **"孚"的本义就是"孵"**（本库需卦卡已引："**卵孚也，如约信也，鸟之孚卵，皆如其期，不失信也**"）。**中间两阴＝卵中之虚，外面四阳＝卵壳。"中孚"＝中间在孵——诚信就是在中间安静地孵着一个东西，到期必出，一天不差。**<br>**② 虚舟。** **彖传"利涉大川，乘木舟虚也"**——**巽为木，中间虚，所以是一条空船。⚠️ 船之所以能载重渡河，正因为它中间是空的。**<br>**③ 鹤鸣与相和。** **九二"鸣鹤在阴，其子和之"**——**中空才能共鸣。**<br>**⚠️ 三个意象合成本卦最高层的一句话：诚信的结构是"中间空着"。不是中间塞满自己的东西，是留出可以被孵、被载、被共鸣的空处。** |
| **领域定义** | **诚信的建立、维持与验证——尤其是在"没有强制力"的关系里**。① 让别人相信你说的话（承诺、报价、时间表、坦白坏消息）；② 建立需要长期互信的关系（合伙、婚姻、师徒、长期供应商）；③ 制度定下来之后如何让人真的执行（序卦传"节而信之"）；④ 团队内部的信任修复；⑤ **⚠️ 以及本卦最实用的一面：辨别"真诚信"与"看起来很诚信"**（上九"翰音登于天，贞凶"）；⑥ 在争议中判断一个人（大象传"议狱缓死"）。<br>凡是"**这件事只能靠人信我，没有任何东西能强制他信**"，都落在中孚卦。 |
| **不归本卦的情况** | ① **要选择跟谁站在一起、要不要归附某人** → **比卦（8）**。**比是"择对象"（卦辞"原筮，元永贞"，反复审断），中孚是"建立并维持信任本身"。**<br>② **要靠愉悦沟通聚人** → **兑卦（58）**。**⚠️ 两卦关系极近（中孚的下卦就是兑），分界是：兑管"让人愉悦"这个动作及其五种形态，中孚管"让人相信"这件事。兑九二"孚兑"正是两卦的接口。**<br>③ **要用柔顺渗透去改变别人** → **巽卦（57）**。<br>④ **要跟人达成共识、找同路人** → **同人卦（13）**。<br>⑤ **要判断一个人该不该被托付重任** → **蒙卦（4，"蒙以养正"）、师上六（"小人勿用"）**。**中孚讲"我怎么被信"，那两处讲"我该信谁"。** |
| **"孚"字本义（⚠️ 全卦最关键的训解）** | **本义是"孵"**——**鸟以身覆卵而抱之。** 本库需卦卡已引其训："**卵孚也，如约信也，鸟之孚卵，皆如其期，不失信也。**"<br>**⚠️ 请注意这条训解里"信"的定义方式：鸟孵卵，到了日子就出壳，不早不晚、一次不差——所以叫"不失信"。**<br>**也就是说：《周易》里的"孚"不是"态度诚恳"，是"到期必兑现"。它是一个关于时间与准确性的词，不是一个关于情感的词。**<br>**"中孚"＝"孚在中"，两层含义合读**：<br>　**① 结构上**——二阴居中，中虚如卵（彖传"柔在内"）；<br>　**② 义理上**——**诚信必须在"中"，即在里面、在心里、在不被看见的地方。** ⚠️ **这一层直接生出了本卦最重要的一对爻：九二"鸣鹤在阴"（在暗处）得应，上九"翰音登于天"（登到最高处发声）贞凶。** |
| **卦辞原文** | 中孚：豚鱼吉，利涉大川，利贞。 |
| **⚠️ 卦辞的关键结构** | **有利（两个"利"）、有贞，缺元、缺亨。**<br>**⚠️ 缺"亨"这一点最值得注意**：**相邻的节卦给"亨"，兑卦给"亨"，涣卦给"亨"，而中孚不给"亨"。**<br>**含义：诚信本身不构成一条"通路"。** 它不带你去任何地方——**它只是让你有资格上路（"利涉大川"）。**<br>**⚠️ 这与本卡第四节第 1 条从"孚"字汇总表里提出的通则完全一致：孚是入场券，不是奖品。**<br>**缺"元"**：诚信不是开创，它是所有事情的底层条件，不是某件事的起点。 |
| **卦辞现代解** | **豚鱼吉**——"豚"＝小猪，"鱼"＝鱼。**彖传释为"信及豚鱼也"——诚信连小猪和鱼都感应得到。**<br>　**⚠️ 为什么举豚与鱼？因为它们是最微贱、最无知、最不可能懂道理的生物。《周易》选它们作为诚信的验收标准，含义极明确：真正的"孚"不需要对方听得懂你的道理。**<br>　**现代落地（这是全卦最好用的一条自查）：判断你的诚信是否成立，不要看能不能说服懂行的人（那可能只是话术），看那些完全听不懂你在做什么的人（新人、外行、孩子、最边缘的同事）是否也信你。信到"豚鱼"那一层，才叫吉。**<br>　（另有一读：**"豚鱼"是祭祀所用的薄物**——用最微薄的祭品也能感格神明，因为心诚。⚠️ 两读都指向同一件事：**孚的成立与所用之物的贵贱、道理的高低无关。** 本库取合读。）<br>**利涉大川**——可以去做需要跨越重大险阻的大事。**彖传归因于"乘木舟虚也"——因为中间是空的，所以是一条能载重的船。**<br>　**⚠️ 这是本库第六种"涉大川资格"**（已有：需"往有功也"、同人"乾行也"、大畜"应乎天也"、谦初六"卑以自牧也"、涣"乘木有功也"）。**中孚的资格最特别：它靠"虚"——靠中间空着，不靠自己有多满。**<br>**利贞**——有益，但必须守正。**⚠️ 彖传特别把这三个字单列出来解释："中孚以利贞，乃应乎天也。"——诚信而守正，才是应乎天。这一句是必要的补丁：孚本身不辨善恶（你也可以对坏事守信），所以必须加"贞"。** |
| **彖传** | 中孚，柔在内而刚得中，说而巽，孚乃化邦也。豚鱼吉，信及豚鱼也。利涉大川，乘木舟虚也。中孚以利贞，乃应乎天也。 |
| **⚠️ 彖传要点（四句，前两句是纲）** | ① **"柔在内而刚得中"**——**柔（六三、六四）在里面，刚（九二、九五）分别得下卦与上卦之中。**<br>　**⚠️ 这八个字是"孚"的结构定义，而且顺序不能颠倒：里面是柔的（虚、软、可容），中枢是刚的（硬、正、得中）。**<br>　**这与本库兑卦彖传"刚中而柔外"恰好相反，值得并读：兑是"刚在中而柔在外"（内核硬，外表软）；中孚是"柔在内而刚得中"（最里面是空软的，而中枢位置上是硬的）。**<br>　**⚠️ 分界：兑讲的是待人的姿态（外柔内刚），中孚讲的是自身的构造（中间要留空，两个中枢要立得住）。**<br>② **⚠️ "说而巽，孚乃化邦也"（本卦最实用的一句）**——**下兑是"说"（悦），上巽是"巽"（入）。先让人愉悦，然后渗进去，诚信才能化育一邦。**<br>　**这句把"孚"的形成机制写成了一个顺序：悦 → 入 → 孚 → 化邦。**<br>　**⚠️ 顺序不可颠倒，这是全卦最容易被违反的一条：人不会先信你再愿意听你，是先愿意跟你相处（兑），你的东西才渗得进去（巽），渗进去了才有孚，有了孚才化得动一个组织（化邦）。**<br>　**跳过"说"直接要求别人信你，就是上九的"翰音登于天"——直接把声音发到最高处，没有人接。**<br>③ **"信及豚鱼也"**——见卦辞现代解。<br>④ **"乘木舟虚也"**——**因为中间空，所以能载重渡险。⚠️ 这是全书对"虚"最正面的一次评价。** |
| **大象传（行动纲领）** | 泽上有风，中孚。君子以议狱缓死。 |
| **⚠️ "议狱缓死"解（一条司法纲领，与噬嗑卦正好相反）** | **"议狱"＝反复讨论、评议案件；"缓死"＝对死刑从缓、尽量宽缓。**<br>**⚠️ 为什么"诚信"这一卦的行动纲领是司法？**<br>**因为狱案是"诚信"这件事的极限场景：你要判定另一个人心里到底是怎么想的，而这件事永远没有确证。** 在这种地方，**《周易》给的指令不是"查清楚"，是"议"和"缓"——多讨论、放慢。**<br>**⚠️ 与本库噬嗑卦（21）恰成一对**：**噬嗑大象传"明罚敕法"——把刑罚立清楚、把法度整明白（严的一面）**；**中孚大象传"议狱缓死"——反复评议、从缓处死（宽的一面）。**<br>**两条合读，本库对"判定他人"这件事就有了完整的两手：法度必须清楚（噬嗑），个案必须从缓（中孚）。清楚是对规则说的，从缓是对人说的。**<br>**⚠️ 与相邻节卦（60）大象传的呼应**：**节"制数度，议德行"——数度用"制"，德行用"议"。中孚"议狱缓死"——狱案也用"议"。**<br>**相邻两卦的纲领里都出现"议"字，而且都用在"人"这一侧：凡涉及对人的判定，《周易》一律用"议"（讨论），不用"制"（定死）。** |
| **总铁律** | ① **孚的结构是"中间空着"**（彖传"柔在内"、"舟虚"）——**不是把自己填满，是留出可被孵、可载重、可共鸣的空处**；<br>② **孚的形成顺序是"说 → 巽 → 孚 → 化邦"**（彖传），**顺序不可颠倒**：先让人愿意相处，再渗进去，才有信，才化得动组织；<br>③ **孚的验收标准是"豚鱼"**——**信到那些完全听不懂你的人那一层，才算成立**；<br>④ **孚必须专一，一分心就不安**（初九"有它不燕"），**而且要断掉横向的结党去专一上承**（六四"马匹亡，绝类上也"）；<br>⑤ **⚠️ 孚在暗处才得应，一登到最高处发声就是贞凶**（九二"鸣鹤在阴，其子和之" ↔ 上九"翰音登于天，贞凶"）——**这是全卦最重的一条**；<br>⑥ **孚本身不辨善恶，所以必须加"贞"**（彖传"中孚以利贞，乃应乎天也"）；<br>⑦ **判定人的时候要"议"和"缓"，不要"制"和"急"**（大象传）。 |

## 二、爻级字段

> ⚠️ **本卦六爻的结构极清晰**：**初九、九二在下兑（悦），是"孚"的建立期；六三、六四是二阴居中（卵之虚），是"孚"的考验期；九五、上九在上巽之上，是"孚"的成熟与变质期。**
> **⚠️ 而全卦最重要的一组是九二与上九——两爻都是"发声"，一个在阴处，一个登到天上，判词一得应一贞凶。**

### 初九 · 虞吉（孚之始：必须专一）

| 字段 | 内容 |
|---|---|
| **爻辞** | 虞吉，有它不燕。 |
| **象传** | 初九虞吉，志未变也。 |
| **位属性** | 阳爻居阳位，**当位**（兑在下，只有初九当位）；居全卦最下——**孚之始**；上承九二。 |
| **判词 → 行动语义** | **吉**（有条件：必须"虞"且不能"有它"） → **先审度定下来，然后不许分心** |
| **关键词解** | **虞**＝**审度、揣量、预先考虑周备**（一说"虞"＝安，义可并存：审度周备然后心安）。<br>**有它**＝**有别的**（另有牵系、另有所图、另有备选）。**它**＝他、别的。<br>**燕**＝**安**（"燕"通"宴"，安也）。**不燕**＝**不安**。<br>**全句：先审度周备则吉；一旦另有牵系，就不安。** |
| **⚠️ 象传"志未变也"是本爻的全部条件** | "**志未变**"＝**心志还没有改变。**<br>**《周易》给"吉"的理由不是"他很诚实"，是"他还没变心"。**<br>**⚠️ 这个说法很冷静：初九的吉是有时效的——它建立在"目前还没有第二个选项"这个事实上。一旦"有它"，吉就换成"不燕"（不安）。**<br>**结论：孚的第一个条件不是德行，是排他性。** |
| **⚠️ 为什么"孚"的第一步是"虞"（审度）而不是"诚"** | **这是全卦最容易被读反的一处。**<br>**按现代直觉，诚信的第一步应该是"真心"。而爻辞给的第一个字是"虞"——审度、算清楚。**<br>**理由在"孚"的本义：孚是"到期必兑现"，不是"态度诚恳"。要保证到期必兑现，第一步必须是把事情算清楚——能不能做到、要多久、代价多大。**<br>**⚠️ 落到现代：诚信的第一步不是承诺，是先算一遍自己到底能不能做到。算之前就承诺，属于诚意有余而"孚"不成立——因为到期你兑现不了。** |
| **识别信号** | ① 一段需要长期互信的关系刚开始（新合作、新岗位、新承诺）；② 你正准备表态、承诺、签字；③ ⚠️ 你手上还留着别的选项（另一个 offer、另一个供应商、另一个可能性），且没有明说；④ 你感到一种说不清的不安（这就是"不燕"）。 |
| **该做** | **① "虞"——先把能不能做到算清楚**：期限、代价、依赖条件，逐项算一遍再表态；<br>**② 处理掉"它"**——**要么放弃备选，要么把备选如实说出来。** 爻辞给的是"有它**不燕**"：**留着不说的备选，代价是你自己的不安。** |
| **不该做** | 在还有别的牵系时先把承诺做满。**⚠️ 注意《周易》在这里没有判"凶"，只判"不燕"（不安）——它不惩罚你，它只告诉你这样活着不安稳。** |
| **与随六二"弗兼与也"的呼应（⚠️ 同一条纪律的两次出现）** | **本库随卦铁律之二："随只能随一个，不可能两头都系"（六二象传"弗兼与也"）。**<br>**中孚初九"有它不燕"——另有牵系就不安。**<br>**⚠️ 两处是同一条纪律，但落点不同：随卦讲的是"跟随对象只能有一个"（对外的选择），中孚初九讲的是"心里不能同时挂着两个"（对内的状态）。**<br>**合读结论：专一在《周易》里不是道德要求，是功能要求——随卦说两头都系则"弗兼与"（两边都得不到），中孚说有它则"不燕"（自己不安）。两处都不谈品德，只谈后果。** |
| **与兑初九"和兑"的对照（同为兑在下的初九）** | **兑初九"和兑，吉"，象传"行未疑也"——平和无目的地让人愉悦，之所以吉是因为"经得起怀疑"。**<br>**中孚初九"虞吉，有它不燕"，象传"志未变也"——审度周备则吉，条件是"心志还没变"。**<br>**两爻同为兑在下的初九、同为当位、同判"吉"、理由都在"没有可疑之处"这一侧。**<br>**⚠️ 分工：兑初九管的是别人对你的怀疑（行未疑），中孚初九管的是你自己心里的第二个选项（有它）。合起来是关系开局的两个条件：外面看不出可疑，里面没有备选。** |

### 九二 · 鸣鹤在阴（⚠️ 全卦最著名的一爻，也是本卦正面样本）

| 字段 | 内容 |
|---|---|
| **爻辞** | 鸣鹤在阴，其子和之。我有好爵，吾与尔靡之。 |
| **象传** | 其子和之，中心愿也。 |
| **位属性** | 阳爻居阴位，**不当位**，但**得中**——下兑之中，即彖传"刚得中"之一；上被六三所乘（六三乘九二之刚）。 |
| **判词 → 行动语义** | **⚠️ 无吉凶判词**，只给了一个感应的场景 → **在暗处做真的事，回应自己会来** |
| **关键词解** | **鸣鹤在阴**——**鹤在幽暗隐蔽之处鸣叫**。"阴"＝背阴处、暗处、不被看见的地方。<br>**其子和之**——**它的幼鸟应和它。** "和"＝应和、呼应。<br>**我有好爵，吾与尔靡之**——"**爵**"＝酒器，引申为酒；"**靡**"＝**共、同（一说"靡"通"縻"，系也；一说训"共"）**。全句：**我有好酒，我与你一同享用。**<br>**⚠️ 后两句是前两句的解释：那种母鹤一鸣、幼鸟就应的关系，落到人事上就是"我有好东西，跟你一起用"。** |
| **⚠️ 本爻为什么没有判词，而这恰恰是它的分量所在** | **全爻二十字，写的全是场景，没有一个吉凶字。**<br>**按本库口径，无判词通常意味着"不在吉凶十级之内"。但本爻是个特殊情况：它不是"不好也不坏"，它是在给"孚"下定义。**<br>**⚠️《周易》选择用一个画面而不是一个判词来定义"孚"：母鹤在没人看见的暗处叫了一声，幼鸟应了。**<br>**这个画面里有三个要素，缺一不可**：<br>**① 在阴**——**在不被看见的地方**（不是为了让人看见才做的）；<br>**② 鸣**——**确实发出了声音**（不是什么都不做）；<br>**③ 其子和之**——**回应来自"其子"，即本来就与你同类、同气的那一方**，不是来自所有人。<br>**⚠️ 三条合起来就是"孚"的工作原理：你在暗处做真的事，该应你的人自然会应；不该应你的人本来也不会应，与你无关。** |
| **⚠️ 象传"中心愿也"** | "**中心愿**"＝**出于内心的意愿**（不是被要求的、不是被交换来的）。<br>**⚠️ 与本库泰六四"不戒以孚"象传完全同语**：**泰六四"翩翩不富，以其邻，不戒以孚"，象传"皆失实也。不戒以孚，中心愿也"。**<br>**本库泰卦卡的结论是："真正好的关系状态是'不需要提防'，且这来自诚信与居中，不来自控制。"**<br>**⚠️ 中孚九二把这条推进了一步：不但不需要提防，而且回应是自愿来的（中心愿也）。这是"孚"能达到的最高状态，而它的前提是"在阴"——不被看见。** |
| **"我有好爵，吾与尔靡之"的操作含义** | **⚠️ 这两句是全卦唯一给出具体动作的地方，而这个动作是"分享一件好东西"。**<br>**不是承诺、不是解释、不是表态——是把手上确实有的好东西拿出来一起用。**<br>**这与本库的"不独富"系列完全同线**：**小畜九五"有孚挛如，富以其邻"，象传"不独富也"；泰六四"不富，以其邻"；谦六五"不富以其邻"。**<br>**⚠️ 本库谦卦卡已把这条提炼为通则："《周易》里'富'从来不是资源问题，是'你和邻近的人的关系'问题——手上的东西必须与旁边的人发生关系，否则它就是负担。"**<br>**中孚九二是这条通则在"孚"上的落实：孚不是靠说出来的，是靠"我有好爵，吾与尔靡之"这个动作做出来的。** |
| **⚠️ 系辞传对本爻的引申** | **⚠️《系辞上传》引本爻并加以解说，大意是：君子居于自己的屋中，说出来的话是善的，千里之外都会响应，何况近处的人；说出来的话不善，千里之外都会背离，何况近处的人。言行是君子的枢机，枢机一发动，就决定了荣辱。**（⚠️ **本条为系辞传引申，原文文句较长，此处只述其义，未逐字照录，待核。**）<br>**这段引申与爻辞的方向完全一致："居其室"就是"在阴"（不被看见的地方），"千里之外应之"就是"其子和之"。**<br>**⚠️ 落到现代最有用的一句：你在没人看见的地方说的话和做的事，决定了远处的人对你的反应。这是"孚"的传播机制，而不是"孚"的表演机制。** |
| **本爻不当位却是全卦正面样本的原因** | **九二阳居阴位，名不正言不顺；但它得中。**<br>**按本库通则"⚠️ 得中可救不当位"，在中孚卦里"得中"具体表现为"在阴而鸣"——不靠位置发声，靠位置之外的真实。**<br>**⚠️ 对照本库兑九二"孚兑，吉，悔亡"（象传"信志也"）：同为兑在下的九二、同为不当位而得中、同讲"孚"。兑九二的动作是"说真话（含说我做不到）"，中孚九二的动作是"在暗处做真的事并分享"。**<br>**两爻合起来是"孚"在枢纽位置上的完整形态：对外说真话（兑九二），对内做真事（中孚九二）。** |
| **识别信号** | ① 你处在实际办事的枢纽位置，但名分不足（不当位而得中）；② 你在做的事没什么人看见（在阴）；③ 你倾向于"是不是该让上面知道一下"；④ 你手上有一件确实的好东西（资源、信息、机会、方法）。 |
| **该做** | **① 继续在暗处做，把事做实**（在阴）；**② 但要"鸣"——把事情本身说清楚、做出来，不是沉默**；**③ 把好东西拿出来与该分享的人一起用（我有好爵，吾与尔靡之）。** |
| **不该做** | **为了让人看见而改换做法。** ⚠️ **本爻与上九是同一件事的两端：把"鸣"从"在阴"搬到"登于天"，判词就从"其子和之"变成"贞凶"**（见上九专项）。 |

### 六三 · 得敌（⚠️ 全库"无判词＋只给心理状态"这一档的标准样本）

| 字段 | 内容 |
|---|---|
| **爻辞** | 得敌，或鼓或罢，或泣或歌。 |
| **象传** | 得敌，位不当也。 |
| **位属性** | 阴爻居阳位，**不当位**——**⚠️ 按结构律"兑在下 → 三必不当位"，这是确定的**；**乘于九二之上——乘刚**；居下兑之顶；**是"中虚"二阴之一**；本库通则"**三多凶**"。 |
| **判词 → 行动语义** | **⚠️ 无吉凶判词，只给了四个摇摆的状态** → **《周易》承认你的难受，但不判你有咎，也不授权你越位** |
| **关键词解** | **得敌**＝**遇到（碰上）了对手**（"得"是遭遇、遇上；"敌"是匹敌者、对手）。<br>**或鼓或罢**＝**时而击鼓（进攻），时而停止。**<br>**或泣或歌**＝**时而哭泣，时而歌唱。**<br>**"或……或……"连用四次，是《周易》里最密集的一次摇摆描写。** |
| **⚠️ 本爻正是本库判词表最后一条口径的标准样本** | **本库判词表已收一条："无判词 ＋ 只给心理状态 → 《周易》承认你的难受，但不判你有咎，也不授权你越位。"**<br>**⚠️ 中孚六三是这条口径最干净的一个样本，而且它比其他样本更完整——因为它连象传都只给位置理由（"位不当也"），一个字的评价都没有。**<br>**读法：**<br>**① 它不判凶**——虽然六三不当位、乘刚、居三多凶之位，四项负面条件俱全；<br>**② 它也不判无咎**——**《周易》没有说"这样没事"**；<br>**③ 它只是把这个状态如实写下来：进也不定、退也不定，哭一阵、唱一阵。**<br>**⚠️ 这种写法本身就是一条信息：在"孚"这件事上，遇到一个真正匹敌的对手时，人的反应就是这样摇摆的，《周易》不认为这需要被批评，但也不认为它是一个可以停留的位置（它没给你任何授权）。** |
| **⚠️ 与兑六三"来兑，凶"的对照（⚠️ 同一个位置、同一句象传，一凶一无判词）** | **⚠️ 这是本卦最有价值的一处结构对照：**<br>**兑六三"来兑，凶"，象传"来兑之凶，位不当也"。**<br>**中孚六三"得敌，或鼓或罢，或泣或歌"，象传"得敌，位不当也"。**<br>**两爻的结构完全相同**：阴爻居三位、兑在下必不当位、乘九二之刚、居兑之顶、三多凶；**两爻的象传给的理由是同一句话："位不当也"。**<br>**⚠️ 而判词一个是全卦唯一的"凶"，一个完全没有判词。**<br>**差别只有一条：兑六三有动作（"来"——主动上门去讨好），中孚六三没有动作（只有情绪的摇摆）。**<br>**⚠️ 合成通则（可直接入库）：位不当 ＋ 有动作 ＝ 凶；位不当 ＋ 只有情绪 ＝ 无判词。**<br>**《周易》在同一个不当位的位置上，惩罚的是动作，不是感受。**<br>**这条通则对读者极实用：处在一个不正的位置上并且心里乱，本身不构成过错；一旦你在这个状态下动手（尤其是向外动手），判词立刻变成凶。** |
| **"得敌"为什么会让人摇摆（结构原因）** | **六三是"中虚"的下面那一阴——它本身是空的、软的。而它遇到的是"敌"（一个匹敌的对手）。**<br>**⚠️ 空的东西碰上硬的东西，唯一的反应就是摇摆。** 这不是性格问题，是结构问题。<br>**同时它乘九二之刚**（下面还顶着一个刚爻），**上面六四也是阴**（同类，帮不上）——**它上下都没有可靠的支点。** |
| **识别信号** | ① 你在一件需要互信的事上碰到了一个真正的对手（能力相当、立场相反）；② 你的反应是反复变化的：一会儿想强硬（鼓），一会儿想罢手（罢），一会儿沮丧（泣），一会儿又觉得没问题（歌）；③ 你的位置本身不正（这件事本来不该由你在这个位置上对抗）；④ 你上下都没有可靠的支点。 |
| **该做** | **① 承认摇摆本身不是错**（爻辞没有判你）；<br>**② 但不要在这个状态里动手**（⚠️ 一动手就掉到兑六三的"凶"）；<br>**③ 回到九二**——**把注意力从"这个对手"移回"在阴而鸣"：做实事、分享手上真有的东西。** 六三上面靠不住、下面顶着刚，**它唯一的活路是不再对着"敌"，而是回到自己那件真的事上。** |
| **不该做** | ① 在摇摆中做决定（每一次摇摆都会产生一个相反的决定，最后什么都不成立，而"孚"正是被这个摧毁的——**孚的本义是"到期必兑现"，反复变卦是它的直接对立面**）；② 为自己的摇摆羞愧到必须证明什么（那会变成上九的"翰音登于天"）。 |
| **与节六三"不节若"的对照（相邻两卦、同一个"兑在下的六三"）** | **节六三"不节若，则嗟若，无咎"，象传"又谁咎也"——没管住自己，事后叹息，判"无可归咎"。**<br>**中孚六三"得敌，或鼓或罢，或泣或歌"，象传"位不当也"——遇到对手，反复摇摆，无判词。**<br>**⚠️ 两爻结构完全相同（都是兑在下的六三，都不当位，都乘九二之刚），《周易》给的都是"不追究"级的处理：一个说"怪不了别人"，一个干脆不评价。**<br>**合读：兑在下的六三是本库确认的"陷阱位"，但它的三种量刑现在齐了——向外做错事判凶（兑六三），向内没管住判无可归咎（节六三），只有情绪不动手则不判（中孚六三）。** |

### 六四 · 月几望（断掉横向的类，专一向上）

| 字段 | 内容 |
|---|---|
| **爻辞** | 月几望，马匹亡，无咎。 |
| **象传** | 马匹亡，绝类上也。 |
| **位属性** | 阴爻居阴位，**当位**（巽在上，四、五当位）；**已入上卦巽**；**上承九五**；下临六三（同为阴，**不乘刚**）；**是"中虚"二阴之另一**；本库通则"**四多惧**"。 |
| **判词 → 行动语义** | **无咎** → **断掉与同类的那份配对，专一向上** |
| **关键词解** | **月几望**＝**月亮将要圆满而未满**（"望"＝月满之日，即十五；"几"＝将近）。<br>**马匹亡**＝**失去了配对的那匹马**（"匹"＝匹配、成对；一说"马匹"即"匹马"，指与自己成对的那一匹）。<br>**⚠️ 关键在"匹"字：亡的不是马，是"配对"这件事。** |
| **⚠️ 象传"绝类上也"是本爻的全部含义** | "**绝类**"＝**断绝与同类的关系**；"**上**"＝向上（承九五）。<br>**全句：断绝了与同类的关系而向上。**<br>**⚠️ 六四的"同类"是谁？是六三——同为阴爻、同在"中虚"、就在它下面。**<br>**六四的动作是：不与六三结成一对，转而单独去承九五。**<br>**⚠️ 这就是"孚"的排他性在结构上的落实：诚信必须专一，而专一的具体动作是"断掉横向的结党"。** |
| **⚠️ 现代落地（本爻是四个爻里最可操作的一个）** | **"马匹"的现代形态：与你同层级、同处境、天然抱团的那个人或那几个人。**<br>　同期入职的伙伴、同样被边缘化的同事、同样有怨言的合作方、同一个圈子里"我们这些人"。<br>**⚠️ 为什么必须"亡"掉这个配对？**<br>**因为横向的抱团与纵向的诚信是互斥的：只要你和六三是一对，你对九五的每一句话就都带着"我们那边"的立场——九五收到的不是你的孚，是你们那一伙的姿态。**<br>**⚠️ 而这与本库随九四完全同线**：**随九四"随有获，贞凶。有孚在道，以明，何咎"——本库随卦卡的结论是"这批人的归属要明确指向'道'，不指向你个人"。**<br>**中孚六四是同一件事的自我版本：你自己的归属也要明确指向上面那个"道"，不指向横向那一伙。**<br>**具体动作**：① **停止与同类的私下通气**（开会前先对口径这类）；② **在公开场合单独表达自己的判断，不用"我们"这个主语**；③ **接受由此产生的孤立**——**判词只给"无咎"，它不承诺你会因此得到好处。** |
| **⚠️ "月几望"三处对照（2026-09-05 修正）** | **⚠️ 本栏原写"共出现两处"，漏了归妹六五。经全样本核查，"月几望"在经文层共 3 处**（与 `知识卡71` 的记载一致，本栏此前与之不一致）：<br>**① 小畜 9 上九**"既雨既处，尚德载，妇贞厉，**月几望，君子征凶**"——想拿，**凶**。<br>**② 中孚 61 六四**"**月几望**，马匹亡，**无咎**"——主动"亡"掉一样东西（配对），**无咎**。<br>**③ 归妹 54 六五**"帝乙归妹，其君之袂不如其娣之袂良，**月几望，吉**"——居尊者主动降格、不做满，**吉**（本卦三处里唯一的"吉"）。<br>**⚠️ 合读结论（3/3 全命中，可入库）：同一个"月几望"的临界点，判词随动作分三档——想拿则凶（征）／肯舍则无咎（亡）／不做满并降格则吉（不如其娣之袂良）。**<br>**⚠️ 撤销一处转引**：本栏原写此结论"给本库的'蓄满即发是陷阱'补上正面答案"。**该通则已于 RULE-012 全样本核查中被推翻（蓄养五卦上爻负面 1/5），转引一并撤销**，见 `知识卡09` 上九栏。**本栏的三处对照不依赖那条通则，独立成立。**<br>**⚠️ "巽在上"那条也须降格**：原写"两处都在巽在上的卦里，不是偶然"。加入归妹（上**震**下兑）后为 **2/3**，**归妹是反例**——按 RULE-012 只能写作**倾向**，不得写作"不是偶然"。 |
| **识别信号** | ① 事情快到临界点了（月几望），但还没成；② 你和同层级的某几个人天然是一伙的，有默认的相互配合；③ 上面有一个更高、你也认的中心（九五）；④ 你察觉到"我们这一伙"的立场正在替你说话；⑤ 你的位置本身是正的（当位）——你不需要靠这伙人活着。 |
| **该做** | **断掉那个配对（马匹亡），单独去承上（绝类上）。** 并接受"无咎"这个判词的含义：**这是免灾，不是得利。** |
| **不该做** | ① 一边抱团一边表忠——**这在中孚卦里就是"有它"（初九），后果是"不燕"（不安）**；② 期待断掉配对之后会有回报（**爻辞只给"无咎"**）。 |
| **与巽六四、涣六四、节六四的四爻合读（⚠️ 本库"当位的六四"已满四例）** | **巽六四"悔亡，田获三品"，象"有功也"——横向交付可分配的成果**；<br>**涣六四"涣其群，元吉"，象"光大也"——散掉自己的小圈子并归公**；<br>**节六四"安节，亨"，象"承上道也"——安然承接上面给的刻度**；<br>**中孚六四"月几望，马匹亡，无咎"，象"绝类上也"——断掉与同类的配对而专一向上。**<br>**⚠️ 四个当位的六四，动作各不相同，但方向完全一致：都是"不把东西攥在自己这一层"。**<br>**巽是把成果分出去，涣是把人交上去，节是把标准接下来，中孚是把横向关系断掉。**<br>**⚠️ 而本库小畜六四"以一柔畜五阳"（把五个阳压在自己这一层）是唯一的反例，结果只能"密云不雨"。**<br>**合成通则（建议入库）：四位是"多惧"之位，它唯一的活法是让东西流过自己，而不是停在自己这里。** |

### 九五 · 有孚挛如（卦主）

| 字段 | 内容 |
|---|---|
| **爻辞** | 有孚挛如，无咎。 |
| **象传** | 有孚挛如，位正当也。 |
| **位属性** | 阳爻居阳位，**当位且得中**，居尊位——**全卦卦主**，即彖传"刚得中"之另一；**巽在上，九五是巽最好的位置**；下有六四来承，上被上九所临。 |
| **判词 → 行动语义** | **无咎**（按本库口径：**无灾，不等于吉利**） → **把诚信牵系起来，维持住，不求更多** |
| **关键词解** | **挛如**＝**牵系相连之貌**（"挛"＝牵、系、连结；"如"是形容词尾）。**有孚挛如**＝**诚信牵系相连**——**上下被诚信牵在一起。** |
| **⚠️ 专项：为什么卦名就叫"中孚"，九五又是"孚"最正的位置，判词却只有"无咎"** | **这是本卦最需要解释的一处，也是本卡从"孚"字汇总表里提出的第五条通则的直接来源。**<br>**九五的条件是全卦最好的：当位、得中、居尊、卦主、处"巽在上"的最佳位置，象传还特别强调"位正当也"。它做的事又正是卦名本身（有孚）。**<br>**可是判词只有"无咎"——不是吉，不是元吉。**<br>**⚠️ 三层理由，逐层递进：**<br>**① 卦辞已经定了调：中孚卦辞缺"亨"。** 诚信本身不构成通路，它只是资格。**卦级不给"亨"，爻级自然不会给"吉"。**<br>**② "挛如"这个词有隐忧。** "挛"是牵系、缠结——**它把人系在你这里。** 而本库随九四的铁律是：**"这批人的归属要明确指向'道'，不指向你个人"（有孚在道，以明）。**<br>　**九五的"挛如"是把上下牵在一起，牵系的中心是九五自己。按随卦的口径，这只能得"无咎"，得不到"吉"。**<br>　**⚠️ 对照最能说明问题：小畜九五爻辞也是"有孚挛如"，但它多了三个字"富以其邻"，象传给的是"不独富也"——它把牵系变成了分享，所以那个"挛如"是有出口的。中孚九五没有这三个字，它的"挛如"只是维持。**<br>**③ 卦主在这一卦的职能就是"维持"。** 全卦的"孚"由九二在暗处做出来（鸣鹤在阴）、由六四断掉横向关系来承接（绝类上），**九五要做的只是把这条链子保持住不断——维持没有增量，所以判"无咎"。**<br>**⚠️ 合成结论：在中孚卦里，最高位者的最好结果就是"孚没有断"。这与相邻涣卦九五（当位得中居尊，判词也只有"无咎"，象传只给"正位也"）完全同构。** |
| **⚠️ 象传"位正当也"——本库这句话已出现三次，全部值得警惕** | **兑九五"孚于剥"，象传"位正当也" → 判词"有厉"**；<br>**中孚九五"有孚挛如"，象传"位正当也" → 判词"无咎"**；<br>**（对照）随九五"孚于嘉"，象传"位正中也" → 判词"吉"。**<br>**⚠️ 三处都是当位得中居尊、都讲"孚"、象传都强调位置正——判词却是"有厉／无咎／吉"三档。**<br>**本库兑卦卡的结论是："位置完全正当，也不能保证不出危险；出危险的原因不在位置，在你把'孚'给了错误的对象。"**<br>**⚠️ 中孚九五补上第三档，并把这条通则说全了：孚的判词与位置无关，只与"孚系在什么上"有关——系在"嘉"（美善）上是吉，系在"剥"（正在剥损你的人事）上是厉，系在"自己"上（挛如）是无咎。** |
| **识别信号** | ① 你在被信任、被依赖的核心位置上，位置完全正当；② 上下确实被一种信任关系牵在一起（挛如）；③ 你感到这份信任的中心是你这个人；④ 你在想"这么好的信任基础，能不能拿来做点什么"。 |
| **该做** | **① 维持住这条链子不断**——**这就是九五的全部职能，"无咎"就是它的满分**；<br>**② ⚠️ 把牵系的中心从自己移到"道"**（随九四"有孚在道，以明"）：**公开说明大家共同服务的目标是什么、最终对谁负责**；<br>**③ 参照小畜九五给"挛如"开一个出口**——**"富以其邻"（把手上的好东西分给旁边的人），象传"不独富也"。** ⚠️ **这是本库为中孚九五能找到的唯一升级路径：把维持性的牵系变成分配性的分享。** |
| **不该做** | ① 拿这份信任去兑换具体好处（**那就从"挛如"掉到兑六三的"来兑"或随九四的"随有获"**）；② 因为"我位置正、我一向讲信用"而对正在剥损你的对象继续给信用（**⚠️ 那正是兑九五"孚于剥，有厉"**）；③ **⚠️ 把这份信任拿去公开声张**——**那就掉到上九的"翰音登于天，贞凶"。** |

### 上九 · 翰音登于天（⚠️ 全卦最重的判词，本卡第二个核心）

| 字段 | 内容 |
|---|---|
| **爻辞** | 翰音登于天，贞凶。 |
| **象传** | 翰音登于天，何可长也。 |
| **位属性** | 阳爻居阴位，**不当位**——**⚠️ 按结构律"巽在上 → 上必不当位"，这是确定的**；居全卦之终。 |
| **判词 → 行动语义** | **贞凶**（按本库口径：**守正也凶——问题不在品德，在处境与选择的根本错位**） → **此爻不可入** |
| **关键词解** | **翰音**＝**高飞之声、高扬的声音**（"翰"＝高飞，一说"翰"为羽；合读为"高高飞扬的声音"）。<br>**登于天**＝**升到天上去。**<br>**全句：声音高高地飞上天去——贞凶。**<br>**⚠️ 注意爻辞里只有"音"，没有"实"。声音上去了，东西没上去。** |
| **⚠️ 专项：九二 ↔ 上九，本卦最重要的一组对照（同一个"发声"，一得应一贞凶）** | **⚠️ 本库巽卦卡已立"同辞异断"的读法（九二／上九同为"巽在床下"，一吉一贞凶），节卦卡又补了一例（初九／九二同为"不出X庭"，一无咎一凶）。中孚卦提供第三例，而且这一例最锋利——因为两爻做的是同一件事：叫。**<br><br>**九二**：鸣鹤**在阴**，其子和之。我有好爵，吾与尔靡之。象："其子和之，**中心愿也**。"<br>**上九**：翰音**登于天**，**贞凶**。象："翰音登于天，**何可长也**。"<br><br>**差别只有一个：在哪里叫。** |

| 对照项 | **九二** · 鸣鹤在阴 | **上九** · 翰音登于天 |
|---|---|---|
| 动作 | **鸣**（发声） | **音**（发声） |
| 地点 | **在阴**（不被看见的暗处） | **登于天**（最高、最显眼处） |
| 有没有"实" | **有**——"我有好爵"（手上确实有好东西） | **没有**——爻辞只有"音"，无一字提实 |
| 回应 | **其子和之**（该应的人自愿应了） | **无回应**（爻辞不提任何回应） |
| 位属性 | 不当位，**但得中** | **不当位，且居卦终** |
| 象传 | **中心愿也**（出于内心的意愿） | **何可长也**（怎么能长久） |
| 判词 | **无判词**（是"孚"的定义） | **贞凶** |

| 字段 | 内容 |
|---|---|
| **⚠️ 结论（可直接入库为通则）** | **"孚"必须在下、在内、在暗处，并且带着实物。**<br>**同一个发声动作：在暗处发、手上有东西，就有人自愿来应（九二）；登到最高处发、手上没东西，就是贞凶（上九）。**<br>**⚠️ 而"贞凶"这个判词的选择极准确：按本库口径，贞凶＝守正也凶，问题不在品德，在处境与选择的根本错位。**<br>**上九不是骗子——它可能非常真诚，它的声音可能句句都是真心话。《周易》判它凶，判的不是它的品德，是"把孚拿到最高处去发布"这个选择本身。**<br>**这正是"中孚"这个卦名的反面：孚在"中"（里面）才是孚，孚"登于天"（外面、最上面）就不是孚了。** |
| **⚠️ 象传"何可长也"的分量** | "**何可长也**"＝**怎么能长久呢？**<br>**⚠️ 这个反问回到了"孚"的本义：孚是"到期必兑现"（鸟孚卵，皆如其期，不失信也）。它本质上是一个关于时间的词。**<br>**而"翰音登于天"的问题恰恰是它没有时间——声音一发就散了，天上留不住东西。**<br>**所以象传的反问不是修辞，是精确的：一个只有声音没有实物的东西，在时间里不可能持续；而不能持续的东西，按定义就不是"孚"。** |
| **⚠️ 现代落地：上九的四种常见形态** | **① 把承诺发布在最显眼的地方。** 公开立誓、全员宣告、写进对外文案——**而支撑它的东西还没有做出来。**<br>**② 用"声量"代替"兑现"。** 反复宣讲理念、价值观、决心；**讲的次数越多，兑现的压力越被声音吸收掉。**<br>**③ 把"我很真诚"本身当成要传达的内容。** ⚠️ **这是最隐蔽的一种：当一个人开始需要向别人证明自己诚信时，他已经在"登于天"了。** 九二的鹤没有证明任何东西，它只是叫了一声。<br>**④ 在关系末期靠声张维持。** ⚠️ **与本库兑上六"引兑"（象传"未光也"）位置完全相同（都是卦终，都是靠加大输出维持），但判词一个是"未光"（白过），一个是"贞凶"。** 差别：**引兑只是没内容（不害人），翰音登于天是把没内容的东西发布到了最高处（透支了信用本身）。** |
| **识别信号** | ① 你正在把一个承诺／理念／决心发布到一个很显眼的地方；② 支撑它的实物（成果、能力、资源、已完成的部分）还不够，或者你说不清有多少；③ 你在这件事上位置不正（不当位）——不完全是你的职权，或不完全是你能兜住的；④ **⚠️ 你能感觉到自己在"表达诚意"，而不是在"交付东西"**；⑤ 你已经在这条路上一段时间了（居卦终）。 |
| **该做** | **① 停止发布。**<br>**② 回九二**：**把声音搬回暗处（在阴），把手上确实有的那件好东西拿出来分享（我有好爵，吾与尔靡之）。**<br>**③ 回初九的"虞"**：**重新算一遍自己到底能兑现多少，然后只承诺那么多。** ⚠️ **"孚"的本义是到期必兑现——修复它的唯一办法是缩小承诺，不是加大声量。** |
| **不该做** | 加大声量、增加公开度、找更权威的场合再说一次。**⚠️ 本爻是"贞凶"，按本库口径这是很重的判词，且爻内无解药——解药只在别的爻（九二、初九）。** |
| **与巽上九"丧其资斧，贞凶"的对照（两个"巽在上"的上九）** | **巽上九"巽在床下，丧其资斧，贞凶"，象传"上穷也／正乎凶也"——到顶还一味卑顺，丢掉了决断力。本库口径："他若一味卑顺，就是在放弃自己唯一不可放弃的职能。"**<br>**中孚上九"翰音登于天，贞凶"，象传"何可长也"——到顶而把孚变成声。**<br>**⚠️ 两爻同为"上九"、同为不当位、同判"贞凶"，而且方向恰好相反：巽上九是姿态低到极处而失去决断，中孚上九是声音高到极处而失去实物。**<br>**⚠️ 合成通则（可入库）："巽在上"的上爻必不当位，它的两种死法是"太低"和"太高"：低到不再拍板（巽上九），高到只剩声音（中孚上九）。中间那条活路是九五的"位正当"与九二的"在阴"。** |
| **与本库"上爻"通则的关系** | 本库通则（艮卦卡所立，兑卦卡补全）：**"上＝物极必反"反的是"不知止的极"，不是"到顶"本身——过刚则悔（乾上九），过柔则凶（巽上九），知止则吉（艮上九），无内容则白过（兑上六）。** 节卦卡又补"过量则贞凶（节上六）"。<br>**⚠️ 中孚上九补上第六种：把内在的东西外发到极处，则贞凶。**<br>**这一种与前五种都不同：前五种讲的是"程度"（太刚、太柔、太多），中孚上九讲的是"方向"——它的量没有过，它的方向反了（孚本该在中，它跑到了天上）。** |

## 三、中孚卦定位速查表

### ⚠️ 核心表：本卦六爻给出的"孚"的六个环节

| 环节 | 爻 | 动作 | 判词 | 象传给的机制 |
|---|---|---|---|---|
| **① 立** | 初九 | **虞**（先算清能不能做到），且不许有备选 | **吉**（有条件） | **志未变也**（还没变心） |
| **② 成** | 九二 | **在阴而鸣 ＋ 拿出好东西分享** | **⚠️ 无判词**（是"孚"的定义） | **中心愿也**（回应是自愿的） |
| **③ 试** | 六三 | **遇到匹敌的对手，反复摇摆** | **⚠️ 无判词**（只给情绪） | **位不当也** |
| **④ 择** | 六四 | **断掉与同类的配对，专一向上** | **无咎** | **绝类上也**（绝同类而上承） |
| **⑤ 守** | 九五 | **把上下牵系住，维持不断** | **无咎** | **位正当也**（维持没有增量） |
| **⑥ 变质** | 上九 | **把孚发布到最高处，只剩声音** | **贞凶** | **何可长也**（留不住） |

> **⚠️ 这张表的读法**：**"孚"的整条路径上，判词最高的是初九的"吉"（而且带条件），中段两爻干脆没有判词，两个当位的爻都只给"无咎"，最后一爻是"贞凶"。**
> **全卦没有一个"元吉"，也没有一个不带条件的"吉"。这不是巧合——见第四节第 1 条的第五条通则。**

### 全爻速查

| 爻 | 角色 | 阶段名 | 一句话识别 | 位属性 | 行动语义 |
|---|---|---|---|---|---|
| 初九 | 孚之始 | 虞吉 | 要表态了，但你手上还留着别的选项 | **当位** | **吉**·先算清楚·处理掉"它" |
| 九二 | 枢纽·在暗处（**正面样本**） | **鸣鹤在阴** | 你在没人看见的地方做事，且手上有件好东西 | 不当位但**得中** | **无判词（孚的定义）**·在阴而鸣·拿出来分享 |
| 六三 | 中虚·遇敌者 | 得敌 | 碰上真正的对手，你一会儿想打一会儿想撤 | **不当位·乘刚**·三多凶 | **无判词（只给情绪）**·不判你，但不要动手 |
| 六四 | 中虚·当位者 | 月几望 | 快到临界点，你和同层几人天然是一伙 | **当位**·上承九五 | **无咎**·断掉配对·单独上承 |
| 九五 | 被信任的核心（**卦主**） | 有孚挛如 | 上下被信任牵着，而中心是你这个人 | **当位·得中·居尊** | **无咎**·维持不断·把中心移到"道" |
| 上九 | 孚变成声 | **翰音登于天** | 你在把还没兑现的东西发布到最显眼处 | 不当位·卦终 | **贞凶**·停止发布·回"在阴" |

**中孚卦三句话**：
1. **"孚"的本义是"孵"——到期必兑现，一天不差**（本库需卦卡所引："鸟之孚卵，皆如其期，不失信也"）。**所以它是一个关于时间与准确的词，不是关于情感的词。这解释了为什么初九的第一个动作是"虞"（先算清楚），而不是"诚"。**
2. **孚的结构是"中间空着"**（彖传"柔在内"、"乘木舟虚也"）——**卵、虚舟、共鸣，三个意象共用同一个结构。船能载重是因为中间空，不是因为中间满。**
3. **⚠️ 孚必须在暗处，一登到最高处就不是孚了**（九二"鸣鹤在阴，其子和之" ↔ 上九"翰音登于天，贞凶"）。**同一个发声动作，在阴处发有人自愿来应，在天上发是贞凶。**

**本卦最反直觉的四条**：
- **卦名叫"中孚"，九五又是"孚"最正的位置（当位、得中、居尊，象传强调"位正当也"），判词却只有"无咎"。** **孚是入场券，不是奖品——它让你有资格上路（利涉大川），不让你赢。**
- **九二是全卦最重要的一爻，却完全没有判词。** **《周易》选择用一个画面（母鹤在暗处叫，幼鸟应了）而不是一个判词来定义"孚"。**
- **六三不当位、乘刚、居三多凶之位，四项负面条件俱全，判词却完全空白。** **同一个位置上，兑六三"来兑"判凶——差别只在有没有动作。位不当＋有动作＝凶，位不当＋只有情绪＝不判。**
- **⚠️ 诚信这一卦的行动纲领是司法："议狱缓死"。** 而 **噬嗑（21）**是"明罚敕法"。**《周易》对规则要"明"和"制"，对人要"议"和"缓"。**（⚠️ 本轮更正：原作"邻卦噬嗑"，误——噬嗑 21 与中孚 61 相距 40 卦；中孚的邻卦是节 60 与小过 62。）

#### ⚠️ 从表里提出的五条通则（本节的实际产出）

> **通则一："孚"永远是前提或凭据，从不是结果——只有一个例外，而那个例外内部又把规则补回来了。**
> 表 A 中十四处，"孚"全部出现在动作之前（有孚 → 才能怎样）。**唯一的例外是革 49 卦辞"巳日乃孚"，彖传自注"革而信之"——注意语序是先"革"后"信"：变革之事，信任要到事情改了之后才拿得到。**
> **⚠️ 而革卦内部有一道三级阶梯，恰好把通则补回来了（这是补齐表 B 之后新得到的一条）：**
> **卦辞"巳日乃孚"（孚是结果）→ 九三"革言三就，有孚"（程序产生孚）→ 九四"有孚改命"（孚重新变成前提，且语序不可颠倒）。**
> **⚠️ 落到现代（这一条能省掉很多无效努力）：绝大多数事情要先有信任才能开始（需、比、坎、中孚）；只有"变革"这一件事，不可能先取得信任再动手。但它也不是"先干完再说"——革卦给的是中间那一步："革言三就"（把方案走完三轮公开成议），孚由程序产生，然后才"有孚改命"。**

> **通则二："孚"的吉凶完全不由孚的强度决定，只由"孚系在什么上"决定。**
> **随九五"孚于嘉" → 吉；兑九五"孚于剥" → 有厉；中孚九五"有孚挛如"（系在自己身上） → 无咎；随九四"有孚在道" → 何咎（免责）。**
> **四处的位属性几乎相同（当位、得中、居尊），象传口气也几乎相同（位正中也／位正当也），判词却从"吉"一路排到"有厉"。**
> **⚠️ 排序（可直接入库）：孚于嘉（美善本身）＞ 孚在道（共同的事业与规则）＞ 孚挛如（系在自己身上）＞ 孚于剥（系在正在剥损你的人事上）。**

> **通则三："孚"可以替代戒备，但不能替代威。**
> **泰六四"不戒以孚"（象"中心愿也"）、比九五"邑人不诫"——本库已立结论："真正好的关系状态是不需要提防，且这来自诚信与居中，不来自控制。"**
> **⚠️ 但大有六五给了必要的补丁："厥孚交如，**威如**，吉"，象传"易而无备也"——只有孚而无威，人就会轻慢你。**
> **合成：孚省掉的是"提防"，省不掉的是"边界"。本库大有卡的原话最准确："柔是容量，威是边界。"**

> **通则四："孚"必须在暗处、在下、在内，并且带着实物。**
> **中孚九二"鸣鹤在阴，其子和之。我有好爵，吾与尔靡之" → 有人自愿来应（象"中心愿也"）**；
> **中孚上九"翰音登于天" → 贞凶（象"何可长也"）。**
> **⚠️ 同一个发声动作，差别只在地点与有没有实物。**
> **这条通则可以反过来当诊断用：当一个人开始需要向别人证明自己诚信时，他已经在"登于天"了。九二的鹤没有证明任何东西，它只是叫了一声，然后把酒拿出来一起喝。**

> **通则五：⚠️ 孚是入场券，不是奖品。**
> **统计表 A ＋ 表 B 的判词：给"吉"的有比初六、大有六五、随九五、兑九二、未济六五；给"无咎／悔亡／厉无咎"的有中孚六四、中孚九五、睽九四、革九四、未济上九前半；给负面的有讼"中吉终凶"、随九四"贞凶"、兑九五"有厉"、中孚上九"贞凶"、未济上九"有孚失是"。**
> **⚠️ 全库现有各处中，没有一处"孚"直接换来"元吉"。**
> **⚠️ 而革卦看似的例外恰恰是最强的证据**：**革卦辞"巳日乃孚，元亨，利贞，悔亡"四德齐全——但"元亨利贞"全部挂在"巳日乃孚"这道闸门之后。孚在那里的角色是闸门，不是奖品：它不给你元亨，它只决定元亨能不能生效。**
> **而中孚卦辞更把这一点写在了卦级：中孚卦辞缺"亨"（相邻的节、兑、涣三卦都给"亨"），只给"利涉大川"。**
> **⚠️ 结论：诚信本身不构成一条通路，它只是让你有资格上路。这解释了为什么中孚九五当位得中居尊、又正做着卦名之事，判词却只有"无咎"——在"孚"这件事上，"没有断"就是满分。**

> **通则六：⚠️ 孚可以被自己花掉——而全书最后一爻就是这样结束的。**
> **⚠️ 这条链的终点在未济（64）：六五"贞吉，无悔，君子之光，有孚，吉"（在六爻无一当位的卦里，"孚"是唯一的凭据，靠它把身外之光变成"君子之光"）→ 上九"有孚于饮酒，无咎。濡其首，有孚失是"（把这份孚用在庆祝上，喝到湿了头，于是"有孚失是"——有孚却失了正）。**
> **⚠️ 而象传给的理由是三个字外加一个字："饮酒濡首，亦不知节也。"**
> **⚠️ 请注意这个理由指向的是节卦（60）：全书最后一爻断送"孚"的原因，被象传归结为"不知节"。**
> **合成通则（本组四卦最重要的一条串联）：节（60）定刻度 → 中孚（61）由刻度生信任 → 小过（62）有了信任就去做事 → 而这条链的最终失败形态在未济上九：不是没有孚，是有孚而不知节，在庆祝里把它花掉了。**
> **⚠️ 落到现代最锋利的一句：信任不是被别人拿走的，是自己在"事情快成了"的松懈里花掉的。而它的解药不在中孚卦，在节卦——"制数度"，给庆祝也定一个刻度。**

### 2. 中孚 ↔ 小过（62）：错卦对，且两卦都是"不易卦"

**中孚（阳阳阴阴阳阳）与小过（阴阴阳阳阴阴）每一爻的阴阳完全相反——两卦是错卦。而且两卦倒过来看还是自己（不易卦）。**
**全书只有八个不易卦：乾、坤、坎、离、颐、大过、中孚、小过。本库已有乾、坤、坎、离；本卡与 62 卡补上其中两个。**

| | 中孚 61 | 小过 62 |
|---|---|---|
| 卦象 | 上巽下兑 | 上震下艮 |
| 阴阳分布 | **四阳夹二阴（中虚）** | **四阴夹二阳（中实）** |
| 鸟象 | **卵**（中虚如卵，"孚"即"孵"） | **飞鸟**（彖传"有飞鸟之象焉"） |
| 涉大川 | **利涉大川**（彖"乘木舟虚也"——中空故能载） | **不可大事**（彖"刚失位而不中"） |
| 规模判断 | 可以做大事 | **可小事，不可大事** |
| 上爻 | 上九 翰音登于天，**贞凶** | 上六 飞鸟离之，**凶，是谓灾眚** |

> **⚠️ 合读结论（本卡与 62 卡共有的一条）：中孚是卵，小过是飞。**
> **同一个鸟的意象，中孚取"未飞而在孵"（中虚，内实之信在里面，所以能载重渡大川）；小过取"已飞而声在形已过"（中实，声音留下了但鸟已经过去，所以只可小事）。**
> **⚠️ 而"中虚能载、中实只可小事"这个反差是全书最反直觉的一条结构判断：满的做不了大事，空的才能。理由在彖传："乘木舟虚也"——船能载重是因为它中间空。**

### 3. ⚠️ 中孚与小畜（9）：两句完全相同的经文，因为它们共用同一个"巽在上"

**《周易》里有两句话在两卦中重复出现，而这两卦恰好都是"巽在上"：**

| 重复的经文 | **小畜 9**（上巽下乾） | **中孚 61**（上巽下兑） |
|---|---|---|
| **"有孚挛如"** | 九五：有孚挛如，**富以其邻**（象"**不独富也**"） | 九五：有孚挛如，**无咎**（象"位正当也"） |
| **"月几望"** | 上九：……**月几望，君子征凶** | 六四：**月几望**，**马匹亡**，无咎 |

> **⚠️ 这不是巧合。两卦的上卦都是巽，而"巽在上"是巽最好的位置（六四、九五皆当位，九五当位得中居尊）——所以两卦的四、五两爻会落在同一种结构条件下，用同一批语汇。**
> **合读产出两条通则：**
> **① 关于"挛如"**：**同一个"有孚挛如"，小畜九五后面接"富以其邻"（象"不独富也"），中孚九五后面只有"无咎"。**
> 　**差别是有没有出口：牵系而分享则"不独富"，牵系而只维持则只能"无咎"。⚠️ 这给中孚九五指出了唯一的升级路径——把维持性的牵系变成分配性的分享。**
> **② 关于"月几望"**：**同一个"月将圆"的临界点，小畜上九想"征"（出手）判凶，中孚六四肯"亡"（放掉配对）判无咎。**
> 　**⚠️ 2026-09-05 修正**：此处原写"给本库已有的通则'蓄满即发都是陷阱'（小畜上九 ＋ 屯九五'大贞凶'）补上正面答案"。**该通则已被 RULE-012 全样本核查推翻，转引撤销**（见 `知识卡09` 上九栏）。
> 　**本条独立的、经得起核的表述**：在"月几望"这个临界点上，经文给了三种动作三种判词——**想拿则凶（小畜上九"征凶"）／肯舍则无咎（中孚六四"马匹亡"）／不做满并降格则吉（归妹六五）**。**3/3 全命中，不借任何通则。**

### 4. 序卦传给出的一条实用链：节 → 中孚 → 小过

**序卦传："节而信之，故受之以中孚。有其信者必行之，故受之以小过。"**

| 环节 | 卦 | 做什么 | 失败形态 |
|---|---|---|---|
| ① 定刻度 | **节 60** | 制数度，议德行 | **苦节，贞凶**（刻度定得太狠） |
| ② 让人相信刻度 | **⚠️ 中孚 61** | 说 → 巽 → 孚 → 化邦 | **翰音登于天，贞凶**（只有声量没有兑现） |
| ③ 有了信就必须去做 | **小过 62** | 可小事，不可大事 | **飞鸟离之，凶，是谓灾眚**（做过了头） |

> **⚠️ 这条链是本库第一条完整的"制度落地链"，而且三个环节各有一种独特的死法：制度定得太狠（节）、只讲不做（中孚）、做过了头（小过）。**
> **中孚在中间这一环的价值最容易被低估：序卦传明确说"节而信之"——制度定完了不会自动生效，中间必须有一道"孚"。而彖传把这道工序的顺序写死了："说而巽，孚乃化邦也"——先让人愿意相处（兑），东西才渗得进去（巽），渗进去了才有孚，有孚才化得动组织。**
> **⚠️ 跳过"说"直接要求执行，就是"翰音登于天"。**

### 5. 结构律的印证 ＋ 三条判词口径的新增

**结构律**（本卦六爻全部对齐，无一例外）：

| | 占初、二、三位（下卦） | 占四、五、上位（上卦） |
|---|---|---|
| **兑**（阳阳阴） | 初九**当位**、九二不当（**得中**）、**六三必不当位** → 中孚 ✓ | — |
| **巽**（阴阳阳） | — | **六四、九五当位（九五得中居尊）、上九必不当位** → 中孚 ✓ |

> **⚠️ 本卡再次印证"巽在上＝巽最好的位置"**：六四"无咎"、九五"无咎"（卦主），**而上九必不当位，判词也果然是全卦最重的"贞凶"。**
> **⚠️ 并且它与巽卦自身的上九形成一条新通则："巽在上"的上爻必不当位，它的两种死法是"太低"（巽上九"巽在床下，丧其资斧，贞凶"）与"太高"（中孚上九"翰音登于天，贞凶"）。中间那条活路是九五。**
> **乘刚检查**：本卦只有一处乘刚——**六三乘九二之刚**。**而六三正是那个"或鼓或罢，或泣或歌"的摇摆之爻**：**下面顶着一个刚（九二），上面是同类（六四）帮不上，所以它只能摇摆。这是"乘刚"在心理层面上最清晰的一次呈现。**

**判词口径的新增（建议入库）**：

> **① "无判词 ＋ 只给心理状态"这一档的标准样本已确定为中孚六三。** 它比其他样本更完整：**连象传都只给位置理由（"位不当也"），一个字的评价都没有。**
> **② 新通则：位不当 ＋ 有动作 ＝ 凶；位不当 ＋ 只有情绪 ＝ 无判词。** 证据是兑六三与中孚六三——**两爻结构完全相同、象传同为"位不当也"，判词一个"凶"一个空白，差别只在有没有动手。**
> **③ 兑在下的六三（本库确认的"陷阱位"）三种量刑现已齐备**：**向外做错事判凶（兑六三"来兑"）／向内没管住判"无可归咎"（节六三"不节若"，象"又谁咎也"）／只有情绪不动手则不判（中孚六三"得敌"）。**

### 6. 本卡打开的卦

**中孚是"兑在下"七卦之一**（履 10、临 19、归妹 54、损 41、节 60、睽 38、中孚 61），**也是"巽在上"七卦之一**（小畜 9、观 20、益 42、渐 53、涣 59、家人 37、中孚 61）。

> ⚠️ **"孚"字专题的取证已基本完成**：**革 49**（通则一的例外及其三级阶梯）、**观 20**（不开口而被仰望的孚）、**睽 38**（双向的"交孚"）、**未济 64**（这条链的终点）**均已落盘并收入表 B。**
> **优先建议（补齐"孚"字专题的最后两块）**：**益 42（上巽下震）九五"有孚惠心，勿问元吉；有孚惠我德"**——**它是全库唯一把"孚"与"元吉"放在同一句里的地方**。⚠️ **通则五（"孚是入场券，不是奖品"）必须靠它做最后一次检验：那个"勿问元吉"究竟是"孚"换来的，还是"惠心"换来的。** 而且益是"巽在上"七卦之一，与本卡同律。
> 再次是 **萃 45（上兑下坤）初六"有孚不终，乃乱乃萃"**——**全库唯一一处明写"孚"半途而废的爻**，与未济上九"有孚失是"合成"孚的两种丢法"：**一种是中途断掉（萃），一种是在庆祝里花掉（未济）。** **它同时也是涣卦卡（59）第 2 条所缺的另一半**（全书唯二的"王假有庙"，一散一聚）。
> 其次是 **观 20（上巽下坤）**——**卦辞"有孚颙若"给出了"孚"的第五种用法（不开口而被仰望）**，且巽卦卡已把它列为第一优先（"蒙是童蒙求我，观是观而化之"）。**它与中孚九二的"在阴而鸣"正好互补：一个是在暗处发声，一个是不发声而被看见。**
