# 知识卡 63 · 既济卦（水火既济）

> ⚠️ **来源标注**：经文层（卦辞/爻辞/彖传/象传）出自《周易》原文；义理层为按本库框架的推演，**无原讲解材料背书，待校**。
> 序卦传："有过物者必济，故受之以既济。"——小过（62）之后，能超越常物者必有所成，于是进入既济。
> **⚠️ 本卦是全书六十四卦中唯一"六爻全部当位"的卦，而它的卦辞是"初吉终乱"。**
> **"唯一"二字已由机械穷举验证**：六十四卦的当位数分布是 **1, 6, 15, 20, 15, 6, 1**（＝二项式系数 C(6,k)），**六十四卦恰好穷尽全部 64 种当位组合，一种不重、一种不漏**——所以"全对"的卦必然有且只有一个（既济），"全错"的卦也必然有且只有一个（未济）。**这两卦是一次完整枚举的两个唯一极点，而《周易》把它们放在了全书最后。**（推导见第四节第 1 条。）
> **本卡与 64 未济卡是离卦（30）卡末节所预告的直接推论**：离卡已写明"既济／未济＝坎离的两种叠法，读完坎、离两卡已可直接推出"。**本卡把那个推导补完，并逐爻验证。**

## 一、卦级字段

| 字段 | 内容 |
|---|---|
| **卦名 / 卦序** | 既济 · 第六十三卦（六十四卦的倒数第二卦） |
| **卦象** | 上坎（水/险）下离（火/明），称"水火既济"。**水在火上——锅里的水架在火上，能把东西煮熟，故曰"已成"。** 按本库第 4 节结构律：**离在下 → 初二三三爻全部当位；坎在上 → 四五上三爻全部当位。两条律相加，本卦六爻无一不当位。** |
| **⚠️ 六爻全当位的唯一性（已机械穷举验证，不是修辞）** | 当位的条件是：初、三、五（阳位）为阳爻，二、四、上（阴位）为阴爻，**即六爻阴阳恰好等于固定模板「阳阴阳阴阳阴」**。满足者**有且只有一种**排列＝下体阳阴阳（离）＋上体阴阳阴（坎）＝**既济**。其**补**（每爻取反）＝下坎上离＝**未济**，则六爻无一当位。<br>**⚠️ 更强的结论见第四节第 1 条：六十四卦的当位数分布经逐卦穷举为 1, 6, 15, 20, 15, 6, 1，恰为二项式系数 C(6,k)——六十四卦不多不少地穷尽了全部 64 种当位组合。因此"六爻全当位的卦必然有且只有一个，六爻全不当位的卦也必然有且只有一个"，就是既济与未济。它们不是"又一对反卦"，是一次完整枚举的两个唯一极点。** |
| **领域定义** | **事情已经办成之后的守成期**。项目上线交付完成、创业渡过生死线进入运营、债务还清、官司结案、拿到学位／职称／目标职位、系统迁移完成转入运维、婚成家立、一场长期治疗稳定下来。凡是"**这件事已经成了，接下来的问题是怎么不把它弄坏**"，都落在既济。 |
| **不归本卦的情况** | ① **全局大势的顺逆判断** → **泰 11 / 否 12**（天地交／不交是大势，不是某一件具体的事成了）；② **刚脱险、水位刚齐平，人还在坎里** → **坎 29 九五**（"祗既平，无咎"，尚未出险）；③ **东西太多、盛大而需减损** → **大有 14**（问题是"满"，既济的问题是"齐备而无可再调"）；④ **你有能力继续而自己决定不继续** → **艮 52**（主动止），既济是**干完了**；⑤ **刚上岸的分享与节制** → **需 5 九五**（单爻场景），既济是整卦都处在"已上岸"。 |
| **"既""济"二字本义** | **既**＝已经、尽、完毕（本义为食尽）。**济**＝**渡水**（涉水而过），引申为成、济事、救助。<br>**⚠️ 这两个字的本义是本卦全部义理的根**：**"既济"的字面意思是"河已经渡过去了"，不是"从此没有河了"。** 渡过一条河是一个**事件**，不是一种**状态**。把事件误当状态，就是本卦所有风险的来源。 |
| **卦辞原文** | 既济：亨，小利贞。初吉终乱。 |
| **⚠️ 断句待核** | 通行本此句有两种断法：**①「亨，小利贞」**（亨通，小事上宜于守正）；**②「亨小，利贞」**（所亨者小，宜于守正）。<br>**彖传作"既济亨，小者亨也。利贞，刚柔正而位当也"，明显是按第 ② 种读的**（"小者亨"＝亨的只是小的部分）。本卡正文按彖传口径解，但两种断法义理指向一致：**既济的"亨"是有折扣的亨。** `⚠️ 版本待核` |
| **⚠️ 卦辞的关键结构（全书唯一自带崩坏预告的卦辞）** | **有亨、有利、有贞，无元**——不给开创性，符合"已成"的性质。<br>但真正特殊的是后四个字：**"初吉终乱"。全书只有这一条卦辞把整件事的时间轴和结局直接写在开头。**<br>**这个句式本库已有先例：讼卦"中吉终凶"。** 本库对讼卦的既定口径是"**'中'＝适可而止，不是'过程中吉利'**"。**"初吉终乱"必须用同一副口径读：它不是"先好后坏的宿命"，而是"到某个点之后不能再按原来的逻辑走"。**<br>**那个点是什么，彖传写得极准——"终止则乱"。点在"止"。** |
| **卦辞现代解** | **亨**——通，但**"小者亨也"**：能通的只是细部、余数、小事，大的格局已经定了，不再有大通可言。<br>**利贞**——彖传给的理由是"**刚柔正而位当也**"：六爻各在其位，所以此时唯一有益的事就是**守住这个正**。**注意：这里的"利贞"是"只剩守正有益"，不是"守正就能获益"。**<br>**初吉终乱**——**开头是吉的（彖传："初吉，柔得中也"，指六二当位得中）；末尾是乱的（彖传："终止则乱，其道穷也"）。**<br>合起来一句话：**这件事已经全部摆对了，因此它现在唯一的走向是往下坏，除非你不停下来。** |
| **彖传** | 既济亨，小者亨也。利贞，刚柔正而位当也。初吉，柔得中也。终止则乱，其道穷也。 |
| **彖传要点（本卦全部要害都在这里）** | ① **小者亨也**——**已成之局只在小处还通。** 想在既济里做大事，方向就错了。<br>② **刚柔正而位当也**——**这是《周易》全书唯一一次用"位当"来解释一整卦的卦辞**，也是本库"八卦上／下结构律"最强的经文背书：**六爻全当位这件事，彖传自己点了名。**<br>③ **初吉，柔得中也**——"初吉"的功劳归给六二（柔而当位得中）。**注意它没有把"初吉"归给"六爻全当位"，只归给一个得中的柔爻。**<br>④ **⚠️ 终止则乱，其道穷也**——**这八个字是全卦、也是本库最重要的一条限定。** 乱的原因不是"成"，是"**止**"；机制不是"运气变坏"，是"**其道穷**"——**路走到头了，没有下一步可走了。**<br>**推论：既济的危险不是外来的，是"齐备"本身产生的——一切都摆对了位置，恰恰意味着再没有可调整的余地。** |
| **大象传（行动纲领）** | 水在火上，既济。君子以思患而豫防之。 |
| **"思患而豫防之"解** | **思患**＝主动去想还会有什么祸患；**豫防**＝"豫"通预，事先防备。<br>**⚠️ 这是全书唯一一条"在最好的时候准备最坏"的纲领。** 六十四卦的纲领里，有让你自强的（乾）、承载的（坤）、蓄力的（坎"常德行习教事"）、发光的（离"继明照于四方"）、止的（艮"思不出其位"）——**只有既济这一条，是在"已经成了"的时刻，命令你去想还会出什么事。**<br>**操作含义（这是全卦最高层的原则）**：**成事之日就是列风险清单之日。** 不是等出问题再解决，而是在没有任何问题的那一天，主动写下"这件事将来会从哪里坏掉"。<br>**⚠️ 与离卦"辨"律的关系**：离卡与同人／大有卡曾立一条"凡卦有离，纲领必与'辨'有关"（类族辨物／遏恶扬善／明辨晳也）。**既济含离，纲领却是"思患豫防"，不含"辨"——这是那条律的第一个明确例外。** 原因：**既济的纲领必须处理"终乱"这个特殊命题，"患"来自上坎（险在前方），它压过了下离的"明"。**（对照 64 未济，上离主导，纲领即回到"慎辨物居方"——那条律在未济一侧成立。） |
| **总铁律** | ① **成之日即思患之日**（大象传）——既济唯一的纲领是预防，不是庆祝。<br>② **乱的原因是"止"，不是"成"**（彖传"终止则乱，其道穷也"）——**所以既济不许停。**<br>③ **不在已成之局里开新战场**（九三"高宗伐鬼方，三年克之"，象传只回一个字："**憊**"）。<br>④ **守成靠"戒"和"时"，不靠"厚"**（六四"终日戒"／九五"不如西邻之时也"）——**在既济，加大投入不产生收益。**<br>⑤ **小人勿用**（九三）——已成之局最经不起的就是把位置给错人。<br>⑥ **最致命的动作是"再往前一点"**（上六"濡其首，厉"）。 |

## 二、爻级字段

### 初九 · 濡其尾（湿的是身后）

| 字段 | 内容 |
|---|---|
| **爻辞** | 濡其尾，无咎。 |
| **象传** | 濡其尾，义无咎也。 |
| **位属性** | 阳爻居阳位，**当位**；居下离之初；**与六四相应**（本卦初↔四、二↔五、三↔上三对全部相应，见第四节）。 |
| **判词 → 行动语义** | 无咎 → **认下身后的瑕疵，继续把河渡完；不回头返工**。 |
| **关键词解** | **濡**＝浸湿。**尾**＝后半身、尾部（渡河的动物，尾在身后）。**义无咎**——"义"＝理当、按道理；**按道理本来就不该有灾**。<br>**⚠️ 这里的"尾"是谁的尾，卦辞没说，但未济卦辞点明了："小狐汔济，濡其尾"。既济／未济共用同一只渡河的狐狸做意象**，这是两卦成对的又一处经文证据。 |
| **⚠️ 本爻的要点** | **湿的是尾，也就是你身后已经过去的那一段。** 既济全卦第一爻就把风险的性质定了：**已成之局里出现的瑕疵，绝大多数在你身后，不在你前面。**<br>象传特意用"**义**"字：**这个"无咎"不是你做对了什么换来的，是按理本来就没灾。** 按本库判词口径，"无咎"本身已经是"无灾，不等于吉利"——**而它是既济全卦最好的一档判词之一（本卦六爻无一"吉"字，见第四节）。** |
| **识别信号** | ① 事情刚成，收尾处还有几块没擦干净（数据不齐、文档没补、有个流程走了捷径、有个人没安顿好）；② 这些不干净的地方**都属于已经完成的部分**，不影响后面；③ 你有强烈的回头返工冲动，或有人在追着你补这些。 |
| **该做** | **承认"尾湿了"，把资源放在前面。** 给身后的瑕疵一个明确的"到此为止"结论，写下来，然后不再动它。 |
| **不该做** | 回头返工求完美。**既济初九的"无咎"是发给"不回头"的人的，不是发给"擦干净"的人的。** |

#### ⚠️ 同辞异断：既济初九"濡其尾，无咎" vs 未济初六"濡其尾，吝"

| | **既济 63 初九** | **未济 64 初六** |
|---|---|---|
| 爻辞 | 濡其尾，**无咎** | 濡其尾，**吝** |
| 象传 | 义无咎也 | **亦不知极也** |
| 爻性／位 | 阳爻居阳位 → **当位** | 阴爻居阳位 → **不当位** |
| 下卦 | 离（明在内，已渡） | 坎（险在内，未渡） |
| 语义 | 湿在身后，不影响前进 | **还没开始渡就已经湿了，且不知深浅（"极"＝限度）** |

> **这是本库第二组"同辞异断"教材**（第一组：巽九二／上九同有"巽在床下"，一"吉，无咎"，一"贞凶"）。
> **⚠️ 而这一组的价值更高，因为它把变量隔离得极干净：同样五个字、同样在初位、同一只狐狸的同一条尾巴，唯一的差别是当位与否，结果就是"无咎"与"吝"。**
> **结论（本卡对"当位"通则最重要的一次校准）**：**当位不决定一整卦的吉凶（见第四节第 3 条），但在同一句爻辞、同一个爻位上，当位与不当位的差别就是"无咎"与"吝"。**
> **也就是说：当位是一个"同一处境内的判别器"，不是一个"跨卦的吉凶预测器"。** 这条口径建议直接补进索引第五节。

### 六二 · 妇丧其茀（丢的是体面，不是本体）

| 字段 | 内容 |
|---|---|
| **爻辞** | 妇丧其茀，勿逐，七日得。 |
| **象传** | 七日得，以中道也。 |
| **位属性** | 阴爻居阴位，**当位·得中**；**乘初九之刚**（离在下，则六二必乘刚——见晋卡对乘刚来源的机械补充）；**上应九五**；**下离唯一的阴爻**，即彖传"初吉，柔得中也"所指之爻。 |
| **判词 → 行动语义** | **无判词，只给方法与时间刻度** → **不追。守中道，等一个短周期。** |
| **关键词解** | **茀**＝车上的遮蔽物（《释文》："茀，车蔽也"），一说通"髴"，妇人覆发的首饰。`⚠️ 二解并存` **两解都指向同一件事：它是装饰性的、显示身份的外物，不是车本身，也不是人本身。**<br>**丧**＝丢失。**逐**＝追赶、追索。**七日得**＝七日之后自然得回。 |
| **⚠️ 本爻的要点（象传把因果给反了常识）** | **象传没有说"追得紧才能得回"，它说"七日得，以中道也"——东西能回来的原因是"你在中道上"，不是"你追得紧"。**<br>合到卦上：**既济之时丢的是"茀"（体面）而不是"车"（本体）；而追体面这个动作本身，需要你离开现在的位置——那就丢了中道，也就丢了"七日得"的前提。**<br>**本库"元吉／吉必有附加条件"的口径在此以另一种形式出现：这里不给判词，但给了一个硬条件——中道。** |
| **识别信号** | ① 事情已经成了，但你丢了一样"面子上的东西"：一个头衔、一次署名、一份该有的体面、一个曾经属于你的位置、一句本该由你说的话；② 你很想立刻把它追回来，并且理由完全正当；③ **把它追回来需要你离开现在的位置或角色。** |
| **该做** | **不追。** 明确区分"丢的是茀还是车"——**如果丢的只是体面，就守住位置，等一个短周期（七日＝一个可数的、很快到来的节点）。** |
| **不该做** | 逐。也不要因为"不追"而自我怀疑：**象传把"不追"直接算作"中道"。** |

#### ⚠️ 与震六二共有"勿逐，七日得"五字（本库第一组跨卦共句）

| | **震 51 六二** | **既济 63 六二** |
|---|---|---|
| 爻辞 | 震来厉，**亿丧贝**，跻于九陵，**勿逐，七日得** | 妇**丧其茀**，**勿逐，七日得** |
| 位属性 | 阴居阴位·**当位·得中·乘刚**（乘震之初九） | 阴居阴位·**当位·得中·乘刚**（乘离之初九） |
| 丢的东西 | **贝**＝本钱、财货（**大损**） | **茀**＝车蔽／首饰（**体面，小损**） |
| 判词 | **厉**（警告） | **无判词** |
| 象传 | 震来厉，**乘刚也** | 七日得，**以中道也** |
| 处方 | **勿逐，七日得** | **勿逐，七日得** |

> **两爻共有整整五个字的处方，而两处的位属性配置完全相同（当位·得中·乘刚），只是损失量级差一档。**
> **结论：「勿逐 · 七日得」是本库可以独立成立的一条处方，触发条件是"当位得中而乘刚时的失物"，与损失大小无关。** 本库对震六二的既定口径是"**冲击来自你下面，与你的对错无关，所以只能认赔、上高地、勿逐**"——**既济六二把它推广了：在你位置正、心也正的情况下丢东西，追它一定会让你离开那个正。**
> **⚠️ 顺带补齐本库的两把时间尺**：索引已立"**冲击型（七日）→ 震；滞留型（三岁）→ 坎**"。**既济一卦同时用到两把尺：六二"七日得"、九三"三年克之"。** 这是全书唯一一卦同时出现两种时间刻度的地方，用法也分得很清：**丢东西用七日（等），打硬仗用三年（耗）。**

### 九三 · 高宗伐鬼方（赢了，但打空了）

| 字段 | 内容 |
|---|---|
| **爻辞** | 高宗伐鬼方，三年克之。小人勿用。 |
| **象传** | 三年克之，憊也。 |
| **位属性** | 阳爻居阳位，**当位**；居下离之顶（本库通则"**三多凶**"）；**上应上六**。 |
| **判词 → 行动语义** | **无吉凶判词，只有一个"憊"字 ＋ 一条禁令** → **先算耗损，再决定要不要打；若必须打，把人选卡死。** |
| **关键词解** | **高宗**＝殷高宗（商代中兴之君）。**鬼方**＝商周时期西北方的敌对部族。**克**＝攻克、战胜。**憊**＝疲惫、耗竭、力尽。<br>**⚠️ 依本库合规口径，此处只作为"一场耗时三年的攻坚战"的类比读，不作史事断言。** |
| **⚠️ 本爻是《周易》对一场胜仗最冷的一次评价** | **爻辞明写"克之"——赢了。象传只回一个字："憊"。**<br>**赢了，但打空了。** 为什么？**因为这是在"既济"（已成之局）里开的战场。** 已成之局的资源是用来守的（六四"终日戒"），抽调三年去攻坚，赢下来也只剩一身疲惫。<br>**按本库判词口径，这一爻不在吉凶十级之内**：它不判你有咎（你确实赢了），也不给你任何好处，**只如实告诉你代价——三年，加一身憊**。它比"无判词＋未光也"（只赔时间与声望）更实，因为**它赔掉的是守成所需的全部力气**。 |
| **"小人勿用"专项** | 本库"**把好东西给错人**"专题此前已积累四例：蒙"蒙以养正"、师上六"小人勿用，必乱邦也"、比"原筮元永贞"、兑九五"孚于剥，有厉"。**既济九三是第五例，而且是位置最特殊的一例**：<br>**师上六的"小人勿用"说在战后封赏的时候；既济九三的"小人勿用"说在仗刚打完、人还疲惫的时候。**<br>**含义：已成之局里，用人错一次，就能把"既济"直接变回"未济"。** 疲惫的时候最容易图省事用听话的人——爻辞正是在这个点上插入禁令。 |
| **识别信号（诊断清单）** | ① 你的主业已经成了，进入守成期；② 你正在打、或想打另一条线上的硬仗：新市场、老对手、一笔旧账、一个非要争赢的道理、一场必须证明自己的官司；③ 你估算需要"三年"（一个长周期）才能拿下；④ 你的理由是"我已经成了，有余力"。 |
| **该做** | **先算"憊"**：这一仗赢下来之后，你还剩多少力气守本业？**如果答案是"很少"，那么这场胜利本身没有意义。**<br>若必须打：**把人选卡死，宁缺毋滥**（小人勿用），并且**给这场仗设一个明确的止损期**。 |
| **不该做** | 用"我已经成了，有余力"当开战理由。**"余力"在既济是幻觉——彖传已经说了"小者亨也"，能通的只有小处。** |

#### ⚠️ 与未济九四"震用伐鬼方，三年有赏于大国"的对照（同一件事，两种结局）

| | **既济 63 九三** | **未济 64 九四** |
|---|---|---|
| 爻辞 | **高宗伐鬼方，三年克之。**小人勿用。 | 贞吉，悔亡。**震用伐鬼方，三年有赏于大国。** |
| 象传 | 三年克之，**憊也** | 贞吉，**志行也** |
| 位属性 | 阳居阳位·**当位**·三多凶 | 阳居阴位·**不当位**·四多惧 |
| 所处卦义 | **已成之局** | **未成之局** |
| 结果 | 克之，但"**憊**" | "**有赏于大国**"，且"**志行**"（志向得以推行） |
| 判词 | 无判词＋一条禁令 | **贞吉·悔亡** |

> **⚠️ 这是全书最干净的一次"同一动作、两种价值"的对照实验：同一场伐鬼方之战，同样打三年。**
> **在"已成"的局里打，是消耗（憊）；在"未成"的局里打，是功业（有赏、志行）。**
> **并且注意位属性是反着的：消耗的那一爻当位，成功的那一爻不当位。**
> **结论（本卡的核心增量之一，建议入索引）**：**一个动作的价值首先由"你在哪一卦"决定，其次才由"你在哪一爻、当不当位"决定。** 本库"三步定位法"的顺序（先定域 → 再定位 → 后定势）在这一对爻上得到了经文层面的直接印证：**定域错了，定位再准也没有意义。**

### 六四 · 繻有衣袽（守成的日常长什么样）

| 字段 | 内容 |
|---|---|
| **爻辞** | 繻有衣袽，终日戒。 |
| **象传** | 终日戒，有所疑也。 |
| **位属性** | 阴爻居阴位，**当位**；**乘九三之刚**；**已入上坎**——按本库坎律"坎在上则六四、九五、上六全部当位、全有转机"，本爻是既济上半场的第一爻；**下应初九**；本库通则"**四多惧**"。 |
| **判词 → 行动语义** | **无判词，只给动作** → **常备最廉价的堵漏材料，每天盯。** |
| **关键词解** | **繻**——通行本作"繻"，《子夏传》作"**濡**"（湿、渗漏），本卡从"濡"义读为**船体渗水**。`⚠️ 二解并存，义理指向一致`<br>**衣袽**＝破旧衣物、旧棉絮，**行船时用来塞舟漏的填料**（"袽"＝败衣、絮）。<br>**终日戒**＝整天戒备不懈。**疑**＝疑虑、放心不下。 |
| **⚠️ 本爻是既济最实用的一爻：它把"守成"具体化成了一个动作** | **船已经在水上了（已经渡过来了），而日常动作是——备好一堆破布，整天堵漏。**<br>**注意器物的规格：不是备新木料，不是请工匠大修，是"衣袽"——最便宜、最不体面、最现成的东西。**<br>象传"**有所疑也**"：**这份"不放心"在既济卦里不是性格缺点，是岗位职责。**<br>**这与本库"忧患即安全"标签完全一致**：离六五"出涕沱若"而判"吉"（居尊而能怕）、坤六四"括囊"（近君而闭口）、履九四"愬愬"（戒惧）——**既济六四补上最平常的一种：每天堵小漏。** |
| **识别信号** | ① 事情已成，你在守；② 你发现总有小的渗漏：小故障、小流失、小抱怨、对不上的小账、某个总是要人工兜一下的环节；③ **你觉得"这么小的事不值得每天盯"**，或者你想"等攒够资源做一次彻底整修"。 |
| **该做** | **备"衣袽"**——把最粗、最便宜、最现成的应急手段常备在手边（一份手工兜底流程、一笔小额备用金、一个可以随时打电话的人、一份离线备份）。**然后每天盯。**<br>**既济的安全来自廉价而持续的戒备，不来自一次昂贵的大修。** |
| **不该做** | 等条件成熟做一次彻底整修——**那是"厚"的思路，紧接着的九五会明确把它否掉。** 也不要因为"名正言顺、一切合规"就放松盯漏（那是上六"濡其首"的入口）。 |
| **与坎六四的对照（两个当位六四都用最粗的器物）** | **坎六四**"樽酒簋贰，**用缶**，纳约自牖，终无咎"——**险中的极简：一樽酒、两簋饭、瓦罐，走窗口**。<br>**既济六四**"**繻有衣袽**，终日戒"——**已成之后的极简：一堆破布，天天堵漏**。<br>**两爻同在四位、同为当位、同处上坎之初，用的都是全书最粗的器物。**<br>**⚠️ 由此可补本库"四位"通则一条**：**四位（多惧之位）的正确动作在任何卦里都偏"粗、小、简、收"，从不偏"厚、大、隆重、扩"。** 现有五例可并读：坤六四括囊（少说）／艮六四止诸躬（缩范围）／巽六四田获三品（交成果）／大有九四匪其彭（缩体积）／明夷六四获心意而出门庭（改取信息）／**既济六四衣袽终日戒（常备粗料、持续盯）**。 |

### 九五 · 东邻杀牛（既济全卦判词最好的一爻，内容是否掉"厚"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 东邻杀牛，不如西邻之禴祭，实受其福。 |
| **象传** | 东邻杀牛，不如西邻之时也。 |
| **位属性** | 阳爻居阳位，**当位·得中·居尊位**；居上坎之中（坎的卦主位）；**下应六二**。 |
| **判词 → 行动语义** | **实受其福** → **把规格降到刚好合于时机；判断力放在"什么时候做"，不放在"做多大"。** |
| **关键词解** | **东邻／西邻**＝相邻的两方（传统解为殷商与周，**本卡依合规口径只取"两种做法"的对比，作类比而非史断**）。**杀牛**＝以牛为牲，**最盛大的祭品**。**禴祭**＝薄祭（一说春夏之祭，礼简物薄）。**实受其福**＝实实在在地领受到福报。 |
| **⚠️ 本爻的要害：全卦最好的判词，配的是最小的投入** | **杀牛（投入最大）不如禴祭（投入最小）——而两者的差别，象传只给了一个字："时"。**<br>合到卦上：**既济之时，六爻已经全部摆对，此时"增加投入"不再产生任何收益；唯一还能产生收益的变量是时机。**<br>**这一爻是本卦"利贞"（只剩守正有益）的正面版本：守正之外，还剩一件事有用——挑对时候。** |
| **本库判词表建议新增一条** | **「实受其福」——建议补入判词表，位置在"利"与"无咎"之间，并注明其特殊语义**：<br>**它是"你确实拿到了实惠"（比"无咎"重，因为有实际所得），但它明确指定了实惠的来源是"合于时"，而不是"投入的大小"。**<br>**与"元吉"的区别**：元吉是根本性圆满（且必有附加条件）；**实受其福是具体的、可兑现的一份回报，附加条件写在象传里，就是"时"。** |
| **与坎九五的对照（同一个上坎的九五，两道封条）** | **坎九五**"**坎不盈**，祗既平，无咎"——象传"中未大也"：**险中，天道直接封住了"盈"这条路。**<br>**既济九五**"不如西邻之禴祭，**实受其福**"——象传"不如西邻之时也"：**已成之后，天道封住了"厚"这条路。**<br>**两爻同为上坎之中、同当位得中居尊，一个不让你满，一个不让你厚。合成一条通则**：**坎在上的九五，其收益上限由外部时机决定，不由你的投入决定。** 这也解释了本库为什么说坎九五"连'吉'字都没有"——**既济九五虽有"福"，但那个"福"同样不是它挣来的，是"时"给的。** |
| **五个尊位的对照（补齐一行）** | 需九五"酒食贞吉"——上岸后的分享与节制｜师六五——选对人然后放手｜讼九五"元吉"——中正折中、案结事了｜坎九五"无咎"——水平即止、不求满｜离六五"吉"——居尊而哭得出来｜**既济九五"实受其福"——以时不以厚**。<br>**⚠️ 六个尊位合读，指向同一条本库通则的第六种形态："居尊位者必须放弃一样特权"——既济九五放弃的是"用规格表达重视"的特权。** |
| **识别信号** | ① 事情已成，你在最高、最正、最中的位置上；② 你打算用"加大投入"来延长或放大成果：加预算、加人、加规格、把仪式办得更隆重、把标准再提一档；③ **有一个投入小得多的做法，你觉得"不够重视"、"拿不出手"。** |
| **该做** | **选"禴祭"。** 把规格降到刚好合于时机，把省下来的注意力全部投到"什么时候做"上。**在既济，时机是唯一的自由变量。** |
| **不该做** | 用规格表达重视。**在既济，规格不产生福，时机才产生福。** 也不要把"薄"误解为"不用心"——**禴祭之所以受福，恰恰因为它把心用在了"时"上。** |

### 上六 · 濡其首（⚠️ 全书最重要的一处"当位却不安全"）

| 字段 | 内容 |
|---|---|
| **爻辞** | 濡其首，厉。 |
| **象传** | 濡其首厉，何可久也。 |
| **位属性** | 阴爻居阴位，**当位**；居全卦之终；**乘九五之刚**；**下应九三**；**是"六爻全当位"的最后一块拼图**。 |
| **判词 → 行动语义** | **厉**（本库口径：**警告，非判死**） → **立刻把头抬出水面：停止"再往前一点"。** |
| **关键词解** | **濡其首**＝连头都浸到水里了。**与初九"濡其尾"首尾照应：同一只渡河的狐狸，开头湿的是尾，最后湿的是头。**<br>**⚠️ 这个对照本身就是全卦的结论**：**湿在身后（尾）无咎，湿到头上（首）就厉。区别不在"湿"，在"湿到哪里"——也就是"你还往前伸了多少"。** |
| **⚠️ 本爻是本库"当位＝名正言顺、风险低"这条通则最锋利的限定** | **上六完全当位（阴爻居阴位），它是六爻全当位的最后一环，而它的判词是"厉"，象传是"何可久也"。**<br>**把这一爻和卦辞"初吉终乱"、彖传"终止则乱，其道穷也"合起来读，本卦的完整论证就成立了：**<br>**① 一切都摆对了位置（六爻全当位）；② 因此再没有可调整的余地（其道穷）；③ 因此任何"再往前一点"都只能是往水里去（濡其首）；④ 因此结局是"厉"、是"乱"。**<br>**⚠️ 结论（本库必须加的限定）：当位说的是"名正言顺"，不是"从此安全"。** 当位描述你在这件事里站得正不正，**它不描述这件事还有没有余地**。 |
| **象传"何可久也"——本库第二次出现的同一句判断** | **离九三**"日昃之离…凶"，象传"**何可久也**"——**没有任何光明可以长久**。<br>**既济上六**"濡其首，厉"，象传"**何可久也**"——**没有任何"已经成了"的状态可以长久。**<br>**两处用完全相同的四个字，指向完全相同的一件事。** 而两处给的解药不同：**离九三的解药是"鼓缶而歌"（认下西斜、朴素自适）；既济上六的解药是"把头抬出来"（停止再往前）。**<br>**合成一条：面对"何可久也"，只有两个正确动作——认下它，或者停下来。没有第三个。** |
| **按本库"上爻限定"口径的精确定位** | 本库口径：**上爻反的是"不知止的极"，不是"到顶"本身；过刚则悔，过柔则凶，知止则吉，无内容则白过。**<br>**既济上六是阴爻（柔）而不知止**——按"过柔则凶"本该判凶（对照坤上六、坎上六、巽上九皆凶）。**它只判"厉"而没判"凶"。**<br>**⚠️ 这就是"当位"在整卦里做的唯一一件实事：它没有改变方向（依然是往坏走），只把伤害降了一档（凶 → 厉）。**<br>**这是本库对"当位＝风险低"最精确的一次校准：当位降档，不改向。** |
| **识别信号（诊断清单）** | ① 事情早已成了，成了很久了；② 你在"再往前一点"：再扩一块、再多要一次、再拖一段时间、再赌一把、再加一个人、再借一次势；③ **你身边已经没有人提出反对意见了——因为一切都名正言顺、于法于理都站得住**；④ 你用"我完全合规、完全正当"给这个动作背书。 |
| **该做** | **把头抬出来。** 承认这一段到此为止，**回到六四的"终日戒"和九五的"以时"**。<br>按彖传"终止则乱，其道穷也"的因果：**要真正解掉这一爻，只有一条路——不要停在"已成"里，去开一个新的"未济"。** 这正是序卦传接下来做的事。 |
| **不该做** | 用"完全正当"给"再往前一点"背书。**⚠️ 上六正是那个"完全正当却已经危险"的位置——这是全书最需要记住的一个坐标。** |
| **与坎上六、乾上九的三角对照** | **乾上九**"亢龙有悔"——**阳刚·不当位·盈极不知止**，判"悔"（退·止·舍）。<br>**坎上六**"系用徽纆…三岁不得，凶"——**阴柔·当位·失道久困**，判"凶"，本库已列为"当位却凶"的稀有案例。<br>**既济上六**"濡其首，厉"——**阴柔·当位·齐备而无余地**，判"厉"。<br>**三爻并读，得到"当位"的完整边界**：**坎上六证明当位救不了"方向错＋时间久"；既济上六证明当位救不了"没有余地"；乾上九证明不当位而不知止最轻也是"悔"。当位从来不是安全凭证，只是一个降档因子。** |

| 六四 | 守成日常 | 繻有衣袽 | 总有小渗漏，你觉得不值得盯 | **当位**·乘刚·入上坎 | **终日戒**·常备粗料·疑即职责 |
| 九五 | 居尊守成 | 东邻杀牛 | 你想加大投入来延长成果 | **当位·得中·居尊** | **实受其福**·以时不以厚 |
| 上六 | 再往前一点 | 濡其首 | 一切都正当，没人反对你 | **当位**·乘刚·全卦之终 | **厉**·何可久也·把头抬出来 |

**⚠️ 位属性一栏请通读一遍：六行全是"当位"。这是六十四卦中唯一的一次。**

**既济卦三句话**：
1. **"既济"的字面意思是"河已经渡过去了"，不是"从此没有河了"。** 渡河是一个事件，不是一种状态——把事件当成状态，就是本卦全部风险的来源。
2. **六爻全当位，卦辞却是"初吉终乱"，而彖传把原因写死了："终止则乱，其道穷也"——乱的原因是"止"，不是"成"。**
3. **已成之局只剩三个有效动作：戒（六四终日戒）、时（九五以时不以厚）、择人（九三小人勿用）。** 无效动作是加大投入（九五否掉"杀牛"），**致命动作是"再往前一点"（上六濡其首）。**

**本卦最反直觉的四条**：
- **六爻全当位，全卦却没有一个"吉"字。** 最好的判词是初九的"无咎"和九五的"实受其福"。**"全部摆对"在《周易》里不是一份奖赏，是一个临界状态。**
- **既济同时是全书当位数最多（6/6）与乘刚数最多（3 处）的卦，两项都是唯一。** **当位并不解除压迫**——位置全对，顶你的那股力一点没少。
- **上六完全当位而判"厉"，象传"何可久也"。** **本库"当位＝风险低"这条通则在这里被加了最终限定：当位说的是"名正言顺"，不是"从此安全"。**
- **⚠️ 六十四卦的当位数分布经穷举是 1, 6, 15, 20, 15, 6, 1，"全对"的卦必然有且只有一个——就是既济，而它的卦辞是"初吉终乱"。** 这给本库"六爻周期"通则一个终局限定：**周期的终点不是"全部摆正"，因为全部摆正在经文里叫"终乱"。**

## 四、⚠️ 本卡对全库的意义

### 1. 结构律的完美实证：六爻全当位的唯一一卦

本库索引第五节已立"**八卦上／下结构律**"，其中坎、离两条最强：

> **坎（阴阳阴）**：在下 → 三爻全不当位；**在上 → 三爻全当位**
> **离（阳阴阳）**：**在下 → 三爻全当位**；在上 → 三爻全不当位

**既济＝上坎＋下离，正好把两条律里"全当位"的那一半各取一份叠起来。逐爻验证如下：**

| 爻位 | 位性 | 爻 | 阴阳 | 当位？ | 所属三画卦 | 结构律预测 |
|---|---|---|---|---|---|---|
| **上**（第六） | 阴位 | 上六 | 阴 | **当位** ✅ | 坎（上） | 坎在上 → 全当位 ✅ |
| **五** | 阳位 | 九五 | 阳 | **当位·得中·居尊** ✅ | 坎（上） | 坎在上 → 全当位 ✅ |
| **四** | 阴位 | 六四 | 阴 | **当位** ✅ | 坎（上） | 坎在上 → 全当位 ✅ |
| **三** | 阳位 | 九三 | 阳 | **当位** ✅ | 离（下） | 离在下 → 全当位 ✅ |
| **二** | 阴位 | 六二 | 阴 | **当位·得中** ✅ | 离（下） | 离在下 → 全当位 ✅ |
| **初** | 阳位 | 初九 | 阳 | **当位** ✅ | 离（下） | 离在下 → 全当位 ✅ |
| **合计** | | | | **6 / 6 当位** | | **两条律同时精确成立，无一例外** |

**⚠️ 而唯一性不止是"这一卦刚好凑齐了"。它是一次完整枚举的必然结果：**

#### ⚠️ 硬结论：六十四卦恰好穷尽全部 64 种当位组合，因此"全对"与"全错"各只有一个

**机制（已逐卦穷举验证）**：某爻是否当位，等于**该爻的阴阳与固定模板「阳阴阳阴阳阴」（自下往上）逐位比对**。而"与一个固定串逐位比对"在 6 位阴阳串的集合上是一个**双射**（一一对应）——比对结果只是把原串按模板做了一次整体翻转，既不合并也不遗漏。**六十四卦正好穷尽全部 2⁶ ＝ 64 个 6 位阴阳串**，所以：

> **六十四卦恰好穷尽全部 64 种当位组合，一种不重、一种不漏。**

**当位数的分布因此必然是二项式系数 C(6,k)：**

| 全卦当位爻数 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| **符合的卦数** | **1** | 6 | 15 | **20** | 15 | 6 | **1** |
| 已完成卡中的例子 | **未济 64** | 讼 6、晋 35 | 大有 14、否 12 | **八纯卦全部在此档**（见下） | 同人 13、泰 11 | 需 5、屯 3、明夷 36 | **既济 63** |

**由此得到三条不可动摇的结论：**

1. **"六爻全当位的卦必然有且只有一个；六爻全不当位的卦也必然有且只有一个。"** 这不是观察，是穷举的必然。**既济六爻阴阳恰等于模板本身（下离上坎），未济恰为模板之补（下坎上离）。**
2. **既济与未济不是"又一对漂亮的反卦"，而是这次完整枚举的两个唯一极点。** 六十四卦的当位分布必然以它们为两端，**任何别的卦都不可能取代它们**。
3. **⚠️ 而《周易》把这两个极点放在了全书的最后两卦——并且给"全对"的那个写「初吉终乱」，给"全错"的那个写「亨」。**

> **这使既济／未济成为本库"当位≠吉凶"通则最强的一份证据，强于晋／明夷那一组反例**（晋 1/6 出"无不利"、明夷 5/6 只有一个"吉"，那还只是"不成正比"）——**这里是把结构变量推到两个数学极点，而经文给出的评价与极点方向完全相反。**
> **并且它给本库"六爻周期"通则一个终局限定：周期的终点不是"全部摆正"，因为全部摆正在经文里叫"终乱"。**

#### ⚠️ 顺带得到一条可以替代整张结构律表的公式（建议入索引）

把每个三画卦"在下卦时的当位数"记作 **d**：**离 3｜乾 2｜震 2｜艮 2｜坤 1｜巽 1｜兑 1｜坎 0**（即索引第五节结构律的前半）。
因为上卦的位性（阴阳阴）恰好是下卦位性（阳阴阳）的**补**，所以同一个三画卦**在上卦时的当位数必然是 3 − d**。于是：

> **⚠️ 全卦当位数 ＝ 3 ＋ d(下卦) − d(上卦)**

**逐卦验算（已完成各卡全部吻合）**：既济 3+3−0＝**6** ✅｜未济 3+0−3＝**0** ✅｜明夷 3+3−1＝**5** ✅｜晋 3+1−3＝**1** ✅｜同人 3+3−2＝**4** ✅｜大有 3+2−3＝**2** ✅｜泰 3+2−1＝**4** ✅｜否 3+1−2＝**2** ✅｜需 3+2−0＝**5** ✅｜讼 3+0−2＝**1** ✅

**这条公式一次说清三件此前要靠逐卦查表才能知道的事：**

1. **八纯卦的当位数必然全部等于 3**（上下同卦，d 相消）。**乾、坤、坎、离、震、艮、巽、兑八卦，一个不例外，全部落在分布正中那一档。** 这为本库"八纯卦是全库地基"又添一条结构理由：**它们在"位"这个维度上全部是中性的，所以八条纲领谈的都不是位置，而是对自己下的指令。**
2. **上下互换的落差 Δ ＝ 2 ×|d(A) − d(B)|**。所以三组反卦的 Δ 只能是 2、4、6（见下一条），**而 Δ＝6 只在 d 相差 3 时出现，也就是只在坎（d=0）与离（d=3）之间出现**。
3. **当位数的极值点只能出现在"下离上坎"与"下坎上离"**：要让 3+d(下)−d(上) 取到 6，必须 d(下)=3 且 d(上)=0，唯一解就是下离上坎。**这就是既济唯一性的第二种证明。**

**另外两条只在这一卦成立的事实：**

- **经文自己点了名**：彖传"**利贞，刚柔正而位当也**"——**这是《周易》全书唯一一次用"位当"来解释一整卦的卦辞。** 本库这条纯结构性的通则在这里拿到了最高级别的经文背书。
- **相应也是满配**：初九↔六四、六二↔九五、九三↔上六，**三对全部一阴一阳，三对全相应**。**既济是"当位满配 ＋ 相应满配"的卦。**

> **⚠️ 而这样一卦的卦辞是"初吉终乱"，上爻判"厉"，全卦无一"吉"字。** 这就是下一条。

### 3. ⚠️ 本卡最重要的贡献："全部当位"却不是最好的卦——本库通则的最终限定

**这是全书最反直觉的一条，也是本卡存在的全部理由。**

本库索引第五节现有口径：

> **当位**：阳爻居阳位、阴爻居阴位＝当位（**名正言顺，风险低**）；反之不当位（名不正言不顺，风险高）。

**既济把这条口径逼到了极限，并且证明"风险低"这三个字必须改写：**

| 观察项 | 既济（6/6 当位） | 未济（0/6 当位） |
|---|---|---|
| 卦辞 | 亨，**小**利贞。**初吉终乱** | **亨**（无折扣） |
| 彖传对卦辞的解释 | 刚柔正而**位当**也 ／ **终止则乱，其道穷也** | **柔得中**也 ／ 虽不当位，**刚柔应**也 |
| 六爻"吉"字数 | **0 个** | **4 个**（九二贞吉、九四贞吉、六五贞吉＋吉） |
| 六爻最好判词 | 无咎 ／ 实受其福 | **贞吉、无悔、君子之光、有孚、吉**（六五一爻五个正面词） |
| 上爻 | 濡其首，**厉**（何可久也） | 有孚于饮酒，**无咎**（＋不知节则失是） |
| 三个柔爻是否乘刚 | **六二、六四、上六——三个柔爻全部乘刚** | 六三、六五乘刚（初六下方无爻） |

> **⚠️ 一个六爻全部当位的卦，全卦没有一个"吉"字，上爻判"厉"，三个柔爻全部乘刚。**
> **一个六爻全部不当位的卦，卦辞给"亨"，全卦四个"吉"字，五爻是全书正面判词最密集的一爻。**

**彖传把机制交代得非常清楚，不需要任何推测：**

> **既济之所以"终乱"——"终止则乱，其道穷也"。乱的原因是"止"，机制是"道穷"（路走到头了）。**
> **未济之所以能"亨"——"柔得中也""虽不当位，刚柔应也"。靠的是得中与相应，与当位无关。**

**由此得到本库的最终限定口径（建议替换索引第五节"当位"一行）**：

> **① 当位说的是"名正言顺"，不是"从此安全"。** 它描述**你在这件事里站得正不正**，**不描述这件事还有没有余地**。
> **② 既济证明的是：一切都摆对了位置，恰恰是最危险的时候——因为再没有可调整的余地。** 全当位＝全部自由度归零＝"其道穷"。
> **③ 当位在整卦层面做的唯一实事是"降档"，不是"改向"。** 既济上六本应"过柔不知止而凶"（对照坤上六、坎上六），当位把它降成了"厉"。**降一档，方向不变。**
> **④ 读卡顺序不能颠倒（承晋／明夷卡的结论）**：**先看上下卦关系定"这是个什么局"，再看当位定"你在这个局里正不正"。** 既济是这条顺序的极端样本——**局是"已成将乱"，而六爻个个都正。**

**⚠️ 与本库已有的"盛极必反"一组合读（这一组现在完整了）：**

| 出处 | 原文 | 说的是什么 | 本库既有口径 |
|---|---|---|---|
| **乾 01 上九** | **亢龙有悔** | **到顶而不知止** | 全卦唯一纯凶级之爻，因盈极不知止 |
| **泰 11 九三** | **无平不陂，无往不复** | **顺境必转，而且这话说在还很顺的时候** | "对顺境将转的预判必须在顶点建立"；本库"趋势预警"标签 |
| **丰 55 彖传** | **日中则昃，月盈则食，天地盈虚，与时消息** `⚠️ 丰卡待补` | **最盛之时即开始亏的时刻** | 待补 |

> **前五条讲"会转"，既济讲"为什么必然转"。**

### 4. 当位的真正作用域：一组隔离得极干净的对照实验

上一条说"当位不预测整卦吉凶"，但**不等于当位没有用**。既济／未济提供了一组变量隔离到极致的样本，把当位的**真实作用域**框了出来：

| 对照 | 既济 63 | 未济 64 | 唯一变量 | 结果差 |
|---|---|---|---|---|
| **初爻同辞** | 初九"**濡其尾**，**无咎**"（象：义无咎也） | 初六"**濡其尾**，**吝**"（象：亦不知极也） | **当位 / 不当位** | **无咎 ↔ 吝**（本库吉凶序相隔三档） |
| **上爻同象** | 上六"**濡其首**，厉"（象：何可久也） | 上九"…**濡其首**，有孚失是"（象：亦不知节也） | 阴柔当位 / 阳刚不当位 | 厉（外部警告）↔ 失是（丢掉自己的凭据） |
| **伐鬼方同事** | 九三"三年克之"（象：**憊也**）·**当位** | 九四"三年有赏于大国"（象：**志行也**）·**不当位** | **所处卦义**（已成 / 未成） | 消耗 ↔ 功业（**且方向与当位相反**） |

> **结论（建议入索引，与晋／明夷卡的结论合并）**：
> **当位是"同一处境内部的判别器"，不是"跨卦的吉凶预测器"。**
> **同一句爻辞、同一个爻位上，当位与不当位的差别是实的（无咎 ↔ 吝）；但跨卦比较时，当位数与吉凶完全不成正比（6/6 无一吉 ↔ 0/6 四个吉）。**
> **"伐鬼方"那一行更进一步：跨卦时，卦义的力量甚至可以把当位的方向压反——当位的那一爻是消耗，不当位的那一爻是功业。**

### 5. 两条本卦独有的技术发现

**① 全卦无一"吉"字（可逐爻核对）**

六爻的判词依次是：**无咎**（初九）／无判词（六二"勿逐，七日得"）／无判词＋禁令（九三"三年克之""小人勿用"，象"**憊也**"）／无判词（六四"终日戒"）／**实受其福**（九五）／**厉**（上六，象"**何可久也**"）。

> **六爻全当位、三对全相应、彖传亲自表彰"位当"的一卦，爻辞与小象里一个"吉"字都没有。** 唯一出现"吉"字的地方是卦辞里的"**初**吉"，而它后面紧跟着"**终乱**"。
> **这是本库"当位不等于吉"最直观的一份证据。**

**② 三个柔爻全部乘刚——当位不解除压迫**

**六二乘初九**（当位·得中 → 丧其茀）、**六四乘九三**（当位 → 终日戒，不得安宁）、**上六乘九五**（当位 → 濡其首，厉）。**既济的三个阴爻，无一不乘刚。**

**⚠️ 而这一条同样已由机械穷举验证，结果比"三处"更强：**

> **六爻中"阴直接压在阳之上"的处数，理论上限是 3**——三处互不重叠的"阳下阴上"必须正好占满（初,二）（三,四）（五,上）这三对相邻爻，**满足者只有「阳阴阳阴阳阴」一种排列**。
> **所以既济是六十四卦中乘刚数唯一达到上限（3 处）的卦。**（未济的乘刚是六三、六五两处：初六下方无爻，所以少一处。）

**⚠️ 于是既济同时拿下两个全书唯一的极值，而且是两个方向相反的极值：当位数满格（6/6，全书唯一）＋ 乘刚数满格（3 处，全书唯一）。**

> **结论（建议补入索引"乘刚"条）**：**当位与乘刚是两个完全独立的维度。"位置全对"与"处处被下面顶着"可以同时成立，而且在既济这一卦里是必然同时成立的**——因为两者都由同一个「阳阴阳阴阳阴」的完美交替结构产生：**交替得越整齐，当位越满，阴压阳的界面也越多。**
> **⚠️ 对读者最有用的一句话：既济的"齐备"是一种绷紧的齐备，不是舒展的齐备。** 这也正是卦辞为什么只给"亨，小者亨也"——**三个柔爻全在被顶，所以只能小亨。**
> **按晋卡对乘刚来源的机械补充（凡三画卦内部有阴直接压在阳上者皆制造乘刚），既济的三处分别来自：离之六二乘初九、跨体之六四乘九三、坎之上六乘九五。**

### 6. 时间刻度与领域缺口

**① 全书唯一同时使用两把时间尺的卦**

本库索引已立："**冲击型（七日）→ 震；滞留型（三岁）→ 坎。**"

| 刻度 | 出处 | 用法 |
|---|---|---|
| **七日** | 震六二"勿逐，**七日得**" ／ **既济六二"勿逐，七日得"** | **等一个短周期，失物自回**（条件：守中道、不追） |
| **三年／三岁** | 坎上六"**三岁**不得，凶" ／ 同人九三"**三岁**不兴" ／ **既济九三"**三年**克之"** ／ 未济九四"**三年**有赏于大国" | **一个长周期的攻坚或滞留，代价是耗尽** |

> **既济一卦同时用到两把尺，且分工极清楚：丢东西用七日（等），打硬仗用三年（耗）。**
> **建议补入索引："七日＝可以等的量级；三年＝会把你打空的量级。读到爻辞里出现时间刻度，先按这两档归类。"**

**② 本卦补上的领域缺口：本库此前没有"守成期"这一格**

本库此前最接近的四卦各差一层（详见第一节"不归本卦的情况"）：**泰 11 是大势判断，需 5 九五是刚上岸的单爻场景，坎 29 九五是人还在坎里，大有 14 的问题是"满"而非"齐备"，艮 52 是自己决定不继续。** 没有一卦处理"**事已办成，问题变成怎么不把它弄坏**"。

> **⚠️ 建议写进路由表的一条分界**：**"我这件事还没成" → 未济（64）／屯（3）／坎（29）；"我这件事成了，怕它坏" → 既济（63）；"我这件事成了，东西太多" → 大有（14）。**
